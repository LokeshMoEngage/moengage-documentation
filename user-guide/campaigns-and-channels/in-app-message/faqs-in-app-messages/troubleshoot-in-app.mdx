## HTML In-App Fails to Load Because of an Invalid Script URL

An HTML in-app message can fail to display on devices when its HTML includes a script tag with an invalid JavaScript file URL, for example:

```html Script Tag
<script src="https://example.com/scripts/app.js"></script>
```

Script tags like this embed JavaScript for validation and other functions. If the URL doesn't point to a valid file, the app throws a `FileNotFound` exception when it renders the message, and the HTML in-app message doesn't load.

```text FileNotFound Exception
java.io.FileNotFoundException: https://example.com/scripts/app.js
    at com.android.okhttp.internal.huc.HttpURLConnectionImpl.getInputStream(HttpURLConnectionImpl.java:255)
    at com.moengage.inapp.internal.repository.InAppFileManager.downloadAndSaveFile(InAppFileManager.kt:158)
```

To fix it, use a valid JavaScript file URL in the script tag. The HTML in-app message then displays the next time the app opens.

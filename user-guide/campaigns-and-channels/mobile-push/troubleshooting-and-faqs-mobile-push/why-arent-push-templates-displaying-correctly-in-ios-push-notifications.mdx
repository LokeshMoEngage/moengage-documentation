## Problem

Push templates (carousel images, background color, font color, and so on) do not display correctly in Push notifications on iOS devices.

## Solution

Perform the following steps to resolve the issue:

- Verify whether the Notification Service Extension and Notification Content Extension are implemented in your app.
- If the Notification Service Extension isn't implemented, set it up as described in [Push Notification Implementation](/developer-guide/ios-sdk/push/basic/ios-push-integration-tutorial#step-1-implement-notification-service-extension-nse).
- If the Notification Service Extension is already implemented, verify its setup against [Push Notification Implementation](/developer-guide/ios-sdk/push/basic/ios-push-integration-tutorial#step-1-implement-notification-service-extension-nse).
- If the Notification Content Extension isn't implemented, set it up as described in [Push Templates](/developer-guide/ios-sdk/push/optional/push-templates).
- If the Notification Content Extension is already implemented, follow the steps in [How to Avoid Push Template Issues in iOS Push Notifications When Notification Content Extension is Implemented?](/user-guide/campaigns-and-channels/mobile-push/troubleshooting-and-faqs-mobile-push/how-to-avoid-push-template-issues-in-ios-push-notifications-when-notification-content-extension-is-implemented)

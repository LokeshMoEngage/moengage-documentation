Use this page to diagnose issues with on-site messages (OSM).

## Image Upload Fails With a File Extension Error

When you upload an image in the OSM editor, you see the error "File extension is not supported."

<img alt="OSM editor showing the File extension is not supported error after an image upload" src="/images/moengage_2a874f.png" />

MoEngage treats any text after a period (`.`) in a file name as the file extension. Some social media apps add characters that contain a period to the start of image file names, which causes this error. To fix it, remove the extra period from the file name. For example, rename `Snapinsta.app_431485390_n_1080.jpg` to `Snapinstaapp_431485390_n_1080.jpg`.

## Page Freezes After the Message Closes

If the web page freezes for a moment after an on-site message closes, make sure the close button calls both of the following functions under **Settings** > **Styling** > **Custom Attributes**:

- `MoeOsm.trackDismiss();`
- `MoeOsm.dismissMessage();`

<img alt="Custom attributes of an OSM close button with the trackDismiss and dismissMessage functions" src="/images/moengage_5ee5a9.png" />

For more information about these functions, refer to [JavaScript Bridge for On-Site Messaging and Landing Pages](/developer-guide/components-for-sdk/javascript-bridge/javascript-bridge-for-on-site-messaging-and-landing-pages#track-dismiss).

## Countdown Timer Stays Static

If the countdown timer in an on-site message doesn't count down, check the timer settings in the campaign. This happens when an invalid character is used to set the countdown.

<img alt="Countdown timer settings in the OSM editor" src="/images/moengage_599858.png" />

## Mobile Web Page Keeps Refreshing

If the mobile web page refreshes continuously while an on-site message campaign runs, and stops refreshing when you stop or pause the campaign, the campaign's expiry time and the countdown timer's expiry time don't match. Set both to exactly the same date and time.

Use this page to diagnose web push issues. For errors listed in a campaign's failure breakdown, see [Troubleshoot Common Web Push Errors](/user-guide/campaigns-and-channels/web-push/faqs-web-push/troubleshoot-common-push-errors).

## Impressions Lower Than Successfully Sent

**Successfully Sent** is the number of web push notifications that MoEngage passes to Firebase Cloud Messaging (FCM). **Impressions** is the number of notifications that reach the user. Impressions can be lower than Successfully Sent when:

- The user doesn't come online before the notification expires.
- The browser isn't running on the user's device.
- Communication between FCM, the browser, and the operating system fails.

<Note>
Operating system settings don't contribute to this difference. When a user grants web push permission in the browser but turns off notifications for that browser at the operating system level, the browser still receives the notification. MoEngage counts the impression and tracks the *Notification Received Web* event, even though the operating system suppresses the on-screen display. MoEngage also counts this user as subscribed and reachable for web push. For more information, see [Browser Permission Versus OS-Level Notification Settings](/user-guide/campaigns-and-channels/web-push/getting-started-with-web-push/web-push-permission-and-reachability#browser-permission-versus-os-level-notification-settings).
</Note>

Use this checklist to rotate the credentials used across your MoEngage workspace. Not every item applies to every workspace. Each section starts with an **Applies if** line: skip the sections you do not use and work through the rest.

For each item, rotate the credential at its source first (MoEngage or your provider), then update the new value everywhere you use it. Start with [MoEngage API Keys](#moengage-api-keys). If you manage more than one workspace, repeat the checklist for each one.

## MoEngage API Keys

**Applies if** your servers, scheduled jobs, or partner tools call MoEngage APIs (data, segments, campaigns, push, Inform, catalog, or analytics).

- **Rotate your API keys.** Go to **Settings** > **Account** > **API keys** (on older workspaces, **Settings** > **Account** > **APIs**). Create a new key, move your integrations to it, then archive the old key so there is no downtime. For more information, refer to [API Key Dashboard](/user-guide/settings/account/api-and-api-keys/api-key-dashboard) and [Rotate Your API Keys and Secure API Access](/user-guide/settings/account/security/rotate-api-keys-and-secure-api-access).
- **Regenerate legacy keys.** You can only regenerate the Data key, Push key, Campaign report / Business events / Custom templates / Catalog key, and the Inform API secret. The old key stops working immediately, so schedule the change and update your integrations right after. For the Push API, recalculate the `X-MOE-PushAPI-Signature` header. For more information, refer to [Rotate Your API Keys and Secure API Access](/user-guide/settings/account/security/rotate-api-keys-and-secure-api-access) and [Inform Settings](/user-guide/settings/miscellaneous/settings-inform).
- **Rotate OAuth 2.0 and AWS STS keys.** Short-lived access tokens expire on their own, but the client secret (OAuth 2.0) and the `MOE-APPSECRET` (AWS STS) do not. Create a new key and archive the old one. For more information, refer to [OAuth 2.0 Overview](/api/oauth/oauth-overview) and [API Key Dashboard](/user-guide/settings/account/api-and-api-keys/api-key-dashboard).
- **Update every place that uses the old key.** This includes backend services, scheduled jobs, CI/CD variables, data pipelines, saved Postman collections, and the partner tools listed in [Partner Integrations](#partner-integrations). Remove old copies from wikis, tickets, chat, and code repositories.
- **Restrict API access by IP (recommended).** Go to **Settings** > **Account** > **Security** > **API firewall**. For more information, refer to [API Firewall](/user-guide/settings/account/security/api-firewall).

## Partner Integrations

**Applies if** you connected a partner from the App Marketplace, or a partner tool sends data to or reads data from MoEngage.

There are two cases:

- **MoEngage holds a partner's credential.** Rotate it at the partner, then update it in MoEngage.
- **A partner holds your MoEngage key.** Rotate it as described in [MoEngage API Keys](#moengage-api-keys), then paste the new key into the partner.

Work through the partners you use:

- **Facebook Audience.** Reset the app secret and revoke the access token in Meta, then select **Disconnect Facebook** and reconnect with the new App ID, app secret, and token. Go to **App Marketplace** > **Facebook Audience**. For more information, refer to [Facebook Audience Settings](/user-guide/campaigns-and-channels/facebook-audience/getting-started-with-facebook-audience/facebook-audience-settings-on-moengage-dashboard).
- **Google Ads Audience.** Remove MoEngage from the Google account's third-party access, then select **Connect with Google** again. Go to **App Marketplace** > **Google Ads Audience**. For more information, refer to [Integrate Google Ads Audience](/user-guide/campaigns-and-channels/google-ads-audience/getting-started-with-google-ads-audience/integrate-google-ads-audience).
- **Other ad and conversion partners** (Meta Conversions, TikTok, Snapchat, Pinterest, Criteo, Reddit, Amazon Ads, and Microsoft Ads). Generate a new token or client secret in the ad platform, then update it. Go to **App Marketplace** > the partner > **Integrate**. For more information, refer to [Retargeting and Audience Sync Integrations](/partner-guide/retargeting-and-audience-sync/overview).
- **Attribution partners** (AppsFlyer, Adjust, Singular, Kochava, Airbridge, Trackier, and Branch). These partners hold your MoEngage attribution key, and Adjust and AppsFlyer Audience may also hold your Data API key. Go to **Settings** > **Analytics** > **Acquisition tracking**. For more information, refer to [Acquisition Tracking](/user-guide/settings/analytics-and-segmentation/acquisition-tracking).
- **Snowflake, BigQuery, Databricks, and Redshift.** Replace the password, key pair, service-account key, or access token used by the MoEngage connection, then update the connection. Go to **App Marketplace** > the warehouse > **Integrate**. For more information, refer to [Snowflake](/partner-guide/data-and-analytics/data-warehouses/snowflake) and [Data and Analytics Integrations](/partner-guide/data-and-analytics/overview).
- **Amazon S3, Google Cloud Storage, and SFTP.** Replace the access key (S3), service-account key (GCS), or SFTP password or key. If you use an IAM role, review its trust policy. Go to **App Marketplace** > the storage app > **Integrate**. For more information, refer to [Amazon S3](/partner-guide/data-and-analytics/cloud-storage/amazon-s3) and [SFTP](/partner-guide/data-and-analytics/cloud-storage/sftp).
- **Outbound Segment Sync.** Rotate the credential of each destination the segment syncs to (ad network, loyalty platform, or warehouse) and update that connection. For more information, refer to [Outbound Segment Sync](/user-guide/data/exports/segments/outbound-segment-sync).
- **Analytics platforms.** Mixpanel and Amplitude use a MoEngage Data API key for cohort syncs and the partner's own key for exports. Rotate both, then update each side. For more information, refer to [Mixpanel](/partner-guide/data-and-analytics/analytics/mixpanel) and [Amplitude Audiences](/partner-guide/data-and-analytics/analytics/amplitude/amplitude-audiences).
- **Other partners that hold your Workspace ID and Data API key.** This includes CDPs (Segment, mParticle, RudderStack, Tealium, Zeotap, Hightouch, Adobe Real-Time CDP, and Amperity), CRM and support tools (Salesforce, HubSpot, Zoho, Zendesk, and Intercom), Zapier, Shopify, and payment tools. Razorpay and Stripe webhook URLs contain the key, so paste the full new URL. For more information, refer to [Partner Integrations](/partner-guide/introduction) and the partner's own page.
- **Partner credentials that MoEngage holds** (Segment write key, mParticle server-to-server key, Mixpanel and Amplitude project keys, and Salesforce connected-app secret). Rotate them at the partner, then update them in **App Marketplace** > the partner > **Integrate**. For more information, refer to [Partner Integrations](/partner-guide/introduction).

## Connected Apps

**Applies if** you send campaigns through a Connected App (a channel or partner app added from the App Marketplace that uses a connector configuration).

- **Rotate the credential used by each Connected App connection.** The fields differ by app, for example an API key, token, or client secret. Generate a new credential in the partner's account, then edit the connection in MoEngage and save it. Go to **App Marketplace** > the app > **Integrate**. For more information, refer to [Create a Channel Connector Config File](/user-guide/campaigns-and-channels/connected-apps/getting-started-with-connected-apps/create-a-channel-connector-config-file).
- **Check campaigns that use the connection.** Confirm that active Connected App campaigns still deliver after the update. For more information, refer to [Create a Connected App Campaign](/user-guide/campaigns-and-channels/connected-apps/create/create-a-connected-app-campaign).

## Push Credentials

**Applies if** you send mobile push through MoEngage. All the following credentials are under **Settings** > **Channels** > **Push** > **App Push**.

- **iOS: APNs authentication key (.p8).** In your Apple Developer account, revoke the key you gave MoEngage and create a new one. Then upload the new .p8 file with its Key ID and Team ID. Go to **App Push** > **iOS (APNS)**. For more information, refer to [APNs Authentication Key](/developer-guide/ios-sdk/push/basic/apns-authentication-key).
- **iOS: legacy certificate (.pem).** If a .pem certificate and its password are still uploaded, revoke the certificate in Apple and switch to a .p8 key. MoEngage no longer accepts new .pem uploads. For more information, refer to [APNs Certificate (Legacy)](/developer-guide/ios-sdk/push/basic/apns-certificate-pem-file-legacy).
- **Android: FCM service-account key.** In Google Cloud or Firebase, create a new service-account key, upload the new JSON file under **Private key file**, then delete the old key. Go to **App Push** > **Android** > **FCM Authentication**. For more information, refer to [FCM Authentication](/developer-guide/android-sdk/push/basic/fcm-authentication).
- **Android: Huawei Push.** Rotate the app secret in the Huawei developer console and update it in MoEngage. Go to **App Push** > **Huawei (Push Amp+)**. For more information, refer to [Configure Huawei Push](/developer-guide/android-sdk/push/optional/push-amp-plus/configuring-huawei-push-on-mo-engage).

Web push needs no action from you.

## SMS, MMS, RCS, and WhatsApp

**Applies if** you added an SMS, MMS, RCS, or WhatsApp sender. The credential depends on your provider: an API key, a username and password, an account SID and auth token, or an access token. Generate a new credential in your provider's account, then edit the sender in MoEngage and save it.

- **SMS and MMS senders.** Go to **Settings** > **Channels** > **SMS, MMS & RCS** > **Sender configuration**. For more information, refer to [Configure an SMS Sender](/user-guide/campaigns-and-channels/sms-mms-and-rcs/sms/getting-started-with-sms/configure-an-sms-sender), [Configure an MMS Sender](/user-guide/campaigns-and-channels/sms-mms-and-rcs/mms/getting-started-with-mms/configure-an-mms-sender), and your provider's page, for example [Twilio](/partner-guide/messaging-channels/sms-providers/configure-twilio).
- **Custom SMS connectors.** Replace any key or token in request headers or URL parameters, and any linked OAuth configuration (refer to [Content API, OAuth, and Connector Campaigns](#content-api-oauth-and-connector-campaigns)). For more information, refer to [Configure Custom Connector for SMS](/user-guide/campaigns-and-channels/sms-mms-and-rcs/sms/getting-started-with-sms/configure-custom-connector-for-sms).
- **RCS senders.** Go to **Settings** > **Channels** > **SMS, MMS & RCS** > **Sender configuration**. For more information, refer to [Configure an RCS Sender](/user-guide/campaigns-and-channels/sms-mms-and-rcs/rcs/getting-started-with-rcs/configure-an-rcs-sender).
- **WhatsApp senders.** For Meta, generate a new access token (use a permanent system-user token if you rely on one) and update it with your App ID, phone number ID, and business account ID. Go to **Settings** > **Channels** > **WhatsApp** > **Sender configuration**. For more information, refer to [Configure Meta Sender](/partner-guide/messaging-channels/whatsapp-providers/meta/configure-meta-sender) and [Configure WhatsApp](/user-guide/campaigns-and-channels/whatsapp/getting-started-with-whatsapp/configure-whatsapp).
- **Messaging apps, voice, and direct mail** (Viber, Telegram, LINE, Slack, MS Teams, Facebook Messenger, Exotel, Knowlarity, and Lob). Replace the token, bot token, or webhook URL. If the credentials are in a Connector campaign header, refer to [Content API, OAuth, and Connector Campaigns](#content-api-oauth-and-connector-campaigns). For more information, refer to [Partner Integrations](/partner-guide/introduction).
- **Send a test message** from each sender after the update to confirm delivery.

## Email Credentials

**Applies if** you send email through your own provider or SMTP server instead of a MoEngage-managed sender. Go to **Settings** > **Channels** > **Email** > **Sender Configuration**.

- **SendGrid, Amazon SES, SparkPost, Mandrill, and Netcore.** Create a new API key or SMTP credential in the provider, update the sender in MoEngage, then delete the old credential. SendGrid uses the same key for the SMTP password, the WebApi key, and the bounce webhook. For more information, refer to [Configure Email Channel](/user-guide/campaigns-and-channels/email/getting-started-with-email/configure-email-channel) and [Configure SendGrid Email Settings](/user-guide/campaigns-and-channels/email/getting-started-with-email/configure-sendgrid-email-settings).
- **Private SMTP servers and email middleware.** Change the SMTP username and password on your server, then update them in the custom SMTP sender. For more information, refer to [Configure Email Channel](/user-guide/campaigns-and-channels/email/getting-started-with-email/configure-email-channel).
- **Send a test email** from each sender after the update.

## Content API, OAuth, and Connector Campaigns

**Applies if** you use Content APIs for personalization, OAuth 2.0 authorization configurations, or Connector campaigns that call your own or a third party's endpoint. These configurations and campaigns often hold credentials in headers and key-value pairs, so check inside each one.

- **OAuth configurations.** Access tokens expire on their own, but the client ID and client secret saved in the configuration do not. Rotate the secret at your authorization server, edit the configuration, and run **Send test**. Use **View list** to see which Content APIs and campaigns use each configuration. Go to **Settings** > **Advanced settings** > **Authorization configuration**. For more information, refer to [Authorization Configuration with OAuth 2.0](/user-guide/settings/advanced-settings/authorization-configuration-with-oauth-20).
- **Content APIs.** Replace any API key or token in the URL parameters or headers. Go to **Settings** > **Advanced settings** > **Content API**. For more information, refer to [Add a Content API](/user-guide/settings/advanced-settings/add-a-content-api).
- **Connector campaigns.** Open every active, scheduled, periodic, and event-triggered Connector campaign, including those inside Flows, and replace any token or key in the headers, URL, or body. For more information, refer to [Create a Connector Campaign](/user-guide/campaigns-and-channels/connectors/create/create-a-connector-campaign).
- **Streams endpoints.** If Streams sends events to your endpoint, change the endpoint's Basic Auth password or header value, then raise a Support ticket to update it. For more information, refer to [Streams](/api/data/moengage-streams).
- **Alert destinations.** Replace Slack, MS Teams, or custom webhook URLs used for alerts. Go to **App Marketplace** > **Alert management**. For more information, refer to [Webhooks](/user-guide/settings/reports-and-alerts/alert-management/alert-destination/webhooks).

Lokalise is a translation management platform that agile teams use to manage multilingual content. Teams that write campaign content in MoEngage move it to Lokalise for translation and then rebuild each localized campaign by hand.

The Lokalise connector gives your Custom Agents access to your Lokalise account over the Model Context Protocol (MCP). An agent finds the content that needs translating, sends it to Lokalise, brings the translations back into MoEngage, and builds the campaign from them. There are no API keys to exchange between the two platforms and no app to install in Lokalise.

<Note>
 Custom Agents and Connectors are currently Early Access features. If you do not see **AI Agents** > **Connectors** in your dashboard, contact your Customer Success Manager (CSM) to request access.
</Note>

MoEngage also integrates with Lokalise through the MoEngage app in Lokalise, which syncs saved templates between the two platforms. Use that approach when you translate campaign templates and want each language to arrive as its own template. Refer to [Lokalise](/partner-guide/personalize-and-optimize/localization/lokalise).

## Overview

You connect your Lokalise account once on the **Connectors** page, and its tools become available to every Custom Agent you run. Each user connects their own Lokalise account, and an agent works with the account of the person who starts the run.

### Prerequisites

Before you begin, make sure that:

* Your workspace has Custom Agents and Connectors enabled.
* You have an active Lokalise account with access to the translation projects you want to use.
* Your MoEngage role includes permission to create content blocks and campaigns. A Custom Agent acts within the MoEngage permissions of the user who runs the agent. Refer to [Custom Agent Essentials: Permissions and Security](/user-guide/ai-and-intelligence/merlin-ai/custom-agents/custom-agents-essentials-permission-and-security).

### Generate a Lokalise API Token

Connecting Lokalise requires a personal API token from your Lokalise account:

1. In Lokalise, click your avatar in the lower-left corner, and then click **Profile Settings**.

   <Frame>
   <img alt="Lokalise account menu with Profile Settings highlighted" src="/images/lokalise-profile-settings-menu.png" />
   </Frame>

2. Click **API tokens**.
3. Click **Generate new token**.
4. Copy the token.

   <Frame>
   <img alt="API tokens tab of a Lokalise profile with the tab, the token, and the Generate new token button highlighted" src="/images/lokalise-api-tokens.png" />
   </Frame>

Keep the token somewhere safe. Lokalise lists it on this page, where you can also delete it when you no longer need the connection.

### Connect Lokalise to MoEngage

1. On the sidebar menu in MoEngage, hover over the Merlin AI menu item <img alt="Merlin AI menu icon" src="/images/merlin-ai-menu-icon.png" style={{ display:"inline" }} />. The **Merlin AI** menu appears.
2. Click **Connectors**.

   <Frame>
   <img alt="Merlin AI menu open on the sidebar with Connectors highlighted" src="/images/merlin-ai-connectors-menu.png" />
   </Frame>

3. In the **Search** box, enter `Lokalise`.
4. Click the **Lokalise** card. The **Connection details** dialog appears.

   <Frame>
   <img alt="Connectors page filtered to Lokalise, showing the Lokalise connector card" src="/images/lokalise-connector-card.png" />
   </Frame>

5. Review the tools Lokalise provides and the terms of usage, and then click **Connect**.
6. On the **Merlin AI wants to connect to your Lokalise** page, paste your token in **API Token**, and then click **Connect**.

   <Frame>
   <img alt="Page asking for a Lokalise API token with the field and the Connect button highlighted" src="/images/lokalise-api-token-prompt.png" />
   </Frame>

7. Close the window once it confirms the connection, and then return to the MoEngage dashboard.

   <Frame>
   <img alt="Window confirming that Merlin AI is connected to Lokalise" src="/images/lokalise-authorization-success.png" />
   </Frame>

Lokalise moves to **Connected**, and a message confirms that your agents can use its tools. To find Lokalise again later, use the **Connected** filter or the **Search** box.

<Frame>
<img alt="Connectors page with a message confirming that Lokalise is connected" src="/images/lokalise-connected.png" />
</Frame>

For the complete connector behavior, per-tool controls, and terms of usage, refer to [Connect External Apps to Custom Agents](/user-guide/ai-and-intelligence/merlin-ai/connectors/connect-external-apps).

## Use Cases

Marketing teams write content blocks in MoEngage in one language and need them in several others. A Custom Agent with access to Lokalise covers that work from end to end:

* **Scheduled translation runs.** Translate the content blocks your team created or edited since the last run, on a schedule, without anyone moving files between the two platforms.
* **Translated campaigns built for you.** Create campaigns from the returned translations, so a localized campaign is ready to review instead of waiting to be rebuilt by hand.
* **Review before anything goes out.** Leave translated campaigns as drafts, so a marketer approves each one before it reaches users.
* **Consistent wording across markets.** Keep the keys and translations an agent writes back in the same Lokalise project your translators already work in.

## Tools

The Lokalise connector covers projects, keys, translations, and contributors, along with file uploads and downloads and translation workflows. The **Connection details** dialog lists every tool the connector provides along with its description and its status, either **Enabled** or **Disabled**.

| Tool group | What an agent does with it |
| --- | --- |
| Projects | Lists the translation projects in your Lokalise account and reads their settings. |
| Keys | Reads, creates, and updates the translation keys that hold your source content. |
| Translations | Reads the translated values for a key and writes them back. |
| Files | Uploads content to a project and downloads the translated result. |
| Translation workflows | Starts and tracks the translation tasks that move content through your review stages. |
| Contributors | Reads the contributors on a project and the languages assigned to them. |

To control which tools your agents can call:

1. On the **Connectors** page, click the **Lokalise** card. The **Connection details** dialog lists every tool with its description and its status.
2. Select the checkbox next to each tool you want to change.
3. Click **Enable** or **Disable**. The **Status** column updates for each tool you selected.

   <Frame>
   <img alt="Connection details dialog for a connected Lokalise account with two tools selected in the table" src="/images/lokalise-tools-enable-disable.png" />
   </Frame>

Disabling matters most for the tools that change data in Lokalise rather than read it. A tool's status belongs to the connector rather than to an individual agent, so it applies to every agent you run, and you can change a status at any time. Refer to [Enable or Disable a Connector's Tools](/user-guide/ai-and-intelligence/merlin-ai/connectors/connect-external-apps#enable-or-disable-a-connectors-tools).

## Example Usage

A connected application is available to every agent you run, so there is nothing to attach in the Agent Builder. What the agent does with Lokalise comes from the instructions you write.

On the sidebar menu in MoEngage, hover over the Merlin AI menu item <img alt="Merlin AI menu icon" src="/images/merlin-ai-menu-icon.png" style={{ display:"inline" }} />, click **Custom Agents**, and create an agent from scratch. Describe the job you want done, answer the questions Merlin AI asks, and set the schedule you want the agent to run on. Refer to [Create and Manage Custom Agents](/user-guide/ai-and-intelligence/merlin-ai/custom-agents/create-and-manage-custom-agents).

### Translate Content Blocks and Create a Campaign

The following instruction covers a complete translation workflow, from finding the content to leaving a campaign ready for review:

```text Agent Instruction
Every day, find the content blocks in my MoEngage workspace that are tagged English and
were created or updated in the last 24 hours, and send them to Lokalise for translation
into German. Keep a record of what you have already sent so that nothing is translated
twice. On each run, check whether the earlier Lokalise translations are complete. When they
are, bring the translated content back into MoEngage as content blocks, and create an
event-triggered push campaign for Android and iOS that targets users who viewed the web
page in the last 3 days. Leave new campaigns as drafts for review, update campaigns that
are still in draft, and flag live campaigns instead of changing them. Save a report of
each run.
```

On each run, the agent finds the content blocks by tag rather than by name, sends only what it has not sent before, waits for the translations to complete, writes them back as content blocks, and creates the campaign as a draft.

<Tip>
 Name every detail the agent cannot infer, including the target languages, the channel, the platforms within that channel, the audience, and what to do with campaigns that are already live. The agent leaves out whatever you do not name, and you then correct it on the draft.
</Tip>

Run the agent a few times against your own content before you make it live, and keep the campaigns as drafts until you trust the output. Refer to [Test Agent](/user-guide/ai-and-intelligence/merlin-ai/custom-agents/create-and-manage-custom-agents#test-agent) and [Make the Agent Live](/user-guide/ai-and-intelligence/merlin-ai/custom-agents/create-and-manage-custom-agents#make-the-agent-live).

<Warning>
 MoEngage does not gate a connector write. An agent that reaches Lokalise can change data in your Lokalise account, so disable the write tools your agents do not need and write the same rule into the agent's instructions.
</Warning>

## FAQs

<AccordionGroup>
  <Accordion title="How does the connector differ from the MoEngage app in Lokalise?">
    The MoEngage app in Lokalise syncs saved templates between the two platforms, and you import and export each one. The connector gives a Custom Agent access to your Lokalise account, so the agent finds the content, translates it, and builds the campaign on a schedule you set. Refer to [Lokalise](/partner-guide/personalize-and-optimize/localization/lokalise).
  </Accordion>

  <Accordion title="Does every agent I run reach Lokalise once I connect it?">
    Yes. You connect an application once, and it becomes available to every agent you run. The agent's instructions decide whether it uses Lokalise on a given run. Refer to [How Connectors Work](/user-guide/ai-and-intelligence/merlin-ai/connectors/connect-external-apps#how-connectors-work).
  </Accordion>

  <Accordion title="Whose Lokalise account does an agent use?">
    The account of the person who starts the run. Each teammate generates their own API token and connects their own Lokalise account on the **Connectors** page, so an agent works with that teammate's Lokalise projects when they run it.
  </Accordion>

  <Accordion title="Can an agent change data in my Lokalise account?">
    Yes, when a tool that writes to Lokalise is enabled. MoEngage does not ask for your approval before a connector write. Disable the tools you want kept out of reach, and write your agent's instructions to match.
  </Accordion>

  <Accordion title="What if the connection to Lokalise drops during a run?">
    Reconnect Lokalise on the **Connectors** page in a separate browser tab, and then send your next message in the same session. Restate any step that the agent skipped so that the agent retries the step. Refer to [Reconnect During a Run](/user-guide/ai-and-intelligence/merlin-ai/connectors/connect-external-apps#reconnect-during-a-run).
  </Accordion>
</AccordionGroup>

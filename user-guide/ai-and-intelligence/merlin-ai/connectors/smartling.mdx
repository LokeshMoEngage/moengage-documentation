Smartling is a translation and localization platform that global brands use to scale content across markets. Teams that write campaign content in MoEngage move it to Smartling for translation and then rebuild each localized campaign by hand.

The Smartling connector gives your Custom Agents access to your Smartling account over the Model Context Protocol (MCP). An agent finds the content that needs translating, submits it to Smartling, brings the translations back into MoEngage, and builds the campaign from them. There is no integration to configure field by field and no file transfer to maintain.

<Note>
 Custom Agents and Connectors are currently Early Access features. If you do not see **AI Agents** > **Connectors** in your dashboard, contact your Customer Success Manager (CSM) to request access.
</Note>

## Overview

You connect your Smartling account once on the **Connectors** page, and its tools become available to every Custom Agent you run. Each user connects their own Smartling account, and an agent works with the account of the person who starts the run.

### Prerequisites

Before you begin, make sure that:

* Your workspace has Custom Agents and Connectors enabled.
* You have an active Smartling account with access to the projects you want to translate into.
* Your MoEngage role includes permission to create content blocks and campaigns. A Custom Agent acts within the MoEngage permissions of the user who runs the agent. Refer to [Custom Agent Essentials: Permissions and Security](/user-guide/ai-and-intelligence/merlin-ai/custom-agents/custom-agents-essentials-permission-and-security).

### Connect Smartling to MoEngage

1. On the sidebar menu in MoEngage, hover over the Merlin AI menu item <img alt="Merlin AI menu icon" src="/images/merlin-ai-menu-icon.png" style={{ display:"inline" }} />. The **Merlin AI** menu appears.
2. Click **Connectors**.

   <Frame>
   <img alt="Merlin AI menu open on the sidebar with Connectors highlighted" src="/images/merlin-ai-connectors-menu.png" />
   </Frame>

3. In the **Search** box, enter `Smartling`.
4. Click the **Smartling** card. The **Connection details** dialog appears.

   <Frame>
   <img alt="Connectors page filtered to Smartling, showing the Smartling connector card" src="/images/smartling-connector-card.png" />
   </Frame>

5. Review the tools Smartling provides and the terms of usage, and then click **Connect**.

   <Frame>
   <img alt="Smartling Connection details dialog with the Connect button highlighted" src="/images/smartling-connection-details.png" />
   </Frame>

6. On the Smartling sign-in page, enter your email address and password, and then click **LOGIN**.

   <Frame>
   <img alt="Smartling sign-in page with the credential fields and the LOGIN button highlighted" src="/images/smartling-sign-in.png" />
   </Frame>

7. Close the window once it confirms the connection, and then return to the MoEngage dashboard.

   <Frame>
   <img alt="Authorization window confirming that Merlin AI is connected to Smartling MCP" src="/images/smartling-authorization-success.png" />
   </Frame>

Smartling moves to **Connected**, and a message confirms that your agents can use its tools. To find Smartling again later, use the **Connected** filter or the **Search** box.

<Frame>
<img alt="Connectors page with a message confirming that Smartling is connected" src="/images/smartling-connected.png" />
</Frame>

For the complete connector behavior, per-tool controls, and terms of usage, refer to [Connect External Apps to Custom Agents](/user-guide/ai-and-intelligence/merlin-ai/connectors/connect-external-apps).

## Use Cases

Marketing teams write content blocks in MoEngage in one language and need them in several others. A Custom Agent with access to Smartling covers that work from end to end:

* **Scheduled translation runs.** Translate the content blocks your team created or edited since the last run, on a schedule, without anyone moving files between the two platforms.
* **Translated campaigns built for you.** Create campaigns from the returned translations, so a localized campaign is ready to review instead of waiting to be rebuilt by hand.
* **Review before anything goes out.** Leave translated campaigns as drafts, so a marketer approves each one before it reaches users.
* **Translation work tracked across runs.** Keep a record of what has already gone to Smartling, so the same content is not submitted and paid for twice.

## Tools

The Smartling connector covers translation jobs, files, strings, glossaries, and issues, along with machine translation. The **Connection details** dialog lists every tool the connector provides along with its description and its status, either **Enabled** or **Disabled**.

| Tool group | What an agent does with it |
| --- | --- |
| Translation jobs | Creates translation jobs, adds content to them, and checks whether a job is complete. |
| Files | Uploads content to a Smartling project and downloads the translated result. |
| Strings | Reads and submits individual source strings and their translations. |
| Glossaries | Reads the glossary terms that keep product and brand wording consistent across languages. |
| Issues | Reads and raises the issues that translators open against a string. |
| Machine translation | Returns machine translations where a human translation is not required. |

To control which tools your agents can call:

1. On the **Connectors** page, click the **Smartling** card. The **Connection details** dialog lists every tool with its description and its status.
2. Select the checkbox next to each tool you want to change.
3. Click **Enable** or **Disable**. The **Status** column updates for each tool you selected.

   <Frame>
   <img alt="Connection details dialog for a connected Smartling account with two tools selected and the Enable and Disable actions above the table" src="/images/smartling-tools-enable-disable.png" />
   </Frame>

Disabling matters most for the tools that change data in Smartling rather than read it. A tool's status belongs to the connector rather than to an individual agent, so it applies to every agent you run, and you can change a status at any time. Refer to [Enable or Disable a Connector's Tools](/user-guide/ai-and-intelligence/merlin-ai/connectors/connect-external-apps#enable-or-disable-a-connectors-tools).

## Example Usage

A connected application is available to every agent you run, so there is nothing to attach in the Agent Builder. What the agent does with Smartling comes from the instructions you write.

On the sidebar menu in MoEngage, hover over the Merlin AI menu item <img alt="Merlin AI menu icon" src="/images/merlin-ai-menu-icon.png" style={{ display:"inline" }} />, click **Custom Agents**, and create an agent from scratch. Describe the job you want done, answer the questions Merlin AI asks, and set the schedule you want the agent to run on. Refer to [Create and Manage Custom Agents](/user-guide/ai-and-intelligence/merlin-ai/custom-agents/create-and-manage-custom-agents).

### Translate Content Blocks and Create a Campaign

The following instruction covers a complete translation workflow, from finding the content to leaving a campaign ready for review:

```text Agent Instruction
Every day, find the content blocks in my MoEngage workspace that are tagged English and
were created or updated in the last 24 hours, and submit them to Smartling for translation
into German. Keep a record of what you have already submitted so that nothing is translated
twice. On each run, check whether the earlier Smartling jobs are complete. When they are,
bring the translated content back into MoEngage as content blocks, and create an
event-triggered push campaign for Android and iOS that targets users who viewed the web
page in the last 3 days. Leave new campaigns as drafts for review, update campaigns that
are still in draft, and flag live campaigns instead of changing them. Save a report of
each run.
```

On each run, the agent finds the content blocks by tag rather than by name, submits only what it has not sent before, waits for Smartling to mark the job complete, writes the translations back as content blocks, and creates the campaign as a draft.

<Tip>
 Name every detail the agent cannot infer, including the target languages, the channel, the platforms within that channel, the audience, and what to do with campaigns that are already live. The agent leaves out whatever you do not name, and you then correct it on the draft.
</Tip>

Run the agent a few times against your own content before you make it live, and keep the campaigns as drafts until you trust the output. Refer to [Test Agent](/user-guide/ai-and-intelligence/merlin-ai/custom-agents/create-and-manage-custom-agents#test-agent) and [Make the Agent Live](/user-guide/ai-and-intelligence/merlin-ai/custom-agents/create-and-manage-custom-agents#make-the-agent-live).

<Warning>
 MoEngage does not gate a connector write. An agent that reaches Smartling can change data in your Smartling account, so disable the write tools your agents do not need and write the same rule into the agent's instructions.
</Warning>

## FAQs

<AccordionGroup>
  <Accordion title="Do I need a separate MoEngage integration for Smartling?">
    No. Smartling connects as a connector on the **Connectors** page, and that connection is the integration. There is no app to install and no credentials to exchange between the two platforms beyond the Smartling sign-in.
  </Accordion>

  <Accordion title="Does every agent I run reach Smartling once I connect it?">
    Yes. You connect an application once, and it becomes available to every agent you run. The agent's instructions decide whether it uses Smartling on a given run. Refer to [How Connectors Work](/user-guide/ai-and-intelligence/merlin-ai/connectors/connect-external-apps#how-connectors-work).
  </Accordion>

  <Accordion title="Whose Smartling account does an agent use?">
    The account of the person who starts the run. Each teammate connects their own Smartling account on the **Connectors** page, so an agent works with that teammate's Smartling projects when they run it.
  </Accordion>

  <Accordion title="Can an agent change data in my Smartling account?">
    Yes, when a tool that writes to Smartling is enabled. MoEngage does not ask for your approval before a connector write. Disable the tools you want kept out of reach, and write your agent's instructions to match.
  </Accordion>

  <Accordion title="What if the connection to Smartling drops during a run?">
    Reconnect Smartling on the **Connectors** page in a separate browser tab, and then send your next message in the same session. Restate any step that the agent skipped so that the agent retries the step. Refer to [Reconnect During a Run](/user-guide/ai-and-intelligence/merlin-ai/connectors/connect-external-apps#reconnect-during-a-run).
  </Accordion>
</AccordionGroup>

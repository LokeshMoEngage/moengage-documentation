You tell a Merlin AI agent what you want in plain English. The agent looks up the campaigns, segments, and analytics it needs, works through the steps, and hands back the finished work: an answer in the task, a campaign draft in the builder, a saved segment, or a file you download.

Agents draft campaigns, build segments, check campaigns before you send them, translate content, and report on performance. An agent works only within your own workspace.

<AgentTaskSimulator />

A task runs in the background, so you send the request and return to it later. For how to read the steps above in a real task, refer to [Anatomy of a Task Transcript](/user-guide/ai-and-intelligence/merlin-ai/agents/run-and-manage-agent-tasks#anatomy-of-a-task-transcript).

Two families of agent run in the **Merlin AI Agents** hub. Both families use the same hub, task list, transcripts, output files, and workspace memory, so the procedures documented for one family apply to the other.

### Choosing Between the Two

Start from the work rather than the agent. Find the job closest to yours in the following table.

| The work in front of you | Use | Why |
| :--- | :--- | :--- |
| Last week's open rates dropped and you need to know what caused it | Global Agent | You are investigating, and each answer changes your next question |
| You want the size and reachability of an audience before you commit to a campaign | Global Agent | A one-off check you act on straight away |
| You need a campaign draft for a brief that will not come up again | Global Agent | Nothing here is worth saving as a reusable agent |
| Every push campaign must be checked for broken links and locale gaps before it goes out | Custom Agent | The same checks, applied the same way, on every campaign |
| The team must translate campaigns to one agreed house style | Custom Agent | Any teammate runs the same agent and gets the same treatment |
| You want last week's channel performance in your inbox every Monday | Custom Agent | Only a Custom Agent runs on a schedule and emails the result |

The distinction is the same in each case. The Global Agent answers what you are asking now, in your own words. A Custom Agent produces the same kind of output on every run, for whoever runs it.

A job that needs several specialists is still a Custom Agent. Attach them to a coordinator agent. Refer to [Build Multi-Agent Workflows](/user-guide/ai-and-intelligence/merlin-ai/agents/build-multi-agent-workflows).

To start your first task, refer to [Merlin AI Agents Home](/user-guide/ai-and-intelligence/merlin-ai/agents/merlin-ai-agents-home), which covers reaching the hub and sending a task to either family.

## Before You Start

- **Availability.** The Global Agent and Custom Agents are Early Access features. If either family does not appear in your dashboard, contact your Customer Success Manager (CSM). For details, refer to [Feature Enablement](/user-guide/ai-and-intelligence/merlin-ai/agents/agent-permissions-and-security#feature-enablement).
- **Permissions.** An agent acts within your own MoEngage permissions. An agent cannot access data or make changes that you cannot access or make yourself.
- **Campaign publishing.** An agent prepares campaign drafts and does not publish a campaign. You publish the campaign from the standard MoEngage campaign builder.
- **MoEngage Credits.** Every agent run, including scheduled runs and multi-agent workflows, consumes MoEngage Credits from your workspace's monthly balance. For more information, refer to [Merlin AI Usage](/user-guide/settings/account/billing/merlin-ai-usage).

<Warning>
  On Android, the following group key and update key combinations can replace an unrelated notification or leave an empty group in the notification drawer. Some devices, such as Motorola, show an empty group as a blank notification.

  - **The same value is used as both a group key and an update key.** This applies to the same campaign and to different campaigns. For example, campaign A has the group key *newssports* and campaign B has the update key *newssports*.
  - **An update key is reused with a different group key or without a group key.** The update replaces the original notification, and the original group is left empty. For example, campaign A has the group key *orderupdates* and the update key *order1234*. Campaign B has no group key and the update key *order1234*. When campaign B arrives, the group of campaign A is left empty.

  To avoid blank notifications:

  - Use different values for the group key and the update key. Never use the same value for both.
  - Always send an update key with the same group key, or always send it without a group key.

  Android SDK 14.07.00 fixed an issue where a blank notification was shown on certain OEMs upon clicking the last notification within a notification group. This fix does not prevent the blank notifications caused by the combinations above.
</Warning>

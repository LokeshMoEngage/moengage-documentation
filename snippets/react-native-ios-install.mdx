  <Tab title="CocoaPods">
    1. Navigate to the `ios` directory.
    2. Run the following command:

       ```bash Bash
       bundle exec pod install
       ```
  </Tab>
  <Tab title="Swift Package Manager (SPM)">
    <Warning>
      SPM support is experimental and requires React Native 0.87 or later. For the supported packages, setup details, and limitations, refer to [iOS Installation](/developer-guide/react-native-sdk/sdk-integration/react-native/sdk-installation/ios).
    </Warning>

    1. Navigate to the `ios` directory.
    2. Set up SPM:

       - If the iOS project still uses CocoaPods, convert it once with `npx react-native spm add --deintegrate`. For more information, refer to [Migrate From CocoaPods to SPM](/developer-guide/react-native-sdk/migration/migration-of-moengage-sdk-from-cocoapods-to-spm).
       - If the iOS project already uses SPM, run:

         ```bash Bash
         npx react-native spm
         ```

    With SPM you no longer run `pod install`. The MoEngage native SDKs resolve automatically from their SPM repositories.
  </Tab>
</Tabs>

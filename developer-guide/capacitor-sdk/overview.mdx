The MoEngage Capacitor plugin wraps the native Android and iOS SDKs and exposes them to your JavaScript or TypeScript code. It tracks events and user attributes, registers push tokens on both platforms, and renders in-app messages.

Start with [Integrating the Capacitor SDK](/developer-guide/capacitor-sdk/sdk-integration/overview) to add and initialize the plugin, then add the channels you need.

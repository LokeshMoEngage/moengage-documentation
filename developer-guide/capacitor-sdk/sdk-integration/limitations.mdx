---
title: "Limitations"
description: "Review unsupported features and native integration requirements when using the MoEngage Capacitor plugin."
---

Compared to the native Android and iOS SDKs, some features are not supported, and others require a native Android or iOS implementation when you use the MoEngage Capacitor plugin.

# Features Not Supported

* Nudges
* Action Buttons in iOS Notifications

# Features That Are Supported but Require Native Integration

* Inbox Module
* Cards Module

Integrating the MoEngage Capacitor plugin takes two steps: add the plugin and its native dependencies, then initialize the SDK.

Initialization comes in two forms. File-based initialization keeps configuration in native config files; the framework and platform pages set it in code instead.

## SDK Installation

| Page | What it covers |
| --- | --- |
| [Framework Dependency](/developer-guide/capacitor-sdk/sdk-integration/basic/sdk-installation/framework-dependency) | Add the plugin and configure native platform dependencies. |
| [Android SDK Installation](/developer-guide/capacitor-sdk/sdk-integration/basic/sdk-installation/android-sdk-installation) | Install the Android SDK using the BOM or manual dependency configuration. |
| [iOS SDK Installation](/developer-guide/capacitor-sdk/sdk-integration/basic/sdk-installation/ios-sdk-installation) | Install the iOS SDK by running `ionic capacitor sync`. |

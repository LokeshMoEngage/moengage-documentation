Push in Capacitor is configured per platform: Firebase credentials and the runtime permission on Android, APNS certificates on iOS. The **Basic** pages cover both, plus the listeners you use for token generation and notification clicks.

## Basic

| Page | What it covers |
| --- | --- |
| [Android Push Configuration](/developer-guide/capacitor-sdk/push/basic/android-push-configuration) | Configure Android push, including FCM setup and push registration. |
| [Android Notification Runtime Permissions](/developer-guide/capacitor-sdk/push/basic/android-notification-runtime-permissions) | Request the Android 13 notification runtime permission. |
| [iOS Push Configuration](/developer-guide/capacitor-sdk/push/basic/ios-push-configuration) | Configure iOS push, including APNS certificates and registration. |
| [Push Callback](/developer-guide/capacitor-sdk/push/basic/push-callback) | Listen for push token generation and notification click events. |

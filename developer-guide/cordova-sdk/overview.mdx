The MoEngage Cordova plugin wraps the native Android and iOS SDKs and exposes them to your JavaScript code. It tracks events and user attributes, registers push tokens on both platforms, and renders in-app messages.

Start with [Integrating the Cordova SDK](/developer-guide/cordova-sdk/sdk-integration/overview) to add and initialize the plugin, then add the channels you need.

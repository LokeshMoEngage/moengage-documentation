Push in Cordova is configured per platform: Firebase credentials and the runtime permission on Android, APNS certificates on iOS. The **Basic** pages cover both, plus the JavaScript callback for notification clicks.

## Basic

| Page | What it covers |
| --- | --- |
| [Android Push Configuration](/developer-guide/cordova-sdk/push/basic/android-push-configuration) | Configure Android push, including FCM setup and push token handling. |
| [Android Notification Runtime Permissions](/developer-guide/cordova-sdk/push/basic/android-notification-runtime-permissions) | Request the Android 13 notification runtime permission. |
| [iOS Push Configuration](/developer-guide/cordova-sdk/push/basic/ios-push-configuration-7xx) | Configure iOS push, including APNS certificates and push registration. |
| [Push Callback](/developer-guide/cordova-sdk/push/basic/push-callback) | Set up JavaScript callbacks for push notification click events. |

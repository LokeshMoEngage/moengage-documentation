## Code Initialization

Initialize the SDK in code. Use manual initialization to pass the configuration in a `MoEngageSDKConfig` instance, or file-based initialization to read the configuration from `Info.plist`.

- Call any one of the below-given initialization methods on `MoEngageCordovaBridge.shared` in **application:didFinishLaunchingWithOptions:** method. Refer [doc](/developer-guide/ios-sdk/sdk-integration/basic/sdk-initialization/manual-initialization) for more info on all the properties which can be configured using **MoEngageSDKConfig**.

  <CodeGroup>

  ```swift Manual Initialization wrap
  /// - Parameters:
  ///   - sdkConfig: MoEngageSDKConfig instance for SDK configuration
  ///   - launchOptions: Launch Options dictionary
  func initializeDefaultInstance(sdkConfig: MoEngageSDKConfig,
                                 launchOptions: [UIApplication.LaunchOptionsKey: Any]?)

  /// - Parameters:
  ///   - sdkConfig: MoEngageSDKConfig instance for SDK configuration
  ///   - sdkState: Enum indicating if SDK is Enabled/Disabled
  ///   - launchOptions: Launch Options dictionary
  func initializeDefaultInstance(sdkConfig: MoEngageSDKConfig,
                                 sdkState: MoEngageSDKState,
                                 launchOptions: [UIApplication.LaunchOptionsKey: Any]?)
  ```

  ```swift File-Based Initialization wrap
  /// Initializes the default instance from Info.plist with additional Cordova configuration.
  /// - Parameter cordovaConfig: MoEngageCordovaSDKDefaultInitializationConfig instance with additional configuration
  func initializeDefaultInstance(additionalCordovaConfig cordovaConfig: MoEngageCordovaSDKDefaultInitializationConfig)

  /// Initializes the default instance from Info.plist with additional configuration.
  /// - Parameter config: MoEngageSDKDefaultInitializationConfig instance with additional configuration
  func initializeDefaultInstance(additionalConfig config: MoEngageSDKDefaultInitializationConfig)
  ```

  </CodeGroup>
- Sample code to initialise from **application:didFinishLaunchingWithOptions:** method:

<CodeGroup>

```swift Manual Initialization wrap
let sdkConfig = MoEngageSDKConfig(appId: "YOUR_WORKSPACE_ID", dataCenter: .data_center_01)
sdkConfig.appGroupID = "APP_GROUP_ID"
sdkConfig.consoleLogConfig = MoEngageConsoleLogConfig(isLoggingEnabled: true, loglevel: .verbose)
MoEngageCordovaBridge.shared.initializeDefaultInstance(sdkConfig: sdkConfig, launchOptions: launchOptions)
```

```swift File-Based Initialization wrap
MoEngageCordovaBridge.shared.initializeDefaultInstance(additionalCordovaConfig: MoEngageCordovaSDKDefaultInitializationConfig())
```

</CodeGroup>

# Data Center

In case your app wants to redirect data to a specific zone due to any data regulation policy please configure the zone in the `MoEngageSDKConfig` object.

For more information on Data Center, refer [here](/developer-guide/ios-sdk/sdk-integration/basic/data-center).

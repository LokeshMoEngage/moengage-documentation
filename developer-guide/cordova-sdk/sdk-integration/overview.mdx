Integrating the MoEngage Cordova plugin takes two steps: add the `cordova-moengage-core` plugin and its native dependencies, then initialize the SDK from JavaScript and on each native platform.

## SDK Installation

| Page | What it covers |
| --- | --- |
| [Framework Dependency](/developer-guide/cordova-sdk/sdk-integration/sdk-installation/framework-dependency) | Add the `cordova-moengage-core` plugin and configure platform settings. |
| [Android SDK Installation](/developer-guide/cordova-sdk/sdk-integration/sdk-installation/android-sdk-installation) | Add the Android SDK dependency using the BOM or manual configuration. |
| [iOS Installation](/developer-guide/cordova-sdk/sdk-integration/sdk-installation/ios-installation) | Install the iOS SDK using CocoaPods. |

## SDK Initialization

| Page | What it covers |
| --- | --- |
| [Framework Initialization](/developer-guide/cordova-sdk/sdk-integration/sdk-initialization/framework-initialization) | Initialize the plugin with `MoECordova.init()`. |
| [Android SDK Initialization](/developer-guide/cordova-sdk/sdk-integration/sdk-initialization/android-sdk-initialization) | Initialize the SDK in your Android application's `onCreate`. |
| [iOS SDK Initialization](/developer-guide/cordova-sdk/sdk-integration/sdk-initialization/ios-sdk-initialization) | Initialize the SDK in your iOS application in code. |

<Note>
  Review [Limitations](/developer-guide/cordova-sdk/sdk-integration/limitations) before you plan your integration. Some features are unsupported or need native implementation.
</Note>

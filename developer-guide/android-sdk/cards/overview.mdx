Cards are persistent, non-intrusive messages that live inside your app rather than interrupting the user, usually as an inbox or newsfeed. You can use the MoEngage card UI as-is, embed it in a Jetpack Compose layout, or take the card payload and build your own views.

| Page | What it covers |
| --- | --- |
| [Cards](/developer-guide/android-sdk/cards/cards) | Set up Cards to deliver persistent inbox and newsfeed messages. |
| [Cards in Jetpack Compose](/developer-guide/android-sdk/cards/cards-ui-compose) | Embed the cards feed in a Compose interface with the `cards-ui-compose` module. |
| [Self Handled Cards](/developer-guide/android-sdk/cards/self-handled-cards) | Build custom card views using the self-handled Cards SDK. |

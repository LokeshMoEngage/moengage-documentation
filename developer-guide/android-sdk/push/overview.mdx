Push notifications on Android need work in two places: the MoEngage dashboard, where you upload your FCM credentials, and your app, where you configure notification metadata, request the runtime permission, and register for a push token. The **Basic** pages cover both and are required for any push integration.

**Advanced** covers customizing display and handling notifications yourself. **Optional** adds campaign types, delivery amplification, and extra surfaces.

## Basic

| Page | What it covers |
| --- | --- |
| [Push Configuration](/developer-guide/android-sdk/push/basic/push-configuration) | Configure notification metadata, icons, and Firebase settings. |
| [FCM Authentication](/developer-guide/android-sdk/push/basic/fcm-authentication) | Generate an FCM private key and upload it to the MoEngage dashboard. |
| [Notification Runtime Permissions](/developer-guide/android-sdk/push/basic/notification-runtime-permissions) | Request the Android 13 notification runtime permission. |
| [Push Token Registration and Display](/developer-guide/android-sdk/push/basic/push-token-registration-and-display) | Register devices using the Firebase Installation ID and display notifications on SDK 15.03.00 and above. |
| [Push Token Registration and Display (Legacy)](/developer-guide/android-sdk/push/basic/push-token-registration-and-display-legacy) | Set up token registration and display on SDK versions below 15.03.00. |

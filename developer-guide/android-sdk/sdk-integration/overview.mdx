Integrating the MoEngage Android SDK takes three steps: configure your build settings, add the SDK dependencies, and initialize the SDK in your `Application` class with your Workspace ID and data center. The **Basic Integration** pages cover all three and are required for every integration.

**Advanced or Optional** pages cover security, custom networking, and dependency choices you can add once the basic integration works.

## Basic Integration

| Page | What it covers |
| --- | --- |
| [Configuring Build Settings](/developer-guide/android-sdk/sdk-integration/basic-integration/configuring-build-settings) | Add the Maven repository and enable Java 8 in your Android project. |
| [Install Using BOM](/developer-guide/android-sdk/sdk-integration/basic-integration/Install-Using-BOM) | Use the MoEngage Bill of Materials to keep module versions compatible. |
| [SDK Initialization](/developer-guide/android-sdk/sdk-integration/basic-integration/sdk-initialization) | Initialize the SDK in your `Application` class with your Workspace ID and data center. |
| [Exclude MoEngage Storage File from Auto-Backup](/developer-guide/android-sdk/sdk-integration/basic-integration/exclude-mo-engage-storage-file-from-auto-backup) | Prevent data corruption after an Android auto-backup restore. |

## Advanced or Optional

| Page | What it covers |
| --- | --- |
| [Installing SDK using Artifact Id](/developer-guide/android-sdk/sdk-integration/advanced-or-optional/installing-sdk-using-artifact-id) | Install individual modules by their Maven Central artifact IDs instead of the BOM. |
| [JWT Authentication](/developer-guide/android-sdk/sdk-integration/advanced-or-optional/jwt-authentication) | Secure data collection by authenticating SDK requests with a JWT. |
| [Add-On Security](/developer-guide/android-sdk/sdk-integration/advanced-or-optional/add-on-security) | Encrypt the data the SDK stores on device using the encrypted storage module. |
| [Custom Proxy Domain - Android](/developer-guide/android-sdk/sdk-integration/advanced-or-optional/custom-proxy-domain-android) | Route SDK traffic through your own subdomain to bypass ad blockers. |
| [Network Security Configuration](/developer-guide/android-sdk/sdk-integration/advanced-or-optional/network-security-configuration) | Whitelist MoEngage domains in a custom network security configuration. |
| [SDK Build Specifications](/developer-guide/android-sdk/sdk-integration/advanced-or-optional/sdk-configuration) | Review the build specifications and library versions used to compile the SDK. |

<Note>
  Use [Install Using BOM](/developer-guide/android-sdk/sdk-integration/basic-integration/Install-Using-BOM) unless you have a reason to pin modules individually. The BOM resolves compatible versions across MoEngage modules for you.
</Note>

The MoEngage Android SDK runs inside your Kotlin or Java app. It tracks events and user attributes, registers push tokens with Firebase Cloud Messaging, and renders in-app messages and cards. Install it from Maven Central using the MoEngage Bill of Materials.

Start with [Integrating the Android SDK](/developer-guide/android-sdk/sdk-integration/overview) to add and initialize the SDK, then add the channels you need.

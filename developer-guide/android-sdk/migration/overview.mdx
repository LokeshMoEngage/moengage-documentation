Each major version of the MoEngage Android SDK has its own migration page covering the APIs, modules, and build configuration that changed. Work through them in order from the version you are on.

## Version Upgrades

| Page | What it covers |
| --- | --- |
| [Updating to 12.x.xx from 11.x.xx](/developer-guide/android-sdk/migration/updating-to-12xxx-from-11xxx) | Updated build configs and modularized InApp and Push. |
| [Updating to 11.x.xx from 10.x.xx](/developer-guide/android-sdk/migration/updating-to-11xxx-from-10xxx) | Updated APIs, Java 8 support, and modular geofence setup. |
| [Migration to 10.x.xx](/developer-guide/android-sdk/migration/migration-to-10xxx) | Updated APIs, removed GCM support, and behavioral changes. |
| [Migration from 4.x to 5.x (One time activity)](/developer-guide/android-sdk/migration/migration-from-4x-to-5x-one-time-activity) | Updated receivers and APIs. |

## Infrastructure and Module Changes

| Page | What it covers |
| --- | --- |
| [Migrating to Firebase Installation ID](/developer-guide/android-sdk/migration/migrating-to-firebase-installation-id) | Move to the Firebase Installation ID when you upgrade to BOM 4.4.0. |
| [Migration To Maven Central](/developer-guide/android-sdk/migration/migration-to-maven-central) | Move your dependencies from JCenter to Maven Central. |
| [Moving from Manifest to Code based Integration](/developer-guide/android-sdk/migration/moving-from-manifest-to-code-based-integration) | Move from manifest metadata to code-based initialization. |
| [Migrating from addon-inbox 6.0.2](/developer-guide/android-sdk/migration/migrating-from-addon-inbox-602) | Move to the `inbox-core` and `inbox-ui` modules. |

<Note>
  Check [Android SDK Deprecated Versions](/developer-guide/android-sdk/deprecated-versions/deprecated-versions) for the support status of your current version before planning an upgrade.
</Note>

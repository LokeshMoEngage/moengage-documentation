---
title: "Enable Advertising Identifier Tracking"
description: "Enable advertising identifier tracking in the MoEngage Android SDK for accurate device analytics."
---

Track the Advertising Identifier if you need more accurate device analytics and reinstall tracking. For more information, refer to [Android Advertising ID Tracking](https://www.moengage.com/docs/user-guide/data/privacy/android-advertising-id-tracking).

## Add Ad Identifier Library

Add the below dependency in the application-level **_build.gradle_** file.

<CodeGroup>

```groovy Groovy wrap
implementation("com.google.android.gms:play-services-ads-identifier:18.0.1")
```

</CodeGroup>

From SDK version **12.1.00**, the SDK does not track the Advertising Identifier by default. To enable Advertising Identifier tracking, use the [enableAdIdTracking()](https://moengage.github.io/android-api-reference/core/com.moengage.core/enable-ad-id-tracking.html) method as shown below.

<Warning>
  Take consent from the user before you enable Advertising Identifier tracking, as required by the [Google Play policy](https://support.google.com/googleplay/android-developer/answer/10144311) on advertising ID usage.
</Warning>

<CodeGroup>

```Kotlin Kotlin wrap
import com.moengage.core.enableAdIdTracking
enableAdIdTracking(context)
```


```Java Java wrap
MoESdkStateHelper.enableAdIdTracking(context);
```

</CodeGroup>

<Info>
  To disable advertising identifier tracking, or to learn how to track Android ID alongside the advertising ID, see [Device Identifier Tracking](/developer-guide/android-sdk/data-tracking/advanced-or-optional/device-identifier-tracking).
</Info>

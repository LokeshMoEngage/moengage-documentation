The MoEngage Android SDK tracks user behavior through events and user attributes. The **Basic** pages cover what every integration needs: identifying users, tracking events, and telling MoEngage whether a launch is an install or an update.

**Advanced or Optional** pages cover device identifiers, locale, and tracking opt-outs.

## Basic

| Page | What it covers |
| --- | --- |
| [Track Events](/developer-guide/android-sdk/data-tracking/basic/track-events) | Track custom user events and their attributes. |
| [Track User Attributes](/developer-guide/android-sdk/data-tracking/basic/track-user-attributes) | Track user attributes and set the unique identifier used for user identification. |
| [Track Install or Update](/developer-guide/android-sdk/data-tracking/basic/track-install-or-update) | Differentiate installs from updates using the `setAppStatus` API. |
| [Enable Advertising Identifier Tracking](/developer-guide/android-sdk/data-tracking/basic/enable-advertising-identifier-tracking) | Enable advertising identifier tracking for device analytics. |
| [Setting Unique Id for SDK versions below 13.6.00](/developer-guide/android-sdk/data-tracking/basic/setting-unique-id-for-sdk-versions-below-13-6-00) | Set a unique user ID for login and logout on SDK versions below 13.6.00. |

## Advanced or Optional

| Page | What it covers |
| --- | --- |
| [Device Identifier Tracking](/developer-guide/android-sdk/data-tracking/advanced-or-optional/device-identifier-tracking) | Enable or disable Android ID and advertising identifier tracking. |

| [Tracking Locale](/developer-guide/android-sdk/data-tracking/advanced-or-optional/tracking-locale) | Track the device locale. |
| [Personalize Experience Events Tracking](/developer-guide/android-sdk/data-tracking/advanced-or-optional/personalize-experience-events-tracking) | Track impression and click events for personalized experiences. |

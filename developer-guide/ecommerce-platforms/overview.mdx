These integrations connect a hosted store to MoEngage. Shopify has a dedicated MoEngage app; WooCommerce and Magento use the Web SDK, deployed through Google Tag Manager or directly.

| Page | What it covers |
| --- | --- |
| [Shopify](/developer-guide/ecommerce-platforms/shopify/overview) | Install the MoEngage app, sync users, orders, and your catalog, and validate the integration. |
| [WooCommerce](/developer-guide/ecommerce-platforms/woo-commerce/woocommerce) | Integrate your store using Google Tag Manager for event and user tracking. |
| [Magento](/developer-guide/ecommerce-platforms/magento/magento) | Integrate the Web SDK using Google Tag Manager or direct integration. |

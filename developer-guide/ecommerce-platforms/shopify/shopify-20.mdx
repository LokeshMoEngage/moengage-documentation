# Overview

This article covers how to install and configure the MoEngage app on your Shopify store. Complete the steps below to authenticate, initialize, and configure the integration before you begin tracking events or syncing data.

## Step 1: Install the MoEngage App

To install the MoEngage app, perform the following steps:

1. In your MoEngage UI, navigate to the **App Marketplace**.
2. Search for **Shopify 2.0**, and then click the tile.
3. Navigate to the **Integrate** tab, and then click **Install MoEngage app on your Shopify** **store**. Use the MoEngage listing in the Shopify App Marketplace to add the app to your store.

   ![InstallShopify.gif](/images/InstallShopify1.gif)

4. Click **Open** to redirect to the Shopify admin UI and complete the installation.

## Step 2: Authenticate

After successful installation, to authenticate, perform the following steps:

1. Navigate to the **MoEngage App Integration** tab.
2. Enter the following credentials from your MoEngage account.
   | Field | Description |
   | --- | --- |
   | App ID | The Workspace ID of your MoEngage account is available at **Settings** \> **Account** \> **APIs** \> **Workspace ID**. |
   | Data API ID | Same as **Workspace ID**. |
   | Data API Key | The Data API Key of the MoEngage account is available at **Settings** \> **App Settings** \> **APIs** \> **API Keys** \> **Data.** |
3. Click **Authenticate** and then click **Continue**.

   <Info>
     **Information** Newly generated API keys can take up to 10 minutes to be activated. If authentication fails after entering new credentials, wait 10 minutes and then try again before raising a support ticket.
   </Info>

## Step 3: Configure Initialization Settings

<Info>
  **Note**

  The following steps must be performed for MoEngage to track user data and events.
</Info>

To configure the initialization settings, perform the following steps:

1. On the **Initialization Settings**, navigate to **Theme Settings** in your Shopify admin.
2. Turn the **MoEngage Shopify app embed** setting toggle on.
3. Click **Save**.

## Step 4: Configuration Settings

MoEngage tracks all standard Shopify events for every store. You do not need to select them. For the list of events, refer to [Events and User Data Tracking](/developer-guide/ecommerce-platforms/shopify/events-and-user-data-tracking).

<Info>
  **Prerequisite**

  MoEngage sets up [Identity Resolution](/user-guide/data/user-data/unified-identity-identity-resolution) for your workspace when you save the configuration for the first time. Identity Resolution can only be set up on a workspace with 1,000 users or fewer. If your workspace has more users, the save fails. Raise a support ticket, and then save the configuration again after the support team resolves it.
</Info>

To configure the settings, perform the following steps:

1. Go to the **Configuration** tab. The **Configure tracking** section lists the user events, user properties, and user identifiers that MoEngage tracks.

   ![Configuration tab in the MoEngage Shopify app showing the Configure tracking and Sync user OPTIN sections](/images/shopify-configuration-tab.png)

2. Expand **User events** to review the events and event attributes that MoEngage tracks. All events are tracked by default and cannot be deselected.
3. Expand **User properties** to review the user attributes that MoEngage syncs to user profiles. For the full list, refer to [Tracked User Attributes](/developer-guide/ecommerce-platforms/shopify/events-and-user-data-tracking#tracked-user-attributes).
   - To stop syncing a property, click the delete icon next to it. You cannot remove **Shopify ID**, **Email**, or **Mobile number**.
   - To sync an additional property, click **+ Custom property**, enter a property name, select a data type, and then select a Shopify source.

   ![User properties section with the Custom property option highlighted](/images/shopify-user-properties.png)

4. Expand **User identifiers** and select your user identifiers. MoEngage uses these identifiers to recognize users and merge their profiles across sessions, devices, and Shopify updates. You can select up to four identifiers:
   - **Shopify ID** is always selected and cannot be cleared.
   - **Email** and **Mobile number** are selected by default. Keep at least one of them selected.
   - To add a fourth identifier, select the checkbox in the last row, and then select an attribute from the **Select option** list. You can select a custom property that uses a Shopify customer metafield of type single-line text, URL, ID, integer, or decimal.

   ![User identifiers section with Shopify ID, Email, and Mobile number selected](/images/shopify-user-identifiers.png)

   <Warning>
     **Warning** After you save the configuration, you cannot change your user identifiers. To change them later, contact the MoEngage support team. Profile merges that happen based on your identifiers cannot be reversed.
   </Warning>

5. Under **Sync user OPTIN**, turn on the **Email subscription sync**, **SMS subscription sync**, and **WhatsApp subscription sync** toggles for the channels whose marketing consent you want to sync from Shopify. For more information, refer to [Marketing Consent Mapping](/developer-guide/ecommerce-platforms/shopify/events-and-user-data-tracking#marketing-consent-mapping).
6. Click **Save configuration**.

<Info>
  The MoEngage app requests permission to read Shopify customer merges. If your store installed the app before this permission was added, Shopify prompts you to approve it the next time you open the app.
</Info>

### Existing Stores

If you configured the MoEngage app before multiple identifiers were available, the following applies to your store:

- Your store keeps the identifier you selected during setup (Email or Phone Number).
- You can save the configuration again to update your user properties and opt-in sync settings without changing your identifier.
- Profile sync requires Identity Resolution on your workspace. If it is not enabled, contact your Customer Success Manager or the support team.
- To add Shopify ID or other identifiers to your store, contact the support team. Until Shopify ID is added, MoEngage does not sync Shopify tags, Shopify LTV, Shopify order count, Shopify last order ID, or Shopify customer merges for your store.

## Step 5: Enable Web Personalization (Optional)

To enable web personalization, perform the following steps:

1. Confirm that Web Personalization is enabled for your MoEngage account. If it is not, contact your Customer Success Manager or the support team.
2. On the **Configuration** tab, turn the **Enable web personalization** **on your store** toggle on.

   ![Settings (1).png](/images/InstallShopify4.png)

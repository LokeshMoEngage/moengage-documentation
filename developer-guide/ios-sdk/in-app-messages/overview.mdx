---
title: "In-App Messages in iOS"
description: "Display contextual in-app messages in your iOS app and handle deep links and custom actions."

---

In-app messages appear while a user is active in your app, which makes them useful for contextual prompts, cross-sell, and onboarding. The SDK renders the message; your app controls where messages are allowed to show and what happens when a user taps one.

| Page | What it covers |
| --- | --- |
| [In-App Nativ](/developer-guide/ios-sdk/in-app-messages/in-app-nativ) | Display contextual in-app messages using the In-App NATIV SDK. |
| [Custom Action Handling](/developer-guide/ios-sdk/in-app-messages/custom-action-handling) | Handle deep link callbacks and custom actions from in-app messages. |

<Note>
  HTML in-app messages can call the SDK from JavaScript. See [JavaScript Bridge for HTML In-Apps](/developer-guide/components-for-sdk/javascript-bridge/javascript-bridge-for-html-in-apps).
</Note>

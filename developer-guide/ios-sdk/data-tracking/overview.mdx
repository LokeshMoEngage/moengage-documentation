Data tracking is how your app tells MoEngage who a user is and what they do. Everything you segment, target, and analyze in the dashboard comes from the events and attributes you send here.

Start with **Basic**, which covers user identity and event tracking. **Advanced** adds context such as locale, sessions, and Personalize experience reporting.

## Basic

| Page | What it covers |
| --- | --- |
| [Install/Update differentiation](/developer-guide/ios-sdk/data-tracking/basic/install-update-differentiation) | Distinguish fresh installs from updates using the `appStatus` API. |
| [Tracking user attributes](/developer-guide/ios-sdk/data-tracking/basic/tracking-user-attributes) | Set user attributes and the unique ID that identifies a user across platforms. |
| [Setting Unique Id for SDK versions below 9.23.0](/developer-guide/ios-sdk/data-tracking/basic/setting-unique-id-for-sdk-versions-below-9-23-0) | Handle login and logout on SDK versions below 9.23.0. |
| [Tracking events](/developer-guide/ios-sdk/data-tracking/basic/tracking-events) | Track custom events and their attributes. |

## Advanced

| Page | What it covers |
| --- | --- |
| [Tracking Locale](/developer-guide/ios-sdk/data-tracking/advanced/tracking-locale) | Track the locale settings of the user's device. |
| [Session and Source Tracking](/developer-guide/ios-sdk/data-tracking/advanced/session-and-source-tracking) | Track user sessions and deep-link source information. |
| [Personalize Experience Events tracking](/developer-guide/ios-sdk/data-tracking/advanced/personalize-experience-events-tracking) | Report impression and click events for Personalize API experiences. |

<Warning>
  Call the logout API when a user signs out. Without it, the next user's activity is attributed to the previous profile. See [Tracking user attributes](/developer-guide/ios-sdk/data-tracking/basic/tracking-user-attributes).
</Warning>

To stop tracking for a user, see [Compliance](/developer-guide/ios-sdk/compliance/compliance).

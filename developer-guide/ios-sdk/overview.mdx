The MoEngage iOS SDK runs inside your Swift or Objective-C app. It tracks events and user attributes, registers push tokens with APNs, and renders in-app messages and cards. Install it with Swift Package Manager or CocoaPods.

Start with [SDK Integration](/developer-guide/ios-sdk/sdk-integration/overview) to install and initialize the SDK, then add the channels you need.

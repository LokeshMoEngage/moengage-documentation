This section covers everything needed to get the MoEngage iOS SDK running in your app: adding the dependency, initializing it with your Workspace ID and data center, and the optional hardening you can add afterwards.

Work through **Basic** in order first. **Advanced** pages are independent of each other — add only what your integration needs.

## Basic

| Page | What it covers |
| --- | --- |
| [SDK Integration](/developer-guide/ios-sdk/sdk-integration/basic/sdk-integration) | Install the SDK using Swift Package Manager or CocoaPods. |
| [SDK Initialization](/developer-guide/ios-sdk/sdk-integration/basic/sdk-initialization) | Initialize the SDK in your `AppDelegate` with your Workspace ID and data center. |
| [Data Center](/developer-guide/ios-sdk/sdk-integration/basic/data-center) | Configure data center redirection so data routes to the correct cluster. |
| [Configuring Project for Architecture Compatibility](/developer-guide/ios-sdk/sdk-integration/basic/Configuring-Project-for-Architecture-Compatibility) | Configure your Xcode project for arm64 compatibility with SDK v10.x.x. |
| [Integration through CocoaPods](/developer-guide/ios-sdk/sdk-integration/basic/integration-through-cocoa-pods) | Install the SDK with the CocoaPods dependency manager. |

## Advanced

| Page | What it covers |
| --- | --- |
| [Custom Proxy Domain - iOS](/developer-guide/ios-sdk/sdk-integration/advanced/custom-proxy-domain-ios) | Route SDK traffic through your own subdomain to bypass ad blockers. |
| [JWT Authentication](/developer-guide/ios-sdk/sdk-integration/advanced/jwt-authentication) | Secure data collection by signing SDK requests with a JWT. |
| [Add-On Security](/developer-guide/ios-sdk/sdk-integration/advanced/add-on-security) | Encrypt data the SDK stores on device using Keychain and encrypted storage. |

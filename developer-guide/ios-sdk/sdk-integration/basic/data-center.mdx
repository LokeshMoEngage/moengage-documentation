---
title: "Data Center"
description: "Configure data center redirection in the MoEngage iOS SDK to route data to the correct cluster."
---

MoEngage supports data redirection to servers in different clusters. Set the data center that matches your account using the initialization method your app implements.

<Tabs>
  <Tab title="Config-Based Initialization">
    Select your dashboard host in the **MoEngage Data Center** field of the [MoEngage config generator](https://app-cdn.moengage.com/sdk/integration/initialization/index.html). The generator writes the matching `DataCenter` value into your configuration. See [Config-Based Initialization](/developer-guide/ios-sdk/sdk-integration/basic/sdk-initialization/config-based-initialization).
  </Tab>
  <Tab title="Manual Initialization">
    Pass the data center to the [`MoEngageSDKConfig`](https://moengage.github.io/ios-api-reference/Classes/MoEngageSDKConfig.html) initializer. See [Manual Initialization](/developer-guide/ios-sdk/sdk-integration/basic/sdk-initialization/manual-initialization).

    <CodeGroup>

    ```swift Swift wrap
    import MoEngageSDK

    let sdkConfig = MoEngageSDKConfig(appId: "YOUR_WORKSPACE_ID", dataCenter: .data_center_01)
    ```

    ```objective-c Objective C wrap
    @import MoEngageSDK;

    MoEngageSDKConfig *sdkConfig = [[MoEngageSDKConfig alloc] initWithAppId:@"YOUR_WORKSPACE_ID" dataCenter:MoEngageDataCenterData_center_01];
    ```

    </CodeGroup>
  </Tab>
</Tabs>

<Note>
  Data center 06 is available from MoEngage iOS SDK version 9.17.3 onwards.
</Note>

Following are the hosts for each data center. Use them to identify your data center from your dashboard host, and to allowlist the SDK API domain:

| `DataCenter` key | `MoEngageDataCenter` value | SDK Host | Dashboard Host |
| :-- | :-- | :-- | :-- |
| `1` | `data_center_01` | sdk-01.moengage.com | dashboard-01.moengage.com |
| `2` | `data_center_02` | sdk-02.moengage.com | dashboard-02.moengage.com |
| `3` | `data_center_03` | sdk-03.moengage.com | dashboard-03.moengage.com |
| `4` | `data_center_04` | sdk-04.moengage.com | dashboard-04.moengage.com |
| `5` | `data_center_05` | sdk-05.moengage.com | dashboard-05.moengage.com |
| `6` | `data_center_06` | sdk-06.moengage.com | dashboard-06.moengage.com |

<Warning>
  Refer to your dashboard host to identify the data center for your account, and consult the MoEngage team before changing the data center in the SDK.
</Warning>

For more information about MoEngage data centers, refer to [Data Centers in MoEngage](/user-guide/data/key-concepts/data-centers-in-moengage).

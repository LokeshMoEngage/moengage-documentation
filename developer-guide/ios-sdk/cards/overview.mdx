Cards are persistent, non-intrusive messages that live inside your app rather than interrupting the user. You can use the MoEngage card UI as-is, or take the card payload and build your own views.

| Page | What it covers |
| --- | --- |
| [Cards in iOS](/developer-guide/ios-sdk/cards/cards-in-i-os) | Create and display card campaigns using the Cards SDK via SPM or CocoaPods. |
| [Self Handled Cards](/developer-guide/ios-sdk/cards/self-handled-cards) | Build custom card views using the self-handled cards SDK and APIs. |

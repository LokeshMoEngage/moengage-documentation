Push notifications on iOS need work in three places: the MoEngage dashboard (APNs credentials), your Xcode project (capabilities and extensions), and your app code (registration and callbacks). The **Basic** pages cover all three and are required for any push integration.

**Optional** pages add individual campaign types and surfaces. **Advanced** covers customizing what the SDK does by default.

## Basic

| Page | What it covers |
| --- | --- |
| [iOS Push Integration Tutorial](/developer-guide/ios-sdk/push/basic/ios-push-integration-tutorial) | End-to-end steps to send, receive, and track rich push notifications. |
| [Push Notifications](/developer-guide/ios-sdk/push/basic/push-notifications) | Push setup in your app, including APNs, templates, and geofencing. |
| [APNS Authentication Key](/developer-guide/ios-sdk/push/basic/apns-authentication-key) | Generate a `.p8` key and upload it to the MoEngage dashboard. |
| [APNS Certificate/PEM file (legacy)](/developer-guide/ios-sdk/push/basic/apns-certificate-pem-file-legacy) | Create and upload a legacy APNs certificate in PEM format. |
| [Actionable Notifications](/developer-guide/ios-sdk/push/basic/actionable-notifications) | Add custom action buttons to standard iOS push notifications. |

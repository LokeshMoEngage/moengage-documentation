description: "Use the MoEngage JavaScript bridge to interact with the SDK from HTML in-app messages, on-site messaging campaigns, and landing pages."
keywords: ["JavaScript bridge", "HTML in-app", "on-site messaging", "landing pages", "track event from HTML"]
---

The JavaScript bridge lets HTML content rendered by MoEngage call back into the SDK, so a template can track an event, handle a click, or dismiss itself. Which bridge you use depends on where the HTML runs.

| Page | What it covers |
| --- | --- |
| [JavaScript Bridge for HTML In-Apps](/developer-guide/components-for-sdk/javascript-bridge/javascript-bridge-for-html-in-apps) | The bridge API available inside HTML in-app message templates. |
| [JavaScript Bridge for On-Site Messaging and Landing Pages](/developer-guide/components-for-sdk/javascript-bridge/javascript-bridge-for-on-site-messaging-and-landing-pages) | Track events, clicks, dismissals, and form submissions from on-site messaging campaigns and landing pages. |

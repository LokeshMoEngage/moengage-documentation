Integrating the MoEngage Flutter SDK takes two steps: add the `moengage_flutter` package and its native dependencies, then initialize the SDK.

Initialization comes in two forms. File-based initialization keeps configuration in native config files; manual initialization sets it in code on each platform.

## SDK Installation

| Page | What it covers |
| --- | --- |
| [Framework Dependency](/developer-guide/flutter-sdk/sdk-integration/sdk-installation/framework-dependency) | Add `moengage_flutter` to your `pubspec.yaml`. |
| [Android](/developer-guide/flutter-sdk/sdk-integration/sdk-installation/android) | Add the required Android dependencies and AndroidX libraries. |
| [iOS](/developer-guide/flutter-sdk/sdk-integration/sdk-installation/ios) | Set up the iOS dependency with CocoaPods or Swift Package Manager. |

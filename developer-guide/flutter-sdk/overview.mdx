The MoEngage Flutter SDK wraps the native Android and iOS SDKs and exposes them to your Dart code. It tracks events and user attributes, registers push tokens on both platforms, and renders in-app messages and cards.

Start with [Integrating the Flutter SDK](/developer-guide/flutter-sdk/sdk-integration/overview) to add and initialize the package, then add the channels you need.

Push in React Native is configured per platform: Firebase credentials and the runtime permission on Android, APNS certificates and entitlements on iOS. The **Basic** pages cover both, plus the callbacks you use to receive tokens and clicks in JavaScript.

iOS also needs notification extensions for rich media and impression tracking.

The MoEngage React Native plugin wraps the native Android and iOS SDKs and exposes them to your JavaScript or TypeScript code. It tracks events and user attributes, registers push tokens on both platforms, and renders in-app messages and cards.

Start with [Integrating the React Native SDK](/developer-guide/react-native-sdk/sdk-integration/overview) to install and initialize the plugin, then add the channels you need.

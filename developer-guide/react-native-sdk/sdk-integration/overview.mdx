Integrating the MoEngage React Native plugin takes two steps: install the plugin and its native dependencies, then initialize the SDK. Choose the path that matches your project, **React Native** or **Expo**.

Initialization comes in two forms. File-based initialization keeps configuration in native config files; manual initialization sets it in code on each platform.

The MoEngage Personalize SDK delivers personalized experiences to visitors on your website. You can let the SDK render an experience, or fetch the payload and render it with your own frontend components.

Start with [Web Personalization - V2](/developer-guide/personalize-sdk/sdk-integration/web-personalization-v2) to install and configure the SDK.

The MoEngage Web SDK runs on your website as a JavaScript snippet. It tracks visitor attributes and events, registers browsers for web push, and renders on-site messages and cards.

Start with [Integrating the Web SDK](/developer-guide/web-sdk/web-sdk-integration/overview) to add and initialize the SDK, then add the channels you need.

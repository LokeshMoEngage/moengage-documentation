The MoEngage Unity SDK wraps the native Android and iOS SDKs and exposes them to your C# code. It tracks events and user attributes, registers push tokens on both platforms, and renders in-app messages.

Start with [Integrating the Unity SDK](/developer-guide/unity-sdk/sdk-integration/overview) to import and initialize the package, then add the channels you need.

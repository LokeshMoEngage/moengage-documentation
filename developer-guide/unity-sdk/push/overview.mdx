Push in Unity is configured per platform: Firebase credentials and the runtime permission on Android, APNS certificates on iOS. The **Basic** pages cover both, plus the click observers you use to react to a notification.

**Optional** features ship as separate Unity packages you import when you need them.

## Basic

| Page | What it covers |
| --- | --- |
| [Android Push Configuration](/developer-guide/unity-sdk/push/basic/android-push-configuration) | Configure Android push, including Firebase and push token setup. |
| [Android Notification Runtime Permissions](/developer-guide/unity-sdk/push/basic/android-notification-runtime-permissions) | Request the Android 13 notification runtime permission. |
| [iOS Push Configuration](/developer-guide/unity-sdk/push/basic/ios-push-configuration) | Configure iOS push, including APNS certificates and push registration. |
| [Push Callback](/developer-guide/unity-sdk/push/basic/push-callback) | Set up click observers to handle notification interactions. |

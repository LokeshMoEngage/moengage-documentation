Integrating the MoEngage Unity SDK takes two steps: import the Unity package into your project, then initialize the SDK. The standard path attaches the `MoEGameObject` script to your scene and sets your workspace ID there.

If you need platform-specific control, initialize from a native config file or in native code instead.

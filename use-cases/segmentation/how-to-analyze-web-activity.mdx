---
title: "How to Analyze web activity"
---

The MoEngage Web SDK (Javascript API) enables you to track all user activity across your website (both desktop and mobile). It seamlessly maps user activity across your app and website to a unique user profile. As a result, you can easily review user behavior on your website and target users across multiple channels effectively.

For more information about tracking events and user properties, refer to [Track website events](/developer-guide/web-sdk/data-tracking/web-sdk-events-tracking) and [Track web user properties](/developer-guide/web-sdk/data-tracking/web-sdk-user-attributes-tracking).

## Prerequisites

To get the best data from your web integration, your technical team should ensure the following:

1. If you have already integrated our mobile SDKs (Android and iOS), you should use the same user property and event names across your App and Web tracking.
2. If you have an identifier to uniquely identify your user, you should track this user property as [mentioned here](/developer-guide/web-sdk/data-tracking/web-sdk-user-attributes-tracking). This will enable the merging of users based on this identifier across all platforms.

## How to see user activity on the Dashboard?

Once this integration is complete, you can see user activity on the user profile and through segmentation queries.

1. On your MoEngage Dashboard, navigate to **Segment** \> **Search Users**, search for a user, and open their [User Profile](/user-guide/data/user-data/user-profile) to check the events tracked for that user.
2. To analyze activity across users, navigate to **Segment** \> **Create Segment** and run segmentation queries on the events you have tracked on your website.
3. To narrow the results to web users, add the event property **Platform** is **WEB**.

Once fired from your website, events show up on the user's profile within 1-2 minutes.

# 新機能

## セグメンテーション

以下の機能が追加されました。

### ネストされた AND/OR クエリのサポート

この機能により、接続演算子（AND/OR）を使用して複数レベルのネストを持つ複雑なクエリを作成し、きめ細かなユーザーセグメントを作成できます。詳細については、[セグメントの組み合わせ](https://moengage-user-guide.mintlify.app/user-guide/segment/segment-operations/rule-based-filter-segments#combining-segments)を参照してください。

### 集計関数のサポート

この機能により、数値属性に対して Minimum、Maximum、Average、Sum、Median などの集計関数を使用してユーザーをフィルタリングし、ユーザーセグメントを作成できます。また、数値属性に対して絶対値または相対パーセンテージによる比較も実行できるようになりました。詳細については、[集計演算子](/ja/user-guide/segment/advanced-concepts/aggregation-operations)を参照してください。

### 過去 N 時間/日/週/月

この機能により、セグメントの作成時に過去 N 時間/日/週/月に基づいてフィルタリングできます。詳細については、[日付と時刻のフィルター](https://moengage-user-guide.mintlify.app/user-guide/segment/advanced-concepts/filters-in-segmentation#date-time-filters)を参照してください。

# 機能強化とパッチリリース

## Email ドラッグ＆ドロップエディター

Email ドラッグ＆ドロップエディターに以下の機能が追加されました。

- 背景画像
- コンテンツタグ
- モバイルデザインモード
- 行内の垂直方向の配置

## インバウンドチャネル

- インバウンドチャネルで下書きを削除できるようになりました。
- 以下のパッチをリリースしました。
  - Campaign Info へのキャンペーン作成者名とメールアドレスの追加
  - Dashboard およびキャンペーン配信のパフォーマンスを高速化するため、すべての API で Gzip 圧縮を利用可能に

---
title: "MoEngage にカスタムデータをインポートするにはどうすればよいですか？"
description: "SDK によるトラッキング以外のカスタムユーザーデータを MoEngage にインポートします。Data Import API を使用して、サーバーから追加のユーザー属性とイベントを送信します。"
---

MoEngage には、ユーザーデータを取得するためのすべてのモバイルプラットフォーム向け SDK と JavaScript SDK があります。ただし、ユーザーに関するすべての情報を SDK レベルで取得できるわけではなく、一部の追加のユーザー属性はお客様のサーバーから送られてくる場合があります。追加情報を当社のサーバーに送信するための [Data Import API](https://www.moengage.com/docs/api/data/data-overview) を提供しています。これらの API を使用して、ユーザー属性やユーザーイベントを当社のシステムに送信できます。

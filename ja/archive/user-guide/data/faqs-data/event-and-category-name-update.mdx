---
title: "イベント名およびカテゴリー名の更新"
description: "MoEngage は読みやすさを向上させるため、一部のイベントとカテゴリーの名前を変更しました。更新されたイベント名、カテゴリー、ユーザープロパティのラベルをこちらでご確認ください。"
---

イベントのドロップダウンには、読みにくいイベント名がいくつかありました。MoEngage は、使いやすさと読みやすさを向上させるため、それらのイベント名とカテゴリー名を変更しました。  
  
イベント名、既存のカテゴリー、新しいイベント名、新しいカテゴリーの一覧を以下に示します。

| 旧名称 | 旧カテゴリー | 更新後の名称 | 更新後のカテゴリー |
| --- | --- | --- | --- |
| MOE\_APP\_EXIT | Tracked User Event | App Exit | Lifecycle |
| MOE\_LOGOUT | Tracked User Event | User Logout | Lifecycle |
| UPDATE | Tracked User Event | App Update | Lifecycle |
| MO\_PUSH\_PREFERENCE\_CHANGED | Tracked User Event | Push Preference Changed iOS | Campaign Activity |
| NOTIFICATION\_DISMISSED\_IOS\_MOE | Tracked User Event | Notification Dismissed iOS | Campaign Activity |
| NOTIFICATION\_RECEIVED\_IOS\_APP\_ACTIVE | Tracked User Event | Notification Received iOS App Active | Campaign Activity |
| USER EXITED FLOW | Tracked User Event | User Exited Flow | Campaign Activity |
| USER ENTERED FLOW | Tracked User Event | User Entered Flow | Campaign Activity |

MOE\_APP\_EXIT はオンデマンドのイベントであり、有料機能です。このイベントがアカウントで利用できない場合は、MoEngage サポートチームにお問い合わせください。

User Properties の 2 つのカテゴリーの名前も変更されました。

| 旧カテゴリー名 | 更新後のカテゴリー名 | 説明 |
| --- | --- | --- |
| MoEngage Tracked Attribute | Tracked Standard Attribute | MoEngage が提供する標準キー (Email、Name など) でクライアントがトラッキングするユーザー属性。 |
| Tracked User Attribute | Tracked Custom Attribute | クライアントが任意のカスタムキーでトラッキングするユーザー属性。 |

これらの変更は、MoEngage ダッシュボードのすべてのイベントのドロップダウンとユーザー属性のドロップダウンに反映されます。変更内容はユーザープロファイルでも確認できます。

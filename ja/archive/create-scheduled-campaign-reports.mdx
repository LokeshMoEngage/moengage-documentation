MoEngage のキャンペーンレポートを、定期的なスケジュールでメールの受信トレイに直接配信するように設定できます。これにより、手作業なしでタイムリーにパフォーマンスのインサイトを受け取ることができます。自動レポートを使用すると、キャンペーンのパフォーマンスを継続的に監視し、手作業なしで主要な指標を追跡し、関係者と効率的にインサイトを共有できます。

## キャンペーンレポートのスケジュール設定

1. MoEngage ダッシュボードの左側のナビゲーションメニューで、**Settings** \> **Analytics** をクリックします。
2. **REPORT SETTINGS** までスクロールします。  
    *<img alt="mceclip0.png" src="/images/moengage_9b4f37.png" />*
3. レポートを受信する時刻を選択します。
4. 配信方法として **Email** と **REST API** のいずれかまたは両方を選択します。  
   REST API を使用するとレポートデータを取得できるため、社内ダッシュボード、ビジネスインテリジェンスツール、またはデータウェアハウスとシームレスに統合して高度な分析を行うことができます。
5. レポートを受信するメールアドレスを入力します。レポートを自社のサーバーに直接ダウンロードする必要があるユーザー向けに、MoEngage は REST API を提供しています。詳細については、[Daily Campaign Report API](https://www.moengage.com/docs/api/campaign-reports/download-campaign-report) を参照してください。
6. **Save** をクリックします。これでレポートのスケジュールが設定されます。

さらにサポートが必要な場合は、MoEngage のカスタマーサクセスマネージャー（CSM）またはサポートチームにお問い合わせください。

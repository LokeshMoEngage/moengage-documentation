成長を重視するマーケティングチームやプロダクトチームにとって、ビジネスの効率、ユーザーの傾向、ユーザーコンバージョン、ユーザーリテンションを分析するために必要なすべての指標は、MoEngage ダッシュボードの **Key Metrics** と呼ばれる1か所で確認できます。ビジネスマーケターにとって、これらは企業のパフォーマンス、成功、および特定のビジネス活動を評価するために使用される4つの主要なビジネスファネルです。主要な指標は企業の目標や戦略によって異なる場合がありますが、MoEngage Key Metrics では次の主要なカテゴリーを提供しています。

- **Acquisition（獲得）** - さまざまなプラットフォーム（Web、Android、iOS）およびソース（サードパーティの広告ソース）を通じて獲得したすべての新規ユーザーのデータを提供します。
- **Engagement（エンゲージメント）** - アプリまたは Web サイト上のアクティブユーザーとそのセッションのデータを提供します。
- **Conversion（コンバージョン）** - ユーザーのコンバージョン率と生み出された収益のデータを提供します。
- **Retention（リテンション）** - ユーザーのリテンション率と、ユーザーが属する RFM セグメントのデータを提供します。

Key Metrics は毎日 00:30 GMT に計算されます。

Key Metrics ダッシュボードには、指定した期間とプラットフォームのデータが表示されます。期間は、デフォルトの保持期間である60日より前の日付範囲まで選択できます。

全体の指標には、選択した期間における Average DAU、Average MAU、Total New Users、Total Uninstalled Users、New Web Push Subscribers、Aggregate Web Push Subscribers、Total Conversion、Total Revenue が表示されます。緑または赤の小さな数値は、前の期間と比較した増加率（緑）または減少率（赤）を示します。前の期間とは、選択した期間の直前にある同じ長さの期間です。

## **個別の指標**

### Daily Active Users と 30 Day Active Users

![Screenshot_2020-05-17_at_10.32.10_PM.png](/images/moengage_cb23b6.png)

Daily Active Users - 特定の日にアプリを開いたユニークユーザーの数です。\
計算方法 - 特定の日に _App/Site Open_ イベントを実行したユニークユーザーの数をカウントします。

30 Day Active Users - 過去30日間にアプリを開いたユニークユーザーの数です。\
計算方法 - 過去30日間に _App/Site Open_ イベントを実行したユニークユーザーの数をカウントします。

Stickiness - Stickiness 比率は、ユーザーがアプリ/サイトにどの程度の頻度でエンゲージしているかを示します。割合が高いほど良好です。これは、DAU になるほど長く定着している MAU が多いことを意味します。\
計算方法 - Stickiness は DAU と MAU の比率（DAU/MAU）として計算できます。

### New Users、Installs、Uninstalled Users

![Screenshot_2020-05-17_at_10.36.21_PM.png](/images/moengage_f96e5f.png)

New Users / Installs - 特定の日の新規ユーザーの数です。\
計算方法 - その日にサインアップした新規ユーザー（_First Seen_ ユーザープロパティが計算日と等しいユーザー）

Uninstalled Users - 特定の日にアンインストールしたユーザーの数です。\
計算方法 - 計算日のユーザー属性「uninstalled time」に基づき、インストールステータスが false であるユーザーの数をカウントします。

Retention Rate - Retention Rate は、特定の日に維持されたユーザーの割合を示します。\
計算方法 - その日の総インストール数に対する純インストール数（インストール数 - アンインストール数）の比率です。

<Note>
  セグメンテーションにおけるアンインストールユーザー数は、イベント「uninstall」に基づいています。
</Note>

### New Web Push Subscribers と Aggregate Web Push Subscribers

<Frame>
  ![Key Metrics Old](/images/key-metrics-old.png)
</Frame>

New Web Push Subscribers - その日に Web プッシュ通知を購読したユーザーの数です。\
計算方法 **-** その日に _Subscribed to Web Push_ イベントを実行したユニークユーザーの数をカウントします。

Aggregate Web Push Subscribers **-** Web プッシュ通知を購読しているユーザーの総数です。\
計算方法 - Web _Push Subscription Status_ ユーザープロパティが true で、Web Push Subscription Time が計算日以前であるユーザーの数をカウントします。

### Goal Event Unique Count と Total Revenue

![Screenshot_2020-05-17_at_10.40.56_PM.png](/images/moengage_006581.png)

Goal Event Unique Count - 特定の日に GOAL イベントを実行したユニークユーザーの数です。\
計算方法 - 特定の日に GOAL イベントを実行したユニークユーザーの数

Total Revenue - GOAL イベントを実行したユーザーによって生み出された総収益です。\
計算方法 - 特定の日の GOAL イベントにおける収益属性の合計です。

Order Value Per Converted User - 注文額は、アプリ/サイトでユーザーが費やした平均金額を追跡します。計算方法 - 平均注文額を計算するには、総収益をコンバージョンしたユーザーの総数で割ります。

これは、**Settings -\> App Settings -\>**  **Workspace ID, Time-Zone, Key Metrics** で選択された App Conversion Goal から算出されます。

### チャートデータのダウンロード

上記のすべてのチャートのデータは、画像またはデータファイルとして、CSV、XLS、PNG、JPEG、PDF などのさまざまな形式でダウンロードできます。ダウンロードするには、チャートの右上にあるダウンロードボタンをクリックします。

チャートに1つの指標のみを表示するには、チャートの線の下にある凡例で他の指標をクリックします。

**Key Metrics とセグメンテーション**

MoE セグメンテーションは、ユーザーデータとイベントデータをリアルタイムで計算します。このリアルタイムのデータスナップショットは、Key Metrics と一致する場合もあれば、一致しない場合もあります。Key Metrics とセグメンテーションの間でデータが一致しない理由は次のとおりです。

1. Key Metrics は特定の時点でのデータのスナップショットです。その時点以降、データが変更または更新される可能性があります（例：ユーザーのマージ、ユーザーの位置情報の更新、OS の更新、LTV の増加など）。そのため、同じデータに対する同じクエリでも、時間が経つと異なる数値になる場合があります。
2. ごくまれに、SDK から送信されたデータの処理に遅延が発生することがあります。このようなまれなケースでは、計算されたデータが正しくない場合があります。MoEngage はこうした異常を継続的に追跡し、それに応じて Key Metrics のデータを更新します。

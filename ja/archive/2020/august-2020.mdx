# 新機能

## Streams

マーケターと開発者の皆様に [MoEngage Streams](https://www.moengage.com/docs/api/data/moengage-streams) をご紹介します。

MoEngage Streams を使用すると、MoEngage のデータを CDP（Segment や m-particle）、データレイク、データウェアハウス、または単純な API エンドポイントなど、任意のサードパーティシステムにリアルタイムでストリーミングできます。

Streams を使用すれば、API エンドポイントを設定するだけでデータを転送でき、システムへのデータフローを可視化できます。

詳細については、[MoEngage Streams](https://www.moengage.com/docs/api/data/moengage-streams "https://help.moengage.com/hc/en-us/articles/360045896572-MoEngage-Streams") を参照してください。

## パートナー統合

### Sendgrid のデータ統合

メールの送信に Sendgrid を使用している場合（トランザクションメールを送信している場合など）、Sendgrid から MoEngage にメールの配信イベントとエンゲージメントイベントを転送できるようになりました。

詳細については、[Sendgrid Data Integration](https://partners.moengage.com/hc/en-us/articles/4422510567700-Sendgrid- "https://help.moengage.com/hc/en-us/articles/360047558651-Sendgrid-Data-Integration") を参照してください。

### Sinch のデータ統合

SMS の送信に Sinch を使用している場合（OTP アラートやトランザクション更新を送信している場合など）、Sinch から MoEngage に SMS の配信レシートを転送できるようになりました。

## セキュリティ

### 2 段階認証

MoEngage アカウントで 2 段階認証によるログインがサポートされるようになりました。2 段階認証により、MoEngage アカウントのセキュリティが強化されます。パスワードと電話ベースの認証コードの両方でアカウントを保護できます。

詳細については、[2 段階認証](/ja/user-guide/settings/account/security/2-step-verification-or-two-factor-authentication-2fa "/user-guide/settings/account/security/2-step-verification-or-two-factor-authentication-2fa") を参照してください。

## プッシュ通知

リリース日: 2020年8月31日

Push Amp\+ で Huawei Messaging Service（HMS）がサポートされるようになりました。

HMS Core は、Android における Google Play Services の代替です。Huawei は最近、Google Firebase Cloud Messaging（FCM）をサポートしない新しいシリーズのデバイスを発売しました。今後も FCM をサポートしないデバイスが多数発売される予定です。これらのデバイスで円滑に機能するよう、Huawei Messaging Service がサポートされています。

HMS は、通知の到達率を高め、エンドユーザーへのリーチとエンゲージメントを向上させるのに役立ちます。

## セグメント分析

### プッシュ通知でリーチ可能なユーザー

リリース日: 2020年8月27日

Create Segment ページでクエリを実行すると、プッシュ通知でリーチ可能なユーザー数を把握できるようになりました。マーケターは、すべてのプラットフォームにわたるプッシュ通知のリーチ可能ユーザー数と、サポートされている各プラットフォーム個別のユーザー数を確認できます。リーチ可能数は、Create Segment ページで作成されたすべてのクエリで利用できます。

![Reachability\_Count.png](/images/moengage_925536.png)

詳細については、[Recent Queries](/ja/user-guide/segment/create-segments/rule-based-filter-segments#recent-queries) と [Understanding Reachability](/ja/user-guide/segment/reachability/user-reachability) を参照してください。

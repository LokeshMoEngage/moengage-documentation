# 新機能

## Cards

**リリース日: 2020年6月24日**

Card キャンペーンは、顧客、サプライヤー、ユーザーとのつながりを維持するための MoEngage の新しいチャネルです。

Card キャンペーンは、以下の機能をサポートしています。

- 邪魔にならないキャンペーン
- 受信トレイで利用可能
- Android と iOS の両方でカスタマイズ可能な受信トレイ
- 受信トレイで無期限または特定の期間表示

Card キャンペーンにより、メールやプッシュ通知でリーチできないユーザーとのコミュニケーションが可能になります。これらのユーザーは、メールの購読を解除しているか、プッシュ通知を無効にしています。

Card キャンペーンは、MoEngage の受信トレイまたはその他の受信トレイを使用します。MoEngage の受信トレイを使用する場合は、Android 向け MoEngage SDK バージョン 10.1.00 および iOS 向けバージョン 6.1.0 が統合されていることを確認してください。

<img alt="cards.gif" src="/images/moengage_40aaea.png" />

Card 機能の詳細については、[Card Campaign](/ja/user-guide/campaigns-and-channels/cards/create/create-a-card-campaign "/user-guide/campaigns-and-channels/cards/create/create-a-card-campaign") を参照してください。

## Amplitude 統合

**リリース日: 2020年6月12日**

[Amplitude](https://amplitude.com/ "https://amplitude.com/") は、プロダクト分析と行動分析を通じて成長を支援する分析プラットフォームです。MoEngage と Amplitude の統合が利用可能になりました。この統合には以下が含まれます。

- Amplitude から行動コホートをエクスポートして、MoEngage でカスタムセグメントを作成します。
- Amplitude からコホートの変更を動的にエクスポートして、MoEngage の対応するカスタムセグメントを更新します。
- より詳細な分析のために、キャンペーンのパフォーマンスデータを Amplitude に送信します。
- 開発者の関与なしで簡単に設定できる統合です。

<img alt="MoEngage_Amplitude_Image.png" src="/images/moengage_7039d0.png" />

統合と使用方法の詳細については、[Amplitude integration](https://partners.moengage.com/hc/en-us/articles/4409507678228-Amplitude-Audiences "https://help.moengage.com/hc/en-us/articles/360044936052-Amplitude-Integration") を参照してください。

  

# 機能強化

## ダッシュボードの編集

**リリース日: 2020年6月12日**

必要に応じてダッシュボードを編集できるようになりました。以下の操作が可能です。

- Custom Dashboards に表示されるチャートを表示または編集する
- Custom Dashboard 内の特定のチャートまたはすべてのチャートを更新する
- URL またはメールを使用して、チャートとダッシュボードをチームメンバーと共有する
- チャートを画像（PNG 形式）または Excel（CSV 形式）としてダウンロードする
- ダッシュボード間でチャートを移動またはコピーする
- 分析のコンテキストを伝えるためにチャートの説明を記載する

<img alt="Chart_Edit.png" src="/images/moengage_ab13d5.png" />

ダッシュボードの編集の詳細については、[Custom Dashboards in Analytics](/ja/user-guide/analyze/dashboards/custom-dashboards "/user-guide/analyze/dashboards/custom-dashboards") を参照してください。

## Flows のコントロールグループと統計

**リリース日: 2020年6月12日**

Flows でコントロールグループを使用して、Flow のパフォーマンスをコントロールグループと比較して測定できるようになりました。コンバージョンのアップリフトを測定して、Flow の有効性を検証できます。

また、以下の方法で Flow のパフォーマンスについてより深いインサイトを得ることもできます。

- ユーザーのコンバージョンとエンゲージメントの経時的な傾向を分析する。
- Flow のすべてのエンゲージメントチャネルの効果を比較する。

<img alt="ControlGroupinFlows.png" src="/images/moengage_55a727.png" />

Flows のコントロールグループの詳細については、[Control Group in Flow](/ja/user-guide/flows-cross-channel-messaging/create/experimentation/control-group-in-flows) を参照してください。

## セグメンテーションにおけるユーザープロファイル

**リリース日: 2020年6月12日**

セグメンテーションのユーザープロファイルが一新されました。

ユーザープロファイルには、新しく強化されたユーザーインターフェースとともに追加機能が搭載されています。以下の機能が強化されました。

- Push、Email、SMS の各チャネルにおけるユーザーのリーチ可能性を、別のセクションで確認できます。
- ユーザープロパティにすばやくアクセスできます。ユーザープロパティは、Localization、Lifecycle、Custom attributes、Standard attributes などのカテゴリーに分類されています。
- より詳細な分析のために、すべてのユーザーアクティビティを別のセクションで確認できます。タイムラインにより、ユーザーの過去のアクティビティを総合的に把握できます。
- ユーザーアクティビティは、選択したイベント、キャンペーン、プラットフォーム、期間でフィルタリングされます。
- ユーザーアクティビティは時間順に並べ替えられます。折りたたみビューではタイムラインを簡単に分析でき、展開ビューでは属性を詳細に分析できます。
- フィルタリングしたイベントの間に実行されたイベントをドリルダウンできます。

<img alt="UserProfile.png" src="/images/moengage_ed892b.png" />

ユーザープロファイルの詳細については、[Analyzing User Profiles](/ja/user-guide/data/user-data/user-profile "/user-guide/data/user-data/user-profile") を参照してください。

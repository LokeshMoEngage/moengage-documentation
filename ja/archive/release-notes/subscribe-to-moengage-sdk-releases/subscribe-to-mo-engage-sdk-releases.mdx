---
title: "MoEngage SDK リリースの購読"
description: "GitHub のリリース通知を購読して、MoEngage が新しい SDK バージョンを公開したときに更新情報を受け取ります。"
---

GitHub のリリースを購読することで、MoEngage がネイティブ SDK およびハイブリッド SDK の新しいバージョンをリリースするたびに通知を受け取れるようになりました。

<Check>
  GitHub にログインしている必要があります。
</Check>

SDK リリース通知を購読するには、次の手順を実行します。

1. 対象の GitHub リポジトリに移動します。

<Info>
  その他の SDK のサポートも近日中に追加する予定です。
</Info>

- Android: https://github.com/moengage/android-dependency-catalog
- iOS: https://github.com/moengage/apple-sdk
- React Native: https://github.com/moengage/React-Native
- Flutter: https://github.com/moengage/Flutter-SDK/
- Unity: https://github.com/moengage/MoEngage-Unity-SDK

2. **Watch** をクリックします。Notifications ポップアップウィンドウが表示されます。\\

   <img
     src="/images/subscribe1.png"
     alt="Subscribe1"
     title="Subscribe1"
   />
3. **Custom** をクリックします。Custom ポップアップウィンドウが表示されます。\\

   ![Subscribe2](/images/subscribe2.png)
4. **Releases** を選択し、**Apply** をクリックします。

MoEngage が SDK の新しいバージョンをリリースするたびに、新しいバージョンが利用可能であることを知らせる通知がメールで届きます。

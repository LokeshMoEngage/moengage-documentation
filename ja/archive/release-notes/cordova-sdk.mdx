<Info>
  **iOS におけるカスタムブール属性のトラッキング**

  このバージョンの SDK に更新すると、iOS デバイスにおいて、MoEngage はブール構文のカスタムユーザー属性を現在の 1/0 ではなく TRUE/FALSE としてトラッキングし始めます。これにより、セグメンテーションやトリガー条件に影響が出る可能性があります。 

  このバージョンでは、ブールデータ型のカスタムユーザー属性をどのようにトラッキングするかを柔軟に選択できるようになりました。デフォルトでは、iOS は TRUE/FALSE を使用する Android のトラッキング方法に合わせられます。ただし、キャンペーンの要件により適している場合は、既存の 1/0 のトラッキング方法を引き続き使用することもできます。

  プラットフォーム間の一貫性を保つため、新しい TRUE/FALSE 方式への移行をお勧めします。ただし、1/0 のトラッキング方法が好ましい特定のユースケースがあることも理解しています。設定を行うには、開発者ドキュメントの[カスタム属性のトラッキングのセクション](/ja/developer-guide/react-native-sdk/data-tracking/Tracking-User-Attributes#Custom-Boolean-User-Attribute)を参照してください。
</Info>

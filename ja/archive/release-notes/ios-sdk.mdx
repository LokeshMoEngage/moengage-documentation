## Core

<span style={{ backgroundColor: '#e6fffb', color: '#008767', borderRadius: '12px', border: '1px solid #B5F5EC', fontSize: '0.9em', padding: '3px 10px', fontWeight: 'bold' }}>新機能:</span>

- `MoEngageBadgeUpdateEnabled`: SDK がアプリのバッジ数を管理するかどうかを制御するための新しい Boolean キーを `Info.plist` のルートレベルに追加しました。デフォルトは `YES` です。アプリが独自にバッジ数を管理する場合は `NO` に設定してください。詳細については、[バッジリセットの無効化](https://www.moengage.com/docs/developer-guide/ios-sdk/push/advanced/custom-notification-handling#disable-badge-reset)を参照してください。

<span style={{ backgroundColor: '#fffbe6', color: '#d46b08', borderRadius: '12px', border: '1px solid #FFE58F', fontSize: '0.9em', padding: '3px 10px', fontWeight: 'bold' }}>改善点:</span>

- バッジ数を、従来の増減ロジックに代わり、通知センター内の MoEngage 通知の実際の数と同期するように更新しました。

<span style={{ backgroundColor: '#fffbe6', color: '#d46b08', borderRadius: '12px', border: '1px solid #FFE58F', fontSize: '0.9em', padding: '3px 10px', fontWeight: 'bold' }}>修正:</span>

- 認識されないサードパーティの Swift クラス名に対して `NSClassFromString` が呼び出されることにより、iOS 15.x および 16.x で SDK 初期化中に発生していたクラッシュを修正しました。

## InApp

## v2.74.00

**リリース日**: 2026年5月7日

- Data tracking: データトラッキングが無効になっている場合に、匿名ユーザーが意図せずログアウトされる問題を修正しました。
- Web SDK Assist: MoEngage Assist Chrome 拡張機能を導入しました。これは、Web SDK の統合をシームレスにデバッグし、ライブのイベントペイロードを検査し、キャンペーンをリアルタイムでトラブルシューティングするために設計された専用のブラウザツールです。詳細については、[こちら](https://www.moengage.com/docs/developer-guide/web-sdk/integration-validation/moengage-assist-chrome-extension)を参照してください。
- Analytics: Firefox および Safari ブラウザのユーザーについて、レポート呼び出しで誤った OS バージョンが送信されていた問題を修正しました。
- Web Push: プッシュ許可をリセットした後に、セルフハンドル Web プッシュ通知が自動的にトリガーされる問題を解決しました。
- SDK: 冗長な `InitData` コンストラクタの呼び出しを排除し、SDK の初期化プロセスを最適化しました。

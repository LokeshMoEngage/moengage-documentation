# 6.0.0(30-03-2022)

## 動作の変更

* ビルド設定を以下のとおり更新しました
	+ compileSdk 30
	+ minSdk 21
	+ targetSdk 30
* SDK バージョン 12.0.00 以降、moe-android-sdk を依存関係として追加しても、以下の機能はデフォルトでは統合されません。これらの機能を使用している場合は、それぞれの統合ドキュメントを参照して依存関係を更新してください。
	+ [In-App](/ja/developer-guide/ios-sdk/in-app-messages/in-app-nativ)
	+ [Push Amplification](/ja/developer-guide/android-sdk/push/optional/push-amplification)
	+ [デバイストリガー](/ja/developer-guide/android-sdk/push/optional/device-triggered)
* SDK を初期化する API は、App-id が null または空の場合に *[IllegalStateException](https://developer.android.com/reference/java/lang/IllegalStateException)* をスローするようになりました。

## 外部ライブラリのバージョン更新

* androidx.core:core 1.3.1 --> 1.6.0
* androidx.appcompat:appcompat 1.2.0 --> 1.3.1
* androidx.lifecycle:lifecycle-process 2.2.0 --> 2.4.0
* com.google.firebase:firebase-messaging 22.0.0 --> 23.0.0
* Kotlin Standard Library 1.4.20 --> 1.6.0

MoEngage SDK バージョンを **12.0.00** に更新しました。詳細については、**12.0.00** の[リリースノート](/ja/developer-guide/release-notes/android-sdk/2023-and-older#12-0-00-16-03-2022)を参照してください。

# v4.0.00 (21-02-2020)

* マニフェストベースの統合のサポートを削除しました
* MoEngage の GCM ライブラリのサポートを削除しました。まだ GCM の依存関係を使用している場合は、FCM の依存関係に移行してください。
* Fresco のサポートを削除しました。In-App で GIF を使用している場合は、代わりに Glide を使用してください。
* SDK の初期化時に sender id が指定されている場合、google-services.json ファイルのデフォルトの sender id の代わりに、その sender id がトークン登録に使用されます。
* InApp Callbacks - InApp Callbacks のリスナーは、インターフェイスではなく具象クラスになりました。詳細については、API ドキュメントを参照してください。
* Self-Handled in-app がメインスレッドで配信されるようになりました  
詳細については、[移行ガイド](/ja/developer-guide/android-sdk/migration/migration-to-10xxx)のドキュメントを参照してください。

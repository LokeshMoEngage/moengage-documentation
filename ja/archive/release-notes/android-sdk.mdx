## InApp 10.2.1

<span style={{ backgroundColor: 'rgba(0, 135, 103, 0.1)', color: '#008767', border: '1px solid #B5F5EC', padding: '2px 10px', borderRadius: '12px', fontSize: '0.85em', fontWeight: 'bold' }}>改善</span>

- 電話番号の検証を改善しました。
- ナッジが表示されない理由のレポートを改善しました。
- 下部ナッジの重なりを防ぐための処理を改善しました。この新しい動作の一環として、
  - 左下または右下のナッジがすでに表示されている場合、SDK は下部ナッジを表示しません。
  - 下部ナッジが表示されている場合、右下または左下のナッジは表示されません。

<span style={{ backgroundColor: 'rgba(212, 107, 8, 0.1)', color: '#D46B08', border: '1px solid #FFE58F', padding: '2px 10px', borderRadius: '12px', fontSize: '0.85em', fontWeight: 'bold' }}>修正</span>

- 予測型「戻る」ジェスチャーが有効な場合に、戻るボタンを押すとクラッシュする問題を修正しました。このクラッシュは、アプリケーション上でアニメーションが実行中で、かつ InApp が閉じられた場合にのみ発生していました (10.2.0 で発生)。

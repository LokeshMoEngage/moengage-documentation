# 新機能

## テストユーザー優先キュー管理

**リリース日**: 2021年5月17日

新しいキャンペーン、アプリのアップデート、または統合のアップデートをテストするために、特定のユーザーのデータをリアルタイムで追跡できるようになりました。

- ユーザーをテストユーザーとして、デバイスをテストデバイスとしてマークできます
- テストユーザーの詳細は User Profile ページに表示されます。
- Segmentation ページで、テストユーザーの検索クエリを作成できます。

## 再設計されたキャンペーン作成ページ

**リリース日**: 2021年5月18日

![Create Campaign01](/images/CreateCampaign011.gif)

以下の変更が行われました。

- 左側のナビゲーションバーにある **Create New** ボタンから、ホーム画面で新しいキャンペーン、セグメント、Flow、またはダッシュボードを作成できるようになりました。
- All Campaigns ページに **Create Campaign** ボタンが追加され、新しいキャンペーンをより速く簡単に作成できるようになりました。
- サイドバーの MoEngage メニューオプション内で、Flows がキャンペーンから分離されました。すべての Flow の下書きには、新しい All Flows ページからのみアクセスできます。
- キャンペーンの下書きが All Campaign ページでも利用できるようになりました
- すべての定期キャンペーンの子キャンペーンインスタンスは、All Campaigns ページに表示されなくなりました
- All Campaigns ページには、キャンペーンの作成日、スケジュール日、または送信日が年とともに表示されます。All Campaigns ページまたは Campaign information ページのタイムスタンプは、アカウント管理者が設定したアカウントのタイムゾーンに従って表示されるようになりました。

### フィルターの変更

- キャンペーンチャネルと配信タイプの直接フィルターが追加されました。定期キャンペーンは Periodic 配信タイプで、API で作成されたキャンペーンは API Triggered で直接識別できるようになりました
- Created By フィルター: キャンペーンと Flow を、キャンペーンや Flow を作成したユーザーでフィルタリングできます

### 命名規則

ユーザーにとってわかりやすくするため、キャンペーンの名称を変更しました。新しい名称は、以下の表に示すように、チャネルと配信タイプに基づいています。

| 旧名称 | 新名称 |
| --- | --- |
| General Push/Email/SMS | One time and Periodic |
| Smart Trigger | Event Triggered |
| Real time Device Trigger | Device Triggered |
| Geo Fence | Location Triggered |

## セグメンテーションにおける SMS と Email のリーチ可能性

**リリース日**: 2021年5月25日

マーケターは、選択した任意のセグメントについて、Push チャネルに加えて SMS チャネルと Email チャネルでリーチ可能なユーザー数を取得できるようになりました。セグメンテーションページで新しいクエリを実行すると、リーチ可能性に関する以下の情報を確認できます。

- リーチ可能なユーザーの合計: 1 つ以上のチャネル（Push、Email、SMS）でリーチ可能なユーザー数。
- 全ユーザーに対するリーチ可能なユーザーの合計の割合。
- Push、Email、SMS の各チャネルでリーチ可能なユーザー数。
- リーチ可能なユーザーの合計に対する、Push、Email、SMS の各チャネルでリーチ可能なユーザーの割合。

同じ情報には、キャンペーン作成ページでターゲットオーディエンスを選択する際に Show Count ボタンをクリックしてアクセスすることもできます。Push キャンペーンの作成時には、Push キャンペーンのリーチ可能なユーザーの合計とともに、Android、iOS、Web のプラットフォーム別のリーチ可能性が表示されます。マーケターは、セグメンテーションクエリのソース情報も確認できます。セグメンテーションクエリの作成元ページは、Create Segment ページのクエリ結果セクションに表示されます。

## On-site Messaging と Web Personalization のキャンペーン分析

**リリース日**: 2021年5月25日

On-site Messaging チャネルと Web Personalization チャネルのキャンペーン分析を有効にしました。キャンペーンのパフォーマンスや、このキャンペーンを閲覧したユーザー数を確認できます。

## In-App、On-site Messaging、Web Personalization のアクセスロール権限のサポート

**リリース日**: 2021年5月27日

MoEngage は、In-App、On-Site Messaging、Web Personalization のキャンペーンに対するアクセス制御をサポートするようになりました。In-App、On-site、Web Personalization のキャンペーンを作成できるのは、許可されたロールのみです。

詳細については、[Access Roles](/ja/user-guide/settings/account/team-management/access-roles "/user-guide/settings/account/team-management/access-roles") を参照してください。なお、これらのチャネルではキャンペーン承認フローはまだサポートされていません。近日中に提供予定です。

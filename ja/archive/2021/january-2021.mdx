# 新機能

## コントロールグループ

### グローバルコントロールグループ

すべてのキャンペーン（すべてのチャネル）に共通のコントロールグループを作成することで、マーケティングとエンゲージメントの取り組みの ROI（投資利益率）を測定できます。

<img alt="Global_Control_Group_RN_Feb_2021.png" src="/images/moengage_69c9c3.png" />

詳細については、[Global Control Groups](/ja/user-guide/settings/advanced-settings/global-control-group "/user-guide/settings/advanced-settings/global-control-group") を参照してください。

## Analytics

### Funnels

Funnel の 2.0 バージョンには、以下の機能があります。

- 1 つのステップに複数のイベントを追加し、複数のファネルを 1 つに統合できます。
- 不要なパスを除外してファネルを分析できます。
- Event Funnels を使用して、ユーザーのすべてのファネル発生を詳細に分析できます。
- さまざまなステップの実行にかかった時間
- ユーザーが次のステップに進む前に、あるステップを実行した回数。
- All steps と First N steps でプロパティを一定に保つことをサポートします。

詳細については、[Funnels](/ja/user-guide/analyze/analytics/funnels/funnels-overview "https://help.moengage.com/hc/en-us/articles/360019719252-Funnels") を参照してください。

## Engage

### In-App キャンペーン分析

In-App キャンペーンのパフォーマンスを可視化するための新しいユーザーエクスペリエンスと、In-App キャンペーンからのコンバージョン追跡の強化には、以下が含まれます。

1. In-App キャンペーンに最大 5 つのコンバージョン目標を設定できます。
2. コンバージョンを追跡するためのアトリビューションウィンドウをカスタマイズできます。
3. In-App キャンペーンによって生み出された収益を計算できます
4. view-through、click-through、in-session などのアトリビューションモデルを使用して、In-App キャンペーンによって生み出されたコンバージョンを確認できます。

<img alt="campaign_analytics.png" src="/images/moengage_92053d.png" />

詳細については、[In-App campaign analytics](/ja/user-guide/campaigns-and-channels/in-app-message/analyze/analyze-in-app-campaigns "/user-guide/campaigns-and-channels/in-app-message/analyze/analyze-in-app-campaigns") を参照してください。

### Facebook Audience キャンペーン（ベータ機能）

リリース日: 2021年1月15日

MoEngage と Facebook の統合により、マーケターは MoEngage での行動分析に基づいて、MoEngage から Facebook のカスタムオーディエンスにユーザーを同期できます。マーケターは、Facebook でこのカスタムオーディエンスに向けてリターゲティングを行い、広告を作成できます。

<img alt="FB_Audience.png" src="/images/moengage_289e83.png" />

詳細については、[Facebook Audience Campaign](/ja/user-guide/campaigns-and-channels/facebook-audience/create/create-a-facebook-audience-campaign "/user-guide/campaigns-and-channels/facebook-audience/create/create-a-facebook-audience-campaign") を参照してください。

## セキュリティ

### Firewall

ダッシュボードへのアクセスを、信頼できる IP アドレスのみに制限および制御できます。Firewall は認証のレイヤーをさらに追加し、セキュリティを強化して、アカウント情報の漏洩を減らします。

詳細については、[Firewall](/ja/user-guide/settings/account/security/firewall "/user-guide/settings/account/security/firewall") を参照してください。

## Flows

### Flows の A/B Split（ベータ機能）

リリース日: 2021年1月11日

Flow パスの最大 5 つのバリエーションで A/B Split テストを実施し、最もパフォーマンスの高いオプションを判断できます。これらの Flow パス全体で、異なるチャネル、同じチャネルでの異なるメッセージ、異なるメッセージ頻度を試すことができます。

<img alt="A_B_split.png" src="/images/moengage_ef9443.png" />

詳細については、[A/B Spilt in Flows](/ja/user-guide/flows-cross-channel-messaging/create/experimentation/ab-split-in-flows "/user-guide/flows-cross-channel-messaging/create/experimentation/ab-split-in-flows") を参照してください。

### Intelligent Path Optimizer（ベータ機能）

リリース日: 2021年1月11日

Intelligent Path Optimizer は、A/B Split の最大 5 つのブランチをテストし、Sherpa が最もパフォーマンスの高いパスに向けてユーザーの配分を自動的に調整します。

<img alt="intelligentpathoptimizer.png" src="/images/moengage_324834.png" />

詳細については、[Intelligent Path Optimizer](/ja/user-guide/flows-cross-channel-messaging/create/intelligence-in-flows/intelligent-path-optimizer "/user-guide/flows-cross-channel-messaging/create/intelligence-in-flows/intelligent-path-optimizer") を参照してください。

### On-site Messaging と Mobile In-App での Flows（ベータ機能）

リリース日: 2021年1月11日

他の MoEngage チャネルに加えて、On-site Messaging と Mobile In-App でも Flows を利用できます。

<img alt="Flows_On-Site_Messaging.png" src="/images/moengage_78c224.png" />

### Flow の廃止（Retire）

リリース日: 2021年1月11日

Flow の廃止とは、Flow を停止する際に、新規ユーザーの Flow への参加を停止しつつ、現在 Flow 内にいるユーザーには Flow の終了まで進行を許可することを、マーケターが選択できるようになったことを意味します。

<img alt="Retiring_Flow.png" src="/images/moengage_a44f57.png" />

詳細については、[Status of Flows](/ja/user-guide/flows-cross-channel-messaging/create/create-flows/status-of-flows) を参照してください。

# 機能強化

## Engage

### On-site Messaging

On-site Messaging エディターのパフォーマンス改善には、以下が含まれます。

1. コードビューを開いて、テンプレートの HTML コードをカスタマイズできます。
2. On-site Messaging テンプレートにパーソナライズされた画像 URL を追加できます。
3. 不要なテンプレートウィジェットを非表示にできるようになりました。たとえば、閉じるボタンや説明テキストウィジェットなどを非表示にできます。

<img alt="osm_editor.png" src="/images/moengage_8bcc29.png" />

詳細については、[On-site Messaging](/ja/user-guide/campaigns-and-channels/on-site-message "https://help.moengage.com/hc/en-us/articles/360019795372-On-site-Messaging") を参照してください。

## セキュリティ

### ユーザーデータのエクスポート

ユーザーデータのセキュリティを強化するため、User Data Export の新しい変更により、エンドユーザーデータのエクスポートは、MoEngage ダッシュボードへのアクセス権を持つ組織内のユーザーのみに制限されます。

詳細については、[User Export Security](/ja/user-guide/analyze/analytics/user-data-exports "/user-guide/analyze/analytics/user-data-exports") を参照してください。

## Funnels

Funnels の機能強化:

- All steps、First N steps、Nth step によるファネルの分割をサポートします。
- 最大 3 つの属性を使用したファネル分割分析をサポートします。
- 同じ属性と異なる属性の両方で、繰り返し発生するイベントのファネルを分析できます。
- ファネルを分割したり、Hour of the Day、Day of the week などの時間関連の属性を固定したりして、ファネルを分析できます。
- Unique Funnels、Event Funnels、Time to convert、Frequency に対するアクション可能な分析をサポートします。

詳細については、[Funnels](/ja/user-guide/analyze/analytics/funnels/funnels-overview "https://help.moengage.com/hc/en-us/articles/360019719252-Funnels") を参照してください。

# 新機能

## アーカイブされたキャンペーン

**リリース日: 2021年6月24日**

In-App、On-Site Messaging、Web Personalization のキャンペーンもアーカイブできるようになりました。アーカイブされたすべてのキャンペーンのステータスは **Archived** になります。ステータスは、MoEngage アプリの All Campaigns ページに表示されます。

一時停止中の In-App キャンペーンもアーカイブできるようになりました

![2](/images/2.png)

## 評価キャンペーンのキャンペーン分析

**リリース日: 2021年6月30日**

MoEngage の In-App キャンペーンでは、星評価テンプレートを活用して、ユーザーにアプリやアプリの特定の機能を評価してもらうことができます。MoEngage では、以下のように特定のキャンペーンで取得された評価指標を確認できます。

## SMS の DLT 規制への準拠

**リリース日: 2021年6月8日**

MoEngage は、SMS に関するインドの DLT 規制に準拠するため、Template ID を導入し、必須フィールドにしました。

詳細については、[DLT impact on SMS](https://moengage-user-guide.mintlify.app/user-guide/campaigns-and-channels/sms-mms-and-rcs/compliance-and-deliverability/dlt-impact-on-sms "https://help.moengage.com/hc/en-us/articles/360057537631") を参照してください。

# 機能強化

## Push - 新機能

リリース日: 2021年6月24日

キャンペーンとチャネル全体で統一感を持たせるためにユーザーインターフェースを再設計し、ユーザーエクスペリエンスを向上させました。

- プッシュキャンペーン作成時のエクスペリエンスを向上させる**まったく新しいエディター**
- **プラットフォーム間でメッセージやコンテンツを簡単にコピー**できるようになりました。Android でコンテンツを作成し、iOS や Web に自動的にコピーできます。
- Show Count を実行すると、ターゲットセグメント内で**プッシュでリーチ可能なユーザーをその場で確認**できます。
- キャンペーン作成の **「Test Campaign」をステップ 2 に移動**しました。これにより、メッセージのテストが簡単になり、行き来する必要がなくなります。

## SMS - 新機能

**リリース日: 2021年6月24日**

SMS キャンペーンでは、以下の機能強化が利用できます。

1. イベントトリガー型 SMS キャンペーンの開始時刻と終了時刻を定義できるようになりました。
2. MoEngage アプリの SMS Settings ページで、Solution Infini の名称が Kaleyra に変更されました
3. キャンペーンの複製アクションについて、古い SMS キャンペーンを新しく設計されたユーザーインターフェースで開けるようにしました

![SMS リリースノート](/images/SMS-release-notes.gif)

## すべてのユーザーが利用可能になった機能

以下の機能がベータ版から一般提供に移行しました。

- Flows のコントロールグループ
- 「has done event」チェックと「user attribute」チェックの待機時間ゼロ
- Flows の廃止（Retire）
- Flows の Push アクションキャンペーンでのロケールのサポート

# 新機能

## Array Filters

Array Filters に基づいてセグメントをフィルタリングできます。Array Filters は数値と文字列の値をサポートしています。

たとえば、リンゴ、マンゴー、オレンジを販売している場合、Array Filters で **any of** または **all of** フィルターを適用して、マンゴーのみをフィルタリングできます。

詳細については、[Filters in Segmentation](/ja/user-guide/segment/advanced-concepts/filters-in-segmentation "/user-guide/segment/advanced-concepts/filters-in-segmentation") を参照してください。

## In-App

すべての In-App キャンペーンで HTML テンプレートを利用できるようになりました。以下のことが可能です。

- In-App メッセージでポップアップを作成する。
- In-App メッセージにカスタム HTML テンプレートを使用する。
- 音声、動画、画像、アニメーション画像、ユーザー入力、アンケート、カルーセルのキャンペーンを使用する。

<img alt="Screen_Shot_2021-09-01_at_3.39.43_PM.png" src="/images/moengage_374e2f.png" />

詳細については、[HTML templates for In-App campaigns](/ja/user-guide/campaigns-and-channels/in-app-message/templates/html-in-app-templates "/user-guide/campaigns-and-channels/in-app-message/templates/html-in-app-templates") を参照してください。

## SMS、Email、Push キャンペーンのパーソナライズされたプレビュー

送信前に、パーソナライゼーションを適用した状態でキャンペーンをプレビューできるようになりました。ユーザーを選択するだけで、キャンペーンで使用されているすべてのパーソナライゼーション属性を試すことができます。  
パーソナライズされたプレビューは、ユーザー属性、イベント属性、プロダクトセット、Content API など、あらゆる種類のパーソナライゼーションをサポートしています。

<img alt="4f3b8bc0-6035-4b0a-9688-e848fa4a4b24.png" src="/images/moengage_843e19.png" />

詳細については、[Personalized Previews](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/personalized-preview "https://help.moengage.com/hc/en-us/articles/4406091894292-Personalised-Previews") を参照してください。

# 機能強化

## SMS と Email でコンバージョン目標が任意に

いただいたフィードバックに基づき、SMS と Email でコンバージョン目標を任意にしました。Push キャンペーンでは、以前からコンバージョン目標が任意になっていました。

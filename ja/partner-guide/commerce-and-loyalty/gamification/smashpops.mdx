# 概要

[Smashpops](https://www.smashpops.com/) は、非常に中毒性が高くカスタマイズされたゲーミフィケーションポップアップを提供し、アプリや Web サイトを通じて新しいメール購読者を獲得し、顧客基盤を拡大できるようにします。

# MoEngage × Smashpops

MoEngage と Smashpops の統合を使用すると、Web サイトでゲームをプレイした顧客をターゲットにし、メールキャンペーンで特典クーポンを提供できます。また、カスタムセグメントを作成してリターゲティングし、休眠ユーザーを呼び戻すこともできます。Smashpops は、誰かがゲームをプレイするたびに MoEngage のユーザー属性を更新し、イベントも転送するため、Flows を使用してタイムリーにターゲティングできます。

# 統合

<Info>
  - Smashpops アカウントにアクセスできることを確認してください。
  - MoEngage アカウントにアクセスできることを確認してください。
</Info>

## ステップ 1: MoEngage から Data API キーとシークレットを取得する

MoEngage ダッシュボードで、Data API ID と Data API キーを控えておきます。これらの値は、Smashpop で統合を設定する際に必要になります。

<Info>
  Data API ID とキーは、**Settings - \> Account -\> APIs** で確認できます。
</Info>

## ステップ 2: Smashpop で MoEngage の統合を設定する

1. Smashpop ダッシュボードで「[Integrations](https://www.smashpops.com/integrations)」に移動し、「Add integration \> MoEngage」をクリックします。

![](/images/partner_15886353505044.png)

2. 次の値を入力します。

| **フィールド** | **説明** |
| --- | --- |
| Data Center (cluster) | MoEngage のデータクラスターのリージョンです。これはダッシュボードの URL [https://dashboard-0\*\*X\*\*.moengage.com/](https://dashboard-0**X**.moengage.com/) で確認できます。「X」の値 (「1」、「2」、または「3」の数字のみ) を入力します。 |
| App ID | 先ほどコピーした Data API ID です。MoEngage アカウントの Workspace ID は、**Settings - \> Account -\> APIs -\>Workspace ID** で確認できます。MoEngage アカウントの Data API ID と Workspace ID は同じです。 |
| API Key | 先ほどコピーした Data API キーです。MoEngage アカウントの Data API キーは、\*\*Settings - \> Account -\> APIs -\> API keys \*\*\>**Data** API 設定で確認できます。 |

3. この情報を入力したら、「Add account」をクリックすると、MoEngage の統合が追加されます。
4. 次に、SmashPops でポップアップを編集し、「Settings \> Data collection」に移動して「\+ Add integration」をクリックし、MoEngage の統合を選択します。

![MoEngage の設定 3](https://www.smashpops.com/blog/wp-content/uploads/2022/11/moengage-setup3.jpg)

5. そこで「Advanced fields bindings」をクリックし、MoEngage に送信する追加プロパティの変数名を入力します (たとえば、クーポンコードには `spps_last_coupon_code`、クーポン名には `spps_last_coupon_name`)。

![MoEngage の設定 4](https://www.smashpops.com/blog/wp-content/uploads/2022/11/moengage-setup4.jpg)

6. その他の任意のカスタムプロパティを追加することもできます。「\+ Add static field」をクリックし、フィールドの値を入力して、MoEngage に送信するフィールドの名前を選択します。
7. 編集が完了したら、ポップアップを保存します。

## ステップ 3: ゲームがプレイされたときに MoEngage でユーザー属性を確認する

1. Smashpop は、MoEngage アカウントにユーザーを (指定したカスタムプロパティとともに) 作成します。

![](/images/partner_15886684903316.png)

2. これらのカスタム属性を使用して MoEngage でカスタムセグメントを作成し、ターゲットを絞ったキャンペーンを送信します。

![](/images/partner_15886779270804.png)

## ステップ 4: ゲームがプレイされたときにイベントトリガーキャンペーンを作成する

1. Smashpops は、「**SmashPops game played** 」イベントも (指定したカスタムプロパティとともに) 送信します。

![](/images/partner_15886893480212.png)

2. このイベントを使用して、イベントトリガーキャンペーンを送信するか、Flows を使用してオムニチャネルのオーケストレーションを作成します。

![](/images/partner_15886964235412.png)

![MoEngage の設定 7](https://www.smashpops.com/blog/wp-content/uploads/2022/11/moengage-setup7.jpg)

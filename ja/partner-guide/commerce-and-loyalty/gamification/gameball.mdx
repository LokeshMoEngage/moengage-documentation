[Gameball](https://www.gameball.co/) は、インタラクティブなチャレンジやインセンティブを通じてユーザーエンゲージメントとリテンションを高めるように設計された、ゲーミフィケーション、ロイヤルティ、報酬のプラットフォームです。

# MoEngage × Gameball

MoEngage と Gameball の統合により、ユーザー属性とイベントを MoEngage アカウントに直接同期できます。これにより、ロイヤルティデータ、報酬、特定のユーザーアクションに基づいて、パーソナライズされたキャンペーンや自動化されたジャーニーを構築できます。

## ユースケース

Gameball を MoEngage と統合すると、次のことが可能になります。

- **パーソナライゼーションの強化** : 残高、現在のレベル、RFM (Recency、Frequency、Monetary) セグメントなどの Gameball のデータを使用して、最もロイヤルティの高いユーザーに特別オファーを送信するなど、高度にパーソナライズされたキャンペーンを作成します。
- **エンゲージメントの自動化** : _Order Placed_、_Coupon Created_、_Reward Campaign Achieved_ などのリアルタイムの Gameball イベントに基づいて、MoEngage でイベントトリガーキャンペーンを作成します。
- **リテンションの向上** : ユーザーのレベル、ポイント、実績を監視して離脱リスクのあるユーザーを特定し、離脱する前にターゲットを絞ったリテンションキャンペーンで再エンゲージメントを図ります。
- **コンバージョンの向上** : 詳細なユーザー属性と取引データを活用してユーザーを効果的にセグメント化し、購入やその他の価値あるアクションにつながる関連性の高いメッセージを送信します。

## ステップ 1: App Marketplace で Gameball を接続する

Gameball アカウントを MoEngage に接続するには、次の手順を実行します。

1. Gameball のダッシュボードで、**App Store** に移動します。
2. サイドバーメニューで、**Integrations** をクリックします。
3. 利用可能なアプリ統合のリストから、**MoEngage** を見つけます。
4. **MoEngage** タイルで、**\+ Connect** をクリックします。\
   <img src="/images/partner_39723558979860.png" />\
   次のような **MoEngage** ダイアログボックスが表示されます。 <img src="/images/partner_39723550780052.png" />
5. MoEngage の UI で、**Settings** \> **Account** \> **APIs** に移動します。
6. **Workspace ID (earlier app id)** の下にある ID をコピーします。
7. **API keys** セクションで、**Data** タイルの API キーをコピーします。 <img src="/images/partner_39488132756116.png" />
8. Gameball ダッシュボードで、**Workspace ID** ボックスにワークスペース ID (App ID) を、**Data API** **Key** ボックスに Data API キーを入力します。
9. **Data Center** リストで、MoEngage のデータセンターを選択します。
10. **Next** をクリックします。\
    <img src="/images/partner_39748954460692.png" />\
    設定が完了すると、Gameball のデータを使用して MoEngage キャンペーンを強化できるようになります。 <img src="/images/partner_39488132757140.png" />

## MoEngage で Gameball のデータを使用する

Gameball のデータが MoEngage にインポートされたら、そのデータを活用して、よりパーソナライズされた効果的なユーザーエンゲージメント戦略を作成できます。

データの活用方法は次のとおりです。

- **パーソナライズされたキャンペーン** : 名前、メール、誕生日、購入履歴などのユーザー属性を使用して、高度にパーソナライズされたマーケティングキャンペーンを作成します。たとえば、特別割引付きの誕生日のあいさつを送信したり、過去の購入に基づいて商品をレコメンドしたりできます。
- **セグメンテーション** : 同期されたセグメントとタグを活用して、行動、好み、アクティビティに基づいてユーザーをグループ化します。これにより、特定のグループに合わせたメッセージでターゲティングでき、コミュニケーションの関連性と効果が高まります。
- **イベントトリガーキャンペーン** : 注文、クーポンの作成、クーポンの使用などの特定のイベントによってトリガーされる自動キャンペーンを設定します。たとえば、ユーザーが注文したときに報酬付きのお礼メールを送信したり、新しいクーポンについて通知したりできます。
- **ユーザージャーニーのマッピング:** インポートしたデータを使用してユーザージャーニーをトラッキングおよび分析し、主要なタッチポイントを特定してエンゲージメント戦略を最適化します。さまざまな段階でユーザーがブランドとどのように関わっているかを理解することで、効果的でタイムリーな施策を立案できます。
- **リテンション戦略** : ポイント残高、レベルの進捗状況、実績を監視して、ロイヤルティの高いユーザーと離脱リスクのあるユーザーを特定します。ロイヤルティの高いユーザーに報酬を提供し、非アクティブの兆候を示すユーザーに再エンゲージメントを図るターゲットキャンペーンを作成します。

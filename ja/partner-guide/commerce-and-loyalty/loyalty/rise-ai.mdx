# はじめに

[Rise.ai](https://rise.ai/) Gift Cards & Loyalty は、e コマースブランドの収益拡大と顧客維持率の向上を支援する強力なアプリです。

# MoEngage × Rise.ai

MoEngage と Rise.ai の連携により、顧客のロイヤルティ情報や紹介リンクを MoEngage キャンペーン内に動的に表示して、コンバージョンを高めることができます。

# 連携

<Info>
  **前提条件**

  - Rise.ai の API を使用するには、Rise.ai の[アクセストークン](https://api.rise.ai/)が必要です。
</Info>

## MoEngage キャンペーンで顧客のロイヤルティカードを表示する

MoEngage の Content API を使用すると、MoEngage キャンペーン内に顧客のロイヤルティカードを動的に取得して、よりパーソナライズされたエクスペリエンスを提供できます。

### ステップ 1: MoEngage Content API を設定する

MoEngage ダッシュボードにログインし、次の手順を実行します: aaa

1. **Settings** -\> **Advanced settings** -\> **Content API** に移動します。Content API 画面の右上にある **\+ Add content API** をクリックします。 <img src="/images/partner_21980717916564.png" alt="ContentAPI_Navogation.png" />
2. エンドポイント URL に Rise.ai API を追加します。ユースケースに応じてエンドポイントは異なります。
   <img src="/images/partner_19963938508564.png" />

顧客のロイヤルティカード情報を表示するには、Rise.ai の [Get Customer Loyalty Card](https://api.rise.ai/) を使用します。

Content API の設定時に、次の URL を挿入します。

[https://application.rise-ai.com/v2/gift-cards/?customer\_id=&#123;&#123;UserAttribute\['customer\_id'\]&#125;&#125;&shop\_url=amazingshop.myshopify.com](https://application.rise-ai.com/v2/gift-cards/?customer_id=&#123;&#123;UserAttribute['customer_id']&#125;&#125;&shop_url=amazingshop.myshopify.com)

Headers に次を追加します。

1. `x-rise-access-token`: Rise.ai の API アクセストークンを入力します。
2. `Accept`: `application/json`
3. 正常なレスポンスが表示されたら、**Save** をクリックしてから **Done** をクリックします。

<Note>
  API をテストすることもできます。API をテストするには、Content API のアクションメニューから「Test」をクリックします。API のレスポンスをテストして検証できます。
</Note>

### ステップ 2: MoEngage キャンペーン内に顧客のロイヤルティカード情報を表示する

MoEngage キャンペーンでこの API を使用するには、次の手順を実行します。

1. キャンペーン作成のステップ 2 で、@ を入力します。
2. ポップアップで、ステップ 1 で設定した Rise.ai の Content API を選択できます。
3. [MoEngage Templating Language](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/jinja-templating-language#content-api) を使用して API レスポンスを解析し、そのコンテンツをキャンペーンで使用できます。
   <img src="/images/partner_19965260285332.png" />
4. Preview タブをクリックすると、リアルタイムでパーソナライズされたキャンペーンを確認できます。
   <img src="/images/partner_19965235942676.png" />
5. 準備ができたら、Publish をクリックしてキャンペーンを送信します。

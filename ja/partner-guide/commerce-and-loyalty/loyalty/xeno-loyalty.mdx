[Xeno](https://ai.xeno.in/search) は、小売ブランドや D2C ブランドがパーソナライズされた顧客体験を構築できるよう設計された、自律型の AI 搭載小売 CRM およびロイヤルティ管理プラットフォームです。階層型ロイヤルティプログラムの管理、ポイントの追跡、顧客の取引行動の把握のためのツールを提供します。

# MoEngage X Xeno

この連携により、Xeno Loyalty から MoEngage へのリアルタイムのアウトバウンドデータフローが実現し、重要なロイヤルティイベントと注文イベントをリアルタイムで同期できます。Xeno を MoEngage に接続すると、ロイヤルティデータをトリガーとして使用し、ターゲットを絞ったリテンション、報酬、エンゲージメントのキャンペーンを展開できます。

<Info>
  Xeno Loyalty 連携は Xeno によって構築および保守されています。カスタマイズのリクエストや Xeno コネクターの動作に固有の問題については、Xeno サポートに直接お問い合わせください。
</Info>

## ユースケース

Xeno Loyalty を MoEngage と連携すると、次のユースケースに対応できます。

- **ロイヤルティ階層アップグレードのお祝い:** Tier Upgrade イベントが発生したときに、MoEngage でお祝いのオムニチャネルキャンペーンを自動的にトリガーします。
- **ポイント交換のリマインダー:** Earn Points イベントと Redeem Points イベントを使用して残高の多い顧客を特定し、有効期限前に報酬を交換するようリマインドします。
- **購入後のエンゲージメントループ:** New Order イベントを受信した後、顧客を MoEngage の購入後ジャーニーに移行させます。
- **返品時のウィンバックキャンペーン:** Xeno から Return Order イベントが送信されたときに、専用のリテンションキャンペーンをトリガーします。

## 主な機能

Xeno Loyalty 連携により、MoEngage 内で次の主要機能を利用できます。

- **注文の追跡:** New Order イベントと Return Order イベントを取得して、顧客を購入後ジャーニーに登録したり、ウィンバックキャンペーンを開始したりします。
- **ポイント管理:** Earn Points イベントと Redeem Points イベントに対して、リアルタイムの残高更新や動機付けのナッジで対応します。
- **階層の進行:** Tier Upgrade イベントを自動キャンペーンでお祝いしたり、Tier Downgrade イベントに再エンゲージメントのフローで対応したりします。
- **精密なセグメンテーション:** Xeno のライブイベントデータを使用して、「最近ポイントを獲得したユーザー」や「VIP」などの動的なコホートを構築します。
- **パフォーマンスのアトリビューション:** MoEngage のコンバージョン分析と Xeno のイベントを関連付けて、収益への直接的な影響を測定します。

## サポートされている同期タイプとイベント

次の表は、Xeno Loyalty から同期されるデータモデルとリアルタイムの行動イベントの概要を示しています。

| 同期タイプ | 同期される内容 |
| --- | --- |
| **イベント** | ロイヤルティと注文に関する行動イベントが MoEngage ユーザープロファイルに記録されます。各イベントには、獲得ポイント、交換ポイント、注文額、階層名などのコンテキスト属性が含まれます。 |

MoEngage にリアルタイムで送信される、サポートされているイベントのマッピング:

| イベント名 | 説明 | MoEngage での推奨される使用方法 |
| --- | --- | --- |
| **New Order** | Xeno で購入注文が完了したときにトリガーされます。 | 購入後ジャーニーやポイントの確認をトリガーします。 |
| **Return Order** | 顧客が返品を開始または完了したときにトリガーされます。 | ウィンバックキャンペーンやリテンションオファーを開始します。 |
| **Earn Points** | 顧客がロイヤルティポイントを獲得したときにトリガーされます。 | リアルタイムの残高更新や進捗のナッジを送信します。 |
| **Redeem Points** | 顧客がロイヤルティポイントを交換したときにトリガーされます。 | 交換を確認し、次回購入のアイテムを提案します。 |
| **Tier Upgrade** | 顧客がロイヤルティ階層を上がったときにトリガーされます。 | 限定特典やオムニチャネルキャンペーンでお祝いします。 |
| **Tier Downgrade** | 顧客が下位の階層に下がったときにトリガーされます。 | 階層ステータスを回復するための再エンゲージメントフローをトリガーします。 |

# 連携

<Info>
  **前提条件**

  連携アクセスが有効になっている、アクティブな Xeno Loyalty アカウント。
</Info>

## ステップ 1: MoEngage の認証情報とエンドポイントを取得する

MoEngage ワークスペースから必要な認証情報を取得するには、次の手順を実行します。

1. **MoEngage** UI にサインインします。
2. 左側のナビゲーションペインで、**Settings** > **Account** > **APIs** に移動します。
3. 次の認証情報を見つけてコピーします。
   - **Workspace ID:** **Workspace ID** セクションにある一意の識別子です。
   - **Data API Key:** **API Keys** ブロックにあるセキュリティトークンです。

## ステップ 2: 専用の MoEngage エンドポイントを取得する

リアルタイムのデータストリーミングを設定するには、カスタムエンドポイントをリクエストします。

1. **MoEngage サポート**チームに連絡し、Xeno Loyalty 連携用の専用 Webhook エンドポイント URL をリクエストします。
2. コピーした **Workspace ID** と、使用中の**データセンター**リージョン（例: DC-01、DC-02）を共有します。

<Info>
  エンドポイント URL はデータセンターごとに異なります。
</Info>

## ステップ 3: Xeno で MoEngage 接続を設定する

エンドポイント URL と認証情報を取得したら、Xeno 内で接続を設定します。

1. Xeno アカウントで、左側のナビゲーションペインにある **Tools** > **Webhooks** セクションに移動します。

   ![Xeno の Tools Webhooks セクション](/images/xeno-loyalty-webhooks.png)
2. **+ Add Webhook** をクリックして設定パネルを開きます。
3. Webhook のフィールドに次の詳細を入力します。

   | フィールド | 値 |
   | --- | --- |
   | **Name Your Webhook** | 一意の識別名を入力します（例: `Moengage_{{Workspace}}`）。 |
   | **Endpoint URL** | MoEngage サポートから提供された専用 URL を入力します。 |
   | **Authorization** | ドロップダウンリストから **Authorization** を選択します。オンラインの Basic Auth Header Generator ツールを使用し、**Workspace ID** をユーザー名、**Data API Key** をパスワードとして Basic 認証トークンを生成します。 |

4. **Events** チェックリストで、MoEngage ワークスペースに同期する特定のイベントを選択します。

   ![Xeno Webhook の Events チェックリスト](/images/xeno-loyalty-events.png)
5. **Save Webhook** をクリックして連携を有効にします。

   ![Xeno の Save Webhook ボタン](/images/xeno-loyalty-save-webhook.png)

## ステップ 4: MoEngage でイベントを確認する

イベントがワークスペースに正常に届いていることを確認するには、次の手順を実行します。

1. MoEngage UI で、**Segment** > **Search Users** に移動します。
2. **電話番号**でテストユーザーを検索します。
3. ロイヤルティポイントや階層名など、想定どおりの属性を持つユーザープロファイルのレコードが表示されることを確認します。

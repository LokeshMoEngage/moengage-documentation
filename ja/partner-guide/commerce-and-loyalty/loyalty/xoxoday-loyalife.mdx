[Xoxoday Loyalife](https://help-loyalife.xoxoday.com) は、ブランドがロイヤルティプログラムを設計、実行、拡大できるよう設計されたエンタープライズ向けロイヤルティ管理プラットフォームです。このプラットフォームは、さまざまな業界にわたって、ポイントの付与、階層構造、交換、会員エンゲージメントを管理します。

# MoEngage \<\> Xoxoday Loyalife

Xoxoday Loyalife 連携は、ロイヤルティプログラムのデータを MoEngage と橋渡しします。この接続により、マーケティングチームは、ポイントの獲得、階層のアップグレード、ポイントの有効期限切れ間近など、特定のロイヤルティのマイルストーンに基づいて、ターゲットを絞ったプッシュ、メール、SMS キャンペーンをトリガーできます。

Loyalife は、夜間の自動処理によってロイヤルティイベントと会員プロファイル属性を MoEngage に同期します。データが MoEngage で利用可能になると、階層、ポイント残高、アクティビティ指標で会員をセグメント化し、クロスチャネルのエンゲージメントを促進できます。

<Info>
  Xoxoday Loyalife 連携は Xoxoday によって構築および保守されています。設定のリクエストや連携の動作に固有の問題については、Loyalife サポートチーム（support@xoxoday.com）にお問い合わせください。
</Info>

## ユースケース

Xoxoday Loyalife を MoEngage に接続すると、オーディエンスデータを同期して次のユースケースに対応できます。

- **報酬の瞬間:** `loyalty_points_earned` イベントを追跡して、会員がポイントを獲得した直後に通知をトリガーし、すぐに交換するよう促します。
- **階層マイルストーンキャンペーン:** ユーザーが `loyalty_tier_upgraded` イベントをトリガーしたときに、お祝いのメッセージと新しい特典の概要を自動で送信します。
- **有効期限のナッジ:** ポイント有効期限予測属性 `points_expiring_30d` を使用して、ポイントが失効する前にタイムリーなリマインダーを送信します。
- **ウィンバックフロー:** `days_since_last_activity` ユーザー属性を使用して休眠会員をセグメント化し、最近取引のないユーザーを再エンゲージします。
- **セグメントベースのターゲティング:** カスタムタグ同期を使用して、特定の Loyalife セグメントに出入りするユーザーを動的にターゲティングします。

## 主な機能

Xoxoday Loyalife 連携により、MoEngage 内で次の主要機能を利用できます。

- **毎日の同期:** 毎晩午前 0 時に、Loyalife は取引イベントと更新されたプロファイルデータを MoEngage に送信する自動同期を実行します。
- **ユーザープロファイルの更新:** 現在のポイント残高、登録の詳細、有効期限の予測で会員プロファイルを更新し、セグメントの正確性を保ちます。

## サポートされているデータタイプ

次の表は、Xoxoday Loyalife からの毎日の同期スキーマの概要を示しています。

| データタイプ | 同期される内容 | 頻度 |
| --- | --- | --- |
| **ロイヤルティイベント** | イベント名、会員識別子、ポイント、獲得タイプ、取引の詳細。 | 夜間同期（1 日のアクティビティ） |
| **会員属性** | ポイント残高、階層レベル、アカウントステータス、登録日、アクティビティ指標、有効期限の予測。 | 夜間の完全更新 |

# 連携

<Info>
  **前提条件**

  この連携を設定する前に、次のものがあることを確認してください。

  - 管理者アクセス権を持つ、アクティブな Xoxoday Loyalife アカウント。
  - Loyalife の Relation Reference と一致する Customer ID を持つ、MoEngage 内の既存のユーザーレコード。
  - **MoEngage API の認証情報**: Workspace ID（App ID）、Data API Key、リージョンのダッシュボード URL。
</Info>

## ステップ 1: Loyalife で接続を設定する

Loyalife 管理ポータルからデータフローを設定するには、次の手順を実行します。

1. **Loyalife** 管理ポータルにサインインします。
2. 左側のナビゲーションメニューで、**Program Settings** > **Integration** をクリックします。

   ![Loyalife の Program Settings Integration ページ](/images/xoxoday-loyalife-integration.png)
3. 連携カタログで **MoEngage Integration** セクションを見つけ、トグルをオンにして設定を開きます。
4. 連携パラメーターを入力します。

   | フィールド | 説明 |
   | --- | --- |
   | **App ID** | MoEngage の Workspace ID。 |
   | **API Key** | MoEngage の Data API Key。 |
   | **Dashboard URL** | リージョンのダッシュボード API URL（例: `https://dashboard-01.moengage.com`）。 |
5. **Save** をクリックします。

   ![Loyalife の MoEngage 連携設定が保存された状態](/images/xoxoday-loyalife-save.png)

<Warning>
  **セキュリティに関する警告:** MoEngage の認証情報は機密情報として扱ってください。公開の場で共有しないでください。Data API Key が漏洩した場合は、MoEngage でキーをローテーションし、直ちに Loyalife の設定を更新してください。
</Warning>

## ステップ 2: MoEngage でデータを確認する

最初の夜間同期（午前 0 時以降）の後、MoEngage でデータを確認するには、次の手順を実行します。

1. **オーディエンス:** **Audience** > **Users** に移動し、`tier` や `points_available` などの属性がプロファイルに表示されていることを確認します。
2. **イベント:** **Analyse** > **Events** に移動し、`loyalty_points_earned` などのイベントを受信していることを確認します。

## ステップ 3: MoEngage でキャンペーンを作成する

MoEngage でキャンペーンを作成するには、次の手順を実行します。

1. **Engage** > **Campaigns** > **+ Create campaign** に移動します。
2. チャネル（**Push**、**Email**、または **SMS**）を選択します。
3. **セグメント:** ロイヤルティ属性（例: `member_lifecycle_stage`）を使用してオーディエンスを定義します。
4. **トリガー:** リアルタイムで対応するには、**Event-triggered delivery** を選択し、ロイヤルティイベント（例: `loyalty_tier_upgraded`）を選択します。詳細については、[こちら](https://help-loyalife.xoxoday.com/user-guides/configuration/moengage)を参照してください。

## トラブルシューティング

| 問題 | 考えられる原因 | 解決策 |
| --- | --- | --- |
| データが表示されない。 | リージョンのエンドポイントの不一致。 | Dashboard URL が MoEngage のリージョンと一致していることを確認してください。リージョンが一致しないと、API がエラーを表示せずに失敗します。 |
| イベントが欠落している。 | ID マッピングの失敗。 | Loyalife の会員の Relation Reference が MoEngage の Customer ID と完全に一致していることを確認してください。一致するものが見つからない場合、MoEngage はデータを破棄します。 |
| 同期が予期せず停止する。 | API キーのローテーション。 | MoEngage の API キーをローテーションした場合は、同期の中断を防ぐために、直ちに Loyalife の Integration 設定でキーを更新する必要があります。 |

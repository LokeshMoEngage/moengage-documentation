[Nector](https://www.nector.io/) は、企業が顧客のリテンションとエンゲージメントを高めるのに役立つ、顧客ロイヤルティおよび報酬のプラットフォームです。販売事業者は、ウォレットコイン、クーポン、紹介ボーナスで顧客に報酬を付与できるほか、顧客レビューを収集および管理することもできます。  
  
## MoEngage × Nector

Nector と MoEngage の統合により、企業は Nector のロイヤルティデータを活用して、MoEngage でタイムリーかつパーソナライズされた自動化を直接トリガーできます。これらのプラットフォームを接続することで、ロイヤルティイベント (ポイントの獲得、クーポンの利用、レビューの投稿など) が手動操作なしで顧客エンゲージメントにつながるようになります。この統合により、次のことが可能になります。

  - Nector から MoEngage にリアルタイムでロイヤルティイベントを送信する。
  - Nector のアクティビティに基づいて、MoEngage で自動化されたメールまたはプッシュ通知のワークフローをトリガーする。
  - マーケティングオートメーションプラットフォーム内で、顧客のロイヤルティ行動を一元的に把握する。

## ユースケース

MoEngage を Nector と統合すると、次のユースケースに対応できます。

  - **報酬の通知** : Nector で顧客にウォレットコインが付与されるたびに、MoEngage を通じてメールまたはプッシュ通知を自動的にトリガーします。
  - **クーポンの配信** : 顧客が Nector でコインを利用したときに、MoEngage のワークフローを通じて割引コードやクーポンを即座に送信します。
  - **紹介の最新情報** : 紹介が成功したときや紹介ボーナスを獲得したときに顧客に通知します。

# 統合

<Info>
設定を開始する前に、次のものが揃っていることを確認してください。

  - 有効な Nector UI アカウント。
  - MoEngage UI へのアクセス権。
  - MoEngage の App ID、Data API キー、サーバープレフィックス。
</Info>

## ステップ 1: Nector で統合を見つける

設定を開始するには、Nector UI で MoEngage を見つける必要があります。Nector で統合を見つけるには、次の手順を実行します。

  1. Nector UI にログインします。
  2. サイドバーで **[Integrations](https://merchant.nector.io/integration-list)** をクリックします。
  3. **Email & WhatsApp Marketing** をクリックします。 ![](/images/partner_43964249403924.png)
  4. **Configure** をクリックします。   
MoEngage の統合ページが表示されます。

## ステップ 2: MoEngage から API キーを取得する

MoEngage から API キーを取得するには、次の手順を実行します。

  1. MoEngage の UI で、**Settings** > **Account** > **APIs** に移動します。
  2. **Workspace ID (earlier app id)** の下にある ID をコピーします。
  3. Nector ダッシュボードで、**App Id** ボックスに Workspace ID (以前の App ID) を貼り付けます。
  4. **Public API Key** ボックスにも、再度 Workspace ID (以前の App ID) を貼り付けます。
  5. 次に、MoEngage の UI で、**API Keys** の下にある **Data API Key** をコピーします。 ![](/images/partner_43967128905620.png)
  6. Nector UI で、**Private API Key** ボックスに Data API キーを貼り付けます。
  7. **Server Prefix** リストで、MoEngage のサーバープレフィックス (例: api-01) を選択します。  
**注** : すべての情報が正しく入力されていることを確認してください。詳細が不足していたり誤っていたりすると、統合は失敗します。
  8. **Initialize** をクリックします。 ![](/images/partner_43964290031252.png)

## ステップ 3: サーバープレフィックスを設定して初期化する

サーバープレフィックスを設定するには、次の手順を実行します。

  1. MoEngage UI の URL を確認します。
  2. URL に基づいて、Nector でサーバープレフィックスを選択します。 
     - URL が dashboard-01.moengage.com で始まる場合 → api-01 を選択します。
     - URL が dashboard-02.moengage.com で始まる場合 → api-02 を選択します。
  3. **Choose Common Property** で、**Email** を選択します。   
これにより、Nector はイベントを MoEngage の正しいユーザープロファイルにマッピングします。
  4. **Initialize** をクリックして統合を有効にします。 ![](/images/partner_43964964785300.png)

## ステップ 4: MoEngage にイベントを送信する

特定のアクションが発生したときに MoEngage にイベントを送信するように Nector を設定できます。たとえば、顧客にウォレットコインが付与されたときに Nector が MoEngage にイベントを送信し、それによって顧客にメールを送信する自動化をトリガーできます。

新しいイベントを追加するには、次の手順を実行します。

  1. MoEngage の統合ページで、**Events** タブをクリックします。
  2. **Create An Event** をクリックします (または **+** ボタンをクリックします)。
  3. **Send Events** タブで、外部統合に通知するイベントを選択します。  
**注** : Nector は多くのイベントをサポートしています。一般的で関連性の高いイベントは次の 2 つです。 
     - **Wallet Coins Rewarded** : Nector でウォレットコインが付与されるたびに送信されます。
     - **Coupon Is Created** : 顧客が Nector でウォレットコインを割引またはクーポンコードに交換するたびに送信されます。

Wallet Coins Rewarded イベントを設定するには、次の手順を実行します。

  1. **Event** リストで、**Wallet Coins Rewarded** をクリックします。
  2. **Event Sent to** リストで、MoEngage をクリックします (これはデフォルトの選択です)。
  3. **Create** をクリックします。  
![](/images/partner_43966341419412.png)  
![](/images/partner_43966341421076.png)  
イベントが作成され、**Events** リストに表示されます。

## ステップ 5: 統合をテストする

統合とイベントの利用可否をテストするには、次の手順を実行します。

  1. Events ページで、作成したイベントの **Send Test Event** をクリックします。
  2. **Send Test Event** ダイアログボックスで、**Search customer via** リストで email が選択されていることを確認します。
  3. **Email id of customer to whom event has to be sent** ボックスに、顧客の有効なメールアドレスを入力します。  
**注** : メールアドレスは、ストアの顧客データベースに存在する顧客に関連付けられている必要があります。
  4. **Send Test Event** をクリックしてイベントをトリガーします。
  5. MoEngage の UI を確認して、イベントが受信されたことを確認します。 ![](/images/partner_43966001101716.png)  
  
<Info>
新規顧客の紹介、コインの有効期限の通知、レビューのリクエストなど、その他のアクティビティのイベントを送信することもできます。これらのイベントの設定については、[Event Details Sent to External Integrations](https://help.nector.io/en/article/event-details-sent-to-external-integrations-frcz1t/?bust=1715669995873) を参照してください。
</Info>

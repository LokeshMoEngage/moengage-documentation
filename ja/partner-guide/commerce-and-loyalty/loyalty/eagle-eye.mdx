# 概要

[Eagle Eye](https://eagleeye.com/) は、リアルタイム、オムニチャネル、パーソナライズされた消費者向けマーケティング活動を支えることで、小売、旅行、ホスピタリティのブランドがエンドカスタマーのロイヤルティを獲得できるようにする、大手 SaaS 企業です。

# MoEngage × Eagle Eye

MoEngage と Eagle Eye の統合により、Content API を通じてウォレットやその他のロイヤルティの詳細を MoEngage キャンペーンで使用し、マーケティング施策のキャンペーンを拡大できます。

以下の例では、次のシナリオを実装します。

1. ウォレットポイント、クーポン、サブスクリプションの有効期限の詳細を追加して、顧客向けのメールキャンペーンをパーソナライズします。
2. すでにウォレットポイントを保有しているものの、過去数か月間買い物をしていない顧客をストアに呼び戻します。

# 統合

<Info>
  **前提条件**

  - Eagle Eye アカウントにアクセスできることを確認してください。
</Info>

## ステップ 1: MoEngage ContentAPI を設定する

MoEngage アカウントで、Settings → Advanced Setting Content API に移動します。

1. _\+ Add Content API_ をクリックします。
2. Eagle Eye API の詳細を入力します。
   ![Screenshot 2024-11-14 at 6.09.45 PM.png](/images/partner_32132212140436.png)
   - **API Name:** Content API エンドポイントの名前です。「Eagle Eye wallet」など、キャンペーンのコンテンツ作成時に呼び出しやすい任意の名前を入力できます。
   - **Method:**_Get_
   - **URL:** EagleEye のウォレットエンドポイントのアドレス `https://api.eagleeyenetworks.com/wallet?identity-value= ` を入力します。
   - **Parameter:** MoEngage と Eagle Eye の間で共通の user\_identifier を入力します。一意の customer\_id、メール ID、または携帯電話番号を使用できます。
   - **Headers:**
     - **X-EES-AUTH-CLIENT-ID:** オンボーディングマネージャーから共有された値をそのまま入力します。
     - **X-EES-AUTH-HASH:** この値はリクエストごとに計算する必要があります。この値は、複数の値を連結して文字列を生成し、その文字列を SHA256 アルゴリズムでハッシュ化することで計算されます。このハッシュ値は、AIR と統合するプラットフォームが API リクエストごとに生成する必要があります。\
       詳細については、[Eagle Eye のドキュメント](https://developer.eagleeye.com/docs/api-authentication)を参照してください。
3. Save をクリックします。テストすることもできます。 <img src="/images/partner_32132212147860.png" alt="Screenshot 2024-11-14 at 6.18.42 PM.png" />

## ステップ 2: MoEngage キャンペーンで Content API エンドポイントを使用する

任意のキャンペーンを作成します。

1. キャンペーン作成のステップ 2 で、@ を入力します。
2. ポップアップで、ステップ 1 で設定した「Eagle Eye Wallet」Content API を選択できます。
   ![Screenshot 2024-11-14 at 6.21.01 PM.png](/images/partner_32132212149908.png)
3. [MoEngage テンプレート言語](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/jinja-templating-language)を使用して API レスポンスを解析し、そのコンテンツをキャンペーンで使用できます。\
   注 - Preview タブをクリックすると、リアルタイムのパーソナライゼーションでキャンペーンを確認できます。
4. 結果に問題がなければ、キャンペーンを公開できます。

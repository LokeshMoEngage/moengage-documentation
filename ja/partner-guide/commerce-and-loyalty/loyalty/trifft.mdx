# はじめに

[TRIFFT](https://www.trifft.io/) は、すぐに導入できるツールキットにより、小売業者にエンタープライズグレードのロイヤルティを提供します。数週間以内に最新のロイヤルティクラブソリューションを立ち上げることができるオールインワンソリューションです。

# MoEngage × Trifft

TRIFFT は、会員を惹きつけて維持するためのロイヤルティ要素を顧客が持てるよう支援するロイヤルティ CRM ソフトウェアです。MoEngage と Trifft の連携により、次のことが可能になります。

- 会員がアプリでアクションを実行したときに、その会員にクーポンコードを割り当てる

# 連携

<Info>
  **前提条件**

  - Trifft の REST API を使用するには、Trifft の API トークンを把握している必要があります。
</Info>

## MoEngage 経由で会員にクーポンコードを割り当てる

MoEngage のコネクターキャンペーンを使用すると、ユーザーがアプリや Web サイトで何らかのアクションを実行したときに Trifft に API 呼び出しを送信し、ユーザーにクーポンコードを割り当てることができます。

MoEngage でコネクターキャンペーンを作成するには、次の手順を実行します。

1. Create Campaign \>\> Connectors \>\> Custom に移動し、ニーズに最も適した配信タイプを選択します。この例では、「Event Triggered」を選択し、イベントとして「Purchased」を選択します。 <img src="/images/partner_20904973731348.png" />
2. キャンペーンのステップ 2 で、次の操作を行います。

### Trifft API を呼び出す

会員にクーポンを割り当てるには、`POST` メソッドを使用してペイロードを設定します。

- メソッドとして POST を選択します
- Headers
  - `Authorization`: ここに API トークンを追加する必要があります: `Bearer <your_api_token>`
  - `Content-Type`: `application/json`
- Webhook URL としてエンドポイントを追加します: `https://api.trifft.io/v1/member/{{ UserAttribute['Email (Standard)'] } }/coupon/<coupon_id>/assign` - \<coupon\_id\> を割り当てるクーポンの ID に置き換えます。
- Body:\
  Body は空のままでかまいません。

```json
// leave it blank
```

![](/images/partner_20904973731860.png)

- 詳細については、[Trift API ドキュメント](https://docs.trifft.io/reference/assign-a-coupon-to-a-member)を参照してください。
- このステップでキャンペーンをテストできます。
- 準備ができたら、このキャンペーンを公開できます。

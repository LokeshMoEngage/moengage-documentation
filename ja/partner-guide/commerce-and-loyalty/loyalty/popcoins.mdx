# はじめに

[POPcoins](https://mypop.in/) は、POPcoins パートナーの Web サイトでショッピングする際に、限定オファーや割引を利用できる通貨です。

# MoEngage × POPcoins

MoEngage と POPcoins の連携により、次のことが可能になります。

1. ログイン、購入、クレジット追加などのライフサイクルイベントを MoEngage に送信する
2. MoEngage 上で顧客の名前、メールアドレス、携帯電話番号の情報を更新するとともに、コイン残高や獲得コインなどのロイヤルティ情報を更新する

# 連携

<Info>
  **前提条件**

  - POPclub ダッシュボードへのアクセス権が必要です。
</Info>

ユーザーのロイヤルティ情報とイベントアクティビティの送信を開始するには、次の手順を実行します。

1. POPclub ダッシュボードで、_Integrations >> MoEngage_ に移動します。

![](/images/partner_26153079888532.png)

2. 次の情報を入力します。

| **フィールド** | **説明** |
| --- | --- |
| Status | 「Inactive」をクリックしてステータスを有効にします。 |
| Primary Selector | MoEngage 上でユーザーを照合するための顧客識別子を選択します。携帯電話番号またはメールアドレスのいずれかを指定できます。POPcoins は MoEngage の顧客 ID に基づいてユーザーの照合を試みることに注意してください。 |
| API Key | MoEngage アカウントの Data API キーは、**Settings -> Account -> APIs -> API keys** > **Data** API 設定で確認できます。 |
| Workspace ID | MoEngage アカウントの Workspace ID は、**Settings -> Account -> APIs -> Workspace ID** で確認できます。 |
| Data Center ID | MoEngage ダッシュボードの URL に基づいて Data Center ID を選択します。[詳細はこちら](/ja/user-guide/data/key-concepts/data-centers-in-moengage)。|

3. MoEngage に送信する指標をトグルで有効にします。

![](/images/partner_26153049998868.png)

4. MoEngage に転送するイベントをトグルで有効にします。

![](/images/partner_26153050014228.png)

5. 「Update configuration」をクリックして連携を保存します。

## POPcoins によって転送されるイベント

| **イベント** | **説明** |
| --- | --- |
| Credit Pending | コインが保留状態です。 |
| Credit Added | コインがユーザーのアカウントに追加されました。 |
| Credit Refund | コインがアカウントに払い戻されました。 |
| Debit Purchased | コインがアカウントから引き落とされました。 |
| Credit Cancelled | コインのクレジットがキャンセルされました。 |
| Popcoins Login | アカウントにログインしました。 |
| Popcoins Signup | サインアップしました。 |

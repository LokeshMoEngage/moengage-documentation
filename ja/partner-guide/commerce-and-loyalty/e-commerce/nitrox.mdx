[NitroX](https://x.nitrocommerce.ai) は、識別済みのユーザーデータと行動イベントを取得して構造化するように設計されたコマースプラットフォームです。NitroX を MoEngage に接続すると、ユーザープロファイルとサポートされている Web サイトのイベントを自動的にエクスポートして、パーソナライズされたマーケティングキャンペーンや行動セグメントを作成できます。

# MoEngage X NitroX

この統合により、NitroX から MoEngage へのリアルタイムのアウトバウンドデータフローが可能になります。NitroX を MoEngage に接続すると、行動データのトリガーを使用して、ターゲットを絞ったリテンション、リカバリー、エンゲージメントのキャンペーンをオーケストレーションできます。

<Info>
  NitroX の統合は Nitro によって構築および保守されています。カスタマイズのリクエストや NitroX コネクタの動作に固有の問題については、Nitro サポートに直接お問い合わせください。
</Info>

## ユースケース

NitroX を MoEngage に接続すると、オーディエンスデータを同期して次のユースケースに対応できます。

- **カゴ落ちのリカバリー:** トラッキングされた `nitro_addtocart` および `nitro_checkout` イベントを使用して、購入を完了しなかったユーザーに対して MoEngage のメールまたはプッシュのシーケンスを自動的にトリガーできます。
- **購入後のエンゲージメント:** `nitro_orders/paid` や `nitro_orders/fulfilled` などのイベントペイロードを使用して、注文確認メッセージを自動化し、クロスセルキャンペーンをトリガーできます。
- **ターゲットを絞った商品レコメンデーション:** `nitro_product_view` および `nitro_category_view` のデータを使用して、閲覧行動に基づいてユーザーをセグメント化し、関連する商品オファーを送信できます。
- **オーディエンスの自動セグメンテーション:** 値が `Nitro` の `created_by` ユーザー属性を使用して、NitroX によって生成されたユーザーを MoEngage で識別し、限定プロモーションのターゲティングに活用できます。

## 主な機能

NitroX の統合により、MoEngage で次の主要な機能を利用できます。

- **リアルタイムのイベント同期:** 商品の閲覧、カートへの追加、チェックアウトの進行などの Web サイトのイベントをリアルタイムで同期できます。
- **ユーザープロファイルのエクスポート:** 識別済みのユーザープロファイルをエクスポートし、Nitro 固有のユーザープロパティをトラッキングして、精度の高いオーディエンスセグメントを作成できます。
- **注文ライフサイクルのトラッキング:** 注文ライフサイクルの同期を自動化し、注文の作成、更新、支払い、フルフィルメントの各時点で注文を取得できます。

## サポートされているイベント

以下の表は、NitroX から同期されるリアルタイムの行動イベントの概要です。

NitroX から MoEngage にエクスポートされるすべての行動イベントには、`nitro_` というプレフィックスが付きます (例: `nitro_view` や `nitro_addtocart`)。

| イベント名 | 説明 |
| --- | --- |
| **page_view** | ユーザーが Web ページを閲覧しました。 |
| **product_view** | ユーザーが商品詳細ページを閲覧しました。 |
| **addtocart** | ユーザーがショッピングカートに商品を追加しました。 |
| **removefromcart** | ユーザーがショッピングカートから商品を削除したか、カートを空にしました。 |
| **checkout** | ユーザーがチェックアウトプロセスを開始しました。 |
| **orders/create** | ユーザーが注文を作成しました。 |
| **orders/paid** | ユーザーが注文の支払いを完了しました。 |
| **orders/updated** | 既存の注文のステータスまたは詳細が変更されました。 |
| **orders/fulfilled** | 注文が発送または配達されました。 |
| **is_consented** | ユーザーがマーケティングコミュニケーションに明示的に同意しました。 |
| **otp_verified** | ユーザーがワンタイムパスワード (OTP) の認証に成功しました。 |

# 統合

<Info>
  **前提条件**

  この統合を設定する前に、MoEngage アカウントから次の認証情報を取得していることを確認してください。

  - **Workspace ID (以前の App ID):** MoEngage ワークスペースの一意の識別子です。
  - **API Key:** API リクエストの認証に使用するキーです。
</Info>

## ステップ 1: MoEngage で認証情報を確認する

認証情報を確認するには、次の手順を実行します。

1. MoEngage の UI で、**Settings** > **Account** > **APIs** に移動します。
2. **Workspace ID (earlier app id)** の下にある ID をコピーします。
3. **API keys** セクションで、**Data** タイルの API キーをコピーします。

   ![Workspace ID と Data API キーが表示された MoEngage の APIs 設定](/images/nitrox-moengage-api-keys.png)

## ステップ 2: NitroX で接続を設定する

NitroX で接続を設定するには、次の手順を実行します。

1. **NitroX** アカウントにサインインします。
2. **NitroX** のサイドバーメニューで、**Integrations** メニュー項目をクリックします。

   ![NitroX の Integrations リスト](/images/nitrox-integrations-list.png)
3. **Integration** リストで **Connect with Moengage** セクションまでスクロールし、トグルをオンにして統合フィールドを展開します。
4. **Region** リストで、MoEngage アカウントに対応するデータセンターのリージョン (例: **DC-04**) を選択します。
5. **Primary Identifier** リストで、MoEngage のユーザー設定に基づいてプライマリ識別子 (**Phone number** または **Email**) を選択します。
6. **Workspace ID / App ID** および **Api Key** ボックスに、[ステップ 1](#step-1-find-your-credentials-in-moengage) で取得した認証情報を入力または貼り付けます。
7. **Save** をクリックします。

   ![NitroX の Connect with Moengage 設定フィールド](/images/nitrox-connect-moengage.png)

## ステップ 3: MoEngage でデータトラッキングを確認する

ユーザープロファイルと行動データが正しく同期されていることを確認するには、次の手順を実行します。

**特定のユーザーを確認するには:**

1. **MoEngage** アカウントの左側のナビゲーションバーで、ターゲットのようなアイコンをクリックして **Segment** メニューを開き、**Search Users** をクリックします。
2. **Search Users** ボックスに、ユーザー ID、メールアドレス、携帯電話番号、名前、または MoEngage ID を入力します。

   ![MoEngage のユーザー検索画面](/images/nitrox-search-users.png)

**NitroX から同期されたすべてのユーザーを表示するには:**

1. **Segment** メニューで、**Create segment** をクリックします。
2. **Filter users by** を選択します。
3. クエリビルダーのタブで、**User property** をクリックします。
4. 最初のドロップダウンリストで **created_by** 属性を選択します。評価演算子のリストで **is** を選択します。タイプのリストで **Constant value** を選択します。
5. 最後の選択オプションのリストで、**Nitro** (大文字と小文字を区別) を検索または選択します。
6. **Show count** をクリックします。

   ![created_by 属性でユーザーをフィルタリングする MoEngage のセグメントクエリ](/images/nitrox-segment-query.png)

クエリが評価され、同期されたプロファイルの合計数が **Query results** パネルに表示されます。

## トラブルシューティング

以下のトラブルシューティング表を使用して、統合に関する一般的な問題を解決してください。

| 問題 | 考えられる原因 | 解決策 |
| --- | --- | --- |
| データが MoEngage に同期されない。 | リージョンの不一致。 | NitroX の統合設定フォームで選択したリージョンが、MoEngage アカウントのデータセンターのリージョンと一致していることを確認してください。 |
| ユーザープロファイルが更新されない。 | プライマリ識別子の不一致。 | NitroX で選択したプライマリ識別子が、MoEngage の設定の Customer ID のタイプと一致していることを確認してください。 |
| 認証に失敗する。 | 無効な API 認証情報。 | MoEngage で **Settings** をクリックし、**APIs** をクリックして、Workspace ID と API Key が空白を含まずに NitroX にコピーされていることを確認してください。 |
| イベントがセグメンテーションに表示されない。 | イベントの検索語が正しくない。 | `nitro_view` や `nitro_addtocart` などのプレフィックスを使用してユーザー行動イベントを検索していることを確認してください。 |
| Nitro 固有のセグメントでユーザー数が 0 になる。 | 属性のターゲティングが正しくない。 | 正確な `created_by` 属性と、大文字と小文字を区別した値 `Nitro` を使用してユーザープロパティをクエリしていることを確認してください。 |

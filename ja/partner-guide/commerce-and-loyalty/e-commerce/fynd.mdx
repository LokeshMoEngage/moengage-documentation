# 概要

[Fynd Commerce Platform](https://www.fynd.com) は、企業がオンラインストアを手軽に管理および成長させられるように設計された、堅牢な e コマースソリューションです。Fynd を使用すると、ブランドはさまざまなチャネルでオンラインプレゼンスを作成、カスタマイズ、最適化できます。

# MoEngage × Fynd

Fynd Commerce Platform は MoEngage とシームレスに統合されており、ブランドは MoEngage を Fynd ストアに簡単に接続できます。Boltic を活用したこの統合により、ユーザー属性と行動データを MoEngage にリアルタイムで転送できます。この設定により、Web プッシュ、オンサイトメッセージング、SMS、メール、Web パーソナライゼーションなどのさまざまなチャネルを活用して、コンバージョンを向上させ、顧客エンゲージメントを高めることができます。

# ユースケース

Fynd Commerce Platform を Boltic Streams および MoEngage と組み合わせて使用するブランドにとって、その活用範囲は幅広く、大きな効果をもたらします。ブランドはこの統合を次のように活用できます。

1. Boltic で収集したブランドの Web サイトからのカスタムイベントデータを、Boltic Streams を使用して MoEngage に送信します。
2. Web サイトから MoEngage に重要な顧客データをエクスポートおよび同期し、リアルタイムのインサイトに基づいて高度にパーソナライズされたキャンペーンを作成できます。
3. Boltic 内でデータストリームや個別の宛先を簡単に一時停止または再開でき、データが MoEngage に届くタイミングと方法を完全に制御できます。
4. Boltic の豊富な構築済みコネクタを活用して、Fynd Commerce Platform のブランドストアと MoEngage を迅速かつシームレスに設定し、すぐにキャンペーンの最適化を開始できます。
5. スキーマ検証プロトコルにより、有効で正しくフォーマットされたイベントのみがブランドの Web サイトから MoEngage に送信されるため、キャンペーン全体でデータの整合性が維持されます。

# 統合

<Info>
  **前提条件**

  - MoEngage アカウントの Workspace ID は、_Settings - > Account -> APIs -> Workspace ID_ で確認できます。
  - MoEngage Data API キー。MoEngage アカウントの Data API キーは、_Settings - > App Settings -> APIs -> API Keys -> Data_ で確認できます。
  - MoEngage のデータセンター。詳細は[こちら](/ja/user-guide/data/key-concepts/data-centers-in-moengage)をご覧ください。
</Info>

# 手順

#### **ステップ 1: ブランドの Web サイトをソースとして追加する**

1. このブランド統合を識別するためのソース名を入力します。 <img src="/images/partner_30278688118548.png" alt="Screenshot 2024-09-03 at 10.00.31 AM.png" />
2. [オプション] タグや説明などの追加情報をソースに追加します。 <img src="/images/partner_30278695672468.png" alt="Screenshot 2024-09-03 at 10.03.32 AM.png" />
3. _Test and Save_ をクリックします。
4. Web サイトに _stream snippet_ をインストールします。stream snippet をコピーし、Web サイトの `<head>` 内のできるだけ上部に貼り付けます。 <img src="/images/partner_30278688119572.png" alt="Screenshot 2024-09-03 at 10.11.27 AM.png" />

## ステップ 2: MoEngage を Boltic の宛先として追加する

1. 宛先名を入力します。 <img src="/images/partner_30278688120212.png" alt="Screenshot 2024-09-02 at 11.43.51 AM.png" />
2. ダッシュボードのエンドポイント URL を入力します。 <img src="/images/partner_30278695674132.png" alt="Screenshot 2024-09-02 at 11.48.09 AM.png" />
3. Data API キーを入力します。 <img src="/images/partner_30278695674900.png" alt="Screenshot 2024-09-02 at 11.48.37 AM.png" />
4. Workspace ID (以前の名称は Data API ID) を入力します。 <img src="/images/partner_30278695675284.png" alt="Screenshot 2024-09-02 at 11.49.57 AM.png" />
5. 宛先をテストして保存します。定義したイベントがアカウントに送信され始めます。

これで、MoEngage を Boltic の宛先として正常に追加できました。定義したイベントがアカウントに送信され始めます。

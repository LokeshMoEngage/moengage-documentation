[Shopflo](https://www.shopflo.com/) は、e コマースストアの顧客体験を向上させるチェックアウトプラットフォームです。シームレスで高速かつ直感的なチェックアウトプロセスを提供し、企業のコンバージョン率の向上とカゴ落ちの削減を支援します。

## MoEngage × Shopflo

MoEngage と Shopflo の統合により、重要なチェックアウトジャーニーのイベントが送信され、顧客エンゲージメントが強化されます。このデータにより、ユーザー行動に関するより深いインサイトを得て、より効果的なセグメントを作成し、コンバージョンを高めて顧客ロイヤルティを育むパーソナライズされたキャンペーンをトリガーできます。この統合により、次のことが可能になります。

- チェックアウトファネルにおけるユーザーの進行状況をリアルタイムでトラッキングする。
- チェックアウト時に収集した顧客データで MoEngage のユーザープロファイルを更新する。
- チェックアウトの放棄や注文の完了などのイベントに対して自動ワークフローをトリガーする。
- チェックアウト時のアクションや購入データに基づいて、きめ細かなユーザーセグメントを作成する。

## ユースケース

Shopflo を MoEngage と統合すると、次のユースケースに対応できます。

- **カゴ落ちのリカバリー** : カートを放棄したユーザーに、プッシュ通知、メール、または SMS でタイムリーなリマインダーを自動的に送信し、購入の完了を促します。
- **購入後のエンゲージメント** : 最近の購入内容に基づいて、新規顧客の歓迎、商品レビューの依頼、ロイヤルティ特典の提供、関連商品の提案などを行うキャンペーンを自動的にトリガーします。
- **行動に基づくセグメンテーション** : カートに追加された商品、使用されたクーポンコード、購入総額など、特定のチェックアウトアクションに基づいて動的なユーザーリストを作成します。
- **ユーザーコミュニケーションのパーソナライズ** : 商品名、注文金額、割引コードなど、完了した注文のデータを使用して、マーケティングメッセージや商品レコメンデーションをパーソナライズします。

### 同期モジュール

次の表は、Shopflo から MoEngage にリアルタイムで同期されるイベントデータとユーザーデータの概要です。

| イベントタイプ | イベント名 | 説明 |
| --- | --- | --- |
| チェックアウトイベント | Address submitted | このイベントは、ユーザーが住所と連絡先の詳細を送信したときにトラッキングされます。 |
| チェックアウトイベント | Payment method selected | このイベントは、ユーザーが支払いオプションを選択したときにトラッキングされます。 |
| チェックアウトイベント | Order Completed | このイベントは、ユーザーが購入を正常に完了したときにトラッキングされます。 |
| ユーザープロファイルイベント | Address submitted | Address Submitted イベントがトラッキングされると、関連するユーザー情報を使用して MoEngage のユーザープロファイルが追加または更新されます。 |

## ステップ 1: MoEngage の API 認証情報を取得する

MoEngage の API 認証情報を取得するには、次の手順を実行します。

1. MoEngage の UI の左側のナビゲーションメニューで、**Settings** \> **Account** \> **APIs** に移動します。
2. **API** ページで、次の認証情報をコピーします。
   1. **Workspace ID** (**earlier app id**) の下にある ID をコピーします。
   2. **API keys** の下にある **Data** をコピーします。
3. **データセンター** : ダッシュボードの URL からデータセンターのコードを確認します。次の表は、データセンター名と URL の対応を示しています。

| DC-03 | [https://dashboard-03.moengage.com](https://dashboard-03.moengage.com) |
| DC-04 | [https://dashboard-04.moengage.com](https://dashboard-04.moengage.com) |

## ステップ 2: Shopflo で統合を設定する

Shopflo で統合を設定するには、次の手順を実行します。

1. [Shopflo](https://dashboard.shopflo.co/settings/integrations?s_id=moengage) ダッシュボードにログインします。
2. **Settings** \>**Integrations** \> **Remarketing** \> **MoEngage** に移動します。
3. **Re-marketing** セクションで、リスト内の **MoEngage** を見つけ、**Click to setup** をクリックして設定パネルを開きます。 <img src="/images/partner_41270993462164.png" />
4. [MoEngage の API 認証情報を取得する](/ja/partner-guide/commerce-and-loyalty/e-commerce/shopflo#step-1-get-your-moengage-api-credentials)でコピーした詳細を入力します。
5. **App ID** ボックスに、**Workspace ID** を入力します。
6. **Data API ID** ボックスに、再度 **Workspace ID** を入力します。
7. **Data API key** ボックスに、**Data API Key** を入力します。
8. **Data Center** リストで、データセンターを選択します。
9. **Customer ID type** リストで、MoEngage でユーザーに使用している識別子を選択します。
10. **MoEngage analytics is enabled** トグルをオンにします。

![](/images/partner_41270993464852.png)

## ステップ 3: 設定を確認する

Shopflo は、認証情報の保存時に自動的に検証を行います。データフローのエンドツーエンドのテストを完全に実行するには、次の手順を実行します。

1. Shopflo ストアで注文ジャーニーを完了します。
2. MoEngage の UI で **Segments** \> **Create segment** に移動し、メール ID を検索します。
3. MoEngage の UI で、ユーザープロファイルがそれぞれのペイロードで作成または更新されていることを確認します。

### MoEngage に送信される Shopflo のイベント

Shopflo の統合では、チェックアウトプロセスにおける顧客のジャーニーをトラッキングするために、いくつかの主要なイベントが MoEngage に送信されます。各イベントには、重要な属性を含むデータペイロードが含まれます。

<Info>
  Shopflo はデータを即座に送信しますが、MoEngage の UI に表示されるまでに若干の遅延が発生する場合があります。
</Info>

#### イベント: Address Submitted

このイベントは、ユーザーが配送情報を送信して支払いステージに進んだ後にトリガーされます。

- **ユーザープロファイルの同期** : このイベントは、_First Name_、_Last Name_、_Phone_、_Email_ などの重要な属性を同期して、MoEngage のユーザープロファイルを作成または更新します。
- **カゴ落ちのリカバリー** : ペイロードには、ユーザーのセッションへの一意のリンクである `checkoutURL` パラメーターが含まれます。キャンペーンでこのリンクを使用すると、情報が入力済みのチェックアウトページにユーザーを戻すことができます。

#### イベント: Address Submitted

このイベントは、ユーザーが配送情報を送信して支払いステージに進んだ後にトリガーされます。

- **ユーザープロファイルの同期** : このイベントは、_First Name_、_Last Name_、_Phone_、_Email_ などの重要な属性を同期して、MoEngage のユーザープロファイルを作成または更新します。
- **カゴ落ちのリカバリー** : ペイロードには、ユーザーのセッションへの一意のリンクである `checkoutURL` パラメーターが含まれます。キャンペーンでこのリンクを使用すると、情報が入力済みのチェックアウトページにユーザーを戻すことができます。

**ペイロードの例** :

<CodeGroup>

```json JSON wrap
{
"line_items": ["41892488839333"],
"checkoutURL": "https://checkout.shopflo.co/?tokenId=88b4c6da9f534f38-bee2-8b706be2c0e0",
"login_type": "cookie_login"
}
```

</CodeGroup>

#### イベント: Payment Method Selected

このイベントは、ユーザーがチェックアウト中に支払いオプション (UPI、クレジットカードなど) を選択したときにトリガーされます。

**ペイロードの例** :

<CodeGroup>

```json JSON wrap
{
"checkoutURL": "https://checkout.shopflo.co/?tokenId=88b4c6da9f534f38-bee2-8b706be2c0e0",
"type": "cookie_login",
"method": "upi"
}
```

</CodeGroup>

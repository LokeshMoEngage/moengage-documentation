# 概要

[Magento](https://business.adobe.com/products/magento/magento-commerce.html) は、企業がオンラインストアを構築および管理するのに役立つオープンソースの e コマースプラットフォームです。マーケティング、検索エンジン最適化、カタログ管理のためのツールが含まれています。

# MoEngage × Magento

Magento と MoEngage の統合により、MoEngage Web SDK をブランドの Magento ストアにシームレスに統合し、ユーザーイベントとデータを簡単にトラッキングできます。この統合により、Web プッシュ、オンサイトメッセージング、SMS、メール、Web パーソナライゼーションなどのさまざまなチャネルを活用して、ストアの訪問者とのエンゲージメントを図り、コンバージョンへと導くことができます。

アカウントでこの統合の使用を開始するには、[MoEngage × Magento ガイド ](/ja/developer-guide/ecommerce-platforms/magento/magento)をお読みください。

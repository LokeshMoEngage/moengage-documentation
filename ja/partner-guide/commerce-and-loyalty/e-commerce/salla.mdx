## 概要

[Salla](https://salla.com/) は、MENA 地域の販売事業者がオンラインストアを開設および管理するのに役立つ e コマースプラットフォームです。この統合により、ストアの顧客データとチェックアウトイベントを MoEngage にシームレスに同期し、オムニチャネルでのエンゲージメントを実現できます。

## 主な機能

- **ノーコードでのセットアップ**: 開発作業なしでストアを接続できます。
- **オムニチャネルエンゲージメント**:
  - **Web**: Web プッシュ通知、オンサイトメッセージング (OSM)、パーソナライゼーション。
  - **モバイルアプリ**: モバイルプッシュ通知、アプリ内メッセージング (Salla の iOS/Android アプリ向け)。
- **リアルタイムトラッキング**: Web とモバイルの両方でイベント (Viewed Product、Added to Cart、Checkout) を同期します。

## ユースケース

- **カゴ落ちのリカバリー**: 顧客がカートに商品を残したままにした場合に、パーソナライズされたメッセージを自動的にトリガーします。
- **新規顧客の歓迎**: 初めての訪問者に合わせたウェルカムメッセージでエンゲージメントを図ります。
- **ショッピング体験のパーソナライズ**: ユーザーの行動に基づいて動的な商品レコメンデーションを表示します。

# 統合手順

<Info>
  **前提条件**

  - 有効な Salla ストア (販売事業者アカウント)。
  - 有効な MoEngage アカウント。
</Info>

## ステップ 1: MoEngage に統合をリクエストする

MoEngage のカスタマーサクセスマネージャーまたは MoEngage サポートに連絡して、Salla の統合設定をリクエストします。

**提供する情報:**

- **Salla Store URL**: 公開中のストアの URL (例: yourstore.salla.sa)
- **Store Name**: Salla の販売事業者名またはストア名

MoEngage からアプリのインストールリンクが提供され、必要な設定について Salla と調整が行われます。

## ステップ 2: MoEngage アプリをインストールする

1. MoEngage から提供されたアプリのインストールリンクをクリックします。
2. まだログインしていない場合は、Salla Merchant Dashboard にログインします。
3. **Install App** または **Add to Store** をクリックします。\
   **My Apps** ページが表示されます。 <img src="/images/partner_44496806792468.png" alt="Salla の My Apps ページ" />

## ステップ 3: アプリの設定を構成する

インストールが完了したら、アプリを設定して MoEngage ワークスペースに接続します。

### 3.1 MoEngage の認証情報を取得する

1. MoEngage ダッシュボードにログインします。
2. **Settings \> Account \> APIs** に移動します。
3. **Workspace ID** と **Data API Key** をコピーします。
4. ダッシュボードの URL (例: `dashboard-04.moengage.com`) に基づいて、**データセンター** (例: DC-04) を確認します。

| データセンター名 | ダッシュボード URL |
| --- | --- |
| DC-01 | [https://dashboard-01.moengage.com](https://dashboard-01.moengage.com) |
| DC-02 | [https://dashboard-02.moengage.com](https://dashboard-02.moengage.com) |
| DC-03 | [https://dashboard-03.moengage.com](https://dashboard-03.moengage.com) |
| DC-04 | [https://dashboard-04.moengage.com](https://dashboard-04.moengage.com) |
| DC-05 | [https://dashboard-05.moengage.com](https://dashboard-05.moengage.com) |
| DC-06 | [https://dashboard-06.moengage.com](https://dashboard-06.moengage.com) |

詳細については、[MoEngage のデータセンター](/ja/user-guide/data/key-concepts/data-centers-in-moengage)を参照してください。

![MoEngage の API 認証情報](/images/partner_44423603010964.png)

<Info>
  **モバイルアプリの設定**

  上記で構成した設定は、Salla モバイルアプリ (iOS/Android) に自動的に適用されます。モバイルの統合では、これらの認証情報 (Workspace ID、API Key) が引き継がれます。

  **注:** モバイルアプリの統合は Salla が所有および管理しています。モバイルアプリ固有の問題やトラブルシューティングのリクエストについては、Salla サポートにお問い合わせください。
</Info>

### 3.2 Salla で設定を入力する

Salla Merchant Dashboard の **MoEngage App Integration** ページで、次の操作を行います。

1. **Workspace ID**: MoEngage の Workspace ID を貼り付けます。
2. **Data API Key**: MoEngage の Data API Key を貼り付けます。
3. **Data Center**: ドロップダウンからデータセンター (例: DC-04) を選択します。
4. **Unique Identifier (Customer ID)**: MoEngage でユーザーを識別する方法として、**Email** または **Phone** を選択します。

<Warning>
  この設定は、ゲストユーザーのデータをログイン済みユーザーのプロファイルに統合するうえで非常に重要です。ビジネスで顧客のプライマリキーとして使用している識別子を選択してください。
</Warning>

5. **SDK Version**: MoEngage サポートから指示がない限り、デフォルト値のままにします。
6. **Enable Personalization** (オプション): Web パーソナライゼーション機能 (動的な商品レコメンデーション、バナーなど) を有効にするには、**ON** に切り替えます。
7. **Debug Logs** (テスト時のみ): ブラウザコンソールでログを表示するには、テスト中のみ **ON** に切り替えます。

<Warning>
  **本番運用前にデバッグモードを無効にする** Debug Logs が有効な場合、データは MoEngage のテスト環境に送信されます。データが本番ワークスペースに送信されるように、本番公開前に必ずこの設定を無効にしてください。
</Warning>

8. **Save** をクリックします。

![MoEngage アプリの設定ページ](/images/partner_44496843915796.png)

## ステップ 4: 統合を確認する

### 4.1 Web SDK を確認する

1. デバッグモードがオンになっていることを確認します。
2. ブラウザで Salla のストアフロントを開きます。
3. デベロッパーツールを開きます (`F12` または `Right Click > Inspect`)。
4. **Console** タブに移動します。
5. `MoEngage: SDK initialized successfully` が表示されていることを確認します。

### 4.2 イベントフローを確認する

1. ストアでテスト操作 (商品の閲覧、カートへの追加など) を行います。
2. MoEngage ダッシュボード \> **Test Environment** に移動します (Debug Logs が ON の場合)。
3. **Analytics \> Events** または **Live Events** ストリームを確認します。
4. 30～60 秒以内にイベントが表示されることを確認します。

<Check>
  **統合の完了**

  これで Salla ストアが MoEngage と統合され、Web とモバイルの両方で顧客イベントがリアルタイムでトラッキングされるようになりました。キャンペーンを作成して顧客とのエンゲージメントを開始できます。
</Check>

## トラッキングされるイベントのリファレンス

プラットフォームに基づいて、次のイベントが自動的にトラッキングされます。

すべてのイベント

| カテゴリ | イベント | プラットフォーム |
| --- | --- | --- |
| **ナビゲーション** | Page Viewed, Product Viewed, Product List Viewed, Product List Filtered, Products Searched | Web、モバイル |
| **カートとチェックアウト** | Product Added to Cart, Product Added, Product Removed, Cart Viewed, Cart Updated, Checkout Started | Web、モバイル |
| **注文** | Order Placed, Order Completed | Web、モバイル |
| **ユーザー** | Signed Up, Signed In, Signed Out, User Profile Updated, Market Selected | Web、モバイル |
| **ウィッシュリスト** | Product Added to Wishlist, Product Removed from Wishlist | Web、モバイル |
| **クーポン** | Coupon Entered, Coupon Applied, Coupon Denied, Coupon Removed | Web、モバイル |
| **エンゲージメント** | Product Reviewed, Product Shared, Promotion Viewed, Promotion Clicked | Web、モバイル |

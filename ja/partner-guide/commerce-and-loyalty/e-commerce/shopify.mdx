# 概要

[Shopify](https://www.shopify.com/) は、あらゆる規模の小売ビジネスの立ち上げ、成長、マーケティング、管理のための信頼できるツールを提供する、世界有数のコマース企業です。Shopify は、信頼性を重視して設計されたプラットフォームとサービスにより、あらゆる人にとってコマースをより良いものにし、世界中の消費者により良いショッピング体験を提供しています。

# MoEngage × Shopify

Shopify と MoEngage の統合により、MoEngage Web SDK をブランドの Shopify ストアにシームレスに統合し、ユーザーイベントとデータを簡単にトラッキングできます。この統合により、Web プッシュ、オンサイトメッセージング、SMS、メール、Web パーソナライゼーションなどのさまざまなチャネルを活用して、ストアの訪問者とのエンゲージメントを図り、コンバージョンへと導くことができます。

アカウントでこの統合の使用を開始するには、[MoEngage × Shopify ガイド](/ja/developer-guide/ecommerce-platforms/shopify/shopify-20)をお読みください。

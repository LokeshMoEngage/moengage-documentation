[TikTok Ads](https://ads.tiktok.com/business/en-US/how-it-works) は、企業やブランドが TikTok アプリの大規模でエンゲージメントの高いユーザーベースを活用し、TikTok プラットフォーム上でより幅広いオーディエンスにリーチするために使用できる有料のプロモーションコンテンツです。

# MoEngage × TikTok Ads

MoEngage と TikTok Ads の統合により、MoEngage ユーザーはユーザーデータを TikTok Ads に追加し、行動トリガーやセグメンテーションに基づいて広告を配信できます。

## ユースケース

TikTok を MoEngage と統合すると、次のユースケースを実現できます。

- **ユーザーエンゲージメントとコンバージョンの向上** : 複数のチャネルを通じて価値の高いユーザーをターゲティングし、購入やエンゲージメントを促進できます。
- **反応の低いユーザーの再エンゲージメント** : 他のマーケティングチャネルへの反応が低いユーザーに対し、過去の行動に基づいたターゲットディスプレイ広告を表示できます。
- **広告費の最適化** : 抑制オーディエンスを作成し、すでにブランドのロイヤルカスタマーであるユーザーに広告が配信されないようにできます。
- **効率的な新規ユーザー獲得** : 類似オーディエンスを作成し、より効率的に新規ユーザーを獲得できます。

# 統合

<Info>
  - **TikTok 広告アカウント** : この統合を使用するには、TikTok の有効な広告アカウントが必要です。
  - TikTok Ads は Connected Segments アドオンの一部です。アカウントで有効にするには、担当の MoEngage カスタマーサクセスマネージャー(CSM)にお問い合わせください。
</Info>

## ステップ 1: App Marketplace で TikTok を接続する

<Info>
  まず、TikTok Ads の Advertiser アカウントを MoEngage ワークスペースに接続します。
</Info>

App marketplace で TikTok を接続するには、次の手順を実行します。

1. MoEngage UI の左側のナビゲーションメニューで、**App marketplace** をクリックします。
2. App Marketplace ページで **TikTok Ads** を検索します。
3. **TikTok Ads** タイルをクリックします。
4. **TikTok Ads** パートナーページで **Integrate** タブをクリックします。
5. <img src="/images/partner_41413147644564.png" /> 矢印をクリックし、次のいずれかのオプションを選択します。
   - Create Audience Segment
   - Update Audience Segment <img src="/images/partner_38799526109076.png" />

選択したコネクタタイプに応じて、次の詳細を入力します。

| フィールド | 必須 | 説明 |
| --- | --- | --- |
| Connection name | はい | TikTok 接続の名前です。 |
| Advertiser ID | はい | TikTok Ads アカウントの Advertiser ID です。 |

![](/images/partner_41413133799188.png)

7. **Connect** をクリックします。これで TikTok 接続が統合されました。\
   **注意:** TikTok コネクタごとにこの手順を繰り返します。

## ステップ 3: MoEngage でキャンペーンを作成してオーディエンスを TikTok Ads に同期する

MoEngage でコネクタキャンペーンを作成するには、次の手順を実行します。

1. MoEngage UI の左側のナビゲーションメニューで、**Engage** をクリックし、**Campaigns** をクリックします。
2. **All campaigns** ページで、\+ Create campaign をクリックします。
3. **Create campaign** ダイアログボックスの **Connected Apps** で **TikTok** をクリックし、最適な配信タイプをクリックします。 <img src="/images/partner_38765492883988.png" />
4. **Select audience** で **Filter users by** をクリックします。
5. **User property** タブで、Pinterest に同期するユーザーセグメントを選択します。他のセグメント条件と組み合わせることもできます。
6. キャンペーンのステップ 2 **Content** で、事前設定済みのコネクタを選択し、送信するコンテンツを指定します。次の詳細を入力します。

| フィールド | 説明 |
| --- | --- |
| **Connector** | 次のアクションを実行できます。 <ul><li>**Create Audience Segment**</li><li>**Update Audience Segment**</li></ul> |
| **Connections** | MoEngage App marketplace に追加した接続を選択します。 |

![](/images/partner_38765492884244.png)

### TikTok の既存のオーディエンスに同期する

TikTok の既存のオーディエンスにユーザーを追加または削除する場合は、そのオーディエンスの ID を指定する必要があります。[TikTok Audience Manager](https://ads.tiktok.com/) にアクセスして、TikTok 上のオーディエンスを確認できます。

1. ヘッダーのナビゲーションバーで **Tools** を選択します。
2. **Audiences** \> **Audience Manager** を選択します。
3. 目的のオーディエンスを見つけて Audience ID を確認します。
4. **Audience ID** 列から Audience ID を控えておきます。 <img src="/images/partner_38765534637460.png" />

### TikTok Ads で新しいオーディエンスを作成する

TikTok で新しいオーディエンスを作成するには、**Create Audience Segment** コネクタを使用して次の手順を実行します。

1. **Create Audience Segment** コネクタと、作成した接続を選択します。
2. Audience Segment Name とその他の必要な詳細を入力します。
3. テストキャンペーンを実行し、レスポンスを確認します。<img src="/images/partner_38765534637716.png" />
4. **Audience list** から、作成した新しいオーディエンスの **Audience ID** をコピーします。\
   **注意**: この ID は、MoEngage からこのオーディエンスにユーザーを同期するために必要です。この ID は、TikTok Ads Manager の Audience list に移動していつでも確認できます。

<Warning>
  このキャンペーンは公開しないでください。公開すると、TikTok 上に重複したオーディエンスが作成されます。
</Warning>

選択したコネクタに応じて、次の情報を指定する必要があります。

<Tabs>
  <Tab title="Create Audience Segment">
    | フィールド | 説明 |
    | --- | --- |
    | **Audience Segment Name** | Audience Segment の名前です。これは **Custom Audience** タイプの Audience Segment です。 |

    <Frame>
      ![Tiktok](/images/tiktok.png)

  </Tab>
  <Tab title="Update Audience Segment">
    | フィールド | 説明 |
    | --- | --- |
    | Audience ID | Audience Segment の ID を指定します。 |
    | Add or remove users | 実行するアクションを次から選択します。 <ul><li>**Add user to Audience Segment**</li><li>**Remove user from Audience Segment**</li></ul> |
    | Send Email ID | メール識別子を TikTok に送信する場合は、このオプションを選択します。このオプションを選択しない場合、Email ID フィールドに値が入力されているかどうかにかかわらず、メール識別子は送信されません。メール識別子は TikTok に送信される前に SHA-256 でハッシュ化されます。 |
    | Email ID | @ を入力し、Email ID を含むユーザー属性を選択します。デフォルトでは、Email には「Email (Standard)」を使用できます。**注意** : TikTok に送信する前に、メール ID が[正規化](https://business-api.tiktok.com/gateway/docs/index?identify_key=c0138ffadd90a955c1f0670a56fe348d1d40680b3c89461e09f78ed26785164b&language=ENGLISH&doc_id=1739940585975809#item-link-Email%20Specific%20Normalization)されていることを確認してください。 |
    | Send Mobile Number | 携帯電話番号の識別子を TikTok に送信する場合は、このオプションを選択します。このオプションを選択しない場合、Mobile Number フィールドに値が入力されているかどうかにかかわらず、MoEngage は携帯電話番号を送信しません。**携帯電話番号**は TikTok に送信される前に SHA-256 でハッシュ化されます。詳細については、[サポートされている形式に関する TikTok のドキュメント](https://ads.tiktok.com/help/article/how-to-create-a-custom-audience-with-a-customer-file)を参照してください。 |

    | Send Advertising IDs | 広告識別子を TikTok に送信する場合は、このオプションを選択します。このオプションを選択しない場合、**Google Advertiser ID** および **iOS Advertising ID** フィールドに値が入力されているかどうかにかかわらず、広告識別子は送信されません。広告識別子は TikTok に送信される前に SHA-256 でハッシュ化されます。 |
    | Google Advertiser ID | @ を入力し、Google Advertising Identifier を含むユーザー属性を選択します。デフォルトでは Google Advertising ID (Android) を使用できます。この識別子を送信しない場合は空欄のままにします。 |
    | iOS Advertising ID | **@** を入力し、iOS Advertising Identifier を含むユーザー属性を選択します。デフォルトでは Advertising Identifier (iOS & Windows) を使用できます。この識別子を送信しない場合は空欄のままにします。 |

  </Tab>

5. これでキャンペーンをテストし、オーディエンスに送信する準備が整いました。**Test** 機能を使用して、コネクタの設定をテストすることもできます。 <img src="/images/partner_38765587441940.png" /> テストユーザーがメッセージを正常に受信すれば、設定は完了です。
6. キャンペーンを公開します。

**注意**: 新しいオーディエンスを作成する場合は、キャンペーンを公開しないでください。

## ステップ 4: TikTok Ads のオーディエンスセグメントを確認する

TikTok Ads Manager アカウントで **Audience** \> **Audience Manager** を選択すると、オーディエンスを確認できます。各オーディエンスのサイズは、約 1,000 に達すると **Audiences** ページに表示されます。

<Info>
  TikTok は ID の更新を非同期で処理します。そのため、オーディエンスサイズが更新されるまで 48 時間かかります。
</Info>

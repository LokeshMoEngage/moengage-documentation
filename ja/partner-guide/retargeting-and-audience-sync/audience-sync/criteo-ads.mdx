[Criteo](https://www.criteo.com/)は、オンラインディスプレイ広告ソリューションを提供する広告会社です。マーケターやメディアオーナーとユーザーを結び付け、ユーザーの意図を分析して効果的な広告を配信します。

# MoEngage × Criteo

MoEngageとCriteoの連携により、ユーザーデータをCriteoに転送できます。これにより、行動トリガーとセグメンテーションに基づいて広告を配信できます。

## ユースケース

CriteoをMoEngageと連携すると、以下のユースケースに対応できます。

- **ユーザーエンゲージメントとコンバージョンの向上** : 複数のチャネルを通じて価値の高いユーザーをターゲットにし、購入やエンゲージメントを促進できます。
- **反応の少ないユーザーへの再エンゲージメント** : 他のマーケティングチャネルへの反応が少ないユーザーに対し、過去の行動に基づいたターゲットディスプレイ広告を表示してターゲティングできます。
- **広告費の最適化** : 抑制オーディエンスを作成して、すでにブランドのロイヤルな消費者であるユーザーに広告が配信されないようにできます。
- **効率的な新規ユーザー獲得** : 類似オーディエンスを作成して、新規ユーザーをより効率的に獲得できます。

# 連携

<Info>
  - **Criteo広告アカウント** : この機能を使用するには、Criteoの有効な広告アカウントが必要です。
  - **Criteoの広告ガイドラインとCriteoのブランドセーフティガイドライン** : Criteoの有効な顧客として、Criteoキャンペーンを開始する前に、Criteoの広告ガイドラインとブランドセーフティガイドラインを遵守できることを確認する必要があります。
  - **Criteoのマーケティング API** : CriteoのマーケティングAPIを使用して、MoEngageを通じてオーディエンスまたはユーザーをCriteoに同期します。これらのマーケティングAPIを使用するには、Criteo AppとAdアカウントが必要です。既存のアプリとAdアカウントを使用することも、MoEngageと接続するために新しく作成することもできます。
  - Criteo AdsはConnected Segmentsアドオンの一部です。アカウントで有効にするには、担当のMoEngage CSM（カスタマーサクセスマネージャー）にお問い合わせください。
</Info>

## ステップ1: Criteoで開発者アプリを作成する

<Info>
  MoEngageでCriteoのマーケティングAPIを使用するには、Criteoの開発者アカウントが必要です。
</Info>

Criteoの開発者アカウントを設定するには、以下の手順を実行します。

1. [Criteo Developers Dashboard](https://login.criteo.com/oauth2/default/v1/authorize?client_id=dev-portal&scope=openid%20profile%20email&response_type=code&redirect_uri=https%3A%2F%2Fpartners.criteo.com%2Fauth&state=dashboard)に移動します。
2. 既存のCriteoアカウントにログインするか、Criteoの担当者に連絡してアカウントを作成します。
3. 組織を作成します。詳細については、[こちら](https://developers.criteo.com/marketing-solutions/docs/create-your-organization)を参照してください。
4. アプリを作成します。詳細については、[こちら](https://developers.criteo.com/marketing-solutions/docs/create-your-app)を参照してください。
5. Authentication Methodステップで、方法として**Authorization code**を選択し、**Create**をクリックします。詳細については、[Authentication Method](https://developers.criteo.com/marketing-solutions/docs/authorization-code-setup)を参照してください。\
   **注意** : 認証方法として**Authorization code**のみを選択してください。\
   <img src="/images/partner_37552793955860.png" />\
   **App activation**ステップに移動します。
6. **C-Growth**と**Marketing Solutions**を選択し、**Next**をクリックします。\
   <img src="/images/partner_37552793956372.png" />\
   **Authorizations**ステップに移動します。
7. **Audiences**ドメインについて、関連する**Authorization**リストから**Manage**を選択し、**Activate app**をクリックします。\
   <img src="/images/partner_37552793956628.png" />\
   ポップアップウィンドウが表示され、Criteoアプリを有効にするための手順を正しく確認するよう求められます。
8. **Activate**をクリックします。\
   <img src="/images/partner_37552815161876.png" />\
   これでアプリが正常に有効になりました。**Application details**ページに移動します。
9. デフォルトでは**App Settings**タブが表示されています。**Redirect URs**で、**Create a new Redirect URI**をクリックします。 <img src="/images/partner_37552815162388.png" />
10. **Create a new Redirect URI parameter**ポップアップウィンドウが表示されます。お使いのMoEngageデータセンターに応じて、**Redirect URL**ボックスに以下の特定のURLを入力します。

| データセンター | Redirect URI |
| --- | --- |
| DC-01 | [https://dashboard-01.moengage.com/v3/partner/oauth/callback](https://dashboard-01.moengage.com/v3/partner/oauth/callback) |
| DC-02 | [https://dashboard-02.moengage.com/v3/partner/oauth/callback](https://dashboard-02.moengage.com/v3/partner/oauth/callback) |
| DC-03 | [https://dashboard-03.moengage.com/v3/partner/oauth/callback](https://dashboard-03.moengage.com/v3/partner/oauth/callback) |
| DC-04 | [https://dashboard-04.moengage.com/v3/partner/oauth/callback](https://dashboard-04.moengage.com/v3/partner/oauth/callback) |

11. **Create**をクリックします。\
    <img src="/images/partner_37552793957524.png" />\
    これでRedirect URIが正常に作成されました。
12. **App credentials**で、**Create new key**をクリックします。\
    <img src="/images/partner_37552793958420.png" />\
    これでAPIキーの認証情報が正常にダウンロードされました。

<Info>
  ダウンロードしたAPIキーファイルから、**Client ID**と**Client Secret**にアクセスできます。MoEngage App MarketplaceでCriteo連携を設定するには、**Client ID**と**Client Secret**のキーが必要です。
</Info>

## ステップ2: App MarketplaceでCriteoを接続する

App MarketplaceでCriteoを接続するには、以下の手順を実行します。

1. MoEngageダッシュボードの左側のナビゲーションメニューで、**App marketplace**をクリックします。
2. App Marketplaceページで、**Criteo**を検索します。 <img src="/images/partner_38547800627860.png" />
3. **Criteo Ads**タイルをクリックします。
4. **Criteo Ads**パートナーページで、**Integrate**タブに移動します。
5. <img src="/images/partner_37186015189652.png" /> 矢印をクリックし、以下のオプションのいずれかを選択します。
   - Create Contact List
   - Update Contact List <img src="/images/partner_38547847656852.png" />
6. 以下の詳細を入力します。

| フィールド | 必須 | 説明 |
| --- | --- | --- |
| Connection name | はい | Criteo接続の名前。 |
| Client ID | はい | 先ほどダウンロードしたCriteo AppのClient ID。既存のアプリを使用している場合は、そのアプリのClient IDを入力する必要があります。 |
| Client Secret | はい | 先ほどダウンロードしたCriteoアプリのClient Secret。既存のアプリを使用している場合は、そのアプリのClient Secretを入力する必要があります。 |
| Advertiser ID | はい | Criteoアプリ上の各広告主に割り当てられる一意の数値識別子。 |

![](/images/partner_38547847660820.png)

7. **Connect**をクリックします。これでCriteo接続の連携が完了します。

## ステップ3: MoEngageでCriteoにオーディエンスを同期するキャンペーンを作成する

MoEngageでキャンペーンを作成するには、以下の手順を実行します。

1. MoEngageダッシュボードの左側のナビゲーションメニューで、**Engage**をクリックし、**Campaigns**をクリックします。
2. All campaignsページで、\*\*\+ Create campaign\*\*をクリックします。
3. **Create campaign**ダイアログボックスの**Connected Apps**で、**Criteo Ads**をクリックし、最も適切な配信タイプをクリックします。 <img src="/images/partner_38547800636180.png" />
4. **Select audience**で、**Filter users by**をクリックします。
5. **User property**タブで、Criteoに同期するユーザーセグメントを選択します。これを他のセグメント条件と組み合わせることもできます。
6. キャンペーンのステップ2の**Content**で、事前に設定したコネクタを選択し、送信するコンテンツを指定します。以下の詳細を入力します。

| フィールド | 説明 |
| --- | --- |
| **Connector** | 以下のアクションを実行できます。 <ul><li>Create Contact List</li><li>Update Contact List</li></ul> |
| **Connections** | MoEngage App Marketplaceに追加した接続を選択します。 |

![](/images/partner_38547800640788.png)

### Criteoの既存のオーディエンスに同期する

Criteoの既存のオーディエンスにユーザーを追加または削除する場合は、そのオーディエンスのIDを指定する必要があります。[Criteo Audience Library](https://marketing.criteo.com/audience-manager/list/segments)に移動すると、Criteoでオーディエンスを確認できます。

1. 左上隅のメニューをクリックし、\>\> **Assets**で**Audiences**を選択します。
2. Audiences \>\> で**Audience Library**を選択し、**Segments**タブを選択します。
3. 目的のセグメントを見つけて、Segment IDを確認します。
4. 「**Id**」列からSegment IDを控えておきます。

![](/images/partner_38547847671572.png)

### Criteoで新しいオーディエンスを作成する

Criteoで新しいオーディエンスを作成するには、以下の「Create Contact List」コネクタを使用できます。以下の手順に従ってください。

1. 「Create Contact List」コネクタと作成した接続を選択します。
2. 以下に記載されているとおりに、Audience Segment Nameとその他の必要な詳細を入力します。
3. テストキャンペーンを実行し、レスポンスを確認します。

![](/images/partner_38547847674260.png)

4. ハイライト表示されたIDがAudience IDです。今後このオーディエンスにユーザーを追加または削除する際に必要になります。上記の手順に従えば、いつでもCriteo内でこのIDを確認できます。

<Warning>
  このキャンペーンは公開しないでください。公開すると、Criteoに同じ名前のオーディエンスが複数作成されます。
</Warning>

## ステップ4: Criteoオーディエンスセグメントを表示する

Criteo Ads Managerアカウントで**Audience Library** **Segments**を選択すると、オーディエンスを確認できます。各オーディエンスのサイズは、メンバー数が約1,000人に達した後にSegmentsページに表示されるようになります。

[Snapchat Ads](https://forbusiness.snapchat.com/) は、企業が Snapchat アプリ上のエンゲージメントの高いオーディエンスにリーチするために使用できるフルスクリーンのデジタル広告です。Snapchat Ads は、企業の次のような取り組みに役立ちます。

- ブランド認知度の向上
- ウェブサイトへのトラフィック誘導
- アプリインストールの促進

# MoEngage × Snapchat

MoEngage と Snapchat Ads の統合により、MoEngage のオーディエンスセグメントを Snapchat と同期できます。これにより、特定のエンドユーザーに合わせた、ターゲティング精度の高い広告キャンペーンを作成できます。

## ユースケース

MoEngage との統合により、次のユースケースを実現できます。

- **Snapchat でのユーザーインタラクションと売上の向上** : MoEngage の詳細なユーザーインサイトを活用して、Snapchat 上で最も価値の高い顧客セグメントを特定し、キャンペーンを配信できます。
- **Snapchat を介した休眠ユーザーの再活性化** : 通常のマーケティング施策への関心が低下したユーザーに対し、Snapchat 上でパーソナライズされたディスプレイ広告を直接配信してエンゲージできます。
- **Snapchat 広告予算の最大化** : Snapchat Ads 内で抑制リストを作成し、広告費を最適化できます。
- **Snapchat での新規顧客獲得の効率化** : Snapchat Ads プラットフォーム内で効果的な類似オーディエンスを構築できます。

# 統合

<Info>
  - **Snapchat ビジネスアカウント** : この機能を使用するには、Snapchat の有効な広告アカウントと、マーケティング API を使用するための広告アカウントが必要です。
  - **Snapchat のマーケティング API** : Snapchat のマーケティング API を使用して、MoEngage 経由でオーディエンスまたはユーザーを Snapchat Ads に同期します。既存のアプリと広告アカウントを使用するか、新しく作成して MoEngage に接続できます。Snapchat の Marketing API にアクセスするには、有効な Snapchat Business アカウントが必要です。
  - Snapchat Ads は Connected Channels アドオンの一部です。アカウントで有効にするには、担当の MoEngage CSM(カスタマーサクセスマネージャー)にお問い合わせください。
</Info>

## ステップ 1: Snapchat でビジネスアカウントを作成する

ビジネスアカウントを設定するには、次の手順を実行します。

1. 任意の Snapchat ユーザー名とパスワードを使用して [Ads Manager](https://businesshelp.snapchat.com/s/article/set-up-snapchat?language=en_US#:~:text=in%20to%20Ads-,Manager,-using%20your%20preferred) にログインします。
2. ビジネス名を入力し、**Next** をクリックします。
3. ビジネスの詳細を入力します。
4. 広告アカウントの国と通貨を確認し、電話番号とビジネスウェブサイトを追加します。
5. **Next** をクリックします。これにより、組織と広告アカウントが作成されます。

ビジネスを作成したら、Marketing API を有効化し、次の手順に従います。

1. [Ads Manager](https://ads.snapchat.com/) にログインします。
2. 左上隅のメニューをクリックして **Business Dashboard** を選択し、**Business Details** を選択します。
3. **\+OAuth App** をクリックします。
4. 利用規約に同意してアクセスを有効化します。
5. **Save** をクリックします。
6. MoEngage を Snapchat アプリの設定に接続するには、次の MoEngage データセンターに応じた URL を **Snap Redirect URI** ボックスに入力します。
   | データセンター | Redirect URI |
   | --- | --- |
   | DC-01 | `https://dashboard-01.moengage.com/v3/partner/oauth/callback` |
   | DC-02 | `https://dashboard-02.moengage.com/v3/partner/oauth/callback` |
   | DC-03 | `https://dashboard-03.moengage.com/v3/partner/oauth/callback` |
   | DC-04 | `https://dashboard-04.moengage.com/v3/partner/oauth/callback` |

![](/images/partner_37557855812756.png)

7. OAuth アプリが作成されたら、**Snap Client ID** と **Snap Client Secret Key** を取得します。

![](/images/partner_37557855814804.png)

<Info>
  - Snapchat を MoEngage App marketplace と統合するには、**Snap Client ID** と **Snap Client Secret Key** が必要です。
  - **Snap Client Secret Key** は生成時に一度だけ表示されます。
</Info>

## ステップ 2: App Marketplace で Snapchat を接続する

App marketplace で Snapchat を接続するには、次の手順を実行します。

1. MoEngage ダッシュボードの左側のナビゲーションメニューで、**App marketplace** をクリックします。
2. App Marketplace ページで **Snapchat** を検索します。<img src="/images/partner_38251623121428.png" />
3. **Snapchat** タイルをクリックします。
4. Snapchat ページで **Integrate** タブに移動します。
5. <img src="/images/partner_37557871671828.png" /> 矢印をクリックし、次のいずれかのオプションを選択します。
   - **Create Customer List**
   - **Add Users to Customer List**
   - **Remove Users from Customer list** <img src="/images/partner_38251623121556.png" />
6. 選択したコネクタタイプに応じて、次の詳細を入力します。
   | フィールド | 必須 | 説明 |
   | --- | --- | --- |
   | Connection name | はい | Snapchat 接続の名前です。 |
   | Snap Client ID | はい | OAuth アプリの Snap Client ID です。 |
   | Snap Client Secret Key | はい | OAuth アプリの Snap Client Secret Key です。 |
   | Advertiser ID | はい | Snapchat Ads アカウントの Advertiser ID です。 |

![](/images/partner_38251623121684.png)

7. **Connect** をクリックします。これで Snapchat 接続が統合されました。

## ステップ 3: MoEngage でキャンペーンを作成してオーディエンスを Snapchat Ads に同期する

MoEngage で Snapchat キャンペーンを作成するには、次の手順を実行します。

1. MoEngage ダッシュボードの左側のナビゲーションメニューで、**Engage** をクリックし、**Campaigns** をクリックします。
2. All campaigns ページで **\+ Create campaign** をクリックします。
3. **Create campaign** ダイアログボックスの **Connected Apps** で **Snapchat** をクリックし、最適な配信タイプをクリックします。 <img src="/images/partner_38251623121940.png" />
4. **Select audience** で **Filter users by** をクリックします。
5. **User property** タブで、Snapchat に同期するユーザーセグメントを選択します。他のセグメント条件と組み合わせることもできます。
6. キャンペーンのステップ 2 **Content** で、事前設定済みのコネクタを選択し、送信するコンテンツを指定します。次の詳細を入力します。

| フィールド | 説明 |
| --- | --- |
| **Connector** | 次のアクションを実行できます。 <ul><li>**Create Customer List**</li><li>**Add Users to Customer List**</li><li>**Remove Users from Customer List**</li></ul> |
| **Connections** | MoEngage App marketplace に追加した接続を選択します。 |

![](/images/partner_38251675507860.png)

### Snapchat の既存のオーディエンスに同期する

Snapchat の既存のオーディエンスにユーザーを追加または削除する場合は、**Audience ID** を指定する必要があります。[Snapchat Ads Manager](http://ads.snapchat.com/) に移動して、Snapchat 上のオーディエンスを確認できます。

1. 左上隅のメニュー \> **Assets** をクリックし、**Audiences** を選択します。
2. **Audience Name** をクリックしてオーディエンスを開きます。
3. URL から Audience ID を控えておきます。

![](/images/partner_38369831839124.png)

### Snapchat で新しいオーディエンスを作成する

Snapchat で新しいオーディエンスを作成するには、_Create Customer list_ コネクタを使用して次の手順を実行します。

1. **Create a customer list** コネクタと、作成した接続を選択します。
2. **Audience Name** とその他の必要な詳細を入力します。
3. テストキャンペーンを実行し、レスポンスを確認します。 <img src="/images/partner_38369831843860.png" /> ハイライトされた ID が Audience ID です。この ID を使用して、このオーディエンスにユーザーを追加または削除します。この ID は Snapchat の[こちら](#sync-to-an-existing-audience-on-snapchat)で確認できます。

<Warning>
  このキャンペーンは公開しないでください。公開すると、Snapchat 上に同じ名前のオーディエンスが複数作成されます。
</Warning>

## ステップ 4: Snapchat Ads のオーディエンスセグメントを確認する

[Snapchat Ads Manager](http://ads.snapchat.com/) で **Assets** \> **Audience** を選択すると、各オーディエンスのサイズと同期されたユーザーを確認できます。

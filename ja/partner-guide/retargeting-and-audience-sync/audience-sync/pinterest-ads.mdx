[Pinterest Ads](https://www.pinterest.com/) では、企業がさまざまなターゲティングオプションを使用して、ウェブサイトを過去に訪問したユーザー、Pin にエンゲージしたユーザー、類似の製品やトピックに関心のあるユーザーなど、特定のオーディエンスにリーチできます。

# MoEngage × Pinterest Ads

MoEngage と Pinterest の統合により、顧客データを Pinterest Ads にシームレスに転送できます。このデータを活用して、特定のユーザー行動やセグメンテーションに基づくターゲット広告リストを作成し、より関連性の高い広告配信を実現できます。

## ユースケース

Pinterest を MoEngage と統合すると、次のユースケースを実現できます。

- **ユーザーエンゲージメントとコンバージョンの向上** : 複数のチャネルを通じて価値の高いユーザーをターゲティングし、購入やエンゲージメントを促進できます。
- **反応の低いユーザーの再エンゲージメント** : 他のマーケティングチャネルへの反応が低いユーザーに対し、過去の行動に基づいたターゲットディスプレイ広告を表示できます。
- **広告費の最適化** : 抑制オーディエンスを作成し、すでにブランドのロイヤルカスタマーであるユーザーに広告が配信されないようにできます。
- **効率的な新規ユーザー獲得** : 類似オーディエンスを作成し、より効率的に新規ユーザーを獲得できます。

# 統合

<Info>
  - **Pinterest ビジネスアカウント** : この機能を使用するには、Pinterest の有効な広告アカウントが必要です。
  - **Pinterest デベロッパーアプリ** : 必要な権限を持つ既存のアプリを使用するか、新しいアプリを作成します。
  - **Pinterest のマーケティング API** : Pinterest のマーケティング API を使用して、MoEngage 経由でオーディエンスまたはユーザーを Pinterest Ads に同期します。これらのマーケティング API を使用するには、Pinterest アプリと広告アカウントが必要です。既存のアプリと広告アカウントを使用するか、新しく作成して MoEngage に接続できます。
  - Pinterest Ads は Connected Segments アドオンの一部です。アカウントで有効にするには、担当の MoEngage CSM(カスタマーサクセスマネージャー)にお問い合わせください。
</Info>

## ステップ 1: Pinterest でデベロッパーアプリを作成する

Pinterest デベロッパーアカウントを設定するには、次の手順を実行します。

1. [Pinterest Developers Platform](https://developer.pinterest.com/) にアクセスします。
2. [Pinterest のドキュメント](https://developers.pinterest.com/docs/getting-started/connect-app/)の手順に従って、新しいアプリを設定するか、既存のアプリを使用します。
3. MoEngage を Pinterest アプリの設定に接続するには、次の MoEngage データセンターに応じた URL を **Redirect link** ボックスに入力します。 <img src="/images/partner_37662413714580.png" />
   | データセンター | Redirect URI |
   | --- | --- |
   | DC-01 | `https://dashboard-01.moengage.com/v3/partner/oauth/callback` |
   | DC-02 | `https://dashboard-02.moengage.com/v3/partner/oauth/callback` |
   | DC-03 | `https://dashboard-03.moengage.com/v3/partner/oauth/callback` |
   | DC-04 | `https://dashboard-04.moengage.com/v3/partner/oauth/callback` |
4. MoEngage には次のスコープへのアクセスが必要です。
   | 必要なスコープ | ユースケース |
   | --- | --- |
   | `ads:write` | Pinterest でオーディエンスを作成および管理できます。 |
   | `ads:read ` | Pinterest の既存のオーディエンスを読み取ることができます。 |
5. Pinterest アプリのダッシュボードの **Configure** タブで、**App id** と **App secret key** を取得します。 <img src="/images/partner_37662413715220.png" />

<Info>
  **App id** と **App secret key** は、MoEngage App marketplace で Pinterest 統合を設定する際に必要です。
</Info>

## ステップ 2: App Marketplace で Pinterest を接続する

App marketplace で Pinterest を接続するには、次の手順を実行します。

1. MoEngage ダッシュボードの左側のナビゲーションメニューで、**App marketplace** をクリックします。
2. App Marketplace ページで **Pinterest** を検索します。 <img src="/images/partner_38252358671508.png" />
3. **Pinterest** タイルをクリックします。
4. **Pinterest** ページで **Integrate** タブに移動します。
5. <img src="/images/partner_37662424803348.png" /> 矢印をクリックし、次のいずれかのオプションを選択します。
   - **Create Customer List**
   - **Update Customer List** <img src="/images/partner_38252406905108.png" />
6. 選択したコネクタタイプに応じて、次の詳細を入力します。

| フィールド | 必須 | 説明 |
| --- | --- | --- |
| **Connection name** | はい | Pinterest 接続の名前です。識別子を含めた接続名を入力します。 |
| **App id** | はい | アプリケーションの一意の ID です。App ID とも呼ばれます。 |
| **App secret key** | はい | アプリのシークレットキーです。Pinterest の **App dashboard** \> **Configure** タブにあります。 |
| **Advertiser ID** | はい | Pinterest Ads アカウントの Advertiser ID です。 |

![](/images/partner_38252358672276.png)

7. **Connect** をクリックします。これで Pinterest 接続が統合されました。

## ステップ 3: MoEngage でキャンペーンを作成してオーディエンスを Pinterest Ads に同期する

MoEngage でキャンペーンを作成するには、次の手順を実行します。

1. MoEngage ダッシュボードの左側のナビゲーションメニューで、**Engage** をクリックし、**Campaigns** をクリックします。
2. All campaigns ページで、\+ Create campaign をクリックします。
3. **Create campaign** ダイアログボックスの **Connected Apps** で **Pinterest** をクリックし、最適な配信タイプをクリックします。 <img src="/images/partner_38252358672788.png" />
4. **Select audience** で **Filter users by** をクリックします。
5. **User property** タブで、Pinterest に同期するユーザーセグメントを選択します。他のセグメント条件と組み合わせることもできます。
6. キャンペーンのステップ 2 **Content** で、事前設定済みのコネクタを選択し、送信するコンテンツを指定します。次の詳細を入力します。

| フィールド | 説明 |
| --- | --- |
| **Connector** | 次のアクションを実行できます。 <ul><li>**Create Customer List**</li><li>**Update Customer List**</li></ul> |
| **Connections** | MoEngage App marketplace に追加した接続を選択します。 |

![](/images/partner_38252406906132.png)

選択したコネクタに応じて、次の情報を指定する必要があります。

<Tabs>
  <Tab title="Create Customer List">
    | フィールド | 説明 |
    | :-- | :-- |
    | **Customer List Name** | Customer List の名前です。指定した名前で新しい Customer List が作成されます。 |
    | **Customer List Type** | この新しい顧客リストで使用する識別子タイプを選択します。デフォルトでは、すべての識別子は SHA-256 でハッシュ化されます。 |

    ![](/images/partner_38252358673812.png)
  </Tab>
  <Tab title="Update Customer List">
    | **フィールド** | **説明** |
    | --- | --- |
    | **Add or remove users** | Customer List にユーザーを追加するか削除するかを選択します。 |
    | **Customer List ID** | Customer List の ID です。 |
    | **Select Identifier Type** | Pinterest でユーザーを照合するための識別子タイプを選択します。MoEngage は次の 2 つの識別子をサポートしています。 <ul><li>Email ID</li><li>Google Advertiser ID</li></ul> |
    | **Identifier Value** | **@** を入力し、識別子の値を含むユーザー属性を選択します。デフォルトでは、Email には「Email (Standard)」、Google Advertiser ID には「Google Advertiser ID (Android)」を使用できます。 |

    ![](/images/partner_38252406907028.png)
  </Tab>
</Tabs>

7. これでキャンペーンをテストし、オーディエンスに送信する準備が整いました。**Test** 機能を使用して、コネクタの設定をテストすることもできます。 <img src="/images/partner_37662413716244.png" /> テストユーザーがメッセージを正常に受信すれば、設定は完了です。
8. キャンペーンを公開します。

**注意** : 新しいオーディエンスを作成する場合は、キャンペーンを公開しないでください。

## ステップ 4: Pinterest Ads のオーディエンスセグメントを確認する

Pinterest Ads Manager アカウントで **Business Manager** \> **Audience** を選択すると、各オーディエンスのサイズを確認できます。

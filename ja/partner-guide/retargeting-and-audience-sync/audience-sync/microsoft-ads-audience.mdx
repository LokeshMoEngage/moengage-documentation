[Microsoft Advertising](https://ads.microsoft.com)は、クリック課金（PPC）型の広告プラットフォームです。企業はキーワードに基づいて広告を表示し、Bing、Yahoo、パートナーサイトを含むMicrosoft Search Network全体で特定のオーディエンスをターゲットにできます。

## MoEngage × Microsoft Advertising

MoEngageとMicrosoft Advertisingの連携により、MoEngageのオーディエンスセグメントをMicrosoft Advertisingに同期できます。これにより、特定のエンドユーザーに合わせた、高度にターゲティングされた広告キャンペーンの作成とコンバージョンの追跡が可能になります。

## ユースケース

MoEngageをMicrosoft Advertisingと連携すると、以下のユースケースに対応できます。

- **ユーザー維持率の向上**: 購入履歴や行動パターンに基づいてリマーケティングキャンペーンを作成し、最近エンゲージしていない既存ユーザーをターゲットにできます。
- **VIPユーザーのターゲティング**: 価値の高いユーザー向けのプレミアムオーディエンスセグメントを作成し、限定オファーやプロモーションを含むパーソナライズされた広告を配信できます。
- **カート放棄からの回復**: ショッピングカートを放棄したユーザーのデータをCustomer Lists（検証待ち）にアップロードし、購入を完了するよう促すターゲット広告を表示できます。
- **広告費の最適化**: 抑制オーディエンスを作成してロイヤルユーザーに獲得広告が表示されないようにしつつ、類似オーディエンスを構築して新規ユーザーを効率的に獲得できます。
- **クロスセルとコンバージョントラッキング**: 補完的な製品でユーザーをターゲットにし、オフラインコンバージョンを追跡して、キャンペーンの効果を測定し、ROIを最適化できます。

# 連携

<Info>
  **前提条件**

   この機能を使用するには、必要な権限を持つ[Microsoft Advertisingアカウント](https://ads.microsoft.com)にアクセスできる必要があります。

  **注意**: Microsoft AdvertisingはConnected Segmentsアドオンの一部です。アカウントで有効にするには、担当のMoEngageカスタマーサクセスマネージャー（CSM）にお問い合わせください。
</Info>

## ステップ1: Microsoft AdvertisingのDeveloper Tokenを取得する

1. [Microsoft Advertisingアカウント](https://ads.microsoft.com/)にログインします。
2. **Tools** \> **Developer settings**に移動します。
3. **Developer settings**ページで、**Developer token**をコピーします。
4. トークンがない場合は、**Request Token**をクリックします。
   <Info>
     **情報**
     - Microsoft Advertising UIを通じて、MicrosoftのCustomer Match Terms and Conditionsに同意する必要があります（1回限りの設定）。
     - MoEngage App Marketplaceで連携を設定するには、Client ID、Client Secret、Developer Tokenのすべてが必要です。
   </Info>
   ![Microsoft Advertisingのdeveloper settingsページからDeveloper Tokenをリクエストする](/images/partner_47757046468116.png)
5. Microsoft Advertisingアカウントのアドレスバーから、**cid**パラメーターと**aid**パラメーターの値をコピーします。

![Screenshot 2026-03-31 at 3.14.52 PM.png](/images/partner_47757046468500.png)

## ステップ2: App MarketplaceでMicrosoft Advertisingを接続する

App MarketplaceでMicrosoft Advertisingを接続するには、以下の手順を実行します。

1. MoEngage UIの左側のナビゲーションメニューで、**App Marketplace**をクリックします。
2. App Marketplaceページで、**Microsoft Advertising**を検索します。
3. **Microsoft Ads Audience**タイルをクリックします。
4. **Microsoft Ads Audience**ページで、**Integrate**タブに移動します。
5.  <img src="/images/partner_41667663675412.png" alt="矢印をクリックし、以下のオプションのいずれかを選択します" />   矢印をクリックし、以下のオプションのいずれかを選択します。
   - **Create Audience**
   - **Update Users to Audience**
6. 選択したコネクタタイプに基づいて、以下の詳細を入力します。
   | フィールド | 必須 | 説明 |
   | --- | --- | --- |
   | Connection name | はい | Microsoft Advertising接続の名前。 |
   | Developer Token | はい | Microsoft AdvertisingのDeveloper Token。 |
   | Customer ID | はい | Microsoft Advertisingアカウントの**Customer ID**。URL内の**cid**で確認できます。 |
   | Account ID | はい | Microsoft Advertisingアカウントの**Account ID**。URL内の**aid**で確認できます。 |
7. **Connect**をクリックします。 <img src="/images/partner_47757046469652.png" alt="Screenshot 2026-03-31 at 3.05.51 PM.png" />
8. アカウントを承認するためのMicrosoftログインページにリダイレクトされます。
9. 管理者権限を持つアカウントでログインし、接続の確立に必要な権限をMoEngageに付与します。 <img src="/images/partner_47757476341396.png" alt="Screenshot 2026-03-31 at 3.49.13 PM.png" />
10. 認証されると、自動的にMoEngageダッシュボードにリダイレクトされます。

## ステップ3: MoEngageでMicrosoft Advertisingにオーディエンスを更新するキャンペーンを作成する

MoEngageでMicrosoft Advertisingキャンペーンを作成するには、以下の手順を実行します。

1. MoEngage UIの左側のナビゲーションメニューで、**Engage**をクリックし、**Campaigns**をクリックします。
2. **All campaigns**ページで、**\+ Create campaign**をクリックします。
3. **Create campaign**ダイアログボックスの**Connected Apps**で、**Microsoft Ads Audience**をクリックし、最も適切な配信タイプをクリックします。
4. **Select audience**で、**Filter users by**をクリックします。
5. **User property**タブで、Microsoft Advertisingに同期するユーザーセグメントを選択します。これを他のセグメント条件と組み合わせることもできます。
6. キャンペーンのステップ2の**Content**で、事前に設定したコネクタを選択し、送信するコンテンツを指定します。

### Microsoft Advertisingの既存のCustomer Listに更新する

Microsoft Advertisingの既存のCustomer Listにユーザーを追加または削除する場合は、Audience IDを指定する必要があります。以下の手順を実行すると、このIDを確認できます。

1. Microsoft Advertisingアカウントで、**Tools & Settings**に移動します。
2. **Audiences** \> で**Audiences Library**を選択します。
3. **ID**列から**Audience ID**を控えておきます。

### Microsoft Advertisingで新しいオーディエンスを作成する

Microsoft Advertisingで新しいオーディエンスを作成するには、**Create Audience**コネクタを使用して以下の手順を実行します。

1. **Create Audience**コネクタと作成した接続を選択します。
2. Audience Nameとその他の詳細を入力します。
3. テストキャンペーンを実行し、レスポンスを確認します。 <img src="/images/partner_47757046470420.png" alt="Microsoft Advertising Customer ListのAudience IDを示すテストキャンペーンのレスポンス" />
4. ハイライト表示されたIDがAudience IDです。このIDを使用して、このAudience Listにユーザーを追加または削除します。[上記の手順](#update-to-an-existing-customer-list-on-microsoft-advertising)に従うと、Microsoft AdvertisingアカウントでこのIDを確認できます。
   <Warning>
     このキャンペーンは公開しないでください。公開すると、Microsoft Advertisingに同じ名前のCustomer Listが複数作成されます。
   </Warning>

### キャンペーンの実行

選択したコネクタに基づいて、以下の情報を指定する必要があります。

<Tabs>
  <Tab title="Create Audience">
    | フィールド | 必須 | 説明 |
    | --- | --- | --- |
    | Audience Name | はい | オーディエンスの名前。指定した名前で新しいAudience Listが作成されます。 |
    | Description | いいえ | オーディエンスの説明を入力します。 |
    | Membership Duration | はい | ユーザーがリストに登録される日数（1～180）。この期間が経過すると、ユーザーは自動的に削除されます。 |
    | Scope | はい | このオーディエンスを使用できるユーザーを定義します。現在のアカウントに限定する場合は**Account**を、カスタマープロファイル配下のすべてのアカウントで共有する場合は**Customer**を選択します。 |

    ![MoEngageのCreate Audienceコネクタのフィールド](/images/partner_47757046471060.png)
  </Tab>
  <Tab title="Update Users to Audience">
    | フィールド | 必須 | 説明 |
    | --- | --- | --- |
    | Audience ID | はい | Microsoft Advertising Customer Listの数値ID。Audience Managerで確認できます。 |
    | Action Type | はい | 実行するアクションを選択します。 <ul><li>Add Users</li><li>Remove Users</li></ul> |
    | Select Identifier | はい | Microsoft Advertisingと照合するユーザー識別子のタイプを選択します。オプションは以下のとおりです。 <ul><li>Email</li><li>Phone</li><li>CRM ID <br />**注意**: すべての識別子は、Microsoft Advertisingに送信される前にSHA-256でハッシュ化されます。</li></ul> |
    | User Identifier Value | はい | 選択した識別子の値。**@**と入力し、関連するユーザーデータを含むユーザー属性を選択します（例: メールアドレスの場合は**Email (Standard)**）。 |

    ![MoEngageのUpdate Users to Audienceコネクタのフィールド](/images/partner_47757038211988.png)
  </Tab>
</Tabs>

1. これでキャンペーンをテストして送信する準備が整いました。Test機能を使用して、コネクタの設定をテストすることもできます。 <img src="/images/partner_41668254724244.png" alt="公開前にMicrosoft Advertisingオーディエンスキャンペーンをテストする" />
2. テストユーザーがメッセージを正常に受信すれば、設定の準備は完了です。
3. キャンペーンを公開します。

## ステップ4: Microsoft AdvertisingのCustomer Listを表示する

Microsoft Advertisingアカウントで**Tools & Settings** \> **Shared Library** \> **Audiences**に移動すると、各Customer Listのサイズと同期されたユーザーを確認できます。

<Info>
  **情報**

  オーディエンスを作成または更新した後、新しいサイズがMicrosoft Advertisingに反映されるまでには、通常24～48時間かかります。
</Info>

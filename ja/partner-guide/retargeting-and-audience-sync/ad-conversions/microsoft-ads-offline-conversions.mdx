---

オフラインコンバージョントラッキングを使用すると、Webサイト外で発生した売上やその他の価値ある顧客行動を、Microsoft Advertisingキャンペーンにアトリビューションできます。これらの行動には、店舗での購入、電話注文、相談などが含まれます。

MoEngageのイベントをMicrosoft Advertisingと同期することで、以下が可能になります。

- デジタル広告費とオフライン収益の間のループを閉じることで、ROI（投資収益率）を正確に測定します。
- クリックではなく実際のコンバージョンデータに基づいてキャンペーンの入札を最適化します。
- 価値の高いオフライン行動を促進するキーワードや広告を把握することで、ターゲティングを改善します。

詳細については、[オフラインコンバージョンに関するMicrosoft Advertisingのドキュメント](https://help.ads.microsoft.com/apex/index/3/en/56852)を参照してください。

<Info>
  **前提条件**

  この機能を使用するには、必要な権限を持つ[Microsoft Advertisingアカウント](https://ads.microsoft.com)にアクセスできる必要があります。

  **注意**: Microsoft Advertising Offline ConversionsはConnected Channelsアドオンの一部です。アカウントで有効にするには、担当のMoEngageカスタマーサクセスマネージャー（CSM）にお問い合わせください。
</Info>

## ステップ1: App MarketplaceでMicrosoft Advertisingを接続する

App MarketplaceでMicrosoft Advertisingを接続するには、以下の手順を実行します。

1. MoEngage UIの左側のナビゲーションメニューで、**App Marketplace**をクリックします。
2. **App Marketplace**ページで、**Microsoft Advertising Offline Conversions**を検索します。
3. **Microsoft Advertising Offline Conversions**タイルをクリックします。
4. **Microsoft Advertising Offline Conversions**ページで、**Integrate**タブに移動します。
5. 以下の詳細を入力します。
   | フィールド | 必須 | 説明 |
   | --- | --- | --- |
   | Connection name | はい | Microsoft Advertising Offline Conversions接続の名前。 |
   | Developer Token | はい | Microsoft Advertisingアカウントの**Tools** \> **Developer settings**にある開発者トークン。 |
   | Customer ID | はい | Microsoft Advertisingアカウントの一意のCustomer ID。URL内の**cid**で確認できます。 |
   | Account ID | はい | コンバージョンが記録されるMicrosoft Advertisingアカウントの一意のID。URL内の**aid**で確認できます。 |
6. **Connect**をクリックします <img src="/images/partner_47757609717524.png" alt="Screenshot 2026-03-31 at 3.50.36 PM.png" />アカウントを承認するためのMicrosoftログインページに移動します。
7. アカウントを承認するためのMicrosoftログインページにリダイレクトされます。
8. 管理者権限を持つアカウントでログインし、接続の確立に必要な権限をMoEngageに付与します。 <img src="/images/partner_47757651023124.png" alt="Screenshot 2026-03-31 at 3.49.13 PM.png" />
9. 認証されると、自動的にMoEngageダッシュボードにリダイレクトされます。

## ステップ2: オフラインコンバージョンを同期するキャンペーンを作成する

コネクタを設定した後、MoEngageキャンペーン内でコンバージョンイベントを送信します。オフラインコンバージョンを同期するキャンペーンを作成するには、以下の手順を実行します。

1. MoEngage UIの左側のナビゲーションメニューで、**Engage**をクリックし、**Campaigns**をクリックします。
2. **All campaigns**ページで、**\+ Create campaign**をクリックします。**Create campaign**ダイアログボックスが表示されます。
3. **Connected Apps**で、**Microsoft Advertising Offline Conversions**をクリックします。
4. キャンペーン作成の**Content**ステップで、MoEngageの属性を以下の必須のMicrosoftフィールドにマッピングします。
   | フィールド | 必須 | 説明 |
   | --- | --- | --- |
   | **Goal Name** | はい | Microsoft Advertisingダッシュボードに表示されるコンバージョン目標の名前。この名前は完全に一致している必要があります。 |
   | **Microsoft Click ID (MSCLKID)** | 任意 | ユーザーが広告をクリックした際にユーザープロファイルに取得された一意のID。 |
   | **Conversion Value** | はい | コンバージョンの金銭的価値。 |
   | **Currency Code** | はい | Microsoft Advertisingアカウントの設定と一致する通貨（例: USDまたはEUR）。 |
   | **Attribution Model** | 任意 | Microsoft Advertising以外で使用されるアトリビューションモデルの名前（例: Linear、Time Decay、Position-based、またはカスタムモデル名）。 |
   | **Attribution Credit** | 任意 | 0から1の間の小数値（例: 50%のクレジットの場合は0.5）。この特定のクリックに割り当てられるコンバージョンの割合を表します。このフィールドは、Microsoft Advertisingで目標が_IsExternallyAttributed_に設定されている場合にのみ適用されます。 |
   | <img src="/images/partner_47757651024020.png" alt="Screenshot 2026-03-31 at 3.54.19 PM.png" /> |

<Info>
  **情報**

  - **90日間の制限**: Microsoft Advertisingは、過去90日以内に発生したクリックに対してのみ取引を照合できます。
  - **わかりやすい命名**: 接続はアカウントごとに固有であるため、混乱を避けるためにコネクタにわかりやすい名前を付けてください（例: MSAds\_US\_Sales）。
  - **データの正確性**: 照合率を最大化するため、MSCLKIDデータが一貫して取得され、ユーザープロファイルに保存されていることを確認してください。
  - **テスト**: 属性のマッピングとコンバージョントラッキングを検証するため、公開前に必ずテストキャンペーンを実行してください。
  - **アカウントレベルの管理**: 適切なアトリビューションと通貨処理を確保するため、Microsoft Advertisingアカウントごとに個別のコネクタを維持してください。
</Info>

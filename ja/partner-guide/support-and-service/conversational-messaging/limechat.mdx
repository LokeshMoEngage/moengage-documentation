# はじめに

LimeChat は、e コマースブランドが WhatsApp 上で販売、サポート、マーケティングを行えるよう支援します。Limechat は、WhatsApp を通じて CAC の削減、リテンションの向上、優れた体験の提供に貢献します。Limechat は次の機能を提供しています。

- 人間レベルの体験を実現する GPT 搭載チャットボット
- スパムにならずに 2 倍の RoI を実現する双方向 WhatsApp キャンペーン
- e コマース向けに構築された AI 対応 CRM

# MoEngage × Limechat

MoEngage と Limechat の統合により、最初のアプローチから会話型体験への誘導、そしてインテリジェントなリターゲティングによるオムニチャネルのフォローアップまで、エンドツーエンドの顧客ライフサイクルをシームレスにオーケストレーションできます。この統合により、次のことが可能になります。

- MoEngage から Limechat キャンペーンをトリガーする
- Limechat から MoEngage にユーザー行動イベントを受信する

# 統合

<Info>
  - Limechat アカウントを持っていることを確認してください。
  - Limechat のアクセストークンにアクセスできることを確認してください。アクセストークンは、Limechat ダッシュボードで Profile \> Profile Settings \> Access token に移動して確認できます。
</Info>

## MoEngage から Limechat キャンペーンをトリガーする

### ステップ 1: Limechat のアカウント ID とアクセストークンを取得する

#### Limechat のアカウント ID を取得する

Limechat ダッシュボードで、URL からアカウント ID をコピーします。

![Untitled 3-05d8344c2466545cc7fffb7c16d7e204.png](/images/partner_27700893924244.png)

#### Limechat のアクセストークンを取得する

Limechat ダッシュボードで、

1. 左下隅にあるプロフィール画像をクリックします
2. **Profile Settings** をクリックします
3. このページの一番下までスクロールし、Access Token をコピーします <img src="/images/partner_27700893927572.png" alt="Untitled 7-98ddd32b3e5bb2e9a6d5e9ad0dbd3909.png" />

### ステップ 2: MoEngage でコネクタキャンペーンを作成する

MoEngage でコネクタキャンペーンを作成するには、

1. Create Campaign \> Connectors \> Custom に移動し、ニーズに最適な配信タイプを選択します <img src="/images/partner_27700893928596.png" alt="Screenshot_2022-02-21_at_10.48.46_PM.png" />
2. キャンペーンのステップ 2 で

- メソッドとして POST を選択します
- Webhook URL として次を追加します: `https://app.limechat.ai/api/v1/accounts/{account_id}/store_notifications/create_notification_limekit/`

ここで、{account_id} をステップ 1 でコピーしたアカウント ID に置き換えます。

- Headers に次を追加します
  - Content-Type を application/json に設定します
  - api\_access\_token に、ステップ 1 でコピーした `{Limechat access token}` を設定します

Body で Raw を選択し、コードをコピーして貼り付けます。

```json
{
"phone": {{UserAttribute['Mobile Number (Standard)'\]}},
"template_id": "112",
"first_name": "{{UserAttribute['FirstName']}}",
"email": {{UserAttribute['email']}},
"template_attributes": [
"Akshay",
"[https://app.limechat.ai/](https://app.limechat.ai/)"
],
"status": "closed",
"additional_attributes": {},
"contact_additional_attributes": {},
"label": ""
}
```

3. これで、キャンペーンをテストして送信する準備が整いました。Create Connector Campaign のステップ 2 にある Test 機能を使用して、コネクタの設定をテストすることもできます。 <img src="/images/partner_27700932088596.png" alt="Screen_Shot_2022-02-22_at_11.12.42_AM.png" />

テストユーザーがメッセージを正常に受信すれば、設定は完了です。キャンペーンを公開してください。

## Limechat からユーザー行動イベントを受信する

### ステップ 1: MoEngage のエンドポイントを取得する

MoEngage のカスタマーサクセスマネージャーに連絡して、Limechat 専用のエンドポイントを取得してください。

### ステップ 2: Limechat で Webhook を設定する

この Webhook と次の情報を Limechat のカスタマーサクセスマネージャーに提供します。

| フィールド | 説明 |
| --- | --- |
| Webhook | カスタマーサクセスマネージャーから提供された MoEngage のエンドポイントです。Headers |
| Header(s) | 次のヘッダーを指定します。 <ul><li>Content-Type: application/json</li><li>Authorization: オンラインの [Basic Auth Header Generator](https://www.debugbear.com/basic-auth-header-generator) ツールを使用して Basic トークンを取得します。ユーザー名に Workspace ID、パスワードに Data API Key を入力します。最終的なトークンは次のようになります(MoEngage Dashboard \>\> Settings \>\> APIs): `Basic Qk5CR1NNNUR4eHh4eHhWQ1hSRFJEWTdSOlFsWHVoTHVaeHh4eHh4QWQrQnBYUEotNw==`</li></ul> |

### **ステップ 3: MoEngage でイベントを確認する**

Limechat で Webhook を設定すると、MoEngage ダッシュボードでこれらのイベントを確認できるようになります。

#### **サポートされているイベント**

| イベント | イベントコード | 説明 |
| --- | --- | --- |
| Message Status Update Event | lc\_message\_status | 特定のフローとノードのメッセージステータスを更新します。 |
| Button Interaction | lc\_button\_clicked | ボタンのインタラクションを通知します。 |
| Opt Out | lc\_user\_wa\_opt\_out | ユーザーがブランドからオプトアウトしたときに通知します。 |
| Conversational & Contact Tag by agents | lc\_tag\_added\_by\_agent | リンクのクリックは、LimeChat がリンクを短縮した場合にのみ機能します。 |
| Opt In | lc\_user\_wa\_opt\_in | ユーザーがブランドにオプトインしたときに通知します |

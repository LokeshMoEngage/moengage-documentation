# はじめに

[Verloop.io](https://verloop.io/) は、企業がチャネル全体で優れた体験を提供できるよう支援します。Verloop の会話型 AI プラットフォームは、高度な NLP と ML を使用して、自然言語で顧客の問題を自動的に解決します。

## ユースケース

_A. 旅行・ホスピタリティ_(情報提供) - ユーザーが旅行パッケージを予約し、次のオプションを含む予約に関する WhatsApp メッセージをユーザーに送信したい場合 -

1. 請求書を取得する
2. 旅程を表示する
3. 折り返し電話をリクエストする

_B. 通信_(コンバージョン) - ユーザーの請求書の支払期日が近づいています。次のオプションを含むリマインダーメッセージを WhatsApp で送信したい場合 -

1. 請求書を表示する
2. 未払い金を支払う
3. アプリを開く

_C. フィンテック_(リテンション) - ユーザーに未請求のポイントがいくつかあります。次のオプションを使って変更を通知したい場合 -

1. 報酬を請求する
2. ポイントを獲得する
3. お問い合わせ

これらの各ユースケースでは、ユーザーが WhatsApp メッセージに返信でき、ボットのレシピがユーザーの問題解決をガイドするか、ユーザーをチームにつなぎます。

# MoEngage × Verloop

MoEngage と Verloop の統合により、最初のアプローチから会話型体験への誘導、そしてインテリジェントなリターゲティングによるオムニチャネルのフォローアップまで、エンドツーエンドの顧客ライフサイクルをシームレスにオーケストレーションできます。

## ステップ 1: Verloop でアウトリーチを作成する

[こちら](https://help.verloop.io/knowledge-base/getting-started-with-outreach/)の手順に従って、Verloop でアウトリーチを作成します。Verloop ダッシュボードで次の操作を行います -

### 新しいアウトリーチを作成する

1. Outreach に移動します。
2. 右上の「\+ New Outreach」ボタンをクリックします。
3. Name**フィールド**に入力して、キャンペーンに名前を付けます。
4. Channel は現在、デフォルトで WhatsApp に設定されています。
5. Tags で適切なタグを追加し、キャンペーンを簡単に識別して他のキャンペーンと区別できるようにします。
6. Trigger type として API を選択します <img src="/images/partner_4678042267284.png" alt="Screenshot_2021-06-30_at_5.14.21_PM.png" />

### アウトリーチテンプレートを定義する

1. 新しいメッセージを作成するには、New Message ボタンをクリックします。既存のリストからメッセージを選択して、既存の承認済みテンプレートを使用することもできます。<img src="/images/partner_4678020635412.png" alt="Screenshot_2021-06-30_at_5.16.33_PM.png" />
2. 「\+ Add Approved Messages」をクリックします。
3. Message でテンプレート名を追加します。
4. WhatsApp Template ID を追加します。
5. 希望する言語を選択します。
6. Template Type で、テキスト、画像、ドキュメントなど、メッセージを表示する形式を選択します。
7. キャンペーンで表示するテンプレートメッセージを入力します。

#### WhatsApp ボタンを有効にする(オプション)

1. ボタンには Call to action と Quick reply の 2 種類があります
2. WhatsApp では、Call to action は最大 2 つ、Quick reply は最大 3 つのボタンを使用できます

**a. Call to action**

i. Call phone number と Visit website の 2 種類から選択できます

ii. Call phone number ボタンでは、ボタンの名前を追加し、ユーザーに電話をかけてもらう電話番号を入力する必要があります。

iii. Visit website ボタンでは、ボタンの名前を追加し、ユーザーを誘導する URL を入力する必要があります。

**b. Quick reply**

i. このオプションでは最大 3 つのボタンを追加できます。

ii. ユーザーに表示するボタン名を追加します。

### 終了アクションを選択する

![](https://lh3.googleusercontent.com/lMzXHj_OXIvsRdbk-U4uEgTFsaUb_RDnjACBPskRAXXvx9IUUh4Al_f0ni0Q8agKP4v5Hv8lg2H1-tvemp5VFoNYnxU3m_wV38pUJYjNxDZq0PX8rlVGZ8zCYHvD1-DxfSvMIZ-l)

このステップでは、エンドユーザーがキャンペーンを操作した直後に次のステップをトリガーし、ユーザーにアクションを促すことができます。

1. Action に移動します。
2. 既存のレシピに従って会話を進めたい場合は、Action で [Bot Recipe](https://docs.verloop.io/build/recipe-builder/overview) をクリックします。そのためには、Bot recipe でドロップダウンを選択し、キャンペーンに最適なレシピを選択します。
3. キャンペーンを公開する前に、テスト連絡先に送信してテストすることもできます。キャンペーンのメッセージをもう一度確認し、Test をクリックします。
4. Live に設定します。

## ステップ 2: MoEngage でコネクタキャンペーンを作成する

MoEngage でコネクタキャンペーンを作成するには、

1. Create Campaign \>\> Connectors \>\> Custom に移動し、ニーズに最適な配信タイプを選択します <img src="/images/partner_4678168106516.png" alt="Screenshot_2022-02-21_at_10.48.46_PM.png" />
2. キャンペーンのステップ 2 で

- メソッドとして POST を選択します
- Webhook URL として次を追加します: [https://whatsappdemo.verloop.io/api/v1/Campaign/SendMessage](https://whatsappdemo.verloop.io/api/v1/Campaign/SendMessage)
- Headers に次を追加します
  - Content-Type を application/json に設定します
  - Authorization に Verloop の認証キーを設定します
- Body で Raw を選択し、Verloop のアウトリーチからコードをコピーして貼り付けます。
  ![Screenshot\_2022-03-10\_at\_5.28.15\_PM.png](/images/partner_4678442093844.png)

**注意-** アウトリーチのコードをコピーするには、_Outreach_ に移動します。_Actions_ \>\> _View details_ をクリックします。Copy _code_ をクリックできます。

<Frame>
  ![Verloop](/images/verloop.png)
</Frame>

3. これで、キャンペーンをテストして送信する準備が整いました。Create Connector Campaign のステップ 2 にある Test 機能を使用して、コネクタの設定をテストすることもできます。 <img src="/images/partner_4678362626196.png" alt="Screen_Shot_2022-02-22_at_11.12.42_AM.png" />

テストユーザーがメッセージを正常に受信すれば、設定は完了です。キャンペーンを公開してください。

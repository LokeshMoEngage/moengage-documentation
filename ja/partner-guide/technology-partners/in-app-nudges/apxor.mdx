# はじめに

[Apxor](https://www.apxor.com/) は、モバイルアプリがエンドユーザーのオンボーディング、アクティベーション、エンゲージメント、リテンション、コンバージョンのために、高度にコンテキスト化されたアプリ内コミュニケーションを作成できるよう支援するアプリインテリジェンスプラットフォームです。

# MoEngage × Apxor

MoEngage と Apxor の統合により、プロダクトチームとマーケティングチームは分析を活用して、コンテキストに応じた高度にパーソナライズされたウォークスルー、ツールチップ、コーチマーク、スポットライト、アプリ内メッセージ、アンケートを作成できます。特定のユーザーグループの行動に影響を与えるために、マーケターは顧客のセグメントを作成でき、Apxor はこれらのセグメントをターゲットにして、効果的なオンボーディング、アクティベーション、機能の導入、お知らせを推進し、Product Led Growth を真に実現します。

## SDK 統合の設定

1. アプリケーションの `build.gradle` ファイルに次の依存関係を追加し、"Sync Now" ボタンをクリックします。パス: /app/build.gradle
   <CodeGroup>
   ```java Java
   dependencies 
   {
       //...
       // Event tracking and a must have dependency for other plugins
       implementation 'com.apxor.android:event-logging-helper:1.5.3@aar'
       // ..
   }
   ```
   </CodeGroup>
2. 選択した SDK のイベントログ API をすべて検索し、Apxor が提供する関数に置き換えます。

次のコードを:

<CodeGroup>

```java Java
Properties properties = new Properties();
```

</CodeGroup>

次のコードに置き換えます。

<CodeGroup>

```java Java
PropertiesWrapper propertiesWrapper = new PropertiesWrapper();
```

</CodeGroup>

また、次のコードを:

<CodeGroup>

```java Java
MoEAnalyticsHelper.INSTANCE.trackEvent(context, "Event", properties);
```

</CodeGroup>

次のコードに置き換えます。

<CodeGroup>

```java Java wrap
MoEngageWrapper.trackEvent(MoEAnalyticsHelper.INSTANCE, context, "Event", propertiesWrapper);
```

</CodeGroup>

# ユースケース

MoEngage を使用してプッシュ、メール、SMS、ソーシャル経由でユーザーをアプリに呼び込み、Apxor を使用してナッジやチュートリアルなどで最適なコンバージョンパスへとユーザーを導きます。MoEngage と Apxor のキャンペーンデータを分析して、オンボーディングと導入のアクティビティを最適化します。この統合の活用例を次に示します。

### パーソナライズされたオンボーディングジャーニーを作成する

MoEngage を使用して、アプリをダウンロードしたものの開いていないユーザーの数を確認します。カスタムセグメントを作成し、パーソナライズされたプッシュ通知を送信して、ユーザーにアプリを開くよう促します。

### ユーザーをファネルの先へ進める

MoEngage のユーザーパス分析を使用して、ユーザーが最も離脱している箇所を特定します。これは、ユーザーが先に進むためにこの段階で追加の情報を必要としている可能性を示しています。このインサイトに基づいて Apxor を使用し、ユーザーに情報を提供するコンテキストに応じたナッジを配置してギャップを埋め、次のステップへ進むよう動機付けます。

### 離脱の可能性が高いユーザーをコンバージョンさせ、維持する

MoEngage の予測セグメンテーションを使用して、長期間休眠状態にあり、離脱する可能性が最も高いユーザーを特定します。新機能、新着商品、またはサブスクリプションプランの変更を知らせるメールや SMS を送信します。その後、Apxor の製品内ツールチップやコーチマークを使用して、最新のアップデートを紹介します。

### ターゲットを絞ったレコメンデーションでアップセルとクロスセルを行う

MoEngage でユーザーの行動を分析し、購入傾向と優良顧客を特定します。MoEngage でメッセージをパーソナライズし、Apxor を使用して適切なタイミングでメッセージを配信し、アップセルやクロスセルのメリットを発見するよう促します。

---
title: "Accelerated Mobile Pages (AMP)"
---

Accelerated Mobile Pages (AMP) は、Google が開発したウェブコンポーネントフレームワークおよびウェブサイト公開テクノロジーで、ウェブコンテンツにユーザーファーストのフォーマットを提供することを目的としています。  
AMP は、モバイルデバイス上でウェブページを瞬時に読み込めるようにするオープンソースプロジェクトです。  
Google で何か (通常はニュース記事) を検索した際に、⚡ のような稲妻アイコンを見たことがあるかもしれません。このアイコンは、それらのページが AMP ページであることを示しています。

詳細については、[オープンソースプロジェクト](https://www.ampproject.org/)を参照してください。

MoEngage は、AMP でユーザーデータとイベントのトラッキング、および Web プッシュ通知チャネルを提供しています。

Accelerated Mobile Pages (AMP) を MoEngage Web SDK と統合するには、次の手順を実行します。

  1. AMP ページが適切に設定されていることを確認します。  
設定の詳細については、[How to create an AMP](https://www.ampproject.org/docs/tutorials/create) を参照してください。
  2. [AMP Event Analytics の設定と統合](/ja/partner-guide/technology-partners/google-amp/configure-and-integrate-amp-event-analytics) (任意ですが推奨)
  3. [AMP Web Push の設定と統合](/ja/partner-guide/technology-partners/google-amp/configure-and-integrate-amp-web-push) (必須)

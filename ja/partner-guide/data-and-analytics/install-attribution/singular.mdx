## はじめに

[Singular](https://www.singular.net/) は、アトリビューション、コスト集計、マーケティング分析、クリエイティブレポート、ワークフローの自動化を提供する統合マーケティング分析プラットフォームです。

## MoEngage × Singular

MoEngage と Singular の連携により、Singular から MoEngage に有料インストールのアトリビューションデータをインポートして、キャンペーン内でインテリジェントに活用できます。

## 連携

<Info>
  **前提条件**

  - 有効な Singular アカウントがあることを確認してください。
  - MoEngage ダッシュボードの **Settings** セクションへのアクセス権があることを確認してください。
</Info>

以下の設定手順に従って Singular の連携を有効にし、MoEngage にコールバックを送信します。

### ステップ 1: MoEngage のアトリビューショントラッキング用アプリキーを取得する

1. MoEngage ダッシュボードで **Settings** \> **Analytics** \> **Acquisition tracking** に移動します。
2. **Acquisition Tracking** をオンにし、ドロップダウンから **Singular** を選択します。これにより **App Key** が生成されます。
   ![Singular が選択され App Key が生成された Acquisition Tracking 設定](/images/partner_22025549296020.png)
3. **Save** をクリックします。
4. **App Key** をコピーします。これは Singular で MoEngage を設定する際に必要です。

### ステップ 2: Singular で MoEngage を設定する

Singular ダッシュボードで、次の手順に従います。

1. **Attribution** \> **Partner Configuration** に移動します。
2. パートナー名 (`MoEngage_Partner`) の入力を開始し、リストから **MoEngage** を選択します。
3. Configuration ウィンドウで、設定する **App** を選択し、次に **App Site** (プラットフォームのバージョン) を選択します。
4. 次のチェックボックスを選択します。
   - **Send Postbacks to Network on All Installs**
   - **Send Event Postbacks on any app installs for this app**
   ![Singular で Postback のチェックボックスが有効になった MoEngage パートナー設定](/images/partner_8998442096532.png)
5. MoEngage アプリに関する次の詳細を入力します。
   | フィールド | 説明 |
   | --- | --- |
   | **App ID** | MoEngage アカウントの Workspace ID。**Settings** \> **Account** \> **APIs** \> **API keys** に移動して確認できます。 |
   | **App Key** | MoEngage アカウントの獲得トラッキングキー。これは前の手順でコピーしたキーです。 |
   | **Region** | MoEngage データクラスターのリージョン。詳細については、[Data Centers in MoEngage](https://www.moengage.com/docs/user-guide/data/key-concepts/data-centers-in-moengage) を参照してください。 |
6. **Save** をクリックします。

## MoEngage で獲得データを使用する方法

MoEngage が Singular からデータを受信し始めたら、次の方法でこのデータを活用できます。

### ユーザー属性

MoEngage は **Campaign Name** と **Publisher Name** の2つのユーザー属性をトラッキングします。これらの属性は、キャンペーン、セグメンテーション、分析で使用できます。インストールの Publisher Name と Campaign Name により、ユーザーのペルソナに関する追加のインサイトが得られます。このデータを活用して、オンボーディングキャンペーンやユーザーファネルを強化し、MoEngage でのマーケティングオートメーション活動をパーソナライズできます。次のセクションでは、このデータを活用するための一般的なユースケースをいくつか紹介します。

![MoEngage の Campaign Name および Publisher Name ユーザー属性](/images/partner_19899387367572.png)

### さまざまなパブリッシャーのパフォーマンスを分析する

Singular 連携は、MoEngage でアプリインストールキャンペーンとソースの効果を分析するのに役立ちます。MoEngage ですでにトラッキングしているデータ (ユーザーイベント、コンバージョンゴール、アンインストール) を使用して、さまざまなアプリインストールキャンペーンのパフォーマンスを比較したり、さまざまなパブリッシャーからのインストールの相対的なパフォーマンスを分析したりして、マーケティング費用を最適化できます。

このデータを分析するには、[MoEngage の獲得ダッシュボード](https://app.moengage.com/v3/#/acquisition)を表示します。

![パブリッシャー別にグループ化された獲得分析ダッシュボード](/images/partner_11286820226452.png)

MoEngage Analytics を使用している場合は、インストールの Publisher Name と Campaign Name の情報を活用してユーザーファネルを分析することもできます。

### さまざまなキャンペーンのパフォーマンスを分析する

連携が有効になった後、ダッシュボードのサイドバーで **Analyze** \> **Acquisitions** に移動して、獲得ダッシュボードで獲得データの分析を確認することもできます。

![キャンペーン別にグループ化された獲得分析ダッシュボード](/images/partner_19899387369108.png)

### オンボーディングキャンペーンの強化

MoEngage のユーザープロパティとして利用できるインストールの Publisher Name と Campaign Name を使用して、セグメントを作成し、MoEngage 経由で送信するプッシュ通知、アプリ内メッセージ、メール、SMS をパーソナライズできます。

インストールアトリビューションデータにより、ユーザーがアプリをインストールした時点で、ライフサイクルにおいてどのように進んでいく可能性があるかについてのインサイトが得られます。これは非常に有用な情報であり、リテンションの向上、最初のコンバージョンまでの時間の短縮、ユーザーあたりの LTV の向上により、オンボーディングキャンペーンのパフォーマンスを高めるのに役立ちます。

| パブリッシャーのカテゴリ | ユースケース |
| --- | --- |
| ユーザーあたりの平均セッション数が少ないパブリッシャー | ユーザーがアプリをインストールした時点から定期的にプッシュ通知を送信し、ユーザーあたりの平均セッション数を増やします。 |
| 平均 LTV が高いパブリッシャー | これらは潜在的なプレミアムユーザーです。キャンペーン戦略を実施して、プレミアムユーザーのセグメントへと育成します。 |
| アンインストール率が高いパブリッシャー | インストール直後に離脱する傾向が高いユーザーを特定し、初回購入のインセンティブを提供します。これにより離脱率を低減できます。 |

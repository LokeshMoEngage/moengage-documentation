## はじめに

MoEngage のテクノロジーパートナーの1つである [Branch](https://branch.io/) を使用すると、インストール獲得データをトラッキングして、MoEngage でのマーケティングオートメーションキャンペーンを強化できます。

## 対象範囲

MoEngage でインストールの Publisher Name と Campaign Name を使用します。

## 連携

<Info>
  **前提条件**

  - 管理者アクセス権を持つ有効な Branch アカウントがあることを確認してください。
  - MoEngage ダッシュボードの **Settings** セクションへのアクセス権があることを確認してください。
</Info>

## 手順

Branch を MoEngage と連携するには、以下の手順に従います。

### ステップ 1: MoEngage のアトリビューショントラッキングキーを取得する

MoEngage ダッシュボードにログインし、次の手順に従います。

1. **Settings** \> **Analytics** \> **Acquisition tracking** に移動します。
2. **Acquisition Tracking** をオンにし、ドロップダウンから **Branch** を選択します。これにより **Attribution Key** が生成されます。 <img src="/images/partner_38390672824980.png" alt="Branch が選択され Attribution Key が生成された Acquisition Tracking 設定" />
3. **Save** をクリックします。
4. **Attribution Key** をコピーします。これは Branch ダッシュボードで MoEngage を設定する際に必要です。

### ステップ 2: Branch ダッシュボードで設定を行う

Branch ダッシュボードで設定を行うには、[Branch の連携ドキュメント](https://docs.branch.io/integrations/moengage/#setup)の手順に従います。

Branch ダッシュボードで次のフィールドを入力します。

![Branch ダッシュボードの MoEngage 設定フィールド](/images/partner_31665308965140.png)

| フィールド | 説明 |
| --- | --- |
| **Data Center** | サインアップした MoEngage データセンターに応じて、次のいずれかを選択します。MoEngage データセンターの確認方法の詳細については、[Data Centers in MoEngage](https://www.moengage.com/docs/user-guide/data/key-concepts/data-centers-in-moengage) を参照してください。 <ul><li>DC-01</li><li>DC-02</li><li>DC-03</li></ul> |
| **Data API ID** | Data API ID と Data API Key は **Settings** \> **Account** \> **APIs** で確認できます。Data API ID は **Workspace ID** と同じです。Data API Key は、同じ画面の **API Keys** \> **Data** で確認できます。 |
| **Data API Key** | ステップ 1 で生成した **Attribution Key** を入力します。 |
| **App ID** | Workspace ID を取得します。MoEngage アカウントの Workspace ID は、**Settings** \> **Account** \> **APIs** \> **Workspace ID** で確認できます。MoEngage アカウントの Data API ID と Workspace ID は同じです。 |

## MoEngage で獲得データを使用する方法

MoEngage が Branch からデータを受信し始めたら、次の方法でこのデータを活用できます。

### ユーザー属性

MoEngage は **Campaign Name** と **Publisher Name** の2つのユーザー属性をトラッキングします。これらの属性は、キャンペーン、セグメンテーション、分析で使用できます。インストールの Publisher Name と Campaign Name により、ユーザーのペルソナに関する追加のインサイトが得られます。このデータを活用して、オンボーディングキャンペーンやユーザーファネルを強化し、MoEngage でのマーケティングオートメーション活動をパーソナライズできます。次のセクションでは、このデータを活用するための一般的なユースケースをいくつか紹介します。

![MoEngage の Campaign Name および Publisher Name ユーザー属性](/images/partner_11468475332500.png)

### さまざまなパブリッシャーのパフォーマンスを分析する

Branch 連携は、MoEngage でアプリインストールキャンペーンとソースの効果を分析するのに役立ちます。ユーザーイベント、コンバージョンゴール、アンインストールなど、MoEngage ですでにトラッキングしているデータを活用して、実施しているさまざまなアプリインストールキャンペーンのパフォーマンスを比較したり、さまざまなパブリッシャーからのインストールの相対的なパフォーマンスを分析したりして、マーケティング費用を最適化できます。

このデータを分析するには、[MoEngage の獲得ダッシュボード](https://app.moengage.com/v3/#/acquisition)を表示します。

![パブリッシャー別にグループ化された獲得分析ダッシュボード](/images/partner_11468492536468.png)

MoEngage Analytics を使用している場合は、インストールの Publisher Name と Campaign Name の情報を活用してユーザーファネルを分析できます。

### さまざまなキャンペーンのパフォーマンスを分析する

連携が有効になった後、ダッシュボードのサイドバーで **Analyze** \> **Acquisitions** に移動して、獲得ダッシュボードで獲得データの分析を確認することもできます。

![キャンペーン別にグループ化された獲得分析ダッシュボード](/images/partner_11468493754388.png)

### オンボーディングキャンペーンの強化

MoEngage のユーザープロパティとして利用できるインストールの Publisher Name と Campaign Name を使用して、セグメントを作成し、MoEngage 経由で送信するプッシュ通知、アプリ内メッセージ、メール、SMS をパーソナライズできます。

インストールアトリビューションデータにより、ユーザーがアプリをインストールした時点で、ライフサイクルにおいてどのように進んでいく可能性があるかについてのインサイトが得られます。これは非常に有用な情報であり、リテンションの向上、最初のコンバージョンまでの時間の短縮、ユーザーあたりの LTV の向上により、オンボーディングキャンペーンのパフォーマンスを高めるのに役立ちます。

| パブリッシャーのカテゴリ | ユースケース |
| --- | --- |
| ユーザーあたりの平均セッション数が少ないパブリッシャー | ユーザーがアプリをインストールした時点から定期的にプッシュ通知を送信し、ユーザーあたりの平均セッション数を増やします。 |
| 平均 LTV が高いパブリッシャー | これらは潜在的なプレミアムユーザーです。キャンペーン戦略を実施して、プレミアムユーザーのセグメントへと育成します。 |
| アンインストール率が高いパブリッシャー | インストール直後に離脱する傾向が高いユーザーを特定し、初回購入のインセンティブを提供します。これにより離脱率を低減できます。 |

## データトラッキング

### カスタムトラッキング

ユーザーが、Branch でトラッキングされていないパブリッシャーや、Branch がユーザーレベルでインストールソース情報を MoEngage に転送することを許可していないパブリッシャーからアプリをインストールする場合があります。

回避策の1つは、そのようなパブリッシャーからインストール情報を取得し、次の API を使用して MoEngage に転送することです。

<Tabs>
  <Tab title="Android">
    ```text wrap
    https://api.moengage.com/v1/installInfo?publisher_name=<publisher_name_of_install>&campaign_name=<campaign_name_of_install>&src=branch&appId=<ENTER_APP_ID_HERE>&advertising_id=<device_GAID>&appAttributionKey=<ENTER_APP_KEY_HERE>
    ```
  </Tab>
  <Tab title="iOS">
    ```text wrap
    https://api.moengage.com/v1/installInfo?publisher_name=<publisher_name_of_install>&campaign_name=<campaign_name_of_install>&src=branch&appId=<ENTER_APP_ID_HERE>&idfv=<device_idfv>&appAttributionKey=<ENTER_APP_KEY_HERE>
    ```
  </Tab>
</Tabs>

API パラメーターの詳細:

| キー | 値 |
| --- | --- |
| `publisher_name` | インストールのパブリッシャー名。 |
| `campaign_name` | インストールのキャンペーン名。 |
| `src` | `branch` |
| `appId` | MoEngage アカウントの Workspace ID。**Settings** \> **Account** \> **APIs** に移動して確認できます。 |
| `advertising_id` (Android のみ) | インストールが検出されたデバイスの Google Advertising ID。 |
| `idfv` (iOS のみ) | インストールが検出された iOS デバイスの IDFV。 |
| `appAttributionKey` | MoEngage ダッシュボードで **Settings** \> **Analytics** \> **Acquisition tracking** に移動して確認できます。 |

## よくある質問

<AccordionGroup>
  <Accordion title="Facebook からのインストールデータを MoEngage で確認できますか?">
    Facebook のデータ共有ポリシーにより、Facebook からのインストールデータは Branch でのみ確認でき、他のプラットフォームには送信されません。これらは MoEngage では **Organic Installs** として表示されます。代わりに、MoEngage API を使用して Facebook のインストールデータを個別に MoEngage に送信することもできます。
  </Accordion>
</AccordionGroup>

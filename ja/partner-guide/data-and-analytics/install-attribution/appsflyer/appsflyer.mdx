# はじめに

[Appsflyer](https://www.appsflyer.com/) は、マーケティング分析、モバイルアトリビューション、ディープリンクを通じてアプリの分析と最適化を支援するモバイルマーケティング分析およびアトリビューションプラットフォームです。

# MoEngage × Appsflyer

MoEngage と AppsFlyer の連携により、AppsFlyer のモバイルインストールアトリビューションデータを活用して、キャンペーンを最適化し、より包括的なキャンペーンを構築する方法をより深く理解できます。この連携により、Appsflyer から MoEngage にインストールトラッキングデータを送信できます。

## 連携の前提条件

- Appsflyer アカウントへのアクセス権があることを確認してください。
- Data API ID と Data API Key は **Settings** -\> **Account** -\> **APIs** で確認できます。Data API ID は **Workspace ID** と同じです。Data API Key は、同じ画面の **API Keys** -\> **Data** セクションで確認できます。
- MoEngage データセンター - サインアップした MoEngage データセンターに応じて、次のいずれかを選択します。MoEngage データセンターの確認方法の詳細については、[こちらの記事](/ja/user-guide/data/key-concepts/data-centers-in-moengage)を参照してください。

AppsFlyer を MoEngage と連携するには、次の手順に従います。

## ステップ 1: MoEngage SDK が正しく設定されていることを確認する

- AppsFlyer は、ユーザーの GAID または Advertising Identifier を使用して獲得データをマッピングします。
- GAID または Advertising Identifier は、モバイルアプリおよびウェブアプリに組み込まれた MoEngage SDK を介して MoEngage に渡す必要があります。
- SDK を介して MoEngage で新しいユーザーが作成される際、GAID と Advertising Identifier も一緒に受信することを想定しています。これらの ID は、ユーザープロファイルに標準属性として保存されます。
- [iOS](https://developers.moengage.com/hc/en-us/articles/4404181384980-Compliance) および [Android](https://developers.moengage.com/hc/en-us/articles/6046152370452-Enable-Advertising-Identifier-Tracking) のデバイス ID トラッキングの設定方法の詳細をお読みください。

## ステップ 2: MoEngage のアトリビューショントラッキング用アプリキーを取得する

1. MoEngage ダッシュボードで **Settings** -\> **Analytics and Data** -\> **Acquisition tracking** に移動します。
2. **Acquisition Tracking** をオンにし、ドロップダウンから **Appsflyer** を選択します。これにより **App Key** が生成されます。 <img src="/images/partner_22025914697108.png" alt="AppsFlyer_REvampedUI.png" />
3. **Save** をクリックします。
4. App Key をコピーします。これは Appsflyer で MoEngage を設定する際に必要です。

## ステップ 3: AppsFlyer ダッシュボードで設定を行う

アプリの AppsFlyer ダッシュボードに移動し、左側のバーで Integrated Partners をクリックします。

![eeb0757-appsflyer\_1.png](/images/partner_17965506065172.png)

検索フィールドに "MoEngage" と入力し、そのロゴをクリックして MoEngage の設定ウィンドウを開きます。

![62f2b99-appsflyer\_dashboard\_setup.png](/images/partner_17965506065812.png)

MoEngage の設定ウィンドウでは Integration タブを使用します。

初回設定時は、Activate Partner ボタンを ON に切り替えて、Integration タブのパラメーターを設定できるようにしてください。パートナーと連携している間は、トグルを ON のままにしてください。有効化後、次の操作を行います。

1. Appsflyer ダッシュボードで Workspace ID、App Key、データセンターを入力して、Appsflyer と MoEngage の間の接続を確立します。
   | **フィールド** | **説明** |
   | --- | --- |
   | Workspace ID | MoEngage アカウントの Workspace ID は、**Settings \> Account \> APIs \> Workspace ID** で確認できます。 |
   | Data API ID | MoEngage アカウントの Data API ID と Workspace ID は同じです。 |
   | Data API Key | MoEngage アカウントの Data API キーは、**Settings \> App Settings \> APIs \> API Keys \> Data** で確認できます。 |
   | Data Center Name | サインアップした MoEngage データセンターを指定します。MoEngage の URL を確認します: `https://dashboard-OX.moengage.com`。MoEngage データセンターのリージョンに基づいて、AppsFlyer ダッシュボードのデータセンター名に正しい値を設定します。[詳細はこちら](/ja/user-guide/data/key-concepts/data-centers-in-moengage)。この値は大文字と小文字が区別されます。使用できる値: <ul><li>`DC-01`</li><li>`DC-02`</li><li>`DC-03`</li><li>`DC-04`</li><li>`DC-06`</li></ul> |
2. **Sending Option**: MoEngage とデータを同期するには、**All media sources, including organic** を選択します。**Off** を選択すると、データは同期されません。
3. **Save Integration** をクリックします。

これで AppsFlyer との連携は完了です。

<Info>
  パートナーからのサードパーティ獲得データは2時間ごとに計算され、Acquisition ダッシュボードの集計データは6時間ごとに更新されます。
</Info>

# MoEngage で獲得データを使用する方法

MoEngage が Appsflyer からデータを受信し始めたら、次の方法でこのデータを活用できます。

## ユーザー属性

"Campaign Name" と "Publisher Name" の2つのユーザー属性をトラッキングします。これらの属性は、キャンペーン、セグメンテーション、分析で使用できます。インストールの Publisher Name と Campaign Name により、ユーザーのペルソナに関する追加のインサイトが得られ、このデータを活用してオンボーディングキャンペーンやユーザーファネルを強化し、MoEngage でのマーケティングオートメーション活動全般をパーソナライズできます。次のセクションでは、MoEngage でこのデータを活用する方法について、よく使われるユースケースをいくつか紹介します。

![0be6c0f-Screen\_Shot\_2019-11-26\_at\_1.04.33\_PM.png](/images/partner_17965494470036.png)

## さまざまなパブリッシャーのパフォーマンスを分析する

Appsflyer 連携は、MoEngage でアプリインストールキャンペーンとソースの効果を分析するのに役立ちます。ユーザーイベント、コンバージョンゴール、アンインストールなど、MoEngage ですでにトラッキングしているデータを活用して、実施しているさまざまなアプリインストールキャンペーンのパフォーマンスを比較したり、さまざまなパブリッシャーからのインストールの相対的なパフォーマンスを分析したりして、マーケティング費用を最適化できます。

![MulitplePublishers\_Appsflyer.png](/images/partner_17965506067732.png)

#### さまざまなキャンペーンのパフォーマンスを分析する

連携が完了した後、ダッシュボードのサイドバーから Analyze -\> Acquisitions に移動して、獲得ダッシュボードで獲得データの分析を確認することもできます。<img src="/images/partner_17965506068500.png" alt="47521bb-Screen_Shot_2019-11-26_at_1.05.54_PM.png" />

MoEngage Analytics を使用している場合は、インストールの Publisher Name と Campaign Name の情報を活用してユーザーファネルを分析することもできます。

## オンボーディングキャンペーンの強化

MoEngage のユーザープロパティとして存在するインストールの Publisher Name と Campaign Name を使用してセグメントを作成し、それに応じて MoEngage 経由で送信するプッシュ通知、アプリ内メッセージ、メール、SMS をパーソナライズできます。

インストールアトリビューションデータにより、ユーザーがアプリをインストールした時点で、ライフサイクルにおいてどのように進んでいく可能性があるかについてのインサイトが得られます。これは非常に有用な情報であり、リテンションの向上、最初のコンバージョンまでの時間の短縮、ユーザーあたりの LTV の向上により、オンボーディングキャンペーンのパフォーマンスを高めるのに役立ちます。

| パブリッシャーのカテゴリ | ユースケース |
| --- | --- |
| ユーザーあたりの平均セッション数が少ないパブリッシャー | ユーザーがアプリをインストールした時点から定期的にプッシュ通知を送信し、ユーザーあたりの平均セッション数を増やします。 |
| 平均 LTV が高いパブリッシャー | これらは潜在的なプレミアムユーザーであり、キャンペーン戦略を実施してプレミアムユーザーのセグメントへと育成できます。 |
| アンインストール率が高いパブリッシャー | アプリのインストール直後に離脱する傾向が高いユーザーを特定し、そのようなユーザーに初回購入のインセンティブを提供することで、離脱率を低減できます。 |

## カスタムトラッキング

ユーザーが、Appsflyer でトラッキングされていないパブリッシャーや、Appsflyer がユーザーレベルでインストールソース情報を MoEngage に転送することを許可していないパブリッシャーからアプリをインストールする場合があります。

これに対する回避策の1つは、そのようなパブリッシャーからインストール情報を取得し、[インストールトラッキング API](https://developers.moengage.com/hc/en-us/articles/4628698189588-Install-tracking-) を使用して MoEngage に転送することです。

# よくある質問

**Q1.**  _Facebook からのインストールデータを MoEngage で確認するにはどうすればよいですか?_ **A.** Facebook のデータ共有ポリシーにより、Facebook からのインストールデータは Appsflyer でのみ確認でき、他のプラットフォームには送信されません。これらは MoEngage では Organic Installs として表示されます。

**Q2.**  _Appsflyer のインストール数が MoEngage のインストール数より少ないのはなぜですか?_ **A.** MoEngage は再インストールが発生するたびに新しいユーザーを作成します。Appsflyer は、以前のインストールが非オーガニックであった場合、再インストールをカウントしません。

**Q3.**  _Appsflyer のインストール数が MoEngage のインストール数より多いのはなぜですか?_ **A.** MoEngage でトラッキングされたインストール数の計算に MoEngage の INSTALL イベントを使用している場合は、連携時にこのイベントが正しく設定されているかどうかを確認してください。以下のドキュメントを参照するか、詳細なお問い合わせについてはサポートチームにご連絡ください。 | [Android](https://developers.moengage.com/hc/en-us/articles/4402050819220) | [iOS](https://developers.moengage.com/hc/en-us/articles/4403910297620)

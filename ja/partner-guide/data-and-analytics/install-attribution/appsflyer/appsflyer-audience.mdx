## はじめに

[Appsflyer](https://www.appsflyer.com/) は、マーケティング分析、モバイルアトリビューション、ディープリンクを通じてアプリの分析と最適化を支援するモバイルマーケティング分析およびアトリビューションプラットフォームです。

## MoEngage × Appsflyer audience

MoEngage と AppsFlyer audience の連携により、AppsFlyer Audiences で構築したユーザーセグメントの力を活用して、ユーザーエンゲージメントを促進し、リマーケティングプログラムの効率を高めることができます。[AppsFlyer audiences](https://www.appsflyer.com/product/audiences/) を MoEngage に直接渡して、効果的なカスタマーエンゲージメントキャンペーンを作成できます。

## 連携

<Info>
  **前提条件**

  - Appsflyer アカウントへのアクセス権があることを確認してください。
  - Data API ID は **Settings** \> **Account** \> **APIs** で確認できます。Data API ID は **Workspace ID** と同じです。Data API Key は、同じ画面の **API Keys** \> **Data** セクションで確認できます。
  - MoEngage データセンター - サインアップした MoEngage データセンターに応じて、次のいずれかを選択します。MoEngage データセンターの確認方法の詳細については、[こちらの記事](https://www.moengage.com/docs/user-guide/data/key-concepts/data-centers-in-moengage)を参照してください。
</Info>

AppsFlyer audience を MoEngage と連携するには、次の手順に従います。

### ステップ 1: Appsflyer で MoEngage を宛先として設定する

1. Appsflyer ダッシュボードで **Create an Outgoing connection** に移動します。
   ![Appsflyer ダッシュボードの Create an Outgoing connection](/images/partner_4963498995476.png)
2. Workspace ID、Secret Key、データセンターの詳細を入力します。
   | フィールド | 説明 |
   | --- | --- |
   | **Workspace ID** | MoEngage アカウントの Workspace ID は、**Settings** \> **Account** \> **APIs** \> **Workspace ID** で確認できます。 |
   | **Data API ID** | MoEngage アカウントの Data API ID と Workspace ID は同じです。 |
   | **Data API Key** | MoEngage アカウントの Data API キーは、**Settings** \> **App Settings** \> **APIs** \> **API Keys** \> **Data** で確認できます。 |
   | **Data Center Name** | MoEngage の URL を確認します: `https://dashboard-OX.moengage.com`。 <br />ダッシュボードの値 (`DC-01`、`DC-02`、`DC-03`、または `DC-04`) に基づいて、Appsflyer ダッシュボードのデータセンター名に正しい値を設定します。[詳細はこちら](https://www.moengage.com/docs/user-guide/data/key-concepts/data-centers-in-moengage)。 |
3. **Save** をクリックします。

### ステップ 2: MoEngage で Appsflyer audience を使用する

連携後、Appsflyer で作成したコホートは MoEngage で[カスタムセグメント](https://www.moengage.com/docs/user-guide/segment/create-segments/manage-segments)として利用できます。カスタムセグメントは、あらゆる MoEngage キャンペーンで使用して、ユーザーにパーソナライズされたメッセージを送信できます。

## レート制限

プラットフォームの安定性を維持するため、MoEngage は AppsFlyer audience のデータ取り込みをワークスペースあたり最大 300 リクエスト/分 (RPM) に制限しています。ワークスペースがこの制限を超えると、MoEngage は HTTP `429 (Too Many Requests)` ステータスコードを返します。

レート制限がデータフローにどのように影響するかについては、AppsFlyer のデフォルトの再試行ポリシーを参照してください。

**再試行の上限到達**: Appsflyer があるデータバッチのすべての再試行を使い切った場合は、Appsflyer サポートチームに連絡して、失敗したリクエストを再送してもらう必要があります。

[Airbridge](https://www.airbridge.io/) は、アプリマーケティングキャンペーンの測定と最適化に役立つモバイルアトリビューションおよびマーケティング分析プラットフォームです。

## MoEngage × Airbridge

MoEngage と Airbridge の連携により、アトリビューションされたアプリインストールイベントが Airbridge から MoEngage アカウントに直接送信されます。これにより、キャンペーンのパフォーマンスを分析し、獲得データに基づいてターゲットを絞ったユーザーセグメントを作成できます。

## ユースケース

Airbridge と MoEngage を連携すると、次のことに役立ちます。

- **ターゲットを絞ったキャンペーンの作成** : Airbridge のアトリビューションデータを使用して、特定のソースから獲得したユーザー向けに、きめ細かくターゲットを絞ったマーケティングキャンペーンを構築できます。
- **パフォーマンス分析** : MoEngage でユーザーの行動をトラッキングすることで、どのキャンペーンやパブリッシャーが最も価値の高いユーザーを獲得しているかを分析できます。
- **ユーザーセグメンテーション** : パーソナライズされたオンボーディングフローやエンゲージメントジャーニーのために、獲得ソースに基づいてユーザーセグメントを作成できます。

# 連携

<Info>
  連携を設定するには、MoEngage ダッシュボードから次の情報が必要です。

  - Workspace ID (旧 app ID)
  - アトリビューションキー
  - データセンター ID
</Info>

## ステップ 1: MoEngage で認証情報を確認する

認証情報を確認するには、次の手順を実行します。

1. MoEngage UI で、**Settings** \> **Account** \> **APIs** に移動します。
2. **Workspace ID (earlier app id)** の下にある ID をコピーします。 <img src="/images/partner_39495204801428.png" />
3. MoEngage UI で、**Settings** \> **Analytics** **and** **Data** \> **Acquisition tracking** に移動します。\*\*\
   **Acquisition tracking** ページが表示されます。
4. **Acquisition tracking** トグルをオンにします。
5. **Attribution Platform** リストで、**Airbridge** を選択します。\
   **Attribution Key** フィールドが表示されます。これがアトリビューションキーです。
6. **Save** をクリックします。 <img src="/images/partner_39495228776596.png" />
7. データセンター ID は、MoEngage へのサインアップ時に割り当てられます。データセンター ID はダッシュボードの URL から確認できます。たとえば、ダッシュボードの URL が [https://dashboard-04.moengage.com/v4/#/auth](https://dashboard-04.moengage.com/v4/#/auth) の場合、データセンターはデータセンター 04 で、データセンター ID は\
   DC-04 です。詳細については、[Data Centers in MoEngage](https://www.moengage.com/docs/user-guide/data/key-concepts/data-centers-in-moengage) を参照してください。

## ステップ 2: Airbridge で連携を設定する

MoEngage の認証情報を確認したら、Airbridge ダッシュボードにログインします。設定を完了するには、次の手順を実行します。

1. サイドバーメニューで **Integrations** をクリックします。**Integrations** メニューが表示されます。
2. **Third-party Integration** をクリックします。
3. **Third-party Integration** ページで、**MoEngage** タイルをクリックします。
   ![](/images/partner_39495524262420.png)
   **MoEngage** ページが表示されます。
4. **Workspace ID** ボックスに、MoEngage からコピーした Workspace ID (app ID) を入力します。
5. **Attribution Key** ボックスに、MoEngage からコピーしたアトリビューションキーを入力します。
6. **Data Center** リストで、MoEngage のデータセンターを選択します。すべての情報が正しく入力されていることを確認してください。詳細が不足しているか正しくない場合、連携は失敗します。
7. **Submit** をクリックします。 <img src="/images/partner_39495588773268.png" />

# MoEngage で獲得データを使用する

MoEngage が Airbridge からデータを受信した後、_Campaign Name_ や _Publisher Name_ などのユーザー属性を使用して、キャンペーンを改善し、オーディエンスをより効果的にセグメント化し、レポートを改善できます。これにより、MoEngage でパーソナライズされたウェルカム体験を作成し、ユーザーをジャーニーにスムーズに誘導し、よりスマートにマーケティングを自動化できます。

![0be6c0f-Screen\_Shot\_2019-11-26\_at\_1.04.33\_PM.png](/images/partner_39681122346132.png)

## パブリッシャーのパフォーマンスを分析する

Airbridge を連携すると、MoEngage はアプリインストールキャンペーンとそのソースの効果を分析するのに役立ちます。Airbridge の獲得データを、MoEngage のユーザーイベント、コンバージョンゴール、アンインストールデータと組み合わせます。その後、さまざまなキャンペーンのパフォーマンスを比較し、さまざまなパブリッシャーからのインストールを分析して、マーケティング費用を最適化できます。

![MulitplePublishers\_Appsflyer.png](/images/partner_39681122347284.png)

## キャンペーンのパフォーマンスを分析する

連携が完了すると、獲得ダッシュボードで獲得データの分析を確認できます。MoEngage で、**Analyze** \> **Acquisition** に移動します。MoEngage Analytics を使用している場合は、_Publisher Name_ および _Campaign Name_ 属性を活用してユーザーファネルを分析することもできます。

![47521bb-Screen\_Shot\_2019-11-26\_at\_1.05.54\_PM.png](/images/partner_39681116232084.png)

<Info>
  MoEngage に表示されるユーザー数と Airbridge から送信された数に差異が見られる場合があります。これは通常、各プラットフォームがユーザーを識別およびアトリビューションする方法の違いによるものです。
</Info>

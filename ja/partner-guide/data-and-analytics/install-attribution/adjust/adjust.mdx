## はじめに

[Adjust](https://www.adjust.com/) は、広告ソースのアトリビューションと高度な分析を組み合わせて、ビジネスインテリジェンスの包括的な全体像を提供するモバイルアトリビューションおよび分析企業です。

## MoEngage × Adjust

MoEngage と Adjust の連携により、非オーガニックのインストールアトリビューションデータをインポートして、ライフサイクルキャンペーン内でよりインテリジェントにセグメント化できます。MoEngage は、Adjust から Campaign Name と Publisher Name を含む Install Postback を受け付けます。

## 連携

<Info>
  **前提条件**

  - Adjust アカウントがあることを確認してください。
  - MoEngage ダッシュボードの **Settings** セクションへのアクセス権があることを確認してください。
</Info>

以下の設定手順に従って Adjust の連携を有効にし、MoEngage にコールバックを送信します。

### ステップ 1: MoEngage のアトリビューショントラッキング用アプリキーを取得する

MoEngage ダッシュボードにログインし、次の手順に従います。

1. **Settings** > **Analytics** > **Acquisition tracking** に移動します。
2. **Acquisition Tracking** をオンにし、ドロップダウンから **Adjust** を選択します。これにより **App Key** が生成されます。

   ![Adjust が選択され App Key が生成された Acquisition Tracking 設定](/images/partner_22022967574676.png)
3. **Save** をクリックします。
4. **App Key** をコピーします。これは Adjust で MoEngage を設定する際に必要です。

### ステップ 2: Adjust で MoEngage を設定する

Adjust ダッシュボードで次の操作を行います。

1. **App options** キャレットに移動します。
2. **Partner Setup** > **Add Partners** を選択し、**MoEngage** を選択します。

   ![MoEngage を選択する Adjust のパートナー設定画面](/images/partner_7896586914836.png)
3. MoEngage アプリに関する次の詳細を入力します。

   | フィールド | 説明 |
   | --- | --- |
   | **Workspace ID** | MoEngage アカウントの Workspace ID は、**Settings** > **Account** > **APIs** > **Workspace ID** で確認できます。 |
   | **Password** | パスワードは MoEngage アカウントの Data API キーで、**Settings** > **Account** > **APIs** > **API keys** > **Data** API 設定で確認できます。これはステップ 1 でコピーしたキーと同じです。 |
   | **Region** | MoEngage データクラスターのリージョンです。[詳細はこちら](https://www.moengage.com/docs/user-guide/data/key-concepts/data-centers-in-moengage)。 |
   | **Tracking key** | MoEngage アカウントの獲得トラッキングキーです。これは前の手順でコピーしたキーです。 |

   設定の詳細については、[Adjust のドキュメント](https://help.adjust.com/en/integrated-partners/moengage)を参照してください。
4. **Save** をクリックします。

## MoEngage で獲得データを使用する方法

MoEngage が Adjust からデータを受信し始めたら、次の方法でこのデータを活用できます。

### ユーザー属性

**Campaign Name** と **Publisher Name** の2つのユーザー属性をトラッキングします。これらの属性は、キャンペーン、セグメンテーション、分析で使用できます。インストールの Publisher Name と Campaign Name により、ユーザーのペルソナに関する追加のインサイトが得られ、このデータを活用してオンボーディングキャンペーンやユーザーファネルを強化し、MoEngage でのマーケティングオートメーション活動全般をパーソナライズできます。次のセクションでは、MoEngage でこのデータを活用する方法について、よく使われるユースケースをいくつか紹介します。

![MoEngage の Campaign Name および Publisher Name ユーザー属性](/images/partner_23949934086676.png)

### さまざまなパブリッシャーのパフォーマンスを分析する

Adjust 連携は、MoEngage でアプリインストールキャンペーンとソースの効果を分析するのに役立ちます。ユーザーイベント、コンバージョンゴール、アンインストールなど、MoEngage ですでにトラッキングしているデータを活用して、実施しているさまざまなアプリインストールキャンペーンのパフォーマンスを比較したり、さまざまなパブリッシャーからのインストールの相対的なパフォーマンスを分析したりして、マーケティング費用を最適化できます。

このデータを分析するには、[MoEngage の獲得ダッシュボード](https://app.moengage.com/v3/#/acquisition)を表示します。

![パブリッシャー別にグループ化された獲得分析ダッシュボード](/images/partner_23949934088212.png)

MoEngage Analytics を使用している場合は、インストールの Publisher Name と Campaign Name の情報を活用してユーザーファネルを分析することもできます。

### さまざまなキャンペーンのパフォーマンスを分析する

連携が有効になった後、ダッシュボードのサイドバーから **Analyze** > **Acquisitions** に移動して、獲得ダッシュボードで獲得データの分析を確認することもできます。

![キャンペーン別にグループ化された獲得分析ダッシュボード](/images/partner_23949934092564.png)

### オンボーディングキャンペーンの強化

MoEngage のユーザープロパティとして存在するインストールの Publisher Name と Campaign Name を使用してセグメントを作成し、それに応じて MoEngage 経由で送信するプッシュ通知、アプリ内メッセージ、メール、SMS をパーソナライズできます。

インストールアトリビューションデータにより、ユーザーがアプリをインストールした時点で、ライフサイクルにおいてどのように進んでいく可能性があるかについてのインサイトが得られます。これは非常に有用な情報であり、リテンションの向上、最初のコンバージョンまでの時間の短縮、ユーザーあたりの LTV の向上により、オンボーディングキャンペーンのパフォーマンスを高めるのに役立ちます。

| パブリッシャーのカテゴリ | ユースケース |
| --- | --- |
| ユーザーあたりの平均セッション数が少ないパブリッシャー | ユーザーがアプリをインストールした時点から定期的にプッシュ通知を送信し、ユーザーあたりの平均セッション数を増やします。 |
| 平均 LTV が高いパブリッシャー | これらは潜在的なプレミアムユーザーです。キャンペーン戦略を実施して、プレミアムユーザーのセグメントへと育成できます。 |
| アンインストール率が高いパブリッシャー | アプリのインストール直後に離脱する傾向が高いユーザーを特定し、そのようなユーザーに初回購入のインセンティブを提供することで、離脱率を低減できます。 |

## 高度な連携

MoEngage × Adjust 連携は、Adjust から MoEngage にイベントも送信します。プッシュ通知やアプリ内メッセージなどの MoEngage の機能を活用するには、追加の連携が必要です。[Adjust CDP との高度な連携についてはこちらをお読みください](/ja/partner-guide/data-and-analytics/install-attribution/adjust/adjust-cdp)。

title: "Amplitude Event Streaming"

## はじめに

[Amplitude の Event Streaming](https://www.docs.developers.amplitude.com/data/destination-event-streaming-overview/) を使用すると、Amplitude 内のイベントデータをスタック全体に送信できます。Event Streaming により、Amplitude の豊富な行動データを使用して顧客プロファイルを充実させ、マーケティング、営業、インフラストラクチャのツールにデータをストリーミングできます。

<Info>
  - Amplitude Event Streaming は Streams アドオンの一部です。アカウントで有効にするには、専任の MoEngage CSM（カスタマーサクセスマネージャー）にお問い合わせください。
  - Amplitude Event Streaming は現在、[Unified Identity](https://moengage-user-guide.mintlify.app/user-guide/data/user-data/unified-identity-identity-resolution) および [Portfolio](https://moengage-user-guide.mintlify.app/user-guide/settings/account/portfolio/portfolio) をサポートしていません。
</Info>

## ユースケース

1. **パーソナライゼーション:** Amplitude から MoEngage にユーザープロパティを送信することで、ユーザーによりパーソナライズされたエクスペリエンスを提供できます。たとえば、ユーザーの位置情報や言語設定に関する情報を送信し、その情報を使用してメッセージやコンテンツをユーザー固有のニーズに合わせることができます。
2. **セグメンテーション:** Amplitude から MoEngage にイベントとイベントプロパティを送信することで、行動に基づいてユーザーのセグメントを作成できます。たとえば、アプリや Web サイトで特定のアクションを完了したユーザーのセグメントを作成し、特定のキャンペーンやメッセージでターゲティングできます。
3. **コンバージョントラッキング:** Amplitude から MoEngage にイベントを送信することで、マーケティングキャンペーンの効果を追跡し、ファネル全体でユーザーの行動を測定できます。たとえば、MoEngage から特定のメッセージを受け取ったユーザーのうち、何人が購入やその他の目的のアクションを完了したかを追跡できます。
4. **A/B テスト:** Amplitude から MoEngage にイベントとイベントプロパティを送信することで、A/B テストを作成・実行してメッセージやコンテンツを最適化できます。たとえば、メッセージの 2 つの異なるバージョンを作成し、それぞれを異なるユーザーセグメントに送信して、どちらのバージョンがより多くのエンゲージメントやコンバージョンにつながるかを追跡できます。

## 連携の前提条件

- Amplitude Data アカウントの認証情報があることを確認してください。
- Data API ID と Data API Key は **Settings** \> **Account** \> **APIs** で確認できます。Data API ID は **Workspace ID** と同じです。Data API Key は、同じ画面の **API Keys** \> **Data** セクションで確認できます。
- MoEngage のデータセンターを確認してください。データセンターは MoEngage ダッシュボードのインスタンスに対応しています。[詳細はこちら](https://www.moengage.com/docs/user-guide/data/key-concepts/data-centers-in-moengage)

## 手順

Amplitude Event Streaming を設定するには、次の手順を実行します。

1. **Amplitude Data** \> **Catalog** に移動します。
2. **Destinations** タブを選択します。
3. **Event Streaming** セクションで、**MoEngage** をクリックします。 <img src="/images/partner_15040702315284.png" alt="MoEngage オプションが表示された Amplitude の Event Streaming 送信先ページ" />
4. 同期名を入力し、**Create Sync** をクリックします。 <img src="/images/partner_15040702750996.png" alt="Amplitude Event Streaming の Create Sync ダイアログ" />
5. フォームに入力します。 <img src="/images/partner_15040737347220.png" alt="MoEngage 向け Amplitude Event Streaming 連携の設定フォーム" />
   1. **toggle status** を **Enabled** に設定します。
   2. **Basic Auth Token** - 認証トークンを生成します（ステップ 4 を参照）。
      - [https://www.debugbear.com/basic-auth-header-generator](https://www.debugbear.com/basic-auth-header-generator) にアクセスします。 <img src="/images/partner_15040736670612.png" alt="Basic Auth Header Generator ツール" />
      - MoEngage の **Data API ID** をユーザー名、**DATA API KEY** をパスワードとして入力します。
      - **Generate Token** ボタンをクリックします。
      - 生成されたトークンをコピーします。
      - 連携設定フォームの Basic Auth Token フィールドにトークンを貼り付けます。
   3. **DATA APP ID** を入力します。
   4. **Data Center Values** を入力します: "01"、"02"、"03"、"04"。詳細については、[こちらの記事](https://www.moengage.com/docs/user-guide/data/key-concepts/data-centers-in-moengage)を参照してください。

   | フィールド | 説明 |
   | --- | --- |
   | **App ID** | MoEngage アカウントの Workspace ID は、**Settings** \> **Account** \> **APIs** \> **Workspace ID** で確認できます。 |
   | **Data API ID** | MoEngage アカウントの Data API ID と Workspace ID は同じです。 |
   | **Data API Key** | MoEngage アカウントの Data API キーは、**Settings** \> **Account** \> **APIs** \> **API keys** \> **Data** API 設定で確認できます。 |
   | **Data Center Name** | MoEngage の URL `https://dashboard-OX.moengage.com` を確認します。ダッシュボードの値に基づいて、Amplitude ダッシュボードのデータセンター名に正しい値を設定します。[詳細はこちら](https://www.moengage.com/docs/user-guide/data/key-concepts/data-centers-in-moengage)。 |
6. **Send events** とフィルターをトグルで切り替えて、送信するイベントを選択します。
   <Note>
     - すべてのイベントを送信することもできますが、Amplitude では最も重要なイベントを選択することを推奨しています。
     - **Event Properties** フィルターを使用して、送信するイベントプロパティを選択します。
   </Note>
7. 完了したら、**Save** をクリックします。

これで、Amplitude から MoEngage へのイベントのストリーミングが開始されます。

<Info>
  **考慮事項**

  Amplitude で Event Streaming を有効にする際は、次の点に注意してください。

  - この連携は、使用する Amplitude プロジェクトごとに有効にする必要があります。
  - Amplitude は、選択したユーザー、イベント、グループのプロパティをイベントとともに送信します。
  - MoEngage は匿名ユーザーの Event Streaming をサポートしていません。
</Info>

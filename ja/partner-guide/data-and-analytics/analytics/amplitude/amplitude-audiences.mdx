## はじめに

[Amplitude](https://amplitude.com/) を使用すると、強力なプロダクト分析と行動分析によって成長を促進できます。ユーザーセグメントに共通する行動や特性を正確に把握し、効果的なターゲティングに活用できます。

<Note>
  Amplitude オーディエンス連携は現在、[Unified Identity](https://moengage-user-guide.mintlify.app/user-guide/data/user-data/unified-identity-identity-resolution) および [Portfolio](https://moengage-user-guide.mintlify.app/user-guide/settings/account/portfolio/portfolio) をサポートしていません。
</Note>

## 対象範囲

- MoEngage と Amplitude により、行動とプロダクトのより詳細な分析を可能にします。
- Amplitude を通じて顧客体験におけるセグメンテーションと実験の効果を測定し、MoEngage を通じてパーソナライズされたメッセージを送信します。
- 行動コホートを Amplitude から MoEngage に直接エクスポートしたり、Streams を利用して MoEngage から Amplitude にデータをエクスポートしたりします。

## メリットとユースケース

次のユースケースは、分析 \+ ユーザーエンゲージメントの取り組みに連携による付加価値をもたらします。

### e コマース

購入傾向の季節的な変化を把握し、該当するユーザーに MoEngage を使用してリッチプッシュ通知を送信します。たとえば、夏に高額商品を購入するユーザーのコホートをターゲットにし、類似のおすすめ商品を含むリッチプッシュ通知を送信します。

### 旅行

Amplitude で、アプリのプレミアムユーザーでもあるミレニアル世代のユーザーのコホートを作成し、MoEngage のメールを使用して人気のユニークな休暇先のおすすめを送信できます。

## 手順

<Info>
  **前提条件**

  - Amplitude アカウントの認証情報があることを確認してください。コホート同期連携を有効にするには、Amplitude にお問い合わせください。
  - MoEngage アカウントの認証情報があることを確認してください。
</Info>

### アカウントで Amplitude と MoEngage の連携を有効にする

1. コホート同期連携を有効にするには、Amplitude に連絡して、アカウントで有効にしてもらってください。
2. Amplitude アカウントで連携が有効になると、Amplitude で MoEngage を送信先として設定できるようになります。設定方法については、以下の手順を参照してください。
3. MoEngage から Amplitude へのデータエクスポート連携を有効にするには、「MoEngage から Amplitude へのキャンペーンデータのエクスポート」に記載されているいくつかの詳細を添えて、MoEngage のカスタマーサクセスマネージャー（CSM）または MoEngage サポートチームにお問い合わせください。

### Amplitude で MoEngage を送信先として設定する

Amplitude で MoEngage を送信先として設定するには、次の手順を実行します。

1. Amplitude にログインし、**Sources and Destinations** に移動します。 <img src="/images/partner_6391038683284.png" alt="Amplitude の Sources and Destinations ページ" />
2. **Sources & Destinations** ページで **Destinations** に移動し、**Add Destination** \> **MoEngage** をクリックします。すると、次の詳細を含むポップアップが表示されます。 <img src="/images/partner_6391025308308.png" alt="Amplitude で MoEngage を送信先として追加するポップアップ" />
3. MoEngage ダッシュボードにログインし、**Settings** に移動して Workspace ID とシークレットキーを取得します。
   <Info>
     Acquisition Settings は **Settings** \> **Analytics** \> **Acquisition tracking** で利用できます。
   </Info>
   1. **Settings** \> **Account** \> **APIs** に移動します。
   2. コピーアイコンをクリックして Workspace ID をコピーします。
   3. **API Keys** セクションの **Data** タイルにあるコピーアイコンをクリックして、シークレットキーをコピーします。 <img src="/images/partner_22181763389844.png" alt="Workspace ID と Data API キーが表示された MoEngage の Settings APIs ページ" />
4. 属性のマッピングは次のとおりです。
   - **User Id** - Amplitude と MoEngage の間でユーザーをマッピングするためのプライマリキーです。Amplitude と MoEngage の両方で、同じ一意のユーザー ID でユーザーを識別していることを確認してください。
   - **moe\_anonymous\_id**: Amplitude と MoEngage の間でユーザーをマッピングするために使用されるセカンダリ識別子で、Amplitude と MoEngage の間で匿名ユーザーをマッピングするために不可欠です。マッピングを可能にするため、MoEngage で `moe_anonymous_id` をユーザー属性として設定し、Amplitude ダッシュボードで選択した属性と MoEngage の `moe_anonymous_id` が同じ値であることを確認してください。
5. 送信先の設定を完了します。

Amplitude ダッシュボードですべての設定が完了したら、**Save** をクリックして MoEngage を送信先として追加します。

## Amplitude から MoEngage へのコホートのエクスポート

<Note>
  コホート名がピリオド（.）で始まらないこと、また次の使用禁止文字を含まないことを確認してください: `|`、`*`、`?`、`\`、`:`、`<`、`>`、`=`、`$`、`"`。
</Note>

特定の行動コホートを Amplitude から MoEngage にエクスポートするには、次の手順を実行します。

1. Amplitude で MoEngage と同期するコホートを開き、**Sync To** をクリックして **MoEngage** を選択します。 <img src="/images/partner_6391046166932.png" alt="Amplitude のコホートを MoEngage に同期するオプション" /> **Sync your cohort to MoEngage** ポップアップが表示されます。 <img src="/images/partner_11619075291796.png" alt="同期オプションを含む Sync your cohort to MoEngage ポップアップ" />
2. 次のいずれかを選択します。
   - **One-Time Sync**: コホートに含まれるユーザーを MoEngage に 1 回だけ送信します。それ以降、コホートは同期されません。
   - **Scheduled Sync**: このコホートの対象となった新規ユーザーや、コホートから削除された既存ユーザーなど、コホートの更新情報が 1 時間ごとまたは 1 日ごとに MoEngage に送信されます。
   - **Near Real Time Sync**: このコホートの対象となった新規ユーザーや、コホートから削除された既存ユーザーなど、コホートの更新情報が 1 分ごとに MoEngage に送信されます。

<Warning>
  Amplitude コホート内のユーザーは、MoEngage の一意のユーザープロファイルとのマッピングが試行されます。MoEngage のシステムにそのユーザープロファイルが存在しない場合、そのユーザーはマッピングされず、コホート/セグメントに追加されません。

  この場合、MoEngage のコホートのユーザー数が Amplitude のコホートよりも少なくなることがあります。コホート同期を実行する前に、すべてのユーザーが MoEngage に存在することを確認してください。
</Warning>

### MoEngage キャンペーンでコホートを使用する

同期後、コホートは次のように MoEngage でカスタムセグメントとして利用できます。

![MoEngage でカスタムセグメントとして表示される Amplitude コホート](/images/partner_6391019524756.png)

このカスタムセグメントは、任意の MoEngage キャンペーンで使用して、このセグメントに含まれるユーザーにパーソナライズされたメッセージを送信できます。

## MoEngage から Amplitude へのキャンペーンデータのエクスポート

<Info>
  **前提条件**

  Amplitude へのエクスポートには、アドオンである MoEngage Streams を使用します。
</Info>

Amplitude へのエクスポートを設定するには、**MoEngage Dashboard** \> **App Marketplace** に移動します。Amplitude を検索し、**Integrate** タブに移動します。

![MoEngage App Marketplace の Amplitude 連携タイル](/images/partner_13910721832212.png)

1. **\+ Add Integration** をクリックします。
2. フォームに入力します: Amplitude API Key - 次に示すように、**Amplitude Account** \> **Settings** \> **ProjectName** \> **General** \> **API Key** で確認できます。 <img src="/images/partner_6391019543316.png" alt="API キーが表示された Amplitude のプロジェクト設定ページ" />
3. 転送するイベントを選択し、データレジデンシーを選択します。
4. **Connect** をクリックします。

MoEngage から送信されたすべてのイベントは、Amplitude で `$source = MOENGAGE` に基づいてフィルタリングすると表示されます。これらのイベントはほぼリアルタイムで Amplitude に送信され、ユーザーの識別には Amplitude と MoEngage の間の共通ユーザー識別子が使用されます。

MoEngage で一意のユーザー ID を設定するための、MoEngage のソース別ドキュメントは次のとおりです。

- [Android](https://www.moengage.com/docs/developer-guide/android-sdk/data-tracking/basic/track-user-attributes)
- [iOS](https://www.moengage.com/docs/developer-guide/ios-sdk/data-tracking/basic/tracking-user-attributes)
- [Web](https://www.moengage.com/docs/developer-guide/web-sdk/data-tracking/web-sdk-user-attributes-tracking)
- [Data API（サーバーサイド連携）](https://www.moengage.com/docs/api/data/data-overview)

<Info>
  Amplitude の User Id と MoEngage の Unique User Id に同じ値を設定していることを確認してください。
</Info>

## レート制限

プラットフォームの安定性を維持するため、MoEngage は Amplitude オーディエンスデータの取り込みを、ワークスペースごとに 1 分あたり最大 300 リクエスト（RPM）に制限しています。ワークスペースがこの制限を超えると、MoEngage は HTTP `429 (Too Many Requests)` ステータスコードを返します。

レート制限がデータフローにどのように影響するかについては、Amplitude のデフォルトの再試行ポリシーを参照してください。

**再試行の上限到達**: Amplitude がデータのバッチに対するすべての再試行を使い切った場合、失敗したリクエストを再実行するには Amplitude サポートチームに連絡する必要があります。

<Warning>
  **Amplitude に送信されるイベントに関する注意事項**

  - Amplitude に送信されるすべてのイベントには、デフォルトで UID が含まれます。これは、MoEngage の一意のユーザープロファイルに存在する ID の値を取得します。存在する場合、Amplitude のユーザープロファイルに存在する User Id に基づいて Amplitude 上のユーザーを照合するために使用されます。
  - すべてのキャンペーンイベントには、デフォルトで `campaign_id`、`campaign_name`、`campaign_type`、`campaign_channel` が含まれます。
  - イベントが追跡されたユーザーのプロファイルに `moe_anonymous_id` 属性があるすべてのキャンペーンイベントは、`device_id` キーとして Amplitude に送信されます。
  - MoEngage のユーザープロファイルに一意のユーザー ID または `moe_anonymous_id` が設定されていないユーザーのイベントは、Amplitude によって破棄されます。
  - すべてのメールキャンペーンイベントには、デフォルトで email\_id が `moe_email_id` として含まれます。
  - すべてのプッシュキャンペーンイベントには、デフォルトで push\_id が `moe_push_id` として含まれます。
  - すべての SMS キャンペーンイベントには、デフォルトで携帯電話番号が `moe_mobile_number` として含まれます。
  - MoEngage Flows の一部であるキャンペーンのすべてのキャンペーンイベントには、2 つの追加属性 `parent_flow_id` と `parent_flow_name` が含まれます。
  - 複数のバリエーションまたはロケールを持つすべてのキャンペーンには、次の追加属性が含まれます。
    - `variation_id`
    - `locale_id`
    - `locale_name`
  - すべてのイベントには、デフォルトで `moengage_user_id` が含まれます。これは MoEngage の内部ユーザー識別子であり、MoEngage の各イベントに設定されます。
</Warning>

さらにサポートが必要な場合は、MoEngage のカスタマーサクセスマネージャー（CSM）またはサポートチームにお問い合わせください。

## よくある質問

<AccordionGroup>
  <Accordion title="Data Exports では最新のユーザー属性が保証されますか？">
    いいえ。Data Exports は主にイベントをほぼリアルタイムでエクスポートするために構築されており、MoEngage のユーザー属性は非同期で更新されるため、現時点ではエクスポートにおけるユーザー属性の最新値を保証することはできません。
  </Accordion>
  <Accordion title="データの受信はどのくらいで開始されますか？">
    通常、アカウントで自動データエクスポートが設定され、データが表示され始めるまでに最大 30 分かかります。
  </Accordion>
  <Accordion title="後から追加のイベントをエクスポートできますか？">
    はい。後から新しいイベントをエクスポートする必要がある場合は、いつでも App Marketplace で設定を編集し、新しいイベントをエクスポートに追加できます。
  </Accordion>

## はじめに

[Faraday.ai](https://faraday.ai/) は、開発者に優しい API を使用して企業が顧客行動を予測できるよう支援する顧客行動予測プラットフォームです。AI による予測を通じて、企業が顧客エンゲージメントを最適化できるようにします。

## MoEngage × Faraday

MoEngage と Faraday の連携により、MoEngage のキャンペーンインタラクションイベントで取得されたデータから、豊富な行動インサイトと予測を導き出すことができます。

## 連携

<Info>
  **前提条件**

  - Faraday アカウントへのアクセス権が必要です。
  - アカウントで [Data Warehouses Exports](https://www.moengage.com/docs/user-guide/data/exports/events/data-warehouse/bigquery-exports) を有効にする必要があります。
</Info>

### ステップ 1: MoEngage Data Warehouses Exports を設定する

MoEngage の [Data Warehouses Exports](https://www.moengage.com/docs/user-guide/data/exports/events/data-warehouse/bigquery-exports) を使用すると、ユーザーのキャンペーンインタラクションデータを Snowflake、Redshift、BigQuery などのデータウェアハウスにエクスポートできます。アカウントでこれらのエクスポートが有効になっていない場合は、カスタマーサクセスマネージャーに相談するか、MoEngage App Marketplace から直接これらの連携の有効化をリクエストできます。

Faraday は現在、MoEngage のエクスポート先となる次のデータウェアハウスをサポートしています。

1. Snowflake
2. Google BigQuery
3. GCS
4. Redshift
5. S3

### ステップ 2: データウェアハウスを Faraday に接続する

Faraday の[ヘルプドキュメント](https://faraday.ai/docs/how-to/connections)に従って、データウェアハウスを Faraday に接続するための設定を行います。

### ステップ 3: Faraday で予測を導き出すなど

データウェアハウスを Faraday に接続すると、顧客ペルソナ、支出予測、再購入の可能性、解約の可能性、商品のおすすめなど、[パーソナライズされた予測](https://faraday.ai/docs/how-to/predictions)を導き出す準備が整います。

解約した顧客、リード、1 回限りの購入者、リピート購入者など、さまざまなユースケースに応じて、Faraday で複数の[コホート](https://faraday.ai/docs/abstractions/cohorts)を作成できます。

### ステップ 4: コホートを MoEngage と同期する

Snowflake を Faraday に接続している場合は、[Snowflake Imports](https://www.moengage.com/docs/user-guide/data/imports/data-warehouses-imports/snowflake-imports) を利用して、作成したコホートを MoEngage にインポートし、ターゲットにすることができます。

## はじめに

[Mixpanel](https://mixpanel.com/) は、プロダクトチームが分析をセルフサービスで行えるようにし、ユーザーのコンバージョン、リテンション、アクティベーションに関する疑問に誰もが答えられるようにします。

## 対象範囲

MoEngage と Mixpanel の連携により、Mixpanel のコホートを MoEngage にインポートしてセグメントを作成し、今後のキャンペーンでユーザーをターゲティングする際に使用できます。また、MoEngage Streams を活用してキャンペーンイベントを Mixpanel にエクスポートし、コンバージョン、リテンション、プロダクト利用状況についてより詳細な分析を行うこともできます。

## メリットとユースケース

Mixpanel でユーザーを分析し、MoEngage を使用してユーザーとエンゲージします。

以下のユースケースは、分析とユーザーエンゲージメントの活動において、この連携がもたらす付加価値を示しています。

### E コマース

購買傾向の季節的な変化を把握し、該当するユーザーに MoEngage 経由でリッチプッシュ通知を送信します。たとえば、夏に高額商品を購入するユーザーのコホートをターゲットにして、類似のおすすめ商品を含むリッチプッシュ通知を送信できます。

### 旅行

Mixpanel で、アプリのプレミアムユーザーでもあるミレニアル世代のユーザーのコホートを作成し、人気でユニークな休暇の旅行先のおすすめを MoEngage のメールで送信できます。

### E ラーニング

プラットフォーム上でビデオシリーズを視聴中にユーザーがどこで離脱しているかを把握し、魅力的なキャンペーンでユーザーを呼び戻しましょう。ユーザー行動に関するインサイトを通じて、どのようなアクションがユーザーのアプリへの復帰を促すのかを全体的に把握できます。

## 連携

<Info>
  **前提条件**

  MoEngage と Mixpanel のログイン認証情報があることを確認してください。
</Info>

MoEngage との Mixpanel 連携は、次の 2 つの部分で構成されています。

### Mixpanel から MoEngage へのコホート同期

Mixpanel から MoEngage への連携により、Mixpanel のコホートを MoEngage にエクスポートし、このコホートに含まれるすべてのユーザーに MoEngage からパーソナライズされたキャンペーンを送信できます。

### MoEngage イベントの Mixpanel へのストリーミング

MoEngage から Mixpanel への連携により、ユーザーが MoEngage キャンペーンにエンゲージした後に生成されるキャンペーンインタラクションイベントを Mixpanel にエクスポートできます。

## Mixpanel での MoEngage 連携の設定

Mixpanel で MoEngage 連携を設定するには、以下の手順に従います。

1. Mixpanel にログインし、**Data Management** > **Integrations** に移動します。

   ![Mixpanel の Data Management Integrations メニュー](/images/partner_4418346033812.png)
2. Integrations ページで MoEngage を検索し、**CONNECT** ボタンをクリックします。以下のように、MoEngage の認証情報を入力するポップアップが表示されます。

   ![Mixpanel の MoEngage 連携接続ポップアップ](/images/partner_4418355207444.png)
3. MoEngage ダッシュボードで **Settings** > **Account** > **API Settings** に移動し、以下のフィールドに入力します。

   | フィールド | 操作 |
   | --- | --- |
   | **USERNAME** | Data API ID を入力するか、コピーして貼り付けます。MoEngage アカウントの Data API ID と Workspace ID は同じです。 |
   | **PASSWORD** | Data API Key を入力するか、コピーして貼り付けます。MoEngage アカウントの Data API キーは、**Settings** > **Account** > **APIs** > **API keys** > **Data** API settings で確認できます。 |
   | **MOE-APPKEY** | Workspace ID を入力するか、コピーして貼り付けます。MoEngage アカウントの Workspace ID は、**Settings** > **Account** > **APIs** > **Workspace ID** で確認できます。 |
   | **MOENGAGE DATACENTER** | MoEngage で登録したデータセンターです。登録したデータセンターの詳細については、[MoEngage のデータセンター](https://www.moengage.com/docs/user-guide/data/key-concepts/data-centers-in-moengage)を参照してください。 |

   ![Workspace ID と API キーが表示された MoEngage の General Settings ページ](/images/partner_4418364492180.png)
4. 保存して続行し、MoEngage を連携として接続します。

詳細については、[Mixpanel - MoEngage Integration](https://help.mixpanel.com/hc/en-us/articles/360049332572-MoEngage-Integration) を参照してください。

## Mixpanel から MoEngage へのコホートのエクスポート

<Note>
  コホート名はピリオド (.) で始まる必要があり、次の制限文字を含めることはできません: `|`、`*`、`?`、`\`、`:`、`<`、`>`、`=`、`$`、`"`。
</Note>

特定のコホートを Mixpanel から MoEngage にエクスポートするには、以下の手順に従います。

1. Mixpanel ダッシュボードのコホートページに移動します。

   ![コホート一覧が表示された Mixpanel のコホートページ](/images/partner_4418355207060.png)
2. 任意のコホートの右側にある三点メニューをクリックし、**Export to** オプションを使用して、そのコホートを MoEngage にエクスポートします。

   ![Mixpanel コホートの Export to オプション](/images/partner_4418346033172.png)

   ポップアップが表示されます。
3. **Export to MoEngage** ポップアップで、次のいずれかを選択します。

   ![同期オプションが表示された Export to MoEngage ポップアップ](/images/partner_4418364490772.png)

   | 選択肢 | 説明 |
   | --- | --- |
   | **One-time export** | コホート内のユーザーを MoEngage に一度だけエクスポートし、以降コホートは同期されません。 |
   | **Dynamic sync** | このコホートの対象となった新しいユーザーやコホートから削除された既存ユーザーなど、コホートの最新情報が **15 分**ごとに MoEngage に送信されるようにします。 |
4. **Begin Sync** をクリックしてエクスポートします。
5. コホートをエクスポートした後、以下のようにエクスポートステータスを確認します。

   ![Mixpanel コホートのエクスポートステータス](/images/partner_4418346032660.png)

### MoEngage キャンペーンでのコホートの使用

エクスポートが完了すると、次の画像のように、コホートが MoEngage のカスタムセグメントとして表示されます。

![MoEngage のカスタムセグメントとして表示された Mixpanel コホート](/images/partner_23582841735316.png)

このカスタムセグメントは、任意の MoEngage キャンペーンで使用して、このセグメント内のユーザーにパーソナライズされたメッセージを送信できます。

### Mixpanel と MoEngage 間のユーザーマッピング

Mixpanel から MoEngage にコホートをエクスポートする際、Mixpanel コホート内のすべてのユーザーは、MoEngage の一意のユーザープロファイルとのマッピングが試行されます。マッピングには、Mixpanel と MoEngage の両方のユーザーに存在する一意のユーザー識別子が使用されます。この識別子は、MoEngage から Mixpanel にキャンペーンイベントを送信する際にも使用されます。

Mixpanel の `distinct_id` にエイリアスを追加し、同じ識別子を MoEngage の ID (一意のユーザー ID) として使用していることを確認する必要があります。

MoEngage での一意のユーザー ID のトラッキングの詳細については、以下を参照してください。

- [Android](https://www.moengage.com/docs/developer-guide/android-sdk/data-tracking/basic/track-user-attributes)
- [iOS](https://www.moengage.com/docs/developer-guide/ios-sdk/data-tracking/basic/tracking-user-attributes)

<Warning>
  Mixpanel コホート内のユーザーは、MoEngage の一意のユーザープロファイルとのマッピングが試行されます。MoEngage のシステムにそのユーザープロファイルが存在しない場合、そのユーザーはマッピングされず、コホート/セグメントにも追加されません。

  この場合、MoEngage のコホートのユーザー数が Mixpanel のコホートよりも少なくなることがあります。コホート同期を実行する前に、すべてのユーザーが MoEngage に存在することを確認してください。
</Warning>

## MoEngage から Mixpanel へのキャンペーンデータのエクスポート

<Info>
  **前提条件**

  Mixpanel へのエクスポートには、アドオンである MoEngage Streams を使用します。
</Info>

MoEngage ダッシュボードで App Marketplace に移動し、Mixpanel を検索します。

1. **+ Add Integration** をクリックして、新しい連携を追加します。
2. フォームに入力します。

   ![MoEngage App Marketplace の Mixpanel 連携](/images/partner_13908623574932.png)
3. Mixpanel プロジェクトトークン - 以下に示すように、Mixpanel ダッシュボードの **Settings** > **Overview** > **Access Keys** > **Project Token** で確認できます。

   ![Project Token が表示された Mixpanel のプロジェクト設定](/images/partner_4418364489364.png)
4. 転送するイベントを選択します。デフォルトでは、MoEngage は次のセクションに記載されているデータポイントを Mixpanel に送信します。
5. **Connect** をクリックして連携を保存します。

MoEngage から送信されたすべてのイベントは、`$source = MOENGAGE` でフィルタリングすることで Mixpanel に表示されます。これらのイベントはほぼリアルタイムで Mixpanel に送信され、MoEngage と Mixpanel 間のユーザープロファイルのマッピングには Mixpanel の `distinct_id` が使用されます。

<Info>
  `mixpanel_distinct_id` を MoEngage の一意のユーザー ID として設定していることを確認してください。
</Info>

<Warning>
  **Mixpanel に送信されるイベントに関する注意点**

  - Mixpanel に送信されるすべてのイベントには、デフォルトで UID が含まれます。これは MoEngage の一意のユーザープロファイルに存在する ID の値を取得するものです。また、`mixpanel_distinct_id` の値に基づいて Mixpanel のユーザーを照合する際にも使用されます。
  - すべてのキャンペーンイベントには、デフォルトで `campaign_id`、`campaign_name`、`campaign_type`、`campaign_channel` が含まれます。
  - すべてのメールキャンペーンイベントには、デフォルトでメール ID が `moe_email_id` として含まれます。
  - すべてのプッシュキャンペーンイベントには、デフォルトでプッシュ ID が `moe_push_id` として含まれます。
  - すべての SMS キャンペーンイベントには、デフォルトで携帯電話番号が `moe_mobile_number` として含まれます。
  - MoEngage Flows の一部であるキャンペーンのすべてのキャンペーンイベントには、2 つの追加属性 `parent_flow_id` と `parent_flow_name` が含まれます。
  - 複数のバリエーションまたはロケールを持つすべてのキャンペーンには、以下の追加属性が含まれます。
    - `variation_id`
    - `locale_id`
    - `locale_name`
  - すべてのイベントには、デフォルトで `moengage_user_id` が含まれます。これは MoEngage 内部のユーザー識別子で、MoEngage の各イベントに設定されます。
  - モバイルアプリから生成されたすべてのイベントには、MoEngage 内部の識別子である `moengage_device_id` が含まれます。
</Warning>

## トラブルシューティング

### セグメントのユーザー数が 0 になっている場合

カスタムセグメント名が "All users" になっていないか確認してください。All users は MoEngage で予約されているため、カスタムセグメント名として使用できません。

### MoEngage ダッシュボードにセグメントが表示されない場合

MoEngage でアーカイブ済みのセグメントを確認してください。[アーカイブ済みのセグメントはこちら](https://dashboard-01.moengage.com/v3/#/segmentation/archived-segments)で確認できます。セグメントのアーカイブを解除してから、再試行してください。

  <Accordion title="自動データエクスポートを使用して過去のデータをエクスポートできますか?">
    現時点では、自動データエクスポートを使用して過去のデータをエクスポートすることはできません。設定後は、エクスポートを有効にした時点から各イベントのデータが表示されるようになります。
  </Accordion>

  <Accordion title="自動データエクスポートに料金はかかりますか?">
    ご利用の料金プランにまだ含まれておらず、後から有効にする必要がある場合は、カスタマーサクセスマネージャーと連携して料金プランに含める必要があります。MoEngage が毎月データウェアハウス/パートナー/API に送信するデータ量によっては、追加料金が発生する場合があります。
  </Accordion>
</AccordionGroup>

# レート制限

MoEngage は、Mixpanel からワークスペースに送信されるデータに対して、取り込みレート制限とペイロード上限を適用します。ワークスペースが制限を超えると、MoEngage は HTTP `429 (Too Many Requests)` ステータスコードを返します。レート制限がデータフローに与える影響については、Mixpanel のデフォルトの再試行ポリシーを参照してください。

Mixpanel のコホートインポートとユーザーまたはイベントのインポートでは制限が異なるため、使用するインポートタイプの値を確認してください。最新の制限については、[パートナーデータ取り込みのレート制限](/ja/partner-guide/data-and-analytics/ingestion-rate-limits)を参照してください。

## はじめに

[Google Cloud Storage](https://cloud.google.com/storage) は、大規模な非構造化データセットを格納できるエンタープライズ向けパブリッククラウドストレージプラットフォームです。

## MoEngage × GCS

MoEngage と GCS の統合により、キャンペーンのインタラクションイベントが Google Cloud Storage バケットにエクスポートされます。その後、これらのファイルを BigQuery にインポートして、さらなる処理と分析を行うことができます。

## 統合

<Info>
  **前提条件**

  - 新しいバケットとサービスアカウントを作成する権限を持つ Google Cloud Platform アカウントがあることを確認してください。
  - MoEngage から Google Cloud Storage へのデータのエクスポートには、有料アドオンである MoEngage Streams を使用します。ご利用のプランで利用可能な機能を確認するには、[Plans and Pricing](https://www.moengage.com/plans-and-pricing/) を参照してください。アカウントで有効にするには、MoEngage のカスタマーサクセスマネージャー（CSM）またはサポートチームにお問い合わせください。
</Info>

### ステップ 1: MoEngage 専用のサービスアカウントを作成する

Google Cloud Platform コンソールで、**IAM & Admin** コンソールに移動します。

1. サイドバーから **Service Accounts** を開きます。
   ![IAM & Admin コンソールの Service Accounts ホーム](/images/partner_12062501879700.png)
2. **\+ Create Service Account** ボタンをクリックします。
3. このサービスアカウントに名前と、必要に応じて説明を付けます。
4. **Create and continue** をクリックします。
   ![Google Cloud での新しいサービスアカウントの作成](/images/partner_12062703174548.png)
5. このサービスアカウントにロール **Basic \> Browser** を追加します。
   ![サービスアカウントへの Basic \> Browser ロールの割り当て](/images/partner_12062802345876.png)
6. **Continue** をクリックします。必要に応じて、このサービスアカウントへのアクセス権をユーザーに付与します。
7. **Done** をクリックします。
8. サービスアカウントの一覧から、作成したサービスアカウントを開きます。
9. **Keys** タブに移動し、**Add Key** をクリックして、**Create new key** を選択します。
   ![サービスアカウントの Keys タブにある Add Key オプション](/images/partner_12062893736724.png)
10. **Key Type** として **JSON** を選択し、**Create** をクリックします。
    ![サービスアカウントキー作成時にキータイプとして JSON を選択](/images/partner_12062926508052.png)
11. 新しいキーが JSON 形式で自動的にダウンロードされます。このファイルは安全に保管してください。後で MoEngage ダッシュボードにアップロードする必要があります。

### ステップ 2: このサービスアカウントにバケットへの権限を付与する

1. サービスアカウントの詳細ページで、サービスアカウントのメールアドレスをコピーします。
   ![詳細ページのサービスアカウントのメールアドレス](/images/partner_12063141549076.png)
2. **Cloud Storage** コンソールに移動し、MoEngage にイベントをエクスポートさせたいバケットを開きます。
3. **Permissions** タブで **Grant Access** をクリックします。
   ![バケットの Permissions タブにある Grant Access オプション](/images/partner_12063166880276.png)
4. **New Principals** フィールドにサービスアカウントのメールアドレスを貼り付けて選択します。
5. ロール **Cloud Storage \> Storage Admin** を割り当てます。
   ![サービスアカウントへの Storage Admin ロールの割り当て](/images/partner_12063216822036.png)
6. **Save** をクリックします。

### ステップ 3: GCP アカウントで API とサービスを有効にする

1. GCP コンソールで **APIs & Services** に移動し、**\+ Enable APIs and Services** をクリックします。
   ![GCP コンソールの Enable APIs and Services オプション](/images/partner_12063295895828.png)
2. **Cloud Storage** を検索し、API の詳細ページを開きます。
3. **Enable** をクリックして有効にします。
   ![GCP での Cloud Storage API の有効化](/images/partner_12063394282388.png)

### 必要な権限に関する注意

エンドツーエンドのテストを実行するには、MoEngage でいくつかの追加の権限を設定する必要があります。IT ポリシーでこれらの権限が許可されていない場合は、スキップできます。ただし、その場合は App Marketplace から接続をテストできません。これらの任意の権限をスキップしても、実際のデータエクスポートには一切影響しません。

| 権限 | 必須 | 説明 |
| --- | --- | --- |
| `resourcemanagement.projects.get` | いいえ | Google Cloud Resource Manager でプロジェクトのメタデータを表示することをユーザーに許可します。MoEngage はテスト中にサービスアカウントにアクセスするためにこの権限を使用します。 |
| `resourcemanagement.projects.getIampolicy` | いいえ | Google Cloud Resource Manager でプロジェクトの IAM ポリシーを表示することをユーザーに許可します。MoEngage はバケットに適切なポリシーが割り当てられているかどうかを確認するためにこの権限を使用します。 |
| `storage.bucket.get` | いいえ | Google Cloud Storage バケットのメタデータを表示することをユーザーに許可します。MoEngage は設定時に指定されたバケットが実際に存在するかどうかを確認するためにこの権限を使用します。 |
| `storage.object.create` | はい | Google Cloud Storage バケット内にオブジェクト（ファイル）を作成することをユーザーに許可します。MoEngage がバケット内にファイルを作成するには、この権限が必要です。 |
| `storage.object.get` | はい | Google Cloud Storage バケット内のオブジェクト（ファイル）の内容を読み取ることをユーザーに許可します。MoEngage がバケット内にファイルが正しく作成されたかどうかを確認するには、この権限が必要です。 |
| `storage.object.update` | はい | Google Cloud Storage バケット内のオブジェクト（ファイル）の内容を変更することをユーザーに許可します。不一致があった場合に MoEngage がファイルを更新するには、この権限が必要です。 |

MoEngage が必要とする必須の権限と、IT ポリシーで承認されたテスト用の任意の権限を組み合わせたカスタムロールを自由に作成してください。

## MoEngage から GCS へのイベントのエクスポート

MoEngage から Google Cloud Storage バケットにイベントをエクスポートできます。エクスポートを設定するには、[GCS エクスポートガイド](/ja/user-guide/data/exports/events/data-warehouse/google-cloud-storage-gcs-exports)を参照してください。

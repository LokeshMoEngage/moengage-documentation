## はじめに

[Sheetlabs](https://sheetlabs.com/) は、スプレッドシートを強力で十分にドキュメント化された API に変換できるプラットフォームです。

## MoEngage と Sheetlabs

Sheetlabs を使用すると、Google Sheets をシンプルな CMS として利用し、MoEngage で送信するキャンペーンに動的コンテンツを提供できます。

## 連携

<Info>
  **前提条件**

  - Sheetlabs アカウントにアクセスできることを確認してください。
</Info>

### ステップ 1: Sheetlabs にテーブルをインポートする

Excel ドキュメントをインポートするか、Google アカウントを接続して Google Sheets をインポートできます。

Sheetlabs ダッシュボードで、Data Tables メニューに移動します。

- Google アカウントからインポートするには、「Import from Google Sheets」をクリックします。その後、Google アカウントを接続し、Sheetlabs に必要な権限を付与します。Sheetlabs には、テーブルのデータを同期し続けるオプションも用意されています。
- CSV または Excel からインポートするには、「Import data table from CSV or Excel」をクリックします。

### ステップ 2: Sheetlabs で API を作成する

![Sheetlabs Dashboard で新しい API を作成する](/images/partner_14982593002516.png)

1. Sheetlabs Dashboard で、APIs メニューに移動します。
2. API を作成するデータテーブルを選択します。
3. API に名前と説明を付けます。
4. データを取得する GET API と、データを挿入する書き込み API を設定できます。

### ステップ 3: MoEngage Content APIs を設定する

MoEngage の [Content APIs](https://www.moengage.com/docs/user-guide/campaigns-and-channels/getting-started/campaign-content/content-apis) を使用して、Sheetlabs をフィードの 1 つとして追加します。ユースケースごとに、Sheetlabs の複数の API を同時に追加できます。

#### API の設定

1. **Settings** \> **Advanced settings** \> **Content API** に移動します。Content API 画面の右上にある **\+ Add content API** をクリックします。
   ![Advanced settings ページから Content API を追加する](/images/partner_21979703984276.png)
2. エンドポイント URL に Sheetlabs API を追加します。

#### API URL

API を設定すると、API Details ページでそのエンドポイント（**Base URL**）を確認できます。

![Base URL が表示された Sheetlabs の API Details ページ](/images/partner_14983550308628.png)

3. Sheetlabs の設定時に設定したヘッダーとパラメーターを入力します。「@」を入力して、パーソナライズされた値を使用することもできます。
   ![MoEngage の Content API 設定でヘッダーとパラメーターを設定する](/images/partner_14983776876180.png)
4. Save をクリックします。MoEngage に Sheetlabs API が追加されたことを確認できます。
   <Note>
     Test ボタンをクリックして API をテストすることもできます。API レスポンスをテストして検証できます。
   </Note>
   ![MoEngage で Sheetlabs Content API のレスポンスをテストする](/images/partner_14983880955924.png)

### ステップ 4: キャンペーンで Content APIs を使用してデータを取得する

これで、キャンペーンでこれらの Content API を使用できます。Content APIs の詳細については、[こちら](https://www.moengage.com/docs/user-guide/campaigns-and-channels/getting-started/campaign-content/content-apis)をご覧ください。

1. キャンペーン作成のステップ 2 で、@ を入力します。
2. ポップアップで、ステップ 2 で設定した Content API を選択できます。
3. [MoEngage Templating Language](https://www.moengage.com/docs/user-guide/campaigns-and-channels/getting-started/message-personalization/jinja-templating-language) を使用して API レスポンスを解析し、そのコンテンツをキャンペーンで使用できます。

## MoEngage Connector Campaign を使用してシートにデータをプッシュする

MoEngage でコネクターキャンペーンを作成するには、次の操作を行います。

1. Create Campaign \> Connectors \> Custom に移動し、ニーズに最も適した配信タイプを選択します。
   ![MoEngage で Custom コネクターと配信タイプを選択する](/images/partner_21979703989396.png)
2. キャンペーンのステップ 2 で次の操作を行います。

### Sheetlabs API を使用してデータを送信する

新しいレコードを作成するには、`POST` メソッドを使用し、JSON 形式で 1 つ以上のレコードを含む配列を指定します。

- メソッドとして `POST` を選択します。
- Webhook URL としてベース URL を追加します。
  ![Sheetlabs 用のコネクターキャンペーンの Webhook 設定](/images/partner_14984508048148.png)
- Body-type として「JSON」を選択し、キーと値のペアを適宜追加します。詳細については、[Sheetlabs のドキュメント](https://app.sheetlabs.com/docs/consumers/writing-data/)を参照してください。

### リクエストをプレビューする

これで、キャンペーンのテストと送信の準備が整いました。Create Connector Campaign のステップ 2 にある Test 機能を使用して、コネクターの設定をテストすることもできます。

# はじめに

[Mozart Data](https://mozartdata.com/) は、誰でも簡単にデータを統合、整理し、分析用に準備できる、すぐに使えるモダンデータスタックを提供します。

# MoEngage × Mozart Data

MoEngage と Mozart Data の連携により、Snowflake をデータウェアハウスとして使用して、MoEngage と Mozart の間でデータをインポートおよびエクスポートできます。この連携を活用すると、Mozart のデータと MoEngage のデータを組み合わせて、ユーザー行動を効果的に分析できます。さらに、ビジネスインテリジェンスツールを使用して、Snowflake に保存されたデータをさらに探索し、インサイトを得ることもできます。この連携により、MoEngage と Mozart の間でシームレスなデータフローが実現し、顧客エンゲージメントの機会を強化し、ユーザー行動をより総合的に理解できるようになります。

# 連携

<Info>
  - この連携には Mozart Data アカウントが必要です。
  - アカウントで [Snowflake Exports](https://www.moengage.com/docs/user-guide/data/exports/events/data-warehouse/snowflake-exports) を有効にする必要があります。
  - アカウントで [Snowflake Imports](https://www.moengage.com/docs/user-guide/data/imports/data-warehouses-imports/snowflake-imports) を有効にする必要があります。
</Info>

Mozart Data では、すべてのデータの保存に Snowflake アカウントを使用する必要があります。MoEngage は Snowflake とのネイティブな双方向連携を備えており、MoEngage との間でデータをシームレスに転送できます。

Snowflake アカウントをお持ちでない場合は、Mozart Data が[新しい Snowflake アカウントをプロビジョニング](https://help.mozartdata.com/docs/setting-up-data-warehouse)できます。

## MoEngage から Mozart Data にデータを送信する

[Snowflake Exports](https://www.moengage.com/docs/user-guide/data/exports/events/data-warehouse/snowflake-exports) を使用して、ユーザーのキャンペーンインタラクションデータを MoEngage から Snowflake テーブルに送信できます。

## Mozart Data から MoEngage にデータを送信する

Mozart Data を使用すると、データに対してさまざまな変換を実行できるほか、より多くの BI ツールやデータソースを Mozart Data にリンクし、それらを組み合わせてより総合的なビューを得ることができます。準備ができたら、[Snowflake Imports](https://www.moengage.com/docs/user-guide/data/imports/data-warehouses-imports/snowflake-imports) を使用してこのデータを MoEngage にインポートできます。現在、ユーザーとイベントのインポートをサポートしています。

## 連携を使用する

Mozart Data のユーザーは、Snowflake データウェアハウスに同期された MoEngage のデータにシームレスにアクセスできます。Mozart Data は強力な SQL 変換レイヤーを提供しており、カスタムビューやテーブルを作成して、MoEngage のメッセージに対するユーザーエンゲージメントを分析できます。MoEngage のデータを、人口統計情報、購買履歴、製品の使用状況などの他のアプリケーションデータと組み合わせることで、エンゲージメント戦略について十分な情報に基づいた意思決定を行い、ユーザーリテンションを向上させるための貴重なインサイトを得ることができます。Mozart Data の Query ツールを使用すると、そのインターフェース内で詳細な分析を実行し、結果をプレゼンテーション用にエクスポートできます。Mozart Data と MoEngage の連携により、データの可能性を最大限に引き出し、データドリブンな意思決定によって顧客エンゲージメント戦略を強化できます。

## はじめに

[Zapier](https://zapier.com/) は、使用しているアプリやサービスを接続してワークフローを自動化できるオンラインプラットフォームです。MoEngage と Zapier の連携を使用すると、Zapier 上の 5,000 以上のアプリを対象としたカスタムワークフローの自動化を作成できます。

「Create or Update User」アクションは、MoEngage にユーザーを追加するのに役立ちます。ユーザーがすでに存在する場合、このアクションはユーザーの属性を更新します。

## ユースケース

このアクションを使用すると、Zapier を使用して複数のソースからほぼリアルタイムでユーザーを作成または更新できます。以下はその一例です。

1. Google Form が送信されたときに、MoEngage のユーザー属性を更新する。
2. Facebook Lead Ad の新しいリードで、MoEngage のユーザーを作成または更新する。
3. HubSpot から MoEngage のユーザーを作成または更新する。
4. Typeform のエントリから MoEngage に新しいユーザーを追加する。
5. Google Sheets の行から MoEngage のユーザーを作成または更新する。

<Info>
  **前提条件**

  Zapier アカウントにアクセスでき、そのアカウントが MoEngage アカウントに接続されていることを確認してください。[こちらの手順に従って Zapier を MoEngage に接続](/ja/partner-guide/data-and-analytics/workflow-automation/zapier/overview#connecting-zapier-to-moengage)できます。
</Info>

## 連携

このアクションは、MoEngage の [User APIs](https://www.moengage.com/docs/api/user/track-user) を使用します。このチュートリアルでは、ユースケース #1「Google Form が送信されたらすぐに MoEngage のユーザー属性を更新する」を取り上げます。[Zapier Dashboard](https://zapier.com/app/dashboard) で、左上の「+ Create Zap」をクリックします。

### ステップ 1: トリガーアプリとして Google Forms を選択する

トリガーとして「Google Forms」と入力して選択します。これが Zap を開始するトリガーになります。

![Zapier でトリガーアプリとして Google Forms を選択する](/images/partner_7721767045524.png)

### ステップ 2: トリガーアプリを設定する

1. ドロップダウンからイベント「New Form Response」を選択します。continue をクリックします。
2. まだ接続していない場合は、Google アカウントを接続します。選択したら continue をクリックします。
3. 「Set up trigger」ステップで、ドロップダウンからフォームを選択します。continue をクリックします。
4. 「Test Trigger」をクリックして、最近のフォーム送信をサンプルデータとして取得します。データがない場合は、自動的に入力されます。
5. このデータに問題がなければ、continue をクリックします。

![フォームを選択した Google Forms トリガーの設定](/images/partner_7721915281300.png)

![Google Form の送信によるテストトリガーのサンプルデータ](/images/partner_7721915254548.png)

### ステップ 3: アクションアプリとして MoEngage を追加する

アプリから「MoEngage」を検索して選択します。

![アクションアプリとして MoEngage を検索して選択する](/images/partner_7568867646612.png)

### ステップ 4: MoEngage アクションを設定する

1. イベントのドロップダウンから「Create or Update User」を選択します。continue をクリックします。
2. 前提条件に従っていれば、MoEngage アカウントがすでに一覧に表示されています。そのアカウントを選択するか、新しいアカウントを接続できます。完了したら continue をクリックします。
3. 次のステップ「Set up action」では、入力するか前のステップからマッピングするための属性とユーザープロパティのリストが表示されます。[詳細はこちら](/ja/api/user/track-user)をご覧ください。

![属性フィールドを含む Create or Update User アクションの設定](/images/partner_7722082187540.png)

![Create or Update User アクションのフィールドの続き](/images/partner_7722082759956.png)

![Create or Update User アクションのカスタム属性セクション](/images/partner_7722116477332.png)

![MoEngage の Create or Update User アクションの追加フィールド](/images/partner_7722116440084.png)

![Create or Update User アクションの最後のフィールドと確認](/images/partner_7722087108116.png)

すべての必須フィールドに入力すると、この設定をテストするオプションが表示されます。キーと値のペアの形式でカスタム属性を追加し、前のトリガーアプリの入力にマッピングすることもできます。

![前のトリガーからカスタムのキーと値の属性ペアを追加する](/images/partner_7722184370324.png)

前のステップからマッピングデータを選択すると、次のようになります。

![Create or Update User アクションに表示されたマッピング済みデータ](/images/partner_7722189009172.png)

4. この設定では、次のようにリンクしています。
   1. `Customer ID` → `Google Forms (Email Address)`
   2. `Other Attributes` → `form_submitted_on` → `Google Forms (Last Submitted Time)`
   3. `Other Attributes` → `another_attribute` → `"I can also write my own text"`
   4. マッピングに問題がなければ、「Continue」をクリックします。
5. この設定をテストするオプションが表示されます。

![Create or Update User アクションのテスト設定画面](/images/partner_7722308968724.png)

![Create or Update User のテスト設定ビューの続き](/images/partner_7722346499092.png)

6. 「Test & continue」をクリックして、この設定をテストします。
7. API 呼び出しが成功すると、「success」が返されます。

![Create or Update User アクションの API 呼び出し成功レスポンス](/images/partner_7722381695764.png)

MoEngage ダッシュボードで確認することもできます。テストユーザーのプロファイルに移動し、カスタム属性を確認します。

![テストユーザーの MoEngage プロファイルでカスタム属性を確認する](/images/partner_7722405725332.png)

8. すべてが正常に動作することを確認したら、「Publish Zap」をクリックします。Google Form に新しい回答が追加されるたびに Zap が実行されます。

## はじめに

[Zapier](https://zapier.com/) は、使用しているアプリやサービスを接続してワークフローを自動化できるオンラインプラットフォームです。MoEngage と Zapier の連携を使用すると、Zapier 上の 5,000 以上のアプリを対象としたカスタムワークフローの自動化を作成できます。

「Import User Event」アクションは、MoEngage にイベントをインポートするのに役立ちます。

## ユースケース

このアクションを使用すると、Zapier を使用して複数のソースのトリガーでカスタムイベントをインポートできます。以下はその一例です。

1. Shopify で New Paid Order が発生したときに、MoEngage で新しいイベントを作成する。
2. Google Form が送信されたときに、MoEngage に新しいユーザーアクションイベントを追加する。
3. 新しい Typeform エントリが作成されたときに、MoEngage で新しいイベントを作成する。
4. 新しい HubSpot Engagement が発生したときに、MoEngage で新しいイベントを作成する。
5. Mailchimp で New Order が作成されたときに、MoEngage で新しいイベントを作成する。

<Info>
  **前提条件**

  Zapier アカウントにアクセスでき、そのアカウントが MoEngage アカウントに接続されていることを確認してください。[こちらの手順に従って Zapier を MoEngage に接続](/ja/partner-guide/data-and-analytics/workflow-automation/zapier/overview#connecting-zapier-to-moengage)できます。
</Info>

## 連携

このアクションは、MoEngage の [Event APIs](/ja/api/event/track-event) を使用します。このチュートリアルでは、ユースケース #1「Shopify で New Paid Order が発生したときに、MoEngage で新しいイベントを作成する」を取り上げます。[Zapier Dashboard](https://zapier.com/app/dashboard) で、左上の「+ Create Zap」をクリックします。

### ステップ 1: トリガーアプリとして Shopify を選択する

トリガーとして「Shopify」と入力して選択します。これが Zap を開始するトリガーになります。

![Zapier でトリガーアプリとして Shopify を選択する](/images/partner_7903582390804.png)

### ステップ 2: トリガーアプリを設定する

1. ドロップダウンからイベント「New Paid Order」を選択します。continue をクリックします。
2. まだ接続していない場合は、Shopify アカウントを接続します。選択したら continue をクリックします。
3. 「Set up trigger」ステップで、要件に応じてフォームに入力します。
4. このデータに問題がなければ、continue をクリックします。
5. このトリガーをテストするオプションが表示されます。「Test Trigger」をクリックしてから「Continue」をクリックします。

![New Paid Order イベントを使用した Shopify トリガーの設定](/images/partner_7903962419220.png)

![Shopify の New Paid Order のテストトリガーのサンプルデータ](/images/partner_7903972701332.png)

### ステップ 3: アクションアプリとして MoEngage を追加する

アプリから「MoEngage」を検索して選択します。

![アクションアプリとして MoEngage を検索して選択する](/images/partner_7568867646612.png)

### ステップ 4: MoEngage アクションを設定する

1. イベントのドロップダウンから「Import User Event」を選択します。continue をクリックします。
2. 前提条件に従っていれば、MoEngage アカウントがすでに一覧に表示されています。そのアカウントを選択するか、新しいアカウントを接続できます。完了したら continue をクリックします。
3. 次のステップ「Set up action」では、入力するか前のステップからマッピングするためのフォームが表示されます。[詳細はこちら](/ja/api/event/track-event)をご覧ください。

![フォームフィールドを含む Import User Event アクションの設定](/images/partner_7904712286484.png)

![イベント属性を含む Import User Event の設定の続き](/images/partner_7904090410004.png)

すべての必須フィールドに入力すると、この設定をテストするオプションが表示されます。このフォームの入力方法については、[Event API](/ja/api/event/track-event) の説明をお読みください。キーと値のペアの形式でカスタム属性を追加し、前のトリガーアプリの入力にマッピングすることもできます。

![Shopify の出力からマッピングしたカスタムイベント属性を追加する](/images/partner_7904186798612.png)

前のステップからマッピングデータを選択すると、次のようになります。

![マッピングが完了した Import User Event の設定](/images/partner_7904321776916.png)

4. この設定では、次のようにリンクしています。
   1. `Customer ID` → `Shopify (Contact Email)`
   2. `Event ID` → `"shopify_new_paid_order"`
   3. `Event Attributes` → `customer_accepts_marketing` → `Shopify (Customer Accepts Marketing)`
   4. `Event Attributes` → `another_attribute` → `"You can write your own values"`
   5. マッピングに問題がなければ、「Continue」をクリックします。
5. この設定をテストするオプションが表示されます。

![Import User Event アクションのテスト設定画面](/images/partner_7904435535636.png)

6. 「Test & continue」をクリックして、この設定をテストします。
7. API 呼び出しが成功すると、「success」が返されます。

![Import User Event の API 呼び出し成功レスポンス](/images/partner_7904439950228.png)

MoEngage ダッシュボードで確認することもできます。MoEngage Dashboard > Settings > Data Management > Events > Custom events タブに移動し、「shopify_new_paid_order」を検索します。

![MoEngage の Custom events タブでインポートされたイベントを確認する](/images/partner_7904581192340.png)

8. すべてが正常に動作することを確認したら、「Publish Zap」をクリックします。Google Form に新しい回答が追加されるたびに Zap が実行されます。

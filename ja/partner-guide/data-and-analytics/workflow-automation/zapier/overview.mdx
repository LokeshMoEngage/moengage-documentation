## はじめに

[Zapier](https://zapier.com/) は、使用しているアプリやサービスを接続してワークフローを自動化できるオンラインプラットフォームです。MoEngage と Zapier の連携を使用すると、Zapier 上の 5,000 以上のアプリを対象にカスタムのワークフロー自動化を作成できます。

## MoEngage と Zapier

MoEngage と Zapier の連携により、MoEngage アカウントを Zapier のマーケットプレイスに掲載されている Google Workplace、Slack、Salesforce、WordPress などのさまざまなサードパーティの連携先に接続し、各種アクションを自動化できます。

たとえば、Google フォームを使用して顧客にベータテストへのオプトインを依頼したとします。ここで、ユーザーが Google フォームに回答するとすぐに、値が *true* のユーザー属性「beta user」が更新されるように、フォームを MoEngage に接続したいとします。Zapier を使用すると、次のワークフローを作成できます: Google フォームでの *Every New Response (トリガー)* ごとに、MoEngage で *Update User (アクション)* を実行します。

Zapier の仕組みについては、[Zapier による Quick Start Guide](https://help.zapier.com/hc/en-us/articles/22234847450893-Zap-workflows-quick-start-guide) で詳しく確認できます。

## トリガーとアクション

Zapier の用語では、「zap」とはアプリやサービスを接続する自動化されたワークフローのことです。どの zap でも、最初にトリガーを指定します。zap を有効にすると、トリガーが検出されるたびに Zapier が該当するアクションを自動的に実行します。

以下のトリガーとアクションがサポートされています。

### サポートされているトリガー

MoEngage の [Connector Campaigns](https://www.moengage.com/docs/user-guide/campaigns-and-channels/connectors/create/create-a-connector-campaign) を使用すると、MoEngage からさまざまな目的で Zapier のワークフローをトリガーできます。

[MoEngage をトリガーとして使用する方法とそのユースケースについてはこちらをお読みください](/ja/partner-guide/data-and-analytics/workflow-automation/zapier/use-moengage-as-a-trigger)。

### サポートされているアクション

以下のアクションがサポートされています。

| アクション名 | 説明 |
| --- | --- |
| [Create or Update User](/ja/partner-guide/data-and-analytics/workflow-automation/zapier/create-or-update-users) | このアクションを使用すると、顧客を MoEngage にインポートできます。ユーザーがすでに存在する場合は、ユーザーの属性を更新します。[このアクションのユースケースを見る](/ja/partner-guide/data-and-analytics/workflow-automation/zapier/create-or-update-users#use-cases)。 |
| [Add or Remove User from Cohort (Audience)](/ja/partner-guide/data-and-analytics/workflow-automation/zapier/update-cohorts-audience) | このアクションを使用すると、Cohort API を使用してコホートにユーザーを追加または削除できます。[このアクションのユースケースを見る](/ja/partner-guide/data-and-analytics/workflow-automation/zapier/update-cohorts-audience#use-cases)。 |
| [Import User Event](/ja/partner-guide/data-and-analytics/workflow-automation/zapier/import-user-event) | このアクションを使用すると、Event API を使用してユーザーイベントを MoEngage にインポートできます。[このアクションのユースケースを見る](/ja/partner-guide/data-and-analytics/workflow-automation/zapier/import-user-event#use-cases)。 |
| [Fetch Campaign Report](/ja/partner-guide/data-and-analytics/workflow-automation/zapier/fetch-campaign-report) | このアクションを使用すると、([レポートビルダー](https://www.moengage.com/docs/user-guide/campaigns-and-channels/campaign-management-and-reports/create-ad-hoc-campaign-reports)で設定した)[キャンペーンレポート](https://www.moengage.com/docs/user-guide/campaigns-and-channels/campaign-management-and-reports/create-ad-hoc-campaign-reports)を取得できます。[このアクションのユースケースを見る](/ja/partner-guide/data-and-analytics/workflow-automation/zapier/fetch-campaign-report#use-cases)。 |

## 連携

<Info>
  **前提条件**

  - Zapier アカウントにアクセスできることを確認してください。
</Info>

### Zapier を MoEngage に接続する

Zap を作成する前に、Zapier を MoEngage アカウントに接続する必要があります。Zapier ダッシュボードで次の操作を行います。

1. My Apps > Add connection に移動します。

![Zapier の My Apps の Add connection 画面](/images/partner_7566825030804.png)

2. MoEngage を検索します。認証情報を入力するための新しいウィンドウが開きます。

![Zapier の MoEngage 認証情報ウィンドウ](/images/partner_7566894151060.png)

これらの認証情報は MoEngage ダッシュボードから取得できます。Data API ID と Data API Key をコピーします。

MoEngage ダッシュボードの情報をもとに、Zapier で次のフィールドに入力します。

| フィールド | 操作 |
| --- | --- |
| Username | Data API ID を入力するか、コピーして貼り付けます。MoEngage アカウントの Data API ID と Workspace ID は同じです。MoEngage アカウントの Workspace ID は **Settings > Account > APIs > Workspace ID** で確認できます。 |
| Password | Data API Key を入力するか、コピーして貼り付けます。MoEngage アカウントの Data API キーは **Settings > Account > APIs > API keys > Data** API 設定で確認できます。 |
| Region | MoEngage で契約した MoEngage のデータセンターです。契約したデータセンターの詳細については、[MoEngage のデータセンター](https://www.moengage.com/docs/user-guide/data/key-concepts/data-centers-in-moengage)を参照してください。 |

3. *Yes, Continue* をクリックします。
4. アプリの一覧に MoEngage が表示されます。ここで MoEngage のアプリ名とリージョンを確認できます。

![Zapier のアプリ一覧に名前とリージョン付きで表示された MoEngage アプリ](/images/partner_7567012951316.png)

これで完了です。MoEngage アカウントが Zapier に接続されたので、要件に応じてワークフローの作成を開始できます。

### 最初の Zap を作成する

次の例では、Google フォームから MoEngage にコホートを送信します。これらのコホートは、MoEngage キャンペーンのターゲティングに使用できます。「Google フォームでの Every New Response (トリガー) ごとに、MoEngage で Add the User to a Cohort (アクション) を実行する」という zap を作成します。

Zapier ダッシュボードで、「Create Zap」ボタンをクリックします。

#### ステップ A: トリガーアプリを選択する

1. 「Google Forms」と入力して選択します。

![Zapier でトリガーアプリとして Google Forms を選択](/images/partner_7568521728148.png)

2. ワークフローエディターで次の操作を行います。
   1. **Choose event:** *New Form Response* を選択します。Continue をクリックし、Google アカウントにサインインします。
   2. **Choose account:** ドロップダウンから接続済みのアカウントを選択し、*Continue* をクリックします。
   3. **Setup trigger:** ドロップダウンボックスからフォーム名を選択し、*Continue* をクリックします。Zapier がトリガーをテストするためのサンプルエントリを取得します。次に Continue をクリックして次のステップに進みます。

![フォームの選択とサンプルデータを表示する Setup trigger ステップ](/images/partner_7568817024404.png)

3. 次に、MoEngage をアクションとして設定する必要があります。「+」をクリックして MoEngage を検索します。

![アクションとして MoEngage を検索して選択](/images/partner_7568867646612.png)

4. アクションの一覧から「Add or Remove User from Cohort (Audience)」を選択します。「Continue」をクリックします。
5. 次に、表示される一覧からアカウントを選択します。以前に接続したアカウントがすでに表示されているはずです。「Continue」をクリックします。
6. フィールドの値を入力します。[Cohort API の詳細はこちら](https://www.moengage.com/docs/api/cohort-sync/sync-cohort-members)をお読みください。値を直接入力することも、前のステップの出力をマッピングすることもできます。

![Google フォームの出力からマッピングされたコホートアクションのフィールド](/images/partner_7568994011924.png)

7. 「Test & Continue」をクリックします。
8. これで Zap を公開する準備が整いました。

## はじめに

[Zapier](https://zapier.com/) は、使用しているアプリやサービスを接続してワークフローを自動化できるオンラインプラットフォームです。MoEngage と Zapier の連携を使用すると、Zapier 上の 5,000 以上のアプリを対象にカスタムのワークフロー自動化を作成できます。

アクション「Add or Remove User From Cohort (Audience)」は、MoEngage のコホート (オーディエンス) を更新するのに役立ちます。コホートにユーザーを追加するか、コホートからユーザーを削除するかを選択できます。ユーザーがすでにコホートに存在する場合、このアクションは何も行いません。

## ユースケース

このアクションを使用すると、Zapier を使用して複数のソースからほぼリアルタイムでコホートを更新できます。利用を開始するためのアイデアをいくつか紹介します。

1. GoTo Webinar の新しい登録者を MoEngage のコホートに追加する。
2. Google Sheets に新しい行が追加されたときに、MoEngage のコホートからユーザーを削除する。
3. Google フォームが送信されたときに、MoEngage のコホートにユーザーを追加する。
4. Facebook Lead Ad の新しいリードを MoEngage 内のコホートに追加する。
5. 新しい Typeform のエントリが作成されたときに、コホートからユーザーを削除する。

<Info>
  **前提条件**

  Zapier アカウントにアクセスでき、そのアカウントを MoEngage アカウントに接続済みであることを確認してください。[こちらの手順に従って Zapier を MoEngage に接続](/ja/partner-guide/data-and-analytics/workflow-automation/zapier/overview#connecting-zapier-to-moengage)できます。
</Info>

## 連携

このアクションは、MoEngage の [Cohort/Audience API](https://www.moengage.com/docs/api/cohort-sync/sync-cohort-members) を使用します。このチュートリアルでは、ユースケース #1「GoTo Webinar の新しい登録者を MoEngage のコホートに追加する」を取り上げます。[Zapier ダッシュボード](https://zapier.com/app/dashboard)で、左上隅にある「+ Create Zap」をクリックします。

### ステップ 1: トリガーアプリとして GoTo Webinar を選択する

トリガーとして「GoTo Webinar」と入力して選択します。これが zap を開始するトリガーになります。

![Zapier でトリガーアプリとして GoTo Webinar を選択](/images/partner_7899336232340.png)

### ステップ 2: トリガーアプリを設定する

1. ドロップダウンからイベント「New Registrant」を選択します。Continue をクリックします。
2. まだ接続していない場合は、GoTo Webinar アカウントを接続します。「Allow」をクリックして Zapier と接続します。選択したら、Continue をクリックして次のステップに進みます。

![GoTo Webinar を Zapier に接続して認可](/images/partner_7900142277396.png)

3. 「Set up trigger」ステップで、ドロップダウンからウェビナーを選択します。Continue をクリックします。
4. 「Test Trigger」をクリックして、最近の登録者をサンプルデータとして取得します。データが存在しない場合は、GoTo Webinar ダッシュボードから新しい登録者を作成できます。
5. このデータに問題がなければ、Continue をクリックします。

![GoTo Webinar の登録者サンプルを使用したテストトリガーの設定](/images/partner_7900176305812.png)

![取得した登録者データを表示するテストトリガーの結果](/images/partner_7900165890964.png)

### ステップ 3: アクションアプリとして MoEngage を追加する

「+」をクリックして新しいステップを追加します。次に、アプリから「MoEngage」を検索して選択します。

![アクションアプリとして MoEngage を検索して選択](/images/partner_7568867646612.png)

### ステップ 4: MoEngage アクションを設定する

1. イベントのドロップダウンから「Add or Remove User From Cohort (Audience)」を選択します。Continue をクリックします。
2. 前提条件に従っていれば、MoEngage アカウントがすでに一覧に表示されているはずです。そのアカウントを選択するか、新しいアカウントを接続できます。完了したら Continue をクリックします。
3. 次のステップ「Set up action」では、入力するか前のステップからマッピングするためのフォームが表示されます。[詳細はこちらをクリックしてください](/ja/api/cohort-sync/sync-cohort-members)。

![Add or Remove User from Cohort アクションイベントを選択](/images/partner_7899503804948.png)

![コホートアクション設定での MoEngage アカウントの選択](/images/partner_7899479160340.png)

ユーザーを追加するか削除するかを選択します。すべての必須フィールドに入力すると、この設定をテストするオプションが表示されます。「User ID」または「Anonymous ID」の少なくとも一方を必ず入力してください。詳細については、[Cohort API のドキュメント](https://www.moengage.com/docs/api/cohort-sync/sync-cohort-members)をお読みください。

キーと値のペアの形式でカスタム属性を追加し、前のトリガーアプリからの入力にマッピングすることもできます。

![追加/削除の選択と必須フィールドを含むコホートアクションの設定](/images/partner_7899927753748.png)

前のステップからマッピングデータを選択すると、次のようになります。

![GoTo Webinar トリガーからマッピングされたデータを含むコホートアクション](/images/partner_7899920176020.png)

4. この設定では、次のようにリンクしています。
   1. `Cohort Name` → `"goto_sample_webinar"`
   2. `Cohort ID` → `"goto_sample_webinar"`
   3. `User ID` → `GoTo Webinar (Email)`
   4. `Anonymous ID` → `GoTo Webinar (Email)`
   5. マッピングに問題がなければ、「Continue」をクリックします。
5. この設定をテストするオプションが表示されます。

![コホート更新の設定をテストするオプション](/images/partner_7899999901716.png)

6. 「Test & continue」をクリックしてこの設定をテストします。
7. API 呼び出しが成功すると、「success」が返されます。

![コホート更新の API 呼び出し成功レスポンス](/images/partner_7900012847764.png)

MoEngage ダッシュボードでも確認できます。MoEngage ダッシュボード > Segment > Create segment に移動します。「Custom Segment」でユーザーをフィルタリングすると、新しく作成したコホートが表示されます。これにより、Zap が成功したことを確認できます。

![MoEngage の Custom Segment で新しいコホートを確認](/images/partner_7900058612756.png)

8. すべてが正常に動作することを確認したら、「Publish Zap」をクリックします。これにより、ウェビナーに新しい登録者が追加されるたびに Zap が実行されます。

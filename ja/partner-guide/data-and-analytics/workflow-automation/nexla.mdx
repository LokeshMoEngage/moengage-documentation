# はじめに

[Nexla](https://www.nexla.com/) は、データプロダクトを中心に構築されたエンタープライズ向けデータ統合プラットフォームです。分析や AI のユーザーが、すぐに使えるデータを簡単かつ迅速に入手できます。

# MoEngage × Nexla

MoEngage と Nexla の連携により、Data Warehouses Exports を活用して、キャンペーンインタラクションデータを Snowflake、BigQuery、Amazon S3 などの送信先にシームレスに送信できます。その後、Nexla がこのデータを効率的に抽出、変換、ロードするため、目的の送信先に簡単に転送して、容易にアクセスし活用できます。この連携では、次のことができます。

- Data Warehouses Exports を使用して、キャンペーンインタラクションイベントを Nexla に転送する
- Snowflake/S3/SFTP Imports を使用して、変換されたデータを Nexla から MoEngage に転送する

# 連携

<Info>
  - この連携には Nexla アカウントが必要です。
  - アカウントで [Data Warehouses Exports](https://www.moengage.com/docs/user-guide/data/imports/data-warehouses-imports/bigquery-imports) を有効にする必要があります。
</Info>

## Nexla で MoEngage をソースとして使用する

### ステップ 1: データウェアハウスにデータを送信する

まだ有効になっていない場合は、アカウントマネージャーに相談して、アカウントで Data Warehouses Exports を有効にしてください。Nexla は現在、MoEngage がキャンペーンインタラクションデータをネイティブにエクスポートできる次のソースをサポートしています。

1. [Snowflake Imports](https://www.moengage.com/docs/user-guide/data/imports/data-warehouses-imports/snowflake-imports)
2. [Amazon S3 Imports](https://www.moengage.com/docs/user-guide/data/imports/file-based-imports/s3-imports)
3. [SFTP Imports](https://www.moengage.com/docs/user-guide/data/imports/file-based-imports/sftp-imports)

アカウントで Automated Exports を設定すると、データウェアハウスにデータが表示されるようになります。

### ステップ 2: Nexla にソースを追加する

Nexla で MoEngage をソースとして使用するには、Snowflake/BigQuery/S3 アカウントを Nexla に接続する必要があります。[Data Source の追加方法](https://docs.nexla.com/user-guides/data-sources/add-data-source)については、Nexla のドキュメントを参照してください。

Nexla に追加のデータを送信する場合は、Connector Campaigns を使用して Nexla に Webhook リクエストを送信することもできます。コネクターキャンペーンを設定するには、[このガイド](https://www.moengage.com/docs/user-guide/campaigns-and-channels/connectors/create/create-a-connector-campaign)と Nexla の [Webhook リファレンス](https://docs.nexla.com/user-guides/connectors/webhook/overview)ドキュメントを参照してください。

## Nexla から MoEngage にデータを送信する

### ステップ 1: データウェアハウスにデータを送信する

Nexla で新しい Data Flow を作成し、サポートされているデータウェアハウスのいずれかを Nexla の Destinations として選択します。[Nexset の送信方法](https://docs.nexla.com/user-guides/data-flows/how-to-send-a-nexset)については、Nexla のドキュメントを参照してください。

Nexla の [REST API](https://docs.nexla.com/user-guides/connectors/rest_api/setup) 送信先を使用して、MoEngage の [Data APIs](https://www.moengage.com/docs/api/data/data-overview) でユーザーとイベントを直接転送することもできます。

### ステップ 2: MoEngage にデータをインポートする

現在、次のデータ送信先を使用して MoEngage にデータをインポートできます。

1. [Snowflake Imports](https://www.moengage.com/docs/user-guide/data/imports/data-warehouses-imports/snowflake-imports)
2. [Amazon S3 Imports](https://www.moengage.com/docs/user-guide/data/imports/file-based-imports/s3-imports)
3. [SFTP Imports](https://www.moengage.com/docs/user-guide/data/imports/file-based-imports/sftp-imports)

## データを変換する

パーソナライズされたデータ[変換](https://docs.nexla.com/user-guides/transformations/designer-overview)を適用したり、Nexla の構築済みコネクターを活用したりする場合は、データセットに関連付けられた **Transform** ボタンをクリックするだけです。Transform Builder にアクセスでき、カスタム変換を簡単に実行できます。Transform Builder の詳しい使用方法については、Nexla が提供する包括的なドキュメントを参照してください。

## 連携を使用する

フローを設定すると、Nexla がソースデータの変更に対応し、新しいデータに合わせてスケールし、スキーマの変更やエラーを通知します。変換、ソース、または送信先を変更するには、オプションを更新するだけで、Nexla がフローを即座に更新します。

## はじめに

[Amazon Redshift](https://aws.amazon.com/redshift/) は、高速かつ強力なフルマネージド型のペタバイト規模のデータウェアハウスサービスで、クラウドコンピューティングプラットフォームである Amazon Web Services の一部です。

## MoEngage × Redshift

MoEngage と Redshift の連携により、キャンペーンインタラクションイベントのデータを Amazon Redshift クラスターに直接エクスポートできます。

## 連携

<Info>
  - Redshift クラスター、ロール、ポリシーを作成・編集する権限を持つ Amazon Web Services アカウントがあることを確認してください。
  - 任意：新しいユーザーを作成するには、Redshift クラスターで新しいユーザーを作成するアクセス権が必要です。
  - MoEngage から Amazon Redshift へのデータのエクスポートには、有料アドオンである MoEngage Streams を使用します。ご利用のプランで利用可能な機能を確認するには、[Plans and Pricing](https://www.moengage.com/plans-and-pricing/) を参照してください。アカウントで有効にするには、MoEngage のカスタマーサクセスマネージャー（CSM）またはサポートチームにお問い合わせください。
</Info>

### ステップ 1：Redshift クラスターがパブリックにアクセス可能であることを確認する

Redshift クラスターで "Publicly Accessible" 設定がオンになっていることを確認してください。

- 新しい Redshift クラスターを作成する場合は、"Network and Security" セクションで "Turn on Publicly accessible" オプションを選択します。 <img src="/images/partner_12060228001300.png" alt="Create-Public.png" />
- すでに Redshift クラスターがある場合は、Properties タブで Network and Security セクションを探します。"Edit" ボタンをクリックします。 <img src="/images/partner_12060217490964.png" alt="Edit-Properties.png" />

プロパティで Publicly accessible をオンにして保存します <img src="/images/partner_12060233602452.png" alt="Edit-Public.png" />

### ステップ 2：MoEngage 用の新しいデータベースユーザーを作成する

MoEngage は、お客様が提供した認証情報を使用して Redshift クラスターに接続します。MoEngage 専用に、権限を制限した新しいユーザーを作成することをおすすめします。既存のユーザーの認証情報を提供することもできます。新しい専用ユーザーを作成するには、Redshift クラスターで以下のコマンドを実行します。

<CodeGroup>

```sql SQL
-- create a new user with a strong password
CREATE USER <username> PASSWORD <password>;
-- create a new schema where MoEngage will dump data
-- you can skip this if you want to use existing schema
CREATE SCHEMA IF NOT EXISTS <schema_name>;
-- grant create access on the above schema or existing schema
GRANT CREATE, USAGE ON SCHEMA <schema_name> TO <username>;
```

</CodeGroup>

既存のスキーマを使用することもできます。MoEngage は、App Marketplace で接続を設定する際に指定したスキーマにテーブルを作成します。

### ステップ 3：MoEngage の IP がクラスターにアクセスできるようにする

新しいセキュリティグループを作成するか、既存のセキュリティグループを編集できます。

#### 新しいセキュリティグループを作成する

EC2 コンソールの "Network & Security" で、Security Groups ページを開きます。"Create security group" ボタンをクリックします。

1. セキュリティグループに名前と、任意で説明を付けます。
2. VPC を選択します（デフォルトでは選択済みです）。
3. 以下の詳細で新しいインバウンドルールを追加します。

| **プロパティ** | **値** |
| --- | --- |
| Type | Redshift |
| Protocol | TCP |
| Port range | 5439 |
| Source | ドロップダウンから **Custom** を選択します。CIDR ブロックには、MoEngage ダッシュボードのデータセンターに応じて、対応する CIDR を入力する必要があります。以下の表を参照してください。 |
| Description | 任意で説明を入力します。 |

"source" フィールドに入力する正しい IP アドレスは、MoEngage のデータセンターのリージョンによって異なります。

| **データセンターのリージョン** | **CIDR ブロック** |
| --- | --- |
| DC-01 | 52.1.205.204/32 |
| DC-02 | 18.195.110.23/32 |
| DC-03 | 3.6.251.95/32 |
| DC-04 | 10.22.3.193/32 |

追加する必要があるインバウンドルールは 1 つだけです。たとえば、MoEngage の DC-01 サーバーを使用している場合は、最初の CIDR ブロックのみを追加します。

![securitygroup.png](/images/partner_12060649054356.png)

4. アウトバウンドルールは空のままにします。
5. 完了したら "Create security group" をクリックします。

#### 既存のセキュリティグループを編集する

EC2 コンソールの "Network & Security" で、Security Groups ページを開きます。セキュリティグループの一覧から、編集するものを開きます。

1. セキュリティグループのページで "Actions" ボタンをクリックし、"Edit inbound rules" を選択します。
2. 上記の表に従って、新しいインバウンドルールを追加します。
3. 完了したら "Save rules" をクリックします。

#### セキュリティグループを Redshift クラスターにアタッチする

1. Redshift コンソールで、Redshift クラスターを開きます。Properties タブに移動します。
2. "Network & Security settings" セクションで、"Edit" ボタンをクリックします。
3. VPC security groups で、作成または編集したセキュリティグループを選択します。
4. 完了したら "Save changes" をクリックします。

### ステップ 4：新しい IAM ポリシーを作成する

MoEngage が S3 から Redshift クラスターにデータを転送できるようにする、新しい IAM ポリシーを作成する必要があります。

![createpolicy.png](/images/partner_12061425942420.png)

1. IAM コンソールの Access Management で、Policies に移動します。"Create policy" ボタンをクリックします。
2. Create Policy ページで JSON タブに切り替え、以下のポリシーを貼り付けます。
   <CodeGroup>
   ```text JSON
   {
       "Version": "2012-10-17",
       "Statement": [
           {
               "Sid": "VisualEditor1",
               "Effect": "Allow",
               "Action": [
                   "s3:Get*",
                   "s3:List*"
               ],
               "Resource": [ "<bucket-arn>",
                             "<bucket-arn>/*"]
           }
       ]
   }
   ```
   </CodeGroup>

`<bucket-arn>` の値は、MoEngage のデータセンターのリージョンによって異なります。

| データセンターのリージョン | `<bucket-arn>` | Resource 配列 |
| --- | --- | --- |
| DC-01 | `arn:aws:s3:::moe-warehouse-exports-us-east-1` | `"Resource": ["arn:aws:s3:::moe-warehouse-exports-us-east-1", "arn:aws:s3:::moe-warehouse-exports-us-east-1/*"]` |
| DC-02 | `arn:aws:s3:::moe-warehouse-exports-eu-central-1` | `"Resource": ["arn:aws:s3:::moe-warehouse-exports-eu-central-1", "arn:aws:s3:::moe-warehouse-exports-eu-central-1/*"]` |
| DC-03 | `arn:aws:s3:::moe-warehouse-exports-ap-south-1` | `"Resource": ["arn:aws:s3:::moe-warehouse-exports-ap-south-1", "arn:aws:s3:::moe-warehouse-exports-ap-south-1/*"]` |
| DC-04 | `arn:aws:s3:::moe-warehouse-exports-us-east-2` | `"Resource": ["arn:aws:s3:::moe-warehouse-exports-us-east-2", "arn:aws:s3:::moe-warehouse-exports-us-east-2/*"]` |

`<bucket-arn>` を、お使いの MoEngage データセンターのリージョンに対応するものに置き換えるだけです。

<img src="/images/partner_12061504085652.png" alt="jsonpolicy.png" /> "Next" をクリックし、任意でタグを追加します。次に "Next: Review" をクリックします。

3. ポリシーに名前と、任意で説明を付けます。準備ができたら "Create policy" をクリックします。<img src="/images/partner_12061562388628.png" alt="reviewpolicy.png" />

### ステップ 5：新しい Redshift IAM ロールを作成する

このロールにより、MoEngage のサーバーが Redshift クラスターにデータを書き込めるようになります。

1. IAM コンソールの Access Management で、Roles に移動します。"Create role" ボタンをクリックします。
2. Trusted entity type として "AWS service" を選択します。Use Case で、"Use cases for other AWS services" から "**Redshift** " を選択します。Redshift のユースケースの種類で、"**Redshift - Customizable** " を選択します。準備ができたら "Next" をクリックします。 <img src="/images/partner_12061766229268.png" alt="newrole.png" />
3. 次のステップで、ステップ 4 で作成したポリシーを選択します。完了したら Next をクリックします。 <img src="/images/partner_12092468888084.png" alt="selectpolicy.png" />
4. ロールに名前を付け、先ほど作成した正しいポリシーがアタッチされているかを確認します。準備ができたら Create Role をクリックします。 <img src="/images/partner_12061832176276.png" alt="createrolefinal.png" />

### ステップ 6：このロールを Redshift クラスターにアタッチする

Redshift コンソールで、Redshift クラスターを開きます。

1. Properties タブで、"Associated IAM roles" セクションに移動します。
2. "Manage IAM roles" ボタンをクリックし、"Associate IAM roles" オプションを選択します。
3. ポップアップのモーダルから、[ステップ 5](#step-5-create-a-new-redshift-iam-role) で作成したロールを選択します。

![attachrole.png](/images/partner_12062024553236.png)

4. "Associate IAM roles" をクリックして、このロールを Redshift クラスターにアタッチします。

### MoEngage から Redshift へのイベントのエクスポート

MoEngage から Redshift クラスターにイベントをエクスポートできます。エクスポートを設定するには、[Redshift エクスポートガイド](/ja/user-guide/data/exports/events/data-warehouse/redshift-exports)を参照してください。

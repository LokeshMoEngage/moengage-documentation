# はじめに

[Chargebee](https://www.chargebee.com/) は、サブスクリプションビジネス向けの業界をリードする Revenue Growth Management (RGM) プラットフォームです。Chargebee は、サブスクリプション管理と定期請求、価格設定と支払いの最適化、収益認識、回収、顧客維持など、包括的なソリューションスイートを提供することで、あらゆる規模の企業の収益拡大を支援することを目指しています。

# MoEngage × Chargebee

Chargebee と MoEngage の連携により、顧客の購入イベントとサブスクリプションイベントをシームレスに同期できます。この連携により、顧客情報の更新、サブスクリプションの変更、支払いの変更などの Chargebee イベントを MoEngage に送信し、Chargebee のデータに基づいてターゲットを絞った高度にパーソナライズされたキャンペーンを実施できます。   
  
ユースケースの例: 

**サブスクリプション更新リマインダーの自動化:** サブスクリプションの更新が近づいている顧客に、プッシュ通知、メール、SMS などのさまざまなチャネルを通じてパーソナライズされたリマインダーを送信できます。これにより、解約を減らし、更新率を高めることができます。

**ターゲットを絞ったアップセルキャンペーン:** 顧客のサブスクリプションデータに基づいて、追加の製品やサービスをアップセルするためのターゲットキャンペーンを作成できます。たとえば、顧客がベーシックプランを利用している場合、プレミアムプランへのアップグレードを促すパーソナライズされたオファーを送信できます。

**カゴ落ちリカバリー:** 顧客がサブスクリプションをカートに追加したものの購入を完了しなかった場合、特別オファーやリマインダーを含むフォローアップメッセージを送信して、取引の完了を促すことができます。

**パーソナライズされたオンボーディング:** Chargebee のデータを使用して新規サブスクライバーにパーソナライズされたオンボーディングメッセージを送信し、最初からエンゲージメントと維持を図ることができます。

**呼び戻しキャンペーン:** サブスクリプションを解約した顧客に対して、特別オファーやインセンティブを含むターゲットを絞った呼び戻しキャンペーンを送信し、再登録を促すことができます。

**支払い失敗の通知:** 支払いが失敗したときに顧客に即座に通知を送信し、支払い情報を更新してサービスの中断を回避するよう促すことができます。

**ロイヤルティプログラム:** Chargebee のサブスクリプションデータを使用して顧客をロイヤルティプログラムに登録し、ポイント残高、利用可能な特典、特別プロモーションに関するターゲットメッセージを送信できます。

<Info>
* Chargebee の Webhook へのアクセス権があることを確認してください。
* この連携は、Chargebee と MoEngage の間の共通識別子として customer_id を使用して動作します。
</Info>

## ステップ 1: MoEngage のエンドポイントを取得する 

Chargebee 連携用の専用エンドポイントを取得するには、MoEngage のカスタマーサクセスマネージャーにお問い合わせください。

## ステップ 2: Chargebee の Webhook を設定する 

Webhook の設定方法の詳細については、[Chargebee のガイド](https://www.chargebee.com/docs/2.0/webhook_settings.html)を参照してください。

  1. _Settings > Configure Chargebee > API Keys and Webhooks_ に移動します。
  2. Webhooks タブに切り替えます。
  3. Add Webhook をクリックします。 
     * **Webhook Name:** Webhook Name は、Chargebee で Webhook を参照する際に使用される名前です。MoEngage events など、任意の Webhook 名を追加します。
     * **Webhook URL:** Webhook の送信先となるエンドポイントを表します。ステップ 1 で取得したエンドポイントと同じです。 
     * **Basic Authentication:** トグルをオンにして、次の詳細を入力します。 
       * User Name: `<MoEngage workspace ID>`
       * Password: `<MoEngage Data API key>`  
`<MoEngage Workspace ID>` と `<MoEngage Data API Key>` は、MoEngage Dashboard >> Settings >> APIs から取得できます。
     * **API Version:** V2 を選択します
     * **Events:** MoEngage に送信する Chargebee イベントを選択します。MoEngage は、顧客情報の更新とサブスクリプションに関連するすべてのイベントをサポートしています。



Test Webhook オプションを使用して、Webhook エンドポイントをテストすることもできます。 

## ステップ 3: MoEngage でターゲットを絞ったキャンペーンを送信する

ユーザーとイベントが MoEngage に表示され始めます。

これで、ユーザーに対してイベントトリガー型キャンペーンを実施できます。

# はじめに

[Purchasely](https://www.purchasely.com/) は、アプリ内サブスクリプションを最大化するための直感的なノーコード Paywall Builder です。これまでにない方法で、ネイティブのペイウォールや A/B テストを構築および実行できるよう顧客を支援します。Purchasely は、ワークフローの自動化や予測インサイトとともに大量メッセージングサービスを提供する、プラットフォームベースのデジタルエンゲージメントおよびコミュニケーションサービス企業です。 

# 連携 

MoEngage × Purchasely 連携により、利用可能なすべての Purchasely イベントを MoEngage に取り込み、サブスクリプションビジネスと顧客行動をより深く理解できます。Purchasely は、すべてのストアのサブスクリプションイベントをトラッキングするための統合データセットを提供します。これらのイベントは Purchasely のバックエンドで生成され、MoEngage に送信できます。

<Info>
* Purchasely アカウントへのアクセス権があることを確認してください。
* この連携をサポートする Purchasely SDK の最小バージョンは 3.6.0 です。 
* MoEngage SDK もアプリに組み込まれている必要があります。
</Info>

Purchasely で生成されたサブスクリプションイベントは、サーバー間連携を使用して MoEngage に送信されます。その結果、MoEngage ダッシュボードですべてのサブスクリプションイベントを確認し、獲得キャンペーンとマッピングできるようになります。

イベントの完全なリストは[こちら](https://docs.purchasely.com/analytics/events/webhook-events/subscription-events)をご覧ください。

# 連携手順 

Purchasely と MoEngage の連携を設定するには、次の手順に従います。 

## 1. ユーザーをイベントに関連付ける 

Purchasely SDK に `${integration_sdk_property}` を指定して、ユーザーをイベントに関連付けます。詳細については、[こちらのドキュメント](https://developers.moengage.com)を参照してください。

## 2. 連携を有効にする

  1. "External integrations" セクションに移動し、MoEngage の編集フォームを開きます。
  
  ![](https://561853519-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FGgUdOzhqa07uh7nB2iZA%2Fuploads%2Fgit-blob-682bb27f47d70dec5567618258797c2aeb9c600b%2FScreenshot%202023-05-25%20at%2016.12.48.png?alt=media)
  
  2. 連携を有効にします
  3. MoEngage アプリの詳細を設定します。  
  MoEngage ダッシュボードで、Workspace ID (旧 App ID)、DATA API ID、DATA API KEY の値をコピーします。  

| フィールド | 説明 |
| --- | --- |
| App ID | MoEngage アカウントの Workspace ID は、**Settings -> Account -> APIs -> Workspace ID** で確認できます。 |
| Data API ID | MoEngage アカウントの Data API ID と Workspace ID は同じです。 |
| Data API Key | MoEngage アカウントの Data API キーは、**Settings -> Account -> APIs -> API keys -> Data** API 設定で確認できます。<br /><br />![](https://561853519-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FGgUdOzhqa07uh7nB2iZA%2Fuploads%2Fgit-blob-345d251c482e05171355c1a019312d33b42266ab%2FScreenshot%202023-05-25%20at%2016.13.10.png?alt=media) |

  4. MoEngage に送信するイベントを有効にします。   
  *注 [任意] - MoEngage に送信されるイベントの名前を上書きできます*
  
  ![](https://561853519-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FGgUdOzhqa07uh7nB2iZA%2Fuploads%2Fgit-blob-4cdf96b4dfe249b64111e70389e35ae01d2e7d21%2FScreenshot%202023-05-25%20at%2016.13.32.png?alt=media)
  
  5. MoEngage に送信するユーザープロパティを有効にします。  
  *注 [任意] - MoEngage に送信されるユーザープロパティの名前を上書きできます*
  
  ![](https://561853519-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FGgUdOzhqa07uh7nB2iZA%2Fuploads%2Fgit-blob-4a8f73fa1aa15bb1dbcad7929c061f964026c6e0%2FScreenshot%202023-05-25%20at%2016.15.18.png?alt=media)
  
  6. _Save_ をクリックします



## 3. 連携をテストする

連携をテストするには、サンドボックス環境 (例: App Store の TestFlight) で一連のアプリ内購入を実行し、イベントが MoEngage ダッシュボードで受信されていることを確認します。

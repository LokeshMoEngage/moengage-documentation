# はじめに

[Pipedrive](https://www.pipedrive.com/) は、企業が営業活動を計画し、商談を監視できる Web ベースのセールス CRM およびパイプライン管理ソリューションです。アクティビティベースのセリング手法に基づいて構築された Pipedrive は、潜在的な商談を成約へと導くためのあらゆるアクションを効率化します。

# MoEngage × Pipedrive

MoEngage と Pipedrive の統合により、Pipedrive と MoEngage の間でデータを簡単に移動できるようになり、マーケティングと営業の取り組みを連携させることができます。たとえば、Pipedrive の Leads を MoEngage の新しいユーザーとしてインポートしたり、Pipedrive 内の Deal Stages に基づいて MoEngage で新しいコホート（セグメント）を作成したりできます。この統合は Zapier を活用して実現しています。この統合により、次のことができます。

A. MoEngage で Pipedrive の連絡先を作成または更新する\
B. MoEngage のカスタムセグメントに Pipedrive の連絡先/人物を追加または削除する

## ユースケース

1. Pipedrive の新しい連絡先を MoEngage に自動的にインポートする。
2. Pipedrive の Person が更新されたときに、MoEngage でも更新する。
3. Person が Pipedrive のフィルターに一致したときに、MoEngage のコホートに追加する。

# 統合

<Info>
  - Pipedrive アカウントがあることを確認してください。
  - この統合を使用するには、Zapier アカウントが必要です。[こちら](/ja/partner-guide/data-and-analytics/workflow-automation/zapier/overview)に記載されている手順に従って、Zapier アカウントと MoEngage アカウントを接続してください。
</Info>

## A. Pipedrive の Leads を MoEngage にインポートする

_注: このワークフローでは、[Create or Update User](/ja/partner-guide/data-and-analytics/workflow-automation/zapier/create-or-update-users) アクションを使用します。_

### ステップ 1: トリガーアプリとして Pipedrive を選択する

![User-Step1.png](/images/partner_9705455097364.png)

1. アプリの一覧から Pipedrive を選択します。
2. "Event" として "New Lead" を選択します。Continue をクリックします。
3. Pipedrive アカウントを接続します。ドロップダウンから Pipedrive アカウントを選択し、Continue をクリックします。
4. "Test trigger" をクリックすると、Zapier が最近の Lead の取得を試みます。Continue をクリックして次のステップに進みます。

![User-Step2.png](/images/partner_9705931096852.png)

### ステップ 2: アクションアプリとして MoEngage を選択する

アプリから "MoEngage" を検索して選択します。

![Import-Step4.png](/images/partner_24724451810324.png)

1. イベントのドロップダウンから "Create or Update User" を選択します。Continue をクリックします。
2. 前提条件に従っていれば、MoEngage アカウントがすでに一覧に表示されているはずです。そのアカウントを選択するか、新しいアカウントを接続できます。完了したら Continue をクリックします。
3. 次のステップ "Set up action" では、入力するか前のステップからマッピングする属性とユーザープロパティの一覧が表示されます。[詳細についてはこちらをクリックしてください](https://moengage-partner-guide.mintlify.app/api/user/track-user)。要件に応じて、関連するカスタムユーザー属性を追加できます。
4. このセットアップでは、次のようにリンクしています。
   1. `Customer ID` -\> `1. Person ID`
   2. `Full Name` -\> `1. Person Name`
   3. `First Name` -\> `1. Person First Name`
   4. `Last Name` -\> `1. Person Last Name`
   5. `Email` -\> `1. Person Email Value`
   6. `Source` -\> "Pipedrive"
   7. `Other Attributes` -\> `pipedrive_lead_value` -\> `1. Value Amount`
   8. `Other Attributes` -\> `pipedrive_org_name` -\> `1. Organization Name`

以下の画像では、マッピングされたフィールドのみを示しています。

![User-Step3-1.png](/images/partner_9706614707092.png)

![User-Step3-2.png](/images/partner_9706614118804.png)

![User-Step3-3.png](/images/partner_9706652176660.png)

5. マッピングに問題がなければ、"Continue" をクリックします。
6. 最後のステップで "Test & continue" をクリックします。
7. API 呼び出しが成功すると、"success" が返されます。

MoEngage ダッシュボードでも確認できます。Pipedrive ユーザーのプロファイルに移動し、カスタム属性を確認します。

![User-Step4.png](/images/partner_9706772908820.png)

これで、関連するユーザー属性を持つユーザーを絞り込んでキャンペーンを送信できます。

## B. MoEngage のカスタムセグメントに Leads を追加する

注: このワークフローでは、[Add or Remove User from Cohort (Audience)](/ja/partner-guide/data-and-analytics/workflow-automation/zapier/update-cohorts-audience) アクションを使用します。

このユースケースでは、Deal Stage "Contact Made"（パイプラインステージ）にある新しいリードを MoEngage 内のカスタムセグメントに自動的に追加する Zap を設定し、後でキャンペーンを使用してリマインダーメールを送信できるようにします。

### ステップ 1: トリガーアプリとして Pipedrive を選択する

![User-Step1.png](/images/partner_9705455097364.png)

1. アプリの一覧から Pipedrive を選択します。
2. "Event" として "Updated Deal Stage" を選択します。Continue をクリックします。
3. Pipedrive アカウントを接続します。ドロップダウンから Pipedrive アカウントを選択し、Continue をクリックします。
4. Stage in Pipeline として "Contact Made (Pipeline)" を選択します。Continue をクリックします。
5. "Test trigger" をクリックすると、Zapier が最近の Deal の取得を試みます。Continue をクリックして次のステップに進みます。

![Cohort-Step1.png](/images/partner_9709120693396.png)

### ステップ 2: アクションアプリとして MoEngage を選択する

アプリから "MoEngage" を検索して選択します。

![Import-Step4.png](/images/partner_24724451810324.png)

1. イベントのドロップダウンから "Add or Remove User From Cohort (Audience)" を選択します。Continue をクリックします。
2. 前提条件に従っていれば、MoEngage アカウントがすでに一覧に表示されているはずです。そのアカウントを選択するか、新しいアカウントを接続できます。完了したら Continue をクリックします。
3. 次のステップ "Set up action" では、入力するか前のステップからマッピングするフォームが表示されます。[詳細についてはこちらをクリックしてください](https://moengage-partner-guide.mintlify.app/api/cohort-sync/sync-cohort-members)。
4. ユーザーを追加するか削除するかを選択します。すべての必須フィールドに入力すると、このセットアップをテストするオプションが表示されます。"User ID" または "Anonymous ID" の少なくとも一方を必ず入力してください。詳細については、[Cohort API ドキュメント](https://moengage-partner-guide.mintlify.app/api/cohort-sync/sync-cohort-members)をお読みください。
5. このセットアップでは、次のようにリンクしています。
   1. `Cohort Name` -\> "pipedrive-pipeline-stage-`1. Stage Name`"
   2. `Cohort ID` -\> "pipedrive-pipeline-stage-`1. Stage Name`"
   3. `Cohort Description` -\> "All Pipedrive Leads that are in `1. Stage Name` Pipeline Stage."
   4. `User ID` -\> `1. Person ID Email`
   5. `Anonymous ID` -\> `1. Person ID Email`

![Cohort-Step2.png](/images/partner_9709377708820.png)

6. マッピングに問題がなければ、Continue をクリックします。
7. このセットアップをテストするオプションが表示されます。

![Cohort-Step3.png](/images/partner_9709546939284.png)

8. "Test & continue" をクリックして、このセットアップをテストします。
9. API 呼び出しが成功すると、"success" が返されます。

MoEngage ダッシュボードでも確認できます。MoEngage ダッシュボード \>\> Segment \>\> Create segment に移動します。"Custom Segment" でユーザーを絞り込むと、新しく作成したコホートがここに表示されます。

![Cohort-Step4.png](/images/partner_9709590529812.png)

これで、Zap が成功したことを確認できます。

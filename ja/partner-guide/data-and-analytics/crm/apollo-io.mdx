# はじめに

[Apollo.io](https://www.apollo.io/) は、営業チームやマーケティングチームが見込み顧客を見つけ、連絡し、エンゲージするために使用するセールスインテリジェンスおよびエンゲージメントプラットフォームです。包括的な B2B データベース、メールの自動化、分析機能を提供しています。

## MoEngage × Apollo.io

[Zapier](https://zapier.com/) を介した MoEngage と Apollo.io の統合により、シームレスなデータ同期を通じてリードナーチャリングのプロセスを自動化できます。

この統合により、次のことができます。

- Apollo.io から MoEngage にユーザーデータとアカウントデータを自動的に送信する。
- 新しい見込み顧客を MoEngage のパーソナライズされたマーケティングキャンペーンに即座に登録する。
- Apollo.io からのリアルタイムの更新により、MoEngage の既存のユーザープロファイルを充実させる。
- 主要なプロスペクティング活動やプロファイルの更新に基づいて、コンテキストに応じたキャンペーンをトリガーする。

## ユースケース

Zapier を使用して Apollo.io を MoEngage と統合すると、次の主要なユースケースに対応できます。

- **自動化されたウェルカムジャーニーとオンボーディングジャーニー**: Apollo.io で "New contact" が保存されると、そのユーザーが MoEngage で自動的に作成または更新されます。これにより、価値の高い見込み顧客をパーソナライズされたウェルカムメールシリーズや自動化されたオンボーディングジャーニーに即座に登録できます。
- **ターゲットを絞ったオーディエンスのセグメンテーションとパーソナライゼーション**: 新しい Apollo.io アカウントの詳細な企業属性データや人口統計データ（"Industry"、"Company Size"、"Job Title" など）を MoEngage に同期します。このデータを使用して正確なセグメント（例: "フィンテック業界の VP"）を作成し、特定のウェビナーへの招待など、高度にターゲットを絞ったキャンペーンを送信できます。
- **リアルタイムのプロファイル拡充**: Apollo.io で "Contact updated" トリガーが実行されると（例: 見込み顧客の役職が変わった場合）、MoEngage の対応するユーザー属性が即座に更新されます。これにより、マーケティングキャンペーンで常に最新のデータを使用して正確なパーソナライゼーションとセグメンテーションを行うことができ、より効果的なアプローチが可能になります。

## 主な機能

この統合では、Zapier を使用して Apollo.io のトリガーを MoEngage に接続し、主にユーザープロファイルの作成と更新を行います。次の表は、統合の主な範囲を説明しています。

| トリガー | 説明 |
| --- | --- |
| New account | Apollo で[新しいアカウントを保存](https://knowledge.apollo.io/hc/en-us/articles/4413032484493-Save-Contacts-and-Accounts)したときにトリガーされます。 |
| Account updated | Apollo で[既存のアカウントを更新](https://knowledge.apollo.io/hc/en-us/articles/5995865049229-View-and-Edit-Account-Profiles)したときにトリガーされます。 |
| New contact | Apollo で[新しい連絡先を保存](https://knowledge.apollo.io/hc/en-us/articles/4413032484493-Save-Contacts-and-Accounts)したときにトリガーされます。 |
| Contact updated | Apollo で[既存の連絡先を更新](https://knowledge.apollo.io/hc/en-us/articles/5995459280525-View-and-Edit-Contact-Profiles)したときにトリガーされます。 |

![](/images/partner_42949566292756.png)

<Info>
  連絡先データまたはアカウントデータを MoEngage に送信する Zap を設定するには、次のものが揃っていることを確認してください。

  - Apollo.io アカウントの統合設定へのアクセス権。
  - Apollo.io と MoEngage の間でユーザープロファイルを紐付けるための共通の識別子（メールアドレスや外部 ID など）。
</Info>

## ステップ 1: Apollo.io を Zapier に接続する

Apollo.io を Zapier に接続するには、次の手順を実行します。

1. **Apollo.io** UI にログインします。
2. 左側のナビゲーションメニューで最後までスクロールし、**Admin** **Settings** をクリックします。
3. **Admin Settings** の展開メニューから **Integrations** をクリックします。<img src="/images/partner_42949537042452.png" />\
   Integrations ページが表示されます。
4. **Search integrations** ボックスで API を検索します。\
   [**API keys**](https://developer.apollo.io/keys/) ページが表示されます。
5. <img src="/images/partner_42949566294036.png" /> **Create new key** をクリックします。<img src="/images/partner_42949537043220.png" />\
   [**Create new API key**](https://docs.apollo.io/docs/create-api-key) ダイアログボックスが表示されます。
6. **Name** の下にある **Name** ボックスに、キーの名前を入力します。
7. **Description** ボックスに、キーの説明を入力します。
8. **APIs** で、検索ボックスを使用するか、**Select an API to associate this key with** リストからこのキーに関連付ける API をクリックします。
9. **Create API key** をクリックします。<img src="/images/partner_42949537043604.png" />\
   これで API キーが正常に作成されました。
10. **Copy the API key** ダイアログボックスで、API キーの横にある <img src="/images/partner_42949566295060.png" />コピーアイコンをクリックします。
11. **Done** をクリックします。<img src="/images/partner_42949566295572.png" />
12. 次に、[Zapier](https://zapier.com/app/login) UI にログインします。
13. 左側のナビゲーションメニューで **App Connections** をクリックします。\
    App Connection ページが表示されます。
14. 右上隅にある **\+ Add connection** をクリックします。\\
    ![](/images/partner_42949566295956.png)
15. **Search for an app** リストで **Apollo** を検索してクリックします。\\
    ![](/images/partner_42949537045780.png)
16. **Add connection** をクリックします。\
    **Allow Zapier to access your Apollo Account?** ウィンドウが表示されます。
17. **API Key Obtained From Apollo (required)** に、ステップ 3 でコピーした Apollo の API キーを貼り付けます。
18. **Name (required)** ボックスに、この Apollo アカウントを識別しやすい名前を入力します。
19. **Yes, Continue to Apollo** をクリックします。\
    <img src="/images/partner_42949566297620.png" />\
    これで Zapier が Apollo に接続されました。この統合を使用して [Zap を作成](https://knowledge.apollo.io/hc/en-us/articles/4415362778509-Integrate-Zapier-with-Apollo#create)できるようになりました。

## ステップ 2: 統合を使用する（Zap を作成する）

Zapier は Zap を使用してアプリやサービスを接続します。各 Zap には、1 つのトリガーと少なくとも 1 つのアクションが含まれます。[Zap を作成](https://knowledge.apollo.io/hc/en-us/articles/4415362778509-Integrate-Zapier-with-Apollo#create)してトリガーが発生すると、Zapier が自動的にアクションを実行します。別のアプリのトリガーに基づいて Apollo でアクションを実行する Zap や、Apollo のトリガーに基づいて別のアプリでアクションを実行する Zap を作成できます。

別のアプリでアクションを実行する Zap を作成するには、次の手順を実行します。

1. [Zapier](https://zapier.com/app/login) ダッシュボードにログインします。
2. 左側のナビゲーションメニューで **\+ Create** をクリックします。
3. 表示されたメニューで **Zaps** をクリックします。\
   <img src="/images/partner_42949537047572.png" />\
   次に、トリガーを設定します。
4. **Trigger** をクリックし、アプリとして Apollo を選択します。\\
   ![](/images/partner_42949566300692.png)
5. サポートされているトリガーのいずれか（例: **New Contact**）を選択し、**Continue** をクリックします。
6. ステップ 1 で接続した **Apollo** アカウントを選択します。
7. **Find Records** をクリックしてトリガーをテストし、サンプルデータを取得します。\\
   ![](/images/partner_42949566302996.png)

次に、アクションを設定します。

8. **Action** をクリックし、MoEngage アプリを検索して選択します。
9. アクションとして **Create or Update User** を選択します。\\
   ![](/images/partner_42949537048724.png)
10. MoEngage UI から取得できる次の認証情報を Zapier に入力します。
    1. **Allow Zapier to access your Apollo Account**\*\*?\*\* ウィンドウの **MoEngage Data Center Region (required)** で、ドロップダウンリストから適切なリージョンをクリックします。
    2. **MoEngage App ID (required)** に、MoEngage からコピーしたワークスペース ID（アプリ ID）を貼り付けます。
    3. **MoEngage Data API Key (required)** に、MoEngage からコピーした Data API Key を貼り付けます。

<Info>
  認証情報を確認するには、次の手順を実行します。

  1. **Workspace ID**（**旧 app id**）の下にある ID をコピーします。
  2. **API keys** の下にある **Data** をコピーします。
  3. データセンター ID は、MoEngage への登録時に割り当てられます。データセンター ID はダッシュボードの URL から確認できます。たとえば、ダッシュボードの URL が [https://dashboard-04.moengage.com/v4/#/auth](https://dashboard-04.moengage.com/v4/#/auth) の場合、データセンターはデータセンター 04 で、データセンター ID は\
     DC-04 です。詳細については、[MoEngage のデータセンター](/ja/user-guide/data/key-concepts/data-centers-in-moengage#list-of-data-centers)を参照してください。
</Info>

11. **Yes, Continue to Apollo** をクリックします。\\
    ![](/images/partner_42949537049748.png)
12. 次に、選択したトリガーに基づいて、Apollo のフィールドと MoEngage のユーザー属性の間のマッピングを作成します。\
    <img src="/images/partner_42949566306452.png" />\
    **Custom Attributes** セクションを使用して、MoEngage のプロファイルに追加の詳細情報を加えます。
    ![](/images/partner_42949566307092.png)
13. **Test step** をクリックします。
    ![](/images/partner_42949537051924.png)
14. **Publish** をクリックします。
    ![](/images/partner_42949566307476.png)

設定後は、Apollo でイベントが発生するたびに、Zap が関連情報とともに MoEngage を自動的にトリガーします。

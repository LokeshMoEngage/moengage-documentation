# はじめに

[Boltic](https://www.boltic.io/) は高度なデータオペレーションおよび自動化プラットフォームであり、その機能の 1 つである Boltic streams により、複数のチャネルにわたって顧客データを定義、トラッキング、最適化することもできます。Boltic streams を MoEngage と連携することで、重要なカスタムイベントと属性のデータをシームレスに転送し、顧客エンゲージメントの取り組みを的確かつ効果的なものにすることができます。すでに Boltic を使用してデータワークフローを管理している場合、Boltic streams - MoEngage 連携により、イベントデータを MoEngage に送信するプロセスが簡素化されます。Boltic streams はデータを MoEngage が理解できる形式に変換してルーティングするため、貴重なエンジニアリングの時間と労力を節約でき、効果的なキャンペーンの作成に集中できます。

# MoEngage × Boltic

Boltic と MoEngage の連携により、ユーザーをトラッキングして MoEngage にデータをルーティングし、顧客エンゲージメント戦略を強化できます。Boltic は以下の機能を提供します。

  * **カスタムイベントの定義:** Boltic streams 内でカスタムイベントを定義して MoEngage にシームレスに転送し、最も関連性の高い顧客インタラクションに基づいてキャンペーンを実施できます。
  * **包括的なイベント分析:** Boltic のイベント分析ダッシュボードを使用して、イベントフローが MoEngage に到達する前にモニタリングおよび最適化し、顧客エンゲージメントの正確性と関連性を確保できます。
  * **シームレスな SDK 連携:** Boltic のリアルタイムデバッガーにより SDK をスムーズに連携でき、有効かつ正しく処理されたイベントのみが MoEngage に送信されるようになります。
  * **柔軟なストリーム制御:** Boltic では、ストリームや個々の宛先を柔軟に一時停止または再開できるため、MoEngage へのデータフローを完全に制御できます。
  * **構築済みコネクターによる迅速なセットアップ:** Boltic の構築済みコネクターにより MoEngage とのセットアップを迅速かつ簡単に行えるため、すぐに顧客データを活用してパーソナライズされたキャンペーンを開始できます。



#  連携

<Info>
**前提条件**

* MoEngage ダッシュボードの Settings >> APIs にアクセスできることを確認してください
</Info>

## ステップ 1: Boltic を MoEngage アカウントに接続する

  1. この MoEngage 宛先を参照するための宛先名を入力します![Screenshot 2024-09-02 at 11.43.51 AM.png](/images/partner_33115695729428.png)
  2. MoEngage ダッシュボードの URL を入力します![Screenshot 2024-09-02 at 11.48.09 AM.png](/images/partner_33115695729812.png)
  3. MoEngage の Data API Key を入力します。これは MoEngage ダッシュボードの Settings >> APIs からアクセスできます
![Screenshot 2024-09-02 at 11.48.37 AM.png](/images/partner_33115695730196.png)
  4. MoEngage の Workspace ID を入力します。これは MoEngage ダッシュボードの Settings >> APIs からアクセスできます
![Screenshot 2024-09-02 at 11.49.57 AM.png](/images/partner_33115664994580.png)
  5. 宛先をテストして保存します。



これで、MoEngage を Boltic の宛先として正常に追加できました。定義したイベントがアカウントに流れ始めます。

## ステップ 2: MoEngage でデータを検証する

Segment >> Search users からユーザーを検索できます。イベントが MoEngage アカウントに流れ始めます。

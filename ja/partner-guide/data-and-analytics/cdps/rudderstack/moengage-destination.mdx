# はじめに

[RudderStack](https://rudderstack.com/) は、顧客のイベントデータを収集し、任意のデータウェアハウスや MoEngage などの多数の分析プロバイダーにルーティングするための、開発者向けのオープンソース顧客データプラットフォームです。エンタープライズ対応であり、イベントデータをその場で処理するための堅牢な変換フレームワークを提供します。

<Note>
  RudderStack 連携は現在、[Unified Identity (Identity Resolution)](https://moengage-user-guide.mintlify.app/user-guide/data/user-data/unified-identity-identity-resolution) および [Portfolio](https://moengage-user-guide.mintlify.app/user-guide/settings/account/portfolio/portfolio) をサポートしていません。
</Note>

# 範囲

MoEngage と RudderStack の連携により、MoEngage でユーザーを追跡できます。この連携では、Android、iOS、Web アプリケーション向けのネイティブ SDK 統合と、バックエンドサービスからのサーバー間連携が提供されます。

# 連携の前提条件

<Info>
  **前提条件**

  RudderStack へのエクスポートには MoEngage Streams を使用します。Streams はアドオンです。アカウントで有効にするには、MoEngage の担当 CSM(カスタマーサクセスマネージャー)にお問い合わせください。
</Info>

- RudderStack アカウントにアクセスできることを確認してください。
  - 設定済みのソース - ソースとは、Web サイト、モバイルアプリ、バックエンドサーバーなど、RudderStack に送信されるデータの発生元です。RudderStack で MoEngage を宛先として設定する前に、ソースを設定する必要があります。
  - Data API ID と Data API Key は MoEngage ダッシュボードで確認できます。Data API ID には **Settings** -\> **Account** -\> **APIs** からアクセスできます。Data API ID は **Workspace ID** と同じです。Data API Key は、同じ画面の **API Keys** -\> **Data** セクションで確認できます。
  - データセンター - データセンターは MoEngage ダッシュボードのインスタンスに対応しています。[詳細はこちら](https://moengage-user-guide.mintlify.app/user-guide/data/key-concepts/data-centers-in-moengage)

# ステップ 1: ソースを追加する

MoEngage へのデータ送信を開始するには、まず RudderStack アプリでソースが設定されていることを確認する必要があります。データソースの設定方法については、[RudderStack](https://www.rudderstack.com/docs/dashboard-guides/sources/) を参照してください。

# ステップ 2: MoEngage を宛先として設定する

データソースを設定したら、RudderStack ダッシュボードの Destinations で **ADD DESTINATION** を選択します。利用可能な宛先のリストから MoEngage を選択します。宛先に名前を付け、Next をクリックします。次の画面が表示されます。<img src="/images/partner_4520772282004.png" alt="screenshot-2020-11-11-at-11.11.28-am.png" />RudderStack ダッシュボードの Connection Settings で、上記のように MoEngage の API ID、API Key、Region を入力してください。

RudderStack ダッシュボードの Android SDK Settings でネイティブ SDK スイッチをオンにすると、Android ソースで RudderStack の Device Mode を有効にできます。同様に、Web の場合は Web SDK Settings、iOS の場合は iOS SDK Settings で設定します。

データセンターは MoEngage ダッシュボードのインスタンスに対応しています。[詳細はこちら](https://moengage-user-guide.mintlify.app/user-guide/data/key-concepts/data-centers-in-moengage)

# ステップ 3: 連携タイプを選択する

RudderStack の Web およびネイティブのクライアントサイドライブラリを MoEngage と統合する際には、サイドバイサイド(デバイスモード)連携またはサーバー間(クラウドモード)連携のいずれかを選択できます。

## 連携タイプ

1.[サイドバイサイド / デバイスモード](https://moengage-partner-guide.mintlify.app/partner-guide/data-and-analytics/cdps/rudderstack/moengage-destination#side-by-side-integration-device-mode): RudderStack は、クライアント(ブラウザーまたはモバイルアプリケーション)から MoEngage にイベントデータを直接送信します。

2.[サーバー間 / クラウドモード](https://moengage-partner-guide.mintlify.app/partner-guide/data-and-analytics/cdps/rudderstack/moengage-destination#server-to-server-integration-cloud-mode): MoEngage SDK はイベントデータを RudderStack に直接送信し、そのデータが変換されて MoEngage にルーティングされます。

RudderStack の[接続モード](https://www.rudderstack.com/docs/destinations/rudderstack-connection-modes/)とそれぞれの利点について詳しくご覧ください。

## サイドバイサイド連携(デバイスモード)

このモードでは、Web サイトまたはモバイルアプリに設定された MoEngage SDK を使用して、イベントを MoEngage に送信できます。[RudderStack のドキュメント](https://www.rudderstack.com/docs/destinations/marketing/moengage/#adding-device-mode-integration)の説明に従って、Android、iOS、または \[React Native\] 用の RudderStack SDK へのマッピングを設定してください。

## サーバー間連携(クラウドモード)

このモードでは、MoEngage SDK はイベントデータを RudderStack に直接送信します。その後、RudderStack はこのデータを変換し、想定される形式で MoEngage にルーティングします。変換は RudderStack システム内で行われます。連携を有効にするには、[RudderStack のドキュメント](https://www.rudderstack.com/docs/destinations/marketing/moengage/#supported-mappings)の説明に従って、RudderStack のメソッドを MoEngage にマッピングする必要があります。

**注意-** RudderStack のサーバーサイド SDK(Java、Python、Node.js、Go、Ruby)は Cloud Mode のみをサポートしています。これは、サーバーサイド SDK が RudderStack のバックエンドで動作し、MoEngage 固有の SDK を読み込むことができないためです。

# ステップ 4: SDK メソッド

MoEngage は、RudderStack の identify および track メソッドをサポートしています。

### Identify

[RudderStack の identify メソッド](https://www.rudderstack.com/docs/destinations/marketing/moengage/#identify)は、ユーザーとそのアクションを関連付けます。RudderStack は、一意のユーザー ID と、名前、メールアドレス、IP アドレスなど、そのユーザーに関連付けられたオプションの特性を取得します。

### Track

[RudderStack の track メソッド](https://www.rudderstack.com/docs/destinations/marketing/moengage/#track)は、すべてのユーザーアクティビティと、それらのアクティビティに関連付けられたプロパティを取得します。

# レート制限

プラットフォームの安定性を維持するため、MoEngage は RudderStack のデータ取り込みを、ワークスペースあたり最大 500 リクエスト/秒(RPS)に制限しています。ワークスペースがこの制限を超えると、MoEngage は HTTP `429 (Too Many Requests)` ステータスコードを返します。レート制限がデータフローにどのように影響するかについては、RudderStack のデフォルトの再試行ポリシーを参照してください。

**再試行の上限到達**: RudderStack がデータのバッチに対するすべての再試行を使い果たした場合は、RudderStack サポートチームに連絡して、失敗したリクエストを再送してもらう必要があります。

# MoEngage のセットアップ

MoEngage をセットアップするには、次の手順を実行します。

1. MoEngage Dashboard \> Settings \> General に移動します。
2. Workspace ID（旧 AppID）をコピーします。
3. **Twilio Segment ダッシュボード**に移動し、**Integrations** に進んで **MoEngage** を選択します。
4. MoEngage Integration を有効にします。
5. MoEngage Settings に移動し、**ステップ 1** で取得した MoEngage Workspace ID（旧 App ID）を入力します。
6. 変更を保存します。

# 追加設定の使用

### データセンター

デフォルト（dc-01）以外のデータセンターを設定するには、localstorage に次の値を追加する必要があります。

`moe_Twiliosegment_cluster: dc_X`（X はダッシュボードホストに応じた数値です）

設定するには、次のヘルパーコードを使用します: `localStorage.setItem('moe_Twiliosegment_cluster', {dataCenter})` {dataCenter} を適切な値に置き換えてください。

データセンターの値は、次の表を参照してください。

| ダッシュボードホスト | データセンター |
| --- | --- |
| dashboard-01.moengage.com | DC\_1 |
| dashboard-02.moengage.com | DC\_2 |
| dashboard-03.moengage.com | DC\_3 |
| dashboard-04.moengage.com | DC\_4 |
| dashboard-06.moengage.com | DC\_6 |

# SDK の統合とデータトラッキング

Web サイトに Twilio Segment をインストールするには、[Install SDK](https://segment.com/docs/connections/sources/catalog/libraries/website/javascript/quickstart/#step-2-copy-the-segment-snippet) を参照してください。

ユーザープロパティをトラッキングするには、[Track User Properties](https://segment.com/docs/connections/sources/catalog/libraries/website/javascript/#identify) を参照してください。

ユーザー行動をトラッキングするには、[Track User Behaviour](https://segment.com/docs/connections/sources/catalog/libraries/website/javascript/#track) を参照してください。

# プッシュの統合

Web サイトにプッシュ通知を統合するには、[Setting up web push](https://www.moengage.com/docs/developer-guide/web-sdk/web-push/configure-and-integrate-web-push) を参照してください。

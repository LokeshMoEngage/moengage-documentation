# はじめに

<Info>
  Twilio Segment 統合は現在、[Unified Identity (Identity Resolution)](https://moengage-user-guide.mintlify.app/user-guide/data/user-data/unified-identity-identity-resolution) および [Portfolio](https://moengage-user-guide.mintlify.app/user-guide/settings/account/portfolio/portfolio) をサポートしていません。
</Info>

[Twilio Segment](https://segment.com/) は、顧客データの収集、クレンジング、アクティベーションを支援するカスタマーデータプラットフォームです。すでに Segment を使用してデータをトラッキングしている場合、MoEngage 統合を使用すると、イベントデータと属性データを簡単に MoEngage に送信できます。

Segment のソースライブラリでデータをトラッキングすると、Segment がデータを MoEngage が理解できる形式に変換して MoEngage にルーティングするため、エンジニアリングの工数を削減できます。詳細については、[MoEngage with Twilio Segment](https://segment.com/docs/connections/destinations/catalog/moengage/) を参照してください。

# 対象範囲

MoEngage と Segment の統合により、ユーザーをトラッキングし、さまざまなユーザー分析プロバイダーにデータをルーティングできます。Segment では次のことが可能です。

| 統合の範囲 | 詳細 |
| --- | --- |
| Segment のデータ（ユーザーとイベント）を MoEngage に送信する | 詳細については、[MoEngage (Destination)](/ja/partner-guide/data-and-analytics/cdps/twillio-segment/getting-started/moengage-destination) を参照してください。 |
| Segment のオーディエンスと computed traits を MoEngage に同期する | 詳細については、[Twilio Segment Engage](/ja/partner-guide/data-and-analytics/cdps/twillio-segment/getting-started/twilio-segment-engage)（旧 Segment Personas）を参照してください。 |
| MoEngage のキャンペーン統合データを Segment に送り返す | 詳細については、[MoEngage (Source)](/ja/partner-guide/data-and-analytics/cdps/twillio-segment/getting-started/moengage-source) を参照してください。 |

# はじめに

[Segment](https://segment.com/) は、顧客データの収集、クレンジング、アクティベーションを支援するカスタマーデータプラットフォームです。

Segment の MoEngage Source を使用すると、MoEngage 上のすべてのキャンペーンインタラクションイベントを Segment に転送し、さらなる処理や分析を行うことができます。

## MoEngage Source を使用するメリット

- すべての顧客データを 1 か所に送信することで、チームのエンゲージメントとマーケティングの取り組みを進化させることができます。
- MoEngage のデータを、すでに Segment に流れているイベントデータと組み合わせることができます。
- MoEngage Source を使用すると、これらのイベントを Destination やウェアハウスに転送できます。
- エンゲージメントとマーケティングの取り組みに関する包括的なレポートを取得できます。

# 統合

<Info>
  **前提条件**

  - MoEngage と Segment のログイン認証情報。
  - Segment へのエクスポートには、アドオンである MoEngage Streams を使用します。
</Info>

## ステップ 1: Segment で新しい MoEngage Source を追加する

1. ワークスペースの [Sources カタログページ](https://app.segment.com/goto-my-workspace/sources/catalog)で、**Add Source** をクリックします。
2. Sources カタログで「MoEngage」を検索し、MoEngage を選択して **Add Source** をクリックします。
3. 次の画面で、Source に**ニックネーム**を付け、その他の設定を行います。
   - ニックネームは Segment アプリ内のラベルとして使用され、Segment はウェアハウス内に関連するスキーマ名を作成します。ニックネームは任意の名前にできますが、ソース自体を表し、環境を区別できる名前（例: `MoEngage_Prod`、`MoEngage_Staging`、`MoEngage_Dev`）を使用することを推奨します。
4. **Add Source** をクリックして設定を保存します。
5. Segment UI から **Write key** をコピーします。このキーは MoEngage App Marketplace で入力する必要があります。<img src="/images/partner_12663037922964.png" alt="SegmentSource.png" />

## ステップ 2: MoEngage で接続の詳細を入力する

![Marketplace.png](/images/partner_12662074940692.png)

1. MoEngage Dashboard > App Marketplace に移動し、Segment を検索して **Add Integration** をクリックします。
2. 接続に名前を付け、**Write Key** を入力して、Segment Region を選択します。\
   注: リージョンをまたぐデータは許可されていないため、MoEngage App Marketplace で選択したリージョンが Segment Workspace Region と異なる場合、Segment はイベントを破棄します。
3. Segment に戻り、MoEngage ソースで **Add Destinations** をクリックして、MoEngage のデータを受信する Destination を追加します。

# よくある質問

<AccordionGroup>
  <Accordion title="データの受信はいつ開始されますか？">
    通常、アカウントで自動データエクスポートがセットアップされ、データが表示され始めるまでに最大 30 分かかります。
  </Accordion>

  <Accordion title="後から追加のイベントをエクスポートできますか？">
    はい。後から新しいイベントをエクスポートする必要がある場合は、App Marketplace でいつでも設定を編集し、新しいイベントをエクスポートに追加できます。
  </Accordion>

  <Accordion title="Automated Data Exports を使用して過去のデータをエクスポートできますか？">
    現時点では、Automated Data Exports を使用して過去のデータをエクスポートすることはできません。設定後は、エクスポートを有効にした時点からの各イベントのデータが表示されるようになります。
  </Accordion>

  <Accordion title="Automated Data Exports には料金がかかりますか？">
    お使いの請求プランにこの機能がまだ含まれておらず、後から有効にする必要がある場合は、カスタマーサクセスマネージャーと協力して請求プランに含めてもらう必要があります。MoEngage が毎月データウェアハウス/パートナー/API に送信するデータ量によっては、追加料金が発生する場合があります。
  </Accordion>
</AccordionGroup>

# はじめに

Tealium EventStream は、データの中心に位置するデータ収集および API ハブです。EventStream は、セットアップとインストールから、受信したユーザーデータの識別、検証、強化まで、データサプライチェーン全体を処理します。EventStream は、イベントフィードとコネクターを使用してリアルタイムでアクションを実行します。

# 連携

この連携は、Tealium から MoEngage のデータ API にデータを転送します。

## 前提条件

- MoEngage および Tealium アカウントのログイン認証情報。
- Tealium のデータ統合 - Tealium コネクターを正常に設定するには、事前にアプリ、サイト、またはサーバーにライブラリをインストールする必要があります。
- Data API ID と Data API Key は **Settings** -\> **Account** -\> **APIs** で確認できます。Data API ID は **Workspace ID** と同じです。Data API Key は、同じ画面の **API Keys** -\> **Data** セクションで確認できます。

## ステップ 1: ソースを設定する

Tealium では、コネクターがデータを取得するための有効なデータソースを最初に設定する必要があります。

1. Tealium の左側のサイドバーで、**Server-Side** の下にある **Sources \> Data Sources \> \+ Add Data Source** に移動します。
2. 利用可能なカテゴリ内で **HTTP API** プラットフォームを見つけ、HTTP API アプリに名前を付けます。これは必須フィールドです。
3. **Event Specifications** のオプションから、含めるイベント仕様を選択します。イベント仕様は、インストールで追跡するイベント名と必須属性を特定するのに役立ちます。これらの仕様は受信イベントに適用されます。<img src="/images/partner_22019338060820.png" alt="event_specs.png" />どのデータが最も価値があり、どの仕様がユースケースに最も適しているかを検討してください。カスタムイベント仕様も利用できます。
4. 次のダイアログで **Get Code** ステップに進みます。ここで提供されるベースコードとイベントトラッキングコードは、インストールガイドとして機能します。これらの手順をチームと共有する場合は、提供されている PDF をダウンロードしてください。完了したら、**Save & Continue** を選択します。<img src="/images/partner_22854875210260.png" alt="Tealium Events_Corrected.png" />
5. これで、保存したソースを表示したり、イベント仕様を追加または削除したりできるようになります。

## ステップ 2: イベントコネクターを作成する

コネクターとは、データを送信するために使用される Tealium と他のベンダーとの間の連携です。これらのコネクターには、パートナーがサポートする API を表すアクションが含まれています。

1. Tealium の左側のサイドバーで、 _Server-Side_ の下にある  _EventStream \> Event Connectors_ に移動します。
2. _\+ Add Connector_ ボタンを選択して、コネクターマーケットプレイスを閲覧します。表示される新しいダイアログボックスで、MoEngage コネクターを検索します。
3. クリックすると、接続の概要と、必要な情報、サポートされているアクション、設定手順の一覧を確認できます。設定は、ソース、設定、アクション、概要の 4 つのステップで構成されます。

### ソース

開いたダイアログで、作成したデータソースを選択し、Event Feed で All Events または必要に応じて特定のイベント仕様を選択します。 _Continue_ をクリックします。<img src="/images/partner_22019338067988.png" alt="Screenshot_2022-02-18_at_2.06.45_PM.png" />

### 設定

次に、 _Add Connector_ を選択します。コネクターに名前を付け、MoEngage の Data API と Data API Key を入力する必要があります。

| **フィールド** | **説明** |
| --- | --- |
| Workspace ID | MoEngage アカウントの Data API ID と Workspace ID は同じです。MoEngage アカウントの Workspace ID は、**Settings - \> Account -\> APIs -\>Workspace ID** で確認できます。 |
| Data API Key | MoEngage アカウントの Data API Key は、\*\*Settings - \> Account -\> APIs -\> API keys \*\*\>**Data** の API 設定で確認できます。 |

![Screenshot\_2022-02-18\_at\_2.06.58\_PM.png](/images/partner_22019350889492.png)

以前にコネクターを作成したことがある場合は、必要に応じて利用可能なコネクターリストから既存のコネクターを使用し、鉛筆アイコンでニーズに合わせて変更したり、ゴミ箱アイコンで削除したりできます。

### アクション

次に、コネクターアクションに名前を付け、設定したマッピングに従ってデータを送信するアクションタイプを選択します。ここでは、MoEngage の属性を Tealium の属性名にマッピングします。選択したアクションタイプに応じて、Tealium で必要なフィールドが異なります。

![Screenshot\_2022-02-18\_at\_2.09.37\_PM.png](/images/partner_22019350891540.png)

| パラメーター | 説明 |
| --- | --- |
| Customer ID | MoEngage SDK で設定され、渡される一意の識別子。 |
| Name | 更新するユーザーの名前。 |
| First Name | ユーザーの名。 |
| Last Name | ユーザーの姓。 |
| Email | ユーザーのメールアドレス。 |
| Age | ユーザーの年齢。 |
| Gender | 男性または女性。大文字と小文字が区別されます。 |
| Mobile | ユーザーの電話番号。 |
| Geography | ユーザーの位置情報、緯度と経度(- lat,lng)。数値の配列の属性タイプである必要があります。 |
| Source | ユーザーの獲得ソース。 |
| Created Time | ユーザーの作成時刻。 |
| Last Seen | ユーザーの最終確認時刻。 |
| Transactions | ユーザーによるトランザクション数。 |
| Revenue | ユーザーのライフタイムバリュー。 |
| Platform | ユーザーがシステムを操作している現在のプラットフォーム(Android、Windows、iOS など)。 |

Finish を選択します。

これで、Tealium のホームページのコネクターリストにコネクターが表示されます。

![Screenshot\_2022-02-18\_at\_2.18.19\_PM.png](/images/partner_22019338090132.png)

## ステップ 3: Tealium コネクターをテストする

コネクターが稼働したら、正しく動作していることを確認するためにテストする必要があります。最も簡単なテスト方法は、Tealium の **Trace Tool** を使用することです。

1. 新しいトレースを開始するには、左側のサイドバーの **Server-Side** オプションで **Trace** を選択します。
2. リアルタイムログを確認します。
3. **Actions Triggered** エントリをクリックして展開し、検証するアクションを確認します。
4. 検証するアクションを探し、ログのステータスを表示します。

Tealium の Trace ツールの実装に関する詳細な手順については、[トレースのドキュメント](https://docs.tealium.com/server-side/trace/)を参照してください。

<Warning>
  **制限事項** 

  Tealium でサポートされているのは、コネクターアクション - Add/Modify User Information のみです。
</Warning>

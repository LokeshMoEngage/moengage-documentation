# はじめに

Tealium は、EventStream、AudienceStream、iQ Tag Management で構成されるユニバーサルデータハブおよび顧客データプラットフォームであり、モバイル、Web、およびサードパーティソースの代替データを接続できます。Tealium と MoEngage の接続により、カスタムイベント、ユーザー属性、購入のデータフローが実現し、データに基づいてリアルタイムでアクションを実行できるようになります。

# 範囲

MoEngage と Tealium の連携により、ユーザーを追跡し、さまざまなユーザー分析プロバイダーにデータをルーティングできます。Tealium の Event Stream と AudienceStream を使用して、Tealium から MoEngage にデータを同期します。

**Event Stream** - Tealium EventStream は、データの中心に位置するデータ収集および API ハブです。EventStream は、セットアップとインストールから、受信したユーザーデータの識別、検証、強化まで、データサプライチェーン全体を処理します。EventStream は、イベントフィードとコネクターを使用してリアルタイムでアクションを実行します。

**Audience Stream -** Tealium AudienceStream は、オムニチャネルの顧客セグメンテーションおよびリアルタイムアクションエンジンです。AudienceStream は、EventStream に流れ込むデータを取得し、顧客とブランドとのエンゲージメントにおける最も重要な属性を表す訪問者プロファイルを作成します。

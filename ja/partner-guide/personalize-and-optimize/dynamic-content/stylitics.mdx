# はじめに 

[Stylitics](https://stylitics.com/) は、小売業者がビジュアルコンテンツを大規模に自動化・配信するためのクラウドベースの SaaS プラットフォームです。Stylitics のバンドルは、商品をコンテキスト化することでインスピレーションを与え、購入への自信を高め、エンゲージメントを向上させ、最終的に平均注文額とコンバージョン率の向上につながります。

MoEngage と Stylitics の統合により、既存のメールキャンペーンを魅力的で関連性の高いバンドルコンテンツで強化し、パーソナライズされた顧客体験を創出できます。

# ユースケース

一般的なトリガーメールプログラムの例を以下に示します。

  * カート放棄メール
  * 閲覧放棄メール
  * 発送確認メール
  * 購入後メール



# 統合

<Info>
**前提条件**

Stylitics アカウントにアクセスできることを確認してください。
</Info>

Stylitics は、この統合のためにバンドルデータを提供します。メールサービスプロバイダーは、Stylitics のバンドルを含めるようにメールテンプレートを作成または更新できます。Stylitics はメールのレイアウトやデザインを変更することはできません。

  * バンドルをメールに統合します。位置とカスタマイズは ESP が決定します。
  * ESP は、Stylitics のコンテンツを含めるようにトリガーメールのコードを更新します。
  * ESP は、更新されたトリガーシリーズのテスト、プレビュー、リリースを行います。



Stylitics が提供するのは、アイテムのバンドルデータのみです。お客様と ESP の間でユーザーデータを保持し、Stylitics のバンドルデータを組み込んでユーザーに送信できます。

# データ交換

次の 3 つのアプローチにより、トリガーメールに Stylitics のバンドルを含めることができます。

## 1\. API アプローチ（推奨）

お客様または ESP は、アイテムごとに API 呼び出しを行い、バンドルデータをメールに入力できます。Stylitics の API はすぐに使用できるため、Stylitics は API 呼び出しに同社の API を使用することを推奨しています。

_注意: Stylitics が実施する A/B テストを行う場合は、ユーザーがメール内でクリックした Stylitics アイテムの PDP URL に styliticsCID パラメーターと styliticsoverride パラメーターを付加する必要があります。例: &styliticsoverride=001?styliticsCID=email[clientname]_

## 2\. フラットファイルアプローチ

お客様または ESP は、フラットファイル内のアイテムのバンドルデータを参照して、バンドルデータをメールに入力できます。Stylitics はバンドルデータを CSV、TXT、または XML 形式にフラット化し、毎日送信できます。また、ESP のニーズに応じてファイル形式の調整を支援することもできます。このファイルの作成には 2～3 週間かかることに注意してください。

### 要件:

  * 場所: Stylitics は、お客様が毎日取得できるように Stylitics の SFTP にファイルを配置するか、お客様から SFTP の認証情報を受け取ってそこにファイルを配置できます。
  * 時間: Stylitics は毎日午前中にファイルを配置します。ファイルが必要な特定の時間がある場合はお知らせください。
  * ファイルキー: ESP がデータを参照できるように、お客様と Stylitics の間でファイルのキーとするアイテムデータ文字列について合意する必要があります。一般的には SKU、item_group_id、または item_number が使用されます。



## 3\. Web サイトデータ抽出アプローチ

ベンダーは、サイトのフロントエンドから Stylitics のコンテンツをスクレイピングし、バンドルデータをメールに挿入できます。Stylitics 側での追加作業は必要ありません。

# メールテンプレートのベストプラクティス

お客様と ESP は、Stylitics のデータとバンドルを挿入するための HTML メールテンプレートを作成します。ベストプラクティスと推奨事項を以下に示します。

  * ユーザーが購入またはインタラクションした最も高価なアイテム、または最初の定価アイテムについて、メール内に 2～4 個のバンドルを表示する
  * 複数の item_number を呼び出し、最初のいくつかのバンドルレスポンスを表示する 
    * アイテムに利用可能なバンドルがない場合のフォールバックオプションを用意する
    * Stylitics のバンドルが配置されているセクションを非表示にする
    * ユーザーが次に閲覧したアイテムのバンドルを表示する
  * バンドル画像と商品タイトルのリスト、サムネイル画像を表示して、ユーザーが明確にクリックスルーできるようにする



_注意: メールは JavaScript をサポートしていないため、Stylitics ウィジェットの JavaScript をメールに挿入することはできません。_

# 分析

Stylitics は、この種のメールプログラムのためにバンドルデータを提供します。そのため、お客様、ESP、Stylitics の間でのオープンなデータ共有をお願いしています。可能であれば、効果を把握してプログラムを改善するために、次の指標をご提供いただけますと幸いです。

  * 送信されたメール数
  * 開封されたメール数
  * 閲覧数とエンゲージメント数
  * クリック率
  * カート追加数
  * 購入数

  * ESP とモックアップを作成する
  * 分析について合意する
  * リリーススケジュールについて合意する

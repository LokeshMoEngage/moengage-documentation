## はじめに

[Aampe](https://www.aampe.com/) は、短文の通知やメッセージングのためのモバイルアプリエンゲージメントおよびパーソナライズのインフラストラクチャを提供しています。

## MoEngage × Aampe

MoEngage と Aampe の統合により、Aampe のパーソナライズドメッセージングソフトウェアを活用して、各ユーザーにより人間味のあるコミュニケーションを送信でき、顧客とのコミュニケーションをリテンション向上のエンジンに変えることができます。Aampe は MoEngage の Push API を利用します。

## 統合

<Info>
**前提条件**

Aampe アカウントにアクセスできることを確認してください。
</Info>

Aampe を MoEngage と統合するには、次の手順に従います。

1. Aampe ダッシュボードに移動し、サイドメニューで Configure >> Push Provider を探します。MoEngage を探し、その横にある Activate スイッチをクリックします。

   ![Step-1.png](/images/partner_11203975042964.png)

2. Aampe がポップアップフォームで MoEngage の詳細を設定するよう求めます。

   ![Step-2.png](/images/partner_11204028742804.png)

3. 以下の表を参照して、上記のフォームに入力します。

   | フィールド | 詳細 |
   | --- | --- |
   | Workspace ID | MoEngage アカウントの Workspace ID は **Settings -> Account -> APIs -> Workspace ID** で確認できます。MoEngage アカウントの Data API ID と Workspace ID は同じです。 |
   | API secret | API secret は API キーです。MoEngage アカウントの Data API キーは **Settings -> Account -> APIs -> API keys -> Data** API 設定で確認できます。 |

4. Activate をクリックして統合を完了します。
   
   ![Step-3.png](/images/partner_11204129113108.png) 

5. これで、Aampe でキャンペーンを作成し、MoEngage 経由で送信できるようになりました。

# はじめに

[Sendtric](https://www.sendtric.com/) は、メールのコンバージョンを最大化し、売上を伸ばし、ランディングページ、メール、マーケティングタッチポイントに緊急性を持たせるのに役立つカウントダウンタイマーを提供しています。

# MoEngage × Sendtric

MoEngage と Sendtric の統合により、期間限定の商品、セール、イベントを含むメールにカウントダウンタイマーを追加できます。

# 統合

<Info>
  **前提条件**

  Sendtric ダッシュボードへのアクセス。
</Info>

## ステップ 1: Sendtric でカウントダウンタイマーを作成する

1. Sendtric ダッシュボードに移動し、カウントダウンタイマーを作成します。Sendtric でのカウントダウンタイマーの作成について詳しくは、[こちらのドキュメント](https://www.sendtric.com/beginners-guide-to-email-countdown-timers/) を参照してください。\\ <img src="/images/partner_23503961439380.png" alt="Screenshot 2024-02-07 at 12.51.34 AM.png" />
2. タイマーを作成すると、_code code_ のオプションが表示されます。
3. このコードをコピーします。これを MoEngage キャンペーンのテンプレート内に貼り付ける必要があります。

## ステップ 2: MoEngage キャンペーン内でこのコードを使用する

MoEngage キャンペーンに Sendtric のコードを含めるには、キャンペーン作成のステップ 2 で次の手順を実行します。

![](/images/partner_23503961440788.png)

1. 新しい HTML ブロックを作成します。
2. ステップ 2 でコピーしたコードを HTML ブロック内に貼り付けます。
3. 「@」と入力してパーソナライズする適切な属性を選択し、`MERGE_TAG` を MoEngage のテンプレートコードに置き換えます。
   <CodeGroup>
   ```html HTML
   <Your copied countdown timer code here>
   ```
   </CodeGroup>

Preview アイコンをクリックしてプレビューを表示するか、キャンペーンをテストすることができます。

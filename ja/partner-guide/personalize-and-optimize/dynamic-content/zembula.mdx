## はじめに

[Zembula](https://www.zembula.com/) を使用すると、マーケターはメールが開封されるたびにその瞬間に更新される、動的でパーソナライズされたメールコンテンツを作成できます。

## MoEngage × Zembula

MoEngage と Zembula の連携により、MoEngage のメールテンプレートに Zembula のユニバーサルコードスニペットを含めることができます。Zembula Universal Code の大きなメリットの 1 つは、受信者がまず中間ページに移動するのではなく、メールから直接ウェブサイトにアクセスして体験を操作できることです。

## 連携

<Info>
**前提条件**

Zembula ダッシュボードへのアクセス権。
</Info>

### ステップ 1: Zembula でユニバーサルコードを作成する

Zembula で Universal Code をインストールして有効にしたら、以下を行います。

1. Campaigns セクションに移動し、共有するキャンペーンを選択します。上部の Email リンクをクリックします。
   
   <img src="https://support.iterable.com/hc/article_attachments/19347979594260/image-0.png" alt="Zembula でキャンペーンを選択する" />
   
2. キャンペーンに名前を付けてスニペットコードを作成します。Zembula でキャンペーンに名前を付け、Create Snippet Code をクリックします。
   
   <img src="https://support.iterable.com/hc/article_attachments/19348020747668/image-1.png" alt="Zembula でキャンペーンに名前を付ける" />
   
3. URL を設定します。Zembula で、体験を表示するページの URL（ホームページなど）を入力します。
   
   <img src="https://support.iterable.com/hc/article_attachments/19348026719508/image-2.png" alt="Zembula で URL を指定する" />
   
4. 画像サイズを設定します。Zembula で画像サイズを設定します。特定の画像サイズを入力するか、画像をレスポンシブのままにすることを選択できます。レスポンシブの場合、受信者が閲覧しているデバイスに応じて自動的にサイズが調整されます。
   
   <img src="https://support.iterable.com/hc/article_attachments/19347994335508/image-4.png" alt="Zembula で画像サイズを設定する" />
   
5. Zembula スニペットをコピーします。
   
   <img src="https://support.iterable.com/hc/article_attachments/19348027008660/image-5.png" alt="Zembula からメールスニペットをコピーする" />

これを MoEngage キャンペーンのテンプレート内に貼り付ける必要があります。

### ステップ 2: MoEngage キャンペーン内でこのコードを使用する

MoEngage キャンペーンにコードを含めるには、キャンペーン作成のステップ 2 で以下を行います。

![](/images/partner_24084399738644.png)

1. 新しい HTML ブロックを作成します。
2. ステップ 2 でコピーしたコードを HTML ブロック内に貼り付けます。テンプレートを一から作成する際に、HTML コードを直接挿入することもできます。

Preview アイコンをクリックしてプレビューを表示するか、キャンペーンをテストできます。

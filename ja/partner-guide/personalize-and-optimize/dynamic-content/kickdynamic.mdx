# はじめに

[Kickdynamic](https://www.tigergraph.com/kickdynamic/) を使用すると、メールで使用するライブ画像を作成できます。このプラットフォームは、カスタマイズなしで必要なものすべてを UI 上で直接作成できるように設計されています。

# MoEngage × Kickdynamic

MoEngage と Kickdynamic の統合により、メールの開封時にパーソナライズされてレンダリングされる動的コンテンツでメールを充実させることができます。

# 統合

## ステップ 1: Kickdynamic でパーソナライズ画像テンプレートを作成する

1. Kickdynamic ダッシュボードで、プラットフォームの Templates エリアに移動し、Content Automation に進んで「\+ New Template」を選択します。
2. Description でテンプレートに名前を付けます。Kickdynamic プラットフォームでブランドに合わせたパーソナライズ画像を作成するには、事前に背景画像をデザインしておく必要があります。次に、キャンバスをクリックし、右側のメニューオプションを使用して作成した背景画像をアップロードします。 <img src="https://675544707-files.gitbook.io/~/files/v0/b/gitbook-legacy-files/o/assets%2F-LaLlWyy5jddi_WjlHBr%2F-M1_ylEtBN4bbufZnl96%2F-M1a01vS4AVufcMEnru5%2FPI%20Template%20-%20Image%203.png?alt=media&token=89f3d15c-4178-43fc-812b-66beba7ecdcd" />
3. パーソナライゼーションの最初のレイヤーを追加するには、「Add Block」ボタンを選択します。キャンバスの中央にブロックが表示されます。
4. 次に、以下で強調表示されている「Connect Source」を選択します。 <img src="https://675544707-files.gitbook.io/~/files/v0/b/gitbook-legacy-files/o/assets%2F-LaLlWyy5jddi_WjlHBr%2F-M1_ylEtBN4bbufZnl96%2F-M1a07NzrDrNkZdJfIr2%2FPI%20Template%20-%20Image%205.png?alt=media&token=3c42e93e-d6f2-4fcb-93da-7099eefd3180" />
5. パーソナライゼーションを表示するには、URL パラメーターに接続します。これにより、MoEngage に保存されている任意のデータをマージできます。
6. 構築中にユーザーが識別しやすい名前をパラメーターに付けます。たとえば、名のパーソナライゼーションの場合、以下の例のように `firstname` や `first_name` という名前にできます。 <img src="https://675544707-files.gitbook.io/~/files/v0/b/gitbook-legacy-files/o/assets%2F-LaLlWyy5jddi_WjlHBr%2F-M1_ylEtBN4bbufZnl96%2F-M1a0Cq-UH2Qdvol-VwP%2FPI%20Template%20-%20Image%207.png?alt=media&token=fb647153-4349-42b9-b7ea-b405db36a507" />
7. Kickdynamic が提供するその他の機能については、[こちら](https://help.kickdynamic.com/widgets/personalised-image-overview/creating-a-personalized-image-template#additional-functionality) を参照してください。

## ステップ 2: Kickdynamic でパーソナライズ画像キャンペーンを作成する

1. Kickdynamic ダッシュボードで、キャンペーンに移動するか新しいキャンペーンを作成し、Content Automation ウィジェットを選択します。
2. メーリングやタグに名前を付け、適切なテンプレートを選択します。 <img src="https://675544707-files.gitbook.io/~/files/v0/b/gitbook-legacy-files/o/assets%2F-LaLlWyy5jddi_WjlHBr%2F-M1a4we2xSlSGpIU-VXN%2F-M1aBRI6PvBnea7Yugys%2FPI%20Campaign%20-%20Image%202.png?alt=media&token=e4ee424e-af12-43c5-8bf6-7a98b7cfeef8" />
3. 画像のリンク先を定義し、Next をクリックします。 <img src="https://675544707-files.gitbook.io/~/files/v0/b/gitbook-legacy-files/o/assets%2F-LaLlWyy5jddi_WjlHBr%2F-M1a4we2xSlSGpIU-VXN%2F-M1aBYHW8WkuG6bKt-bZ%2FPI%20Campaign%20-%20Image%203.png?alt=media&token=15aa2331-dd1f-4fa0-9ad9-1f79df6c1e97" />
4. テンプレートでリンクされたすべての URL パラメーターは、次のように自動的にタグに反映されます。 <img src="https://675544707-files.gitbook.io/~/files/v0/b/gitbook-legacy-files/o/assets%2F-LaLlWyy5jddi_WjlHBr%2F-M1a4we2xSlSGpIU-VXN%2F-M1aBa1Fo9nfuru3pOtY%2FPI%20Campaign%20-%20Image%204.png?alt=media&token=40ad1ca2-86b6-4662-8287-5efb3af2fa95" />
5. 生成されたタグ内で、次のように `value` を MoEngage のパーソナライゼーションコードに置き換えます。
   <CodeGroup>
   ```html HTML wrap
   <a href="https://img.kickdyn.com/clickimgdf.ashx?c=28495.TxzzAhrqBwPFnJiC5zNy&firstname=%7B%7BUserAttribute%5B'First%20Name'%5D%7D%7D">
   <img src="https://img.kickdyn.com/imgdf.png?c=28495.TxzzAhrqBwPFnJiC5zNy&firstname=%7B%7BUserAttribute%5B'First%20Name'%5D%7D%7D" width="640" height="427" border="0"/> </a>
   ```
   </CodeGroup>

メールの開封時に、マージコードによってメールを開封した特定の購読者に関連付けられたデータが取得されます。この値によって、Kickdynamic タグに表示する内容が指定されます。たとえば、名のマージであれば「Katie」や「Henry」などが表示されます。

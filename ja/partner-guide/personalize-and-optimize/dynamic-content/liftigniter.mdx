## はじめに

[LiftIgniter](https://www.liftigniter.com/) は、ファーストパーティの行動データに（プライバシーを侵害することなく）機械学習を適用し、サイト上の商品やコンテンツのレコメンデーションをパーソナライズします。

## MoEngage と LiftIgniter

MoEngage と LiftIgniter の統合により、MoEngage キャンペーン内でパーソナライズされたコンテンツレコメンデーションを送信し、利用率とクリック率を向上させることができます。

## 統合

<Info>
  **前提条件**

  - LiftIgniter API トークン（API の呼び出しに必要）。
  - LiftIgniter JavaScript キー。
</Info>

MoEngage の Content API を使用すると、レコメンデーションを MoEngage キャンペーンに動的に取り込み、よりパーソナライズされたエクスペリエンスを提供できます。

### ステップ 1: MoEngage Content API を設定する

1. **Settings** \> **Advanced settings** \> **Content API** に移動します。Content API 画面の右上にある **\+ Add content API** をクリックします。 <img src="/images/partner_21979738782100.png" alt="Add content API ボタンが強調表示された MoEngage の Content API 画面" />
2. エンドポイント URL に LiftIgniter API を追加します。エンドポイントはユースケースによって異なります。 <img src="/images/partner_20130868953364.png" alt="LiftIgniter のエンドポイント URL が表示された Content API 設定画面" /> 顧客にレコメンデーションを表示するには、LiftIgniter の [Model Query API](https://documenter.getpostman.com/view/2166502/liftigniter-api-collection/7TFGvSV#340404f6-68fd-4844-90d9-7b93994440b9) を使用します。Content API を設定する際に、次の URL を挿入します。
   ```text wrap
   https://query.petametrics.com/v3/<jsk>/{{UserAttribute['ID']}}/model
   ```
   `<jsk>` を [JavaScript キー](https://console.liftigniter.com/settings/keys) に置き換えます。URL パラメーターは空のままにします。
3. **Headers** に次を追加します。
   - `x-api-key`: [LiftIgniter API キー](https://documenter.getpostman.com/view/2166502/liftigniter-api-collection/7TFGvSV#intro)。
   - `Content-Type`: `application/json`。
4. **Save** をクリックし、成功のレスポンスが表示されたら **Done** をクリックします。

<Tip>
  MoEngage から API を直接テストできます。Content API のアクションメニューから **Test** をクリックすると、レスポンスを確認して設定を検証できます。
</Tip>

### ステップ 2: MoEngage キャンペーン内にレコメンデーションを表示する

MoEngage キャンペーンで API を使用するには、次の手順を実行します。

1. キャンペーン作成のステップ 2 で、`@` と入力します。
2. パーソナライゼーションのポップアップで、ステップ 1 で設定した LiftIgniter Content API を選択します。
3. [MoEngage Templating Language](https://www.moengage.com/docs/user-guide/campaigns-and-channels/getting-started/message-personalization/jinja-templating-language) を使用して API レスポンスを解析し、そのコンテンツをキャンペーンで使用します。  <img src="/images/partner_20131004588436.png" alt="LiftIgniter のレコメンデーションを挿入している MoEngage のパーソナライゼーションエディター" />
4. **Preview type** の下にある **Personalized** タブをクリックすると、リアルタイムのパーソナライゼーションが適用されたキャンペーンを確認できます。 <img src="/images/partner_20131075562004.png" alt="レンダリングされた LiftIgniter のレコメンデーションを表示している MoEngage の Personalized プレビュータブ" />
5. キャンペーンを公開します。

<Check>
  受信者には、ユーザー ID に一致するパーソナライズされた LiftIgniter のレコメンデーションでレンダリングされたコンテンツブロックが表示されます。
</Check>

## はじめに

[Rocketium](https://rocketium.com/) は、動画とディスプレイバナーの自動化を通じて、ブランドや企業のアプリ内および Web サイトのコンバージョン向上を支援するクリエイティブオートメーションプラットフォームです。このクリエイティブオートメーションプラットフォームにより、マーケターやデザイナーは顧客ライフサイクル全体にわたって、より関連性の高いキャンペーンをより迅速に実施できます。

## MoEngage × Rocketium

MoEngage と Rocketium の統合により、Rocketium のクリエイティブを MoEngage キャンペーンで使用できます。

## 統合

<Info>
  **前提条件**

  Rocketium アカウントを持っていることを確認してください。
</Info>

次の 2 種類の統合がサポートされています。

1. Rocketium のクリエイティブを画像 URL として追加し、MoEngage キャンペーンで直接使用する。
2. パーソナライズされた Rocketium のクリエイティブ（ユーザー属性に基づいてその場でレンダリングされるもの）を MoEngage で取得する。

### 1. 直接の画像 URL を使用する

#### ステップ 1: Rocketium でプロジェクトを作成する

1. 必要なテンプレートを使用して新しいプロジェクトを作成します。 <img src="https://knowledge.rocketium.com/hs-fs/hubfs/1-2.png?width=688&name=1-2.png" alt="1-2" />
2. （ユーザーのパーソナライズされたデータに基づいて）さまざまなバリアントを作成するには、[Rocketium guide on spreadsheet imports](https://docs.rocketium.com/campaign/scale/spreadsheet-import) を参照してプロジェクトを構築・公開します。\<MoEngage でパーソナライズされたクリエイティブを使用する場合に利用できます\>

#### ステップ 2: Rocketium のプロジェクト URL を取得する

1. オーバーフローメニューから Share ボタンをクリックします。 <img src="https://knowledge.rocketium.com/hs-fs/hubfs/4-1.png?width=688&name=4-1.png" alt="4-1" />
2. このモーダルの下部にあるリンクをコピーします。これは次のステップで MoEngage でキャンペーンを作成する際に使用します。 <img src="https://knowledge.rocketium.com/hs-fs/hubfs/6.png?width=688&name=6.png" alt="6" />

#### ステップ 3: MoEngage キャンペーンで Rocketium の URL を使用する

MoEngage キャンペーンに Rocketium の URL を含めるには、キャンペーン作成のステップ 2 で次の操作を行います。

### 2. パーソナライズされた URL を使用する

Rocketium のクリエイティブを複数のキャンペーンで使用する場合は、MoEngage の Content API に保存できます。上記のステップ 1 とステップ 2 で説明したとおりに URL を取得したら、次の手順を実行します。

#### ステップ 1: MoEngage で Content API を追加する

1. **Settings** -\> **Advanced settings** -\> **Content API** に移動します。Content API 画面の右上にある **\+ Add content API** をクリックします。 <img src="/images/partner_21979803447572.png" alt="ContentAPI_Navogation.png" />
2. エンドポイント URL に Rocketium のサブドメインを追加します。

##### API URL

この URL は、前のステップでコピーしたものと同じである必要があります。

`https://cdn.rocketium.com/api/v1/creatives/jzHSMr-EpLBP`

##### パラメーター

パラメーターには、スプレッドシートで作成したパーソナライズ用のパラメーター名を指定します。

![Screenshot\_2022-03-14\_at\_6.30.08\_PM.png](/images/partner_4769504056084.png)

3. Save をクリックします。MoEngage に Rocketium API が追加されたことが確認できます。 <img src="/images/partner_4769549932436.png" alt="Screenshot_2022-03-14_at_6.32.11_PM.png" />

**注意 -** Test ボタンをクリックして API をテストすることもできます。API のレスポンスを確認して検証できます。

![Screenshot\_2022-03-14\_at\_6.33.02\_PM.png](/images/partner_4769591925908.png)

#### ステップ 2: MoEngage キャンペーンで Content API を使用する

これで、これらの Content API をキャンペーンで使用できます。Content API の詳細については、[こちら](https://www.moengage.com/docs/user-guide/campaigns-and-channels/getting-started/campaign-content/content-apis) を参照してください。

1. キャンペーン作成のステップ 2 で、`@` と入力します。
2. ポップアップで、ステップ 2 で設定した Rocketium Content API を選択できます。 <img src="/images/partner_4769784416788.png" alt="Screenshot_2022-03-14_at_6.37.19_PM.png" />
3. Done をクリックして、レスポンスをキャンペーンに含めます。
4. MoEngage のテンプレート言語を使用して API レスポンスを解析し、そのコンテンツをキャンペーンで使用できます。Rocketium は画像 URL をキー "Media" で送信します。Rocketium のレスポンスの例:
   <CodeGroup>
   ```json JSON wrap
   {
   	"Variation Name": "Bangalore",
   	"Media": "https://rocketium.com/images/v2/5dbfc45e87a3cc65f174f77d/resized/1587304799860.png",
   	"Caption 1": "Bangalore",
   	"Caption 2": "SALE",
   	"Caption 3": "up to",
   	"Caption 4": "70% OFF",
   	"Caption 5": "SELECT PRODUCT",
   	"Caption 6": "SHOP NOW",
   	"Gender": "Female",
   	"Location": "Bangalore",
   	"url": "https://rocketium.com/images/export/4fd4c2b6-7183-4483-0823-947b4ccf9f58/image-1618478395354_1080x1080.png"
   }
   ```
   </CodeGroup>

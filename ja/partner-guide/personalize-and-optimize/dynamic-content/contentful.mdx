# はじめに

[Contentful](https://www.contentful.com/) は、あらゆるプラットフォームに向けてコンテンツを作成、管理、配信できるヘッドレスコンテンツ管理システムです。一般的なコンテンツ管理システム（CMS）とは異なり、Contentful では独自のコンテンツモデルを作成できるため、管理するコンテンツを自分で決めることができます。

# MoEngage × Contentful

MoEngage × Contentful の統合により、Contentful のコンテンツを Web サイト、モバイルアプリ（iOS、Android、Windows）、その他多くのプラットフォームなど、複数のチャネルに配信できます。また、キャンペーンで MoEngage の Content API を介して Contentful からコンテンツを動的に取得することもできます。

# 統合

<Info>
**前提条件**

- Content Delivery API Campaign 機能を備えた Contentful アカウントにアクセスできることを確認してください
</Info>

## ステップ 1: Contentful の API 認証情報を取得する

Contentful アカウントで、次の操作を行います。

1. _Settings > API keys_ に移動します。
API キーをまだ持っていない場合は、新しく作成します。
2. API アクセストークンを作成または取得します。
   1. _Add API key_ を選択します。
   2. 必要な詳細を入力し、適切な環境を選択します。
   3. Save を選択し、_Space ID_ と _Content Delivery API - access token_ をコピーします。
3. Contentful API を通じてアクセスするコンテンツモデルを特定します。

## ステップ 2: MoEngage で Content API を設定する

MoEngage で Content API キャンペーンを作成するには、次の操作を行います。

1. Settings >> Advanced Settings >> Content APIs に移動します
2. _Add Content API_ をクリックします。
![Screenshot 2025-02-17 at 9.04.58 PM.png](/images/partner_34882304994452.png)
3. 詳細を入力します

| キー | 値 |
| --- | --- |
| Method | POST |
| Webhook URL | `https://cdn.contentful.com/spaces/{space_id}/environments/{environment_id}/entries` さまざまなアセットを取得するには、特定の変数を含める必要があります。この例の URL リクエストは、Contentful の Entry エンドポイントを対象としています。このエンドポイントには、`{space_id}` と `{environment_id}`、または `{entry_id}` と `{access_token}` などの変数が必要です。これらは Contentful インスタンスから取得できます。 |
| Headers | Contentful の設定に応じた適切な認証を定義するには、[こちらの Contentful ドキュメント](https://www.contentful.com/developers/docs/references/content-delivery-api/#/introduction/authentication)を参照してください。 |
| Body | コンテンツタイプに適した本文を定義するには、[こちらの Contentful ドキュメント](https://www.contentful.com/developers/docs/references/content-delivery-api/#/introduction/authentication)を参照してください。 |

注:
- この例の Content Delivery API URL は、Contentful で利用可能なエンドポイントの 1 つのみを使用しています。
- 異なる URL を活用することで、さまざまなユースケースを実現できます。たとえば、[Image API](https://www.contentful.com/developers/docs/references/images-api/) を使用して、Contentful に保存されている画像を取得できます。詳細については、[Content Delivery API](https://www.contentful.com/developers/docs/references/content-delivery-api/) を参照してください。

4. Test をクリックし、Save をクリックします。

完了したら、[キャンペーンでの Content API](https://www.moengage.com/docs/user-guide/campaigns-and-channels/getting-started/campaign-content/content-apis#step-2-test-the-content-api) の使用に関する MoEngage のドキュメントを参照してください。

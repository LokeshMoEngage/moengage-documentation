## はじめに

[Dynamic Yield](https://www.dynamicyield.com/) は、デジタルチャネル全体でコンテンツ、商品、オファーを各顧客にアルゴリズムでマッチングし、収益の向上とロイヤルティの促進を実現する Experience Operating System です。

## MoEngage と Dynamic Yield

MoEngage と Dynamic Yield の統合により、パーソナライズされたコンテンツとターゲットを絞ったメールキャンペーンを組み合わせることができます。この統合により、企業は Dynamic Yield のコンテンツブロックとレコメンデーションブロックを MoEngage のメールキャンペーンに直接埋め込むことができます。

Dynamic Yield の AI を活用したパーソナライズと MoEngage のメールマーケティング機能を組み合わせることで、適切なコンテンツを適切な顧客に適切なタイミングで届け、エンゲージメントと ROI を最大化できます。

## 統合

<Info>
  **前提条件**

  - Dynamic Yield ダッシュボードへのアクセス権。
</Info>

Dynamic Yield の Experience Email を使用すると、マーケターはビジュアルなドラッグアンドドロップエディターで、静的なメールを完全にパーソナライズされた体験に変えることができます。

### ステップ 1: Dynamic Yield で Experience Email キャンペーンをデザインする

1. Dynamic Yield ダッシュボードで **Email** > **Experience Emails** に移動し、**Create New** をクリックします。

   ![Create New ボタンが強調表示された Dynamic Yield の Experience Emails 画面](https://support.dynamicyield.com/hc/article_attachments/4404282767377)
2. メールの作成方法を選択します。ゼロから作成する、以前のメールをコピーする、またはテンプレートを使用する、のいずれかです。
3. 見出し領域に、キャンペーンのキャンペーン名、メモ、ラベルを入力します。
4. メールのビルディングブロックを挿入して編集します。画面右側のメニューからドラッグアンドドロップして、要素を追加、配置、編集します（ビルディングブロックをクリックすると、すべてのデザインオプションが表示されます）。メールのビルディングブロックには次のものがあります。
   1. [Recommendations](https://support.dynamicyield.com/hc/en-us/articles/4404013832465-Experience-Email#h_01FQBRAK3MEJCQ9MVGDZ32RA2T): ユーザーに完全にパーソナライズされたレコメンデーションを提供するウィジェット。
   2. [Dynamic Content](https://support.dynamicyield.com/hc/en-us/articles/4404013832465-Experience-Email#h_01FQBRAZ76DCD881CTC1MCJ2AM): オーディエンスごとに異なるプロモーションやメッセージをターゲティングします。
5. 設定を更新します。
   1. URL パラメーターを使用して、分析ソフトウェアでクリックを追跡します（任意）。必要に応じて、表示されているデフォルトにパラメーターを追加します。
   2. アトリビューションウィンドウを選択します。
6. **Save & Exit** をクリックします。コードが生成されるまでは、メールの任意の要素に戻って編集できます。

#### レコメンデーションブロックを設定する

レコメンデーションブロックでは、アルゴリズムとフィルターを設定して、メールが開封されたときにレンダリングされるカスタマイズされたコンテンツを配信できます。レコメンデーションブロックを設定するには、Dynamic Yield の[ヘルプドキュメント](https://support.dynamicyield.com/hc/en-us/articles/4404013832465-Experience-Email#h_01FQBRAK3MEJCQ9MVGDZ32RA2T)の手順に従ってください。

#### 動的コンテンツブロックを設定する

Dynamic Content を使用すると、ユーザーごとに異なるプロモーションやメッセージを届けることができます。ターゲティングは、アフィニティまたはオーディエンスのいずれかに基づいて行えます。メールが開封されると、Dynamic Yield がどのパーソナライズされた体験を配信するかを決定します。動的コンテンツブロックを設定するには、Dynamic Yield の[ヘルプドキュメント](https://support.dynamicyield.com/hc/en-us/articles/4404013832465-Experience-Email#h_01FQBRAZ76DCD881CTC1MCJ2AM)の手順に従ってください。

### ステップ 2: MoEngage と統合するためのコードを準備する

この統合により、Dynamic Yield を活用したパーソナライズされたレコメンデーションウィジェットと動的コンテンツを MoEngage のメールキャンペーンに埋め込むことができます。MoEngage へのキャンペーンの埋め込みは簡単で、1 つの埋め込みコードを MoEngage のメールエディターに貼り付けるだけです。

**Code Parameters** アイコンをクリックして、今後のすべてのメールの ESP マージタグを設定します。

![ESP マージタグのフィールドが表示された Dynamic Yield の Code Parameters モーダル](https://support.dynamicyield.com/hc/article_attachments/4406402305937)

| フィールド | 説明 |
| --- | --- |
| `cuid_type` | [ユーザーを識別した](https://support.dynamicyield.com/hc/en-us/articles/360034332473-Identifying-Users-#identifying-users-via-events-0-1)方法（例: メールアドレス）に合わせて、ユーザー ID のタイプを設定します。 |
| `cuid` | `{{UserAttribute['Email (Standard)']}}` |
| `locale` | `{{UserAttribute['Locale Language']}}` |
| `version` | `{{UserAttribute['version_number']}}` |

メールの準備ができたら、コードを生成して MoEngage キャンペーンに埋め込みます。

1. **Experience Emails** で、キャンペーンの行にある **Generate Code** をクリックします。

   ![Generate Code ボタンが強調表示された Dynamic Yield の Experience Emails リスト](https://support.dynamicyield.com/hc/article_attachments/4404708221457)
2. もう一度 **Generate Code** をクリックします。コードが生成され、メールのプレビューが表示されます。

   ![生成された埋め込みコードとメールのプレビューが表示された Dynamic Yield のコード生成モーダル](https://support.dynamicyield.com/hc/article_attachments/4404016645777)
3. **Copy to Clipboard** をクリックします。

コードを取得したら、新しい MoEngage メールキャンペーンを作成し、メール本文にコードを貼り付けます。

### ステップ 3: 新しい MoEngage キャンペーンを作成する

MoEngage キャンペーンにコードを含めるには、キャンペーン作成のステップ 2 で次の操作を行います。

![Custom HTML editor テンプレートが選択された MoEngage メールキャンペーンのステップ 2](/images/partner_23084176021140.png)

1. **Custom HTML editor** テンプレートを選択し、**Edit/Paste HTML template** をクリックします。
2. ステップ 2 でコピーしたコードを貼り付けます。

**Preview** アイコンをクリックして、レンダリングされたキャンペーンを確認するか、キャンペーンをテストします。

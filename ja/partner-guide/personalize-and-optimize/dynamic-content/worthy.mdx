## はじめに

[Worth AI](https://worthy.ai/) は、AI アルゴリズムを活用して、非常に高速な処理時間、比類のない精度、独自のユーザー体験を提供する審査（アンダーライティング）プラットフォームです。

## MoEngage × Worthy

Worthy と MoEngage の連携により、Worthy のドラッグアンドドロップエディターを使用してパーソナライズされたリッチなアプリ内体験を簡単に作成し、MoEngage キャンペーンを通じて配信できます。

さらに、Worthy は以下を自動的に行います。

- メッセージング用の Connected Content サーバーとセキュアな API を作成します。
- MoEngage に直接表示される分析とクリックトラッキングを備えたアプリ内メッセージを構築します。
- Worthy のドラッグアンドドロップエディターから HTML を自動的にエクスポートし、MoEngage の Custom Code アプリ内メッセージキャンペーンで使用できるようにします。これには、必要な API 接続と設定した動的コンテンツが含まれます。

## ユースケース

- ユーザーのオンボーディング時の選択に基づくカスタムのウェルカム体験
- 特別なイベントやプロモーション向けのアプリ内体験
- アプリ内の行動に基づく顧客フィードバックと評価の収集
- アプリの製品アイデアの迅速なテスト
- リッチなお知らせ、ニュース、コミュニティの最新情報

## 連携

<Info>
**前提条件**

Worthy アカウントの管理者アクセス権が必要です。
</Info>

### ステップ 1: Worthy でパーソナライズされたメッセージを作成する

Worthy ダッシュボードでアプリに移動し、Message Creator を選択して、ユーザーのエンゲージメントに使用するパーソナライズされたメッセージを作成します。

### ステップ 2: MoEngage キャンペーンを作成する

[MoEngage でアプリ内キャンペーンを作成します。](https://www.moengage.com/docs/user-guide/campaigns-and-channels/in-app-message/create/create-in-app-campaign) _Start From Scratch_ タブを選択します。

![Screenshot 2025-02-14 at 4.34.29 PM.png](/images/partner_34807870395540.png)

### ステップ 3: パーソナライズされたメッセージを MoEngage にコピーする

Worthy の Message Creator で、以下を行います。

1. Export をクリックします。
2. エクスポートされたコンテンツをコピーし、キャンペーンのステップ 2 のエディターに貼り付けます。

以上です。パーソナライズされたメッセージをすぐにテストできます。

## はじめに

[Movable Ink](https://movableink.com/) は、デジタルマーケターが魅力的でユニークなビジュアルエクスペリエンスを作成できるクラウドベースのソフトウェアプラットフォームです。Movable Ink プラットフォームには、キャンペーンに組み込めるカスタマイズオプションが用意されています。

## 対象範囲

投票、カウントダウンタイマー、スクラッチなどの Movable Ink の Intelligent Creative 機能を活用して、MoEngage のクリエイティブ機能を拡張できます。Movable Ink と MoEngage の統合により、動的でデータドリブンなメッセージに対するよりバランスの取れたアプローチが可能になり、ユーザーにとって重要な事柄に関するリアルタイムの要素を提供できます。

## メリットとユースケース

Movable Ink と MoEngage の統合は、メッセージング戦略のレベルアップに役立ちます。

1. エンゲージメントの瞬間に、すべての顧客向けにパーソナライズされたコンテンツを自動的に作成します。例:
   - カウントダウンタイマー機能を使用して、大規模なセール（ブラックフライデー、バレンタインデー、ホリデーセールなど）が近づいていることをユーザーに通知します。
   - スクラッチ機能を、プロモーションコードを配布するための楽しくインタラクティブな方法として使用します。
   - API、Web、CSV、CRM ソースなどのリアルタイムデータを使用して、リッチプッシュ通知用のクリエイティブを構築します。
2. データに簡単にアクセスして、顧客の心に響くユニークで革新的なコンテンツを作成します。
3. 顧客プロファイル、在庫、位置情報などのリアルタイムデータを使用して、関連性の高いコンテンツをターゲティングして生成します。

## 統合

<Info>
  **前提条件**

  - Movable Ink アカウントのログイン認証情報。
</Info>

MoEngage では、メール、プッシュ通知、アプリ内キャンペーンに Movable Ink のコンテンツを含めることができます。まず Movable Ink でキャンペーンコンテンツを作成して画像のソース URL を取得し、その URL を MoEngage キャンペーンで参照します。

### ステップ 1: Movable Ink のデータソースを作成する

データソースを作成します。CSV、Web サイトのインポート、API 統合のいずれかを使用できます。データソースの詳細については、[Movable Ink のドキュメント](https://support.movableink.com/hc/en-us) を参照してください。

![Movable Ink のデータソース作成画面](/images/partner_4421164890132.png)

### ステップ 2: Movable Ink プラットフォームでキャンペーンを作成する

Movable Ink のホーム画面からキャンペーンを作成します。email-from-HTML、email-from-image、またはプッシュ、アプリ内、Content Cards（推奨）を含むあらゆるチャネルで使用できるブロックから選択できます。ブロックで利用可能なさまざまなコンテンツオプションも確認することをお勧めします。

![利用可能なキャンペーンタイプが表示された Movable Ink のキャンペーン作成画面](/images/partner_4421153293076.png)

Movable Ink には、テキストや画像などの要素をドラッグ＆ドロップできる使いやすいエディターがあります。データソースにデータを入力済みの場合は、データプロパティを使用して画像を動的に生成できます。パーソナライゼーションの条件に一致しないユーザー向けのフォールバックを作成することもできます。

![パーソナライゼーションデータを画像要素にマッピングしている Movable Ink エディター](/images/partner_4421165077012.png)

完了する前に、動的画像をプレビューし、クエリパラメーターをテストして画像の表示を確認します。完了すると、Movable Ink によって MoEngage で使用できる動的 URL が生成されます。

詳細については、[Movable Ink のドキュメント](https://support.movableink.com/hc/en-us) を参照してください。

### ステップ 3: Movable Ink のコンテンツ URL を取得する

MoEngage キャンペーンに Movable Ink のコンテンツを含めるには、Movable Ink が提供するソース URL を確認します。

1. **Finish & Export** タブに移動し、クリエイティブタグをエクスポートします。
2. クリエイティブタグから画像 URL（`img src`）をコピーします。

![画像 URL が強調表示された Movable Ink の Finish & Export タブ](/images/partner_4421174149652.png)

### ステップ 4: MoEngage キャンペーンで Movable Ink の URL を使用する

MoEngage キャンペーンに Movable Ink の画像 URL を含めるには、キャンペーン作成のステップ 2 で次の操作を行います。

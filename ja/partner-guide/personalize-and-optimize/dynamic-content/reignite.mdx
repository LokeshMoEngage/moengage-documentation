# はじめに

[Reignite](https://www.reignitehq.com/) は、メールマーケターが高度な 1 対 1 のメールパーソナライゼーションを作成・管理できるリアルタイムのメールパーソナライゼーションソフトウェアです。Reignite は、Recipe Builder _、_ AI による商品レコメンデーション、天気と位置情報によるターゲティング、リアルタイムのメールコンテンツを提供しています。すべてのコンテンツはリアルタイムで適応します。

# MoEngage × Reignite

MoEngage と Reignite の統合により、Reignite のパーソナライズされたコンテンツを MoEngage のメールキャンペーンで使用できます。

# 統合

<Info>
  **前提条件**

  Reignite アカウントへのアクセス。
</Info>

## ステップ 1: Reignite でコンテンツを作成する

Reignite ダッシュボードで、次の手順を実行します。

1. MoEngage に追加する画像またはキャンペーンの _tags_ セクションに移動します。\\
   ![b3CwzExHoC52H2YpCUccEocdcRHpbxI9iA.png](/images/partner_23504495694100.png)

<Note>
  画像やリンクの URL に渡される可変データが、MoEngage の jinja 構文になっていることを確認してください。これにより、メールを送信する際に MoEngage がこれらのプレースホルダーを顧客のデータに置き換え、Reignite が各個人の固有のデータを使用して画像をレンダリングします。
</Note>

2. 画像タグを取得したら、それをコピーします。これを MoEngage キャンペーンのテンプレート内に貼り付ける必要があります。

## ステップ 2: MoEngage キャンペーン内でこのコードを使用する

MoEngage キャンペーンにコードを含めるには、キャンペーン作成のステップ 2 で次の手順を実行します。

1. 新しい HTML ブロックを作成します。
2. ステップ 2 でコピーしたコードを HTML ブロック内に貼り付けます。
3. 「@」と入力してパーソナライズする適切な属性を選択し、`MERGE_TAG` を MoEngage のテンプレートコードに置き換えます。
   <CodeGroup>
   ```html HTML
   <Your copied HTML code here>
   ```
   </CodeGroup>

Preview アイコンをクリックしてプレビューを表示するか、キャンペーンをテストすることができます。

## はじめに

[Pega](https://www.pega.com/) は、カスタマーエンゲージメントとデジタルプロセスオートメーションソフトウェアの大手プロバイダーです。そのプラットフォームにより、企業はカスタマーサービス、営業自動化、マーケティング、オペレーション向けのアプリケーションを構築・展開できます。Pega のソリューションは、人工知能（AI）と機械学習（ML）を使用して顧客データを分析し、プロセスを自動化して効率を高め、金融、ヘルスケア、保険、通信などのさまざまな業界で顧客体験を向上させます。

## MoEngage × Pega

Pega システムと MoEngage の統合により、企業はエンドツーエンドの顧客ワークフローとキャンペーンオーケストレーションを自動化できます。Pega のワークフロー自動化機能と MoEngage のキャンペーン管理ツールを組み合わせることで、企業は複雑な多段階のカスタマージャーニーをシームレスに作成、実行、監視でき、顧客ライフサイクル全体を通じて一貫性のある関連性の高いメッセージを確実に届けられます。

## 統合

<Info>
  **前提条件**

  Pega アカウントへの管理者アクセスが必要です。
</Info>

### MoEngage キャンペーンに Pega のコンテンツを埋め込む

MoEngage の Content API を使用すると、Pega によって生成されたオファーを MoEngage キャンペーン内に動的に追加し、よりパーソナライズされたエクスペリエンスを提供できます。

#### ステップ 1: MoEngage Content API を設定する

1. Settings APIs Content API に移動します。
   ![Screenshot\_2022-03-08\_at\_6.21.00\_PM.png](/images/partner_29522196676628.png)
2. ここに Pega API の詳細を追加します。ユースケースに最適な API を選択するには、[Pega API docs](https://docs.pega.com/bundle/platform/page/platform/data-integration/pega-api-services.html) を参照してください。
3. 「Save」をクリックし、成功のレスポンスが表示されたら「Done」をクリックします。
   <Note>
     API をテストすることもできます。API をテストするには、Content API のアクションメニューから「Test」をクリックします。API のレスポンスを確認して検証できます。
   </Note>

#### ステップ 2: MoEngage キャンペーン内にコンテンツを表示する

MoEngage キャンペーンでこの API を使用するには、次の手順を実行します。

1. キャンペーン作成のステップ 2 で、`@` と入力します。
2. ポップアップで、ステップ 1 で設定した Pega Content API を選択できます。
3. [MoEngage Templating Language](https://www.moengage.com/docs/user-guide/campaigns-and-channels/getting-started/message-personalization/jinja-templating-language) を使用して API レスポンスを解析し、そのコンテンツをキャンペーンで使用できます。
   <Note>
     Preview タブをクリックすると、リアルタイムのパーソナライゼーションが適用されたキャンペーンを確認できます。
   </Note>
4. キャンペーンを公開します。

## Storyly

[Storyly](https://storyly.io/) は、ストーリーを埋め込むためのユーザーエンゲージメントプラットフォームです。Storyly は、モバイルブランドがモバイル画面の限界を超えてオーディエンスとエンゲージし、統合後は開発作業なしで魅力的なエクスペリエンスを作成できるようにすることで、マーケティング戦略を強化します。

## MoEngage × Storyly

MoEngage × Storyly 統合により、次のことが可能になります。

1. Storyly の [Create Audiences](https://docs.storyly.io/page/create-audiences-from-the-outcome-of-interactive-components) を使用して、Storyly のオーディエンスを MoEngage に送信する
2. [MoEngage の Custom destinations](https://www.moengage.com/docs/user-guide/data/exports/segments/outbound-segment-sync) を使用して、MoEngage のセグメントを Storyly に送信する

## 統合

<Info>
  **前提条件**

  - Storyly アカウントを持っていることを確認してください。
  - Storyly SDK とアプリの間でカスタムパラメーターを設定しておく必要があります。[詳細はこちら](https://docs.storyly.io/page/exporting-audiences-to-moengage)。
  - MoEngage アカウントで Custom destinations が有効になっていることを確認してください。
</Info>

## Storyly のオーディエンスを MoEngage に同期する

### ステップ 1: Storyly で MoEngage を設定する

まず、Storyly Dashboard で MoEngage アカウントを接続します。

1. Storyly Dashboard で **Settings** に移動し、**Integrations** タブを見つけます。
2. **Integrations** の下に **MoEngage** が表示されます。**Connect** をクリックしてください。
   ![1280](https://files.readme.io/f8b5332-6.png)

**Connect** をクリックすると、次の 3 つのフィールドへの入力を求められます。

| フィールド名 | 説明 |
| --- | --- |
| Integration Name | 複数の統合を持つ場合があるため、それぞれを区別できるように、統合に任意の名前を付けることができます。 |
| Workspace ID | API ID は Workspace ID です。MoEngage アカウントの Workspace ID は、**Settings -\> Account -\> APIs -\> Workspace ID** で確認できます。MoEngage アカウントの Data API ID と Workspace ID は同じです。 |
| API Key | MoEngage アカウントの Data API キーは、**Settings -\> Account -\> APIs -\> API keys -\> Data** API 設定で確認できます。 |

![1280](https://files.readme.io/debb78e-7.png)

3. **DATA API ID** と **DATA API Key** をコピーし、**Storyly Dashboard** の対応するフィールドに貼り付けます。
   ![1280](https://files.readme.io/52e9812-8.png)
4. **Connect MoEngage** をクリックすると、統合は完了です。
   ![1280](https://files.readme.io/1fb8c2e-9.png)

これ以降、上記のとおり、Storyly でインタラクティブコンポーネントの結果からオーディエンスを作成した場合は、それらのオーディエンスを MoEngage にエクスポートするオプションが表示されます。

### ステップ 2: オーディエンスを MoEngage に送信する

1. **Settings \> Data Management \> Audiences** で、作成したオーディエンスを確認できます。**Export** ボタンをクリックすると、**Send to MoEngage** オプションが表示されます。
   ![1280](https://files.readme.io/bd7028b-5.png)
2. **Send to MoEngage** をクリックすると、使用する統合を選択し、MoEngage に表示されるカスタム属性の **Key Title** を指定するよう求められます。
3. **Start Process** をクリックすると、オーディエンスのサイズに応じて、処理の完了まで数分かかります。
   ![1280](https://files.readme.io/81f4652-12.png)

### ステップ 3: Storyly のオーディエンスからカスタムセグメントを作成する

1. 処理が完了したら、**MoEngage Dashboard** に移動し、左側のペインから **Segments** に移動して **Create Segment** オプションをクリックします。
2. その画面で **User Property** をクリックし、下にスクロールして **Tracked Custom Attribute** セクションで Storyly からエクスポートしたカスタム属性を見つけます。
   ![1280](https://files.readme.io/892c981-13.png)
3. カスタム属性を選択した後、**"is"** を選択して Storyly Dashboard 上のオーディエンス名を入力すると、そのオーディエンスのすべてのユーザーを含むセグメントを作成できます。

## MoEngage のセグメントを Storyly に同期する

### ステップ 1: MoEngage 用の新しいオーディエンスを作成する

1. _Storyly Dashboard_ の _Audiences_ タブに移動し、右上の _\+ New Audience_ をクリックします。_Create Audience for MoEngage_ オプションを選択します。オーディエンスに名前を付けて、_Continue_ をクリックします。
   ![Screenshot\_2023-04-14\_at\_12.48.24\_PM.png](/images/partner_14860692138260.png)
2. _Storyly_ によって、オーディエンスの **Key** と、**Value** としての固有のトークンが生成されます。これらの値をコピーしてください。統合を設定する際に MoEngage Dashboard に貼り付けます。

### ステップ 2: MoEngage でカスタムデスティネーションを設定する

1. _App Marketplace \>\> Custom Destinations_ に移動します。
   ![Screenshot\_2023-04-14\_at\_12.43.35\_PM.png](/images/partner_14860636958484.png)
2. _Add Custom Destination_ をクリックします。
3. _Destination name_ に _Storyly_ を追加し、説明（任意）を追加します。
   ![Screenshot\_2023-04-14\_at\_12.44.25\_PM.png](/images/partner_14860669866516.png)
4. _Integrate_ タブに移動し、_Add Integration_ をクリックします。
   ![Screenshot\_2023-04-14\_at\_12.45.29\_PM.png](/images/partner_14860673919252.png)
5. MoEngage Dashboard に戻り、次の詳細を入力します。
   - **Integration name:** 任意の名前を付けることができます。
   - **Method:** _POST_ オプションを選択します。
   - **URL endpoint:** 次のエンドポイントを入力します: `https://core.storyly.io/audience/moengage/export-callback`
   - **Parameters:** _\+KV pair_ をクリックし、前のステップで Storyly Dashboard からコピーした _Key_ と _Value_ を貼り付けます。
   - **User identifier:** カスタムパラメーターを介してすでに Storyly に渡している識別子（ID、メールアドレスなど）を選択します。次に、_Destination identifier_ フィールドに _identity_ と入力します。
   ![Screenshot\_2023-04-14\_at\_12.52.14\_PM.png](/images/partner_14860747067924.png)
6. Next をクリックします。統合をテストするオプションが表示されます。_User value_ を入力して _Test_ ボタンをクリックします。テストが成功すると、成功メッセージが表示されます。
7. _Add Integration_ を直接クリックして、テストをスキップすることもできます。
   ![Screenshot\_2023-04-14\_at\_12.55.12\_PM.png](/images/partner_14860736611860.png)

### ステップ 3: セグメントを Storyly に送信する

1. _Segment_ に移動し、インポートするセグメントの右横にある 3 つのドットをクリックして、_Sync Segment_ オプションを選択します。
   ![Screenshot\_2023-04-14\_at\_1.11.57\_PM.png](/images/partner_14860894636820.png)
2. _Destination_ として、設定したカスタムデスティネーションを選択します。
   ![Screenshot\_2023-04-14\_at\_1.12.06\_PM.png](/images/partner_14860895243796.png)
3. _Sync Frequency_ とその他の関連する詳細を選択します。
4. _Save Sync_ をクリックします。

これ以降、MoEngage のセグメントは Storyly のオーディエンスに同期されます。同期されたすべてのセグメントは、_Synced Segments_ タブで確認できます。

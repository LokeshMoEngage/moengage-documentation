## はじめに

[Wyng](https://www.wyng.com/) を使用すると、適切なタイミングで消費者のエンゲージメントを高め、嗜好やその他のゼロパーティデータを収集し、リアルタイムでパーソナライズするインタラクティブなデジタル体験（クイズ、プリファレンスセンター、プロモーションなど）を簡単に構築できます。

## MoEngage × Wyng

MoEngage と Wyng の連携により、Wyng の体験を通じて獲得したゼロパーティデータを活用して、MoEngage のキャンペーンと Flows でのインタラクションをパーソナライズできます。Wyng はプリファレンスセンターを提供することもでき、消費者はブランドと共有するデータや嗜好（コミュニケーションの希望を含む）を管理できます。

## 連携

<Info>
  **前提条件**

  Wyng アカウントにアクセスできることを確認してください。
</Info>

### ステップ 1: MoEngage エンドポイントを取得する

専用エンドポイントの取得については、MoEngage の Customer Success Manager にお問い合わせください。MoEngage Connected Sources を使用して独自のマッパーを定義できます。

### ステップ 2: Wyng で Webhook を設定する

以下の手順に従って Wyng で Webhook を作成します。詳細については、[Wyng のドキュメント](https://help.wyng.com/s/article/Send-form-entries-through-webhook-integration)を参照してください。Wyng ダッシュボードで以下を行います。

1. _More_ \>\> Integrations に移動します。
2. Add Integrations をクリックします。
   ![Screenshot 2025-02-14 at 3.52.52 PM.png](/images/partner_34807488534164.png)
3. Webhooks をクリックします。
   ![Screenshot 2025-02-14 at 3.44.28 PM.png](/images/partner_34807516389012.png)
4. Webhook の詳細を入力します。
   | フィールド | 説明 |
   | --- | --- |
   | Webhook name | Webhook 名を入力します。MoEngage という名前にできます |
   | Data source | Wyng の既存のデータソースを 1 つ選択します |
   | Data destination | 送信先として URL endpoint を選択します |
   | Choose experience | MoEngage と共有する既存のフォーム/体験データを 1 つ選択します |
   | URL | Customer Success Manager から提供された MoEngage エンドポイントを入力します |
   | Custom Headers | 以下のカスタムヘッダーを追加します。<br /><br />**Content-Type**: `application/json`<br />**Authorization**: オンラインの [Basic Auth Header Generator](https://www.debugbear.com/basic-auth-header-generator) ツールなどを使用して Basic トークンを取得します。ユーザー名に Workspace ID、パスワードに Data API Key を入力します（MoEngage Dashboard \>\> Settings \>\> APIs）。最終的なトークンは次のようになります: `Basic Qk5CR1NNNUR4eHh4eHhWQ1hSRFJEWTdSOlFsWHVoTHVaeHh4eHh4QWQrQnBYUEotNw==` これをここに値として貼り付けます。 |
   | Request Body | リクエストボディを定義します。MoEngage にユーザー属性またはイベント属性として送信するフィールドを追加します。<br /><br /><img src="/images/partner_34807488535188.png" alt="Screenshot 2025-02-14 at 3.48.27 PM.png" /> |
5. 「Save」をクリックして Webhook を追加します。

### ステップ 3: MoEngage でターゲットキャンペーンを送信する

ユーザーとイベントが MoEngage に表示され始めます。これで、ユーザーに対してイベントトリガー型キャンペーンを実行できます。

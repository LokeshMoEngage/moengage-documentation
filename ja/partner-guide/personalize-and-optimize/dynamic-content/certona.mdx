# はじめに

[Certona](https://monetate.com/) プラットフォームは、カスタマーライフサイクル全体にわたってパーソナライズを推進します。高度に個別化されたメールキャンペーンから機械学習を活用した商品レコメンデーションまで、Certona はパーソナライズの力を最大限に活用できるよう支援します。

# MoEngage × Certona

MoEngage と Certona の統合では、Content API を介して Certona の機械学習による商品レコメンデーションを MoEngage キャンペーンで活用します。

# 統合

<Info>
  **前提条件**

  - Certona アカウントを持っていることを確認してください。
  - Certona REST API エンドポイントにアクセスできることを確認してください。このエンドポイントは、ユーザー ID に基づいてレコメンドコンテンツを取得するために、MoEngage Content API で直接使用されます。
</Info>

Certona の REST API を使用して、パーソナライズされたコンテンツをキャンペーンに挿入します。これは、次の Certona REST API エンドポイントを MoEngage Content API に追加することで実現できます。

### ステップ 1: MoEngage で Content API を追加する

MoEngage ダッシュボードにログインし、次の手順に従います。

1. **Settings** -\> **Advanced settings** -\> **Content API** に移動します。Content API 画面の右上にある **\+ Add content API** をクリックします。
   ![ContentAPI\_Navogation.png](/images/partner_21979648411668.png)
2. Certona API をエンドポイント URL に追加します。
   ![Screenshot\_2022-10-18\_at\_3.33.26\_PM.png](/images/partner_10170418355732.png)
   Test ボタンをクリックして API をテストすることもできます。API レスポンスを確認して検証できます。

### ステップ 2: MoEngage キャンペーンで Content API を使用する

これで、これらの Content API をキャンペーンで使用できるようになりました。Content API の詳細については、[こちら](https://www.moengage.com/docs/user-guide/campaigns-and-channels/getting-started/campaign-content/content-apis)を参照してください。

1. キャンペーン作成のステップ 2 で、@ を入力します。
2. ポップアップで、ステップ 2 で設定した Certona Content API を選択できます。
3. [MoEngage Templating Language](https://www.moengage.com/docs/user-guide/campaigns-and-channels/getting-started/message-personalization/jinja-templating-language) を使用して API レスポンスを解析し、そのコンテンツをキャンペーンで使用できます。
   ![Screenshot\_2022-10-18\_at\_3.41.01\_PM.png](/images/partner_10170418825108.png)
   Preview タブをクリックすると、リアルタイムのパーソナライズが適用されたキャンペーンを確認できます。

# はじめに

[Personalize.AI](https://www.zs.com/solutions/artificial-intelligence-and-analytics/personalize-ai) は MoEngage と提携し、MoEngage を通じて送信されるパーソナライズされたメッセージやオファーを配信することで、増分収益を生み出します。

# MoEngage × Personalise.AI

MoEngage と Personalize.AI の統合により、Content API を使用して Personalise.AI のコンテンツを MoEngage キャンペーンで使用できます。

# ユースケース

- 柔軟な層別化を含むテストを展開し、顧客のフィードバックから成果を導き出す
- 施策、タイミング、コンテンツを含む、アイテムやオファーのパーソナライズされたレコメンデーションを提供する
- 優先すべき目標を特定し、最適なオーディエンスをターゲティングして離脱したユーザーを再エンゲージする
- 位置情報データを活用して、新規オープンした店舗に適したオーディエンスを見つける
- 類似モデリングを使用して、新規ユーザーの限られたデータを補完し、最も関連性の高いレコメンデーションとマッチングする
- 顧客のライフサイクル全体を通じてエンゲージメントを高める適切な方法を特定する
- 顧客の解約可能性を事前に評価してリスクスコアを割り当て、解約の早期兆候を発見する
- パーソナライズされた介入で顧客をターゲティングし、非アクティブになるのを防ぐ

# 統合

<Info>
  **前提条件**

  Personalise.AI アカウントにアクセスできることを確認してください。
</Info>

Content API を使用して Personalise.AI に接続し、その動的コンテンツを MoEngage キャンペーンで使用できます。詳細については、[MoEngage Content APIs](https://www.moengage.com/docs/user-guide/campaigns-and-channels/getting-started/campaign-content/content-apis#step-2-use-content-apis-in-campaigns) のドキュメントを参照してください。

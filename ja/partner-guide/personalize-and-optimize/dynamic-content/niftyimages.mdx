# はじめに

NiftyImages は、マーケターがメールキャンペーン向けに動的でパーソナライズされたコンテンツを作成できるプラットフォームです。パーソナライズ画像、カウントダウンタイマー、ライブソーシャルフィード、ルールベースの画像など、メールのリアルタイムパーソナライゼーションを提供します。

# MoEngage × NiftyImages

MoEngage と NiftyImages の統合により、パーソナライズ画像、カウントダウンタイマー、動的タイマー、ルールベースの画像、データソース画像、リアルタイム画像など、複数の動的要素を表示できます。

# 統合

<Info>
  **前提条件**

  NiftyImages ダッシュボードへのアクセス。
</Info>

## ステップ 1: NiftyImages で動的要素を作成する

1. NiftyImages ダッシュボードに移動し、Personalized Image を作成します。\\ <img src="/images/partner_23141609149460.png" />
2. 画像を作成したら、画像を保存して共有 URL を取得できます。\\ <img src="/images/partner_23141662212756.png" />
3. このコードをコピーします。これを MoEngage キャンペーンのテンプレート内に貼り付ける必要があります。

## ステップ 2: MoEngage キャンペーン内でこのコードを使用する

MoEngage キャンペーンに NiftyImages のコードを含めるには、キャンペーン作成のステップ 2 で次の手順を実行します。

![](/images/partner_23141609168660.png)

1. 新しい HTML ブロックを作成します。
2. ステップ 2 でコピーしたコードを HTML ブロック内に貼り付けます。Dynamic Image を挿入することもできます。
3. 「@」と入力してパーソナライズする適切な属性を選択し、`MERGE_TAG` を MoEngage のテンプレートコードに置き換えます。
   <CodeGroup>
   ```html HTML wrap
   <https://img1.niftyimages.com/sxxh/jc0i/xxx5?name={{UserAttribute['First Name']}}>
   ```
   </CodeGroup>

Preview アイコンをクリックしてプレビューを表示するか、キャンペーンをテストすることができます。

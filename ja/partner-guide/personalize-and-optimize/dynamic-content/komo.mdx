[Komo](https://www.komo.tech/) は、ゲーミフィケーション、インタラクティブコンテンツ、コンテスト、賞品、ロイヤルティを専門とするカスタマーエンゲージメントプラットフォームです。

## MoEngage × Komo

MoEngage と Komo の統合により、Komo Engagement Hubs を通じてファーストパーティおよびゼロパーティのデータを収集できます。これらのハブは、インタラクティブコンテンツやゲーミフィケーション機能を提供する動的なマイクロサイトです。これらのハブから収集されたユーザーデータは、MoEngage Connected Sources に送信されます。

- Komo で収集したファーストパーティおよびゼロパーティのユーザーデータを MoEngage にリアルタイムで取り込みます。
- ユーザーがアンケート、投票、クイズの質問に回答した際の市場調査データやユーザーの好みのデータを取り込みます。
- ユーザーがエンゲージメントを続け、自身に関するデータをさらに共有するにつれて、MoEngage 内のユーザープロファイルを段階的に構築します。
- MoEngage から送信されるトランザクションメールのデザインを標準化します。

## ユースケース

1. **データ収集 - フォーム送信による市場調査**: ユーザーが Komo でカスタマイズ可能なデータ収集フォームを送信すると、Webhook でマッピングされた Komo のフィールドが MoEngage に渡されます。
2. **市場調査**: Komo は、ユーザーがクイズの質問、投票、性格診断、スワイパーなどに回答した際に収集された市場調査データを渡すことができます。このデータにより、フォーム送信で収集されたデータ以上にユーザーのプロファイルを充実させることができます。

## 統合

<Info>
  **前提条件**

  Komo アカウントにアクセスできることを確認してください。
</Info>

### ステップ 1: Komo Engagement Hub とカードを公開する

データ収集フォームを含むカードを少なくとも 1 つ持つ Komo Engagement Hub を公開する必要があります。公開後、ユーザーエクスペリエンスをエンドツーエンドでテストし、統合が正しく機能していることを確認できます。

![Screenshot 2025-02-17 at 9.19.21 PM.png](/images/partner_34883085032852.png)

### ステップ 2: MoEngage Connected Sources のエンドポイントを取得する

MoEngage のカスタマーサクセスマネージャーに相談し、Connected Source 専用のエンドポイントを取得してください。Connected Source の作成時に設定を共有する必要があります。

### ステップ 3: Komo で Webhook を設定する

Komo ダッシュボードで、次の手順を実行します。

1. **Hub Settings** タブに移動します。
2. **Integrations** セクションを選択します。
3. **webhooks** を選択します。
4. **Connect** をクリックします。

![Screenshot 2025-02-17 at 9.23.29 PM.png](/images/partner_34883100172564.png)

[Komo Webhook documentation](https://knowledge.komo.tech/integrations-webhooks) に記載されている手順に従います。フィルターと条件を設定したら、次の項目を設定します。

![Screenshot 2025-02-17 at 9.30.54 PM.png](/images/partner_34883100175124.png)

- **URL**: ステップ 2 で受け取ったエンドポイントです。
- **Headers**:
  - **Content-Type**: `application/json`
  - **Authorization**: オンラインの Basic Auth Header Generator ツールを使用して Basic トークンを取得します。ユーザー名に Workspace ID を、パスワードに Data API Key を入力します（MoEngage Dashboard \> Settings \> APIs）。最終的なトークンは次のようになります: `Basic Qk5CR1NNNUR4eHh4eHhWQ1hSRFJEWTdSOlFsWHVoTHVaeHh4eHh4QWQrQnBYUEotNw==`。これを値として貼り付けます。
  - **Body**: ユースケースに応じて Body を定義します。

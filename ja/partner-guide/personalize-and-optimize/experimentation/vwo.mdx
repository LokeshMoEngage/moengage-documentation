# はじめに

[VWO](https://vwo.com/) は、クライアントがインサイトを簡単に発見し、製品のアイデアをテストできるようにすることで、主要なビジネス指標を改善するコネクテッドプラットフォームです。マーケターは製品や機能の体験をテストできます。

# MoEngage × VWO

MoEngage × VWO の連携により、VWO アカウントのウェブサイト訪問者データを MoEngage アカウントに送り、さらに分析できます。これにより、VWO のテストにおけるバリエーションのパラメーターを分析してパフォーマンスを評価し、MoEngage キャンペーンを使用してより適切にターゲティングできます。

# 連携

<Info>
  **前提条件**

  - VWO アカウントにアクセスできることを確認してください。
  - MoEngage の Workspace ID にアクセスできることを確認してください。Workspace ID を取得するには、Settings \>\> General Settings に移動します。
</Info>

## ステップ 1: ウェブページにデータトラッキングを追加する

MoEngage でテスト結果を分析するには、[こちらのドキュメント](https://www.moengage.com/docs/developer-guide/web-sdk/web-sdk-integration/basic-integration/web-sdk-integration)の説明に従って MoEngage 用のデータトラッキングを設定する必要があります。データトラッキングを追加したら、ネットワークコールを使用して VWO から MoEngage に送信されたデータを特定し、確認できます。確認するには、以下の手順を実行します。

1. VWO キャンペーンが実行されているページで右クリックし、_Inspect element_ を選択します。
2. _Network_ タブで _MoEngage_ を検索して、ネットワークコールをフィルタリングします。
3. ネットワークコールを表示するには、ページの再読み込みが必要な場合があります。
4. ネットワークコールを選択して詳細を表示します。
5. _Payload_ \>\> _Request payload_ セクションに移動します。展開して、送信されているデータの詳細を表示します。<img src="https://help.vwo.com/hc/article_attachments/5878286173337/Network_Call.png" alt="Network_Call.png" />

### 送信されるデータの仕様

VWO からのデータは、以下の仕様で MoEngage に送信されます。

```json
"vwo":[["exp_name,var_name"]]
```

ここで、`exp_name` は VWO のキャンペーン名、`var_name` はバリエーション名です。

## ステップ 2: VWO アカウントで連携を有効にする

連携は、アカウントレベルとキャンペーンレベルの両方で有効にできます。

**A. アカウントレベル -** デフォルトで、連携がすべてのキャンペーン（今後のキャンペーンを含む）に適用されることを意味します。

アカウントレベルで MoEngage 連携を有効にするには、以下を行います。

1. VWO アカウントにログインします。
2. _Integrations_ に移動し、MoEngage を検索します。
3. MoEngage タイルを選択し、_Enable Now_ をクリックして有効にします。<img src="https://help.vwo.com/hc/article_attachments/5859527210137/Integrated.png" alt="Integrated.png" />

**B. キャンペーンレベル -** 連携が特定のキャンペーンに適用されることを意味します。

既存のキャンペーンで MoEngage 連携を有効にするには、キャンペーン設定を編集する必要があります。

1. _Settings \>\> Others_ に移動します。
2. _Integrate_ with third-party products セクションを展開し、_MoEngage_ を選択します。

![Integrate\_with\_Third-party\_apps.png](https://help.vwo.com/hc/article_attachments/5859491532697/Integrate_with_Third-party_apps.png)

これで、キャンペーンレベルで VWO のテストデータを MoEngage に送信し始めることができます。

## ステップ 3: MoEngage で VWO データを分析する

MoEngage でデータを分析またはセグメント化するには、以下を行います。

1. Segment \>\> Create segment に移動します。
2. User Behaviour で、イベントのドロップダウンから **VWO** を選択します。<img src="https://help.vwo.com/hc/article_attachments/5859501221273/Tracked_User_Events.png" alt="Tracked_User_Events.png" /> 
3. ウェブサイトにアクセスした訪問者について追跡する訪問回数と、訪問が行われた期間を指定します。 
   **注-** ここでの訪問回数は、VWO キャンペーンに含まれるページへの訪問のみを厳密に対象とします。
4. 属性フィルターで `vwo_campaign_name` または `vwo_variation_name` を選択すると、特定の VWO キャンペーンまたはバリエーション名に基づいてユーザーをさらにセグメント化できます。
   <Frame>
     ![Vwo](/images/vwo.png)
   </Frame>
5. 完了したら、これを MoEngage のカスタムセグメントとして保存するか、これらのユーザーをターゲットとするキャンペーンを作成できます。

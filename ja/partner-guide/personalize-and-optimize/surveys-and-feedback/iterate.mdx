# はじめに

[Iterate](https://iteratehq.com/) は、訪問者、顧客、ユーザーから直接学ぶことができるリサーチツールのスイートです。Iterate を使用すると、メールアンケートの送信、アンケートへのリンクの共有、ウェブサイトやモバイルアプリ製品内でのアンケートの直接表示を簡単に行えます。

# MoEngage × Iterate

MoEngage と Iterate を使用すると、メール、プッシュ、ウェブ、アプリ内メッセージなど、MoEngage のさまざまなキャンペーンタイプを通じて Iterate のアンケートへのリンクを送信し、顧客データを強化できます。この連携により、以下のことができます。

- **すべてのチャネルでアンケートを展開する:** Iterate は MoEngage のチャネルとシームレスに連携し、メールにアンケートを埋め込んだり、アプリやウェブサイト内のアプリ内メッセージやオンサイトメッセージとしてネイティブに展開したりできます。
- **回答を MoEngage の顧客プロファイルに送信する:** Iterate のアンケートは、回答を MoEngage に送り返してカスタムユーザープロパティとして設定することで、顧客プロファイルと連携します。このデータを使用して、カスタムセグメントを作成し、パーソナライズされたキャンペーンを実現できます。

# 連携

<Info>
  - Iterate でアンケートを作成する権限があることを確認してください。
  - MoEngage ダッシュボードにアクセスできることを確認してください。
</Info>

## ステップ 1: Iterate で MoEngage 連携を設定する

![](https://downloads.intercomcdn.com/i/o/701651657/275e4931f6062769c1509cce/image.png)

MoEngage に接続するには、MoEngage ダッシュボードで確認できる MoEngage の Data API ID と Data API Key が必要です。MoEngage を Iterate に接続するには、Iterate アカウントにログインして会社の設定ページに移動し、「API & Integrations」セクションにそれらを入力します。

| **フィールド** | **説明** |
| --- | --- |
| App ID and Data API ID | MoEngage アカウントの Workspace ID は、**Settings - \> Account -\> APIs -\>Workspace ID** で確認できます。MoEngage アカウントの Data API ID と Workspace ID は同じです。 |
| Data Center ID | MoEngage のデータクラスターのリージョン。[詳細はこちら](https://www.moengage.com/docs/user-guide/data/key-concepts/data-centers-in-moengage) 例: 01、02、03、04 |
| Data API Key | MoEngage アカウントの Data API キーは、**Settings** - \> **Account** -\> **APIs** -\> **API keys** \>**Data** の API 設定で確認できます。 |

## ステップ 2: Iterate でアンケートを作成する

Iterate のアンケートは、MoEngage を介して 3 つの方法で配信できます。

- [MoEngage のメールキャンペーンを介したアンケートの配信](http://help.iteratehq.com/en/articles/8496383-delivering-surveys-via-moengage-email-messages)
- [MoEngage のアプリ内メッセージを介したアンケートの配信](http://help.iteratehq.com/en/articles/8392598-delivering-surveys-via-moengage-in-app-messages)
- [MoEngage のオンサイトメッセージを介したアンケートの配信](http://help.iteratehq.com/en/articles/8496381-delivering-surveys-via-moengage-on-site-messages)

## ユーザー属性名をカスタマイズする

![](https://downloads.intercomcdn.com/i/o/145216708/1a8f5605ddf9292038088e3c/Screen+Shot+2019-09-01+at+5.15.58+PM.png)

デフォルトでは、質問に対して作成されるユーザー属性はその質問文と同じです。たとえば、「Overall, how satisfied are you with Iterate?」という質問文の質問は、MoEngage ではユーザー属性 `Overall, how satisfied are you with Iterate?` として追加されます。場合によっては、これをカスタマイズしたいことがあります。この例では、質問の属性名を `CSAT Score`（顧客満足度スコア）に変更します。

そのためには、前のステップで _Customize user attribute names_ をクリックし、任意のカスタム名を入力します。

## モバイルアプリまたはウェブサイトの回答から MoEngage にデータを入力する

モバイルアプリのアンケート（いずれかの SDK を使用）やウェブサイトのアンケートから MoEngage にアンケートデータを入力するのも同様に簡単です。アンケートに関連付けるデータとしてユーザーのメールアドレスを渡し、アンケートダッシュボードの Integrations ドロップダウンメニューで MoEngage 連携を有効にする必要があります。Iterate のコールバックで MoEngage のイベントを送信できます。

アンケート内でユーザーにデータを関連付ける方法については、以下を参照してください。

- [アプリ内モバイルアンケート](https://help.iteratehq.com/en/articles/4457590-associating-data-with-a-user-or-response)
- [ウェブサイトアンケート](https://help.iteratehq.com/en/articles/2835009-associating-data-with-a-user-or-response)

# はじめに

[Blitzllama](https://www.blitzllama.com/) の GPT を活用したフィードバック分析は、アンケートの回答をトピックや感情に自動的に分類し、推奨事項を提示します。 

# MoEngage × Blitzllama

MoEngage と Blitzllama の連携により、MoEngage Connector Campaigns を介して、MoEngage の既存のユーザーセグメントを Blitzllama に送信できます。コホートを Blitzllama に同期することで、同じユーザーグループについてより深く知ることができます。

# 連携

<Info>
  **前提条件**
  
  - Blitzllama アカウントがあることを確認してください。
  - Blitzllama の API にアクセスできることを確認してください。
</Info>

## ステップ 1: MoEngage でコネクタキャンペーンを作成する 

MoEngage でコネクタキャンペーンを作成するには、以下を行います。

1. Create Campaign >> Connectors >> Custom に移動し、ニーズに最も適した配信タイプを選択します。![Screenshot_2022-02-21_at_10.48.46_PM.png](/images/partner_30317159032980.png)
2. キャンペーンのステップ 2 で、以下を行います。 
   - メソッドとして POST を選択します。
   - Webhook URL として `<Your Blitzllama dashboard URL>` を追加します。
   - Headers で以下を設定します。 
     - Content-Type を `application/json` に設定します。
     - 値 `<to be fetched from your Blitzllama dashboard>` を指定して `x-api-key` を追加します。
   - Body で Raw を選択し、リクエストをコピーして貼り付けます。参考として [Blitzllama のドキュメント](https://documentation.blitzllama.com/sdk/api)を参照できます。 
3. この時点で、キャンペーンをテストして送信する準備が整っています。Create Connector Campaign のステップ 2 で利用できる Test 機能を使用して、コネクタの設定をテストすることもできます。![Screen_Shot_2022-02-22_at_11.12.42_AM.png](/images/partner_30317172449556.png)

テストユーザーがメッセージを正常に受信した場合、設定は完了です。そのままキャンペーンを公開できます。

## ステップ 2: Blitzllama で同期したコホートを使用する

キャンペーンが実行されるとすぐに、Blitzllama でセグメント（コホート）を確認できます。これらのコホートは、さらにフィルタリングできない点を除き、他のすべてのコホートと同様に使用できます。  
  
上記のいずれかの手順で問題が発生した場合は、お気軽に tech@blitzllama.com までメールでお問い合わせいただくか、サポートチャットでご連絡ください。

## はじめに

[Crowdin](https://crowdin.com/) は、ローカリゼーション管理のためのクラウドベースのソフトウェアです。Crowdin はアプリのユーザーインターフェイス、ウェブサイト、マーケティング、サポートコンテンツのローカリゼーションを効率化し、複数の言語でコンテンツを配信できるようにします。

## MoEngage と Crowdin

MoEngage と Crowdin の連携により、メールテンプレートとコンテンツブロックを翻訳できます。また、MoEngage アカウントから Crowdin プロジェクトにコンテンツとクリエイティブを同期し、翻訳を MoEngage に戻すこともできます。

## 連携

<Info>
  **前提条件**

  - Crowdin アカウント。
  - Crowdin の翻訳プロジェクトへのアクセス権。Crowdin ダッシュボードからサインアップしてプロジェクトを作成できます。
</Info>

### ステップ 1: Crowdin または Crowdin Enterprise で MoEngage アプリを設定する

#### Crowdin

1. [Crowdin マーケットプレイスの MoEngage アプリ](https://store.crowdin.com/moengage)に移動します。
2. **Install** をクリックしてアカウントに追加します。
3. MoEngage のコンテンツローカリゼーション用に作成したプロジェクトを開きます。
4. **Settings** \> **Integrations** に移動します。
5. **Applications** セクションで、MoEngage アプリをクリックします。
6. ダイアログボックスで、MoEngage の認証情報（データセンター、Workspace ID、Data API キー）を入力します。
   | フィールド | 説明 |
   | --- | --- |
   | App ID | MoEngage の Workspace ID。**Settings** \> **Account** \> **APIs** \> **Workspace ID** で確認できます。 |
   | Data API ID | MoEngage の Data API ID。Workspace ID と同じです。 |
   | Data API Key | MoEngage の Data API キー。**Settings** \> **App Settings** \> **APIs** \> **API Keys** \> **Data** で確認できます。 |
   | Data Center Name | MoEngage の URL `https://dashboard-OX.moengage.com` を確認します。ダッシュボードの値（`DC-01`、`DC-02`、`DC-03`、または `DC-04`）に基づいて、Crowdin で対応する値を設定します。詳細については、[MoEngage のデータセンター](https://www.moengage.com/docs/user-guide/data/key-concepts/data-centers-in-moengage)を参照してください。 |
   ![4 つのフィールドが入力された Crowdin の MoEngage アプリ認証情報ダイアログ](/images/partner_10360750343188.png)
7. **Log in with MoEngage** をクリックします。

#### Crowdin Enterprise

1. **Workspace** \> **Marketplace** に移動します。
2. MoEngage アプリの **Install** をクリックして組織に追加します。
3. MoEngage のコンテンツローカリゼーション用のプロジェクトを開きます。
4. **Applications** \> **Custom** に移動します。
5. MoEngage アプリをクリックします。
6. ダイアログボックスで、MoEngage の認証情報（データセンター、Workspace ID、Data API キー）を入力します。
   | フィールド | 説明 |
   | --- | --- |
   | App ID | MoEngage の Workspace ID。**Settings** \> **Account** \> **APIs** \> **Workspace ID** で確認できます。 |
   | Data API ID | MoEngage の Data API ID。Workspace ID と同じです。 |
   | Data API Key | MoEngage の Data API キー。**Settings** \> **App Settings** \> **APIs** \> **API Keys** \> **Data** で確認できます。 |
   | Data Center Name | MoEngage の URL `https://dashboard-OX.moengage.com` を確認します。ダッシュボードの値（`DC-01`、`DC-02`、`DC-03`、または `DC-04`）に基づいて、Crowdin で対応する値を設定します。詳細については、[MoEngage のデータセンター](https://www.moengage.com/docs/user-guide/data/key-concepts/data-centers-in-moengage)を参照してください。 |
   ![4 つのフィールドが入力された Crowdin Enterprise の MoEngage アプリ認証情報ダイアログ](/images/partner_10360750343188.png)
7. **Log in with MoEngage** をクリックします。

### ステップ 2: Crowdin と MoEngage 間でコンテンツを共有する

#### A. MoEngage から Crowdin にコンテンツを送信する

翻訳用のコンテンツを MoEngage からインポートするには、以下を行います。

1. MoEngage 連携を開きます。
2. MoEngage セクション（右パネル）で、翻訳するファイルを選択します。
3. **Sync** をクリックします。

#### B. Crowdin から MoEngage に翻訳を送信する

1. MoEngage 連携を開きます。
2. 左側のセクションで、MoEngage に同期するファイルを選択します。
3. **Sync to MoEngage** をクリックします。

![Crowdin と MoEngage 間の同期用に選択されたファイルが表示された Crowdin の MoEngage 連携 UI](https://developer.app.crowdin.net/assets/4e814fb1-8662-4064-b7e0-6cce176288b5)

#### 自動同期

翻訳用のコンテンツを MoEngage から自動的にインポートするには、以下を行います。

ファイルを選択し、MoEngage 連携の右パネルで **Scheduled sync** をクリックします。選択したファイルは、スケジュールされた時刻（デフォルトでは 1 日 1 回）に送信されます。同じボタンで、翻訳済みファイルを Crowdin から MoEngage にエクスポートできます（左パネル）。**Disable Sync** をクリックすると同期を無効にできます。

### ステップ 3: MoEngage キャンペーンで翻訳を使用する

#### メールテンプレート

テンプレートが作成されると、メールキャンペーンのステップ 2 でアクセスできます。新しいテンプレートは **My saved templates** セクションに表示されます。

![保存された Crowdin テンプレートのセクションが表示された MoEngage メールキャンペーンのステップ 2](https://www.moengage.com/docs/user-guide/campaigns-and-channels/email/create/create-an-email-campaign)

詳細については、[メールキャンペーンを作成する](https://www.moengage.com/docs/user-guide/campaigns-and-channels/email/create/create-an-email-campaign)を参照してください。

#### コンテンツブロック

コンテンツブロックが作成されると、**Content** \> **Content Blocks** からアクセスできます。詳細については、[Content Blocks](https://www.moengage.com/docs/user-guide/content/content-blocks/content-blocks) を参照してください。

## はじめに

[Open Weather](https://openweathermap.org/) は、高度な気象データサイエンスを実践する IT エキスパートとデータサイエンティストのチームです。OpenWeather は、地球上のあらゆる地点について、過去・現在・予報の気象データを高速な API を通じて提供しています。

## MoEngage と Open Weather

MoEngage と Open Weather の統合により、マーケティングキャンペーンを充実させ、パーソナライズできます。ユーザーの位置情報と気象データをその場で取得し、パーソナライズされたキャンペーンをリアルタイムで送信できます。

たとえば、E コマースブランドは次のような購入をユーザーに促すことができます。

- ユーザーの所在地の天気が晴れのときは、サングラス。
- 雨が降る可能性が高いときは、傘。

## 統合

<Info>
  **前提条件**

  - Open Weather アカウント。
  - Open Weather API キーへのアクセス権。互換性のある API キーについては、Open Weather のアカウントマネージャーにお問い合わせください。詳細については、[Open Weather API](https://openweathermap.org/api/one-call-3) を参照してください。
  - 各ユーザーの座標（緯度と経度）を MoEngage のユーザー属性として追跡していること。
</Info>

### 利用可能な API

MoEngage キャンペーンでは、次の Open Weather API を使用できます。

1. [現在の気象データ](https://openweathermap.org/current)
2. [時間別予報 — 4 日間](https://openweathermap.org/api/hourly-forecast)
3. [One Call API](https://openweathermap.org/api/one-call-api)
4. [日別予報 — 16 日間](https://openweathermap.org/forecast16)
5. [気候予報 — 30 日間](https://openweathermap.org/api/forecast30)
6. [5 日間の天気予報](https://openweathermap.org/forecast5)
7. [Road risk API](https://openweathermap.org/api/road-risk)

### 手順

以下の例では、ユーザーの座標における現在の気象条件に基づいて 3 つのメッセージバリエーションを示します。MoEngage Content API を通じて Current Weather API を使用し、気象の詳細を取得します。

#### ステップ 1: MoEngage で Content API を追加する

1. **Settings** \> **Advanced settings** \> **Content API** に移動します。Content API 画面の右上にある **\+ Add content API** をクリックします。 <img src="/images/partner_21979759864596.png" alt="Add content API ボタンが強調表示された MoEngage の Content API 画面" />
2. Current Weather API の詳細を追加します。 **API URL**
   ```text wrap
   https://api.openweathermap.org/data/2.5/weather?lat={{UserAttribute['latitude']}}&lon={{UserAttribute['longitude']}}&appid=<your open weather API key>
   ```
   **Parameters** パラメーターは自動的に入力されます。値をパーソナライズ変数で更新します。`@` を入力して変数を選択してください。 <img src="/images/partner_7428214057364.png" alt="緯度と経度がユーザー属性にマッピングされた MoEngage のパラメーターエディター" />
3. **Save** をクリックします。
4. Open Weather API が Content API のリストに表示されます。 <img src="/images/partner_7428241169300.png" alt="新しい Open Weather API が表示された MoEngage の Content API リスト" />

<Tip>
  キャンペーンで使用する前に、Content API の **Test** をクリックしてレスポンスを検証してください。
</Tip>

#### ステップ 2: MoEngage キャンペーンで Content API を使用する

これで、この Content API をキャンペーンで使用できるようになりました。詳細については、[Content APIs](https://www.moengage.com/docs/user-guide/campaigns-and-channels/getting-started/campaign-content/content-apis) を参照してください。

1. キャンペーン作成のステップ 2 で、`@` を入力します。
2. パーソナライズのポップアップで、ステップ 1 で設定した Open Weather Content API を選択します。 <img src="/images/partner_7428246362644.png" alt="Open Weather Content API を挿入している MoEngage のパーソナライズエディター" />
3. [MoEngage Templating Language](https://www.moengage.com/docs/user-guide/campaigns-and-channels/getting-started/message-personalization/jinja-templating-language) を使用して API レスポンスを解析し、現地の天気に基づいてキャンペーンのコンテンツを定義します。例:
   - 現地の天気が _Sunny_ の場合 → 「日焼け止めを買いましょう」。
   - 現地の天気が _Rain_ の場合 → 「傘を買いましょう」。

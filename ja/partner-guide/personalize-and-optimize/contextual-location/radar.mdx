## はじめに

[Radar](https://www.onradar.com/) は、ジオフェンシング、ジオコーディング、マップを提供する包括的な位置情報プラットフォームで、世界中の数百万台のデバイスで位置情報ベースの体験を実現しています。主要な製品には、Geofences、Trip Tracking、Geo APIs があります。

## MoEngage と Radar

MoEngage と Radar の統合では、位置情報ベースのデータの力を活用してマーケティングキャンペーンを強化します。Radar の Geo APIs を使用して MoEngage キャンペーンで近くの場所を表示し、関連性の高いコンテキストに即した情報をユーザーに提供できます。 

この統合により、次のことが可能になります。

- 位置情報をトリガーとするメッセージや位置情報でターゲティングしたメッセージを送信して、エンゲージメントとコンバージョンを高めます。
- Radar から MoEngage にユーザー属性とイベントを同期します。
- ユーザーが実店舗の近くにいるときにキャンペーンを自動化します。
- ユーザーの移動を追跡し、移動データに基づいてキャンペーンをトリガーします。

## ユースケース

Radar を MoEngage と統合すると、次のユースケースに対応できます。

- **位置情報をトリガーとするエンゲージメント**: ユーザーが実店舗周辺のジオフェンスに入ったり出たりしたときに、来店を促すプロモーションメッセージや特別オファーなどのパーソナライズされたキャンペーンをトリガーします。
- **位置情報でターゲティングしたキャンペーン**: 特定の店舗やイベントの近くにいるユーザーに位置情報ベースのメッセージを送信し、関連性の高いコンテキストに即した情報でエンゲージメントとコンバージョンを促進します。
- **ユーザーデータとイベントデータの同期**: Radar から MoEngage にユーザー属性とイベントを自動的に同期します。これにより、両方のプラットフォームにわたる統合されたユーザープロファイルが得られ、ターゲットマーケティングに活用できます。

### ステップ 1: Radar で MoEngage を設定する

MoEngage を Radar に接続するには、次の手順を実行します。

1. MoEngage UI で、**Settings** \> **Account** \> **APIs** に移動します。
2. **Workspace ID**（旧 App ID）の値をコピーします。
3. **API keys** セクションで、**Data** タイルの API キーをコピーします。
   ![Workspace ID と Data API キーのフィールドが表示された MoEngage の Settings ページ](/images/partner_43168327059988.png)
4. Radar ダッシュボードで **Integrations** ページに移動し、**MoEngage** をクリックします。
5. **Enabled** オプションを **Yes** に設定し、**Workspace ID** と **Data API Key** をそれぞれのフィールドに貼り付けます。
6. MoEngage のデータセンターに対応する **API Endpoint** を選択します（たとえば、アカウントが `https://api-01.moengage.com` 上にない場合は、正しいエンドポイントを選択します）。
   この設定後、Radar はカスタムイベントとユーザー属性をリアルタイムで MoEngage に自動送信します。
7. 各 Radar ユーザーに `moengage:customer_id` メタデータキーを設定し、対応する MoEngage ユーザープロファイルにマッピングします。
   <CodeGroup>
   ```kotlin Android wrap
   Radar.setMetadata(JSONObject().put("moengage:customer_id", "example@radar.com"))
   ```
   ```swift iOS
   Radar.setMetadata(["moengage:customer_id": "example@radar.com"])
   ```
   </CodeGroup>

## MoEngage キャンペーンで近くの場所を表示する

Radar Geo APIs を使用して、キャンペーンメッセージ内に近くの場所を直接表示するなど、動的な位置情報ベースの情報でキャンペーンを充実させることができます。これには、Radar の _Search Places_ API を呼び出す MoEngage Content API を設定します。

### ステップ 1: MoEngage Content API を設定する

MoEngage Content API を設定するには、次の手順を実行します。

1. MoEngage UI で、**Settings** \> **Advanced settings** \> **Content API** に移動します。
2. 右上にある **\+ Add content API** をクリックします。**Add content API** ダイアログボックスが表示されます。
   ![Add content API ボタンが強調表示された MoEngage の Content API リスト](/images/partner_43168327060500.png)
3. API エンドポイント URL を設定します。
   1. **API name** ボックスに、API のわかりやすい名前（例: `RadarNearbyPlaces`）を入力します。
   2. **Method** で **GET** を選択します。
   3. **URL** ボックスに、ユーザーの緯度と経度をパラメーターとして含む Radar Search Places エンドポイントを貼り付けます。
      ```text wrap
      https://api.radar.io/v1/search/places?near={{UserAttribute['Latitude']}},{{UserAttribute['Longitude']}}&chains=starbucks&limit=5
      ```
      エンドポイント URL はユースケースによって異なります。サポートされているすべてのパラメーターについては、[Radar Search Places API リファレンス](https://radar.com/documentation/api#search-places)を参照してください。
4. **URL Parameters** セクションで、チェーンを指定します。
   <Note>
     プロジェクトにチェーンマッピングがある場合は、チェーンのスラッグではなくマッピングされた ID を使用してください。
   </Note>
5. **Headers** で、必要なキーと値のペア（例: `Authorization: <your-api-key>`）を指定します。
   ![Radar 用に URL パラメーターとヘッダーが設定された MoEngage の Add content API ダイアログ](/images/partner_23074987194772.png)
6. **Dynamic values** セクションで、キーとそれに対応する値を定義します。
7. **Save** をクリックします。

Content API の詳細については、[Content APIs](https://www.moengage.com/docs/user-guide/campaigns-and-channels/getting-started/campaign-content/content-apis) を参照してください。

### ステップ 2: MoEngage キャンペーン内に場所を表示する

Content API を設定した後、キャンペーンでそれを使用して近くの場所を表示します。

1. キャンペーン作成のステップ 2 で、`@` を入力します。**Personalization** ダイアログボックスが表示されます。
2. **Select attribute** リストで、前のステップで設定した Radar Nearby Places Content API をクリックします。
3. [MoEngage Templating Language](https://www.moengage.com/docs/user-guide/campaigns-and-channels/getting-started/message-personalization/jinja-templating-language) を使用して API レスポンスを解析し、そのコンテンツをキャンペーンに含めます。以下の Jinja スニペットは、場所のリストを反復処理してその名前を出力します。
   ```jinja wrap
   {% set response = ContentApi.RadarNearbyPlaces({"params":{"near":"{{UserAttribute['Latitude']}},{{UserAttribute['Longitude']}}","chains":"target,walmart"},"static_params":{},"dynamic_params":{},"request_body":{}}) %}
   {% for place in response.places %}
   {{ place.name }}
   {% endfor %}
   ```
4. **Preview** をクリックすると、リアルタイムのパーソナライズが適用されたキャンペーンが表示されます。
   ![Radar Content API から返された近くの場所が表示された MoEngage のキャンペーンプレビュー](/images/partner_23075330470676.png)

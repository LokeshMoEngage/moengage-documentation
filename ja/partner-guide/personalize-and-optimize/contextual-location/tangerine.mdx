## はじめに

[Tangerine](https://corporate.tangerine.io/) は、Store360 というオムニチャネルプラットフォームを設計、構築、運用しています。

Store360 は、実店舗とオンラインストアをつなぎ、消費者と店舗スタッフの店内体験を向上させるオムニチャネルイネーブラープラットフォームです。小売業者のモバイルアプリユーザーやその店内エンゲージメントを含む、実店舗への来店トラフィックを追跡・分析します。

## MoEngage と Tangerine

MoEngage と Tangerine の統合により、MoEngage の未加工のキャンペーンデータおよびインプレッションデータを Snowflake 経由で Store360 に取り込むことができます。この統合データを使用して、ブランドはキャンペーンが実店舗への来店や店内エンゲージメントに与える影響を測定できます。

## ユースケース

キャンペーンが実店舗への来店に与える影響を分析します。ブランドは MoEngage を使用して、消費者の来店を促すキャンペーンメッセージを送信します。

キャンペーン期間中、Store360 はユーザー ID で識別されるモバイルアプリユーザーの来店を記録します。Store360 の Insight 分析機能を使用すると、ブランドは送信・既読されたメッセージ（MoEngage のデータ）から、どの受信者が何人実店舗を訪れたか（Store360 のデータ）まで、キャンペーンのファネル全体を可視化できます。

## 統合

<Info>
  **前提条件**

  - Store360 アカウントへのアクセス権。
  - MoEngage の Snowflake データエクスポートへのアクセス権。
</Info>

### ステップ 1: MoEngage で Snowflake エクスポートを有効にする

[Snowflake Exports](https://www.moengage.com/docs/user-guide/data/exports/events/data-warehouse/snowflake-exports) の手順に従って、MoEngage で Snowflake データエクスポートを有効にします。

### ステップ 2: MoEngage のデータを受信するように Store360 を設定する

MoEngage が Snowflake テーブルに送信するデータへのアクセスを有効にするよう、Tangerine の管理チームに依頼します。

### ステップ 3: モバイルアプリに Store360 SDK を統合する

モバイルアプリユーザーの来店や店内アクティビティを MoEngage のキャンペーンデータおよびインプレッションデータとあわせて追跡・分析するには、Store360 SDK のインストールドキュメントに記載されている手順に従って、モバイルアプリに Store360 SDK を統合します。

<Note>
  Tangerine は、Tangerine と Store360 の間でクライアント契約が締結された後に Store360 のドキュメントを提供します。
</Note>

## サービス提供地域

現在、Store360 サービスは日本とインドネシアで商用提供されています。Tangerine は、米国、タイ、シンガポール、ベトナム、韓国での Store360 製品の提供開始を計画しています。

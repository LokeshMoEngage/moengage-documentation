## はじめに

[Infillion](https://infillion.com/) は、位置情報データを活用してマーケティングの関連性を高めるのに役立ちます。ジオフェンシングソフトウェアおよびビーコンと組み合わせた位置情報 SDK により、パーソナライズされた近接認識型のモバイル体験を実現します。

## MoEngage と Infillion

ビーコンとジオフェンスのサポートを MoEngage のターゲティングおよびキャンペーンと組み合わせることで、ユーザーの物理的な行動をより深く理解し、それに応じたメッセージを送信できます。

![ジオフェンスを使用して位置情報ベースのキャンペーンを展開する方法を示す図](https://www.moengage.com/wp-content/uploads/blog/2016/05/geo-image.png)

この統合により、次のようなユースケースが可能になります。

- **マーケティング**: コンテキストに即したメッセージを送信し、体験型のカスタマージャーニーを構築します。
- **競合分析**: 競合他社の所在地周辺にトリガーを設定し、消費者のトレンドやパターンを把握します。
- **オーディエンスインサイト**: ユーザーの訪問行動を把握し、その知見に基づいてさらにセグメント化します。

## 統合

<Info>
  **前提条件**

  - この統合を使用するには、Infillion マネージャーアカウントが必要です。
  - Infillion Location SDK は、近接ビーコンとジオフェンスを使用して、マクロおよびミクロの位置情報ベースのモバイル体験を実現します。SDK を実装し、ジオフェンス（またはビーコン）を設定しておく必要があります。
</Info>

### SDK のセットアップ

MoEngage と Infillion を統合するには、Infillion Location SDK を実装し、Infillion マネージャーアカウントを作成します。以下の Android、FireOS、iOS 向けの統合では、ユーザーが新しい場所に入るたびに固有のカスタムイベントが作成されます。これらのイベントは、キャンペーンやフローでのトリガーおよびリターゲティングに使用できます。

<Tip>
  50 か所を超える場所を作成する予定の場合は、汎用的な `Places Entered` カスタムイベントを 1 つ作成し、場所の名前をイベントプロパティとして追加してください。
</Tip>

1. [Infillion のドキュメント](https://docs.gimbal.com/)に従って、Android および iOS 向けの [Infillion SDK](https://manager.gimbal.com/sdk_downloads) をアプリに統合します。
2. Infillion の [places REST API](https://docs.gimbal.com/rest.html) を使用して、ユーザーの場所を取得します。
3. MoEngage のワークスペース ID と API キーを入力して、Infillion アカウントを MoEngage にリンクします。
4. MoEngage SDK でカスタムイベントを設定します。Infillion は Android、FireOS、iOS で MoEngage と統合できます。
5. これらのイベントのプロパティ（例: `Place Name`、`Dwell Time`）をログに記録します。
6. これらのプロパティとイベントを使用して、MoEngage でキャンペーンやフローをトリガーします。

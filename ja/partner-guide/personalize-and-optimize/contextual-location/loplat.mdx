## はじめに

[Loplat](https://www.loplat.com/) は、オフラインの位置情報ベースプラットフォームのリーディングカンパニーです。loplat SDK を使用して店舗の来店客数を増やし、店舗での購入を促すマーケティングキャンペーンを実施できます。キャンペーン終了後は、来店客数の分析によって店舗のパフォーマンスを測定できます。

## MoEngage と Loplat

MoEngage と loplat の統合により、loplat の位置情報サービス（店舗 POI およびカスタムジオフェンス）を使用して、ジオコンテキストに基づくマーケティングキャンペーンをトリガーしたり、オフラインアクティビティからカスタムイベントを作成したりできます。ユーザーが loplat X で設定したターゲット地点を訪れると、キャンペーンと位置情報がリアルタイムで MoEngage に送信されます。

## ユースケース

loplat が提供するカスタムイベントの位置情報データをキャンペーンで使用して、次のようなユースケースを実現できます。

- **免税店のプロモーション通知**: 空港の搭乗ゲート付近にいるユーザーに免税店の割引クーポンを送信します。
- **電気自動車（EV）充電ステーションのプッシュ通知**: EV 充電ステーションの周囲にジオフェンスを設定し、ユーザーが近くにいるときに通知して充電を促します。

## 統合

<Info>
  **前提条件**

  - loplat X アカウント。アカウントをリクエストするには `support@loplat.com` にメールでお問い合わせください。
  - loplat SDK は、ユーザーの店舗訪問を認識し、位置情報イベントを処理し、ユーザーが静止しているか移動しているかを判別します。店舗の来店客数の分析や、入店時のプッシュメッセージ送信などに使用できます。SDK は Android と iOS でのみ利用できます。
  - MoEngage の **Workspace ID** と **Data API Key** へのアクセス権。どちらも MoEngage ダッシュボードの **Settings** > **APIs** で確認できます。
</Info>

### SDK のセットアップ

![loplat と MoEngage の SDK 統合フローを示す図](/images/partner_34806064717588.png)

#### ステップ 1: SDK を統合する

以下の手順に従って、アプリに loplat SDK と MoEngage SDK を統合します。

loplat SDK に設定された MoEngage ユーザー ID は、位置認識結果について loplat X を介して MoEngage にリンクされます。

- Android 向け loplat SDK の使用を開始する: [https://developers.loplat.com/en/docs/android/](https://developers.loplat.com/en/docs/android/)
- iOS アプリについても同等の手順に従ってください。

#### ステップ 2: MoEngage でイベントトリガー型キャンペーンを作成する

[イベントトリガー型キャンペーンを作成する](https://www.moengage.com/docs/user-guide/campaigns-and-channels/email/create/create-an-email-campaign)の手順に従って、loplat のイベントで配信されるキャンペーンを作成します。

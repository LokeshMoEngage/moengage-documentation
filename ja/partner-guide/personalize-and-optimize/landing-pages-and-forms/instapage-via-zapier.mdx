## はじめに

[Instapage](https://instapage.com/) は、マーケティングキャンペーン向けのランディングページを作成、パーソナライズ、最適化するためのランディングページプラットフォームです。

## MoEngage と Instapage

MoEngage と Instapage の連携により、マーケターはランディングページからユーザーデータをシームレスに取得し、パーソナライズされたエンゲージメントキャンペーンに活用できます。この連携により、ターゲットを絞ったメッセージング、動的コンテンツのパーソナライゼーション、コンバージョン率の向上を実現できます。

## 連携

<Info>
  **前提条件**

  - 有効な Instapage アカウントがあることを確認してください。
  - この連携を使用するには Zapier アカウントが必要です。[Zapier の概要](/ja/partner-guide/data-and-analytics/workflow-automation/zapier/overview#connecting-zapier-to-moengage)の手順に従って、Zapier アカウントと MoEngage アカウントを接続してください。
</Info>

## Instapage のリードを MoEngage にインポートする

<Note>
  このワークフローでは [Create or Update User](/ja/partner-guide/data-and-analytics/workflow-automation/zapier/create-or-update-users) アクションを使用します。
</Note>

リードを MoEngage にユーザーとしてインポートし、その値をユーザー属性として保存できます。これにより、MoEngage でターゲットキャンペーン用のカスタムセグメントを作成できます。

### ステップ 1: トリガーアプリとして Instapage を選択する

![Instapage がトリガーアプリとして選択された Zapier のトリガー設定画面](/images/partner_26219218323860.png)

1. アプリのリストから **Instapage** を選択します。
2. イベントとして **Form Submission** を選択し、**Continue** をクリックします。
3. Instapage アカウントを接続します。ドロップダウンから Instapage アカウントを選択し、**Continue** をクリックします。
4. 接続するページを選択し、**Continue** をクリックします。

   ![利用可能なランディングページが表示された Zapier の Instapage ページ選択画面](https://help.instapage.com/hc/article_attachments/19297089046423)

5. **Test trigger** をクリックします。Zapier が最近のリードの取得を試みます。**Continue** をクリックして次のステップに進みます。

   ![取得された Instapage のリードが表示された Zapier のトリガーテスト結果](https://help.instapage.com/hc/article_attachments/19297043707543)

### ステップ 2: アクションアプリとして MoEngage を選択する

アプリのリストから **MoEngage** を検索して選択します。

![MoEngage がアクションアプリとして選択された Zapier のアクション設定画面](/images/partner_26218603194900.png)

1. イベントのドロップダウンから **Create or Update User** を選択し、**Continue** をクリックします。
2. [前提条件](/ja/partner-guide/data-and-analytics/workflow-automation/zapier/overview)に従っている場合、MoEngage アカウントはすでにリストに表示されています。それを選択するか新しいアカウントを接続し、**Continue** をクリックします。
3. **Set up action** ステップでは、手動で入力するか前のステップからマッピングする属性とユーザープロパティのリストが表示されます。詳細については、[Create or Update User API リファレンス](https://www.moengage.com/docs/api/user/track-user)を参照してください。必要に応じて、関連するカスタムユーザー属性を追加します。
4. マッピングに問題がなければ、**Continue** をクリックします。
5. 最後のステップで、**Test & continue** をクリックします。
6. テストが成功すると、`success` レスポンスが表示されます。

### MoEngage でリードを確認する

MoEngage ダッシュボードでリードを確認できます。Instapage のリードのユーザープロファイルに移動し、カスタム属性（設定している場合）を確認します。

![Instapage のリードから取得されたカスタム属性が表示された MoEngage のユーザープロファイル](/images/partner_26219216089108.png)

これで、関連するユーザー属性を持つユーザーをフィルタリングしてキャンペーンを送信したり、ターゲットを絞ったカスタムセグメントを作成してリードのエンゲージメントを高めたりできます。

<Check>
  Instapage のリードが、マッピングされたすべての属性が入力された状態で MoEngage にユーザーとして表示されます。
</Check>

# はじめに

Kudosity は、世界 114 以上の宛先への信頼性の高い接続を提供する、企業向けのメッセージングおよびエンゲージメントプラットフォームです。インテリジェントにパーソナライズされた SMS、MMS、オムニチャネルメッセージング、会話型 AI を通じて、顧客との本物の関係を築くことができます。

<Note>
  Kudosity アカウントと API キーを用意していることを確認してください。認証情報に問題がある場合、または認証情報がない場合は、Kudosity サポートにお問い合わせください。
</Note>

# Kudosity をカスタム SMS コネクター (サービスプロバイダー) として設定する

この記事では、MoEngage ダッシュボードで Kudosity をカスタム SMS コネクター (サービスプロバイダー) として設定する方法について説明します。

続行する前に、Kudosity API (Transmitsms) を呼び出すための次のパラメーターを用意していることを確認してください。API URL、API Key、API Secret は、[Kudosity の設定](https://burst.transmitsms.com/profile) で確認できます。[Kudosity SMS API についてはこちら](https://developer.transmitmessage.com/) で確認することもできます。

![Screenshot 2025-02-25 at 12.14.24 PM.png](/images/partner_35096210737812.png)

| パラメーター | 説明 |
| --- | --- |
| API URL | このフィールドには、送信者に API リクエストを送信する際に使用する URL の情報が含まれます。Kudosity の API URL は次のとおりです。<br />[https://api.transmitsms.com/send-sms.json](https://api.transmitsms.com/send-sms.json) |
| API Key | API キーは、Kudosity へのリクエストを認証するために使用される一意の識別子です。 |
| API Secret | API シークレットは、Kudosity API にアクセスする際のセキュリティを強化するために API キーと併用される機密キーです。<br />**注** : Kudosity アカウントに登録したばかりの場合は、API シークレットを設定する必要があります。複雑で安全なものにしてください。 |

MoEngage ダッシュボードにログインし、次の手順に従います。

1. **Settings** -\> **Channel** -\> **SMS** に移動します。
2. 右上隅にある **\+ Sender** をクリックします。
3. **\+ Add custom service provider** をクリックします。
4. **Service Details** ページで次の詳細を追加します。\\ <img src="/images/partner_35096210738324.png" alt="Screenshot 2025-02-25 at 12.24.19 PM.png" />

| フィールド | 説明 |
| --- | --- |
| **Mark as default** | このトグルをオンにすると、設定中のサービスプロバイダーのデフォルト送信者としてこの送信者がマークされます。デフォルトとしてマークすると、キャンペーン作成時に別の送信者を選択しない限り、MoEngage からのすべての SMS キャンペーンの送信にこの送信者が使用されます。 |
| **Service provider name** | このフィールドは MoEngage ダッシュボードで設定するサービスプロバイダーを識別するもので、一意である必要があります。Kudosity サービスを作成するため、ここには _Kudosity_ と入力します。 |
| **Sender name** | このフィールドは、キャンペーンやアラートの作成時に使用できる、読みやすい送信者名を識別します。 |
| **Sender ID** | このフィールドは送信者 ID で、SMS メッセージを送信するために Kudosity で設定した電話番号です。送信者は Kudosity アカウントの <br />[https://kudosity.transmitsms.com/u/senders](https://kudosity.transmitsms.com/u/senders) で設定できます。 <img src="/images/partner_35096210738452.png" alt="Screenshot 2025-02-25 at 12.30.40 PM.png" /> |
| **Sender type** | 送信者タイプを選択します。利用可能なオプションは次のとおりです。<ul><li>**Promotional** : ブランドに関する情報の送信、お得な情報のプロモーション、またはユーザーとのエンゲージメントに送信者を使用する場合は、このオプションを選択します。</li><li>**Transactional** : 取引に関するアラート、OTP、セキュリティ情報、またはトランザクションとして分類できる情報の送信に送信者を使用する場合は、このオプションを選択します。</li></ul> |

5. API の詳細を設定します。

| フィールド | 説明 |
| --- | --- |
| **API URL** | このフィールドには、送信者に API リクエストを送信する際に使用する URL の情報が含まれます。Kudosity の API URL は [https://api.transmitsms.com/](https://api.transmitsms.com/) です。 |
| **Method** | HTTP メソッドとして **POST** を選択します。 |
| **Headers** | ヘッダーに次のキーと値のペアを作成します。 <img src="/images/partner_35096210738836.png" alt="value.png" /> <ul><li>**Authorization** : Basic \<value\> <br />**注** : これは API Key と API Secret を組み合わせた Base64 エンコード文字列です。Base64 エンコードキーの作成方法については、こちらの Kudosity のドキュメントを参照してください: [https://developers.kudosity.com/docs/step-3-make-an-api-request](https://developers.kudosity.com/docs/step-3-make-an-api-request)</li><li>**Content-Type** : application/x-www-form-urlencoded</li></ul> |
| **Body type** | Body type を **Form** に設定し、次の詳細を追加します。 <img src="/images/partner_35096218331284.png" alt="Screenshot 2025-02-25 at 12.48.03 PM.png" /> <ol><li>**message** フィールドに _Moesms\_message_ を追加して、MoEngage のメッセージをリクエストに渡します。</li><li>**to** フィールドに _Moesms\_destination_ を追加して、MoEngage の宛先をリクエストに渡します。</li><li>**sender** フィールドに、Kudosity アカウントの Sender ID を追加します。送信者は Kudosity アカウントの <br />[https://kudosity.transmitsms.com/u/senders](https://kudosity.transmitsms.com/u/senders) で設定できます。</li></ol> |

6. **Send test SMS** をクリックして、設定を確認します。
7. **Next** をクリックします。
8. MoEngage ダッシュボードで送信者を作成した後、配信トラッキングを設定できます。配信トラッキングの詳細については、[カスタムコネクターの配信トラッキング](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/sms/getting-started-with-sms/configure-custom-connector-for-sms) を参照してください。
9. **Save** をクリックして、送信者設定を保存します。

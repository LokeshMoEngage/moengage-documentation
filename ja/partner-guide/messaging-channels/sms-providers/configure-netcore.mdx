# はじめに

Netcore は、マーケターが消費者の声に耳を傾け、分析し、対話を構築できるよう支援する、人工知能を活用したマーケティングオートメーションおよびカスタマーエンゲージメントプラットフォームを提供しています。

<Info>
  **前提条件** Netcore ダッシュボードにアクセスできることを確認してください。
</Info>

# Netcore をカスタム SMS コネクター（サービスプロバイダー）として設定する

この記事では、MoEngage ダッシュボードで Netcore をカスタムコネクターとして設定する方法を説明します。設定後は、Netcore カスタムコネクターを選択するだけで SMS を送信できます。

キャンペーンを作成する前に、Netcore アカウントの **_FeedId、username、_** および **_Password_** を用意してください。これらが見つからない場合は、Netcore の担当者にお問い合わせください。

MoEngage ダッシュボードにログインし、次の手順を実行します。

1. **Settings** -\> **Channel** -\> **SMS** -\> **Sender Configuration** に移動します。
2. 右上の **\+Add Service Provider** をクリックします。
3. **Sender Details** 画面で次の詳細を追加します。

| フィールド | 説明 |
| --- | --- |
| **Mark as default** | このトグルをオンにすると、設定中のサービスプロバイダーのデフォルト送信者としてこの送信者がマークされます。デフォルトに設定すると、キャンペーン作成時に別の送信者を選択しない限り、MoEngage から送信されるすべての SMS キャンペーンでこの送信者が使用されます。 |
| **Service provider name** | このフィールドは MoEngage ダッシュボードで設定するサービスプロバイダーを識別するもので、一意である必要があります。ここにサービスプロバイダー名を入力します。 |
| **Sender name** | このフィールドは、キャンペーンやアラートの作成時に使用できる、読みやすい送信者名を識別します。 |
| **Sender type** | Sender type は **Promotional** または **Transactional** のいずれかです。ブランドに関する情報の送信、キャンペーンやお得な情報の宣伝、ユーザーとのエンゲージメントに Sender を使用する場合は、Sender type として Promotional を選択します。取引に関するアラート、OTP、セキュリティ情報、またはトランザクションの性質を持つと分類できる情報の送信に Sender を使用する場合は、Sender type として Transactional を選択します。 |

4. 次の詳細を追加して Webhook を設定します。

| フィールド | 説明 |
| --- | --- |
| **API URL** | このフィールドには、Sender に API リクエストを送信する際に使用する URL の情報が含まれます。この情報は Sender の API ドキュメントで確認できます。ここに Sender の API エンドポイントを入力します。 <br />Netcore の API URL は次のとおりです: `http://bulkpush.mytoday.com/BulkSms/SingleMsgApi?feedid=123456&username=9876543210&password=abcde&To=[[Mobile Number]]&Text=SampleMessage` |
| **Method** | HTTP メソッドとして **GET** を選択します。 |

5. これは GET リクエストであるため、次の画像のように URL パラメーターが API URL から自動入力されます。 <img src="/images/partner_21971372339092.png" alt="NetCore_NewUI_PG_DT.png" />
6. 次のキーの値を変更します。
   1. **Feedid**、**username**、**password** - アカウントの認証情報に従って設定します
   2. **To** - ユーザーの携帯電話番号を渡すために _Moesms\_destination_ を追加します。
   3. **Text** - _Moesms\_message_ を追加します
   4. トランザクションメッセージを送信する場合は、Netcore からアカウントに割り当てられた Sender ID を含む、送信者 ID 用の URL パラメーター（**senderId**）を追加します。
7. **Send a test SMS** で設定を確認します。
8. **Save** をクリックして Sender Configuration を保存します。
9. MoEngage ダッシュボードで送信者を作成した後、配信トラッキングを設定できます。配信トラッキングの詳細については、[カスタムコネクターの配信トラッキング](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/sms/getting-started-with-sms/configure-an-sms-sender)を参照してください。
10. 配信トラッキングレスポンスの属性は、手動または自動でマッピングできます。

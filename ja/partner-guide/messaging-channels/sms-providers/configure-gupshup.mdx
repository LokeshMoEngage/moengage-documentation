# はじめに

Gupshup は、毎月 60 億件を超えるメッセージを支える、業界をリードする会話型メッセージングプラットフォームです。新興市場のあらゆる業種の大小数千の企業が、Gupshup を使用してマーケティング、セールス、サポートにわたる会話型エクスペリエンスを構築しています。

<Info>
  **前提条件** SMS Gupshup アカウントの **_UserId_** や **_Password_** などのログイン認証情報を用意していることを確認してください。認証情報に問題がある場合、または認証情報がない場合は、Gupshup サポートにお問い合わせください。
</Info>

## SMS コネクター (サービスプロバイダー) を設定する

MoEngage ダッシュボードにログインし、次の手順に従います。

1. **Settings** -\> **Channels** -\> **SMS** -\> **Sender configuration** に移動します。
2. **Gupshup** をクリックします。
3. **Sender Details** 画面で次の詳細を追加します。

| フィールド | 説明 |
| --- | --- |
| **Mark as default** | このトグルをオンにすると、設定中のサービスプロバイダーのデフォルト送信者としてこの送信者がマークされます。デフォルトとしてマークすると、キャンペーン作成時に別の送信者を選択しない限り、MoEngage からのすべての SMS キャンペーンの送信にこの送信者が使用されます。 |
| **Sender type** | 送信者タイプは **Promotional** または **Transactional** のいずれかです。ブランドに関する情報の送信、お得な情報のプロモーション、またはユーザーとのエンゲージメントに送信者を使用する場合は、Sender type として Promotional を選択します。取引に関するアラート、OTP、セキュリティ情報、またはトランザクションとして分類できる情報の送信に送信者を使用する場合は、Sender type として Transactional を選択します。 |
| **Sender ID** | ユーザーに SMS を送信する番号です。 |
| **Username** | Gupshup アカウントのユーザー名です。 |
| **Password** | Gupshup アカウントのパスワードです。 |

4. **テスト SMS を送信** して、設定を確認します。
5. **Save** をクリックして、送信者設定を保存します。
6. 配信トラッキングを有効にするには、Delivery tracking URL をコピーして Gupshup ポータルに貼り付けます。詳細については、「Gupshup で配信トラッキングを有効にする」を参照してください。

## 配信トラッキング

SMS の配信トラッキングを有効にするには、次の手順に従います。

1. [Gupshup ポータルにログインします](https://enterprise.smsgupshup.com/)。
2. [Settings -\> SMS Settings](http://enterprise.smsgupshup.com/settings) に移動します。
3. MoEngage の Delivery Tracking URL [https://api-01.moengage.com/sms/dlr/gupshup](https://api-01.moengage.com/sms/dlr/gupshup) を使用し、Gupshup ポータルで Transactional SMS アカウントの Real-Time Delivery URL に貼り付けます。 k

![EnableDeliveryTracking.png](/images/partner_10165866771604.png)

<Warning>
  Gupshup では、配信トラッキング URL を GET リクエストとして設定する必要があります。GET リクエストとして設定するには、Gupshup のアカウントマネージャーにお問い合わせください。
</Warning>

# はじめに

Twilio は、世界中の数十万の企業と 1,000 万人以上の開発者が、独自のパーソナライズされた顧客体験を構築するために使用しているカスタマーエンゲージメントプラットフォームです。

<Info>
  **前提条件** Twilio ダッシュボードにアクセスできる必要があります。
</Info>

# SMS/MMS コネクター（サービスプロバイダー）として設定する

<Info>
  Twilio は MMS もサポートしています。以下と同じ手順に従って、Twilio を MMS 送信者として設定できます。
</Info>

以下では、MoEngage で Twilio を SMS/MMS プロバイダーとして設定する手順を順を追って説明します。作業を進める前に、Twilio アカウントのログイン認証情報を用意してください。MoEngage カスタマーサクセスマネジメント（CSM）チームにサポートを依頼することもできます。

MoEngage ダッシュボードにログインし、次の手順を実行します。

1. **Settings** \> **Channel** \> **SMS, MMS & RCS** \> **Sender configuration** に移動します。
2. 右上の **\+Add Service Provider** をクリックします。
3. **Add Sender** 画面で **Twilio** を選択します。
4. 初めてアカウントを設定する場合は、認証情報を入力する必要があります。Twilio アカウントにログインした後、[Twilio コンソール](https://console.twilio.com/?frameUrl=/console)で必要な情報を確認できます。
   - **Username**: **Twilio Account SID** です。
   - **Password**: **Twilio Auth Token** です。 <img src="/images/partner_21971989388692.png" alt="Twilio_NewUI_Authentication.png" />
5. Twilio Account SID と Auth token を入力したら、**Save** をクリックして認証情報を保存します。\
   Twilio の認証はアカウントレベルで行われるため、送信者ごとに追加する必要はありません。ただし、認証パラメーターを変更する必要がある場合は、Twilio の横にある「Reauthenticate」リンクをクリックして設定を更新できます。

![Twilio\_NewUI\_ReAuthentication.png](/images/partner_21971996286868.png)

これで Twilio 送信者を設定できます。

6. **Sender Details** 画面で次の詳細を追加します。

| フィールド | 説明 |
| --- | --- |
| **Mark as default** | このトグルは送信者の作成中は無効になります。MoEngage アカウントで最初に作成された送信者が、SMS キャンペーンのデフォルト送信者としてマークされます。デフォルト送信者は、[送信者をデフォルトとしてマークする](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/sms/getting-started-with-sms/configure-an-sms-sender)に記載の手順に従って変更できます。 |
| **This sender supports MMS** | Twilio を MMS 送信者として設定するには、このチェックボックスを選択します。 |
| **Sender name** | このフィールドは、キャンペーンやアラートの作成時に使用できる、読みやすい送信者名を識別します。 |
| **Sender type** | 送信者タイプは次のいずれかです:<br />\* **Short Code**<br />\* **Long Code**<br />\* **Messaging Service**<br />\* **Alphanumeric Sender ID**<br />適切な送信者タイプを選択します。 |
| **Sender ID** | ユーザーに SMS を送信する際の送信元番号です。選択したタイプに対応する番号を追加してください。詳細については、[ShortCodes](https://console.twilio.com/us1/develop/sms/senders/short-codes?frameUrl=%2Fconsole%2Fsms%2Fshort-codes%3Fx-target-region%3Dus1)、[LongCodes](https://console.twilio.com/us1/develop/phone-numbers/manage/active?frameUrl=%2Fconsole%2Fphone-numbers%2Fincoming%3Fx-target-region%3Dus1)、[MessagingServices](https://console.twilio.com/us1/develop/sms/services?frameUrl=/console/sms/services) を参照してください。**注** : Sender type が **Messaging Service** の場合は、Sender ID フィールドに Messaging Service SID を入力します。 |
| **Mobile Originated (MO) callback URL** | このコールバック URL は、ワークスペースが属するデータセンター（DC）によって異なります。コールバック URL は次のとおりです: <ul><li>DC 01 の場合: [https://api-01.moengage.com/v1/campaigns/outbound/sms/callbacks/mo/twilio](https://api-01.moengage.com/v1/campaigns/outbound/sms/callbacks/mo/twilio)</li><li>DC 02 の場合: [https://api-02.moengage.com/v1/campaigns/outbound/sms/callbacks/mo/twilio](https://api-02.moengage.com/v1/campaigns/outbound/sms/callbacks/mo/twilio)</li><li>DC 03 の場合: [https://api-03.moengage.com/v1/campaigns/outbound/sms/callbacks/mo/twilio](https://api-03.moengage.com/v1/campaigns/outbound/sms/callbacks/mo/twilio)</li><li>DC 04 の場合: [https://api-04.moengage.com/v1/campaigns/outbound/sms/callbacks/mo/twilio](https://api-04.moengage.com/v1/campaigns/outbound/sms/callbacks/mo/twilio)<br /><br />このフィールドは、**Keyword management** の下にある **Manage keyword based responses** トグルを有効にした場合にのみ使用できます。</li></ul> |
| **SMS unsubscribe text** | このフィールドに入力したテキストは、SMS キャンペーンのコンテンツ作成時に **SMS opt-out instruction** チェックボックスを選択すると表示されます。SMS opt-out instruction を使用すると、作成した SMS キャンペーンに、顧客が以降の SMS メッセージの受信をオプトアウトできるテキストを含めることができます。このフィールドは、**Keyword management** の下にある **Manage keyword based responses** トグルを有効にした場合にのみ使用できます。 |

7. **Send a test SMS** で設定を確認します。
8. **Save** をクリックして Sender Configuration を保存します。
9. **Check balance** をクリックして、アカウントの残高を確認することもできます。

## 配信コールバック

ロングコードとショートコードのどちらの場合も、MoEngage は Twilio への API 呼び出しで配信コールバック URL を渡すことにより、配信レシートを自動的にトラッキングします。SMS 配信をトラッキングするための追加設定は不要です。

Messaging Services の場合は、Messaging Service ごとに Twilio ダッシュボードで Delivery Callback URL を追加する必要があります。手順は次のとおりです。

1. Twilio Dashboard にログインします。
2. **Messaging** \> **Services** に移動します。

![Twilio\_MessagingServices.png](/images/partner_11468751356180.png)

3. Messaging Service を選択します。左側のパネルに別のメニューが表示されます。
4. Messaging Service 名の下にある **Integration** タブをクリックします。**Delivery Status Callback** までスクロールし、コールバック URL - _[https://api-01.moengage.com/sms/dlr/twilio](https://api-01.moengage.com/sms/dlr/twilio)_ を入力します。

![Twilio\_Integration.png](/images/partner_11468752701332.png)

# コンテンツ設定を構成する

Twilio を MMS 送信者として設定する場合は、Twilio ダッシュボードで MMS Converter を有効にする必要があります。これにより、MMS 形式をサポートしていない宛先にもアウトバウンド MMS メッセージを送信できます。このようなメッセージでは、MMS Converter が添付メディアを、ファイルにリンクする短縮 URL に置き換えてメッセージ本文に挿入します。この設定を有効にするには、次の手順を実行します。

1. Twilio コンソールにログインします。
2. 設定が必要な Messaging Service に移動し、**Content Settings** をクリックします。
3. **MMS Converter** トグルをオンにします。

![Screenshot 2025-09-16 at 4.54.49 PM.png](/images/partner_42712122553108.png)

# キーワード管理を設定する

このセクションでは、キーワード管理の設定方法について説明します。

## MoEngage の設定の変更

キーワード管理を設定するには、MoEngage ダッシュボードの **Sender Details** 画面で次の 2 つのフィールドを入力する必要があります。これらのフィールドは、**Keyword management** の下にある **Manage keyword-based responses** トグルを有効にした場合にのみ表示されます。

![image (2)n.png](/images/partner_30862038839444.png)

- **Mobile Originated (MO) callback URL**: このコールバック URL は、所属する DC によって異なります。コールバック URL は次のとおりです。
  - DC 01 の場合 - [https://api-01.moengage.com/v1/campaigns/outbound/sms/callbacks/mo/twilio](https://api-01.moengage.com/v1/campaigns/outbound/sms/callbacks/mo/twilio)
  - DC 02 の場合 - [https://api-02.moengage.com/v1/campaigns/outbound/sms/callbacks/mo/twilio](https://api-02.moengage.com/v1/campaigns/outbound/sms/callbacks/mo/twilio)
  - DC 03 の場合 - [https://api-03.moengage.com/v1/campaigns/outbound/sms/callbacks/mo/twilio](https://api-03.moengage.com/v1/campaigns/outbound/sms/callbacks/mo/twilio)
  - DC 04 の場合 - [https://api-04.moengage.com/v1/campaigns/outbound/sms/callbacks/mo/twilio](https://api-04.moengage.com/v1/campaigns/outbound/sms/callbacks/mo/twilio)
- **SMS unsubscribe text**: SMS unsubscribe text を使用すると、作成した SMS キャンペーンに、顧客が以降の SMS メッセージの受信をオプトアウトするためのテキストを含めることができます。このフィールドに入力したテキストは、SMS キャンペーンのコンテンツ作成時に **SMS opt-out instruction** チェックボックスを選択すると、オプトアウトテキストとして表示されます。

## Twilio コンソールでの変更

設定済みの送信者について、次の手順を実行して Twilio コンソールでキーワード管理を設定します。

1. Twilio コンソールにログインします。
2. 設定が必要な Messaging Service に移動し、**Integration** をクリックします。

![twilio.png](/images/partner_30862023360148.png)

3. **Incoming Messages** の下で **Send a webhook** を選択します。
4. **Request URL** フィールドに、MoEngage ダッシュボードの **Mobile Originated (MO) callback URL** フィールドに追加したものと同じコールバック URL を入力します。
5. メソッドとして **HTTP Get** を選択します。

# はじめに

MessageWhiz は、組織が複数のチャネルにわたって顧客にリーチし、エンゲージメントを管理し、双方向の会話を行えるようにする、SMS およびメッセージング管理のマルチエージェントプラットフォームです。

<Info>
  この記事では、MoEngage ダッシュボードで MessageWhiz をカスタムコネクター (サービスプロバイダー) として設定する手順について説明します。
</Info>

# MessageWhiz をカスタム SMS コネクター (サービスプロバイダー) として設定する

<Info>
  この記事では、MoEngage ダッシュボードで MessageWhiz をカスタムコネクター (サービスプロバイダー) として設定する手順について説明します。
</Info>

MoEngage ダッシュボードにログインし、次の手順を実行します。

1. **Settings** \> **Channel** \> **SMS** \> **Sender configuration** に移動します。
2. 右上隅にある **\+ Add Sender** をクリックします。
3. **\+ Add custom service provider** をクリックします。
4. Sender Details 画面で詳細と設定を追加します。

| フィールド | 説明 |
| --- | --- |
| **Mark as default** | このトグルをオンにすると、この送信者が MessageWhiz のデフォルト送信者としてマークされます。デフォルトとしてマークすると、キャンペーン作成時に別の送信者を選択しない限り、MoEngage からのすべての SMS キャンペーンの送信にこの送信者が使用されます。これは必須ではありません。 |
| **Service provider name** | このフィールドは MoEngage ダッシュボードで設定するサービスプロバイダーを識別するもので、一意である必要があります。ここにサービスプロバイダーの名前を入力します。MessageWhiz と入力します。 |
| **Sender name** | このフィールドは、キャンペーンやアラートの作成時に使用できる、読みやすい送信者名を識別します。 |
| **Sender type** | 送信者タイプは **Promotional** または **Transactional** のいずれかです。<ul><li>ブランドに関する情報の送信、お得な情報のプロモーション、またはユーザーとのエンゲージメントに送信者を使用する予定の場合は、Promotional を選択します。</li><li>取引に関するアラート、OTP、セキュリティ情報、またはトランザクションとして分類できる情報を送信する場合は、送信者タイプとして Transactional を選択します。</li></ul> |

5. 次の詳細を追加して Webhook を設定します。

| フィールド | 説明 |
| --- | --- |
| **API URL** | このフィールドには、送信者に API リクエストを送信する際に使用する URL の情報が含まれます。この情報は送信者の API ドキュメントから取得できます。ここに送信者の API エンドポイントを入力します。MessageWhiz の API URL は次のとおりです。<br />[https://sms.messagewhiz.com/sms](https://sms.messagewhiz.com/sms) |
| **Method** | HTTP メソッドとして **POST** を選択します。 |
| **Body Type** | Body Type として **JSON** を選択し、次の詳細を追加します。<br />&#123;<br />"messages": \[<br />&#123;<br />"text": "Moesms\_message",<br />"dest": \[Moesms\_destination\],<br />"send": "SENDER\_ID"<br />&#125;<br />"key": "API\_KEY",<br />"ver": "1.0"<br />\]<br /> 次のキーの値を変更します。<ul><li>SENDER\_ID と API\_KEY: MessageWhiz アカウントの認証情報に基づいて設定します。<br />(API キーの末尾に '=' がある場合は、Key Value Pair セクションに '=' を明示的に追加してください)<br /></li></ul> |

6. **Send test SMS** をクリックします。画面上部に新しいステップが表示されます。
7. 3 - Delivery Tracking (optional) をクリックし、Delivery Tracking URL をコピーします。
8. 画面上部の Sender Details をクリックします。
   1. Key と Value のテーブルに新しい行を追加します。
   2. Key に callback という名前を付け、API URL を貼り付けます。
      | Key | Value |
      | --- | --- |
      | api\_key | "Customer key" |
      | from | Test sender |
      | to | Moesms\_message |
      | text | Moesms\_destination |
      | callback | ここに配信トラッキング URL を貼り付けます。 |
9. テスト SMS を再度送信し、**Next** をクリックします。
10. Delivery Tracking URL のパラメーターを確認し、**Save** をクリックします。<img src="/images/partner_30756712777620.png" alt="Karix_NewUI_PG_DT.png" />

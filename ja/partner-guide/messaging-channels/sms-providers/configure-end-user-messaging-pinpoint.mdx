---
title: "End User Messaging (Pinpoint) の設定"
---

End User Messaging (Pinpoint) は、Amazon Web Services (AWS) が提供するサービスで、企業がターゲットを絞ったパーソナライズされたテキストメッセージを顧客に送信できるようにします。

# SMS コネクター (サービスプロバイダー) として設定する

以下では、MoEngage で End User Messaging (Pinpoint) を目的の SMS プロバイダーとして設定する手順を順を追って説明します。

MoEngage ダッシュボードにログインし、次の手順に従います。

1. **Settings** \> **Channel** \> **SMS** \> **Sender configuration** に移動します。
2. 右上隅にある **\+Add Sender** をクリックします。
3. **Add Sender** 画面で **End User Messaging (Pinpoint)** を選択します。
   ![Screenshot 2025-04-16 at 10.21.22 AM.png](/images/partner_36643778315028.png)
4. **Sender Details** 画面で次の詳細を追加します。
   ![2025-04-02\_17-51-11.png](/images/partner_36227075252372.png)

| フィールド | 説明 |
| --- | --- |
| **Mark as default** | このトグルは送信者の作成中は無効になります。MoEngage アカウントで最初に作成された送信者が、SMS キャンペーンのデフォルト送信者としてマークされます。デフォルト送信者は、[送信者をデフォルトとしてマークする](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/sms/getting-started-with-sms/configure-an-sms-sender) に記載の手順に従って変更できます。 |
| **Sender type** | 送信者タイプは **Transactional** または **Promotional** のいずれかです。<ul><li>取引に関するアラート、OTP、セキュリティ情報、またはトランザクションとして分類できる情報の送信に送信者を使用する場合は、**Sender type** として **Transactional** を選択します。</li><li>ブランドに関する情報の送信、お得な情報のプロモーション、またはユーザーとのエンゲージメントに送信者を使用する場合は、**Sender type** として **Promotional** を選択します。</li></ul> |
| **Sender name** | このフィールドは、キャンペーンやアラートの作成時に使用できる、読みやすい送信者名を識別します。 |
| **Operating country** | このフィールドは、メッセージの送信先となる国を識別します。 |
| **From type** | このフィールドは、エンドユーザーに SMS を送信する番号のタイプを識別します。From type には **Short code**、**Long code**、**Sender ID** があります。 |
| **SMS Service Number** | エンドユーザーに SMS を送信する送信者 ID です。たとえば、HDBCBK は HDFC 銀行がエンドカスタマーにメッセージを送信する際に使用しています。 |
| **Region** | AWS アカウントが設定されているリージョンを選択します。たとえば、AWS アカウントがムンバイでホストされている場合は、Asia Pacific (Mumbai) を選択する必要があります。 |
| **AWS access key** | AWS End User Messaging アカウントへのアクセスに使用するアクセスキーです。このキーが AWS End User Messaging アカウントのみにアクセスできることを確認してください。 |
| **AWS secret key** | AWS End User Messaging アカウントへのアクセスに使用するシークレットキーです。このキーが AWS End User Messaging アカウントのみにアクセスできることを確認してください。 |
| **Configuration set** | SMS 送信者の詳細を設定する際に AWS End User Messaging で作成した Configuration set の名前です。 |
| **Delivery tracking URL** | 配信確認を受け取るには、Delivery tracking URL をコピーして AWS End User Messaging ポータルに貼り付けます。 |
| **Incoming Message URL** | 受信確認を受け取るには、Incoming Message URL をコピーして AWS End User Messaging ポータルに貼り付けます。 |

5. **テスト SMS を送信** して、設定を確認します。
6. **Save** をクリックして、送信者設定を保存します。

# 配信トラッキングを設定する

配信トラッキングを設定すると、メッセージがエンドユーザーに配信されたかどうかを監視できます。

## AWS コンソールでの変更

設定済みの送信者について、AWS コンソールで配信トラッキングを設定するには、次の手順を実行します。

1. AWS コンソールにログインし、**AWS End User Messaging** を選択します。
2. 次のページの **Get started** セクションで、**SMS** \> **Manage SMS** を選択します。
   ![aws 1.png](/images/partner_36471908990612.png)
3. **Overview** ページで、**Step 2. Create a configuration set** にある **Manage sets** をクリックします。
   ![AWS 2.png](/images/partner_36471908994580.png)
4. 次の **Configuration sets** ページで、**Create configuration set** をクリックします。
   ![AWS 3.png](/images/partner_36471908995348.png)
5. **Create set** ページの **Configuration set name** ボックスに Configuration set の名前を入力し、**Create configuration set** ボタンをクリックします。ここで入力した名前をコピーし、MoEngage ダッシュボードで **Sender details** を設定する際に **Configuration set** ボックスに貼り付けます。
   ![AWS 4.png](/images/partner_36471909003924.png)
6. 次のページで **Event settings** タブに移動し、**Add event destination** をクリックします。
   ![AWS 5.png](/images/partner_36471909005332.png)
7. **Add event destination** ページの **Event Details** セクションで、次の詳細を入力します。
   ![AWS 6.png](/images/partner_36471909009300.png)
   1. **Event destination name** ボックスにイベント送信先の名前を入力します。
   2. **Destination type** として **Amazon SNS** を選択します。
   3. **New SNS standard topic** オプションを選択します。
   4. **Topic name** ボックスに新しい SNS トピックの名前を入力します。例: _test-new-topic_。
   5. **Event publishing** の下にある **Enabled** トグルをオンにします。
8. **Event types** セクションで、次を選択します。
   1. **All SMS events**
   2. **All MMS events**
   3. **All voice events**
9. **Create event** をクリックします。作成後、ベンダーが AWS にコールバックを送信するたびに、AWS は作成されたイベント送信先にコールバックを転送します。イベント送信先には SMS トピックのセットがあり、AWS はすべてのコールバックリクエストを SMS トピックに追加します。
10. SMS トピックから MoEngage にすべての配信フィードバックをプッシュするには、**Amazon SNS** に移動する必要があります。
    ![AWS 7.png](/images/partner_36471909010196.png)
11. Amazon SNS ページで **Topics** をクリックし、上記の手順で作成した SNS トピックを検索します。この例では、トピック名は _test-new-topic_ です。
    ![AWS 9.png](/images/partner_36471909011092.png)
12. トピック名をクリックし、次のページで **Subscriptions** \> **Create new subscription** に移動します。サブスクリプションは、SNS トピックにメッセージがプッシュされるたびに通知できます。
    ![AWS 10.png](/images/partner_36471909013396.png)
13. **Create subscription** ページで、次の詳細を追加します。
    ![AWS 11.png](/images/partner_36471909014420.png)
    1. **Topic ARN** は自動入力されます。
    2. **Protocol** として **HTTPS** を選択します。
    3. **Endpoint** ボックスに、MoEngage ダッシュボードからコピーした **Delivery tracking URL** を貼り付けます。
    4. **Raw message delivery** チェックボックスは有効に **しない** でください。
    5. **Create Subscription** をクリックします。正しく動作させるため、メッセージの送信を開始する前に、サブスクリプションの **Status** が **Confirmed** になっていることを確認してください。
       ![AWS 12.png](/images/partner_36471909016980.png)

# 受信メッセージ URL を設定する

受信メッセージ URL を設定すると、メッセージへの返信を追跡して、それに応じたアクションを実行できます。

## AWS コンソールでの変更

設定済みの送信者について、AWS コンソールで受信メッセージ URL を設定するには、次の手順を実行します。

1. AWS コンソールにログインし、**AWS End User Messaging** を選択します。
2. 次のページの **Get started** セクションで、**SMS** \> **Manage SMS** を選択します。
   ![aws 1.png](/images/partner_36471908990612.png)
3. 左側のパネルで **Configurations** をクリックし、**Phone numbers** を選択します。
   ![AWS 13.png](/images/partner_36471909019028.png)
4. **Phone numbers** ページで、受信メッセージを設定する電話番号を選択します。
5. 次のページで、**Two-way SMS** \> **Edit settings** に移動します。
   ![AWS 14.png](/images/partner_36471909021972.png)
6. **Edit settings** ページで、次の詳細を入力します。
   ![AWS 15.png](/images/partner_36471909023764.png)
   1. **Enable two-way message** チェックボックスをオンにします。
   2. **Destination type** として **Amazon SNS** を選択します。
   3. **New SNS standard topic** オプションを選択します。
   4. **Incoming messages destination** ボックスに、受信メッセージを受け取る Amazon SNS トピックの名前を入力します。例: _incoming-sms-topic._
   5. **Two-way channel role** で、**Use SNS topic policies** を選択します。
7. **Save changes** をクリックします。
8. **Amazon SNS** に移動します。
   ![AWS 7.png](/images/partner_36471909010196.png)
9. Amazon SNS ページで **Topics** をクリックし、上記の手順で作成した SNS トピックを検索します。配信コールバック用と受信メッセージ用に作成するトピックは別々である必要があることに注意してください。この例では、トピック名は _incoming-sms-topic_ です。
10. トピック名をクリックし、次のページで **Subscriptions** \> **Create new subscription** に移動します。サブスクリプションは、SNS トピックにメッセージがプッシュされるたびに通知できます。
    ![AWS 16.png](/images/partner_36471909025684.png)
11. **Create subscription** ページで、次の詳細を追加します。
    ![AWS 17.png](/images/partner_36471909026324.png)
    1. **Topic ARN** は自動入力されます。
    2. **Protocol** として **HTTPS** を選択します。
    3. **Endpoint** ボックスに、MoEngage ダッシュボードからコピーした **Incoming messages URL** を貼り付けます。
    4. **Raw message delivery** チェックボックスは有効に **しない** でください。
    5. **Create Subscription** をクリックします。正しく動作させるため、メッセージの送信を開始する前に、サブスクリプションの **Status** が **Confirmed** になっていることを確認してください。
       ![AWS 18.png](/images/partner_36471909027092.png)

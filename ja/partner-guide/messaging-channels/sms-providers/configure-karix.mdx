# はじめに

Karix は、企業が複数のチャネルにわたる双方向のマーケティングやカスタマーケアのやり取りをインテリジェントにパーソナライズできるようにする、モバイルエンゲージメントおよびコミュニケーションプロバイダーです。

<Info>
  **前提条件** Karix のダッシュボードにアクセスでき、Karix アカウントの API キーを用意していることを確認してください。
</Info>

# Karix をカスタム SMS コネクター (サービスプロバイダー) として設定する

この記事では、MoEngage ダッシュボードで Karix をカスタムコネクターとして設定する方法について説明します。

MoEngage ダッシュボードにログインし、次の手順に従います。

1. **Settings** \> **Channel** \> **SMS** \> **Sender Configuration** に移動します。
2. 右上隅にある **\+Add Service Provider** をクリックします。
3. **Sender Details** 画面で次の詳細を追加します。**Mark as default** このトグルをオンにすると、設定中のサービスプロバイダーのデフォルト送信者としてこの送信者がマークされます。デフォルトとしてマークすると、キャンペーン作成時に別の送信者を選択しない限り、MoEngage からのすべての SMS キャンペーンの送信にこの送信者が使用されます。

| フィールド | 説明 |
| --- | --- |
| **Service provider name** | このフィールドは MoEngage ダッシュボードで設定するサービスプロバイダーを識別するもので、一意である必要があります。ここにサービスプロバイダーの名前を入力します。 |
| **Sender name** | このフィールドは、キャンペーンやアラートの作成時に使用できる、読みやすい送信者名を識別します。 |
| **Sender type** | 送信者タイプは **Promotional** または **Transactional** のいずれかです。ブランドに関する情報の送信、お得な情報のプロモーション、またはユーザーとのエンゲージメントに送信者を使用する場合は、Sender type として Promotional を選択します。取引に関するアラート、OTP、セキュリティ情報、またはトランザクションとして分類できる情報の送信に送信者を使用する場合は、Sender type として Transactional を選択します。 |

4. 次の詳細を追加して Webhook を設定します。

| フィールド | 説明 |
| --- | --- |
| **API URL** | このフィールドには、送信者に API リクエストを送信する際に使用する URL の情報が含まれます。この情報は送信者の API ドキュメントから取得できます。ここに送信者の API エンドポイントを入力します。Karix の API URL は [http://japi.instaalerts.zone/httpapi/JsonReceiver](http://japi.instaalerts.zone/httpapi/JsonReceiver) です。 |
| **Method** | HTTP メソッドとして **POST** を選択します。 |
| **URL Parameters** | このオプションを使用して、API に渡す URL パラメーターをキーと値のペアとして追加します。この情報は送信者の API ドキュメントから取得できます。たとえば、API URL の呼び出しで GET メソッドを使用する場合、API Key や Authorization などのすべてのパラメーターが URL パラメーターとして渡されます。 |
| **Headers** | このオプションを使用して、API に渡すリクエストヘッダーをキーと値のペアとして追加します。この情報は送信者の API ドキュメントから取得できます。Authorization ヘッダーを追加します。 |

5. **Body Type** として JSON を選択し、次の詳細を追加します。
   <CodeGroup>
   ```json JSON
   {
     “messages”: [
       {
           “text”: “Moesms_message”,
           “dest”: [Moesms_destination],
           “send”: “SENDER_ID”
       }
     ],
     “key”: “API_KEY”,
     “ver”: “1.0”
   ]/pre
   ```
   </CodeGroup>
   次のキーの値を変更します。
   SENDER\_ID と API\_KEY - Karix アカウントの認証情報に従って設定します 
   (API キーの末尾に '=' がある場合は、Key Value Pair セクションに '=' を明示的に追加してください)
6. **テスト SMS を送信** して、設定を確認します。
7. **Save** をクリックして、送信者設定を保存します。
8. MoEngage ダッシュボードで送信者を作成した後、配信トラッキングを設定できます。配信トラッキングの詳細については、[カスタムコネクターの配信トラッキング](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/sms/getting-started-with-sms/configure-custom-connector-for-sms) を参照してください。
9. 配信トラッキングのレスポンスの属性は、手動または自動でマッピングできます。

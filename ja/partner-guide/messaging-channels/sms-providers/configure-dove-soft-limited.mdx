# はじめに

[Dove Soft Limited](https://dovesoft.io/) は、SMS、Voice、Email、RCS、WhatsApp Business Messaging などのエンタープライズ向けコミュニケーションサービスを提供しています。MoEngage と Dove Soft Limited の SMS 連携により、次の方法でエンドユーザーとコミュニケーションを取ることができます。

- Promotional、Service Implicit、Service Explicit といったさまざまなカテゴリーでの一括 SMS コミュニケーション。
- リアルタイムの配信状況の更新。

さらに、安全な SMS プラットフォームを通じてパーソナライズされたテキストを送信することで、セールスおよびマーケティングのエンゲージメントを自動化できます。

<Info>
  **前提条件**

  - Dove Soft Limited から必要な SMS Push API の詳細を取得した SMS アカウントを持っていることを確認してください。
  - アカウントのリージョンがインドの場合は、テンプレートを含む DLT 承認済みの詳細情報が必要です。
</Info>

# カスタム SMS コネクター (サービスプロバイダー) を設定する

次の手順を実行します。

1. MoEngage UI の左側のナビゲーションメニューで、**Settings** \> **Channel** \> **SMS & Connectors** に移動します。 <img src="/images/partner_39295173906964.png" alt="Screenshot 2025-07-14 at 3.09.47 PM.png" />
2. **SMS Connector Config** タブをクリックします。
3. Custom Connectors の横にある **\+ CREATE** をクリックします。 <img src="/images/partner_39295163500564.png" alt="Screenshot 2025-07-14 at 3.10.21 PM.png" />
4. 次の詳細を追加します。
   | フィールド | 説明 |
   | --- | --- |
   | Sender Type | Dove Soft の SMS アカウントに基づいて、送信者タイプとして Promotional または Transactional を選択します。<ul><li>ブランドに関する情報の送信、お得な情報のプロモーション、またはユーザーとのエンゲージメントに送信者を使用する場合は、送信者タイプとして **Promotional** を選択します。</li><li>取引に関するアラート、OTP、セキュリティ情報、またはトランザクションとして分類できる情報の送信に送信者を使用する場合は、送信者タイプとして **Transactional** を選択します。</li></ul> |
   | Connector Name | SMS コネクターを一意に識別するための名前 (例: "Dove Soft") を入力します。 |
   | Sender Name | 送信者名 (DLT 承認済みヘッダー) を入力します。 |
   | API URL | <ol><li>TIL から提供された HTTP エンドポイントに応じて、**POST** オプションを選択します。</li><li>Dove Soft の SMS Push エンドポイント (GET/POST) を、それぞれの認証情報/詳細とともに入力します。<ul><li>**POST API**: <ul><li>エンドポイント: [https://api.dovesoft.io/api/json/sendsms/](https://api.dovesoft.io/api/json/sendsms/)</li><li>POST エンドポイントでサポートされている JSON ペイロード構造を入力します。</li></ul></li></ul></li></ol> |
   | URL Parameters | キーと値のペア/JSON パラメーターの詳細: <ul><li>senderid= \[DLT 承認済みヘッダー\]</li><li>sms=Moesms\_message \[DLT 承認済みメッセージテキスト\]</li><li>mobiles=Moesms\_destination \[SMS の送信先の携帯電話番号\]</li><li>unicode=任意のフィールド \[0 は通常の英語 SMS テキストの場合の "false"、1 は Unicode SMS テキストの場合の "true" を示します。\]</li><li>isShortUrl=任意のフィールド \[0 は "false"、1 は "true" で、mobiCOMM CPaaS アプリケーションが長い URL を短縮 URL に変換します。\]</li><li>encryptContent=任意のフィールド \[0 は "false"、1 は "true" で、mobiCOMM CPaaS アプリケーションが暗号化されたコンテンツをデータベースに保存します。\]</li><li>entityid : **任意のフィールド** \[DLT PE ID\]</li><li>tempid : **任意のフィールド** \[DLT Template ID\]</li></ul> |
   | Headers | POST エンドポイントの場合は、次のキーと値のペアを入力します。<ul><li>Key: content-type Value: application/json</li><li>Key: key Value:XXXXXXXXXXX</li></ul> |
   | Delivery tracking | 配信トラッキングを行うには、カスタムコネクターを保存した後に編集します。次に **Map fields manually** オプションを選択し、次のようにマッピングします。<ul><li>Unique sent ID field: messageid</li><li>Unique delivery ID field \*: messageid</li><li>Delivery status field \*: errorstatus</li><li>Success values for delivery status \*: DELIVRD</li><li>Failure reason field \*: errorreason</li></ul> 設定のために、SMS 配信トラッキング URL を Times と共有してください。 |
5. **Body Type** (POST の場合のみ) には、次のコードを入力します。
   <CodeGroup>
   ```json JSON
    {
   "listsms": [
   {
   "sms": "Moesms_message",
   "mobiles": "Moesms_destination",
   "senderid": "[DLT approved Header]"
   }
   ]
   }
   ```
   </CodeGroup>
6. **Save** をクリックして、送信者設定を保存します。

# トラブルシューティング

テストメッセージの送信中や設定の保存中に問題が発生した場合は、次の手順を実行します。

- Dove Soft Limited のエンドポイントとそれぞれのパラメーター/JSON 構造は大文字と小文字が区別されるため、正しく追加されていることを確認してください。
- 問題が解決しない場合は、MoEngage にサポートリクエストを送信してエラーコードを取得してください。
- MoEngage サポートチームからエラーコードを受け取ったら、Dove Soft Limited のサポートチームに連絡して問題を解決してください。サポートメール: [**support@dove-soft.com**](mailto:support@dove-soft.com)

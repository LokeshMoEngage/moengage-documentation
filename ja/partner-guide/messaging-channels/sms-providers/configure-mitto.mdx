# はじめに

Mitto はオムニチャネルコミュニケーションソリューションのグローバルリーダーであり、SMS、音声、チャットアプリ向けの高度なテクノロジーとシームレスな連携によってビジネスの成長を支援しています。

<Info>
  **前提条件** Mitto のダッシュボードにアクセスでき、Mitto アカウントに関連付けられた API キーを用意していることを確認してください。
</Info>

# Mitto をカスタム SMS コネクター (サービスプロバイダー) として設定する

この記事では、MoEngage ダッシュボードで Mitto をカスタムコネクターとして設定する方法について説明します。

1. MoEngage ダッシュボードにログインします。
2. **Settings** \> **Channel** \> **SMS & Connectors** に移動します。
3. SMS Connector Config タブをクリックします。
4. **Custom Connectors** の下にある **\+ Create** をクリックします。 <img src="/images/partner_25209294465044.png" />
5. 次の詳細を追加します。
   - **Sender Type** : 要件に応じて **Transactional** または **Promotional** を選択します。ブランドに関する情報の送信、お得な情報のプロモーション、またはユーザーとのエンゲージメントに送信者を使用する場合は、Sender Type を **Promotional** に設定します。取引に関するアラート、OTP、セキュリティ情報、またはトランザクションとして分類できる情報の送信に送信者を使用する場合は、Sender Type を **Transactional** に設定します。 <img src="/images/partner_25209294470676.png" />
   - **Connector Name** : このフィールドは設定するカスタムコネクターを識別するもので、一意である必要があります。ここにコネクターの名前 **Mitto** を入力します。
   - **Sender Name** : このフィールドは、キャンペーンやアラートの作成時に使用できる、読みやすい送信者名を識別します。
   - **Is Default Sender** : この送信者をデフォルト送信者として設定する場合は、yes を選択します。
   - **API URL** : SMS サービスプロバイダーのベース URL です。
     - URL: [https://rest.mittoapi.com/sms.json](https://rest.mittoapi.com/sms.json)
     - ドロップダウンから POST を選択します。
   - **Headers**
     - **Content-Type** : application/json を選択します。
     - **X-Mitto-API-Key** : Mitto の一意の API キーを入力します。
     - **Body** : raw を選択し、次のペイロードを入力します。
       <CodeGroup>
       ```json JSON
        
       { 
       "from": "Mitto", 
       "to": "Moesms_destination",
       "text": "Moesms_message",
       "deliveryStatusesToNotify":"DELIVERED"
       }
       ```
       </CodeGroup>

![](/images/partner_25209294473876.png)

6. 配信トラッキング URL を連携します。

![](/images/partner_25209273896852.png)

7. 配信レスポンスで必要な属性とフィールドをマッピングします。 <img src="/images/partner_25209273900180.png" />
8. **Save** をクリックします。設定が完了しました。

これで、Mitto を MoEngage の SMS プロバイダーとして正常に設定できました。

# はじめに

Vonage は、消費者および企業向けの Communication Platform as a Service（CPaaS）プロバイダーであり、クラウドホスト型の音声、ビデオ、チャット、ショートメッセージサービス（SMS）を通じて、顧客があらゆるデバイスでつながり、コミュニケーションを取れるようにします。Vonage の SMS 機能と API 設定の最新情報については、Vonage の [SMS Channel User Guide](https://api.support.vonage.com/hc/en-us/articles/29661933371036-MoEngage-Connector-SMS-Channel-Guide) を参照してください。

<Info>
  **前提条件**

  Vonage ダッシュボードにアクセスできることを確認してください。
</Info>

# Vonage をカスタム SMS コネクター（サービスプロバイダー）として設定する

Vonage Conversations for MoEngage コネクターは Vonage Cloud Runtime 上で動作します。設定には、MoEngage でのカスタム SMS 送信者の作成、コネクターインスタンスのデプロイ、コネクター管理パネルでのベアラートークンの生成、配信トラッキングの設定が含まれます。このコネクターは、Standalone と Conversational Connect の 2 つの動作モードをサポートしています。

前提条件、詳細な設定手順、配信フィールドのマッピング、トラブルシューティングについては、[Vonage MoEngage Connector SMS Channel Guide](https://api.support.vonage.com/hc/en-us/articles/29661933371036-MoEngage-Connector-SMS-Channel-Guide) を参照してください。

# 代替手段: Vonage SMS API を直接使用する（コネクターを使用しない場合）

この記事では、MoEngage ダッシュボードで Vonage をカスタムサービスプロバイダーとして設定する方法を説明します。

作業を進める前に、Vonage API（Nexmo）の呼び出しに必要な次のパラメーターを用意してください。**Key** と **Secret** は [Vonage Dashboard](https://dashboard.nexmo.com/private/dashboard) で確認できます。[Vonage SMS API についてはこちら](https://docs.nexmo.com/messaging/sms-api/api-reference#authentic)もご覧ください。

| パラメーター | 説明 |
| --- | --- |
| api\_key | - お客様の Key。例: `api_key=n3xm0rocks` |
| api\_secret | - お客様の Secret。例: `api_secret=12ab34cd` |

MoEngage ダッシュボードにログインし、次の手順を実行します。

1. **Settings** \> **Channels** \> **SMS & RCS** \> **Sender configuration** \> **SMS** に移動します。
2. 右上の **\+Add SMS Sender** をクリックします。

<img src="images/vonage-sms-add-sender-button.png" alt="Add SMS Sender ボタンが表示された SMS & RCS の Sender configuration ページ" />

3. **Sender Details** 画面で次の詳細を追加します。

<img src="images/vonage-sms-direct-api-sender-details.png" alt="Vonage SMS API を直接使用する送信者の Sender Details 画面。General details と API details のフィールドが表示されています" />

| フィールド | 説明 |
| --- | --- |
| **Mark as default** | このトグルをオンにすると、設定中のサービスプロバイダーのデフォルト送信者としてこの送信者がマークされます。デフォルトに設定すると、キャンペーン作成時に別の送信者を選択しない限り、MoEngage から送信されるすべての SMS キャンペーンでこの送信者が使用されます。 |
| **Service provider name** | このフィールドは MoEngage ダッシュボードで設定するサービスプロバイダーを識別するもので、一意である必要があります。ここにサービスプロバイダー名を入力します。 |
| **Sender name** | このフィールドは、キャンペーンやアラートの作成時に使用できる、読みやすい送信者名を識別します。 |
| **Sender type** | Sender type は **Promotional** または **Transactional** のいずれかです。ブランドに関する情報の送信、キャンペーンやお得な情報の宣伝、ユーザーとのエンゲージメントに Sender を使用する場合は、Sender type として Promotional を選択します。取引に関するアラート、OTP、セキュリティ情報、またはトランザクションの性質を持つと分類できる情報の送信に Sender を使用する場合は、Sender type として Transactional を選択します。 |

4. 次の詳細を追加して Webhook を設定します。

| フィールド | 説明 |
| --- | --- |
| **API URL** | このフィールドには、Sender に API リクエストを送信する際に使用する URL の情報が含まれます。この情報は Sender の API ドキュメントで確認できます。ここに Sender の API エンドポイントを入力します。Vonage URL は次のとおりです: [https://rest.nexmo.com/sms/json](https://rest.nexmo.com/sms/json) |
| **Method** | HTTP メソッドとして **POST** を選択します。 |
| **URL Parameters** | このオプションを使用して、API に渡す URL パラメーターをキーと値のペアとして追加します。この情報は Sender の API ドキュメントで確認できます。たとえば、API URL の呼び出しで GET メソッドを使用する場合、API Key や Authorization などのすべてのパラメーターは URL パラメーターとして渡されます。 |
| **Headers** | このオプションを使用して、API に渡すリクエストヘッダーをキーと値のペアとして追加します。この情報は Sender の API ドキュメントで確認できます。Authorization ヘッダーを追加します。 |
| **Body Type** | Body Type として **Form** を選択し、次の詳細を追加します:<br /><br /><img src="/images/partner_21971526686484.png" alt="Vonage_NewUI_SenderConfig.png" /><br /><br />1. **Key** と **Secret** は [Vonage Dashboard](https://dashboard.nexmo.com/private/dashboard) で確認できます。<br />2. **to** フィールドに、ユーザーの携帯電話番号を渡すための _Moesms\_destination_ を追加します。<br />3. **text** フィールドに _Moesms\_message_ を追加します。<br />4. **from** フィールドに、Vonage から提供されたアカウントの送信者 ID を追加します。 |

5. **Send a test SMS** で設定を確認します。
6. **Save** をクリックして Sender Configuration を保存します。
7. MoEngage ダッシュボードで送信者を作成した後、配信トラッキングを設定できます。配信トラッキングの詳細については、[カスタムコネクターの配信トラッキング](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/sms/getting-started-with-sms/configure-an-sms-sender)を参照してください。

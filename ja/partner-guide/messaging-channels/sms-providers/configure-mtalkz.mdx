# はじめに

[Mtalkz](https://mtalkz.com/) は、プラットフォームベースのデジタルエンゲージメントおよびコミュニケーションサービス企業で、大量メッセージングサービスに加え、マーケティングオートメーション、ワークフローオートメーション、AI/ML を活用した予測インサイトを提供しています。

# 統合

<Warning>
  **前提条件**

  Mtalkz Dashboard にアクセスでき、アカウントの API キーを保有していることを確認してください。
</Warning>

## Mtalkz をカスタム SMS コネクターとして設定する

MoEngage ダッシュボードにログインします。

1. _SMS Connector Config タブ_ をクリックします。
2. _Custom Connecters_ の下で、_\+CREATE._ をクリックします。 <img src="https://lh4.googleusercontent.com/zh1yjNfHUs8T5aZFpLpZwNUVKZkxyMMNaVXaiXLLGshfNPDTfbRLCf4fDyOqfEepSSaR9XRSKK20V1rw790tQk0fDfcY_kEzrRnaKFVGPsEmZGcv4BwFGqAH3W1IT3-sGnkRtl7VfckkzISQj6zGkSU" />
3. 次の詳細を追加します。
   - **Sender Type-** 要件に応じて Transactional または Promotional を選択します。
     - Promotional: ブランドに関する情報の送信、キャンペーンやお得な情報の宣伝、ユーザーとのエンゲージメントに Sender を使用する場合は、Sender Type として Promotional を選択します。
     - Transactional: 取引に関するアラート、OTP、セキュリティ情報、またはトランザクションの性質を持つと分類できる情報の送信に Sender を使用する場合は、Sender Type として Transactional を選択します。
   - **Connector Name -** このフィールドは MoEngage ダッシュボードで設定するカスタムコネクターを識別するもので、一意である必要があります。ここにコネクター名を入力します - MTALKZ
   - **Sender Name -** このフィールドは、キャンペーンやアラートの作成時に使用できる、読みやすい送信者名を識別します。
   - **Is Default Sender -** ユーザーの選択（Yes または No を選択）
   - **API URL -** SMS サービスプロバイダーのベース URL と、SMS 送信 API を呼び出す際に使用できるすべてのクエリパラメーターです。
     ```text wrap
     [http://msg.mtalkz.com/V2/http-api-post.php?campaign_name=moengage&message=Moesms_message&number=Moesms_destination&template_id=Moesms_dltTemplateId](http://msg.mtalkz.com/V2/http-api-post.php?campaign_name=moengage&message=Moesms_message&number=Moesms_destination&template_id=Moesms_dltTemplateId)
     ```
     <img src="/images/partner_17119783701140.png" alt="スクリーンショット" />\
     ドロップダウンボタン: _GET_ を選択します
   - **URL Parameters:** Campaign\_name - moengage\
     Message - Moesms\_message\
     Number - Moesms\_destination\
     Template\_id -Moesms\_dltTemplateId\
     <img src="/images/partner_17119791138580.png" alt="スクリーンショット" />
   - **Headers:** Content-Type - application/json
   - **Body:**  _RAW_ を選択し、次のペイロードを入力します。
     ```json
     {  
       "apikey": "apikey",  
       "senderid": "MTALKZ",  
       "number": "Moesms_destination",  
       "message":"Moesms_message",  
       "campaign_name":"moengage DLR",  
       "format":"json"  
     }
     ```
     ![スクリーンショット](/images/partner_17119776516372.png)
4. Save をクリックします。以上で設定は完了です。

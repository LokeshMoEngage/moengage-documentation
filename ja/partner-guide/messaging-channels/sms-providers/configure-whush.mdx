# はじめに

Whush は、SMS、IVR/OBD、WABA などのサービスを提供する CPaaS プラットフォームで、企業が顧客と効率的にコミュニケーションを取れるようにします。Whush のサービスは包括的かつエンドツーエンドであり、企業は DLT 登録からキャンペーン管理まで、適切なタイミングで適切なチャネルを使用して、安心してお任せいただけます。

# Whush をカスタム SMS コネクター（サービスプロバイダー）として設定する

この記事では、コミュニケーションキャンペーンのスケジュール設定に MoEngage を使用している企業向けに、MoEngage プラットフォームで Whush をカスタム SMS コネクター（サービスプロバイダー）として設定する方法を説明します。

MoEngage ダッシュボードにログインし、次の手順を実行します。

1. **Settings** -\> **Channel** -\> **SMS** に移動します。
2. **Sender Configuration** タブで **\+ Add Sender** をクリックします。Add sender ページが表示されます。
3. ステップ 1「Service Provider」で、**\+ Add custom service provider** をクリックします。Add Custom Connector sender ページが表示されます。
4. ステップ 2「Sender Details」で次の詳細を追加します。

| フィールド | 説明 |
| --- | --- |
| **Mark as default** | このトグルをオンにすると、設定中のサービスプロバイダーのデフォルト送信者としてこの送信者がマークされます。デフォルトに設定すると、キャンペーン作成時に別の送信者を選択しない限り、MoEngage から送信されるすべての SMS キャンペーンでこの送信者が使用されます。 |
| **Service provider name** | このフィールドは MoEngage ダッシュボードで設定するサービスプロバイダーを識別するもので、一意である必要があります。「Whush」と入力します。 |
| **Sender name** | このフィールドは、キャンペーンやアラートの作成時に使用できる、読みやすい送信者名を識別します。「Whush」と入力します。 |
| **Sender type** | 送信者タイプを選択します。利用可能なオプションは次のとおりです: <ul><li>**Transactional** : 取引に関するアラート、OTP、セキュリティ情報、またはトランザクションの性質を持つと分類できる情報の送信に送信者を使用する場合は、このオプションを選択します。</li><li>**Promotional** : ブランドに関する情報の送信、お得な情報の宣伝、ユーザーとのエンゲージメントに送信者を使用する場合は、このオプションを選択します。</li></ul> |

5. 次の詳細を追加して Webhook を設定します。

| フィールド | 説明 |
| --- | --- |
| **API URL** | このフィールドには、送信者に API リクエストを送信する際に使用する URL の情報が含まれます。この情報は送信者の API ドキュメントで確認できます。ここに送信者の API エンドポイントを入力します。Whush の API URL は次のとおりです: [https://whush.pludous.com/whush-send-sms](https://whush.pludous.com/whush-send-sms) |
| **Method** | HTTP メソッドとして **POST** を選択します。 |
| **URL parameters** | このオプションを使用して、API に渡す URL パラメーターをキーと値のペアとして追加します。この情報は送信者の API ドキュメントで確認できます。たとえば、API URL の呼び出しで GET メソッドを使用する場合、API Key や Authorization などのすべてのパラメーターは URL パラメーターとして渡されます。 |
| **Headers** | このオプションを使用して、API に渡すリクエストヘッダーをキーと値のペアとして追加します。この情報は送信者の API ドキュメントで確認できます。Authorization ヘッダーを追加します。 |

6. **Body Type** フィールドに、次のコードを入力します。
   <CodeGroup>
   ```text JSON wrap
   curl --location 'https://api.whush.io/api/v1/one2One' \
   --header 'Content-Type: application/json' \
   --header 'apikey: A2D31FB9BA1C7E1356FF' \
   --data '{
   "credentials": {
        "password": "apimo",
        "user": "apimo"
   				},
   "options": {},
   "unicode": "false",
   "from": "CRDHAT",
   "shortMessages": [
   	{
   	"recipient": "Number",
   	"corelationId": "0e6503aa-1ac7-4a0c-9819-beb69cfdedca",
   	"message": "Template"
   	}
   ]
   }'
   ```
   </CodeGroup>
7. **Send test SMS** をクリックして設定を確認します。
8. **Save** をクリックして送信者の設定を保存します。
9. MoEngage ダッシュボードで送信者を作成した後、配信トラッキングを設定できます。配信トラッキングの詳細については、[カスタムコネクターの配信トラッキング](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/sms/getting-started-with-sms/configure-custom-connector-for-sms)を参照してください。
10. 配信トラッキングレスポンスの属性は、手動または自動でマッピングできます。

# はじめに

Gupshup は、SMS、WhatsApp、Facebook Messenger など、さまざまなメッセージングチャネルでチャットボットやその他の会話型エクスペリエンスを構築、デプロイ、管理できる会話型メッセージングプラットフォームです。

# RCS コネクター (サービスプロバイダー) を設定する

MoEngage ダッシュボードで Gupshup をコネクターとして設定するには、次の手順を実行します。

1. MoEngage ダッシュボードの左側のナビゲーションメニューで、**Settings** \> **Channels** \> **SMS/RCS** \> **Sender configuration** に移動します。
2. **RCS** タブで、**\+** **Add RCS Sender** をクリックします。
3. **Gupshup** タイルをクリックします。
4. **Sender Details** ページで、次の詳細を追加します。
   ![Screenshot 2025-03-17 at 2.45.34 PM.png](/images/partner_35725588796948.png)

| フィールド | 説明 |
| --- | --- |
| **Mark as default** | このトグルをオンにすると、設定中のサービスプロバイダーのデフォルト送信者としてこの送信者がマークされます。デフォルトとしてマークすると、キャンペーン作成時に別の送信者を選択しない限り、MoEngage からのすべての RCS キャンペーンの送信にこの送信者が使用されます。 |
| **Sender type** | 送信者タイプを選択します。利用可能なオプションは次のとおりです。<ul><li>**Promotional** : ブランドに関する情報の送信、お得な情報のプロモーション、またはユーザーとのエンゲージメントに送信者を使用する場合は、このオプションを選択します。</li><li>**Transactional** : 取引に関するアラート、OTP、セキュリティ情報、またはトランザクションとして分類できる情報の送信に送信者を使用する場合は、このオプションを選択します。</li><li>**OTP** : OTP の送信に送信者を使用する場合は、このオプションを選択します。</li></ul> |
| **Sender Name** | 送信者の名前を入力します。このフィールドは、キャンペーンやアラートの作成時に使用できる、読みやすい送信者名を識別します。 |
| **Sender ID** | 送信者 ID を入力します。これは、RBM がユーザーに RCS メッセージを送信するために使用する RCS エージェント/ボット ID です。 |
| **API URL** | この API URL は Gupshup チームから取得できます。 |
| **User ID** | RCS 番号が登録されている Gupshup アカウント (Notification アカウント) のユーザー名です。Gupshup のユーザー名は通常、2000201234 (サンプル値) のような 10 桁の数字です。 |
| **Password** | Gupshup アカウントのパスワードです。 |

5. **Save** をクリックして、この送信者設定を保存します。
6. **Incoming Messages & Delivery callback URL**: 配信トラッキングを設定すると、メッセージがエンドユーザーに配信されたかどうかを監視できます。また、受信メッセージ URL を設定すると、メッセージへの返信を追跡して、それに応じたアクションを実行できます。MoEngage ダッシュボードからこの URL をコピーし、設定してもらえるよう Gupshup チームにメールで送信してください。

# はじめに

ICS は、企業が複数のチャネルにわたる双方向のマーケティングやカスタマーケアのやり取りをインテリジェントにパーソナライズできるようにする、モバイルエンゲージメントおよびコミュニケーションプロバイダーです。MoEngage は RCS メッセージング向けに ICS とのネイティブ連携を提供しており、ブランドは MoEngage プラットフォームから直接、テンプレート化された RCS メッセージを簡単に送信できます。

# MoEngage で ICS を RCS 送信者として設定する

次の手順を実行します。

1. MoEngage UI の左側のナビゲーションメニューで、**Settings** \> **Channels** \> **SMS, MMS & RCS** \> **Sender configuration** に移動します。
2. **RCS** タブで、**\+ Add RCS Sender** をクリックします。
   ![ics 2.png](/images/partner_45070290844692.png)
3. **ICS** タイルをクリックします。
   ![ics1.png](/images/partner_45035483033492.png)
4. Sender Details ページで、次の詳細を追加します。
   ![ics 3.png](/images/partner_45035483033748.png)

| フィールド | 説明 |
| --- | --- |
| **Sender type** | 送信者タイプを選択します。利用可能なオプションは次のとおりです。<ul><li>**Promotional** : ブランドに関する情報の送信、お得な情報のプロモーション、またはユーザーとのエンゲージメントに送信者を使用する場合は、このオプションを選択します。</li><li>**Transactional** : 取引に関するアラート、OTP、セキュリティ情報、またはトランザクションとして分類できる情報の送信に送信者を使用する場合は、このオプションを選択します。</li><li>**OTP** : OTP の送信に送信者を使用する場合は、このオプションを選択します。</li></ul> |
| **Sender Name** | 送信者の名前を入力します。このフィールドは、キャンペーンやアラートの作成時に使用できる、読みやすい送信者名を識別します。 |
| **Sender ID** | 送信者 ID を入力します。これは、RBM がユーザーに RCS メッセージを送信するために使用する RCS エージェント/ボット ID です。 |
| **API URL** | この API URL は ICS チームから取得できます。 |
| **Authorization** | このフィールドは、ValueFirst プラグインの設定セクションで確認できる Bearer トークンを指します。このトークンは ICS チームから取得できます。 |
| **Incoming Messages & Delivery callback URL** | 配信トラッキングを設定すると、メッセージがエンドユーザーに配信されたかどうかを監視できます。受信メッセージ URL を設定すると、メッセージへの返信を追跡して、それに応じたアクションを実行できます。MoEngage UI からこの URL をコピーし、設定のために ICS チームにメールで送信してください。 |

5. **Save** をクリックして、この設定を保存します。

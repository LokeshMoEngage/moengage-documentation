# はじめに

Equence は、インド全土の企業に SMS、音声、WhatsApp、RCS メッセージングを提供するエンタープライズモビリティソリューションプロバイダーです。MoEngage は RCS 向けに Equence とネイティブに統合されており、1 つ以上の Equence 送信者を通じてユーザーに RCS メッセージを送信できます。

<Tip>
  **前提条件**

  Equence アカウントにアクセスでき、RCS エージェントが登録されているアカウントの認証トークンを保有していることを確認してください。認証情報についてサポートが必要な場合は、Equence のアカウントマネージャーまたは Equence サポートにお問い合わせください。
</Tip>

# Equence を RCS コネクター (サービスプロバイダー) として設定する

Equence をコネクターとして設定するには、次の手順を実行します。

1. MoEngage UI の左側のナビゲーションメニューで、**Settings** \> **Channels** \> **SMS & RCS** \> **Sender configuration** に移動します。
2. **RCS** タブで、**\+ Add RCS Sender** をクリックします。
3. **Equence** タイルをクリックします。
   ![RCS サービスプロバイダーとして Equence を選択](/images/configure-equence-rcs-select-provider.png)
4. **Sender Details** ページで、次の詳細を追加します。
   ![Equence RCS の Sender Details ページ](/images/configure-equence-rcs-sender-details.png)

| フィールド | 説明 |
| --- | --- |
| **Sender type** | 送信者タイプを選択します。利用可能なオプションは次のとおりです。<ul><li>**Transactional**: 取引に関するアラート、セキュリティ情報、またはトランザクションとして分類できる情報の送信に送信者を使用する場合は、このオプションを選択します。</li><li>**Promotional**: ブランドに関する情報の送信、お得な情報のプロモーション、またはユーザーとのエンゲージメントに送信者を使用する場合は、このオプションを選択します。</li><li>**OTP**: OTP の送信に送信者を使用する場合は、このオプションを選択します。</li></ul> |
| **Sender Name** | 送信者の名前を入力します。このフィールドは、キャンペーンやアラートの作成時に使用できる、読みやすい送信者名を識別します。 |
| **Sender ID** | 送信者 ID を入力します。これは、RCS Business Messaging (RBM) がユーザーに RCS メッセージを送信するために使用する RCS エージェントまたはボット ID です。 |
| **Authorization** | 認証に使用されるベアラートークンです。このトークンは、Equence のアカウントマネージャーまたは Equence サポートから取得できます。 |

5. **Incoming Messages & Delivery callback URL** をコピーし、Equence ポータルに貼り付けて配信確認を受信できるようにします。
6. **Save** をクリックして、この送信者設定を保存します。

# はじめに

Alot Solutions は、SMS、WhatsApp、Voice、Email、RCS、Chatbot を通じて企業が顧客とエンゲージできるようにする、大手コミュニケーションプラットフォームです。安全でスケーラブルかつパーソナライズされたエンゲージメント戦略を提供し、キャンペーンを最適化してカスタマーサービスを強化します。あらゆる規模の企業から信頼されています。

<Tip>
  Alot Solutions のダッシュボードにアクセスでき、Alot Solutions アカウントの API キーを用意していることを確認してください。
</Tip>

# Alot Solutions をカスタム RCS コネクター (サービスプロバイダー) として設定する

Alot Solutions をコネクターとして設定するには、次の手順を実行します。

1. MoEngage UI の左側のナビゲーションメニューで、**Settings** \> **Channels** \> **SMS & RCS** \> **Sender configuration** に移動します。
2. **RCS** タブで、**\+** **Add RCS Sender** をクリックします。
3. **alotdigital** タイルをクリックします。
4. Sender Details ページで、次の詳細を追加します。 <img src="/images/partner_39721982683028.png" alt="RCS_Details.png" />

| フィールド | 説明 |
| --- | --- |
| **Mark as default** | このトグルをオンにすると、設定中のサービスプロバイダーのデフォルト送信者としてこの送信者がマークされます。デフォルトとしてマークすると、キャンペーン作成時に別の送信者を選択しない限り、MoEngage からのすべての RCS キャンペーンの送信にこの送信者が使用されます。 |
| **Sender type** | 送信者タイプを選択します。利用可能なオプションは次のとおりです。<ul><li>**Promotional**: ブランドに関する情報の送信、お得な情報のプロモーション、またはユーザーとのエンゲージメントに送信者を使用する場合は、このオプションを選択します。</li><li>**Transactional**: 取引に関するアラート、セキュリティ情報、またはトランザクションとして分類できる情報の送信に送信者を使用する場合は、このオプションを選択します。</li><li>**OTP**: OTP の送信に送信者を使用する場合は、このオプションを選択します。</li></ul> |
| **Sender Name** | このフィールドは送信者を識別します。ここに送信者の名前を入力します。 |
| **Sender ID** | 送信者 ID を入力します。これは、RBM がユーザーに RCS メッセージを送信するために使用する RCS エージェント/ボット ID です。 |
| **API URL** | このフィールドには、送信者に API リクエストを送信する際に使用する URL の情報が含まれます。ここに送信者の API エンドポイントを入力します。Alot Solutions の API URL は [https://web.rcspro.in/api/v1/rcsmt/sendMessage](https://web.rcspro.in/api/v1/rcsmt/sendMessage) です。 |
| **Authorization** | 認証に使用する Bearer トークンです。このトークンは Alot Solutions チームから取得できます。 |

5. **Save** をクリックして、この送信者設定を保存します。\
   配信トラッキングを設定すると、エンドユーザーへのメッセージ配信のステータスを監視できます。同様に、ユーザーの返信を追跡して適切なアクションを実行するには、受信メッセージ URL を設定する必要があります。続行するには、MoEngage UI から URL をコピーし、設定のために Alot Solutions チームにメールで送信してください。

# SMS フォールバックを設定する

SMS フォールバックを設定するには、次の手順を実行します。

1. MoEngage UI の左側のナビゲーションメニューで、**Settings** \> **Channels** \> **SMS & RCS** \> **Sender configuration** に移動します。
2. **SMS** タブで、右上隅にある **\+ Add custom service provider** をクリックします。
3. Sender Details ページで、次の詳細を追加します。 <img src="/images/partner_39721989653268.png" alt="sms_config.png" />

| フィールド | 説明 |
| --- | --- |
| **Mark as default** | このトグルをオンにすると、設定中のサービスプロバイダーのデフォルト送信者としてこの送信者がマークされます。デフォルトとしてマークすると、キャンペーン作成時に別の送信者を選択しない限り、MoEngage からのすべての SMS キャンペーンの送信にこの送信者が使用されます。 |
| **Service Provider Name** | このフィールドは MoEngage UI で設定するサービスプロバイダーを識別するもので、一意である必要があります。ここにサービスプロバイダーの名前を入力します。 |
| **Sender Name** | このフィールドは送信者を識別します。ここに送信者の名前を入力します。 |
| **Sender ID** | 送信者 ID を入力します。<br />**注**: インド電気通信規制庁 (TRAI) のガイドラインに準拠するため、インドの顧客に送信される短縮リンクを含む SMS メッセージには、この送信者 ID が [HTTP://ux.mnge.co/SenderID/XXXXX](HTTP://ux.mnge.co/SenderID/XXXXX) の形式で含まれます。 |

![](/images/partner_39592896166164.png)

| フィールド | 説明 |
| --- | --- |
| **Sender type** | 送信者タイプは Promotional または Transactional です。<ul><li>**Promotional**: ブランドに関する情報の送信、お得な情報のプロモーション、またはユーザーとのエンゲージメントに送信者を使用する場合は、このオプションを選択します。</li><li>**Transactional**: 取引に関するアラート、OTP、セキュリティ情報、またはトランザクションとして分類できる情報の送信に送信者を使用する場合は、このオプションを選択します。</li></ul> |
| **API URL** | このフィールドには、送信者に API リクエストを送信する際に使用する URL の情報が含まれます。この情報は送信者の API ドキュメントから取得できます。ここに送信者の API エンドポイントを入力します。Alot Solutions の API URL は [https://web.rcspro.in/api/v1/rcsmt/sendMessage](https://web.rcspro.in/api/v1/rcsmt/sendMessage) です。 |
| **Method** | HTTP メソッドとして **POST** を選択します。 |
| **URL Parameters** | このオプションを使用して、API に渡す URL パラメーターをキーと値のペアとして追加します。この情報は送信者の API ドキュメントから取得できます。たとえば、API URL の呼び出しで GET メソッドを使用する場合、API Key や Authorization などのすべてのパラメーターが URL パラメーターとして渡されます。 |

![sms header details.png](/images/partner_39721989654164.png)

| フィールド | 説明 |
| --- | --- |
| **Headers** | キーに **Content-Type**、値に **application/json** を指定したリクエストヘッダーを含めます。 |
| **Body Type** | Body Type として **JSON** を選択し、次の詳細を追加する必要があります。 |

<CodeGroup>

```json JSON
{
  "Account": {
    "APIKey": "Your_API_Key_Here",
    "SenderId": "Your_Sender_ID_Here",
    "Channel": "Your_Route_Name_Here",
    "DCS": 0,
    "FlashSms": 0,
    "PEID": "Your_Entity_ID_Here"
  },
  "Messages": [
    {
      "Number": "Moesms_destination",
      "Text": "Moesms_message",
      "DLTTemplateId": "Moesms_dltTemplateId"
    }
  ]
}
```

</CodeGroup>

**注**:

- **APIKey**: Alot Solutions アカウントの API キーを入力します。
- **SenderId:** キャンペーン用に承認された送信者 ID に置き換えます。
- **Channel**: 正しいルート名 ("TRANS" や "PROMO" など) を使用します。
- **PEID**: Alot Solutions から提供された一意の Entity ID に置き換えます。

4. **テスト SMS を送信** して、設定を確認します。
5. **Save** をクリックして、送信者設定を保存します。
6. MoEngage UI で送信者を作成した後、配信トラッキングを設定できます。 <img src="/images/partner_39721982686228.png" alt="sms dlr details.png" />

## DLR 手動フィールドマッピングガイド

次のフィールドマッピングで DLR 設定を行う必要があります。

- 一意の ID を格納する属性: MessageData.\[0\].MessageId
- 一意の配信 ID を格納する属性: MessageId
- 配信ステータスを格納する属性: ErrorCode
- 配信ステータスの成功値: 000, 001
- 失敗理由を格納する属性: MessageStatus

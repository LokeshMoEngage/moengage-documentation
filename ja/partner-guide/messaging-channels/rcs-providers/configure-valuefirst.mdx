# はじめに

MoEngage は RCS メッセージング向けに ValueFirst とのネイティブ連携を提供しており、ブランドは MoEngage プラットフォームから直接、テンプレート化された RCS メッセージを簡単に送信できます。この連携では、メッセージの配信、既読、クリックに関するリアルタイムのインサイトも MoEngage UI 内で提供されるため、ブランドはキャンペーンのパフォーマンスを効果的に追跡できます。この強力な組み合わせにより、ブランドは大規模に顧客と有意義でパーソナライズされた関係を築くことができます。

# MoEngage で ValueFirst を RCS 送信者として設定する

次の手順を実行します。

1. MoEngage UI の左側のナビゲーションメニューで、**Settings** \> **Channels** \> **SMS & RCS** \> **Sender Configuration** に移動します。
2. **RCS** タブで、**\+ Add RCS Sender** をクリックします。 <img src="/images/partner_39330454501780.png" alt="IMG 3.jpg" />
3. **ValueFirst** タイルをクリックします。 <img src="/images/partner_39330454503316.png" alt="IMG 1.jpg" />
4. Sender Details ページで、次の詳細を追加します。 <img src="/images/partner_39330454504212.png" alt="IMG 2.jpg" />

| フィールド | 説明 |
| --- | --- |
| **Sender Type** | 送信者タイプを選択します。利用可能なオプションは次のとおりです。<ul><li>**Promotional** : ブランドに関する情報の送信、お得な情報のプロモーション、またはユーザーとのエンゲージメントに送信者を使用する場合は、このオプションを選択します。</li><li>**Transactional** : 取引に関するアラート、OTP、セキュリティ情報、またはトランザクションとして分類できる情報の送信に送信者を使用する場合は、このオプションを選択します。</li><li>**OTP** : OTP の送信に送信者を使用する場合は、このオプションを選択します。</li></ul> |
| **Sender Name** | 送信者の名前を入力します。このフィールドは、キャンペーンやアラートの作成時に使用できる、読みやすい送信者名を識別します。 |
| **Sender ID** | 送信者 ID を入力します。これは、RBM がユーザーに RCS メッセージを送信するために使用する RCS エージェント/ボット ID です。これは (ValueFirst から取得した) **RCS ボット ID** です。 |
| **Authorization** | このフィールドは、ValueFirst プラグインの設定セクションで確認できる Bearer トークンを指します。これは ValueFirst チームから取得できます。 |
| **API URL** | この API URL は ValueFirst チームから取得できます。 |

5. **Save** をクリックして、この設定を保存します。

# 配信トラッキング (コールバック) を設定する

配信トラッキングを設定すると、メッセージがエンドユーザーに配信されたかどうかを監視できます。受信メッセージ URL を設定すると、メッセージへの返信を追跡して、それに応じたアクションを実行できます。MoEngage UI からこの URL をコピーして ValueFirst チームにメールで送信するか、アカウントマネージャーに相談して設定を依頼してください。

# はじめに

[OneXtel](https://www.onextel.com/) は、シームレスなエンドツーエンドのコミュニケーションソリューションを提供する、大手 CPaaS (Communication Platform as a Service) プロバイダーです。あらゆる規模の企業向けに、SMS、Voice、WhatsApp、Chatbot、RCS、Email などのチャネルのサービスを提供しています。

<Info>
  次のものにアクセスできることを確認してください。

  - 365cx.io 上の有効な OneXtel アカウント
  - 有効な MoEngage アカウント
</Info>

# OneXtel を MoEngage の RCS コネクタープロバイダーとして設定する

次の手順を実行します。

1. MoEngage UI の左側のナビゲーションメニューで、**Settings** \> **Channels** \> **SMS & RCS** \> **Sender Configuration** に移動します。
2. **RCS** タブで、**\+ Add RCS Sender** をクリックします。

   ![RCS 送信者](/images/rcs-sender.png)
3. **OneXtel** タイルをクリックします。

   ![タイル](/images/tile.png)
4. **Sender Details** ページで、次の詳細を追加します。

   ![詳細ページ](/images/details-page.png)

| フィールド | 説明 |
| --- | --- |
| **Sender type** | 送信者タイプを選択します。利用可能なオプションは次のとおりです。<ul><li>**Transactional**: 取引に関するアラート、OTP、セキュリティ情報、またはトランザクションとして分類できる情報の送信に送信者を使用する場合は、このオプションを選択します。</li><li>**Promotional**: ブランドに関する情報の送信、お得な情報のプロモーション、またはユーザーとのエンゲージメントに送信者を使用する場合は、このオプションを選択します。</li><li>**OTP**: OTP の送信に送信者を使用する場合は、このオプションを選択します。</li></ul> |
| **Sender Name** | 送信者の名前を入力します。このフィールドは、キャンペーンやアラートの作成時に使用できる、読みやすい送信者名を識別します。 |
| **Sender ID** | 送信者 ID を入力します。これは、RBM がユーザーに RCS メッセージを送信するために使用する RCS エージェント/ボット ID です。これは (OneXtel から取得した) **RCS ボット ID** です。 |
| **API URL** | この API URL は OneXtel チームから取得できます。 |
| **Authorization** | このフィールドは、認証に使用する Bearer トークンを指します。このトークンは OneXtel チームから取得できます。 |

5. **Save** をクリックして、この設定を保存します。

## **Incoming Messages & Delivery callback URL を設定する**

配信トラッキングを設定すると、メッセージがエンドユーザーに配信されたかどうかを監視できます。受信メッセージ URL を設定すると、メッセージへの返信を追跡して、それに応じたアクションを実行できます。MoEngage UI からこの URL をコピーして OneXtel チームにメールで送信するか、アカウントマネージャーに相談して設定を依頼してください。

---
title: "Sinch India の設定"
---

Sinch India は、パーソナライズされた安全でスケーラブルなメッセージングエクスペリエンスを通じて、企業が顧客とつながることを可能にするクラウドコミュニケーションプラットフォームです。SMS、音声、メール、RCS、WhatsApp などに対応した強力な API とソリューションのスイートにより、Sinch は顧客とのあらゆるタッチポイントでシームレスなオムニチャネルエンゲージメントを実現します。

# Sinch India を RCS コネクター (サービスプロバイダー) として設定する

Sinch India をコネクターとして設定するには、次の手順を実行します。

1. MoEngage UI の左側のナビゲーションメニューで、**Settings** \> **Channels** \> **SMS & RCS** \> **Sender configuration** に移動します。
2. **RCS** タブで、**\+ Add RCS Sender** をクリックします。
3. **Sinch India** タイルをクリックします。
4. Sender Details ページで、次の詳細を追加します。
   ![MoEngageConfiguration.png](/images/partner_39591320439444.png)

| フィールド | 説明 |
| --- | --- |
| Sender type | 送信者タイプを選択します。オンボーディング時に Sinch India で作成したものと同じ送信者タイプである必要があります。<ul><li>**Promotional** : ブランドに関する情報の送信、お得な情報のプロモーション、またはユーザーとのエンゲージメントに送信者を使用する場合は、このオプションを選択します。</li><li>**Transactional** : 取引に関するアラート、セキュリティ情報、またはトランザクションとして分類できる情報の送信に送信者を使用する場合は、このオプションを選択します。</li><li>**OTP** : OTP の送信に送信者を使用する場合は、このオプションを選択します。</li></ul> |
| Sender Name | 送信者の名前を入力します。このフィールドは、キャンペーンやアラートの作成時に使用できる、読みやすい送信者名を識別します。 |
| Sender ID | 送信者 ID を入力します。これは SmartTA に表示される Sinch プラットフォームのアプリ ID です。Sinch India のオンボーディングチームから取得できます。 |
| API URL | この API URL は Sinch India のオンボーディングチームから取得できます。 |
| ProjectID | この ProjectId は Sinch India のオンボーディングチームから取得できます。 |
| AppID | この App ID は Sinch India のオンボーディングチームから取得できます。 |
| User | この User は Sinch India のオンボーディングチームから取得できます。 |
| Pass | この Pass は Sinch India のオンボーディングチームから取得できます。 |

5. **Save** をクリックして、この送信者設定を保存します。
6. **Incoming Messages and delivery callback URL** : 配信トラッキングを設定すると、メッセージがエンドユーザーに配信されたかどうかを監視できます。受信メッセージ URL を設定すると、メッセージへの返信を追跡して、それに応じたアクションを実行できます。MoEngage UI からこの URL をコピーし、設定してもらえるよう Sinch India のオンボーディングチームにメールで送信してください。

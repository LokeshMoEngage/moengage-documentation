# はじめに

Trustsignal は、SMS、WhatsApp、RCS、Email、Voice など、さまざまなメッセージングチャネルでチャットボットやその他の会話型エクスペリエンスを構築、デプロイ、管理できる会話型メッセージングプラットフォームです。

<Info>
  **前提条件**

  Trustsignal のダッシュボードにアクセスでき、Trustsignal アカウントの API キーを用意していることを確認してください。
</Info>

# RCS コネクター (サービスプロバイダー) を設定する

MoEngage ダッシュボードで Trustsignal をコネクターとして設定するには、次の手順を実行します。

1. MoEngage ダッシュボードの左側のナビゲーションメニューで、**Settings** \> **Channels** \> **SMS, MMS & RCS** \> **Sender configuration** に移動します。
2. **RCS** タブで、**\+ Add RCS Sender** をクリックします。
3. **Trustsignal** タイルをクリックします。
   ![Trustsignal.png](/images/partner_45035469240596.png)
4. Sender Details ページで、次の詳細を追加します。
   ![TrustsignalSenderDetails.png](/images/partner_45035669641108.png)

| フィールド | 説明 |
| --- | --- |
| **Sender type** | 送信者タイプを選択します。利用可能なオプションは次のとおりです。<ul><li>**Promotional** : ブランドに関する情報の送信、お得な情報のプロモーション、またはユーザーとのエンゲージメントに送信者を使用する場合は、このオプションを選択します。</li><li>**Transactional** : 取引に関するアラート、OTP、セキュリティ情報、またはトランザクションとして分類できる情報の送信に送信者を使用する場合は、このオプションを選択します。</li><li>**OTP** : OTP の送信に送信者を使用する場合は、このオプションを選択します。</li></ul> |
| **Sender Name** | 送信者の名前を入力します。このフィールドは、キャンペーンやアラートの作成時に使用できる、読みやすい送信者名を識別します。 |
| **Sender ID** | 送信者 ID を入力します。これは、RBM がユーザーに RCS メッセージを送信するために使用する RCS エージェント/ボット ID です。 |
| **Authorization** | 認証に使用する Bearer トークンです。このトークンは Trustsignal チームから取得できます。 |
| **Incoming Messages & Delivery callback URL** | 配信トラッキングを設定すると、メッセージがエンドユーザーに配信されたかどうかを監視できます。受信メッセージ URL を設定すると、メッセージへの返信を追跡し、それに応じたアクションを実行できます。MoEngage ダッシュボードからこの URL をコピーし、設定してもらえるよう Trustsignal チームにメールで送信してください。 |

5. **Save** をクリックして、この送信者設定を保存します。

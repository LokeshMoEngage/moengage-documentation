# アラートの送信先を選択する

Alert Manager を使用すると、ユーザーが最もアクティブな場所でユーザーにリーチでき、アプリを切り替える必要のないリアルタイムのアラートを実現できます。メールに加えて Slack にもリアルタイムのアラートを直接配信できるようになったため、ツールを切り替えることなくユーザーに通知できます。

## MoEngage × Slack

MoEngage と Slack の統合により、Slack をアラートの送信先として設定できます。これにより、チームはアラートを即座に受信でき、ダッシュボードを切り替える必要のないリアルタイムのアラートを実現できます。

<Info>
  このガイドでは、特にアラート管理の送信先として Slack を設定する方法について説明します。その他のユースケース (Zapier 経由でのユーザーエンゲージメントメッセージの送信など) で Slack を使用する場合は、[Slack (Zapier 経由)](/ja/partner-guide/messaging-channels/messaging-apps/slack-via-zapier) を参照してください。
</Info>

この統合により、次のことが可能になります。

- 重要なシステムアラートやキャンペーンアラートを特定の Slack チャネルに直接プッシュする。
- Slack に送信するアラート (Flow Stats、Token Expiry など) をカスタマイズする。
- メール通知とは独立してアラートのサブスクリプションを管理する。

## ユースケース

Slack をアラートの送信先として統合すると、次のようなユースケースに役立ちます。

- **即時通知** : 優先度の高いアラート (APNS Token Expiry など) をエンジニアリングチームや運用チームの Slack チャネルに直接送信することで、メールの煩雑さを回避できます。
- **ワークフローの統合** : マーケティングチームやプロダクトチームが、日常のコミュニケーションツール内で Flow のパフォーマンス統計を確認できるようにします。
- **プラットフォームの安定性** : キャンペーンの統計が想定されるしきい値から外れた場合にすぐに把握できるため、迅速な軌道修正が可能になります。

# 統合

<Info>
  設定を開始する前に、次のものが揃っていることを確認してください。

  - アクティブな Slack ワークスペース。
  - Slack ワークスペースで Slack アプリを作成し、Incoming Webhooks を有効化する権限。
  - アラート管理を設定する権限を持つ MoEngage ワークスペースへのアクセス。
</Info>

アラート管理用の Slack ワークフローを作成するには、次の手順を実行します。

- [ステップ 1: Slack アプリを作成する](#step-1:-create-a-slack-app)
- [ステップ 2: Webhook URL を生成する](#step-2:-generate-a-webhook-url)
- [ステップ 3: Webhook URL を介して Slack を統合する](#step-3:-integrate-slack-into-alert-management-via-webhook-url)

## ステップ 1: Slack アプリを作成する

1. Slack ワークスペースにログインします。
2. [https://api.slack.com/apps/new](https://api.slack.com/apps/new) に移動します。
3. Slack api ページで、**Create an App** をクリックします。
   ![](/images/partner_42946256996628.png)
4. **Create an app** ウィンドウで、**From scratch** をクリックします。
   ![](/images/partner_42946257000084.png)
5. **Name app & choose workspace** ダイアログボックスで、次の詳細を入力します。
   1. **App Name** ボックスに、アプリの名前を入力します。
   2. **Pick a workspace to develop your app in** リストで、ワークスペースを選択します。
   3. **Create App** をクリックします。
      ![](/images/partner_42946257002772.png)
6. **Display Information** ページで、次の詳細を入力します。
   1. アプリ名
   2. 簡単な説明
   3. アプリアイコンとプレビュー
   4. 背景色
   5. 詳細な説明
      ![](/images/partner_42946257002900.png)
7. Slack アプリケーションに移動し、[Slack チャネルを作成](https://slack.com/intl/en-in/help/articles/201402297-Create-a-channel)します。Webhook URL を生成するユーザーがこのチャネルのメンバーであることを確認してください。

## ステップ 2: Webhook URL を生成する

1. [Slack App Management Dashboard](https://api.slack.com/apps) に移動します。
2. 一覧から、前のステップで作成したアプリ名を選択します。
   ![webhook0.png](/images/partner_42946257003156.png)
3. 左側のメニューの **Features** で、**Incoming Webhooks** を選択します。
4. **Activate Incoming Webhooks** トグルをオンにします。
5. 下にスクロールして、**Request to Add New Webhook** をクリックします。
   ![webhooksfinal.png](/images/partner_42946312120724.png)
6. Webhook URL を発行する Slack チャネルを選択します。この Webhook URL により、Slack アプリを通じて、選択した Slack チャネルにプログラムでメッセージを配信できます。生成された URL をコピーして、アラート設定に統合します。

<Info>
  この Webhook URL を生成するには、ワークスペース管理者の承認が必要な場合があります。必要に応じて、管理者にメッセージを送信して承認をリクエストできます。
</Info>

## ステップ 3: Webhook URL を介して Slack をアラート管理に統合する

1. MoEngage UI の左側のナビゲーションメニューで、App marketplace を選択します。または、Create alert ページの **Send Alerts On** リストで \+ Add alert destination をクリックします。
   ![slackkkkkkk.png](/images/partner_42946312120980.png)
2. App marketplace ページで **Alert Management** をクリックし、**Slack** を選択します。
   ![slack2.png](/images/partner_42946312121620.png)
3. Slack ページで、**Integrate** タブをクリックします。
   ![slackintegrate.png](/images/partner_42946257005972.png)
4. **Integrate** タブで、次の詳細を入力します。
   - **Connection name** : 接続名を入力します。
   - **Connection URL** : ステップ 2 で作成した Webhook URL を入力します。
5. **Connect** をクリックします。
   ![slackkk3.png](/images/partner_42946257006612.png)
6. 接続を定義すると、[Alert management](/ja/user-guide/settings/reports-and-alerts/alert-management/getting-started/create-an-alert) ページでアラートを作成する際に、**Send Alerts On** リストから定義した新しい送信先を選択できるようになります。_Email_ 、_Slack_ 、またはその両方を選択できます。
   ![dashboard4.png](/images/partner_42946257006996.png)
7. 送信先を追加すると、[Alert management](/ja/user-guide/settings/reports-and-alerts/alert-management/getting-started/create-an-alert) ページで定義したアラートの送信先を確認できます。
   ![slackemailfinal.png](/images/partner_42946257007252.png)

<Info>
  - Slack に送信されるアラートは Webhook によってトリガーされます。
  - メールと Slack の両方にアラートが設定されている場合、メール通知の配信を停止しても Slack アラートの配信には影響せず、引き続き送信されます。
</Info>

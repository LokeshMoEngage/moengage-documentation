# はじめに

[Slack](https://www.slack.com/) は、多目的なコミュニケーションプラットフォームであり、コラボレーションハブです。インスタントメッセージング、音声通話とビデオ通話、グループで情報を共有し協力して作業するための一連のツールが含まれています。

# MoEngage × Slack

MoEngage と Slack の統合により、MoEngage が取得したイベントに関するタイムリーな更新情報を Slack 内で直接受け取ることができます。また、Slack ワークスペースに参加したユーザーを MoEngage にインポートすることもできます。この統合は Zapier Actions によって実現されており、これを使用してチャネルごとに異なるコホート (セグメント) を作成し、各チャネルのメンバーに個別にエンゲージすることもできます。この統合により、次のことが可能になります。

1. MoEngage をトリガーとして使用する
2. MoEngage で Slack のコンタクトを作成または更新する
3. MoEngage のカスタムセグメントに Slack メンバーを追加または削除する
4. MoEngage にイベントをインポートする

## ユースケース

1. MoEngage でイベントがトリガーされたときに Slack メッセージを送信する。
2. 新しいメンバーが初めて Slack ワークスペースに参加したときに、MoEngage で新しいユーザーを作成する。
3. パブリックチャネルで新しいメンション (サポートチームなど) が送信されたときに、MoEngage に新しいイベントを追加する。
4. メッセージに新しいリアクションが追加されたときに、MoEngage のコホートにそのユーザーを追加する。

# 統合

<Info>
  - Slack の管理者アカウントを持っていることを確認してください。
  - Zapier アカウントにアクセスでき、そのアカウントが MoEngage アカウントに接続されていることを確認してください。[こちらの手順に従って Zapier を MoEngage に接続できます。](/ja/partner-guide/data-and-analytics/workflow-automation/zapier/overview)
</Info>

## MoEngage でイベントが発生したときに Slack メッセージを送信する

このユースケースでは、MoEngage の[コネクターキャンペーン](/ja/user-guide/campaigns-and-channels/connectors/create/create-a-connector-campaign)を活用します。このチュートリアルでは、ユースケース #1: MoEngage でのアンインストールごとに Slack メッセージを投稿する、を取り上げます。[Zapier Dashboard](https://zapier.com/app/dashboard) で、左上隅の "\+ Create Zap" をクリックします。

### ステップ 1: トリガーアプリとして Webhook by Zapier を選択する

トリガーとして "Webhook by Zapier" と入力して選択します。これが Zap を開始するトリガーになります。

![UseCase2-Step1.png](/images/partner_7926866117268.png)

### ステップ 2: トリガーアプリを設定する

1. ドロップダウンからイベント "Catch Hook" を選択します。continue をクリックします。
2. "Set up trigger" ステップで、"Pick off a Child Key" は空白のままにします。continue をクリックします。
3. 固有の Webhook URL が表示されます。

![UseCase2-Step2.png](/images/partner_7926954721812.png)

4. この URL は、コネクターキャンペーンを設定する際に必要になるため、手元に控えておいてください。

### ステップ 3: MoEngage でコネクターキャンペーンを設定する

1. MoEngage Dashboard に移動します。
2. 次のいずれかのオプションを使用します。
   1. **All Campaigns** ページで、**Create Campaign** をクリックします。\
      Create Campaign ページが表示されます。
      ![CreateCampaign\_RightNav.png](/images/partner_4491322708756.png)
   2. **Create New** \> **Campaign** をクリックします。\
      Create Campaign ページが表示されます。
      ![CreateCampaignLeftNav.png](/images/partner_4491307125908.png)
3. Connectors の下にある **Custom** をクリックします。
4. キャンペーンの配信タイプとして "Event-Triggered" を選択します。
   - 配信タイプの詳細については、[配信タイプ](/ja/user-guide/campaigns-and-channels/getting-started/introduction/moengage-channels)を参照してください。
5. 次の画面で、キャンペーンに名前を付け、Criteria として "Device Uninstall" を選択します。
6. トリガーとして "immediately" を選択します。

![UseCase2-Step3.png](/images/partner_7927058977300.png)

7. このユースケースでは、オーディエンスとして "All users" を選択します。問題がなければ "next" をクリックします。
8. コンテンツ画面で、ペイロードと前のステップで取得した Webhook URL を定義します。
9. メソッドとして "POST" を選択します ([Zapier の Webhooks](https://zapier.com/help/create/code-webhooks/trigger-zaps-from-webhooks) の詳細をご覧ください)。
10. 先ほどコピーした Webhook URL を入力します。
11. 要件に応じてヘッダーとパラメーターを定義します。このユースケースでは、ペイロードの body のみを定義します (@ を入力してパーソナライズされた値を挿入することもできます)。

![UseCase2-Step4.png](/images/partner_7927086198932.png)

12. 次に、この Webhook をテストする必要があります。下にスクロールしてテストユーザーのデータを入力し、"test" をクリックします。
13. テストが成功したことを示す新しいモーダルが表示されます。

![UseCase2-Step5.png](/images/partner_7927131912084.png)

14. Zapier エディターに戻ります。

### ステップ 4: Zapier で Webhook の設定をテストする

1. "Test Trigger" をクリックして、MoEngage で送信したテストキャンペーンを取り込みます。
2. このデータに問題がなければ、MoEngage でコネクターキャンペーンを公開できます。
3. Zapier に戻り、continue をクリックしてワークフローに次のステップを追加します。

![UseCase2-Step6-1.png](/images/partner_7927184596756.png)

![UseCase2-Step6-2.png](/images/partner_7927154337940.png)

### ステップ 5: アクションアプリとして Slack を追加する

"\+" をクリックして新しいステップを追加します。次に、アプリから "Slack" を検索して選択します。

![UseCase2-Step7.png](/images/partner_7927158176660.png)

### ステップ 6: Slack アクションを設定する

1. イベントのドロップダウンから "Send Direct Message" を選択します。continue をクリックします。
2. 次に、Slack に接続する必要があります。完了したら、ドロップダウンから接続済みのアカウントを選択し、continue をクリックします。
3. 次のステップ "Set up action" では、値を入力するか前のステップからマッピングするためのフォームが表示されます。ここでは "To Username" と "Message Text" の値のみを入力します。"Send as a bot?" では必ず "Yes" を選択してください。

前のステップからデータをマッピングすることもできます。

![UseCase2-Step8.png](/images/partner_7927271509908.png)

フォームは次のようになります。

![UseCase2-Step9-1.png](/images/partner_7927482584980.png)

![UseCase2-Step9-2.png](/images/partner_7927343636756.png)

![UseCase2-Step9-3.png](/images/partner_7927343615508.png)

4. この設定をテストするオプションが表示されます。

![UseCase2-Step10.png](/images/partner_7927379699732.png)

5. "Test & continue" をクリックして、この設定をテストします。
6. API 呼び出しが成功すると、"success" が返されます。

![UseCase2-Step11.png](/images/partner_7927375976980.png)

Slack でも確認できます。新しいメッセージが表示されているはずです。

![UseCase2-Step12.png](/images/partner_7927447035412.png)

7. すべてが正常に動作することを確認したら、"Publish Zap" をクリックします。新しいアンインストールが発生するたびに Zap が実行され、Slack で通知を受け取ります。

## 新しい Slack ユーザーを MoEngage にインポートする

_注: このワークフローでは、[Create or Update User](/ja/partner-guide/data-and-analytics/workflow-automation/zapier/create-or-update-users) アクションを使用します。_

### ステップ 1: トリガーアプリとして Slack を選択する

![User-Step1.png](/images/partner_9689761170964.png)

1. アプリの一覧から Slack を選択します。
2. "Event" として "New User" を選択します。continue をクリックします。
3. Slack アカウントを接続します。ドロップダウンから Slack アカウントを選択し、continue をクリックします。
4. "Test trigger" をクリックすると、Zapier が最近の New User の取得を試みます。continue をクリックして次のステップに進みます。

![User-Step2.png](/images/partner_9689861491348.png)

### ステップ 2: アクションアプリとして MoEngage を選択する

アプリから "MoEngage" を検索して選択します。

![Import-Step4.png](/images/partner_24724451810324.png)

1. イベントのドロップダウンから "Create or Update User" を選択します。continue をクリックします。
2. 前提条件に従っている場合は、MoEngage アカウントがすでに一覧に表示されています。それを選択するか、新しいアカウントを接続できます。完了したら continue をクリックします。
3. 次のステップ "Set up action" では、値を入力するか前のステップからマッピングするための属性とユーザープロパティの一覧が表示されます。[詳細はこちらをクリックしてください](/ja/api/user/track-user)。要件に応じて、関連するカスタムユーザー属性を追加できます。
4. この設定では、次のようにリンクしています。
   1. `Customer ID`-\>`1. ID`
   2. `Full Name`-\>`1. Real Name`
   3. `First Name`-\>`1. Profile First Name`
   4. `Last Name`-\>`1. Profile Last Name`
   5. `Email`-\>`1. Profile Email`
   6. `Source`-\> "Slack"
   7. `Other Attributes`-\>`is_bot`-\>`1. Is Bot`

以下の画像では、マッピングされたフィールドのみを示しています。

![User-Step3-1.png](/images/partner_9690081836180.png)

![User-Step3-2.png](/images/partner_9690081648020.png)

![User-Step3-3.png](/images/partner_9690105826580.png)

5. マッピングに問題がなければ、"Continue" をクリックします。
6. 最後のステップで、"Test & continue" をクリックします。
7. API 呼び出しが成功すると、"success" が返されます。

MoEngage ダッシュボードでも確認できます。Hubspot ユーザーのプロファイルに移動し、カスタム属性を確認してください。

![User-Step4.png](/images/partner_9690263434388.png)

これで、関連するユーザー属性を持つユーザーをフィルタリングしてキャンペーンを送信できます。

## MoEngage のカスタムコホートに Slack ユーザーを追加する

_注: このワークフローでは、[Add or Remove User from Cohort (Audience)](/ja/partner-guide/data-and-analytics/workflow-automation/zapier/update-cohorts-audience) アクションを使用します。_

### ステップ 1: トリガーアプリとして Slack を選択する

![User-Step1.png](/images/partner_9689761170964.png)

1. アプリの一覧から Slack を選択します。
2. "Event" として "New Reaction Added" を選択します。continue をクリックします。
3. Slack アカウントを接続します。ドロップダウンから Slack アカウントを選択し、continue をクリックします。
4. 追跡するリアクションとチャネルを選択します。必要に応じて、個々のユーザーによるリアクションを追跡することもできます。準備ができたら continue をクリックします。
5. "Test trigger" をクリックすると、Zapier が最近のリアクションの取得を試みます。continue をクリックして次のステップに進みます。

![Cohort-Step1.png](/images/partner_9690451115156.png)

### ステップ 2: アクションアプリとして MoEngage を選択する

アプリから "MoEngage" を検索して選択します。

![Import-Step4.png](/images/partner_24724451810324.png)

1. イベントのドロップダウンから "Add or Remove User From Cohort (Audience)" を選択します。continue をクリックします。
2. 前提条件に従っている場合は、MoEngage アカウントがすでに一覧に表示されています。それを選択するか、新しいアカウントを接続できます。完了したら continue をクリックします。
3. 次のステップ "Set up action" では、値を入力するか前のステップからマッピングするためのフォームが表示されます。[詳細はこちらをクリックしてください](/ja/api/cohort-sync/sync-cohort-members)。
4. ユーザーを追加するか削除するかを選択します。すべての必須フィールドに入力すると、この設定をテストするオプションが表示されます。"User ID" または "Anonymous ID" の少なくとも一方を必ず入力してください。詳細については、[Cohort API ドキュメント](/ja/api/cohort-sync/sync-cohort-members)をお読みください。
5. この設定では、次のようにリンクしています。
   1. `Cohort Name`-\> "slack-reactions-`1. Reaction`"
   2. `Cohort ID`-\> "slack-reactions-`1. Reaction`"
   3. `Cohort Description`-\> "All Slack users that have reacted with 💯."
   4. `User ID`-\>`1. User Profile Email`
   5. `Anonymous ID`-\>`1. User Profile Email`

![Cohort-Step2.png](/images/partner_9690651950484.png)

6. マッピングに問題がなければ、continue をクリックします。
7. この設定をテストするオプションが表示されます。

![Cohort-Step3.png](/images/partner_9690750125076.png)

8. "Test & continue" をクリックして、この設定をテストします。
9. API 呼び出しが成功すると、"success" が返されます。

MoEngage ダッシュボードでも確認できます。MoEngage Dashboard \>\> Segment \>\> Create segment に移動します。"Custom Segment" でユーザーをフィルタリングすると、新しく作成したコホートが表示されます。

![Cohort-Step4.png](/images/partner_9690777306900.png)

これで、Zap が成功したことを確認できます。

## MoEngage にイベントをインポートする

_注: このワークフローでは、[Import User Event](/ja/partner-guide/data-and-analytics/workflow-automation/zapier/import-user-event) アクションを使用します。_

### ステップ 1: トリガーアプリとして Slack を選択する

![User-Step1.png](/images/partner_9689761170964.png)

1. アプリの一覧から Slack を選択します。
2. "Event" として "New Reaction Added" を選択します。continue をクリックします。
3. Slack アカウントを接続します。ドロップダウンから Slack アカウントを選択し、continue をクリックします。
4. 追跡するリアクションとチャネルを選択します。必要に応じて、個々のユーザーによるリアクションを追跡することもできます。準備ができたら continue をクリックします。
5. "Test trigger" をクリックすると、Zapier が最近のリアクションの取得を試みます。continue をクリックして次のステップに進みます。

![Cohort-Step1.png](/images/partner_9690451115156.png)

### ステップ 2: アクションアプリとして MoEngage を選択する

アプリから "MoEngage" を検索して選択します。

![Import-Step4.png](/images/partner_24724451810324.png)

1. イベントのドロップダウンから "Import User Event" を選択します。continue をクリックします。
2. 前提条件に従っている場合は、MoEngage アカウントがすでに一覧に表示されています。それを選択するか、新しいアカウントを接続できます。完了したら continue をクリックします。
3. 次のステップ "Set up action" では、値を入力するか前のステップからマッピングするためのフォームが表示されます。[詳細はこちらをクリックしてください](/ja/api/event/track-event)。

すべての必須フィールドに入力すると、この設定をテストするオプションが表示されます。このフォームの入力方法については、[Event API](/ja/api/event/track-event) の説明をお読みください。キーと値のペアの形式でカスタム属性を追加し、前のトリガーアプリからの入力にマッピングすることもできます。

4. この設定では、次のようにリンクしています。
   1. `Customer ID`-\>`1. Message User ID`
   2. `Event ID`-\>"slack\_reaction\_`1. Reaction`"
   3. `Event Attributes`-\>`message_permalink` -\>`1. Message Permalink`
   4. マッピングに問題がなければ、"Continue" をクリックします。

![Event-Step2.png](/images/partner_9691747449236.png)

![Event-Step2-2.png](/images/partner_9691792178580.png)

5. この設定をテストするオプションが表示されます。

![Event-Step1.png](/images/partner_9691153893652.png)

6. "Test & continue" をクリックして、この設定をテストします。
7. API 呼び出しが成功すると、"success" が返されます。

MoEngage ダッシュボードでも確認できます。MoEngage Dashboard \>\> Settings \>\> Data Management \>\> Events \>\> Custom events タブ \>\> "slack\_reaction\_100" を検索します。

![Event-Step3.png](/images/partner_9691894872596.png)

8. すべてが正常に動作することを確認したら、"Publish Zap" をクリックします。Slack のメッセージに新しいリアクションが追加されるたびに Zap が実行されます。

# はじめに

[Line](https://line.me/en/) は、数百万人のアクティブなユーザーに利用されている、世界で最も人気のあるインスタントメッセージングプラットフォームの 1 つです。LINE を通じて、ブランドはリッチなメッセージングで顧客と簡単にエンゲージできます。

## MoEngage × Line

MoEngage と Line の統合により、高度なセグメンテーション、予測機能、パーソナライズ、トリガー機能を活用して、Line でユーザーにメッセージを送信できます。

# 統合

<Info>
  - **Line ビジネスアカウント** : この統合を使用するには、[Line 公式ビジネスアカウント](https://www.linebiz.com/jp-en/)が必要です。Line メッセージを送信すると、メッセージは Line 公式アカウントに関連付けられ、ユーザーにはアカウント名とページが表示されます。
  - **Messaging API チャネル** : Line の[公式アカウントマネージャー](https://developers.line.biz/en/docs/messaging-api/getting-started/#using-oa-manager)で Messaging API を有効にすると、Messaging API チャネルが作成されます。このチャネルを使用して顧客とコミュニケーションを取ることができます。
  - **チャネルアクセストークン** : [チャネルアクセストークン](https://developers.line.biz/en/docs/messaging-api/channel-access-tokens/)を使用すると、Line 公式アカウントを友だち追加したユーザーにメッセージを送信できます。これは **Line Developer Console** の **Messaging API** タブで確認できます。
  - **Line ユーザー ID** : LINE でメッセージを送信するには、ユーザーの Line ID (ユーザー名とは異なります) が必要です。ユーザーが Line 公式アカウントを友だち追加すると、Line の Users API を通じてそのユーザーの Line ID にアクセスできます。
  - Line は Connected Channels アドオンの一部です。アカウントで有効にするには、MoEngage の担当 CSM (カスタマーサクセスマネージャー) にお問い合わせください。
</Info>

Line では、ブランドがユーザーの同意を得ていれば、プロモーションメッセージと非プロモーションメッセージの両方をユーザーに送信できます。ユーザーに送信するには、次のいずれかの条件を満たす必要があります。

- Line 公式アカウントを友だち追加しているユーザー
- Line 公式アカウントが参加しているグループチャットまたは複数人チャット
- 1 対 1 のチャットで 7 日以内に Line 公式アカウントにメッセージを送信したユーザー (\*)

## ステップ 1: ユーザーの Line ID を収集する

Line でメッセージを送信するには、ユーザーを一貫して識別しやり取りするために、ユーザーの Line ID を収集する必要があります。Line ID はユーザーの Line ユーザー名とは異なります。Line ID は Line によって生成され、Line API とやり取りする際に使用できます。

Line ID は、Line の [User ID API](https://developers.line.biz/en/reference/messaging-api/#get-follower-ids) を使用して取得できます。このエンドポイントは、Line 公式アカウントを友だち追加したか、アカウントにメッセージを送信し、ブロックしていないすべてのユーザーの Line ID の一覧を返します。

エンドポイント `https://api.line.me/v2/bot/followers/ids` に GET リクエストを送信すると、フォロワーの Line ID を取得できます。

## ステップ 2: ユーザーの Line ID を MoEngage に保存する

Line ID の一覧を取得したら、カスタムのトラッキング対象ユーザー属性またはプロパティである **line\_id** として MoEngage に追加する必要があります。次のいずれかを実行できます。

- [User Data API](/ja/api/user/track-user) を使用してこのデータを MoEngage に渡す。
- MoEngage 内の [User Imports](/ja/user-guide/data/imports/manual-uploads) を使用してアップロードする。

## ステップ 3: Line を MoEngage と統合する

Line を MoEngage と統合するには、次の手順を実行します。

1. MoEngage ダッシュボードの左側のナビゲーションメニューで、**App marketplace** をクリックします。
2. App Marketplace ページで **Line** を検索します。 <img src="/images/partner_34809950982292.png" />
3. **Line** タイルをクリックします。
4. Line ページで **Integrate** タブに移動し、**\+ Add connection** をクリックします。
5. 次の詳細を入力します。

| フィールド | 説明 |
| --- | --- |
| **Connection name** | Line 接続の名前です。 |
| **Channel Access Token** | [Channel Access Token](https://developers.line.biz/en/docs/basics/channel-access-token/) を使用すると、Line 公式アカウントを友だち追加したユーザーにメッセージを送信できます。**Line Developer Console** の **Messaging API** タブにあります。 |

![Screenshot 2024-11-27 at 1.45.34 PM (1).png](/images/partner_32563617062164.png)

6. **Connect** をクリックします。これで Line 接続が統合されました。
   ![Screenshot 2024-11-19 at 9.28.25 PM (1).png](/images/partner_32563617063316.png)

## ステップ 4: MoEngage で Line メッセージを送信するキャンペーンを作成する

MoEngage でキャンペーンを作成するには、次の手順を実行します。

1. MoEngage ダッシュボードの左側のナビゲーションメニューで **Engage** をクリックし、**Campaigns** をクリックします。
2. All campaigns ページで、\+ Create campaign をクリックします。
3. Create campaign ダイアログボックスの **Connected Apps** で **Line** をクリックし、最も適した配信タイプをクリックします。 <img src="/images/partner_34809950989588.png" />
4. **Select audience** で **Filter users by** をクリックします。
5. **User property** タブで、**line\_id** が存在するユーザーのセグメントを選択します (他のセグメント条件と組み合わせることができます)。 <img src="/images/partner_4461536877076.png" alt="Screen_Shot_2022-02-22_at_4.45.12_PM.png" />
6. キャンペーン作成のステップ 2 で、事前設定済みのコネクターを選択し、送信するコンテンツを指定します。次の詳細を入力します。

| フィールド | 説明 |
| --- | --- |
| **Connector** | 使用する事前設定済みのコネクターを選択します。 |
| **Connections** | MoEngage App marketplace に追加した接続を選択します。 |
| **LINE ID** | LINE ID を入力します。これは Line メッセージングプラットフォーム上で各ユーザーに割り当てられる一意の識別子です。ここではパーソナライズも使用できます。 |
| **Message** | 送信するメッセージの内容を入力します。ここではパーソナライズも使用できます。 |

![](/images/partner_32563617064980.png)

7. これで、キャンペーンをテストして送信する準備が整いました。_Test_ 機能を使用して、コネクターの設定をテストすることもできます。\
   <img src="/images/partner_32563639472276.png" />\
   テストユーザーがメッセージを正常に受信できれば、セットアップは完了です。 
8. キャンペーンを公開します。

## グループまたはルームに Line メッセージを送信する

LINE のグループまたはルームにキャンペーンを送信するには、次の手順を実行します。

1. グループまたはルームにメッセージを送信するために、MoEngage で新しいユーザーを作成します。ここでの LINE ID がグループ ID またはルーム ID であることを確認してください。これらの ID の詳細については、[こちら](https://developers.line.biz/en/reference/messaging-api/#send-push-message)を参照してください。
2. そのユーザー用のセグメントを作成してユーザーを選択します。セグメントには 1 人のユーザーのみが含まれるようにしてください。キャンペーンに複数のユーザーが選択されていると、メッセージがグループまたはルームに何度も送信されます。
3. Create Campaign のステップ 2 で、グループまたはルームの LINE ID を入力します。ここではパーソナライズも使用できます。

## キャンペーン分析

MoEngage のキャンペーンでは、キャンペーンのパフォーマンスを分析できる強力な分析機能を提供しています。MoEngage の各チャネルには、キャンペーン目標を定量化するのに役立つ詳細な指標が用意されています。MoEngage の分析機能の詳細については、[キャンペーン分析](/ja/user-guide/campaigns-and-channels/connected-apps/analyze/connected-apps-campaign-analytics)を参照してください。

LINE キャンペーンでは、デフォルトで次の指標が提供されます。

- **Attempted** : フリークエンシーキャップ (FC) を超過したユーザーを除外した後、LINE キャンペーンの対象となり、メッセージの送信を試みたユーザーの数として計算されます。
- **Failed** : Line がメッセージを送信しなかったユーザー、またはキャンペーンで使用されたユーザー属性やイベント属性に対する値が見つからなかったユーザーの数です。
- **Successfully sent** : LINE API がユーザー/グループ/ルームへのメッセージ送信リクエストを受け付けた場合 (ステータスコード 200)、キャンペーンは成功としてマークされます。LINE Message API のレスポンスの詳細については、LINE のヘルプドキュメントを参照してください。

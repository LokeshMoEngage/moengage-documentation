# はじめに

[Stripo](https://stripo.email/) は、インタラクティブな要素を含むレスポンシブなメールの作成とデザインを支援する、ドラッグ＆ドロップ式のメールテンプレートビルダーです。Stripo のユーザーは、Stripo エディターで HTML を編集したり、さまざまなデバイスでどの要素を表示または非表示にするかを決定したりすることもできます。

# MoEngage × Stripo

MoEngage と Stripo の統合により、カスタマイズした _Stripo メール_ をエクスポートし、メールテンプレートとして MoEngage に送信できます。

# 統合

<Info>
  **前提条件**

  Stripo アカウントを持っていることを確認してください。
</Info>

## ステップ 1: Stripo メールを作成する

Stripo ダッシュボードで任意のメールテンプレートを作成します。次に、上部の _Export_ をクリックします。

![Screenshot\_2022-12-12\_at\_12.19.42\_PM.png](/images/partner_11531901735188.png)

## ステップ 2: テンプレートを MoEngage にエクスポートする

1. ポップアップで、_Export to ESV_ セクションに移動します。
2. _MoEngage_ を検索します。
   ![Screenshot\_2022-12-12\_at\_12.21.29\_PM.png](/images/partner_11531938039956.png)
3. _MoEngage_ カードをクリックします。ポップアップが表示されます。
   ![Screenshot\_2022-12-12\_at\_12.23.16\_PM.png](/images/partner_11531939376148.png)
4. MoEngage アカウントの詳細を追加し、_Export_ をクリックします。

| **フィールド** | **説明** |
| --- | --- |
| Connector name | コネクターの名前です。識別しやすいように MoEngage アプリの名前を入力できます。 |
| Select your instance | MoEngage データクラスターのリージョンです。詳細はこちら |
| API key | API key は Workspace ID です。MoEngage アカウントの Workspace ID は、**Settings -\> Account -\> APIs -\> Workspace ID** で確認できます。MoEngage アカウントの Data API ID と Workspace ID は同じです。 |
| API Secret key | API Secret key は Data API Key です。MoEngage アカウントの Data API key は、**Settings -\> Account -\> APIs -\> API keys -\> Data** API settings で確認できます。 |

注: これは 1 回限りのセットアップです。今後のエクスポートでは、同じ認証情報が自動的に使用されます。 <img src="/images/partner_11531983065236.png" alt="Screenshot_2022-12-12_at_12.30.35_PM.png" />

## ステップ 3 - MoEngage キャンペーンでの利用

### メールテンプレート-

テンプレートが作成されると、メールキャンペーンのステップ 2 でアクセスできるようになります。新しく作成されたテンプレートは _My saved templates_ セクションに表示されます。

![Screenshot\_2022-09-20\_at\_7.46.36\_PM.png](https://developers.moengage.com/hc/article_attachments/9471445838868/Screenshot_2022-09-20_at_7.46.36_PM.png)

メールキャンペーンでのテンプレートの使用について詳しくは、[こちらをクリックしてください](https://www.moengage.com/docs/user-guide/campaigns-and-channels/email/create/create-an-email-campaign)。

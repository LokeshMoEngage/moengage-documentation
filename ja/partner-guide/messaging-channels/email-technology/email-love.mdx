# はじめに

MoEngage のテクノロジーパートナーの 1 つである [Email Love](https://emaillove.com/) を使用すると、Figma 内で視覚的に豊かで本番環境に対応したメールテンプレートを直接作成し、MoEngage ワークスペースにエクスポートできます。

## MoEngage × Email Love

Email Love Figma プラグインと MoEngage を連携させることで、デザインチームとマーケティングチームは、メールの作成からローンチまでのワークフロー全体を効率化できます。このインテグレーションにより、次のことが可能になります。

- 共同作業が可能な Figma 環境内で、高精度でレスポンシブなメールレイアウトを直接デザインできます。
- 最終デザインを、MoEngage での配信に最適化された、クリーンで本番環境に対応した HTML テンプレートとしてエクスポートできます。
- 新規または更新されたメールテンプレートを、ワンクリックで MoEngage ワークスペースに直接転送できます。
- ブランドの一貫性とデザインの完全な忠実性を維持し、手動コーディングのエラーを排除して、テンプレートの更新を大幅に迅速化し、開発リソースを解放できます。

## ユースケース

Email Love と MoEngage を連携させることで、次のユースケースに役立ちます。

- **デザイン主導の迅速なデプロイ**：デザイナーは Figma で高精度でレスポンシブなメールレイアウトをすばやく作成または反復でき、ワンクリックでクリーンで本番環境に対応した HTML テンプレートを MoEngage に直接プッシュして、すぐにキャンペーンのローンチや A/B テストを行えます。
- **一貫性と効率性の保証**：このインテグレーションにより、手動コーディングのエラーを排除し、テンプレートの更新を大幅に迅速化し、開発リソースを解放することで、MoEngage でデプロイされるすべてのメールが完璧なブランドの一貫性とデザインの忠実性を維持できます。

# インテグレーション

<Info>
  開始する前に、次の要件を満たしていることを確認してください。

  - 有効な Email Love Figma プラグインのサブスクリプション。
  - API アクセス権のある MoEngage アカウント。
  - MoEngage ワークスペースの管理者権限または適切な権限。
</Info>

標準データを直接かつシンプルに同期するには、この接続方法を使用します。このプロセスをセットアップするには、次の手順を実行します。

1. [MoEngage で認証情報を確認する](/ja/partner-guide/messaging-channels/email-technology/email-love#step-1-find-your-credentials-in-moengage)
2. [プラグインを MoEngage に接続する](/ja/partner-guide/messaging-channels/email-technology/email-love#step-2-connect-the-plugin-to-moengage)
3. [メールテンプレートをエクスポートする](/ja/partner-guide/messaging-channels/email-technology/email-love#step-3-export-your-email-template)
4. [MoEngage でテンプレートにアクセスする](/ja/partner-guide/messaging-channels/email-technology/email-love#step-4-access-your-template-in-moengage)

## ステップ 1：MoEngage で認証情報を確認する

認証情報を確認するには、次の手順を実行します。

1. MoEngage UI で、**Settings** \> **Account** \> **APIs** に移動します。
2. **Workspace ID (earlier app id)** の下にある ID をコピーします。
3. **API keys** セクションで、**Data** タイルの API キーをコピーします。
   ![](/images/partner_42710236272660.png)
4. **Instance ID** は MoEngage へのサインアップ時に割り当てられ、ダッシュボードの URL から確認できます。たとえば、ダッシュボードの URL が [https://dashboard-04.moengage.com/v4/#/auth](https://dashboard-04.moengage.com/v4/#/auth) の場合、データセンターは 04 で、**Instance ID** は DC-04 です。詳細については、[MoEngage のデータセンター](/ja/user-guide/data/key-concepts/data-centers-in-moengage)を参照してください。

<Info>
  今後の参照のために、これらの認証情報を安全な場所に保存してください。
</Info>

## ステップ 2：プラグインを MoEngage に接続する

### ステップ 2.1：エクスポートメニューを開く

エクスポートメニューを開くには、次の手順を実行します。

1. Figma でメールデザインを開きます。
2. Email Love プラグインを起動します。
3. 右上隅にある **Export** をクリックします。
   ![](/images/partner_42710236274068.png)
4. **Export** の下にある HTML コードのリストで、**MoEngage** を見つけてクリックします。
   ![](/images/partner_42710228241556.png)

### ステップ 2.2：API 接続を設定する

API 接続を設定するには、次の手順を実行します。

1. **Change API key** をクリックします。
2. **Moengage Workspace ID** ボックスに、MoEngage からコピーしたワークスペース ID（アプリ ID）を貼り付けます。
3. **Moengage API Key** ボックスに、MoEngage からコピーした Data API Key を貼り付けます。
4. **Moengage** **API Key Name** ボックスに、API キー接続の名前を入力します。
5. **How to get Moengage API Key** の下にある **Select Instance id** リストで、お使いのインスタンス（例：DC -O4）を見つけてクリックします。
6. **Set API key** をクリックします。\
   <img src="/images/partner_42710228242452.png" />\
   これで MoEngage に正常に接続されました。

## ステップ 3：メールテンプレートをエクスポートする

次のいずれかのオプションを使用して、メールテンプレートをエクスポートします。

### オプション A：API による直接エクスポート（推奨）

1. 右上隅にある **Export** **to MoEngage** をクリックします。\
   <img src="/images/partner_42710228243348.png" />\
   プラグインが HTML を MoEngage のテンプレートライブラリに自動的にプッシュします。

### オプション B：手動コピー

1. **File Size** セクションで、**Copy MoEngage code** をクリックします。\
   <img src="/images/partner_42710236275604.png" />\
   HTML コードがクリップボードにコピーされます。MoEngage で新しいテンプレートを作成する際に、手動で貼り付けることができます。

## ステップ 4：MoEngage でテンプレートにアクセスする

MoEngage でテンプレートにアクセスするには、次の手順を実行します。

1. MoEngage UI の左側のナビゲーションで、**Content** \> **Templates** をクリックします。
2. **Email** をクリックします。
3. **Folders** の下にある **Figma Designs** をクリックします。
4. 新しくエクスポートしたテンプレートを名前で見つけます。\
   <img src="/images/partner_42710236276244.png" />\
   テンプレートをメールキャンペーンや自動化されたフローで使用します。

## 複数の接続を管理する

Email Love Figma プラグインは複数の MoEngage 接続をサポートしているため、さまざまなクライアントやワークスペースにまたがって簡単に作業できます。

**追加の接続を追加するには**：

1. エクスポートメニューで **Change API key** をクリックします。
2. 新しい認証情報を入力します。
3. 接続の一意の名前を入力します。
4. ドロップダウンリストを使用して接続を切り替えます。

## トラブルシューティング

### 接続の問題

**問題**：「Unable to connect to MoEngage」

- API 認証情報が正しいことを確認してください。
- 正しい Instance ID を使用していることを確認してください。
- API キーに必要な権限があることを確認してください。

**問題**：「Template not appearing in MoEngage」

- テンプレートが同期されるまで少し時間をおいてください。
- MoEngage ダッシュボードを更新してください。
- 正しいワークスペースを確認していることを確認してください。

### エクスポートエラー

**問題**：**Export** **to MoEngage** がグレー表示になっている。

- メールデザインが完成していることを確認してください。
- すべての必須要素が適切にフォーマットされていることを確認してください。
- プラグインのサブスクリプションが有効であることを確認してください。

## ベストプラクティス

- **接続にわかりやすい名前を付ける**：「Client Name - Production」のようなわかりやすい名前を使用します。
- **デプロイ前にテストする**：本番のキャンペーンで使用する前に、必ず MoEngage でエクスポートしたテンプレートをプレビューしてください。
- **認証情報を安全に保管する**：API キーは安全に保管し、アクセスを許可されたチームメンバーのみに制限してください。
- **直接エクスポートを使用する**：API によるエクスポート方法は、より高速で、コピー＆ペーストのエラーの可能性を減らします。

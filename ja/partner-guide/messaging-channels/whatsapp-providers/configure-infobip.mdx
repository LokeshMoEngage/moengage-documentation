---
title: "Infobip の設定"
---

MoEngage は WhatsApp 向けに Infobip とネイティブに連携しているため、MoEngage はメッセージを送信し、配信および既読の分析を表示できます。この連携により、企業は Infobip が提供する 1 つ以上の Sender を介して、テンプレート化された WhatsApp メッセージを送信できます。

## Sender の設定

MoEngage ダッシュボードで Infobip の Sender を設定するには、Settings-\>WhatsApp-\>Sender Configuration に移動します。左側のリストメニューから Infobip を選択し、\+ Sender をクリックして、詳細を設定します。

![Infobip\_SenderConfig.png](/images/partner_13790780655764.png)

1. **Sender Name**（_必須_）- _Sender name_ は Sender プロファイルに付ける名前で、MoEngage 内でキャンペーンを作成する際に簡単に識別できるようにするためのものです。_Sender Name_ は 5～50 文字である必要があります。
2. **WhatsApp business number**（_必須_）- ユーザーに WhatsApp メッセージを送信するために使用する、WhatsApp に（直接または Infobip 経由で）登録された電話番号です。Infobip では、_Channels & Numbers -\>WhatsApp -\>Senders_ で Sender の詳細を確認できます。
3. **API base URL**（_必須_）- [Infobip アカウントにログイン](https://portal.infobip.com/login/)し、[Homepage](https://portal.infobip.com/homepage/) に移動します。コピーアイコンをクリックして API base URL（以下の例ではマスクされて表示されています）をコピーし、貼り付けます。

<img src="/images/partner_13790755874836.png" alt="Infobip_APIBaseURL.png" /> 

4. **API Key**（_必須_）- [Infobip アカウントにログイン](https://portal.infobip.com/login/)し、[Homepage](https://portal.infobip.com/homepage/) に移動します。Manage API Keys をクリックします。API Key のリストから、使用するものをコピーします。API Key がない場合は、New API Key をクリックして新しいキーを生成します。<img src="/images/partner_13790755925140.png" alt="Infobip_APIKey.png" />

MoEngage 内で WhatsApp メッセージの配信を追跡するには、MoEngage Delivery Tracking URL をコピーして Infobip に共有し、先方で更新してもらう必要があります。URL は以下のように表示されます。

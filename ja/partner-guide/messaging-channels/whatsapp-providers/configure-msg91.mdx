MoEngage は MSG91 とネイティブに連携しており、テンプレート化された WhatsApp メッセージを送信し、Sender の配信および既読の分析を表示できます。

MSG91 と MoEngage の設定は、次の 2 つのステップで行います。

ステップ 1：[Sender の設定](#sender-configuration)

ステップ 2：[配信トラッキング](#delivery-tracking)

# Sender の設定

MoEngage ダッシュボードで MSG91 の Sender を設定するには、以下の手順に従います。

1. **Settings** **\>** **WhatsApp \>** **Sender Configuration** に移動します。
2. **Sender configuration** タブの左ペインから **\+Add connector** をクリックします。

<Info>
  MSG91 をすでにコネクターリストに追加している場合は、左ペインから MSG91 を選択できます。

  ![MSG19A.png](/images/partner_34936155200916.png)
</Info>

3. **Choose a connector** ドロップダウンから **MSG91** を選択し、**Done** をクリックします。
   ![MSG91B.png](/images/partner_34936155201300.png)
4. 以下の詳細を追加します。

| フィールド名 | 説明 |
| --- | --- |
| Sender Name | <ul><li>Sender プロファイルに名前を付けます。</li><li>この名前は Sender に表示されるため、MoEngage 内でキャンペーンを作成する際に簡単に識別できます。</li><li>**Sender Name** は必須フィールドで、5～50 文字である必要があります。</li></ul> |
| WhatsApp business number | <ul><li>ユーザーに WhatsApp メッセージを送信するために使用する、WhatsApp に（MSG91 経由で）登録された電話番号を国番号付きで入力します。電話番号を入力する際は、プラス記号を付けないでください。</li><li>これは必須フィールドで、WABA 番号とも呼ばれます。</li></ul> |
| API URL | ベンダーから API URL を取得し、**API URL** フィールドに入力します。サンプル URL：<br />[**https://control.msg91.com/api/v5/whatsapp/whatsapp-outbound-message/**](https://control.msg91.com/api/v5/whatsapp/whatsapp-outbound-message/) |
| Authkey | MSG91 の authkey を入力します。 |

5. **Save** をクリックします。
6. MSG91 に API トークンの有効化／検証を依頼します。
7. 連携が成功すると、次のメッセージが表示されます。
   ![SaveIntegration.png](/images/partner_34936335056404.png)

# 配信トラッキング

MoEngage 内で WhatsApp メッセージの配信を追跡するには、**MoEngage Delivery Tracking URL** をコピーし、MSG91 ダッシュボードで更新する必要があります。

![MSG91C.png](/images/partner_34936155201812.png)

<Info>
  上の画像の URL はサンプルです。MoEngage ダッシュボードから正確な URL をコピーし、MSG91 ダッシュボードで更新してください。
</Info>

## Delivery Tracking URL を追加する手順

MoEngage Delivery Tracking URL を MSG91 ダッシュボードに追加するには、次の手順を実行します。

1. MSG91 ダッシュボードにログインし、**WhatsApp \> Webhooks** に移動します。
2. **Outbound Message** Webhook に **Delivery Tracking URL** を追加します。<img src="/images/partner_34936171025556.png" alt="MSG91D.png" />
3. 左側のパネルで **Number** をクリックし、MoEngage と連携する WhatsApp 番号の編集オプションをクリックします。<img src="/images/partner_34936155202580.png" alt="MSG91E.png" />
4. 次のページの **Integration** タブで、**MoEngage Plugin Integration** をオンにして **Save** をクリックします。
   ![MSG91F.png](/images/partner_34936179650324.png)

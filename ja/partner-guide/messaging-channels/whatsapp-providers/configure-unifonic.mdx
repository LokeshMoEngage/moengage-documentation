---
title: "Unifonic の設定"
---

MoEngage は Unifonic を通じた WhatsApp のネイティブ連携を提供しており、企業は Unifonic が提供する WhatsApp 番号を介してテンプレート化されたメッセージを送信できます。この連携を使用すると、MoEngage は送信したメッセージの配信および既読の分析を提供します。

## Sender の設定

MoEngage ダッシュボードで Unifonic の Sender を設定するには、次の手順を実行します。

1. **Settings** -\>**WhatsApp** -\>**Sender Configuration** に移動します。
2. 左側のメニューで **\+Add connector** をクリックします。
3. ドロップダウンに表示される WhatsApp プロバイダーまたはコネクターのリストから **Unifonic** を選択し、**Done** をクリックします。

![Unifonic.png](/images/partner_21322771184404.png)

4. 画面右上の **\+ Sender** をクリックして、Sender の詳細を設定します。

![Unifonic\_SenderConfiguration.png](/images/partner_21322771185044.png)

5. 以下の詳細を追加します。

| フィールド名 | 説明 |
| --- | --- |
| **Sender name** | このフィールドは、Sender プロファイルに付ける名前を示します。この名前は Sender に表示されるため、MoEngage 内でキャンペーンを作成する際に簡単に識別できます。_Sender Name_ は 5～50 文字である必要があります。これは必須フィールドです。 |
| **WhatsApp business number** | このフィールドは、ユーザーに WhatsApp メッセージを送信するために使用する、WhatsApp に（直接または Unifonic 経由で）登録された電話番号を示します。これは Unifonic プラットフォームに登録したビジネス番号と同じものです。これは必須フィールドで、WABA 番号とも呼ばれます。 |
| **API URL** | このフィールドは、MoEngage から WhatsApp リクエストが送信される Unifonic の API URL を示します。 |
| **public-id** | このフィールドは、Unifonic WhatsApp API リクエストに必要な公開キーを示します。公開キーを取得するには、[Get your API Access](https://docs.unifonic.com/docs/getting-your-api-access) に記載されている手順に従ってください。 |
| **secret** | このフィールドは、Unifonic WhatsApp API リクエストに必要なシークレットキーを示します。シークレットキーを取得するには、[Get your API Access](https://docs.unifonic.com/docs/getting-your-api-access) に記載されている手順に従ってください。 |
| **template-namespace** | Template namespace の値については、Unifonic サポートまたはアカウントマネージャーにお問い合わせください。 |

6. 連携が成功すると、次のメッセージが表示されます。

![SaveIntegration.png](/images/partner_21322692397460.png)

## 配信トラッキング

MoEngage 内で WhatsApp メッセージの配信を追跡するには、MoEngage Delivery Tracking URL をコピーし、Unifonic の WhatsApp Settings で WebHook として追加する必要があります。次の手順を実行します。

1. MoEngage で Settings-\>WhatsApp-\>Sender Configuration-\> Unifonic に移動すると、以下のように URL が表示されます。

![Unifonic\_DT.png](/images/partner_21322903654676.png)

2. MoEngage ダッシュボードから正確な URL をコピーします。
3. [Configuring WebHook URLs](https://docs.unifonic.com/docs/message-delivery-status) に記載されている手順に従います。
4. MoEngage で Unifonic の Sender 用の WhatsApp キャンペーンを作成するには、Unifonic で事前承認済みのテンプレートが必要です。
5. MoEngage では、事前承認済みの Unifonic テンプレートと一字一句同じテンプレートを作成できます。詳細については、[テンプレートの追加](/ja/user-guide/campaigns-and-channels/whatsapp/getting-started-with-whatsapp/whatsapp-templates)を参照してください。

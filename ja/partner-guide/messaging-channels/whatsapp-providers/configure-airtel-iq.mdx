---
title: "Airtel IQ の設定"
---

MoEngage は Airtel IQ との WhatsApp ネイティブ統合を提供しています。この統合により、企業は Airtel IQ を利用した送信者を使用して、テンプレート化された WhatsApp メッセージを送信できます。MoEngage はメッセージを送信し、配信および既読の分析を表示できます。

## 送信者の設定

MoEngage ダッシュボードで Airtel IQ の送信者を設定するには、次の手順を実行します。

1. Settings-\>WhatsApp-\>Sender Configuration に移動します。
2. 左側のメニューから Airtel IQ を選択し、\+ Sender をクリックします。
   ![moengage1.png](/images/partner_20195377304596.png)
3. 次の詳細を追加します。

| フィールド名 | 説明 |
| --- | --- |
| Sender name | このフィールドは、送信者プロファイルに付ける名前を示します。この名前は送信者に表示されるため、MoEngage 内でキャンペーンを作成する際に簡単に識別できます。_Sender Name_ は 5～50 文字である必要があります。これは必須フィールドです。 |
| WhatsApp business number | このフィールドは、ユーザーに WhatsApp メッセージを送信するために使用する、WhatsApp に（直接または Airtel IQ 経由で）登録された電話番号を示します。Airtel IQ では、_Channels & Numbers -\_\_\> WhatsApp -\> Senders_ で送信者の詳細を確認できます。これは必須フィールドで、WABA 番号とも呼ばれます。 |
| Authorization\* | WhatsApp の認証情報（ユーザー名とパスワード）については、Airtel IQ Delivery Team（[iqservicesupport@airtel.com](mailto:iqservicesupport@airtel.com)）にお問い合わせください。 |

## 配信トラッキング

MoEngage 内で WhatsApp メッセージの配信をトラッキングするには、MoEngage の Delivery Tracking URL をコピーして Airtel IQ と共有し、Airtel IQ 側で更新してもらう必要があります。URL は次のように表示されます。

![DT\_Karix.png](/images/partner_20195383245460.png)

<Info>
  この URL はサンプルです。Airtel IQ チームと共有する前に、MoEngage ダッシュボードから正確な URL をコピーしてください。
</Info>

## **Delivery Tracking URL を追加する手順**

1. [Airtel IQ アカウントにログイン](https://www.airtel.in/business/b2b/airtel-iq/dashboard/#/)し、My Account -\> Channel Setting に移動します
2. WABA アカウントを選択します。
3. DLR Call Back を更新する必要がある携帯電話番号を選択します。
4. DLR Call Back に MoEngage の Webhook を入力して保存します。

![moengage2.png](/images/partner_20195393724436.png)

統合が成功すると、次のメッセージが表示されます。

![SaveIntegration.png](/images/partner_20195407105940.png)

<Info>
  - MoEngage で Airtel IQ 送信者の WhatsApp キャンペーンを作成するには、Airtel IQ で事前承認されたテンプレートが必要です。テンプレートは、[Airtel IQ Template Management](https://www.airtel.in/business/b2b/airtel-iq/dashboard/#/whatsapp/template-manager/builder) の左側のメニューで Template Management オプションを選択して作成できます。
  - MoEngage でも同じテンプレートをそのまま作成できます。詳細については、[テンプレートの追加](/ja/user-guide/campaigns-and-channels/whatsapp/getting-started-with-whatsapp/whatsapp-templates)を参照してください。
</Info>

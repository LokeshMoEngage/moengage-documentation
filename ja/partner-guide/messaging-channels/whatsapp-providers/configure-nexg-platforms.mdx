# はじめに

MoEngage は WhatsApp 向けに NexG Platforms とのネイティブ連携を提供しています。この連携により、テンプレート化された WhatsApp メッセージを送信し、MoEngage UI 内で配信および既読に関する包括的な分析を確認できます。

<Info>
  設定を始める前に、以下が揃っていることを確認してください。

  - NexG Platforms ダッシュボードへのアクセス権
  - NexG Platforms アカウントに関連付けられた API キー
  - WhatsApp for Business（WABA）に登録および検証済みの電話番号
</Info>

# NexG Platforms を WhatsApp コネクターとして設定する

このセクションでは、MoEngage UI で NexG Platforms をサービスプロバイダーとして設定する方法について説明します。

## ステップ 1：Sender Configuration にアクセスする

Sender Configuration にアクセスするには、次の手順を実行します。

1. MoEngage UI にサインインします。
2. **Settings** \> **Channels** \> **WhatsApp** \> **Sender configuration** に移動します。
3. **\+ Add connector** をクリックします。WhatsApp connector ダイアログボックスが表示されます。
4. **Choose a connector** リストで **NexG** を選択し、**Done** をクリックします。<img src="/images/partner_46267770930836.png" />

## ステップ 2：Sender の詳細を設定する

Sender の詳細を設定するには、次の手順を実行します。

1. **Sender configuration** ページで、右上の **\+ Sender** をクリックします。
2. **Sender Details** ページで、以下の情報を入力します。

| フィールド | 説明 |
| --- | --- |
| **Sender name** | この Sender プロファイルの一意でわかりやすい名前を入力します。この名前は、MoEngage でキャンペーンを作成する際に Sender を識別するために使用されます。5～50 文字で入力してください。 |
| **WhatsApp business number** | メッセージの送信に使用する、WhatsApp に登録された電話番号（WABA 番号）を入力します。 |
| **API URL** | このフィールドには、Sender に API リクエストを送信する際に使用する URL の情報が含まれます。この情報は Sender の API ドキュメントから入手できます。<br />ベンダーから提供された API エンドポイントを入力します。NexG Platforms の API URL は次のとおりです。<br />[https://automate.nexgplatforms.com/api/v1/wa/moengage](https://automate.nexgplatforms.com/api/v1/wa/moengage) |
| **authorization** | ベンダーから取得した API キーを入力します。 |

![](/images/partner_46267773716628.png)

3. **Save** をクリックします。連携が成功すると、Sender の詳細が保存されたことを確認する成功メッセージが表示されます。<img src="/images/partner_46409361111188.png" alt="nexG.png" />

# 配信トラッキング

MoEngage 内で WhatsApp メッセージの配信ステータスを追跡するには、MoEngage の Delivery Tracking URL を NexG Platforms に提供し、次の手順を実行する必要があります。

1. **Sender Details** ページで、**Enable delivery tracking** を見つけます。
2. 配信トラッキング URL の横にあるコピーアイコン <img src="/images/partner_46267692555540.png" />をクリックします。<img src="/images/partner_46267750877332.png" />
3. 配信コールバックを有効にするために、この URL を NexG Platforms の担当者に提供するか、NexG Platforms のアカウント設定で更新します。

<Info>
  - MoEngage で NexG Platforms の Sender 用の WhatsApp キャンペーンを作成するには、NexG Platforms で事前承認済みのテンプレートが必要です。
  - MoEngage で作成するテンプレートの内容が、承認済みの NexG Platforms テンプレートと一字一句一致していることを確認してください。詳細については、[テンプレートの追加](/ja/user-guide/content/template/templates)を参照してください。
</Info>

---
title: "ConvertWay の設定"
---

MoEngage は ConvertWay とネイティブに連携しており、Flows やキャンペーンを通じて MoEngage からエンドユーザーに WhatsApp テンプレートを直接送信できます。これにより、自動メッセージやマーケティングキャンペーンのコミュニケーションチャネルとして WhatsApp を活用し、顧客エンゲージメントを高めることができます。

ConvertWay と MoEngage の設定は、次の 2 つのステップで行います。

ステップ 1：[Sender の設定](#sender-configuration)

ステップ 2：[配信トラッキング](#delivery-tracking)

<Info>
  連携の前に、以下が揃っていることを確認してください。

  - MoEngage アカウント
  - ConvertWay（CW）アカウント
  - WhatsApp Business API（WABA）番号
</Info>

# Sender の設定

MoEngage ダッシュボードで ConvertWay の Sender を設定するには、以下の手順に従います。

1. **Settings** **\>** **WhatsApp \>** **Sender Configuration** に移動します。
2. **Sender configuration** タブの左ペインから **\+Add connector** をクリックします。

<Info>
  ConvertWay をすでにコネクターリストに追加している場合は、左ペインから ConvertWay を選択できます。

  ![image (19).png](/images/partner_35797513598740.png)
</Info>

3. **Choose a connector** ドロップダウンから **ConvertWay** を選択し、**Done** をクリックします。
   ![Convertway.png](/images/partner_35797530059412.png)
4. 以下の詳細を追加します。

| フィールド名 | 説明 |
| --- | --- |
| Sender Name | <ul><li>Sender プロファイルに名前を付けます。</li><li>この名前は Sender に表示されるため、MoEngage 内でキャンペーンを作成する際に簡単に識別できます。</li><li>**Sender Name** は必須フィールドで、5～50 文字である必要があります。</li></ul> |
| WhatsApp business number | <ul><li>ユーザーに WhatsApp メッセージを送信するために使用する、WhatsApp に（直接または ConvertWay 経由で）登録された電話番号を国番号付きで入力します。</li><li>ConvertWay アカウントでは、**Settings** \> **WhatsApp Business Account** で Sender の詳細を確認できます。</li><li>これは必須フィールドで、WABA 番号とも呼ばれます。</li></ul> |
| API URL | ベンダーから API URL を取得し、**API URL** フィールドに入力します。サンプル URL：<br />[https://app.theconvertway.com/api/v1/send\_messages/moengage/sendwhatsapp](https://app.theconvertway.com/api/v1/send_messages/moengage/sendWhatsapp) |
| Authorization | **Basic CW\_LICENSE\_KEY** CW\_LICENSE\_KEY は、ConvertWay アカウントの **Settings** \> **Profile** で確認できます。 |

5. **Save** をクリックします。
6. ConvertWay に API トークンの有効化／検証を依頼します。
7. 連携が成功すると、次のメッセージが表示されます。
   ![SaveIntegration.png](/images/partner_35364754398740.png)

# 配信トラッキング

MoEngage 内で WhatsApp メッセージの配信を追跡するには、**MoEngage Delivery Tracking URL** をコピーして ConvertWay に共有し、更新してもらう必要があります。次の URL が表示されます。

![Screenshot 2025-03-05 at 4.57.46 PM.png](/images/partner_35364867363348.png)

<Info>
  上の画像の URL はサンプルです。MoEngage ダッシュボードから正確な URL をコピーし、ConvertWay ダッシュボードで更新してください。
</Info>

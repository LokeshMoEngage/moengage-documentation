---
title: "Mitto の設定"
---

MoEngage は WhatsApp 向けに Mitto とネイティブに連携しています。この連携により、企業は Mitto が提供する Sender を使用してテンプレート化された WhatsApp メッセージを送信できます。MoEngage はメッセージを送信し、配信および既読の分析を表示できます。

## Sender の設定

MoEngage ダッシュボードで Mitto の Sender を設定するには、次の手順を実行します。

1. **Settings** -\>**WhatsApp** -\>**Sender Configuration** に移動します。
2. 左側のメニューで \+Add connector をクリックします。
3. ドロップダウンの WhatsApp プロバイダーまたはコネクターのリストから **Mitto** を選択し、**Done** をクリックします。

![Mitto\_WAConnector.png](/images/partner_23656681897108.png)

4. 画面右上の **\+ Sender** をクリックし、以下の説明に従って Sender の詳細を設定します。

![Mitto\_WAConnector\_Configuration.png](/images/partner_23656666969492.png)

5. 以下の詳細を追加します。

| フィールド名 | 説明 |
| --- | --- |
| **Sender name** | このフィールドは、Sender プロファイルに付ける名前を示します。この名前は Sender に表示されるため、MoEngage 内でキャンペーンを作成する際に簡単に識別できます。_Sender Name_ は 5～50 文字である必要があります。これは必須フィールドです。 |
| **WhatsApp business number** | このフィールドは、ユーザーに WhatsApp メッセージを送信するために使用する、WhatsApp に（直接または Mitto 経由で）登録された電話番号を示します。これは必須フィールドで、WABA 番号とも呼ばれます。 |
| **API URL** | このフィールドは、MoEngage から WhatsApp リクエストが送信される Mitto の API URL を示します。これは必須フィールドです。 |
| **Authorization** | このフィールドは、Mitto プラットフォームの HTTP Basic アカウントの詳細を示します。これは必須フィールドです。 |
| **Enable delivery tracking** | MoEngage 内で WhatsApp メッセージの配信を追跡するには、MoEngage Delivery Tracking URL をコピーし、Mitto プラットフォームで Webhook として追加する必要があります。配信トラッキング URL は、以下のように MoEngage の WhatsApp ダッシュボードで確認できます。<br /> <img src="/images/partner_23656724417044.png" alt="Mitto_WAConnector_DeliveryTracking.png" /> <br />注：この配信トラッキング URL はサンプルです。MoEngage ダッシュボードから URL をコピーし、Mitto プラットフォームに追加してください。 |

6. **Save** をクリックします。連携が成功すると、次のメッセージが表示されます。

![SaveIntegration.png](/images/partner_23656419583892.png)

<Info>
  - MoEngage で Mitto の Sender 用の WhatsApp キャンペーンを作成するには、Mitto で事前承認済みのテンプレートが必要です。
  - MoEngage でも同じテンプレートを一字一句そのまま作成できます。詳細については、[テンプレートの追加](/ja/user-guide/campaigns-and-channels/whatsapp/getting-started-with-whatsapp/whatsapp-templates)を参照してください。
</Info>

---
title: "8x8 の設定"
---

MoEngage は 8x8 との WhatsApp ネイティブ統合を提供しています。この統合により、企業は 8x8 を利用した送信者を使用して、テンプレート化された WhatsApp メッセージを送信できます。MoEngage はメッセージを送信し、配信および既読の分析を表示できます。

## 送信者の設定

MoEngage ダッシュボードで 8x8 の送信者を設定するには、次の手順を実行します。

1. **Settings** -\> **Channels** -\> **WhatsApp** -\> **Sender configuration** に移動します。
2. **\+ Add connector** をクリックします。WhatsApp コネクターのポップアップウィンドウが表示されます。
   ![8x8 - 3.png](/images/partner_27662397720852.png)
3. **Choose a connector** ドロップダウンリストから 8x8 を選択し、**Done** をクリックします。
4. 次の詳細を追加します。
   ![8x8 - 1.png](/images/partner_27641445388948.png)

| フィールド | 説明 |
| --- | --- |
| **Sender name** | このフィールドは、送信者プロファイルに付ける名前を示します。この名前は送信者に表示されるため、**MoEngage 内でキャンペーンを作成する際に**簡単に識別できます。送信者名は 5～50 文字である必要があります。これは必須フィールドです。 |
| **WhatsApp business number** | このフィールドは、ユーザーに WhatsApp メッセージを送信するために使用する、WhatsApp に（直接または 8x8 経由で）登録された電話番号を示します。8x8 Connect では、左側のメニュー -\> Chat Apps -\> Channels で WhatsApp ビジネス番号を確認できます。 |
| **API URL** | <ol><li>8x8 Connect ポータルにログインします。</li><li>左側のメニューから **API keys** セクションに移動します。</li><li>手順の下で、任意のサブアカウントをクリックしてコピーします。</li><li>次の URL の "Your\_Chosen\_Sub-account" を、コピーしたサブアカウントに置き換えます: [https://chatapps.8x8.com/api/v1/subaccounts/Your\_Chosen\_Subaccount/partners/moengage/wa](https://chatapps.8x8.com/api/v1/subaccounts/Your_Chosen_Subaccount/partners/moengage/wa)</li></ol> |
| **Authorization** | 同じ **API keys** セクションで下にスクロールし、既存の API キーを選択するか、MoEngage 統合専用の API キーを作成できます。 |

5. **Save** をクリックします。\
   統合が成功すると、次のメッセージが表示されます。
   ![SaveIntegration.png](/images/partner_27662320239252.png)

## 配信トラッキング

MoEngage 内で WhatsApp メッセージの配信をトラッキングするには、MoEngage の Delivery Tracking URL をコピーし、設定を依頼するために当社のサポートチームと共有する必要があります。URL は次のように表示されます。

![8x8 - 2.png](/images/partner_27641445397396.png)

<Info>
  - MoEngage で 8x8 送信者の WhatsApp キャンペーンを作成するには、8x8 で事前承認されたテンプレートが必要です。
  - MoEngage でも同じテンプレートをそのまま作成できます。詳細については、[テンプレートの追加](/ja/user-guide/campaigns-and-channels/whatsapp/getting-started-with-whatsapp/whatsapp-templates)を参照してください。
</Info>

---
title: "Route Mobile の設定"
---

MoEngage は WhatsApp 向けに Route Mobile と連携しています。この連携により、企業は Route Mobile が提供する Sender を使用してテンプレート化された WhatsApp メッセージを送信できます。MoEngage はメッセージを送信し、配信および既読の分析を表示できます。

## Sender の設定

MoEngage ダッシュボードで Route Mobile の Sender を設定するには、次の手順を実行します。

1. Settings-\>WhatsApp-\>Sender Configuration に移動します。
2. 左側のメニューで \+Add connector をクリックします。
3. ドロップダウンに表示される WA プロバイダーまたはコネクターのリストから Route Mobile を選択し、_Done_ をクリックします。

![RML\_ChooseConnector.png](/images/partner_18093483788052.png)

4. 画面右上の \+ Sender をクリックし、以下の説明に従って Sender の詳細を設定します。<img src="/images/partner_18093483789972.png" alt="RML_SenderConfig.png" />

| フィールド名 | 説明 |
| --- | --- |
| Sender name | このフィールドは、Sender プロファイルに付ける名前を示します。この名前は Sender に表示されるため、MoEngage 内でキャンペーンを作成する際に簡単に識別できます。_Sender Name_ は 5～50 文字である必要があります。これは必須フィールドです。 |
| WhatsApp business number | このフィールドは、ユーザーに WhatsApp メッセージを送信するために使用する、WhatsApp に（直接または Route Mobile 経由で）登録された電話番号を示します。これは必須フィールドで、WABA 番号とも呼ばれます。 |
| API KEY | このフィールドは、MoEngage から Route Mobile への WhatsApp リクエストを承認するために必要な API KEY を示します。この情報を取得するには、[support@routemobile.com](mailto:support@routemobile.com) および [whatsapp@routemobile.com](mailto:whatsapp@routemobile.com) にお問い合わせください。 |
| Enable delivery tracking | MoEngage で WhatsApp メッセージの配信を追跡するには、MoEngage Delivery Tracking URL をコピーして Route Mobile チームに渡します。URL は以下のように表示されます。<br /> <img src="/images/partner_18093483791380.png" alt="RML_DTConfig.png" /><br />**注**：この URL はサンプルです。Sender の設定時に MoEngage ダッシュボードから正確な URL をコピーしてください。 |

5. Save をクリックして Sender の詳細を保存します。連携が成功すると、成功メッセージが表示されます。

![SuccessMsg.png](/images/partner_18069890177428.png)

## Delivery Tracking URL を追加する手順

1. Route Mobile の WhatsApp アカウントにログインします。
2. 以下の画像に示すように、WhatsApp Profile Management タブに移動します。
3. 以下に示すように、MoEngage ダッシュボードで確認できる配信コールバック URL（Enable Delivery Callback セクションを参照）を、Profile Management セクション内の Callback URL フィールドに追加します。
   <img src="/images/partner_18328181454228.png" alt="RouteMobile_waba_config_page.png" />

<Note>
  - MoEngage で Route Mobile の Sender 用の WhatsApp キャンペーンを作成するには、Route Mobile で事前承認済みのテンプレートが必要です。
  - MoEngage でも同じテンプレートを一字一句そのまま作成できます。詳細については、[テンプレートの追加](/ja/user-guide/campaigns-and-channels/whatsapp/getting-started-with-whatsapp/whatsapp-templates)を参照してください。
</Note>

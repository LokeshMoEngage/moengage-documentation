---
title: "Tata Communications の設定"
---

MoEngage は WhatsApp 向けに Tata Communications とネイティブに連携しているため、MoEngage はメッセージを送信し、配信および既読の分析を表示できます。この連携により、企業は Tata Communications を使用してテンプレート化された WhatsApp メッセージを送信できます。

# Sender の設定

MoEngage ダッシュボードで Tata Communications の Sender を設定するには、次の手順を実行します。

1. _Settings- \>WhatsApp-\>Sender Configuration_ に移動します。
2. 左側のメニューで _\+Add connector_ をクリックします。
3. ドロップダウンの WA プロバイダーまたはコネクターのリストから _TataCommunications_ を選択し、_Done_ をクリックします。

![WAConnector.png](/images/partner_19097905869972.png)

4. 画面右上の \+ Sender をクリックして、Sender の詳細を設定します。

![SenderConfig\_TataComms.png](/images/partner_19097905879572.png)

5. 以下の詳細を追加します。

| フィールド名 | 説明 |
| --- | --- |
| Sender name | _Sender name_ は Sender プロファイルに付ける名前で、MoEngage 内でキャンペーンを作成する際に簡単に識別できるようにするためのものです。_Sender Name_ は 5～50 文字である必要があります。 |
| WhatsApp business number | ユーザーに WhatsApp メッセージを送信するために使用する、WhatsApp に登録された電話番号です。これは必須フィールドで、WABA 番号とも呼ばれます。 |
| Authorization | Authorization に API Key を入力します。API キーを受け取るには、Tata Communications チームにオフラインで連絡し、件名に「_\<Your Company Name\> / WhatsApp API Key for MoEngage_」と記載して [designanddelivery@tatacommunications.com](mailto:designanddelivery@tatacommunications.com) にメールを送信してください。API キーを受け取ったら、Authorization フィールドに貼り付けます。 |
| Enable Delivery Tracking | MoEngage 内で WhatsApp メッセージの配信を追跡するには、MoEngage Delivery Tracking URL（このセクションで確認できます）をコピーして Tata Communications チームに共有し、先方で更新してもらう必要があります。<br /><img src="/images/partner_19097895179924.png" alt="DT_TataComms.png" /><br />**注**：これはサンプル URL です。MoEngage ダッシュボードから正確な URL をコピーし、Tata Communications チームに共有してください。 |

<Note>
  - MoEngage で Tata Communications の Sender 用の WhatsApp キャンペーンを作成するには、Tata Communications で事前承認済みのテンプレートが必要です。
  - MoEngage でも同じテンプレートを一字一句そのまま作成できます。詳細については、[テンプレートの追加](/ja/user-guide/campaigns-and-channels/whatsapp/getting-started-with-whatsapp/whatsapp-templates)を参照してください。
</Note>

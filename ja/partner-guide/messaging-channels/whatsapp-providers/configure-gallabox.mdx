title: "Gallabox の設定"
---

MoEngage は WhatsApp 向けに Gallabox とネイティブに連携しています。この連携により、企業は Gallabox を利用してテンプレート化された WhatsApp メッセージを送信できます。MoEngage はメッセージを送信し、配信および既読の分析を表示できます。

## Sender の設定

MoEngage ダッシュボードで Gallabox の Sender を設定するには、次の手順を実行します。

1. Settings-\>WhatsApp-\>Sender Configuration に移動します。
2. 左側のメニューで \+Add connector をクリックします。
3. ドロップダウンの WA プロバイダーまたはコネクターのリストから Gallabox を選択し、_Done_ をクリックします。

![WA\_Gallabox.png](/images/partner_18391710233876.png)

4. 画面右上の \+ Sender をクリックして、Sender の詳細を設定します。

![WA\_GallaboxConfig\_MoE.png](/images/partner_18391764774164.png)

5. 以下の詳細を追加します。

| フィールド名 | 説明 |
| --- | --- |
| Sender name | このフィールドは、Sender プロファイルに付ける名前を示します。この名前は Sender に表示されるため、MoEngage 内でキャンペーンを作成する際に簡単に識別できます。_Sender Name_ は 5～50 文字である必要があります。これは必須フィールドです。 |
| WhatsApp business number | このフィールドは、ユーザーに WhatsApp メッセージを送信するために使用する、WhatsApp に（直接または Gallabox 経由で）登録された電話番号を示します。これは Gallabox プラットフォームに登録したビジネス番号と同じものです。これは必須フィールドで、WABA 番号とも呼ばれます。Gallabox から WABA 番号を取得するには、次の手順を実行します。<ol><li>Settings -\> WhatsApp Channel -\> WhatsApp に移動します。</li><li>WhatsApp Number をコピーしてここに貼り付けます。</li></ol> |
| Authorization | このフィールドは API Key を示し、API 呼び出しを行っているアカウントを識別するために使用されます。詳細については、[設定手順](#steps-to-configure-moengage-on-gallabox)を参照してください。 |

6. 連携が成功すると、次のメッセージが表示されます。

![SaveIntegration.png](/images/partner_18391676705556.png)

## Gallabox で MoEngage を設定する手順

1. Gallabox アカウントにサインインします。
2. 左側のナビゲーションペインで Integrations をクリックします。
3. 以下に示すように、Available apps から MoEngage を選択し、integration をクリックします。<img src="/images/partner_18392225089172.png" alt="WA_Gallabox_Step1.png" />
4. 開いたインテグレーションウィンドウで、このインテグレーションに付ける名前を入力し、_Connect_ をクリックします。<img src="/images/partner_18392235896084.png" alt="WA_Gallabox_Step2.png" />
5. MoEngage Integration の設定ページにリダイレクトされます。_Configuration_ タブをクリックし、チャネルとして Whatsapp を選択します。<img src="/images/partner_18392235897364.png" alt="WA_Gallabox_Step3.png" />
6. MoEngage で確認できる配信コールバック URL を _Status URL_ フィールドに追加します。詳細については、[配信トラッキング](#delivery-tracking)を参照してください。
7. Update Configuration をクリックします。設定が更新されると、以下に示すように Configuration セクションに API Secret が表示されます。<img src="/images/partner_18392256616340.png" alt="WA_Gallabox_Step4 (1).png" />
8. API Secret をコピーし、MoEngage ダッシュボードの Authorization フィールドに貼り付けます。詳細については、[Sender の詳細](#sender-configuration)セクションのステップ 5 を参照してください。

## 配信トラッキング

MoEngage 内で WhatsApp メッセージの配信を追跡するには、MoEngage Delivery Tracking URL をコピーして Gallabox の Configuration 設定に追加する必要があります。次の手順を実行します。

1. MoEngage で Settings-\>WhatsApp-\>Sender Configuration-\> Gallabox に移動すると、以下のように URL が表示されます。

![WA\_Gallabox\_DT.png](/images/partner_18391736599316.png)

2. MoEngage ダッシュボードから正確な URL をコピーします。
3. Gallabox の設定ウィンドウの Status URL フィールドに貼り付けます。

<Note>
  - MoEngage で Gallabox の Sender 用の WhatsApp キャンペーンを作成するには、Gallabox で事前承認済みのテンプレートが必要です。
  - MoEngage でも同じテンプレートを一字一句そのまま作成できます。詳細については、[テンプレートの追加](/ja/user-guide/campaigns-and-channels/whatsapp/getting-started-with-whatsapp/whatsapp-templates)を参照してください。
</Note>

---
title: "Kaleyra の設定"
---

MoEngage は WhatsApp 向けに Kaleyra と連携しています。この連携により、企業は Kaleyra が提供する Sender を使用してテンプレート化された WhatsApp メッセージを送信できます。MoEngage はメッセージを送信し、配信および既読の分析を表示できます。

## Sender の設定

MoEngage ダッシュボードで Kaleyra の Sender を設定するには、次の手順を実行します。

1. Settings-\>WhatsApp-\>Sender Configuration に移動します。
2. 左側のメニューで \+Add connector をクリックします。
3. ドロップダウンに表示される WA プロバイダーまたはコネクターのリストから Kaleyra を選択し、_Done_ をクリックします。

![WA\_Connector\_Kalyera.png](/images/partner_15850777861012.png)

4. 画面右上の \+ Sender をクリックし、以下の説明に従って Sender の詳細を設定します。<img src="/images/partner_15851419755796.png" alt="ConfigureKalyeraSender.gif" />

| フィールド名 | 説明 |
| --- | --- |
| Sender name | このフィールドは、Sender プロファイルに付ける名前を示します。この名前は Sender に表示されるため、MoEngage 内でキャンペーンを作成する際に簡単に識別できます。_Sender Name_ は 5～50 文字である必要があります。これは必須フィールドです。 |
| WhatsApp business number | このフィールドは、ユーザーに WhatsApp メッセージを送信するために使用する、WhatsApp に（直接または Kaleyra 経由で）登録された電話番号を示します。これは必須フィールドで、WABA 番号とも呼ばれます。 |
| sid | SID は Kaleyra アカウントのセキュリティ識別子で、API リクエストでこの情報を送信することは必須です。SID を取得するには、[Kaleyra の開発者ドキュメント](https://developers.kaleyra.io/docs/view-api-key-and-sid)に記載されている手順を参照してください。 |
| api-key | API Key は、API 呼び出しを行っているアカウントを識別するために使用されます。ここに Kaleyra アカウントの API Key を入力します。API Key を取得するには、[Kaleyra の開発者ドキュメント](https://developers.kaleyra.io/docs/view-api-key-and-sid)に記載されている手順を参照してください。 |
| delivery-report-callback-url | MoEngage で WhatsApp メッセージの配信を追跡するには、次の手順を実行します。<ul><li>Kaleyra で WhatsApp の配信コールバックを有効にします。そのためには、配信コールバックの有効化セクションに記載されている手順に従ってください。</li><li>MoEngage Delivery Tracking URL をコピーし、API リクエストで Kaleyra に渡します。WhatsApp メッセージの配信トラッキングを有効にするには、_Enable delivery tracking_ セクションで MoEngage が提供する配信トラッキング URL をコピーして貼り付けます。</li><li>URL は以下のように表示されます。<img src="/images/partner_15850757996308.png" alt="Enable_DT_WA.png" /></li><li>**注**：この URL はサンプルです。Sender の設定時に MoEngage ダッシュボードから正確な URL をコピーしてください。</li></ul> |
| kaleyra-host | リクエストを送信するための API URL です。サンプルのホスト URL：[https://api.in.kaleyra.io/](https://api.in.kaleyra.io/)**注**：これはサンプル URL です。ホストの詳細については Kaleyra チームにお問い合わせください。 |

5. Save をクリックして Sender の詳細を保存します。連携が成功すると、上記のように成功メッセージが表示されます。

### **Kaleyra で配信トラッキングを有効にする手順**

1. kaleyra.io にログインします。
2. 右上のプロファイル名をクリックします。
3. リストから _Settings_ をクリックします。
4. 表示されたページで、_Settings_ タブをクリックします。_Enable WhatsApp Callback URLs_ セクションのテキストエリアに [https://moengage-whatsapp-prod.kaleyra.io](https://moengage-whatsapp-prod.kaleyra.io) を追加します。
5. Save をクリックします。

<Info>
  - MoEngage で Kaleyra の Sender 用の WhatsApp キャンペーンを作成するには、Kaleyra で事前承認済みのテンプレートが必要です。
  - MoEngage でも同じテンプレートを一字一句そのまま作成できます。詳細については、[テンプレートの追加](/ja/user-guide/campaigns-and-channels/whatsapp/getting-started-with-whatsapp/whatsapp-templates)を参照してください。
</Info>

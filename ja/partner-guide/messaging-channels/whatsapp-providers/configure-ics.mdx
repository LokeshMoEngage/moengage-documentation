---
title: "ICS の設定"
---

MoEngage は WhatsApp 向けに ICS と連携しており、メッセージの送信と配信分析の表示が可能です。この連携により、企業は ICS が提供する 1 つ以上の Sender を使用して、テンプレート化された WhatsApp メッセージを送信できます。

<Info>
  **前提条件**

  * この連携を使用するには、ICS で稼働中の WhatsApp Business API アカウントが必要です。
  * ICS WhatsApp と接続するには、MoEngage アカウントが必要です。
</Info>

## Sender の設定

MoEngage ダッシュボードで ICS の Sender を設定するには、次の手順を実行します。

1. **Settings** \> **WhatsApp** \> **Sender Configuration** に移動します。
2. 左側のメニューにある WhatsApp プロバイダーのリストから **ICS** を選択し、**+ Sender** をクリックします。

<img src="/images/configure-ics-sender-config-full.png" alt="ICS WhatsApp の Sender 設定" />

3. 以下の詳細を追加します。

| フィールド名 | 説明 |
| ---------- | ------------ |
| **Sender name** | MoEngage でこの Sender を識別するための名前を入力します。この名前は、MoEngage 内でキャンペーンを作成する際に Sender を識別するために使用されます。これは必須フィールドです。 |
| **WhatsApp business number** | WhatsApp メッセージの送信に使用する、WhatsApp に（ICS 経由で）登録された電話番号を国番号付きで入力します（例：919898989898）。これは必須フィールドで、WABA 番号とも呼ばれます。 |
| **API URL** | リクエストを送信するための API URL を入力します。この API URL は ICS チームから入手できます。これは必須フィールドです。 |
| **Authorization** | 認証に使用する Bearer トークンを入力します。このトークンは ICS チームから入手できます。これは必須フィールドです。 |

4. WhatsApp の配信トラッキングを有効にするには、Sender Configuration 画面の **Enable delivery tracking** に表示されている MoEngage の **Delivery Tracking URL** をコピーし、ICS チームに共有して先方で設定してもらいます。
5. **Save** をクリックします。連携が成功すると、成功メッセージが表示されます。

<Info>
  * MoEngage で ICS の Sender 用の WhatsApp キャンペーンを作成するには、ICS で事前承認済みのテンプレートが必要です。
  * MoEngage でも同じテンプレートを一字一句そのまま作成できます。詳細については、[テンプレートの追加](/ja/user-guide/campaigns-and-channels/whatsapp/getting-started-with-whatsapp/whatsapp-templates)を参照してください。
</Info>

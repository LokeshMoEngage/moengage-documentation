---
title: "Kwikchat（GoKwik）の設定"
---

MoEngage は Kwikchat（GoKwik）とネイティブに連携しており、テンプレート化された WhatsApp メッセージを送信し、Sender の配信および既読の分析を表示できます。

Kwikchat（GoKwik）と MoEngage の設定は、次の 2 つのステップで行います。

ステップ 1：[Sender の設定](#sender-configuration)

ステップ 2：[配信トラッキング](#delivery-tracking)

# Sender の設定

MoEngage ダッシュボードで Kwikchat（GoKwik）の Sender を設定するには、以下の手順に従います。

1. **Settings** **\>** **WhatsApp \>** **Sender Configuration** に移動します。
2. **Sender configuration** タブの左ペインから **\+Add connector** をクリックします。

<Info>
  Kwikchat（GoKwik）をすでにコネクターリストに追加している場合は、左ペインから Kwickchat（GoKwik）を選択できます。

  ![select kwikchat left pane.png](/images/partner_25025136908692.png)
</Info>

3. **Choose a connector** ドロップダウンから **Kwikchat (GoKwik)** を選択し、**Done** をクリックします。
   ![select kwikchat.png](/images/partner_25025136919828.png)
4. 以下の詳細を追加します。

| フィールド名 | 説明 |
| --- | --- |
| Sender Name | <ul><li>Sender プロファイルに名前を付けます。</li><li>この名前は Sender に表示されるため、MoEngage 内でキャンペーンを作成する際に簡単に識別できます。</li><li>**Sender Name** は必須フィールドで、5～50 文字である必要があります。</li></ul> |
| WhatsApp business number | <ul><li>ユーザーに WhatsApp メッセージを送信するために使用する、WhatsApp に（Kwikchat 経由で）登録された電話番号を入力します。\* Sender の詳細は **Kwikchat\>Whatsapp Profile \> phone number** で確認できます。</li><li>これは必須フィールドで、WABA 番号とも呼ばれます。</li></ul> |
| API URL | ベンダーから API URL を取得し、**API URL** フィールドに入力します。サンプル URL：<br />[**https://apiv2.tellephant.com/v1/moengage**](https://apiv2.tellephant.com/v1/moengage) |
| X-api-key | <ul><li>Kwikchat（Gokwik）アカウントの API トークンをコピーし、MoEngage ダッシュボードの **X-api-key** フィールドに貼り付けます。</li><li>API トークンは、[Kwikchat（Gokwik）アカウントにログイン](https://app.tellephant.com/)し、**Integrations\> API** に移動すると確認できます。<br /><img src="/images/partner_25025446748692.png" alt="API token.png" /></li></ul> |

5. **Save** をクリックします。
6. Kwikchat に API トークンの有効化／検証を依頼します。

# 配信トラッキング

MoEngage 内で WhatsApp メッセージの配信を追跡するには、**MoEngage Delivery Tracking URL** をコピーし、Kwikchat（Gokwik）ダッシュボードで更新する必要があります。

![copy api.png](/images/partner_25025269610900.png)

<Info>
  上の画像の URL はサンプルです。MoEngage ダッシュボードから正確な URL をコピーし、Kwikchat（Gokwik）ダッシュボードで更新してください。
</Info>

MoEngage Delivery Tracking URL を Kwikchat（Gokwik）ダッシュボードに追加するには、次の手順を実行します。

1. [Kwikchat（Gokwik）アカウントにログイン](https://app.tellephant.com/)し、**Integrations \> Webhook** に移動します。
2. **DELIVERY RESPONSE WEBHOOK** セクションの **Webhook URL** フィールドに URL を貼り付け、**Webhook Status** を有効にします。
3. **Moengage Integration** チェックボックスをオンにし、**UPDATE WEBHOOKS** ボタンをクリックします。
   ![webhook.png](/images/partner_25025446755348.png)
   連携が成功すると、次のメッセージが表示されます。
   ![](/images/partner_25024891022868.png)

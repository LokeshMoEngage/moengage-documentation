---
title: "ValueFirst の設定"
---

MoEngage は WhatsApp 向けに ValueFirst とネイティブに連携しています。この連携により、企業は ValueFirst を利用してテンプレート化された WhatsApp メッセージを送信できます。MoEngage はメッセージを送信し、配信および既読の分析を表示できます。

## Sender の設定

MoEngage ダッシュボードで ValueFirst の Sender を設定するには、次の手順を実行します。

1. Settings-\>WhatsApp-\>Sender Configuration に移動します。
2. 左側のメニューで \+Add connector をクリックします。
3. ドロップダウンに表示される WA プロバイダーまたはコネクターのリストから ValueFirst を選択し、_Done_ をクリックします。

![ValueFirst\_ChooseConnector.png](/images/partner_18328807133588.png)

4. 画面右上の \+ Sender をクリックして、Sender の詳細を設定します。

![ValueFirst\_SenderConfig.png](/images/partner_18093478902164.png)

5. 以下の詳細を追加します。

| フィールド名 | 説明 |
| --- | --- |
| Sender name | このフィールドは、Sender プロファイルに付ける名前を示します。この名前は Sender に表示されるため、MoEngage 内でキャンペーンを作成する際に簡単に識別できます。_Sender Name_ は 5～50 文字である必要があります。これは必須フィールドです。 |
| WhatsApp business number | このフィールドは、ユーザーに WhatsApp メッセージを送信するために使用する、WhatsApp に（直接または ValueFirst 経由で）登録された電話番号を示します。これは ValueFirst プラットフォームに登録したビジネス番号と同じものです。これは必須フィールドで、WABA 番号とも呼ばれます。 |
| Authorization | このフィールドは、ValueFirst プラグインの Configuration セクションにある _Basic Token_ を示します。詳細については、設定手順を参照してください。 |

6. 連携が成功すると、次のメッセージが表示されます。

![SaveIntegration.png](/images/partner_18067308059924.png)

## ValueFirst で MoEngage を設定する手順

1. アプリケーションポータル（以下のリンク）で、名前、メールアドレス、会社の詳細を入力してサインアップします。[https://moengage.vfplugin.com/signup](https://moengage.vfplugin.com/signup)
2. サインアップフォームで指定したメールアドレスとパスワードを使用して、アプリケーションポータルにログインします。
3. 'ValueFirst WhatsApp' タブをクリックし、ValueFirst の Username、Password、WhatsApp の電話番号を設定します。

![VF\_Login.png](/images/partner_18329918462100.png)

4. ポータルから Inbound Webhook をコピーし、ValueFirst の営業チームまたはサポートチームに共有できます。
5. 以下の画像に示すように、'MoEngage WhatsApp' タブをクリックし、Sender Configuration で Authorization として使用する Basic Token をコピーします。

![ValueFirst\_Steps (1).png](/images/partner_18069170183060.png)

## 配信トラッキング

MoEngage 内で WhatsApp メッセージの配信を追跡するには、MoEngage Delivery Tracking URL をコピーして ValueFirst の Configuration 設定に追加する必要があります。次の手順を実行します。

1. MoEngage で Settings-\>WhatsApp-\>Sender Configuration-\> ValueFirst に移動すると、以下のように URL が表示されます。

![ValueFirst\_EnableDT.png](/images/partner_18069481393556.png)

2. MoEngage ダッシュボードから正確な URL をコピーします。
3. Connector アプリにログインし、'MoEngage WhatsApp' タブに移動します。
4. 以下に示すように、MoEngage WhatsApp コネクターからコピーした Delivery Tracking URL を貼り付けて、Status Callback と Incoming Callback を設定します。

![ValueFirst\_DTConfig.png](/images/partner_18069637665556.png)

5. MoEngage で ValueFirst の Sender 用の WhatsApp キャンペーンを作成するには、ValueFirst で事前承認済みのテンプレートが必要です。テンプレートは、ValueFirst プラットフォームの Approved Templates セクションで作成できます。
6. MoEngage でも同じテンプレートを一字一句そのまま作成できます。詳細については、[テンプレートの追加](/ja/user-guide/campaigns-and-channels/whatsapp/getting-started-with-whatsapp/whatsapp-templates)を参照してください。

---
title: "Yellow.ai の設定"
---

MoEngage は WhatsApp 向けに Yellow.ai とネイティブに連携しています。この連携により、企業は Yellow.ai が提供する Sender を使用してテンプレート化された WhatsApp メッセージを送信できます。MoEngage はメッセージを送信し、配信および既読の分析を表示できます。

## Sender の設定

MoEngage ダッシュボードで Yellow.ai の Sender を設定するには、次の手順を実行します。

1. **Settings** -\> **WhatsApp** -\> **Sender Configuration** に移動します。
2. 左側のメニューで **\+Add connector** をクリックします。
3. ドロップダウンに表示される WA プロバイダーまたはコネクターのリストから **Yellow.ai** を選択し、**Done** をクリックします。

![WAConnector\_Yellow.ai.png](/images/partner_20394787315220.png)

4. 画面右上の **\+ Sender** をクリックし、以下の説明に従って Sender の詳細を設定します。

![WAConnector\_Yellow.ai\_Sender.png](/images/partner_20394804045844.png)

5. 以下の詳細を追加します。

| フィールド名 | 説明 |
| --- | --- |
| **Sender name** | このフィールドは、Sender プロファイルに付ける名前を示します。この名前は Sender に表示されるため、MoEngage 内でキャンペーンを作成する際に簡単に識別できます。_Sender Name_ は 5～50 文字である必要があります。これは必須フィールドです。 |
| **WhatsApp business number** | このフィールドは、ユーザーに WhatsApp メッセージを送信するために使用する、WhatsApp に（直接または Yellow.ai 経由で）登録された電話番号を示します。これは必須フィールドで、WABA 番号とも呼ばれます。 |
| **API URL** | Sender Configuration 画面に表示される配信トラッキング URL を Yellow.ai の担当者（POC）に共有し、API URL（Webhook URL）を受け取ります。共有された URL を **API URL** フィールドに貼り付けます。 |
| **Authentication** | Sender Configuration 画面に表示される配信トラッキング URL を Yellow.ai の担当者（POC）に共有し、Authentication（API Key）を受け取ります。共有された API Key を **Authentication** フィールドに貼り付けます。 |
| **Enable delivery tracking** | MoEngage 内で WhatsApp メッセージの配信を追跡するには、MoEngage Delivery Tracking URL をコピーして Yellow.ai に共有し、MoEngage と Yellow のプラットフォーム連携で更新してもらう必要があります。配信トラッキング URL は、以下のように MoEngage の WhatsApp ダッシュボードで確認できます。<br /><img src="/images/partner_20395231941268.png" alt="Yellow.ai_DTURL.png" /><br />注：この配信トラッキング URL はサンプルです。Yellow.ai チームに共有する前に、MoEngage ダッシュボードから正確な URL をコピーしてください。 |

6. **Save** をクリックします。連携が成功すると、次のメッセージが表示されます。

![SaveIntegration.png](/images/partner_20394560973844.png)

## Yellow.ai プラットフォームの連携で実行する手順

1. Yellow.ai プラットフォームのインテグレーションページに移動します。
2. **Postback URL をコピーする** — MoEngage を選択し、手順セクション（ページの右側）に記載されている Postback URL をコピーします。
3. **Postback URL と Notification Engine API を有効にする**
   1. **Engagement** \> **Preferences** に移動します。
   2. Postback URL と Notification Engine API の両方を有効にします。
   3. 前のステップでコピーした Postback URL を貼り付けます。
   4. **Save** をクリックして確定します。
      ![20.png](/images/partner_29224402214676.png)

<Info>
  - MoEngage で Yellow.ai の Sender 用の WhatsApp キャンペーンを作成するには、Yellow.ai で事前承認済みのテンプレートが必要です。テンプレートは Yellow.ai の engagement セクションで作成できます。
  - MoEngage でも同じテンプレートを一字一句そのまま作成できます。詳細については、[テンプレートの追加](/ja/user-guide/campaigns-and-channels/whatsapp/getting-started-with-whatsapp/whatsapp-templates)を参照してください。
</Info>

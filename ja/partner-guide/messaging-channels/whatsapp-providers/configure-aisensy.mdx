---
title: "AiSensy の設定"
---

MoEngage は WhatsApp 向けに AiSensy と連携しています。この連携により、企業は AiSensy が提供する Sender を使用してテンプレート化された WhatsApp メッセージを送信できます。MoEngage はメッセージを送信し、配信および既読の分析を表示できます。

## Sender の設定

MoEngage ダッシュボードで AiSensy の Sender を設定するには、次の手順を実行します。

1. Settings-\>WhatsApp-\>Sender Configuration に移動します。
2. 左側のメニューで \+Add connector をクリックします。
3. ドロップダウンに表示される WA プロバイダーまたはコネクターのリストから AiSensy を選択し、_Done_ をクリックします。

![AiSensy.png](/images/partner_16579679366932.png)

4. 画面右上の \+ Sender をクリックし、以下の説明に従って Sender の詳細を設定します。<img src="/images/partner_16579655876372.png" alt="AiSensy_Configuration.png" />

| フィールド名 | 説明 |
| --- | --- |
| Sender name | このフィールドは、Sender プロファイルに付ける名前を示します。この名前は Sender に表示されるため、MoEngage 内でキャンペーンを作成する際に簡単に識別できます。_Sender Name_ は 5～50 文字である必要があります。これは必須フィールドです。 |
| WhatsApp business number | このフィールドは、ユーザーに WhatsApp メッセージを送信するために使用する、WhatsApp に（直接または AiSensy 経由で）登録された電話番号を示します。これは必須フィールドで、WABA 番号とも呼ばれます。AiSensy では、Channels & Numbers -\>WhatsApp -\>Senders で Sender の詳細を確認できます。 |
| authentication | このフィールドは API Key を示し、API 呼び出しを行っているアカウントを識別するために使用されます。ここに AiSensy アカウントの API Key を入力します。API Key を取得するには、次の手順を実行します。<ul><li>AiSensy アカウントにログインします。</li><li>インテグレーションセクションに移動します。</li><li>MoEngage を選択します。</li><li>Get Started タブで、Connect MoEngage セクションに移動します。</li><li>'_Click to copy'_ をクリックして API Key をコピーします。</li><li>MoEngage ダッシュボードの Sender Configuration の詳細にある authentication フィールドに API Key を貼り付けます。<img src="/images/partner_16551014107540.png" alt="moengage2.png" /></li></ul> |
| delivery-report-callback-url | MoEngage で WhatsApp メッセージの配信を追跡するには、MoEngage の Delivery Tracking URL をコピーして AiSensy チームに渡します。URL は以下のように表示されます。<ul><li>**注**：この URL はサンプルです。Sender の設定時に MoEngage ダッシュボードから正確な URL をコピーしてください。配信トラッキング URL を AiSensy に追加するには、次の手順を実行します。</li><li>AiSensy アカウントにログインします。</li><li>インテグレーションセクションに移動します。</li><li>MoEngage を選択します。</li><li>Get Started タブで、Connect MoEngage セクションに移動します。</li><li>MoEngage が提供する配信トラッキング URL（_Enable delivery tracking_ セクション内）をコピーし、AiSensy ダッシュボードの Enter MoEngage Webhook URL フィールドに貼り付けます。<br /><img src="/images/partner_16551014107540.png" alt="moengage2.png" /></li></ul> |

5. Save をクリックして Sender の詳細を保存します。連携が成功すると、成功メッセージが表示されます。

![SuccessMsg.png](/images/partner_16585441670548.png)

<Info>
  - MoEngage で AiSensy の Sender 用の WhatsApp キャンペーンを作成するには、AiSensy で事前承認済みのテンプレートが必要です。
  - MoEngage でも同じテンプレートを一字一句そのまま作成できます。詳細については、[テンプレートの追加](/ja/user-guide/campaigns-and-channels/whatsapp/getting-started-with-whatsapp/whatsapp-templates)を参照してください。
</Info>

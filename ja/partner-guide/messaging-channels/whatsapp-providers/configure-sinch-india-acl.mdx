---
title: "Sinch India（ACL）の設定"
---

MoEngage は WhatsApp 向けに [Sinch India](https://sinch.com/in/apis/whatsapp/) とネイティブに連携しています。この連携により、企業は Sinch India が提供する Sender を使用してテンプレート化された WhatsApp メッセージを送信できます。MoEngage はメッセージを送信し、配信および既読の分析を表示できます。

### 前提条件

- この連携を使用するには、Sinch India で稼働中の [WhatsApp Business API](https://sinch.com/messaging/whatsapp-business-api/) アカウントが必要です。
- Sinch India WhatsApp と接続するには、MoEngage アカウントが必要です。

## Sender の設定

1. **Settings \> WhatsApp \> Sender Configuration** に移動します。
2. 左側のメニューから Sinch India を選択し、**\+ Sender** をクリックします。

![](/images/partner_24713654769684.png)

以下の詳細を追加します。

| フィールド名 | 説明 |
| --- | --- |
| Sender Name | このフィールドは、Sender プロファイルに付ける名前を示します。この名前は Sender に表示されるため、MoEngage 内でキャンペーンを作成する際に簡単に識別できます。Sender Name は 5～50 文字である必要があります。これは必須フィールドです。 |
| WhatsApp Business number | このフィールドは、ユーザーに WhatsApp メッセージを送信するために使用する、Sinch India 経由で WhatsApp に登録された電話番号を示します。これは必須フィールドで、WABA 番号とも呼ばれます。 |
| API URL | Sinch India から提供された HTTP / HTTPS エンドポイントを入力します。 |
| user | Sinch India から提供されたユーザー名を入力します。 |
| pass | Sinch India から提供されたパスワードを入力します。 |
| isEncrypted | デフォルト値：_false_ |

## 配信トラッキング

MoEngage 内で WhatsApp メッセージの配信を追跡するには、MoEngage Delivery Tracking URL をコピーして Sinch India に共有し、先方で更新してもらう必要があります。配信トラッキング URL は、以下のように MoEngage ダッシュボードで確認できます。

![](/images/partner_24713654772500.png)

すべての詳細を追加したら、**Save** をクリックして Sender を追加します。連携が成功すると、次のメッセージが表示されます。

![SaveIntegration.png](/images/partner_24711403405076.png)

# はじめに

Vonage は、ブランドが WhatsApp で顧客とつながるのを支援する Communication Platform as a Service (CPaaS) プロバイダーです。Vonage MoEngage Connector は、Vonage Cloud Runtime (VCR) 上に構築されたセルフサービス型のノーコード統合です。MoEngage のキャンペーン実行レイヤーと Vonage のメッセージングインフラストラクチャを橋渡しし、Vonage を通じて直接 WhatsApp キャンペーンを大規模に送信できるようにします。詳細については、Vonage の [WhatsApp Channel User Guide](https://api.support.vonage.com/hc/en-us/articles/29661901573276-MoEngage-Connector-WhatsApp-Channel-Guide) を参照してください。

このコネクターは、Standalone と Conversational Connect の 2 つの動作モードをサポートしています。Conversational Connect モードに固有の前提条件と設定手順については、[Vonage WhatsApp Channel Guide](https://api.support.vonage.com/hc/en-us/articles/29661901573276-MoEngage-Connector-WhatsApp-Channel-Guide) のセクション 2 を参照してください。

<Info>
  **前提条件**

  * API キーを取得するための [Vonage Dashboard](https://dashboard.nexmo.com/private/dashboard) へのアクセス権。
  * コネクターインスタンスをデプロイするための [Vonage Cloud Runtime](https://developer.vonage.com/en/cloud-runtime) へのアクセス権。
  * 送信者番号がオンボーディング済みの、登録済みかつ Meta の承認を受けた WhatsApp Business Account (WABA)。
  * Signature secret を取得するための Vonage Dashboard Settings へのアクセス権 (Standalone モードのみ)。Conversational Connect モードの場合、Webhook の署名は代わりに Conversational Connect Developer Portal から取得します。
  * MoEngage ダッシュボードの管理者権限と、MoEngage テナントで WhatsApp チャネルが有効になっていること。
</Info>

## Sender の設定

MoEngage ダッシュボードで Vonage の Sender を設定するには、次の手順を実行します。

1. **Settings** > **Channels** > **WhatsApp** > **Sender configuration** に移動します。
2. **+ Add connector** をクリックし、コネクターのリストから **Vonage Connector** を選択します。
3. [Vonage WhatsApp Channel Guide](https://api.support.vonage.com/hc/en-us/articles/29661901573276-MoEngage-Connector-WhatsApp-Channel-Guide) のセクション 3 (Conversational Connect モード、ステップ 1～8) またはセクション 4 (Standalone モード、ステップ 1～5) に従って、Vonage Cloud Runtime に Vonage Conversations for MoEngage コネクターをデプロイし、その後このページに戻って Sender を設定します。
4. 次の詳細を追加します。

| フィールド名 | 説明 |
| --- | --- |
| Sender name | MoEngage でキャンペーンを作成する際に識別できるよう、この Sender プロファイルにわかりやすい名前を付けます。 |
| WhatsApp business number | Vonage に登録されている WABA 番号 (国番号を含む) です。 |
| API URL | Vonage コネクターの管理パネルからコピーします。この値を取得するには、[Step 10: Configure the Sender Profile in MoEngage](https://api.support.vonage.com/hc/en-us/articles/29661901573276-MoEngage-Connector-WhatsApp-Channel-Guide#:~:text=Step%2010%3A%20Configure%20the%20Sender%20Profile%20in%20MoEngage) に記載されている手順を実行してください。 |
| Authorization | 値を `Bearer <token>` に設定し、`<token>` を生成したベアラートークンに置き換えます。このトークンを生成するには、[Step 9: Generate a Bearer Token for Authentication](https://api.support.vonage.com/hc/en-us/articles/29661901573276-MoEngage-Connector-WhatsApp-Channel-Guide#:~:text=Step%209%3A%20Generate%20a%20Bearer%20Token%20for%20Authentication) に記載されている手順を実行してください。 |
| Template Sync URL | API URL と同様に、Vonage コネクターの管理パネルからコピーします。 |

<img src="images/vonage-sender-details.png" alt="Vonage WhatsApp 送信者の Sender Details 画面。送信者と認証のフィールドが表示されています" />

5. **Save** をクリックして、この Sender 設定を保存します。

<Info>
  Vonage の Sender で WhatsApp キャンペーンを実行するには、事前承認済みの WhatsApp テンプレートが必要です。Sender を保存した後、**Settings** > **WhatsApp** > **Approved templates** に移動し、**Sync Template** をクリックしてテンプレートをインポートします。テンプレートが取り込まれない場合は、正確な名前、言語、カテゴリ、プレースホルダー構造を指定して手動で追加します。Conversational Connect モードのカルーセルテンプレートを含む詳細については、[Vonage WhatsApp Channel Guide](https://api.support.vonage.com/hc/en-us/articles/29661901573276-MoEngage-Connector-WhatsApp-Channel-Guide) のセクション 5.1 を参照してください。
</Info>

## 配信トラッキングを有効にする

WhatsApp の配信トラッキングを有効にするには、保存後に表示される **MoEngage Delivery Tracking URL** をコピーし、Vonage コネクターの管理パネルで更新します。

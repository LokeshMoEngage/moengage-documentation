# はじめに

[PFL](https://www.pfl.com/) は、戦略や制作から配送、効果測定に至るまでのプロセス全体を管理することで、大規模なダイレクトメールを簡素化します。

# ユースケース

PFL × MoEngage のインテグレーションにより、MoEngage のフローからパーソナライズされたダイレクトメールを送信し、デジタルチャネルと並行して物理的な郵便物をオーケストレーションすることで、真のクロスチャネルのカスタマーエクスペリエンスを実現できます。

# インテグレーション

<Info>
  **前提条件**

  1. PFL ダッシュボードへのアクセス権があることを確認してください。 

  2. PFL Webhook キーと PFL URL があることを確認してください。これらがない場合は、PFL のカスタマーサクセスマネージャーとのインストールコールをスケジュールしてください。注文を行う各 PFL ストアの API キーを提供してもらえます。
</Info>

PFL と連携するには、PFL API を使用して、MoEngage コネクター経由で受信者データを送信します。

## ステップ 1：MoEngage でコネクターキャンペーンを作成する

MoEngage でコネクターキャンペーンを作成するには、

1. Create Campaign \>\> Connectors \>\> Custom に移動します

![Screenshot\_2022-02-21\_at\_10.48.46\_PM.png](/images/partner_23502530346900.png)

2. キャンペーンのステップ 2 で、次を選択します -

#### a) URL の詳細

| キー | 値 |
| --- | --- |
| Method | POST |
| Webhook URL | \<PFL URL\> |
| URL params | -- |

#### b) ヘッダー

次の 2 つのヘッダーを追加します

| キー | 値 |
| --- | --- |
| Authorization | Bearer \<PFL Webhook key\> |

#### c) リクエストボディ

次のリクエストボディでは、RAW を選択し、PFL 開発チームから提供されたペイロードを入力します。

## ステップ 3：設定をテストする

この時点で、キャンペーンをテストして送信する準備が整っているはずです。コネクターキャンペーン作成のステップ 2 で利用できるテスト機能を使用して、コネクターの設定をテストすることもできます。

![Screen\_Shot\_2022-02-22\_at\_11.12.42\_AM.png](/images/partner_23502530348564.png)

設定をテストするか、キャンペーンをトリガーしたら、PFL ダッシュボードを確認してください。

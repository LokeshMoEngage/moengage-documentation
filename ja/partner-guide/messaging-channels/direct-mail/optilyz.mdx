# はじめに

[Optilyz](https://optilyz.com/) は、より顧客中心で、持続可能かつ収益性の高いダイレクトメールキャンペーンを実行できるダイレクトメール自動化プラットフォームです。

# ユースケース

Optilyz と MoEngage のコネクターを使用して、レター、ポストカード、セルフメーラーなどのダイレクトメールを顧客に送信します。ダイレクトメールをデジタルチャネルのように運用するということは、大量郵送から脱却し、（デジタル）カスタマージャーニーの一部としてこのチャネルを活用することを意味します。ダイレクトメールへの現代的なアプローチのメリットは次のとおりです。

- 関連性の向上、追加のユースケース、より簡単な A/B テスト、クロスチャネル効果によるコンバージョン率の向上
- 自動化とエンドツーエンドのソリューションによる工数の削減
- 包括契約とコストの透明性によるコストの削減

# インテグレーション

<Info>
  **前提条件**

  1. Optilyz ダッシュボードへのアクセス権があることを確認してください。
  2. Optilyz API キーがあることを確認してください。Optilyz API キーは、Optilyz のカスタマーサクセスマネージャーから提供されます。
  3. Optilyz Automation ID があることを確認してください。Automation ID は、ページヘッダーのボックス内で確認できます。Optilyz ダッシュボードで、（データを送信する）オートメーションに移動してください。まず、アカウントでオートメーションが有効化されている必要があります。
</Info>

optilyz と連携するには、[optilyz API](https://www.optilyz.com/doc/api/) を使用して受信者データを MoEngage コネクターに送信します。

## ステップ 1：MoEngage でコネクターキャンペーンを作成する

MoEngage でコネクターキャンペーンを作成するには、

1. Create Campaign \>\> Connectors \>\> Custom に移動します

![Screenshot\_2022-02-21\_at\_10.48.46\_PM.png](/images/partner_4455800640660.png)

2. キャンペーンのステップ 2 で、次を選択します -

#### a) URL の詳細

![Screenshot\_2022-02-28\_at\_1.51.23\_PM.png](/images/partner_4520579794964.png)

| キー | 値 |
| --- | --- |
| Method | POST |
| Webhook URL | `https://www.optilyz.com/api/v2/automations/<OPTILYZ_AUTOMATION_ID>/recipient` |
| URL params | -- |

#### b) ヘッダー

![Screenshot\_2022-02-28\_at\_1.53.18\_PM.png](/images/partner_4520560536724.png)

次の 2 つのヘッダーを追加します

| キー | 値 |
| --- | --- |
| Authorization | `{{ '<OPTILYZ_API_KEY>:' \| base64_encode }}` |
| Content-Type | application/json |

#### c) リクエストボディ

次のリクエストボディでは、任意のパーソナライゼーション属性を使用し、[Optilyz の API ドキュメント](https://www.optilyz.com/doc/api/)に従ってカスタムリクエストテンプレートを構築できます。

`variation` フィールドは任意で、オートメーション内のどのデザインを使用するかを定義できます。variation を省略した場合、Optilyz は定義されたバリエーションのいずれかをランダムに割り当てます。 <img src="/images/partner_4520577566484.png" alt="Screenshot_2022-02-28_at_1.57.59_PM.png" />

## ステップ 3：設定をテストする

この時点で、キャンペーンをテストして送信する準備が整っているはずです。コネクターキャンペーン作成のステップ 2 で利用できるテスト機能を使用して、コネクターの設定をテストすることもできます。

![Screen\_Shot\_2022-02-22\_at\_11.12.42\_AM.png](/images/partner_4460621328788.png)

設定をテストするか、キャンペーンをトリガーしたら、Optilyz ダッシュボードを確認してください。

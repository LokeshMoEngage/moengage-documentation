# はじめに

[Poplar](https://heypoplar.com/) は、カスタマージャーニーのあらゆる段階で顧客の成長促進を支援する、パフォーマンス重視のダイレクトメールソリューションです。

# ユースケース

Poplar × MoEngage のインテグレーションにより、MoEngage のキャンペーンやフローから物理的な郵便物を送信できます。

# インテグレーション

<Info>
  **前提条件**

  1. Poplar ダッシュボードへのアクセス権があることを確認してください。
  2. Poplar API キーがあることを確認してください。必要に応じて、MoEngage 用に作成することもできます。
</Info>

Poplar と連携するには、[Poplar API](https://developers.heypoplar.com/endpoints/mailing) を使用して、MoEngage コネクター経由で受信者データを送信します。

## ステップ 1：MoEngage でコネクターキャンペーンを作成する

MoEngage でコネクターキャンペーンを作成するには、

1. Create Campaign \> Connectors \> Custom に移動します

![Screenshot\_2022-02-21\_at\_10.48.46\_PM.png](/images/partner_23503517648020.png)

2. キャンペーンのステップ 2 で、次を選択します -

#### a) URL の詳細

| キー | 値 |
| --- | --- |
| Method | POST |
| Webhook URL | [https://api.heypoplar.com/v1/mailing](https://api.heypoplar.com/v1/mailing) |
| URL params | -- |

#### b) ヘッダー

次の 2 つのヘッダーを追加します

| キー | 値 |
| --- | --- |
| Authorization | Bearer `<Poplar API key>` |
| Content-Type | application/json\> |

#### c) リクエストボディ

次のリクエストボディでは、RAW を選択して、次のペイロードを入力します -

<CodeGroup>

```json JSON wrap
{"campaign_id": "{{UserAttribute['campaign_id']}}","recipient": {"city": "{{UserAttribute['City']}}","email": "{{UserAttribute['Email']}}","state": "{{UserAttribute['State']}}","address_1": "{{UserAttribute['Address line 1']}}","address_2": "{{UserAttribute['Address line 2']}}","first_name": "{{UserAttribute['First Name']}}","last_name": "{{UserAttribute['Last Name']}}","postal_code": "{{UserAttribute['Postal code']}}"},"merge_tags": {"promo-code": ""},"creative_id": "<any sample id>"}
```

</CodeGroup>

## ステップ 3：設定をテストする

この時点で、キャンペーンをテストして送信する準備が整っているはずです。コネクターキャンペーン作成のステップ 2 で利用できるテスト機能を使用して、コネクターの設定をテストすることもできます。

![Screen\_Shot\_2022-02-22\_at\_11.12.42\_AM.png](/images/partner_23503517650964.png)

設定をテストするか、キャンペーンをトリガーしたら、Poplar ダッシュボードを確認してください。

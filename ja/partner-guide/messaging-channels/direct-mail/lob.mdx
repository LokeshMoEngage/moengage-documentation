# はじめに

[Lob](https://www.lob.com/) は、ユーザーにダイレクトメールを送信できるオンラインサービスです。

# インテグレーション

MoEngage と Lob のインテグレーションでは、MoEngage コネクターと Lob API を活用して、レター、ポストカード、小切手などを郵送します。

<Info>
  **前提条件**

  1. Lob ダッシュボードへのアクセス権があることを確認してください。 
  2. Lob API キーがあることを確認してください。Lob API キーは、Lob ダッシュボードの名前の下にある設定セクションで確認できます。
</Info>

## ステップ 1：Lob エンドポイントを選択する

コネクターでリクエストする HTTP URL は、Lob に対して実行できるアクションごとに異なります。次の例では、ポストカード API エンドポイント `https://api.lob.com/v1/postcards` を使用しています。ユースケースに適したエンドポイントを選択するには、[エンドポイントの完全なリスト](https://lob.com/docs#intro)を参照してください。

![lob\_api\_endpoint.png](/images/partner_4455759370516.png)

## ステップ 2：MoEngage でコネクターキャンペーンを作成する

MoEngage でコネクターキャンペーンを作成するには、

1. Create Campaign \>\> Connectors \>\> Custom に移動します

![Screenshot\_2022-02-21\_at\_10.48.46\_PM.png](/images/partner_4455800640660.png)

2. キャンペーンのステップ 2 で、次を選択します -

#### a) URL の詳細

![Screenshot\_2022-02-21\_at\_11.06.00\_PM.png](/images/partner_4455954213396.png)

キー

| キー | 値  | 注記 |
| --- | --- | --- |
| Method | POST | |
| Webhook URL | [https://your-lob-API-endpoint](https://your-lob-API-endpoint) | |
| URL params | -- | 任意。URL にパーソナライズされた値が含まれる場合にのみ必要です

#### b) ヘッダー

![Screenshot\_2022-02-21\_at\_11.09.42\_PM.png](/images/partner_4455986787604.png)

次の 2 つのヘッダーを追加します

| キー | 値 |
| --- | --- |
| Authorization | Basic \<lob-API-key\> |
| Content-Type | application/json |

#### c) リクエストボディ

以下は、Lob のポストカードエンドポイントのリクエストボディの例です。このリクエストボディは基本の Lob テンプレートで提供されていますが、他のエンドポイントを使用する場合は、それに応じて Liquid フィールドを調整する必要があります。 <img src="/images/partner_4455989176596.png" alt="Screenshot_2022-02-21_at_11.11.34_PM.png" />

## ステップ 3：設定をテストする

この時点で、キャンペーンをテストして送信する準備が整っているはずです。コネクターキャンペーン作成のステップ 2 で利用できるテスト機能を使用して、コネクターの設定をテストすることもできます。

![Screen\_Shot\_2022-02-22\_at\_11.12.42\_AM.png](/images/partner_4460621328788.png)

設定をテストするか、キャンペーンをトリガーしたら、Lob ダッシュボードを確認してください。

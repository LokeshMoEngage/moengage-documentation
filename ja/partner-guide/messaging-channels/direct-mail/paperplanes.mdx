# はじめに

[Paperplanes](https://flypaperplanes.co.uk/) は、より顧客中心で収益性の高いダイレクトメールキャンペーンを実行できるダイレクトメール自動化プラットフォームです。

# ユースケース

Paperplanes と MoEngage のコネクターを使用して、レター、ポストカード、セルフメーラーなどのダイレクトメールを顧客に送信します。ダイレクトメールをデジタルチャネルのように運用するということは、大量郵送から脱却し、（デジタル）カスタマージャーニーの一部としてこのチャネルを活用することを意味します。ダイレクトメールへの現代的なアプローチのメリットは次のとおりです。

- 関連性の向上、追加のユースケース、より簡単な A/B テスト、クロスチャネル効果によるコンバージョン率の向上
- 自動化とエンドツーエンドのソリューションによる工数の削減
- 包括契約とコストの透明性によるコストの削減

# インテグレーション

<Info>
  **前提条件**

  1. Paperplanes ダッシュボードへのアクセス権があることを確認してください。
  2. Paperplanes の API キーとシークレットキーがあることを確認してください。Paperplanes に連絡して、API キーとシークレットを生成してもらってください。
</Info>

Paperplanes と連携するには、Paperplane API を使用して受信者データを MoEngage コネクターに送信します。

## ステップ 1：MoEngage でコネクターキャンペーンを作成する

MoEngage でコネクターキャンペーンを作成するには、

1. Create Campaign \>\> Connectors \>\> Custom に移動します

![Screenshot\_2022-02-21\_at\_10.48.46\_PM.png](/images/partner_23502193497492.png)

2. キャンペーンのステップ 2 で、次を選択します -

#### a) URL の詳細

| キー | 値 |
| --- | --- |
| Method | POST |
| Webhook URL | [https://api.paperplaneslive.com/api/submit](https://api.paperplaneslive.com/api/submit) |
| URL params | -- |

#### b) ヘッダー

次の 2 つのヘッダーを追加します

| キー | 値 |
| --- | --- |
| api-key | `<Paperplane API key>` |
| api-secret | `<Paperplane secret>` |

#### c) リクエストボディ

次のリクエストボディでは、任意のパーソナライゼーション属性を使用して、カスタムリクエストテンプレートを構築できます。Raw を選択して、次のように入力します -

```text
{
"DestinationListId": 0,
"Records": [{
"CustomerID": "...",
"first_name": "...",
"last_name": "...",
"Address1": "...",
"Address2": "...",
"Address3": "...",
"Address4": "...",
"Address5": "...",
"Postcode": "...",
"AdditionalData": {}
}]
}
```

@ を使用して特定のユーザー属性/イベント属性を選択し、パーソナライゼーションを行うことができます。

## ステップ 3：設定をテストする

この時点で、キャンペーンをテストして送信する準備が整っているはずです。コネクターキャンペーン作成のステップ 2 で利用できるテスト機能を使用して、コネクターの設定をテストすることもできます。

![Screen\_Shot\_2022-02-22\_at\_11.12.42\_AM.png](/images/partner_23502193500820.png)

設定をテストするか、キャンペーンをトリガーしたら、Paperplanes ダッシュボードを確認してください。

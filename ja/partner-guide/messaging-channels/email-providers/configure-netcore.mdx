# はじめに

Netcore を使用すると、メールサーバーを維持することなくメールを配信できます。さらに、Netcore はインフラストラクチャのスケーリング、ISP との関係管理、レピュテーションの監視、ホワイトリストソリューションやリアルタイムインサイトの提供など、すべての技術的な側面を処理します。これらの機能を活用して MoEngage と Netcore を連携させることで、MoEngage でメールキャンペーンを作成し、Netcore アカウントを通じて送信できます。

# インテグレーション

<Info>
**前提条件**

Netcore アカウントへのアクセス権があることを確認してください。
</Info>

## MoEngage でメールコネクターを設定する

  1. MoEngage ダッシュボードにログインし、**App marketplace** に移動します。
  2. 表示される次の画面で、**Categories** の下にある **Emails >Netcore** を選択します。
![netcore 1.png](/images/partner_28932713239700.png)
  3. 表示される **Netcore** ページで、**Integrate** タブを選択し、**Add integration** をクリックします。
![netcore 2.png](/images/partner_28932713245588.png)



## SMTP 設定を構成する

  1. **Sender Name** を入力します。
  2. **SMTP Host Name** を **smtp.netcorecloud.net** に設定します。
  3. **SMTP Port** として **25、2525、**または **587** を選択します。一部のホスティング会社が設定しているレート制限を回避するため、推奨ポートは 587 です。
  4. **SMTP Protocol** として **TLS** を選択します。
  5. **SMTP Username** と **SMTP Password** は、Netcore Email API の認証情報です。Netcore のユーザーインターフェイスの **Settings** > **Integrations** で確認できます。

  6. ユーザーが自分で再購読できるようにする場合は、**Web API Key** を使用できます。
![Screenshot 2024-07-30 at 12.01.38 PM.png](/images/partner_28932713246484.png)  
  




## 配信停止設定を構成する

配信停止の仕組みを設定するには、**MoEngage Tracking** または **None** のいずれかを選択できます。プロモーションメールキャンペーンで **None** を選択すると、スパムとして分類される可能性が高くなります。詳細については、[こちら](/ja/user-guide/campaigns-and-channels/email/create/track-email-unsubscribes)を参照してください。 

![Screenshot 2024-07-30 at 12.04.41 PM.png](/images/partner_28932665055764.png)

## List Unsubscribe Email を設定する

List-Unsubscribe メールを設定するには、**MoEngage managed** または **Self-managed** オプションのいずれかを使用できます。詳細については、[こちら](/ja/user-guide/campaigns-and-channels/email/getting-started-with-email/list-unsubscribe-email)を参照してください。

![Screenshot 2024-07-30 at 12.05.55 PM.png](/images/partner_28932665056788.png)

## 配信、バウンス、苦情を設定する 

この情報は、以下の手順に従って Netcore Email API パネルで Webhook を設定することで取得します。 

  1. Netcore Email API アカウントにログインします。
  2. **Settings** > **Webhooks** に移動します。
  3. **Individual Events** を選択し、以下のイベントを選択して、それぞれに MoEngage ダッシュボード内のインテグレーションフォームで提供されている同じコールバック URL を貼り付けます。 
     1. **Delivered**
     2. **Bounces**
     3. **Invalids**
     4. **Drops**
     5. **Opened,**
     6. **UnSubscribes**
     7. **Spam Reports**
  4. 保存する前に、必ず Webhook を検証してください。
![Screenshot 2024-07-30 at 12.06.54 PM.png](/images/partner_28932665059220.png)



コネクターの設定はすべて完了です。**Save** をクリックすると、これらの設定（認証情報などを含む）がテストされて保存されます。

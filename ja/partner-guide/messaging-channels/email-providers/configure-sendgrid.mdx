# はじめに

SendGrid は、メールサーバーを維持することなくメールを送信できるクラウドベースの SMTP プロバイダーです。SendGrid は、インフラストラクチャのスケーリングから ISP へのアウトリーチ、レピュテーションの監視、ホワイトリストサービス、リアルタイム分析まで、すべての技術的な詳細を管理します。

<Info>
  - Sendgrid アカウントへのアクセス権があることを確認してください。
  - Sendgrid アカウントがセットアップされ、設定されていることを確認してください。
</Info>

# Sendgrid アカウントを設定する

[https://sendgrid.com/pricing](https://sendgrid.com/pricing) で SendGrid にサインアップし、料金プランを選択できます。アカウントの作成後、必要に応じて「Set Up \+ Configure」ボタンをクリックして、アカウントでドメインをホワイトラベル化できます。

![sendgrid\_1.png](/images/partner_25555571507476.png)

新しいドメインを追加し、「Save」をクリックします。次に、ドメインの DNS 設定に SendGrid が指定する TXT レコードを追加します。これにより、メール受信者に表示される「via sendgrid.net」が削除されます。

![sendgrid\_2.png](/images/partner_25555540427028.png)

# MoEngage で Sendgrid を設定する

MoEngage ダッシュボードで **Settings** \> **Channel** \> **Email** \> **Sender Configuration** \> **Add Sender** \> **Sendgrid** に移動して、Sendgrid の SMTP サービスを設定します。

## SMTP 設定を構成する

[SendGrid の SMTP コネクターの設定はこちら](https://sendgrid.com/docs/Integrate/index.html#-SMTP-Relay)で確認できます。

- **Sender Name** を入力します。
- **SMTP Host name、Port**、**Protocol** type は、リンク先の詳細から入力できます。一部の企業が設定しているレート制限を回避するため、推奨ポートは 587 です。
- **SMTP Username と Password** は、SendGrid アカウントの認証情報です。
- **Web API Key** は SMTP パスワードと同じです。このフィールドは必須ではありません。

![Screenshot 2024-07-02 at 8.05.20 PM.png](/images/partner_28108675297556.png)

## 配信停止設定と List Unsubscribe Email を設定する

- **Unsubscribe Settings** で **Sendgrid Tracking** オプションを選択します。MoEngage は、以下のコールバック URL で Sendgrid から受信した配信停止情報を使用して、配信停止をトラッキングします。
- **List unsubscribe email** で、
  - **MoEngage Managed** オプションを選択すると、MoEngage はトランザクション以外のすべてのメールのヘッダーに、独自の mail-to と https URL を含めます。
  - **Self Managed** オプションを選択した場合は、**One-click unsubscribe URL** と **List unsubscribe email** を入力します。これにより、MoEngage はトランザクション以外のすべてのメールのヘッダーにある mail-to と https URL にこれらを含めます。

![Screenshot 2024-07-02 at 8.31.45 PM.png](/images/partner_28109193634708.png)

## SendGrid のバウンスと苦情の設定を構成する

この情報は、**SendGrid Account -\> Mail Settings** で Event Notifications を ON に設定することで取得します。

![sendgrid\_4.png](/images/partner_25555540432276.png)

次に、**MoEngage Dashboard** \> **Settings** \> **Email** \> **Sender Configuration** \> **SendGrid** \> **Bounces & Complaint Tracking (Callback URL)** から URL をコピーし、上記の HTTP POST URL テキストボックスに貼り付けます。

![Screenshot 2024-07-02 at 8.33.20 PM.png](/images/partner_28109148208532.png)

配信停止、バウンス、苦情のトラッキングを有効にするには、以下のスナップショットでチェックされているアクションを選択します。

![sendgrid\_6.png](/images/partner_25555540439572.png)

コネクターの設定はすべて完了です。**Save** をクリックすると、これらの設定（認証情報などを含む）がテストされて保存されます。その後、**General Settings** で SendGrid をデフォルトのコネクターとして選択できます。

# はじめに

Amazon Simple Email Service（SES）は、開発者があらゆるアプリケーション内からメールを送信できる、費用対効果が高く、柔軟でスケーラブルなメールサービスです。Amazon SES はすばやく設定でき、トランザクションメール、マーケティングメール、大量メール配信など、さまざまなメールのユースケースをサポートできます。

# インテグレーション

<Info>
  **前提条件**

  Amazon SES アカウントへのアクセス権があることを確認してください。
</Info>

## メールコネクターを設定する

Amazon Web Services アカウントは [http://aws.amazon.com/](http://aws.amazon.com/) で作成できます。アカウントの作成後、**AWS Console -\> SES** に移動し、ドメインの DNS 設定に指定された TXT レコードを追加してドメインを検証します。

![](/images/partner_28109708426004.png)

新しい Amazon SES アカウントはサンドボックスアカウントである可能性があります。その場合は、Amazon SES に本番アカウントをリクエストする必要があります。リクエストしないと、SMTP 設定は構成されません。[詳細はこちらに記載されています](http://docs.aws.amazon.com/ses/latest/DeveloperGuide/request-production-access.html)。リクエストでは、Daily Sending Quota と Maximum Sending Rate の上限引き上げを申請することもできます。Amazon が本番アカウントへのアクセスを確認するまでには、通常 4 時間かかります。

SES のバウンスと苦情は Amazon SNS を通じてトラッキングされます。詳細については、この記事の後半で説明します。

## SMTP 設定を構成する

SMTP コネクターの設定は、**AWS Account -\> SES -\> SMTP Settings** で確認できます。

![](/images/partner_28109708429588.png)

- **SMTP Host name、Port、Protocol type** は、上記の詳細から入力できます。ポート 25 はメールがスロットリングされる割合が高いため、使用しないでください。
- **SMTP Username と Password** は、「Create My SMTP Credentials」ボタンをクリックして取得できます。SMTP 認証情報の生成は限られているため、認証情報は必ず記録に保存してください。[_認証情報の生成について詳しくはこちら_](https://docs.aws.amazon.com/ses/latest/DeveloperGuide/smtp-credentials.html)。
- **Maximum send rate** は「Sending Statistics」タブに記載されています。

![](/images/partner_28109715889556.png)

- 「MoEngage Tracking」を選択すると、MoEngage の配信停止ページの URL がメールのフッターとして追加されます - 「If you'd like to unsubscribe and stop receiving these emails [click here](https://api-01.moengage.com/v1/emailunsubscribe?wid=%40%24xy%2A%40%21h_%C3%B6%C3%B01%1A%C2%B1%C3%8A%5B%C3%88&xid=%40%24xy%2A%40%21h%C2%A0%0F%C3%BB%1A%60%C2%A2%C3%94%C3%A3x%C2%92%C3%85%C3%BB%C2%A1%C2%98%22%1F%5C%C3%A8%2CT%7F%C3%AD%C2%B4%C2%AAy%C3%8BZ%C2%A4%C3%A6%C3%BD%C3%AB%02%C3%86%C3%BC%C3%9F%C2%96xHd%3D%C3%9A%C3%8BY%C3%A9%C3%8EXq.%C2%99%C2%B6O%3Aam%C2%A6%C2%93%C3%B2%C2%B6Cu%2FS%C2%81%3E%C2%AD%60%C3%9FB%C2%85%7C%C2%B0E%3D%C3%B1Q%C3%B3%3E%C2%8Cj%C3%B0%C2%8C%C2%A6%C2%9E%C2%B7&yid=%40%24xy%2A%40%21h%1Bd6V%7D%C3%AB%C3%B3%C2%8E%04%22tUJRw%C2%BD%3E%18Ne%C2%B0%C3%AC%C2%AFtv%C2%99%C3%90%C3%A7%C2%94%C3%98%C2%83D&zid=ushithwa%40moengage.com&url=https://google.com/)」。
- デフォルトでは、MoEngage は顧客を標準のランディングページにリダイレクトします。そこで利用できるオプションは再購読のみです。配信停止の理由を収集するなどの目的で、顧客をカスタムのランディングページに誘導したい場合は、**Unsubscribe Page URL** に独自のランディングページへのリンクを入力できます。

- **None** を選択すると、MoEngage はメールキャンペーンに配信停止リンクを含めません。この場合、メールコンテンツの作成時に配信停止リンクを含める責任はお客様にあります。プロモーションキャンペーンで配信停止リンクを含めない場合、スパムとして識別される可能性が高くなります。

## List Unsubscribe Email を設定する

**List unsubscribe email** で、

- **MoEngage Managed** オプションを選択すると、MoEngage はトランザクション以外のすべてのメールのヘッダーに、独自の mail-to と https URL を含めます。
- **Self Managed** オプションを選択した場合は、**One-click unsubscribe URL** と **List unsubscribe email** を入力します。これにより、MoEngage はトランザクション以外のすべてのメールのヘッダーにある mail-to と https URL にこれらを含めます。

![Screenshot 2024-07-02 at 8.43.02 PM.png](/images/partner_28109715898644.png)

## バウンスと苦情を設定する

このトラッキングは [_Amazon SNS 通知_](http://docs.aws.amazon.com/ses/latest/DeveloperGuide/configure-sns-notifications.html)を通じて実装されます。詳細は次のとおりです。

SES でドメインが検証されたら、ドメイン名を選択し、Notifications の下にある「Edit Configuration」ボタンをクリックします。次に、新しい SNS トピックを作成し、SNS Topic Configuration で Bounces と Complaints にこのトピックを選択して、「Save Config」をクリックします。

![](/images/partner_28109715901460.png)

次に、**AWS Console -\> SNS -\> Topics** に移動し、最近作成したトピックをクリックします。

![](/images/partner_28109708452372.png)

次に、**MoEngage Dashboard** \> **Settings** \> **Sender Configuration** \> **Amazon SES** \> **Bounces & Complaint Tracking (Callback URL)** から URL をコピーします。 <img src="/images/partner_28109715907860.png" alt="Screenshot 2024-07-02 at 8.45.27 PM.png" />

SNS Topic Details に戻り、「Create Subscription」をクリックして、以下のスナップショットに示すように Endpoint に URL を貼り付けます。

![](/images/partner_28109715910804.png)

Amazon SES は、ハードバウンスとソフトバウンスの両方の情報を MoEngage に渡します。これは、MoEngage の [Email イベント](/ja/user-guide/data/event-data/derived-events-and-attributes)である Email Bounced と Email Soft Bounced として利用できます。

Amazon SES のさまざまなバウンスタイプとサブタイプについては、[こちらのドキュメント](https://docs.aws.amazon.com/ses/latest/dg/notification-contents.html#bounce-object)を参照してください。

# 配信トラッキングを設定する

配信トラッキングは [_Amazon SNS 通知_](http://docs.aws.amazon.com/ses/latest/DeveloperGuide/configure-sns-notifications.html)を通じて実装されます。設定手順は次のとおりです。

SES でドメインが検証されたら、ドメイン名を選択し、Notifications の下にある「Edit Configuration」ボタンをクリックします。

1. 新しい SNS トピックを作成し、以下に示すように SNS Topic Configuration で Delivery Tracking にこのトピックを選択します。 <img src="/images/partner_10222483126676.png" alt="mceclip0.png" />
2. 「Save Config」をクリックします。
3. **AWS Console -\> SNS -\> Topics** に移動し、最近作成したトピックをクリックします。
4. Create Subscription をクリックし、表示される画面で次の詳細を入力します。 <img src="/images/partner_10222705453332.png" alt="mceclip2.png" />
   - **Topic**：このフィールドには、サブスクリプションを作成するトピックの詳細が自動的に入力されます。
   - **Protocol**：HTTPS
   - **Endpoint**：以下に示すように、**Moengage App Settings -\> Email Settings -\> Connector Configurations -\> Amazon SES -\> Callback URL** からエンドポイント URL をコピーします。 <img src="/images/partner_28109708463380.png" />
5. 以下に示すように、**Moengage App Settings -\> Email Settings -\> Connector Configurations -\> Amazon SES -\> Callback URL** から URL をコピーします。
6. 「Enable raw message delivery」チェックボックスのチェックを外します。
7. Create Subscription をクリックします。以下に示すように、Subscriptions メニューにこのサブスクリプションが表示されます。 <img src="/images/partner_10222727824148.png" alt="mceclip3.png" />
8. しばらく（1～2 時間）経ってもステータスが Pending confirmation のままの場合は、サブスクリプションを選択して Request confirmation をクリックします。
   ![mceclip4.png](/images/partner_10222755901460.png)

これで、配信トラッキングの設定が完了しました。

コネクターの設定はすべて完了です。「Save」ボタンをクリックすると、これらの設定（認証情報などを含む）がテストされて保存されます。その後、General Settings で Amazon SES をデフォルトのコネクターとして選択できます。

**注：** すべてのメールイベント（バウンス、苦情、配信）は、MoEngage User ID レベルですべてのユーザーごとに一意にトラッキングされます。

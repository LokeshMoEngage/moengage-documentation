# はじめに

[Knowlarity](https://www.knowlarity.com/) は、あらゆるビジネスのニーズと規模に適した、コスト効率が高く、カスタマイズ可能で信頼性の高いクラウドコミュニケーションサービスを提供しています。

# MoEngage × Knowlarity

MoEngage の Connector Campaigns を使用して、ユーザーにタイムリーな音声キャンペーンを送信できます。

# 統合

MoEngage の Connector Campaign を使用して Knowlarity API をトリガーします。以下は、Knowlarity の Call Campaign API を呼び出す方法のチュートリアルです。

## ステップ 1: API エンドポイントと仕様を確認する

[Knowlarity のドキュメント](https://developer.knowlarity.com/api-reference)を読み、ユースケースに応じたエンドポイントを把握します。

## ステップ 2: MoEngage でコネクターキャンペーンを設定する

MoEngage でコネクターキャンペーンを作成するには、

1. Create Campaign \>\> Connectors \>\> Custom に移動し、ニーズに最も適した配信タイプを選択します

![Screenshot\_2022-02-21\_at\_10.48.46\_PM.png](/images/partner_25027527543700.png)

2. キャンペーンのステップ 2 で次を行います

### Knowlarity API を呼び出す

Knowlarity で新しい Call Campaign を作成するには、`POST` メソッドを使用してペイロードを設定します。

- メソッドとして POST を選択します
- Headers:
  - `x-api-key`: お客様の Application Access Key
  - `Authorization`: `Your SR_API_KEY`
  - `Content-Type`: `application/json`
- Webhook URL としてエンドポイントを追加します: `https://kpi.knowlarity.com/Basic/v1/account/call/campaign/add-numbers/`
- Body:
  <CodeGroup>
  ```json JSON wrap
  {
      "order_id": {{ EventAttribute['order_number'] }},
      "additional_number": "+91{{ UserAttribute['Mobile Number (Standard)'] }}"
  }
  ```
  </CodeGroup>

![](/images/partner_25027527566356.png)

- 詳細については、[Knowlarity のドキュメント](https://developer.knowlarity.com/api-reference#api_ref_link81)を参照してください。

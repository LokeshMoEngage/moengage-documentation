# はじめに

[Exotel](https://exotel.com/) は、コミュニケーション API、オムニチャネルのコンタクトセンター、クラウド上の会話型 AI プラットフォームで構成される、フルスタックのカスタマーエンゲージメントプラットフォームです。

# MoEngage × Exotel

MoEngage の Connector Campaigns を使用して、ユーザーにタイムリーな音声キャンペーンを送信できます。

<Info>
  - Exotel アカウントにアクセスできることを確認してください。
  - Exotel API にアクセスできることを確認してください。
</Info>

# 統合

MoEngage の Connector Campaign を使用して Exotel API をトリガーします。以下は、Exotel の Call Campaign API を呼び出す方法のチュートリアルです。

## ステップ 1: API エンドポイントと仕様を確認する

Exotel のドキュメントを読み、ユースケースに応じたエンドポイントを把握します。

## ステップ 2: MoEngage でコネクターキャンペーンを設定する

MoEngage でコネクターキャンペーンを作成するには、

1. Create Campaign \>\> Connectors \>\> Custom に移動し、ニーズに最も適した配信タイプを選択します

![Screenshot\_2022-02-21\_at\_10.48.46\_PM.png](/images/partner_19201585784852.png)

2. キャンペーンのステップ 2 で次を行います

### Exotel API を呼び出す

Exotel で新しい Call Campaign を作成するには、`POST` メソッドを使用してペイロードを設定します。

- メソッドとして POST を選択します
- Headers:
  - Basic 認証の場合は、Exotel の API キーをユーザー名として、API トークンをパスワードとして使用します。
- Webhook URL としてエンドポイントを追加します: `https://<your_api_key>:<your_api_token><subdomain>/v2/accounts/<your_sid>/campaigns`
- Body:
  <CodeGroup>
  ```json JSON wrap
  {
      "campaigns": [
          {
              "name": "Exotel_2022-08-08 16:33:22",
              "caller_id": "0xxxx83280",
              "lists": [
                  "b7799a24becf436da672163858e8165d"
              ],
              "campaign_type": "dynamic",
              "flow_type": "ivr",
              "read_via_text": "Hi {{UserAttribute['First Name']}} {{UserAttribute['Last Name']}}, your order ID is {{EventAttribute['Order ID']}}. Press 1 to proceed, press 2 to abort"
          }
      ]
  }
  ```
  </CodeGroup>

![ContentAPI.png](/images/partner_15015623766548.png)

- 詳細については、[Exotel のドキュメント](https://developer.exotel.com/api/ccm-calls)を参照してください。

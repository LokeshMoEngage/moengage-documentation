## はじめに

このガイドでは、Salesforce Marketing Cloud（SFMC）で MoEngage カスタムアクティビティをセットアップするための詳細な手順を説明します。スムーズなインテグレーションと使用のために、以下の手順に従ってください。

<Info>
  **前提条件**

  - Salesforce Marketing Cloud へのアクセス：Administrator および Marketing Cloud Administrator の権限が必要です。
  - MoEngage API 認証情報：MoEngage API（Settings > Accounts > APIs）へのアクセス権があることを確認してください。
</Info>

## ステップ 1：MoEngage カスタムアクティビティをセットアップする

MoEngage カスタムアクティビティをセットアップするには、次の手順を実行します。

1. Salesforce Marketing Cloud（SFMC）にログインします。

   ![Salesforce Marketing Cloud のログイン画面](/images/partner_36576006441364.png)

2. SFMC の設定にアクセスします。

   ![ダッシュボードから SFMC の設定にアクセスする](/images/partner_36576006441620.png)

3. 「Installed Packages」をクリックすると、このタブがページの右側に表示されます。

   ![SFMC 設定の Installed Packages タブ](/images/partner_36576013645972.png)

4. 新しいパッケージを作成します。

   ![SFMC の Installed Packages で新しいパッケージを作成する](/images/partner_36576013646228.png)

5. パッケージの詳細を追加します。名前を「MoEngage Custom Activity」とし、説明を「Used to send one-time push notifications and run Event Trigger campaigns」とすることができます。

   ![MoEngage Custom Activity パッケージの名前と説明を入力する](/images/partner_36576013646484.png)

6. MoEngage コンポーネントを追加します。

   ![パッケージに MoEngage コンポーネントを追加する](/images/partner_36576006447124.png)

7. Add Component をクリックします。

   ![SFMC パッケージ設定の Add Component ボタン](/images/partner_36576006447636.png)

8. 「Journey Builder Activity」を選択し、「Next」をクリックします。

   ![コンポーネントタイプとして Journey Builder Activity を選択する](/images/partner_36576006447764.png)

9. Save をクリックします。
10. MoEngage Event Destination についても同じ手順を繰り返します。

    ![MoEngage Event Destination コンポーネントを追加する](/images/partner_36576013650708.png)

## ステップ 2：CloudPage とデータエクステンションをセットアップする

MoEngage ワークスペースの詳細を取得するために、CloudPage とデータエクステンションをセットアップする必要があります。これらは、Journey Builder で MoEngage デスティネーションを設定する際に使用できます。

1. SFMC のホームページに移動します。
2. 「Platform」>「Package Manager」をクリックします。

   ![SFMC で Platform > Package Manager に移動する](/images/partner_36576006448404.png)

   「Package Manager」をクリックすると、Package Manager ページにリダイレクトされます。

3. 「Deployment」タブをクリックします。
4. 「Deploy」をクリックします。

   ![Package Manager の Deployment タブと Deploy ボタン](/images/partner_36576013651476.png)

5. MoEngage ソリューションパッケージの [JSON ファイル](https://partners.moengage.com/hc/en-us/article_attachments/45740967830932)をアップロードします。

   ![MoEngage ソリューションパッケージの JSON をアップロードする](/images/partner_36576013651860.png)

   [任意] 該当する場合は、「CloudPages Domain」を選択して「Next」をクリックします。

   ![デプロイ時に任意の CloudPages Domain を選択する](/images/partner_36576006449428.png)

6. システムがセットアップを検証し、問題がないかを確認します。検証が完了したら、Deploy をクリックします。

   ![Package Manager で検証して Deploy をクリックする](/images/partner_36576006449556.png)

### データエクステンションと CloudPage を公開する

7. 「Homepage」に移動します。
8. 「Web Studio」をクリックし、「CloudPages」をクリックします。

   ![Web Studio > CloudPages に移動する](/images/partner_36576006449684.png)

9. 「CloudPages」をクリックすると、このページに移動します。「CloudPages」をクリックし、「MoEngage Data Tracking」サブフォルダーをクリックして、最後に「MoEngage Campaign Tracking CloudPage」をクリックします。
10. 「矢印」をクリックしてドロップダウンリストを開き、「Edit」をクリックします。

    ![MoEngage Campaign Tracking CloudPage を編集する](/images/partner_36576013658644.png)

11. 「Save」をクリックし、「Schedule/Publish」をクリックします。

    ![MoEngage Campaign Tracking CloudPage を保存して公開する](/images/partner_36576013658900.png)

12. 「CloudPages」ページに戻り、「MoEngage Credentials」サブフォルダーをクリックして、「User Authentication Page」をクリックします。
13. 「矢印」をクリックしてドロップダウンリストを開き、「Edit」をクリックします。

    ![User Authentication Page CloudPage を編集する](/images/partner_36576006451220.png)

14. 「Save」をクリックし、「Schedule/Publish」をクリックします。

    ![User Authentication Page を保存して公開する](/images/partner_36576013659540.png)

## データエクステンションと外部キーを確認する

以下のデータエクステンション（DE）が適切に命名・設定されていることを確認してください。

### A. MoEngage Tracking Data

キャンペーンのトラッキング情報を保存します。

1. 「Homepage」に移動します。
2. 「Audience Builder」をクリックし、「Contact Builder」をクリックします。

   ![Audience Builder > Contact Builder に移動する](/images/partner_36576006452372.png)

3. 「Data Extensions」タブを選択します。
4. 「Data Extensions」フォルダーをクリックし、「MoEngage Data Track」サブフォルダーをクリックします。
5. 「MoEngage Tracking data」エクステンションを選択します。

   ![MoEngage Tracking data データエクステンションの詳細](/images/partner_36576013660052.png)

   ここで「External Key」を確認できます。正確であることを確認してください。[任意] 外部キーを入力または変更する必要がある場合は、「External Key」入力フィールドをクリックし、外部キーを貼り付けるか入力して、「Done」をクリックします。

### B. MoEngage Credentials

Data Tracking CloudPage の認証情報を保存します。

1. 「Homepage」に移動します。
2. 「Audience Builder」をクリックし、「Contact Builder」をクリックします。

   ![Audience Builder > Contact Builder に移動する](/images/partner_36576013660564.png)

3. 「Data Extensions」タブを選択します。
4. 「Data Extensions」フォルダーをクリックし、「MoEngage Data Track」サブフォルダーをクリックします。
5. 「MoEngage Tracking Credential」を選択します。

   ![MoEngage Tracking Credential データエクステンションの詳細](/images/partner_36576013660820.png)

   ここで「External Key」を確認できます。正確であることを確認してください。[任意] 外部キーを入力または変更する必要がある場合は、「External Key」入力フィールドをクリックし、外部キーを貼り付けるか入力して、「Done」をクリックします。

### C. MoEngage Event Activity Log

Event カスタムアクティビティの情報を記録します。

1. 「Homepage」に移動します。
2. 「Audience Builder」をクリックし、「Contact Builder」をクリックします。

   ![Audience Builder > Contact Builder に移動する](/images/partner_36576006453524.png)

3. 「Data Extensions」タブを選択します。
4. 「Data Extensions」フォルダーをクリックし、「MoEngage Event DE」サブフォルダーをクリックします。
5. 「MoEngage Tracking Credential」を選択します。

   ![データエクステンションを含む MoEngage Event DE フォルダー](/images/partner_36576006453908.png)

6. 「MoEngage Event Activity Log」を選択します。

   ここで「External Key」を確認できます。正確であることを確認してください。[任意] 外部キーを入力または変更する必要がある場合は、「External Key」入力フィールドをクリックし、外部キーを貼り付けるか入力して、「Done」をクリックします。

   ![MoEngage Event Activity Log の External Key フィールド](/images/partner_43091841847828.png)

### D. MoEngage Push Activity Log

Push カスタムアクティビティの情報を記録します。

1. 「Homepage」に移動します。
2. 「Audience Builder」をクリックし、「Contact Builder」をクリックします。

   ![Audience Builder > Contact Builder に移動する](/images/partner_36576006453524.png)

3. 「Data Extensions」タブを選択します。
4. 「Data Extensions」フォルダーをクリックし、「MoEngage Push DE」サブフォルダーをクリックします。
5. 「MoEngage Push Activity Log」を選択します。

   ![データエクステンションを含む MoEngage Push DE フォルダー](/images/partner_36576006453908.png)

   ここで「External Key」を確認できます。正確であることを確認してください。[任意] 外部キーを入力または変更する必要がある場合は、「External Key」入力フィールドをクリックし、外部キーを貼り付けるか入力して、「Done」をクリックします。

   ![MoEngage Push Activity Log の External Key フィールド](/images/partner_43091889316756.png)

## データエクステンションを設定する

### A. データエクステンションを設定する

1. ソリューションパッケージの認証情報データエクステンションの外部キーを「MoEngage Credentials」に変更します。

   ![認証情報データエクステンションの外部キーを変更する](/images/partner_43091841852564.png)

2. ソリューションパッケージの「Sync Users to MoEngage」データエクステンションの外部キーを「Sync Users to MoEngage」に変更します。

   ![Sync Users to MoEngage データエクステンションの外部キーを変更する](/images/partner_43091889328020.png)

3. ソリューションパッケージの「User Sync Automation Logs」データエクステンションの外部キーを「User Sync Automation Logs」に変更します。

   ![User Sync Automation Logs データエクステンションの外部キーを変更する](/images/partner_43091841854484.png)

## MoEngage ワークスペースを接続する

### A. 認証情報の CloudPage にアクセスする

SFMC ダッシュボードで、次の手順を実行します。

1. 「Web Studio」>「CloudPages」>「MoEngage Credentials」サブフォルダーに移動します。最後に「MoEngage Authentication Page」をクリックします。Edit をクリックします。
2. 「Page URL」をクリックして認証ページを開きます。

   ![MoEngage Authentication Page の URL を開く](/images/partner_36576013661716.png)

3. MoEngage ワークスペースの詳細を入力し、Submit をクリックします。

| フィールド | 値 |
| --- | --- |
| Data center | MoEngage のデータセンターを選択します。詳細については、[MoEngage のデータセンター](https://www.moengage.com/docs/user-guide/data/key-concepts/data-centers-in-moengage)を参照してください。 |
| Workspace Name | ワークスペース名を入力します。MoEngage ダッシュボードのヘッダーに表示されています。以下のスクリーンショットを参照してください。 |
| Workspace ID | Settings > Accounts > APIs に移動します。 |
| Data API key | Settings > Accounts > APIs に移動します。 |
| Campaign (Push) API Key | Settings > Accounts > APIs に移動します。 |

![MoEngage ダッシュボードのヘッダーに表示されるワークスペース名](/images/partner_36576013662100.png)

![MoEngage の Settings で Workspace ID、Data API key、Campaign API key を確認する](/images/partner_36576006455316.png)

[任意] 完了後、新しく追加したワークスペースがデータエクステンションに存在するかどうかを確認することもできます。

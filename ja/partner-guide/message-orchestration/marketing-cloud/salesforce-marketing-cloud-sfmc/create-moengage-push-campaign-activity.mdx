## はじめに

このガイドでは、SFMC で MoEngage Push Campaign カスタムアクティビティを作成するための詳細な手順を説明します。

<Info>
  **前提条件**

  - Salesforce Marketing Cloud へのアクセス：SFMC へのアクセス権があることを確認してください。
</Info>

## 手順

### MoEngage Push を設定する

1. SFMC ジャーニーで、「MoEngage Push」アクティビティをドラッグ＆ドロップします。

   ![SFMC で MoEngage Push アクティビティをドラッグ＆ドロップする](/images/partner_36576366510356.png)

2. 「MoEngage Push」をクリックします。
3. 3 ステップのプロセスで、キャンペーンの関連詳細を入力します。各フィールドの詳細については、[MoEngage Push API ドキュメント](/ja/api/push/push-api)を参照してください。

**重要な注意事項**

| コンテキスト | 値 |
| --- | --- |
| Workspace Name | ワークスペース名を入力します。MoEngage ダッシュボードのヘッダーに表示されています。<br /><br /><img src="/images/partner_36576366510484.png" alt="MoEngage ダッシュボードのヘッダーに表示されるワークスペース名" /><br /><br /><em>ワークスペース名は、「MoEngage User Authentication Page」CloudPage で入力したものと同じである必要があります。ワークスペース名を確認するには、「MoEngage Credentials DE」という名前のデータエクステンションに移動し、「MoEngage Credentials」を開きます。</em> |
| キャンペーンコンテンツのパーソナライズ | Message フィールドのメッセージをパーソナライズするには、データエクステンション（DE）のフィールド名を mustache 構文で <code>&#123;&#123;Field Name&#125;&#125;</code> の形式で使用できます。<br /><br />フィールド名がターゲット DE と完全に一致していることを確認してください。フィールド名が正しい場合は、ターゲット DE の対応する値が入力されます。正しくない場合は、プレースホルダー <code>&#123;&#123;Field Name&#125;&#125;</code> がそのまま表示されます。 |

カスタムアクティビティのセットアップが完了したら、ジャーニーを続行できます。

### MoEngage でキャンペーンを表示する

All Campaigns ページに移動して、作成されたすべてのキャンペーンを表示できます。これらは MoEngage で API トリガーのプッシュキャンペーンとして作成されます。

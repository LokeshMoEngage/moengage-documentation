## はじめに

[Salesforce Marketing Cloud（SFMC）](https://www.salesforce.com/eu/products/marketing-cloud/platform/)は、カスタマージャーニーを管理し、メール、モバイル、ソーシャル、ウェブなどのさまざまなチャネルでパーソナライズされた体験を提供するために設計されたデジタルマーケティングプラットフォームです。自動化、分析、オーディエンスのセグメンテーションやコンテンツ作成のためのツールを通じて、マーケターが大規模に顧客とエンゲージできるよう支援します。

## MoEngage と SFMC

このインテグレーションは Salesforce Marketing Cloud（SFMC）と MoEngage を接続し、SFMC プラットフォーム内で MoEngage の機能を直接活用できるようにします。

- **SFMC Journey Builder：** SFMC Journey Builder 内から、MoEngage のコア機能であるプッシュキャンペーンとイベントを使用できます。
  - SFMC Journey Builder 内のカスタムアクティビティとしての MoEngage Push Campaign。SFMC ジャーニーから MoEngage のプッシュキャンペーンを直接トリガーできます。
  - SFMC Journey Builder 内のカスタムアクティビティとしての MoEngage Events。MoEngage の任意のイベントトリガーキャンペーン（プッシュ、SMS、メール、アプリ内メッセージ、WhatsApp など）をトリガーして、エンドユーザーにメッセージを送信できます。
- **双方向（MoEngage から SFMC）：** MoEngage が収集したキャンペーンインタラクションデータを、リアルタイムで SFMC に送り返すことができます。これは MoEngage Streams をベースに動作します。
- **ユーザー同期（SFMC から MoEngage）：** ハイパーパーソナライズされたメッセージングのために、SFMC データエクステンションをユーザー/属性として MoEngage に同期できます。

### ユースケース

- **クロスチャネルのオンボーディングジャーニー：** 新規顧客がサインアップすると（SFMC で取得）、SFMC Journey Builder でウェルカムメールから始まるオンボーディングジャーニーを開始します。1 日後、同じ SFMC ジャーニーから MoEngage のプッシュ通知を直接トリガーして、アプリのエンゲージメントを促したり、主要な機能を紹介したりします。
- **ターゲットを絞った再エンゲージメントプッシュ：** SFMC データエクステンション内で 90 日間購入していないユーザーを特定します。SFMC Journey Builder を使用してこれらのユーザーをジャーニーに登録し、カスタムジャーニーアクティビティを介して有効化された MoEngage のプッシュ機能を活用して、特別オファーを含むパーソナライズされた MoEngage プッシュ通知キャンペーンをトリガーします。
- **エンリッチされたアプリ内パーソナライゼーション：** SFMC データエクステンションに保存されている顧客のロイヤルティティアのステータスや最近の製品カテゴリーへの関心を、MoEngage のユーザープロファイルに同期します。この更新された属性データを MoEngage 内で使用して、アプリ内メッセージ/メールや後続のモバイルキャンペーンをパーソナライズし、より関連性の高いユーザー体験を提供します。
- **統合されたキャンペーンパフォーマンス分析：** SFMC からトリガーされた MoEngage プッシュキャンペーンを送信した後、MoEngage Streams を使用して、エンゲージメントデータ（MoEngage でトラッキングされたクリックやコンバージョンなど）を専用の SFMC データエクステンションにフィードバックします。このデータを SFMC 内で使用して、フォローアップメールキャンペーン用のセグメントを構築したり、クロスチャネルキャンペーン全体の効果を分析したりします。
- **イベントベースのマルチチャネルメッセージング：** SFMC 内の複雑なセグメンテーションやアクティビティトリガー（例：ユーザーが高額な製品を閲覧したが購入しなかった）に基づいて、SFMC Journey Builder の MoEngage Event カスタムアクティビティを使用し、MoEngage で特定のイベント（`High_Interest_No_Purchase` など）をトリガーします。このイベントにより、MoEngage のキャンペーンオーケストレーションで管理される複数のチャネル（例：プッシュ + メール + アプリ内メッセージ）を使用した連携キャンペーンを MoEngage 内で開始できます。

## インテグレーション

<Info>
  **前提条件**

  - SFMC アカウントとジャーニーアカウントがあり、管理者アクセス権とカスタムアクティビティをインストールするアクセス権があることを確認してください。
  - MoEngage API（Settings > Accounts > APIs）へのアクセス権があることを確認してください。
</Info>

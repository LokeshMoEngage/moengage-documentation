パートナーの皆様、ようこそ！

このガイドは、MoEngage App Marketplace でインテグレーションを構築、テスト、公開するためのロードマップです。以下の手順を最初から最後まで進めるか、現在のプロセスに該当するセクションに直接移動してください。

このジャーニーは 7 つのステージで構成されています：**探索 → サンドボックス → 構築 → テスト → 提出 → ドキュメント化 → ローンチ**。

構築を始める前に、MoEngage のパートナーエコシステムの仕組みと利用可能なツールについて、少し時間をかけて理解してください。

### 実現できることを探索する

MoEngage は幅広いインテグレーションパターンをサポートしています。以下のユースケースを理解することで、お使いのプラットフォームに適したアプローチを選択できます。

<AccordionGroup>
  <Accordion title="MoEngage にデータを送信する — ユーザープロファイル、イベント、セグメントを MoEngage に同期">
    - [**ユーザーデータを送信する**](/ja/partner-guide/integrate-with-us/explore-capabilities/send-user-data)：お使いのプラットフォームから MoEngage にユーザープロファイルと属性を同期します。

    CRM、CDP、e コマースプラットフォーム、フォームツール、およびユーザーデータを収集するあらゆるシステムに最適です。
  </Accordion>

  <Accordion title="MoEngage からデータを受信する — MoEngage からお使いのプラットフォームにデータをストリーミング">
    - [**データを受信する**](/ja/partner-guide/integrate-with-us/explore-capabilities/receive-data)：MoEngage からお使いのプラットフォームにユーザーデータとイベントデータをリアルタイムでストリーミングします。

    MoEngage のエンゲージメントデータを必要とする分析プラットフォーム、データウェアハウス、BI ツールに最適です。
  </Accordion>

  <Accordion title="キャンペーンをトリガー・実行する — アプリからキャンペーンを開始、または外部コンテンツを使用">
    - [**キャンペーンをトリガーする**](/ja/partner-guide/integrate-with-us/explore-capabilities/trigger-campaigns)：アプリケーション内のアクションに基づいて MoEngage でマーケティングキャンペーンを開始します。
    - [**外部クリエイティブを使用する**](/ja/partner-guide/integrate-with-us/explore-capabilities/use-external-creatives-in-campaigns)：マーケターが MoEngage キャンペーン内で、お使いのプラットフォームの画像、GIF、その他のクリエイティブを使用できるようにします。

    メッセージングプラットフォーム、広告ネットワーク、クリエイティブツール、マーケティングオートメーションシステムに最適です。
  </Accordion>

  <Accordion title="エンリッチとパーソナライズ — リアルタイムデータの取得や動的コンテンツの作成">
    - [**データを動的に取得する**](/ja/partner-guide/integrate-with-us/explore-capabilities/dynamically-fetch-data)：アプリケーションのリアルタイムデータで MoEngage キャンペーンをエンリッチします。
    - [**コンテンツクリエイティブを作成する**](/ja/partner-guide/integrate-with-us/explore-capabilities/create-content-creatives)：キャンペーンで使用する動的でパーソナライズされたコンテンツを作成できるようにします。

    レコメンデーションエンジン、コンテンツ管理システム、パーソナライゼーションプラットフォームに最適です。
  </Accordion>
</AccordionGroup>

サポートされているすべてのパターンの概要については、[インテグレーションのユースケース](/ja/partner-guide/integrate-with-us/explore-capabilities/integration-use-cases)を参照してください。

## ステップ 2：サンドボックスを取得する

構築を始めるには、MoEngage Sandbox Workspace が必要です。これは、本番稼働前にプラットフォームを探索し、インテグレーションを構築して、十分にテストできる専用環境です。

<Info>
  **サンドボックスをリクエストする**

  [アカウント設定ガイド](/ja/partner-guide/integrate-with-us/foundations/account-setup)に従ってアクセスをリクエストしてください。1～2 営業日以内にサンドボックスの認証情報が届きます。
</Info>

## ステップ 3：インテグレーションの方法を選択する

MoEngage では、インテグレーションを構築するための主な方法が 2 つあります。適切な選択は、ユースケース、技術要件、および必要な制御の程度によって異なります。

<CardGroup cols={2}>
  <Card title="Connected Apps — ローコードフレームワーク（推奨）" icon="zap">
    シンプルな設定ファイルでインテグレーションロジックを定義します。大掛かりなエンジニアリングは不要です。

    2 つのサブタイプがあります：
    - **Connected Sources**：Webhook を介して MoEngage にデータを送信します。
    - **Connected Channels**：MoEngage からお使いのアプリにデータを送信します。
  </Card>
  <Card title="MoEngage API — カスタムインテグレーション（上級者向け）" icon="wrench">
    REST API を使用してデータフローを完全に制御できます。必要なカスタムインテグレーションを自由に構築できます。

    以下に最適です：
    - 複雑または独自のユースケース
    - ロジックのきめ細かな制御
    - 専任の開発リソースを持つチーム
  </Card>
</CardGroup>

### 詳細な比較

| 基準 | Connected Apps | MoEngage API |
| --- | --- | --- |
| ユースケース | MoEngage へのユーザー/イベントの送信、または MoEngage からのキャンペーン実行とオーディエンス同期 | Connected Apps でカバーされない、非常に複雑または独自のフロー |
| エンジニアリング工数 | 低 — 設定主導で、カスタムバックエンドは不要 | 高 — カスタムコード、API 処理、エラー管理 |
| ローンチまでの期間 | 数日～数週間 | 数週間～数か月 |
| 柔軟性 | 設定オプションを備えた標準化されたフレームワーク | あらゆる側面をきめ細かく完全に制御 |

<Tip>
  **推奨事項：** サポートされているすべてのユースケースでは、まず **Connected Apps** から始めてください。より迅速かつシンプルで、インテグレーションパターンの大部分をカバーしています。ユースケースで本当に必要な場合にのみ、API による方法を選択してください。
</Tip>

### Connected Apps：Sources と Channels

Connected Apps を選択した場合、次の問題はデータがどの方向に流れるかです。

<CardGroup cols={2}>
  <Card title="Connected Sources" icon="arrow-up" href="/ja/partner-guide/integrate-with-us/build-integration/connected-sources">
    お使いのプラットフォームから MoEngage **へ**データを送信します。JSON マッパー設定を使用して、Webhook ベースのインテグレーションを構築します。

    一般的なユースケース：
    - CRM の連絡先とプロファイルの同期
    - フォーム送信とリード獲得のストリーミング
    - e コマースイベント（注文、カート）のトラッキング
    - 支払い/サブスクリプションイベントの送信
  </Card>
  <Card title="Connected Channels" icon="arrow-down" href="/ja/partner-guide/integrate-with-us/build-integration/connected-apps">
    MoEngage からお使いのプラットフォーム**へ**データを送信します。ダッシュボード内でアップロードする JSON 設定ファイルを使用して、チャネルコネクターを構築します。

    一般的なユースケース：
    - お使いのプラットフォーム経由でのメッセージ送信（SMS、チャット）
    - 広告プラットフォームへのオーディエンス同期
    - サポート/CRM ツールへのデータプッシュ
    - 外部システムでのアクションのトリガー
  </Card>
</CardGroup>

## ステップ 4：インテグレーションをテストする

堅牢で信頼性の高いインテグレーションは、パートナーシップを成功させる鍵です。徹底的なテストにより、共通のお客様にスムーズな体験を提供し、ソリューションへの信頼を築くことができます。すべてのテストは **MoEngage Sandbox Workspace** で実施してください。

<Info>
  完全なガイドはこちら：[インテグレーションをテストする](/ja/partner-guide/integrate-with-us/build-integration/test-your-integration)。
</Info>

## ステップ 5：公開のために提出する

インテグレーションが正しく動作するようになったら、レビューのために提出します。プロセスは、インテグレーションが設定される場所によって異なります。

<CardGroup cols={2}>
  <Card title="外部設定" icon="globe">
    セットアップは**お使いのプラットフォーム**で行われます。MoEngage は、セットアップ手順のドキュメントへのリンクとともに、お使いのアプリをマーケットプレイスに掲載します。

    例：お使いのプラットフォームに「Connect to MoEngage」ボタンがあり、認証フローを管理している場合。
  </Card>
  <Card title="内部設定" icon="house">
    セットアップは **MoEngage 内**で行われます（例：Connected Apps）。MoEngage は、レビュー後に設定済みのアプリをプラットフォームに公開します。

    提出の詳細については、[Connected Apps](/ja/partner-guide/integrate-with-us/build-integration/connected-apps) ガイドを参照してください。
  </Card>
</CardGroup>

<Warning>
  **提出時に含めるもの：** エンドツーエンドのテスト手順、検証のためのプラットフォームへのアクセス、およびデータフローとキャンペーンが想定どおりに動作していることの確認。
</Warning>

## ステップ 6：インテグレーションガイドを作成する

お客様がインテグレーションを理解し、セットアップし、問題をトラブルシューティングできるよう支援します。明確で構造化されたガイドは、サポートの負荷を軽減し、導入を促進します。

[MoEngage パートナーインテグレーションドキュメントガイド](/ja/partner-guide/integrate-with-us/documentation-guide/writing-guide/getting-started)に従って、インテグレーションの包括的なヘルプガイドを作成してください。

## ステップ 7：掲載とプロモーション

アプリ内マーケットプレイスに加えて、MoEngage は公開されている [MoEngage App Marketplace](https://www.moengage.com/app-marketplace) でパートナーを紹介しています。これは、より幅広いオーディエンスにソリューションを紹介する共同マーケティングおよびリード獲得の機会です。

### インテグレーションをプロモーションする

承認されると、MoEngage パートナーとして掲載され、収益につながるパートナーシップの機会が得られます。共通のお客様や見込み客に向けて、インテグレーションをプロモーションすることをお勧めします。

アイデアやリソースについては、[インテグレーションのプロモーション方法](/ja/partner-guide/integrate-with-us/publish-integration/promote-integration)を参照してください。

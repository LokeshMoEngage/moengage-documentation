title: "主要な概念"
---

MoEngage とのインテグレーションを始めるにあたり、以下の用語が役立ちます。

## 1. ユーザー

MoEngage の**ユーザー**は、個々の顧客を表します。各ユーザーには、属性（名前、メールアドレス、所在地など）とデバイス情報を格納する一意のプロファイルがあります。このプロファイルは、その顧客を理解し、エンゲージするための中心的な記録です。

詳細については、[ユーザーデータ](/ja/user-guide/data/user-data "null")ガイドで、MoEngage SDK を介して取得されるデータについて説明しています。これには、MoEngage への受信データとマッピングする可能性のある標準ユーザー属性のほか、[ユーザー ID 管理](/ja/user-guide/data/user-data/unified-identity-identity-resolution "null")や[ユーザーのマージ](/ja/user-guide/data/user-data/anonymous-to-registered-user-merge "null")などが含まれます。

## 2. イベント

**イベント**とは、ユーザーがアプリ内またはウェブサイト上で行うアクションです。例として、「Item added to Cart」、「Purchase made」、「article\_read」などがあります。イベントはユーザーの行動を理解するためにトラッキングされ、パーソナライズされたキャンペーンのトリガーに使用できます。

詳細については、[イベントデータ](/ja/user-guide/data/event-data "null")ガイドで、MoEngage で一般的にトラッキングされるさまざまな種類のイベント、[イベントの命名規則](/ja/user-guide/data/key-concepts/event-naming-conventions "null")に関するベストプラクティス、およびユーザーがトラッキングするイベント（カスタムイベント）について説明しています。

## 3. セグメント

セグメントとは、特定のプロパティまたは値によって定義されるユーザーのグループです。セグメントは、キャンペーンの送信や、ユーザーの特定の情報や行動特性の分析に使用できます。[MoEngage のセグメント](/ja/user-guide/segment/create-segments/rule-based-filter-segments)の詳細をご覧ください。

## 4. エンゲージメントチャネル

MoEngage では、キャンペーンでユーザーにリーチするためのさまざまなチャネルを提供しています。

1. **SMS：**[SMS の詳細はこちら](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/sms/getting-started-with-sms/introduction-to-sms)
2. **Email：** [メールキャンペーンの詳細はこちら](/ja/user-guide/campaigns-and-channels/email/create/create-an-email-campaign)
3. **Push：** [プッシュ通知の詳細はこちら](/ja/user-guide/campaigns-and-channels/mobile-push/notification-features-and-behavior/android-push-notification-channels)
4. **Flows：** [MoEngage Flows の詳細はこちら](/ja/user-guide/flows-cross-channel-messaging/getting-started/overview-flows/overview-flows)
5. **Connectors：** [コネクターの詳細はこちら](/ja/user-guide/campaigns-and-channels/connectors/create/create-a-connector-campaign)
6. **In-Apps：** [アプリ内メッセージの詳細はこちら](/ja/user-guide/campaigns-and-channels/in-app-message/create/create-in-app-campaign)
7. **On-Site：** [オンサイトメッセージの詳細はこちら](/ja/user-guide/campaigns-and-channels/on-site-message/create/create-osm-campaign)
8. **Connected Apps：** [Connected Apps の詳細はこちら](/ja/user-guide/campaigns-and-channels/connected-apps/create/create-a-connected-app-campaign)

## 5. Streams

MoEngage では、ユーザーアクションやキャンペーンインタラクションイベントなど、MoEngage に存在するイベントを、[MoEngage Streams](/ja/api/data/moengage-streams) を介してほぼリアルタイムで独自の API エンドポイントに転送できます。

## 6. データセンター

MoEngage は複数のデータセンターを運用しており、サインアップ時にいずれかのデータセンターに所属することになります。データセンターはダッシュボードの URL から確認できます。[詳細はこちら](/ja/user-guide/data/key-concepts/data-centers-in-moengage)

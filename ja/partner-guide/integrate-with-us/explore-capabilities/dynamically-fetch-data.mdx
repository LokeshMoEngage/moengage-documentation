# はじめに 

マーケターは、マーケティングのパーソナライゼーションを拡張して、顧客エンゲージメントとコンバージョンを高めたいと考えています。API 経由でアクセスできるコンテンツ (パーソナライズされたクーポンコード、商品カタログ、商品属性など) を MoEngage キャンペーンに挿入したいと考えています。 

# 対象範囲 

この機能は現在、メールキャンペーンとプッシュキャンペーンでのみサポートされています。 

# 連携

[MoEngage Content API](/ja/user-guide/campaigns-and-channels/getting-started/campaign-content/content-apis) を使用すると、パーソナライズされたデータを取得してキャンペーンに直接挿入できます。Content API を使用すると、Web サーバーから直接、または一般公開されている API からコンテンツを取得できます。連携を開始するには、[ヘルプドキュメント](/ja/user-guide/campaigns-and-channels/getting-started/campaign-content/content-apis)の手順に従ってください。

また、[Talon.one](/ja/partner-guide/commerce-and-loyalty/loyalty/talon-one) や [Rocketium](/ja/partner-guide/personalize-and-optimize/dynamic-content/rocketium) などの他のテクノロジーパートナーが、Content API を使用してそれぞれクーポンコードとクリエイティブを取得している方法も確認できます。

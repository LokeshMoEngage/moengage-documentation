# はじめに

マーケターは、ユーザーの情報 (ユーザープロファイル、デバイス、ユーザーのアクション) を MoEngage で追跡する必要があります。ユーザーデータは、ユーザーをより適切にセグメント化し、エンゲージするのに役立ちます。

当社の [Data API](/ja/api/data/data-overview) を使用すると、すべてのユーザーデータとアクティビティを MoEngage で追跡できます。

# 対象範囲

次の連携がサポートされています。

| 機能 | API の詳細 | 説明 |
| --- | --- | --- |
| Connected Source | [Connected Sources](/ja/partner-guide/integrate-with-us/build-integration/connected-sources) | あらゆる外部プラットフォームから MoEngage に直接リアルタイムでデータをストリーミングします。CRM、e コマースプラットフォーム、マーケティングツール、カスタムアプリケーションを連携できます。次のことができます。 <ul><li>新しいユーザーを作成する</li><li>新しいユーザープロパティを作成する</li><li>ユーザーの既存のユーザープロパティを更新する</li><li>イベントを送信する (ユーザーのアクションを追跡する)</li></ul> |
| ユーザー | [Track User](https://moengage.com/docs/api/user/track-user) | User API は、MoEngage でユーザーとユーザープロパティを追加または更新するのに役立ちます。次のことができます。 <ul><li>新しいユーザーを作成する</li><li>新しいユーザープロパティを作成する</li><li>ユーザーの既存のユーザープロパティを更新する</li></ul> |
| イベント | [Track Event](https://moengage.com/docs/api/event/track-event) | <ul><li>Event API は、ユーザーのアクションを追跡するのに役立ちます。</li></ul> |
| セグメント | [Cohort Audience Sync](https://moengage.com/docs/api/cohort-sync/sync-cohort-members) | Segment API は、次のことに役立ちます。 <ul><li>MoEngage ダッシュボードのユーザーを使用して MoEngage でカスタムセグメントを作成する</li><li>セグメントにユーザーを追加/セグメントからユーザーを削除する</li></ul> |
| インストールトラッキング | [Track User](https://moengage.com/docs/api/user/track-user) | <ul><li>Install Tracking API は、MoEngage でインストールアトリビューションデータ (キャンペーン名とパブリッシャー名) を追跡するのに役立ちます</li></ul> |

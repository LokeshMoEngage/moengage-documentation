# はじめに

マーケターは MoEngage を使用してユーザーとエンゲージします。ユーザーのインタラクションに基づいて収集されたすべてのデータは、さらに分析やリターゲティングの目的で使用されます。MoEngage では、キャンペーンレポート、定期的なイベントデータのダンプ、リアルタイムのデータイベントのストリームという形式で、このデータにアクセスする機能を提供しています。

これらを使用して、MoEngage アカウントから情報を受信したり、MoEngage を貴社の製品に組み込んだりできます。

# 連携

以下の詳細を参照してください。

| **機能** | **API の詳細 ** | **説明** |
| --- | --- | --- |
| Connected Apps | [概要](/ja/user-guide/campaigns-and-channels/connected-apps/getting-started-with-connected-apps/overview) | Connected Apps は、数回のクリックでさまざまなチャネルをシームレスに連携できる MoEngage のフレームワークです。 |
| Streams | [MoEngage Streams](/ja/api/data/moengage-streams) | [Streams](https://help.moengage.com/hc/en-us/articles/360045896572-MoEngage-Streams) を使用すると、ユーザーのアクションやキャンペーンのインタラクションイベントなど、MoEngage 内のイベントをほぼリアルタイムで独自の API エンドポイントに転送できます。 |
| MoEngage S3 から他のデータウェアハウスへのデータ転送 | [AWS Data Exports](/ja/user-guide/data/exports/events/data-warehouse/s3-exports) | MoEngage は、顧客のイベントデータを安全な S3 の場所にアップロードします。これを基に自動化を構築して、MoEngage S3 から他のデータウェアハウスにデータを転送できます。 |
| キャンペーンレポート | [Download Campaign Reports](/ja/api/campaign-reports/download-campaign-report) | Campaign Report API は、キャンペーンレポートのダウンロードに役立ちます。この API は、MoEngage で設定された[キャンペーンレポート](https://moengage.com/docs/user-guide/campaigns-and-channels/campaign-management-and-reports/create-ad-hoc-campaign-reports)を取得するためのエンドポイントを提供します。 |

<Info>
  Streams は、デフォルトではアカウントで有効になっていない場合があります。有効にするには、MoEngage サポートチームにお問い合わせください。
</Info>

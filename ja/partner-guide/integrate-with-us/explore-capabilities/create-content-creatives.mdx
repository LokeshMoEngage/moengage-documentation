# はじめに

マーケターは、MoEngage キャンペーン全体で使用したりリターゲティングに活用したりできる、インパクトのあるクリエイティブを作成する必要があります。クリエイティブは、パーソナライズされた[メールテンプレート](/ja/user-guide/campaigns-and-channels/email/create/customize-your-email-content)や[コンテンツブロック](/ja/user-guide/content/content-blocks/content-blocks) (ヘッダー、フッター、クーポンコードなど、キャンペーン間で再利用可能な要素) の形式で作成できます。

当社の [API](/ja/api/in-app-templates/in-app-templates-overview) を使用すると、MoEngage で直接コンテンツクリエイティブを作成できます。

# 対象範囲

次の連携がサポートされています。

| 機能 | API の詳細 | 説明 |
| --- | --- | --- |
| メールテンプレート | [Email Templates](/ja/api/email-templates-1/email-templates-1-overview) | Email Template API は、MoEngage でテンプレートを取得、作成、更新するのに役立ちます。 |
| コンテンツブロック | [Content Block](/ja/api/content-blocks/content-blocks-overview) | Content Block API は、MoEngage でコンテンツブロックを取得、作成、更新するのに役立ちます。 |

# ユースケース

### 1. コンテンツをローカライズする

たとえば、顧客が MoEngage でメールテンプレートを作成しており、受信したコンテンツの言語を自動的に検出して即座に別の言語に翻訳する機能を構築したいとします。

[Get API](/ja/api/email-templates-1/email-templates-1-overview) を使用して MoEngage からメールテンプレートを取得し、貴社プラットフォームでローカライズしてから、[Create](/ja/api/email-templates/create-email-template-v2) API または [Update](/ja/api/email-templates/update-email-template) API を使用して、ローカライズしたテンプレートを MoEngage に送り返すことができます。

このようにして、MoEngage API をローカライズされたコンテンツに活用できます。

### 2. クリエイティブを同期する

たとえば、顧客がエンドユーザー向けに優れたクリエイティブやコンテンツを作成できるテンプレートツールを提供しているとします。そして、顧客がこれらのインパクトのあるコンテンツを MoEngage キャンペーンを通じて送信したいと考えています。

[Create](/ja/api/email-templates/create-email-template-v2) API または [Update](/ja/api/email-templates/update-email-template) API を使用して、貴社プラットフォームから MoEngage にメールテンプレートを同期できます。これらのテンプレートは、[MoEngage キャンペーン](/ja/user-guide/campaigns-and-channels/email/create/create-an-email-campaign)内で直接使用できます。

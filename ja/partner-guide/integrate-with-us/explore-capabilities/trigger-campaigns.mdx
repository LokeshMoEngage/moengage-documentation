# はじめに

MoEngage では、外部ソースから新しいキャンペーンを作成したり、既存のキャンペーンをトリガーしたりできます。[MoEngage キャンペーン](/ja/user-guide/campaigns-and-channels)について詳しくお読みください。

# 対象範囲

次の 2 つのユースケースがサポートされています。

## 1. 新しいキャンペーンを作成する

Campaign API を使用して新しいキャンペーンを作成できます。現在、MoEngage では Push API キャンペーンの作成のみをサポートしています。

| チャネル | API の詳細 | 説明 |
| --- | --- | --- |
| プッシュ | [Send Push Notification](/ja/api/push/push-api) | Push API は、次のことに役立ちます。 <ol><li>通知を送信するためのキャンペーン (すべてのユーザーまたはユーザーのグループを対象) を作成する。</li><li>一意のユーザー属性を使用して単一のユーザーをターゲットにする。</li><li>ユーザーごとにペイロードをパーソナライズする。</li></ol> |

## 2. 新しいキャンペーンをトリガーする

マーケターは、外部ソースから MoEngage 上の既存のキャンペーンをトリガーできます。

**ステップ 1 -**

MoEngage でイベントトリガーキャンペーンを作成します。イベントトリガーキャンペーンは、特定のイベントが発生した場合にのみユーザーに対してトリガーされます。[イベントトリガーキャンペーン](/ja/user-guide/campaigns-and-channels/getting-started/triggers/event/create-an-event-triggered-campaign)について詳しくお読みください。

**ステップ 2 -**

外部ソースからトリガーを設定して、当社の [Event API](https://developers.moengage.com/hc/en-us/articles/4413174104852-Event-) を呼び出すことができます。イベントが追加されるとすぐに、キャンペーンがユーザーに送信されます。

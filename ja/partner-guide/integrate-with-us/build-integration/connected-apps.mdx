Connected Apps は、外部プラットフォームを MoEngage のカスタマーエンゲージメントエコシステムと連携させるための、MoEngage のローコードフレームワークです。このガイドでは、**MoEngage からお客様のプラットフォームへ**データを送信する連携である **Connected Channel** の構築手順を説明します。

<Info>
  **📌 別の方法をお探しですか?**

  ユースケースが MoEngage **へ**データを送信するもの (CRM の同期、イベントトラッキング、フォームの送信など) である場合は、代わりに **Connected Sources** が必要です。利用を開始するには、[お問い合わせください](mailto:partnerships@moengage.com)。
</Info>

## ステップ 2: MoEngage で App を作成する

![](/images/partner_46907610154772.png)

まず、App Marketplace で [App を作成](/ja/user-guide/campaigns-and-channels/connected-apps/getting-started-with-connected-apps/create-an-app)します。

1. MoEngage ダッシュボードで **App Marketplace** に移動します。
2. 右上隅にある **\+ Create app** ボタンをクリックします。
3. ダイアログボックスで次の操作を行います。

- 一意の **App name** を入力します。
- **App type** として **Channel** を選択します。
- **Create** をクリックします。

これで App が作成されました。次に、コネクターを追加してユースケースを定義します。

---

## ステップ 3: コネクターを作成する

連携がサポートする各ユースケースは、**Connector** として定義されます。1 つの App に複数のコネクターを持たせることができます。たとえば、メッセージングアプリには、SMS の送信、MMS の送信、グループへのメッセージ送信のための個別のコネクターを用意できます。

各 Connector には、独自の **JSON 設定ファイル**が必要です。これは、特定のユースケースにおいて MoEngage がお客様の App とどのようにやり取りするかを指示する設計図です。

---

## ステップ 4: 設定ファイルを作成してアップロードする

JSON 設定ファイルは、コネクターの中核です。MoEngage がお客様の API とどのようにやり取りするか、ユーザーからどのような入力が必要か、レスポンスをどのように処理するかを指示します。

### 1. ファイルを作成する

包括的なヘルプドキュメントでは、このファイルを作成するための詳細なステップバイステップガイドを、例やベストプラクティスとともに提供しています。

📘 [**完全なガイドを読む: Channel Connector 設定ファイルを作成する**](/ja/user-guide/campaigns-and-channels/connected-apps/getting-started-with-connected-apps/create-a-channel-connector-config-file)

### 2. ファイルをアップロードする

JSON 設定ファイルの準備ができたら、次の操作を行います。

1. MoEngage App Marketplace の App ページに戻ります。
2. **Configure** タブをクリックします。
3. **\+ Add configuration** をクリックします。
4. JSON ファイルをアップロードします。検証エラーがある場合は、システムから通知されます。
5. アップロードが成功したら、**Add** をクリックします。

これでコネクターが作成されました。追加の設定ファイルを作成してアップロードすることで、App にさらにコネクター (ユースケース) を追加できます。

---

## ステップ 5: 連携をテストする

スムーズなユーザーエクスペリエンスを実現するには、徹底的なテストが不可欠です。次の 3 つのサブステップに従って、連携をエンドツーエンドで検証します。

### 5.1: 接続を作成する

1. App ページで **Integrate** タブに移動します。
2. **\+ Add integration** をクリックします。
3. 接続に一意の **Connection name** (例: 「My Test Connection」) を付けます。
4. App Marketplace スコープで定義した入力変数に値を入力します。
5. **Connect** をクリックします。

### 5.2: テストキャンペーンを実行する

1. MoEngage で新しいキャンペーン (例: 1 回限りのプッシュキャンペーン) を作成します。
2. キャンペーンの作成プロセスで、新しい Connected Channel を選択します。
3. 前のステップで作成した **Connection** を選択します。
4. キャンペーン固有の入力変数に値を入力します。
5. テストセグメントに対してキャンペーンを開始します。

### 5.3: キャンペーンの統計情報を確認する

1. キャンペーンのパフォーマンスページを確認します。
2. 「Sent」と「Failed」の数値が、キャンペーン中に受け取った API レスポンスを反映していることを確認します。たとえば、テストで 10 件のメッセージを送信し、すべてが 200 OK レスポンスを受け取った場合は、「Sent」イベントが 10 件表示されるはずです。

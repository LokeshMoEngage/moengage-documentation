# 概要 🚀

_(連携の中核となる価値を説明してください。マーケターが MoEngage のセグメンテーションとキャンペーントリガーを使用して、貴社のチャネルにメッセージを送信したりオーディエンスを同期したりする方法を説明してください。概要レベルで、メリットを中心に記述してください。)_

MoEngage と **\[Partner Name\]** の連携により、貴社の強力なチャネルを MoEngage のカスタマーエンゲージメントエンジンに直接接続できます。これにより、マーケターは MoEngage の高度なセグメンテーション、パーソナライゼーション、分析を使用して、優れたオムニチャネルジャーニーを展開し、貴社プラットフォーム上のユーザーとつながることができます。

**\[Partner Name\]** をチャネルとして有効にすることで、ブランドは従来のマーケティングを超えて、注目を集めて行動を促すリッチでインタラクティブな体験を提供できます。

# ユースケース 🎯

_(この連携でユーザーが実現できる主な内容を 2～3 件挙げてください。具体的かつ行動指向で記述してください。)_

**メッセージングチャネルの場合:**

- **リッチなプロモーションオファーの送信** : 画像、動画、インタラクティブなボタンを含む視覚的に魅力的なプロモーションを配信し、コンバージョンを高めます。
- **タイムリーなトランザクション通知のトリガー** : ユーザーが最もよく利用するチャネルで、注文確認や配送状況の更新を即座に通知します。

**広告オーディエンスチャネルの場合:**

- **高度にターゲティングされた広告キャンペーンの構築** : MoEngage からカスタムセグメントを同期して、強力な類似オーディエンスを作成したり、貴社プラットフォーム上の高価値ユーザーをリターゲティングしたりします。
- **広告費を最適化するための除外リストの作成** : 特定のユーザーセグメント (最近の購入者など) を広告キャンペーンから除外して、効率と ROI を向上させます。

# 連携の設定 🛠️

_(ユーザー ID の取得からキャンペーンの開始まで、設定フロー全体をパートナーにガイドしてください。以下のステップは、Connected Channel 連携の一般的なパターンを反映しています。)_

## ステップ 1: \[Partner Name\] プラットフォームでの設定 (該当する場合)

_(このステップは、OAuth アプリの作成など、最初に貴社側での設定が必要な連携にとって重要です。)_

_(貴社プラットフォームのダッシュボード内で必要な設定について、明確なステップバイステップの手順を提供してください。可能な場合はスクリーンショットを含めてください。)_

**広告パートナーの例:**

1. Business Manager にログインし、新しい OAuth アプリを作成します。
2. アプリの設定で、お使いのデータセンターの MoEngage Redirect URI を追加します。
3. `Client ID` と `Client Secret` を生成してコピーします。

## ステップ 2: MoEngage で \[Partner Name\] コネクターを設定する

1. MoEngage ダッシュボードで、**App Marketplace** に移動します。
2. **\[Partner Name\]** を検索し、タイルをクリックします。
3. **Integrate** タブに移動し、**\+ Add connection** をクリックします。
4. 接続の詳細を入力します。

| フィールド | 必須 | 説明 |
| :-- | :-- | :-- |
| Connection name | はい | この接続を識別するためのわかりやすい名前。 |
| \[Auth Credential 1\] | はい | (「Bot Token」や「Client ID」などの正確な名前を記載してください)。認証情報を貼り付けるようにユーザーに指示します。 |
| \[Auth Credential 2\] | はい | (「Client Secret」などの正確な名前を記載してください)。 |

5. **Connect** をクリックして設定を保存します。

## **ステップ 3: MoEngage で \[Partner Name\] キャンペーンを作成する**

1. **Create Campaign** \> **Connected Apps** \> **\[Partner Name\]** に移動します。
2. 配信タイプを選択し、ターゲットオーディエンスを選択します。
3. \[**重要なターゲティングルール:** 連携で特定のユーザー ID を使用する場合は、`[your_partner_id]` が**存在する**ユーザーをターゲットにするフィルターを追加するようにユーザーに指示してください。\]
4. キャンペーン作成画面で、コネクターを設定します。

_(連携に合ったオプションを以下から選択してください。)_

### **オプション A: メッセージを送信する場合**

_(貴社チャネルで利用可能なコネクターと、キャンペーンフォームにおける各コネクターのフィールドを詳しく説明してください。)_

| フィールド | 説明 |
| :-- | :-- |
| **Connector** | 目的のアクション (例: `Add Users to Customer List` または `Remove Users from Customer List`) を選択します。 |
| **Connections** | 作成した **\[Partner Name\]** の接続を選択します。 |
| **Receiver ID** | ID が保存されている MoEngage のユーザー属性にマッピングします。例: `{{UserAttribute['[partner_name]_id']}}`。 |
| **Message Content** | _(テキスト、画像、動画、ボタンなど、サポートしているさまざまなメッセージタイプと、それぞれに必要なフィールドを詳しく説明してください。)_ |

### オプション B: オーディエンスを同期する場合

_(貴社チャネルで利用可能なコネクターと、キャンペーンフォームにおける各コネクターのフィールドを詳しく説明してください。)_

| フィールド | 説明 |
| :-- | :-- |
| **Connector** | 目的のアクション (例: **Add Users to Customer List** または **Remove Users from Customer List**) を選択します。 |
| **Connections** | 作成した **\[Partner Name\]** の接続を選択します。 |
| **Customer List ID** | ユーザーを同期する、貴社プラットフォーム上のオーディエンスリストの ID。 |
| **User Identifiers** | _(ユーザーを同期するためにマッピングする必要があるユーザー属性 (例: Email、Google Advertising ID) を詳しく説明してください。)_ |

5. **Test** 機能を使用してサンプルリクエストを送信し、設定を確認します。
6. 検証が完了したら、キャンペーンを公開します。

# トラブルシューティングとよくある質問❓

_(ユーザーが直面する可能性のある一般的な問題とその解決策を 2～3 件挙げてください)_。

_例:_

**問題の例: テストメッセージが失敗する、またはオーディエンスが更新されない。**

- **User ID の欠落:** メッセージングチャネルの場合、テストユーザーに `[partner_name]_id` 属性の値があることを確認してください。
- **Audience ID が正しくない:** 広告チャネルの場合、`Customer List ID` が正しく、広告アカウントに適切な権限があることを確認してください。
- **ユーザーの同意:** ユーザーが貴社のボット/ビジネスアカウントを登録しており、ブロックしていないことを確認してください。

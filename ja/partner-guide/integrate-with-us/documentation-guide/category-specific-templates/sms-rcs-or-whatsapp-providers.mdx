# 概要 🚀

_(連携の中核となる価値を説明してください。MoEngage を通じて貴社のサービスを使用することで、共通の顧客がメッセージングの目標をどのように達成できるかに焦点を当ててください。概要レベルで、メリットを中心に記述してください。)_

MoEngage と **\[Partner Name\]** の連携により、**\[Partner Name\]** をサービスプロバイダーとして使用して、高度にパーソナライズされたスケーラブルな \[SMS、RCS、WhatsApp\] メッセージをユーザーに配信できます。

MoEngage ダッシュボードで **\[Partner Name\]** アカウントを設定することで、MoEngage の強力なセグメンテーション、ユーザージャーニーのオーケストレーション、分析機能を活用し、当社の信頼性の高い配信インフラストラクチャを通じてメッセージを送信できます。これにより、マーケターは単一のプラットフォームからコミュニケーション戦略を管理できるシームレスなワークフローを利用できます。

# ユースケース 🎯

_(この連携でユーザーが実現できる主な内容を 2～3 件挙げてください。具体的かつ行動指向で記述してください。)_

- **リアルタイムのトランザクションアラートのトリガー** : OTP、注文確認、配送状況の更新など、時間的制約のあるメッセージを MoEngage Flows から直接送信します。
- **大規模なプロモーションキャンペーンの実施** : パーソナライズされたオファーやコンテンツを含むプロモーション用の \[SMS/RCS/WhatsApp\] 一斉配信を、MoEngage で作成したターゲットユーザーセグメントに配信します。
- **会話型ジャーニーの自動化** : MoEngage で追跡したユーザーの行動に基づいて、カート放棄のリマインダー、再エンゲージメントメッセージ、ウェルカムシーケンスをトリガーします。

# 連携の設定 🛠️

_(このセクションでは、MoEngage での送信者の設定と、貴社プラットフォームでの配信コールバックの設定という 2 つの主要な設定手順をユーザーに明確にガイドしてください。)_

## ステップ 1: MoEngage で \[Partner Name\] 送信者を設定する

- MoEngage UI の左側のナビゲーションメニューで、**Settings** -\> **Channel** -\> **\[チャネルを選択:` SMS`、`RCS`、または `WhatsApp`\]** -\> **Sender Configuration** に移動します。
- **\+ Add Sender** (または **\+Add Service Provider**) をクリックし、一覧から **\[Partner Name\]** を選択します。貴社のサービスが一覧にない場合は、**Custom** を選択します。
- 必要な送信者の詳細を入力します。

_(以下の表を使用して、MoEngage で必要な各フィールドを詳しく説明してください。「説明」列には、ユーザーが入力すべき内容と、最も重要な点として、ダッシュボードのどこでそれを確認できるかを正確に記載してください。スクリーンショットの掲載を強くお勧めします。)_

| フィールド | 説明 |
| --- | --- |
| **Sender Name** | MoEngage でこの送信者を識別するためのわかりやすい名前 (例: 「\[Partner Name\] Transactional」)。 |
| **API URL** | メッセージを送信するための具体的な API エンドポイント URL を指定します。 |
| **Authentication** | _認証方法を説明してください。正確なヘッダーキーと、値 (例: API Key、Auth Token) の確認場所に関する手順を記載してください。_<br />**例:**<br />**Header Key:**`Authorization`<br />**Value:**`Basic <YOUR_API_KEY` |
| **Sender ID / From Number** | ここにユーザーが入力すべき内容 (例: 貴社から購入したショートコード、ロングコード番号、または英数字の Sender ID) を説明してください。 |
| **(必要に応じてその他のカスタムフィールドを追加)** | (その用途と値の確認場所を説明してください。) |

**パートナーへの注記:** API Key や Account SID など、必要な各認証情報を顧客がどこで確認できるかを示す、貴社プラットフォームのスクリーンショットを含めてください。これはドキュメントの中で最も役立つ部分です。

## ステップ 2: 配信トラッキング (コールバック URL) を設定する

MoEngage でメッセージの配信ステータス (例: 送信済み、配信済み、失敗) を追跡するには、**\[Partner Name\]** ダッシュボードで Webhook/コールバック URL を設定する必要があります。

1. MoEngage で送信者を保存すると、一意の **Callback URL** が生成されます。この URL をコピーします。
2. **\[Partner Name\]** ダッシュボードにログインします。
3. _(貴社プラットフォームの設定で、ユーザーがこの Callback URL をどこに貼り付けるべきかを正確に示す、明確なステップバイステップの手順とスクリーンショットを提供してください。Webhook を特定のイベントタイプ用に設定する必要があるか、GET/POST のどちらのリクエストにすべきかを明記してください。)_

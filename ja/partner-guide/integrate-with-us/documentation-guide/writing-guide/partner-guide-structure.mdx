## トラブルシューティングとよくある質問❓

_(ユーザーが直面する可能性のある一般的な問題とその解決策を 2～3 件挙げてください)_。

_例:_

**問題: \[Partner name\] からのデータが MoEngage に表示されない**。

- **API 認証情報を確認する** : **\[Partner name\]** ダッシュボードに移動し、MoEngage の `APP ID` と `DATA API KEY` が正しく入力されていることを再確認してください。先頭や末尾にスペースがないことを確認してください。
- **初回同期の遅延を確認する** : 初期設定後、最初のユーザーデータとイベントが MoEngage に表示されるまでに最大 15～30 分かかることがあります。この時間が経過した後に、MoEngage ダッシュボードを再度確認してください。
- **データが送信されていることを確認する** : **\[Partner name\]** アカウントのイベント配信ログまたはアウトバウンドデータのセクションを確認し、データが MoEngage のエンドポイントに実際に送信されていることを確認してください。データが送信されていない場合、問題は **\[Partner name\]** の設定にあります。
- **User ID のマッピングを確認する** : 重複したプロファイルの作成を避けるため、**\[Partner name\]** で使用しているプライマリユーザー識別子 (`customer_id` や `email` など) が、MoEngage で `User ID` として設定されているものと一致していることを確認してください。

**よくある質問** :

- **\[Partner name\] から MoEngage へのデータ同期はどのくらいの頻度で行われますか?**\
  **回答** : データは 15 分ごとに同期されます **\[正しい同期頻度を記載してください。例: リアルタイム、15 分ごと、24 時間に 1 回\]**。_(これは各パートナーに確認する必要がある重要な詳細です。)_
- **この連携は過去のユーザーデータを同期しますか?**\
  **回答** : **\[正しい動作を記載してください\]** この連携では、有効化後に生成されたユーザーとイベントのデータのみを同期します。/ **\[Partner name\]** から 1 回限りの履歴データのエクスポートを実行し、別途 MoEngage にインポートできます。
- **MoEngage にはどのような具体的なデータポイント (属性とイベント) が送信されますか?**\
  **回答** : MoEngage に転送される属性とイベントの完全な一覧については、このガイドの **Data Flow and Mapping** セクションを参照してください。
- **問題が解決しない場合は誰に問い合わせればよいですか?**\
  **回答** : データ設定や **\[Partner name\]** からイベントがトリガーされない問題については、**\[Partner Support Email/Link\]** からサポートチームにお問い合わせください。MoEngage 内でのデータ処理やキャンペーン設定に関する問題については、カスタマーサクセスマネージャーにお問い合わせください。

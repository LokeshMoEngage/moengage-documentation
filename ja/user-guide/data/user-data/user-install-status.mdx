インストールステータスは、特定のユーザーに対してアプリケーションがインストールされているかどうかを示し、ユーザーレベルで基本的なインストール情報を提供します。

# インストールステータスの追跡

MoEngage は、複数の方法でインストールステータスを追跡します。

- SDK 統合を通じて [Install/Uninstall/Reinstall トラッキング](/ja/user-guide/getting-started/integration-validation/installuninstallreinstall-integration-validation) を設定する
- ユーザーのデバイスに送信されたサイレントプッシュメッセージに対して、Firebase Cloud Messaging (FCM) または Apple Push Notification Service (APNs) からアプリがインストールされているかどうかを示すシグナルが返されるのを観測する。なお、サイレントプッシュ通知は Apple デバイスではサポートされなくなりました。ダッシュボードの設定ページから [このトラッキングを有効化](/ja/user-guide/settings/analytics/uninstall-tracking) できます。
- リアルタイムのアンインストールトラッキングのために、MoEngage SDK で [Firebase 統合](https://www.moengage.com/docs/developer-guide/components-for-sdk/tracking/real-time-uninstall-tracking) を設定する

MoEngage がユーザーによるアプリのインストールを検出した場合、インストールステータスは true に設定され、それ以外の場合は false に設定されます。複数のデバイスを持つユーザーの場合、少なくとも 1 台のデバイスにインストールされていれば、インストールステータスは true になります。

# MoEngage ダッシュボードでのインストールステータスの確認

MoEngage ダッシュボードで特定のユーザーのインストールステータスを確認するには、以下の手順に従います。

1. MoEngage ダッシュボードにログインし、**Segments** \> **Create Segments** に移動します。
2. **Query results** で、目的のクエリを展開します。
3. クエリの **Sample users** で、インストールステータスを確認したいユーザーをクリックします。Create segment UI の検索バーを使用してユーザーを直接検索することもできます。

# インストールステータスが不正確になる要因

インストールステータスの追跡が不正確になる要因には、次のようなものがあります。

- **不正確なフィードバック情報** - サイレントプッシュメッセージは通常、APNS や FCM などの通知プロバイダーのフィードバックサービスによって追跡されます。これらのフィードバックサービスは通常、プッシュメッセージを配信できなかった場合 (プッシュバウンスとも呼ばれます) にアプリケーションへ通知し、これは顧客がアプリケーションをアンインストールしたことを示します。フィードバックはアプリがプッシュメッセージの配信を試みたときにのみ生成されるため、ユーザーがアンインストールした正確なタイミングを知ることはほぼ不可能です。
- **iOS 10 でのサイレントプッシュ通知の廃止** - iOS 10 でサイレントプッシュ通知が廃止されたことにより、ユーザーレベルでのアンインストールの追跡が困難になっています。以前は、配信失敗を示すフィードバックによって、ユーザーがアプリをアンインストールしたことを検出するためにサイレントプッシュ通知が使用されていました。しかし、その廃止により、アンインストールを正確に追跡することがますます難しくなっています。
- **アンインストール前のユーザーのログアウト** - ユーザーがアプリをアンインストールする前にログアウトすると、アンインストールの追跡が不正確になる可能性があります。これは、ユーザーがアプリをもう積極的に使用していなくても、アプリがデバイスにインストールされたままであるために発生します。アンインストールの追跡は通常、アプリがアンインストールされたためにメッセージを配信できないことをアプリに通知するプッシュ通知サービスからのフィードバックに依存しています。しかし、ユーザーがアンインストールせずにログアウトした場合、アプリは引き続きプッシュ通知を受信するため、実際のアンインストールとログアウトしたセッションを区別することが困難になります。
- **デバイスのアーカイブ** - デバイスがアーカイブされた場合、ユーザーのインストールステータスはアーカイブ後も最大 60 日間保持されるため、アンインストールの追跡が不正確になる可能性があります。デバイスがアーカイブされるということは、そのデバイスがもう積極的に使用されていないか、ユーザーのアカウントに接続されていないことを意味します。しかし、アンインストール追跡の仕組みがアーカイブ状態を認識せず、ユーザーのインストールステータスを TRUE のまま保持し続ける場合があります。その結果、ユーザーが実際にはアプリをアンインストールしているにもかかわらず、アクティブなインストールがあるとみなされ、アンインストールの追跡が不正確になります。

インストールステータスを分析し、ユーザーエンゲージメントやリテンションの指標を正確に解釈する際には、これらの制限を考慮することが重要です。

MoEngageは、デフォルトでいくつかのユーザー属性を生成します。これらは派生ユーザー属性と呼ばれます。これらは、セグメンテーションや分析でユーザーをセグメント化するためのフィルターとして使用できます。

<Info>
  ワークスペースで[Portfolio](/ja/user-guide/settings/account/portfolio/portfolio)が有効になっている場合、派生ユーザー属性の動作が変わります。詳細については、[Portfolio: Data Ingestion and Management](/ja/user-guide/data/key-concepts/portfolio-data-ingestion-and-management)を参照してください。
</Info>

派生イベントとイベント属性の一覧については、[こちら](/ja/user-guide/data/event-data/derived-events-and-attributes)を参照してください。

# ユーザー属性

カテゴリ別のユーザー属性の一覧：

<Info>
  以下の表の**Internal**列と**External**列は、各ユーザー属性の作成または更新に使用できる特定の方法または発生源を指しており、以下のように定義されます。

  - 内部：属性はMoEngage SDKを使用して作成または更新されるか、プラットフォーム内部のアクティビティから直接派生します。
  - 外部：属性は、以下を含む外部入力を使用して作成または更新できます。
    - MoEngage API（Track User APIなど）
    - ファイルインポート
    - パートナー統合
    - その他の互換性のある外部ソース
</Info>

### ライフタイムバリュー（LTV）の設定

LTVは、ブランドとの関係全体を通じて、1つの顧客アカウントから企業が得られると見込む総収益を表す重要な指標です。MoEngageでは、収益を生み出すイベントをマッピングすることで、ユーザープロファイル内でLTVを直接計算できます。

LTVを設定するには、以下の手順を実行します。

![Screenshot 2025-07-07 at 10.53.37 AM.png](/images/moengage_7e792e.png)

1. MoEngageダッシュボードにログインし、**Settings** \> **General Settings**に移動します。
2. **General settings**ページで、**Goal mapping**セクションに移動します。
3. **Goal mapping**セクションで、以下の値を選択します。
   - **Conversion goal**フィールドで、ユーザーによる収益を生み出すアクションを示す特定のイベントを選択します（例：Product Purchased、Order Placed、Subscription Renewed）。
   - **Revenue attribute**フィールドで、そのイベント内で取引の実際の金額を含むイベント属性を選択します（例：price、total\_amount、revenue）。
   - **Currency**フィールドで、金額の通貨を選択します（例：USD、EUR、INR）。これにより、LTVの正確な集計とレポートが保証されます。
4. **Save**をクリックします。保存後、MoEngageは各ユーザーについて、指定されたイベント属性の金額を自動的に集計します。この集計された合計は、各ユーザープロファイルにLTVユーザー属性として保存されます。

<Info>
  - 関連する収益データを取り込む前に、MoEngageでGoal Mappingを設定しておくことが不可欠です。設定していない場合、すでに取り込まれた過去のデータについてはLTVが計算されません。つまり、LTVのゴールマッピングを設定した後に取り込まれたデータ（過去日付のイベントを含む）のみが、LTV属性の更新に反映されます。
  - 現在、上記の方法で計算されたLTV属性は、APIやFile Importを使用して直接更新または上書きすることはできません。
  - 標準のGoal Mapping機能では実現できない、より複雑またはカスタムなLTV計算が必要な場合は、代わりにカスタムユーザー属性を追跡することをお勧めします。
</Info>

<Info>
  IPアドレスを通じて取得される、最後に確認された市区町村、国、郵便番号、州/都道府県からなる位置情報は、各ユーザーセッション中に30分間隔で更新されます。ユーザーが移動中の場合、位置情報が異なる場合があることに注意してください。IPアドレスに基づく位置情報の精度は70～80%の範囲です。

  正確で永続的な位置情報が必要な場合は、カスタム属性を作成し、MoEngageのデータAPI、SDK、ファイルインポート、またはその他のデータソースを使用して、位置情報をご自身で追跡/更新することをお勧めします。
</Info>

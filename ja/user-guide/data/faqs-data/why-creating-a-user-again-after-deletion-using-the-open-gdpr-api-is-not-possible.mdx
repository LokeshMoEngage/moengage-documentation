## 問題

Open General Data Protection Regulation（GDPR）API を使用してユーザーを削除した後、MoEngage ダッシュボードで同じユーザーをすぐに再作成することができません。

## 説明

Open GDPR API を使用してユーザーを削除すると、そのユーザーのキャッシュデータが 24 時間システムに残ります。ユーザーを再作成できるのは、この 24 時間が経過した後のみです。

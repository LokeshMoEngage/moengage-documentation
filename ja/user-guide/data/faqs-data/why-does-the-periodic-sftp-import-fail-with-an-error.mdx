## 問題

定期的な Secure File Transfer Protocol（SFTP）インポートが失敗し、次のエラーが発生します。

file not found at the location.

<img alt="インポートエラー.png" src="/images/moengage_480553.png" />

## 解決策

次の手順を実行します。

1. **エラーメッセージを確認します:**
   - インポートページに移動し、エラーの詳細を確認します。
   - ステータスにカーソルを合わせると、エラーメッセージが表示されます。
2. **初回インポートの場合はファイルの場所を確認します:**
   - 指定した SFTP の場所にファイルが存在することを確認します。
   - 初回のインポート試行中にこのエラーが発生した場合は、ファイルが正しいフォルダーに配置されていることを確認してください。
3. **定期インポートでの重複処理を確認します:**
   - 定期インポートでは、ファイルが別のインポートの一部としてすでに処理されている場合に、このエラーが発生することがあります。
4. **ファイル管理のベストプラクティス:**
   - 各ファイルが 1 つのインポートでのみ処理されるようにしてください。
   - 同じファイルを複数のインポートで使用する必要がある場合は、一意のファイル名を割り当てるか、ファイルを別々のフォルダーパスに保存してください。

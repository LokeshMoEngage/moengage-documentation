description: "MoEngage で使用できる Unique ID の値と制限されている値を確認します。SDK 実装時の問題を避けるため、ユーザー識別子を正しく設定します。"
---

この記事では、MoEngage でユーザーの一意の識別子（UniqueID）を設定する際に考慮すべき要点について説明します。

## 手順

1. UniqueID フィールドでは、次の値は使用できません。
   <CodeGroup>
   ```text Values
   "unknown"
   "guest"
   "null"
   "0"
   "1"
   "true"
   "false"
   "user_attribute_unique_id"
   "(empty)"
   “na"
   "n/a"
   ""
   "dummy_seller_code"
   "user_id"
   "id"
   "customer_id"
   "uid"
   "userid"
   "none"
   "-2"
   "-1"
   "2"
   ```
   </CodeGroup>

2. 実装中に問題が発生した場合は、MoEngage のカスタマーサクセスマネージャー（CSM）またはサポートチームにお問い合わせください。

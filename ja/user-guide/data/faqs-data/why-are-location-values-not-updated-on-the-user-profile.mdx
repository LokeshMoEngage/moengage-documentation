---

## 問題

Server-to-Server API（S2S API）または Amazon Simple Storage Service（S3）インポートを通じて渡された **City**、**State**、**Country** などの位置情報が、MoEngage ダッシュボードのユーザープロファイルで更新されません。 
<img alt="s3 インポート.png" src="/images/moengage_88018b.png" />

## 説明

1. **内部属性:**
   - 位置情報属性（city、state、country）は、App/Site opened イベントによってトリガーされる SDK 呼び出し時に、ユーザーの IP アドレスから取得される内部属性です。
   - これらの属性は、潜在的な競合や不整合を避けるために SDK によって管理されます。
2. **更新の制限:**
   - これらの属性は、次の方法では更新できません。
     - ファイルインポート（S3）
     - S2S API 呼び出し（v1/customer および v1/transition）
   - これらの方法で更新を試みても SDK による更新で上書きされる可能性があり、大規模なユーザーベースではデバッグが困難になります。
3. **ユーザー作成時の動作:**
   - これらの属性はユーザー作成時にはサポートされますが、その後は SDK 以外のソースから変更することはできません。
   - 値は SDK 呼び出しが発生した後にのみ更新できます。
4. **SDK 連携の代替手段:**
   - SDK 連携を予定していない場合は、カスタムユーザー属性を使用して位置情報を保存および管理してください。
   - これにより、SDK によってトラッキングされる内部属性との競合を回避できます。

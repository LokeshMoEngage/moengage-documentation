---
title: "MoEngage でユーザーの削除を確認するには？"
description: "Delete User API を呼び出した後、ユーザープロファイルが MoEngage から正常に削除されたことを確認します。セグメンテーション検索と API のステータスレスポンスを確認します。"
---

この記事では、**Delete User API** を使用して、ユーザーが MoEngage システムから正常に削除されたかどうかを確認する方法について説明します。削除処理には最大 24 時間かかるため、確認手順に進む前に必要な待機時間が経過していることを確認してください。

## 手順

1. **24 時間待つ**:
   - Delete User API リクエストを送信してから少なくとも 24 時間が経過していることを確認します。削除処理が完了するまでにこの時間が必要です。
2. **セグメンテーション検索ダッシュボードを確認する**:
   - 削除したユーザーの **Unique ID** または **User ID** を取得します。
   - MoEngage ダッシュボードで **Segment** \> **Create segment** に移動します。
   - 右上の検索バーを使用してユーザーを検索します。
   - **Unique ID** または **User ID** を使用して検索を実行します。
     - 検索結果にユーザーの詳細が表示される場合、削除は完了していません。
     - 検索結果が空の場合、ユーザーは正常に削除されています。
3. **Get User API を使用する**:
   - MoEngage の [Get User](https://www.moengage.com/docs/api/user/get-user) API ドキュメントに記載されているとおりに、**Get User API** を使用して API 呼び出しを行います。
   - API レスポンスで:
     - **users\_not\_found** フィールドを探します。
       - このフィールドが存在し、ユーザーの詳細が含まれている場合は、ユーザーが削除されたことが確認できます
       - 存在しない場合は、users フィールドでユーザーの情報を確認します。

<Info>
  すべての確認方法は、Delete User API リクエストを送信してから 24 時間が経過した後にのみ実行してください。
</Info>

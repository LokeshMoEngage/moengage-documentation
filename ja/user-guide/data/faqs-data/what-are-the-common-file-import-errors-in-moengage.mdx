---
title: "MoEngage でよくあるファイルインポートエラーとは？"
description: "MoEngage でよくあるファイルインポートエラーを特定して解決します。行数の不一致、S3 および SFTP のアップロード失敗、データ検証の問題を修正します。"
---

MoEngage の **Data Imports** または **User Imports** 機能を使用してファイルをインポートする際に、エラーが発生する場合があります。この記事では、よくあるエラーとその解決方法について説明します。

**ファイルエラー**:

| エラーメッセージ | 対処法 |
| --- | --- |
| - Error in uploading file | ファイルエンコーディングが UTF-8 であり、すべての文字が UTF-8 でデコード可能であることを確認します。また、非 ASCII 文字をすべて削除します。 |
| - Field larger than field limit | 各セルのデータが 128 KB（131,072 文字）未満であることを確認します。 |
| - The column value for the selected identifier attribute (ID), which in this case is \{column\_name}, is absent. For instance, refer to row \{row\_number} - Event datetime missing. Please check your file. - The column value for the selected identifier attribute (ID), which in this case is \{column\_name}, is absent. For instance, refer to row \{row\_number}; Column value found larger than the max size-limit. Please check opening and closing quotes in Row number: \{row\_number} | 必須の属性（例: ID 値、イベント時刻の値）がすべて存在することを確認します。 |
| - Column value found larger than the max size-limit. Please check opening and closing quotes in Row number: \{row\_number} | CSV フィールドの値が許容上限を超えていないことを確認します。 |
| - Number of rows in the file exceed the hourly limit, please get in touch with support to understand the allowed rate limits | 許容上限を超えているため、サポートに連絡してレート制限を確認します。 |
| - No data found in the file. - Only Headers are present in the file, no other data found. - The file only contains empty rows, no other data found. | CSV ファイルが不完全または空でないことを確認します。 |
| - A \{user/aux} import with the same import name has already been used in a previous import. Please use a new unique import name. | インポート名またはファイル名が一意であることを確認します。 |

アップロードしたファイルの総行数と処理された行数に不一致がある場合があります。これは、インポート時に **Do not create new users** を選択した場合に発生します。新しいユーザーが作成されるようにするには、このオプションを選択しないでください。

MoEngage では、S3 または SFTP バケットに保存されたファイルを使用してユーザーとイベントをインポートできます。**Data Imports** 機能を使用して S3 または SFTP 経由でファイルをアップロードする際に、次のエラーが発生する場合があります。

**認証情報/接続の問題:**

| エラーメッセージ | 対処法 |
| --- | --- |
| - SFTP folder path not valid / connection issue / credentials failing / server down | SFTP サーバーの設定を確認します。 |
| - S3 server down, connection timeout, endpoint error connection | S3 の接続設定を確認します。 |

**Data Imports** 機能を使用する際に、次の暗号化および復号のエラーが発生する場合があります。

**暗号化/復号のエラー:**

| エラーメッセージ | 対処法 |
| --- | --- |
| - Decryption key is missing, please connect with Support team - Decryption key is wrong; please crosscheck the private key | MoEngage ダッシュボードに正しい復号キーが入力されていることを確認します。 |
| - Signing key verification failed - Signing key missing, please enter the signing key - Signing key verification failed, please recheck the signing key | 正しい署名キーを入力します。 |
| - Unable to decrypt the file; please crosscheck the public encryption key | 正しい公開暗号化キーを確認して使用します。 |
| - File is not in encrypted format, please encrypt and retry | ファイルが正しい暗号化キーで暗号化されていることを確認します。 |
| - File is in encrypted format, please setup PGP encryption in MoEngage to decrypt the file | ファイルが暗号化されている場合は、MoEngage ダッシュボードで暗号化設定を構成します。インポートを編集して復号を設定します。 |

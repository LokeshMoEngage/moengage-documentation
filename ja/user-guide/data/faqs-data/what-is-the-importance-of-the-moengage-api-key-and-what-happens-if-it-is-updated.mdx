## 問題

MoEngage 上の Android および iOS プラットフォームのアプリについて、**MoEngage API キー**を更新することの重要性と潜在的な影響を把握しておく必要があります。MoEngage API キーは、スクリーンショットに示すように、ダッシュボードの **Settings** \> **APIs** セクションで確認できます。 

<img alt="API key.png" src="/images/moengage_71d567.png" />

## 解決策

MoEngage API キーを正常に更新し、潜在的な影響に対処するには、次の手順に従います。

1. **即時の変更**: API キーはいつでも再生成して保存できます。
   - API キーを再生成するには、MoEngage ダッシュボードで **Settings** \> **API** に移動します。
2. **古い API キーと新しい API キーのサポート**:
   - 新しい API キーが再生成されると、古いキーは直ちに無効になります。
   - MoEngage では、古い API キーと新しい API キーの同時使用はサポートされていません。
3. **実装の更新**:
   - すべての実装箇所で、古い API キーを新しいキーに置き換える必要があります。
   - このプロセス中、Workspace ID（旧 app id）は変わりません。
4. **データ損失のリスク**:
   - 必要なすべての箇所で新しい API キーに更新しないと、データが失われる可能性があります。中断を避けるため、適切に実装してください。

<Info>
これらの手順は、現在の MoEngage ダッシュボードに適用されます。新しいダッシュボードが間もなく利用可能になります。詳細については、[API Key Dashboard](/ja/user-guide/settings/account/api-and-api-keys/api-key-dashboard) を参照してください。
</Info>

---

## 問題

アンインストールイベントのみを含む匿名ユーザープロファイルが作成されます。このプロファイルには実際のユーザー情報が含まれておらず、登録済みプロファイルにもマッピングされていません。

<img alt="匿名ユーザー.png" src="/images/moengage_b5c3c4.png" />

## 解決策

次の手順を実行します。

- **Activity info** でアンインストールイベントを展開し、キャンペーンの詳細を確認します。
- このイベントに関連付けられている **Campaign ID** を特定します。  
<img alt="キャンペーン id.png" src="/images/moengage_d2c7ce.png" />
- ダッシュボードで **Campaign ID** を検索します。
- キャンペーンが **All Users** を対象にスケジュールされていた場合、キャンペーンが配信される前にユーザーがアプリケーションをアンインストールしていたことを示します。

MoEngage はこのユーザーについて適切なアンインストールコールバックを受信しなかったため、このアンインストールイベントをトラッキングするためにゲストプロファイルが作成されました。このプロセスにより、登録済みユーザープロファイルにマッピングされていなくても、アンインストールイベントが確実に記録されます。

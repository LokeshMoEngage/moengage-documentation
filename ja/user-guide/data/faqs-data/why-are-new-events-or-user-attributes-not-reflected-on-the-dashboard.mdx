## 問題

S2S API 呼び出しまたは SDK リクエストを通じて送信された新しいイベントまたはユーザー属性が、ダッシュボードに表示されません。

## 解決策

次の手順を実行します。

1. Data Management の設定（**Settings** \> **Data Management**）を確認します。イベントまたはユーザー属性が設定でブロックまたは非表示になっていないことを確認してください。Data Management へのアクセス権がない場合は、管理者またはマネージャーにお問い合わせください。
2. イベント/ユーザー属性の上限を確認します。Data Management の設定で、イベントまたはユーザー属性の上限を超えていないことを確認してください。

<Info>
イベントまたはユーザー属性の上限を超えている場合は、使用されていないイベントまたはユーザー属性をブロックして新しい属性の取り込み用の枠を確保するか、上限の引き上げについて CSM にお問い合わせください。
</Info>

詳細については、[概要 - Data Management](/ja/user-guide/settings/data-management/overview-data-management)をお読みください。

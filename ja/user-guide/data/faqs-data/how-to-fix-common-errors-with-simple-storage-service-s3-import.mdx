---
title: "Simple Storage Service（S3）インポートでよくあるエラーを修正するには？"
description: "MoEngage での S3 インポートでよくあるエラー（ファイルが見つからない、504 タイムアウト、ファイルサイズの上限など）をトラブルシューティングします。ファイルを整理して問題を解決します。"
---

## 問題

実装上の問題により、MoEngage がファイルを処理できません。

<Info>
ユーザーインポートでは各ファイルが 1 GB 未満、イベントまたは補助データのインポートでは各ファイルが 500 MB 未満でない限り、インポートは失敗します。
</Info>

<img alt="インポート失敗.png" src="/images/moengage_07946e.png" />

## 手順

以下の手順を実行します。

1. **よくある問題を確認する:** インポートが失敗した場合は、ステータスの詳細を確認します。ステータスにカーソルを合わせると、「file not found」エラーが表示される場合があります。
2. **ファイルサイズ:** 各ファイルが、ユーザーインポートの場合は 1 GB 未満、イベントまたは補助データのインポートの場合は 500 MB 未満であることを確認します。PGP で暗号化されたファイルの場合、MoEngage はまずファイルを復号してからサイズを確認するため、暗号化された状態で上限を下回っているファイルでも失敗することがあります。
3. **504 エラーへの対処:**
   - 504 エラーは、1 つの S3 バケットに大量のファイルがあることが原因で発生することがよくあります。1 つのフォルダーに 1000 を超えるファイルがあると、タイムアウトが発生する可能性があります。
   - これを解決するには、フォルダーをファイル数の少ない複数のフォルダー（各フォルダー \<=100）に分割します。バックエンドの S3 インポートのファイル取得 API には、現在 5 分のタイムアウトが設定されています。

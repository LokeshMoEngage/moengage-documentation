title: "コネクターキャンペーンで Delete API を使用して複数のユーザープロファイルを削除するには？"
description: "開発者の支援なしで MoEngage の複数のユーザープロファイルを削除します。カスタムユーザーセグメントを使用したコネクターキャンペーンで Delete API を利用し、一括削除します。"
---

コネクターキャンペーンで Delete API を使用すると、開発チームや IT チームの支援なしで複数のユーザープロファイルを削除できます。

## 手順

以下の手順を実行します。

1. **カスタムセグメントを作成する:**
   - MoEngage から削除するすべてのユーザーを特定し、それらのユーザーのカスタムセグメントを作成します。
2. **コネクターキャンペーンを設定する:**
   - **One-Time Custom Connector campaign** を作成します。
   ![custom connector.png](/images/moengage_bb31ce.png)
   - 作成したカスタムセグメントを、このキャンペーンのオーディエンスとして選択します
   ![user audience.png](/images/moengage_2869f1.png)
3. **API リクエストを設定する:**
   - ステップ 2 の **Content** ページで、適切なヘッダーとキーと値のペアを使用して、POST 呼び出しに API 情報を追加します。
   ![content api.png](/images/moengage_7f0908.png)
   - 次のキーと値を使用します。
     - Key: identity\_type ; Value: customer\_id
     - Key: identity\_value; Value: @ を使用して、このキーの ID を動的にパーソナライズします。
     - [Delete API のサンプル cURL リクエスト](https://www.moengage.com/docs/api/user/delete-users)を参照してください。
     ![key value.png](/images/moengage_bff7dc.png)
4. **配信制御を設定する:**
   - リクエストの失敗を防ぐため、配信制御のリクエスト上限を 1 分あたり 4,000 リクエストに設定します。
5. **キャンペーンを公開する:**
   - キャンペーンを公開して、指定したカスタムセグメント内のすべてのユーザーを削除します。

<Info>
  - この方法は、匿名ユーザープロファイルの削除には適用されません。
  - ユーザープロファイルの削除をリクエストするには、MoEngage のカスタマーサクセスマネージャー（CSM）またはサポートチームにお問い合わせください。
</Info>

## 問題

Data アプリケーションプログラミングインターフェイス（API）では、IP ではなくドメインをホワイトリストに登録することが推奨されています。

<Info>
タイムアウトエラーやネットワークエラーなどのエラーが原因で、特定の User API および Event API リクエストに対してネットワークアドレス変換（NAT）IP フォワーディングを有効にする必要が生じる場合があります。
</Info>

## 説明

- MoEngage はマルチテナントシステムを使用しているため、スケールとセキュリティをサポートするために IP が頻繁に変更されます。
- ドメイン `api-xx.moengage.com` は固定であるため、ドメインホワイトリストの方が IP ホワイトリストよりも信頼性が高くなります。
- MoEngage API は認証を使用してリクエストを検証し、セキュリティを確保しています。
- 固定 IP が必要な場合は、MoEngage 側でのカスタム実装が必要になりますが、通常これは避けられます。
- IP をキャッシュしないでください。MoEngage からのレスポンスでエラーが発生した場合でも、ドメインホワイトリストで十分です。

## 問題

ファイルのインポート時に "empty rows" エラーが発生します。

## 説明

"empty rows" エラーは通常、ファイルに空白行が含まれている場合に発生します。これらの行は、特に Microsoft Excel などのツールを使用している場合に、ファイルの作成時や保存時に意図せず追加されることがよくあります。

## 解決策

次の手順を実行します。

1. Notepad や Google Sheets などのテキストエディターでファイルを開きます。
2. ファイルの末尾までスクロールし、下矢印キーを押します。カーソルが下に移動する場合は、ファイルに空の行が含まれています。
3. 空の行を削除します。
4. テキストエディターから直接、ファイルを CSV ファイルとして保存します。
5. 更新したファイルを再インポートします。

<Info>
Notepad や Google Sheets などのテキストエディターを使用すると、ファイルに空の行が含まれるのを防ぐことができます。
</Info>

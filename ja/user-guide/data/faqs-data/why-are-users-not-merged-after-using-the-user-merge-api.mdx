## 問題

User Merge API を使用しても、ユーザーがマージされません。

## 説明

この問題は、_ID_ ではなく _MoEngage ID_ を渡したことが原因で発生します。

なお、Identity Resolution 機能が有効になっているワークスペースでは、Merge User API は機能しません。

## 解決策

次の手順を実行します。

1. _ペイロードを更新します_。マージする ID と保持する ID で、次のペイロードを更新します。
   <CodeGroup>
   ```json Code
   {
   “merge_data”: [
   {
   “merged_user”: “user_id_that_you_want_to_merge“,
   “retained_user”: “user_id_that_you_want_to_retain”
   }
   ]
   }
   ```
   </CodeGroup>

2. _正しい識別子を使用します。_ UID はユーザーの一意の識別子であり、MoEngage はこれを[ユーザープロファイルの ID 属性](/ja/user-guide/data/user-data/user-profile)に保存します。ユーザーのマージには、ユーザープロファイルの UID/ID 属性のみを使用してください。

![ユーザープロファイル id.png](/images/moengage_896d2c.png)

<Info>
  MoEngage では、作成元に関係なく、登録済みユーザーのみを別の登録済みユーザーとマージできます。
</Info>

## 問題

ユーザーインポートのステータスが **Processing** 状態のままになっていますが、実際には処理が行われていません。

## 解決策

次の手順を実行します。

1. **インポートの詳細を確認します:**
   - MoEngage ダッシュボードにログインし、インポートステータスの詳細を確認します。
   - インポートは多くの場合、**Processing** または **Pending** と表示されます。
2. **レート制限と複数のアップロード:**
   - この問題は、同じ 1 時間以内に複数のファイルがアップロードされた場合に発生することがあります。
   - ファイルは、1 時間あたりおよび 1 日あたりの利用可能なレート制限に基づいて処理されます。これらの制限はインポートページで確認できます（レート制限がアップグレードされている場合は、アカウントマネージャーまたはカスタマーサクセスマネージャーに連絡してレート制限を確認してください）。  
   <img alt="processed.png" src="/images/moengage_8e19b7.png" />
3. **Pending 状態:**
   - ファイルが **Processing** 状態のままになっている場合、実際には **Pending** 状態である可能性があります。
   - レート制限がリフレッシュされて処理が再開されると、ファイルのステータスが更新されます。 
   <img alt="pending.png" src="/images/moengage_5b6468.png" />
4. **後で再確認します:**
   - 後でインポートページを再度確認し、インポートが完了したことを確認できます。

この記事では、提供されているスクリプトを使用して Data API の Auth Token を生成する方法について説明します。

## 手順

1. **必要な入力**:
   - **Workspace ID（旧 app id）**
   - **API キー**
   Workspace ID と API キーを確認するには、MoEngage ダッシュボードで **Settings** \> **APIs** に移動します。キーの作成と管理については、[API Key Dashboard](/ja/user-guide/settings/account/api-and-api-keys/api-key-dashboard) を参照してください。
   
   ![Auth token.png](/images/moengage_bedf6e.png)
2. **Auth Token を生成する**:
   次のスクリプトを使用して、指定したアプリの Auth Token を生成します。
   <CodeGroup>
   ```python Python wrap
   import base64
   import subprocess
   app_id = str(input("Enter the APP ID or Worskspace ID: ")).strip()
   app_key = str(input("Enter the secret key: ")).strip()
   secret_string = app_id + ":" + app_key
   secret_string_bytes = secret_string.encode("ascii")
   base64_bytes = base64.b64encode(secret_string_bytes)
   base64_string = base64_bytes.decode("ascii")
   subprocess.run("pbcopy", text=True, input=base64_string)
   print("Token copied to your clipboard")
   ```
   </CodeGroup>

<Info>
  実行すると、Auth Token が生成され、自動的にクリップボードにコピーされます。
</Info>

---

## 問題

Amazon Simple Storage Service/Secure File Transfer Protocol（S3/SFTP）インポートの実行中、ファイルを取得しようとすると次のエラーが表示されます。

'\>' not supported between instances of 'NoneType' and 'int'.

<img alt="none type.png" src="/images/moengage_797483.png" />

## 解決策

次の手順を実行します。

- 親フォルダー内のサブフォルダー名を確認します。名前にスペースが含まれている場合は、SFTP サーバー上で名前を変更し、インポートを再試行してください。

<Warning>
MoEngage では、S3/SFTP を通じたインポートで、空白スペースを含むファイル名またはフォルダー名はサポートされていません。
</Warning><Info>
一部のインポートファイルが失敗する場合は、ファイル内にデータが多すぎるセルがないか確認してください。ファイル内の各セル（またはフィールド）の最大許容文字数は 131,072 文字です。この制限を超えると、インポート操作が失敗する可能性があります。
</Info>

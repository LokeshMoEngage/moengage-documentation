一般データ保護規則（GDPR）フレームワークは、欧州連合（EU）に居住する個人の個人データの収集および処理に関するガイドラインを定めています。この規則は、ユーザーが自身のデータを完全に管理できるようにすることを目的としています。

MoEngage は GDPR に記載されたガイドラインに準拠しており、個々のユーザーから寄せられたリクエストに簡単に対応できる業界標準の API と SDK を構築しています。

この記事では、GDPR に基づくユーザーの権利と、MoEngage を使用する際にそれぞれの権利に準拠するための推奨事項について詳しく説明します。

## 消去の権利

### 概要

「消去の権利」により、データ主体は、お客様のサーバーおよび MoEngage などのデータ処理者のサーバーから、自身に関するすべての情報を削除できます。

### 実装方法

この権利に準拠するため、MoEngage から自身のデータの消去をリクエストした特定のユーザーに関連するすべての個人データを削除する GDPR/CCPA API を提供しています。詳細については、[GDPR/CCPA API](https://www.moengage.com/docs/api/gdpr/submit-a-gdpr-ccpa-data-request) を参照してください。

この API は、入力として次のいずれかのパラメーターを受け付けます。

- ID（ログインユーザーの場合は必須）
- メールアドレス
- 携帯電話番号
- GAID（匿名ユーザーの場合は必須）
- IDFA（匿名ユーザーの場合は必須）

ユーザーの個人データを削除すると、その個人データは MoEngage から消去されます。キャンペーンおよびアプリ使用状況の分析の整合性を維持するため、エンドユーザーが削除されても匿名の集計データは変更されません（たとえば、エンドユーザーが削除されても、MoEngage はアプリの MAU 数やキャンペーン統計を減らしません）。ただし、このデータは削除されたエンドユーザーのプロファイルとは一切関連付けられていないため、匿名化および集計されたデータを個々のユーザーに結び付けることはできません。

特定のユーザーの個人データを削除する API リクエストが行われた後、リクエストの完了には最大 7 日かかります。ただし、すべてのログおよびバックアップからこのデータを削除するには 60 日かかる場合があります。各ユーザーに関連する個人データの消去リクエストの処理を正当化するため、データを 60 日間保持する必要があります。

GDPR 消去 API の詳細については、[GDPR/CCPA API](https://www.moengage.com/docs/api/gdpr/submit-a-gdpr-ccpa-data-request) を参照してください。

## アクセス権

### 概要

GDPR に基づき、データ主体は、自身のデータが処理されていることの確認、自身のデータへのアクセス、およびプライバシー通知で提供する必要がある情報に概ね相当するその他の補足情報を得る権利を有します（[GDPR 第 15 条](https://gdpr-info.eu/art-15-gdpr/)を参照）。

### 実装方法

MoEngage からユーザーデータをエクスポートできます。MoEngage ダッシュボードの Segmentation モジュールに移動し、必要に応じてデータをダウンロードします。詳細については、[ユーザーデータのエクスポート](/ja/user-guide/analyze/analytics/user-data-exports)を参照してください。

MoEngage は、（MoEngage にデータアクセスをリクエストした）特定のユーザーに関連するすべての個人データを返す API も提供しています。詳細については、[Get User API](https://www.moengage.com/docs/api/user/get-user) を参照してください。

## 訂正の権利

### 概要

GDPR に基づき、データ主体は、個人データが不正確または不完全な場合に訂正を受ける権利を有します。該当する個人データを第三者に開示している場合は、可能な限りその訂正について第三者に通知する必要があります。

### 実装方法

MoEngage のお客様は、Data Import API のいずれかを使用して、MoEngage 内の特定のユーザーのデータを更新できます。これらはデフォルトですべてのクライアントで有効になっており、エンドユーザーが情報の更新をリクエストした際にいつでも使用できます。MoEngage Data Import API と MoEngage でユーザーデータを更新する方法については、[こちら](https://www.moengage.com/docs/api/data/data-overview)を参照してください。

## データポータビリティの権利

### 概要

データポータビリティの権利により、個人は自身の個人データを取得し、さまざまなサービス間で再利用できます。

### 実装方法

アクセス権と同様に、MoEngage のお客様は、任意のユーザー識別子に基づいて特定のユーザーのデータを簡単にダウンロードできます。Admin および Manager のアクセス権を持つ MoEngage ダッシュボードユーザーは、ダッシュボードから直接ユーザーデータをダウンロードできます。詳細については、[ユーザーデータのエクスポート](/ja/user-guide/analyze/analytics/user-data-exports)を参照してください。

MoEngage の Get User API を使用して、特定のユーザーに関するデータをリクエストすることもできます。詳細については、[Get User API](https://www.moengage.com/docs/api/user/get-user) を参照してください。

## 処理の制限の権利

### 概要

データ主体は、データが不正確であるか不適切に取得された場合に、自身の個人データの特定のサブセットの処理をブロックまたは抑制する権利を有します。処理が制限されている場合、個人データを保存することは許可されますが、それ以上処理することはできません。今後も制限が確実に守られるよう、その個人に関する必要最小限の情報のみを保持できます。

### 実装方法

GDPR の「処理の制限の権利」に基づくユーザーのデータトラッキングのオプトアウトリクエストに準拠するため、MoEngage の SDK にはデータトラッキングをオプトアウトするメソッドが用意されています。

SDK の機能を活用してデータ処理を制限する方法については、以下を参照してください。

[ANDROID](https://www.moengage.com/docs/developer-guide/android-sdk/compliance/compliance) | [iOS](https://www.moengage.com/docs/developer-guide/ios-sdk/compliance/compliance) | [Web](https://www.moengage.com/docs/developer-guide/web-sdk/web-sdk-integration/basic-integration/web-sdk-integration)

SDK からデータ処理が停止されると、次のような匿名でトラッキングできるイベントを除き、イベントはトラッキングされません。

- Push（Notification Received Android、Notification Clicked Android、Notification Swiped Android）
- iOS Push（Notification Sent iOS、Notification Clicked iOS）
- Web Push（Notification Received Web、Notification Clicked Web）
- In-App（InApp Shown Android、InApp Clicked Android、InApp Closed Android、App Rated）
- In-App（InApp Shown iOS、InApp Clicked iOS、InApp Closed iOS、App Rated）
- 匿名ライフサイクルイベント（MOE\_APP\_EXIT、TOKEN\_EVENT、App/Site Opened、Viewed Web Page）
- 統計イベント（NOTIFICATION\_OFFLINE\_MOE,DT\_CAMPAIGN\_SCHEDULED、EVENT\_ACTION\_COPY\_COUPON\_CODE）

SDK のデータトラッキングのオプトアウトメソッドを実装する際は、次の点に注意してください。

- データトラッキングをオプトアウトしても、データの消去は保証されません。データの処理を制限し、かつ完全に消去するには、消去 API リクエストを別途行ってください。
- データトラッキングをオプトアウトしても、プッシュ通知が送信されないことは保証されません。デバイス/ユーザーへのプッシュ通知を抑制するには、[キャンペーンメッセージのオプトアウト](https://moengage-user-guide.mintlify.app/user-guide/data/privacy/gdpr#opt-out-of-campaign-messages)を参照してください**。**

## 異議を唱える権利

### 概要

データ主体は、いつでも自身の個人データの処理に異議を唱える権利を有します。これにより、個人はお客様による自身の個人データの処理を事実上停止または阻止できます。

### 実装方法

お客様のユーザーが個人データの処理に異議を唱える権利を行使した場合は、この記事の「処理の制限の権利」セクションに記載されている手順に従って、そのユーザーの個人データの処理を制限する必要があります。

また、この記事の「消去の権利」セクションに記載されている手順に従って、このユーザーの個人データを消去する必要があります。

## 通知を受ける権利

### 概要

データ主体は、お客様が自身の個人データをどのように扱うかについて通知を受ける権利を有します。

### 実装方法

ユーザーがアプリまたはウェブサイトの利用登録を行う際、実際に個人データを取得する前に、その個人情報をどのように使用するかをユーザーに通知する必要があります。プッシュ通知、メール、SMS などのマーケティングコミュニケーションを送信する前にユーザーの同意を得る必要があり、また個人データを他の目的で使用する予定がある場合はその方法も通知する必要があります。

MoEngage は、お客様のデータ主体の個人データを責任を持って使用し、不要になった時点で削除します。エンドユーザーのデータの処理方法の詳細については、MoEngage の[プライバシーポリシー](https://www.moengage.com/privacy-policy/)を参照してください。

## キャンペーンメッセージのオプトアウト

GDPR に基づき、プッシュ通知、SMS、その他のメッセージを送信する前にユーザーの同意を得る必要があります。一部のユーザーまたはデバイスへのメッセージを自動的に制限したい場合は、次のオプションをお勧めします。

### Preference Management の使用

すべてのユーザーからプッシュ許可を取得し、ユーザー属性として設定できます。設定後、プッシュ通知をオプトアウトしたユーザーをキャンペーンのセグメンテーションから除外できます。詳細については、[Preference Management](/ja/user-guide/campaigns-and-channels/mobile-push/getting-started-with-mobile-push/preference-management-for-push-notifications) を参照してください。

### プッシュ通知と In-App をブロックする SDK メソッドの使用

MoEngage SDK を使用すると、特定のデバイスでプッシュ通知と In-App メッセージを制限できます。ユーザーがアプリへの登録時にプッシュ通知および/または In-App メッセージの送信に同意しなかった場合は、SDK から直接これらを制限できます。プッシュ通知および In-App または On-site メッセージのオプトアウトの詳細については、次の SDK ドキュメントを参照してください。

<Info>
Android SDK バージョン 12 および iOS SDK バージョン 8 以降では、プッシュ通知と In-App メッセージのオプトアウトはサポートされなくなりました。
</Info>

#### Android:

- [プッシュ通知のオプトアウト](https://www.moengage.com/docs/developer-guide/android-sdk/compliance/compliance)
- [In-App メッセージのオプトアウト](https://www.moengage.com/docs/developer-guide/android-sdk/compliance/compliance)

#### iOS:

- [プッシュ通知のオプトアウト](https://www.moengage.com/docs/developer-guide/ios-sdk/compliance/compliance)
- [In-App メッセージのオプトアウト](https://www.moengage.com/docs/developer-guide/ios-sdk/compliance/compliance)

#### Web:

- プッシュ通知のオプトアウト: デフォルトでは、Web Push 通知にはユーザーによる明示的なオプトインが必要です。特定のブラウザでプッシュ通知を無効にするには、既存のブラウザ機能を利用できます。
- [On-site メッセージのオプトアウト](https://www.moengage.com/docs/developer-guide/web-sdk/onsite-messaging/configure-and-integrate-on-site-messaging)

## プライバシーバイデザイン

### 広告識別子のオプトアウト

プライバシーバイデザインの一環として、MoEngage の SDK では、必要に応じて広告識別子をオプトアウトできます。

詳細については、SDK ドキュメントを参照してください。

[Android](https://www.moengage.com/docs/developer-guide/android-sdk/sdk-integration/basic-integration/sdk-initialization) | [iOS](https://www.moengage.com/docs/developer-guide/ios-sdk/sdk-integration/basic/sdk-initialization)

### アーカイブポリシー

ユーザーのプライバシーを保護するため、MoEngage はユーザーのデータを真に必要な期間のみ保存します。これに準拠するため、不要になったデータを自動的に削除するアーカイブポリシーを設けています。

アーカイブポリシーの詳細については、[データアーカイブポリシー](/ja/user-guide/data/key-concepts/data-archival-retention-policy)を参照してください。

このほか、GDPR 準拠に関するその他のご質問やサポートが必要な場合は、MoEngage のカスタマーサクセスマネージャー（CSM）またはサポートチームにお問い合わせください。

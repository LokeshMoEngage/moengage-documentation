# 概要

_PII マスキング_機能を使用すると、組織はキャンペーンプレビュー内の個人を特定できる情報（PII）フィールドをマスキングすることで、機密情報を保護できます。これにより、ユーザー属性やイベント属性などの PII データが UI 上に公開されず、プライバシー基準に準拠できます。

Personalized Preview 機能を使用すると、顧客データのプライバシーを損なうことなく、コンテンツを検証し、パーソナライゼーションをテストできます。データ管理または Content API で PII としてマークされたフィールドはマスキングされ、通常は UI 上で "XXXX" として表示されます。一方、非 PII フィールドは平文のまま表示されます。

この機能により、データプライバシーが強化され、PII の不正な公開が防止され、安全なキャンペーンテストが可能になります。

<Info>
  この機能は、パーソナライゼーションプレビューをサポートするすべてのチャネルに適用されます。
</Info>

# ユースケース

PII マスキング機能のユースケースの例を次に示します。

- キャンペーンプレビューでパーソナライゼーションをテストしたい場合、PII マスキングは機密情報を非表示にしながら、非 PII フィールドを平文で表示します。これにより、PII データを公開することなく、コンテンツを正確に検証できます。
- キャンペーンコンテンツ用に Content API からデータを取得する必要がある場合、PII としてマークされたフィールドは自動的にマスキングされるため、UI プレビューでの不正アクセスを防止し、データプライバシーを維持できます。
- 特定のロールに PII を表示する権限がない場合、PII マスキングはパーソナライズプレビュー内の PII フィールドをマスキングしてプライバシーを保護し、承認されたロールのみが機密情報にアクセスできるようにします。
- コンテンツのレンダリングを確認するために Personalized Preview を使用する必要がある場合、PII マスキングは機密情報をマスキングしつつ非 PII の詳細を平文で表示することで、顧客データを保護します。これにより、プライバシーのリスクなしに効果的なプレビューとテストが可能になります。

# パーソナライゼーションコンテンツ内のマスキングされた属性

PII マスキング機能により、携帯電話番号や姓などのユーザー属性は管理者のみが表示できるようになります。他のすべてのユーザーには、これらの属性は "private" として表示されます。

![MaskPII1.png](/images/moengage_f54f57.png)

この機能を使用すると、ユーザープロファイルだけでなく、パーソナライズされたコンテンツ内の PII フィールドもマスキングできます。

<img alt="image (13).png" src="/images/moengage_cef6af.png" /> このアップデートにより、マスキング対象としてマークされたユーザー属性またはイベント属性は、パーソナライゼーションコンテンツでもマスキングされて表示されます。これはパーソナライゼーションプレビューをサポートするすべてのチャネルに適用され、プラットフォーム全体でマスキングされた値が一貫して保護されます。

# Content API 内のマスキングされた属性

Content API を追加する際、レスポンスで PII を受け取る場合があります。この機能を使用すると、API レスポンス内の特定の値をマスキングして、PII への不正アクセスを防止できます。

これを行うには、次の手順を実行します。

1. **Content API **ページの **Actions** 列で、省略記号アイコンをクリックし、**Edit** を選択します。Content API を使用したパーソナライズキャンペーンの作成の詳細については、[Content API](/ja/user-guide/campaigns-and-channels/getting-started/campaign-content/content-apis) を参照してください。
   ![PIImasking2.png](/images/moengage_58feba.png)
2. **Edit Content API **ページで、**Mask PII fields** の下にある **Yes** をクリックします。<img alt="EditcontentAPI.png" src="/images/moengage_352235.png" />
3. Select fields to mask リストで、マスキングするフィールドを選択します。たとえば、次の画像では coord. lon、coord.lat を選択しています。**Done** をクリックします。
   ![image (17).png](/images/moengage_b2dbc5.png)
4. この Content API をコンテンツのパーソナライズに使用すると、前の手順で選択したフィールドの値がマスキングされます。
   ![image (18).png](/images/moengage_fa4138.png)

<Info>
  フィールドの値は "xxx" としてマスキングされます。これらのフィールドを使用する操作でも、ユーザープロファイルから取得された元の値ではなく、"xxx" の値が使用されます。
</Info>

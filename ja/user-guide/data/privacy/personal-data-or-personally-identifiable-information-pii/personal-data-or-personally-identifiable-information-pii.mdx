# 個人データまたは PII とは

**PII**（**Personally Identifiable Information**、個人を特定できる情報）とは、識別された、または識別可能な自然人に関するあらゆるデータです。

識別可能な自然人とは、特に氏名、識別番号、位置データ、オンライン識別子などの識別子、またはその自然人の身体的、生理的、遺伝的、精神的、経済的、文化的、社会的アイデンティティに固有の 1 つ以上の要素を参照することにより、直接的または間接的に識別できる人を指します。個人データの例には、氏名、住所、生年月日、IP アドレスなどがあります。

組織は、合意されたビジネス目的に従って、PII を使用してユーザーや対象者を識別、連絡、または所在を特定できます。個人データまたは個人データのセットに対して実行される、収集、記録、整理、構造化、保存、改変または変更、検索、参照、使用、送信による開示、配布その他の方法による利用可能化、照合または結合、制限、消去または破壊などの操作または一連の操作は、「個人データの処理」と呼ばれます。

**データ管理者**（Data Controller）とは、個人データを処理する手段と方法を決定する主体です。MoEngage は、雇用主として処理の手段と目的を決定するため、従業員データを処理する際にはデータ管理者として機能します。

**データ処理者**（Data Processor）とは、データ管理者に代わって個人データを処理する主体です。MoEngage は、データ管理者（MoEngage のお客様）が決定したユースケース向けのサービス提供の一環として、お客様がエンドユーザーの個人データを処理するのを支援する際に、データ処理者として機能します。

郵便番号、生年月日、性別、パスワードなどの特定の個人データフィールドは、それ単独では個人を識別できない場合がありますが、他の個人データフィールドと組み合わせることで生存する個人を一意に識別できる場合には PII となります。

# MoEngage における PII の保護

MoEngage は、PII データを保護するための 3 つのオプションを提供しています。これらのオプションは、さまざまなビジネス要件と運用要件に対応しています。データマスキング、データ暗号化、トークン化のうち、ニーズに最も適したアプローチを選択できます。

## PII を MoEngage に送信する場合

PII を MoEngage に送信する場合は、次の機能を利用してデータを保護できます。

- **PII マスキング**  
  MoEngage では、特定の属性を PII として指定し、マスキングしてセキュリティを確保できます。このデータを表示およびダウンロードできるのは管理者のみです。詳細については、[PII マスキング](/ja/user-guide/data/privacy/personal-data-or-personally-identifiable-information-pii/pii-masking)を参照してください。
- **PII データ暗号化**  
  MoEngage は、システム内に保存された PII データを暗号化する機能を提供しています。PII としてマークされたユーザー属性またはイベント属性はすべて暗号化できます。デフォルトでは、暗号化された属性ではマスキングも有効になります。これらの属性は、MoEngage ダッシュボードで表示またはダウンロードできません。詳細については、[PII データ暗号化](/ja/user-guide/data/privacy/personal-data-or-personally-identifiable-information-pii/pii-data-encryption)を参照してください。

## PII を MoEngage に送信しない場合

PII を MoEngage に送信しない場合は、次の機能を活用してワークフローを実現できます。

- **PII トークン化送信**ユーザーの完全な匿名性を確保するため、MoEngage はトークン化送信をサポートしています。このアプローチでは実行時に PII データを取得するため、MoEngage 内に保存する必要がありません。詳細については、[PII トークン化送信](/ja/user-guide/data/privacy/personal-data-or-personally-identifiable-information-pii/pii-tokenized-sending)を参照してください。

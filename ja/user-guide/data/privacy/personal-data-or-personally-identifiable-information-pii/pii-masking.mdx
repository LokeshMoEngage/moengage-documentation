description: "MoEngage で個人を特定できる情報をマスキングし、ワークスペースのチームメンバーによる機密ユーザーデータの表示やダウンロードを防止します。"
---

MoEngage は、エンドユーザーの個人を特定できる情報（PII）を保護します。管理者は、暗号化の有無にかかわらず、任意のユーザー属性またはイベント属性をマスキングできます。さらに、管理者が PII としてマークされたユーザー属性またはイベント属性を暗号化すると、MoEngage は自動的にその属性をマスキングします。

<Info>
MoEngage ダッシュボードでマスキングされていない PII データを表示し、PII 属性をエクスポートする権限を持つのは管理者のみです。  
  
ただし、管理者に対しても PII データをマスキングしたい場合や、管理者による PII のエクスポートを完全にブロックしたい場合は、MoEngage のカスタマーサクセスマネージャー（CSM）またはサポートチームにお問い合わせください。
</Info>

マスキングにより、機密データがワークスペース内の他のユーザー（マーケター、マネージャー、アナリスト、開発者など）に直接表示されることを防ぎ、MoEngage UI からのダウンロードも防止します。これにより、ユーザーデータのセキュリティとプライバシーがさらに強化されます。

# ユーザー属性をマスキングする

ユーザー属性をマスキングするには、次の手順を実行します。  
 <img alt="PII masking.gif" src="/images/moengage_d2341c.png" />

1. MoEngage ダッシュボードの左側のナビゲーションメニューで、**Settings** \> **Data management** をクリックします。
2. **Data management** ページで、**User attributes** タブをクリックします。
3. 目的のユーザー属性を検索し、その属性の横にある省略記号アイコンをクリックします。
4. **Edit attribute** をクリックします。
5. **Edit attribute details** サイドドロワーで、**Mask attribute** トグルをオンにして、機密データがワークスペース内の他のユーザーから確実に隠されるようにします。
6. **Save** をクリックします。

# イベント属性をマスキングする

<img alt="PII masing event attributes.gif" src="/images/moengage_ea3c01.png" />

1. MoEngage ダッシュボードの左側のナビゲーションメニューで、**Settings** \> **Data management** をクリックします。
2. **Data management** ページで、**Events** タブをクリックします。
3. イベントを検索し、イベントを展開してその下のイベント属性を表示します。その属性の横にある省略記号をクリックします。
4. **Edit attribute** をクリックします。
5. **Edit attribute details** サイドドロワーで、**Mask attribute** トグルをオンにします。このトグルをオンにすると、ワークスペース内の他のユーザーから PII が非表示になります。
6. **Save** と **Continue** をクリックします。

# マスキングされたユーザー属性とイベント属性を表示する

ユーザー属性またはイベント属性をマスキングした後、ワークスペースのユーザーは、割り当てられたロールと権限に応じて、MoEngage UI の次のページ、タブ、ダイアログボックスでそれらを表示できます。

## ユーザー検索ボックス

マスキングされたユーザー属性またはイベント属性は、Create Segment ページで表示できます。**Search user by ID, Email, Mobile No, or MoEngage ID** 検索ボックスでユーザーを検索します。

マスキングされた属性へのアクセス可否は、割り当てられたロールによって異なります。これらの属性を表示する権限がある場合は、マスキングされた属性の実際の値を確認できます。権限がない場合は、**Name** 列に **Private** および **---**（マスキング）として表示されます。<img alt="user_search.png" src="/images/moengage_9587ca.png" />

## ユーザー表示ウィンドウ

マスキングされたユーザー属性またはイベント属性は、**Showing users after segmentation** ページで表示できます。**Showing users after segmentation** ページを表示するには、次の手順を実行します。

1. **Create Segment** ページでセグメントを作成する際に **Show count** をクリックし、**Query results** を展開します。
2. **Sample users** セクションで、**Show more** をクリックします。
3. **Showing users after segmentation** ページに、セグメンテーション後のすべてのユーザーが表示されます。  
   マスキングされた属性へのアクセス可否は、割り当てられたロールによって異なります。これらの属性を表示する権限がある場合は、マスキングされた属性の実際の値を確認できます。権限がない場合は、**Private** および **---**（マスキング）として表示されます。  
    <img alt="user_popup.png" src="/images/moengage_6e3442.png" />

## ユーザーエクスポートウィンドウ

マスキングされたユーザー属性またはイベント属性は、**Export users data** ダイアログボックスで表示できます。MoEngage は、ロールに基づいて **Export users data** ダイアログボックスでマスキングされたユーザー属性を無効にします。つまり、ロールでマスキングにアクセスできない場合、**Create Segment** ページの **Export users** オプションを使用してマスキングされた属性をエクスポートすることはできません。

<img alt="Export.png"  src="/images/moengage_362d1c.png"  />

## ユーザープロファイルページ

マスキングされたユーザー属性またはイベント属性は、User Profile ページで表示できます。User Profile ページでマスキングされた属性を表示するには、次の手順を実行します。

1. **Create Segment** ページでセグメントを作成する際に **Show count** をクリックし、**Query results** を展開します。
2. **Sample users** セクションで、目的のユーザーを選択してユーザープロファイルを表示します。  
   マスキングされた属性へのアクセス可否は、割り当てられたロールによって異なります。これらの属性を表示する権限がある場合は、マスキングされた属性の実際の値を確認できます。権限がない場合は、**Private** として表示されます。

**Create Segment** ページの **Search user by ID, Email, Mobile No, or MoEngage ID** 検索ボックスを使用して User Profile ページにアクセスすることもできます。検索ボックスでユーザーを検索し、目的のユーザーの名前をクリックします。  
 <img alt="user profile.png" src="/images/moengage_89cdc3.png" />

## User Info タブ

2. **Sample users** セクションで、目的のユーザーを選択してユーザープロファイルを表示します。
3. **User Profile** で **User info** タブをクリックし、**User Properties** をクリックします。  
   マスキングされた属性へのアクセス可否は、割り当てられたロールによって異なります。これらの属性を表示する権限がある場合は、マスキングされた属性の実際の値を確認できます。権限がない場合は、**Private** として表示されます。

## 値の候補

Segmentation ページおよび Analytics ページでのマスキングされた値の候補の表示は、ロールによって異なります。   
マスキングへのアクセス権がないロールでは、これらの候補は無効になります。一方、マスキングの権限を持つロールでは、マスキングされた候補の背後にある実際の値を確認できます。

## Analytics ページでのユーザープロパティによる Split by または Group by

**Analyze** の [Behavior](/ja/user-guide/analyze/analytics/behavior)、[Funnel](/ja/user-guide/analyze/analytics/funnels)、[Retention](/ja/user-guide/analyze/analytics/retention) ページで、**Split by** または **Group by user property** 機能の属性を選択する場合、属性の表示はロールによって異なります。ロールでマスキングにアクセスできない場合、マスキングされた属性は無効になります。アクセスできる場合は、マスキングされた属性の実際の値を表示できます。  
 <img alt="PII Analytics.png" src="/images/moengage_73d0b6.png" />

# ダッシュボード以外の機能

MoEngage UI 以外の機能は PII マスキングをサポートしていません。そのため、[Open Analytics](/ja/user-guide/analyze/custom-analysis/open-analytics)、[S3 Exports](/ja/user-guide/data/exports/events/data-warehouse/s3-exports)、[MoEngage Streams](https://www.moengage.com/docs/api/data/moengage-streams) では PII マスキングを利用できません。

これらの機能はデフォルトでは利用できず、手動での有効化が必要で、リクエストに応じて有効化されます。セキュリティとデータのニーズに応じて、チームにこれらの機能へのアクセス権を付与できます。

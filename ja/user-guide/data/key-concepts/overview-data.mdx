データとは、保存、分析、追跡したいあらゆる情報のことです。MoEngage のオンボーディング時に最初に行うことの 1 つは、さまざまなオプションを通じてデータを MoEngage に統合することです。このデータは通常、セグメントの作成や分析、キャンペーンの実行に使用されるユーザー属性とイベントで構成されます。

## データの種類

- **ユーザー** - ユーザーデータにはユーザーに関する情報が含まれ、システム内のすべてのユーザーについてユーザープロファイルで確認できます。MoEngage では、各ユーザーについて、MoEngage の派生属性または標準属性と、MoEngage に送信できる任意のカスタムユーザー属性の情報を利用できます。MoEngage は、ユーザーの行動に基づいて派生属性を生成します。詳細については、[ユーザープロファイル](/ja/user-guide/data/user-data/user-profile)および[派生ユーザー属性](/ja/user-guide/data/user-data/derived-user-attributes)を参照してください。
- **デバイス** - 1 人のユーザーに複数のデバイスが関連付けられている場合があり、これは MoEngage にデバイスデータとして保存されます。広告識別子（広告主がオファーをパーソナライズするのに役立つ、モバイルデバイスに関連付けられた一意のユーザー ID）などのデバイス固有の属性は、ユーザープロファイルで確認できます。
- **イベント** - イベントとは、ユーザーの行動やアクションに関連する出来事です。たとえば、ログイン、ログアウト、ウェブページの閲覧、カートへの商品の追加などです。イベントデータには、こうしたイベントに関する情報が含まれます。イベントは以下のように分類されます。
  - **派生イベント** - MoEngage は、ユーザーのアクションと行動に基づいて、派生イベントと呼ばれる標準イベントのリストを生成します。詳細については、[派生イベント](/ja/user-guide/data/event-data/derived-events-and-attributes)を参照してください。
  - **カスタムイベント** - ビジネスに固有のイベントを定義し、MoEngage で追跡できます。
- **補助** - 補助データは、MoEngage にインポートできる一時的なデータです。詳細については、[補助データ](/ja/user-guide/data/imports/auxiliary-data)を参照してください。

## データ操作

データに対して以下の操作を実行できます。

- **作成と更新** - 以下を使用して、MoEngage でデータを作成および更新できます。

|タイプ|SDK| S2S API と Bulk Upload API | File Imports（CSV、S3、SFTP） | パートナー統合（CDP と CRM） |
| --- | --- | --- | --- | --- |
| ユーザー | 作成、更新 | 作成、更新 | 作成、更新 | 作成、更新 |
| デバイス | 作成、更新 | サポート対象外 | サポート対象外 | サポート対象外 |
| イベント | 作成 | 作成 | 作成 | 作成 |

- **削除** - GDPR/CCPA API を使用して、MoEngage からデータを削除できます。詳細については、[Erase API](https://www.moengage.com/docs/api/gdpr-ccpa/gdpr-ccpa-overview) を参照してください。

## データ管理

MoEngage には、データを効果的に管理するための Data Management ダッシュボードが用意されています。以下のことが可能です。

- 不要なイベント、イベント属性、ユーザー属性をブロックまたは非表示にする
- MoEngage に統合されているすべてのイベント属性とユーザー属性を表示する
- マーケターが目的を理解できるよう、属性（イベントとユーザー）にわかりやすい表示名を追加する
- 属性に許可するデータ型を指定する - これにより、セグメンテーションや分析の際に、許可されたデータ型に関連する演算子が表示されるようになります。

詳細については、[データ管理](/ja/user-guide/settings/data-management/overview-data-management)を参照してください。

## データのエクスポート

MoEngage が受信または生成したすべてのユーザーイベントとキャンペーンイベントは、以下を使用してパートナーツールにエクスポートできます。

- [Data Warehouse Exports](/ja/user-guide/data/exports/events/data-warehouse/s3-exports)（AWS、GCP、Redshift、BigQuery）
- パートナーツールへの [MoEngage Streams](https://www.moengage.com/docs/api/data/moengage-streams)。

エクスポートしたデータをさらに分析して、ユーザーの行動や好みなどに関するインサイトを得ることができます。

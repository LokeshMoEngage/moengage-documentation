MoEngage は複数のデータセンターを保有しており、お客様はサインアップ時に特定のデータセンターに所属することになります。データセンターに基づいて、ダッシュボードのアクセス URL、SDK、REST API エンドポイントが提供されます。

サインアップの前に、MoEngage オンボーディングマネージャーに相談して、お客様のニーズに適したデータセンターを確認できます。サインアップ後は、ダッシュボードの URL からデータセンターを特定できます。

詳しくは、MoEngage カスタマーサクセスマネージャー（CSM）またはサポートチームにお問い合わせください。MoEngage のさまざまなデータセンターについて詳しく説明します。

# 複数のデータセンターを持つことの意義

アプリケーションの複数のインスタンスをホストし、サインアップを複数のデータセンターに分散させることで、各データセンターのデータ量が分散され、サービスを最適化できます。また、ユーザーデータを特定の地域でホストするというコンプライアンス要件がある場合もあります。

MoEngage アカウントにサインアップできるのはいずれか 1 つのデータセンターのみであり、MoEngage で追跡するユーザーデータは同じデータセンターに保存されます。

# 地域別データセンターへのサインアップ

MoEngage にサインアップする際は、いずれかのデータセンターを選択してサインアップできます。

<Info>
  特定の地域にデータを保存する具体的な要件がない場合は、MoEngage にデータセンターの選択をお任せいただくことをお勧めします。これにより、ご利用期間を通じて最適化されたサービスを提供できます。
</Info>

データプライバシーやデータレジデンシーの要件により、ユーザーのデータを特定の地域に保存する必要がある場合は、以下の推奨事項に従ってサインアップしてください。

| データを保存すべき地域 | 選択するデータセンター | ステータス |
| --- | --- | --- |
| 米国 | DC-01, DC-04 | 両方のデータセンターで積極的にオンボーディング中 |
| EU | DC-02 | 積極的にオンボーディング中 |
| インド | DC-03 | 積極的にオンボーディング中 |
| シンガポール | DC-05 | 新規オンボーディングは利用不可 |
| インドネシア | DC-06 | 積極的にオンボーディング中 |

ユーザーのデータを特定の地域に保存する要件がない場合、どのデータセンターでサインアップしても影響はありません。すべてのデータセンターは同一であり、同様の機能、SLA、レイテンシーをサポートしています。

手動アップロードを使用すると、MoEngageダッシュボードでCSVを直接アップロードしてユーザーまたはイベントをインポートできます。接続を設定せずに、他のプラットフォームからの移行、属性の一括更新、1回限りの履歴データの読み込みを行う場合に便利です。

<Note>
  手動アップロードは、自動化されたファイルインポートやウェアハウスインポートとはいくつかの点で異なります。

  - **CSVのみ**: JSONはサポートされていません。
  - **定期的なスケジュール設定なし**: アップロードは即時または特定の日時に実行できますが、定期的なスケジュールでは実行できません。
  - **Object/JSON (複合) 型は非対応**: マッピングはダッシュボードで列ごとに行います。
</Note>

ユーザーとイベントでは、エントリーポイントとワークフローが異なります。インポートするエンティティを選択してください。

<Tabs>
  <Tab title="ユーザー">
    ユーザーアップロードでは、新しいユーザープロファイルを作成したり、既存ユーザーの属性を更新したりできます。既存ユーザーの更新で新しいユーザーが作成されることはなく、すでにMoEngageに存在するユーザーのみが更新されます。

    **エントリーポイント:** **Segment** > **User Imports** > **Import Users**。

    ### ステップ1: CSVをアップロードする

    ユーザーリストのタイプを選択し、ファイルをアップロードします。

    - **Registered Users**: 登録済みアカウントを持つユーザーです。ファイルには、**ID** 属性にマッピングされる一意のユーザー識別子の列が含まれている必要があります。
    - **Anonymous Users**: サインアップしていないものの、識別子 (メールアドレス、携帯電話番号など) で認識できるユーザーです。識別子は **Anonymous ID** 属性にマッピングされます。

    サンプルファイルをダウンロードして、想定されるフォーマットを確認してください。CSVを参照して選択するかドラッグ&ドロップし、ファイルにヘッダーが含まれているかどうかを指定します。必要に応じて **update existing users only** を選択します。**Next** をクリックします。

    <Info>
      識別子がすでにMoEngageに存在する場合、既存ユーザーが新しい属性で更新されます。存在しない場合、MoEngageはその識別子で新しいユーザーを作成します。
    </Info>

    ### ステップ2: 列を設定する

    各CSV列をMoEngageのユーザー属性にマッピングします (または新しい属性を作成します)。上位3行 (ヘッダーを除く) とすべての列が表示されます。

    - **識別子の設定**: 登録ユーザーの場合は、1つの列を **ID** としてマークします。[Unified Identity](/ja/user-guide/data/user-data/unified-identity-identity-resolution) が有効な場合は、追加の識別子もマッピングするオプションがあります。匿名ユーザーの場合は、列を **Anonymous ID** としてマークします。
    - **新しい属性の追加**: **+** をクリックし、一意の属性名を入力します。
    - **カンマを含む値**: カンマを含む値は二重引用符で囲んでください (例: `"221B, Baker Street, London"`)。囲まない場合、カンマより前のテキストのみがインポートされます。
    - **列のスキップ**: **Skip the column** をクリックして列を除外します。**Show Skipped Columns** を切り替えると、スキップした列を非表示にしたり再度含めたりできます。

    <Info>
      列名は大文字と小文字が区別され、ダッシュボード上の属性名と完全に一致する必要があります。イベント、イベント属性、ユーザー属性のプレフィックスとして `moe_` を使用しないでください。これは予約済みのシステムプレフィックスであり、使用すると事前の連絡なしに定期的にブラックリストに登録される可能性があります。
    </Info>

    ### インポートの動作

    MoEngageにすでに存在するユーザーの属性を一括更新するには、**Update existing users only** を選択します。そのアップロードから新しいユーザーは作成されず、識別子がMoEngageに存在しない行は無視されます。オフのままにすると、アップロードでユーザーの更新に加えて作成も行われます。

    ### インポート通知を送信する

    通知をオンにし、インポートの作成、成功、失敗時に通知を受け取る最大 **10件のメール受信者** を選択します。マッピングが完了したら、**Next** をクリックします。

    ### ファイルセグメントとして保存する

    **Save as File Segment** をオンにして名前を入力すると、インポートしたユーザーからキャンペーンで使用できるセグメントが作成されます。

    - **既存のセグメント**: ユーザーは追加モードで追加されます。新しいユーザーが追加され、削除されるユーザーはありません。
    - **新しいセグメント**: 更新モードとして、**Replace** (各インポートでセグメントのユーザーを完全に置き換え) または **Append** (各インポートでユーザーを追加し、削除はなし) を選択します。

    <Warning>
      ファイルセグメント名に `/` やUnicode文字を使用しないでください。使用するとインポートが失敗します。
    </Warning>

    ### ステップ3: アップロードをスケジュールする

    インポートを実行するタイミングを定義します。

    - **As soon as possible**: **Done** をクリックすると開始されます。
    - **At specific date and time**: 選択した開始日時に実行されます。

    最初のインポート後、**Past Imports** セクションに過去のインポートとそのステータスが表示されます。処理が完了すると、アップロードの詳細を記載したメールが届きます。

    <ReachabilityNote />
  </Tab>
  <Tab title="イベント">
    イベントアップロードでは、過去のイベントのインポート、プラットフォーム切り替え時のイベントデータの移行、大量のイベントの一括アップロードを行えます。

    **エントリーポイント:** **Data** > **Data Imports** > **Events** タブ > **Import** > **Events** > **Upload CSV**。

    <Info>
      1つのCSVファイルでアップロードできるイベントは一度に1つのみです。1つのファイルで複数のイベントをアップロードすることはできません。
    </Info>

    ### ステップ1: ソースとフォーマット

    1. **Import name**: インポートの名前を入力します。
    2. **Select event**: アップロードするイベントを選択するか、**Create new event** をクリックして **Event name** を入力し、**Create** をクリックします。
    3. **Select file**: CSV (150 MB未満) をドラッグ&ドロップまたはアップロードします。サンプルファイルをダウンロードして、想定されるフォーマットを確認してください。各列はイベント属性を表します。
    4. **File preview**: **Preview file** をクリックして、最初の5行をプレビューします。
    5. **Next** をクリックします。

    ### ステップ2: インポートの設定とアクション

    **必須マッピング**: 必須のMoEngage属性である **User Identifier** と **Event time** を、CSVの列にマッピングします。Event timeをマッピングする際は、日時フォーマットとタイムゾーンを選択します。

    **列のマッピング**: 残りのCSV列をMoEngageのイベント属性にマッピングします。

    1. リストから属性を選択するか、**Create new attribute** をクリックして **Attribute name** と **Data type** を入力し、**Create** をクリックします。
    2. 各属性の **Data type** を選択します。
    3. 列を除外するには **Skip column** を選択します。マッピング済みの必須フィールドは無効になります。

    **Send Import Status**: インポートステータスを受け取る最大 **10件のメール受信者** を選択し、**Next** をクリックします。

    ### ステップ3: アップロードをスケジュールする

    - **As soon as possible**: **Schedule Import** をクリックすると開始されます。
    - **At specific date and time**: 選択した開始日、開始時刻、タイムゾーンで実行されます。

    **Schedule Import** をクリックしてイベントデータをインポートします。

    ### インポートしたイベントデータを表示する

    インポートされたイベントは **Data** > **Data Imports** > **Events** に一覧表示されます。**Actions** をクリックして、インポートの詳細を **View** (および **Export file** でメールにエクスポート) するか、インポートを **Duplicate** して同じイベントのCSVを再アップロードします。

    インポートステータス: **Successful**、**Processing**、**Archived**、**Failed**。
  </Tab>
</Tabs>

# リファレンス

以下の内容は、ユーザーアップロードとイベントアップロードの両方に適用されます。

## サポートされているデータ型

String、Numeric、Boolean、Datetime、Array (String、Double、Float、Int)。

| 型 | 説明 | マッピングファイルでの値 |
| --- | --- | --- |
| String | 任意の文字列値 (例: `ABC`、`ABC123`)。 | `"type": "string"` |
| Double | 任意の小数値 (例: `3.14159`、`-123.1`)。 | `"type": "double"` |
| Boolean | `true` または `false`。 | `"type": "bool"` |
| Date Time | 任意の日時値 (例: `2019/02/22 17:54:14.933`)。 | `"type": "datetime"` |

## 言語と空の値

MoEngageは、言語と空の値を次のように処理します。

- **言語**: UTF-8でデコード可能な文字を使用して、任意の言語のデータをインポートできます。
- **空の値**: 空の値もインポートされます。MoEngageは空の値で属性を作成または更新します。

## 制限

手動アップロードには次の制限があります。

<DataArchival />

- **ファイルサイズ**: CSV 1ファイルあたり150 MB未満。
- **行数**: 1つのCSVファイルは、1時間あたりの行数制限までサポートします。1時間あたりの行数制限を超えるファイルは拒否されます。5行未満のファイルはエラーの原因となる場合があるため、必要に応じてダミー行を追加してください。
- **列/属性**: ユーザーは100列、イベントは1イベントあたり100列。

## サポートされていないもの

手動アップロードは次のものをサポートしていません。

- 属性タイプ _list_ およびその他の複合型 (JSON、ディクショナリなど)。
- CSVファイルの複数行サポートはデフォルトで無効になっています。この機能が必要な場合は、サポートにお問い合わせください。`Ctrl+M` や `\r` など、`\n` 以外の改行フォーマットはサポートされていません。複数行サポートを有効にすると、インポートの処理速度に悪影響を及ぼす可能性があります。
- JSONファイル。

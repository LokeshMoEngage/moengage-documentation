MoEngage は、デフォルトでいくつかのイベントと属性を生成します。これらは派生イベントおよび派生属性と呼ばれます。これらは、セグメンテーションや分析においてユーザーをセグメント化するためのフィルターとして使用できます。

[派生ユーザー属性の一覧はこちら](/ja/user-guide/data/user-data/derived-user-attributes)をご覧ください。

## イベント / ユーザーアクティビティ

カテゴリ別のイベント一覧:

### ライフサイクル

| 名前 | 説明 | プラットフォーム |
| --- | --- | --- |
| App/Site Opened | アプリまたはウェブサイトでユーザーセッションが開始されたときにトラッキングされます。また、ユーザーの Last Active Time と App/Site Open Time の時間差が 30 分を超える場合にのみトラッキングされます。 | Android, iOS, Web, TV |
| Viewed Web Page | ユーザーがウェブページにアクセスしたときにトラッキングされます。イベント属性としてページ URL を選択すると、特定のページにアクセスしたユーザー数を確認したり、Drop-off capture" のイベントトリガー型 Web Push を設定したりできます。 | Web, TV |
| App Exit | アプリがバックグラウンドに移行するたびにトラッキングされます。 | Android, iOS, TV |
| User Logout | ユーザーがアプリ/サイトからログアウトしたとき、またはユーザーがリセットされたときにトラッキングされます。 | Android, iOS, Web, TV |
| Push ID Register Android | MoEngage システムが Android デバイスのプッシュ ID を登録したときにトラッキングされます。属性 registered\_by にステータスが含まれます。 | Android, TV (Android TV のみ) |
| User Merged | 既知のユーザーに対して、MoEngage のユーザーオブジェクトがマージされるたびにトラッキングされます。 | User Merging |
| App Update | ユーザーがアプリをアップデートしたときにトラッキングされます。 | Android, iOS, TV |

### 課金対象の標準イベント

課金対象の標準イベント(Billable Standard Events)は、お客様のリクエストに応じてプラットフォームがトラッキングする、MoEngage の定義済みイベントです。他の派生イベント(自動的にトラッキング)やカスタムイベント(SDK やインテグレーション経由でお客様が送信)とは異なり、課金対象の標準イベントは、特定のイベント/アクションの取得を MoEngage に依頼した場合に生成されます。これらのイベントが発生するたびに、課金対象のイベント数にカウントされます。

課金対象の標準イベントはオンデマンドでトラッキングされるため、1 つ以上の課金対象の標準イベントを有効にするには、サポートチケットを作成する必要があります。データは、リクエストに応じてイベントが有効化された日以降のもののみ利用可能になることにご注意ください。

ソース別のイベント属性一覧:

### SDK イベントの場合

| 名前 | 説明 |

| utm\_medium | キャンペーンのメディア。例: CPC、email、push |
| utm\_campaign | UTM キャンペーン名。例: Summer sale |
| utm\_id | UTM キャンペーン ID。例: 12DSW55 |
| utm\_content | キャンペーンのコンテンツ情報。例: logoclick |

| Device Height | 画面の幅(ピクセル単位) |
| Device Manufacturer | デバイスのメーカー。例: Apple |
| Device Model | デバイスのモデル名。例: Dell Inspiron |
| Device Screen Dimension | Width\*Height 形式の画面サイズ |
| Device Width | 画面の高さ(ピクセル単位) |
| Network Type | ネットワークの種類。例: Wifi、4G |
| OS Version | オペレーティングシステムのバージョン。例: iOS 11 |

<Info>
  - MoEngage がトラッキングする一部のイベントやシステムイベント(例: App/Site opened)では、デバイス情報が[イベント属性](/ja/user-guide/data/event-data/derived-events-and-attributes#event-attributes)としてトラッキングされます。これらのイベント属性は分析とセグメンテーションに使用できます。
  - MoEngage SDK によってトラッキングされる[デバイス属性](/ja/user-guide/data/event-data/derived-events-and-attributes#device-attributes)は、分析とセグメンテーションには使用できません。
</Info>

| Campaign Type | キャンペーンが送信されたチャネル(Email、SMS、Push など)を表します。 |
| Delivery Type | キャンペーンの配信タイプ(One-Time、Periodic など)を表します |
| Campaign Tags | キャンペーンに追加されたタグを表します。これはすべてのキャンペーン関連イベントでトラッキングされます |

## デバイス属性

MoEngage SDK は次のデバイス属性を収集します:

<Note>
  MoEngage SDK は次のデバイス属性をデバイスレベルで収集します。これらの属性はユーザーのプロファイルではなく、特定のデバイスインスタンスに紐付けられます:

  **セグメンテーションで利用可能**

  次のデバイス属性はユーザー属性にコピーされ、セグメンテーションでユーザープロパティとして利用できます:

  - **Advertising Identifier** (iOS/Windows): "Advertising Identifier" ユーザー属性として利用可能
  - **moe\_gaid** (Android): Google Advertising ID
  - **Browser Details (moe\_w\_ds)**: Web ユーザーの場合、プラットフォーム、ブラウザ、メーカーを含みます
  - **Mobile User (moe\_mweb)**: ユーザーがモバイル Web でアクセスしたかどうか

  **セグメンテーションで利用不可**

  以下に記載されているその他のデバイス属性はすべて、セグメンテーションでユーザー属性として利用できません:

  - **iOS:** IDFV, os\_ver, device\_tz, model, model\_name
  - **Web/MWeb:** os, os\_platform, os\_ver, model, device\_ts, device\_tz, push\_id
  - **TV:** os\_key, moe\_os\_type, unique\_id, push\_id, status, OS\_VERSION, MODEL, app\_version
</Note>

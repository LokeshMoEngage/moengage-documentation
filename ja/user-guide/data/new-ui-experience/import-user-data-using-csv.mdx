ユーザーインポートを使用すると、CSV ファイルを介して新しいユーザープロファイルをインポートしたり、既存ユーザーのプロファイルデータを更新したりできます。これは、他のプラットフォームから MoEngage に移行する場合や、大規模なユーザーセグメントに対して一括更新を行う場合に特に便利です。この機能が役立つ一般的なシナリオを以下に示します。

- **新規ユーザーのインポート** - Mobile/Web SDK の統合を待たずに、Email キャンペーンや SMS キャンペーンをすぐに開始する場合に便利です。
- **既存ユーザーの更新** - MoEngage の既存ユーザーの特定のユーザー属性を更新できます。これは、一意のクーポンコードを含む通知の送信など、これらのユーザー属性に基づいてセグメント化またはパーソナライズされたキャンペーンを実行する場合に便利です。**注**: 既存ユーザーの更新では、新しいユーザーは追加されません。既存ユーザーのみが更新されます。

CSV を使用してユーザーデータをインポートするには、次の手順を実行します。

1. MoEngage のサイドバーメニューで、**Segment** メニュー項目 <img alt="Screenshot 2025-06-16 at 3.25.14 PM.png"  src="/images/moengage_1f780e.png"  /> にカーソルを合わせます。**Segment** メニューが表示されます。
2. **User Imports** をクリックします。  
    <img alt="user imports nw.png"  src="/images/moengage_cdf3ab.png"  />
3. User imports ページで、**Import users** をクリックします。

<img alt="USERIMPORTS.png" src="/images/moengage_55c2b9.png" />

以下の手順では、MoEngage プラットフォームにユーザーをインポートする方法を説明します。

## ステップ 1: ユーザーの CSV リストをアップロードする

ユーザーをインポートする最初のステップは、User Attributes を含むユーザーの詳細が記載された .CSV ファイルをアップロードすることです。MoEngage では、ユーザーリストをログインユーザー（Web サイトまたはアプリにサインアップしたユーザー）のリストとして、または匿名ユーザー（アプリや Web サイトを使用または訪問したものの、登録していないユーザー）のリストとしてインポートできます。これら 2 種類のユーザーリストについて、以下で詳しく説明します。

- **Registered Users:** アプリ/Web サイトに登録済みのアカウントを持つユーザーです。これらのユーザーはシステム内で一意の識別子を持っている必要があり、このアップロードでは、この一意のユーザー識別子を含む列をユーザー属性 "ID" に必ずマッピングする必要があります。このアップロードは主に、これらの登録ユーザーのユーザー属性を更新するために使用されます。
- **Anonymous Users:** アプリ/Web サイトにまだサインアップしていないものの、メールアドレスや携帯電話番号など、ユーザーを識別するための何らかの識別子があるユーザーです。このアップロードタイプでは、リストの列（メールアドレス、携帯電話番号など）をユーザーの "Anonymous ID" としてマークする必要があります。このアップロードを使用すると、識別可能な一意の識別子を使用して MoEngage に匿名ユーザーを作成し、Email/SMS キャンペーンを送信できます。

<img alt="CreateImport.png" src="/images/moengage_b05c46.png" />

各アップロードでは、CSV ファイルで想定されるデータ形式をわかりやすく示したサンプルファイルをダウンロードすることもできます。実行するアップロードタイプを選択したら、"Browse" ボタンをクリックして目的の .csv ファイルを選択します。上の画像に示されている領域にファイルをドラッグ＆ドロップすることもできます。

さらに、それぞれのオプションを選択することで、ファイルにヘッダーが含まれているかどうか、または既存ユーザーの詳細のみを更新するかどうかを指定できます。ファイルのアップロードが正常に完了したら、"Next" ボタンをクリックして次のステップに進みます。

<Info>
システムにすでに存在するログインユーザーの一意の識別子（または匿名ユーザーの匿名識別子）を指定した場合、既存ユーザーは新しい属性で更新されます。識別子が存在しない場合、MoEngage はその識別子で新しいユーザーを作成します。
</Info>

## ステップ 2: CSV ファイルの列を設定する

**ユーザー属性のマッピング**

このステップでは、アップロードした CSV ファイルの各列を既存のユーザー属性にマッピングする（または新しいユーザー属性を作成する）必要があります。CSV ファイルの上位 3 行（ヘッダーを除く）とすべての列が表示されます（すべての列を表示するには横にスクロールします）。各列について、ドロップダウンからユーザー属性を選択します。

<img alt="CreateIMport_Step2.png" src="/images/moengage_e3f9c9.png" />

<Info>
- 列名では大文字と小文字が区別されます。ダッシュボード上の属性名と完全に一致している必要があります。
- イベント、イベント属性、ユーザー属性の名前を付ける際に、"moe\_" をプレフィックスとして使用することはできません。これはシステムプレフィックスであり、使用すると事前の通知なしに定期的にブラックリストに登録される可能性があります。
</Info>
<Info>

</Info>

**識別子の設定**

ログインユーザーの場合、ドロップダウンから **ID** を選択して、いずれかの列をユーザーの一意の識別子として必ず指定する必要があります。

<img alt="CreateIMport_Step_2.png" src="/images/moengage_6aa194.png" />

匿名ユーザーの場合、列にカーソルを合わせて **Anonymous ID** チェックボックスを選択することで、任意の列を匿名識別子として指定できます。

<img alt="CreateIMport_Step_2_1.png" src="/images/moengage_d2cc95.png" />

**新しいユーザー属性の追加**

列がユーザーに追加する新しい属性である場合は、"+" をクリックして属性の名前を入力します。新しい属性名が既存の属性のいずれかと同じ場合は、別の名前を入力する必要があります。

**カンマを含む値の追加**

いずれかの列の値にカンマ (,) が含まれている場合は、値が複数の列に分割されずに保持されるよう、値をダブルクォーテーション ("") で囲んでください。たとえば、列に値 (221B Baker Street, London) が含まれている場合は、*ダブル*クォーテーションで囲む必要があります ("221B, Baker Street, London")。それ以外の形式では、"," より前のデータのみがその列の値として扱われます。

**サポートされるデータタイプ**

ファイル内の列の値では、次のデータタイプがサポートされています。

- String
- Numeric
- Boolean
- Datetime
- Array (String, Double, Float, Int)

### サポートされるユーザー属性タイプ

| タイプ | 説明 | Manifest での値 |
| --- | --- | --- |

| Double | 任意の小数値。使用できる値の例は 3.14159、241.23、-123.1 です。 | "type": "double" |

**言語サポート**

UTF-8 でデコード可能な文字を使用している限り、任意の言語でデータをインポートできます。  
**空の値**

ファイルに空の値が含まれている場合でも、それらは MoEngage にインポートされます。この場合、値が空のユーザー属性が作成または更新されます。

**列のスキップ**

いずれかの列をスキップする必要がある場合は、"Skip the column" をクリックするだけで、その列を設定する必要がなくなります。スキップした列を非表示にするには、設定の下にある "Show Skipped Columns" チェックボックスの選択を解除します。

<img alt="Screen_Shot_2017-04-05_at_3.01.27_PM.png" src="/images/moengage_8ffbc6.png" />

スキップした列を再度含める場合は、"Show Skipped Columns" チェックボックスを選択し、その列の "Include & Configure" をクリックしてください。

## **ファイルセグメントの作成**

ユーザーインポートのワークフロー中に、インポートしたユーザーのファイルセグメントを作成できます。これを行うには、"Save as File Segment" トグルを選択し、ファイルセグメントの名前を入力します。正常に完了すると、このカスタムセグメントがファイルセグメントのリストに表示されるようになり、そこから任意のキャンペーンで使用できます。

<img alt="SaveFileSegment.png" src="/images/moengage_b8ffc5.png" />

**Finish** をクリックすると、データがアップロードされます。すべてのインポートのリストが表示され、そのステータスによってアップロードが処理されたかどうかがわかります。アップロードが処理されると、アップロードの詳細が記載されたメールが届きます。**注**: ファイルセグメント名には */* や *Unicode* 文字を使用できません。使用するとインポートが失敗します。

## ステップ 3: インポートのスケジュール設定

このステップでは、ファイルをインポートするタイミングを定義します。MoEngage は次のタイプのインポートをサポートしています。

1. **As soon as possible**: **Done** をクリックすると、すぐにファイルのインポートが開始されます。
2. **At specific date and time**: 選択した **Start date** と **Start time** に基づいてインポートを実行できます。

<img alt="Step3.png" src="/images/moengage_55781c.png" />

**過去のインポート**

最初のユーザーインポートの後、アカウント内の過去のインポートとその詳細を示すセクションが表示されます。

<Info>
インポートされたユーザーのチャネル到達可能性とカスタムセグメントは、インポート完了から 30 分後に利用可能になります。これに合わせてキャンペーンを計画することをお勧めします。
</Info>

# 配列のサポート

- 単純な配列がサポートされています。ネストされた配列や連想配列はサポートされていません。
- CSV でサポートされている区切り文字は "|" です。
- サポートされているデータタイプは、array double（数値）と array string です。**Step 2: Import configuration and action** を実行する際に、**Map columns** セクションの **Map column to attribute** 列の下にあるリストでこれらのデータタイプを選択できます。**  
   <img  src="/images/moengage_1edaac.png"  />**
- 配列内のすべての要素は同種である必要があります。つまり、すべて integer またはすべて string である必要があります。同種でない場合、MoEngage は要素の型変換（変換）を試みてからデータを保存します。CSV フィールド内の配列の例は次のとおりです: [1|2|3] <img  src="/images/moengage_b707b3.png"  />
- 配列の型変換: 配列に複数のデータタイプの要素 [“1” | 2 | “abc”] があり、定義されたデータタイプが Array Integer の場合、MoEngage に最終的に取り込まれる配列は [ 1, 2 ] になります。この場合、"abc" は integer に変換できない文字列であるため、最終的な配列には含まれず MoEngage に取り込まれません。MoEngage での型変換の詳細については、[こちら](/ja/user-guide/settings/data-management/overview-data-management)を参照してください。

# 現在サポートされていないもの

- 属性タイプ *list* およびその他の複合型（JSON、辞書など）。
- "\n" 以外の改行文字形式 - 現在 .csv ファイルでサポートされている改行文字は "\n" のみです。"Ctrl+M" や "\r" などの他の形式はサポートされていません。
- ファイルの行数が 5 行未満の場合、ファイルのインポート中にエラーが発生する可能性があります。この場合は、ダミー行をいくつか追加してインポートしてください。

# 概要

MoEngage では、SFTP フォルダーに保存されたファイルを使用してユーザーとイベントをインポートできます。

# インポートの種類

MoEngage は SFTP フォルダーから以下をインポートできます。

1. **登録ユーザー**: MoEngage にすでに登録されているユーザーです。
2. **匿名ユーザー**: MoEngage にまだ登録されていないユーザーです。
3. **イベント**（標準およびユーザー定義）: MoEngage は、Campaign Interaction Events などの標準イベントに加えて、独自のユーザー定義イベントもインポートできます。
4. **補助データ**: 一時的に追加されるユーザーです。

# ファイルの準備

サポートされているファイルの種類、命名規則、ファイル構造などについては、[ファイルインポートのヘルプドキュメント](/ja/user-guide/data/imports/overview-imports)を参照してください。ファイルの準備ができたら、SFTP フォルダー内に配置する必要があります。

## フォルダー構造

すべてのファイルを 1 つのフォルダーに配置します。フォルダーのパスはインポートの設定時に構成できます。

MoEngage はサブフォルダー内のファイルを検索しないことに注意してください。

## ステップ 1: SFTP 接続とファイル形式を選択する

#### **ユーザーインポート**

登録ユーザーと匿名ユーザーのどちらをインポートするかを選択できます。

<img alt="SFTPRegisteredUser.png"  src="/images/moengage_53c849.png"  />

インポートする方を選択してください。登録ユーザーのインポートと匿名ユーザーのインポートでは、想定されるファイル名が異なります。詳細については、[命名規則](/ja/user-guide/data/imports/overview-imports)のセクションを参照してください。

#### **イベントインポート**

イベントインポートでは、インポートするイベントを選択できます。

<img alt="SFTPEventsSetup.png"  src="/images/moengage_6f6644.png"  />

選択したイベントによって、ファイル名が異なります。ファイル名は、選択したイベントの Event Name で始まる必要があります。「Select event」ドロップダウンには、MoEngage アプリで利用可能なすべてのイベントの Display Name が表示されます。これらのイベントの中には、Display Name と Event Name が異なるものがあります。イベントを選択すると、MoEngage はそのイベントに対して想定されるファイル名を Event Description ボックスに表示します。

<img alt="IMport_Popup.png"  src="/images/moengage_fafedd.png"  />

上記の例では、「App/Site Opened」が選択したイベントの Display Name で、その Event Name は `MOE_APP_OPENED` です。そのため、ファイル名は `MOE_APP_OPENED_` で始まる必要があります。詳細については、[命名規則](/ja/user-guide/data/imports/overview-imports)のセクションを参照してください。

ドロップダウンの最後にある「+ Create event」オプションをクリックして、新しいイベントを作成することもできます。

<img alt="CreateNewEvent.png"  src="/images/moengage_43bb91.png"  />

イベントには一意の名前を付けてください。デフォルトでは、Display Name は Event Name と同じになります。[Data Management](/ja/user-guide/settings/data-management/overview-data-management) ページで、このイベントやその他の MoEngage イベントを表示または編集できます。ここで作成した新しいイベントは、最初のインポートが成功した後にのみアプリで利用可能になることに注意してください。

### SFTP 認証情報を選択する

最初のステップである **Source** **and format** では、使用する SFTP 接続とインポート元のフォルダーを MoEngage に指定する必要があります。開始するには、以下の手順を実行します。

1. **SFTP connection** リストで、このインポートに使用する SFTP 接続を選択します。SFTP 接続をまだ作成していない場合は、**SFTP connection** リストの最後にある **+ Add connection** をクリックします。詳細については、[新しい SFTP 接続を構成する](https://partners.moengage.com/hc/en-us/articles/26763225201172-SFTP#h_01JFHD1Q8VFS8SCBZZWCERE7Z2)を参照してください。
2. 以下の詳細を入力します。

| **フィールド** | **説明** |
| --- | --- |
| **Folder URL** | フォルダー URL を入力します。これはファイルが存在するフォルダーのパスです。MoEngage はサブフォルダー内を検索しません。末尾にスラッシュを含めないでください。  **注**: MoEngage は現在ルートフォルダーをサポートしていないため、すべてのファイルが 1 つのフォルダー内にあることを確認してください。  **確認方法**  フォルダーパスは、`sftp://[host-name]/` で始まり、末尾のスラッシュを除いた完全なパスです。  例:   - `sftp://files.hostname.com/my_folder` - `sftp://127.0.0.1/my_folder/sub_folder` |
| **Is your file encrypted?** | 暗号化されたファイルをインポートする場合は、**Is your file encrypted?** チェックボックスを選択します。  MoEngage は暗号化されたファイルのインポートをサポートしています。現在は [PGP 暗号化](/ja/user-guide/data/file-based-imports/use-pgp-encryption-in-moengage)をサポートしています。詳細については、[MoEngage は PGP 暗号化をどのように処理しますか？](/ja/user-guide/data/file-based-imports/use-pgp-encryption-in-moengage)を参照してください。 |
| **Decryption Key** | 復号キーを入力します。このフィールドは、**Is your file encrypted?** チェックボックスを選択すると表示されます。これは PGP 秘密鍵です。  PGP キーはご自身で生成することも、MoEngage に生成させることもできます。  例:  -----BEGIN PGP PRIVATE KEY BLOCcK----- ` xcMGBGVqq74BCADKpWRLSAdcTtDKpT+LCUCqDoZQ2dlgeBiXNovBVyTPlAOPQSqX bnNGs+U4RpHebjvTxaWCLDBGYOvtZbtv6WvPIF7lzXrIv+DcgLMBQp2b3t+ohRBi 41Ch8CZ04F2lxbVBo`  -----END PGP PRIVATE KEY BLOCK----- |
| **Signing Key** | 署名キーを入力します。このフィールドは、**Is your file encrypted?** チェックボックスを選択すると表示されます。  署名キーが構成されている場合は、**Signing key** セクションに次の形式で入力します。例:  -----BEGIN PGP PUBLIC KEY BLOCK-----  `xqq74BCADKpWRLSAdcTtD45nl24KpT+LCUCqDoZQ2dlgeBiXNovBVyTPlAOPQSqX bnNGs+U4RpHebjvTxaWCLDBGYOvtZbtv6WvPIF7lzXrIv+DcgLMBQp2b3t+ohRBi 41Ch8CZ04F2lxboksCwnl31laEuQkk8MERlcthB9AiKvSEf6jihLcPSVVanrQUQN77UZf sFCynJXweqijZxtmUl9V1838sUVOoTzfmGwu7PzV99tAiOlxBjYF9SXIYY/GOoJN Zuz8uOaXWtFPmV536uQT`  -----END PGP PUBLIC KEY BLOCK----- |
| **Key passphrase** | 暗号化キーペアとともに生成されたキーのパスフレーズを入力します。 |

### インポート名

### ファイル構成

<img alt="FileNameConfig.png" src="/images/moengage_19ba9f.png" />

ファイル名に含まれる DateTime 形式を選択します。上記で定義した[命名規則](/ja/user-guide/data/imports/overview-imports)に従い、ファイル名は `_.csv` で終わる必要があります。サポートされている DateTime 形式については、[前述の表を参照](/ja/user-guide/data/imports/overview-imports)してください。下の情報メッセージは選択した DateTime 形式に応じて更新されるため、ファイル名が想定どおりかどうかを簡単に照合できます。

SFTP 認証情報とファイル名の形式を構成すると、MoEngage は SFTP サーバーへの接続を試み、指定された形式で利用可能な最新のファイルを取得します。指定された場所に少なくとも 1 つのファイルがあることを確認してください。ファイルがない場合は続行できません。準備ができたら、「Fetch file」ボタンをクリックして最近のファイルを取得します。

SFTP 認証情報と選択したファイル形式が正しければ、MoEngage は最近のファイルの上位 5 行のプレビューを表示します。

<img alt="FileNameConfig_1.png" src="/images/moengage_42a05d.png" />

ただし、SFTP サーバーからファイルを取得する際にエラーが発生する場合があります。一般的なエラーは次のとおりです。

- **Given credentials are not correct** - SFTP 認証情報が正しくないことを意味します。正しい認証情報を入力し、もう一度ファイルを取得してください。
- **Please check the folder path and try again** - フォルダーパスが正しくないか、指定されたフォルダーパス内に CSV ファイルが存在しないことを意味します。
- **Found zero data rows in the file** - MoEngage が取得したファイルのヘッダー行の後に行がない（ファイルの総行数が 1）ことを意味します。最初の行は常にヘッダー行として扱われるため、ファイルには少なくとも 2 行（ヘッダー行 1 行 + データ行 1 行）が必要です。詳細については、[ファイル構造](/ja/user-guide/data/imports/overview-imports)を参照してください。

ファイルのプレビューに問題がなければ、Next をクリックしてマッピングのステップに進みます。

## ステップ 2: 列を MoEngage 属性にマッピングする

このステップでは、CSV ファイルの列を MoEngage に存在する属性にマッピングする必要があります。すべての列が縦に並んで表示されます。

<img alt="CreateIMport_Step1.png"  src="/images/moengage_d02c37.png"  />

1. **Column name** - マッピングする列名です（前のステップで取得したファイルの最初の行から取得されます）。列名の下には、参考としてサンプル値（前のステップで取得したファイルの 2 行目から取得されます）も表示されます。
2. **Map attribute** - CSV の列をマッピングする MoEngage 属性を選択します。新しい属性を作成することもできます。一部の属性は複数のデータ型からの取り込みをサポートしているため、列のデータ型も選択する必要があります。「DateTime」列の場合は、[形式](/ja/user-guide/data/imports/overview-imports)も選択する必要があります。
3. **More actions** - 必要に応じて列をスキップできます。スキップした列はインポートされません。

インポートの種類に応じて、いくつかの必須マッピングがあります。

1. **ユーザーインポート** - 次の内容を含む列を選択する必要があります。
   1. 登録ユーザー -
      1. User ID - ファイルには、一意のユーザー識別子（システム内のユーザーアカウントを識別するもの）を含む列が必須です。
   2. 匿名ユーザー - 
      1. Anonymous ID - ファイル内の列（メールアドレス、携帯電話番号など）をこれらのユーザーの識別子としてマークする必要があります。
2. **イベントインポート** - 次の内容を含む列を選択する必要があります。
   1. User ID - この列は、MoEngage のユーザーを CSV ファイルと照合するために使用されます。
   2. Event Time - Event Time (UTC) または Event Time (App Timezone) のいずれかをマッピングする必要があります。Event Time (UTC) を選択した場合、インポートされたイベントの「Event Time」は MoEngage ダッシュボードの設定で選択したタイムゾーンに変換されます: <img alt="AppTimezone.png" src="/images/moengage_3bd275.png" />

必須マッピングがマークされると、マッピングテーブルの列名に反映され、その列をスキップ可能としてマークできなくなります。

+Add Field をクリックして、ダッシュボードから直接フィールドを追加することもできます。これにより、リストの下部に新しいフィールドが作成され、属性マッピングを手動で入力できます。

### マニフェストファイル

必要に応じて、[マニフェストファイル](/ja/user-guide/data/imports/overview-imports)をアップロードしてこれらの列を自動マッピングできます。

マニフェストファイルをアップロードするには、マッピングテーブルの右上にある「Upload mapping file」オプションをクリックします。

<img alt="MapColumns (1).png" src="/images/moengage_d05b58.png" />

新規インポートの場合は、インポート用の適切なマッピングファイルを作成する際の参考として使用できるサンプルマニフェストファイルが用意されています。既存のインポートを複製してマッピングファイルをアップロードする場合は、既存のマッピングファイルがすでに追加されており、ダウンロードできます。

<img alt="UploadMapping_1.png"  src="/images/moengage_ca6cf0.png"  />

マニフェストファイルをアップロードし、Done をクリックします。マッピングはそれに応じて自動構成されます。マニフェストファイルに記載されているものの、現在 MoEngage に存在しない追加の属性については、モーダルが開き、属性を作成するためにそれらの属性が一覧表示されます。

<img alt="CreateNewAttributes (1).png" src="/images/moengage_e181f3.png" />

MoEngage 以外の属性を持つ列は空白のままになり、列を手動でマッピングするか、新しい属性を作成できます。マニフェストファイルが記載どおりの[想定される規則](/ja/user-guide/data/imports/overview-imports)に従っていることを確認してください。

マニフェストファイルに存在するものの CSV ファイルに存在しない追加の列は無視されます。また、既存の CSV 列のマッピングがマニフェストファイルに存在しない場合、MoEngage はマッピングを空白のままにし、手動で構成できるようにします。

マニフェストファイル内の列が存在しない MoEngage 属性にマッピングされている場合、マッピングは空白になるため、まず UI から新しい属性を手動で作成してからマッピングする必要があることに注意してください。

### インポート通知の送信

<img alt="SendImportStatus.png" src="/images/moengage_10b298.png" />

必要に応じて、インポートのステータスをメールで通知するように選択できます。ステータスメールの送信先として最大 10 件のメールアドレスを選択します。以下の場合にメールが届きます。

1. インポートが成功した場合。
2. インポートが失敗した場合（考えられる失敗の原因とともに通知されます）。

すべてのマッピングに問題がなければ、Next をクリックします。エラーがある場合は、修正してから先に進んでください。

## ステップ 3: インポート頻度を選択する

<img alt="Frequency.png"  src="/images/moengage_766c90.png"  />

このステップでは、SFTP サーバーからファイルをインポートするタイミングを定義する必要があります。以下の種類のインポートがサポートされています。

1. 1 回限りのインポート: できるだけ早くインポートを実行するか、後の日時に実行する（スケジュール）かを選択できます。
2. 定期インポート: インポートを毎時、毎日、毎週、毎月、または間隔や詳細設定を指定して実行するように選択できます。

実行のたびに、MoEngage は構成された [DateTime 形式](/ja/user-guide/data/imports/overview-imports)のファイルを取得しようとするため、[ファイル名](/ja/user-guide/data/imports/overview-imports)が適切に構成されていることを確認してください。

必要に応じて、指定した回数の実行後または特定の日付にインポートを終了するかどうかを指定できます。準備ができたら「Done」をクリックします。

## 重複インポート

一度に構成できる一意のインポートは 1 つだけです。以下が**すべて**同じである場合、そのインポートは重複インポートと見なされます。

1. **インポートの種類** - Users / Events
2. **インポートのサブタイプ** - Event Name / Registered / Anonymous - イベント名が同じ場合、または同じ SFTP パスを持つ登録ユーザー/匿名ユーザーのインポートがすでに存在する場合。
3. **SFTP フォルダーパス** - ホスト名を含む完全なフォルダーパス。

上記のいずれか 1 つでも異なれば、そのインポートは一意と見なされます。

# よくある質問

<Accordion title="インポートが失敗しました。何が問題だったかを確認するにはどうすればよいですか？">

右側の省略記号をクリックし、**View** をクリックしてインポートの詳細を確認します。**Failed** ステータスにカーソルを合わせると、理由を確認できます。

</Accordion>
<Accordion title="S3/SFTP フォルダーからファイルを取得する際にエラーが発生した場合はどうなりますか？">

デフォルトでは、失敗した場合にインポートは再試行されません。ただし、失敗時にメールアラートを受け取るように構成できます。

</Accordion>
<Accordion title="スケジュールされたインポートが、最近アーカイブされたセグメントにデータを追加した場合はどうなりますか？">

その場合でも、新しいデータはアーカイブされたセグメントに追加されます。必要に応じてセグメントのアーカイブを解除できます。

</Accordion>
<Accordion title="MoEngage は定期実行で新しいファイルをどのように取得しますか？">

特定のワークスペースのスケジュール実行では、MoEngage はファイル名のプレフィックスに基づいて S3/SFTP フォルダー内で識別されたすべての新しいファイルを取得し、処理します。特定の MoEngage ワークスペースのデータインポートでは、フォルダーの場所とファイル名の組み合わせによってこれらのファイルを一意に識別します。

</Accordion>
<Accordion title="定期的なデータインポートで、以前に処理されたファイルが取得されることはありますか？">

いいえ。一度処理されたファイルは、ファイル名が同じで同じフォルダーの場所にある場合、再度処理されることはありません。ただし、同じファイルが別のフォルダーの場所にも配置されている場合、新しいフォルダーの場所が構成された MoEngage の新しいデータインポート設定によってそのファイルが取得されます。

</Accordion>
<Accordion title="1 つの CSV ファイルにユーザーデータとイベントデータの両方を含めることはできますか？">

いいえ。MoEngage ワークスペースダッシュボードでのデータインポートは、ユーザーデータとイベントデータで個別に設定する必要があるため、ファイルにはユーザー属性データまたはイベントデータのいずれかのみを含める必要があります。

</Accordion>
<Accordion title="実行中のインポートを停止することはできますか？">

インポート処理が開始されると、途中で停止することはできません。これは、データが複数のステップを経て処理されるため、中断すると結果が不完全または不整合になる可能性があるためです。現在のインポートが完了するまで待つことをお勧めします。

</Accordion>
<Accordion title="スケジュールされたインポートの今後の実行を停止するにはどうすればよいですか？">

はい、今後スケジュールされたインポートが自動的に実行されないように停止できます。これを行うには、Data Imports ダッシュボードでインポートスケジュールを見つけ、Actions メニューから「Archive」オプションを選択します。これにより、次回のスケジュール時刻に実行されなくなります。

</Accordion>
<Accordion title="インポートが停止しているように見える場合や、時間がかかっている場合はどうすればよいですか？">

インポートが停止しているように見える場合や、通常より時間がかかっている場合は、待つことをお勧めします。システムにはこのような状況を自動的に処理するチェック機能があり、必要に応じて再試行します。処理中に同じインポートを手動で再度開始すると競合が発生し、元のインポートが正常に完了しなくなる可能性があります。

</Accordion>

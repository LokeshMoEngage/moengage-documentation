インストールステータスは、特定のユーザーに対してアプリケーションがインストールされているかどうかを示し、ユーザーレベルで基本的なインストール情報を提供します。

# インストールステータスの追跡

MoEngage は、複数の方法でインストールステータスを追跡します。

- SDK 統合を通じて [Install/Uninstall/Reinstall トラッキング](/ja/user-guide/getting-started/integration-validation/installuninstallreinstall-integration-validation)を設定する
- ユーザーのデバイスに送信されたサイレントプッシュメッセージに対して、Firebase Cloud Messaging (FCM) または Apple Push Notification Service (APNs) から、アプリがインストールされているかどうかを示すシグナルが返されるタイミングを監視する。なお、サイレントプッシュ通知は Apple デバイスではサポートされなくなりました。ダッシュボードの設定ページから[このトラッキングを有効化](/ja/user-guide/settings/analytics/uninstall-tracking)できます。
- リアルタイムのアンインストールトラッキングのために、MoEngage SDK で [Firebase 統合](https://developers.moengage.com/hc/en-us/articles/4470336528532-Real-time-Uninstall-Tracking#01GWGFTGZ8K4MNMC657R6WWWPW)を設定する

MoEngage がユーザーによるアプリのインストールを検出した場合、インストールステータスは true とマークされます。それ以外の場合は false とマークされます。複数のデバイスを持つユーザーの場合、少なくとも 1 つのデバイスにインストールされていれば、インストールステータスは true になります。

# インストールステータスが不正確になる要因

インストールステータスの追跡が不正確になる要因がいくつかあります。

- **不正確なフィードバックの詳細** - サイレントプッシュメッセージは通常、APNS や FCM などの通知プロバイダーのフィードバックサービスによって追跡されます。これらのフィードバックサービスは通常、プッシュメッセージを配信できない場合（プッシュバウンスとも呼ばれます）にアプリケーションに通知し、これは顧客がアプリケーションをアンインストールしたことを示します。フィードバックはアプリがプッシュメッセージの配信を試みたときにのみ生成されるため、ユーザーがアンインストールした正確なタイミングを知ることはほぼ不可能です。
- **iOS 10 でのサイレントプッシュ通知の非推奨化** - iOS 10 でサイレントプッシュ通知が非推奨になったことで、ユーザーレベルでのアンインストールの追跡が困難になっています。以前はサイレントプッシュ通知を使用して、フィードバックが配信失敗を示すことでユーザーがアプリをアンインストールしたことを検出していました。しかし、非推奨化に伴い、アンインストールを正確に追跡することはますます困難になっています。
- **アンインストール前のユーザーのログアウト** - ユーザーがアプリをアンインストールする前にログアウトすると、アンインストールの追跡が不正確になる可能性があります。これは、ユーザーがアプリをアクティブに使用しなくなっても、アプリがデバイスにインストールされたままであるために発生します。アンインストールの追跡は通常、アプリがアンインストールされたためにメッセージを配信できない場合にアプリに通知するプッシュ通知サービスからのフィードバックに依存しています。しかし、ユーザーがアンインストールせずにログアウトした場合、アプリはプッシュ通知を受信し続けるため、実際のアンインストールとログアウトしたセッションを区別することが困難になります。
- **デバイスのアーカイブ** - ユーザーのインストールステータスはアーカイブ後も最大 60 日間保持されるため、デバイスがアーカイブされるとアンインストールの追跡が不正確になる可能性があります。デバイスがアーカイブされるということは、そのデバイスがアクティブに使用されなくなった、またはユーザーのアカウントに接続されなくなったことを意味します。しかし、アンインストール追跡の仕組みはアーカイブされたステータスを認識せず、ユーザーのインストールステータスを TRUE のまま保持し続ける場合があります。その結果、ユーザーが実際にはアプリをアンインストールしていても、アクティブなインストールがあると見なされ、アンインストールの追跡が不正確になります。

インストールステータスを分析し、ユーザーエンゲージメントやリテンションの指標を正確に解釈する際には、これらの制限を考慮することが重要です。

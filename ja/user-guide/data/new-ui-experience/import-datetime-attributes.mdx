# はじめに

この記事では、[Data Warehouses](/ja/user-guide/data/imports/setting-up-a-data-warehouse-import) から MoEngage に日時属性を正しくインポートする方法について説明します。これにより、セグメンテーションクエリを正確に構築でき、よりパーソナライズされたターゲティングと分析が可能になります。

# ステップ 1: データを準備する

MoEngage が想定する形式に従ってデータを準備する方法については、[こちらのドキュメント](/ja/user-guide/data/imports/overview-imports)を参照してください。サポートされている日時形式の一覧は、[こちらのセクション](/ja/user-guide/data/imports/overview-imports)に記載されています。

# ステップ 2: サンプルファイルをアップロードする

属性を日時として正しくインポートするには、これらの属性の Allowed Datetime タイプを MoEngage に通知する必要があります。まず、次の列を含むサンプルの .csv ファイルを作成します。

Table

| 列名 | 値 |
| --- | --- |
| `id` | サンプルのユーザー ID。一意のユーザー識別子を指定してください。 |
| `` | 属性のサンプル値。 |
| `` | 属性のサンプル値。 |

__PROTECTED_0__

## ユースケースの例

この例では、次の日時型の属性をインポートします。

- 形式が `YYYY-MM-DD` の `my_birthday`
- 形式が `YYYY-MM-DD hh:mm:ss` の `my_order_time`
- 形式が `YYYY-MM-DDThh:mm:ssTZD` の `my_user_creation_time`

この例のサンプルファイルを[ダウンロード](https://dashboard-static-assets.s3.amazonaws.com/partners-integration-ui/app-marketplace-public/helpdoc/Import-Datetime-Attr-Example.csv)して、手順に沿って進めることができます。

# ステップ 3: サンプルファイルをアップロードする

すべての日時属性とその想定形式を含むサンプルファイルの準備ができたら、次の手順を実行します。

1. MoEngage のサイドバーメニューで、**Segment** メニュー項目 <img alt="Screenshot 2025-06-16 at 3.25.14 PM.png"  src="/images/moengage_9eed76.png"  /> にカーソルを合わせます。**Segment** メニューが表示されます。
2. **User Imports** をクリックします。  
    <img alt="user imports nw.png"  src="/images/moengage_3edd9f.png"  />
3. User imports ページで、**Import users** をクリックします。
4. **Import name** ボックスに、インポートを識別できる名前を入力します。
5. **Select user** type で、**Registered users** を選択します。
6. サンプルファイルを選択します。**Preview file** をクリックして、すべてのデータが正しく読み込まれているかを確認します。  
    <img  src="/images/moengage_c6eb65.png"  />
7. **Next** をクリックしてマッピングに進みます。
8. 最初の列をユーザー識別子としてマークします。
9. 各日時属性について、リストから **+ Create new** **attribute** をクリックし、MoEngage に新しい属性として追加します。  
    <img  src="/images/moengage_bf9aee.png"  />
10. **Data type** リストで **Date time** を選択し、**Date time format** リストで正しい日時形式を選択します。これらは自動的に取得されるよう試みられます。  
     <img  src="/images/moengage_ed9ef8.png"  />
11. すべての属性を作成してそのタイプを指定したら、インポートの準備が整います。  
     <img src="/images/moengage_911eb0.png" />
12. **Next** をクリックして続行します。
13. インポート頻度として **As soon as possible** を選択し、インポートをスケジュールします。
14. ファイルがアップロードされ、インポートが試行されます。

# ステップ 4: これらの属性のデータタイプを固定する

<Info>
ステータス、表示設定、許可されるデータタイプ、表示名、説明の変更などの操作を実行できるのは、アカウントの Admin のみです。
</Info>

インポートが完了したら、次の手順を実行します。

1. MoEngage ダッシュボードの左側のナビゲーションメニューで、**Segments** をクリックし、[Data Management](/ja/user-guide/settings/data-management/overview-data-management) をクリックします。
2. この[ドキュメント](/ja/user-guide/settings/data-management/overview-data-management)の手順を実行して、新しく作成した属性の許可されるデータタイプを設定します。
3. 各属性で **datetime** を選択してください。これは User Attributes と Event Attributes の両方に対して実行する必要があります。
4. 各属性に正しいデータタイプを固定すると、それらは日時として MoEngage に正しく取り込まれます。

# ステップ 5: データをインポートする

これで、MoEngage にデータをインポートする準備が整いました。新しく作成した属性をそれぞれ対応する列にマッピングしてください。

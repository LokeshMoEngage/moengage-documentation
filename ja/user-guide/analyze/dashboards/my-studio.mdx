世界が進化し続けるにつれて、データと分析がもたらす課題と機会も変化しています。MoEngage の **My Studio** を使用すれば、データ管理の煩わしさから解放され、効率的で生産性の高いワークフローを実現できます。予期しない中断による進捗の喪失、分析に基づく意思決定の遅れ、大量のレポートの中で全体像を見失うことを心配する必要はもうありません。**My Studio** には、保存した分析を 1 か所に保管できるさまざまな機能が用意されており、作業を簡単に取り出して中断したところから再開できます。人気のある分析を探索するプロセスを効率化すると同時に、プロジェクトのインスピレーションの源としても役立ちます。

# ユースケース

- My Studio は、企業が主要業績評価指標(KPI)を常に把握するうえで重要な役割を果たします。個人用のスペースを使用して、重要な指標とレポートをすべて一元管理するハブを作成できます。
- 分析の検索、並べ替え、フィルタリングがより簡単かつ効率的になり、好みや優先順位に応じて作業を整理できます。
- My Studio のコラボレーション機能を使用すると、ディスカッションを促進し、アイデアを共有し、目標の達成に向けて協力して取り組むことができます。チームが常に情報を把握し、積極的に関与し、会社の全体的なビジョンと足並みをそろえられるようになります。

# My Studio への移動

保存した分析を作成する前に、まず MoEngage ダッシュボードで **My Studio** の場所を確認しましょう。

1. MoEngage ダッシュボードにログインし、左側のメニューバーに移動します。
2. **Analyse** をクリックし、**My Studio** を選択します。
   <img
     alt="my studio.png"
     src="/images/moengage_4f3bab.png"
     style={{ width:"34%" }}
   />
3. My Studio ダッシュボードに入ると、保存したすべての分析が次の詳細とともに表示されます。
   | Name | Description | Last Updated | Analyses Type |
   | --- | --- | --- | --- |
   | 分析を保存したユーザーの名前。 | 分析の簡単な説明。 | 分析が最後に更新された日時。 | 分析のカテゴリ:  - Users - Behavior - Funnels - Retention - Session and source - User paths |
   検索バーを使用して保存した分析を検索したり、分析タイプに基づいて結果をフィルタリングしたりできます。

# 保存した分析

分析を実行し、後で再度確認すると思われる場合、MoEngage では分析を **My Studio** に保存することをお勧めします。保存するには、**Save** ドロップダウンをクリックし、保存先のワークスペース(この場合は Studio)を選択します。このセクションでは、**Users** 分析を保存する例を取り上げます。

保存した分析を作成するには、次の手順に従います。

1. MoEngage ダッシュボードにログインし、左側のメニューバーに移動します。
2. **Analyse** で、分析タイプとして **Users** を選択します。
   <img
     alt="users.png"
     src="/images/moengage_2bf37b.png"
     style={{ width:"31%" }}
   />
3. **Select user property** ドロップダウンから分析に適したユーザープロパティを選択し、**APPLY** をクリックしてイベントを実行します。
   <img
     alt="user property event.png"
     src="/images/moengage_be3e02.png"
     style={{ width:"51%" }}
   />
   **APPLY** をクリックすると、分析データをグラフ形式と表形式の両方で確認できます。
   ![clickapply.png](/images/moengage_9d4079.png)
4. **Save** ドロップダウンをクリックし、**Save to Studio** を選択します。
   <img
     alt="save to studio.png"
     src="/images/moengage_a33edc.png"
     style={{ width:"39%" }}
   />
5. ポップアップで分析の名前と説明を入力し、**Save** をクリックして確定します。
   <img
     alt="analysis name.png"
     src="/images/moengage_213ac3.png"
     style={{ width:"50%" }}
   />
   "Analysis saved successfully" という成功メッセージが表示されます。
6. MoEngage ダッシュボードの **My Studio** に移動して、新しく保存した分析を表示します。
   ![demo analysis.png](/images/moengage_601fe9.png)

# 保存した分析の共有

<Info>
  この機能は、MoEngage Analytics の Product Analytics パッケージでのみ利用できます。アカウントで有効にするには、MoEngage のカスタマーサクセスマネージャー(CSM)またはサポートチームにお問い合わせください。
</Info>

分析を My Studio に保存したら、チームメンバーや外部のオーディエンスと共有して、コラボレーションや知識の共有を促進できます。この機能では、分析を閲覧または編集できるユーザーを詳細に制御できます。

My Studio のリストビューから分析を共有するには、次の手順を実行します。

1. My Studio の **Saved Analysis** タブで、共有したい分析をリストから探します。
2. 分析名の横にある縦の省略記号(...)をクリックします。
   ![Screenshot 2025-04-22 at 4.24.17 PM.png](/images/moengage_b9a6d1.png)
3. リストから **Share** を選択します。**Share** 設定ウィンドウが表示されます。
   ![Screenshot 2025-04-22 at 4.25.31 PM.png](/images/moengage_623a12.png)
4. 共有設定を構成します。詳細については、以下の[共有設定の構成](/ja/user-guide/analyze/dashboards/my-studio#configuring-sharing-settings)を参照してください。
   ![2025-04-22\_16-40-59.png](/images/moengage_8fcaf6.png)

または、分析を保存した直後や、分析の表示/編集中に共有することもできます。分析ページから共有するには、ページヘッダーの右上にある **Share** ボタンをクリックします。

![Screenshot 2025-04-22 at 4.42.05 PM.png](/images/moengage_242e3a.png)

## 共有設定の構成

共有を開始する方法にかかわらず、同じポップアップウィンドウが表示され、アクセス権限を設定できます。

### 一般アクセスの共有

共有可能なリンクを受け取ったすべてのユーザーに対して、一般的なアクセス権限を設定できます。設定するには、次の手順を実行します。

1. **Copy Link** ボタンをクリックして、一意で安全な共有可能なリンクをクリップボードにコピーします。
   ![2025-04-22\_16-38-24.png](/images/moengage_0dac0f.png)
2. 一般アクセスの Edit または View 権限を設定します。詳細については、以下の[権限について](/ja/user-guide/analyze/dashboards/my-studio#understanding-permissions)を参照してください。

このリンクをメール、チャット、またはその他のチャネルで共有します。

### 特定のメンバーへのアクセス

より細かく制御するために、特定の個人をメールで招待し、それぞれのアクセスレベルを個別に設定できます。特定のメンバーを招待するには、**Share** ポップアップウィンドウで次の手順を実行します。

1. **Share access to** リストから、分析を共有するメンバーのメールアドレスを選択します。
2. **Access type** リストから、指定したユーザーに付与する権限レベル(**View** または **Edit**)を選択します。
   ![00000000.gif](/images/moengage_e4bee6.png)
3. **Share** をクリックします。

招待されたユーザーには、共有された分析への直接リンクとチャートのプレビューを含むメール通知が届きます。ユーザーの名前と権限は、アクセス権を持つユーザーのリストに表示されます。

## 権限について

### Edit アクセス

**Edit** アクセスを付与されたユーザーには、次の権限があります。

- **分析の変更:** 分析のパラメーターと設定を変更できます。
- **変更の保存:** 分析の更新を保存できます。変更を保存すると、すべてのコラボレーターにとって元の分析が変更されることに注意してください。元のバージョンを保持したい場合は、**Save as a new analysis** の使用を検討してください。
- **他のユーザーの招待:** 追加のユーザーと分析を共有し、View または Edit のいずれかの権限を付与できます。
- **分析の削除:** 分析を完全に削除できます。削除の前に確認のプロンプトが表示されます。コラボレーターが分析を削除した場合、元の所有者にメールで通知されます。

### View アクセス

**View** アクセスを付与されたユーザーには、次の権限があります。

- **分析の閲覧:** 分析の設定と結果を確認し、可視化を操作できます。
- **編集不可:** 分析の設定に変更を加えたり、変更を保存したりすることはできません。
- **他のユーザーの招待不可:** 閲覧専用ユーザーの場合、分析をさらに共有するオプションは無効になっています。
- **アクセスのリクエスト(間接的な共有):** View アクセスを持つユーザーが、権限を持たないユーザーと分析の URL を共有した場合、受信者はアクセスをリクエストできます。このリクエストは、保存した分析の元の所有者に送信されます。

# 下書き

MoEngage Analytics で分析を実行すると、進捗が下書きとして自動的に保存されます。これらの下書きには、**My Studio** ページの **Drafts** タブから簡単にアクセスできます。このタブは進行中のすべての分析を一元管理する場所として機能し、中断したところから簡単に作業を再開できます。

![Screenshot 2025-03-17 at 3.59.01 PM.png](/images/moengage_6cb1ff.png)

自動保存された各下書きについて、説明、最終更新日、有効期限、分析タイプを確認できます。

<Info>
  最終更新日から 30 日以上経過した下書きの分析は、自動的に削除されます。
</Info>

## 最近の項目

</Info>

# 分析の表示、編集、削除

## 表示/編集

Studio で、表示または編集したい分析の行をクリックするか、縦の省略記号をクリックして **View/Edit** を選択します。

保存した分析を編集した後は、**Save** ドロップダウンから **Save as a new analysis** を選択する必要があります。これにより、同じ分析の新しい下書きが生成され、Studio に保存されます。

<img
  src="/images/moengage_7ff2aa.png"
  alt="save as new analysis.png"
  style={{ width:"37%" }}
/>

<Warning>
  分析は、指定したイベントを実行し、分析に一意の名前を付けた場合にのみ保存されます。

  ![new name.png](/images/moengage_5b42e5.png)
</Warning>

## 削除

My Studio ダッシュボードで、削除したい分析の縦の省略記号をクリックし、**Delete** を選択します。

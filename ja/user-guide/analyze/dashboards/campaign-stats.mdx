# Campaign Stats

このダッシュボードでは、MoEngage のさまざまなチャネルにわたるすべてのキャンペーンを包括的に把握できます。キャンペーンのパフォーマンスを概観し、重要な指標をトラッキングできます。全体像を把握するための集計データに加えて、個々のキャンペーンに関連する特定の指標にもアクセスできます。

まず、このダッシュボードには、キャンペーンに不可欠な一連の KPI が表示されます。

<img alt="Screenshot 2025-01-20 at 10.35.47 AM.png" src="/images/moengage_524ce7.png" />

## 全体のパフォーマンス

**Overall performance** セクションには、すべてのアクティブなチャネルのデータが 1 つのビューにまとめて表示されます。ここでは、さまざまな指標にわたって異なるチャネルを比較できます。データはチャートビューとテーブルビューの両方で利用できます。表示される指標はチャネルによって異なる場合があります。

<img alt="Screenshot 2025-01-20 at 10.38.07 AM.png" src="/images/moengage_6123d9.png" />

各チャネルで利用可能な指標については、[Metric and channel types](/ja/user-guide/analyze/dashboards/key-metrics) を参照してください。

## チャネルのパフォーマンス

ダッシュボードのこのセクションでは、チャネル固有の分析が表示され、各チャネルに関連する指標を測定できます。データはチャート形式とテーブル形式の両方で利用できます。

さらに、視覚的な分析を強化するために、右側に **Campaign summary** カードがあります。このカードには、そのチャネル内のキャンペーンの総数と、関連する各指標の最高値と最低値の概要が表示されます。

<img alt="2025-01-20_10-45-41 (1).gif" src="/images/moengage_6f7ac3.png" />

### 指標とチャネルタイプ

各チャネルで表示される指標は次のとおりです。

| チャネル | 指標 |
| --- | --- |
| Push | Sent、Impression、Click、Conversion、Revenue、CTR、CVR、Impression rate |
| Email | Sent、Delivered、Click、Conversion、Revenue、CTR、CVR、Delivery rate |
| SMS | Sent、Delivered、Click、Conversion、Revenue、CTR、CVR、Delivery rate |
| Cards | Sent、Impression、Delivered、Click、Conversion、Revenue、CTR、CVR、Impression rate、Delivery rate |
| Flows | Total trips、Engaged trips、Converted trips、CVR |
| In-App | Impression、Click、Conversion、Revenue、CTR、CVR |
| On-Site | Impression、Click、Conversion、Revenue、CTR、CVR |
| Connectors | Attempted、Sent、Conversion、Revenue、CVR、Success rate |
| Web personalization | Impression、Click、Conversion、Revenue、CTR、CVR |
| FB audience | Eligible、Attempted、Synced、Conversion、User attempted、User synced |

各指標の詳細については、[Campaigns and Channels](/ja/user-guide/campaigns-and-channels) の Analyze セクションを参照してください。

## 詳細設定

### フィルターと期間

**Campaign stats** ダッシュボードでは、アトリビューションタイプに基づいてデータをフィルタリングし、期間を設定できます。フィルターを使用するには、次の手順に従います。

1. 表示されたリストからアトリビューションタイプを選択します。アトリビューションタイプの詳細については、Campaigns and Channels の Analyze セクションを参照してください。
2. 目的の期間を設定し、**Apply** をクリックします。選択したフィルターに従ってダッシュボードが更新され、関連するデータが表示されます。

<img alt="2025-01-20_11-10-35 (1).gif" src="/images/moengage_201c80.png" />

### ビューの切り替え

**Overall performance** ダッシュボードでは、ダッシュボードを可視化するための次のオプションがあります。

- チャートビューとテーブルビューを切り替えて、データをより詳細に確認できます。  
   <img alt="2025-01-20_11-24-45 (1).gif" src="/images/moengage_cdba70.png" />
- テーブルビューでは、テーブルを昇順および降順に並べ替えることができます。  
   <img alt="2025-01-20_11-27-34 (1).gif" src="/images/moengage_79f68e.png" />
- 各チャネルについて、データを折れ線グラフまたは縦棒グラフで可視化できます。  
   <img alt="2025-01-20_12-00-34 (1).gif" src="/images/moengage_f67dd3.png" />
- これらのチャートは、時間別、日別、週別、月別の粒度で表示できます。  
   <img alt="Screenshot 2025-01-20 at 12.03.12 PM.png" src="/images/moengage_0f5734.png" />

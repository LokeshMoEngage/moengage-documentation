# 概要

これらのダッシュボードを使用すると、あらゆるプロダクトやマーケティングのニーズに合わせたカスタム分析チャートやレポートを追加できます。このダッシュボードには複数のチャートやレポートを追加し、同時にモニタリングできます。

カスタムダッシュボードは次の 2 つの方法で作成できます。

- [プライベートダッシュボード](/ja/user-guide/analyze/dashboards/custom-dashboards#private-dashboard)
- [ワークスペースダッシュボード](/ja/user-guide/analyze/dashboards/custom-dashboards#workspace-dashboard)

## プライベートダッシュボード

<Info>
  この機能は、MoEngage Analytics の Product Analytics パッケージでのみ利用できます。アカウントで有効にするには、MoEngage のカスタマーサクセスマネージャー(CSM)またはサポートチームにお問い合わせください。
</Info>

プライベートダッシュボードには組み込みのアクセス制御があり、ダッシュボードの所有者と特定の権限を持つメンバーがダッシュボードにアクセスできます。

表示する情報にアクセス制限や機密性が必要な場合は、プライベートダッシュボードを作成してください。プライベートダッシュボードは、次のようなシナリオで使用します。

- **機密データ**: ダッシュボードに財務データ、戦略計画、個人のパフォーマンス指標、クライアント固有の詳細などの機密情報が含まれている場合、プライベートダッシュボードにより、承認されたユーザーのみがアクセスできるようになります。
- **作成途中**: ダッシュボードがまだ開発中または改良中の場合は、プライベートにすることで、完成して承認されるまで、より多くのオーディエンスによる早すぎる閲覧や使用を防ぐことができます。
- **対象を絞ったコラボレーション**: ダッシュボードが特定のチーム、プロジェクトグループ、または一連のステークホルダー向けである場合、プライベートダッシュボードを使用すると、所有者は関連する個人にのみアクセス権を付与でき、情報が意図したオーディエンスに確実に届きます。ダッシュボードを変更する必要があるコラボレーターには _Editor_、読み取り専用アクセスのみが必要なユーザーには _Viewer_ など、異なるロールを割り当てることができます。
- **個人的な使用**: 個人的なトラッキング、目標のモニタリング、または個人的な分析のために作成したダッシュボードは、プライベートにしておくことで個人データを安全に保つことができます。

## ワークスペースダッシュボード

ワークスペースダッシュボードは、デフォルトでワークスペースへのアクセス権を持つすべてのユーザーが閲覧できます。ダッシュボードの所有者は、全員に編集権限を付与することもできます。この場合、ワークスペースへのアクセス権を持つ全員がダッシュボードを編集できます。

ダッシュボードの所有者は、編集アクセスを特定のユーザーに制限することもできます。これにより、それらのユーザーのみがダッシュボードを編集し、新しいチャートを追加できるようになります。

表示する情報が、特定のワークスペースまたはコラボレーショングループのすべてのメンバーに関連し、共有することを意図している場合は、ワークスペースダッシュボードを作成してください。ワークスペースダッシュボードを使用できるシナリオには、次のようなものがあります。

- **チーム/グループ全体での可視性**: ダッシュボードのコンテンツ(パフォーマンス、プロジェクトの最新情報、共有リソースなど)に、閲覧のための個別の招待を必要とせずに、ワークスペース内の全員が簡単にアクセスできるようにする必要がある場合に、このタイプのダッシュボードを使用します。
- **デフォルトでの透明性**: デフォルトの権限をすべてのワークスペースメンバーに対する閲覧アクセスにしたい場合は、このタイプのダッシュボードが最適な選択肢です。
- **コラボレーション環境**: グループでの取り組みをサポートするダッシュボードや、すべてのメンバーが同じ情報を見ることでメリットが得られる指標に最適です。
- **柔軟な編集制御**: ワークスペースメンバーはデフォルトで閲覧できますが、所有者は編集権限の制御を保持します。

ワークスペースダッシュボードのユーザー権限の定義は次のとおりです。

- **デフォルトのアクセス**:
  - デフォルトでは、プライベートダッシュボードを変更できるのは所有者のみです。
  - ワークスペースダッシュボードの場合、ワークスペースに追加された全員がデフォルトで閲覧アクセスを持ちます。
- **Owner**: ダッシュボードを作成したユーザーは、作成、変更、削除、ユーザー管理を含む完全な制御権を持ちます。ダッシュボードの所有者は、ダッシュボード全体のアクセス権限を設定できます。これには、View for all、Edit for all、Edit for specific users が含まれます。
- **Editors**: ダッシュボードの所有者が別のユーザーをコラボレーションまたは編集に招待すると、そのユーザーにこのアクセス権が付与されます。Editor は次のことができます。
  - ダッシュボードを編集する。
  - 新しい Editor と Viewer をダッシュボードに招待する。
  - ユーザー権限を管理し、別の Editor の権限を Viewer に、または Viewer の権限を Editor に変更する。
- **Viewers**: Viewer は、アクセス権が付与されたダッシュボードへの読み取り専用アクセス権を持ちます。編集アクセスをリクエストでき、そのリクエストはメールでダッシュボードの所有者に送信されます。新しいユーザーをダッシュボードの閲覧や編集に招待することはできません。

<Info>
  ダッシュボードを削除できるのは所有者のみです。
</Info>

# ダッシュボードの作成

カスタムダッシュボードは、次の 2 つの方法で追加できます。

### ナビゲーションバーから

1. 左側のナビゲーションサイドバーから **\+ Create New** をクリックし、**Dashboard** をクリックします。**Create dashboard** ウィンドウが表示されます。
2. **Dashboard name** フィールドに、ダッシュボードの名前を入力します。
3. **Dashboard visibility** セクションで、ダッシュボードへのアクセス方法を選択します。

   ![2025-04-04_16-59-39 (1).gif](/images/moengage_61dba6.png)
4. 公開範囲のタイプを選択したら、**Create** をクリックします。

### 分析から

MoEngage Analytics の Users、Behavior、Funnels、Retention、Session and Source セクションで実行したすべての分析は、テーブルやチャートの形式でカスタムダッシュボードに追加できます。

1. ダッシュボードにチャートまたはテーブルを追加するには、分析画面の右上にある **Save** をクリックし、必要に応じて **Save chart to the dashboard** または **Save table to the dashboard** を選択します。
2. 分析は、リストから既存のダッシュボードに保存するか、新しいダッシュボードを作成して保存できます。目的のオプションを選択します。
3. それぞれのフィールドに **Chart name** と **Description** を入力します。
4. **Create new** を選択した場合は、目的の **Dashboard visibility** とアクセス権限を選択します。
5. **Save** をクリックして確定します。

   ![2025-04-04_17-14-07 (1).gif](/images/moengage_19cca0.png)

Customer Journey Analytics(CJA)パッケージでは最大 10 個、Product Analytics(PA)パッケージでは最大 300 個のカスタムダッシュボードを作成でき、各ダッシュボードには最大 20 個のチャートを組み込むことができます。

# ダッシュボードの管理

ダッシュボードは完全に自由に管理できます。MoEngage Analytics には、ダッシュボードのエクスペリエンスを向上させるさまざまな機能が用意されています。

## ダッシュボードを共有する

ダッシュボードを共有するには、次の手順を実行します。

1. 右上の **Share** ボタンをクリックします。

   ![Screenshot 2025-10-06 at 11.52.59 AM.png](/images/moengage_537c13.png)
2. 目的の **Dashboard visibility** タイプを選択します。**Workspace** ダッシュボードと **Private** ダッシュボードの両方を共有できます。

   <img
     alt="2025-10-01_12-15-51.png"
     src="/images/moengage_d1c23c.png"
     style={{ width:"59%" }}
   />
3. **Share access to** セクションで、ダッシュボードを共有するユーザーのメールアドレスを入力します。最大 50 件のメールアドレスを入力できます。

   <img
     alt="2025-10-01_12-30-05.png"
     src="/images/moengage_17d088.png"
     style={{ width:"59%" }}
   />
4. **Access type** ドロップダウンから、これらのユーザーに付与するアクセス権限として **Viewer** または **Editor** を選択します。

   <img
     alt="2025-10-01_12-23-51.png"
     src="/images/moengage_bdb65f.png"
     style={{ width:"57%" }}
   />
5. **Share** をクリックします。ダッシュボードが選択したユーザーと共有され、ユーザーにメール通知が送信されます。
6. ダッシュボードを共有した後、各ユーザーのアクセスを管理できます。次の操作が可能です。
   - 権限レベル(Edit または View)を変更する
   - ダッシュボードの所有権を移譲する
   - アクセスを完全に削除する

## ダッシュボードフィルター

フィルターを適用するには、次の手順に従います。

1. **Dashboard Filter** セクションをクリックし、**Duration** ボックスで期間を選択します。
2. **\+ Filter users** をクリックして目的のカスタムセグメントでフィルタリングするか、セグメントを作成し、**Apply** をクリックします。

   \\

   ![Dashboard filters.gif](/images/moengage_9e370c.png)

   **Compare to past** を使用すると、時系列の比較を実行できます。

   ![2025-01-20_14-44-00 (1).gif](/images/moengage_91641b.png)

選択したフィルターは、ダッシュボード内のすべてのチャートに適用されます。

## 更新

ダッシュボードを開くと、すべてのチャートが自動的に更新され、結果はその日の終わりまで保存されます。個々のチャートはいつでも更新でき、新しい分析をクエリできます。更新ボタンをクリックすると、ダッシュボードはチャートのクエリを再実行し、分析に利用可能な最新のデータを表示します。更新ボタンの横には、最後の更新からの経過時間を示すテキストが表示されます。

![2025-01-20_14-49-45 (1).gif](/images/moengage_486d48.png)

## 編集

目的の分析に合わせて、チャートを変更したり、クエリパラメーターを調整したりできます。

分析レポートを編集するには、チャート領域をクリックするか、**View / Edit** をクリックします。分析の編集機能を使用すると、それぞれの Behavior、Funnel、Retention、または Session and Source ページに移動し、すべての分析パラメーターがあらかじめ読み込まれます。

![2025-01-20_15-22-34 (1).gif](/images/moengage_c28cac.png)

ここでは、次の操作が可能です。

- チャート名とチャートの説明を変更する。
- クエリパラメーター(イベントとフィルター)を変更し、分析を保存する。
- **Save as** を使用して、同じ分析または変更した分析を別のダッシュボードに保存する。
- チャート分析をあるダッシュボードから別のダッシュボードに移動する。
- **Copy link** または **Email link** を使用して分析を共有する。

## サイズ変更と位置変更

分析の表示は、半幅と全幅の 2 つのサイズに調整できます。そのためには、省略記号メニューで **Resize** をクリックします。

チャートのヘッダーバーをクリックしてドラッグし、ダッシュボード上の好きな位置にドロップすることで、分析の位置を変更することもできます。チャートのヘッダーにカーソルを合わせると、カーソルが変化し、ヘッダーをつかんで移動できることが示されます。

![Chart Resize.gif](/images/moengage_4dcf52.png)

## チャートとテーブルの表示モード

ダッシュボードのチャートには、表示されたデータに関する詳細なインサイトを提供する主要業績評価指標(KPI)が含まれています。これらの KPI には、特定の日または週のデータポイント、すべてのデータポイントの平均、前のデータポイントと最初のデータポイントの両方と比較した変化率など、さまざまな関連情報が反映されます。この情報を理解するには、KPI の下にある凡例を参照してください。

![KPI Legends.png](/images/moengage_8c6921.png)

チャートで KPI が利用可能な場合、個々の分析には 5 つの異なる表示モードがあります。

![Chart Views.gif](/images/moengage_c909f4.png)

- **Chart**: このオプションでは、より深いインサイトを得るためのデータの可視化が提供されます。
- **Chart & KPI**: このオプションでは、包括的な情報として、チャートレポートの視覚的なインサイトとクイック分析が提供されます。
- **KPI**: このオプションでは、チャートレポートの全体的な分析と、チャートで利用可能なデータを使用して計算された包括的な情報が提供されます。
- **Table**: このオプションでは、表形式のビューを取得し、データを CSV 形式でダウンロードすることもできます。
- **Table Transposed view**: このオプションでは、テーブルの縦方向と横方向を入れ替えて、好みの形式でテーブルを表示および共有できます。

## ダッシュボードを購読する

ダッシュボードを購読すると、ダッシュボードのスナップショットをメールで受け取ることができます。この機能を使用すると、ダッシュボードの購読を通じて、組織内外のユーザーとカスタムダッシュボードを共有できます。選択したダッシュボードについて、これらのメールレポートを受信する頻度を設定することもできます。

<Note>
  1 つのワークスペースで作成できるダッシュボードの購読は、Product Analytics パッケージでは最大 25 件、CJA パッケージでは最大 10 件です。
</Note>

購読するには、次の手順に従います。

1. 上部にある Subscribe アイコンをクリックし、**Subscribe to the Dashboard** をクリックします。
2. **Subscribe to the Dashboard** ウィンドウの **Send report to field** に、メールレポートの送信先のメールアドレスを入力または貼り付けます。受信者のリストはカンマ区切りのリストとして追加されます。各購読には最大 50 人のメール受信者を追加できます。\
   未登録のユーザーの場合、メールドメインをホワイトリストに登録する必要があります。詳細については、[Manage Subscription Domain Whitelisting](/ja/user-guide/analyze/dashboards/custom-dashboards#manage-subscription-domain-whitelisting) を参照してください。

   ![CreateSub.gif](/images/moengage_012290.png)
3. **Frequency of sending** **reports** セクションを設定して、特定の日時にダッシュボードレポートを送信します。

   ![Screenshot 2025-01-20 at 3.43.19 PM.png](/images/moengage_dd91fb.png)
4. **Subscribe** をクリックして購読を作成します。

## 購読の管理

既存の購読を管理するには、次の手順を実行します。

1. **Settings** \> **Reports and Alerts** \>**Dashboard Subscriptions** に移動します。ダッシュボードのすべての購読のリストが表示されます。
2. メールアドレスまたはダッシュボード名で購読を検索します。
3. 購読を展開して、購読者と購読解除者のリストを表示します。

### 新しい購読の編集または削除

既存の購読を編集または削除するには、<Icon icon="ellipsis-vertical" size={32} /> をクリックして購読を編集または削除します。

### ダッシュボードの購読を解除する

ダッシュボードの購読を解除するには、次の 3 つの方法があります。

- **メールに埋め込まれた購読解除リンクをクリックする**: 個々のユーザーの購読が解除されます。
- **購読を編集してメール ID を削除する**: **Dashboard Subscriptions** ページで、1 人または複数のユーザーを削除して、それらのユーザーへの購読の送信を停止できます。
- **購読を削除する**: **Dashboard Subscriptions** ページで購読を削除すると、今後のすべてのメールが停止されます。

### 購読のアクセスと権限

次の表では、購読を管理するためのロールと権限について説明します。

ロールと権限の詳細については、[Access Roles](/ja/user-guide/settings/account/team-management/access-roles) を参照してください。

| 購読を管理するためのアクション   | ロールとアクセス                                                                                                                                                                                                                                          |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 購読の作成                | ダッシュボードへのアクセス権を持つすべてのユーザーロールが購読を作成できます。                                                                                                                                                                               |
| 購読の編集または削除        | - すべてのユーザーロールは、自分が作成した購読を編集または削除できます。 - 他のユーザーロールの購読を編集または削除できるのは、Manager と Administrator のみです。                                                                                           |
| 購読リストへのユーザーの追加 | - すべてのユーザーロールは、MoEngage ダッシュボードに所属するユーザーを購読リストに追加できます。 - MoEngage ダッシュボードに所属していないユーザーを購読リストに追加できるのは、Manager と Administrator のみです(ドメインがホワイトリストに登録されている必要があります)。 |

## 購読ドメインのホワイトリストの管理

ドメインのホワイトリスト登録は、データの機密性の保護に役立ちます。Administrator と Manager は、ダッシュボードの購読に使用するドメインをホワイトリストに登録できます。

![WhitelistDomain.gif](/images/moengage_89c884.png)

ドメインをホワイトリストに登録するには、次の手順を実行します。

1. **Settings** \> **Dashboard Subscriptions** に移動します。
2. **Dashboard Subscriptions** ページで **Create/Manage** をクリックし、**Manage Domain Whitelist** を選択します。
3. **Select email domains to whitelist** フィールドに、ホワイトリストに登録するドメインを入力または貼り付けます。例: abc.com
4. **Update** をクリックして、ドメイン名をホワイトリストに登録します。最大 5 つのドメインをホワイトリストに登録できます。

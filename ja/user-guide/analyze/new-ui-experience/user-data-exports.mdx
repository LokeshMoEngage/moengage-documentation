MoEngage ダッシュボードでは、ユーザー属性をエクスポートできます。目的のユーザーセグメントで絞り込み、ユーザー属性をエクスポートできます。

例:

- エンゲージしていたもののアンインストールしたユーザーのメール ID をエクスポートし、Facebook で再エンゲージメントキャンペーンを実施する。
- 非アクティブなユーザーの電話番号をエクスポートし、再アクティブ化のために SMS を送信する。

## エクスポートの実行

データをエクスポートするには、次の手順を実行します。

1. MoEngage のサイドバーメニューで、**Segment** メニュー項目 <img alt="Screenshot 2025-06-16 at 3.25.14 PM.png"  src="/images/moengage_0bd0b7.png"  /> にカーソルを合わせます。**Segment** メニューが表示されます。
2. **+ New Segment** をクリックします。  
    <img alt="Screenshot 2025-06-13 at 2.52.15 PM.png"   src="/images/moengage_1abdec.png"   />   
   Create segment ページが表示されます。
3. エクスポートするセグメントのクエリを作成して実行します。クエリは Query Results セクションに表示されます。  
    <img alt="query results.png" src="/images/moengage_aa10d3.png" />
4. **Query Results** セクションで特定のクエリをクリックし、**Export users** をクリックします。  
    <img alt="export users.png" src="/images/moengage_f44f76.png" />   
   Export users data ポップアップウィンドウが表示されます。自分のメール ID があらかじめ選択されています。   
    <img alt="export data popup.png"  src="/images/moengage_2519e0.png"  />
5. **File name** フィールドにファイル名を入力します。
6. **User attribute** ドロップダウンリストから、抽出するユーザー属性を選択します。
7. **Export** をクリックします。

<Info>
- エクスポートされたファイルの日付と時刻の属性は、ダッシュボードのタイムゾーンに関係なく、常に UTC で提供されます。
- 個人を特定できる情報（PII）としてマークされたユーザー属性のエクスポートは、MoEngage ダッシュボードで制限されています。[詳細はこちら](/ja/user-guide/data/privacy/personal-data-or-personally-identifiable-information-pii/pii-masking)。
- ユーザーデータのエクスポートのフェアユース制限:  
  エクスポートできるデータポイント数（行数 x 列数）は最大 2,000 万で、これを超えるとエクスポートが失敗する可能性が高くなります。たとえば、次のようなエクスポートが可能です。
  - 2,000 万行 x 1 列、または
  - 400 万行 x 5 列、または
  - 100 万行 x 20 列  
    これらの制限を変更するには、CSM にお問い合わせください。
</Info>

## エクスポートのセキュリティ

ユーザーエクスポートはプライベートなエクスポートサービスです。MoEngage ダッシュボードにアクセスできるユーザーは、指定されたアカウントにログインしている場合に、エクスポートファイルにアクセスできます。MoEngage ダッシュボードまたは指定されたアカウントにログインしていないユーザーは、エクスポートを利用できません。

ユーザーエクスポートのメールとファイルのダウンロードリンクは、エクスポートを生成したユーザーのメールアドレスにのみ送信されます。他のダッシュボードユーザーは、MoEngage ダッシュボードの Data Export ページの User Export タブからこのファイルにアクセスできます。

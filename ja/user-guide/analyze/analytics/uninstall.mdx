アンインストール分析では、アンインストールイベント、またはアプリや Web サイトをアンインストールしたユーザーを可視化します。

アンインストール分析を表示するには、MoEngage Dashboard \> Analyze \> Uninstalls に移動します。

<img
  alt="Menu.png"
  src="/images/moengage_3fa6ba.png"
  style={{ width:"31%" }}
/>

次の 2 種類のアンインストール分析が有効になっています。

**Uninstall Events**: デバイスのアンインストールイベントに焦点を当てます。

**User Uninstalls**: アプリをアンインストールしたユニークユーザーに焦点を当てます。

![Uninstall.png](/images/moengage_cb1238.png)

アンインストール分析を利用するには、アプリの Uninstall Settings が設定されていることを確認してください。詳細については、[Uninstall Settings](/ja/user-guide/settings/analytics/uninstall-tracking) を参照してください。

# User Uninstalls と Uninstall Events の違い

User Uninstalls は、アプリをアンインストールしたユニークユーザーの数を示します。ユーザーが複数のデバイスにアプリをインストールしている場合、そのユーザーはすべてのデバイスからアプリをアンインストールした場合にのみ User Uninstalls にカウントされます。この分析はユーザーレベルであるため、都市、国、セッション数などのユーザー属性でフィルタリングできます。

Uninstall Events は、アプリがアンインストールされた回数を示します。ユーザーがアプリをアンインストールし、再インストールして、再度アンインストールした場合、両方のアンインストール操作が Uninstall Events タブに表示されます。この分析はデバイス上でのユーザーのアクションに基づくため、OS バージョンやデバイスモデルなどのデバイス属性でフィルタリングできます。

# User Uninstalls

User Uninstalls 分析では、どのユーザーがアプリをアンインストールしているかについて、日単位の精度でより深いインサイトが得られます。

次の 2 種類のユーザーアンインストールの可視化を利用できます。

- User Uninstalls By Time
- User Uninstalls By Attribute

## User Uninstalls By Time

User Uninstalls By Time では、次のような日単位の精度の情報が得られます。

- 期間とプラットフォームを指定して、日次、週次、または月次のアンインストール数を表示できます。
- チャートには、設定した期間の総アンインストール数も表示されます。

![useruninstallsbytime.png](/images/moengage_c35dd5.png)

## User Uninstalls By Attribute

User Uninstalls By Attribute では、ユーザー属性でグループ化したさまざまな範囲またはカテゴリの分析が得られます。

- 任意の**文字列型、数値型、またはブール型のユーザー属性**でアンインストールをグループ化できます。
- チャートに表示されるすべてのアンインストールの合計も上部に表示されます。
- **文字列属性**の場合、デフォルトでは、アンインストール数の上位最大 10 個の属性値がグラフに表示されます。
- たとえば、Last Known City の上位 10 件がアンインストール数順に表示されます。
- その他の値のアンインストール数を確認したい場合は、**入力ボックスに属性値を入力**し、**APPLY** をクリックします。

![useruninstallsbyattribute.png](/images/moengage_107c7e.png)

- **数値属性**の場合、グラフには属性値のさまざまな範囲ごとのアンインストール数が表示されます。
- たとえば、No. of Sessions の場合、デフォルトでは 1-1、2-5、6-10、11-50、51-199 の範囲にグループ化されたアンインストール数が表示されます。
- これらの範囲を変更したい場合は、**スライダーのつまみを必要な位置に移動**し、"APPLY" をクリックします。
- スライダーの上限も変更できます。上限の最小値は 10 です。

![Noofsessions.png](/images/moengage_53c3d5.png)

<Info>
  アンインストール数は、利用可能な最新のデータに基づいています。次の理由により、過去のアンインストール数が変更される場合があります。

  - ユーザーがアプリをアンインストールして再インストールした場合
  - ユーザーの統合またはユーザーの削除
</Info>

# Uninstall Events

デバイスのアンインストールイベントについて、次の 2 種類の可視化を利用できます。

- Uninstall Events By Time
- Uninstall Events By Attribute

## Uninstall Events by Attribute

![uninstallseventsbyattributes.png](/images/moengage_546ff5.png)

グラフには次の特徴があります。

1. プラットフォームと期間(**過去 60 日間**まで)に基づいてフィルタリングできます。
2. CSV、jpeg、png、pdf、SVG ベクター画像形式でダウンロードできます。
3. 上部に**すべてのアンインストールの合計**が表示されます。
4. 数値属性について、**範囲のカスタマイズと上限の変更**をサポートしています。
5. 数値属性の**上限の最小値は 10** です。
6. アンインストールイベント数の**上位 10 個の属性値**が表示されます。

Lifetime Activity には、Days since last active や Days till last active などの属性があります。

- **Days since last active** を使用すると、そのデバイスでのユーザーのアンインストール時刻と、ユーザーの最終アクティブ時刻との間の日数に応じて、デバイスのアンインストールデータを可視化できます。
- **Days till last active** を使用すると、ユーザーの最終アクティブ時刻と、そのデバイスを使用するユーザーが MoEngage プラットフォームで最初に検出された時刻(MoEngage でのユーザー作成時刻)との間の日数に応じて、デバイスのアンインストールデータを可視化できます。

さらにサポートが必要な場合は、MoEngage のカスタマーサクセスマネージャー(CSM)またはサポートチームにお問い合わせください。

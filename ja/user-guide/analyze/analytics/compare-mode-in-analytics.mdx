MoEngage AnalyticsのCompare Modeを使用すると、Time Seriesや複数のSegmentsなど、さまざまな要素で分析を比較できます。インサイトごとに個別の分析を実行する代わりに、このモードでは1つの分析を使用して複数の視点からインサイトを得ることができます。

Compare Modeを活用することで、データをより包括的に理解し、業務の改善につながる実用的なインサイトを得ることができます。このアプローチにより、効率が向上し、冗長性が削減され、最終的にはより良い意思決定が促進されます。

# 時系列比較

時系列比較(Time Series Comparison)を使用すると、過去の期間の重要な指標を並べて比較できます。単一期間のパフォーマンス指標を調べるのとは対照的に、このアプローチでは複数の期間にわたるデータを比較できるため、トレンドとパフォーマンスをより包括的かつ文脈に沿って把握できます。指標が時間とともにどのように変化するかをより深く理解することで、過去のデータに基づいた情報に基づく意思決定が可能になり、ビジネス成果の向上につながります。

製品機能のユーザーエンゲージメント指標を分析する際、6月と5月のデータを比較すると、パターン、成長の軌跡、または新たな懸念事項が明らかになることがあります。したがって、時系列比較には次のような利点があります。

1. **文脈に沿った分析:** 時間の文脈で指標を理解することで、データに深みが加わります。ユーザーアクティビティの急増は印象的に見えるかもしれませんが、前月と比較すると減少傾向が明らかになる場合があります。
2. **迅速なパターン認識:** 時系列データの比較は、特に売上やユーザーエンゲージメントの季節変動に関連する繰り返しパターンを特定するのに役立ちます。これらのパターンをすばやく検出し、システムのパフォーマンスと動作に関する貴重なインサイトを得ることができます。情報に基づいた意思決定を行い、業務を最適化するのに役立ちます。
3. **データドリブンな予測:** データドリブンな予測により、過去のトレンドに基づいて将来のパフォーマンスを予測し、戦略を先回りして調整できます。

## 時間比較モードでのActionable Analytics

Actionable Analyticsは、**_現在の期間でのみ_**実行できます。

Behavior分析やFunnel分析では、現在の期間の線または棒のデータポイントをクリックするだけでActionable Analyticsを使用できます。Retention分析では、現在の期間のRetentionテーブルを使用してActionable Analyticsを適用します。

# セグメント比較

セグメント比較(Segment Comparison)を使用すると、MoEngage Analyticsで複数のユーザーセグメントを同時に包括的に分析できます。この機能により、さまざまなセグメントのデータを並べて精査でき、より包括的なインサイトを得ることができます。1つのセグメントのデータを個別に分析するのではなく、さまざまなセグメント間で指標を比較対照できるため、データをより徹底的に理解できます。セグメント比較はデータを分析する効率的な方法でもあり、よりきめ細かな解釈を得るのに役立ちます。

たとえば、先月購入したユーザーと購入しなかったユーザーという2つの異なるユーザーグループの行動を評価しているとします。Segment Comparison機能を使用すると、これら2つのセグメントの違いと類似点を並べて分析できます。さらに、次のような利点があります。

1. **全体的な理解:** 異なるセグメントを比較することで、パターンや異常を包括的に理解できます。これにより、単一のセグメントを分析する際に見落とされがちなインサイトが明らかになる場合があります。この360度の視点は、情報に基づいた意思決定を行ううえで非常に貴重です。
2. **マーケティング施策の最適化:** グロースマーケターは、このアプローチを活用して、パフォーマンスの低いセグメントをすばやく特定し、リソースとキャンペーンをより効果的に配分することで、マーケティング施策を最適化できます。
3. **ユーザーエクスペリエンスの向上:** プロダクトマネージャーは、セグメント比較を活用して特定のユーザーグループ向けに製品機能を調整し、ユーザーエクスペリエンスとユーザー満足度を向上させることができます。

## セグメント比較モードでのActionable Analytics

Actionable Analyticsは、**_分析中に選択したすべてのセグメントで_**実行できます。

Behavior分析やFunnel分析では、現在の期間の線または棒のデータポイントをクリックするだけでActionable Analyticsを使用できます。Retention分析では、現在の期間のRetentionテーブルを使用してActionable Analyticsを適用します。

# カスタムダッシュボードでのCompare Mode

MoEngage AnalyticsのCustom Dashboardsに統合されたCompare Mode機能を使用すると、2つの異なるデータセットを並べて、Time SeriesまたはSegmentのデータを簡単に比較できます。この機能により、データセットごとに個別のレポートを作成する必要がなくなるため、プロセスが効率化され、貴重な時間を節約できます。1つのレポートを使用して複数の角度からインサイトを得ることで、意思決定能力を高め、実用的なインサイトを生成するプロセスを迅速化できます。

カスタムダッシュボードには、Behavior、Funnels、Session and Source、Retentionのチャートとテーブルが含まれます。

- カスタムダッシュボードで**時系列比較**を実行するには、次の手順を実行してください。\
  _Dashboard Filters -\> Select Duration -\> Select Previous Duration -\> Apply_

  <Frame>
    ![時系列比較](/images/time-series-comparison.png)
  </Frame>
- カスタムダッシュボードで**セグメント比較**を実行するには、次の手順を実行してください。\
  _Dashboard Filters -\> Click Filter users -\> Select Segments -\> Apply_

![](/images/moengage_8365a1.png)

### 比較カスタムダッシュボードのユースケース:

1. **キャンペーンの最適化:** 2つの異なるキャンペーンの効果を評価する際、時系列比較によりパフォーマンス指標を並べて確認できます。この直接的な比較は、どのキャンペーン戦略がより良い結果を生み出しているかを特定するのに役立ちます。
2. **オーディエンスの理解:** セグメント比較は、オーディエンスの行動を理解しようとする際に非常に役立ちます。たとえば、オーガニック検索で獲得したユーザーと有料キャンペーンで獲得したユーザーの指標を比較することで、予算配分や戦略の調整について情報に基づいた意思決定を行うことができます。
3. **機能の導入状況の分析:** 新機能をリリースする際、プロダクトマネージャーは時系列比較を使用してリリース前後のユーザーエンゲージメントを分析し、機能の成功度を測定できます。
4. **ユーザー行動のインサイト:** さまざまなユーザーセグメントがプラットフォームとどのようにやり取りしているかを比較することで、プロダクトマネージャーは個々のユーザーニーズに基づいてエクスペリエンスを調整できます。たとえば、あるユーザーセグメントが別のセグメントよりも特定の機能を多く使用している場合、そのインサイトを活用してそのセグメント向けに製品エクスペリエンスを最適化できます。
5. **反復的な製品開発:** カスタムダッシュボードのセグメント比較により、さまざまなユーザーグループが変更にどのように反応しているかを動的に把握できます。この継続的なフィードバックループにより、製品の改善が実際のユーザーニーズに沿ったものになります。

# Step 1: イベントを定義する

イベントとは、ユーザーがアプリ上で実行し、トラッキングされるあらゆるアクションを指します。すべてのBehavior分析には少なくとも1つのイベントが必要で、最大10個のイベントを同時に追加できます。

![Screenshot 2025-01-02 at 12.43.32 PM.png](/images/moengage_a50392.png)

各イベントは、**\+ Attributes**を使用してさらにフィルタリングできます。Platform、App Versionなど、ユーザーが実行した特定のアクションに対するイベントフィルターを追加します。

![2025-01-02_12-48-01 (1).gif](/images/moengage_2e166d.png)

**\+ Attributes**を再度使用し、各イベントに対して**AND**/**OR**を使用して複数の属性を組み合わせます。たとえば、**OR**フィルターを使用して2つのプラットフォームのデータを組み合わせます。特定のプラットフォームのデータを取得し、特定のWebサイトへの訪問を確認したい場合は、**AND**フィルターを使用します。

![2025-01-02_12-54-33 (1).gif](/images/moengage_8052dc.png)

**Split by**を使用すると、特定の属性を使用してデータを比較できます。比較するには、**\+ Split By**をクリックし、比較したい属性をリストから選択します。たとえば、さまざまなプラットフォームで再生された曲数のチャートを取得する場合は、イベントとして_product_viewed_を選択し、**Split By**リストで_Platform_を選択します。**Split by**は、[Step 4](#step-4-select-the-comparison-and-the-duration)の**Group by user property**オプションと合わせて、合計10個の属性という上限を共有します。

![Screenshot 2025-01-02 at 1.09.29 PM.png](/images/moengage_dc1a67.png)

**\+ Add Event**を使用して、Behaviorチャートに最大10個のイベントを追加できます。

# Step 2: ユーザーをフィルタリングする

デフォルトでは、すべてのユーザーに対してBehavior分析を実行できます。ただし、User Properties、User Activity、User Affinity、またはCustom Segmentsを使用してフィルタリングしたユーザーグループに対してクエリを実行することもできます。ユーザーのフィルタリングはセグメントの作成と同様です。詳細については、[Create Segment](/ja/user-guide/segment/create-segments/rule-based-filter-segments)を参照してください。

代わりにセグメント間で結果を比較するには、Compare Modeを使用します。最大5つのセグメントを選択できます。詳細については、[Compare Mode in Analytics](/ja/user-guide/analyze/analytics/compare-mode-in-analytics)を参照してください。

![2025-01-02_13-25-45 (1).gif](/images/moengage_6b5fa8.png)

# Step 3: 分析オプションを選択する

イベントを定義したら、データの計算方法を選択できます。次のオプションを利用できます。

<img
  alt="Screenshot 2025-01-02 at 5.19.16 PM.png"
  src="/images/moengage_706710.png"
  style={{ width:"41%" }}
/>

- **Total events**: このオプションは、ユーザーが実行した選択したアクションまたはイベントの合計数を提供します。
- **Unique users**: このオプションは、選択したイベントを完了した個別ユーザーの数を提供します。
- **Total events per user**: このオプションは、個々のユーザーごとの合計イベント数の集計値を提供します。たとえば、ユーザーあたりの平均再生曲数を取得できます。利用できる集計タイプは次のとおりです。

  ![2025-01-02_18-04-36.png](/images/moengage_2b6da4.png)
- **Unique sessions**: このオプションは、選択したイベントが実行されたユニークセッションの合計数を提供します。
- **Aggregation**: このオプションは、選択したイベントまたはアクションのカウントを集計します。サポートされている集計関数は、sum、minimum、maximum、average、median、percentile、distinct countです。集計オプションは数値属性でのみ利用できます。percentileを選択した場合は、1から100までの値を入力します。

  ![2025-01-02_17-37-39 (1).gif](/images/moengage_183b19.png)

  イベントの属性を集計できます。これらの属性は、集計関数のタイプを選択した後にリストに表示されます。利用できる属性は、分析の最初に定義したイベントによって異なります。

高度なBehaviorオプションの詳細については、[Advanced](/ja/user-guide/analyze/analytics/behavior/advanced-behavior-analysis)を参照してください。

# Step 4: Select the Comparison and the Duration

属性でイベントを分割する機能に加えて、**Behavior Options**タブの**Group by user property**オプションを使用して、選択したすべてのイベントを共通のユーザープロパティでグループ化することもできます。たとえば、異なるサブスクリプションティアのユーザーが行った成功注文数を比較できます。

![Screenshot 2025-01-03 at 12.08.46 PM.png](/images/moengage_df4e4e.png)

**Split by**属性を含めて、最大10個の属性を選択できます。\
_Group by user property_の属性を選択したら、分析の期間を指定します。

<img
  alt="Screenshot 2025-06-16 at 3.41.28 PM.png"
  src="/images/moengage_2f477c.png"

# Step 5: チャートを選択する

クエリが生成されたら、希望する可視化タイプを選択します。Line、Area、Bar、Column、Pieチャートを切り替えることができます。各チャートにはそれぞれの意味があります。

- 折れ線グラフ(Line)は、データのトレンド、変化、パターンの分析に広く使用されます。時間の経過に伴うデータの表示や比較によく使用されます。

  ![Screenshot 2025-01-03 at 12.29.51 PM.png](/images/moengage_1fc408.png)

  折れ線グラフは次の方法で表示できます。

  <img
    alt="LineChart_LiLoCum.png"
    src="/images/moengage_a2999d.png"
    style={{ width:"25%" }}
  />
  - **Linear**: チャートはデータを連続した線で表示します。
  - **Logarithmic**: チャートはY軸の値を対数値にスケーリングします。
  - **Cumulative**: チャートは、チャートに表示されている最新の期間までのすべての値を累積します。
- 面グラフ(Area)は、折れ線グラフと棒グラフを組み合わせて、時間の経過に伴うデータの変化を示します。これらのチャートは、1つ以上のグループの数値が時間の経過とともにどのように変化するかを示します。収益の成長など、データのトレンドを示すためによく使用されます。

  ![Screenshot 2025-01-03 at 12.51.06 PM.png](/images/moengage_997a25.png)
- 棒グラフ(Bar)または縦棒グラフ(Column)は、さまざまなデータカテゴリやシリーズにわたって異なる指標を比較するために使用されるグラフです。

  <Tabs>
    <Tab title="縦棒グラフ">
      ![Screenshot 2025-01-03 at 12.58.53 PM.png](/images/moengage_2e2565.png)
    </Tab>
    <Tab title="横棒グラフ">
      ![Screenshot 2025-01-03 at 12.59.43 PM.png](/images/moengage_52b8d6.png)
    </Tab>
  </Tabs>
- 円グラフ(Pie)は、明確な部分に分割できるカテゴリデータを可視化するためによく使用されます。全体に対するさまざまなカテゴリの相対的な割合や寄与を表示します。

  ![Screenshot 2025-01-03 at 1.00.54 PM.png](/images/moengage_9b6f63.png)

折れ線グラフ、面グラフ、縦棒グラフ、棒グラフは、絶対数またはパーセンテージを使用してスケーリングされます。折れ線グラフ、面グラフ、棒グラフ、縦棒グラフでは、数値ビューとパーセンテージビューを切り替えることができます。

<img

/>

### 粒度

可視化しやすいように、レポートをHourly、Daily、Weekly、Monthlyの粒度に分割することもできます。選択した粒度に基づいて、ユニークユーザーが表示されます。Hourlyの粒度は、最大31日間の期間で利用できます。

### 過去との比較

Behavior分析中に、現在のチャートを過去のトレンドと比較できます。一定期間の任意のデータポイントを、前の期間の対応するデータポイントと比較できます。

![2025-01-03_13-17-17 (1).gif](/images/moengage_8c7bad.png)

次の期間でチャートを比較できます。

- Previous Day
- Previous Week
- Previous Month
- Previous Quarter
- Previous Year
- Custom Range

時間比較は、折れ線グラフ、棒グラフ、縦棒グラフでのみ利用できます。時間比較とセグメント比較を同時に使用することはできません。2つ目のセグメントを追加するとセグメント比較が開始されるため、過去と比較したい場合はセグメントを1つだけにしてください。詳細については、[Compare Mode in Analytics](/ja/user-guide/analyze/analytics/compare-mode-in-analytics)を参照してください。

# Step 6: テーブル

チャートに加えて、データは表形式でも分析に利用できます。テーブルを並べ替えたり、転置機能を使用して表示を変更したりできます。さらに、データをCSV形式でダウンロードすることもできます。詳細については、[こちら](/ja/user-guide/analyze/analytics/getting-started-with-analytics/overview)を参照してください。

# My Studioまたはカスタムダッシュボードに保存する

これで分析の準備が整いました。後でアクセスするために、分析を保存できます。

保存するには:

1. 右上隅の<Icon icon="floppy-disk" size={32} />アイコンをクリックし、**Save to My Studio**をクリックします。
2. さらに、分析をカスタムダッシュボードに保存することもできます。リストから必要なオプションを選択します。

   <img
     src="/images/moengage_463cad.png"
     alt="Screenshot 2025-01-06 at 3.35.49 PM.png"
     style={{ width:"31%" }}
   />
3. 分析を保存するダッシュボードを選択します。既存のダッシュボードを選択するか、新しいダッシュボードを作成できます。

   <img
     src="/images/moengage_f3c0f8.png"
     alt="Screenshot 2025-01-06 at 3.39.23 PM.png"
     style={{ width:"55%" }}
   />
4. 識別しやすいように、分析の名前を入力します。
5. 分析の簡単な説明を入力します。
6. **Save**をクリックします。

**Analyze** \> **My Studio**に移動すると、分析にアクセスできます。カスタムダッシュボードにアクセスするには、**Dashboards**に移動します。

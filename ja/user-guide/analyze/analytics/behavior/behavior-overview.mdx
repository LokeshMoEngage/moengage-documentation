Behavior分析は、Webアプリケーションやモバイルアプリケーションにおけるユーザーインタラクションに関する貴重なインサイトを提供します。この分析を使用すると、特定のイベントを追跡し、新たなトレンドを評価できるため、製品やマーケティングキャンペーンの効果とパフォーマンスを評価できます。わかりやすく可視化するためのグラフィカルなチャートや、詳細な分析のための表形式のレポートを生成できます。

# ユースケース

マーケターや製品オーナーは、Behavior分析を使用して次のような質問に答えることができます。

- アプリのMonthly Active Users(MAU)またはDaily Active Users(DAU)は何人か?
- 先月、旅行アプリでホテルの予約数が最も多かった都市はどこか?
- Eコマースアプリに追加した最新の製品から、先月どれだけの収益を得たか?
- 注文から得られた収益に基づくユーザーの分布はどうなっているか?
- ユーザーのさまざまなセグメントで、何曲の異なる曲が再生されているか?
- ユーザーがアプリを使用して行う注文の平均数はいくつか?
- 先月、顧客の各ユーザーが行った注文数の中央値はいくつか?
- 音楽または動画ストリーミングアプリで、最もアクティブでないリスナーは1日、1週間、または1か月に何分再生したか?

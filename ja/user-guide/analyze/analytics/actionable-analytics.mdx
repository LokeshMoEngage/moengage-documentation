# 概要

Actionable Analyticsにより、実行するすべての分析が単なる情報提供からアクションにつながるものへと変わります。生成されたインサイトはカスタムセグメントとして保存でき、これらのセグメントに対してさまざまなアクションを実行できます。

<Info>
この機能は、MoEngage AnalyticsのProduct Analyticsパッケージでのみ利用できます。アカウントで有効にするには、MoEngageのCustomer Success Manager(CSM)またはSupportチームにお問い合わせください。
</Info>

いずれかのチャートビューで、データポイント(棒グラフの棒や折れ線グラフの点など)をクリックすると、分析から直接次のアクションを実行できるメニューが開きます。

- [View sample users](/ja/user-guide/analyze/analytics/actionable-analytics#view-sample-users)
- [Create segment](/ja/user-guide/analyze/analytics/actionable-analytics#create-segment)
- [Create campaign](/ja/user-guide/analyze/analytics/actionable-analytics#create-campaign)
- [Analyze users](/ja/user-guide/analyze/analytics/actionable-analytics#analyze-users)
- [Export users](/ja/user-guide/analyze/analytics/actionable-analytics#export-users)

## View Sample Users

*View sample users*を使用すると、選択したデータポイントに含まれる最大50人のサンプルユーザーのリストを表示でき、データの検証に役立ちます。**View sample users**をクリックすると、ユーザーのリストを表示するウィンドウが表示されます。任意のユーザーをクリックすると、その**User Profile**を表示できます。  
 <img alt="2025-11-03_18-20-33 (1).gif" src="/images/moengage_2d043c.png" />

## Create Segment

選択したユーザーをカスタムセグメントとして保存し、後でアクションを実行できます。次の手順に従います。

1. **Create segment**をクリックします。**Create segment for Analytics**ダイアログボックスが表示されます。
2. **Segment name**ボックスに名前を入力します。
3. **Create**をクリックします。  
     
    <img alt="2025-11-03_15-38-35 (1).gif" src="/images/moengage_8df5b4.png" />

## Create Campaign

これらのユーザーに対して直接キャンペーンを作成できます。次の手順に従います。

1. **Create campaign**をクリックします。**Create a campaign for Analytics**ダイアログボックスが表示されます。
2. **Segment name**ボックスに名前を入力します。
3. **Campaign channel**と**Delivery type**を選択します。
4. **Create**をクリックします。キャンペーンの作成の詳細については、[Campaigns and Channels](/ja/user-guide/campaigns-and-channels/getting-started/introduction/moengage-channels)を参照してください。  
    <img alt="2025-11-03_16-09-29 (1).gif" src="/images/moengage_69de43.png" />

## Analyze Users

ユーザーグループをさらに分析できます。次の手順に従います。

1. **Analyze users**をクリックします。**Analyze users for Analytics**ダイアログボックスが表示されます。
2. **Segment name**ボックスに名前を入力します。
3. **Analysis types**リストから分析タイプを選択します。
4. **Analyze**をクリックします。詳細については、[こちら](/ja/user-guide/analyze/analytics)を参照してください。  
    <img alt="2025-11-03_18-11-05 (1).gif" src="/images/moengage_f95792.png" />

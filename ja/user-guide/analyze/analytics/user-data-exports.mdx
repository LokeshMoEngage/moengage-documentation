title: "ユーザーデータのエクスポート"
description: "MoEngage のセグメントからメール ID や電話番号などのフィルタリングされたユーザー属性をエクスポートし、外部チャネルで再エンゲージメントキャンペーンを実施します。"
---

MoEngage ダッシュボードでは、ユーザー属性をエクスポートできます。目的のユーザーセグメントをフィルタリングして、ユーザー属性をエクスポートできます。

例:

- エンゲージしていたもののアンインストールしたユーザーのメール ID をエクスポートし、Facebook で再エンゲージメントキャンペーンを実施する。
- 非アクティブなユーザーの電話番号をエクスポートし、再活性化のために SMS を送信する。

## エクスポートの実行

1. MoEngage ダッシュボードに移動し、左側のナビゲーションから **Segment** \> **Create segment** を選択します。Create segment ページが表示されます。
2. エクスポートしたいセグメントのクエリを作成して実行します。クエリは Query Results セクションに表示されます。

   ![query results.png](/images/moengage_6d4610.png)
3. **Query Results** セクションで特定のクエリをクリックし、**Export users** をクリックします。

   ![export users.png](/images/moengage_37b68f.png)

   Export users data ポップアップウィンドウが表示されます。お客様のメール ID があらかじめ選択されています。

   <img
     src="/images/moengage_a096b9.png"
     alt="export data popup.png"
     style={{ width:"51%" }}
   />
4. **File name** フィールドにファイル名を入力します。
5. **User attribute** ドロップダウンリストから、抽出したいユーザー属性を選択します。
6. **Export** をクリックします。

<Info>
  - エクスポートされたファイル内の日付と時刻の属性は、ダッシュボードのタイムゾーンに関係なく、常に UTC で提供されます。
  - 個人を特定できる情報(PII)としてマークされたユーザー属性のエクスポートは、MoEngage ダッシュボードで制限されています。[詳細はこちら](/ja/user-guide/data/privacy/personal-data-or-personally-identifiable-information-pii/pii-masking)。
  - ユーザーデータエクスポートのフェアユース制限:\
    エクスポートできるデータポイント数(行数 x 列数)は最大 2,000 万であり、これを超えるとエクスポートが失敗する可能性が高くなります。たとえば、次のようなエクスポートが可能です。
    - 2,000 万行 x 1 列、または
    - 400 万行 x 5 列、または
    - 100 万行 x 20 列\
      これらの制限を変更するには、CSM にお問い合わせください。
</Info>

## エクスポートのセキュリティ

ユーザーエクスポートは非公開のエクスポートサービスです。MoEngage ダッシュボードへのアクセス権を持つユーザーは、指定されたアカウントにログインしている場合に限り、エクスポートファイルにアクセスできます。MoEngage ダッシュボードまたは指定されたアカウントにログインしていないユーザーは、エクスポートを利用できません。

ユーザーエクスポートのメールとファイルのダウンロードリンクは、エクスポートを生成したユーザーのメールアドレスにのみ送信されます。その他のダッシュボードユーザーは、MoEngage ダッシュボードの Data Export ページにある User Export タブからこのファイルにアクセスできます。

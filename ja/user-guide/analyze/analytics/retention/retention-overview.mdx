MoEngage AnalyticsのRetentionは、ユーザーリテンションに関するインサイトを提供します。ユーザーリテンションは、ユーザーのロイヤルティを評価し、製品の継続ユーザーベースを測定するうえで重要な要素です。

Retentionチャートは、さまざまなコホートをグラフィカルに表現するため、直感的に理解できます。さらに、詳細な分析のために表形式のレポートをダウンロードすることもできます。これらの包括的なレポートは、さまざまなコホートにわたる時間の経過に伴うリテンションのトレンドを評価するのに役立ちます。

コホートとは、同様の行動を共有するユーザーのグループです。Web分析やアプリ分析の文脈では、コホートは特定の期間内に同じイベントを完了したユーザーを指します。たとえば、音楽ストリーミングアプリで15日間連続してアクティブに音楽を聴いている新規ユーザーでコホートを構成する場合があります。

# ユースケース

Retentionは、次のような質問に答えるのに役立ちます。

- 登録後にプラットフォームを利用しているユーザーは何人か?
- Eコマースアプリで特定の製品を閲覧し、アプリに戻って製品を購入したユーザーの割合は何パーセントか?
- カートを放棄したユーザーのうち、リマインダーキャンペーンのターゲットとなり、その後3日以内に戻って購入を完了したユーザーは何人か?
- 有料チャネルのユーザーの質は、他のチャネルと比べてどうか?
- ゲームアプリで、Level 5に到達したユーザーのリテンション率(翌日にプレイしに戻ってくる割合)は、Level 1にしか到達しなかったユーザーと比べてどうか?

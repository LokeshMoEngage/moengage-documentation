User Paths は、イベントの軌跡を分析することで、Web サイトやアプリ内でのユーザーのインタラクションとナビゲーションを可視化します。この分析では、特定のターゲットイベントの前後に実行されたイベントに焦点を当て、ユーザーの行動パターンを明らかにします。よく使われるナビゲーション経路を特定し、ユーザー体験における潜在的なボトルネックや摩擦ポイントを突き止めることができます。これらのパスは、定義された時間枠内で目的のイベントから始まる、または目的のイベントに収束するイベントシーケンスで構成されます。

# ユースケース

マーケターやプロダクトオーナーは、User Paths を使用して次のような質問に答えることができます。

- ユーザーはアプリをインストールまたは起動した直後に何をしているか?
- ユーザーは購入やアプリのアンインストールの直前に何をしているか?
- ユーザーは通知をクリックしてから購入を完了するまでに、どのような経路をたどっているか?
- ユーザーのオンボーディングジャーニーをどのように分析し、最適化できるか?

User Analysis を使用すると、ユーザーベース全体の中でユーザーグループを定義するユーザーと属性を分析できます。この分析は、特定の地域のユーザー数や言語の好みなど、ユーザーに関する傾向を特定するのに役立ちます。User Analysis は、ユーザー体験のパーソナライズ、特定のオーディエンスのターゲティング、個々のニーズや好みに合わせたコンテンツ、サービス、製品の調整に役立ちます。

## ユースケース

User Analysis で答えられる質問の例を次に示します。

- デバイスタイプとコンバージョン率を使用して、さまざまなデバイスでのユーザーの好みを分析する方法
- ユーザーの所在地と平均注文額を使用して、地域ごとの支出パターンを特定する方法
- チェックアウトを放棄したユニークユーザー数を、プラットフォームまたはデバイス別に分析する方法
- デバイスでトリガーされたプッシュ通知に基づいて、ストアで購入したユーザーの総数を分析する方法
- 特定のドメインでメールにエンゲージしたユーザー数を特定する方法

[Behavior](/ja/user-guide/analyze/analytics/behavior/behavior-overview)、[Funnel](/ja/user-guide/analyze/analytics/funnels/funnels-overview)、[Retention](/ja/user-guide/analyze/analytics/retention/retention-overview) の分析は、イベント属性とユーザー属性の値で比較または分割できます。分割機能を使用すると、選択した属性に含まれる値ごとに分析を比較できます。

例 - ユーザーがどの都市からアプリを開いているか、Funnel 分析でさまざまなキャンペーンを比較する、さまざまなユーザープログラムによるリテンションを比較する、などです。

分析はイベント属性またはユーザー属性に対して実行できます。MoEngage Analytics では、ユーザーのアクションはイベントであり、イベントにはイベント属性があります。ユーザーのプロパティはユーザー属性です。

# 分割分析の実行

## Behavior での分割分析

分割分析を実行するには、Behavior ページでイベントに **Split by** 属性を追加し、Apply ボタンをクリックします。

<img alt="split_on_event_attribute.png" src="/images/moengage_fafe05.png" />

ユーザー属性で分割分析を実行するには、Behavior ページの設定オプションで **Group by user property** 属性を追加し、Apply ボタンをクリックします。

<img alt="Split_on_user_attribute.png" src="/images/moengage_dfda65.png" />

Behavior 分析では、**Split by** と **Group by user property** のオプションを合計 10 個まで追加できます。

## Funnel での分割分析

分割分析を取得するには、Funnel ページに **Split Funnel** 属性を追加し、Apply ボタンをクリックします。このドロップダウンには、ユーザー属性とイベント属性の両方が含まれます。分析には最大 3 つの属性を選択できます。

<img alt="Split_02.png" src="/images/moengage_93c4ce.png" />

## Retention での分割分析

分割分析を取得するには、Retention ページに **Split Cohort** 属性を追加します。このドロップダウンには、ユーザー属性とイベント属性の両方が含まれます。最大 10 個の属性を追加できます。  
 <img alt="Split_03.png" src="/images/moengage_6a091c.png" />

## ユーザー属性の鮮度

**Split by** または **Group by user property** の分析で選択されたすべてのユーザー属性は、MoEngage で利用可能なユーザー属性の最新の値です。MoEngage では、ユーザー属性の過去の値による分割分析は提供していません。

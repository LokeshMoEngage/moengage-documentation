## 問題

User Path チャート内で予期しないイベントのシーケンスが見られ、特定のイベントがまとめてグループ化されたり、時系列順に表示されなかったりします。こうした不一致によりユーザー体験がわかりにくくなり、ユーザーのステップを正確に分析して理解することが難しくなります。

## 解決策

この問題に対処するには、次の要因を考慮してください。

1. **User paths における Dropoff**
   - "Dropoff" は **User paths** グラフにおける集約されたバケットまたはステップを表し、通常はパスの最後に表示されます。
   - 同じステップ内のイベントは縦方向に並べられますが、この順序に特別な意味はありません。
2. **Server-to-Server(S2S)イベント**
   - S2S イベントには user\_time 属性が含まれていない場合があり、その場合は代わりにサーバー時刻が使用されます。
3. **サーバー時刻の影響**
   - アプリからイベントがプッシュまたは同期される際、イベントが立て続けに発生すると、同じサーバー時刻を共有する場合があります。
   - これにより、実際のシーケンスにかかわらず、複数のイベントが **User paths** グラフの同じステップに表示されることがあります。

<Info>
- **User paths** とグラフ内のイベントの表示は、S2S イベントを含むイベントの性質とタイミングの影響を受けます。
- 同じステップ内のイベントの縦方向の順序に特別な意味はありません。
- 同じステップに表示されるイベントは、必ずしもそのシーケンスや時系列が途切れていることを示すものではありません。
</Info>

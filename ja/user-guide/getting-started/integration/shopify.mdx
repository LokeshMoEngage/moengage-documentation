Shopify `<>` MoEngage統合を使用すると、MoEngage Web SDKをブランドのShopifyストアにシームレスに統合し、ユーザーイベントとデータをトラッキングできます。Web Push、On-Site Messaging、SMS、Email、Web Personalizationなどのチャネルを使用してストア訪問者にアプローチし、コンバージョンへと促すことができます。

この統合により、リアルタイムのデータ同期を有効にし、パーソナライズされたレコメンデーションを提供し、クロスチャネルエンゲージメントを活用してコンバージョンを向上させることができます。

また、Analyticsを使用してShopifyストアでのユーザー行動を把握し、インサイトを得ることもできます。

[MoEngageをShopifyストアに統合するための詳細な手順ドキュメント](https://www.moengage.com/docs/developer-guide/ecommerce-platforms/shopify/shopify-20)を参照してください。

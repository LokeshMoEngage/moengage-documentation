この記事では、MoEngage Android SDK がデフォルトで収集するすべての情報を一覧で示します。

## デフォルトイベント

MoEngage Android SDK は次のイベントを収集します。

| **イベント名** | **説明** |
| --- | --- |
| User Logout | ユーザーがアプリまたは Web サイトからログアウトしたとき、またはユーザーがリセットを行ったときにトラッキングされます。 |
| Viewed Web Page | ユーザーが Web ページにアクセスしたときにトラッキングされます。イベント属性としてページ URL を選択すると、特定のページにアクセスしたユーザー数を確認したり、"Drop-off capture" のイベントトリガー型 Web プッシュの設定に使用したりできます。 |
| Notification Received Android | ユーザーが Android デバイスで通知を受信したときにトラッキングされます。 |
| Notification Clicked Android | ユーザーが Android デバイスで通知をクリックしたときにトラッキングされます。 |
| In-App Shown Android | Android デバイスでユーザーにアプリ内メッセージが表示されたときにトラッキングされます。 |
| In-App Clicked Android | ユーザーが Android デバイスでアプリ内メッセージをクリックしたときにトラッキングされます。 |
| In-App Closed Android | ユーザーが Android デバイスで閉じるボタンをクリックしてアプリ内メッセージを閉じたときにトラッキングされます。 |
| In-App Rating Done | ユーザーがアプリ内キャンペーンを通じて評価を送信したときにトラッキングされます。 |

## デフォルトのユーザー属性

MoEngage SDK は、一般的に使用またはトラッキングされるユーザー属性をトラッキングするためのヘルパーメソッドまたは API を提供しています。これらの属性をトラッキングするには、ヘルパーメソッドを使用する必要があります。ヘルパーメソッドの対象となる属性の一覧は次のとおりです。

- User ID
- First Name
- Last Name
- Full Name
- Email ID
- Mobile Number
- Gender
- Location

ヘルパーメソッドの使用方法については、[Track User Attributes](https://www.moengage.com/docs/developer-guide/android-sdk/data-tracking/basic/track-user-attributes) を参照してください。

## デバイス情報

MoEngage Android SDK は次のデバイス属性を収集します。

| **識別子** | **オプション** |
| --- | --- |
| OS Version | いいえ |
| API level | いいえ |
| Model Name | いいえ |
| Product Name | はい |
| Manufacturer | はい |
| Google Advertising Identifier (GAID) | はい |
| GAID tracking status | はい |
| Carrier | はい |
| Device Density | はい |
| Device Width | はい |
| Device Height | はい |
| Android Id | はい |
| Network Type | いいえ |
| Device Timezone | いいえ |

<Info>
  - MoEngage SDK は特定のデバイスデータをトラッキングしますが、その一部はオプションです。デフォルトでは、これらのオプション属性は無効、つまり "オプトアウト" になっています。これらのオプション属性を有効にするには、MoEngage SDK の対応するメソッドを呼び出します。
  - デバイス情報は収集されますが、現時点では MoEngage ダッシュボードで分析に使用することはできません。
</Info>

MoEngage が生成するイベントと属性の詳細については、[Derived Events and Attributes](/ja/user-guide/data/event-data/derived-events-and-attributes) を参照してください。

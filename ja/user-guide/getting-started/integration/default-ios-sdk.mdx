この記事では、MoEngage iOS SDK がデフォルトで収集するすべての情報を一覧で示します。

## デフォルトイベント

MoEngage iOS SDK は次のイベントを収集します。

| イベント名 | 説明 |
| --- | --- |
| INSTALL/UPDATE | SDK の appStatus(\_:) メソッドの呼び出し時にトラッキングされます。 |
| REINSTALL | アプリの再インストール時にトラッキングされます。 |
| MO\_PUSH\_PREFERENCE\_CHANGED | iOS でアプリのプッシュ権限設定が変更されたときにトラッキングされます。 |
| NOTIFICATION\_RECEIVED\_IOS\_MOE | 通知の受信時にトラッキングされます。 |
| NOTIFICATION\_CLICKED\_IOS\_MOE | 通知のクリック時にトラッキングされます。 |
| NOTIFICATION\_DISMISSED\_IOS\_MOE | 通知を閉じたときにトラッキングされます。 |
| MOE\_GEOFENCE\_HIT | ジオフェンスがトリガーされたときにトラッキングされます。 |
| MOE\_IN\_APP\_SHOWN | アプリ内メッセージが表示されたときにトラッキングされます。 |
| MOE\_IN\_APP\_CLICKED | アプリ内メッセージがクリックされたときにトラッキングされます。 |
| MOE\_IN\_APP\_DISMISSED | 閉じるボタンでアプリ内メッセージが閉じられたときにトラッキングされます。 |
| MOE\_IN\_APP\_AUTO\_DISMISS | ユーザーの操作なしにアプリ内メッセージが自動的に閉じられたときにトラッキングされます。 |
| MOE\_APP\_RATED | ユーザーがアプリ内キャンペーンを通じて評価したときにトラッキングされます。 |
| DT\_CAMPAIGN\_SCHEDULED | リアルタイムトリガーキャンペーンが後で表示されるようにスケジュールされたときにトラッキングされます。 |
| DT\_CAMPAIGN\_SCHEDULE\_FAILED | リアルタイムトリガーキャンペーンのスケジュール中にエラーが発生したときにトラッキングされます。 |
| MOE\_APP\_EXIT | アプリがバックグラウンドに移行したときにトラッキングされます。 |
| MOE\_LOGOUT | SDK の resetUser メソッドが呼び出されたときにトラッキングされます。 |

## デフォルトのユーザー属性

MoEngage iOS SDK は次のユーザー属性を収集します。この情報を MoEngage に渡す方法については、[Tracking User Attributes](https://www.moengage.com/docs/developer-guide/ios-sdk/data-tracking/basic/tracking-user-attributes) を参照してください。

| **ユーザー属性名** | **説明** |
| --- | --- |
| USER\_ATTRIBUTE\_UNIQUE\_ID | ユーザーの一意の ID |
| USER\_ATTRIBUTE\_USER\_NAME | ユーザーのフルネーム |
| USER\_ATTRIBUTE\_USER\_FIRST\_NAME | ユーザーの名 |
| USER\_ATTRIBUTE\_USER\_LAST\_NAME | ユーザーの姓 |
| USER\_ATTRIBUTE\_USER\_EMAIL | ユーザーのメールアドレス |
| USER\_ATTRIBUTE\_USER\_MOBILE | ユーザーの携帯電話番号 |
| USER\_ATTRIBUTE\_USER\_GENDER | ユーザーの性別 |
| USER\_ATTRIBUTE\_USER\_BDAY | ユーザーの生年月日(ユーザーの生年月日の NSDate インスタンスを指定して setUserDateOfBirth() を呼び出したときにトラッキングされます) |
| USER\_ATTRIBUTE\_USER\_LOCATION | ユーザーの緯度と経度 |
| ADVERTISING\_IDENTIFIER | デバイスの IDFA |
| USER\_PUSH\_PREFERENCE | SDK メソッド trackUserPushPreference(\_:forAppID:) を使用してトラッキングされるユーザーのプッシュ設定 |
| gdpr\_push\_opt\_out | GDPR のプッシュのオプトアウトステータス(true または false) |

## デバイス情報

MoEngage iOS SDK は次のデバイス属性を収集します。

| **識別子** | **情報** | オプション |
| --- | --- | --- |
| ADVERTISING\_IDENTIFIER | IDFA(広告配信のみに使用される、各デバイスに固有の英数字の文字列) - [参考リンク](https://developer.apple.com/documentation/adsupport/asidentifiermanager/1614151-advertisingidentifier "https://developer.apple.com/documentation/adsupport/asidentifiermanager/1614151-advertisingidentifier") | はい |
| device\_IDFV | identifierForVendor(アプリのベンダーに対してデバイスを一意に識別する英数字の文字列) - [参考リンク](https://developer.apple.com/documentation/uikit/uidevice/1620059-identifierforvendor "https://developer.apple.com/documentation/uikit/uidevice/1620059-identifierforvendor") | はい |
| device\_tz | デバイスのタイムゾーン | いいえ |
| model | デバイスのモデルタイプ(例: "iPhone" または "iPad") | いいえ |
| model\_name | 具体的なデバイスのモデル名(例: "iPhone 7" または "iPhone X") | いいえ |
| os\_ver | デバイスの現在の iOS バージョン | いいえ |
| moe\_push\_opted | デバイス設定で現在設定されているプッシュ設定(true または false) | いいえ |

<Info>
現時点では、セグメンテーションと分析に使用できるのは、ダッシュボード上の ADVERTISING IDENTIFIER のみです。GDPR のオプトアウトメソッドでデータトラッキングがオプトアウトされている場合、IDFA と IDFV は収集されません。
</Info>

MoEngage が生成するすべてのイベントと属性の一覧については、[Derived Events and Attributes](/ja/user-guide/data/event-data/derived-events-and-attributes) を参照してください。

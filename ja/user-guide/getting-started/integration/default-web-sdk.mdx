このドキュメントでは、Web SDKによってデフォルトで収集されるすべての情報を一覧で示します。

# デフォルトイベント

MoEngage Web SDKによって収集されるイベントは次のとおりです。

| **イベント名** | **説明** |
| --- | --- |
| Unsubscribed from Web Push | ユーザーがWeb Pushの購読を解除したとき |
| Viewed Web Page | ユーザーがページを訪問したときにトラッキングされます |
| Viewed Web Push Soft-ask | ソフトアスクがユーザーに表示されたときにトラッキングされます |
| Closed Web Push Soft-ask | ユーザーがソフトアスクを閉じた、または拒否したとき |
| Accepted Web Push Soft-ask | ユーザーがソフトアスクを許可したとき |
| Subscribed to Web Push | Web Pushの購読が成功し、プッシュトークンを受信したとき |
| Displayed Web Push Subscription | ハードアスクがユーザーに表示されたとき |
| Allowed Web Push Subscription | ユーザーがハードアスクを許可したとき |
| Dismissed Web Push Subscription | ユーザーがハードアスクを閉じたとき |
| Denied Web Push Subscription | ユーザーがハードアスクを拒否したとき |
| Onsite Message Template clicked | Onsite Messagingテンプレートがクリックされたとき |
| Onsite Message Template shown | Onsite Messagingテンプレートが読み込まれたとき |
| Onsite Message Template closed | Onsite Messagingテンプレートが閉じられたとき |
| Onsite Message Template auto dismiss | キャンペーン作成時に指定した時間が経過し、Onsite Messagingテンプレートが自動的に閉じたとき |
| Web Personalization clicked | Web Personalizationがクリックされたとき（クライアント側でdata.click()のように呼び出す必要があります） |
| Web Personalization shown | Web Personalizationが表示されたとき（クライアント側でdata.imp()のように呼び出す必要があります） |
| Web Personalization delivered | Web Personalizationの呼び出しが正常に配信されたとき |
| Notification Received Web | ユーザーがブラウザで通知を受信したときにトラッキングされます |
| Notification Clicked Web | ユーザーがブラウザで通知をクリックしたときにトラッキングされます |

# イベント属性情報

MoEngage Web SDKによって収集されるデバイス属性は次のとおりです。

| **属性名** | **説明** |
| --- | --- |
| URL | ページの現在のURL |
| moe\_logged\_in\_status | ユーザーがログインしているかどうかを示すブール値 |
| moe\_first\_visit | ユーザーが初めてページを訪問したかどうかを示すブール値 |

# デフォルトのユーザー属性

MoEngage Web SDKで収集できるユーザー属性は次のとおりです。

1. First Name
2. Last Name
3. Full Name
4. Email Id
5. Mobile Number
6. Gender
7. Birth Date

これらの情報をMoEngageに渡す方法については、[こちら](https://www.moengage.com/docs/developer-guide/web-sdk/data-tracking/web-sdk-user-attributes-tracking)をクリックしてください。

# デバイス情報

MoEngage Web SDKによって収集されるデバイス属性は次のとおりです。

| **識別子** | **情報** |
| --- | --- |
| os | Web / MWeb |
| os\_platform | User Agent。ブラウザに関する情報 |
| os\_ver | ブラウザ名 |
| model | ブラウザ名 |
| device\_ts | デバイスのタイムスタンプ |
| device\_tz | デバイスのタイムゾーン |
| push\_id | SDKによって生成されたプッシュトークン |

<Info>
  デバイス情報は収集されますが、現時点ではMoEngageダッシュボードで分析に使用することはできません。
</Info>

MoEngageが生成するすべてのイベントと属性の一覧については、[こちら](/ja/user-guide/data/event-data/derived-events-and-attributes)をクリックしてください。

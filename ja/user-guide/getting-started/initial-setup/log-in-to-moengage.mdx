MoEngage では、認証 (ユーザーが誰であるか) と認可 (どのワークスペースにアクセスできるか) を分離しています。SSO アカウントの取り消しやワークスペースレベルのポリシー変更など、あるワークスペースでアクセスの問題が発生しても、他のワークスペースには影響しません。

ログイン方法を選択してください。
- 最後に使用したワークスペースに**直接ログインする**。
- **一度本人確認を行い**、アクセスが許可されている任意のワークスペースから選択する。

<Tip>
  **前提条件**

  - **初回ログイン (招待されたユーザーとして)**: ワークスペースに招待された後、初めてログインする前に 1 回限りのセットアップを完了してください。詳細については、[招待ユーザーとしてワークスペースのセットアップを完了する](/ja/user-guide/getting-started/initial-setup/sign-up-with-moengage-or-create-a-new-account-in-moengage#finish-your-workspace-setup-as-an-invited-user)を参照してください。
  - **2 回目以降のログイン**: ワークスペースのログインページの URL を手元に用意しておいてください。ログイン URL を確認するには、下記の[ログインページを確認する](#find-your-login-page)を参照してください。
  - **2 段階認証**: ワークスペースで 2 段階認証が必須の場合は、ログインする前にデバイスで設定してください。詳細については、[デバイスで 2 段階認証を設定する](#set-up-2-step-verification-on-your-device)を参照してください。
</Tip>

## ログインページを確認する

各ワークスペースは特定のデータセンターに存在します (例: DC-01 は `dashboard-01.moengage.com`)。グローバルログインページを使用してログイン URL を確認します。

<Steps>
  <Step title="グローバルログインページを開く">
    [dashboard.moengage.com](https://dashboard.moengage.com/v4/#/auth) にアクセスします。
    <img src="/images/login1.png" style={{ width:"60%" }} alt="MoEngage グローバルログインページ" />
  </Step>
  <Step title="仕事用メールアドレスを入力する">
    **Work email** ボックスにメールアドレスを入力します。
  </Step>
  <Step title="データセンターに進む">
    **Continue** をクリックします。MoEngage は、正しいデータセンター上にある、最後に使用したワークスペースのログインページにリダイレクトします。
    <img src="/images/loginpage1.png" style={{ width:"60%" }} alt="データセンターのログインページ" />

    <Info>
      認証のため、ログインページにはメールアドレスがあらかじめ入力されています。
    </Info>

    <Info>
      最後に使用したワークスペースでシングルサインオン (SSO) が有効になっている場合、MoEngage はそのデータセンターの Login with Single Sign-On ページに自動的にリダイレクトします。
      <img src="/images/loginviasso.png" style={{ width:"60%" }} alt="SSO" />
    </Info>
  </Step>
</Steps>

別のワークスペースにログインするには、いずれかのページで **Login to a different workspace** をクリックします。フロー全体については、[別のワークスペースにログインする](#log-into-a-different-workspace)を参照してください。

<Info>
  誤ったデータセンターのログインページが表示された場合は、**Find your data centre** をクリックしてグローバルログインページに戻り、メールアドレスを再入力してください。
</Info>

今後すばやくアクセスできるように、ログイン URL をブックマークしておいてください。データセンターの詳細については、[MoEngage のデータセンター](/ja/user-guide/data/key-concepts/data-centers-in-moengage)を参照してください。

## 最後に使用したワークスペースにログインする

データセンターのログインページから、最後に使用したワークスペースにログインします。初めてログインする場合、MoEngage は招待されたワークスペースにリダイレクトします。

ワークスペースで使用するログイン方法は Admin が設定します。

- [パスワード](#log-in-to-your-last-used-workspace)
- [Google](#log-in-to-your-last-used-workspace)
- [SSO](#log-in-to-your-last-used-workspace)

<Tabs>
  <Tab title="パスワード">
    <Info>
      Admin がログイン方法を **Password or Google sign in** に設定している場合は、メールアドレスとパスワード、または **Google** ボタンのいずれかでログインできます。
    </Info>

    1. Web ブラウザで MoEngage ワークスペースの URL にアクセスします。ログインページが表示されます。 <img src="/images/webbrowserlogin.png" style={{ width:"60%" }} alt="ログインページ" />
    2. **Work email** ボックスにメールアドレスを入力します。
    3. **Password** ボックスにパスワードを入力します。
    4. **Login** をクリックします。パスワードでログインする場合、2 段階認証は必須です。下記の [2 段階認証を完了する](#complete-2-step-verification)を参照してください。
  </Tab>

  <Tab title="Google">
    <Info>
      Admin がログイン方法を **Google Sign In only** に設定している場合は、**Google** オプションを使用してログインします。
    </Info>

    1. Web ブラウザで MoEngage ワークスペースの URL にアクセスします。ログインページが表示されます。 <img src="/images/webbrowserlogin.png" style={{ width:"60%" }} alt="ログインページ" />
    2. **Google** をクリックします。
    3. **Choose an account** ページで、Google アカウントを選択します。 <img src="/images/moengage_889824.png" style={{ width:"45%" }} alt="Google アカウントを選択" />
    4. **Sign in to moengage.com** ページで、**Continue** をクリックします。 <img src="/images/moengage_c8a1fa.png" style={{ width:"45%" }} alt="moengage.com にサインイン" /> Google でログインする場合、2 段階認証は必須です。下記の [2 段階認証を完了する](#complete-2-step-verification)を参照してください。
  </Tab>

  <Tab title="SSO">
    <Info>
      Admin がログイン方法を **Single Sign On (SSO) only** に設定している場合は、SSO を使用してログインします。
    </Info>

    1. Web ブラウザで MoEngage ワークスペースの URL にアクセスします。ログインページが表示されます。
    2. **SSO** をクリックします。 <img src="/images/clicksso.png" style={{ width:"45%" }} alt="SSO" /> **Login using SSO** ページが表示されます。前の画面でメールアドレスを入力した場合は、あらかじめ入力されています。
    3. **Work Email** ボックスにメールアドレスを入力します。
    4. **Continue** をクリックします。 <img src="/images/loginviasso.png" style={{ width:"60%" }} alt="SSO" /> MoEngage は、認証のために組織の Identity Provider (IdP) にリダイレクトします。
    5. 認証情報を使用して SSO IdP にログインします。
    6. 認証に成功すると、MoEngage はダッシュボードにリダイレクトします。ワークスペースで 2 段階認証が有効になっている場合は、下記の [2 段階認証を完了する](#complete-2-step-verification)を参照してください。
  </Tab>
</Tabs>

## 別のワークスペースにログインする

このフローを使用すると、使用が許可されている任意のワークスペースにログインできます。本人確認はワークスペースのアクセスチェックより前に行われるため、あるワークスペースでアクセスの問題が発生しても、他のワークスペースには影響しません。

<Steps>
  <Step title="別のワークスペースを選択する">
    ログインページ (または [dashboard.moengage.com](https://dashboard.moengage.com/v4/#/auth)) で、**Login to a different workspace** をクリックします。
  </Step>
  <Step title="メールアドレスを入力する">
    **Work email** ボックスにメールアドレスを入力します。前のページで入力した場合は、あらかじめ入力されています。
  </Step>
  <Step title="本人確認を行う">
    **Continue** をクリックします。**User authentication** ページが表示されます。

    <img src="/images/logintodiffws.gif" style={{ width:"70%" }} alt="別のワークスペースにログイン" />

    <Info>
      User authentication では、ワークスペースを表示する前に 2 段階認証コードを使用して本人確認を行います。設定の詳細については、[デバイスで 2 段階認証を設定する](#set-up-2-step-verification-on-your-device)を参照してください。
    </Info>

    認証アプリを開き、MoEngage アカウントの 6 桁のコードを確認して、認証ボックスに入力します。
  </Step>
  <Step title="ワークスペースと環境を選択する">
    **Continue** をクリックします。**Login to a different workspace** というタイトルのワークスペース一覧が表示されます。アクセスするワークスペースと環境を選択します。各エントリには次の情報が表示されます。

    - ワークスペース名
    - 最後に使用したワークスペースかどうか
    - ログイン方法
    - 環境 (Live または Test)

    <img src="/images/logindiffws2.gif" style={{ width:"70%" }} alt="ワークスペースを選択してログイン" />
  </Step>
  <Step title="ワークスペースの認証を完了する">
    選択したワークスペースに設定されているログイン方法を使用して認証を完了します。

    - **パスワード**: パスワードを入力し、**Login** をクリックします。
    - **Google Sign-In**: **Google** をクリックし、Google アカウントを選択します。
    - **SSO**: **SSO** をクリックすると、組織の Identity Provider (IdP) にリダイレクトされます。
  </Step>
</Steps>

MoEngage により、選択したワークスペースにログインされます。

## MCP 接続経由でログインする

MoEngage MCP (Model Context Protocol) サーバー経由で AI アシスタント (Claude や ChatGPT など) を接続すると、自然言語の会話を通じてキャンペーンやデータを操作できます。このログインフローはダッシュボードではなく MCP 接続を認証するもので、独自のセッション動作があります。

ログインフロー全体、セッションの詳細、および設定については、[MoEngage MCP Server and Connector](/ja/user-guide/ai-and-intelligence/merlin-ai/moengage-mcp-server#authentication) を参照してください。

## 2 段階認証を完了する

2 段階認証が有効になっている場合、認証後に MoEngage は 2-Step Verification ページを表示します。

<Warning>
  セキュリティ上の理由から、ログイン方法が **Password or Google sign in** または **Google Sign In only** に設定されているワークスペースでは、2 段階認証は必須であり、無効にすることはできません。このようなワークスペースのすべてのユーザーは、ログインのたびに 2 段階認証を完了する必要があります。ログイン方法の詳細については、[ログイン方法を設定する](/ja/user-guide/settings/account/security/set-up-the-login-method)を参照してください。
</Warning>

**初回設定時:** MoEngage から 2 段階認証の設定を求められます。[デバイスで 2 段階認証を設定する](#set-up-2-step-verification-on-your-device)を参照してください。

**2 回目以降のログイン時:** 認証アプリの 6 桁のコードを入力します。 <img src="/images/2-stepverification.png" style={{ width:"45%" }} alt="2 段階認証コードの入力" />

1. デバイスで認証アプリを開き、MoEngage ワークスペースの 6 桁のコードを確認します。
2. 2-Step Verification ページで、**Verification code** ボックスにコードを入力します。
3. **Continue** をクリックします。MoEngage によりダッシュボードにログインされます。

<Tip>
  新しいデバイスの設定や追加のリカバリーコードの取得など、2 段階認証に関するサポートについては、[トラブルシューティング](#troubleshooting)を参照してください。
</Tip>

<Info>
  [別のワークスペースにログインする](#log-into-a-different-workspace)フローでは、これに相当するステップは **User authentication** と呼ばれ、ワークスペースの選択後ではなく選択前に行われます。
</Info>

## デバイスで 2 段階認証を設定する

2 段階認証には認証アプリのコードが必要です。アプリは 30 秒ごとに新しい 6 桁のコードを生成します。一度設定すれば、以降のすべてのログインで使用できます。

<Tip>
  **前提条件**

  スマートフォンに認証アプリ (例: Google Authenticator) が必要です。

  - Google Authenticator: [Google Play](https://play.google.com/store/apps/details?id=com.google.android.apps.authenticator2&hl=en_IN&gl=US) | [App Store](https://apps.apple.com/us/app/google-authenticator/id388497605)
  - Twilio Authy: [Google Play](https://play.google.com/store/apps/details?id=com.authy.authy) | [App Store](https://apps.apple.com/us/app/twilio-authy/id494168017)
</Tip>

<Accordion title="2 段階認証が必要になるタイミングと仕組み">
  設定は次のシナリオで行われます。
  - Admin が MoEngage にサインアップするか、新しいワークスペースを作成した場合 (デフォルトで有効)。
  - 2 段階認証が有効になっているワークスペースに招待された場合。[ワークスペースのセットアップを完了](/ja/user-guide/getting-started/initial-setup/sign-up-with-moengage-or-create-a-new-account-in-moengage#finish-your-workspace-setup-as-an-invited-user)した後にプロンプトが表示されます。
  - ログイン後に Admin が 2 段階認証を有効にした場合。自動的にログアウトされ、次回のログイン時にプロンプトが表示されます。
  - **My Profile** で自分のアカウントに対して有効にした場合。

  2 段階認証は、ワークスペースとユーザーの 2 つのレベルで機能します。

  - **ワークスペースレベル**: 2 段階認証がワークスペースの全員に適用されるかどうかは、ワークスペースのログイン方法によって異なります。ログイン方法が **Password or Google sign in** または **Google Sign In only** の場合、セキュリティ上の理由から 2 段階認証はすべてのユーザーに必須であり、Admin は無効にできません。**Single Sign On (SSO) only** を使用するワークスペースのみ、[Settings > Security > 2-step verification](/ja/user-guide/settings/account/security/2-step-verification-or-two-factor-authentication-2fa) から無効にできます。
  - **ユーザーレベル**: ワークスペースで SSO を使用しており、Admin が 2 段階認証を強制していない場合でも、**My Profile** から自分のアカウントに対して有効にできます。

  各ワークスペースには独自の 2 段階認証設定があるため、あるワークスペースでは強制し、別のワークスペースでは無効にすることができます。
</Accordion>

1. 2-Step Verification ページで、**Setup device Authentication** をクリックします。Set your device authentication ページが表示されます。
   <img src="/images/twofactorrestscanner.png" style={{ width:"60%" }} alt="Set your device authentication ページ" />

   <img src="/images/moengage_2e8e23.png" style={{ width:"35%" }} alt="認証アプリのプラスアイコン" />

   <img src="/images/moengage_2d1624.png" style={{ width:"36%" }} alt="認証コードの追加画面" />

3. 認証アプリに MoEngage を追加します。次のいずれかのオプションを使用して MoEngage を追加します。
   <Tabs>
     <Tab title="QR コード">
       1. **Scan a QR code** をタップします。
          <img src="/images/moengage_9ecee6.png" style={{ width:"35%" }} alt="Scan a QR code オプション" />
       2. **Set your device authentication** ページに表示されている QR コードをスキャンします。認証アプリに MoEngage が追加され、6 桁のコードの生成が開始されます。
     </Tab>
     <Tab title="セットアップキー">
       1. **Enter a setup key** をタップします。
          <img src="/images/moengage_e6d745.png" style={{ width:"36%" }} alt="Enter a setup key オプション" />
       2. **Enter account details** 画面で、次のフィールドに入力します。

          | フィールド | 必須 | 説明 |
          | --- | --- | --- |
          | Account name | 任意 | アカウント名を入力します。 |
          | Your key | はい | **Set your device authentication** ページに表示されている 32 桁のシークレットキーを入力します。 <br /><img alt="セットアップキー" src="/images/twofactorrestscanner.png" style={{ width:"90%" }} /> |
          | Type of key | 任意 | **Time based** (現在時刻に基づく OTP) または **Counter based** (増加するカウンターに基づく OTP)。 |
          | <img src="/images/moengage_c59fc2.png" style={{ width:"90%" }} alt="キーの種類の選択" /> |  |  |
       3. **Add** をタップします。認証アプリに MoEngage が追加され、6 桁のコードの生成が開始されます。
          <img src="/images/moengage_bf333b.png" style={{ width:"36%" }} alt="認証が追加されました" />
     </Tab>
   </Tabs>

4. **Enter the 6 digit verification code** ボックスに、認証アプリに表示されている現在のコードを入力します。

   <Info>
     各コードの有効期間は 30 秒です。その後、認証アプリは新しいコードを生成します。

   <img src="/images/2-stepverification.png" style={{ width:"45%" }} alt="認証コードを入力" />
5. **Continue** をクリックします。これで、デバイスで 2 段階認証が設定されました。
6. **Download recovery codes** をクリックして、バックアップコードを CSV ファイルとして保存します。詳細については、[リカバリーコード](#recovery-codes)を参照してください。
   <img src="/images/downloadrecoverycodes.png" style={{ width:"45%" }} alt="リカバリーコードをダウンロード" />

7. **Login** をクリックします。**[ログインページ](#log-in-to-your-last-used-workspace)**が表示されます。

## リカバリーコード

リカバリーコードは、2 段階認証のメインデバイスが一時的に利用できない場合に使用できる、1 回限り使用可能な 10 個のバックアップコードです。MoEngage は、2 段階認証を初めて設定したとき、またはリセットしたときにこれらを生成します。

- 安全な場所に保管してください。
- 各コードは 1 回のみ使用できます。
- 新しいコードを取得するには、[トラブルシューティング](#troubleshooting)の **2 段階認証をリセットする**を参照してください。

## ワンタイムパスワード (OTP) 認証

アカウントのセキュリティを保護するため、新しいデバイス、別の場所、見慣れない IP アドレス、または通常とは異なる時間帯からのログインなど、認識されていないサインインアクティビティを検出した場合、MoEngage は認証アプリのコードの代わりにワンタイムパスワード (OTP) の入力を求めることがあります。MoEngage は、登録されているメールアドレスに認証コードを直ちに送信します。

## トラブルシューティング

<Info>
  ログインページで **Contact support** をクリックすると、サポートチケットを直接作成できます。
</Info>

<AccordionGroup>
  <Accordion title="正しいコードが拒否される">
    ログインに使用するデバイスと認証アプリがインストールされているデバイスの両方が、同じタイムゾーンに設定されていることを確認してください。コードは時間ベースで、30 秒後に期限切れになります。

  </Accordion>

  <Accordion title="パスワードまたは 2 段階認証のリセット中にブラウザ拡張機能がエラーを引き起こす">
    パスワードマネージャー、広告ブロッカー、フォーム自動入力拡張機能などのブラウザ拡張機能は、**Reset Password** ページや **2-Step Verification** ページの動作を妨げる場合があります。拡張機能を無効にするか、プライベート/シークレットブラウザウィンドウを使用してから、再度お試しください。
  </Accordion>

  <Accordion title="このワークスペースはブロックされています">
    "This workspace has been blocked. Please contact our support team for assistance." というエラーが表示されます。アカウントに未払い金がある場合、MoEngage はワークスペースをブロックします。MoEngage Support チームに連絡して未払い金を解決し、ワークスペースのブロックを解除してください。
  </Accordion>

  <Accordion title="メールアドレスに関連付けられた DB がない">
    "No DBs associated with email." というエラーが表示されます。これは、MoEngage へのアクセス権が取り消された場合に発生します。再度アクセス権を付与してもらえるよう、管理者に連絡してください。
  </Accordion>

  <Accordion title="ログインメールアドレスの変更">
    MoEngage では、既存アカウントのメールアドレスの変更はサポートされていません。新しいメールアドレスを使用するには、次の手順を実行します。

    1. Admin に、新しいメールアドレスをワークスペースに[招待する](/ja/user-guide/settings/account/team-management/manage-members#invite-members)よう依頼します。
    2. 以前のメールアドレスからのアクセスが不要になった場合は、Admin にその[アクセス権を取り消す](/ja/user-guide/settings/account/team-management/manage-members#revoke-a-member’s-access)よう依頼します。
  </Accordion>

  <Accordion title="正しいログインページかどうかわからない">
    ワークスペースの正しいログイン URL を使用していることを確認してください。各ワークスペースは特定のデータセンターでホストされています。詳細については、[MoEngage のデータセンター](/ja/user-guide/data/key-concepts/data-centers-in-moengage)を参照してください。
  </Accordion>

  <Accordion title="リセットメールが届かない">
    組織で MoEngage のドメインがブロックされていないことを確認してください。
  </Accordion>

  <Accordion title="パスワードを忘れた場合">
    <Steps>
      <Step title="パスワードのリセットをリクエストする">
        ワークスペースのログインページで、**Forgot Password?** をクリックします。 <img src="/images/forgot1.png" style={{ width:"60%" }} alt="パスワードリセットのリンク" />
      </Step>
      <Step title="メールアドレスを入力する">
        MoEngage のメールアドレスを入力し、**Send Link** をクリックします。 <img src="/images/forgot2.png" style={{ width:"45%" }} alt="リセットリンクを送信" />
      </Step>
      <Step title="リセットリンクを開く">
        メールに記載されているリセットリンクをクリックします。 <img src="/images/moengage_d301e8.png" style={{ width:"60%" }} alt="パスワードリセットメール" />
      </Step>
      <Step title="新しいパスワードを作成する">
        パスワードには次の要素が含まれている必要があります。
        - 8～20 文字
        - 大文字を 1 文字以上
        - 数字を 1 文字以上
        - 次の特殊文字を 1 文字以上: `! @ # $ % ^ & * ( ) _ ? / , < > ; : { } | ~`
        
        <img src="/images/forgot3.png" style={{ width:"45%" }} alt="パスワードリセットフォーム" />
        **Reset Password** をクリックします。新しいパスワードで[ログイン](#log-in-to-your-last-used-workspace)します。
      </Step>
    </Steps>
  </Accordion>

  <Accordion title="認証アプリを再インストール/変更した場合、またはデバイスを紛失/変更した場合に 2 段階認証をリセットする">
    新しい認証デバイスを設定する場合 (デバイスを変更または交換した場合)、または既存のリカバリーコードを使い切った後に新しいリカバリーコードを生成する場合は、2 段階認証をリセットします。

    <Tip>
      **前提条件:** 事前にデバイスで 2 段階認証を設定しておく必要があります。
    </Tip>

    1. 認証情報を使用して[ワークスペースへのログイン](#log-in-to-your-last-used-workspace)を試みます。
    2. ** Reset 2-Step Verification** ページで、仕事用メールアドレスを入力し、**Send link** をクリックします。 <img src="/images/reset2stepverification.png" style={{ width:"45%" }} alt="リセットリンクを受け取る" />
    3. MoEngage からメールアドレスにリセットリンクが送信されます。
    4. MoEngage からのメールを開き、**here to reset your 2FA credentials** をクリックします。 <img src="/images/moengage_b61f2f.png" style={{ width:"60%" }} alt="リセットメール" /> 新しいブラウザタブで Login to your accounts ページが開きます。 <img src="/images/logintoyourworkspace.png" style={{ width:"60%" }} alt="Login to your accounts ページ" />
    5. 認証情報を使用してログインします。MoEngage により 2-Step Verification ページに移動します。
    6. **Setup your device** をクリックします。Set up your device authentication ページが表示されます。 <img src="/images/twofactorrestscanner.png" style={{ width:"60%" }} alt="デバイス認証を設定" />
       QR コードまたはセットアップキーのいずれかを使用して、認証アプリに MoEngage を追加します。両方のオプションの詳細については、[設定手順](#configuration-steps)を参照してください。
    7. **Enter the 6 digit verification code** ボックスに、認証アプリのコードを入力します。
       <Info>
         各コードの有効期間は 30 秒です。
       </Info>
    8. **Confirm** をクリックします。これで、デバイスで 2 段階認証がリセットされました。今後のすべてのログインでは、この新しい認証アプリインスタンスの認証コードを使用してください。
    9. **Download recovery codes** をクリックして、新しいバックアップコードを CSV ファイルとして保存します。 <img src="/images/downloadrecoverycodes.png" style={{ width:"45%" }} alt="リカバリーコードをダウンロード" /> 以前のリカバリーコードは使用できなくなります。
    10. **Login** をクリックします。
  </Accordion>

  <Accordion title="認証アプリにアクセスできない場合 リカバリーコードを使用してログインする">
    2 段階認証のメインデバイスが一時的に利用できない場合は、リカバリーコードを使用します。

    <Tip>
      事前にリカバリーコードをダウンロードしておく必要があります。詳細については、[リカバリーコード](#recovery-codes)を参照してください。
    </Tip>

    <Steps>
      <Step title="認証情報でログインする">
        認証情報を使用して[ワークスペースにログイン](#log-in-to-your-last-used-workspace)します。
      </Step>
      <Step title="リカバリーコードに切り替える">
        2-Step Verification ページで、**Enter recovery code** をクリックします。 <img src="/images/recovery1.png" style={{ width:"45%" }} alt="2 段階認証のリカバリーコード入力リンク" />
      </Step>
      <Step title="コードを入力する">
        保存したリカバリーコードのいずれかを入力します。 <Info>各コードは 1 回のみ使用できます。</Info>
      </Step>
      <Step title="認証する">
        **Continue** をクリックします。 <img src="/images/recovery2.png" style={{ width:"45%" }} alt="リカバリーコードを認証" /> ログインが完了します。
      </Step>
    </Steps>

    <Tip>
      リカバリーコードをすべて使い切った場合は、上記の **2 段階認証をリセットする**を参照して新しいコードを生成してください。
    </Tip>
  </Accordion>

  <Accordion title="MCP 経由で接続できない">
    MCP 経由で接続できない場合は、パスワードをリセットしてから再接続してください。上記の **パスワードを忘れた場合** を参照してください。
  </Accordion>

  <Accordion title="アカウントのロック">
    ログイン試行が不審と判断された場合、MoEngage はセキュリティ対策としてアカウントをロックします。

    <Warning>
      ユーザーまたは Admin が誤ったログイン認証情報またはメール OTP を 4 回入力すると、MoEngage はアカウントをロックします。
    </Warning>

    - **ユーザーの場合**: 3 時間 (180 分) 待ってから、正しい認証情報を使用してログインします。または、MoEngage Admin に連絡すると、より早くアカウントのブロックを解除できます。
    - **Admin の場合**: 3 時間 (180 分) 待ってから、正しい認証情報を使用してログインします。

    **Admin としてユーザーのアカウントのブロックを解除するには:**

    1. MoEngage ダッシュボードの左側のナビゲーションメニューで、**Settings > Account > Team management** をクリックします。 <img src="/images/moengage_55ddca.png" alt="Settings、Account、Team management に移動" />
    2. Team management ページで、**Members** タブをクリックします。
    3. **Search member(s)** ボックスに、アカウントがブロックされているユーザーのメールアドレスを入力します。 <img src="/images/moengage_4a4aff.png" alt="ブロックされたチームメンバーをメールアドレスで検索" />
    4. **Action** 列で省略記号アイコンをクリックし、**Unblock** をクリックします。**Unblock** オプションは、ステータスが Blocked のアカウントにのみ表示されます。 <img src="/images/moengage_b4b802.png" alt="ブロックされたチームメンバーのアカウントのブロックを解除" />

    MoEngage によりアカウントのブロックが解除され、ユーザーは正しい認証情報を使用してログインできるようになります。
  </Accordion>

MoEngage では、MoEngage ダッシュボードのワークスペースごとにプロフィールを管理できます。**My Profile** セクションには次のタブがあります。

- [General](/ja/user-guide/getting-started/initial-setup/manage-your-profile#general)
- [Security](/ja/user-guide/getting-started/initial-setup/manage-your-profile#security)
- [Preferences](/ja/user-guide/getting-started/initial-setup/manage-your-profile#preferences)
- [Appearance](/ja/user-guide/getting-started/initial-setup/manage-your-profile#appearance)

# General

**General** タブでは、現在のワークスペースにおける個人情報を編集できます。

1. 右上隅でプロフィールアイコンをクリックし、**My Profile** をクリックします。 <img src="/images/moengage_4abf33.png" alt="Screenshot 2025-04-22 at 6.37.04 PM.png" />
2. **My profile** ページでは、デフォルトで **General** タブが選択されています。
3. 右上隅の **Edit** をクリックします。 <img src="/images/moengage_25c22a.png" alt="Screenshot 2025-04-22 at 6.39.29 PM.png" />
4. プロフィール画像を追加します。
   1. プロフィールアイコンにカーソルを合わせ、編集アイコンをクリックします。 <img src="/images/moengage_0ca52c.png" />
   2. **Update** をクリックします。
   3. プロフィール画像を選択し、**Open** をクリックします。
      <Info>
        MoEngage では、.jpeg、.jpg、.png ファイルのみがサポートされています。
      </Info>
5. 次の詳細を編集します。
   | フィールド | 説明 |
   | --- | --- |
   | Name | 名前を入力します。 |
   | Email Id | このフィールドは読み取り専用です。 |
   | Role | このフィールドは読み取り専用です。 |
   | Active Since | このフィールドは読み取り専用です。 |
   | Job title | 役職を入力します。 |
   | Department | 部署名を入力します。 |
   | Phone number | 国番号を選択し、電話番号を入力します。 |
   | Date of birth | 日付ピッカーを使用して生年月日を選択します。 |
6. **Save** をクリックします。個人情報が更新されます。

# Security

**Security** タブには、現在のワークスペースのセキュリティを強化するためのツールが用意されています。

1. 右上隅でプロフィールアイコンをクリックし、**My Profile** をクリックします。 <img alt="Screenshot 2025-04-22 at 6.37.04 PM.png" src="/images/moengage_4abf33.png" />
2. **My profile** ページで、**Security** をクリックします。 <img src="/images/moengage_1fde0f.png" />
3. 次のタスクを実行できます。
   - [パスワードを変更する](#change-your-password)
   - [2 段階認証を管理する](#manage-2-step-verification)
   - [アクティブなデバイスからログアウトする](#log-out-of-your-active-devices)

## パスワードを変更する

パスワードを変更するには、次の手順を実行します。

1. **Security** タブで、**Password** セクションの右上隅にある **Change password** をクリックします。 <img src="/images/moengage_48bf1e.png" alt="Screenshot 2025-04-22 at 6.51.05 PM.png" />
2. 次の詳細を入力します。
   | フィールド | 説明 |
   | --- | --- |
   | Old password | 古いパスワードまたは既存のパスワードを入力します。 |
   | New password | 新しいパスワードを入力します。パスワードが次の条件を満たしていることを確認してください。 <ul><li>8～20 文字で構成されている。</li><li>大文字を 1 文字含む。</li><li>数字を 1 文字含む。</li><li>!@#\$%^&\*()\_?/,`<>`;:`{}` ~ のうち特殊文字を 1 文字含み、スペースを含まない。</li></ul> |
   | Retype new password | 新しいパスワードを再入力します。 |
3. **Save** をクリックします。パスワードが更新されます。

## 2 段階認証を管理する

MoEngage では、2 段階認証を使用して MoEngage ワークスペースを保護できます。これにより、パスワードの漏洩による不正アクセスのリスクを軽減できます。Admin は、ワークスペースレベルですべてのユーザーに対して有効にできます。詳細については、[2 段階認証または二要素認証 (2FA)](/ja/user-guide/settings/account/security/2-step-verification-or-two-factor-authentication-2fa) を参照してください。ただし、ユーザーレベルで管理することもできます。

### 2 段階認証を設定する

<Info>
  **Setup device** オプションは、次の両方の条件を満たす場合に表示されます。

  - Admin がワークスペースレベルで 2 段階認証を無効にしている。
  - ワークスペースに初めてログインする。
</Info>

1. My profile ページで、**Security** をクリックします。 <img src="/images/moengage_9e14ca.png" />
2. **2-step verification** の横にある **Setup device** をクリックします。 <img src="/images/moengage_c76b87.png" /> Set up your device authentication ポップアップウィンドウが表示されます。 <img src="/images/moengage_58eb44.png" alt="setup.png" />
3. 認証アプリ (例: Google Authenticator) を開き、**\+** アイコンをタップします。
   <img
     src="/images/moengage_3dbec7.png"
     style={{ width:"35%" }}
   />
   Add an authentication code 画面が表示されます。
   <img
     src="/images/moengage_dad2a7.png"
     style={{ width:"38%" }}
   />
4. 次のいずれかの認証オプションを使用します。
   - **QR コードを使用する**
     1. **Scan a QR code** をタップします。Scan code 画面が表示されます。
        <img
          src="/images/moengage_416a39.png"
          style={{ width:"35%" }}
        />
     2. MoEngage ダッシュボードの Set up your device authentication ポップアップウィンドウに表示されている QR コードをスキャンします。デバイスに認証が追加されます。認証アプリが 6 桁のコードを生成します。
   - **セットアップキーを使用する**
     1. **Enter a setup key** をタップします。
        <img
          src="/images/moengage_c6bdf9.png"
          style={{ width:"41%" }}
        />
     2. **Enter account details** 画面で、次の詳細を入力します。
        | フィールド | 必須 | 説明 |
        | --- | --- | --- |
        | Account name | 任意 | アカウント名を入力します。 |
        | Your key | はい | MoEngage ダッシュボードの Set up your device authentication ポップアップウィンドウに表示されている 32 桁のシークレットキーを入力します。  <img alt="setup.png" src="/images/moengage_58eb44.png" /> |
        | Type of key | 任意 | キーの種類です。サポートされている値は次のとおりです。 <ul><li>**Time based**: OTP は現在時刻に基づいて生成されます。</li><li>**Counter based**: OTP は増加するカウンターに基づいて生成されます。</li></ul> オプションを選択します。次の例では、_Time based_ が選択されています。 |
        <img
          src="/images/moengage_f6ebb2.png"
          style={{ width:"45%" }}
        />
     3. **Add** をタップします。
     4. **Account name** ボックスに入力した名前で、デバイスに認証が追加されます。認証アプリが 6 桁のコードを生成します。
        <img
          src="/images/moengage_20e2ed.png"
          style={{ width:"48%" }}
        />
5. **Enter the 6-digit verification code below** ボックスに、認証アプリが生成した 6 桁の認証コードを入力します。
   <Info>
     認証アプリが生成する各認証コードの有効期間は 30 秒のみです。その後、認証アプリは新しいコードを生成します。
   </Info>
   ![setup copy.png](/images/moengage_e5d748.png)
6. **Submit** をクリックします。\
   これで、MoEngage ワークスペース用の 2 段階認証がデバイスで正常に設定されました。

### 2 段階認証を有効にする

<Info>
  **Enable device** オプションは、Admin がワークスペースレベルで 2FA を無効にしており、かつ自分のワークスペースで有効にしていない場合にのみ表示されます。
</Info>

現在のワークスペースで 2FA を有効にするには、次の手順を実行します。

1. **My profile** ページで、**Security** をクリックします。 <img src="/images/moengage_9e14ca.png" />
2. **2 step verification** の横にある省略記号アイコンをクリックし、**Enable device** をクリックします。 <img src="/images/moengage_1379cd.png" /> Enable device ポップアップウィンドウが表示され、ワークスペースで 2FA を有効にするかどうかの確認が求められます。
3. **Enable** をクリックします。 <img src="/images/moengage_a0e357.png" />\
   これで、ワークスペースで 2FA が正常に有効になりました。

ワークスペースで 2FA を有効にすると、MoEngage ダッシュボードから自動的にログアウトされます。再度 MoEngage ダッシュボードにログインする際に、デバイスで 2 段階認証を設定する必要があります。詳細については、[デバイスで 2 段階認証を設定する](/ja/user-guide/getting-started/initial-setup/log-in-to-moengage#set-up-2-step-verification-on-your-device)を参照してください。

### 2 段階認証を削除する

<Info>
  **Remove device** オプションは、次の両方の条件を満たす場合にのみ表示されます。

  - 自分のワークスペースで 2FA を有効にしている。
  - Admin がワークスペースレベルで 2FA を無効にしている。
</Info>

現在のワークスペースから 2FA を削除するには、次の手順を実行します。

1. **My profile** ページで、**Security** をクリックします。 <img src="/images/moengage_9e14ca.png" />
2. **2 step verification** の横にある省略記号アイコンをクリックし、**Remove** **device** をクリックします。 <img src="/images/moengage_f7608e.png" /> Remove device ポップアップウィンドウが表示され、ワークスペースから 2FA を削除するかどうかの確認が求められます。
3. **Remove** をクリックします。 <img src="/images/moengage_d964c4.png" />\
   これで、ワークスペースから 2FA が正常に削除されました。

## アクティブなデバイスからログアウトする

**Active devices** には、このワークスペースへのアクセスに使用したすべてのデバイスが表示されます。デバイスからログアウトするには、次の手順を実行します。

1. ログアウトするアクティブなデバイスの横にあるログアウトアイコンをクリックします。デバイスが正常にログアウトされます。 <img src="/images/moengage_23de27.png" alt="Screenshot 2025-04-22 at 6.10.10 PM.png" />
2. すべてのアクティブなデバイスからログアウトするには、省略記号アイコンをクリックし、**Logout of all devices** をクリックします。 <img src="/images/moengage_19a4f9.png" alt="Screenshot 2025-04-22 at 6.11.19 PM.png" /> Logout ポップアップウィンドウが表示され、確認が求められます。
3. **Logout** をクリックします。 <img src="/images/moengage_db7bcc.png" />

# Preferences

**Preferences** タブでは、MoEngage ワークスペースの優先言語を選択したり、今後サポートしてほしい新しい言語を提案したりできます。

## ワークスペースの言語を選択する

MoEngage ワークスペースの言語はデフォルトで英語に設定されていますが、MoEngage がサポートする任意の言語に変更できます。

<Info>
  MoEngage は現在、日本語とブラジルポルトガル語をサポートしています。
</Info>

<Note>
  これは Early Access 機能です。ワークスペースで有効にするには、CSM に連絡するか、[サポートチケットを作成](/ja/user-guide/contact-support/raise-a-support-ticket-through-moengage-dashboard)してください。
</Note>

ワークスペースの言語を選択するには、次の手順を実行します。

1. **My profile** ページで、**Preferences** タブをクリックします。Language preferences ページが表示されます。
2. **Workspace language** リストで、優先言語を選択します。 <img alt="language preference.png" src="/images/moengage_e59a28.png" />

ワークスペースが選択した言語に切り替わります。

## 言語を提案する

**Workspace language** リストに優先言語が見つからない場合は、言語を提案できます。言語を提案するには、次の手順を実行します。

1. **Suggest a language** をクリックします。Suggest a language ダイアログボックスが表示されます。 <img src="/images/moengage_e8e46d.png" alt="Screenshot 2025-04-22 at 6.33.02 PM.png" />
2. **Select preferred language** リストで、MoEngage にサポートしてほしい言語を選択します。
3. **Done** をクリックします。

MoEngage が優先言語のサポートを開始すると、通知が届きます。

ワークスペースのテーマを変更するには、次のいずれかの手順を実行します。

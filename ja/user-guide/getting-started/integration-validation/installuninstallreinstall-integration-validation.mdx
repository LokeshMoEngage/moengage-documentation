このヘルプ記事では、Android および iOS プラットフォームにおけるインストール/アップデート/アンインストール/再インストールなど、**ユーザーアクションのテスト**に関する具体的な情報を説明します。

# 何を検証するのか

インストール、アップデート、アンインストール、再インストールが適切にトラッキングされていることを確認します。INSTALL イベントと UPDATE イベントは、SDK によって自動的にはトラッキングされません。SDK の連携方法に応じて、この情報を SDK に渡す必要があります。

# 検証方法

まず、MoEngage SDK と統合した後の Android/iOS 用のアプリビルドを入手します。

- デバイスにアプリビルドをインストールしてアプリを開くと、[ユーザープロファイル](/ja/user-guide/data/user-data/user-profile)に **INSTALL** イベントがトラッキングされます。

  <img alt="mceclip0.png" src="/images/moengage_7028cc.png" />
- 新しいバージョンがあり、デバイス上の既存のアプリにそのアプリビルドを上書きインストールした場合、ユーザープロファイルに **UPDATE** イベントがトラッキングされます。  
   <img alt="mceclip2.png" src="/images/moengage_249dea.png" />
- デバイスからアプリを削除またはアンインストールした場合、**UNINSTALL** がトラッキングされます(サイレントプッシュ、またはプッシュキャンペーンの送信/テストによる)。詳細については、[Uninstall tracking](/ja/user-guide/settings/analytics/uninstall-tracking) を参照してください。  
   <img alt="mceclip3.png" src="/images/moengage_d10c10.png" />
- アプリをアンインストールした後、同じデバイスに再度インストールすると、ユーザープロファイルに **REINSTALL** イベントがトラッキングされます。  
   <img alt="mceclip1.png" src="/images/moengage_07e072.png" />

# 成功基準

INSTALL、UPDATE、UNINSTALL、REINSTALL は、プッシュによるユーザーへの到達可能性を決定するため、ユーザープロファイル上でイベントとして正しくトラッキングされる必要があります。

<img alt="mceclip0.png"  src="/images/moengage_5a09ca.png"  />

- ユーザーがまだアプリをインストールしている場合、ユーザー属性の **Install status** は **true** になります。 <img alt="mceclip0.png"  src="/images/moengage_d0e485.png"  />

# 考えられる問題と解決策

- インストール/アップデートが正しくトラッキングされない場合、インストール時にユーザーをターゲットにして登録離脱のユースケースに対応するキャンペーンや、アプリのバージョンアップを促すキャンペーンを作成できません。INSTALL/UPDATE の問題を修正するには、プラットフォームに応じて [Android](/ja/developer-guide/android-sdk/data-tracking/basic/track-install-or-update) および [iOS](/ja/developer-guide/ios-sdk/data-tracking/basic/install-update-differentiation) を確認してください。
- アンインストールのトラッキングが正しく実装されていない場合、システム内に到達不能な古いユーザーが増えるなど、プッシュ配信に問題が生じる可能性があります。UNINSTALL トラッキングの問題を修正するには、こちらの[リンク](/ja/user-guide/settings/analytics/uninstall-tracking)を確認してください。

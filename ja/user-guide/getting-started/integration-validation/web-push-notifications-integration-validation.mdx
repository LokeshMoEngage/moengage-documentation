この記事では、Web プッシュ通知連携を手動で検証する方法を段階的に説明します。

# 何を検証するのか

プッシュ通知が正しく動作していることを確認します。

# 検証手順

1. プッシュトークンの生成

- [ユーザープロファイル](/ja/user-guide/data/user-data/user-profile)ページで、Web プッシュアイコンが緑色になっている必要があります。
  <Frame>
    ![DCT 450](/images/DCT-450.png)
  </Frame>
- ブラウザーに MoEngage 拡張機能をインストールして確認することもできます。[リンク](https://chrome.google.com/webstore/detail/moengage-sdk/dhggnkfnnoebbfofpimfehcklnekmbgi)
  <Frame>
    ![Download(18)](/images/download\(18\).png)
  </Frame>

2. デバイスでのプッシュ通知の受信

- ダッシュボードで、自分のデバイス向けに一般的なプッシュキャンペーンを作成します
- 作成の第 3 段階にあるテストオプションから通知をテストします。
- 成功のレスポンスが返された場合は、キャンペーンを作成します。失敗した場合は、失敗の理由を確認してください。
  <Frame>
    ![Download(19)](/images/download\(19\).png)
  </Frame>

3. 通知のリダイレクト

- キャンペーンの作成時にリダイレクト URL を指定します。メッセージを受信したらクリックし、その URL にリダイレクトされるか確認します
  <Frame>
    ![DCT 442](/images/DCT-442.png)
  </Frame>

4. 通知の統計情報

- キャンペーンが送信されると、キャンペーンの統計情報にインプレッションとクリックが表示されます。
  <Frame>
    ![Download(21)](/images/download\(21\).png)
  </Frame>

# 成功基準

1. ユーザーのプッシュトークンが生成されている必要があります
2. 通知が正しく表示される必要があります
3. リダイレクトが想定どおりに動作する必要があります
4. インプレッションとクリックが記録される必要があります。

# 考えられる問題と解決策

1. トークンが正しく生成されない場合、到達可能なユーザーベースが実際のユーザー数よりも少なくなります。トークンに関する問題を修正するには、[Web](/ja/developer-guide/web-sdk/web-push/web-push-overview) SDK のドキュメントを確認してください。
2. リダイレクトが正しくないと、混乱や機会損失につながります。
3. クリックとインプレッションが記録されない場合、キャンペーンの効果を把握できません。インプレッションとクリックのトラッキングに関する問題を修正するには、[Web](/ja/developer-guide/web-sdk/web-push/web-push-overview) SDK のドキュメントを確認してください。

ユーザーイベントの連携は、連携全体の中で最も重要な部分の 1 つです。イベントが MoEngage に正しく送信されていることを確認するには、以下の手順に従います。

# 何を検証するのか

- イベントトラッキングが想定どおりに動作していること。
- すべての属性がトラッキングされていること
- 属性のデータ型が正しいこと

# 検証方法

## イベントトラッキングを確認する

- アプリで、MoEngage でトラッキングする必要があるイベントを実行します
- MoEngage ダッシュボードで[ユーザープロファイル](/ja/user-guide/data/user-data/user-profile)を開き、Activity info に移動します
- このセクションで、実行したすべてのイベントを確認できます。 

<img src="/images/download1.png" alt="Download1" />

## イベント属性を確認する

- アクティビティ情報ページでイベントをクリックします。イベントが展開され、イベント属性が表示されます。
- イベントとともに渡す必要があるすべての属性を確認します
- Event Source は SDK、Platform はイベントが実行されたデバイスの種類、type は tracked user events である必要があります。 

<img src="/images/download2.png" alt="Download2" />

## 属性のデータ型を確認する

- 文字列データ型の属性には、is、contains、starts with などの文字列関連の演算子が必要です
- 日付属性には、on、in between、before、after などの演算子が必要です
- 数値属性には、equal to、greater than、in between などの演算子が必要です

# 考えられる問題と解決策

- 一意のイベント名 - プラットフォーム間でイベントに一意の名前を付けてトラッキングすることが最も重要です。
- イベント属性のデータ型 - プラットフォーム間でデータ型の一貫性を保つことも重要です。
- 適切なイベントトラッキングがないと、ユーザーの行動を特定できず、自動化キャンペーンを作成できません。イベントに関する問題を修正するには、[Android](/ja/developer-guide/android-sdk/data-tracking/basic/track-events)、[iOS](/ja/developer-guide/ios-sdk/data-tracking/basic/tracking-events)、[Web](/ja/developer-guide/web-sdk/data-tracking/web-sdk-events-tracking) のドキュメントを参照してください。

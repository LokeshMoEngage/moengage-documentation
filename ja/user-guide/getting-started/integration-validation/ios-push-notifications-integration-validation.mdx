この記事では、iOS プッシュ通知連携を手動で検証する方法を段階的に説明します。

# 何を検証するのか

プッシュ通知がデバイスで正しく動作していることを確認します。検証を進める前に、.pem/.p8 ファイルが [MoEngage ダッシュボードにアップロード](/ja/user-guide/campaigns-and-channels/mobile-push/getting-started-with-mobile-push/configure-mobile-push)されていることを確認してください。

# 検証方法

## 1. プッシュトークンの生成

  - [ユーザープロファイル](/ja/user-guide/data/user-data/user-profile)ページで、iOS のプッシュアイコンが緑色になっている必要があります。 
  <img alt="UserProfile_TestOptions.png" src="/images/moengage_8aa84d.png" />

2. デバイスでのプッシュ通知の受信

  - ダッシュボードで、自分のデバイス向けに一般的なプッシュキャンペーンを作成します。
  - 作成の第 3 段階にあるテストオプションから通知をテストします。
  - 成功のレスポンスが返された場合は、キャンペーンを作成します。テストが失敗した場合は、失敗の理由を確認してください。

  <img alt="download__12_.png" src="/images/moengage_63df2f.png" />

  - デバイス上のプッシュ通知にアイコンが表示されていることを確認します。

3. 通知のリダイレクト

  キャンペーン作成時には、次の画像に示すように、以下のデフォルトのクリックアクションがサポートされています。

  - 画面に移動
  - ディープリンク
  - リッチランディング

  ![Notification\_Redirection.png](/images/moengage_dba2f0.png)

**画面に移動**

キャンペーンの作成時に、画面に移動するオプションを選択し、ボックスに画面名を貼り付けます。通知を受信したらクリックし、ドロップダウンで選択した画面がアプリで開くことを確認します。

<img
  alt="NavigateToAScreen.png"
  src="/images/moengage_6bf763.png"
  style={{ width:"54%" }}
/>

**ディープリンク**

キャンペーンの作成時に、ディープリンクオプションを選択し、URL を追加します。通知をクリックすると、ユーザーはアプリ内の意図した箇所に正確にリダイレクトされる必要があります。

<img
  alt="Deeplinking.png"
  src="/images/moengage_63e380.png"
  style={{ width:"50%" }}
/>

**リッチランディング**

キャンペーンの作成時に、リッチランディングオプションを選択し、URL を追加します。通知をクリックすると、ユーザーは指定した URL の Web ページにリダイレクトされる必要があります。

<img
  alt="RichLanding.png"
  src="/images/moengage_cbfb0f.png"
  style={{ width:"55%" }}
/>

4. 通知の統計情報

  - キャンペーンが送信されると、キャンペーンの統計情報にインプレッションとクリックが表示されます。 

  <img alt="download__16_.png" src="/images/moengage_37cfcb.png" />

# 成功基準

1. ユーザーのプッシュトークンが生成されている必要があります。
2. 通知が正しく表示される必要があります。
3. リダイレクト(3 種類)が想定どおりに動作する必要があります。
4. インプレッションとクリックが記録される必要があります。
5. リッチ通知(ある場合)では、画像のレンダリング、通知音、ボタンとそのリダイレクトなどを確認してください。

# 考えられる問題と解決策

1. ユーザーのプッシュトークンが生成されている必要があります。プッシュトークンに関する問題を修正するには、[iOS](/ja/developer-guide/ios-sdk/push/basic/ios-push-integration-tutorial) のドキュメントを確認してください。
2. 通知が正しく表示される必要があります。
3. リダイレクト(3 種類)が想定どおりに動作する必要があります。
4. インプレッションとクリックが記録される必要があります。インプレッションまたはクリックに関する問題を修正するには、[iOS](/ja/developer-guide/ios-sdk/push/basic/ios-push-integration-tutorial) のドキュメントを確認してください。
5. リッチ通知(ある場合)では、画像のレンダリング、通知音、ボタンとそのリダイレクトなどを確認してください。リッチプッシュに関する問題を修正するには、[iOS](/ja/developer-guide/ios-sdk/push/basic/ios-push-integration-tutorial) のドキュメントを確認してください。
6. 注 - 以前のバージョンでは iOS のインプレッショントラッキングはデフォルトで提供されていませんでしたが、iOS 10 以降では [Notification Service extension](/ja/developer-guide/ios-sdk/push/basic/ios-push-integration-tutorial) の機能を使用して統合できます。

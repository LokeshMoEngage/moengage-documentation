このヘルプ記事では、Android、iOS、Web サイトの各プラットフォームにおけるログイン/ログアウト/ユーザー属性に関するユーザープロファイルのテストについて説明します。

# 何を検証するのか

ログイン ID、メールアドレス、電話番号、その他のユーザー属性が正しくトラッキングされていることを確認します

# 検証方法

- まず、MoEngage SDK と統合した後の Android/iOS 用のアプリビルドまたは Web サイトを用意します。
- デバイスにアプリビルドをインストールするか Web サイトを開いたら、アプリ/Web サイトの設計に応じて、メールアドレス、電話番号、ソーシャルログインなどの個人情報でログインします。
- ログインに成功すると、アプリ/Web サイトがデータを取得し、MoEngage ダッシュボードにユーザープロファイルが作成されます。
- ログインに成功したら、以下のように、アプリ/Web サイトでトラッキングされたメールアドレス、電話番号、または ID を使用して MoEngage のセグメンテーションダッシュボードで検索できます。ユーザーが作成されている場合、結果の件数は 1 と表示されます。以下に示すように、Sample Users セクション内の人物アイコンをクリックすると、[ユーザープロファイル](/ja/user-guide/data/user-data/user-profile)を確認できます。

![DCT 1675](/images/DCT-1675.png)

![DCT 1675 2](/images/DCT-1675-2.png)

- 説明のとおり、ID、メールアドレス、電話番号、その他のユーザー属性が MoEngage ダッシュボードで正しくマッピングされていることを確認します。一部のユーザー属性は MoEngage SDK によって標準ユーザー属性としてトラッキングされ、**Tracked Standard Attribute** の下に表示されます。

![Mceclip2](/images/mceclip2.png)

- カスタムユーザー属性がトラッキングされている場合は、説明のとおりに確認できます。MoEngage SDK によってトラッキングされない標準ユーザー属性以外の属性は、**Tracked Custom Attribute** の下に表示されます。

![Mceclip1 1](/images/mceclip1-1.png)

# 成功基準

- ID は MoEngage システムで最も重要なデータポイントの 1 つです。どのユーザーでもユーザー属性のトラッキングは重要ですが、登録ユーザーには ID が必須です。ユーザーに一意の ID が指定されていない場合、Android、iOS、Web、またはその他の分析システムのトラッキングにわたるユーザーのマージやプロファイル管理が単一のプロファイルに同期されません。アプリ/Web サイトのログイン時にログイン ID が正しく設定されていれば、ユーザープロファイルは説明のとおりに表示されます。同様に、その他すべてのユーザー属性もトラッキングされる必要があります。ログイン ID またはユーザー属性に関する問題を修正するには、[Android](/ja/developer-guide/android-sdk/data-tracking/basic/track-user-attributes)、[iOS](/ja/developer-guide/ios-sdk/data-tracking/basic/tracking-user-attributes)、[Web](/ja/developer-guide/web-sdk/data-tracking/web-sdk-user-attributes-tracking) を参照してください

![Mceclip3 1](/images/mceclip3-1.png)

- アプリにログアウト機能があり、正しく実装されている場合は、Logout ボタンをクリックすると正常にトラッキングされ、Android、iOS、Web などのプラットフォーム名とともに説明のとおりに表示されます。ログアウトの問題を修正するには、[Android](/ja/developer-guide/android-sdk/data-tracking/basic/track-user-attributes)、[iOS](/ja/developer-guide/ios-sdk/data-tracking/basic/tracking-user-attributes)、[Web](/ja/developer-guide/web-sdk/data-tracking/web-sdk-user-attributes-tracking) を参照してください。

  ![Mceclip4 1](/images/mceclip4-1.png)

# 考えられる問題と解決策

- アプリ/Web サイトへのログイン時にログイン ID が正しく設定されていない場合、ユーザーデータが破損する可能性があります。\
  ログイン ID に関する問題を修正するには、[Android](/ja/developer-guide/android-sdk/data-tracking/basic/track-user-attributes)、[iOS](/ja/developer-guide/ios-sdk/data-tracking/basic/tracking-user-attributes)、[Web](/ja/developer-guide/web-sdk/data-tracking/web-sdk-user-attributes-tracking) を参照してください。
- ログイン ID、メールアドレス、電話番号、その他のユーザー属性がユーザープロファイルで正しくトラッキングされていない場合、プッシュ、SMS、メールチャネルでのコミュニケーションのデータ破損につながり、パフォーマンス統計にも問題が生じる可能性があります。ユーザー属性に関する問題を修正するには、[Android](/ja/developer-guide/android-sdk/data-tracking/basic/track-user-attributes)、[iOS](/ja/developer-guide/ios-sdk/data-tracking/basic/tracking-user-attributes)、[Web](/ja/developer-guide/web-sdk/data-tracking/web-sdk-user-attributes-tracking) を参照してください。
- ユーザーのログアウト時にログアウトがトラッキングされない場合、データが破損する可能性があります。ログアウトの問題を修正するには、[Android](/ja/developer-guide/android-sdk/data-tracking/basic/track-user-attributes)、[iOS](/ja/developer-guide/ios-sdk/data-tracking/basic/tracking-user-attributes)、[Web](/ja/developer-guide/web-sdk/data-tracking/web-sdk-user-attributes-tracking) を参照してください。

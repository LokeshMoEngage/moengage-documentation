この記事では、Android プッシュ通知連携を手動で検証する方法を段階的に説明します。

# 何を検証するのか

プッシュ通知がデバイスで正しく動作していることを確認します。

# 検証方法

1. プッシュトークンの生成

- [ユーザープロファイル](/ja/user-guide/data/user-data/user-profile)ページで、Android のプッシュアイコンが緑色になっている必要があります。
  ![DCT 407](/images/DCT-407.png)

2. デバイスでのプッシュ通知の受信

- ダッシュボードで、自分のデバイス向けに一般的なプッシュキャンペーンを作成します。
- 作成の第 2 段階にあるテストオプションから通知をテストします。
  ![AndroidTest.png](/images/moengage_6561be.png)
- 成功のレスポンスが返された場合は、キャンペーンを作成します。失敗した場合は、失敗の理由を確認してください。
- デバイス上のプッシュ通知に 2 つのアイコンが表示されていることを確認します。

3. 通知のリダイレクト

キャンペーン作成時には、次の画像に示すように、以下のデフォルトのクリックアクションがサポートされています。

- 画面に移動
- ディープリンク
- リッチランディング

![NotificationRedirection\_Android.png](/images/moengage_6b3732.png)

**画面に移動**

キャンペーンの作成時に、画面に移動するオプションを選択し、ドロップダウンから画面を選択します。通知を受信したらクリックし、ドロップダウンで選択した画面がアプリで開くことを確認します。

<img
  alt="Navigate_to_screen_Android.png"
  src="/images/moengage_ee4077.png"
  style={{ width:"49%" }}
/>

**ディープリンク**

キャンペーンの作成時に、ディープリンクオプションを選択し、URL を追加します。通知をクリックすると、ユーザーはアプリ内の意図した箇所に正確にリダイレクトされる必要があります(KV ペアがある場合は追加してください)。

<img

  style={{ width:"58%" }}
/>

**リッチランディング**

キャンペーンの作成時に、リッチランディングオプションを選択し、URL を追加します。通知をクリックすると、ユーザーは Web にリダイレクトされる必要があります。

/>

4. 通知の統計情報

- キャンペーンが送信されると、キャンペーンの統計情報にインプレッションとクリックが表示されます。
  ![Download1 1](/images/download1-1.png)

# 成功基準のまとめ

1. ユーザーのプッシュトークンが生成されている必要があります
2. 小さいアイコンと大きいアイコンを含め、通知が正しく表示される必要があります
3. リダイレクト(3 種類)が想定どおりに動作する必要があります
4. インプレッションとクリックが記録される必要があります。
5. リッチ通知(ある場合)では、画像のレンダリング、通知音、ボタンとそのリダイレクトなどを確認してください。

# 考えられる問題と解決策

1. トークンが正しく生成されない場合、到達可能なユーザーベースが実際のユーザー数よりも少なくなります。トークンの問題を修正するには、[Android](/ja/developer-guide/android-sdk/push/basic/push-configuration) のドキュメントを確認してください。
2. リダイレクトが正しくないと、混乱や機会損失につながります
3. クリックとインプレッションが記録されない場合、キャンペーンの効果を把握できません。インプレッションまたはクリックのトラッキングに関する問題を修正するには、[Android](/ja/developer-guide/android-sdk/push/basic/push-configuration) のドキュメントを確認してください。

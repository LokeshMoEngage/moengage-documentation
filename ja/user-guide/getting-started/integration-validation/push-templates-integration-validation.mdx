このヘルプ記事では、Android および iOS プラットフォームにおけるプッシュテンプレートのテストについて具体的に説明します。

# 何を検証するのか

基本、スタイル付き、カルーセルのプッシュ通知をデバイスで受信できることを確認します。

# 検証方法

- まず、MoEngage SDK と統合した後の Android/iOS 用のアプリビルドを入手します。
- デバイスにアプリビルドをインストールしたら、アプリを開いて一度閲覧します。
- 次に、MoEngage ダッシュボードに移動し、以下のスクリーンショットのようにプッシュキャンペーンを作成します。
  ![DCT-326-2.png](/images/moengage_f33f63.png)
- プッシュキャンペーン作成の次のステップで、キャンペーンの詳細を入力してからコンテンツを選択します。以下のスクリーンショットのように、Basic Notification、Stylised Push Notification、Simple Image Carousel Push Notification の 3 つのオプションがあります。
  ![DCT-326-3.png](/images/moengage_4ec95c.png)
- **Basic Push Notification** - デザインのない基本的なプッシュ通知レイアウトで、Message Title、Message Body、summary などのプッシュの主要パラメーターがあります。これらの詳細を入力し、デバイスで受信したプッシュをテストできます。
  ![DCT-326-4.png](/images/moengage_138a2f.png)
- **Stylised Push Notification** - 高度なデザインオプションを備えたスタイル付きプッシュ通知レイアウトで、Message Title、Body、Summary などの同じ主要パラメーターがあります。これらの詳細を入力し、デバイスで受信したプッシュをテストできます。
  ![DCT-326-5.png](/images/moengage_fb4fd9.png)
- **Image Carousel Push Notification** - 高度なデザインオプションを備えたスタイル付き画像カルーセルプッシュ通知レイアウトで、Message Title、Body、Summary などの主要パラメーターに加え、複数画像用のアクションスライドもあります。これらの詳細を入力し、デバイスで受信したプッシュをテストできます。
  ![DCT-326-6.png](/images/moengage_a696b9.png)

# 考えられる問題と解決策

Push Templates 機能が実装されていない場合、スタイル付きプッシュや画像付きカルーセルプッシュをキャンペーンで使用できません。Push Templates に関する問題を修正するには、[Android](/ja/developer-guide/android-sdk/push/optional/push-templates) および [iOS](/ja/developer-guide/ios-sdk/push/optional/push-templates) のドキュメントを確認してください。

MoEngage はカスタマーエンゲージメントプラットフォームです。ユーザーに関するデータや、アプリまたはウェブサイトでのユーザーの行動データを MoEngage に送信すると、MoEngage はユーザーごとに 1 つのプロファイルを構築します。プラットフォームのその他すべての機能は、これらのプロファイルを基に動作します。ユーザーをセグメント化し、複数のチャネルでユーザーにリーチし、ユーザー体験をパーソナライズし、結果を分析できます。MoEngage の AI レイヤーである Merlin AI は、これらすべてにわたって機能します。

## MoEngage の仕組み

このページで紹介する一部の機能は、ご利用の MoEngage プランまたは有料アドオンによって異なります。たとえば、Inform はプランによって異なり、イベントエクスポートは Streams アドオンに、セグメント同期は Connected Segments アドオンに含まれます。

<FeatureAvailability />

### 1. データを収集する

開発者が MoEngage SDK をアプリまたはウェブサイトに統合し、REST API を通じてサーバーサイドのデータを送信します。データチームは、ファイルをインポートしたり、データウェアハウスを接続したりすることもできます。詳細については、[概要 - データ](/ja/user-guide/data/key-concepts/overview-data)および[インポート](/ja/user-guide/data/imports/overview-imports)を参照してください。

### 2. ユーザープロファイルを統合する

MoEngage は、受信したイベントと属性をユーザーごとに 1 つのプロファイルに統合します。匿名で閲覧した後にサインインした訪問者も、1 つのプロファイルを保持します。詳細については、[ユーザープロファイル](/ja/user-guide/data/user-data/user-profile)および[匿名ユーザーから登録ユーザーへのマージ](/ja/user-guide/data/user-data/anonymous-to-registered-user-merge)を参照してください。

### 3. ユーザーとエンゲージする

プロファイルデータからセグメントを作成し、単一チャネルでのワンタイムキャンペーンや、ユーザーの行動に応じて複数のチャネルをまたいでユーザーを誘導するフローで、それらのユーザーにリーチします。Inform でトランザクションアラートを送信し、訪問者ごとにウェブサイトをパーソナライズします。詳細については、[セグメンテーションの基本](/ja/user-guide/segment/getting-started/basics-of-segmentation)、[MoEngage のチャネル](/ja/user-guide/campaigns-and-channels/getting-started/introduction/moengage-channels)、[概要 - Flows](/ja/user-guide/flows-cross-channel-messaging/getting-started/overview-flows/overview-flows)、[概要 - Inform](/ja/user-guide/inform/overview-inform)、および[概要 - Personalize](/ja/user-guide/personalize/overview/overview-personalize)を参照してください。

### 4. 結果を測定する

アプリやウェブサイトでのユーザーの行動と、キャンペーンやフローのパフォーマンスを追跡し、セグメントやメッセージを改善します。詳細については、[MoEngage Analytics](/ja/user-guide/analyze/moengage-analytics/overview)を参照してください。

### Merlin AI

Merlin AI は、ユーザー行動を予測し、メッセージごとに最適な時間とチャネルを選択し、セグメントやフローの作成を支援し、コンテンツを生成します。キャンペーンおよびオファーのディシジョニングにより、各ユーザーが受け取るキャンペーンやオファーが選択されます。詳細については、[Merlin AI Studio](/ja/user-guide/ai-and-intelligence/merlin-ai/merlin-ai-studio)を参照してください。

### データの送信

イベントをデータウェアハウスやクラウドストレージにエクスポートしたり、セグメントを広告ネットワークやその他のツールに同期したり、MoEngage MCP サーバーを通じて AI アシスタントをワークスペースに接続したりできます。詳細については、[概要 - イベントエクスポート](/ja/user-guide/data/exports/events/overview-events-exports)、[アウトバウンドセグメント同期](/ja/user-guide/data/exports/segments/outbound-segment-sync)、および[MoEngage MCP サーバーとコネクタ](/ja/user-guide/ai-and-intelligence/merlin-ai/moengage-mcp-server)を参照してください。

## 主要な概念

これらの用語は、ダッシュボードやドキュメント全体で使用されます。全一覧については、[知っておくべき用語](/ja/user-guide/getting-started/overview/terms-to-know)を参照してください。

| 用語 | 意味 |
| --- | --- |
| ワークスペース | MoEngage ダッシュボードでチームが作業するアカウントです。各ワークスペースには Test 環境と Live 環境があります。 |
| Test 環境と Live 環境 | Test 環境は統合と QA のための環境で、Live 環境は本番データとキャンペーンのための環境です。各環境には独自のワークスペース ID と設定があり、**Settings** > **Account** > **General settings** から確認できます。詳細については、[Live 環境と Test 環境](/ja/user-guide/getting-started/initial-setup/dashboard-overview#live-and-test-environments)を参照してください。 |
| データセンター | MoEngage がワークスペースをホストするリージョンです。ダッシュボードの URL や、SDK および API のエンドポイントを決定します。詳細については、[MoEngage のデータセンター](/ja/user-guide/data/key-concepts/data-centers-in-moengage)を参照してください。 |
| ユーザープロパティ | 名前、メールアドレス、都市など、ユーザーのプロパティです。 |
| イベント | 商品の閲覧や購入など、ユーザーが行うアクションです。イベントは独自の属性を持つことができます。 |
| セグメント | ターゲティングまたは分析の対象となるユーザーのグループです。ユーザーデータに対する条件で定義するか、ファイルからアップロードします。 |
| キャンペーン | プッシュ通知やメールなど、1 つのチャネルで送信するメッセージです。 |
| フロー | ユーザーの行動に応じて複数のチャネルをまたいでユーザーを誘導する、複数ステップのジャーニーです。 |

## ワークスペースを設定する

ステップ 3 と 5、およびステップ 4 でのプッシュ認証情報の追加には、開発者の作業が必要です。

<Steps>
  <Step title="ログインしてアクセスを保護する">
    ダッシュボードにログインし、2 段階認証を設定します。組織で ID プロバイダーを使用している場合は、シングルサインオン (SSO) を設定します。

    詳細については、[MoEngage へのログイン](/ja/user-guide/getting-started/initial-setup/log-in-to-moengage)および[シングルサインオン (SSO)](/ja/user-guide/settings/account/security/single-sign-on-sso)を参照してください。
  </Step>

  <Step title="チームを招待する">
    チームメンバーを追加し、それぞれにアクセスロールを割り当てて、必要なダッシュボードの部分のみが表示されるようにします。

    詳細については、[メンバーの管理](/ja/user-guide/settings/account/team-management/manage-members)および[アクセスロール](/ja/user-guide/settings/account/team-management/access-roles)を参照してください。
  </Step>

  <Step title="データを統合する">
    開発者が MoEngage SDK をアプリまたはウェブサイトに追加し、使用する予定のイベントと属性をトラッキングします。開発者が作業を始める前に、統合チェックリストを使用してトラッキングする内容について合意しておきます。

    どの環境がデータを受信するかは SDK によって決まります。Android と iOS では、デバッグビルドは Test 環境に、署名済みのリリースビルドは Live 環境にデータを送信します。Web SDK では、開発者が SDK の設定で環境を `TEST` または `LIVE` に設定します。

    詳細については、[統合チェックリスト](/ja/user-guide/getting-started/integration/integration-checklist)、[SDK 統合ガイド](/ja/developer-guide/introduction)、および[インポート](/ja/user-guide/data/imports/overview-imports)を参照してください。
  </Step>

  <Step title="チャネルを設定する">
    使用する予定の各チャネルを設定します。たとえば、メール送信者を接続したり、SMS または WhatsApp プロバイダーを接続したり、プッシュ認証情報を追加したりします。プッシュ認証情報は、Android の場合は Firebase プロジェクトから、iOS の場合は Apple Developer アカウントから取得します。Test 環境と Live 環境の両方に追加してください。

    詳細については、[MoEngage のチャネル](/ja/user-guide/campaigns-and-channels/getting-started/introduction/moengage-channels)を参照してください。
  </Step>

  <Step title="統合を検証する">
    アプリのデバッグビルド、または `TEST` に設定したウェブサイトを使用して、データが Test 環境に送信されるようにします。イベントとユーザープロパティが MoEngage に届いていること、テスト用のプッシュ通知とアプリ内メッセージがデバイスに届いていることを確認します。検証が完了したら、アプリの署名済みビルドをリリースするか、ウェブサイトを `LIVE` に設定して、本番データが Live 環境に送信されるようにします。

    詳細については、[ユーザーイベント統合の検証](/ja/user-guide/getting-started/integration-validation/user-events-integration-validation)、[ユーザープロパティ/プロファイル統合の検証](/ja/user-guide/getting-started/integration-validation/user-attributeprofile-integration-validation)、[Android プッシュ通知統合の検証](/ja/user-guide/getting-started/integration-validation/android-push-notifications-integration-validation)、[iOS プッシュ通知統合の検証](/ja/user-guide/getting-started/integration-validation/ios-push-notifications-integration-validation)、[Web プッシュ通知統合の検証](/ja/user-guide/getting-started/integration-validation/web-push-notifications-integration-validation)、および[アプリ内通知統合の検証](/ja/user-guide/getting-started/integration-validation/in-app-notifications-integration-validation)を参照してください。
  </Step>

  <Step title="最初のキャンペーンを開始する">
    リーチしたいユーザーのセグメントを作成し、キャンペーンを送信して、結果を確認します。

    詳細については、[セグメンテーションの基本](/ja/user-guide/segment/getting-started/basics-of-segmentation)、[プッシュキャンペーンの作成](/ja/user-guide/campaigns-and-channels/mobile-push/create/create-push-campaigns)、および[キャンペーン統計](/ja/user-guide/analyze/dashboards/campaign-stats)を参照してください。
  </Step>
</Steps>

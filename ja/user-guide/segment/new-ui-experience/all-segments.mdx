All Segments ページでは、MoEngage で作成・使用されているすべてのカスタムセグメントを一元的に表示できます。これにより、グロースチームはカスタムセグメントの概要を 1 か所ですばやく把握し、それらに対してアクションを実行できます。また、All Segments ページから各カスタムセグメントの詳細ページに移動することもできます。アカウントで Teams が有効になっている場合は、アクセス権のあるすべてのチーム向けに作成されたカスタムセグメントが表示されます。特定のチーム向けに作成されたカスタムセグメントを表示するには、**All Segments for** ドロップダウンリストでチームを選択します。

# すべてのセグメント

このページにはすべてのカスタムセグメントが一覧表示され、カスタムセグメント名、セグメントタイプ（ファイルセグメントまたはフィルターセグメント）、セグメントの作成日時、セグメントの最終実行日時（クエリまたはキャンペーンでセグメントが最後に実行された日時）、およびカスタムセグメントに対して実行できるアクションが表示されます。

カスタムセグメント名をクリックすると、そのセグメントの詳細ページに移動します。

テーブルは任意の列で昇順または降順に並べ替えることができます。デフォルトでは、最終実行日時の降順で並べ替えられています。

<img alt="Teams_AllSegments.png" src="/images/moengage_3d956b.png" />

検索ボックスに目的のセグメント名を入力して、セグメントを検索できます。

セグメントは、セグメントタイプ（ファイルセグメントまたはフィルターセグメント）でフィルタリングすることもできます。

1. **ファイルセグメント** - グロースチームがユーザーリストをアップロードしたときに作成されるカスタムセグメントです。一意のユーザーを識別するユーザー属性のいずれかを含むユーザーリストをインポートすると、それらのユーザーのカスタムセグメントが作成されます。[ファイルセグメントの詳細については、こちらの記事をご覧ください](/ja/user-guide/segment/create-segments/file-segments)。

2. **フィルターセグメント** - MoEngage ダッシュボードから作成されるカスタムセグメントです。グロースチームはルールと条件を作成してユーザーセグメントを定義できます。ルールと条件は、ユーザー属性/プロパティ、イベントとイベントプロパティ、およびその両方の組み合わせに適用できます。[フィルターセグメントの詳細はこちらをご覧ください。](/ja/user-guide/segment/create-segments/rule-based-filter-segments)

**+ Segment** をクリックするとパネルが開き、**Create Segment** ページ（フィルターセグメントを作成する場合）、RFM セグメントページ、**Create File Segment** ポップアップ（ファイルセグメントを作成する場合）に移動できます。Teams が有効で、複数のチームに所属している場合は、**+ Segment** をクリックする前に **Teams** ドロップダウンからチームを選択する必要があります。

<Note>
Segmentation Filters を使用した MoEngage Teams はベータ機能です。アカウントで有効にするには、CSM にお問い合わせください。
</Note>

## アーカイブ済みセグメント

All Segments ページで Archived Segment トグルをクリックすると、アーカイブ済みセグメントの一覧ページに移動します。

過去 6 か月以内にアーカイブされたフィルターセグメント（最大 1000 件のアーカイブ済みセグメント）がここに一覧表示されます。ここからこれらのセグメントのアーカイブを解除できます。

アーカイブ日から 30 日を超えたファイルセグメントは有効期限切れとなるため、このページには表示されません。[ファイルセグメントの詳細はこちらをご覧ください。](/ja/user-guide/segment/create-segments/file-segments) アーカイブから 30 日以内であれば、このページからファイルセグメントのアーカイブを解除できます。

# カスタムセグメントに対するアクション

| アクション | 説明 |
| --- | --- |
| View | ファイルセグメントとフィルターセグメントのどちらの場合も、View をクリックするとそのセグメントの詳細ページに移動します。 |
| Edit | 1. フィルターセグメントの場合、Edit オプションを選択すると、セグメントのフィルターが事前入力された状態で Create Segments ページが開きます。これらのフィルターを編集し、新しいクエリを新しいカスタムセグメントとして保存できます。 2. ファイルセグメントの場合、Edit オプションを使用して、既存のファイルセグメントのユーザーを追加、削除、または置換できます。[ファイルセグメントの詳細はこちらをご覧ください。](/ja/user-guide/segment/create-segments/file-segments) |
| Duplicate | 1. フィルターセグメントの場合、Duplicate オプションを選択すると、セグメントのフィルターが事前入力された状態で Create Segments ページが開きます。これらのフィルターを編集し、新しいクエリを新しいカスタムセグメントとして保存できます。 2. ファイルセグメントは複製できません。 |
| Archive | ファイルセグメントとフィルターセグメントはいずれも、セグメントソースに応じてダッシュボードからアーカイブできます。 |
| Export Users | Export Users を使用すると、そのセグメントに属する 1 つ以上のユーザー属性をダウンロードできます。最新のユーザーリストを取得するには、ユーザーをエクスポートする前にカスタムセグメントを実行してください。 |
| Create Campaign | Create Campaign アクションを選択すると、セグメントの定義が Target Audience に事前入力された状態でキャンペーン作成ページに移動します。 |
| Analyze Segment | Segmentation ページからセグメントを直接分析できます。このアクションにより、Behavior、Funnels、Retention、Session and Source、User Paths、RFM 分析の Target audience セクションにセグメントが自動入力されます。 |

## セグメントソース

すべてのカスタムセグメントは、MoEngage 上のどこで作成されたか、またはどこから MoEngage システムにインポートされたかに応じて、次のいずれかのソースに分類されます。

| ソース | 説明 | 利用可能なアクション |
| --- | --- | --- |
| Segmentation | MoEngage Segmentation から作成されたカスタムセグメントのソースは Segmentation になります。 | 1. View  2. Edit  3. Duplicate  4. Archive/Unarchive  5. Export Users  6. Create Campaign  7. Analyze Segment |
| CSV Upload, API, Import Users | ファイルセグメントとして MoEngage システムにアップロードされたカスタムセグメントです。ファイルセグメントは複製できません。 | 1. View  2. Edit  3. Archive/Unarchive  4. Export Users  5. Create Campaign  6. Analyze Segment |
| Campaigns, Analyse, Prediction, Campaign Locale, Global Control Group, Custom | Campaigns、Analyze、Predictions など、Segmentation 以外のソースから MoEngage 上で作成されたカスタムセグメントです。これらのセグメントが含まれるキャンペーンや分析に影響を与える可能性があるため、Edit、Duplicate、Archive、Unarchive などの編集アクションは利用できません。 | 1. View  2. Export Users  3. Create Campaign  4. Analyze Segment |
| Cohort Sync, Amplitude, Mixpanel, mParticle, Segment IO | 他のサードパーティまたは外部ソースから MoEngage システムにインポートされたカスタムセグメントです。外部で管理されているため、Edit、Duplicate、Archive、Unarchive などの編集アクションは利用できません。 | 1. View  2. Export Users  3. Create Campaign  4. Analyze Segment |

# セグメントの詳細

任意のセグメントの詳細ページにアクセスするには、次の手順を実行します。

1. MoEngage のサイドバーメニューで、**Segment** メニュー項目 <img alt="Screenshot 2025-06-16 at 3.25.14 PM.png"  src="/images/moengage_9fbff8.png"  /> にカーソルを合わせます。**Segment** メニューが表示されます。
2. **All Segments** をクリックします。  
    <img alt="Screenshot 2025-06-17 at 10.54.43 AM.png"   src="/images/moengage_732db1.png"   />   
   All Segments ページが表示されます。
3. 任意のセグメント名の **Actions** 列で、省略記号をクリックして **View** を選択します。  
    <img alt="Screenshot 2025-06-17 at 10.57.38 AM.png"  src="/images/moengage_a0970c.png"  />

Segment Details ページには、セグメントのタイプ、説明、作成日時、ソース、最終実行日時が表示されます。

このページには、カスタムセグメントのユーザー数、到達可能なユーザー、最終更新日時も表示されます。ここからセグメントを実行して、最新のユーザー数と到達可能なユーザーを取得することもできます。

カスタムセグメントに対するすべてのアクション（編集、複製、アーカイブ、ユーザーのエクスポート、キャンペーンの作成）は、セグメントタイプとセグメントソースに基づいてこのページで利用できます。

グロースチームは、現在 Create Segment ページで利用できるのと同様に、到達可能性とサンプルユーザーの情報も確認できます。また、セグメントのタイプに応じて Segment Edit History を確認することもできます。

<img alt="All_segments_3.gif" src="/images/moengage_f732dc.png" />

## 到達可能性とサンプルユーザー

**Reachable Users**

すべてのアウトバウンドチャネル（Push、Email、SMS）にわたる到達可能なユーザー数が表示されます。到達可能なユーザー数は、特定のチャネルごとに個別に確認することもできます。

**サンプルユーザー**のイニシャルまたは GU（Guest の略）- これらのバブルをクリックすると、ユーザープロファイルが開きます。

## セグメント編集履歴

Segment Details ページの Segment Edit History セクションは、選択したセグメントのセグメントタイプに基づいて表示されます。

### ファイルセグメントの編集履歴

ファイルセグメントの編集履歴には、Segment Edited on（編集日時）、Operation（ユーザーの Add、Remove、Replace）、Status of Operation、処理されたファイルの詳細の各列が表示されます。

<img alt="All_Segments_4.png" src="/images/moengage_c52fce.png" />

Status of Operation には次の値があります。

1. Pending: 処理キューに別のファイルがすでにあるため、まだ処理されていないファイルセグメントです。
2. Processing: システムで現在処理中のファイルセグメントです。
3. Successful: 正常に処理され、属性が更新されたファイルセグメントです。
4. Failed: 処理中に失敗したファイルセグメントです。このステータスにカーソルを合わせると、失敗の理由も確認できます。

処理されたファイルの詳細:

1. 1. Attribute name: この列には、ファイルでアップロードされたユーザー属性とそのデータ型が表示されます。
   2. Valid attributes: アップロードされたファイル内で正常に処理されたレコードの数を示します。
   3. Users resolved: ファイルで提供されたユーザー属性で更新された既存ユーザーの数を示します。これらのユーザーはカスタムセグメントの一部になります。
   4. Invalid attributes: ファイル内で処理中に失敗したレコードの数を示します。

デフォルトでは、このテーブルは「Segment edited on」列で並べ替えられ、最新の編集が最初に表示されます。ファイルセグメントの編集履歴では、直近 20 件の編集を確認できます。

### フィルターセグメントの編集履歴

フィルターセグメントの編集履歴には、Segment edited on（編集日時）、Segment description、Option（Use this version）の各列が表示されます。

<img alt="All_Segments_5.png" src="/images/moengage_96d8e3.png" />

セグメントの古いバージョンで **Use this version** をクリックすると、現在のセグメント定義を選択したバージョンに更新できます。セグメント数を更新して、編集したセグメントの最新のユーザー数と到達可能性を取得してください。

デフォルトでは、このテーブルは「Segment edited on」列で並べ替えられ、最新の編集が最初に表示されます。フィルターセグメントの編集履歴では、直近 20 件の編集を確認できます。

## 同期済みセグメント

MoEngage で作成した顧客セグメントを、テックスタック内の他のプラットフォームに同期して送信できます。詳細については、[Outbound Segment Sync](/ja/user-guide/data/exports/segments/outbound-segment-sync) を参照してください。

グロースチームは、ユーザーとユーザーデータに対して独自の分析を行うことがよくあります。分析後、グロースチームはこれらのユーザーをキャンペーンで使用したり、さらに分析を行ったりしたいと考えます。

これらのユーザーは MoEngage にアップロードしてファイルセグメントとして使用できます。ファイルセグメントはユーザーのリストです。ファイルセグメントは MoEngage のキャンペーンや Analytics に使用できます。

ファイルセグメントを使用すると、自社で行ったユーザー分析によって特定したユーザーセグメントを柔軟に作成し、ターゲットにすることができます。一意のユーザーを識別するユーザー属性のいずれかを含むユーザーリストをインポートすると、それらのユーザーのカスタムセグメントが作成されます。

# ファイルセグメントの作成

ファイルセグメントを作成するには、次の手順を実行します。

1. MoEngage のサイドバーメニューで、**Segment** メニュー項目 <img alt="Screenshot 2025-06-16 at 3.25.14 PM.png"  src="/images/moengage_a43049.png"  />  にカーソルを合わせます。**Segment** メニューが表示されます。
2. **+ All Segments** をクリックします。  
    <img alt="Screenshot 2025-06-17 at 10.54.43 AM.png"  src="/images/moengage_2c3e92.png"  />   
   All Segments ページが表示されます。
3. **+ Segment** をクリックします。  
    <img alt="2025-06-17_12-05-45.png" src="/images/moengage_11f966.png" />   
   **New Segment** ダイアログボックスが表示されます。
4. **File Segment** をクリックします。  
    <img alt="Screenshot 2025-06-17 at 12.08.20 PM.png"  src="/images/moengage_be5dd2.png"  />   
   **Create file segment** ダイアログボックスが表示されます。
5. 次の手順を実行します。  
    <img alt="File_segment_3.gif"  src="/images/moengage_94aa1c.png"  />
   1. **Custom segment name** と **Segment description** を入力します。

      <Note>
      `All Users` という名前は MoEngage で予約されているため、カスタムセグメント名として使用できません。また、名前には `:` `|` `*` `?` `\` `<` `>` `=` `$` `"` の文字を含めることはできず、ピリオド（.）で始めること、空白のみで構成すること、200 文字を超えることもできません。無効な名前または予約済みの名前を持つファイルセグメントは拒否され、カスタムセグメントのドロップダウンに表示されないか、0 ユーザーと表示されます。これは、API または外部インテグレーションを通じて作成されたファイルセグメントにも適用されます。
      </Note>

   2. ユーザーリストを含むファイルを選択します。CSV をアップロードするか、その URL を指定できます。
   3. リストで使用しているユーザー属性を選択します。たとえば、ユーザーの Driving ID のリストがある場合は、ユーザー属性のドロップダウンから Driving ID を選択します。
   4. カスタムセグメントの作成後に MoEngage が通知できるよう、1 つ以上のメール ID を指定します。

**注:** メールを受信した後にセグメントが表示されない場合は、ページを更新して検索してください。

<Warning>
ユーザー属性の値は、1 人のユーザーを一意に識別するものである必要があります。属性値が複数のユーザーを識別する場合（たとえば、値が「London」の city 属性には多数のユーザーが該当する可能性があります）、これらの複数のユーザーが 1 つの属性にマッピングされてセグメントの一部となり、他のユーザーがセグメントに含まれなくなる可能性があります。

たとえば、5 件のメールをアップロードし、最初のメールが 3 人のユーザー（A、B、C）に一致し、残りの 4 件のメールがそれぞれ 1 人のユーザー（D、E、F、G）に一致したとします。この場合、システムはランダムに 5 人のユーザーを選択してファイルセグメントに追加します。

システムは 2,000 件の属性値ごとのバッチで処理を行い、各バッチで最大 2,000 人のユーザーをファイルセグメントに追加します。ユーザー属性値が少ない場合でも、より多くのユーザーがファイルセグメントに追加される可能性があります。たとえば、1500 件のユーザー属性値が 2500 人のユーザーに該当する場合、システムはこの 2500 人のうち 2000 人をランダムにファイルセグメントに追加します。
</Warning>

## ファイル形式

MoEngage システムにアップロードする前に、ファイルを確認してください。次の点を確認してください。

- ファイルに重複する値がないこと
- ファイルに空の行や空の列がないこと
- ユーザー属性を含む 1 列のみの CSV ファイルであること
- ファイルサイズが 64 MB を超えないこと  
  [サンプルファイルのリンク](https://app-cdn.moengage.com/assets/Sample_GAIDs.csv)

ファイル内の値に文字の制限はなく、ユーザー属性値には任意の文字を使用できます。文字の制限はファイルセグメント名にのみ適用され、ファイルの内容には適用されません。ただし、先頭または末尾のスペース、二重引用符で囲まれた値、UTF-8 以外の文字があると、値がユーザーと一致せず、最終的なユーザー数が少なくなる可能性があります。

## カスタムセグメントの利用可能性

MoEngage システムはファイルセグメントのリクエストを受信するとすぐに、カスタムセグメントを作成します。カスタムセグメントの作成後、システムはユーザーを処理し、それらのユーザーをカスタムセグメントに追加します。  
そのため、カスタムセグメントはファイルの処理中も、ファイルの処理が失敗した場合も**利用可能**です。ファイルセグメントが処理されると、そのステータス（完了または失敗）がメールで通知されます。

ファイルのアップロード/処理が失敗した場合は、同じカスタムセグメント名を使用してファイルを再度アップロードできます。システムは、指定されたカスタムセグメントに新しいユーザーを追加します。この機能により、既存のファイルカスタムセグメントに新しいユーザーを追加することもできます。

## ファイルセグメント処理のステータスと警告

ファイルセグメントが完全に処理される前に使用することで発生する問題を防ぐため、MoEngage は UI に警告を表示します。これらの警告により、セグメントがまだ処理中かどうか、またいつ使用するのが望ましいかを把握できます。  
 <img alt="Screenshot 2025-05-19 at 3.16.56 PM.png" src="/images/moengage_dc6ffb.png" />

<Info>
これらの警告は次のページに表示されます。

- Create segment ページ
- すべてのキャンペーン作成ページの **Target audience** セクション
- 分析ページの **Target audience** セクション
</Info>

### セグメント使用時の警告

別のセグメントの作成、キャンペーンのターゲティング、または分析で使用するために、まだ処理中のファイルセグメントを選択すると、警告メッセージが表示されます。警告は次の条件に基づいて表示されます。

- **選択した単一のセグメントが処理中の場合**: "Users are being updated in this segment - `<*Custom Segment name*>`. We suggest that you wait until the confirmation email is received to use this segment in a campaign. Keep an eye here for the latest update."
- **別のセグメントにネストされたセグメントが処理中の場合**: "Users are being updated in these segments - `<**Custom Segment 1, Custom Segment 2, Custom Segment 3 names**>`. These segments are nested in the parent segment chosen. We suggest that you wait until the confirmation email is received to use the segment in a campaign. Keep an eye here for the latest update."

ページを更新するか、セグメントを再度選択すると、最新のステータスを確認できます。キュー内の最後のファイルが正常に処理されると、この警告は表示されなくなります。

### セグメント詳細ページでの警告

現在更新中（つまり、ファイルのアップロードがまだ処理中）のカスタムセグメントの詳細ページに移動すると、次のような警告メッセージが表示されます: "Users are being updated in this segment - `<*CS name linked*>`. We suggest that you wait until the confirmation email is received to use this segment in a campaign. Keep an eye here for the latest update."

ページを更新すると、セグメントの最新のステータスを確認できます。ファイルの処理が正常に完了すると、この警告は表示されなくなります。

## ユーザーの利用可能性

ファイルセグメントには、MoEngage に存在するユーザーのみを含めることができます。MoEngage システムに存在しないユーザーをアップロードした場合、そのユーザーは処理されず、ファイルセグメントの一部になることはできません。

新しいユーザーを MoEngage にアップロードし、それらのユーザーのファイルセグメントを作成するには、[Import Users](/ja/user-guide/data/imports/manual-uploads) を参照してください。

ファイルセグメントを使用してアップロードできるユーザーの総数は、1 日あたり 200 万人に制限されています。  
（この上限はカスタマイズ可能です。上限を引き上げるには、サポートにお問い合わせください。）

# ファイルセグメントの編集

既存のファイルセグメントは、MoEngage ダッシュボードから編集できます。MoEngage ダッシュボードでは、ファイルセグメントに対して次のアクションを実行できます。

1. Add users: 既存のファイルセグメントに新しいユーザーリストを追加できます。
2. Remove users: 既存のファイルセグメントからユーザーリストを削除できます。
3. Replace users: 既存のファイルセグメント内のユーザーリストを置き換えることができます。

ステップ 1:

Segment \> All Segments ページから、編集するファイルセグメントに移動します。

ステップ 2:

Actions タブで、More Actions の縦の省略記号をクリックし、Edit オプションを選択します。

ステップ 3:

1. Add users、Remove users、Replace users の中から、ファイルセグメントに対して実行する編集アクションを選択します。
2. 追加、削除、または置換するユーザーリストを含むファイルを選択します。CSV をアップロードするか、その URL を指定できます。
3. リストで使用しているユーザー属性を選択します。たとえば、ユーザーの Driving ID のリストがある場合は、ユーザー属性のドロップダウンから Driving ID を選択します。
4. カスタムセグメントの処理後に MoEngage が通知できるよう、1 つ以上のメール ID を指定します。

<img alt="File_segment_4.gif" src="/images/moengage_71d706.png" />

ファイルセグメントのすべての機能（セグメントの作成、ファイルセグメントからのユーザーの削除と置換）には、[File Segment API](/ja/api/file-segments/create-file-segment) を使用してアクセスすることもできます。

# ファイルセグメントのアーカイブ/アーカイブ解除

ファイルセグメントは MoEngage ダッシュボードからアーカイブできます。

1. 過去 60 日間に実行されていない（クエリが実行されていない）ファイルセグメントは、自動的にアーカイブされます。
2. アーカイブされたファイルカスタムセグメントのすべてのユーザーは、アーカイブから 30 日後に削除されます。そのため、アーカイブから 30 日が経過すると、アーカイブされたカスタムセグメントは 0 ユーザーを返します。

<Accordion title="MoEngage のファイルセグメントとアップロードしたファイルでユーザー数が異なるのはなぜですか？">

## 問題

アップロードしたファイルと MoEngage のファイルカスタムセグメントとの間で、ユーザー数に不一致があります。

</Accordion>
## 説明

これらの差異が生じる考えられる理由は次のとおりです。

- 0 件
  - **誤った属性が指定されている:** ファイルセグメントのアップロード時に選択した属性が、ファイル内の値と一致していません。たとえば、選択した属性が *age*（double データ型）であるのに、ファイルに *name*（string データ型）の値が含まれている場合、MoEngage に一致するユーザーが存在せず、0 件になります。
  - **ファイルをダウンロードできない:** 指定したファイル URL が非公開または期限切れの場合、MoEngage はファイルをダウンロードできず、カスタムセグメントにユーザーが追加されないため 0 件になります。
  - **CSV の内容が不適切:** 値の先頭または末尾のスペース、スペースのみの行、UTF-8 以外の文字、二重引用符で囲まれた値、カンマで終わる値などの問題があると、ユーザー数が 0 件になる可能性があります。
  - **ファイル処理の遅延:** ファイルをアップロードしても、ユーザーはすぐにはカスタムセグメントに追加されません。処理時間はファイル内の値の数に応じて長くなります。アップロード直後にカスタムセグメントをクエリすると、0 件になる場合があります。
- 件数が少ない
  - **MoEngage のユーザーが少ない:** ファイルに記載された値が MoEngage の値と一致しない場合、それらは考慮されず、ユーザー数が少なくなります。
  - **CSV の内容が不適切:** 0 件のシナリオと同様に、CSV の内容に問題があるとユーザー数が少なくなる可能性があります。
  - **ファイルのアップロードがまだ処理中:** ファイルのアップロード直後に、0 ユーザーのカスタムセグメントが作成されます。その後、ファイルの処理中にユーザーが追加されます。処理中にセグメントをクエリすると、ユーザー数が少なく表示される場合があります。
- 件数が多い
  - **属性値が複数のユーザーに一致する:** ファイルで指定した値が MoEngage の複数のユーザーに一致する場合、一致したすべてのユーザーがカスタムセグメントに追加されるため、ユーザー数が多くなります。

詳細については、[File Segments](/ja/user-guide/segment/create-segments/file-segments) をお読みください。

<Accordion title="ファイルセグメントへの CSV アップロードが失敗するのはなぜですか？">

## 問題

ファイルセグメントで CSV ファイルをアップロードする際に、次のエラーメッセージが表示されます。

There seems to be an error. We are working to fix this.

</Accordion>
## 解決策

次の手順を実行します。

1. **ファイル形式を確認する**:
   - ファイルが CSV 形式であることを確認します。
2. **ファイルサイズを確認する**:
   - ファイルサイズが 64 MB を超えていないことを確認します。ファイルが許容上限より大きい場合は、アップロードする前にサイズを小さくします。
3. **一意の識別子の列を確認する**:
   - ファイルに、セグメントの一意の識別子として指定された列が 1 列のみ含まれていることを確認します。
   - 一意の識別子（UID）を使用することをお勧めします。
4. **空の行と不要なデータを削除する**:
   - ファイルの末尾に空の行がないか確認します。
   - 問題の原因となる可能性のある不要な値や重複する値を削除します。
5. **レコードの値を属性のデータ型に合わせる**:
   - レコードの値が指定されたデータ型と一致していることを確認します。
6. **サポートされていない文字を避ける**:
   - 値からサポートされていない文字を削除します。たとえば、特殊文字や二重引用符（"）はサポートされていません。

詳細については、[File Segments](/ja/user-guide/segment/create-segments/file-segments) をお読みください。

<Accordion title="ファイルセグメントへのサードパーティリンクのアップロードが失敗するのはなぜですか？">

## 問題

ファイルセグメントでサードパーティリンクをアップロードする際に、次のエラーメッセージが表示されます。

There seems to be an error. We are working to fix this.

</Accordion>
## 解決策

次の手順を実行します。

1. **非公開ファイルの IP をホワイトリストに登録する**:
   - ファイルが非公開の場合は、関連する IP アドレスをホワイトリストに登録して、MoEngage のみにアクセスを許可します。
2. **ファイル形式を確認する**:
   - ファイルが CSV 形式であることを確認します。
3. **ファイルサイズを確認する**:
   - ファイルサイズが 64 MB を超えていないことを確認します。ファイルが許容上限より大きい場合は、アップロードする前にサイズを小さくします。
4. **一意の識別子の列を確認する**:
   - ファイルには、セグメントの一意の識別子となる列が 1 列のみ含まれている必要があります。
5. **空の行と不要なデータを削除する**:
   - ファイルの末尾に空の行がないか確認します。
   - 問題の原因となる可能性のある不要な値や重複する値を削除します。
6. **レコードの値を属性のデータ型に合わせる**:
   - レコードの値が指定されたデータ型と一致していることを確認します。
7. **サポートされていない文字を避ける**:
   - 値からサポートされていない文字を削除します。たとえば、特殊文字や二重引用符（"）はサポートされていません。

詳細については、[File Segments](/ja/user-guide/segment/create-segments/file-segments) をお読みください。

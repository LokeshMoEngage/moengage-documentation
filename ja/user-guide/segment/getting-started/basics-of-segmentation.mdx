セグメンテーションとは、共通のプロパティや行動パターンを持つユーザーをグループ化するプロセスです。セグメントは、ユーザー属性、イベント、イベント属性、またはこれら 3 つすべての組み合わせに基づいて作成できます。

MoEngage Segmentation を使用すると、特定の都市のユーザー、過去 30 日間に購入したユーザー、最後のセッションが 7 日以上前のユーザーなどのオーディエンスを作成できます。これらのセグメントは、パーソナライズされたキャンペーンの送信や行動傾向の分析に使用できます。

<Note>
  1 つのワークスペースには、最大 1,000 個のアクティブなセグメント（ファイル、フィルター、カスタムの合計）を作成できます。この制限を引き上げるには、サポートにお問い合わせください。
</Note>

## MoEngage はどのようなデータを使用しますか？

セグメントは、MoEngage がユーザーについて保存している次の 2 種類の主要なデータから作成されます。

- **ユーザー属性** — ユーザーが誰であるかを表すプロパティ
- **イベントとイベント属性** — ユーザーが行ったことの記録

<Tip>
  **前提条件**

  セグメンテーションを開始する前に、ユーザープロパティ、またはイベントとイベントプロパティが MoEngage に存在することを確認してください。データフローを設定するには、MoEngage の [Developer](/ja/developer-guide/introduction) および [API](/ja/api/introduction) ドキュメントを参照してください。
</Tip>

これらのデータタイプを理解すると、どのセグメントタイプとフィルターを使用するかを判断しやすくなります。MoEngage がデータを保存・整理する方法の全体像については、[MoEngage のデータの概要](/ja/user-guide/data/key-concepts/overview-data)を参照してください。

### ユーザー属性

ユーザー属性は、メールアドレス、名前、都市、サブスクリプションステータス、アプリで追跡しているカスタムプロパティなど、MoEngage におけるユーザーのプロパティです。属性値はほぼリアルタイムで更新され、常に最新の既知の値を反映します。MoEngage はユーザー属性の履歴値を保存しません。

ユーザー属性に基づくセグメントの例:

- 最後に確認された国がインドのユーザー
- メールの配信を停止したユーザー
- Push iOS Reachability が true のユーザー

一部のユーザー属性は MoEngage によって自動的に生成され、それ以外はアプリやデータパイプラインから送信されます。詳細については、[ユーザープロファイル](/ja/user-guide/data/user-data/user-profile)および[派生イベントと属性](/ja/user-guide/data/event-data/derived-events-and-attributes)を参照してください。

### イベントとイベント属性

イベントは、App Open、Add to Cart、Product Purchase など、ユーザーが実行するアクションです。各イベントには、商品カテゴリ、価格、プラットフォームなど、そのアクションに固有のプロパティであるイベント属性を含めることができます。

ユーザー属性とは異なり、イベントは履歴として保存され、期間を指定してクエリを実行できます。

イベントに基づくセグメントの例:

- 過去 90 日間にカテゴリ "sportswear" で 3 回以上注文したユーザー
- 過去 30 日間にカテゴリ "laptop" のページを 5 回以上閲覧したユーザー
- 過去 30 日間にカテゴリ "mobiles" で 1 回以上カートに追加したユーザー

イベントトラッキングの完全なガイドについては、[イベントトラッキングの完全ガイド](/ja/user-guide/data/event-data/a-complete-guide-to-event-tracking)を参照してください。

## セグメントでのデータの使用方法

### フィルター

フィルターは、ユーザー属性またはイベント属性に適用して、一致するユーザーを特定するための条件です。たとえば、ロンドンのユーザーや、過去 30 日間にシャツを購入したユーザーを絞り込むことができます。

使用可能なフィルタータイプと演算子の詳細なリファレンスについては、[セグメンテーションのフィルター](/ja/user-guide/segment/advanced-concepts/filters-in-segmentation)を参照してください。[MoEngage MCP セグメンテーションツール](/ja/user-guide/ai-and-intelligence/merlin-ai/moengage-mcp-server#segments)を使用して、AI アシスタント経由でこれらのフィルターを作成・検証することもできます。

### 結合

複数のセグメント条件は、AND、OR、または Exclude ロジックを使用して結合されます。

- **OR** — いずれかの条件に一致するユーザー
- **AND** — 両方の条件に一致するユーザー
- **Exclude** — 一方の条件のユーザーから、もう一方の条件と重複するユーザーを除いたもの

## MoEngage へのデータの取り込み

セグメントを作成する前に、MoEngage にユーザーに関するデータが必要です。データを送信する最も一般的な方法は次のとおりです。

- **SDK 統合** — モバイルまたは Web SDK が、ユーザー属性とイベントをリアルタイムで送信します。開始するには、[Developer Guide](/ja/developer-guide/introduction) を参照してください。
- **API 統合** — MoEngage [Data API](/ja/api/introduction) を使用して、プログラムでデータを送信します。

<Note>
  セグメントの作成を開始するために、SDK または API の統合は必要ありません。ユーザーデータがファイルまたはデータウェアハウスにある場合は、[File Segments](/ja/user-guide/segment/create-segments/file-segments)（CSV リストをアップロード）または [Warehouse Segments](/ja/user-guide/segment/create-segments/warehouse-segments)（BigQuery、Snowflake、Redshift に直接接続）を使用して、すぐにオーディエンスを作成できます。
</Note>

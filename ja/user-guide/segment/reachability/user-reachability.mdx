その名のとおり、リーチャビリティ (Reachability) とは、MoEngage 上の各コミュニケーションチャネルまたはプラットフォームを使用して連絡またはつながることができるユーザーの数を表します。

この記事では、Push、Email、SMS、WhatsApp チャネルのリーチャビリティがどのように算出されるかを説明します。Push チャネルについては、各プラットフォームのリーチャビリティについても説明します。また、MoEngage ダッシュボード上のさまざまなページにおける算出方法も示します。

# リーチャビリティ

MoEngage の各モジュールにおけるリーチャビリティ:

## セグメンテーション

セグメンテーションページ（[Create segment](/ja/user-guide/segment/create-segments/rule-based-filter-segments)）で実行されたクエリには、Push、Email、SMS、WhatsApp チャネルのリーチャビリティと、これら 4 つのチャネル全体のリーチャビリティが表示されます。

![Reachability\_WA.png](/images/moengage_0252c5.png)

セグメンテーションページには、チャネルのページで実行されたクエリも表示されます。これらは source 列で識別できます。

セグメンテーションページでのリーチャビリティの算出:

- Email ID は **Settings** -\> **Channels** -\> **Email** -\> **General settings** から取得されます
- 携帯電話番号は **Settings** -\> **Channels** -\> **SMS** -\> **General settings** から取得されます

### チャネル全体でリーチ可能なユーザー

Reachability カード上部の **Reachable users** の数は、4 つのチャネルのうち少なくとも 1 つでリーチ可能なセグメント内のユーザー数です。この数は、各チャネルのリーチャビリティの合計ではなく、和集合です。

- 複数のチャネルでリーチ可能なユーザーは 1 回だけカウントされます。
- この数は、常に **Reachability by channel** に表示される個々のチャネルの数以上になります。

上のスクリーンショットでは、セグメントにリーチ可能なユーザーが 22 人いますが、個々のチャネルの最大数は 19 です。各チャネルの下に表示される割合は、総ユーザー数ではなく **Reachable users** の数に対して算出されます。たとえば、リーチ可能なユーザー 22 人のうち Email でリーチ可能なユーザーが 9 人の場合、40.91% になります。

## ユーザープロファイル

[ユーザープロファイル](/ja/user-guide/data/user-data/user-profile)は、特定のユーザーのさまざまなチャネルおよびプラットフォームにおけるリーチャビリティを表します。

![Reachability\_WA2.png](/images/moengage_0eb3b0.png)

Push リーチャビリティカード上の緑色のアイコンは、特定のプラットフォームでリーチャビリティが true であることを表します。上記のいずれかのプラットフォームでリーチャビリティが true の場合、全体の Push リーチャビリティは true となり、Push リーチャビリティカード上に緑色のチェックマークで表示されます。すべてのプラットフォームでリーチできない場合は、赤色の感嘆符で表示されます。

同様に、Email、SMS、WhatsApp についても、ユーザーがリーチ可能な場合は、リーチャビリティカード上に緑色のアイコンと緑色のチェックマークで表示されます。リーチ不可のユーザーには、赤色のアイコンと赤色の感嘆符が表示されます。

ユーザープロファイルページでのリーチャビリティの算出:

- Email ID は **Settings** -\> **Channels** -\> **Email** -\> **General settings** から取得されます
- 携帯電話番号は **Settings** -\> **Channels** -\> **SMS** -\> **General settings** から取得されます

## キャンペーン

キャンペーンを送信する前に、ユーザーをセグメント化する必要があります。セグメントには、すべてのユーザーまたは目的のユーザーグループを含めることができます。セグメント化されたユーザーのすべてがリーチ可能とは限りません。該当するユーザーについて、必要な情報や必要な許可が得られていない場合があるためです。\
アウトバウンドチャネルとそれぞれのリーチャビリティの一覧は次のとおりです。

### Push

Push キャンペーンページで実行されたクエリには、Android、iOS、Web の Push リーチャビリティと、これら 3 つのプラットフォーム全体のリーチャビリティが表示されます。

![Push.png](/images/moengage_0ae478.png)

詳細については、[Push リーチャビリティ](/ja/user-guide/segment/reachability/push-reachability)を参照してください。

### Email

Email キャンペーンページで実行されたクエリには、Email リーチャビリティが表示されます。\
リーチャビリティの算出には、キャンペーンページの **User attribute with email address** リストで指定された属性が Email キャンペーンで使用されます。

![Email.png](/images/moengage_021428.png)

詳細については、[Email リーチャビリティ](/ja/user-guide/segment/reachability/email-reachability)を参照してください。

### SMS

SMS キャンペーンページで実行されたクエリには、SMS リーチャビリティが表示されます。

リーチャビリティの算出には、キャンペーンページの **User attribute that stores user’s mobile numbers** リストで指定された属性が SMS キャンペーンで使用されます。

![SMS.png](/images/moengage_f3ece5.png)

詳細については、[SMS リーチャビリティ](/ja/user-guide/segment/reachability/sms-reachability)を参照してください。

### WhatsApp

WhatsApp キャンペーンページで実行されたクエリには、WhatsApp リーチャビリティが表示されます。（[WhatsApp を設定する](/ja/user-guide/campaigns-and-channels/whatsapp/getting-started-with-whatsapp/configure-whatsapp)）

リーチャビリティの算出には、**Settings** -\> **Channels** -\> **WhatsApp** -\> **General settings** で指定された属性が WhatsApp キャンペーンで使用されます。ユーザーが WhatsApp の携帯電話番号を持ち、ユーザーの WhatsApp Opt-In ステータスが _True_ である必要があります。

![Reachability\_WA3.png](/images/moengage_734c74.png)

詳細については、[WhatsApp リーチャビリティ](/ja/user-guide/segment/reachability/whatsapp-reachability)を参照してください。

## セグメンテーションとキャンペーンのリーチャビリティの違い

同じセグメントでも、**Create segment** ページのリーチ可能なユーザー数が、キャンペーンページの数より多くなる場合があります。これは次の違いによるものです。

| 違い | セグメンテーション | キャンペーン |
| --- | --- | --- |
| コントロールグループ | [コントロールグループ](/ja/user-guide/campaigns-and-channels/getting-started/introduction/control-groups)に含まれるユーザーを含めます。 | コントロールグループに含まれるユーザーはキャンペーンから除外されるため、除外します。 |
| 携帯電話番号の検証 | 携帯電話番号の形式や国番号を検証しません。 | SMS または WhatsApp キャンペーンを送信する前に、携帯電話番号、国番号、形式を検証します。 |
| Email アドレスの検証 | Email アドレスが存在し、Hard Bounce、Spam、Unsubscribe の各ユーザープロパティが false であることをチェックします。 | 同じチェックを実行し、さらに Email アドレスに `@` 記号が含まれていることを確認します。 |
| ソース属性 | **Settings** \> **Channels** で設定された Email および携帯電話番号の属性を使用します。 | Email および SMS キャンペーンでは、キャンペーンページで選択された属性を使用します。これは異なる属性である場合があります。 |

## Open Analytics

リーチャビリティは、MoEngage ウェアハウスに存在するデータを使用して直接算出できます。Open Analytics を使用すると、リーチャビリティを算出し、それに関連する必要なデータを取得できます。[Open Analytics を使用したリーチャビリティについては、こちらをクリックしてください](/ja/user-guide/analyze/analytics-how-to/reachability-queries-for-open-analytics)。

# リーチャビリティの算出

## Push

Push リーチャビリティは、以下のパラメーターによって算出されます。

1. ユーザーが少なくとも 1 台のアクティブなデバイスを持っていること。
   - iOS の場合、デバイスにアプリがインストールされている必要があります。
   - Android の場合、デバイスにアプリがインストールされており、デバイスが Push 通知をオプトアウトしていない必要があります。
   - Web の場合、ユーザーがウェブサイトに一度アクセスしたことがあり、ブラウザの許可をオプトインしている必要があります。
2. このデバイスの Push トークンが存在すること。
3. iOS と Android のそれぞれでのリーチャビリティについては、該当するプラットフォームのアクティブなデバイスが少なくとも 1 台存在し、そのデバイスにアプリがインストールされている必要があります。
4. MoEngage は、サイレント Push（設定が ON の場合に定期的に実行）または Push 通知からのフィードバックに基づいて、ユーザーのリーチャビリティも更新します。

上記のパラメーターに基づいて、システムはすべてのプラットフォームのリーチャビリティコードを生成します。リーチャビリティコードは、ユーザー属性 '_Reachability Push Android_'、'_Reachability Push iOS_'、'_Reachability Push Web_' に保存されます。これらの属性の値（リーチャビリティコード）が 200 の場合、ユーザーは該当するプラットフォームでリーチ可能と見なされます。

### ユーザーのオプトイン設定と Push リーチャビリティ

iOS、Android（13 以降）、Web では、アプリのインストール時に Push 通知の送信について明示的にユーザーの許可が求められます。ユーザーは、デバイスのアプリ設定に移動して設定を選択することで、Push 通知の受信をオプトインまたはオプトアウトできます。

## Email

Email リーチャビリティは、以下のパラメーターによって算出されます。

1. ユーザーの Email が存在すること
2. ユーザープロパティ **Hard Bounce** が false であること
3. ユーザープロパティ **Spam** が false であること
4. ユーザープロパティ **Unsubscribe** が false であること
5. ユーザーの Email に '@' が含まれていること

<Info>
  Email キャンペーンでは、Email リーチャビリティに上記のすべてのパラメーターが考慮されます。\
  セグメンテーションとユーザープロファイルでは、最初の 4 つのパラメーターを考慮して Email リーチャビリティが算出されます。
</Info>

すべてのユーザーについて、デフォルトでは Hard Bounce、Spam、Unsubscribe は false です。ユーザーが Email の配信を停止した場合、または Email をスパムとしてマークした場合、それぞれ Unsubscribe と Spam が true に更新されます。ユーザーの Email がバウンスした場合は、Hard Bounce が true に更新されます。

## SMS

SMS リーチャビリティは、以下のパラメーターによって算出されます。

ユーザーがリーチ可能であるためには、携帯電話番号が存在する必要があります。リーチャビリティの算出では、携帯電話番号の形式の検証は行われません。

<Warning>
  Mobile Number 属性は **string** データ型として保存する必要があります。他の型（例: `double`）として追跡されている場合、該当するユーザーは SMS でリーチ可能としてカウントされず、セグメントに SMS でリーチ可能なユーザーが 0 人と表示される場合があります。これを修正するには、[Data Management](/ja/user-guide/settings/data-management/overview-data-management) ダッシュボードで Mobile Number のデータ型を String に固定し、修正したデータを再送信します。Mobile Number は [E.164 形式](/ja/user-guide/settings/advanced-settings/e164-phone-number-format)で追跡してください。
</Warning>

また、システムは実際に SMS キャンペーンを送信する前に、携帯電話番号、国番号、形式を検証します。

## WhatsApp

WhatsApp リーチャビリティは、以下のパラメーターによって算出されます。

1. ユーザーがリーチ可能であるためには、MoEngage に携帯電話番号が存在する必要があります。
2. その携帯電話番号に有効な WhatsApp アカウントがある必要があります。
3. WhatsApp Opt-In ステータスが True である必要があります。

<Info>
  正しく機能させるには、Mobile Number 属性を文字列データ型として保存する必要があります
</Info>

また、システムは実際に WhatsApp キャンペーンを送信する前に、携帯電話番号、国番号、形式を検証します。

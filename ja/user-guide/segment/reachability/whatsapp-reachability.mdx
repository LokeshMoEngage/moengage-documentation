WhatsApp リーチャビリティは、セグメント内で WhatsApp チャネル経由でリーチ可能なユーザー数を示します。最もパフォーマンスの高いチャネルでユーザーにリーチすることが目的の場合、キャンペーン送信に WhatsApp チャネルを選択するかどうかを判断するために WhatsApp リーチャビリティの数値が必要です。

この記事では、WhatsApp チャネルのリーチャビリティがどのように算出されるかを説明します。また、WhatsApp 経由でリーチ可能なユーザーのリーチャビリティを計算する際に考慮されるパラメータも記載しています。さらに、ユーザーが WhatsApp チャネル経由でリーチできない理由と、リーチ不可能なユーザーをリーチ可能なユーザーに変えるための解決策の候補を一覧にしています。

## **ユーザーリーチャビリティ - WhatsApp キャンペーン**

WhatsApp キャンペーンを使用すると、マーケターは WhatsApp 経由でユーザーにリーチできます。リーチ可能なユーザー数は、登録済みの電話番号で WhatsApp を受信できるユーザーの数を示します。

![Reachability by Channel.gif](/images/moengage_2d0328.png)

## **WhatsApp キャンペーンのユーザーリーチャビリティはどのように計算されますか？**

WhatsApp リーチャビリティは、以下の条件に基づいて算出されます。

ユーザーがリーチ可能であるためには、Mobile Number（String）が存在している必要があります。Segmentation/Recent クエリでのリーチャビリティ計算では、携帯電話番号の形式の検証は行われません。携帯電話番号が存在することに加えて、WhatsApp のサブスクリプションステータスが True である必要があります。これら 2 つの条件の両方を使用して、WhatsApp チャネルのユーザーリーチャビリティが算出されます。

<Info>
  正しく機能させるために、Mobile Number 属性は文字列データ型で保存する必要があります
</Info>

ただし、WhatsApp キャンペーンを送信する前に、システムは携帯電話番号、国コード、および形式を検証します。

ユーザープロファイルで携帯電話番号の有無を確認する方法は次のとおりです。

![SMS mobile attribute.gif](/images/moengage_81101f.png)

WhatsApp のサブスクリプションステータスが True の場合、ユーザーはリーチ可能と見なされ、それ以外の場合はリーチ不可能と見なされます。WhatsApp のサブスクリプションステータスは、以下に示すようにユーザープロファイルで確認できます。

![](/images/moengage_825fa8.png)

<Info>
  「Create segment」ページと「WhatsApp campaign」ページでリーチ可能なユーザー数に差異が生じる場合があります。これは、セグメンテーションではユーザーデータとキャンペーン受信の許可が存在するかどうかのみを確認し、リーチ可能なユーザーを計算する際に携帯電話番号の検証やコントロールグループの考慮を行わないためです。
</Info>

## **ユーザーがリーチ不可能な理由を分析して特定するには？**

ステップ 1: Analyse に移動し、「Users」を選択してユーザー分析を行います

ステップ 2: User Properties セクションにあるユーザー属性（Mobile number (Standard) または WhatsApp Subscription Status）を選択します

ステップ 3: 下の User Analysis Options で、Analysis type として「Distribution」を選択し、Apply ボタンをクリックします

ステップ 4: 生成されたグラフを分析し、WhatsApp チャネルでリーチ不可能な理由とそのユーザー数を確認します

![Analytics SMS mobile attribute.gif](/images/moengage_a3a715.png)

## **ユーザーのリーチ不可能な問題を解決するための解決策の候補**

| **リーチ不可能な理由** | **これを解決するための解決策の候補** |
| --- | --- |
| **ユーザーデータが不正確/携帯電話番号が存在しない**  <br />MoEngage 内のユーザーの携帯電話番号が不正確であるか、携帯電話番号が存在しないことを示します  <br />_（セグメンテーションでリーチ可能なユーザーを計算する際には不正確な携帯電話番号の検証は行われず、チェックは WhatsApp キャンペーンの送信直前に行われます）_ | これらのユーザーのセグメントを作成し、InApps、Push、Email などのアウトバウンドまたはインバウンドチャネルを使用してキャンペーンを実行できます。その際、CTA を使用してアプリ上のユーザープロファイルやランディングページにリダイレクトし、携帯電話番号を正しく入力するよう依頼できます。 |
| **サブスクリプションステータス**  <br />ユーザーの WhatsApp サブスクリプションステータスを示します。  <br />_（ユーザーが stop、opt-out などのキーワードを入力して WhatsApp メッセージの受信をオプトアウトした場合に該当します）_ | WhatsApp サブスクリプションのオプトアウトによりリーチ不可能になったユーザーは、SMS チャネルのように「Start、Resume」と入力してオプトインし直すことはできません。アウトバウンドまたはインバウンドのいずれのチャネルでユーザーをターゲティングしても、ユーザーが WhatsApp コミュニケーションにオプトインすることにはつながりません。クライアントは、適切な WhatsApp サブスクリプション API を使用するか、ファイルアップロードを使用して、特定のユーザーの WhatsApp サブスクリプションステータスを手動で変更する必要があります。 |

**注**: 上記の解決策はあくまで候補の一部であり、期待どおりの結果や成功につながるとは限りません。

## **例:**

携帯電話番号が存在しないために WhatsApp チャネル経由でリーチ不可能なユーザーをターゲティングしたい場合は、次の方法で行えます。

ステップ 1: チャート上で理由を選択します（例: Mobile number - Empty）

ステップ 2: セグメントを作成するか、特定のチャネルと配信タイプを選択してアクションを実行し、メール配信停止ユーザーをターゲティングします

ステップ 3: キャンペーンページでコンテンツを設定します

## ![Analytics targetting.gif](/images/moengage_092c3b.png)

同様に、さらに多くの条件でユーザーをターゲティングできます。たとえば、ユーザープロファイルに携帯電話番号が存在するものの、WhatsApp サブスクリプションをオプトアウトしたユーザーなどです。

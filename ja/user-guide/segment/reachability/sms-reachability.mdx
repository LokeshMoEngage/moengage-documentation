SMS リーチャビリティは、セグメント内で SMS チャネルを通じてリーチ可能なユーザー数を示します。最もパフォーマンスの高いチャネルでユーザーにリーチすることが目的である場合、キャンペーン送信に SMS チャネルを選択するかどうかを判断するために、SMS リーチャビリティの数値が必要です。

この記事では、SMS チャネルのリーチャビリティがどのように算出されるかを説明します。また、SMS でリーチ可能なユーザーのリーチャビリティを算出する際に考慮されるパラメーターも示します。さらに、ユーザーが SMS チャネルでリーチできない理由と、リーチ不可のユーザーをリーチ可能なユーザーに転換するための解決策の候補も記載しています。

## **ユーザーリーチャビリティ - SMS キャンペーン**

SMS キャンペーンでは SMS を通じてユーザーにリーチでき、リーチ可能なユーザー数は、登録済みの電話番号で SMS を受信する資格があるユーザーの数になります。

![Reachability by Channel.gif](/images/moengage_bc928c.png)

## **SMS キャンペーンのユーザーリーチャビリティはどのように算出されますか？**

SMS リーチャビリティは、以下で説明する 2 つの条件に基づいて算出されます。

**1. 属性 Mobile number (Standard) に携帯電話番号の文字列値が存在すること**

ユーザーがリーチ可能であるためには、Mobile Number (String) が存在する必要があります。セグメンテーション/最近のクエリにおけるリーチャビリティの算出では、携帯電話番号の形式の検証は行われません。

<Info>
  正しく機能させるには、Mobile Number 属性を文字列データ型として保存する必要があります
</Info>

ただし、実際に SMS キャンペーンを送信する前に、システムは携帯電話番号、国番号、形式を検証します。

ユーザープロファイルで携帯電話番号の有無を確認する方法は次のとおりです。

![SMS mobile attribute.gif](/images/moengage_1340f3.png)

**2. サブスクリプション管理（SMS subscription status 属性）**

アカウントでサブスクリプション管理が有効になっている場合、SMS チャネルでのユーザーのリーチャビリティを決定する属性（SMS subscription status）が追加でチェックされます。SMS subscription status が True の場合、ユーザーはリーチ可能としてマークされ、それ以外の場合はリーチ不可としてマークされます。

![SMS subscription status.gif](/images/moengage_9cfa63.png)

アカウントでサブスクリプション管理が有効になっていない場合、リーチャビリティの算出では携帯電話番号の有無のみがチェックされます。アカウントでサブスクリプション管理が有効になっている場合、上記 2 つの条件のいずれかが満たされないと、ユーザーは SMS キャンペーンを受信できません（リーチ不可）。

<Info>
  "Create segment" ページと "SMS campaign" ページでリーチ可能なユーザー数が異なる場合があります。これは、セグメンテーションではユーザーデータとキャンペーンを受信するためのユーザーの許可が存在するかどうかのみをチェックし、携帯電話番号の検証は行わず、リーチ可能なユーザーの算出時にコントロールグループを考慮するためです。
</Info>

## **ユーザーがリーチ不可である理由を分析して特定するには？**

ステップ 1: Analyse に移動し、"Users" を選択してユーザー分析を行います

ステップ 2: User Properties セクションにあるユーザー属性（Mobile number (Standard) または SMS Subscription Status）を選択します

ステップ 3: 下の User Analysis Options で Analysis type として "Distribution" を選択し、Apply ボタンをクリックします

ステップ 4: 生成されたグラフを分析し、SMS チャネルでリーチできない理由をユーザー数とともに確認します

![Analytics SMS mobile attribute.gif](/images/moengage_98261e.png)

## **ユーザーのリーチ不可の問題を解決するための解決策の候補**

| **リーチ不可の理由** | **これを解決するための解決策の候補** |
| --- | --- |
| **ユーザーデータが正しくない/携帯電話番号が存在しない**  <br />MoEngage 内のユーザーの携帯電話番号が正しくないか、携帯電話番号が存在しないことを示します  <br />_(セグメンテーションでリーチ可能なユーザーを算出する際には、誤った携帯電話番号の検証は行われません。このチェックは SMS キャンペーンの送信直前に行われます)_ | これらのユーザーのセグメントを作成し、InApps、Push、Email などのアウトバウンドまたはインバウンドチャネルを使用してキャンペーンを実行できます。この場合、CTA を使用してユーザーをアプリのユーザープロファイルやランディングページにリダイレクトし、携帯電話番号を正しく入力するよう依頼できます。OTP を使用して、入力された番号が正しいかどうかを検証することもできます。 |
| **Subscription status（SMS チャネルでサブスクリプション管理が有効になっている場合のみ）**  <br />ユーザーが SMS をオプトアウトまたは配信停止したかどうかを示します  <br />これらのユーザーは SMS チャネルでリーチ不可と見なされます | _(これは、アカウントで "**Subscription Management**" が有効になっている場合にのみ適用されます)_  <br />SMS でリーチできないこれらのユーザーを、In-app、Email、WhatsApp、Push などの他のチャネルでターゲティングします。キャンペーンの成果としてこれらのユーザーが再度配信登録するよう、キャンペーンコンテンツを工夫して使用します。ユーザーを SMS メッセージの受信トレイにリダイレクトする CTA を提供し、オプトインにつながるキーワード（例: Start、Begin など）を入力してもらいます。 |

**注**: 上記の解決策は候補の一部であり、期待どおりの結果や成功につながる場合とそうでない場合があります。

## **例:**

携帯電話番号が存在しないために SMS チャネルでリーチできないユーザーをターゲティングしたい場合は、次の方法で実行できます。

ステップ 1: グラフで理由を選択します（例: Mobile number - Empty）

ステップ 2: Email の配信を停止したユーザーをターゲティングするために、特定のチャネルと配信タイプを選択して、セグメントを作成するかアクションを実行します

ステップ 3: キャンペーンページでコンテンツを設定します

## ![Analytics targetting.gif](/images/moengage_64b252.png)

同様に、さらに条件を追加してユーザーをターゲティングできます。たとえば、ユーザープロファイルに携帯電話番号は存在するものの、SMS の配信登録をオプトアウトしたユーザーなどです。

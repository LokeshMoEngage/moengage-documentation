Push リーチャビリティは、セグメント内で Push チャネルを通じてリーチ可能なユーザー数を示します。最もパフォーマンスの高いチャネルでユーザーにリーチすることが目的である場合、キャンペーン送信に Push チャネルを選択するかどうかを判断するために、Push リーチャビリティの数値が必要です。

この記事では、Push チャネルのリーチャビリティがどのように算出されるかを説明します。Push チャネルについては、各プラットフォーム（Web、Android、iOS）のリーチャビリティについても説明します。また、Push でリーチ可能なユーザーのリーチャビリティを算出する際に考慮されるパラメーターも示します。さらに、ユーザーが Push チャネルでリーチできない理由と、リーチ不可のユーザーをリーチ可能なユーザーに転換するための解決策の候補も記載しています。

## **ユーザーおよびプラットフォームのリーチャビリティ - Push キャンペーン**

キャンペーンで Push チャネルを使用すると、Web、Android、iOS の 3 種類のデバイスでユーザーにリーチできます。Push キャンペーンでは Push 通知を通じてユーザーにリーチでき、リーチ可能なユーザー数は、Push 通知を受信する資格があるユーザーの数になります。

![push platform wise.gif](/images/moengage_875c0b.png)

## **Push キャンペーンのユーザーリーチャビリティはどのように算出されますか？**

Push リーチャビリティは、以下のパラメーターによって算出されます。

1. ユーザーが少なくとも 1 台のアクティブなデバイスを持っていること。
   - iOS の場合、デバイスにアプリがインストールされており、デバイスが Push 通知をオプトインしている必要があります。
   - Android の場合、デバイスにアプリがインストールされており、デバイスが Push 通知をオプトアウトしていない必要があります。
   - Web の場合、ユーザーがウェブサイトに一度アクセスしたことがあり、ブラウザの許可をオプトインしている必要があります。
2. このデバイスの Push トークンが存在すること。
3. iOS と Android のそれぞれでのリーチャビリティについては、該当するプラットフォームのアクティブなデバイスが少なくとも 1 台存在し、そのデバイスにアプリがインストールされている必要があります。

上記のパラメーターに基づいて、システムはすべてのプラットフォームのリーチャビリティコードを生成します。リーチャビリティコードは、ユーザー属性 '_Reachability Push Android_'、'_Reachability Push iOS_'、'_Reachability Push Web_' に保存されます。これらの属性の値（リーチャビリティコード）が 200 または 201 の場合、ユーザーは該当するプラットフォームでリーチ可能と見なされます。

MoEngage は、サイレント Push（設定が ON の場合に定期的に実行）または Push 通知からのフィードバックに基づいて、ユーザーのリーチャビリティも更新します。

## **ユーザーがリーチ不可である理由を分析して特定するには？**

ステップ 1: Analyse に移動し、"Users" を選択してユーザー分析を行います

ステップ 2: User Properties セクションでユーザー属性（Push reachability Android、Push reachability iOS、Push reachability web のいずれか）を選択します

ステップ 3: 下の User Analysis Options で Analysis type として "Distribution" を選択し、Apply ボタンをクリックします

ステップ 4: 生成されたグラフを分析し、Push チャネルでリーチできない理由を分布数とともに確認します

![push video1.gif](/images/moengage_875fa6.png)

同様に、3 つのプラットフォーム（Android、iOS、Web）すべてをまとめて、または他のプラットフォームを個別に分析することもできます。

## **例:**

Push の配信を停止したすべてのユーザーに Push 通知の配信登録をしてもらいたい場合は、次の方法で実行できます。

ステップ 1: 円グラフで Push の配信を停止したユーザーを示すセクションを選択します

ステップ 2: Push の配信を停止したユーザーをターゲティングするために、特定のチャネルと配信タイプを選択して、セグメントを作成するかアクションを実行します

ステップ 3: キャンペーンページでコンテンツを設定します

![push video 2.gif](/images/moengage_0380d1.png)

同様に、Push チャネルでリーチできない他の理由を持つユーザーもターゲティングできます。

Flow のエクスポートでは、選択した Flow の詳細なレポートが提供され、そのパフォーマンスの分析に役立ちます。これらのレポートには次の詳細が含まれます。

- Flow ステージの詳細
- エントリーと離脱の統計
- コントロールグループ
- 配信統計
- コンバージョン

これらの詳細は、特定の日付範囲で抽出することも、日別に分割して抽出することもできます。

# キャンペーンをエクスポートする手順

1. All Flows ページから対象の Flow に移動します。
2. バージョンセレクターで、データをエクスポートするバージョンを選択します。デフォルトでは、Flow のアクティブなバージョンが選択されています。
3. 上部の "Duplicate" の横にある "Export" をクリックします。 <img alt="Export.png" src="/images/moengage_1b0f52.png"  />
4. 以下の手順に従ってポップアップに詳細を入力し、Export をクリックしてレポートを取得します。
      - メール ID を入力します。デフォルトでは、ログインしているアカウントのメール ID が入力されています。
      - レポートタイプを選択します
            - **Campaigns** - このレポートは、選択した日付/日付範囲におけるすべてのアクションキャンペーンのパフォーマンスを確認するのに役立ちます。レポートに表示される数値は、ユーザーがいつ Flow に参加したかに関係なく、選択した期間内に記録されたものです: <img alt="CampaignsType.png"  src="/images/moengage_09113e.png"  />
            - **Users**- このレポートは、選択した日付/日付範囲内に参加したユーザーに関連するすべての統計を確認するのに役立ちます。 <img alt="UsersType.png"  src="/images/moengage_0d00a4.png"  />
      - レポートを生成する期間を定義します。
      - Campaigns レポートタイプの場合、集計レポートまたは日別レポートのいずれかを生成できます。
5. 生成されたレポートは、入力したメール ID に zip 形式で送信されます。

Flow のすべてのバージョンのレポートのエクスポートの詳細については、[Flow パフォーマンスデータのエクスポート](/ja/user-guide/flows-cross-channel-messaging/getting-started/overview-flows/all-flows#exporting-flow-campaign-data)を参照してください。

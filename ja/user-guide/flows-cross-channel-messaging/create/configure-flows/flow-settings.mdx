# Flows の構成

Flows では、以下の設定を構成できます。

| 設定 | 説明 |
| --- | --- |
| Campaign Tags | ドロップダウンからキャンペーンタグを最大 5 つまで選択します。詳細については、[Campaign Tags](/ja/user-guide/campaigns-and-channels/getting-started/introduction/campaign-tags) を参照してください。 |
| Conversion Goal |  |
| Goal Name | ゴールを管理・識別するためのゴール名を入力します。 |
| Event Name | ゴールのトラッキングに使用する定義済みイベントをドロップダウンから選択します。<br />詳細については、[Events and Attributes](/ja/user-guide/data/event-data/derived-events-and-attributes) を参照してください。 |
| New Attribute | クリックすると、トラッキング対象のゴールを絞り込むための定義済み属性、条件、値を追加できます。<br />詳細については、[Events and Attributes](/ja/user-guide/data/event-data/derived-events-and-attributes) を参照してください。 |
| Track goal for | ユーザーがキャンペーンを受信した後、ゴールをトラッキングする期間を時間単位で定義します。<br />ゴールは、ユーザーのキャンペーンインプレッション/クリックから最大 10 日間トラッキングできます。 |
| Exit on conversion | Exit on conversion トグルを有効にすると、ユーザーがプライマリコンバージョンゴールを達成した時点で、そのユーザーを Flow から強制的に離脱させます。 |
| Messaging Control |  |
| Ignore DND Settings | **_Ignore DND Settings_ をオンにする**<br />Ignore DND Settings をオンにすると、該当する Flow から送信されるメッセージに **_Do Not Disturb (DND) 設定が適用されなくなります_**。たとえば、メッセージは常時送信されます。<br />**_Ignore DND Settings_ をオフにする**<br />この設定をオフにすると、該当する Flow から送信されるメッセージに **_Do Not Disturb (DND) 設定が適用されます_**。たとえば、DND 時間中はメッセージが送信されません。<br />詳細については、[Frequency Capping (FC) and Do Not Disturb (DND) for Flows](/ja/user-guide/flows-cross-channel-messaging/create/configure-flows/frequency-capping-fc-and-do-not-disturb-dnd-for-flows) を参照してください。 |
| Ignore frequency capping | Frequency Capping (FC) を使用すると、特定の期間中にユーザーに送信されるメッセージ数を制限できます。この制限はチャネル (プッシュ、メール、コネクタ) 単位で適用されます。詳細については、チャネルレベルの [Frequency capping](/ja/user-guide/settings/channels/delivery-controls/frequency-capping) を参照してください。<br />**Ignore_frequency capping_ をオンにする**<br />Ignore frequency capping をオンにすると、該当する Flow から送信されるメッセージに対して、チャネルレベルのキャッピングがすべて無視されます。<br />**_Ignore frequency capping_ をオフにする**<br />この設定をオフにすると、チャネルレベルの FC 設定がすべて Flow のメッセージに適用されます。<br />詳細については、[Frequency Capping (FC) and Do Not Disturb (DND) for Flows](/ja/user-guide/flows-cross-channel-messaging/create/configure-flows/frequency-capping-fc-and-do-not-disturb-dnd-for-flows) を参照してください。 |
| Count for the frequency capping | **Ignore frequency capping** がオンの場合、マーケターは該当する Flow から送信されたチャネルメッセージを FC のカウント対象にするかどうかを決定できます。これにより、他の Flow/キャンペーンから送信されるメッセージをさらに制御できます。<br />詳細については、[Frequency Capping (FC) and Do Not Disturb (DND) for Flows](/ja/user-guide/flows-cross-channel-messaging/create/configure-flows/frequency-capping-fc-and-do-not-disturb-dnd-for-flows) を参照してください。 |
| Enable DeDuplication | 重複排除は、Fixed time エントリータイプの Flow にのみ適用されます。<br />Enable DeDuplication トグルがオンの場合、マーケターは、同じチャネル識別子 (SMS/WhatsApp の場合は携帯電話番号、メールの場合はメール ID など) が異なるユーザーに関連付けられていても、24 時間はそれらの識別子へのメッセージ送信を防止できます。<br />コネクタの場合、マーケターは Flow に追加されたすべてのコネクタステージで重複排除に使用するユーザー属性を選択する必要があります。<br />例:<br />同じ携帯電話番号とメールを持つユーザープロファイル A と B が Periodic Flow に入るとします。Periodic Flow でマーケターがこの設定をオンにすると、キャンペーンステージ (Email、SMS、WhatsApp) に最初に入ったユーザープロファイルのみがキャンペーンを受信します。 |
| Preferences |  |
| Push | [Preference Management](/ja/user-guide/campaigns-and-channels/mobile-push/getting-started-with-mobile-push/preference-management-for-push-notifications) 設定を使用して特定のユーザーをキャンペーンから自動的に除外している場合に使用します。<br />Push をクリックすると、設定を上書きしてオプトアウトしたユーザーを含め、Flow のアクションキャンペーンをユーザーに配信します。 |
| SMS | SMS をクリックすると、設定を上書きしてオプトアウトしたユーザーを含め、Flow のアクションキャンペーンをユーザーに配信します。 |
| WhatsApp | WhatsApp をクリックすると、設定を上書きしてオプトアウトしたユーザーを含め、Flow のアクションキャンペーンをユーザーに配信します。 |

<Warning>
  Flows では、マーケターがチャネルレベルで設定した Frequency Capping と DND 設定が使用されます。例:

    1. Flows を使用して送信されるメールメッセージは、メールの FC と DND 設定に基づいて制御されます。
    2. Flows を使用して送信されるプッシュメッセージは、プッシュの FC と DND 設定に基づいて制御されます (他のチャネルも同様です)。
    3. Flows を使用して送信される WhatsApp メッセージは、WhatsApp の FC と DND 設定に基づいて制御されます。

  デフォルトの Flow を作成した場合、FC と DND 設定は無視されます。既存の Flow を開いてこれらの設定を編集できます。編集後、以降に送信されるすべてのメッセージに設定が適用されます。

  Enable Deduplication は、Periodic Flow と One-time Flow にのみ適用されます。

    1. デフォルトでは、DeDuplication はオフになっています。
    2. DeDuplication は、実際にキャンペーンの送信を試行する前に行われます。そのため、重複排除の後でも、パーソナライゼーションの失敗や Frequency Capping などの失敗理由により、メッセージが送信されない場合があります。
</Warning>
<Info>これらの設定はいずれも Facebook Audience キャンペーンには適用されません。Flow キャンペーンにこの設定が存在する場合でも、FB Audience ではバイパスされます。</Info>

# 複数のコンバージョン目標

Flows の複数のコンバージョン目標を使用すると、マーケターは、実行されると Flow の成功を反映するユーザーイベントを最大 5 つまで追跡できます。また、コンバージョン目標のいずれかから得られた収益を追跡することもできます。 

複数のコンバージョン目標は、次の用途に使用できます。

- ユーザーがプライマリコンバージョン目標を実行する過程でたどる中間ステップの追跡
  - 例: "Add to cart" は、ユーザーがアイテムを "Purchase" するために必要な中間ステップです

<Info>
- Exit on conversion トグルが有効になっている場合、プライマリコンバージョン目標を達成したユーザーは Flow から強制的に離脱させられます。
</Info>
- Flow から配信されたキャンペーンの結果としてユーザーが実行する可能性のある補助イベントの追跡
  - 例: ユーザーが実際に "purchase" を実行しなくても、"Add to wishlist" もキャンペーンの成功として記録されます。

# 収益パフォーマンスの追跡

MoEngage を使用すると、キャンペーンの収益を非常に簡単に追跡できます。キャンペーンの収益と投資収益率 (RoI) を確認できます。

複数のコンバージョン目標を使用すると、複数のビジネス指標を追跡したり、ユーザーアクションのファネルを可視化したりできるようになりました。

たとえば、Flow を公開した後、何人の顧客が製品 iPhone の Purchase イベントを実行したかを追跡したいとします。コンバージョン目標の設定は次のようになります。ここでは、*iPhonePurchase* が **Goal Name**、*Purchased product* が追跡したい **App Event**、*product name* が **value** として *iPhone* を持つ *attribute* です。

<img alt="545.png" src="/images/moengage_b79507.png" />

コンバージョン目標を設定する際に、収益を追跡する目標を選択できます。

以下の例では、***orderSuccessful*** イベントの収益を追跡しています。

<img alt="ordersuccessful.png" src="/images/moengage_5215c7.png" />

収益の追跡はオプションであり、必須ではありません。Revenue performance をクリックして無効にすることができます。Revenue performance トグルが有効になっている場合、以下のスクリーンショットに示すように、**Stats セクション**から Revenue と Revenue Boost の指標を追跡できます。これらの指標の詳細については、[こちら](/ja/user-guide/flows-cross-channel-messaging/analyze-flows/analyze-a-flow)をクリックしてください。

<img alt="68CD8ED2-EA4E-421A-A334-4B1AAA768B0E_1_201_a.jpeg" src="/images/moengage_bd88d7.png" />

目標を選択した後、注文の合計金額を取得する数値属性を選択できます。この例では、注文の合計価格が収益として追跡されます。また、金額を報告する通貨を選択することもできます。

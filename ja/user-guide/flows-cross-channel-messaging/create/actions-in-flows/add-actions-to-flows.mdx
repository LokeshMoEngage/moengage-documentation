# キャンバスへのアクションの追加

MoEngage キャンバスで、次の操作を行います。

- **\+** をクリックし、次のいずれかの操作を行ってキャンペーンを追加します。
  - チャネルが属するカテゴリをクリックします。
    | カテゴリ名 | このカテゴリに属するチャネル |
    | --- | --- |
    | Messaging | Push、Email、SMS、RCS、WhatsApp、InApp、Onsite、Cards |
    | Social and Ads | Facebook および Google Ads Audience |
    | Others | Connector および Next Best Action |
    ![Add via Category.gif](/images/moengage_65ca3e.png)
    <Info>
      よく使用される 5 つのステージが、**All stages** タブの **Frequently Used** セクションに表示されます。利用可能なステージのリストは、ワークスペースに基づいて動的に変化します。必要なステージをクリックして Flow に追加します。
      ![image.png](/images/moengage_88a186.png)
    </Info>
  - **Actions** タブをクリックします。
  ![Moving\_to\_Action\_tab.gif](/images/moengage_96ff21.png)
  - 検索バーからキャンペーンを直接検索します。
  ![Search\_to\_Add.gif](/images/moengage_7b976a.png)

次に、いずれかのキャンペーンをクリックします。

<Tabs>
  <Tab title="Push">
    ユーザーがこのステージに到達すると、ユーザーにアクティブなデバイスがある場合はプッシュが送信されます。マーケターは、Android、iOS、Web デバイス向けのメッセージを同時に構成できます。

    マーケターは、新しいプッシュメッセージを設定する (ユーザー属性でパーソナライズ可能) か、既存のキャンペーンのキャンペーン ID を使用してそのキャンペーンからメッセージをインポートできます\*\*。\*\*

    ![Adding Push.gif](/images/moengage_871a13.png)

    ### サポートされているプラットフォーム

    Push では次のプラットフォームがサポートされています。

    - Android
    - iOS
    - Web
  </Tab>
  <Tab title="Email">
    ユーザーがこのステージに到達すると、ユーザーのアクティブなメール購読先にメールが送信されます。

    マーケターは、メールを一から作成することも、既存のメールテンプレートを使用することもできます。

    ![Adding Email.gif](/images/moengage_42c227.png)
  </Tab>
  <Tab title="Connector">
    ユーザーがこのステージに到達すると、Connector で定義されたアクションが実行されます。たとえば、Connector を次のように構成できます。

    - MoEngage で直接サポートされていない任意のチャネルにメッセージを送信する。
    - サードパーティシステムまたは MoEngage のユーザーデータを更新する。たとえば、ユーザーがプレミアムサブスクリプションの購入などの特定のイベントを実行した場合、Connector キャンペーンを使用して、このイベントに関連付けられた任意のユーザープロパティを更新できます。

    ![Connector Addition.gif](/images/moengage_84d6da.png)
  </Tab>
  <Tab title="SMS">
    ユーザーがこのステージに到達すると、SMS 設定に従ってユーザーに SMS が送信されます。

    - Flows での SMS の使用計画の詳細については、[SMS 設定の構成](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/sms/getting-started-with-sms/configure-an-sms-sender)を参照してください。
    - SMS メッセージのパーソナライズの詳細については、[パーソナライゼーション](/ja/user-guide/flows-cross-channel-messaging/create/actions-in-flows/personalization-in-flows)を参照してください。

    ![Adding SMS.gif](/images/moengage_d52957.png)
  </Tab>
  <Tab title="RCS">
    ユーザーがこのステージに到達すると、行われた構成に従ってユーザーに RCS メッセージが送信されます。RCS は、Flow キャンバス上で Email や SMS などの他のチャネルと並んで専用のチャネルとして表示されます。

    ![add rcs to flows.gif](/images/moengage_0ab44a.png)

    **Configure RCS Message** パネルでは、次の詳細を指定できます。

    - **Campaign name:** Flow ステージキャンペーンの一意の名前を入力します。
    - **User attribute that stores user's mobile number:** ユーザーの携帯電話番号を保存している特定の属性を選択します。
    - **Select sender**: 承認済みの送信者を選択します。
    - **Select template:** メッセージのカスタムテンプレートを選択します。
    - **Personalization**: `{{Name}}` や `{{Link}}` などのユーザー属性を使用して、Title、Body、Suggestion などのフィールドをパーソナライズできます。
    - **Test Campaign**: このセクションを使用して特定のユーザーにテストメッセージを送信し、公開前にパーソナライズされたプレビューを確認します。
    - **Preview type**: このオプションを使用して、メッセージコンテンツの表示方法を切り替えることができます。
      - Default: このオプションでは、一覧表示されたフィールドに入力されたとおりにメッセージが表示されます。
      - Personalized: このオプションでは、パーソナライゼーションタグを実際の値に置き換えて、エンドユーザーに表示されるとおりにメッセージが表示されます。
    - **Import data from another campaign**: このオプションを使用すると、既存のキャンペーンからメッセージコンテンツをインポートして、現在の Flow ステージで再利用できます。
    - **A/B Test**: A/B Test 機能を使用すると、単一の Flow ステージ内でメッセージコンテンツの複数のバリエーションをテストできます。
    - **Locale**: Locale 機能を使用すると、ユーザーの優先言語または地域に基づいてメッセージのコンテンツをカスタマイズできます。これにより、同じキャンペーンをグローバルなオーディエンスに送信しながら、現地の言語でメッセージを配信できるため、関連性とユーザーエクスペリエンスが向上します。

    <Info>
      - フォールバックは、RCS キャンペーンの作成ステップ自体では直接サポートされていません。代わりに、Flow の後続ノードを使用して、別のチャネル経由でフォールバックメッセージを送信してください。
      - 既存のキャンペーンからコンテンツをインポートする場合、関連付けられた SMS フォールバック構成は、専用の RCS ノードではサポートされていないため除外されます。
      - [Intelligent Path Optimizer](/ja/user-guide/flows-cross-channel-messaging/create/intelligence-in-flows/intelligent-path-optimizer) (IPO) は、現在 RCS チャネルではサポートされていません。
    </Info>

    ![Configure RCS Message.png](/images/moengage_9a3988.png)

    Flow 内で RCS アクションの直後にステージを構成する場合、**Conditions and controls** タブで次の条件を使用できます。

    - **アクション条件:**
      - RCS sent successfully
      - RCS delivered successfully
      - RCS read successfully
      - RCS clicked
      ![rcs metrics.png](/images/moengage_010dcd.png)

    Flow が公開中の場合、RCS ステージにカーソルを合わせると、次の指標を表示してパフォーマンスを分析できます。

    - **Sent**
    - **Delivered**
    - **Read**
    - **Click (CTR)**
    - **Conversions(CVR)**
    - **Conversion Events**

    ![stats.png](/images/moengage_e40a3f.png)

    情報アイコンをクリックすると、[キャンペーン分析と情報](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/rcs/analyze-rcs-campaigns)ページが表示されます。

    ### 統計

    **Stats** タブでは、RCS チャネル専用のセクションを含む、Flow のパフォーマンスの包括的なビューを確認できます。

    #### エンゲージメントトレンド

    このセクションでは、RCS チャネルでフィルタリングされた Flow パフォーマンスの集計指標を表示できます。次の主要業績評価指標 (KPI) が個別の指標カードとして表示されます。

    - **Sent**: メッセージが送信されたユーザーの総数。
    - **Delivered** (配信率): メッセージを正常に受信したユーザーの総数と、Flow の平均配信率。
    - **Read** (既読率): メッセージを開いて閲覧したユーザーの数と、Flow の平均既読率 (RCS 固有の指標)。
    - **Clicks** (CTR): メッセージのリンクまたはアクションがクリックされた総回数と、Flow の平均クリック率。
    - **Conversions** (CVR): メッセージを受信した後にコンバージョンイベントを完了したユニークユーザーの数と、Flow の平均コンバージョン率。

    エンゲージメントトレンドは、対応するオプションを選択することで、Time Series、Table、または Series with Table 形式で表示できます。

    ![engagement trends.png](/images/moengage_ed4549.png)

    #### エラー失敗の内訳

    このセクションは、メッセージ配信に関する問題のトラブルシューティング専用です。

    RCS Failure Breakdown: RCS チャネルに固有の失敗の内訳を表示します。これにより、既存の Flows のインフラストラクチャとフレームワークを活用して、未配信や送信失敗の理由を特定できます。

    ![RCS failure breakdown.png](/images/moengage_0dda38.png)

    #### キャンペーン統計

    この表は、RCS チャネルでフィルタリングされた Flow 内の各キャンペーンのパフォーマンスの詳細な行ごとの概要を提供します。

    - **含まれる指標**: この表には、Campaign Name、Type、Total User Entries、Total Sents、Delivered/Opened/Impressions/Synced/Reads、Clicks、Unique Conversions が表示されます。

    ![campaign stats.png](/images/moengage_ad02af.png)

    ### サポートされているプラットフォーム

    RCS では次のプラットフォームがサポートされています。

# Flows キャンバスでの検索

<Note>
  これはアーリーアクセス機能です。アカウントでこの機能を有効にするには、CSM に連絡するか、サポートチケットを作成してください。
</Note>

複雑なジャーニーや事前構築済みのテンプレートを扱う場合、特定のステージを手動で見つけるのは時間がかかることがあります。キャンバス検索機能を使用すると、コンテキストを失うことなく、名前、タイプ、または ID で任意のステージを即座に見つけて移動できます。この機能は、Draft と Published (表示のみ) の両方の状態で完全に利用できます。
検索バーは、次のいずれかの方法で起動できます。

  - ツールバーアイコン: キャンバス右下のツールバーの右端にある虫眼鏡アイコンをクリックします。
  - キーボードショートカット: キャンバス上の任意の場所で Ctrl+F (Windows/Linux) または Cmd+F (macOS) を押します。

起動すると、キャンバスの上部中央に検索バーが表示されます。検索では、入力と同時にクエリがリアルタイムで評価されます (最低 1 文字が必要)。MoEngage は、次のステージの詳細を優先順位に従って部分一致または完全一致で検索します。

  - **Stage Name**: ノードカードに表示されるカスタムラベル (例: "Day 3 Re-engage")。
  - **Stage Type**: システム定義のアクション (例: "Email"、"Push"、"Wait for/till")。
  - **Stage ID**: ステージの一意のシステム識別子。

# コピーと貼り付け

MoEngage キャンバスでは、Flow のステージとブランチをコピーして貼り付けることができます。MoEngage でマーケターが作成する Flow のほぼすべてに、少なくとも 1 つのチャネルで複数のアクションキャンペーンが含まれています。すべてのキャンペーンは異なりますが、ほとんどのキャンペーンはコンテンツがわずかに異なるだけで、キャンペーンの構成パラメーターの大部分は同じです。マーケターが Flow のブランチとステージをコピーして貼り付けられるようにすることで、目的の Flow をすばやく簡単に作成できるようになり、時間と労力を節約できます。

<Tabs>
  <Tab title="ステージのコピー">
    1. ステージをコピーするには、コピーするステージにカーソルを合わせ、以下に示すようにコピーアイコン  <img alt="CopyIcon.png" src="/images/moengage_ee5e85.png" /> をクリックします。

    ![CopyAction.png](/images/moengage_a34915.png)

    コピーアイコンをクリックすると、キャンバスの右下隅に次のメッセージが表示されます。

    ![PasteOption.png](/images/moengage_6ac8c3.png)

    2. ステージを貼り付ける場所にカーソルを合わせ、'\+' アイコンをクリックします。コピーしたステージの名前が表示されたアプリドロワーが表示されます。

    ![pasting\_Push1.png](/images/moengage_53ff4c.png)

    3. ステージ名をクリックして貼り付けます。\
       コピーした Flow ステージを貼り付けると、以下に示すように 'Copy - `<FlowStageName>`' という名前で表示されます。以下の例では、コピーされた Flow ステージの名前は 'Push1' です。したがって、コピーされた Flow の名前は 'Copy - Push1' になります。

    ![PastedVersion.png](/images/moengage_1e1934.png)

    <Info>
      1. ステージをコピーすると、ステージのタイプに関係なく、ステージの構成もコピーされます。
      2. エントリーステージと離脱ステージはコピーできません。エントリーステージと離脱ステージ以外のすべてのステージをコピーできます。
      3. Flow ステージをコピーした後、コピーしたステージは、新しいステージをコピーするか Flow キャンバスから移動するまでクリップボードに残ります。
    </Info>
  </Tab>
  <Tab title="ブランチのコピー">
    1. ブランチをコピーするには、コピーするブランチにカーソルを合わせ、以下に示すようにコピーアイコン  <img alt="CopyIcon.png" src="/images/moengage_ee5e85.png" /> をクリックします。
    
    ![Copy and paste 1.png](/images/moengage_ccd279.png)
    
    コピーアイコンをクリックすると、キャンバスの右下隅に次のメッセージが表示されます。 <img src="/images/moengage_339839.png" alt="Copy and paste 2.png" /> 
    2. ブランチを貼り付ける場所にカーソルを合わせ、'\+' アイコンをクリックします。コピーしたブランチの名前が表示されたアプリドロワーが表示されます。

    ![Pasting\_branch.png](/images/moengage_c01cb9.png)

    3. ブランチ名をクリックして貼り付けます。\
       コピーした Flow ブランチを貼り付けると、貼り付けられたステージの名前には "Copy" というプレフィックスが付きます。次の例では、Branch 1 の一部としてコピーされた Push ステージの名前は "Upcoming Sale" です。したがって、貼り付けられたステージの名前は "Copy - Upcoming Sale" になります。

    ![Copy and paste 4.png](/images/moengage_2aa009.png)

    <Info>
      1. ブランチをコピーすると、ステージのタイプに関係なく、すべてのステージの構成もコピーされます。
      2. Exit ステージのみを含むブランチはコピーできません。

      ![copy and paste error.png](/images/moengage_46e0af.png)

      3. Flow ブランチをコピーした後、コピーしたブランチは、新しいブランチをコピーするか Flow キャンバスから移動するまでクリップボードに残ります。
      4. GoTo ステージを含むブランチは、離脱ステージの上にのみ貼り付けることができます。 <img src="/images/moengage_c89e0a.png" alt="copy and paste error 2.png" />

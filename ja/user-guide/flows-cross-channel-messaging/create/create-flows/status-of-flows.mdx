ライフサイクルにおけるフローのさまざまなステータスについて、以下で説明します。ステータスは All Flows ページで確認できます。同じステータスに基づいてフローをフィルタリングできます。開いているすべてのフローで、フローの現在のステータスが右上隅に表示されます。

![Screenshot 2024-01-25 at 10.41.52 AM.png](/images/moengage_000ce9.png)

フローのステータスは次のとおりです。

| フローのステータス | フローのエントリータイプ | 説明 | 可能な次のアクション |  |
| --- | --- | --- | --- | --- |
| Draft | すべて | フローが作成された、または公開前に保存された場合 | Edit  <br />Save  <br />Publish  <br />Duplicate |  |
| Scheduled | すべて | フローが公開され、ユーザーのエントリーが将来の指定日時にスケジュールされている場合。 | Edit  <br />Export  <br />Duplicate  <br />Stop  <br />Create a New Version |  |
| Active | Event-Triggered または Previous Flow exit | フローが公開され、スケジュールされた時刻が開始した場合 | Edit  <br />Export  <br />Duplicate  <br />Pause  <br />Stop  <br />Retire  <br />Create a New Version |  |
|  | Time-based Entry | ユーザーがフローに入っている場合 |  |  |
|  |  | 定期フローのスケジュールが期限切れになる前。 |  |  |
|  |  | 1 回限りのエントリーフローにすべてのユーザーが入った場合 |  |  |
|  |  | フローにアクティブなトリップがある場合 |  |  |
| Paused | すべて | フローが一時停止された場合。 | Edit  <br />Export  <br />Duplicate  <br />Resume  <br />Create a New Version |  |
| Stopped | すべて | フローが停止された場合。 | Export  <br />Duplicate |  |
| Retired | すべて | 次の場合: <ol><li>フローがリタイアされた</li><li>既存のバージョンの上に新しいバージョンが作成され、公開された</li></ol> | Export  <br />Duplicate |  |
| Completed | Time-Based Entry | 次の場合: <ol><li>1 回限りのフローにアクティブなフロートリップがない。</li><li>定期フローのスケジュールの期限切れ後にアクティブなトリップがない。</li></ol> | Export  <br />Duplicate |  |
|  | Event-Triggered または Previous Flow exit | アクティブなフロートリップがなく、スケジュールされた終了日時が過去である場合 |  |  |

フローは一時停止、停止、リタイアできます。Scheduled、Completed、Active は MoEngage によって定義されます。

<Note>
  時間ベースのフローでは、ユーザーが一括でエントリーし、1 インスタンスまたは 1 回の実行あたり 1,000 万ユーザーの制限があります。詳細については、[フローの作成](/ja/user-guide/flows-cross-channel-messaging/create/create-flows/create-a-flow#when-will-users-enter-the-flow)を参照してください。
</Note>

# 編集

公開後、フローに入るユーザーと各ステージでのパフォーマンスに関するフローの統計が表示されます。

編集できるのは、アクティブ、スケジュール済み、または一時停止中のフローのみです。変更を行うと現在のフローの新しいバージョンが作成され、公開または保存できます。フローの編集の詳細については、[こちら](/ja/user-guide/flows-cross-channel-messaging/create/create-flows/editing-a-flow)を参照してください。

新しいバージョンを作成する変更は、新しいバージョンの公開後にフローに入るユーザーにのみ影響します。既存のユーザーは新しいバージョンの影響を受けません。既存のユーザーは、エントリー時にアクティブだったバージョンでトリップを続行します。

バージョンを作成しない変更（キャンペーンのコンテンツの編集など）をフローに加えた場合、その変更は、フローの再公開後に編集されたステージを通過するユーザーにのみ反映されます。フローの再公開前にすでに編集されたステージを通過した他のユーザーは、変更の影響を受けません。

# 複製

既存のフローを複製するには、**Actions** をクリックし、**Duplicate** をクリックします。All Flows ページの **Actions** オプションからアクティブなフローを複製することもできます。フローの特定のバージョンを複製するには、まずバージョンセレクターでそのバージョンを選択してから、同じオプションを使用します。

これにより、作成済みのフロー/作成済みのバージョンの複製インスタンスが新しいタブで開き、変更、保存、公開できます。

# 一時停止/再開

アクティブなフローを一時停止するには、**Actions** をクリックし、**Pause** をクリックします。

一時停止すると、アクティブなフロートリップは現在のフローステージで一時停止し、次のステージに進みません。一時停止により、フローを再開した後でも、一部のユーザーがいずれかのフローステージで無期限に停滞する場合があります。

一時停止状態では次のようになります。

- 新しいユーザーはフローに入りません
- メッセージは送信されません
- 条件は評価されません
- すでにフロー内にいるユーザーは、フローの次のステップに進みません。

一時停止中のフローはいつでも再開できます。再開すると、MoEngage はフローを一時停止した時点のフローステージから、ユーザーのアクティブなフロートリップの処理を開始します。

# 停止

公開済みのフローを完全に停止するには、**Actions** をクリックし、**Stop** をクリックします。

![バージョンセレクターと Active ステータスバッジの横で、Stop オプションが強調表示された Actions メニュー](/images/flows-stop-actions-menu.png)

フローを停止すると、フロー内のユーザーは現在のステージで停止し、新しいユーザーはフローに入れなくなります。停止したフローは再開できません。

![Stop Flow Confirmation.png](/images/moengage_de7592.png)

この確認は、フローの以前のバージョンにアクティブなトリップが残っていない場合に表示されます。以前のバージョンにアクティブなトリップがある場合、MoEngage はフローのすべてのバージョンをまとめて停止する別の確認を表示します。詳細については、[アクティブな旧バージョンを持つフローの停止](/ja/user-guide/flows-cross-channel-messaging/create/create-flows/editing-a-flow#stopping-a-flow-that-has-active-older-versions)を参照してください。

# フローのリタイア

フローを停止する際、マーケターは、フローへの新しいエントリーを防ぎながら、現在フロー内にいるユーザーがフローの退出に向けて進むことを許可するよう選択できます。これをフローの **Retiring**（リタイア）と呼びます。

<Note>
  リタイアしたフローでは、すでにフロー内にいるユーザーがフローの退出に向けて進み続けるため、キャンペーンの有効期限が切れるか、ユーザーがフローから退出するまで、それらのユーザーはフローからアプリ内メッセージやオンサイトメッセージを受信し続けることがあります。フローを停止した後は、このようなことは起こりません。詳細については、[フローが停止した後もユーザーがアプリ内メッセージを受信するのはなぜですか?](/ja/user-guide/campaigns-and-channels/in-app-message/faqs-in-app-messages/why-do-users-receive-in-app-messages-even-after-the-flow-has-stopped)および[フローが停止した後もユーザーが OSM キャンペーンを受信するのはなぜですか?](/ja/user-guide/campaigns-and-channels/on-site-message/faqs-on-site-message/why-do-users-receive-osm-campaigns-even-after-the-flow-has-stopped)を参照してください。
</Note>

これは、既存のフローにステージを追加または削除するためにフローを複製する場合に特に便利です。複製したフローを公開したら、ユーザーが両方のフローに入ることを避けるため、必ず元のフローをリタイアしてください。

フローをリタイアするオプションは、Flows キャンバスの右上にある Actions をクリックすると表示されます。

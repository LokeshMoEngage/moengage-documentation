フローテンプレートは、オンボーディング、インセンティブ付与、エンゲージメントといった目標に基づいてフローを作成するためのヒントを提供します。カゴ落ちのリマインダー送信、解約リスクのある顧客へのアプローチ、アプリ/ウェブサイトのエンゲージメント向上のために、単一チャネルまたは複数チャネルのフローを作成できます。各種フローテンプレートについて以下で説明します。

# テンプレートの種類

基本的なテンプレートの種類は、アダプションとエンゲージメントの 2 つです。アダプションテンプレートは新規顧客のオンボーディングに使用でき、単一チャネルと複数チャネルで利用できます。エンゲージメントテンプレートは、単一チャネル、複数チャネル、またはウェブやアプリなどの特定のチャネルで利用できます。アプリやウェブサイトのエンゲージメント向上、特定の商品を閲覧した顧客や特定の商品をカートに追加したまま放置した顧客とのエンゲージメント、解約リスクのある顧客へのアプローチに使用できます。

フローの作成時に次のいずれかのテンプレートを選択するか、空白のキャンバスから始めて任意のフローを構築できます。

| テンプレートの種類 | テンプレート名 | 説明 |
| --- | --- | --- |
| Adoption | Onboard Customers - Single Channel | このテンプレートを使用して、新規顧客を歓迎し、製品やサービスでのジャーニーをガイドします。このテンプレートは、オンボーディング段階の顧客とのコミュニケーションや、オンボーディング後の初回購入への後押しに単一チャネルを使用します。 |
| Adoption | Onboard Customers - Multi-Channel | このテンプレートを使用して、新規顧客を歓迎し、複数のチャネルで顧客とコミュニケーションを取ります。A/B テストを活用して新規ユーザーとのコミュニケーションに最適なチャネルを特定し、その情報を他のオンボーディングフローに活用できます。このテンプレートでは、ロケールと条件分岐を使用してユーザーの現地語を特定し、同じ言語でコミュニケーションを取ります。 |
| Engagement | Abandoned Cart Reminder - Single Channel | このテンプレートを使用して、カートに商品を追加したもののまだ購入していないユーザーにリマインダーを送信します。このテンプレートでは Wait For/Till ノード要素を使用して一定の遅延後にナッジを送信し（ユーザーがカートに商品を追加してから一定時間経過後にのみナッジが送信されます）、設定した時間の経過後にユーザーがカートを放置したか購入したかを確認してからコミュニケーションを送信します。このテンプレートでは、コミュニケーションに単一チャネルを使用します。 |
| Engagement | Abandoned Cart Reminder - Multi Channel | このテンプレートを使用して、複数のチャネルを活用し、カートを放置したユーザーに購入を促します。 |
| Engagement | Browse Abandonment - Multi-Channel | このテンプレートを使用して、商品を閲覧したり特定のカテゴリの商品を検索したりしたものの、まだ購入していない顧客とエンゲージメントを図ります。このテンプレートはコンテキストに沿ったコミュニケーションの送信に役立ち、Intelligent Path Optimization (IPO) を活用して、Merlin AI によりユーザーを最もパフォーマンスの高いパスに自動的かつインテリジェントに振り分けることができます。 |
| Engagement | Customer Reactivation - Multi-channel | このテンプレートを使用して、長期間プラットフォームでアクティブでない顧客とエンゲージメントを図ります。このテンプレートは、厳選したオファーの送信や休眠顧客とのコミュニケーションに役立ちます。このテンプレートでは Next Best Action (NBA) を使用しているため、各顧客が最もエンゲージしやすいチャネルで、最もエンゲージしやすい時間にコミュニケーションが送信されます。 |
| Engagement | Periodic Customer Reactivation - Multi-channel | このテンプレートを使用して、休眠顧客と定期的に（10 日ごとに）エンゲージメントを図ります。このテンプレートは NBA を活用し、各顧客が好むチャネルで、そのチャネルで最もエンゲージしやすい時間にコミュニケーションを取ります。 |
| Engagement | Engage customers on App | このテンプレートを使用して、数日間アプリを利用していない顧客と NBA を使用してエンゲージメントを図ります。このテンプレートでは、アプリ内キャンペーンとカードキャンペーンを使用して、顧客がアプリを開いた際に購入を促します。 |
| Engagement | Engage customers on Web | このテンプレートを使用して、数日間アプリを利用していない顧客と NBA を使用してエンゲージメントを図ります。このテンプレートでは、Web Push、On-site messaging、Cards、Google Ads を組み合わせて、顧客がアプリを開いた際に購入を促します。 |

注:

1. フローテンプレートを編集して、必要に応じてイベントチェックを追加したり、キャンペーンコンテンツを編集したりできます。
2. 必要に応じて、テンプレートにステージを追加または削除できます。

テンプレートを選択したら、次の操作を行います。

1. フローのエントリー条件を追加し、ターゲットオーディエンスとコンバージョンゴール（ある場合）を定義します
2. テンプレート内のキャンペーンを確認し、必要に応じて変更します
3. ビジネスのユースケースに応じて、必要であれば新しいステージやパスを追加します
4. 必要なカスタマイズを行ったら、フローをテストして公開します。

MoEngage Dashboard の All Flows セクションには、公開済みの Flow キャンペーンのパフォーマンス統計が表示され、Flows を検索/表示したり、その統計をエクスポートしたりするオプションも用意されています。下書き状態の Flows も表示できます。

All Flows セクションにアクセスするには、ダッシュボードで **Engage-\>Flows** に移動します。

## Flows の検索

フローキャンペーンは、名前、flow-id、作成日、エントリータイプ、ステータス、キャンペーンタグに基づいて検索できます。

複数のバージョンがあるフローの場合、名前、ステータス、パフォーマンスの列には最新のアクティブバージョンの値が表示され、タグや作成者などのフィルターもそのバージョンに対して照合されます。そのため、後のバージョンで追加したタグは、元のバージョンに再適用しなくてもフィルターで機能します。

![Filter.png](/images/moengage_c7ef34.png)

さらにサポートが必要な場合は、MoEngage のカスタマーサクセスマネージャー (CSM) またはサポートチームにお問い合わせください。

## Flow キャンペーンデータのエクスポート

Flow キャンペーンのデータをエクスポートして、社内レポートを作成したり、追加のインサイトを収集したりできます。データをエクスポートするには、All Flows ページの上部にあるエクスポートボタンをクリックするだけです。

![Screenshot\_2022-09-19\_at\_5.28.40\_PM.png](/images/moengage_9595fd.png)

キャンペーンのエクスポートオプションと、レポートを定期的に配信するようスケジュールする方法については、[こちら](/ja/user-guide/campaigns-and-channels/campaign-management-and-reports/create-ad-hoc-campaign-reports)をご覧ください。

**注**:

- このセクションからフローをエクスポートすると、(アクティブバージョンのデータだけでなく) Flow のすべてのバージョンのデータがエクスポートされます。
- フローの特定のバージョンのデータをエクスポートしたい場合は、Engage -\> Flows -\> 特定の Flow を選択して Flow に移動し、バージョンセレクターでデータをエクスポートしたいバージョンを選択します。Canvas の上にある Flow Details Ribbon の右上隅にある Export をクリックします。

## Flows のパフォーマンス

All Flows ページでは、各フローについて、フローが公開された日からのすべてのバージョンにわたるパフォーマンスを、次の指標で確認できます。

| 指標 | 説明 |
| --- | --- |
| Trips Started | フローが公開された日から開始されたトリップの数です。<br />これは、ユーザーがフローにエントリーした回数です。 |
| Converted Trips | フローが公開された日から、すべてのバージョンにわたって、トリップの期間中に Primary Goal について少なくとも 1 回のコンバージョンにつながったエンゲージ済みトリップの数です。 |
| Conversion Rate (CVR) | CVR の計算式は ((すべてのバージョンにおける Primary Goal の Converted Trips の合計)/(すべてのバージョンにおける Engaged Trips の合計))\*100 です。 |

## キャンペーンのアーカイブ

フローキャンペーンをアーカイブするには、More Action アイコン <Icon icon="ellipsis-vertical" size={32} color="#767676" /> をクリックしてから、**Archive** <Icon icon="box-archive" size={32} color="#767676" /> をクリックします。キャンペーンをアーカイブした後は、ページの **More Filters** のすぐ下にある **Archived campaigns** をオンに切り替えると、一覧で確認できます。キャンペーンのアーカイブを解除するには、More Action アイコンをクリックしてから、**Unarchive** <Icon icon="share-from-square" size={32} color="#767676" /> をクリックします。

---

## 問題

MoEngage プラットフォームで、Push 通知、Email、WhatsApp、SMS を含む複数のチャネルにわたって、特定のエンドユーザーがコミュニケーションを受信しないようにしたいと考えています。

## 解決策

以下の手順を実行して、チャネルの抑制を管理するか、MoEngage サポートを通じて直接ブロックリストへの登録をリクエストします。

### MoEngage ダッシュボードおよび API によるエンドユーザーの抑制

#### Push 通知

以下の手順を実行して、Push 通知を無効にします。

1. MoEngage ダッシュボードの左側のナビゲーションメニューで、Settings \> Channel \> Push に移動します。
2. **Preference Management** をクリックします。
3. 対象のエンドユーザーに対して Push 通知を無効にします。

<Note>
    詳細な手順については、[Preference Management for Push Notifications](https://www.moengage.com/docs/user-guide/campaigns-and-channels/mobile-push/getting-started-with-mobile-push/preference-management-for-push-notifications) を参照してください。
</Note>

#### Email

以下のいずれかの手順を実行します。

- Server-to-Server (S2S) API 呼び出しを使用して、ユーザー属性 **moe\_unsubscribe** を true に更新します。
- MoEngage ダッシュボードで File Import ツールを使用して、対象のエンドユーザーのユーザー属性 **moe\_unsubscribe** を true に設定する CSV ファイルをアップロードします。

#### WhatsApp

以下のいずれかの手順を実行します。

- S2S API 呼び出しを使用して、ユーザー属性 **moe\_wa\_subscription** を false に更新します。
- MoEngage ダッシュボードで File Import ツールを使用して、対象のエンドユーザーのユーザー属性 **moe\_wa\_subscription** を false に設定する CSV ファイルをアップロードします。

#### SMS

以下のいずれかの手順を実行します。

- S2S API 呼び出しを使用して、ユーザー属性 **moe\_sms\_subscription** を false に更新します。
- MoEngage ダッシュボードで File Import ツールを使用して、対象のエンドユーザーのユーザー属性 **moe\_sms\_subscription** を false に設定する CSV ファイルをアップロードします。

### MoEngage サポートを通じた一括ブロックリスト登録のリクエスト

以下の手順を実行して、MoEngage にエンドユーザーを直接ブロックしてもらいます。

1. ブロックする必要があるエンドユーザーの MoEngage ID または一意の識別子を収集します。
2. MoEngage ダッシュボードで、サポートチケットを送信します。
3. 一括ブロックのリクエストとして、サポートチケット内でエンドユーザーのリストを直接共有します。

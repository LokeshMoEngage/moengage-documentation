title: "Live ワークスペースと Test ワークスペースを切り替える際のログインプロセスはどのように機能しますか？"
description: "MoEngage ダッシュボード環境で Live ワークスペースと Test ワークスペースを切り替える際のログインおよび二要素認証のフローについて説明します。"
---

Live ワークスペースと Test ワークスペースを切り替える際のログインプロセス、特に二要素認証 (2FA) とログインの階層を理解することは、異なる環境間をスムーズに移動するために不可欠です。

## 手順

<Tip>
- Live と Test の両方のデータベースへのアクセス権があること。
- ログインの階層を確認すること: SSO ログイン > Google サインイン > シンプルログイン。
- 各ワークスペースで 2FA を有効にする方法を理解していること。
- Live データベースで 2FA が有効になっているかどうかを確認すること。
- Test データベースで 2FA が有効になっていないかどうかを確認すること。
</Tip>

以下の手順を実行します。

1. **Live ワークスペースから Test ワークスペースへの切り替え:**
   - 適切な認証情報 (例: メールアドレス、パスワード、Google Authenticator) を使用して Live ワークスペースにログインします。
   - ログインプロセスで再ログインを求められないことを確認します。
   - ログアウトせずに Test ワークスペースに切り替えます。
   - ダッシュボードユーザーが再ログインせずに Test ワークスペースに切り替えられるかどうかを確認します。
2. **Test ワークスペースから Live ワークスペースへの切り替え:**
   - 指定されたログイン方法 (例: メールアドレスとパスワード) を使用して Test ワークスペースにログインします。
   - ログアウトせずに Live ワークスペースに切り替えます。
   - ログインプロセスで再ログインを求められるかどうかを確認します。
   - Test から Live に切り替える際に、ダッシュボードユーザーが認証情報 (例: メールアドレス、パスワード、Google Authenticator) の入力を求められるかどうかを確認します。

覚えておくべき階層は、SSO ログイン \> Google サインイン \> シンプルログインです。

<Info>
**シナリオ**

- Live ワークスペースでは Google Authenticator を使用しています。
- Test ワークスペースではメールアドレスとパスワードを使用しています。

**動作**

- Live から Test への切り替え: Google サインインはシンプルログインよりも優先度が高いため、ユーザーはログアウトせずに切り替えることができます。
- Test から Live への切り替え: 階層 (Google サインイン > シンプルログイン) により、ユーザーはログアウトされ、再ログインを求められます。
</Info>

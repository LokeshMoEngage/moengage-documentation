---

## 手順

ユーザー属性またはイベント属性の float、long、big integer の値を処理するには、Jinja を使用します。

<Warning>
  _round_ 関数は Jinja 2.8 バージョンではサポートされていないため、代わりに _format_ 関数を使用することをお勧めします。
</Warning>

## 例

Jinja 構文は次のようになります。

<CodeGroup>

```json Jinja wrap
${{'%0.2f'| format(sumHST | float) }} --> User attribute
${{'%0.2f'| format(EventAttribute.totalTaxLessAllInclusiveTaxes|float)}} --> Event attribute
```

</CodeGroup>

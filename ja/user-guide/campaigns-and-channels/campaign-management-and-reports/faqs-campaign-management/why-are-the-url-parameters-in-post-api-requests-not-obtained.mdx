title: "POST API リクエストで URL パラメータが取得されないのはなぜですか？"
description: "MoEngage の Custom Connector と Content API では、URL パラメータは GET リクエストでのみサポートされています。POST リクエストでは URL パラメータは渡されません。"
---

## 問題

Custom Connector のリクエストで指定した URL パラメータが、結果として送信される POST API 呼び出しに含まれません。

<img alt="Untitled design (21).png"  src="/images/moengage_6e1251.png"  />

## 解決策

- Custom Connector または Content API 呼び出しで POST リクエストを行う場合、リクエストに含まれる URL パラメータは送信されません。
- URL パラメータは GET リクエストでのみサポートされており、POST リクエストではサポートされていません。
- この制限は、Content API 呼び出しと Custom Connector API 呼び出しの両方に適用されます。
  <Warning>
  POST リクエストは URL パラメータをサポートしていません。
  </Warning>

# 概要

キャンペーン移行機能を使用すると、同じデータセンター（DC）内のあるワークスペースから別のワークスペースへキャンペーンを移動できます。この機能は次の目的で使用できます。

- キャンペーンを一から作り直すことなく、テストワークスペースから本番ワークスペースへ移行する。ユーザーとして追加されているワークスペースのリストのみが表示されます。
- 複数のワークスペースで同様のキャンペーンが必要な場合に、1 つのキャンペーンを作成してから他の複数のワークスペースに移行する。
- 同じキャンペーンを複数回移行する。
- 移行先ワークスペースでインポートしたキャンペーンに加えた変更が、移行元ワークスペースの元のキャンペーンに影響しないようにする。

<Info>
  この機能は、In-app Messaging、On-site Messaging（OSM）、Web Personalization、Connected Apps、Cards を除くすべてのチャネルで、キャンペーンのみ（フローは対象外）の移行をサポートしています。
</Info>

# キャンペーンをインポートする

<Tip>
  ロールに **Campaigns** コンポーネントの **Create and Manage** 権限がある場合、キャンペーンをインポートできます。
</Tip>

あるワークスペースから別のワークスペースへキャンペーンを移行するには、次の手順を実行します。

1. MoEngage ダッシュボードの All campaigns ページに移動します。
2. 右上隅にある **Import Campaign** をクリックします。Import campaign ページが表示されます。

キャンペーンのインポートには、次の 2 つのステップがあります。

1. [キャンペーンの選択](/ja/user-guide/campaigns-and-channels/campaign-management-and-reports/campaign-migration#step-1-select-campaigns)
2. [インポートされたキャンペーン](/ja/user-guide/campaigns-and-channels/campaign-management-and-reports/campaign-migration#step-2-imported-campaigns)

## ステップ 1: キャンペーンの選択

![](/images/moengage_164da2.png)

1. Import campaign ページで、**Source workspace** リストから移行元ワークスペースを選択します。これは、キャンペーンのインポート元となるワークスペースです。移行元ワークスペースを選択すると、そのワークスペース内のキャンペーンのリストが下に表示されます。
2. 名前または ID で必要なキャンペーンを検索します。
3. チャネル、配信タイプ、作成日でキャンペーンをフィルタリングできます。
4. フィルターアイコンをクリックします。Filter campaigns ダイアログボックスで、ステータス、キャンペーンタグ、プラットフォーム、キャンペーン作成者でキャンペーンをフィルタリングできます。
5. **Import** をクリックします。
   ![](/images/moengage_6e4f2d.png)
6. ワークスペースで **Team** 機能が有効になっている場合は、**Destination team** を選択して **Import** オプションを有効にします。
   ![](/images/moengage_971639.png)
   ステップ 2 のインポートされたキャンペーンに移動します。

<Info>
  **Draft** 以外の任意のステータスのキャンペーンを移行できます。1 回のインポートで選択できるキャンペーンは最大 15 件です。
</Info>

## ステップ 2: インポートされたキャンペーン

1. キャンペーンをインポートすると、そのキャンペーンは **Draft** ステータスになり、横に **Import Status** が表示されます。次の表に、考えられるインポートステータスを示します。
   | **ステータス** | **定義** | **例** |
   | --- | --- | --- |
   | **Successful** | キャンペーンが正常にインポートされたことを示します。 |  |
   | **Imported with errors** | インポートされたキャンペーンに必須フィールドの値が欠落していることを示します。キャンペーンを公開する前に、これらのエラーを修正する必要があります。 | たとえば、移行元ワークスペースのキャンペーンで、移行先ワークスペースに存在しない _productpurchase_ イベントを使用している場合、**Imported with errors** ステータスが表示されます。 |
   | **Imported with warnings** | インポートされたキャンペーンに警告があることを示します。警告があってもキャンペーンは公開でき、修正は任意です。 | たとえば、移行元ワークスペースのキャンペーンで、移行先ワークスペースに存在しない _sales_ タグを使用している場合、**Imported with warnings** ステータスが表示されます。 |
   | **Imported with errors & warnings** | インポートされたキャンペーンに、必須フィールドと任意フィールドの両方の値が欠落していることを示します。キャンペーンを公開する前に、すべてのエラーを修正する必要があります。 | たとえば、移行元ワークスペースのキャンペーンでパーソナライズ用の Content API とキャンペーンタグを使用しており、これらが移行先ワークスペースで利用できない場合、**Imported with errors & warnings** ステータスが表示されます。表示されたリンクをクリックして **Draft** モードでキャンペーンにアクセスし、これらの問題を修正してください。 |
   | **Failed** | 必要な条件が満たされていないため、キャンペーンのインポートに失敗したことを示します。 | たとえば、移行元ワークスペースで WhatsApp キャンペーンが作成されているものの、移行先ワークスペースで WhatsApp チャネルが有効になっていない場合、WhatsApp キャンペーンのインポートは失敗します。失敗の理由を確認するには、キャンペーン名の下にある矢印を展開します。エラーを修正してから、移行先ワークスペースでキャンペーンを公開する必要があります。 |
2. インポートされたすべてのキャンペーンを表示するには、**View imported campaigns** をクリックします。All campaigns ページの **Drafts** タブが開きます。ここでは、インポートされたキャンペーンのソースとして **Imported** が表示されます。エラーまたは警告のあるキャンペーンには、名前の横に警告またはエラーの記号が表示されます。
   ![](/images/moengage_baa54b.png)

# インポートされたキャンペーンのエラーと警告を特定して解決する

All campaigns ページの **Drafts** タブで、エラーまたは警告のあるキャンペーン名をクリックすると、キャンペーンが **Draft** モードで開きます。各キャンペーンステップの上部に、次の情報を含むセクションが表示されます。

| **エラーステータスと件数** | **定義** |
| --- | --- |
| **Errors & warnings on this page** | 現在のキャンペーンページまたはステップにおけるエラーと警告の件数を示します。 |
| **Total errors & warnings in this campaign** | このキャンペーンにおける警告とエラーの合計件数を示します。 |
| **Resolved** | このキャンペーンで解決されたエラーと警告の件数を示します。 |
| **Fix pending** | このセクションには、エラーと警告の理由が一覧表示されます。この情報を使用して問題を修正してください。問題を修正したら、その横にある更新ボタンをクリックします。**Resolved** の件数がそれに応じて更新されます。 |

![](/images/moengage_5a20b6.png)

すべてのキャンペーンステップにわたる警告、エラー、解決済みの問題をすべて表示するには、**Total errors & warnings in this campaign** の横にある **Learn More** をクリックします。

![](/images/moengage_cc7038.png)

<Info>
  - インラインのエラーメッセージが表示されない限り、警告があっても次のステップに進むことができます。たとえば、_addtocart_ イベントが利用できない場合は、移行先ワークスペースのセグメンテーションで同じイベントを使用するか、より適切な別のイベントを選択することで問題を解決できます。
  - 移行されたキャンペーンでは、自動保存機能は利用できません。
</Info>

# インポートされたキャンペーンを公開する

エラーと警告を解決したら、**Publish** をクリックしてキャンペーンを開始します。すべてのエラーを修正せずにキャンペーンを公開しようとすると、**Errors/Warnings still pending** ダイアログボックスが表示されます。このダイアログボックスには、残っているすべてのエラーと警告が一覧表示されます。キャンペーンを正常に配信するには、すべてのエラーを修正する必要があります。警告があるキャンペーンは公開できますが、エラーがあるキャンペーンは公開できません。

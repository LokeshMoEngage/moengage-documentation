### メッセージコンテンツの例

#### 単一メッセージオブジェクトの構造

SFTP および S3 でアーカイブされた単一メッセージのファイル内容の例を次に示します。

<CodeGroup>

```json S3 wrap
{
 "message_content": {
 "summary": "{message_summary}", 
 "related_urls": ["{image_or_deep_link_url}"],
 "title": "🎉 MarketingCampaigner Implemented!!",
 "message": "Sample push notification message"
      }, 
 "backup_content": {
 "summary": "{message_summary}",
 "related_urls": ["{image_or_deep_link_url}"],
 "message": "{message_body_content}",
 "title": "{message_title}",
 "message_details": {
 "sent_time": "Tue, 21 Jan 2025 09:54:59 EST",
  "template_info": {
      "id": "basic", 
      "type": "Native"
      },
 "delivery_type": "API_TRIGGERED", 
  "service": {
       "type": "APNs"
      },
 "channel": "push", 
 "message_type": "campaign", 
 "message_id": "{{message_id}}",
 "message_to": "", 
 "platform": "ios"
      }
      }
```

<Info>
  - UI の _View Sent Message_ 機能は、SFTP 方式では使用できません。
  - パーソナライズされていないメッセージの場合、SFTP によるメッセージアーカイブではメッセージコンテンツのコピーは 1 つのみとなり、MoEngage はメッセージを受信したすべてのユーザーの "user\_ids" を追加します。
</Info>

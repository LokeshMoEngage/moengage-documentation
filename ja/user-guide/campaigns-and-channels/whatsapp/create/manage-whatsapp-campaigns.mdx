MoEngageでWhatsAppキャンペーンを効果的に管理するには、キャンペーンのさまざまなステータスとその管理方法を理解しておくと役立ちます。このガイドでは、WhatsAppキャンペーンを表示、複製、削除する方法について説明します。

## WhatsAppキャンペーンのステータスを理解する

以下の表は、MoEngageでWhatsAppキャンペーンが取りうるさまざまなステータスについて説明しています。

| ステータス | 説明 |
| --- | --- |
| Draft | キャンペーンは下書き状態で、公開されていません。 |
| Not Sent | キャンペーンはどのターゲットオーディエンスにも送信されていません。 |
| Sending | キャンペーンは現在ターゲットオーディエンスに送信中です。 |
| Scheduled | キャンペーンは将来の時刻にターゲットオーディエンスへ送信されるようにスケジュールされています。 |
| Sent | キャンペーンはすべてのターゲットオーディエンスに送信されました。 |
| Active | キャンペーンは送信済みで、すべてのターゲットオーディエンスが利用できます。 |
| Paused | キャンペーンはすべてのターゲットオーディエンスに対して一時停止されています。 |
| Stopped | キャンペーンはすべてのターゲットオーディエンスに対して停止されています。 |
| Expired | キャンペーンはすべてのターゲットオーディエンスに対して期限切れになっています。 |
| Under Review | キャンペーンは現在、キャンペーン承認プロセスの一環としてレビュー中です。詳細については、[キャンペーン承認ワークフロー](/ja/user-guide/settings/account/team-management/campaign-approval-workflow)を参照してください。 |
| Rejected | キャンペーンはキャンペーン承認プロセス中に却下されました。詳細については、[キャンペーン承認ワークフロー](/ja/user-guide/settings/account/team-management/campaign-approval-workflow)を参照してください。 |

## WhatsAppキャンペーンを表示する

キャンペーンの詳細を表示すると、キャンペーンのパフォーマンスとステータスをモニタリングできます。Campaign infoページにアクセスすると、主要な指標の確認、オーディエンスのエンゲージメントの分析、配信のトラッキング、コンバージョン目標の評価を行えます。これにより、キャンペーンのパフォーマンスを包括的に把握でき、今後のマーケティング活動においてデータに基づいた意思決定を行うのに役立ちます。WhatsAppキャンペーンを表示するには、以下の手順を実行します。

1. MoEngageダッシュボードで、**Engage** \> **All Campaigns** に移動します。
2. **All Campaigns** ページで、フィルターを使用して目的のキャンペーンを検索します。チャネルフィルターを使用して、WhatsAppキャンペーンのみを表示することもできます。
3. 必要なキャンペーンを絞り込んだ後、以下のいずれかの方法でキャンペーンの詳細を表示します。
   - キャンペーン行の右側にある省略記号メニューをクリックし、**View** を選択します。
   - キャンペーン行を直接クリックして、**Campaign Info** ページを開きます。

![](/images/moengage_24b158.png)

## WhatsAppキャンペーンを複製する

キャンペーンを複製すると、時間と手間を節約できます。新しいキャンペーンを一から作成する代わりに、成功したキャンペーンをテンプレートとしてすばやく再利用できます。WhatsAppキャンペーンを複製するには、以下の手順を実行します。

1. MoEngageダッシュボードで、**Engage** \> **All Campaigns** に移動します。
2. **All Campaigns** ページで、フィルターを使用して複製するキャンペーンを検索します。
3. 必要なキャンペーンを絞り込んだ後、以下のいずれかの方法でキャンペーンを複製します。

- 省略記号アイコンをクリックし、 **Duplicate** をクリックします。
- キャンペーンをクリックして **Campaign Info** ページを開きます。このページで、**Duplicate** (<img alt="duplicatebutton.png" src="/images/DuplicateButton-2.png" style={{ display:"inline", width: "10%"  }} />) ボタンをクリックします。

## WhatsAppキャンペーンを削除する

キャンペーンを削除すると、ダッシュボードから完全に削除されます。削除できるのは、Draft状態のキャンペーンのみです。これにより、アクティブなキャンペーンと完了したキャンペーンのリストを整理された状態に保てます。WhatsAppキャンペーンを削除するには、以下の手順を実行します。

1. MoEngageダッシュボードで、**Engage** \> **Drafts** に移動します。**All Campaigns** ページから下書きを探すこともできます。

![](/images/moengage_2bbdbc.png)

2. 対象の下書きキャンペーンで、以下のいずれかの手順を実行してキャンペーンを削除します。
   - 削除するキャンペーンの **Actions** 列にある削除アイコン( <Icon icon="trash" iconType="solid" color="grey" />)をクリックします。
   - キャンペーン名の横にあるチェックボックスをクリックすることもできます。以下に示すように、上部バーの **Delete** をクリックします。この方法を使用すると、複数の下書きを同時に削除できます。 <img src="/images/moengage_6d354f.png" alt="WA Delete Campagin.png" />

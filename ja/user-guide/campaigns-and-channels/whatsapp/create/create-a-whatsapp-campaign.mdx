# WhatsAppキャンペーンを作成する手順

キャンペーンの作成プロセスは、以下の3つのステップで構成されます。

1. [ターゲットユーザー](/ja/user-guide/campaigns-and-channels/whatsapp/create/create-a-whatsapp-campaign#step-1-target-users): キャンペーンのターゲットオーディエンスを定義します。
2. [コンテンツ](/ja/user-guide/campaigns-and-channels/whatsapp/create/create-a-whatsapp-campaign#step-2-content): 送信するキャンペーンのコンテンツを定義します。
3. [スケジュールと目標](/ja/user-guide/campaigns-and-channels/whatsapp/create/create-a-whatsapp-campaign#step-3-schedule-and-goals): キャンペーンの配信スケジュールと目標を定義します。

## Step 1: Target Users

このセクションには以下が含まれます。

キャンペーンの詳細セクションには、以下のフィールドがあります。

### オーディエンスの選択

このセクションには、キャンペーンのターゲットオーディエンスを選択するためのセグメンテーションフィルターがあります。以下のオプションを使用できます。

    このフィルターオプションを選択すると、すべてのアプリユーザーにキャンペーンを送信します。このオプションを使用する場合、複数のフィルターを追加することはできません。

    1. ドロップダウンリストから目的の属性を選択します。選択した属性に基づいたフィルターが有効になります。たとえば、数値の属性には「is equal to」、「is not equal to」、「is between」などのフィルター条件があり、文字列の属性には別のフィルターがあります。
    2. フィルター値を入力して、目的のユーザーセグメントを作成します。
    3. **\+ Nested Filter** をクリックしてフィルターを追加し、ネストされたANDまたはOR条件を作成します(任意)。

  <Tab title="ユーザー行動でフィルター">
    このフィルターオプションを選択すると、アプリ/サイトの起動、商品の閲覧など、ユーザーの行動に基づいてユーザーをターゲットにします。**User Behavior** タブをクリックし、以下を実行します。

    6. **\+ Nested Filter** をクリックしてフィルターを追加し、ネストされたANDまたはOR条件を作成します(任意)。

    詳細については、[セグメントを作成する](/ja/user-guide/segment/create-segments/rule-based-filter-segments)を参照してください。

  </Tab>

    このフィルターオプションを選択すると、特定の属性値でアクションを実行したユーザーに基づいて作成されたユーザーグループをターゲットにします。詳細については、[ユーザーアフィニティ](/ja/user-guide/segment/create-segments/affinity-segments)を参照してください。**User Affinity** タブをクリックし、以下を実行します。

    - **Most no. of times**: 値を入力するか矢印を使用して、上位のユーザーの割合を指定します。
    - **Least no. of times**: 値を入力するか矢印を使用して、下位のユーザーの割合を指定します。

    1. 利用可能なカスタムセグメントのリストから、ターゲットオーディエンスとするカスタムセグメントを選択します。

フィルター条件を選択した後、以下の操作も実行できます。

- **複数のフィルターを作成する**: このオプションを使用すると、複数のユーザープロパティルール、ユーザーアクティビティルール、カスタムセグメントルールを作成して組み合わせ、複雑なユーザーセグメントを作成できます。
  1. **\+ Filter** をクリックします。
  2. **AND** または **OR** をクリックします。
  3. 属性またはイベントを選択し、フィルター条件を定義します。
- **Exclude Users**: このチェックボックスを選択すると、キャンペーンから除外するユーザーのフィルター条件を定義できます。
- **Send campaign to the users ignoring Opt-in preference**: このオプションを選択すると、オプトイン設定を無視して、ターゲットセグメント内のすべてのユーザーにキャンペーンを送信します。これにより、メッセージング規制への完全な準拠が確保され、望まれないコミュニケーションが防止されます。詳細については、[前提条件](/ja/user-guide/campaigns-and-channels/whatsapp/getting-started-with-whatsapp/prerequisites)を参照してください。
- **Reset filters**: このオプションをクリックすると、セグメンテーションフィルターがリセットされます。
- **Show count**: このボタンをクリックすると、設定されたセグメントに現在含まれているユーザーの総数が表示されます。

## Step 2: Content

このセクションでは、WhatsAppキャンペーンにコンテンツを追加する方法について説明します。

1. 送信者を選択します。
2. ドロップダウンからテンプレートを検索または選択します。詳細については、[WhatsAppテンプレート](/ja/user-guide/campaigns-and-channels/whatsapp/getting-started-with-whatsapp/whatsapp-templates)を参照してください。
3. テンプレートで定義されたとおりにコンテンツをカスタマイズします。

### WhatsAppでのパーソナライズ

WhatsAppキャンペーンのコンテンツをパーソナライズするには、

1. **Content** セクションに表示されるフィールドに @ を入力します。フィールドは、選択した送信者とテンプレートによって異なります。
2. **WhatsApp Personalization** ポップアップウィンドウが表示され、**Data personalization**、**Content blocks**、**Aux data** をパーソナライズできます。

詳細については、[WhatsAppキャンペーンをパーソナライズする](/ja/user-guide/campaigns-and-channels/whatsapp/create/personalize-whatsapp-campaign)を参照してください。 <img alt="whatsapp.png" src="/images/moengage_666697.png" />

### URL短縮 - 注意事項

URL短縮については、以下の点に注意してください。

1. 短縮リンクは14日で期限切れとなり、期限切れ後はトラッキングできません。顧客が期限切れのリンクを開くと、「**This link is no longer active**」というメッセージが表示されます。
2. 短縮リンクでユーザー属性やイベント属性を使用する場合、属性名は以下に従う必要があります。
   1. スペースを含めないでください。
   2. 属性にリンクが含まれる場合、その値に http:// または https:// を含めないでください。これらは属性の前に追加してリンクを短縮できます。
3. アポストロフィやカンマなどの特殊文字は、短縮リンクではサポートされていません。
4. 短縮するリンクでは、複数のJINJA操作はサポートされていません。たとえば、(短縮するリンク内で)ProductでContent APIリンクを使用すること、またはその逆はサポートされていません。

### Dynamic Link Tracking

Dynamic Link Trackingを使用するには、

1. WhatsAppパートナーの承認用に提出するテンプレートには、次のURLを含める必要があります: [_https://ux.mnge.co_](https://ux.mnge.co)_._ URL内の「x」はMoEngageのデータセンター(DC)を指します。MoEngageは各顧客を異なるDCでホストしています。DCマッピングを[こちら](/ja/user-guide/data/key-concepts/data-centers-in-moengage)で参照してDC番号(Xの値)を確認し、URL内の「X」の値を置き換えてください。
2. 以下の設定でMoEngageにテンプレートを作成します。 <img src="/images/moengage_351f8e.png" alt="Button_DynamicLinkTracking.png" />
3. キャンペーンの作成時に、目的のURLを追加します。リンクは自動的に短縮されます。

MoEngageでは、プレビューに表示されるWhatsAppメッセージを確認することをお勧めします。

<Accordion title="UTMパラメーターの追加">

</Accordion>

## Step 3: Schedule and Goals

このセクションには以下が含まれます。

- [配信コントロール](/ja/user-guide/campaigns-and-channels/whatsapp/create/create-a-whatsapp-campaign#delivery-controls): 通知のスロットリング、フリークエンシーキャップ、有効期限設定などの高度な配信コントロールオプションを選択します。

### Delivery Schedule

<Accordion title="Periodic">
  このオプションを選択すると、指定した日時に定期的にキャンペーンを送信します。このセクションでは、以下のフィールドを使用できます。

  - **Campaign time zone**: キャンペーンを送信するタイムゾーン。
  - **Start date**: キャンペーンを送信する日付。
  - **Send time**: キャンペーンを送信する時刻。時間帯に応じて **am** または **pm** を選択します。
  - **Periodic:** キャンペーンの周期。**Daily**、**Weekly**、**Monthly** のオプションがあります。
    | 周期 | 説明 |
    | :-- | :-- |
    | **Daily** | **Repeat every**: このオプションでは、キャンペーンを繰り返す間隔を日数で指定できます。 たとえば、3日ごとに繰り返すよう選択し、キャンペーンが月曜日に開始された場合、次は木曜日に実行されます。 |
    | **Weekly** | <ul><li>**Repeat every**: このオプションでは、キャンペーンを繰り返す間隔を週数で指定できます。たとえば、3週間ごとに繰り返すよう選択し、キャンペーンが第1週に開始された場合、次は第4週に実行されます。</li><li>**Repeat on**: このオプションでは、キャンペーンを送信する曜日を指定できます。たとえば、毎週月曜日、水曜日、金曜日にキャンペーンを送信したい場合は、このオプションでこれらの曜日を選択します。</li></ul> |
    | **Monthly** | <ul><li>**Repeat every**: このオプションでは、キャンペーンを繰り返す間隔を月数で指定できます。 たとえば、3か月ごとに繰り返すよう選択し、キャンペーンが1月に開始された場合、次は4月に実行されます。</li><li>**Repeat on**: このオプションでは、以下を実行できます。 <ul> <li>**Days of month**: 日付を指定して繰り返すキャンペーンの場合は、このオプションを選択します。キャンペーンを送信する月の日付を選択します。たとえば、毎月5日と25日にキャンペーンを送信するには、カレンダーウィジェットで5日と25日を選択します。**注**: 選択した日付が指定した月に存在しない場合(短い月の場合)、キャンペーンはその月の最終日に送信されます。たとえば、30日と31日を選択し、月が2月の場合、キャンペーンは28日に1回送信されます。</li><li>**Days of week**: このオプションを選択すると、キャンペーンを送信する曜日を指定できます。たとえば、毎週月曜日、水曜日、金曜日にキャンペーンを送信したい場合は、このオプションでこれらの曜日を選択します。 <br />**注**: ある月に該当する曜日が存在しない場合(たとえば、第5土曜日)、そのインスタンスのキャンペーンはスキップされます。また、重複する場合(たとえば、第4月曜日と最終月曜日)は、1つのインスタンスのみが送信されます。</li></ul></li></ul> |
  - **Ends**: キャンペーンが終了する日付。以下のオプションを使用できます。
    - **Never**: キャンペーンは毎日実行されるようにスケジュールされます。
    - **On**: キャンペーンは **End Date** フィールドで指定した日付に終了します。
    - **After**: キャンペーンは **occurrences** フィールドで指定した回数の実行後に終了します。

  **イベントトリガー型キャンペーンはいつ送信されますか?**

  キャンペーンは、以下の場合にのみ送信されます。

  - この種のトリガーの作成に使用されるイベントプロパティ/属性(flight\_timeの例など)が、有効な日時形式である場合。日時形式でない場合、文字列には[サポートされている形式](/ja/user-guide/campaigns-and-channels/getting-started/triggers/event/create-an-event-triggered-campaign#supported-formats)のいずれかのデータが含まれている必要があります。選択した属性にこれらの形式のいずれのデータも含まれていない場合、キャンペーンはユーザーに送信されません。
  - 属性の日時の値が、トリガー条件が満たされた時刻より後である場合。
  - 属性の日時の値が、トリガー条件が満たされた時刻 \+ 30日より前である場合。たとえば、トリガー条件が日付Dに満たされた場合、通知は属性値がD\+30より前である場合にのみ送信されます。
  - インテリジェントな遅延最適化(**With Delay**)は、相対タイミングで送信されるキャンペーンでは機能しません。

### Conversion Goals

コンバージョン目標を追加して、キャンペーンのビジネス指標をトラッキングできます。最大5つのコンバージョン目標をトラッキングできます。任意のアプリイベントをコンバージョン目標のアクティビティとして選択でき、複数のコンバージョン目標を設定できます。最初の目標がプライマリ目標として扱われます。

たとえば、キャンペーンの送信後にiPhoneを購入した顧客数をトラッキングしたいとします(イベント: 購入イベント、商品: iPhone)。コンバージョン目標の設定は、以下の画像のようになります。

![ConVErsionGoals.png](/images/moengage_693599.png)

複数のコンバージョン目標を使用すると、複数のビジネス指標をトラッキングしたり、ユーザーアクションのファネルを可視化したりできます。たとえば、以下を確認したい場合は、複数のコンバージョン目標を使用して確認できます。

- 商品ページを閲覧したユーザーは何人ですか?
- そのうち、その商品をカートに追加したユーザーは何人ですか?
- そのうち、注文を完了したユーザーは何人ですか?

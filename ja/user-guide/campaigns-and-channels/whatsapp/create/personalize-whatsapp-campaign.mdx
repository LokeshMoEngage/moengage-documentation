[パーソナライズ](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/overview)により、マーケティングメッセージがユーザーにとってより関連性の高いものになります。WhatsAppキャンペーンをカスタマイズすることで、オーディエンスとのより強いつながりを築き、メッセージの受け入れられ方を向上させることができます。

この記事では、One Time、Periodic、Event Triggeredのメッセージを含む、MoEngageのWhatsAppキャンペーンでパーソナライズを使用する方法について説明します。

<Info>
  パーソナライズの条件やロジックを作成すると、チップとして表示されます。チップアクションの詳細については、[こちら](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/dynamic-content-personalization)を参照してください。
</Info>

WhatsAppキャンペーンのメッセージにパーソナライズされたコンテンツを追加するには、

1. キャンペーン作成プロセスで、[Step 2: Content](/ja/user-guide/campaigns-and-channels/whatsapp/create/create-a-whatsapp-campaign#step-2-content)に移動します。
2. パーソナライズ可能なWhatsAppのコンテンツフィールドには、プレースホルダーテキスト **Type @ to personalize** が表示されています。
3. コンテンツフィールドで、パーソナライズされたコンテンツを挿入したい位置に **@** 記号を入力します。**WhatsApp Personalization** エディターが表示されます。

![WhatsAppPersonlization.gif](/images/moengage_f6def8.png)

**WhatsApp Personalization** エディターでは、以下を実行できます。

- [データのパーソナライズ](/ja/user-guide/campaigns-and-channels/whatsapp/create/personalize-whatsapp-campaign#data-personalization)
- [Content blocksを使用したパーソナライズ](/ja/user-guide/campaigns-and-channels/whatsapp/create/personalize-whatsapp-campaign#personalize-using-content-blocks)
- [補助データを使用したパーソナライズ](/ja/user-guide/campaigns-and-channels/whatsapp/create/personalize-whatsapp-campaign#personalize-using-auxiliary-data)

# Data Personalization

ユーザー属性、Product Sets(Recommendations)、Content APIを使用して[メッセージをパーソナライズ](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/overview)できます。メッセージフィールドにパーソナライズを挿入するには、@ を入力します。以下の画像のように、パーソナライズメニューが開きます。

![Screenshot 2025-09-08 at 4.36.24 PM.png](/images/moengage_86260a.png)

### フォールバックを選択する

メッセージをパーソナライズする場合、フォールバックオプションを使用すると、選択した属性がユーザーに対して利用できない場合や正しく表示されない場合でも、常にコンテンツが表示されるようになります。

以下のフォールバックオプションから選択できます。

- 失敗した属性の代替がない場合は、**No Fallback** を選択します。パーソナライズに失敗した場合、パーソナライズされた属性は空の文字列に置き換えられます。
- パーソナライズに失敗した場合にWhatsAppメッセージを送信しないようにするには、**Do not send SMS & RCS** を選択します。
- 失敗した属性を任意のテキストに置き換える場合は、**Replace text** を選択します。パーソナライズに失敗した場合、パーソナライズされた属性は **Fallback text** フィールドに入力したテキストに置き換えられます。

<Info>
  カスタム属性に、MoEngageの標準属性と同じ名前を付けないようにしてください。同じ名前のカスタム属性と標準属性をパーソナライズに使用すると、パーソナライズが正しく行われない可能性があります。
</Info>

## Recommendations(Product Sets)を使用してパーソナライズする

Recommendations(Product sets)を使用すると、リアルタイムかつコンテキストに応じた商品のレコメンデーションを顧客に伝えることができます。詳細については、[Recommendations](/ja/user-guide/content/recommendations/personalize-campaign-with-recommendations)を参照してください。

<Tip>
  **前提条件**

  - 設定済みで、ユーザーアクションにマッピングされたRecommendation(Product sets)。
  - Recommendations(Product sets)のデータを格納するプレースホルダーを含む、事前承認済みのWhatsAppテンプレート。たとえば、ユーザー属性からユーザー名をパーソナライズし、Recommendation(Product sets)からおすすめ商品のタイトルとリンクを追加したい場合は、以下の例で説明するように、3つのプレースホルダーを含むテンプレートの承認を得てください。
</Tip>

WhatsAppを使用して動的な商品レコメンデーションを送信するには、以下を実行します。

1. キャンペーン作成プロセスのステップ2で、Recommendationsテンプレートが承認されている送信者を選択します。
2. 承認済みのテンプレートを選択します。
3. @ を入力してプレースホルダーを入力します。表示されるパーソナライズ画面で、ユーザー属性とProduct Setの属性を選択します。
   1. Product Setの場合は、目的のProduct Setを選択してOKをクリックします。これにより、Product Setがプレースホルダーに追加されます。Product Setには通常、アイテムのリストが含まれており、各アイテムには名前、タイトル、ID、画像リンクなどの特定の属性があります。Product Setをそのまま追加すると、Product Setのすべてのコンテンツがメッセージに表示されます。
   2. Recommendationsセットから1つのアイテムのみを追加するには、以下で説明するようにProduct Setをループ処理して目的のアイテムを取得します。このアイテムについて、forループ内で @ を入力し、パーソナライズウィンドウでProduct Setから目的のプロパティを選択して、目的の属性を取得します。
4. パーソナライズされたプレビューをクリックして、特定のユーザー向けのメッセージを確認します。

![WA\_ContentCreation.png](/images/moengage_6b5913.png)

以下の例では、テンプレートに3つのプレースホルダーがあります。

1. 1つ目のプレースホルダーはパーソナライズに使用され、_firstname_ ユーザー属性を使用して取得されます。
2. 2つ目のプレースホルダーは、`ProductSet` というProduct Setをループ処理してProduct Setの最初のアイテムを取得し、以下のJINJAコードを使用してそのタイトルを表示します。この例では、おすすめ商品は **Sneakers** です。
   <CodeGroup>
   ```text JINJA
   {% if ProductSet.product_recommendations%}
   {% for product in ProductSet.Recommendations[0:1]%}
   {{product.title}}
   {% endfor %}
   {% else %}
   MOE_NOT_SEND
   {% endif %}
   ```
   </CodeGroup>
3. 3つ目のプレースホルダーは、以下のJINJAコードを使用してRecommendationsのProduct Setをループ処理し、おすすめ商品のリンクを取得します。
   <CodeGroup>
   ```text JINJA
   {% if ProductSet.Recommendations%}
   {% for product in ProductSet.Recommendations[0:1]%}
   {{product.link}}
   {% endfor %}
   {% else %}
   MOE_NOT_SEND
   {% endif %}
   ```
   </CodeGroup>

JINJAの詳細については、[MoEngageテンプレート言語](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/jinja-templating-language)を参照してください。

## Content APIを使用してパーソナライズする

WhatsAppキャンペーンは、Content APIを使用してパーソナライズし、関連性の高いタイムリーな情報をユーザーに配信できます。

### Content APIを追加する

Content APIはMoEngageダッシュボードに追加できます。**Settings** \> **APIs** \> **Content API** に移動してContent APIにアクセスし、**Add** をクリックしてContent APIを追加します。詳細については、[Content APIを使用してコンテンツをパーソナライズする](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/personalize-content-using-content-apis)を参照してください。

### Content APIを使用してパーソナライズされたキャンペーンを作成する

1. コンテンツ作成ステップで **@** を入力して、パーソナライズエディターを呼び出します。
2. **SMS and RCS personalization** ポップアップで、**Data Personalization** タブに移動します。
3. Content APIを検索し、リストからAPIを選択します。
4. **Done** をクリックします。 <img src="/images/moengage_cf5656.png" alt="Screenshot 2025-09-08 at 5.22.32 PM.png" />

# Personalize Using Content Blocks

Content Blocksは、さまざまなキャンペーンで使用できる再利用可能なコンテンツスニペットです。ヘッダー、フッター、署名ブロック、利用規約などの標準的な要素に特に便利です。

コンテンツブロックを使用してメッセージをパーソナライズするには、

1. コンテンツセクションに @ を入力します。
2. 表示されるパーソナライズメニューで、**Content blocks** タブをクリックします。
3. 挿入するコンテンツブロックを選択します。
4. **Done** をクリックすると、選択したContent Blockが以下のようにメッセージに追加されます。
5. **Insert only the content of the content block** トグルをオンにすると、コンテンツが既存のコンテンツブロックから切り離され、今後コンテンツブロックを更新してもキャンペーンには反映されなくなります。この手順は任意です。 詳細については、[Content Blocks](/ja/user-guide/content/content-blocks/content-blocks)を参照してください。

# Personalize Using Auxiliary Data

パーソナライズエディターで補助データの属性を選択することで、補助データを使用してWhatsAppのコンテンツをパーソナライズできます。

補助データの属性を使用してコンテンツをパーソナライズするには、

1. パーソナライズがサポートされているフィールドに @ を入力して、パーソナライズエディターを呼び出します。
2. **Aux Data** タブを選択します。
3. **Aux data** ドロップダウンリストで、パーソナライズに使用する属性を含む補助データファイルを選択します。
4. **Lookup value** ドロップダウンリストで、インポート時に補助データに指定したプライマリキーを選択します。これにより、補助データを取得する対象のユーザーが識別されます。
5. **Attribute** ドロップダウンリストで、補助データを使用してパーソナライズする属性を指定します。
6. **Done** をクリックします。補助データのJINJAがフィールドまたはエディターに追加されます。 <img src="/images/moengage_af2977.png" alt="Screenshot 2025-09-08 at 4.49.05 PM.png" />

詳細については、[補助データを使用してキャンペーンコンテンツをパーソナライズする](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/personalize-content-using-auxiliary-data)を参照してください。

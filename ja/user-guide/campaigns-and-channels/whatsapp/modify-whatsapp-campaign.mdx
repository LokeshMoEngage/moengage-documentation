最初のWhatsAppキャンペーンを送信する前に、MoEngageでWhatsAppキャンペーンがとりうるさまざまなステータスを理解しておく必要があります。また、これらのキャンペーンを表示する方法や、要件に応じて複製または削除する方法も知っておく必要があります。

## ステータス

次の表は、WhatsAppキャンペーンのすべてのステータスを説明しています。

| ステータス | 説明 |
| --- | --- |
| Draft | キャンペーンは下書き状態で、公開されていません。 |
| Not Sent | キャンペーンはどのターゲットオーディエンスにも送信されていません。 |
| Sending | キャンペーンはターゲットオーディエンスに送信中です。 |
| Scheduled | キャンペーンはターゲットオーディエンスへの送信がスケジュールされています。 |
| Sent | キャンペーンはすべてのターゲットオーディエンスに送信されました。 |
| Active | キャンペーンは送信済みで、すべてのターゲットオーディエンスが利用できます。 |
| Paused | キャンペーンはすべてのターゲットオーディエンスに対して一時停止されています。 |
| Stopped | キャンペーンはすべてのターゲットオーディエンスに対して停止されています。 |
| Expired | キャンペーンはすべてのターゲットオーディエンスに対して期限切れになっています。 |
| Under Review | キャンペーンはキャンペーン承認プロセスによるレビュー中です。詳細については、[キャンペーン承認ワークフロー](/ja/user-guide/settings/account/team-management/campaign-approval-workflow)を参照してください。 |
| Rejected | キャンペーンはキャンペーン承認プロセスで却下されました。詳細については、[キャンペーン承認ワークフロー](/ja/user-guide/settings/account/team-management/campaign-approval-workflow)を参照してください。 |

詳細については、[キャンペーン承認ワークフロー](/ja/user-guide/settings/account/team-management/campaign-approval-workflow)を参照してください。

## 表示

1. MoEngageのサイドバーメニューで、**Engage** メニュー項目 <img alt="Screenshot 2025-06-04 at 4.32.53 PM.png"  src="/images/moengage_aa2e73.png"  /> にカーソルを合わせます。**Engage** メニューが表示されます。
2. **All Campaigns** をクリックします。  
    <img alt="Screenshot 2025-06-17 at 4.09.44 PM.png"  src="/images/moengage_8921ea.png"  />   
   All campaignsページが表示されます。
3. フィルターを使用して、表示したいキャンペーンを検索します。MoEngageには、作成したすべてのWhatsAppキャンペーンを表示できるチャネルフィルターも用意されています。  
    <img alt="Screenshot 2025-06-23 at 2.31.50 PM.png" src="/images/moengage_7a96ab.png" />

その後、次のいずれかの方法でWhatsAppキャンペーンを表示できます。

- - 右側の省略記号アイコンをクリックし、**View** を選択します。
  - キャンペーンの行をクリックして **Campaign Info** ページを開きます。

## 複製

次のいずれかの方法でWhatsAppキャンペーンを複製します。

1. All campaignsページで、省略記号アイコンをクリックし、**Duplicate** をクリックします。
2. キャンペーンをクリックして **Campaign Info** ページを開きます。このページで、<img alt="DuplicateButton.png"  src="/images/moengage_ec9bd7.png"  /> ボタンをクリックします。

## 削除

削除できるのは下書き状態のキャンペーンのみです。これらのキャンペーンにアクセスするには、All campaignsページの上部にある **Drafts** をクリックします。

<img alt="Screenshot 2025-06-23 at 2.39.18 PM.png" src="/images/moengage_c5c3df.png" />

WhatsAppキャンペーンを削除するには:

1. **All Campaigns** ページで、右上の **Drafts** をクリックします。
2. 削除したいキャンペーンの **Actions** 列にある省略記号アイコンをクリックし、**Delete** をクリックします。  
    <img alt="Screenshot 2025-06-23 at 2.47.13 PM.png" src="/images/moengage_049509.png" />
3. **Confirmation** ポップアップウィンドウで、**Confirm** をクリックします。  
   削除したいキャンペーンのチェックボックスを選択することもできます。以下のように、上部のバーにある **Delete** をクリックします。  
    <img alt="Screenshot 2025-06-23 at 2.50.49 PM.png" src="/images/moengage_c04992.png" />   
   これにより、複数の下書きを同時に削除できます。

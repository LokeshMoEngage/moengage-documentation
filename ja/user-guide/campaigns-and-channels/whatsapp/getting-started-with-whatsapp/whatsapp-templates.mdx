WhatsAppテンプレートは、企業が事前定義されたパーソナライズメッセージを整備できるようにすることで、コミュニケーションを効率化します。MoEngageを使用してWhatsAppメッセージを送信し、WhatsAppによって(直接、またはWhatsAppサービスプロバイダーやBSPを通じて)すでに承認またはホワイトリスト登録されたテンプレートをMoEngageプラットフォームで使用できます。\
この機能により、業務効率の向上、自動通知の確立、WhatsAppでの顧客エンゲージメントの強化、ブランドへの信頼向上が可能になります。

# ユースケース

- 新製品を発売する場合は、カルーセルWhatsAppテンプレートを使用して限定コレクションを紹介できます。
- 期間限定オファーがある場合は、Limited Time Offer WhatsAppテンプレートでタイマーを設定し、終了前に顧客にお得な取引を利用してもらえます。

# MoEngageにテンプレートを追加する

<Info>
  MoEngageにテンプレートを追加する前に、承認済みのすべてのWhatsAppテンプレートにアクセスできることを確認してください。テンプレートはBSPダッシュボードからアクセスできます。
</Info>

承認済み/ホワイトリスト登録済みのWhatsAppテンプレートをMoEngageに追加するには、MoEngage _Dashboard -\> Settings -\> WhatsApp -\> Approved Templates_ に移動します。UIで **\+ Template** をクリックします。

</Info>

### ヘッダー

ヘッダーは任意で、次のタイプを使用できます。

- テキスト(最大60文字、プレースホルダーを1つ含めることができます)
- 画像
- 動画
- ドキュメント
- 位置情報 テキスト以外のヘッダーは静的または動的にできます。固定の画像やドキュメントのリンクを使用することも、ユーザーごとにパーソナライズされた画像/ドキュメントを使用することもできます。動的フィールドはキャンペーン作成時に設定できます。詳細については、[画像のパーソナライズ](/ja/user-guide/settings/account/security/overview)を参照してください。 <img src="/images/moengage_90782b.png" alt="WATemplateHeader.png" /> MoEngageがサポートするメディアタイプ、メディア形式、ファイルサイズは次のとおりです。

| コンテンツタイプ | サポートされる形式とファイルサイズ |
| --- | --- |
| 画像 | サポートされる画像タイプは `JPG`、`JPEG`、`PNG` です。最大ファイルサイズは5MBです。 |
| ドキュメント | サポートされるドキュメントタイプは `PDF` です。最大ドキュメントサイズは5MBです。 |
| 動画 | サポートされるファイルタイプは `MP4`、`3GPP` です。最大ファイルサイズは15MBです。 |

4. 設定が完了したら、画面右下の **Save** を選択します。

# テンプレート管理

すべてのWhatsAppテンプレートを管理するには、MoEngage Dashboard -\> Settings -\> WhatsApp -\> Approved Templatesに移動します。テンプレートを追加すると、キャンペーンで使用中かどうかに応じてテンプレートを管理できます。

| テンプレートの使用状況 | 許可されるテンプレートアクション |
| --- | --- |
| どのキャンペーンでも使用されていないテンプレート | View、Edit、Duplicate、Delete |
| いずれかのキャンペーンで使用されているテンプレート | View、Duplicate |

# ベンダーからMoEngageへのテンプレートの同期

MoEngageでは、設定済みのパートナーからMoEngageプラットフォームにテンプレートを同期できます。テンプレートを同期すると、前回の更新時刻以降にパートナーポータルで更新されたすべてのテンプレートが自動的に取得されます。

テンプレートを同期するには:

1. MoEngage Dashboard \> **Settings** \> **WhatsApp** \> **Approved templates** に移動します。
2. Approved templatesタブの右上にある **Sync Template** をクリックします。 <img src="/images/moengage_8218a9.png" alt="Template sync.png" />

同期が完了すると、次のいずれかのメッセージが表示されます。

- **Sync successful**: コネクターからのすべてのテンプレートがMoEngageに正常に同期されました。成功した変更の概要を確認でき、最終更新時刻に基づいてテンプレートを表示することもできます。
- **Sync failure**: コネクターからMoEngageへのテンプレートの同期に失敗しました。同期が失敗した理由を確認できます。
- **Mixed sync results**: コネクターからMoEngageへのテンプレートの同期が部分的に成功しました。正常に同期されたテンプレートについては成功した変更の概要を、同期に失敗したテンプレートについては失敗の理由を確認できます。

テンプレート同期後のステータスは次のとおりです。

| ステータス | 説明 | 次に可能なアクション |
| --- | --- | --- |
| Created | ベンダーポータルで作成したテンプレートは承認のために送信されていますが、Metaによってまだ承認されていません。Metaはテンプレートを承認または却下できます。 | このテンプレートを使用してWhatsAppキャンペーンを作成できます。 |
| Approved | ベンダーポータルで作成したテンプレートがMetaによって承認されています。 | 承認されたテンプレートを使用してWhatsAppキャンペーンを作成できます。 |
| Rejected | ベンダーポータルで作成したテンプレートがMetaによって却下されています。 | 却下されたテンプレートを使用してWhatsAppキャンペーンを作成することはできません。MoEngageで却下されたテンプレートを編集して保存すると、Manually approved状態に移行します。テンプレートがベンダーポータル上のテンプレートと完全に同一でない状態でこのテンプレートを使用してWhatsAppキャンペーンを作成すると、テンプレートの不一致によりキャンペーンの作成が失敗します。次の操作を行う必要があります。<ol><li>ベンダーポータルで却下されたテンプレートを更新し、Metaから承認を得ます。</li><li>MoEngageでテンプレートを新しいコンテンツで更新するか、MoEngageでテンプレートを削除して再度同期します。</li></ol> |
| Suspended | ベンダーポータルからMoEngageへのテンプレートの初回同期後、その後の同期において:<ul><li>ベンダーポータルとMoEngageでテンプレートのコンテンツが同じ場合は、ステータスのみが更新されます。たとえば、Manually approvedのテンプレートはApprovedに、ApprovedのテンプレートはRejectedに移行することがあります。</li><li>ベンダーポータルでテンプレートのコンテンツを更新した場合、MoEngageとベンダーの間でコンテンツに差異があるため、Suspendedとしてマークされます。</li></ul> | 省略記号アイコン(<Icon icon="ellipsis-vertical" iconType="solid" />)をクリックし、**View usage** を選択します。Active campaignsポップアップが表示され、このテンプレートを使用して作成されたキャンペーンが表示されます。<ul><li>テンプレートがどのキャンペーンでも使用されていない場合は、MoEngageでテンプレートを削除し、再度 **Sync template** をクリックします。MoEngageが最新のコンテンツを取得します。停止中のテンプレートを削除するには:   <ol> <li>既存のキャンペーンを停止します。   </li><li> 省略記号アイコン(<Icon icon="ellipsis-vertical" iconType="solid" />)をクリックし、**Delete** を選択します。 </li></ol></li><li>テンプレートがいずれかのキャンペーンで使用されている場合は、MoEngageでテンプレートを更新し、再度 **Sync template** をクリックします。コンテンツを更新するには:  <ol><li>テンプレートがいずれかのキャンペーンで使用されている場合は、MoEngageでテンプレートを編集し、ベンダーポータル上のコンテンツと正しく一致するように手動でコンテンツを追加して、テンプレートを保存します。 </li><li> 変数を追加または削除した場合は、キャンペーンに詳細を追加してください。 </li><li> テンプレートのコンテンツがパートナーポータル上のコンテンツと一致しているかどうかを確認するには、**Sync template** をクリックします。</li></ol></li></ul> |
| Manually approved | MoEngageでテンプレートを編集して保存すると、Manually approved状態に移行します。テンプレートがベンダーポータル上のテンプレートと完全に同一でない状態でこのテンプレートを使用してWhatsAppキャンペーンを作成すると、テンプレートの不一致によりキャンペーンの作成が失敗します。 | MoEngageでテンプレートを更新し、コンテンツがベンダーポータルのテンプレートのコンテンツと完全に一致するようにする必要があります。 |

<Info>
  - 現在、GupshupとKarixからテンプレートを同期できます。同期が完了するまでに最大15分かかる場合があります。
  - 各同期では、過去2日間に更新されたテンプレートが同期されます。
</Info>

## WhatsAppテンプレート停止アラートの管理

ベンダーからMoEngageにWhatsAppテンプレートを同期すると、テンプレートには **Created**、**Approved**、**Rejected**、**Suspended** などのさまざまなステータスが付与されます。

ベンダーダッシュボードとMoEngageの間でコンテンツの不一致がある場合、テンプレートは **Suspended** ステータスになります。コミュニケーションが中断されないように、MoEngageはテンプレートの停止が発生した瞬間に通知するリアルタイムアラートを提供します。

### 停止アラートを設定する理由

以前は、テンプレートが停止状態に移行したことにユーザーが気付かず、キャンペーンが失敗することがありました。これらのアラートを使用すると、次のことが可能になります。

- **影響を受けるキャンペーンの特定:** 停止されたテンプレートを使用しているアクティブなキャンペーンをすぐに確認できます。
- **ダウンタイムの最小化:** ベンダーレベルでテンプレートを修正するか、MoEngageキャンペーンでテンプレートを差し替えるなど、迅速に対応できます。
- **マルチチャネル通知の受信:** チームが普段使用している場所(Slack、Teams、Email、Webhooks)でアラートを受け取れます。

### 停止アラートの設定

WhatsAppテンプレートの停止に関する[アラートを作成する](/ja/user-guide/settings/reports-and-alerts/alert-management/getting-started/create-an-alert)には:

1. MoEngageダッシュボードの左側のナビゲーションメニューで、**Settings \> Reports and Alerts \> Alert Management** に移動します。
2. Alert managementページで、**\+ Create alert** をクリックします。
3. Create alertページで、次の詳細を入力します。
   - **Alert name:** アラートの名前を入力します。
   - **Create Alerts On:** リストから `WhatsApp Template Suspension` を選択します。
   - **Send Alert On:** アラートを送信する通知チャネルを選択します。
   - **Add alert destination:** Slack、MS Teams、またはカスタムWebhook経由でアラートを受信する外部の送信先を設定します。
   - **Members:** このアラートを受信するメンバーを追加します。
4. **Create** をクリックしてアラートを作成します。

これで、MoEngageはすべてのテンプレート同期を監視し、いずれかのテンプレートのステータスが **Suspended** に変わると通知をトリガーします。

### アラート通知について

テンプレートが停止されると、アラートには次の重要な情報が含まれます。

- **テンプレートの詳細:** テンプレート名、言語、送信者/プロバイダー名が含まれます。
- **タイムスタンプ:** 停止が発生した正確な時刻が、アプリのタイムゾーン(例: ニューヨーク時間)で表示されます。
- **アクティブなキャンペーンの可視性:** 停止されたテンプレートを現在使用しているすべてのキャンペーンのリストです。これには次が含まれます。
  - 1回限りのスケジュール配信キャンペーン
  - 定期キャンペーン
  - イベントトリガーキャンペーン
  - Flows

<Note>
  アラートは現在アクティブなキャンペーンまたは将来の日付のキャンペーンへの影響に焦点を当てているため、作成後すぐに送信されたキャンペーンはリストに表示されません。
</Note>

### テンプレートの失敗への対処

停止されたテンプレートを使用してキャンペーンを送信しようとすると、キャンペーンログに失敗理由 `Failed to send due to template was suspended` が表示されます。

キャンペーン内でこのエラーが発生した場合、MoEngageではキャンペーンのインターフェースから **Create an Alert** への直接のショートカットが提供され、その特定のテンプレートで今後同様の事象が発生した際に通知を受け取れるようになります。

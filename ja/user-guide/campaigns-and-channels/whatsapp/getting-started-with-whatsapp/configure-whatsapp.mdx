MoEngageでWhatsApp Messagingを使用するには、まずWhatsAppチャネルを設定する必要があります。MoEngageでWhatsAppチャネルを設定するには、**Settings** \> **Channels** \> **WhatsApp** に移動します。

<Tip>
  開始する前に、[こちら](/ja/user-guide/campaigns-and-channels/whatsapp/getting-started-with-whatsapp/prerequisites)に記載されているすべての前提条件を満たしていることを確認してください。
</Tip>

WhatsAppチャネルを設定する手順は以下のとおりです。

1. [送信者プロファイルを設定する](/ja/user-guide/campaigns-and-channels/whatsapp/getting-started-with-whatsapp/configure-whatsapp#configure-your-sender-profile)
2. [WhatsAppによって承認済みのテンプレートを追加する](/ja/user-guide/campaigns-and-channels/whatsapp/getting-started-with-whatsapp/configure-whatsapp#add-whatsapp-templates)
3. [MoEngageでWhatsAppのオプトインを更新する](/ja/user-guide/campaigns-and-channels/whatsapp/getting-started-with-whatsapp/configure-whatsapp#update-whatsapp-opt-in-on-moengage)

## Configure your Sender Profile

![Screenshot 2025-09-02 at 5.16.09 PM.png](/images/moengage_b385a7.png)

WhatsApp Business Solution Provider(BSP)またはWhatsApp Service Provider(WSP)の設定は、WhatsAppキャンペーンを実行するための必須の前提条件です。これにより、ビジネスとWhatsAppプラットフォームの間の技術的な統合が確立され、MoEngageがお客様に代わってメッセージを開始および送信できるようになるため、重要です。

WhatsApp BSP/WSPは、WhatsApp設定のSender configurationタブで追加および管理できます。Sender configurationタブには、**Settings** \> **Channels** \> **WhatsApp** \> **Sender configuration** のパスでアクセスできます。

WhatsAppの送信者を追加するには、以下の手順を実行します。

1. **Sender configuration** タブで、**\+ Add connector** をクリックします。
   ![add connector WA.png](/images/moengage_6ec05d.png)
2. **WhatsApp connector** ダイアログボックスで、ドロップダウンからコネクターを選択します。**Choose a connector** ドロップダウンには、MoEngageがサポートするすべてのコネクターが一覧表示されます。
3. コネクターを追加した後、そのコネクターを選択します。**Sender 1** は自動入力されます。そのコネクターに送信者を追加するには、横にある **\+ Sender** をクリックします。
   ![add sender wa.png](/images/moengage_da969a.png)
4. 選択したコネクターに基づいて送信者の詳細を追加します。送信者の設定を完了するには、各[WhatsAppプロバイダー](/ja/partner-guide/messaging-channels/whatsapp-providers/configure-meta)の記事を参照してください。
5. **Save** をクリックします。

## Add WhatsApp Templates

WhatsAppテンプレートを使用すると、企業は事前定義されたパーソナライズされたメッセージを作成でき、コミュニケーションを効率化できます。MoEngageを使用してWhatsAppメッセージを送信でき、WhatsAppによって(直接、またはWhatsApp Service ProviderやBSPを通じて)承認済みまたはホワイトリストに登録済みのテンプレートをMoEngageプラットフォームで使用できます。承認済みのテンプレートはすべて、WhatsApp設定の **Approved templates** タブに一覧表示されます。テンプレートの承認とMoEngageでのテンプレート詳細の設定については、[WhatsAppテンプレート](/ja/user-guide/campaigns-and-channels/whatsapp/getting-started-with-whatsapp/whatsapp-templates)を参照してください。

![Screenshot 2025-09-02 at 6.12.23 PM.png](/images/moengage_09db99.png)

## Update WhatsApp Opt-in on MoEngage

MoEngageでオプトインステータスを更新することをお勧めします。General settingsタブでは、エンドユーザーのWhatsApp番号、WhatsAppオプトインステータス、WhatsApp Lead & Messageを保存するフィールドを設定できます。General settingsタブには、**Settings** \> **Channels** \> **WhatsApp** \> **General settings** のパスでアクセスできます。

<Frame>
  ![Download (1)](/images/download-\(1\).png)
</Frame>

- 以下のフィールドを使用して、WhatsAppの携帯電話番号とオプトインステータスを保存する属性を選択します。
  | フィールド | 説明 |
  | --- | --- |
  | **Select the attribute in which user's WhatsApp mobile number is stored** | このフィールドは、MoEngageでWhatsAppの携帯電話番号を保存する属性を示します。ドロップダウンから _Mobile Number_ を選択します。 |
  | **Select the attribute in which user's WhatsApp Opt-In is stored** | このフィールドは、MoEngageでWhatsAppのオプトインステータスを保存する属性を示します。ドロップダウンから _WhatsApp Subscription Status_ を選択します。 |
- 携帯電話番号の形式を設定すると、すべての携帯電話番号がWhatsAppプロバイダーに正しく渡されることが保証されます。これはメッセージを正常に配信するために不可欠です。アプリケーションの携帯電話番号の形式を設定するには、**Set the mobile number format** リンクをクリックします。 **Mobile number management** ページに移動します。詳細については、[携帯電話番号の標準化](/ja/user-guide/settings/advanced-settings/mobile-number-standardization)を参照してください。形式が正しくない携帯電話番号が原因で配信エラーが発生した場合は、[WhatsAppキャンペーンの一般的なエラー](/ja/user-guide/campaigns-and-channels/whatsapp/troubleshooting-and-faqs-whatsapp/common-errors-in-whatsapp-campaigns)を参照してください。
- 以下のトグルを使用して、WhatsApp Lead & Messageを設定します。
  <Info>
    [PIIトークン化送信](/ja/user-guide/data/privacy/personal-data-or-personally-identifiable-information-pii/pii-tokenized-sending)が有効になっている場合、以下のトグルをオンにすることはできません。
  </Info>
  | トグル | 説明 |
  | --- | --- |
  | **Create a new profile if message is received from new number** | 以前は、MoEngageは既存のユーザープロファイルがないユーザーから受信したWhatsAppメッセージを破棄していました。このトグルをオンにすると、MoEngageはメッセージの受信時に新規ユーザーのユーザープロファイルを自動的に生成し、これらのコミュニケーションが確実に保存されるようにします。 |
  | **Store all incoming messages from all customers** | 以前は、MoEngageはクイック返信など、キャンペーンに直接関連する受信メッセージのみを保持していました。このトグルをオンにすると、MoEngageはすべての既存ユーザーからのすべての受信メッセージを保存します。 **注:**  このトグルと併せて **Create a new profile if message is received from new number** トグルをオンにすると、MoEngageは既存ユーザーと新規作成されたユーザーの両方からのすべての受信メッセージを保存し、_WhatsApp Message Received_ という名前のイベントでトラッキングします。 |
- **Save** をクリックして設定を保存します。

## Configure Delivery Control Settings

[フリークエンシーキャップ(FC)](/ja/user-guide/settings/channels/delivery-controls/frequency-capping)と[Do Not Disturb(DND)](/ja/user-guide/settings/channels/delivery-controls/do-not-disturb)を設定して、ユーザーに最適な数のメッセージを送信し、DNDの時間帯には送信しないようにします。この手順は任意です。

## Whitelist IPs

MoEngageはメッセージの送信に動的IPを使用します。WhatsApp BSP/WSPが静的IPアドレスを必要とする場合は、提供されている[ドキュメント](/ja/user-guide/settings/account/security/ip-whitelisting-in-moengage)で詳細を参照してください。この手順は任意です。

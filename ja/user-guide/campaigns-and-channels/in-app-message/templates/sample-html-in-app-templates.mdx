# HTML In-App テンプレート

HTML In-App テンプレートを使用すると、柔軟な方法で高度にカスタマイズされた目を引く In-App メッセージを作成できます。これらのテンプレートを活用することで、独自の体験でユーザーのエンゲージメントを高め、アプリケーションから直接価値のあるデータを収集できます。この記事では、利用可能な HTML In-App テンプレートの種類と、MoEngage キャンペーンでの使用方法について説明します。

HTML In-App キャンペーンの作成の詳細については、[In-App キャンペーン用の HTML テンプレート](/ja/user-guide/campaigns-and-channels/in-app-message/templates/html-in-app-templates)を参照してください。

## 利用可能なテンプレート

| **テンプレート名** | **説明** |
| --- | --- |
| [Carousel](/ja/user-guide/campaigns-and-channels/in-app-message/templates/sample-html-in-app-templates#carousel-template) | 複数の製品、サービス、オファーを自動スクロールで表示します。 |
| [Survey](/ja/user-guide/campaigns-and-channels/in-app-message/templates/sample-html-in-app-templates#survey-template) | ユーザーの関心、フィードバック、意見を収集します。 |
| [Lead Generation](/ja/user-guide/campaigns-and-channels/in-app-message/templates/sample-html-in-app-templates#lead-generation-template) | メールアドレス、携帯電話番号、その他のユーザー情報を取得します。 |
| [Promotional](#promotional-template) | 実施中のオファーや売れ筋の製品・サービスを宣伝します。 |
| [Spin the Wheel](/ja/user-guide/campaigns-and-channels/in-app-message/templates/gamification-templates#spin-the-wheel) | ユーザーが特定のアクションを実行することでホイールを回し、ランダムに生成された賞品やオファーを獲得できる、インタラクティブなゲーミフィケーションのポップアップを表示します。 |
| [Scratch Card](/ja/user-guide/campaigns-and-channels/in-app-message/templates/gamification-templates#scratch-card) | ユーザーが特定のアクションを実行することでスクラッチして、ランダムに生成された賞品やオファーを表示・獲得できる、ビジュアルなスクラッチカードのポップアップを表示します。 |

Carousel テンプレートを使用すると、自動的にスクロールする複数の製品、サービス、オファーを表示できます。画面スペースをあまり使わずに、さまざまなアイテムを紹介できる優れた方法です。

### カスタマイズの詳細

1. カルーセル内の画像ごとに異なるコールトゥアクション（CTA）を設定します。以下の画像でハイライトされているコードは、各要素のアクションを定義する方法を示しています。
   ![Screen\_Shot\_2021-09-03\_at\_10.57.13\_AM.png](/images/moengage_9cf855.png)
   たとえば、ある要素をクリックするとユーザーは [https://www.moengage.com](https://www.moengage.com) にリダイレクトされ、別の要素をクリックするとイベントのトラッキングのみが行われます。[MoEngage JS Bridge のドキュメント](/ja/developer-guide/components-for-sdk/javascript-bridge/javascript-bridge-for-html-in-apps)に記載されている任意のアクションを定義できます。ハイライトされたコード内の `moengage.trackClick(2)` 関数はクリックをトラッキングします。関数内の引数（(1) や (2) など）により、カルーセルの異なる要素に対するクリックを区別できます。
2. モバイルデバイスでは、このテンプレートは縦向きモードで最適に動作します。横向きモードでは、ユーザーにスクロールバーが表示されます。タブレットと TV では、このテンプレートはどの向きでも正しく表示されます。

Survey テンプレートを使用すると、アプリ内で直接ユーザーの関心、フィードバック、意見を収集できます。ユーザーの感情を把握し、製品を改善するのに役立ちます。

### カスタマイズの詳細

1. アンケートの回答をユーザー属性として取得します。たとえば、以下のコードスニペットの 88 行目では、ユーザーの入力を `survey_response` ユーザー属性として取得しています。この属性名は必要に応じてカスタマイズできます。 <img alt="Screen_Shot_2021-09-03_at_10.27.16_AM.png" src="/images/moengage_5ba799.png" />
2. ユーザーが回答を送信したときに `MOE_RESPONSE_SUBMITTED` イベントをトリガーします。88 行目の下にあるハイライトされたコードは、フィードバックフォームからのユーザー入力を含む `survey_response` イベント属性とともに、このイベントをトラッキングします。イベント名とイベント属性名は必要に応じてカスタマイズできます。このイベントがトラッキングされた後、MoEngage の外部にデータを送信したり、フォローアップキャンペーンをトリガーしたりするために使用できます。 <img alt="Screen_Shot_2021-09-03_at_10.27.02_AM.png" src="/images/moengage_767da4.png" />
3. 以下に示すように、このテンプレートのデータは MoEngage のユーザープロファイルに表示されます。 <img alt="Screen_Shot_2021-09-06_at_3.06.15_PM.png" src="/images/moengage_c091aa.png" />
4. モバイルデバイスでは、このテンプレートは縦向きモードで最適に動作します。横向きモードでは、ユーザーにスクロールバーが表示されます。タブレットと TV では、このテンプレートはどの向きでも正しく表示されます。

### カスタマイズの詳細

1. ユーザーの入力を、**First Name** や **Email** などの MoEngage の標準属性に直接保存します。
2. ユーザーがこのフォームを送信したときに `MOE_RESPONSE_SUBMITTED` イベントをトリガーします。このイベントを使用して、MoEngage の [Streams](/ja/api/data/moengage-streams) や [Connector Campaigns](/ja/user-guide/campaigns-and-channels/connectors/create/create-a-connector-campaign) で、収集したデータを外部の API エンドポイントに送信できます。以下の画像でハイライトされているコードは、入力データをユーザー属性およびイベントとしてトラッキングします。 <img alt="Screen_Shot_2021-09-03_at_11.32.31_AM.png" src="/images/moengage_fd8925.png" />
3. このフォームでデータがトラッキングされた後、以下に示すようにユーザープロファイルで確認できます。また、このイベントを使用して、さまざまな統合を通じて MoEngage の外部にデータを送信することもできます。

## 重要な考慮事項

HTML In-App テンプレートを使用する場合:

- **HTML/CSS の専門知識:** これらのテンプレートを効果的にカスタマイズするには、HTML と CSS の基本的な理解が必要です。
- **MoEngage JS Bridge:** インタラクティブなアクションの定義やイベントのトラッキングには、MoEngage JS Bridge に関する知識が不可欠です。
- **テスト:** 最適な表示と機能を確保するため、カスタマイズしたテンプレートは必ずさまざまなデバイスと画面の向きで十分にテストしてください。詳細については、[In-App キャンペーンのテスト](/ja/user-guide/campaigns-and-channels/in-app-message/create/test-your-in-app-campaign)を参照してください。
- **レスポンシブ対応:** 一貫したユーザー体験を提供するため、さまざまな画面サイズと解像度に適応するレスポンシブなテンプレートをデザインしてください。
- **デバッグ:** ブラウザーの開発者ツールやアプリ内デバッグツールを使用して、カスタム HTML のレンダリングや機能に関する問題を特定し、解決してください。

これらのテンプレートは、ユーザーのエンゲージメントを高めるための強力なツールです。これらのガイドラインに従うことで、効果的でパーソナライズされた In-App 体験を作成できます。

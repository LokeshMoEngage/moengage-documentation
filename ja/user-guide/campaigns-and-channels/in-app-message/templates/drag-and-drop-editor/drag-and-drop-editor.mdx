新しい **Drag and Drop editor** を使用すると、アプリ内キャンペーンのあらゆる要素をカスタマイズできます。MoEngage では、事前構築済みテンプレートをカスタマイズして使用することも、新しいキャンペーンを一から作成することもできます。

Drag and Drop エディターには、アプリ内キャンペーンのコンテンツセクションからアクセスできます。ここでは、次の 2 つのオプションがあります。

- [空白のキャンバスから始める](#start-with-a-blank-canvas)
- [事前構築済みテンプレートを確認する](#explore-pre-built-templates)

# 空白のキャンバスから始める

**Start with a blank canvas** をクリックすると、Drag and drop エディターにリダイレクトされます。

![](/images/moengage_810549.png)

## コンテンツ

コンテンツセクションには、アプリ内キャンペーンに追加できるすべてのブロックが含まれています。キャンペーンを開始すると、コンテンツブロックを追加する必要がある行が自動的に追加されます。

1. **Title**: タイトルブロックを使用すると、キャンペーンにタイトルテキストを追加できます。**Title block** をクリックすると、タイトルのスタイルとフォントを変更できます。右側に **Content Properties** セクションが開き、さらに変更を加えることができます。 <img src="/images/moengage_574013.png" />
   - ブロックの下にある **Delete** アイコンと **Duplicate** アイコンをクリックして、ブロックを削除または複製することもできます。
2. **Paragraph**: 段落ブロックを使用すると、キャンペーンにテキストを追加できます。ここでは、タイトルブロックと同様にテキストを変更できます。
3. **List**: リストブロックを使用すると、キャンペーンに順序なしリストを追加できます。ここでは、タイトルブロックと同様にテキストを変更できます。
4. **Image**: 画像ブロックを使用すると、キャンペーンに画像を追加できます。画像をブロックにドラッグアンドドロップするか、**Browse** をクリックして新しい画像をアップロードできます。 <img src="/images/moengage_6f1075.png" />
   - 画像を追加した後、右側のエディターで幅と配置を変更できます。**Apply Effect** をクリックして、画像のフィルター、サイズ変更、トリミングなどを行うこともできます。
   - 属性を使用して、画像にリンクを追加したり、クリックトラッキングを有効にしたりできます。
5. **Button**: ボタンブロックを使用すると、キャンペーンにボタンを追加できます。ボタンのスタイルを設定し、アクションを追加することもできます。ボタンを画面にドラッグアンドドロップし、クリックすると編集オプションが表示されます。
6. **Divider**: 区切り線ブロックは、他の 2 つのコンテンツブロックまたは行の間に区切り線を追加するために使用できます。区切り線の幅とスタイルは、コンテンツプロパティセクションで変更できます。
7. **Spacer**: スペーサーブロックは、2 つのコンテンツブロックまたは行の間に配置して、間隔を空けることができます。
8. **Social**: ソーシャルブロックを使用すると、キャンペーンにソーシャルメディアのリンクを追加できます。関連する URL は、エディターの右側にあるコンテンツプロパティセクションで追加できます。 <img src="/images/moengage_58b653.png" />
   - コンテンツプロパティセクションで **New Element** をクリックして、キャンペーンに含めたいその他のソーシャルメディアのリンクを追加することもできます。
9. **HTML**: HTML ブロックを使用すると、キャンペーンにカスタム HTML を追加できます。
10. **Video**: 動画ブロックを使用すると、キャンペーンに動画を追加できます。YouTube 動画、Vimeo 動画、または動画の URL をアップロードできます。
11. **Icons**: アイコンブロックを使用すると、キャンペーンにアイコンを追加できます。コンテンツプロパティセクションで **Apply Effects** をクリックして、アイコンのフィルター、サイズ変更、トリミングなどを行うことができます。 <img src="/images/moengage_4396fd.png" />
    - アイコン画像自体の変更に加えて、**More options** ボタンを有効にすると、アイコンの URL を変更したり、アイコンにテキストを追加したりすることもできます。
12. **Menu**: メニューブロックを使用すると、キャンペーンにメニューを作成できます。ここで複数の項目を追加し、コンテンツプロパティセクションで変更できます。
13. **Text**: テキストブロックを使用すると、キャンペーンにテキストを追加できます。テキストはテキストブロック内で直接編集でき、テキストブロックをクリックしてその上にあるエディターにアクセスすると、フォントやスタイルのオプションを追加できます。
14. **GIFs**: GIF ブロックを使用すると、キャンペーンに動画を追加できます。Giphy で GIF を検索し、追加したい GIF を選択できます。
15. **Form**: フォームボックスを使用すると、キャンペーンにフォームを追加して、アプリ内でユーザー情報を収集できます。詳細については、[アプリ内キャンペーンにフォームを追加する](/ja/user-guide/campaigns-and-channels/in-app-message/templates/drag-and-drop-editor/add-forms-to-your-in-app-campaign)を参照してください。

<Info>
  コンテンツブロックの CSS を上書きしたい場合は、**Content Properties** セクションで **Block identifier** をオンに切り替えて、コンテンツブロックの ID を取得できます。この ID を HTML 要素で使用することで、コンテンツブロックの CSS を変更できます。これを使用してテンプレートのフォントを変更する方法の詳細については、FAQ を参照してください。   <img src="/images/moengage_ff2e94.png" />
</Info>

## 縦向きモードと横向きモード

アプリ内キャンペーンの表示は、縦向きモードと横向きモードで大きく異なります。キャンペーンが不自然に見えないように、使用するコンテンツブロックを変更および編集できます。

1. 縦向きモードまたは横向きモードのいずれかで、コンテンツブロックを非表示にすることができます。
   - **Content Properties** セクションの **Block Options** に移動します。
   - **More options** ボタンが有効になっていることを確認します。
   - 縦向きモードでコンテンツブロックを非表示にする場合は、**Mobile** アイコンをクリックします。
   - 横向きモードでコンテンツブロックを非表示にする場合は、**Desktop** アイコンをクリックします。 <img src="/images/moengage_acd85d.png" />
2. **Content Properties** の **Auto width** セクションを使用して、横向きモード用にアプリ内キャンペーンを変更することもできます。
   - 縦向きモードで要素が画面の幅全体を覆うようにする場合は、**Full width on mobile** チェックボックスを選択します。
   - その後、スライダーを使用して、横向きモードでのコンテンツブロックの幅を変更できます。
   - または、コンテンツブロックの幅を自動的に固定する **Auto width** オプションを選択することもできます。 <img src="/images/moengage_4f787d.png" />

## 属性

画像、動画、ボタン、GIF に **attributes** を追加できます。追加するには、エディターの右側にある **Content Properties** セクションを下にスクロールし、**\+ Add New Attribute** をクリックします。提供されている属性から検索するか、独自のカスタム属性を追加できます。

![](/images/moengage_26ebab.png)

MoEngage が提供する属性の一覧は次のとおりです。

1. **Navigation**: このアクションを使用すると、この属性を割り当てたコンテンツブロックをユーザーがクリックしたときに、アプリ内の Web ビューで Web ページを開くことができます。 <img src="/images/moengage_f236c1.png" />
2. **Track Event**: このアクションを使用すると、アプリ内メッセージのクリック時にイベントを追跡し、それとともにイベント属性も追跡できます。 <img src="/images/moengage_761878.png" />
3. **Set User Attribute**: このアクションは、変更したい任意のユーザー属性に選択した値を割り当てます。ユーザーがこの属性を持つコンテンツブロックをクリックするとすぐに、選択したユーザー属性が入力した値に設定されます。 <img src="/images/moengage_4aaa78.png" />
4. **Copy Coupon Code**: このアクションを使用すると、コンテンツブロックにクーポンコードを追加できます。ユーザーがコンテンツブロックをクリックすると、クーポンコードがキーボードにコピーされます。この属性にパーソナライゼーションを追加することもできます。 <img src="/images/moengage_5e9f49.png" />
5. **Call**: この属性を割り当てたコンテンツブロックをユーザーがクリックするとすぐに、ユーザーに電話をかけることができます。そのためには _Mobile No._ を入力します。 <img src="/images/moengage_22518b.png" />
6. **SMS**: ユーザーがメッセージをクリックするとすぐに、ユーザーにメッセージを送信できます。SMS を送信するには、_Mobile No_. と _Message_ の内容を入力します。 <img src="/images/moengage_b8b8eb.png" />
7. **Custom Action**: モバイルアプリでカスタムアクションを定義し、ユーザーがアプリ内キャンペーンをクリックしたときに実行することもできます。 <img src="/images/moengage_3a2aef.png" />
8. **Navigate to Notification Settings**: ユーザーがこの属性を持つコンテンツブロックをクリックすると、アプリの通知設定にリダイレクトされます。

<Info>
  - アクションが追加されたすべてのコンテンツブロックで、クリックトラッキングが自動的に有効になります。
  - 1 つのコンテンツブロックに複数の種類のアクションを追加した場合、各アクションが 1 回の追跡クリックとしてカウントされます。
</Info>

## 行

行を画面にドラッグアンドドロップして、アプリ内キャンペーンのレイアウトを作成できます。すべてのコンテンツブロックは行に追加され、その位置と配置を変更できます。

#### 行のプロパティ

エディターで行をクリックすると、画面右側の **Row Properties** セクションにアクセスできます。このセクションでは、行の背景、行のレイアウト、列の構造などを変更できます。

行の背景色を変更したり、必要に応じて画像や動画を追加したりすることもできます。

![](/images/moengage_e1685f.png)

<Info>
  **Content area background color** オプションは、行のテキストに背景色を設定します。代わりに **Row background color** オプションを使用すると、行の背景全体が塗りつぶされます。
</Info>

### 設定

エディターの設定を使用して、すべてのリンクのデフォルトのフォントとリンクの色を標準化できます。

![](/images/moengage_176635.png)

# 事前構築済みテンプレートを確認する

**drag and drop editor** 用の事前構築済みテンプレートを見つけるには、**Explore pre-built templates** をクリックするか、フィルターを使用して探します。

- 検索: **Search templates** セクションで **Drag and drop** を検索します。 <img src="/images/moengage_ce0710.png" />
- **Filter By Editor**: **Drag and drop** チェックボックスを選択し、利用可能なテンプレートを表示します。 <img src="/images/moengage_8a0363.png" />

事前構築済みテンプレートのすべてのブロックをカスタマイズして、アプリ内キャンペーンを作成できます。

## テンプレート

エディターの右上にある **menu** アイコンをクリックすると、テンプレートを保存、変更、またはリセットできます。**Change template** をクリックすると、テンプレート選択メニューにリダイレクトされ、空白のキャンバスで作業するか、MoEngage の事前構築済みテンプレートのいずれかを使用するかを選択できます。

![](/images/moengage_77eb0d.png)

<Info>
  **Drag and drop editor** の上部にある **Mirror Platforms** オプションを使用すると、iOS と Android の両方のプラットフォームで同じ変更を同時に行うことができます。

  ![](/images/moengage_718723.png)
</Info>

### テンプレートの設定

エディターの下部にある **Template Settings** に移動して、**Allowed device orientation** を選択できます。また、アプリ内キャンペーンを表示するデバイスタイプを選択することもできます。

![](/images/moengage_a200ff.png)

# FAQ

## アプリ内 Drag and Drop エディターでカスタムフォントを使用するにはどうすればよいですか？

MoEngage のアプリ内ドラッグアンドドロップエディターを使用してテンプレートにカスタムフォントを組み込むには、次の詳細な手順に従います。

#### **1. フォントファイルをホストする**

まず、カスタムフォントファイルが安全なドメインまたは公開アクセス可能な URL でホストされていることを確認します。たとえば、`https://yourdomain.com/fonts/yourfont.ttf` のような URL を使用できます。

デモ用に、Roboto フォントのサンプルリンクを次に示します: `https://fonts.gstatic.com/s/roboto/v30/KFOmCnqEu92Fr1Mu5mxKKTU1Kvnz.woff2`

アップロードが成功したことを確認するには、URL をクリックしてフォントファイルのダウンロードが開始されることを確認します。

#### **2. テンプレートを選択する**

エディター内で変更したいテンプレートを選択します。このテンプレートは、ドラッグアンドドロップ機能に対応している必要があります。

![inapp select template.png](/images/moengage_18cbde.png)

#### **3. 要素の識別子を変更する**

カスタムフォントを適用したい要素（テキストや見出しなど）を特定します。テンプレート内の要素をクリックして、そのプロパティを開きます。

- **見出し要素の場合:** ブロック識別子機能を有効にし、`heading_id` などの一意の識別子を割り当てます。
- **テキスト要素の場合:** 同様に、`text_id` などの一意の識別子を割り当てます。

この例では、両方の要素に同じフォントを適用したいため、両方の要素に text\_id 識別子を使用します。

![inapp add block id value.png](/images/moengage_e937bd.png)

#### **4. HTML コンテンツブロックを追加する**

HTML コンテンツブロックをテンプレート内の目的の位置にドラッグアンドドロップします。この HTML 要素はユーザーには表示されず、テンプレート内のフォントスタイルを変更するためだけに使用します。

![inapp add html block.png](/images/moengage_d46651.png)

#### **5. カスタムフォントのコードを挿入する**

HTML コンテンツブロック内の既存のコードを次の CSS に置き換えて、カスタムフォントを定義および適用します。

```html wrap
<style> @font-face {  font-family: 'customfont',  src: url('https://yourdomain.com/fonts/yourfont.ttf'); /* Use your hosted font URL */ } div[class$="text_id"], #text_id {  p, h1 {   font-family: customfont !important;  } }</style>
```

この CSS スニペットは、`@font-face` ルールを使用して、指定した URL でホストされているフォントを使用する 'customfont' を定義します。さらに、ID が `text_id` の要素内にあるすべての段落 (`p`) または見出し (`h1`) でカスタムフォントが使用されるようにします。

![inapp add css code.png](/images/moengage_9b58a4.png)

#### **6. プレビューして公開する**

エディターで変更をプレビューし、カスタムフォントが正しく適用されていることを確認します。問題がなければ、キャンペーンの公開に進むことができます。

## テンプレートに閉じる (×) ボタンを追加するにはどうすればよいですか？

テンプレートに閉じる (×) ボタンを追加するには、以下の詳細な手順に従います。

1. 閉じるボタンの画像を URL として用意します。
2. 以下に示すように、新しい行要素を追加し、画像要素をドラッグアンドドロップします。 <img src="/images/moengage_899dc9.png" alt="2025-03-25_17-38-51 (1).gif" />
3. 画像要素をクリックし、以下に示すように **Url** フィールドに画像の URL を入力します。 <img src="/images/moengage_5edddd.png" alt="2025-03-25_17-43-41 (1).gif" />
4. 必要に応じて画像を調整します。 <img src="/images/moengage_c64de3.png" alt="2025-03-25_17-46-39 (1).gif" />
5. **ATTRIBUTES** セクションで、**Add new attribute** をクリックします。
6. _class_ を選択し、_close-btn_ に設定します。 <img src="/images/moengage_ebe001.png" alt="2025-03-25_18-03-32 (1).gif" />

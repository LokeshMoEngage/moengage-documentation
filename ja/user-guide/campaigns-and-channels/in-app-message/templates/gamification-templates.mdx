# 概要

今日のデジタル世界では、ゲーミフィケーションはウェブサイト訪問者のエンゲージメントを高め、ユーザーエクスペリエンスを向上させる戦略としてますます人気が高まっています。アプリにゲーミフィケーションを取り入れる効果的な方法の 1 つが、ゲーミフィケーションポップアップの活用です。この記事では、ゲーミフィケーションポップアップを使用すべき理由と、その設定方法について説明します。

### **ゲーミフィケーションポップアップを使用する理由**

ゲーミフィケーションポップアップは、アプリに次のようなさまざまなメリットをもたらします。

1. **エンゲージメントの向上**: ゲーミフィケーションポップアップは、訪問者に楽しくインタラクティブな体験を提供することで、アプリをより魅力的にします。これにより、訪問者がウェブサイトに長く滞在し、より多くのページを閲覧するようになり、最終的にコンバージョンの可能性が高まります。
2. **ユーザーエクスペリエンスの向上**: ゲーミフィケーションポップアップは、訪問者に独自で記憶に残る体験を提供し、競合他社とアプリを差別化することで、ユーザーエクスペリエンスを向上させます。
3. **リード獲得の改善**: ゲーミフィケーションポップアップを使用して、訪問者に連絡先情報の提供を促すインセンティブを与えることができ、その情報をリード獲得に活用できます。

# MoEngage のゲーミフィケーションポップアップ

MoEngage では、デフォルトで 2 種類のアプリ内ゲーミフィケーションポップアップを利用できます。

### **スピンホイール**

スピンホイールポップアップは、ユーザーがアプリの画面を訪問したとき、または特定のアクションを実行したときに表示するよう設定できるインタラクティブなポップアップです。ポップアップには仮想のホイールが表示され、ユーザーはボタンをクリックしてホイールを「回す」ことができます。ホイールは回転した後、ランダムに生成された賞品またはオファーの位置で止まり、ユーザーはポップアップに表示される指示に従ってそれを受け取ることができます。

## ゲーミフィケーションポップアップキャンペーンの使用

ゲーミフィケーションポップアップのメリットを理解したところで、アプリでゲーミフィケーションキャンペーンを作成する方法を見ていきましょう。

1. 新しいアプリ内キャンペーンを開始します。
2. キャンペーン作成のステップ 1 を完了します。
3. 次へをクリックします。
4. HTML テンプレートまでスクロールします。
5. 'Spin the Wheel' または 'Scratch card' テンプレートを選択します。
6. テンプレートがコードビューで開きます。
7. 以下に示すように、ユースケースに応じてコードを設定します。
8. キャンペーンをスケジュールし、配信コントロールを設定して、キャンペーンを公開します。

## ゲーミフィケーションポップアップの設定

### **スピンホイールテンプレート**

1. _背景画像の変更_\
   テンプレートの背景画像を変更するには、コードの 12 行目から 14 行目にある style タグのコメントを解除し、画像のパスを追加します。 <img src="/images/moengage_bed4dd.png" alt="background_change_code.png" />
2. _勝利アイコンや敗北アイコンなど、テンプレート内のその他の画像の変更_ コードには、どこを変更すればよいかがわかるようにコメントが付けられています。テンプレート内の画像を変更するには、`<img />` タグを検索し、既存のソースを使用する画像のソースに置き換えます。
3. _ホイールのセクターの追加または削除_\
   ホイールのセクターは、コード内の "DATA" 変数を使用して作成されます。ユースケースに応じてセクターを追加または削除できます。すべてのセクターに一意の ID を設定してください。 <img src="/images/moengage_7b3f3b.png" alt="Screenshot_2023-04-14_at_6.37.31_PM.png" />
4. _セクターの変更_ 各キーの値を変更することで、各セクターを変更できます。
   | キー | 説明 |
   | --- | --- |
   | id | 一意の番号です。 |
   | weightage | weightage が大きいほど、ユーザーがホイールを回したときにそのセクターが当たる確率が高くなります。<br />注: weightage は、キャンペーン期間中にセクターがユーザーに割り当てられる回数を指定するものではありません。<br />たとえば、weightage を次のように設定したとします。<br />Sector 1 - 50 <br />Sector 2 - 30 <br />Sector 3 - 15 <br />Sector 4 - 5   <br />この場合、weightage はキャンペーン期間全体を通じて Sector 4 が 5 人のユーザーにのみ割り当てられることを意味するものではありません。このポップアップが表示されたユーザーにとって、Sector 1 が当たる確率 (50%) が Sector 4 の確率 (5%) よりも高いことを意味します。すでに 5 人のユーザーが Sector 4 を獲得していても、ユーザーは Sector 4 を獲得する可能性があります。 |
   | label | セクターに表示するテキストです。 |
   | code | ユーザーが特定のセクターに止まったときに表示するクーポンです。 |
   | win | ユーザーがこのセクターを獲得したときに勝利画面を表示する場合は yes に設定します。特定のセクターで敗北画面を表示する場合は、win を no に設定します。 |
   | color | 各セクターの色です。 |

## キャンペーン結果の表示

既存のテンプレートには、クリックとデータのトラッキングがデフォルトで追加されています。ボタンを追加する場合は、必ずクリックトラッキングを追加してください。トラッキングの詳細については、[こちらのドキュメント](https://www.moengage.com/docs/developer-guide/components-for-sdk/javascript-bridge/javascript-bridge-for-html-in-apps)を参照してください。

キャンペーンを公開した後、Campaign info ページに移動すると、テンプレートの結果を確認できます。

![Screenshot\_2023-04-14\_at\_6.55.39\_PM.png](/images/moengage_c57405.png)

ユーザーに表示されたクーポンコードは、イベント MOE_RESPONSE_SUBMITTED の coupon_code 属性に保存されます。クーポンコードの使用状況はアプリ側に保存されるため、このデータからはユーザーが使用したクーポンコードの数はわかりません。このデータからわかるのは、ユーザーにどのクーポンコードが表示されたかのみです。

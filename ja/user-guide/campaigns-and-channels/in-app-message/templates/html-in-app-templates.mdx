# はじめに

HTML アプリ内メッセージを活用すると、複雑なアプリ内メッセージのレイアウトを作成して使用し、アプリ内にいるユーザーのエンゲージメントを高めることができます。

HTML アプリ内メッセージでは、次の機能がサポートされています。

- HTML テンプレートを使用して、モバイルアプリ内でポップアップを表示できます。これにより、アプリ内キャンペーンでアンケート、リード獲得、スピンホイールなどの機能を利用できるようになります。サンプルテンプレートは[こちら](/ja/user-guide/campaigns-and-channels/in-app-message/templates/sample-html-in-app-templates)で入手できます。
- アプリ内メッセージキャンペーンでの横向きモードと縦向きモードのサポート
- アプリ内メッセージキャンペーンでのタブレットと TV OS のサポート
- カスタム HTML テンプレートのアップロード: 独自のアプリ内テンプレートを作成して ZIP ファイルとしてアップロードするか、アプリ内キャンペーンの作成時に HTML を貼り付けるだけで使用できます。

# HTML アプリ内キャンペーンの作成

アプリ内キャンペーン作成の 2 番目のステップ (キャンペーン作成のコンテンツセクション) には、次の 3 つのタブがあります。

1. All templates
2. Custom template editor
3. Saved templates

![ContentCreation\_InAppCampaigns.png](/images/moengage_ed8a39.png)

All Templates セクションでは 4 つの標準の事前構築済み HTML テンプレートを利用でき、キャンペーンの作成に使用できます。Custom template editor では HTML テンプレートを作成でき、エディターに HTML コードを入力または貼り付けることができます。

## All Templates セクションの事前構築済み HTML テンプレート

アプリ内キャンペーンで HTML テンプレートを使用するには、次の手順に従ってください。

1. キャンペーン作成のステップ 2 で、'All templates' タブに移動し、以下に示すように HTML テンプレートセクションまでスクロールします。
2. 4 つの HTML テンプレートと、カスタム HTML エディターを使用してカスタム HTML テンプレートを作成するオプションがあります。任意の HTML テンプレートを選択するか、カスタム HTML テンプレートを作成します。

### Pop-up Survey Template の詳細

このテンプレートは、アンケートに対するユーザーの回答を取得するために使用できます。

#### **ステップ 1: ユーザーの回答をユーザー属性で取得する**

以下の画像に示すように、アンケートの回答はユーザー属性として取得されます。Code View にはテンプレートの HTML コードが表示されており、Popup-Survey Template のコードの 88 行目で、ユーザーが入力した内容をユーザー属性 _"survey\_response"_ として取得しています。ユーザー属性名は必要に応じてカスタマイズできます。

![PopupSurvey\_CodeView.png](/images/moengage_d52a1c.png)

**コードスニペット:**

HTML

```html wrap
<a class="btn btn-cstm-light " data-dismiss="modal" aria-label="Close" onclick="moengage.trackClick(); moengage.trackEvent('MOE_RESPONSE_SUBMITTED',{survey_response: document.querySelector('input[name=customRadio]:checked').value},{},{},false,true); moengage.setUserAttribute('survey_response', document.querySelector('input[name=customRadio]:checked').value); moengage.dismissMessage();">Share Feedback</a>
```

#### ステップ 2: ユーザーの回答時にイベントをトリガーする

ユーザーが回答を送信したときに、イベント "MOE\_RESPONSE\_SUBMITTED" をトリガーします。テンプレートのコードでは、これは 88 行目で行われています。フィードバックフォームからユーザーの入力を取得するイベント属性 "survey\_response" が、MOE\_RESPONSE\_SUBMITTED イベントのトラッキングに使用されます。イベント名とイベント属性名は必要に応じてカスタマイズできます。トラッキングされたこのイベントは、必要に応じて MoEngage の外部にデータを送信したり、フォローアップキャンペーンをトリガーしたりするために使用できます。

![PopupSurvey\_TrackEvent.png](/images/moengage_95e0c0.png)

**コードスニペット**

JSON

```json wrap
onclick="moengage.trackClick(); moengage.trackEvent('MOE_RESPONSE_SUBMITTED',{survey_response: document.querySelector('input[name=customRadio]:checked').value},{},{},false,true);
```

#### ステップ 3: データのトラッキング

このテンプレートのデータは、以下に示すようにトラッキングされ、MoEngage のユーザープロファイルに保存されます。

### Fullscreen Lead Gen Template の詳細

#### ステップ 1: ユーザーの詳細を MoEngage 属性で取得する

ユーザーが入力した内容を、MoEngage の標準属性である First Name と Email にそれぞれ保存します。

ステップ 2: イベントをトリガーする

ユーザーがこのフォームに回答を送信したときに、イベント "MOE\_RESPONSE\_SUBMITTED" をトリガーします。このイベントを活用して、MoEngage 経由でこのデータを外部 API エンドポイントに送信できます。以下の画像のハイライトされたコードは、入力データをユーザー属性およびイベントとしてトラッキングする役割を担っています。

![LeadGen\_CodeView.png](/images/moengage_b4c0ec.png)

コードスニペット:

JSON

```json wrap
<button class="btn btn-cstm-dark btn-block btn-cta" data-dismiss="modal" aria-label="Close" onclick="moengage.setFirstName(document.getElementById('moe_name').value);moengage.setEmailId(document.getElementById('moe_email').value);moengage.trackEvent('MOE_RESPONSE_SUBMITTED',{firstName: document.getElementById('moe_name').value, email: document.getElementById('moe_email').value},{},{},false, true); moengage.trackClick(1); moengage.dismissMessage()">Subscribe</button>
```

### Fullscreen Carousel Template の詳細

#### ステップ 1: 各画像の CTA を定義する

以下のコードのハイライトされた行に示すように、カルーセルの各画像に Call to Action を定義できます。

![Carousel\_CodeView.png](/images/moengage_c92b30.png)

コードスニペット:

HTML

```html wrap
<a href="#" class="btn btn-cstm-light btn-cta" onclick="moengage.openRichLanding('https://www.moengage.com'); moengage.trackClick(1); moengage.dismissMessage()">get started</a>
```

HTML

```html wrap
<a href="#" class="btn btn-cstm-light btn-cta" onclick="moengage.openRichLanding('https://www.moengage.com/nativ/'); moengage.trackClick(2); moengage.dismissMessage()">get started</a>
```

カルーセルテンプレートでは、ユーザーがカルーセルの 1 つの要素をクリックすると [https://www.moengage.com](https://www.moengage.com) にリダイレクトされ、次の要素をクリックするとイベントがトラッキングされます。同様に、[こちら](https://www.moengage.com/docs/developer-guide/components-for-sdk/javascript-bridge/javascript-bridge-for-html-in-apps)の JS Bridge セクションに記載されているアクションを定義できます。\
上記のコードスニペット内の moengage.trackClick(2) 関数は、クリックのトラッキングを担当します。関数内の引数 (1) と (2) により、カルーセルの異なる要素に対するクリックを区別できます。

### デバイスの向き

モバイルデバイスでは、このテンプレートは縦向きモードとの互換性が最も高くなります。このテンプレートを横向きモードで表示すると、ユーザーにはスクロールオプションが表示されます。タブレットと TV では、このテンプレートはどの向きでも期待どおりにレンダリングされます。

# HTML テンプレートの準備

HTML アプリ内メッセージは、モバイルアプリ上でフルスクリーンの Web ビュー内にレンダリングされ、MoEngage SDK は HTML に何の操作も加えずにそのままレンダリングします。

アプリ内メッセージとして表示する HTML テンプレートを準備する際は、次の点に注意してください。

- MoEngage が提供する[サンプル HTML テンプレート](/ja/user-guide/campaigns-and-channels/in-app-message/templates/sample-html-in-app-templates)を使用してください。直接ダウンロードして MoEngage にアップロードすることも、必要に応じて編集することもできます。これらのサンプルテンプレートは、独自の HTML テンプレートをゼロから構築する際の参考にもなります。
- HTML テンプレートは、常にモバイルアプリの画面全体を占有します。テンプレートの HTML が画面全体を占有しない場合でも、そこには透明な Web ビューが存在し、ユーザーがアプリを操作できなくなります。この仕様のため、テンプレートの背後には常に透明なオーバーレイを配置することをお勧めします。これは HTML テンプレートの背景として設定できます。
- テンプレートからのすべてのインタラクションは、キャンペーンのパフォーマンス統計 (クリックなど) を計算するため、またはユーザーデータポイント (イベント、ユーザー属性 - メール、携帯電話番号、評価など) として、MoEngage にデータポイントとして記録する必要があります。[JavaScript Bridge for HTML In-Apps](https://www.moengage.com/docs/developer-guide/components-for-sdk/javascript-bridge/javascript-bridge-for-html-in-apps) を活用し、HTML テンプレート内で使用してください。
- iOS では、次の 2 点に注意する必要があります。
  - デフォルトでは、Web ビューでズームとスケーリングが有効になっています。無効にするには、HTML でメタタグを使用する必要があります。
  - ノッチのある iOS デバイスでは、コンテンツがノッチと重ならないように、セーフエリアをサポートするよう CSS を更新してください。
- 画像で説明されているように HTML テンプレート内で指定された背景画像については、これらの URL がテンプレートのスタイル内にあるため、MoEngage は URL をプリフェッチしません。**背景画像にはアップロードしたアセットの URL を使用しないでください。** このような場合は、MoEngage SDK が実行時にダウンロードしてレンダリングする絶対 URL が必要です。その他のすべての画像については、アプリ内メッセージのレンダリング時にバッファが発生しないよう、画像をプリフェッチします。 <img src="/images/moengage_df5641.png" alt="Screen_Shot_2021-09-06_at_1.08.44_PM.png" />

## サポートされているコンポーネント

HTML アプリ内テンプレートはすべての HTML および CSS コンポーネントをサポートしていますが、次のコンポーネントは特に重要で、HTML アプリ内キャンペーンから大きな価値を引き出すことができます。

| 要素 | ユースケース |
| --- | --- |
| Audio / Video | アプリ内キャンペーンからビデオファイルやオーディオファイルを再生して、ユーザーに情報を伝えることができます。これらは、ユーザーのオンボーディングプロセスで特に役立ちます。 |
| Image / GIF | アプリ内キャンペーンでオファー、コンテンツ、製品、サービスを宣伝し、リッチな画像でユーザーの注意を引くことができます。  注: GIF ファイルはアップロードできませんが、絶対 URL を使用してテンプレートに追加できます。 |
| Input | HTML アプリ内キャンペーンを使用して、メールアドレスや携帯電話番号などのユーザー入力を取得できます。 |
| Survey | HTML アプリ内キャンペーンを使用して、モバイルアプリでアンケートを実施できます。 |
| Carousel | カルーセルのようなインタラクションを使用して、1 つのポップアップで複数のオファー、製品、サービスを表示できます。 |

## ZIP ファイルのアップロード

![Screen\_Shot\_2021-09-03\_at\_10.29.12\_AM.png](/images/moengage_9116d5.png)

ZIP ファイルを準備する際は、次の点を必ず守ってください。

- .zip ファイルのサイズが 5MB 未満であることを確認してください。

- GIF ファイルはアップロードできませんが、絶対 URL を使用してテンプレートに追加できます。

# HTML テンプレートコンテンツのパーソナライズ

すべての HTML テンプレートのコンテンツをパーソナライズできます。キャンペーン作成のステップ 2 の Content タブで、パーソナライズしたいコード行に移動し、**@** と入力します。

User Attributes、User Events、Product Sets、Content APIs、Content Blocks を使用してコンテンツをパーソナライズできます。

詳細については、以下を参照してください。

- [MoEngage テンプレート言語 (JINJA)](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/jinja-templating-language)
- [派生イベントと属性](/ja/user-guide/data/event-data/derived-events-and-attributes)
- [Product Sets](/ja/user-guide/content/recommendations/getting-started/catalogs)
- [Content APIs](/ja/user-guide/campaigns-and-channels/getting-started/campaign-content/content-apis)
- [Content Block](/ja/user-guide/content/content-blocks/content-blocks)

![HTMLInApp.gif](/images/moengage_d81def.png)

次の操作を行います。

1. @ と入力してコンテンツをパーソナライズします。
2. Data personalization または Content Block のいずれかをクリックします。
3. Data personalization タブをクリックし、ドロップダウンから次のいずれかを選択します。
   1. User Attributes
   2. パーソナライズの代替 (フォールバック) として、次のいずれかを選択します。
      - No Fallback\
        パーソナライズされたコンテンツ用のオプションを選択します。このオプションでは、パーソナライズが機能しない場合に代替は使用されません。
      - Do not send In-App\
        パーソナライズが機能しない場合にアプリ内メッセージを送信しないオプションを選択します。
      - Replace Text\
        パーソナライズが機能しない場合に使用するテキストを入力または貼り付けます。
   3. Product Sets
   4. Content API
      1. Content API のパラメーターの値を変更します。
4. Content Block をクリックします。
   1. 挿入するコンテンツブロックを選択します。
   2. Insert only the content of the content block をクリックします。
      <Info>
        このオプションを選択した場合:
        - コンテンツのみが挿入されます。
        - コンテンツはコンテンツブロックとの接続が解除されます。
        - コンテンツブロックでのコンテンツの更新は、挿入されたコンテンツには反映されません。
      </Info>
5. Done をクリックします。

# その他の新機能

HTML アプリ内メッセージでは、さらに次の機能を活用できます。

## 横向きモードでのアプリ内メッセージの表示

アプリ内キャンペーンを横向きモードで表示する必要がある場合は、HTML アプリ内テンプレートを活用し、Template Settings に移動して設定できます。

![DeviceOrientation.png](/images/moengage_28ede9.png)

SDK バージョンを 11.4.00 (Android) および 7.1.0 (iOS) にアップグレードする必要があります。デバイスの向きのデフォルトの選択は Both で、HTML アプリ内キャンペーンはデフォルトで縦向きモードと横向きモードの両方で表示されます。

注意点:

- アプリ内キャンペーンが縦向きモードのみに設定されている場合、デバイスが縦向きモードから横向きモードに回転すると、アプリ内メッセージは閉じられます。
- デバイスが縦向きモードで、アプリ内キャンペーンが横向きモードのみに設定されている場合、アプリ内キャンペーンは表示されません。
- 選択したデバイスの向きは、異なるバリエーションやプラットフォーム間で同じままです。
- Android では、デバイスを回転させるとアプリ内メッセージが閉じられ、再度レンダリングされます。

## タブレットまたは TV でのアプリ内メッセージの表示

タブレットや TV でアプリ内メッセージを表示する必要がある場合は、HTML アプリ内キャンペーンを活用できます。

![DeviceTypes.png](/images/moengage_f7f161.png)

デフォルトの選択は Mobile のみのため、ターゲットにする必要がある追加のデバイスは、キャンペーン作成時に別途設定する必要があります。

## ネイティブテンプレートの HTML コードのコピー

_\*\* HTML コードをコピーする前に、DB で HTML アプリ内メッセージが有効になっていることを確認してください\*\*_

ネイティブのアプリ内テンプレートを変更したいのに、できなかったことはありませんか? ボタンをクリックするだけでネイティブテンプレートの HTML をコピーし、カスタム HTML エディターで編集して、キャンペーンを公開できるようになりました。

手順は次のとおりです。

1. キャンペーン作成のステップ 2 で、編集したいテンプレートを選択します。
2. テンプレートのプレビューの上にある "Copy HTML" をクリックして、選択したテンプレートの HTML コードをコピーします。 <img src="/images/moengage_aa13a3.png" alt="Copy_HTML.png" />
3. 次に、ケバブメニューをクリックしてテンプレートを変更します。 <img src="/images/moengage_ad20e9.png" alt="Change_template.png" />
4. Custom template editor タブから "Custom HTML Upload" を選択します。 <img src="/images/moengage_d0bedb.png" alt="Select_custom_HTML.png" />
5. エディター内の既存のコードをすべて削除し、cmd\+v または ctrl\+v を使用して新しいコードをエディターに貼り付けます。 <img alt="Copy_HTML_after_paste.png" src="/images/moengage_814560.png" />
6. これで、テンプレートのコードを編集し、ビジネス目標に応じて変更できます。

**この機能を使用する際の注意点**

- コピーしたコードにはクリックトラッキングがデフォルトで含まれないため、この場合はクリックトラッキングを実装する必要があります。方法については[こちら](https://www.moengage.com/docs/developer-guide/components-for-sdk/javascript-bridge/javascript-bridge-for-html-in-apps#track-event)をお読みください。
- ネイティブテンプレートで設定されたアクションは、ここに自動的にコピーされません。お客様側でゼロから実装する必要があります。たとえば、別の画面に移動するコードを追加する方法は[こちら](https://www.moengage.com/docs/developer-guide/components-for-sdk/javascript-bridge/javascript-bridge-for-html-in-apps#navigation-actions)をご覧ください。
- クローズボタンも実装する必要があります。方法は[こちら](https://www.moengage.com/docs/developer-guide/components-for-sdk/javascript-bridge/javascript-bridge-for-html-in-apps#track-dismiss)をご覧ください。
- テンプレートに動的なコンポーネントがある場合は、JavaScript を使用してコード内でインタラクションも処理してください。
- ナッジテンプレートの HTML コードをエディターに貼り付けると、公開時にアプリ内に埋め込まれるのではなく、オーバーレイポップアップとして表示されます。
- 公開後のエラーを避けるため、横向きモードと縦向きモードの両方でキャンペーンをテストしてください。

   ```html wrap
   <html><head><style>@font-face { font-family: Pacifico; src: url('assets/17423800370465841_gy3/Pacifico.ttf'); } h1 {font-family: Pacifico}</style></head><body><h1>Hey, June</h1></body></html>
   ```

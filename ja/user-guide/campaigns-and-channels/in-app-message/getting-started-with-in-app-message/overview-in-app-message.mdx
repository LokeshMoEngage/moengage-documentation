---

アプリ内メッセージは、ユーザーがアプリケーションをアクティブに使用している間にエンゲージできる強力なチャネルです。コンバージョンの促進、関連性の高いレコメンデーションの表示、新規ユーザーのオンボーディング、フィードバックの収集を目的とした、美しく文脈に沿ったメッセージを作成できます。しかも、メッセージはアプリにネイティブな見た目と操作感を保ちます。

アプリの外に表示されるプッシュ通知とは異なり、アプリ内メッセージはアプリのインターフェース内に表示されるため、控えめで関連性の高いコミュニケーション体験を提供します。特定のユーザーアクションや属性によってトリガーされるため、適切なメッセージを適切なユーザーに最適なタイミングで届けることができます。

<Note>
  1 つのワークスペースで同時にアクティブにできるアプリ内メッセージまたは On-Site Messaging キャンペーンは最大 200 件です。この上限を引き上げるには、サポートにお問い合わせください（MTU に基づいて追加費用が発生します）。
</Note>

<Tip>
アプリ内メッセージの作成と送信を開始する前に、MoEngage SDK がモバイルアプリケーションに正常に統合されていることを確認してください。詳細については、[iOS SDK](/ja/developer-guide/ios-sdk/in-app-messages/in-app-nativ)、[Android SDK](/ja/developer-guide/android-sdk/in-app-messages/in-app-nativ)、およびその他の SDK については[開発者向けドキュメント](/ja/developer-guide)を参照してください。
</Tip>

# ユースケース

アプリ内メッセージは汎用性が高く、さまざまなマーケティングおよびプロダクトの目標達成に活用できます。一般的なユースケースは次のとおりです。

- **新規ユーザーのオンボーディング**: 初回セッション中にアプリの主要機能をユーザーに案内し、アクティベーションとリテンションを向上させます。
- **プロモーションと特別オファー**: セール、割引、限定特典を告知して購入を促進し、収益を向上させます。これらのメッセージにクーポンコードや画像を埋め込んだり、メッセージにディープリンクを設定してユーザーをディープリンク先の画面や URL に誘導したりできます。
- **機能の告知とアップデート**: 新機能や重要なアップデートをユーザーに知らせ、導入と利用を促進します。
- **フィードバックとアンケート**: 貴重なユーザーフィードバックの収集、アンケートの実施、Net Promoter Score (NPS) キャンペーンの実施により、ユーザー満足度を把握します。
- **トランザクションの確認**: 購入、予約、プロフィール更新の成功などのアクションに対して、即座に確認を提供します。
- **ナッジとリマインダー**: プロフィールの完成や新機能の利用など、特定のアクションの完了に向けてユーザーを誘導します。
- **権限取得の事前案内**: 最初にその価値を説明することで、プッシュ通知や位置情報へのアクセス許可をユーザーに促します。

# 次のステップ

アプリ内メッセージの概要を理解したら、次のステップに進むことができます。

- [**テンプレートを確認する**](/ja/user-guide/campaigns-and-channels/in-app-message/templates/in-app-templates): 事前構築済みのノーコードオプションから完全にカスタマイズ可能な HTML テンプレートまで、利用可能なさまざまな種類のテンプレートを把握します。これにより、メッセージに適した形式を選択できます。
- [**キャンペーンを作成する**](/ja/user-guide/campaigns-and-channels/in-app-message/create/create-in-app-campaign): 最初のアプリ内キャンペーンを構築する手順を段階的に学びます。これには、ターゲットオーディエンスの定義、テンプレートの選択、コンテンツのパーソナライズ、配信スケジュールの設定が含まれます。
- [**キャンペーンを分析する**](/ja/user-guide/campaigns-and-channels/in-app-message/analyze/analyze-in-app-campaigns): キャンペーンの公開後に、そのパフォーマンスを測定する方法を理解します。今後のアプリ内メッセージ戦略の最適化に役立つ主要な指標と分析について学びます。

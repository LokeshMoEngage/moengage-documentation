MoEngage でロケールを使用すると、複数の言語で In-App メッセージを送信できます。ロケールを使用すると、さまざまなオーディエンスに合わせてメッセージを調整でき、キャンペーンの効果を高めることができます。

MoEngage アカウントには最大 256 個のロケールを設定できます。各 In-App キャンペーンには、1 つのデフォルトロケールを含めて最大 11 個のロケールを適用できます。

アカウントへのロケールの追加の詳細については、[キャンペーンメッセージのローカライズ](/ja/user-guide/campaigns-and-channels/getting-started/campaign-content/localize-campaign-messages)を参照してください。

# 新しいロケールを追加する

アカウントに新しいロケールを追加するには、次の手順に従います。

1. キャンペーン作成フローで **Content** ステップに移動します。次に、**Locale** ボタン <img alt="Locale ボタンのアイコン" src="/images/moengage_085a44.png" /> をクリックします。ロケール選択リストが表示されます。
2. **+New locale** をクリックします。
3. 次のオプションを含む **Add new locale** ウィンドウが表示されます。

| フィールド | 説明 |
| --- | --- |
| **Locale name** | ロケール名を入力します。 |
| **User property** | 属性のドロップダウンリストからユーザープロパティを選択します。 |
| **Filter** | **+Filter** をクリックし、ロケールのフィルター値を入力します。詳細については、[セグメントの作成](/ja/user-guide/segment/create-segments/rule-based-filter-segments)を参照してください。 |
| **Exclude users** | **Exclude Users** をクリックして、特定のユーザーがキャンペーンを受信しないようにします。詳細については、[Preference Management](/ja/user-guide/campaigns-and-channels/mobile-push/getting-started-with-mobile-push/preference-management-for-push-notifications) を参照してください。 |

4. **Add** をクリックして新しいロケールを MoEngage アカウントに保存するか、**Cancel** をクリックして破棄します。

<img alt="'Add New Locale' ポップアップに詳細を入力して新しいロケールを追加するプロセスを示すアニメーション。" src="/images/moengage_d9b3d0.png" />

注: ここで作成したロケールは、キャンペーンに直接追加されるのではなく、アカウントで利用可能なロケールのリストに追加されます。キャンペーンに追加するには、次のセクションの手順に従ってください。

<Info>
**ロケールのキャッシュポリシー**

User Locale の更新には、サーバー側で 3 時間のキャッシュ期間があります。そのため、ユーザーのロケール属性が更新された場合、新しいロケールが In-App Messaging キャンペーンに反映されるまでに最大 3 時間かかることがあります。リアルタイムのロケール変更に基づく即時のコンテンツ更新には、この遅延が発生する可能性があります。
</Info>

# キャンペーンにロケールを追加する

既存のロケールを In-App キャンペーンに追加するには、次の手順に従います。

1. キャンペーン作成フローでコンテンツのステップに移動します。次に、**Locale** ボタン <img alt="Locale ボタンのアイコン" src="/images/moengage_085a44.png" /> をクリックします。
2. 表示されたロケール選択リストから、In-App キャンペーンに追加するロケールを選択します。
3. **Add** をクリックします。**Choose content for new added locales** ウィンドウが表示されます。ここでは、追加したロケール用に新しいコンテンツを作成するか、デフォルトロケールからコンテンツをコピーするかを選択できます。  
    <img alt="Choose content for new added locales ウィンドウのスクリーンショット。" src="/images/moengage_43215d.png" />
4. **Choose locale content from** のドロップダウンリストから、次のいずれかを選択します。
   - **Create new content**: このオプションは、ロケールをキャンペーンに追加し、そのロケール用のコンテンツを作成できるようにします。
   - **Copy from locale Default**: このオプションは、ロケールを追加し、デフォルトロケールのコンテンツをそのロケールにコピーします。
5. **Done** をクリックして選択したロケールをキャンペーンに追加するか、**Cancel** をクリックして追加せずにウィンドウを閉じます。

<img alt="キャンペーンにロケールを追加し、コンテンツのオプションを選択するプロセスを示すアニメーション。" src="/images/moengage_1f55bb.png" />

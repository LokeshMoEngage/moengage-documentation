---
title: "In-App キャンペーンをテストする"
description: "MoEngage の In-App キャンペーンでエンドツーエンドのテストを実行し、公開前にトリガー条件、オーディエンスのターゲティング、配信制御を検証します。"
---

In-App キャンペーンをテストして、ユーザーに対してどのように表示され、どのように動作するかを確認できます。この機能を使用すると、すべてのトリガータイプでエンドツーエンドのテストを実行し、トリガー条件、オーディエンスのターゲティング、配信制御が期待どおりに機能することを確認できます。

## In-App キャンペーンをテストする

キャンペーンをテストするには、

- キャンペーン作成プロセスの 3 番目のステップで、**Test Campaign** をクリックします。

![](/images/moengage_2ac546.png)

## テストを設定する

Configure 画面で、次の詳細を指定します。

![](/images/moengage_dc49f9.png)

1. **Target Platform**: ターゲットプラットフォームとして **Android** を選択します。
   - **注**: この機能は現在、Android デバイスのみをサポートしています。
2. **Unique Identifier**: テストデバイスを識別するためのユーザー属性（Device ID、Advertising ID など）を選択します。6 種類のユーザー属性から選択できます。
   ![](/images/moengage_136c11.png)
3. **Enter the Unique Identifier**: In-App キャンペーンをテストするデバイスの一意の識別子を入力します。

これらの詳細を入力したら、**Send Test Campaign** をクリックします。デバイスにプッシュ通知が送信されます。次の段階に進み、テストを続行します。

## テストを実行する

この段階では、キャンペーンをテストするために実行するアクションのリストが表示されます。これらのアクションは、キャンペーン作成時に設定したトリガーによって異なります。

- On App Open
- On Specific Screen
- On Custom Event

### On App Open トリガー

![](/images/moengage_57d6a6.png)

テストを完了するには、プッシュ通知をクリックします。アプリを開くと、In-App キャンペーンがすぐに表示されます。

手順を完了したら、**View Test Results** をクリックします。

### On Specific Screen トリガー

特定の画面によってトリガーされる In-App キャンペーンをテストする場合、**Perform these steps** の下に追加のステップが表示されます。

**Go to screen:** _選択した画面_

このテストを完了するには、アプリで選択した画面に移動します。たとえば、"Checkout Screen" で表示するようにキャンペーンを設定した場合は、アプリのチェックアウト画面に移動します。

In-App キャンペーンを確認したら、**View Test Results** をクリックします。

### On Custom Event トリガー

カスタムトリガーイベントを使用する In-App キャンペーンをテストする場合、次のステップが表示されます。

**Perform trigger:** _選択したトリガー_

このテストを完了するには、アプリで選択したカスタムイベントを実行します。たとえば、キャンペーンが "Add to Cart" イベントによってトリガーされる場合は、アプリで **Add to Cart** ボタンをクリックします。

手順を完了したら、**View Test Results** をクリックします。

![](/images/moengage_b2ed82.png)

<Info>
  テストの手順を正しく実行しなかった場合、テスト結果にエラーが表示されます。その場合は、テストプロセスを最初からやり直す必要があります。
</Info>

## テスト結果を確認する

テスト結果画面には、In-App キャンペーンが正常に実行されたかどうかが表示されます。

- **Test Results** リストに緑色のチェックマークが表示されている場合、キャンペーンは正常に実行されています。テストデバイスを使用して、In-App キャンペーンのすべての視覚要素が正しく表示されていることを確認してください。
  ![](/images/moengage_ed43d7.png)
- **Test Results** リストに赤い×印が表示されている場合、キャンペーンは正常に実行されていません。エラーはイベントの下に一覧表示されます。エラーを修正してから、**Re-test** をクリックしてキャンペーンを再度テストします。
  - ポップアップの右下にある **Re-test** ボタンをクリックして、In-App キャンペーンを再テストします。
    ![Screenshot 2024-03-21 at 1.38.35 PM.png](/images/moengage_fa7ac4.png)
- キャンペーンのトリガーが **On Custom Event** の場合、**Test Results** の下に **Perform trigger** も表示されます。**Perform trigger** の横に緑色のチェックマークがある場合は、トリガーイベントが正常に実行されたことを示しており、テストは成功しているはずです。
  - それ以外の場合、**Perform trigger** の横に赤い×印が表示され、エラーがあることを示します。エラーメッセージに問題の詳細が表示されます。

## 一般的なエラーと解決方法

次の表は、テスト中に発生する可能性のある一般的なエラーとその解決方法を示しています。

| エラー | 解決方法 |
| --- | --- |
| Push notification not clicked | プッシュ通知を受信しない場合は、**Re-test** をクリックしてテストをやり直し、次の設定手順を確認してください: <ol><li>アプリをバックグラウンドから削除します。</li><li>プッシュ通知を有効にします。iOS または Android 13 以降でテストしている場合は、プッシュ通知が有効になっていることを確認してください。</li><li>Apple Push Notification service（APNS）証明書がない場合は、追加または更新します。詳細については、[こちら](/ja/developer-guide/ios-sdk/push/basic/apns-certificate-pem-file-legacy)を参照してください。</li><li>ユーザーの解決を確認します。テストユーザーが存在し、このユーザーにデバイスが紐付けられていることを確認してください。</li></ol> |
| Screen was not visited | キャンペーンの設定で画面名が正しくないか、テスト中にその画面にアクセスしていません。考えられる理由は次のとおりです: <ol><li>誤った画面にアクセスした。キャンペーン作成プロセスのステップ 1 で設定した画面に移動してください。</li><li>画面が存在しない。設定した画面名がアプリ内に存在するかどうかを開発者に確認してください。</li></ol> |
| Context not visited | キャンペーンの設定でコンテキスト名が正しくないか、テスト中にそのコンテキストにアクセスしていません。考えられる理由は次のとおりです: <ol><li>誤ったコンテキストにアクセスした。キャンペーンを再テストし、キャンペーン作成プロセスのステップ 1 で設定したコンテキストに移動してください。</li><li>コンテキストが存在しない。設定したコンテキスト名がアプリ内に存在するかどうかを開発者に確認してください。</li></ol> |
| Trigger action not performed | キャンペーンの設定でトリガーアクションが正しくないか、テスト中にトリガーアクションが実行されていません。考えられる理由は次のとおりです: <ol><li>カスタムイベントのトリガーアクションが実行されていない。選択したカスタムイベントを実行してアプリ内表示をトリガーし、キャンペーンを再テストしてください。</li><li>誤った画面でトリガーアクションを実行した。アプリ内表示をトリガーするには、"`{screen_name}`" 画面で選択したカスタムイベントを実行してください。</li><li>誤ったコンテキストでトリガーアクションを実行した。アプリ内表示をトリガーするには、"`{context_name}`" コンテキストで選択したカスタムイベントを実行してください。</li><li>イベント属性が正しくない。設定した `"{attribute_name}"` イベント属性を確認してください。属性が存在しないか、正しくない可能性があります。</li></ol> |
| Trigger time not executed | 設定したトリガー時間に達していません。キャンペーンがトリガーされるまで、選択した画面で \[5 秒\] 待ってください。キャンペーンのテストでは、60 分未満の遅延時間がサポートされています。 |
| Campaign not visible | キャンペーンが表示されない理由として次の点を確認し、解決してからキャンペーンを再テストしてください: <ol><li>**開いた画面で showInApp() メソッドが呼び出されていない**: テスト中に開いた画面に "showInApp" メソッドがありません。このメソッドは、キャンペーンを画面に表示するために必要です。Android の場合は[こちら](/ja/developer-guide/android-sdk/in-app-messages/in-app-nativ)、iOS の場合は[こちら](/ja/developer-guide/ios-sdk/in-app-messages/in-app-nativ)に記載されている手順に従って設定してください。</li><li>**開いた画面で showNudge() メソッドが呼び出されていない**: テスト中に開いた画面に "showNudge" メソッドがありません。このメソッドは、キャンペーンを画面に表示するために必要です。</li><li>**開いた画面で getSelfHandledInApp() メソッドが呼び出されていない**: テスト中に開いた画面に "getSelfHandledInApp" メソッドがありません。このメソッドは、キャンペーンを画面に表示するために必要です。</li><li>**Nudge の位置が正しくない**: この Nudge キャンペーンは誤った位置（`({nudge_position})`）に表示されました。SDK で正しい Nudge の位置が設定されていることを確認してください。</li><li>**配信エラー**: [In-App キャンペーン分析の配信エラーのセクション](/ja/user-guide/campaigns-and-channels/in-app-message/analyze/analyze-in-app-campaigns)を参照してください。</li></ol> |

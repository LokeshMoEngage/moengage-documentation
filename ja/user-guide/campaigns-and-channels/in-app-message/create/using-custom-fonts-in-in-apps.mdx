この記事では、MoEngage の In-App メッセージにカスタムフォントを追加する方法について説明します。カスタムフォントを使用すると、一貫したブランディングを維持し、アプリユーザーにシームレスな体験を提供できます。

<Tip>
カスタムフォントは、Android SDK バージョン 10.0.0 以降および iOS SDK バージョン 6.0.0 以降でのみサポートされています。
</Tip>

# In-App メッセージにカスタムフォントを追加する

In-App メッセージングキャンペーンにカスタムフォントを追加するには、次の手順に従います。

1. キャンペーン作成の **Step 2** に移動します。
2. **Custom font** チェックボックスを選択します。
3. **Custom font** チェックボックスの下にあるテキストボックスに、カスタムフォント名を入力します。

   <img alt="Custom font チェックボックスとテキストボックスを示すスクリーンショット" src="/images/moengage_d4c2e8.png" />
4. 指定したフォント名がアプリバンドル内で利用可能であることを確認します。
   - **Android** の場合: フォントファイルをアプリバンドル内の `res/font/` フォルダーに配置します。詳細については、[XML でのフォントの追加に関する Android Developer ドキュメント](https://developer.android.com/develop/ui/views/text-and-emoji/fonts-in-xml)を参照してください。
   - **iOS** の場合: フォントファイルをアプリにバンドルします。詳細については、[iPhone](https://support.apple.com/en-in/guide/iphone/iphb2517689c/ios) および [iPad](https://support.apple.com/en-in/guide/ipad/ipad952422ba/ipados) へのフォントの追加に関する Apple のドキュメントを参照してください。
5. In-App メッセージにカスタムフォントを適用しない場合は、テキストボックスを空のままにします。
6. カスタムフォントを使用した In-App メッセージの表示を確認するには、**Test Campaign** 機能を使用します。詳細については、[In-App キャンペーンのテスト](/ja/user-guide/campaigns-and-channels/in-app-message/create/test-your-in-app-campaign)を参照してください。

<Info>
カスタムフォントは、ダッシュボードのメッセージプレビューには表示されません。メッセージ内のフォントを確認するには、Test Campaign 機能を使用してください。
</Info>

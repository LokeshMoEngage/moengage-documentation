キャンペーンメッセージが各種デバイスで期待どおりに表示されることを確認するために、テストを行う必要があります。デバイスの種類は多岐にわたるため、MoEngage Dashboard のメッセージプレビューが実際のデバイスでの表示と常に一致するとは限りません。_Test Campaign_ 機能を使用すると、選択したデバイスで In-App メッセージをテストできます。

# Test Campaign 機能を見つける

### In-App Nativ Version 3

In-App Nativ Version 3 を使用している場合、**Test Campaign** 機能は、In-App メッセージを定義した後の [キャンペーン作成のステップ 2](/ja/user-guide/campaigns-and-channels/in-app-message/create/create-in-app-campaign) にあります。

![TestingInApp\_01.png](/images/moengage_b65021.png)

### In-App Nativ Version 2

In-App Nativ Version 2 の場合、**Test Campaign** 機能は、キャンペーンを公開する前のキャンペーン作成の最終ステップで利用できます。これは、一般的な In-App メッセージとイベントトリガー型の In-App メッセージの両方に適用されます。

![Screen\_Shot\_2020-08-19\_at\_12.47.16\_PM.png](/images/moengage_602eaf.png)

# In-App メッセージをテストする方法

**Test Campaign** 機能を使用すると、アプリ上で In-App メッセージを確認し、アニメーションやクリック時のアクションなどの主要な機能をテストできます。

ライブユーザーに対してキャンペーンを有効にする前に、デバイスで In-App メッセージを受信するには、次の手順を実行します。

1. キャンペーン作成中に **Preview in-app** セクションに移動します。
2. 以下に示すように、テストユーザーを識別するための属性を選択します。

![TestingIn\_App\_02.png](/images/moengage_81a021.png)

ユーザーは、任意のデバイス識別子（Google Advertising ID、IDFA、プッシュ ID など）または任意のユーザー識別子（ID、Email ID、Mobile Number など）で識別できます。

<Tip>
  テストキャンペーンで使用する前に、MoEngage でユーザーのプロパティを設定しておいてください。
</Tip>

MoEngage がテストキャンペーンの送信を試みると、次のようになります。

|  |  |
| --- | --- |
| 選択した属性と値で MoEngage がユーザーを識別できない場合、次のエラーメッセージが表示されます: | <img alt="UserNotfounderror.png" src="/images/moengage_81a3ab.png" /> |
| MoEngage がユーザーを正常に識別した場合、次の確認メッセージが表示されます: | <img alt="TestCampaignSentMessage.png" src="/images/moengage_1896f7.png" /> |

MoEngage がテストキャンペーンをユーザーに正常に送信すると、以下に示すように、デバイスでプッシュ通知を受信します。

<img
  alt="Screenshot_20200819-124130.png"
  src="/images/moengage_fb1b63.png"
  style={{ width:"41%" }}
/>

このプッシュ通知をタップするとアプリが開き、以下に示すように In-App メッセージが表示されます。テストキャンペーンでは、メッセージが表示されるまでに最大 15 秒かかる場合があります。ライブキャンペーンではこの遅延はありません。

<img
  alt="Screenshot_20200819-124222.png"
  src="/images/moengage_ba44c7.png"
  style={{ width:"42%" }}
/>

<Info>
  MoEngage がこのプッシュ通知を送信するのはテストキャンペーンの場合のみです。ライブキャンペーンのユーザーには、キャンペーンの条件を満たしてトリガーアクションを実行した後に、In-App メッセージが直接表示されます。
</Info>

テストキャンペーンでは、フリークエンシーキャップと表示制御は無視されます。テストキャンペーンは、メッセージのルック＆フィールのみをテストするためのものです。

### テストキャンペーンに関する一般的な問題のトラブルシューティング

#### In-App Nativ Version 2

In-App Nativ Version 2（旧バージョン）を使用している場合、プッシュ通知をタップした後にアプリで In-App メッセージが表示されないという問題が断続的に発生することがあります。この既知の問題は、アプリ内に実装したカスタムリダイレクトが原因で発生します。これを解決するには、SDK を最新バージョンに更新して、**Test Campaign** 機能をシームレスに使用できるようにしてください。

#### In-App Nativ Version 3

|  |  |
| --- | --- |
| In-App Nativ Version 3 で、旧バージョンの In-App SDK（Android SDK 10.0.0 より前、iOS SDK 6.0.0 より前）をターゲットにする場合は、以下に示すようにこのオプションのチェックボックスを選択します: | <img alt="OlderVersion.png" src="/images/moengage_fd8115.png" /> |

これにより、旧バージョンの SDK でもテストキャンペーンが機能するようになります。ただし、MoEngage では MoEngage SDK を最新バージョンに更新することを推奨しています。In-App SDK の詳細については、[In-App NATIV](/ja/developer-guide/android-sdk/in-app-messages/in-app-nativ) を参照してください。

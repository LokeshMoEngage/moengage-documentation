## アプリ内メッセージアクションでキーと値のペアを使用する

キーと値（KV）のペアは、In-App Messaging キャンペーン内の特定のアクションに関連付けることができる追加のデータ要素です。各 KV ペアはキーと値で構成されます。キーはデータの説明で、値はデータそのものです。KV ペアを使用すると、ユーザーがキャンペーンを操作したときにアプリへ追加の情報を送信できます。これにより、よりパーソナライズされ、動的で、トラッキング可能なユーザー体験を作成できます。

マーケターや開発者は、KV ペアを使用してユーザーとのインタラクションを強化し、動的なコンテンツを有効にし、キャンペーンのトラッキングを改善します。また、開発者は KV ペアを使用して、特定のアクションに対してアプリのコードにカスタムパラメーターを渡します。

### 始める前に

- さまざまなアクションに対してアプリが想定している具体的なデータ（キーと値）を把握しておきます。

### アプリ内メッセージアクションにキーと値のペアを追加する

KV ペアを追加するには、次の手順を実行します。

1. In-App Message キャンペーンの **Content** セクションで、**Preview** 領域からウィジェットを選択します。
   ![2024-12-13\_10-58-15 (1).gif](/images/moengage_c5ad55.png)
2. **Actions** セクションまでスクロールします。**\+ Action** をクリックします。
   ![2024-12-13\_11-01-57 (1).gif](/images/moengage_b98e5f.png)
3. **Custom** リストからアクションを選択します。
4. **\+ New KV pair** をクリックして、このアクションにキーと値のペアを追加します。
   ![2024-12-13\_11-04-06 (1).gif](/images/moengage_72547c.png)
5. **Key value pairs** で、**Enter name** フィールドにキーを、**Data** フィールドに値を入力します。

さまざまなアクションタイプでキーと値のペアを使用する方法は次のとおりです。

## ナビゲーションアクションにおけるキーと値のペア

ナビゲーションアクションを使用する場合、KV ペアはアプリ内の遷移先の画面または URL に追加の情報や指示を送信します。

#### ナビゲーションにキーと値のペアを使用する理由

- **パーソナライゼーション:** ユーザーの興味や行動に基づいて、特定のコンテンツへユーザーを誘導します。たとえば、`productId` を渡してユーザーを特定の商品ページへ誘導します。または、`email` アドレスを渡して、次のページのフォームにユーザーのメールアドレスを事前入力します。
- **動的コンテンツ:** アプリがコンテンツを動的に読み込んで表示できるようにし、ユーザー体験を向上させます。
- **トラッキングと分析:** `source` などのパラメーターを含めて、ナビゲーションの遷移元を追跡します。これはキャンペーンのパフォーマンスを把握するのに役立ちます。

**例:**

- キー: `productId`、値: `12345`
- キー: `source`、値: `inAppCampaign`
- キー: `email`、値: `{{UserAttribute['u_em']}}`

## イベントトラッキングアクションにおけるキーと値のペア

イベントをトラッキングする場合、KV ペアはイベント属性として機能します。これにより、イベントに関する詳細情報が提供されます。

#### イベントのトラッキングにキーと値のペアを使用する理由

- **分析の強化:** イベントデータを充実させ、ユーザー行動に関するより深いインサイトを得られます。
- **オーディエンスのセグメンテーション:** 詳細なイベント属性を使用して、今後のキャンペーン向けに精度の高いユーザーセグメントを作成できます。
- **自動アクションのトリガー:** 特定の KV ペアを設定して、フォローアップメッセージの送信など、MoEngage 内の自動マーケティングアクションをトリガーできます。

**例:**

イベント名: `ButtonClicked`

- キー: `buttonType`、値: `SubscribeButton`
- キー: `campaignId`、値: `promo_2024`

## カスタムアクションにおけるキーと値のペア

カスタムアクションの場合、開発者はキーと値のペアをカスタムパラメーターとして使用できます。これらのパラメーターはアプリのコードに渡され、特定の関数を実行します。

#### カスタムアクションにキーと値のペアを使用する理由

- **柔軟性:** 開発者は KV ペアを使用して柔軟なアクションを定義し、アプリのコードを変更せずに更新できます。
- **パーソナライズされたユーザー体験:** さまざまなパラメーターを渡して、個々のユーザーや特定のキャンペーン目標に合わせてアプリの動作を調整できます。
- **動的な更新:** アプリが最新の情報でアプリ内メッセージに応答できるようになり、エンゲージメントが向上します。

**例:**

アクション名: `OpenFeature`

- キー: `featureName`、値: `AugmentedRealityViewer`
- キー: `accessLevel`、値: `premium`

### トラブルシューティング

- **データ型の誤り:** 入力する値が、対応するキーに対してアプリが想定しているデータ型と一致していることを確認してください。データ型が正しくないと、アクションが失敗したり、データが誤って解釈されたりする可能性があります。
- **キーの不一致:** MoEngage で使用するキー名が、アプリのコードが想定しているものと完全に一致していることを確認してください。タイプミスや大文字・小文字の違いがあると、アプリがデータを認識できない場合があります。
- **アプリ側の実装:** キーと値のペアは、モバイルアプリのコード内で適切に処理する必要があります。アクションが期待どおりに動作しない場合は、これらのペアを受け取って使用するロジックを開発者が正しく実装しているか確認してください。

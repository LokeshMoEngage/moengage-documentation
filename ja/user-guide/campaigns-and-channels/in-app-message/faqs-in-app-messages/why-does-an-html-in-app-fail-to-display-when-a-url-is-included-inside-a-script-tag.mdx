## 問題

デバイス上で script タグを使用すると、HTML In-App が失敗する場合があります。

## 説明

- 一部の HTML In-App には、次の script タグが含まれています。

```text wrap
<script src="[https://kit.fontawesome.com/b6929c81b4.js](https://kit.fontawesome.com/b6929c81b4.js)"></script>
```

- このタグは、検証やその他の JavaScript 機能を有効にするための JavaScript コードを埋め込みます。
- この script タグを含む HTML In-App キャンペーンを公開すると、スクリーンショットに示すように、アプリで表示した際に例外が発生します。

<Frame>
  ![10](/images/10.png)
</Frame>

- `FileNotFound` 例外は、script タグ内の JavaScript ファイルの URL `https://kit.fontawesome.com/b6929c81b4.js` が無効であり、デバイス上で HTML In-App が読み込まれないことを示しています。

## 解決策

script タグに有効な JavaScript ファイルの URL を指定すると、例外が発生しなくなり、アプリを再度開いたときに HTML In-App が正常に表示されます。

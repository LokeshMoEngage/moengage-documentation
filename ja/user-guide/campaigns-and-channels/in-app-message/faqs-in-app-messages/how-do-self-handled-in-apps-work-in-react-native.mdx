---
title: "React Native でセルフハンドル型 In-App はどのように機能しますか？"
description: "MoEngage を使用した React Native でのセルフハンドル型アプリ内メッセージの仕組み（単一および複数回の呼び出し時のコールバック処理とイベントの順序を含む）について説明します。"
---

React Native のセルフハンドル型 In-App 機能では、アクティブなコールバックが完了した後にのみ、新しいイベントリスナーが設定されます。このアプローチにより、イベントが個別に処理され、コールバックの正しい順序と実行が維持されます。

仕組みは次のとおりです。

- **単一呼び出しのシナリオ**  
  アプリ内でセルフハンドル型 In-App メソッドが 1 回呼び出された場合、イベントリスナーはペイロードを 1 回だけ取得してログに記録します。以下は実装のサンプルスニペットです。

   <img alt="scenario 1b.png" src="/images/moengage_b22985.png" />
- **複数回呼び出しのシナリオ**  
  セルフハンドル型 In-App メソッドが短時間に連続して複数回呼び出された場合でも、React Native のイベント処理モデルにより、リスナーは 1 回だけ応答します。例:  
   <img alt="scenario 2a.png" src="/images/moengage_935906.png" />   
   <img alt="scenario 2b.png" src="/images/moengage_046739.png" />

このように順序立ててイベントを処理することは、アプリケーションの安定性と予測可能性を保つうえで非常に重要です。セルフハンドル型の各 In-App メッセージを 1 つずつ処理することで、開発者はすべてのメッセージが適切に管理されるようにでき、全体的なユーザー体験が向上します。

---

## 問題

In-App キャンペーンを表示するための標準のデフォルトメソッドはありますが、カスタムロジックに基づいてその表示を動的に制御することはできません。

## 説明

In-App メッセージを動的に非表示にできなかったカスタムロジックでは、Boolean 値を true または false に初期化しています。

```ruby
#val isInAppEnable = true
if(isEnable) {
showInApp()
}
val isInAppEnable = false
if(isEnable) {
showInApp()
}
```

## 解決策

次のいずれかの手順を実行します。

- イベントベースの In-App を使用して、特定の画面でのカスタムイベントに基づいて In-App メッセージを表示または非表示にします。
- 複数の画面を扱う場合は、画面名を指定したコンテキスト In-App を使用して、In-App メッセージの表示を切り替えます。

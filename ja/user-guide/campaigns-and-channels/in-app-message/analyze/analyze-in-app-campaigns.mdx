# はじめに

キャンペーン分析ページには、All campaignsページからIn-app Messagingキャンペーンを開いたとき、またはキャンペーンを公開したときにアクセスできます。このページを使用して、In-appキャンペーンのパフォーマンスを可視化できます。

<Info>
  - すべての指標は、アプリのタイムゾーンで計算および表示されます。
  - In-appの分析と情報は、**MoEngage Go**モバイルアプリでも確認できます。パフォーマンス統計の監視、コンバージョンの追跡、キャンペーン詳細の確認をスマートフォンから直接行えます。詳細については、[MoEngage Go](/ja/user-guide/moengage-go/moengage-go-overview)を参照してください。
</Info>

# In-app情報および分析ページへのアクセス

In-appキャンペーンの作成に成功すると、Campaign Infoページにリダイレクトされます。このページには、次の方法でもアクセスできます。

1. MoEngageダッシュボードの左側のナビゲーションメニューで、**Engage**をクリックし、**Campaigns**をクリックします。**All campaigns**ページが表示されます。
2. **Select channel**リストで、**In-app**を選択します。
   ![2025-04-01\_10-50-40 (1).gif](/images/moengage_4425bd.png)
3. 分析を表示するIn-appキャンペーンを選択します。
   ![2025-04-01\_10-56-20.png](/images/moengage_7d29f5.png)
   Campaign Infoページには次の情報が表示されます。
   - [キャンペーンの詳細](#campaign-details)
   - [分析](#analytics)
   - [クリック分析](#click-analysis)
   - [情報](#info)

# Campaign Details

![inapp details.png](/images/moengage_2dd14f.png)

このセクションでは、In-appキャンペーンの概要を確認できます。次の詳細が含まれます。

- キャンペーン名
- キャンペーンが作成されたプラットフォーム
- キャンペーンが作成された日時
- キャンペーンを作成したユーザー
- キャンペーンID
- プロジェクトID：キャンペーンに関連付けられたプロジェクトの一意の識別子です。このフィールドは、[Portfolio](/ja/user-guide/settings/account/portfolio/portfolio)が有効なワークスペースで作成されたキャンペーンでのみ使用できます。

このセクションから、キャンペーンの編集、複製、一時停止を行うことができます。

# Analytics

![analytics.png](/images/moengage_1cd836.png)

以下のセクションでは、In-Appキャンペーン分析ページのさまざまな構成要素について説明します。

## キャンペーン統計の集計

このセクションには、選択したフィルターに対する集計されたキャンペーン指標が表示されます。

### フィルター

次のフィルターを使用できます。

- **Date range**：選択した期間の指標が表示されます。
  ![Screenshot 2025-04-01 at 11.29.34 AM.png](/images/moengage_260fce.png)
- **Attribution type**：キャンペーンのコンバージョンを表示するには、**Attribution Type**リストで次のいずれかのアトリビューションタイプを選択します。
  - **View Through**：メッセージを表示した後にコンバージョンイベントが実行されたことを示します。
  - **Click Through**：メッセージをクリックした後にコンバージョンイベントが実行されたことを示します。
  - **In-session**：メッセージを表示してから30分以内にコンバージョンイベントが実行されたことを示します。 <img alt="Screen_Shot_2020-11-30_at_7.37.07_PM.png" src="/images/moengage_27d624.png" />
- **Platforms**：キャンペーン分析の指標を表示するプラットフォームを選択します。

キャンペーン統計の集計セクションには、キャンペーンの次の指標が表示されます。

- **Impressions**：このキャンペーンのメッセージが表示された回数です。
- **Clicks**：このキャンペーンのメッセージがクリックされた回数です。
  - **CTR**：クリック率で、CTR = Clicks/Impressionsとして計算されます。
- **Close**：このキャンペーンのメッセージが閉じられた回数です。
- **Conversion Events**：アトリビューションウィンドウ内で、このキャンペーンのメッセージを表示またはクリックした後にコンバージョンイベントが実行された合計回数です。この数値は、選択したアトリビューションタイプによって異なります。
- **Conversions**：このキャンペーンのメッセージを表示またはクリックした後にコンバージョンイベントが実行された合計回数です。この数値は、選択したアトリビューションタイプによって異なります。
  - **CVR**：コンバージョン率で、CVR = Conversions/Impressionsとして計算されます。

### キャンペーン収益

<Tip>
  キャンペーン分析で収益情報を確認するには、コンバージョンイベントで収益属性を有効にしてください。
</Tip>

主要なコンバージョン目標に加えて、収益属性を定義できます。この属性を設定すると、キャンペーン分析ページで次の指標を確認でき、キャンペーンによって生み出された正確な収益を把握できます。詳細については、[Schedule and Goals](/ja/user-guide/campaigns-and-channels/in-app-message/create/create-in-app-campaign)を参照してください。 <img alt="Screen_Shot_2020-11-30_at_7.40.58_PM.png" src="/images/moengage_f7f9eb.png" />

- **Total Campaign Revenue**：このキャンペーンによって生み出された総収益を表します。
- **Average Order Value**：このキャンペーンのコンバージョンイベントから生み出された平均収益を示します。Average Order Value = キャンペーンの総収益/コンバージョンイベントの総数です。
- **Average Revenue Per Converted User**：コンバージョンイベントを実行した各ユーザーによって生み出された総収益を表します。Average Revenue Per Converted User = キャンペーンの総収益/コンバージョンの総数です。

<Note>
  収益属性がオブジェクト配列内にある場合、MoEngageの計算結果が想定と一致しない可能性があります。詳細については、[オブジェクト属性を使用した収益トラッキング](/ja/user-guide/campaigns-and-channels/campaign-management-and-reports/conversion-and-attribution#how-revenue-is-calculated-for-object-array-attributes)を参照してください。
</Note>

## キャンペーンパフォーマンス

このセクションでは、キャンペーン指標の経時的な変化を可視化できます。

![Screen\_Shot\_2020-11-30\_at\_7.41.11\_PM.png](/images/moengage_9fa5d4.png)

次の操作を実行できます。

- キャンペーンパフォーマンスのインプレッション、クリック、コンバージョン、コンバージョンイベントを確認できます。これらは、上記のキャンペーン統計の集計セクションで説明したものと同様です。
- ヘッダーから期間、アトリビューションタイプ、プラットフォームを変更できます。時間軸はアプリのタイムゾーンに従って表示されます。
- **Table**ビューに切り替えて、時系列データを表形式で表示することもできます。
  ![2025-04-01\_12-10-01 (1).gif](/images/moengage_427865.png)
- セグメンテーションを使用して、_Mobile In-App Shown_イベントと_Mobile In-App Clicked_イベントでそれぞれフィルタリングすることで、In-appキャンペーンを受信したユーザーやクリックしたユーザーをセグメント化できます。

### 子キャンペーンのパフォーマンス

キャンペーンパフォーマンスセクションには、親キャンペーンのパフォーマンスに関する情報が含まれます。子キャンペーンの統計は、**Child campaign performance**セクションで確認できます。以下に示すように、**Recurrence**の横にある矢印アイコンをクリックするか、テーブルビューに切り替えてテーブル内のRecurrenceフィールドをクリックすることで、各子キャンペーンの分析を表示できます。

子キャンペーンの分析および情報ページは新しいタブで開き、編集、一時停止、複製はできません。ただし、これらの操作は親キャンペーンから行うことができます。

![InApp\_Periodic.gif](/images/moengage_80beb2.png)

## コンバージョン目標の統計

このセクションでは、各コンバージョン目標のパフォーマンスを可視化できます。In-appキャンペーンには最大5つのコンバージョン目標を追加でき、このセクションで各コンバージョン目標のパフォーマンスを確認できます。

![Screen\_Shot\_2020-11-30\_at\_7.41.21\_PM.png](/images/moengage_edd580.png)

ここで、**(Primary)**と表示されている目標が主要なコンバージョン目標です。前のセクションでは主要なコンバージョン目標の集計のみが表示されますが、このセクションでは各コンバージョン目標のパフォーマンスを確認できます。

このセクションの左上にあるカードにも主要なコンバージョン目標のパフォーマンスが表示されます。これはキャンペーンのパフォーマンスを示す主要な指標としても扱われます。

右上から時系列ビューに切り替えて、データの経時的な推移を確認できます。

## キャンペーン配信統計

このセクションでは、さまざまなキャンペーン配信の失敗とその理由について説明します。エラーは次の項目に分類されます。

| 失敗の種類 | 理由 | 説明 |
| --- | --- | --- |
| Selection Failure | Higher priority campaign available | より優先度の高いキャンペーンが利用可能だったため、このキャンペーンは選択されませんでした。キャンペーンの優先度をcriticalに設定すると、他のすべてのキャンペーンよりも優先して選択されるようになります。 |
|  | Maximum Times Shown | キャンペーンの最大表示回数の上限を超えてしまうため、メッセージは表示されませんでした。詳細については、[Maximum Times Shown](https://moengage.com/docs/user-guide/campaigns-and-channels/on-site-message/analyze/campaign-delivery-mobile-in-app-and-on-site-messaging-campaigns)を参照してください。 |
|  | Minimum Delay Condition | キャンペーンで設定されたキャンペーン間の最小遅延の条件を満たさなかったため、メッセージは表示されませんでした。詳細については、[Minimum Delay Between In-App Campaigns](https://moengage.com/docs/user-guide/campaigns-and-channels/in-app-message/create/create-in-app-campaign)を参照してください。 |
|  | Global Delay Condition | In-appキャンペーンに対してグローバルに設定されたキャンペーン間の最小遅延の条件を満たさなかったため、メッセージは表示されませんでした。詳細については、[Global Delay Between In-App Campaigns](https://moengage.com/docs/user-guide/settings/channels/delivery-controls/minimum-delay-between-campaigns)を参照してください。 |
|  | Screen Mismatch | ユーザーが、このキャンペーンのトリガー条件で指定された画面とは異なる画面にいたため、メッセージは表示されませんでした。 |
|  | Context Mismatch | ユーザーが、このキャンペーンの_show in app context_で指定されたものとは異なるアプリコンテキストにいたため、メッセージは表示されませんでした。詳細については、[App Context](https://moengage.com/docs/user-guide/campaigns-and-channels/in-app-message/create/contextual-in-app-messages)を参照してください。 |
|  | Campaign Expired | キャンペーンの有効期限が切れていたため、メッセージは表示されませんでした。 |
|  | Unsupported Orientation | ユーザーのデバイスの向きがテンプレートで指定されたものと異なっていたため、メッセージは表示されませんでした。たとえば、一部のIn-appテンプレートには縦向きや横向きなどの特定の向きが設定されている場合があります。ユーザーのデバイスの向きが指定された向きと異なる場合、メッセージは表示されません。 |
|  | In-App Blocked | 開発者がアプリ内でその画面のIn-appメッセージをブロックしていたため、メッセージは表示されませんでした。 |
|  | User not on Android 13 or already opted in | ユーザーがAndroid 13のOSバージョンを使用していなかったか、すでにAndroid 13のプッシュ通知をオプトインしていたため、メッセージは表示されませんでした。これは、2ステップのオプトインにIn-app通知を使用する場合に該当します。詳細については、[Push Opt-ins](https://moengage.com/docs/user-guide/campaigns-and-channels/mobile-push/notification-features-and-behavior/android-push-permission-and-reachability)を参照してください。 |
| Delivery Failure | API failure | API側で障害が発生した場合に発生します。 |
|  | Personalization failure | パーソナライゼーションで使用される属性が特定のユーザーで利用できない場合に発生します。 |
|  | Campaign Paused | 実行中のIn-appキャンペーンが一時停止された場合に発生します。 |
|  | Campaign Under Review | 承認者がIn-appキャンペーンをレビュー中の状態に移行した場合に発生します。キャンペーンのレビュー、承認、却下は、キャンペーン承認フロー（CAF）が有効な場合にのみ行えます。詳細については、[CAF](https://moengage.com/docs/user-guide/settings/account/team-management/campaign-approval-workflow)を参照してください。 |
|  | Campaign Rejected | 承認者がIn-appキャンペーンを却下済みの状態に移行した場合に発生します。キャンペーンのレビュー、承認、却下は、キャンペーン承認フロー（CAF）が有効な場合にのみ行えます。詳細については、[CAF](https://moengage.com/docs/user-guide/settings/account/team-management/campaign-approval-workflow)を参照してください。 |
|  | Missing parameters | キャンペーンで使用されている一部のパラメーターが欠落している場合に発生します。 |
|  | Campaign archived | 実行中のキャンペーンがアーカイブされた場合に発生します。 |
|  | Campaign control group | ユーザーがIn-appキャンペーンの対象条件を満たしているものの、キャンペーンのコントロールグループに該当するため、ターゲットオーディエンスから除外された場合に発生します。 |
|  | Global control group | ユーザーがIn-appキャンペーンの対象条件を満たしているものの、グローバルコントロールグループに該当するため、ターゲットオーディエンスから除外された場合に発生します。 |
| Display Failure | Another campaign visible | 同時に別のキャンペーンがすでに表示されていたため、メッセージは表示されませんでした。 |
|  | Image failure | 画像のダウンロードに失敗したため、メッセージは表示されませんでした。 |
|  | GIF failure | 必要なGIFライブラリがアプリに統合されていないため、メッセージは表示されませんでした。 |
|  | Height exceeded | メッセージの高さがデバイスの高さを超えたため、メッセージは表示されませんでした。 |
|  | Internal server error | 内部エラーが発生したため、メッセージは表示されませんでした。 |
|  | File download failure | ファイルがダウンロードされなかったため、メッセージは表示されませんでした。 |

## フォーム入力

ダッシュボードの**Form Inputs**セクションに移動すると、ユーザーがキャンペーンを操作した際に送信した回答を確認できます。これらの回答には、アンケートや入力フィールドを含むテンプレートなどが含まれる場合があります。詳細については、[Add Forms to your In-app Campaign](/ja/user-guide/campaigns-and-channels/in-app-message/templates/drag-and-drop-editor/add-forms-to-your-in-app-campaign)を参照してください。

次の詳細を確認できます。

- **Locales**：ロケールはデフォルトに設定されていますが、リストから変更できます。
- **Variations**：リストで特定のバリエーションを選択すると、対応する指標が表示されます。
- **Total rows**：回答を送信したユーザーの総数です。リストから次の属性に基づいてユーザーをフィルタリングできます。
  - **User ID**
  - **Name**
  - **Email**\
    ![form input filter attributes.png](/images/moengage_5097e6.png)
- 各ユーザー属性に対する回答は、隣接する列に表示されます。たとえば、ID「x1z2y3」のユーザーが「[xyz@gmail.com](mailto:xyz@gmail.com)」をメールアドレスとして使用して回答を送信したとします。リストで_User ID_を選択すると、分析ページにはユーザーID「x1z2y3」と対応する回答「[xyz@gmail.com](mailto:xyz@gmail.com)」が表示されます。同様に、リストで_Name_または_Email_を選択すると、ユーザーの名前またはメールアドレスと対応する回答が表示されます。
  <Info>
    - 回答はiOSとAndroidの両方がまとめて表示されます。プラットフォームに基づいて回答をフィルタリングすることはできません。データを個別に表示したい場合は、iOSとAndroidで異なる属性をトラッキングするようにしてください。
    - Form inputsテーブルには最大7つの属性が表示されます。すべての属性を表示するには、次の手順を実行します。
      1. MoEngageダッシュボードの左側のナビゲーションメニューで、**Segment**をクリックし、**Create segment**をクリックします。
      2. **Filter users by**タブで、**User behavior**をクリックします。
      3. _Has Executed_を選択し、_Response Submitted_イベントを選択します。
      4. イベントの期間とキャンペーンIDを指定して、キャンペーンに回答を送信したユーザー数をより正確に取得します。
      5. **Show count**をクリックして結果を分析します。
      6. **Query Results**の下に、キャンペーンに回答を送信したユーザー数が表示されます。
  </Info>
- ユーザーの回答を含むCSVファイルをダウンロードすることもできます。
  ![download csv file form inputs.gif](/images/moengage_f7b3c7.png)
  <Warning>
    エクスポートできる属性は最大10個までです。より絞り込んだデータを取得するには、期間、ロケール、バリエーションのフィルターを使用してください。
  </Warning>

# Click Analysis

ユーザーがIn-appメッセージのどこを正確にクリックしているかを知るには、**Click analysis**タブを参照してください。ここでは、In-appメッセージの各ウィジェットのクリック指標を確認できます。期間、バリエーション、ロケール、プラットフォームで結果をフィルタリングできます。

![Screenshot 2024-10-01 at 4.53.07 PM.png](/images/moengage_a9a127.png)

ウィジェットをクリックしたユーザーのセグメントを作成するには、省略記号メニューをクリックし、**Create segment**を選択します。そこから、セグメントを作成したり、新しいキャンペーンの作成やセグメントの分析など、さらなるアクションを実行したりできます。

![ScreenRecording2024-10-01at4.53.28PM-ezgif.com-video-to-gif-converter.gif](/images/moengage_4533a1.png)

# Info

**Info**タブでは、次の情報を確認できます。

- キャンペーンの優先度を含む通知のプレビュー。
- キャンペーンのセグメンテーション条件。
- キャンペーンのトリガーアクション。キャンペーンがいつ、どのようにトリガーされるかを示します。
- キャンペーンの目標。キャンペーンに関連付けられたコンバージョン目標が表示されます。
- キャンペーンの配信スケジュール。定期キャンペーンの場合は、周期、キャンペーンのアクティブウィンドウ（スケジュールされた実行期間中にキャンペーンがユーザーに表示される時間帯）、開始時刻、終了時刻、次回の実行、タイムゾーンの情報が表示されます。
- キャンペーンの配信コントロール。キャンペーンの表示回数、グローバル遅延設定、キャンペーン間の最小遅延時間、自動非表示設定などが含まれます。

![InApp\_PeriodicCampaignsInfo (2).png](/images/moengage_e3d991.png)

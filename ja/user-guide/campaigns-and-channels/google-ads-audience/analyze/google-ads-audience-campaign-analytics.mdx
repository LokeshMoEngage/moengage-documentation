# キャンペーン分析

<Info>
  MoEngageは、すべてのメトリクスをアプリのタイムゾーンで計算して表示します。
</Info>

このセクションでは、Campaign Analyticsで利用できるメトリクスについて説明します。

| フィールド | 説明 |
| --- | --- |
| Eligible users | 以下に基づいてキャンペーンの対象となるユーザー数: <ol><li>定義されたセグメンテーション条件およびトリガー条件（該当する場合）を満たしていること。</li><li>プロファイルに有効な識別子（Device ID、Mobile Number、またはEmail）があること。</li></ol> |
| Attempted | MoEngageがGoogle Ads APIにデータを送信したユーザー数。 |
| Successfully synced | 試行されたユーザーのうち、データがGoogle Adsオーディエンスに正常に追加されたユーザー数。  注: GoogleのAPIはオーディエンスデータを非同期で同期します。MoEngageは、Google Ads APIからの2xxレスポンスをCustomer Listオーディエンスへの追加成功とみなします。 |
| Failed to add | 試行されたユーザーのうち、内部または外部の理由によりデータをGoogle Adsオーディエンスに追加できなかったユーザー数。詳細については、Campaign Failure Breakdownを参照してください。 |
| Conversions | 正常に同期されたユーザーのうち、アトリビューションウィンドウ内にコンバージョンイベントを実行したユーザーのユニーク数。 |
| Conversion events | 正常に同期されたユーザーがアトリビューションウィンドウ内に実行したコンバージョンイベントの総数。 |

<Info>
  キャンペーン作成時のConversion Goalの設定は任意です。MoEngageは、Conversion Goalを設定した場合にのみ、これらのコンバージョンメトリクスを追跡して表示します。
</Info>

## 配信タイプ別のキャンペーンデータについて

### 標準キャンペーンのメトリクス

上の表に記載されているメトリクスは、すべてのキャンペーン配信タイプに適用されます。

### 定期キャンペーンのメトリクス

定期キャンペーンでは、親キャンペーンの全体的なメトリクスを表示できます。子キャンペーン（キャンペーンが実行された各インスタンス）ごとのメトリクスは、別の表に表示されます。

## キャンペーンパフォーマンスの分析

### キャンペーン統計をフィルタリングする

定期キャンペーンおよびイベントトリガーキャンペーンのキャンペーン統計は、以下のオプションを使用してフィルタリングできます。

1. **Aggregation Type:** **Total** または **Average** を選択します。
2. **Date Range:** キャンペーンインスタンスのデータを表示する期間を選択します。

### Time Trendsを表示する

Time Trendsセクションには、アトリビューションウィンドウの詳細を含め、キャンペーンメトリクスが時間の経過とともにどのように推移するかが表示されます。

![Time\_Trends.png](/images/moengage_26c657.png)

### Campaign Failure Breakdownについて

いずれかのユーザーに対してキャンペーンが失敗した場合、Campaign Failure Breakdownセクションに失敗の理由がエラーテーブルで表示されます。

![Campaign\_failure\_breakdown.png](/images/moengage_fc4954.png)

#### 一般的な失敗理由

このセクションでは、キャンペーンが失敗する原因となるエラーの種類を示します。

##### アクセスおよびログインのエラー

- Googleログインが無効です。
- アクセストークンの有効期限が切れているか、無効です。
- Google Adsアカウントへのアクセス権限が拒否されました。
- Google Adsの権限が不十分です。Google Adsのアクセススコープを確認してください。

これらのエラーは、アクセス権限が不十分であるか、認証情報が無効であることを示しています。アカウントが有効であり、Google Adsアカウントに対する管理者または標準のアクセス権限があることを確認してください。

##### データ関連の失敗

- Google Ads Audience Syncの対象となるユーザーがいません。
- Google AdsアカウントのCustomer IDが無効です。

##### API/サービス関連のエラー

これらの失敗は、Googleへのデータアップロード時の問題、Googleから返される一般的なエラー、または接続の問題が原因で発生する可能性があります。これには、MoEngageまたはGoogleのいずれかにおけるサービス停止も含まれます。

# キャンペーン情報

Campaign Infoセクションには、キャンペーンに関する以下の詳細が表示されます。

| フィールド | 説明 |
| --- | --- |
| Segmentation | キャンペーンのターゲットユーザーセグメント。 |
| Qualification Criteria | ユーザーがキャンペーンの対象となるために満たす必要があるフィルターと条件。 |
| Google Ads Audience | オーディエンスをGoogle Adsのカスタムオーディエンスに追加するか、削除するか。 |
| Campaign Goals | キャンペーンに設定された目標。 |
| Delivery Schedule | キャンペーンインスタンスの開始時刻と終了時刻。 |

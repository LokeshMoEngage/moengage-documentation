Cards は、パーソナライズされたキャンペーン、オファー、レコメンデーションを配信するための独自のカスタマイズ可能なエンゲージメントチャネルです。Card はユーザーのアプリの受信箱やニュースフィードに保持され、ユーザーの作業の流れを妨げません。MoEngage Cards Inbox または Self-handled Cards を使用して、アプリケーション上のユーザーに Card キャンペーンを配信できます。

| --- | --- |
| <img src="/images/moengage_e159c3.png" alt="MoENgageCards.png" /> | <img src="/images/moengage_21663e.png" alt="self handled.png" /> |

<Info>
  - MoEngage Cards Inbox は MoEngage Push Notification Center とは異なります。どちらもコンテンツ配信用の受信箱として機能しますが、配信先が同じ場所にあるとは限りません。
  - Card は **Cards Inbox** 内に表示され、プッシュ通知は **Notification Inbox** に表示されます。詳細については、[プッシュ通知](https://www.moengage.com/docs/developer-guide/ios-sdk/push/basic/push-notifications)を参照してください。
</Info>

## メリット

- **永続的なメッセージング** - プッシュ通知、SMS、In-app 通知などの他のチャネルとは異なり、Card は一度配信されると、長期間にわたってユーザーのアプリ体験の一部として残ります。Card を使用すると、ユーザーはいつでも都合のよいときにアプリにアクセスしてコンテンツを参照できます。そのため、Card はブランドからのあらゆるコミュニケーションの集約場所として、他のチャネルと組み合わせるのに最適です。
- **オプトイン不要**: 他のチャネルとは異なり、Card はアプリ体験の一部であるため、ユーザーからの許可は必要ありません。
- **簡単なセグメンテーション、トリガー、パーソナライズ**: Card では、MoEngage が提供する優れたパーソナライズ機能とセグメンテーション機能をすべて利用できます。これにより、適切なユーザーに適切なタイミングで意図したメッセージを届けることができます。
- **インタラクションデータ**: Card の分析を MoEngage で追跡できます。
- **邪魔にならない**: Card はユーザーのアプリ体験のネイティブな一部として表示され、ユーザーを妨げません。これによりユーザーの受容性が高まり、エンゲージメントが向上します。

## ユースケース

- オファーとプロモーション
- ゲーミフィケーションとコンテストへの参加登録
- リマインダーとヒント、ポリシーおよび利用規約の変更
- 取引とサービスの更新情報
- カート/ウィッシュリストのリマインダー
- レコメンデーション

## Cards の配置と配信

MoEngage は、カスタマイズ可能で統合しやすい App Inbox を提供し、さまざまなプラットフォーム([Android](https://www.moengage.com/docs/developer-guide/android-sdk/cards/cards#install-using-bom)、[iOS](https://www.moengage.com/docs/developer-guide/ios-sdk/cards/cards-in-i-os#sdk-installation)、[Web](https://www.moengage.com/docs/developer-guide/web-sdk/cards/cards#sdk-installation))でアプリケーションを利用するユーザーへの Card の配信、表示、管理を行います。以下のいずれかの方法を使用して、アプリケーション上のユーザーに Card を配信できます。

    | **Cards UI** | スタイルオプションを使用して、Basic Card および Illustration Card のテンプレートとともに、Inbox(フィード)の UI を変更し、ブランドガイドラインに合わせてカスタムフォント、テーマカラー、ラベルを設定できます。<br /><img alt="MoENgageCards.png" src="/images/moengage_e159c3.png"style={{ width: "120px" }} /> |

  ### MoEngage Cards Inbox の UI

  この UI は、実装時に以下のようにブランドテーマの要件に合わせてカスタマイズできます。

    - ラベル(フィードページのタイトル)。
    - 背景テーマ。
    - カテゴリタブ - フォント、フォントサイズ、選択時/非選択時のタブのテキスト色、選択時/非選択時のタブの背景色。
    - Card のヘッダー、メッセージ、Call to Action ボタン(CTA)、タイムスタンプのデフォルトスタイル。
    - Card のデフォルトの背景色。
    - 未クリック Card のインジケーターの色。
    - 受信箱が空の状態のコンテンツ。

  ### Cards の配信期間

  Card がユーザーに対して作成または更新されると、Card サーバーとの次回の同期で配信できる状態になります。同期は以下のように行われます。

    |  |  |
    | --- | --- |
    | **次回のアプリオープン時** | ユーザーがアプリを開き、直近 45 分以内に前回の同期が行われていない場合、受信箱が同期されます。 |
    | **次回の受信箱オープン時** | ユーザーが受信箱を開き、直近 5 分以内に前回の同期が行われていない場合、受信箱が同期されます。 |
    | **次回のプルして更新時** | ユーザーがプルして更新し、直近 5 秒以内に前回の同期が行われていない場合、受信箱が同期されます。 |

  ### Cards の配信期間

  Card がユーザーに対して作成または更新されると、Card の取得リクエストが送信されるたびに Card が取得されて送信されます。同期は以下のように行われます。

    |  |  |
    | --- | --- |
    | **次回の Card 取得リクエスト時** | Card の取得リクエストが送信され、直近 45 分以内に前回の同期が行われていない場合、受信箱が同期されます。 |
    | **次回の同期付き Card 取得リクエスト時** | 直近 5 分以内に前回の同期が行われていない場合、受信箱が同期されます。 |
  </Tab>

    |  |  |
    | --- | --- |

    | **Cards UI** | カスタム UI  <img src="/images/moengage_ad0565.png" style={{ width: "120px" }}/> |
    | **分析の追跡** | サポートされていません。 |
    | **最適な対象** | 以下を行いたいチーム: <ul><li>独自のカスタム Inbox(フィード)UI を作成する。</li><li>アプリのコンテンツに合わせたアプリウィジェット、バナー、コンテンツカルーセルを作成する。- Card のペイロードを外部システムに送信する。</li></ul> |
    | **サポートされるプラットフォーム** | サーバーベースであり、SDK は不要です。 |

  ### Cards の配信期間

  Card がユーザーに対して作成または更新されると、Card の取得リクエストが送信されるたびに Card が取得されて送信されます。これは前回の取得には依存しません。サーバーサイドの実装であるため、受信したデータに基づいて受信箱を同期する必要があります。

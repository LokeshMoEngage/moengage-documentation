---
title: "Cards はどのように SDK に同期されますか?"
description: "アプリ起動時のサーバーリクエストからローカルストレージへの保存と表示、自動更新のトリガーまで、MoEngage Cards が SDK に同期される仕組みを説明します。"
---

MoEngage Cards は、以下のプロセスで SDK に同期されます。

1. アプリが MoEngage SDK を初期化すると、MoEngage サーバーに接続します。
2. SDK は最新の Card を取得するために、MoEngage サーバーにネットワークリクエストを送信します。
3. サーバーは、コンテンツとメタデータを含む Card データのペイロードで応答します。
4. SDK は取得した Card データをデバイスのローカルに保存します。
5. その後、アプリはこのローカルに保存されたデータを使用してユーザーに Card を表示します。SDK は、アプリが開かれたときや特定のトリガー(アプリの再開や特定のイベントなど)が発生したときに、このプロセスを繰り返して Card データを更新する場合があります。

この同期メカニズムにより、アプリの受信箱には常に最新の Card コンテンツが保持されます。

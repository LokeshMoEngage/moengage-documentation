title: "MoEngage SDK はいつ Card データを同期しますか?"
description: "MoEngage SDK は、アプリ起動時から 45 分ごとに Card データを同期します。Card を手動で更新する方法と、Self-handled Card の更新の扱い方を説明します。"
---

## 同期のタイミング

- MoEngage SDK は、新しく公開された Card を取得するために、45 分ごとに自動的に API を呼び出します。
- 最初の API 呼び出しはアプリ起動時に行われ、その後は 45 分ごとに呼び出されます。
- MoEngage が提供する UI を開くと、ローカルストレージに保存されている Card が表示されます。
- コンテンツを手動で更新するには、画面を更新します。5 秒以内に API がトリガーされ、最新の Card が取得されます。
- Self-Handled Card の場合:
  - `getCards()` はローカルストレージから Card を取得します。ローカルストレージは 45 分ごとの API 呼び出しに基づいて更新されます。そのため、新しく取得された Card が表示されるまでに最大 45 分の遅延が発生する場合があります。
  - `fetchCards()` は API 呼び出しを直接トリガーして、サーバーから最新の Card を取得し、ローカルストレージを更新します。この関数は、前回の API 呼び出しから 5 分以上経過している場合にのみ使用できます。5 分以内に使用した場合は、ローカルストレージからのみ Card を取得します。ほとんどの場合、`fetchCards()` のほうが最新のコンテンツをすばやく取得できます。

## 送信の追跡

- Sent ステータスは、ユーザーがアプリの受信箱を開いたかどうかにかかわらず、MoEngage サーバーがユーザーに Card キャンペーンを正常に送信したときに追跡されます。

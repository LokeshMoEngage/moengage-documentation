この記事では、MoEngage の Push Amplification™ ソリューションの最初のバージョンである Push Amplification™ と、それがキャンペーンのリーチやインプレッションに与える影響について説明します。

<Info>
  Push Amplification™ の効果がダッシュボードに表示されるのは、2020 年 4 月 3 日 12:00 AM GMT 以降に作成されたキャンペーンのみです。
</Info>

## Push Amplification™ とは何か、どのように機能するのか

Push Amplification™ は、FCM による通知配信が失敗した場合に使用されるフォールバック配信サービスです。通知の配信が失敗すると、Push Amplification™ はその失敗を検出し、通知をアプリユーザーのデバイスに直接配信します。これにより、FCM では届かなかったはずのユーザーにリーチできます。Push Amplification™ の詳細については、こちらの[ページ](https://www.moengage.com/push-amplification/)を参照してください。

![mceclip0.png](/images/moengage_81d3b9.png)

アカウントで Push Amplification™ を有効にするには、MoEngage のカスタマーサクセスマネージャー (CSM) またはサポートチームにお問い合わせください。

<Info>
  - Push Amplification™ は Android でのみ機能します。One-Time Push、Periodic Push、Event-Triggered Push、Location-Triggered Push、および Flows キャンペーンを使用して送信される Push で利用できます。
  - Device-Triggered Push には適用されません。
</Info>

## Push Amplification™ によるアップリフトの測定

アカウントで Push Amplification™ が正常に有効化された後、キャンペーンを設定すると、そのキャンペーンのインプレッションとクリックに対する Push Amplification™ の効果を測定できます。キャンペーンの送信後、**Campaign** \> **Analytics** に移動し、Platform として Android を選択します。

![mceclip0.png](/images/moengage_c078e2.png)

Push Amplification™ による貢献は黄色で表示されます。ドーナツグラフの黄色と緑色の部分にカーソルを合わせると、FCM で得られたインプレッションに対して Push Amplification™ で得られたインプレッション数を確認できます。クリックのドーナツグラフについても同様です。

各ドーナツグラフの下には、Push Amplification™ による % アップリフトが表示されます。% アップリフトの数値にカーソルを合わせると、FCM による個別の貢献と合計の貢献を確認できます。

![mceclip1.png](/images/moengage_6954c9.png)

## アップリフトの計算方法

このセクションでは、アップリフトの計算に使用される数式について説明します。

<Tabs>
  <Tab title="インプレッションのアップリフト">
  ![mceclip2.png](/images/moengage_befad9.png)

  すべての計算の基準は FCM です。インプレッションの % アップリフトは、まずキャンペーン配信率における Push Amplification™ の貢献を算出し、それを FCM の配信率で割って計算します。ここでの配信率とは、インプレッション数 / 送信された通知数です。

  次の数式は、キャンペーン配信率における Push Amplification™ の貢献の計算方法を示しています。このために、キャンペーン全体の配信率から FCM によるキャンペーン配信率への貢献を差し引きます。

  ![mceclip3.png](/images/moengage_70e1f4.png)

  ![Screenshot\_2020-04-07\_at\_1.50.34\_PM.png](/images/moengage_e770fd.png)

  </Tab>
  <Tab title=" クリックのアップリフト">
  クリックのアップリフトを追跡するには、アプリの SDK バージョンが 9802 以降であることを確認してください。クリックの追跡は SDK バージョン 9802 以降でのみ利用可能です。このため、計算されたアップリフトは実際のクリックのアップリフトよりも低くなる場合があります。

  ![mceclip4.png](/images/moengage_895da2.png)

  クリックの % アップリフトは、インプレッションのアップリフトと同じロジックで計算されます。つまり、まずキャンペーンで得られた全クリックにおける Push Amplification™ の貢献を算出し、それを FCM 経由のクリック数で割って計算します。
  </Tab>
</Tabs>

<Info>
  - コンバージョンおよびコンバージョンゴールのアップリフトは現在利用できません。MoEngage はこれらの機能に取り組んでおり、近日中に利用可能になる予定です。
  - Push Amplification™ は Android ベースの機能であるため、インプレッションとクリックのアップリフトは Android にのみ適用されます。
  - 全体的なレベルでの Push Amplification™ の効果を示すため、All Platforms のインプレッションのアップリフトを表示しています。ただし、Android のクリックのアップリフトと All Platforms のクリックのアップリフトは常に同じであるため、All Platforms ではクリックのアップリフトは表示されません。
  - Push Amplification™ のデータとアップリフトは All Locales について表示されます。現在、Push Amplification™ のロケール別データは追跡していません。
  - Push Amplification™ のクリック追跡は SDK バージョン 9.8.02 以降でのみ開始されたため、クリックのアップリフトは実際のアップリフトよりも低くなる場合があります。
  - Push Amplification™ はバックアップ配信サービスであるため、Push Amplification™ を通じて試行された通知は送信数にカウントされません。ただし、ユーザーが Push Amplification™ を通じて通知を受信した場合、インプレッションはカウントされます。そのため、インプレッション数が送信数を上回る場合があります。\
  例: あるキャンペーンで "Google Authentication Error (GAE)" のためにすべてのユーザーのデバイスへの通知送信が失敗した場合、送信数は 0 になります。しかし、Push Amplification™ によって配信されるため、このキャンペーンでインプレッションとクリックが発生する場合があります。
</Info>

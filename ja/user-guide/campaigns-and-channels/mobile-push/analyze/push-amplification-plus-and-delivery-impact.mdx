# 概要 - Push Amplification™ Plus

この記事では、MoEngage の高度な Push Amplification™ ソリューションである Push Amplification™ Plus と、それがキャンペーンのリーチやインプレッションに与える影響について簡単に説明します。

![new2.png](/images/moengage_09420f.png)

MoEngage の Push Amplification™ ソリューションの最初のバージョンの詳細については、[Push Amplification™ と配信への影響](/ja/user-guide/campaigns-and-channels/mobile-push/analyze/push-amplification-and-delivery-impact)を参照してください。

<Info>
  Push Amplification™ Plus の効果がダッシュボードに表示されるのは、2020 年 4 月 3 日 12:00 AM GMT 以降に作成されたキャンペーンのみです。
</Info>

## Push Amplification™ が必要な理由

プッシュ通知は、モバイルアプリのユーザーとエンゲージするための信頼性の高い手段です。エンゲージメントやリテンションのプログラムを成功させるために、マーケターはキャンペーンのリーチを最大化したいと考えています。しかし Android の場合、40～70% のユーザーに通知が届きません。送信した通知をユーザーが受信できない理由は複数あります。詳細については、[送信したプッシュ通知をユーザーが受信できない理由](/ja/user-guide/campaigns-and-channels/mobile-push/troubleshooting-and-faqs-mobile-push/why-arent-end-users-receiving-push-notifications)を参照してください。

Push Amplification™ Plus は、マーケターがプッシュ通知の配信を改善し、より多くのユーザーにメッセージを届けられるよう支援します。

## Push Amplification™ Plus とは

Push Amplification™ Plus は、MoEngage の業界初の Push Amplification™ ソリューションである Push Amplification™ の高度なバージョンで、Android デバイスメーカー全体でプッシュ通知の配信率を最大 40% 向上させるように設計されています。さらに、Xiaomi デバイスではプッシュ配信率が最大 75% 向上したという実績がお客様から報告されています。

Push Amplification™ Plus は、次の 2 つのサービスを組み合わせたものです。

- 対象となるデバイス向けの強化されたプッシュ通知配信サービス
- FCM による通知配信が失敗した場合に使用されるフォールバック配信サービス ([Push Amplification™ と呼ばれます](/ja/user-guide/campaigns-and-channels/mobile-push/analyze/push-amplification-and-delivery-impact))

## Push Amplification™ Plus の仕組み

マーケターは、キャンペーンの送信時に Push Amplification™ Plus を使用するかどうかを選択できます。Push Amplification™ Plus を使用するキャンペーンでは、ターゲットセグメントから Push Amplification™ Plus でリーチ可能な対象デバイスが特定されます。これらの対象デバイスには、Push Amplification™ Plus によって直接通知が送信されます。Push Amplification™ Plus による配信率は FCM よりも高いため、これらのデバイスは FCM の対象にはなりません。

ターゲットセグメント内で Push Amplification™ Plus サービスの対象外となる残りのデバイスには、FCM を通じて通知が送信されます。FCM の配信が失敗すると、Push Amplification™ が動作を開始します。Push Amplification™ は通知配信の失敗を検出し、FCM のフォールバックとして機能して、ユーザーのデバイスに通知を配信します。これにより、マーケターは FCM では届かなかったはずのユーザーにリーチできます。その結果、リーチが拡大し、全体の配信率が最大 40% 向上します。詳細については、こちらの[ページ](https://www.moengage.com/push-amplification/)を参照してください。

## Push Amplification™ Plus を有効にする方法

アカウントで Push Amplification™ Plus を有効にするには、MoEngage のカスタマーサクセスマネージャー (CSM) またはサポートチームにお問い合わせください。

アカウントで Push Amplification™ Plus が正常に有効化された後は、キャンペーンレベルで Push Amplification™ Plus を使用できます。つまり、一部の Push キャンペーンでは Push Amplification™ Plus を有効にし、他のキャンペーンでは使用せずに、Push Amplification™ Plus を使用していないキャンペーンと全体の配信を比較できます。

キャンペーンで Push Amplification™ Plus を使用するには、次の手順に従います。

1. **Target user** ページで、プラットフォームとして Android を選択します。
2. **Send this campaign using Push Amplification™ Plus** チェックボックスを選択します。

![Targetplatform\_AMP%2B.png](/images/moengage_3a7f19.png)

<Info>
  - Push Amplification™ は Android でのみ機能します。One Time Push、Periodic Push、Event-Triggered Push、Location-Triggered Push、および Flows キャンペーンを使用して送信される Push で利用できます。
  - Device-Triggered Push には適用されません。
  - Push Amplification™ Plus は Push Amplification™ の高度なバージョンであるため、Push Amplification™ Plus を有効にすると Push Amplification™ も有効になります。
</Info>

## Push Amplification™ Plus によるアップリフトの測定

アカウントで Push Amplification™ Plus が正常に有効化された後、キャンペーンを設定すると、そのキャンペーンのインプレッションとクリックに対する Push Amplification™ Plus の効果を測定できます。キャンペーンの送信後、**Campaign** \> **Analytics** に移動し、Platform として Android を選択します。

![mceclip0.png](/images/moengage_267e43.png)

Push Amplification™ Plus による貢献は黄色で表示されます。ドーナツグラフの黄色と緑色の部分にカーソルを合わせると、FCM で得られたインプレッションに対して Push Amplification™ Plus で得られたインプレッション数を確認できます。クリックのドーナツグラフについても同様です。

各ドーナツグラフの下には、Push Amplification™ Plus による % アップリフトが表示されます。% アップリフトの数値にカーソルを合わせると、FCM による個別の貢献と合計の貢献を確認できます。

![mceclip1.png](/images/moengage_febb13.png)

一部のキャンペーンでは、Push Amplification™ Plus によるこれらの指標への貢献があるにもかかわらず、インプレッションまたはクリックのグラフの下に % アップリフトの値が表示されない場合があります。これは、Push Amplification™ Plus による % アップリフトが 0 であるため、ダッシュボードに表示されないことを意味します。

次の例では、インプレッションには正の % アップリフトがあります。しかし、クリックデータへの Push Amplification™ Plus の貢献は非常に小さいため、無視できるほど、つまり 0 % のアップリフトとなっています。

![mceclip0.png](/images/moengage_362767.png)

Push Amplification™ Plus を無効にしてキャンペーンを作成した場合、Push Amplification™ Plus の対象となるデバイスも含めて、キャンペーンは FCM によって配信されます。FCM の配信が失敗した場合、アカウントで Push Amplification™ が有効になっていれば、Push Amplification™ が動作を開始します。このような場合は、[Push Amplification™](/ja/user-guide/campaigns-and-channels/mobile-push/analyze/push-amplification-and-delivery-impact) によるアップリフトまたは効果が表示されます。

上記の Push Amplification™ Plus に関する説明と同じルールが、Push Amplification™ の統計にも適用されます。

キャンペーンの送信後、Campaign Info ページで Push Amplification™ Plus のステータスを確認できます。キャンペーンで Push Amplification™ Plus を有効にした場合、**Send via Push Amplification™ Plus:** には "Yes" と表示されます。キャンペーンで Push Amplification™ Plus を無効にした場合、**Send via Push Amplification™ Plus:** には "No" と表示されます。

![mceclip2.png](/images/moengage_6d0324.png)

<Accordion title="定期キャンペーン">
  定期キャンペーンでは、各子キャンペーンの送信時に Push Amplification™ Plus が有効だったか無効だったかに基づいて、子キャンペーンごとに Push Amplification™ Plus のアップリフトが表示されます。親キャンペーンについては、Push Amplification™ Plus のアップリフトを含む集計統計が表示されます。ただし、次の制限があります。

  - Push Amplification™ Plus を有効にした子キャンペーンを 1 つも送信していない場合、親キャンペーンには Push Amplification™ のアップリフトが表示されます。
  - Push Amplification™ Plus を有効にした子キャンペーンを 1 つでも送信した場合、親キャンペーンには Push Amplification™ Plus のアップリフトが表示されます。

  次の図は、この制限を説明したものです。

## アップリフトの計算方法

このセクションでは、アップリフトの計算に使用される数式について説明します。

<Tabs>
  <Tab title="インプレッションのアップリフト ">
  ![mceclip4.png](/images/moengage_34e3a3.png)

  すべての計算の基準は FCM です。インプレッションの % アップリフトは、まずキャンペーン配信率における Push Amplification™ Plus の貢献を算出し、それを FCM の配信率で割って計算します。ここでの配信率とは、インプレッション数 / 送信された通知数です。

  次の数式は、キャンペーン配信率における Push Amplification™ Plus の貢献の計算方法を示しています。このために、キャンペーン全体の配信率から FCM によるキャンペーン配信率への貢献を差し引きます。

  ![mceclip5.png](/images/moengage_6b6b5b.png)

  ![mceclip0.png](/images/moengage_369b27.png)
  </Tab>
  <Tab title="クリックのアップリフト">
  クリックのアップリフトを追跡するには、アプリの SDK バージョンが 9802 以降であることを確認してください。クリックの追跡は SDK バージョン 9802 以降でのみ利用可能です。このため、計算されたアップリフトは実際のクリックのアップリフトよりも低くなる場合があります。

  ![mceclip7.png](/images/moengage_3df479.png)

  クリックの % アップリフトは、インプレッションのアップリフトと同じロジックで計算されます。つまり、まずキャンペーンで得られた全クリックにおける Push Amplification™ Plus の貢献を算出し、それを FCM 経由のクリック数で割って計算します。

  数式中の "Adjusted Clicks by FCM" とは、同じキャンペーンを FCM のみで (つまり Push Amplification™ や Push Amplification™ Plus を使用せずに) 送信した場合に得られたはずのクリックを考慮して、FCM によるクリックを調整したものを意味します。

  ![mceclip11.png](/images/moengage_a956d9.png)

  FCM の調整済みクリックには、FCM による実際のクリック \+ Push Amplification™ Plus を使用してキャンペーンが配信されたデバイスから得られたはずのクリックが含まれます。このため、FCM 経由の CTR = Push Amplification™ Plus 経由の CTR という妥当な仮定を置いています。ここで CTR = クリック数 / インプレッション数です。

  - 全体的なレベルでの Push Amplification™ Plus の効果を示すため、All Platforms のインプレッションのアップリフトを表示しています。ただし、Android のクリックのアップリフトと All Platforms のクリックのアップリフトは常に同じであるため、All Platforms ではクリックのアップリフトは表示されません。

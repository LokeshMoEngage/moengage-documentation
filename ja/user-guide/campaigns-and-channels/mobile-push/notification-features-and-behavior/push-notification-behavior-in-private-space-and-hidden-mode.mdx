# Android 15 の Private Space

Android 15 で、Google は Private Space を導入しました。これは、ユーザーがデバイス上に機密性の高いアプリケーション用の独立したセキュアな領域を作成できる機能です。この領域は別のユーザープロファイルで動作し、追加の認証が必要です。詳細については、[こちら](https://umang91.medium.com/android-15-private-spaces-a08983480deb)を参照してください。

## Private Space 内のアプリの通知動作

アプリが Private Space 内にある場合、次のシナリオが適用されます。

- Private Space にインストールされたアプリケーションが通知を投稿すると、その通知には Private Space 内のアプリケーションからのものであることを示すロックアイコンが表示されます。
- Private Space にインストールされたアプリケーションの通知動作は、領域の状態（ロック中またはロック解除中）によって異なります。
  - 領域のロックが解除されている場合、通知はメイン領域のアプリケーションと同様に通常どおり受信および表示されます。
  - Private Space がロックされている場合:
    - アプリケーションは通知を表示しません。
    - 領域のロックが解除されると、ロック中に受信した通知が表示されるか、アプリケーションに配信されます。
- 領域がロック解除状態からロック状態に移行すると、システムは通知シェードから Private Space 内のアプリの通知をすべて消去します。
- 領域のロックが解除される前に **Expiration settings** に基づいて期限切れとなったメッセージは、アプリケーションに表示または配信されず、そのようなメッセージに関連する通知のインプレッションも取得されません。

# iOS 18 の Hidden Mode

iOS 18 で、Apple は Hidden Mode を導入しました。これは、ユーザーがアプリをロックして非表示にできる新機能です。プライバシーとセキュリティの強化により、ユーザーエクスペリエンスが向上します。詳細については、[こちら](https://support.apple.com/en-in/guide/iphone/iph00f208d05/18.0/ios/18.0)を参照してください。

この機能を使用すると、アプリの起動に追加のセキュリティを設定できます。

- ユーザー認証（Face ID、Touch ID、またはパスワード）を必須にする
- 非表示にして認証を必須にする

## Hidden Mode 内のアプリの通知動作

アプリが Hidden Mode 内にある場合、次のシナリオが適用されます。

- アプリの通知は表示されません。アプリが Hidden Mode から解除された後に受信した新しい通知は表示されます。
- 通知のインプレッションは、アプリが Hidden Mode にあるかどうか、また通知が表示されるかどうかに関係なくトラッキングされます。

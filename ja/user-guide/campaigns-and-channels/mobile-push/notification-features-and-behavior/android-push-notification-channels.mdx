[Android 通知チャネル](https://developer.android.com/develop/ui/views/notifications#ManageChannels)（Android Oreo、API レベル 26 で導入）を使用すると、ユーザーがプッシュ通知の設定をきめ細かく管理できるようになります。ユーザーはアプリ全体の通知のオン/オフを切り替える代わりに、個々のチャネルごとにオプトアウト、サウンド、バイブレーションなどの設定を調整できます。

<Info>
**前提条件**
通知チャネルを使用する前に、次の要件を満たしていることを確認してください。
    * **Target SDK:** アプリのターゲットが Android Oreo（Android 8.0 / API レベル 26）以降である必要があります。アプリが古いバージョンをターゲットにしていても Android Oreo デバイスで実行される場合、Android 7.1 / API レベル 25 と同様に動作します。
    * **MoEngage SDK:** MoEngage Android SDK を **v8.0.00** 以降に更新してください。
</Info>

## 設定のワークフロー

キャンペーンの通知チャネルを設定するには、次の手順に従います。

### ステップ 1: 通知チャネルを管理する

開発者がアプリで設定した通知チャネルを MoEngage ダッシュボードにマッピングします。

1. キャンペーン作成フローの [ステップ 2: コンテンツの定義](/ja/user-guide/campaigns-and-channels/mobile-push/create/create-push-campaigns#step-2-define-content)に移動します。
2. [Basic details](/ja/user-guide/campaigns-and-channels/mobile-push/create/push-templates#common-push-template-elements) セクションを展開します。
3. **Notification channel** ドロップダウンメニューを見つけます。
4. **+ Manage notification channel** をクリックして、設定モーダルを開きます。

![Android プッシュコンポーザーの Notification Channel ドロップダウンメニュー](/images/createnewchannel.png)

モーダルには、開発チームがアプリで設定したすべてのチャネルが一覧表示されます。各行には次の情報が表示されます。

- チャネル名
- チャネル ID（アプリのコードで定義されたもの）
- 重要度レベル（デバイス上で通知がどの程度目立つ形で表示されるかを制御する優先度）

<Tip>
**Channel ID** と **Importance** の値は、開発者がアプリで設定した値と一致している必要があります。どの値を使用すべきかわからない場合は、開発チームに確認してください。
各チャネル名と ID は一意である必要があります。重複する値を入力すると、モーダルで保存がブロックされ、競合するフィールドがエラーとしてハイライトされます。保存する前に値を修正してください。
</Tip>

**Importance について**

*Importance* は、開発者がアプリのコードでそのチャネルに設定した内容を反映するために宣言するラベルです。このチャネルの通知がどの程度目立つか、つまりサウンドを再生するか、バナーとしてポップアップするか、サイレントのままにするかを決定します。MoEngage は、デバイスや SDK から重要度を読み取りません。マーケターがキャンペーン用のチャネルを選択する際にその動作を把握できるよう、手動で設定します。

新しいチャネルでは、Importance は必須です。値を選択するまでチャネルを保存できません。

<Warning>
ダッシュボードで Importance を変更しても、アプリがすでにインストールされているデバイスには影響しません。Android では、チャネルの作成後にそのチャネルの重要度がロックされます。ここで設定した値は、新規インストールにのみ適用されます。
</Warning>

**General** チャネル（MoEngage のフォールバックチャネル）の重要度は固定されており、モーダルではグレーアウト表示されます。編集することはできません。

<Note>
設定する重要度は、開発者がアプリのコードでそのチャネルに設定した内容と一致している必要があります。一致しない場合、エンドユーザーには、ダッシュボードに表示されるラベルではなく、アプリで定義された動作が適用されます。
</Note>

![チャネル名、ID、重要度のフィールドを表示する Manage notification channel モーダル](/images/add-a-new-channel.gif)

### ステップ 2: デフォルトチャネルを設定する（任意）

今後のキャンペーン作成を効率化するため、特定のチャネルをデフォルトとして指定できます。

1. チャネルを追加して保存した後、その横にある **Default** ラジオボタンを選択します。
2. **Save** をクリックします。 
MoEngage は、今後のすべてのキャンペーンでこのチャネルを事前に選択します。


### ステップ 3: キャンペーン配信用のチャネルを選択する

キャンペーンに最適なチャネルを選択します。チャネルを通じて送信されるすべての通知は、そのチャネルに設定された動作を共有します。

<Info>
**フォールバック動作:** 無効な Channel ID を指定した場合やチャネルの選択をスキップした場合、MoEngage は Android 8.0（API レベル 26）以降のユーザーへの通知配信に自動的に **General** チャネルを使用します。
</Info>

## チャネルの重要度レベルのリファレンス

チャネルを選択すると、ダッシュボードにその重要度レベルに基づく動作の概要が表示されます。

| Importance | 説明 |
| :---- | :---- |
| **Urgent** | バナーとしてポップアップし、サウンドを再生します。ロック画面とステータスバーに表示されたままになります。時間的制約のある通知に最適です。 |
| **High** | サウンドを再生し、ロック画面に表示されますが、バナーはポップアップしません。ユーザーを中断する必要のない重要な更新に適しています。 |
| **Medium** | サイレントです。ステータスバーとロック画面に表示され、サウンドやバイブレーションはありません。一般的なアクティビティフィードに適しています。 |
| **Low** | サイレントで控えめです。ステータスバーアイコンもサウンドもありません。ユーザーは通知シェードを引き下げたときにのみ確認できます。 |
| **None** | 完全に非表示です。サウンド、ステータスバーアイコン、通知シェードでのアラートのいずれもありません。 |


## 例外処理: 不明または未設定の重要度

Importance 機能が導入される前に追加されたチャネルは、重要度が **Unknown** と表示され、チャネルピッカーでアンバー色のインジケーターが付きます。**Unknown** はエラーではありません。重要度がまだ宣言されていないことを意味し、チャネルが壊れているわけではありません。重要度が Unknown のチャネルでも、引き続きキャンペーンを送信できます。アンバー色のフラグは、レベルの設定を促すものです。

解決するには、**Manage notification channel** を開き、Unknown の各チャネルに重要度レベルを選択して **Save** をクリックします。

**チャネルの重要度が Unknown の場合にダッシュボードに表示される内容:**

1. **チャネルピッカー:** チャネル名の横にアンバー色のインジケーターとともに **Unknown** と表示されます。
2. **インライン警告:** Notification Channel フィールドの下に、次のメッセージが表示されます: *"Channel importance: Unknown. Ask channel implementer to define the required further behavior for the device."*
3. **エラーバナー:** より広範な警告が表示される場合があります: *"Missing importance breakdown. The behaviour of notification cannot be determined. Explore channel importance for expected behaviour."*


<Info>
MoEngage は、アプリ内の通知チャネルを作成、読み取り、更新、削除しません。チャネルのライフサイクル全体は、開発者がアプリのコードで管理します。
</Info>

## エンドユーザーのエクスペリエンスと制御

開発者が Android Notification Manager でチャネルを作成・登録すると、その後コードでチャネルの動作を変更することはできません。その時点以降、これらの設定はユーザーが完全に制御します。

ダッシュボードで宣言された重要度にかかわらず、ユーザーはデバイスの設定からチャネルを変更またはブロックできます。ユーザーレベルの設定は、常にアプリの設定よりも優先されます。

ユーザーは、デバイスの **Settings** に移動するか、通知を長押しして、チャネルを調整またはブロックできます。ユーザーが次のいずれかの設定を変更すると、そのチャネルに対するアプリのデフォルト設定よりもユーザーの設定が優先されます。

* 重要度  
* サウンド  
* ライト  
* バイブレーション  
* ロック画面に表示  
* 「Do Not Disturb」の上書き

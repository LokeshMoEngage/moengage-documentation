# 概要

_Push Notification Center_ 機能は、受信したプッシュ通知の履歴をユーザーに提供します。これにより、重要なメッセージを見逃すことがなくなり、後から確認できるようになるため、ユーザーエンゲージメントが向上します。

MoEngage では、Push Notification Center を実装するための 2 つの異なるアプローチを提供しています。

- **MoEngage Push Notification Center**: 豊富な UI カスタマイズ機能を備えた、すぐに使えるオプションです。
- **Self-Handled Push Notification Center**: 完全にカスタマイズ可能なセルフハンドルの Push Notification Center です。

| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| <ul><li>アプリケーション内に組み込まれた受信トレイで、基本的な UI カスタマイズオプションを備え、プッシュ通知の履歴を表示します。</li><li>MoEngage SDK によって管理およびレンダリングされます。</li><li>たとえば MoEngage Push Notification Center では、ユーザーが過去の通知を閲覧する受信トレイのルック＆フィールを MoEngage が提供しますが、一部の要素はカスタマイズできます。</li></ul> | <ul><li>MoEngage SDK の通知ペイロードを使用して、アプリチームが開発するカスタムの受信トレイです。この場合、MoEngage は通知コンテンツ（メッセージのテキストなど）を提供し、開発者が UI を設計および構築します。</li><li>開発者は、アプリのデザインガイドラインに基づいて UI を設計および構築します。</li><li>たとえば Self-Handled Push Notification Center では、受信トレイのデザインを完全にコントロールでき、MoEngage のデータを使用して受信トレイにコンテンツを表示します。</li></ul> |

どの実装方法を選択した場合でも、Push Notification Center は、ユーザーエンゲージメントの向上、メッセージの永続化、アプリケーション内の全体的なユーザーエクスペリエンスの向上に役立つ有用なツールです。

# メリット

- **永続的なコンテンツ:** ユーザーは、通知ドロワーから通知を消去した後でも、アプリ内でプッシュ通知を操作できます。
- **インタラクションデータ:** Notification Center 内で行われたインタラクションは、MoEngage ダッシュボードでトラッキングできます。
- **押し付けがましくない:** Notification Center のコンテンツは、ユーザーのアプリエクスペリエンスのネイティブな一部として表示され、ユーザーの操作を妨げません。これによりユーザーの受容性が高まり、エンゲージメントが向上します。

# ユースケース

- オファーとプロモーション
- ゲーミフィケーションとコンテストへの参加
- リマインダーとヒント
- ポリシーおよび利用規約の変更
- 取引およびサービスの更新
- カートまたはウィッシュリストのリマインダー
- レコメンデーション

# Push Notification Center の機能

<Info>
  特に記載がない限り、これらの機能は両方の Notification Center タイプに適用されます。
</Info>

| 要素                  | 説明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 配信メカニズム       | プッシュ通知が APNS/FCM 経由で配信されたとき、またはバックアップ配信メカニズムによりアプリが開かれるたびに配信されます。                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| リーチ範囲             | 対象となり、プッシュ通知をオプトインしているすべてのユーザー。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| トリガーオプション           | <ul><li>Bulk（1 回限り）</li><li>Trigger Based<ul><li>Event-triggered</li><li>Device triggered</li><li>Location triggered</li><li>Business event triggered</li><li>Flow triggered</li></ul></li><li>Periodic</li><li>Inform</li></ul>                                                                                                                                                                                                                                                                                                                                                               |
| コンテンツの保持        | メッセージは、受信したデバイス上にローカルに保存されます。アンインストール、ログアウト、またはデータ消去後は保持されません。                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| コンテンツの動作         | 通知は配信後も静的なままです。一括削除はサポートされていません。ユーザーは個々の通知を削除できます。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| 有効期限オプション            | キャンペーンの作成時に、メッセージが期限切れになるまで Notification Center に保持される期間（日数）を設定できます。詳細については、[こちら](/ja/user-guide/campaigns-and-channels/mobile-push/create/create-push-campaigns)を参照してください。                                                                                                                                                                                                                                                                                                                                                   |
| グループ化と置換 | <ul><li>通知は個別のエントリとして表示されます。</li><li>MoEngage Push Notification Center では、_Grouping_ および _Replacement_ 機能はサポートされていません。</li><li>Self-Handled Push Notification Center では、カスタム UI 用にグループキーと更新キーがペイロードで利用できます。</li></ul>                                                                                                                                                                                                                                                                                                 |
| メディアのサポート            | 大きな画像、アイコン、その他のメディアは MoEngage Push Notification Center ではサポートされていませんが、Self-Handled Push Notification Center ではカスタム UI 用にペイロードで利用できます。                                                                                                                                                                                                                                                                                                                                                                                                           |
| 表示と配信   | Notification Center のコンテンツは、次の方法でユーザーに表示できます。<ul><li>いくつかの UI カスタマイズオプションを備えた MoEngage Push Notification Center<ul><li>ユーザーのアクションで起動できるフルページの *Activity* として、または</li><li>アプリのアクティビティに埋め込まれた *Fragment* として（Android のみ）</li></ul></li><li>Self-handled Push Notification Center では、通知ペイロード全体にアクセスでき、それを使用してカスタム UI を構築できます。</li></ul> 詳細については、[Notification Center の表示と配信](#notification-center-placement-and-delivery)を参照してください。 |

### Notification Center の表示と配信

次のいずれかの方法を使用して、アプリケーション上でユーザーに Notification Center を表示できます。

<Tabs>
  <Tab title="MoEngage Push Notification Center">
  MoEngage Push Notification Center は、ユーザーの Notification Center または受信トレイにプッシュ通知をフィードとして表示します。

    |                            |                                                                                                                                                                                                                                                                                 |
    | -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
    | **統合の工数**     | 低  基本的な統合と UI カスタマイズ値の設定が必要です。                                                                                                                                                                                                  |
    | **Notification Center UI** | MoEngage Push Notification Center UI では、受信トレイの外観について次のような基本的なカスタマイズが可能です。<ul><li>Activity テーマ</li><li>Activity ラベル</li><li>ツールバーのスタイル</li><li>メッセージテキストの外観<ul><li>ヘッダー</li><li>メッセージ</li><li>タイムスタンプ</li></ul></li><li>スクロールバーのスタイル</li><li>空の Notification Center のスタイル</li></ul> |
    | **トラッキング分析**     | 配信、インプレッション、クリックを自動的にトラッキングします。                                                                                                                                                                                                                        |
    | **最適な対象**              | 開発者が限られており、アプリ内にフィード（受信トレイ）を構築したいチーム。                                                                                                                                                                                         |
    | **サポートされるプラットフォーム**    | Android（Native）、iOS（Native）。                                                                                                                                                                                                                                                 |
  </Tab>
  <Tab title="Self-Handled Push Notification Center">
   Self-handled Push Notification Center では、独自の受信トレイ UI を作成し、アプリのコンテンツに合わせてフィード、アプリウィジェット、バナー、コンテンツカルーセルの形式でプッシュ通知を表示できます。

    |                                              |                                                                                                                                                                                                                                              |
    | -------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
    | **統合の工数**                       | 高  カスタム UI の構築と、UI にデータを表示するための通知ペイロードの解析が必要です。                                                                                                                                                 |
    | **Self-Handled Push Notification Center UI** | アプリのデザインガイドラインに従って、UI を完全にコントロールできます。                                                                                                                                                                            |
    | **トラッキング分析**                       | 配信と削除は自動的にトラッキングされます。クリックは SDK 関数を使用して別途トラッキングする必要があります。  **注**: これらのイベントの設定の詳細については、ご使用のプラットフォームの [SDK ドキュメント](#next-steps)を確認してください。 |
    | **最適な対象**                                | 次のことを行いたいチーム:   <ul><li>カスタムの受信トレイ（フィード）UI を作成する。</li><li>アプリのコンテンツ内に配置するアプリウィジェット、バナー、コンテンツカルーセルを作成する。</li></ul>                                                                                   |
    | **サポートされるプラットフォーム**                      | Android（Native）、iOS（Native）、React Native、Flutter。                                                                                                                                                                                       | 
  </Tab>
</Tabs>

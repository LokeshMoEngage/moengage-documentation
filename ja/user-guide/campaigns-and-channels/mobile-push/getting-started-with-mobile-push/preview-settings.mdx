Push の Preview Settings を使用すると、キャンペーン作成プロセスの 2 番目のステップでデバイスプレビューに表示されるアイコンとテキストを変更できます。

このデバイスプレビューにより、プッシュ通知が実際のデバイスでどのように表示されるか、また書式を調整する必要があるかどうかを確認できます。

この機能を使用するには、**Settings \> Channels \> Push \> Preview Settings** に移動します。

<Tip>
**前提条件**

[*Portfolio*](/ja/user-guide/settings/account/portfolio/portfolio)*が有効な*ワークスペースでは、Preview settings を設定する前に、MoEngage の [Portfolio](/ja/user-guide/settings/account/portfolio/portfolio) に少なくとも 1 つのプロジェクトを追加する必要があります。プロジェクトの追加方法の詳細については、[こちら](/ja/user-guide/settings/account/portfolio/portfolio)を参照してください。
</Tip>

## プロジェクトの選択

Portfolio に複数のプロジェクトがある場合、**Preview settings** タブの下にドロップダウンが表示されます。ドロップダウンメニューから設定するプロジェクトを選択します。関連する設定（App name、App icon など）が自動的に読み込まれます。プロジェクトが 1 つだけの Portfolio では、すべての設定がそのプロジェクトに適用されます。

<Info>
Preview Settings は実際のデバイスでの表示には影響しません。ここで追加したアイコンは、プッシュキャンペーンのデバイスプレビューでのみ表示されます。
</Info>

### Android

<img src="/images/moengage_b02d7c.png" />

1. **App Name (preview)**：デバイスに表示されるアプリ名を入力します。実際のアプリ名は、Google Play Console に表示される名前です。
2. **App icon**：アップロードボックスをクリックしてアプリアイコンをアップロードできます。実際のアプリアイコンは、アプリを MoEngage Push と連携する際に設定されます。詳細については、[Push Configuration](/ja/developer-guide/android-sdk/push/basic/push-configuration) を参照してください。
   - アルファチャネル画像のみサポートされています。
   - RGB 画像はサポートされていません。
   - 必要な最小解像度：*72 x 72 px*
   - *.png* 形式の画像のみサポートされています。
3. **Large app icon**：アップロードボックスをクリックして大きいアプリアイコンをアップロードできます。実際の Large app icon は、プッシュキャンペーンの作成時に設定できます。
   - 推奨解像度：*120 x 120 px*
   - *.png* 形式の画像のみサポートされています。

### iOS

<img src="/images/moengage_a1f998.png" />

**App Icon**：アップロードボックスをクリックしてカスタムアプリアイコンをアップロードできます。iOS アプリのアプリアイコンとして使用しているものと同じアイコンを使用してください。

- 最小解像度：*180 x 180 px*
- *.png* 形式の画像のみサポートされています。

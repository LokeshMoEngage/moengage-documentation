モバイルプッシュを設定するには、**Settings** \> **Channels** \> **Push** \> **App Push** に移動します。

<Tip>
ワークスペースで [Portfolio](/ja/user-guide/settings/account/portfolio/portfolio) が有効になっている場合、Mobile Push の設定を行う前に、MoEngage Portfolio に少なくとも 1 つのプロジェクトを追加する必要があります。プロジェクトの追加方法の詳細については、[こちら](/ja/user-guide/settings/account/portfolio/portfolio)を参照してください。
</Tip>

## プロジェクトの選択

ポートフォリオに複数のプロジェクトがある場合、App Push 設定タブの上部にドロップダウンが表示されます。設定するプロジェクトを選択すると、関連する設定（秘密鍵ファイルなど）が自動的に読み込まれます。プロジェクトが 1 つのみのポートフォリオでは、すべての設定がそのプロジェクトに適用されます。

## Android (FCM)

Android デバイス向けにプッシュ通知を設定するには、MoEngage で FCM を認証する必要があります。**FCM Authentication** のフィールドの設定の詳細については、[FCM 認証](/ja/developer-guide/android-sdk/push/basic/fcm-authentication)を参照してください。

## iOS (APNS)

### iOS 認証

iOS アプリにプッシュ通知を送信するには、Apple Push Notification Service (APNS) が必要です。iOS デバイス向けにプッシュ通知を設定するには、利用可能な以下の APNS iOS 認証方法のいずれかを選択し、ドキュメントに従って詳細を設定します。

1. [APNS 認証キー](/ja/developer-guide/ios-sdk/push/basic/apns-authentication-key)
2. [APNS プロバイダー証明書](/ja/developer-guide/ios-sdk/push/basic/apns-certificate-pem-file-legacy)

### iOS インプレッションの表示

*Show iOS Impressions* トグルを有効にすると、Campaign Analytics ページと All Campaigns ページに iOS のインプレッション数が表示されます。iOS のインプレッション数を有効にするには、iOS SDK との追加の統合が必要です。詳細については、[Notification Service Extension](/ja/developer-guide/ios-sdk/push/basic/ios-push-integration-tutorial) セクションを参照してください。

<Info>
*Show iOS Impressions* トグルはデフォルトでオフになっており、iOS SDK の統合が完了した場合にのみ有効になります。
</Info>

## Huawei (Push AMP+)

Huawei デバイスにプッシュ通知を送信するには、Huawei のフィールドを設定する必要があります。詳細については、[MoEngage での Huawei Push の設定](/ja/developer-guide/android-sdk/push/optional/push-amp-plus/configuring-huawei-push-on-mo-engage)を参照してください。

## IP のホワイトリスト登録

Push キャンペーンで Content API または PII トークン化を使用するためにシステムで IP のホワイトリスト登録が必要な場合は、[こちら](/ja/user-guide/settings/account/security/ip-whitelisting-in-moengage)を参照してください。

## 問題

プッシュキャンペーンで、キャンペーンの失敗の内訳に次のエラーが表示されます。

INVALID\_SERVER\_CREDS

![](/images/moengage_ea004e.png)

## 解決策

- "INVALID\_SERVER\_CREDS" エラーが表示されるのは、指定された送信者 ID とサーバーキーが異なる GCM または FCM プロジェクトに属している可能性があるためです。
- この問題を解決するには、設定済みの送信者 ID とサーバーキーを使用してください。
- プッシュ設定に正しい FCM キー (または証明書) が設定されていることを確認し、google-services.json ファイル (追加している場合) ではなく ServiceKey.json ファイルを含めてください。
- MoEngage ダッシュボードで **Private key file (Recommended)** を確認します。
  - 任意のテキストエディターで秘密鍵の JSON ファイルを開きます。
  - JSON ファイルに記載されている _project\_id_ が Firebase のプロジェクト ID と一致していることを確認します。
  - Service Accounts ページにすでに秘密鍵がある場合は、新しい秘密鍵を生成する必要はありません。
     <img src="/images/moengage_77d443.png" />
    <Info>
      FCM プロジェクトでは、送信者 ID は google-services.json ファイルで確認できます。
    </Info>

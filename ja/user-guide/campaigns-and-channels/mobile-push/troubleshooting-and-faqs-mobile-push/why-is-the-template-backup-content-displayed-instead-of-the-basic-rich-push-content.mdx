## 問題

Basic リッチプッシュテンプレートにコンテンツを追加すると、Basic リッチプッシュのコンテンツではなくテンプレートのバックアップコンテンツが表示されます。

<img
  alt="backup content.png"
  src="/images/moengage_9eea00.png"
  style={{ width:"44%" }}
/>

<Info>
  この問題は、MoEngage のリッチ通知の依存関係がアプリレベルの build.gradle ファイルに追加されていないために発生します。
</Info>

## 解決策

次の手順を実行してください。

1. リッチプッシュ通知では、表示されるコンテンツはデバイスとそのバージョンによって異なります。
2. リッチプッシュテンプレートのキャンペーンデータが次のセクションに追加されていることを確認します。
   - **Basic details**
   - **Template Backup**
      <img src="/images/moengage_6a30c5.png" alt="basic and template.png" />
3. プレビュー画面では、Basic details を変更するとメッセージのタイトルと本文が更新されます。
    <img src="/images/moengage_3e2ab5.png" alt="basic.png" />
4. **Template Backup** セクションでテンプレートのバックアップコンテンツをカスタマイズできます。 <img alt="template.png" src="/images/moengage_ad0ad1.png" />
5. テンプレートのバックアップコンテンツと Basic リッチプッシュのコンテンツが正しく表示されるように、MoEngage のリッチ通知の依存関係をアプリレベルの build.gradle ファイルに必ず追加してください。
   ```groovy Code
   build.gradle(:app)
             
   dependencies {
       implementation(moengage.richNotification)
   }
   ```

## トークンドロップとは

トークンドロップとは、MoEngage プラットフォームがアプリケーションのすべてのユーザーのプッシュトークンを保持していない状況またはケースを指します。たとえば、アプリケーションが毎日 100 人の新規ユーザーによってインストールされているにもかかわらず、MoEngage プラットフォーム上には 60 人分のトークンしかない場合、これは 40% のトークンドロップとみなされます。

## 修正が重要な理由

エンドユーザーにプッシュ通知を送信するには、プッシュトークンが必要です。プッシュトークンがなければプッシュを送信できません。そのため、ユーザーのエンゲージメントを維持するには、トークンドロップを修正することが非常に重要です。  
トークンドロップが発生する理由  
トークンドロップはさまざまな理由で発生する可能性があります。

- インターネット接続が不安定または接続がないために、Firebase SDK がトークンを生成しない。
- Play サービスのバージョンの不一致。デバイス上の Play サービスのバージョンが、アプリケーションで使用されている Firebase のバージョンと互換性がない
- アプリケーションに、MoEngage SDK にトークンを渡すかどうかを決定する内部チェック/フラグがあり、トークン生成時にそのフラグが無効になっているため、トークンが MoEngage SDK に渡されない。
- 統合エラー。プッシュトークンが MoEngage SDK に渡されていない。

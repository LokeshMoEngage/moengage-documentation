## 問題

テストプッシュ通知キャンペーンを送信しようとすると、通知が失敗し、次のメッセージが表示されます。

Installed User not found for Mobile Number = 0000000000  
 <img  src="/images/moengage_06d833.png"  />

## 解決策

- プッシュ通知が確実に送信されるように、Mobile Number 属性ではなく、到達可能なユーザーの一意の ID フィールドを使用してください。
- 一意の ID フィールドは、ユーザープロファイル内の **ID** という名前で確認できます。  
   <img  src="/images/moengage_93aff4.png"  />
- 一意の ID は各ユーザーに固有であり、ユーザーがプッシュ通知を受信できるかどうかを判断するために使用されます。

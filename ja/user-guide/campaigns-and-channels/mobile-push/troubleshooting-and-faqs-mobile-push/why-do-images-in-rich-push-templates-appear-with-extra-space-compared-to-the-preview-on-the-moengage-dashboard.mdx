## 問題

リッチプッシュ通知 (カルーセルを含む) の画像が、MoEngage UI のリッチプッシュテンプレートのプレビューとは異なり、モバイルデバイスで表示すると余白付きで表示されることがあります。

## 説明

- 以下に示すように、バージョンカタログまたはアーティファクト ID のいずれかを使用して、アプリレベルの `build.gradle` ファイルにリッチプッシュ通知の依存関係が追加されていることを確認します。

<CodeGroup>

```kotlin Kotlin wrap
build.gradle (:app)
implementation(moengage.richNotification) // using moengage version catalog
or
implementation("com.moengage:rich-notification:$sdkVersion") // using artifact id
```

</CodeGroup>

- MoEngage のバージョンカタログをプロジェクトに統合するには、[Installing Version Catalog](https://developers.moengage.com/hc/en-us/articles/4407395989268-Installing-Version-Catalog) のドキュメントを参照してください。
- アーティファクト ID を使用して MoEngage のリッチ通知の依存関係を統合するには、[Installing SDK using Artifact Id](/ja/developer-guide/android-sdk/sdk-integration/advanced-or-optional/installing-sdk-using-artifact-id) のドキュメントを参照してください。
- インテグレーションが正しく、Android OS のバージョンが 12 以降の場合、上記の動作は想定どおりです。通知のレイアウトとカスタマイズ可能な領域の詳細については、[Behavior changes: Apps targeting Android 12](https://developer.android.com/about/versions/12/behavior-changes-12) を参照してください。

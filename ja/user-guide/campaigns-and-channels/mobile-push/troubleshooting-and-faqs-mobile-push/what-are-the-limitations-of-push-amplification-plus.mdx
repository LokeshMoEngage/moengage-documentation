Push Amplification™ Plus は、プッシュ通知の配信率を最大 40% 向上させ、より多くのユーザーにメッセージを届けられるように設計されています。ただし、このサービスには一定の制限事項があります。

### SDK の互換性

Push Amplification™ Plus は、以下の SDK の指定バージョン以降でのみ利用できます。

| **Android SDK の種類** | **Huawei での Push Amplification™ Plus のサポート** |
| --- | --- |
| Native Android SDK | SDK バージョン 10.3.00 以上 |
| React Native | SDK バージョン 6.0.0 以上 |
| Segment Integration SDK | SDK バージョン 4.2.00 以上 |
| Flutter | SDK バージョン 2.0.0 以上 |
| Cordova | SDK バージョン 6.0.0 以上 |
| Unity | 利用不可 |
| Xamarin | 利用不可 |

### ダイレクト配信サービスの制限事項

以下の制限事項は、ダイレクト配信サービスに適用され、フォールバック配信サービスには適用されません。

1. **フォールバックメカニズムなし**: プライマリ配信サービスは配信率が高い（75%〜95%）ため、Push Amplification™ のフォールバックメカニズムはサポートされていません。
2. **カスタム表示なし**: Push Amplification™ Plus の拡張配信サービスは、クライアントアプリがキーと値のペアを解析するか MoEngage ペイロードを直接使用して通知の表示を処理するカスタム表示をサポートしていません。
3. **文字数制限**: タイトルの最大長は 40 文字（スペースを含む）、メッセージの最大長は 1,024 文字（スペースを含む）です。
4. **通知画像のサポートなし**: Huawei は通知画像をサポートしていません。ただし、小さいアプリアイコンと大きいアプリアイコンはサポートされています。
5. **データペイロードなし**: データペイロードの送信はサポートされていません。
6. **カスタマイズされた通知チャネルなし**: Huawei が提供する標準のチャネルはサポートされていません。カスタムチャネルまたは MoEngage のデフォルトチャネルを使用できます。FCM とは異なり、設定が正しくない場合、デフォルトチャネルは HMS のフォールバックとして機能しません。
7. **通知メッセージアイコンのカスタマイズなし**: 通知メッセージアイコンのカスタマイズはサポートされていません。
8. **その他の制限事項**:
   - "Notification Cleared" イベントはトラッキングされません。
   - Notification Center には、クリックされた通知のみが表示されます。
   - 通知クリアのコールバックは機能しません。
   - 通知受信のコールバックは機能しません。
   - プッシュテンプレートは機能しません。基本的なプッシュ通知のみがサポートされています。
   - プッシュ表示プロパティのカスタマイズは機能しません。
   - キーと値のペアによる表示の制御は機能しません。

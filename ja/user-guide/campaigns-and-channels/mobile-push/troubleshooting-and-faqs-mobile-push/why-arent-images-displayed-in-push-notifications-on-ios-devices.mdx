## 問題

iOS デバイスでプッシュ通知に画像が表示されません。

## 解決策

問題を解決するには、次の手順を実行します。

- アプリで使用している MoEngage SDK のバージョンを確認します。SDK のバージョンを確認するには、podfile.lock を開いて *MoEngage-iOS-SDK* を検索し、記載されているバージョンをメモします。
- アプリに Notification Service Extension が実装されているかどうかを確認します。
- Notification Service Extension が実装されていない場合は、MoEngage SDK のバージョンに応じて、該当するリンクの手順に従ってください。
  - MoEngage-iOS-SDK (7.x.x) を使用しているプロジェクトの場合は、[How to Avoid Common Push Notification Issues on iOS Devices Using iOS SDK version 7.x.x?](/ja/user-guide/campaigns-and-channels/mobile-push/troubleshooting-and-faqs-mobile-push/how-to-avoid-common-push-notification-issues-on-ios-devices-using-ios-sdk-version-7xx) を参照してください。
  - MoEngage-iOS-SDK (8.x.x) を使用しているプロジェクトの場合は、[How to Avoid Common Push Notification Issues on iOS Devices Using iOS SDK version 8.x.x?](/ja/user-guide/campaigns-and-channels/mobile-push/troubleshooting-and-faqs-mobile-push/how-to-avoid-common-push-notification-issues-on-ios-devices-using-ios-sdk-version-8xx) を参照してください。
  - MoEngage-iOS-SDK (9.x.x) を使用しているプロジェクトの場合は、[How to Avoid Common Push Notification Issues on iOS Devices Using iOS SDK version 9.x.x?](/ja/user-guide/campaigns-and-channels/mobile-push/troubleshooting-and-faqs-mobile-push/how-to-avoid-common-push-notification-issues-on-ios-devices-using-ios-sdk-version-9xx) を参照してください。
- Notification Service Extension がすでに実装されている場合は、MoEngage SDK のバージョンと AppDelegate ファイル (Swift、Objective-C) に応じて、該当するリンクの手順に従ってください。
  - MoEngage-iOS-SDK (7.x.x) と Swift を使用しているプロジェクトの場合は、[How to Avoid Common Push Notification Issues on iOS Devices Using iOS Swift version 7.x.x?](/ja/user-guide/campaigns-and-channels/mobile-push/troubleshooting-and-faqs-mobile-push/how-to-avoid-common-push-notification-issues-on-ios-devices-using-ios-swift-version-7xx) を参照してください。
  - MoEngage-iOS-SDK (8.x.x) と Swift を使用しているプロジェクトの場合は、[How to Avoid Common Push Notification Issues on iOS Devices Using iOS Swift version 8.x.x?](/ja/user-guide/campaigns-and-channels/mobile-push/troubleshooting-and-faqs-mobile-push/how-to-avoid-common-push-notification-issues-on-ios-devices-using-ios-swift-version-8xx) を参照してください。
  - MoEngage-iOS-SDK (9.x.x) と Swift を使用しているプロジェクトの場合は、[How to Avoid Common Push Notification Issues on iOS Devices Using iOS Swift version 9.x.x?](/ja/user-guide/campaigns-and-channels/mobile-push/troubleshooting-and-faqs-mobile-push/how-to-avoid-common-push-notification-issues-on-ios-devices-using-ios-swift-version-9xx) を参照してください。
  - MoEngage-iOS-SDK (7.x.x) と Objective-C を使用しているプロジェクトの場合は、[How to Avoid Common Push Notification Issues on iOS Devices Using iOS Objective C version 7.x.x?](/ja/user-guide/campaigns-and-channels/mobile-push/troubleshooting-and-faqs-mobile-push/how-to-avoid-common-push-notification-issues-on-ios-devices-using-ios-objective-c-version-7xx) を参照してください。
  - MoEngage-iOS-SDK (8.x.x) と Objective-C を使用しているプロジェクトの場合は、[How to Avoid Common Push Notification Issues on iOS Devices Using iOS Objective C version 8.x.x?](/ja/user-guide/campaigns-and-channels/mobile-push/troubleshooting-and-faqs-mobile-push/how-to-avoid-common-push-notification-issues-on-ios-devices-using-ios-objective-c-version-8xx) を参照してください。
  - MoEngage-iOS-SDK (9.x.x) と Objective-C を使用しているプロジェクトの場合は、[How to Avoid Common Push Notification Issues on iOS Devices Using iOS Objective C version 9.x.x?](/ja/user-guide/campaigns-and-channels/mobile-push/troubleshooting-and-faqs-mobile-push/how-to-avoid-common-push-notification-issues-on-ios-devices-using-ios-objective-c-version-9xx) を参照してください。

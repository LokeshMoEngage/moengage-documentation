## 問題

到達可能なユーザーに iOS でプッシュ通知を送信すると、「BadDeviceToken」エラーが表示されます。

## 説明

このエラーは次のシナリオで発生します。

- ビルドが Debug 環境にある状態で、Live ダッシュボードからプッシュ通知を送信した場合。
- ビルドが Release 環境にある状態で、Test ダッシュボードからプッシュ通知を送信した場合。
- Debug 環境のビルドが Production 用の Apple 証明書を使用してアーカイブされている状態で、いずれかのダッシュボードからプッシュ通知をテストしようとした場合。
- Release 環境のビルドが Development 用の Apple 証明書を使用してアーカイブされている状態で、いずれかのダッシュボードからプッシュ通知をテストしようとした場合。

## 解決策

このエラーを回避するには、次の設定を行ってください。

- *Debug 構成*。Developer 証明書と MoEngage の Test ダッシュボードを使用します。
- *Release 構成*。Production または AdHoc 証明書と MoEngage の Live ダッシュボードを使用します。

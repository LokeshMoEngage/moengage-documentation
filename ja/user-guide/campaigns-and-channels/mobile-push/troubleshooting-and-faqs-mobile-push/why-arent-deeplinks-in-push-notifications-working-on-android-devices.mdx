## 問題

Android デバイスでプッシュ通知のディープリンクが機能しません。

## 解決策

ディープリンクは Android アプリ開発および MoEngage でサポートされています。開発者側のディープリンクの実装が正しいかどうかを確認するには、次の手順を実行します。

1. ディープリンク URL をテストします。キャンペーンで使用しているものと同じリンクを使用して、サードパーティアプリ (WhatsApp、Slack、Web ブラウザーなど) からディープリンク URL でアプリが正しく開くことを確認します。開かない場合、問題は開発者の実装にある可能性が高いです。MoEngage は Android が提供するネイティブのディープリンク機能を使用しています。ディープリンクの実装の詳細については、Android の公式ドキュメントを参照してください。  
   - [Create Deep Links to App Content](https://developer.android.com/training/app-links/deep-linking)
   - [Handling Android App Links](https://developer.android.com/training/app-links)
2. *ハイブリッドフレームワークの場合*。一部のハイブリッドフレームワークでは、開発者がアプリ内のナビゲーションにルートを使用しています。ただし、これらのルートは通常アプリ内でのみ有効であるため、アプリの外部から開いた場合には機能しない可能性があります。適切なディープリンクのインテグレーションについては、上記の Android ドキュメントを参照してください。
3. ディープリンクがサードパーティアプリからは機能するものの、MoEngage のプッシュ通知では機能しない場合:
   - MoEngage SDK がプッシュ通知を作成している場合、SDK が古いディープリンク URL 形式を使用して URL に MoEngage のデータを付加しているため、正しく解析できない可能性があります。この場合は、MoEngage のカスタマーサクセスマネージャー (CSM) またはサポートチームにお問い合わせください。
   - MoEngage SDK がプッシュ通知を作成していない場合、アプリ開発者がコード内のディープリンクの実装を確認する必要があります。

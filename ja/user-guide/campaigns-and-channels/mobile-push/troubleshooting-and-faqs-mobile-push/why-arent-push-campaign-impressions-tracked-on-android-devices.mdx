## 問題

MoEngage SDK が Android デバイスまたは SDK でプッシュキャンペーンのインプレッションをトラッキングしません。

## 解決策

プッシュキャンペーンのインプレッションの問題は、いくつかの要因によって発生する可能性があります。

- MoEngage SDK がデフォルトでプッシュ通知を処理する場合:
  - SDK の初期化を確認します。SDK が遅延して初期化されていないかを確認してください。
    - SDK が遅延して初期化されている場合は、以下の MoEngage ドキュメントのリンクに記載されているとおり、SDK の初期化をデフォルト設定に変更してください。SDK は、コールバック内ではなく、メインスレッド上の Application クラスの **onCreate()** メソッドで初期化してください。
      - [Android Native](/ja/developer-guide/android-sdk/sdk-integration/basic-integration/sdk-initialization)
      - [React Native](/ja/developer-guide/react-native-sdk/sdk-integration/react-native/sdk-initialization/manual-initialization/android)
      - [Flutter](/ja/developer-guide/flutter-sdk/sdk-integration/sdk-initialization/manual-initialization/android-sdk-initialization)
      - [Cordova](/ja/developer-guide/cordova-sdk/sdk-integration/sdk-initialization/android-sdk-initialization)
      - [Unity](/ja/developer-guide/unity-sdk/sdk-integration/sdk-initialization/manual-initialization/android)
      - [Capacitor](/ja/developer-guide/capacitor-sdk/sdk-integration/basic/sdk-initialization/android-sdk-initialization)
  - ネットワークの問題を確認します。ネットワークの問題 (プライベート DNS や広告ブロッカーなど) により、SDK から MoEngage バックエンドへのデータの同期が妨げられている可能性があります。
- MoEngage SDK がカスタマイズを加えてプッシュ通知を処理する場合:
  - SDK の初期化を確認します。SDK が遅延して初期化されていないことを確認してください (上記の項目を参照)。
  - PushMessageListener/PluginPushCallback のコードを確認します。Builder が MoEngage SDK のコールバックに干渉していないことを確認してください。
- アプリがプッシュ通知を処理する場合:
  - SDK の初期化を確認します。SDK が遅延して初期化されていないことを確認してください (上記の項目を参照)。
  - プッシュ通知の処理を確認します。プッシュ通知を受信したときに、アプリ開発者が MoEngage SDK に通知していることを確認してください。アプリは、onMessageReceived() コールバック内で **logNotificationReceived()** メソッドを使用してプッシュ通知を作成する必要があります。詳細については、[Push Display Handled by Application](/ja/developer-guide/android-sdk/push/advanced/push-display-handled-by-application) を参照してください。

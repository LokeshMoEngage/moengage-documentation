## 問題

到達可能なユーザーに iOS でプッシュ通知を送信すると、「InvalidProviderToken」エラーが発生します。

## 説明

このエラーは通常、次の場合に発生します。

- AuthKey (.p8 ファイル) をアップロードした箇所で、誤ったチーム ID が指定されている。
- AuthKey (.p8 ファイル) をアップロードした箇所で、誤ったキー ID が指定されている。
- Apple Developer Keys で AuthKey (.p8 ファイル) が失効し、新しいキーが生成されている。

## 解決策

このエラーを解決するには、開発チームが上記の問題を特定して対処する必要があります。

## 問題

プッシュ通知は、アプリがフォアグラウンドまたはバックグラウンドにある場合は機能しますが、アプリが終了した状態では機能しません。この問題は特に Hybrid SDK 統合で発生します。

<Warning>
これは、ReactNative のメソッドを使用してプッシュペイロードを MoEngage に渡す場合の既知の制限です。
</Warning>

## 説明

- 最も一般的な原因は、SDK が正しく初期化されていないことです。詳細については、[SDK Initialization](/ja/developer-guide/android-sdk/sdk-integration/basic-integration/sdk-initialization) のドキュメントを参照してください。

## 解決策

- ReactNative のメソッドを使用してプッシュペイロードを渡している場合は、MoEngage にプッシュペイロードの処理を任せるか、Android ネイティブのメソッドを使用して MoEngage SDK に渡すことを推奨します。
- SDK が初期化されていない場合は、
  - Application クラスの *onCreate()* メソッドで MoEngage SDK を初期化します。
  - SDK がワーカースレッドではなく、*onCreate()* 内のメインスレッドで初期化されていることを確認します。

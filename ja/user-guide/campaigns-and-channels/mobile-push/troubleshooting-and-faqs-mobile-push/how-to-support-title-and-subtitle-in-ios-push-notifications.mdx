title: "iOS プッシュ通知でタイトルとサブタイトルをサポートする方法"
description: "MoEngage で iOS プッシュ通知にタイトルとサブタイトルのサポートを追加します。SDK バージョン 2.4 以上と、アプリでの適切な alert ペイロードの解析が必要です。"
keywords: ["iOS push subtitle", "title and subtitle", "alert payload", "aps alert parsing", "iOS SDK 2.4"]
---

iOS プッシュ通知で、メッセージとともにタイトルとサブタイトルを送信できるようになりました。アカウントでこの機能を有効にするには、次の点を確認してください。

- MoEngage iOS SDK は SDK バージョン 2.4 以降でこの変更をサポートしています。そのため、アプリ（またはアプリユーザー）が 2.4 未満の MoEngage iOS SDK バージョンを使用していないことを確認してください。該当する場合は、MoEngage iOS SDK を最新バージョンに更新してください。
- プッシュ通知のペイロードを解析し、ペイロードから "alert" キーにアクセスしている場合は、解析ロジックが以下に示す両方のバリエーションのプッシュ通知ペイロードをサポートしていることを確認してください。
  - **タイトルとサブタイトルなし**:
    ```json Code
    ...
    "aps" : {
    "alert" : "Push Message",
    "mutable-content" : 1,
    "badge" : 1
    }
    ...
    ```
  - **タイトルとサブタイトルあり:**
    ```json Code
    ...
    "aps" : {
    "alert" : {
        "title": "New Push Title",
        "subtitle" : "New Subtitle - from iOS10",
    "body":"Push Message"
    },
    "mutable-content" : 1,
    "badge" : 1
    }
    ...
    ```
  上記の点を確認したら、MoEngage サポートに連絡して、アカウントでこの機能を有効にしてください。

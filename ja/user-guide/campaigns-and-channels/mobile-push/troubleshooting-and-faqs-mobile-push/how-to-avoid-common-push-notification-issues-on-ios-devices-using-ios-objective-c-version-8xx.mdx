## 問題

Objective C バージョン 8.x.x で、プッシュ通知がデバイスに正常に配信されているにもかかわらず、プッシュキャンペーンのインプレッションがトラッキングされない、画像がレンダリングされないなど、プッシュ通知に関する一般的な問題が発生しています。

<Info>
  プッシュキャンペーンのインプレッションをトラッキングするには、MoEngage ダッシュボードで **Show iOS impressions** トグルがオンになっていることを確認してください。

  ![iOS imp.png](/images/moengage_458274.png)
</Info>

## 解決策

以下の手順を実行します。

1. **各構成について、プロジェクトのメインターゲットで app\_group\_id を確認する**: 構成間で同じ app\_group\_id を追加することも、異なる app\_group\_id を追加することもできます。
   <Info>
     構成で異なる Bundle Identifier を使用しながら同じ app\_group\_id を共有している場合、問題が発生する可能性があります。具体的には、Bundle Identifier が異なり app\_group\_id が同じ 2 つのアプリが同じデバイスにインストールされている場合、Notification Service Extension が失敗する可能性があります。 これを回避するために複数の構成で同じ app\_group\_id を使用できますが、その場合は 1 台のデバイスですべてのアプリを同時にテストできないことに注意してください。
   </Info>
   ![app group.png](/images/moengage_d35dec.png)
2. **SDK の初期化時に app\_group\_id を確認する**:
   - info.plist を使用して SDK を初期化する場合は、info.plist ファイルの MoEngage キー内に APP\_GROUP\_ID キーが存在する必要があります。
   - sdkConfig を使用して SDK を初期化する場合は、AppDelegate ファイル内の sdkConfig 変数に APP\_GROUP\_ID が含まれている必要があります。\
     **info.plist 内の app\_group\_id:**
     ![app id.png](/images/moengage_b4b13a.png)
   **sdkConfig 変数内の app\_group\_id:** 
   <CodeGroup>
   ```objective-c Objective-C wrap
   MOSDKConfig\* sdkConfig = [[MOSDKConfig alloc] initWithAppID: @"XXXXXXXXXXXXXXXX"];
   sdkConfig.moeDataCenter = MODataCenterData_center_0X;
   sdkConfig.appGroupID = @"group.com.XXXXXXXXXXXXXXXX";
   ```
   </CodeGroup>
4. **Notification Service Extension ターゲットを確認する**:
   - **プッシュ通知を有効にする**: 拡張ターゲットの Signing & Capabilities セクションで、必ず Push Notifications を有効にし、AppGroupId を追加してください。
     ![enable.png](/images/moengage_82ff4d.png)
   - **最小デプロイ iOS バージョンを揃える**: Notification Service Extension の最小デプロイ iOS バージョンが、メインアプリの iOS バージョンと一致していることを確認します。 <img alt="support.png" src="/images/moengage_431d64.png" />
5. MORichNotification フレームワークを Notification Service Extension ターゲットに統合します。
   ```objective-c Objective-C
   target 'MoEngageDemo' do
     use_frameworks!
     pod 'MoEngage-iOS-SDK'
   end
   target 'MoEngageNotificationService' do
     use_frameworks! #use use_frameworks only if included in main target as in above scenario
     pod 'MoEngageRichNotification'
   end
   ```
6. NotificationService.m ファイルは次のようになります。
   ```objective-c Objective-C
   #import "NotificationService.h"
   #import 
   @interface NotificationService ()
    
   @property (nonatomic, strong) void (^contentHandler)(UNNotificationContent *contentToDeliver);
   @property (nonatomic, strong) UNMutableNotificationContent *bestAttemptContent;
    
   @end
    
   @implementation NotificationService
    
   - (void)didReceiveNotificationRequest:(UNNotificationRequest *)request withContentHandler:(void (^)(UNNotificationContent * _Nonnull))contentHandler {
       @try {
         	[MORichNotification setAppGroupID: @"group.com.XXXXXXXXXXXXXXXX"];
           self.contentHandler = contentHandler;
           self.bestAttemptContent = [request.content mutableCopy];
           [MORichNotification handleWithRichNotificationRequest:request withContentHandler:contentHandler];
       } @catch (NSException *exception) {
           NSLog(@"MoEngage : exception : %@",exception);
       }
   }
    
   /// Save the image to disk
   - (void)serviceExtensionTimeWillExpire {
       // Called just before the extension will be terminated by the system.
       // Use this as an opportunity to deliver your "best attempt" at modified content, otherwise the original push payload will be used.
       self.contentHandler(self.bestAttemptContent);
   }
   @end
   ```
7. **メインアプリターゲットの Build Phases を確認する**: メインアプリターゲットの Build Phases セクションで、Embed App Extensions / Embed Foundation Extensions セクションを見つけます。**Copy only when installing** オプションがオフになっていることを確認します。
   ![copy.png](/images/moengage_9bb544.png)
8. **構成間で appGroupId を統一する**: プロジェクト内のすべてのスキームと構成（Debug/Release/QA/UAT など）で appGroupId が統一されていることを確認します。
9. **ビルド構成を揃える**: プロジェクトを実行またはアーカイブする際は、メインターゲットと Notification Service Extension ターゲットの Build Configuration が同じスキーム/構成を指していることを確認します。
   ![run.png](/images/moengage_569a68.png)
   ![build.png](/images/moengage_29f224.png)

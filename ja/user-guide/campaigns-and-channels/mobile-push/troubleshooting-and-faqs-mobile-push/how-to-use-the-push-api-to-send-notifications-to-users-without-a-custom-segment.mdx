## 問題

Push API を通じて、一意の ID に基づく特定のユーザーグループに通知を送信できません。通知を送信する前にカスタムセグメントを作成する必要があり、ユーザーを直接ターゲットにしようとする際に非効率になります。

## 解決策

- Push API を使用して一意の ID に基づく特定のユーザーグループにプッシュ通知を送信するには、単一ユーザー Push API を使用します。
- 同じシグネチャまたは ID で API をトリガーし、個々のユーザーごとにユーザー ID を変更します。
- これにより、目的のユーザーセットがプッシュ通知を受信できます。

<Info>
- セグメントを使用して特定のユーザーグループに通知を送信するには、一意の ID を都度変更しながら複数回 API を呼び出すことができます。
- これにより、セグメント内の特定のユーザーをターゲットにして通知を送信できます。
</Info>

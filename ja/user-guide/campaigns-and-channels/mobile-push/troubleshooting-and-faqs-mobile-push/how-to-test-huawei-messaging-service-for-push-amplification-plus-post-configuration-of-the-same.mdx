[こちら](/ja/developer-guide/android-sdk/push/optional/push-amp-plus/configuring-huawei-push-on-mo-engage)で説明されているとおりにアプリケーションに HMS を統合し、MoEngage ダッシュボードでアカウントを設定した後、この記事で説明するガイドラインと手順を確認して検証を行ってください。

**HMS をテストするための前提条件**

- EMUI バージョンを搭載した Huawei Android デバイス

## HMS を検証するための手順

ビルドに応じて環境（TEST/LIVE）を選択し、MoEngage ダッシュボードでキャンペーンを作成します。

1. Engage-\>Campaigns-\> Create Campaign-\>Push Campaign

<img
  alt="Screenshot_2022-09-20_at_11.45.39_AM.png"
  src="/images/moengage_5286d6.png"
  style={{ width:"42%" }}
/>

2. 一般キャンペーンを作成します

Segmentation \> Select Platform _Android_ に移動します。選択するとすぐに、Push Amplification™ Plus を使用してキャンペーンを送信するかどうかを選択するオプションが表示されます。一般プッシュキャンペーンの作成については、[こちら](/ja/developer-guide/android-sdk/push/optional/push-amp-plus/configuring-huawei-push-on-mo-engage)をクリックしてください。

<img
  src="/images/moengage_baa7d9.png"
  alt="Screenshot_2022-09-20_at_11.43.08_AM.png"
  style={{ width:"62%" }}
/>

<img
  src="/images/moengage_c80953.png"
  alt="Screenshot_2022-09-20_at_11.49.50_AM.png"
  style={{ width:"62%" }}
/>

3. TEST CAMPAIGN ボタンをクリックし、以下に示すように、テスト用のユーザーを識別するための属性のいずれかを選択してデバイスをターゲットにします。

識別子には、任意のデバイス識別子（Google Advertising Id、push\_id など）や、ID、メールアドレス、携帯電話番号などの任意のユーザー識別子を使用できます。テストキャンペーンでこれらを使用する前に、MoEngage でユーザーにこれらのプロパティが設定されていることを確認してください。

<Note>
  デバイスのプッシュトークンを使用して HMS 通知をテストする場合は、テストに使用するトークンが HMS プッシュトークンではなく FCM のトークンであることを確認してください。
</Note>

![Screenshot\_2022-09-20\_at\_11.54.42\_AM.png](/images/moengage_020032.png)

4. アプリがプッシュを受信したら、通知をクリックし、その後以下に示すようにユーザーをクリックして、しばらく（2〜3 分）待ちます。

![image6.png](/images/moengage_43b443.png)

5. プッシュが HMS 経由で配信されたことを確認するには、イベント **Notification Clicked Android** をクリックし、以下に示すように値が **hmsPush** の source キーがあるかを確認します。これにより、プッシュが HMS 経由で送信されたことが確認できます。

![image7.png](/images/moengage_e19a32.png)

Source キーが表示されない場合は、こちらの[リンク](/ja/developer-guide/android-sdk/push/optional/push-amp-plus/configuring-hms-push-kit)を参照して、ドキュメントに従って統合手順が完了しているかを確認してください。

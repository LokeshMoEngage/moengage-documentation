## 問題

位置情報ベースのプッシュ通知を使用する際に問題が発生します。

## 解決策

1. AndroidManifest.xml ファイルを開き、以下の依存関係を追加します。

  ![13](/images/13.png)
</Frame>

2. アプリレベルの `build.gradle` ファイルを開き、以下の依存関係を追加します。

<Frame>
  ![14](/images/14.png)
</Frame>

<Frame>
  ![16](/images/16.png)
</Frame>

3. 位置情報トリガー型プッシュキャンペーンを作成するには、[Location Triggered](/ja/developer-guide/android-sdk/push/optional/location-triggered) ドキュメントの以下のセクションを参照してください。

- ジオフェンスの作成
- ジオフェンスに出入りするユーザー
- ジオフェンス内に滞在するユーザー

4. ドキュメントに従って必要な依存関係と権限を追加した後、Android 14 以降のデバイスでアプリを開くと、スクリーンショットに示すようにユーザーの権限が表示されます。

<Frame>
  ![15](/images/15.png)
</Frame>

Android デバイスには、2 つの位置情報権限の設定があります。

- **Allow all the time**
- **Allow only while using the app**: Android 14 以降のデバイスでは、デフォルトでアプリがアクティブな間のみ位置情報へのアクセスが許可されます。
- Android 14 以降のデバイスでは、デフォルトの `"Allow only while using the app"` の位置情報権限により、アプリが閉じられているかバックグラウンドにある場合、ジオフェンスおよび位置情報トリガー型プッシュがブロックされます。位置情報トリガー型キャンペーンがすべての状態で実行されるように、位置情報権限の設定を `"Allow all the time"` に変更してください。

これは、Android 14 以降を実行しているすべてのデバイスのデフォルトの動作です。

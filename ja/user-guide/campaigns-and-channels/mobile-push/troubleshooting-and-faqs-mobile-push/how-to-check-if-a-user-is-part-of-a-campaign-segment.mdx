MoEngage でユーザーがキャンペーンセグメントに含まれているかを確認するには、次の手順に従います。

1. MoEngage ダッシュボードの左側のナビゲーションメニューで **Segments** をクリックし、**Create segment** をクリックします。
2. **Create Segment** ページで、キャンペーンで使用したものと同じセグメント定義を使用します。
3. キャンペーンが最初に送信された時間範囲を指定します。
4. **AND** を使用してクエリを追加します。**AND** クエリで、メールアドレス、ユーザー ID、その他の識別子などのユーザー属性でユーザーを検索します。
5. **Show count** をクリックします。結果にユーザープロファイルが表示された場合、そのユーザーはセグメントに含まれていました。そうでない場合、クエリの結果は 0 件と表示されます。

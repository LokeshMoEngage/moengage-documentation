MismatchsenderId は、主に MoEngage ダッシュボードにアップロードされた秘密鍵と Android プロジェクト内の google-services.json ファイルとの競合が原因で、プッシュ通知の送信中に発生することがあります。秘密鍵と json ファイルは同じプロジェクトのものを使用してください。

### 誤った google-services.json ファイル

すべての Firebase プロジェクトには **Project ID** があります。正しい json ファイルかどうかを確認するには、**いくつか**の点を確認します。

- この Project ID が、Android アプリに含まれる google-services.json ファイル内のものと同じである必要があります。

<img alt="Screenshot 2024-02-01 at 1.37.44 PM.png" src="/images/moengage_795adb.png" />

- マニフェストファイル内のパッケージ名も、google-services.json ファイル内の **package name** と一致している必要があります

<img alt="Screenshot 2024-02-01 at 2.40.20 PM.png" src="/images/moengage_5f40fd.png" />

### MoEngage ダッシュボード上の誤った秘密鍵

正しい秘密鍵をアップロードしたかどうかを確認するには、秘密鍵内の project\_id が Firebase Project ID と一致している必要があります。

秘密鍵の json ファイルは任意のテキストエディタで開くことができ、値がプロジェクト ID である **project\_id** キーが含まれています。

<img alt="Screenshot 2024-02-01 at 2.37.14 PM.png" src="/images/moengage_05c0d9.png" />

秘密鍵は通常、サービスアカウントページから生成されます。すでに鍵がある場合は、新しい鍵を**生成しないでください**。

## 問題

Swift バージョン 7.x.x を使用するデバイスにプッシュ通知が正常に配信されているにもかかわらず、プッシュキャンペーンのインプレッションがトラッキングされない、画像がレンダリングされないなど、プッシュ通知に関するよくある問題が発生しています。

<Info>
  プッシュキャンペーンのインプレッションをトラッキングするには、MoEngage ダッシュボードで **Show iOS impressions** トグルがオンになっていることを確認してください。

  ![iOS imp.png](/images/moengage_a3edc2.png)
</Info>

## 解決策

次の手順を実行します。

1. **各構成でプロジェクトのメインターゲットに app\_group\_id があるか確認する**：
   構成間で同じ app\_group\_id を追加することも、異なるものを追加することもできます。
   <Info>
     構成で異なる Bundle Identifier を使用しながら同じ app\_group\_id を共有している場合、問題が発生する可能性があります。具体的には、Bundle Identifier が異なり app\_group\_id が同じ 2 つのアプリが同じデバイスにインストールされている場合、Notification Service Extension が失敗することがあります。
     これを回避するために、複数の構成で同じ app\_group\_id を使用できますが、その場合は 1 台のデバイスですべてのアプリを同時にテストすることはできない点に注意してください。
   </Info>
   ![app group.png](/images/moengage_053674.png)
2. **SDK の初期化時に app\_group\_id があるか確認する**：
   - info.plist を使用して SDK を初期化している場合は、info.plist ファイルの MoEngage キー内に APP\_GROUP\_ID キーが存在している必要があります。
   - sdkConfig を使用して SDK を初期化している場合は、AppDelegate ファイル内の sdkConfig 変数に APP\_GROUP\_ID が存在している必要があります。\
     **info.plist 内の app\_group\_id：**
   ![app id.png](/images/moengage_667e35.png)
   **sdkConfig 変数内の app\_group\_id：**
   ```swift Swift
   var sdkConfig = MOSDKConfig.init(appID: "XXXXXXXXXXXXXXXX")
   sdkConfig.moeDataCenter = DATA_CENTER_0X
   sdkConfig.appGroupID = "group.com.XXXXXXXXXXXXXXXX"
   //if SDK initialized without sdkConfig in AppDelegate file
   MoEngage.setAppGroupID("group.com.moengage.MIPL567.demo")
   ```
   ```Objective-C Objective-C
   MOSDKConfig\* sdkConfig = [[MOSDKConfig alloc] initWithAppID: @"XXXXXXXXXXXXXXXX"];
   sdkConfig.moeDataCenter = DATA_CENTER_0X;
   sdkConfig.appGroupID = @"group.com.XXXXXXXXXXXXXXXX";
   //if SDK initialized without sdkConfig in AppDelegate file
   [MoEngage setAppGroupID: @"group.com.XXXXXXXXXXXXXXXX"];
   ```
3. **Notification Service Extension ターゲットがあるか確認する**：
   - **Push Notifications を有効にする**：Extension ターゲットの Signing & Capabilities セクションで、必ず Push Notifications を有効にし、AppGroupId を追加してください。
   ![enable.png](/images/moengage_23f29a.png)
   - **最小デプロイ iOS バージョンを揃える**：Notification Service Extension の最小デプロイ iOS バージョンが、メインアプリの iOS バージョンと一致していることを確認します。
   ![support.png](/images/moengage_cb3695.png)
4. MORichNotification フレームワークを Notification Service Extension ターゲットに統合します。
   ```swift Swift
   target 'MoEngageDemo' do
     use_frameworks!
     pod 'MoEngage-iOS-SDK'
   end
   target 'MoEngageNotificationService' do
     use_frameworks! #use use_frameworks only if included in main target as in above scenario
     pod 'MORichNotification'
   end
   ```
5. NotificationService.swift ファイルは次のようになります。
   ```swift Swift
   import UserNotifications
   import MORichNotification
    
   class NotificationService: UNNotificationServiceExtension {
    
       var contentHandler: ((UNNotificationContent) - Void)?
       var bestAttemptContent: UNMutableNotificationContent?
    
       override func didReceive(_ request: UNNotificationRequest, withContentHandler contentHandler: @escaping (UNNotificationContent) - Void) {	
         MORichNotification.setAppGroupID("group.com.XXXXXXXXXXXXXXXX")
         self.contentHandler = contentHandler
         bestAttemptContent = (request.content.mutableCopy() as? UNMutableNotificationContent)
         MORichNotification.handle(request, withContentHandler: contentHandler)
       }
       
       override func serviceExtensionTimeWillExpire() {
           // Called just before the extension will be terminated by the system.
           // Use this as an opportunity to deliver your "best attempt" at modified content, otherwise the original push payload will be used.
           if let contentHandler = contentHandler, let bestAttemptContent =  bestAttemptContent {
               contentHandler(bestAttemptContent)
           }
       }
   }
   ```
6. **メインアプリターゲットの Build Phases を確認する**：メインアプリターゲットの Build Phases セクションで、Embed App Extensions / Embed Foundation Extensions セクションを見つけます。**Copy only when installing** オプションのチェックが外れていることを確認します。

![copy.png](/images/moengage_cfdd8e.png)

7. **構成間で appGroupId を統一する**：プロジェクト内のすべてのスキームと構成（例：Debug/Release/QA/UAT）で appGroupId が一致していることを確認します。
8. **ビルド構成を揃える**：プロジェクトを実行またはアーカイブする際は、メインターゲットと Notification Service Extension ターゲットの Build Configuration が同じスキーム/構成を指していることを確認します。

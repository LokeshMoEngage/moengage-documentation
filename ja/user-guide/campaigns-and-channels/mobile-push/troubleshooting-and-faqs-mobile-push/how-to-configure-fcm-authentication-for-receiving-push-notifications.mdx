## 問題

送信者 ID の不一致により、MoEngage ダッシュボードからのプッシュ通知が Android デバイスで受信されません。

## 手順

Firebase Cloud Messaging (FCM) 認証を設定するには、次の手順を実行します。

1. Firebase コンソールを開き、**Projects settings** セクションに移動します。
2. **Service accounts** タブで **Generate new private key** をクリックし、選択した言語に関係なく、JSON 形式で秘密鍵をダウンロードします。
    <img alt="新しい秘密鍵の生成.png" src="/images/moengage_9f36c9.png" />
3. ダウンロードした秘密鍵の JSON ファイルを開き、project\_id が Android プロジェクトのルートディレクトリにある google-services.json ファイル内のものと一致していることを確認します。 <img alt="project id google services.png" src="/images/moengage_57c032.png" />
    <img alt="project id.png" src="/images/moengage_f89e6f.png" />
4. MoEngage ダッシュボードの左側のナビゲーションメニューで、**Settings** \> **Channels** \> **Push** に移動します。
5. Push ページで **App push** タブをクリックし、**Android (FCM)** タブをクリックします。
6. **Private key file (Recommended)** をクリックします。
7. **Choose file** ボタンを使用して秘密鍵の JSON ファイルをアップロードし、**Save** をクリックします。   <img alt="ファイルの選択.png" src="/images/moengage_b4ed21.png" />\
   統合開発環境 (IDE) の Logcat ウィンドウに、push\_id を含む report 呼び出しのリクエストボディが表示され、デバイスとプロジェクトが MoEngage ダッシュボードに登録されます。
   ![register.png](/images/moengage_ec19ed.png)
8. MoEngage ダッシュボードで、**User Profile** \> **User Info** \> **Reachability** \> **Push.** に移動します。緑色のチェックマークは、Android デバイスがプッシュ通知を受信できることを示します。 <img alt="プッシュ到達可能性（編集済み）.png" src="/images/moengage_35ff1e.png" />
9. **TEST PUSH** をクリックします。**STATUS : SENT** と表示され、デバイスに到達可能で通知が受信されたことを示します。
    <img alt="テストプッシュ（編集済み）.png" src="/images/moengage_ec111b.png" />
   <img alt="テストプッシュ 2.png" src="/images/moengage_6c92f4.png" />

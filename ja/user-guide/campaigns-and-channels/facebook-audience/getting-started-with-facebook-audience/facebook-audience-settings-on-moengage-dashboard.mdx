---
title: "MoEngage ダッシュボードでの Facebook Audience 設定"
description: "Facebook アカウントを MoEngage に接続するための 1 回限りの設定を行います。カスタムオーディエンスキャンペーン用に App ID、シークレット、広告アカウントを構成します。"
---

この記事では、Facebook に必要な 1 回限りの設定について説明します。この設定により、MoEngage と Facebook アカウントの間に接続が確立されます。設定を進める前に、ドキュメント [カスタムオーディエンス連携のための Facebook 設定](/ja/user-guide/campaigns-and-channels/facebook-audience/getting-started-with-facebook-audience/understanding-facebook-setup-for-custom-audience-integration) で説明している必要な構成に従って、アプリと広告アカウントを準備してください。

<Info>
  - これは 1 回限りの設定です。この手順を再度行う必要があるのは、アプリシークレットまたはユーザートークンが無効になった場合のみです。
  - FB の設定は、MoEngage ダッシュボードへの Admin アクセス権を持つユーザーが追加/変更できます。詳細については、[アクセスロール](/ja/user-guide/settings/account/team-management/access-roles) を参照してください。
</Info>

準備ができたら、以下の説明に従って次のフィールドを取得します。

Facebook アカウントを MoEngage と連携するには、Settings -\> App marketplace に移動し、Facebook audience を選択します。

![FB Audience.png](/images/moengage_dcf843.png)

1. **App ID:**

- [https://developers.facebook.com/apps/](https://developers.facebook.com/apps/ "https://developers.facebook.com/apps/") に移動します。同期するアプリを選択します。App ID は左側の上部バーに表示されています。
- または、[https://business.facebook.com/settings/apps](https://business.facebook.com/settings/apps "https://business.facebook.com/settings/apps") に移動することもできます。同期するアプリを選択し、アプリ名の下に表示されている App ID をコピーします。

2. **App secret**:

- [FB アプリダッシュボード](https://developers.facebook.com/apps) で、Settings \> Basic に移動します。
- App secret の下にある Show をクリックします。
- プロンプトが表示された場合は、パスワードを入力すると App secret が表示されます。

3. **Access token:**

- [FB アプリダッシュボード](https://developers.facebook.com/apps) に移動し、MoEngage と同期するアプリを選択します。
- **Marketing API** \> **Tools** \> **Get Access Token** に移動します。
- ads\_management と ads\_read の権限を選択します。
- **Get Token** ボタンをクリックします。
- または、[こちら](https://developers.facebook.com/docs/marketing-api/get-started/authentication) の説明に従って、FB の Graph API Explorer からアクセストークンを取得することもできます。

![mceclip1.png](/images/moengage_0ddc25.png)

4. **Business ID **(任意)**:**

このフィールドは、ここで使用するアクセストークンのユーザーが複数の FB ビジネスアカウントにアクセスでき、特定の 1 つのビジネスアカウントとのみ同期したい場合にのみ必要です。取得するには、[FB ビジネス情報ページ](https://business.facebook.com/settings/info) に移動します。

![mceclip2.png](/images/moengage_041702.png)

すべてのフィールドを入力したら、Connect to Facebook ボタンをクリックします。

接続に成功すると、ログインしているユーザーに関連付けられているすべての広告アカウントのリストが取得されます。そのうちの 1 つをデフォルトとして選択できます。

![Screenshot\_2021-01-28\_at\_6.37.50\_PM.png](/images/moengage_d0c1ec.png)

ログインしているユーザーが FB ビジネスアカウントにアクセスできなくなった場合など、後でこれらの設定を変更したい場合は、Disconnect Facebook をクリックします。フィールドを再度入力し、Connect to FB をクリックします。

<Note>
  アカウントの接続時やオーディエンスの同期時に `business_management` 権限エラーなどのエラーが発生した場合は、[FB Audience の一般的なエラーのトラブルシューティング](/ja/user-guide/campaigns-and-channels/facebook-audience/troubleshooting-and-faqs-facebook-audience/troubleshoot-common-errors-in-fb-audience) を参照してください。
</Note>

<Info>
  - これらのフィールドは、アカウントからすべての広告アカウントを取得するために必要です。また、キャンペーンの実行時に FB への API 呼び出しを行うたびに、アクセストークンが必要になります。
  - 上記で入力したアクセストークンは短期間有効なアクセストークンで、数時間しか有効ではありません。このアクセストークンを提供いただくと、MoEngage 側で長期間有効なアクセストークンに変換して保存し、トークンの有効期限も延長します。
  - 長期間有効なアクセストークンの有効期限は 60 日または無期限など、より長くなります。トークンの有効性は定期的に確認され、今後 7 日以内に期限切れになる場合は、トークンの有効期限が延長されます。延長されたトークンを取得するには、App ID と App secret が必要です。
  - ユーザートークンまたは App secret が無効になった場合は、設定ページのフィールドを更新するよう通知されます。
  - アクセストークンがどの Business ID にもマッピングされていない場合、ユーザーに関連付けられたデフォルトの広告アカウントが取得され、権限エラー (このオーディエンスを作成/編集するにはビジネスアカウントが必要です) が発生します。Meta の設定で、アクセストークンが適切な Business ID にマッピングされていることを確認してください。

  Facebook に接続したら、[この記事](/ja/user-guide/campaigns-and-channels/facebook-audience/create/create-a-facebook-audience-campaign) の説明に従って FB Audience キャンペーンの作成を開始できます。
</Info>

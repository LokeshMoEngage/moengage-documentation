# Campaign Analytics

<Info>
  すべての指標は、アプリのタイムゾーンで計算および表示されます。
</Info>

キャンペーン分析セクションには、次の情報が含まれます。

| フィールド | 説明 |
| --- | --- |
| Eligible users | セグメンテーション条件と、該当する場合はトリガー条件を満たしたことにより、キャンペーンの対象となったユーザーの数です。 |
| Attempted | 対象ユーザーのうち、キャンペーンが Facebook に渡す識別子 (Device Identifier (Device ID) または Customer Match Identifiers (Mobile Number、Email)) を少なくとも 1 つ持っているユーザーの数です。同期できるのはこれらのユーザーのみです。ユーザーが別のチャネル (プッシュなど) で到達可能であっても、Attempted ユーザーにはなりません。これらの識別子を少なくとも 1 つ持っていない場合、MoEngage はそのユーザーを Facebook に送信できないため、ここではカウントされません。 |
| Successfully synced | Attempted ユーザーのリストのうち、Facebook コンソールに追加されたユーザーの数です。 |
| Conversions | 正常に同期されたユーザーのうち、アトリビューションウィンドウ内にコンバージョンイベントを受け取ったユーザーのユニーク数です。 |
| Conversion events | 正常に同期されたユーザーのうち、アトリビューションウィンドウ内にコンバージョンイベントを受け取ったユーザーの数です。 |

<Note>
  - Conversion Goal はキャンペーンの作成時には任意です。上記のコンバージョン関連の指標は、キャンペーンの作成時にこれを追加した場合に測定および表示されます。
  - Successfully synced はバッチレベルで確認されます。MoEngage はユーザーをバッチ単位で Facebook コンソールに送信し、Facebook はバッチを受信したことを確認します。確認済みのバッチ内の一部の個別ユーザーは、Facebook の内部処理中に報告されることなく除外される場合があるため、この指標にはそうした個別の除外が反映されないことがあります。
  - Facebook オーディエンスが Facebook 広告センターで同期されるまでには、6〜48 時間かかります。
</Note>

上記の表の指標は、すべての配信タイプで利用できます。

### 定期キャンペーンの Campaign Analytics

定期キャンペーンの場合、上記の統計は親キャンペーンについて表示されます。子キャンペーン (キャンペーンの各実行インスタンス) の統計は、これらの統計の下にある表に表示されます。

![定期的な Facebook Audience キャンペーンの各実行について、Eligible users、Attempted、Successfully synced、Conversion events、Conversions を示す Child Campaign Performance の表。](/images/facebook-audience-child-campaign-stats.png)

## キャンペーン統計のフィルター

これらのフィルターは、定期キャンペーンとイベントトリガーキャンペーンでのみ利用できます。

1. **Aggregation Type**: ここでは Total/Average を選択できます。
2. **Date Range**: キャンペーンインスタンスに関する情報を表示する日付範囲を選択できます。

キャンペーン失敗の内訳セクションには、キャンペーンの実行中に発生したエラーや失敗が一覧表示されます。これらには、以下に示すように、アクセス関連のエラー、データ関連の失敗、API/サービス関連の失敗があります。

これらのエラーの理解に関する詳細については、[FB Audience の一般的なエラーのトラブルシューティング](/ja/user-guide/campaigns-and-channels/facebook-audience/troubleshooting-and-faqs-facebook-audience/troubleshoot-common-errors-in-fb-audience)を参照してください。

# Campaign Info

Campaign Info タブには、次の情報が含まれます。

| フィールド | 説明 |
| --- | --- |
| Segmentation | このセクションには、キャンペーン用に選択したターゲットセグメントに関する情報が含まれます。 |
| Qualification Criteria | このセクションには、ターゲットセグメント内のユーザーがキャンペーンの対象となるために満たす必要があるフィルターと条件に関する情報が含まれます。 |
| Facebook audience | このセクションには、オーディエンスがカスタムオーディエンスに追加されるか、カスタムオーディエンスから削除されるかに関する情報が含まれます。 |
| Goals | このセクションには、キャンペーンに設定された目標に関する情報が含まれます。 |
| Timing | このセクションには、キャンペーンインスタンスの開始時刻と終了時刻を含む、キャンペーンの配信スケジュールに関する情報が含まれます。 |

# よくある質問

<AccordionGroup>
  <Accordion title="MoEngage で同期済みと表示されるユーザーと、Facebook Ads Manager で同期されたユーザーに差があるのはなぜですか？">
    この差は、次の 2 つの要因によって生じる可能性があります。

    - **同期の遅延:** MoEngage がオーディエンスを同期した後、Facebook がそれを Facebook Ads Manager で利用可能にするまでに 6〜48 時間かかります。この期間より前に確認すると、数がまだ一致しない場合があります。
    - **バッチレベルの確認:** MoEngage はユーザーをバッチ単位で Facebook に送信し、Facebook がバッチの受信を確認した時点でユーザーを **Successfully synced** としてカウントします。Facebook は内部処理中に (たとえば識別子が一致しない場合に)、確認済みバッチ内の一部の個別ユーザーを、その除外を報告することなく除外する場合があります。その結果、最終的に Facebook カスタムオーディエンスに表示されるユーザー数が、MoEngage の **Successfully synced** の数より少なくなることがあります。
  </Accordion>
  <Accordion title="Attempted の数が Eligible の数より少ないのはなぜですか？">
    Eligible users は、セグメンテーション条件とトリガー条件に基づいてキャンペーンの対象となるすべてのユーザーです。ユーザーが **Attempted** としてカウントされるのは、キャンペーンが Facebook に渡す識別子 (Device ID、Mobile Number、または Email) を少なくとも 1 つ持っている場合のみです。これらの識別子をいずれも持っていない対象ユーザーは Facebook に送信できないため、Attempted としてカウントされません。
  </Accordion>
  <Accordion title="プッシュで到達可能なユーザーが Facebook に同期されませんでした。なぜですか？">
    プッシュなどの別のチャネルで到達可能であっても、ユーザーを Facebook に同期できるとは限りません。Facebook Audience の同期は、キャンペーンが Facebook Marketing API に渡す識別子 (Device ID、Mobile Number、または Email) をユーザーが少なくとも 1 つ持っているかどうかに依存します。ユーザーがこれらの識別子をいずれも持っていない場合、プッシュで到達可能であっても、MoEngage はそのユーザーを Facebook に送信できません。
  </Accordion>
</AccordionGroup>

この記事では、Google Postmaster アカウントのセットアップ手順について説明します。これは、MoEngage UI で[ドメインレピュテーション](/ja/user-guide/campaigns-and-channels/email/deliverability/domain-reputation/domain-reputation-in-moengage)データを受け取るために必須の手順です。Google Postmaster アカウントをセットアップするには、以下の手順を実行します。

1. お客様側で [Google Postmaster を設定](https://support.google.com/a/answer/9981691?hl=en&visit_id=638589862558411978-3959488909&rd=2#)します。
2. ドメインの Google Postmaster の [READ アクセス権](https://support.google.com/a/answer/9981691?hl=en&visit_id=638589862558411978-3959488909&rd=2#)を [MoEngage の Google Postmaster アカウント](mailto:googlepostmoe@moengage.com)と共有します。

# Google Postmaster の設定

お客様側で Google Postmaster を設定するには、以下の手順を実行します。

1. ブラウザで Gmail アカウントにログインします。
2. [Google Postmaster Tools](https://postmaster.google.com/u/0/managedomains?pli=1) に移動します。
3. 右下にある **Add**（\+）ボタンをクリックします。
4. ルートドメイン（example.com）を追加します。
5. ドメインの **TXT** レコードまたは **CNAME** レコードをコピーします。
6. DNS サーバーに移動し、TXT レコードまたは CNAME レコードのいずれかを追加します。
7. Google Postmaster に移動し、ドメインを検証します。公開した DNS レコードが反映されるまでに最大 24 時間かかる場合があります。
8. ルートドメイン（example.com）が検証されたら、**Add**（\+）アイコンをクリックして、メールに使用するすべてのサブドメインを追加します。ルートドメインがすでに検証されている場合、サブドメインは追加の DNS レコードを追加しなくても検証されます。

## MoEngage の Google Postmaster アカウントとの READ アクセス権の共有

ドメインの読み取りアクセス権を MoEngage の Google Postmaster アカウントと共有するには、Google Postmaster アカウントで以下の手順を実行します。

1. Google Postmaster アカウントにログインします。
2. 検証済みのドメインにマウスを合わせ、<Icon icon="ellipsis-stroke-vertical" type="solid" /> をクリックします
3. **Manage Users** をクリックします。
4. 右下にある **Add** \+ をクリックします。
5. MoEngage の Google Postmaster アカウントを追加し、**Next** をクリックします。MoEngage の Google Postmaster アカウントは [googlepostmoe@moengage.com](mailto:googlepostmoe@moengage.com) です。
6. すべてのドメインとサブドメインについて、前の手順を繰り返します。

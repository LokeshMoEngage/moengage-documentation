# 概要

メールのパフォーマンスは、メールの配信指標とエンゲージメント指標に基づいて評価されます。これには次のものが含まれます。

- 配信指標は、送信数に対する配信数の比率、バウンスの発生、遅延（deferral）などの要素を評価します。
- 一方、エンゲージメント指標は、ポジティブな結果からネガティブな結果まで、より幅広い指標を含みます。
  - ポジティブなエンゲージメント指標には、配信、開封、クリック、コンバージョンなどの指標があります。
  - 反対に、ネガティブなエンゲージメント指標には、スパム苦情やメールの配信停止のケースが含まれます。

メールパフォーマンスを向上させるには、ネガティブなエンゲージメントを低く抑えながら、配信とポジティブなエンゲージメントを高める必要があります。そのためには、次のことを実施する必要があります。

- [履歴を分析する](/ja/user-guide/campaigns-and-channels/email/deliverability/email-performance/optimize-the-email-performance#analyze-your-history)
- [改善すべき領域を見つける](/ja/user-guide/campaigns-and-channels/email/deliverability/email-performance/optimize-the-email-performance#find-areas-of-improvement)
- [キャンペーンを計画する](/ja/user-guide/campaigns-and-channels/email/deliverability/email-performance/optimize-the-email-performance#plan-your-campaigns)

# 履歴を分析する

メールパフォーマンスを向上させるには、改善が必要な具体的な領域を特定することが不可欠です。そのためには、過去6か月間のメールパフォーマンスデータを振り返って評価し、繰り返し発生するパターンがないかを確認する必要があります。メールパフォーマンスの履歴を分析するには、次の項目を確認します。

- 配信指標とエンゲージメント指標の傾向
- ドメインレピュテーションのデータ
- スパム苦情率
- アクティブユーザーベースの成長
- 受信トレイ到達率（インボックスプレースメント）レポート

最新の傾向だけに注目して全体的な傾向を見落とすと、数か月にわたるメールパフォーマンスの緩やかな低下を見逃す可能性があります。メールパフォーマンスの履歴を分析する中で問題が見つかった場合は、[デバッグ](/ja/user-guide/campaigns-and-channels/email/deliverability/self-debugging-email-deliverability-issues)と[修復](/ja/user-guide/campaigns-and-channels/email/deliverability/domain-reputation/issues-with-domain-reputation-and-preventive-measures)を行い、メール計画をランプアップする必要があります。

# 改善すべき領域を見つける

メールパフォーマンスを分析し、分析中に特定した問題に対処した後は、改善の余地がある領域を特定することが重要です。メールパフォーマンスを向上させることができる次の領域と、それぞれの領域に対する提案を検討してください。

# キャンペーンを計画する

到達率やパフォーマンスの問題はすぐには解決できないため、メールキャンペーンを計画することが重要です。各最適化オプションを効果的に実施するための戦略を策定してください。

- [メールパフォーマンスチェックリスト](/ja/user-guide/campaigns-and-channels/email/deliverability/email-performance/checklist-to-review-email-performance)を実行して、すべての指標を綿密に確認・監視します。
- 学んだことに応じて計画を見直し、調整します。
- これを四半期ごとに繰り返します。

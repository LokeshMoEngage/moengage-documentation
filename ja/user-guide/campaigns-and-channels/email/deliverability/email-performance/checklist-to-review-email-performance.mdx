---
title: "メールパフォーマンスを確認するためのチェックリスト"
description: "このチェックリストを使用して、MoEngage でメールのパフォーマンスと送信者レピュテーションを確認します。ランプアップ中やレピュテーション低下の診断時に、主要な要因を評価できます。"
---

パフォーマンスやレピュテーションの問題が見られた場合は、送信者/ドメインごとに以下を確認してください。ランプアップ中の顧客の監視、レピュテーション低下の分析、またはレピュテーション改善に向けた進捗の評価を行う際には、これらすべての要因を評価することが重要です。

<Info>
  これらはすべて、異なるサブドメインごとに実施する必要があります。
</Info>

| **基準** | **監視すべき要因** |
| --- | --- |
| [コンプライアンス](https://www.moengage.com/blog/email-compliance/) | <ul><li>すべてのコンプライアンス要件を満たしていますか？</li><li>満たしていない場合は、すべてを一時停止し、まずこれを修正してください。</li></ul> |
| メール設定 | <ul><li>[メール設定](/ja/user-guide/campaigns-and-channels/email/getting-started-with-email/email-setup-and-content-validation)は引き続き正常ですか？</li><li>正常でない場合は、問題のあるドメイン/IP セットからの送信をすべて一時停止し、修正してから再開してください。</li></ul> |
| 送信量 | <ul><li>送信量はランプアップ計画（該当する場合）に沿っていますか？ <ul><li>沿っていない場合は、一時停止 -\> 後戻り -\> すべての指標が正常であることを確認 -\> 再開 の順に対応してください。</li></ul></li><li>送信量の急増はありましたか？ <ul><li>送信量の急増とは、過去 30 日間の最大送信量の 150% を超える送信量を指します。</li><li>急増があった場合、なぜ発生したのでしょうか？再発を防ぐためにどのような対策を講じましたか？</li><li>頻度を減らしてメール開封者にのみ送信し、各 Postmaster に問題の原因と、回復/再発防止のために講じた措置を説明してください。</li></ul></li></ul> |
| 送信頻度 | <ul><li>IP を温かい状態に保つのに十分な回数を、週/隔週ごとに送信していますか？ <ul><li>送信していない場合は、他のライフサイクルのユースケースを試し、Postmaster に送信が散発的である理由を説明してください。</li></ul></li><li>使用している RPM はいくつですか？ <ul><li>遅延/配信の遅れ/不定期な送信がある場合は、RPM を下げてください。</li></ul></li></ul> |
| 配信率 | <ul><li>平均配信率はどのくらいですか？ <ul><li>98% を下回っている場合は、その原因を確認してください。</li></ul></li><li>ハードバウンスが多い場合は、オーディエンスの収集ポイントを保護し、ダブルオプトインを導入し、ウェルカムキャンペーンを送信し、ハードバウンスが想定どおりに自動抑制されているかどうかを確認してください。</li><li>ソフトバウンスが多い場合は、エラーの説明を確認し、それに応じて修正してください。</li></ul> |
| 遅延 | <ul><li>遅延 \[event: Event Deferred\] はありますか？ <ul><li>ある場合は、1 日一時停止してキューをクリアし、少ない送信量と低い RPM で再開し、Postmaster サポートに連絡してください。</li></ul></li></ul> |
| 開封率とクリック率 | <ul><li>すべての ISP におけるユニーク開封率は[ベンチマーク](https://info.moengage.com/thank-you-resources-email-benchmarks-report-2023?submissionGuid=998837dc-1063-47e5-b7aa-f78c0442e603)と同等ですか？ <ul><li>同等でない場合は、送信戦略を見直してください。</li></ul></li></ul> |
| スパム苦情（Gmail） | <ul><li>スパム率がしきい値を超えていますか？ <ul><li>超えている場合は、[ユーザー収集ソース](/ja/user-guide/campaigns-and-channels/email/deliverability/best-practices/best-practices-to-be-followed-while-collecting-user-emails)を確認し、適切な期待値が設定されているか、[送信パターン](/ja/user-guide/campaigns-and-channels/email/deliverability/best-practices/best-practices-regarding-sending-patterns)が最適か、コンテンツがユーザーに関連しているかを確認してください。</li></ul></li></ul> |
| スパム苦情（統計から） | <ul><li>スパム率がしきい値を超えていますか？ <ul><li>超えている場合は、[ユーザー収集ソース](/ja/user-guide/campaigns-and-channels/email/deliverability/best-practices/best-practices-to-be-followed-while-collecting-user-emails)を確認し、適切な期待値が設定されているか、[送信パターン](/ja/user-guide/campaigns-and-channels/email/deliverability/best-practices/best-practices-regarding-sending-patterns)が最適か、コンテンツがユーザーに関連しているかを確認してください。</li></ul></li></ul> |
| ドメインと IP のレピュテーション（Gmail） | <ul><li>[ドメインレピュテーション](/ja/user-guide/campaigns-and-channels/email/deliverability/domain-reputation/issues-with-domain-reputation-and-preventive-measures)は LOW/BAD ですか？ <ul><li>該当する場合は、すべてを一時停止し、低下の根本原因を調査し、根本的な問題を修正し、Google Postmaster サポートに連絡し、ゆっくりと再開してランプアップしてください。</li></ul></li></ul> |
| SNDS ステータス（Microsoft） | <ul><li>[フィルター済みステータス](/ja/user-guide/campaigns-and-channels/email/getting-started-with-email/email-glossary#filtered-results-in-snds)は RED ですか？ <ul><li>該当する場合は、すべてを一時停止し、低下の根本原因を調査し、根本的な問題を修正し、Microsoft Postmaster サポートに連絡し、ゆっくりと再開してランプアップしてください。</li></ul></li></ul> |
| 受信トレイ配置 | <ul><li>全体の配置率は 95% を下回っていますか？ <ul><li>特定のドメインでのみ低くなっていますか？</li><li>他のすべての指標（パフォーマンス、レピュテーション、苦情）を確認し、それに応じて修正してください。</li></ul></li></ul> |
| ブロックリスト | <ul><li>IP やドメインがブロックリスト/ブラックリストに掲載されていますか？ <ul><li>ブロックは、ソフトバウンスの理由を確認することで特定できます。</li><li>掲載されている場合は、削除を申請してください。</li></ul></li></ul> |
| 次のステップ | <ul><li>過去 6 か月間の傾向を確認し、ギャップを見つけて最適化してください。</li><li>[ベストプラクティス](/ja/user-guide/campaigns-and-channels/email/deliverability/best-practices/best-practices-for-email-deliverability)に従ってください。</li></ul> |

# 概要

スパムトラップとは、メールボックスプロバイダーがメール送信者のメールリスト管理の実践状況を評価するために作成または転用したハニーポットアドレスです。スパムトラップのアドレスは有効なため、メールは配信されますが、メールに対してエンゲージすることは決してありません。  
スパムトラップの主な目的は、スパマーやリスト管理が不十分な送信者を検出することです。トラップには次の 3 種類があります。

- **プリスティントラップ**: 未承諾のメールを送信する送信者を検出するトラップです。プリスティンスパムトラップは、実在の人物が一度も使用したことのないメールアドレスで、スパムメールを特定するためだけに作成されます。
- **リサイクルトラップ**: リストの衛生管理を行っていない送信者を検出するトラップです。リサイクルトラップは、ユーザーに放棄され、しばらくバウンスが続いた後に、メールボックスプロバイダーによってトラップに転用された古いメールアドレスです。
- **タイポトラップ**: メールのベストプラクティスに従っているかどうかで送信者を検出するトラップです。タイポトラップは、gail.com、yaho.com、homail.com など、主要なドメインの入力ミスを含むアドレスです。確認済みオプトインを実施し、非アクティブユーザーのサンセット（配信対象からの除外）を行っているメール送信者は、これらのトラップに引っかかることはありません。

# スパムトラップがメールリストに紛れ込む理由

スパムトラップがメールに登録したり、メールにエンゲージしたりすることはありません。スパムトラップはさまざまな経路でメールリストに紛れ込む可能性があります。その一部を以下に示します。

- 購入したリスト、ソーシャルメディアのスクレイピング、またはあらゆる種類の明示的なサインアップによってユーザーを収集している場合、トラップに引っかかる可能性が高くなります。
- バウンスしたユーザーを永続的に抑制していない場合、リサイクルトラップに引っかかる可能性が高くなります。通常、ベンダーを変更する際に、以前に抑制されていたユーザーを抑制しないと、それらのユーザーがリストに紛れ込むことがあります。
- エンゲージしていないユーザーのサンセットを行わないと、リスト内のトラップは増え続けます。

# スパムトラップに引っかかった場合の影響

リスト管理のベストプラクティスに従っている送信者は、スパムトラップに引っかかることはありません。そのため、継続的にスパムトラップに引っかかる送信者はスパマーとみなされる可能性があります。程度の差はありますが、基本的に次のような影響が考えられます。

- 配信の遅延（メールのレート制限と延期）
- 配信率の低下（メールのソフトバウンス）
- エンゲージメントの低下（メールが迷惑メールフォルダに振り分けられる可能性）
- ドメインおよび IP レピュテーションの低下

# スパムトラップを回避するための予防策

スパムトラップがデータベースに紛れ込み、その数が増えるのを防ぐには、以下の管理のベストプラクティスに従ってください。

- [ユーザー収集方法](/ja/user-guide/campaigns-and-channels/email/deliverability/best-practices/best-practices-to-be-followed-while-collecting-user-emails)がクリーンであることを確認します。
- ハードバウンスは直ちに抑制します。別のベンダーに移行する場合でも、抑制された状態が維持されるようにしてください。ハードバウンスを抑制する方法については、[こちら](/ja/user-guide/campaigns-and-channels/email/deliverability/email-delivery-rates#reduce-hard-bounce)を参照してください。
- 9 か月間アクティビティのない非アクティブユーザーはサンセットし、メール配信から永続的に抑制します。

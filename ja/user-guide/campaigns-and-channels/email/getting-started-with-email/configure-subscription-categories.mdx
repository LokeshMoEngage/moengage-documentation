# 概要

サブスクリプションカテゴリは、ブランドから受信したいコミュニケーションの種類を顧客が柔軟に選択できるようにするための手段です。この機能により、ユーザーは関心のあるコミュニケーションカテゴリのみをオプトインできます。サブスクリプションカテゴリを使用すると、ユーザーの好みに合わせてコミュニケーションを調整し、オーディエンスをより深く理解できます。サブスクリプションカテゴリは、配信停止率の低減、顧客エンゲージメントの向上、およびブランドと顧客との関係の改善に役立ちます。

たとえば、製品アップデート、ニュースレター、お知らせなどのカテゴリを設けることができます。製品アップデートに関心のあるユーザーは、ブランドのメールコミュニケーションすべてを配信停止する代わりに、製品アップデートのみを購読できます。

メールの末尾に配信停止リンクのみを追加し、ユーザーが配信停止を選択した場合、そのユーザーはブランドからのすべてのプロモーションメールの受信を停止します。一方、設定管理ページを用意すれば、ブランドから受信できるさまざまな種類のコンテンツについて選択肢を提示できます。顧客は、自分の好みに応じて希望するカテゴリを購読するか、すべてを配信停止することができます。

### ユースケース

バス、ホテル、航空券の予約を提供する旅行ブランドの場合、設定管理ページでは、これらの各サービスについて以下のオプションを用意できます。

- プロモーション
- おすすめ
- お得情報

# ユーザーはどのようにカテゴリを購読しますか？

ユーザーがブランドからのメールの受信を停止したい場合は、メールフッターの配信停止リンクをクリックします。サブスクリプション設定を管理する仕組みがない場合、ユーザーはブランドからのすべてのプロモーションコミュニケーションを配信停止するしかありません。しかし、サブスクリプションカテゴリを設定していれば、ユーザーに設定を管理するオプションを提供でき、ユーザーはサブスクリプション設定ページに移動して、関連性があり関心のあるカテゴリを購読できます。

# 知っておくべき用語

**Categories**

顧客に送信されるコミュニケーションの分類です。ブランドが発信するさまざまなジャンルのコンテンツを表します。たとえば、旅行予約 Web サイトのカテゴリには、プロモーション、割引、特典などがあります。

**Groups**

グループはカテゴリの集合です。カテゴリをより文脈に沿った形でユーザーに提示するのに役立ちます。たとえば、旅行予約 Web サイトでバスと航空券の予約を提供しているとします。同じプロモーションカテゴリが両方に適用される場合があります。グループを使用すると、関連するカテゴリを各見出しの下にまとめてユーザーに提示できます。

注: カテゴリは一意であり、MoEngage はカテゴリレベルでサブスクリプションをトラッキングします。

**Landing Page**

ランディングページは、ユーザーがメールフッターの **Manage preferences** をクリックしたときにリダイレクトされる URL です。ユーザーが選択できるすべてのカテゴリが表示されます。

# 設定

MoEngage ランディングページを設定するには、ダッシュボードで **Settings** \> **Channel** \> **Email** \> **Subscription Categories** に移動します。**Configure Subscription Categories** をクリックして、サブスクリプションカテゴリを構成するランディングページを選択します。

サブスクリプションカテゴリを初めて設定する場合は、以下に示すように、MoEngage ランディングページまたはカスタムランディングページを選択できます。

## MoEngage ランディングページ

MoEngage ランディングページを選択すると、以下の画面が表示され、カテゴリとグループの追加やランディングページのプレビューを行えます。

![MoE\_Landing\_Page\_-\_First\_Time.png](/images/moengage_9960d7.png)

配信停止に MoEngage Tracking を使用している場合は、デフォルトの MoEngage ランディングページまたはカスタムランディングページのいずれかを使用してユーザー設定を管理できます。

## カスタムランディングページ

このオプションを使用すると、カスタマイズしたランディングページを使用し、ランディングページのデザインを完全に制御できます。**Custom Landing** ページオプションを選択した場合は、以下に示すように設定ページの URL を追加する必要があります。

![Edit\_Custom\_Landing\_URL.png](/images/moengage_5d85f5.png)

カスタムランディングページを使用している場合、ユーザー設定を手動で MoEngage に移行する必要があります。これは Update Subscription Preferences API を使用して行えます。詳細については、[Update Preferences API](https://www.moengage.com/docs/api/subscription-preferences/update-subscription-preferences) および [Bulk Update Subscription Preferences API](https://www.moengage.com/docs/api/subscription-preferences/bulk-update-subscription-preferences) を参照してください。

<Info>
  **MoEngage ランディングページとカスタムランディングページの比較** \
  MoEngage ランディングページは、すべてのユーザーがデフォルトのオプションとして利用できます。ランディングページを構築するリソースがない場合は、MoEngage ランディングページを選択できます。MoEngage のサブスクリプショントラッキングを有効にし、カテゴリとグループを使用してランディングページをカスタマイズします。幅広いカスタマイズオプションが必要な場合は、カスタムランディングページを選択し、ニーズに応じて構築できます。カスタムランディングページをデザインしたら、カテゴリ名とランディングページの URL を追加するだけです。
</Info>

# カテゴリ、グループ、ランディングページの構成

## MoEngage ランディングページ

**Configure Subscription Categories** オプションで **MoEngage Landing Page** を選択します。

### カテゴリ

Categories セクションでは、カテゴリの追加、編集、無効化、アーカイブを行えます。

![CategoriesPage\_MoELP.png](/images/moengage_5bbe25.png)

#### カテゴリの追加

カテゴリを追加するには、**Categories** セクションの右上にある **\+Add category** をクリックします。

表示される **Add a new Category** 画面で以下の詳細を入力し、右下の **Add** をクリックしてカテゴリを追加します。

![add new category.png](/images/moengage_9c93a2.png)

#### Category Name

MoEngage はカテゴリ名を使用してカテゴリを一意に識別します。これはカテゴリを識別するために内部で使用され、ランディングページ上でユーザーには表示されません。グループを使用する際の混乱を避けるため、カテゴリ名を作成する際に、そのカテゴリが属するグループへの参照を追加することをお勧めします。

たとえば、プロモーションやお知らせなどのカテゴリが複数のグループに適用される場合があります。Promotions-Buses、Promotions-Flights などのグループ参照を追加すると、カテゴリを区別しやすくなります。MoEngage はカテゴリ名を使用してサブスクリプションをトラッキングします。

#### Display Name

ランディングページに表示されるカテゴリのラベルです。表示名は一意である必要はなく、異なるグループ間で同じでもかまいません。たとえば、Flights と Buses というグループの下にプロモーションカテゴリがある場合、表示名は両方とも Promotions にできますが、カテゴリ名は一意である必要があります（たとえば、Promotions\_Flights、Promotions\_Buses など）。表示名は見た目上のプレースホルダーです。

#### Description

このフィールドはランディングページに表示され、カテゴリの目的と、顧客がこのカテゴリを購読した場合に受け取るコンテンツの種類に関する情報を説明します。

#### Groups

このフィールドはランディングページに表示され、カテゴリを利用可能なグループにリンクするのに役立ちます。このフィールドは任意であり、カテゴリとグループのマッピングはカテゴリ作成後に行うこともできます。

<Info>
  1. 新しいカテゴリを作成すると、デフォルトですべてのユーザーがそのカテゴリを購読している状態になります。
  2. カテゴリは最大 25 個まで追加できます。さらに追加するには、既存のカテゴリのいずれかをアーカイブしてください。アーカイブされたカテゴリには制限はありません。
</Info>

### 各カテゴリでサポートされている操作

すべてのカテゴリ（有効および無効）は、左側のペインの Categories セクションに表示されます。各カテゴリ行の末尾にある縦三点アイコンをクリックすると、以下の操作を実行できます。

| 操作 | 説明 |
| --- | --- |
| Edit | カテゴリがマッピングされている表示名、説明、グループを編集できます。カテゴリ名は編集できません。カテゴリを編集するには、カテゴリ行の末尾にある縦三点アイコンをクリックし、編集オプションを選択します。 |
| Enable | カテゴリ行の Status トグルをオンにして、カテゴリを有効にすることもできます。新しく作成されたカテゴリは自動的に有効になります。 |
| Disable | カテゴリ行の Status トグルをオフにして、カテゴリを無効にできます。カテゴリを無効にする前に、そのカテゴリに関連付けられている実行中のイベントトリガー型キャンペーンや定期キャンペーンを停止してください。  カテゴリを無効にすると、カテゴリ一覧の末尾に移動します。無効になったカテゴリは編集できません。カテゴリを一時的に使用しない場合に無効にできます。 |
| Archive | このオプションを使用してカテゴリをアーカイブできます。これにより、Categories セクションの一覧から削除されます。カテゴリをアーカイブすると、追加されていたグループから削除されます。  カテゴリをアーカイブするには、以下に示すように、カテゴリ行の末尾にある縦三点アイコンをクリックし、アーカイブオプションを選択します。  アーカイブされたすべてのカテゴリを表示するには、カテゴリページの右上にある Archived トグルを有効にします。使用しなくなったカテゴリはアーカイブできます。アーカイブされたカテゴリは、ユーザープロファイルのサブスクリプション設定に表示されません。詳細については、[User Profile](/ja/user-guide/campaigns-and-channels/email/getting-started-with-email/configure-subscription-categories#view-user-preferences) を参照してください。 <br />  注: <ol><li>このカテゴリに関連付けられている実行中のイベントトリガー型キャンペーンや定期キャンペーンは停止する必要があります。停止しない場合、カテゴリのアーカイブ時にエラーメッセージが表示されます。</li><li>カテゴリがアーカイブされている状態で API を使用してステータスを更新しようとすると、エラーメッセージが返されます。</li></ol> |
| Unarchive | カテゴリのアーカイブを解除するには、以下の手順を実行します。 <ol><li>Archived トグルをオンにして、アーカイブされたカテゴリを表示します。</li><li>アーカイブを解除するカテゴリの行の末尾にある縦三点アイコンをクリックし、unarchive を選択します。</li></ol> このカテゴリは無効な状態になり、全カテゴリページの末尾に表示されます。 |

### グループ

Groups セクションでは、グループの追加、編集、並べ替えを行えます。

![Screenshot 2024-06-24 at 10.20.11 AM.png](/images/moengage_9420a5.png)

#### グループの追加

グループを追加するには、Groups セクションの右上にある **\+Add Group** をクリックします。**Group Name** を追加し、**Save** をクリックして新しいグループを追加します。このグループは、カテゴリ作成時のカテゴリとグループのマッピング用のグループドロップダウンで使用できるようになります。MoEngage はグループ名を使用してグループを一意に識別します。

![Screenshot 2024-06-24 at 10.20.51 AM.png](/images/moengage_4f75a7.png)

グループを作成したら、Add categories ページで新しいカテゴリを追加して作成したグループにリンクするか、既存のカテゴリを編集してグループドロップダウンで新しく作成したグループにリンクすることで、カテゴリを追加できます。また、Arrange セクションで別のグループまたは未分類からカテゴリをドラッグして、グループにカテゴリを追加することもできます。

#### 未分類のカテゴリ

これはデフォルトのグループで、どのグループにもマッピングされていないカテゴリがここに表示されます。未分類のカテゴリグループは削除できません。

### 各グループでサポートされている操作

グループの編集、削除、並べ替えを行えます。

| 操作 | 説明 |
| --- | --- |
| Edit | グループの編集では、グループ名を編集できます。グループを編集するには、グループ一覧の末尾にある縦三点アイコンをクリックし、編集オプションを選択します。 |
| Delete | グループを削除すると、Groups ページから削除されます。グループにマッピングされていたカテゴリは、削除後に未分類のカテゴリに移動されます。グループを削除するには、グループ一覧の末尾にある縦三点アイコンをクリックし、削除オプションを選択します。 |
| Arrange | Groups ページの右上にある Arrange をクリックすると、グループとカテゴリを並べ替えることができます。以下に示すように、Arrange Groups and Categories ページがポップアップ表示されます。  <img alt="ArrangeGroups.gif" src="/images/moengage_8e31aa.png" />  この画面では、グループ内のカテゴリの順序の並べ替え、グループ間でのカテゴリの移動、グループの順序の並べ替えを行えます。  Done をクリックして変更を保存します。 |
| Collapse all | Collapse all をクリックすると、すべてのグループが折りたたまれ、グループ名のみが表示されます。 |

#### パーソナライズされたプレビュー

このオプションでは、特定のユーザーのサブスクリプション設定情報を使用して、ランディングページのパーソナライズされたプレビューを表示できます。以下のいずれかの詳細を指定してユーザーを選択できます。

1. **ID** - ユーザープロファイルに存在する ID の値です。詳細については、[Client ID](/ja/user-guide/data/user-data/user-profile) を参照してください。
2. **Email** - トラッキングされている標準属性 Email (Standard) に存在するユーザーのメール ID です。

詳細については、[Personalized Preview](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/personalized-preview) を参照してください。

</Info>

## カスタムランディングページ

**Configure Subscription Categories** オプションで **Custom Landing Page** を選択し、独自に構築した **Manage Preferences** ページの URL を指定します。MoEngage はこの URL をメールテンプレートの下部に自動的に追加します。

<Info>
  カスタムランディングページをホストする場合、すべてのユーザーのユーザー設定を MoEngage に送り返す責任はお客様にあります。その方法については、[こちら](https://www.moengage.com/docs/api/subscription-preferences/update-subscription-preferences) を参照してください。
</Info>

### カテゴリ

Categories セクションでは、カテゴリの追加、編集、無効化、アーカイブを行えます。

#### カテゴリの追加

カスタムランディングページでサポートされているカテゴリを追加できます。カテゴリを追加するには、Categories セクションの右上にある \+Add category をクリックします。カスタムランディングページオプションでは、カテゴリを追加する際に、MoEngage で各カテゴリのカテゴリ名のみを指定できます。\
カテゴリ名は、MoEngage がサブスクリプションのトラッキングに使用する一意の識別子です。ユーザーのサブスクリプション設定を手動で更新する際の参照として機能します。作成後にカテゴリ名を編集することはできません。

### 各カテゴリでサポートされている操作

| 操作 | 説明 |
| --- | --- |
| Enable | カテゴリ行の Status トグルをオンにして、カテゴリを有効にできます。すべてのカテゴリはデフォルトで有効な状態です。 |
| Disable | 以下の画像に示すように、カテゴリ行の Status トグルをオフにして、カテゴリを無効にすることもできます。  カテゴリを無効にする前に、そのカテゴリに関連付けられている実行中のイベントトリガー型キャンペーンや定期キャンペーンを停止してください。  カテゴリを無効にすると、カテゴリ一覧の末尾に移動します。無効になったカテゴリは編集できません。カテゴリを一時的に使用しない場合に無効にできます。無効になったカテゴリは、ユーザープロファイルでグレー表示されます。  <br />**注:**  MoEngage でカテゴリを無効にする場合は、カスタムランディングページからも必ず削除してください。削除せずにユーザーがそのカテゴリの設定を更新した場合、MoEngage はそのカテゴリの設定を更新しません。また、変更が無効になったカテゴリのみに対するものであった場合、イベントも発生しません。 |
| Archive | このオプションを使用してカテゴリをアーカイブできます。これにより、Categories セクションの一覧から削除されます。カテゴリをアーカイブすると、追加されていたグループから削除されます。  カテゴリをアーカイブするには、以下に示すように、カテゴリ行の末尾にある縦三点アイコンをクリックし、アーカイブオプションを選択します。  アーカイブされたすべてのカテゴリを表示するには、Categories ページの右上にある Archived トグルを有効にします。使用しなくなったカテゴリはアーカイブできます。アーカイブされたカテゴリは、ユーザープロファイルのサブスクリプション設定に表示されません。詳細については、[User Profile](/ja/user-guide/campaigns-and-channels/email/getting-started-with-email/configure-subscription-categories#view-user-preferences) を参照してください。 <br />**注:** <ul><li>このカテゴリに関連付けられている実行中のイベントトリガー型キャンペーンや定期キャンペーンは停止する必要があります。停止しない場合、カテゴリのアーカイブ時にエラーメッセージが表示されます。</li><li>カテゴリがアーカイブされている状態で API を使用してステータスを更新しようとすると、エラーメッセージが返されます。</li><li>MoEngage でカテゴリをアーカイブする場合は、カスタムランディングページからも必ず削除してください。削除せずにユーザーがそのカテゴリの設定を更新した場合、MoEngage はそのカテゴリの設定を更新しません。また、変更がアーカイブされたカテゴリのみに対するものであった場合、イベントも発生しません。</li></ul> |
| Unarchive | カテゴリのアーカイブを解除するには、以下の手順を実行します。 <ol><li>Archived トグルをオンにして、アーカイブされたカテゴリを表示します。</li><li>アーカイブを解除するカテゴリの行の末尾にある縦三点アイコンをクリックし、unarchive を選択します。   このカテゴリは無効な状態になり、全カテゴリページの一番最後に表示されます。</li></ol> |

## ランディングページの切り替え

サブスクリプションカテゴリセクションの上部ペインにある _Change_ アイコンをクリックすると、ランディングページを切り替えることができます。ランディングページを切り替えても、ユーザー設定は保持されます。

### MoEngage からカスタムランディングページへの切り替え

MoEngage ランディングページからカスタムランディングページに切り替えると、ランディングページの URL の入力を求められます。カテゴリ名のみが保持され、グループに関する情報は保持されません。

カスタムランディングページから MoEngage ランディングページに切り替える場合は、以下に示すように、各カテゴリの表示名や説明などの追加の詳細を入力する必要があります。

## 配信停止したユーザーのクエリ

Segmentation を使用して、特定のカテゴリの配信を停止したユーザーのリストを取得できます。これを行うには、Segmentation に移動して以下の手順を実行します。

2. **User Property** タブをクリックし、**Select Attribute** ドロップダウンから **Email Unsubscribed Categories** を検索します。
3. **Select Option** ドロップダウン内で、目的のカテゴリを検索します。

<Tabs>
  <Tab title="Drag and Drop エディター ">
    以下の手順を実行して、サブスクリプションカテゴリのランディングページリンクを Drag and Drop エディターに直接挿入します。

  </Tab>

# CSV によるサブスクリプションカテゴリのアップロード

以下の手順に従って、CSV アップロードでユーザーのサブスクリプションカテゴリをアップロードします。

1. MoEngage ダッシュボードにログインします。
2. **Segment** \>**User Imports** に移動します。
3. 表示される **User imports** 画面で、右上にある **Import Users** をクリックします。 <img src="https://lh7-us.googleusercontent.com/docsz/AD_4nXdvb6Q27S0g7OKpCzFnTtbRu8j77HFkgNer7rUu9TThDbuggM01tyUdJ-tq9nnx4uQ3zvbjtoWRZZDfMIhtT5C8vumEHhdf4fqLd8EyLTrVwyI48iRX8La3-HUk0VYIklWrXzyDiZ-wnfFLyb31egVXO7s?key=h6N4579FtfGdvVQUk6bmkg" />
4. **Import name** フィールドにインポートの名前を入力します。
5. **Select user type** で **Registered users** を選択します。
6. **Select file** フィールドで **upload from the computer** をクリックして、CSV ファイルをアップロードします。CSV ファイルをアップロードする際は、以下の点に従ってください。アップロードする CSV ファイルでは、
   1. 1 つの列を ID 用に確保する必要があります。これは、顧客を一意に識別するために使用する顧客 ID です。たとえば、顧客のメール ID などです。
   2. 顧客の配信を停止するサブスクリプションカテゴリの配列用に、別の列を用意します。配信停止カテゴリは次の形式で渡します: _\["abc"|"xyz"|"def"\]_; ここで _abc_、_xyz_、_def_ は配信停止カテゴリです。たとえば、マーケターとして、メール ID が [_john@gmail.com_](mailto:john@gmail.com) の _John_ という顧客を _unsubscategory1_ と _unsubscategory2_ から配信停止する必要があるとします。この場合、アップロードする CSV ファイルは次の形式にする必要があります:\
      [_john@gmail.com_](mailto:john@gmail.com)_, \["unsubscategory1"|"unsubscategory2"\]_。メール ID は 1 つの列に、\["unsubscategory1"|"unsubscategory2"\] は別の列に追加する必要があります。 <img src="https://lh7-us.googleusercontent.com/docsz/AD_4nXfZSJyYW2NnySKuFiHoTAdp2FECMK1Z_b_wFX7rX15jLTuArThZsbvwuceqAK52zWa0rizhF8v1ux1UvO1gLjd7jurvElF_n8K-bdSirF0hktYcwbDmnVxD1E9fJoMOoOHUMr1ZNmhn0UwuppGtTYlI10Dr?key=h6N4579FtfGdvVQUk6bmkg" />
7. ファイルをアップロードしたら、**Preview file** をクリックしてアップロードしたファイルをプレビューします。**Next** をクリックします。 <img src="https://lh7-us.googleusercontent.com/docsz/AD_4nXd7ySJGtSw6XyqdcEMzQD1L7OeUgZattYmOXv9RbmoOGtc3EL1-EcnwDmtkNUlBLy5gI4QpHR75qzLhkQMjVrZ3yMVEJHFecsrnYjioX-CocJXSAZoj-D2Ll92DtCOvzP_aivA3-kUWcXIpZzNOpU9lOrUD?key=h6N4579FtfGdvVQUk6bmkg" />
8. 表示される画面では、CSV ファイルに基づいて **Required mapping** セクションにすべての値があらかじめ読み込まれています。必要に応じて値を変更することもできます。
9. **Map columns** セクションで、_Identifier_ 列（この例ではメール ID）を **ID** に、_Email Unsubscribed Categories_ 列を **Email Unsubscribe Categories** 属性にマッピングします。カテゴリは **Array String** 形式であらかじめ読み込まれています。 <img src="https://lh7-us.googleusercontent.com/docsz/AD_4nXfeJu8vg8B7PFvURwX0CvZwzHbyo6RNkI0zTStv5yINM1nv1Gdt8iwTwLicnF-1tDAIAssvmvIxLLpbyho8MPCu0TOEtKhY0ZcTQj-aRDuSevKgzhIZGy9fFALCQg6imFB0zQUIiG61aMhW5ZyOPkH6Yd1K?key=h6N4579FtfGdvVQUk6bmkg" />

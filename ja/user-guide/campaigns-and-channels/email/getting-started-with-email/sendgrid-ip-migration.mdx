この記事では、専用 SendGrid IP またはアウトバウンド Eメールを、あるアカウントから別のアカウントへ移行する方法について説明します。

この移行を実行したい場合で、アカウントが親アカウントまたはサブユーザーとして接続されていない場合は、移行リクエストを進めるために両方のアカウントの管理者が書面で同意する必要があります。

# 移行前の主な考慮事項

ドメインが高いレピュテーションを維持しており、同様に高いレピュテーションを持つ専用 IP に関連付けられているとします。その場合、移行された IP はすでにウォームアップ済みであるため、ランプアップに必要な時間が短縮され、移行にメリットがあります。

SendGrid から IP を移行する前に、次の点を理解しておいてください。

- **移行できるのは専用 IP のみです。** 共有 IP は複数のアカウントやドメインと相互に接続されているため、移行できません。
- 移行にメリットがあるのは、**ドメインレピュテーションの高い IP を移行する**場合のみです。
- **移行は切り替え方式のプロセスです**。SendGrid サポートチームがクライアントのアカウントから IP を削除し、MoEngage の SendGrid アカウントに追加するため、この期間中に短いダウンタイムが発生します。2 つの異なる SendGrid アカウントの IP を同時に使用することはできないことに注意してください。
- *n* 個の ESP、ベンダー、または SendGrid アカウントから、ドメインまたはサブドメインを並行して使用できます。技術的には問題ありませんが、推奨されません。
- 移行中にはダウンタイムが発生します。この移行プロセスには調整が必要であり、ダウンタイム中またはダウンタイム前に DNS を検証する必要があります。IP を移行した直後に MoEngage から Eメールを送信できる準備が整っていることを確認してください。IP を移行した後、MoEngage から最初の Eメールを送信するまでに 2〜3 週間以上かかると、その間に IP のレピュテーションが失われます。

IP の移行は、その IP がすでに高いレピュテーションと少なくとも 3 か月間の良好な送信履歴を持ち、すでにランプアップ済みである場合にのみ適した選択肢です。

- 新しく移行された IP がランプアッププロセスを経ていない場合、移行によるメリットはありません。
- レピュテーションが低く配信に問題のある IP を移行した場合、その修正に多くの時間 (少なくとも 6〜8 週間) を費やす必要があります。

# SendGrid IP を移行する

次の手順では、SendGrid IP をあるアカウントから別のアカウントへ移行するプロセスについて説明します。

1. 専用 IP をホストしているアカウントの管理者は、IP を新しいアカウントに移行するよう依頼する Eメールを SendGrid サポートに送信する必要があります。Eメールには次の情報を含める必要があります。
   - 移行する IP アドレス。
   - この IP が関連付けられているアカウント。
   - この IP の移行先となるアカウント。
2. 専用 IP を受け入れるアカウントの管理者も、専用 IP を自分のアカウントに受け入れる意思を確認する Eメールを SendGrid サポートに送信する必要があります。この Eメールにも、対象の IP アドレスと移行先のアカウントを含める必要があります。
3. SendGrid サポートチームは、両方のアカウント管理者から書面による許可を受け取った後、移行プロセスを進めます。IP がアカウント間で移動されるため、ダウンタイムが発生する場合があります。
4. 移行を実施したい希望日を含めることができます。
5. 移行後、SendGrid サポートチームは両方のアカウント管理者に、プロセスが完了し、専用 IP が新しいアカウントで有効になったことを通知します。

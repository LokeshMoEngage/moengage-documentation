# IP アドレス

ビジネスの IP アドレスはメールマーケティングにおいて不可欠です。システムで IP ホワイトリスト登録が必要な場合は、[こちら](/ja/user-guide/settings/account/security/ip-whitelisting-in-moengage)を参照してください。

## メールマーケティングにおける IP アドレスの重要性

メールサービスプロバイダーは、大量のメールを送信するすべての送信者に「IP レピュテーション」を割り当てます。IP レピュテーション（良いか悪いか）は、その IP を使用するマーケターの行動に応じて時間をかけて構築されます。メールマーケターがメールサービスプロバイダーから良好な IP レピュテーションを得ている場合、メールはリストの受信者の受信トレイに配信されやすくなります。IP レピュテーションが低い場合、マーケティングメールが迷惑メールフォルダに振り分けられたり、配信が完全にブロックされたりする可能性があります。

## 専用 IP と共有 IP

| 専用 IP | 共有 IP |
| --- | --- |
| 特定の送信者専用に確保されます。このような IP を使用する利点は、その IP のレピュテーションを完全に管理できることです。 | 複数の送信者間で共有されます。IP が共有されているため、各送信者のパフォーマンスが IP のレピュテーションに影響します。 |
| IP レピュテーションを維持するために、ウォームアップとランプアップ、および一貫した送信パターンが必要です。 | IP のウォームアップは不要ですが、新しいドメインからメールを送信する場合はドメインのウォームアップが必要です。 |
| 大量かつ一貫した送信パターンを持つ送信者に適しています。 | 送信量が少なく、送信頻度が低い送信者に適しています。 |

## 必要な IP の数

必要な IP の数は、主に 1 日あたりのピーク送信量、送信頻度、オーディエンスの質、ターゲット地域によって異なります。ピーク送信量がわからない場合や送信パターンが確立していない場合は、アカウント内のメール購読ユーザー数を照会できます。それがピーク送信量の目安となります。推奨事項は以下のとおりです。

| 1 日あたりのメール送信量 | IP の数 |
| --- | --- |
| 1M | 1 |
| 1M - 3M | 2 |
| > 3 M | MoEngage によるカスタマイズされたソリューション |

## MoEngage による IP の割り当て

MoEngage は、MoEngage Email Delivery サービスを利用しているお客様に**専用 IP を割り当てます**。MoEngage のメール到達率コンサルタント（EDC）が、お客様の送信量、送信パターン、オーディエンスの分布を分析し、必要に応じて IP を割り当てます。独自のメールコネクタを使用している場合は、ベンダーに確認する必要があります。

MoEngage は事前にウォームアップされた IP を提供しません。各送信者について、その送信者自身のメールを使用してゼロからランプアップを行います。唯一の例外は、すでにウォームアップ済みの専用 SendGrid IP をお持ちの場合です。その場合は、その IP を MoEngage アカウントに移行し、キャンペーンを開始できます。

# ドメイン

メールドメインは、メールアドレスの "@" 記号の後に表示される一意の識別子です。組織のメールがホストされているオンライン上の場所を表します。たとえば、メールアドレス "example@moengage.com" では、メールドメインは "moengage.com" です。メールドメインは、メールを正しいメールサーバーにルーティングするうえで重要な役割を果たします。

## メールマーケティングにおけるドメインの重要性

- **ブランディング**: カスタムメールドメインを使用すると、ブランドアイデンティティを強化し、受信者によりプロフェッショナルな印象を与えることができます。メールコミュニケーションに信頼性と信用を加えることができます。
- **メール到達率:** 独自のメールドメインを持つことで、メール到達率を向上させることができます。一部のメールサービスプロバイダーはカスタムドメインからのメールを優先するため、メールが受信トレイに届く可能性が高まります。
- **セキュリティの強化:** カスタムメールドメインを使用すると、高度なスパムフィルター、暗号化プロトコル、多要素認証の導入など、セキュリティ対策をより適切に管理できます。これにより、メールコミュニケーションと機密情報を不正アクセスから保護できます。
- **カスタマイズと柔軟性:** メールドメインを使用すると、組織内のさまざまな目的や部門に応じて複数のメールアドレスを柔軟に作成できます。たとえば、一般的なお問い合わせには info@business.com、カスタマーサポートには support@business.com を使用できます。このカスタマイズにより、組織の効率が向上し、メールのやり取りを効果的に管理できます。

## ドメイン、サブドメイン、From アドレスの違い

#### 例 1

Web サイトが https://www.moengage.com/ の場合:

- ドメイン: moengage.com
- サブドメイン: anything.moengage.com
- From アドレス: anything@anything.moengage.com

#### 例 2

メールの送信元が MoEngage Inc `<support@moengage.com>` の場合:

- 送信者名: MoEngage Inc
- From アドレス: support@moengage.com
- From ドメイン: moengage.com

#### 例 3

メールの送信元が MoEngage `<info@alerts.moengage.com>` の場合:

- 送信者名: MoEngage
- From アドレス: info@alerts.moengage.com
- From ドメイン: alerts.moengage.com
- "alerts.moengage.com" は "moengage.com" のサブドメインです

## メールキャンペーンでのサブドメインの使用

ルートドメインを使用してトランザクションメールを送信できます。ただし、その他の種類のメールにはすべてサブドメインを使用することをお勧めします。プロモーションメールは、送信元ドメインのレピュテーションに影響を与える可能性が高くなります。これは、そのドメインから送信されるメールの到達率や受信トレイへの配置に直接関係します。トランザクションメールとプロモーションメールの両方を同じドメインから送信すると、プロモーションキャンペーンのパフォーマンスが低い場合に、トランザクションメールのパフォーマンスに影響する可能性があります。

## 必要なドメインの数

必要なドメインの数は、主に 1 日あたりのピーク送信量、送信頻度、ユースケースによって異なります。ただし、最低でも 2 つのサブドメインを使用することをお勧めします。1 つはトランザクションメール用、もう 1 つはその他すべてのメール送信用です。

| 送信者 | 送信頻度 | メール送信量 | 推奨ドメイン |
| --- | --- | --- | --- |
| A | NA | < 10K/日 | <ul> <li>One-time、Periodic、Event-triggered、Flow キャンペーン用に 1 つのサブドメイン </li><li> トランザクションキャンペーン用に 1 つのサブドメイン</li></ul> |
| B | 月 1 回以下 | NA | <ul> <li> One-time、Periodic、Event-triggered、Flow キャンペーン用に 1 つのサブドメイン </li><li> トランザクションキャンペーン用に 1 つのサブドメイン </li></ul> |
| C | 月 4 回以上 | > 100K/日 | <ul> <li> One-time および Periodic キャンペーン用に 1 つのサブドメイン </li><li>Event-triggered および Flow キャンペーン用に 1 つのサブドメイン </li><li> トランザクションキャンペーン用に 1 つのサブドメイン </li></ul> |

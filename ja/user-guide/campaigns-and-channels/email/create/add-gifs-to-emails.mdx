# メリット

アニメーションGIFは、メールキャンペーンを大きく強化できます。GIFには次のようなメリットがあります。

- **視覚的な魅力**: GIFはメールにダイナミックで魅力的な要素を加え、視覚的により魅力的なものにします。
- **エンゲージメントの向上**: GIFの動きは読者の注意を引くことができ、受信者がメッセージに注目しやすくなるため、エンゲージメント率の向上につながる可能性があります。
- **感情を伝える**: GIFは感情や反応を効果的に伝えることができ、プレーンテキストや静止画像では実現できない人間味をメールに加えます。
- **コンセプトを説明する**: 複雑なアイデアや製品も、GIFを使用するとより明確に説明できます。受信者がメールから離れることなく、仕組みをすばやく示すことができます。

# メールにGIFを追加する

メールキャンペーンにGIFを追加するには、次の手順を実行します。

1. メール作成フローのステップ2: コンテンツに移動します。
2. メールにGIFを追加する際は、次の方法を検討してください。
   
   - **GIFのドラッグアンドドロップ**: GiphyなどのプラットフォームからGIFを入手できます。ドラッグアンドドロップした後、MoEngage GIFsで簡単に検索できます。 <img src="/images/moengage_66ffc7.png" alt="GIF from GIPHY.gif" />
   
   - **画像ブロックの使用**: または、画像ブロックを使用してGIFのURLを指定し、挿入することもできます。
  
   <img src="/images/moengage_95b606.png" alt="2025-03-12_14-31-20.gif" />

# ベストプラクティス

メールコミュニケーションにGIFを組み込む際は、次の重要な要素を慎重に検討する必要があります。

- **GIFのアスペクト比とサイズ**: GIFのアスペクト比とサイズは正確に選択する必要があります。大きすぎる画像は正しく読み込まれない場合があります。
- **読み込み速度とサブスクライバーのエンゲージメント**: メールとそのコンテンツの読み込み速度は非常に重要です。読み込みに時間がかかると、受信者のエンゲージメントが低下する可能性があります。
- **ファイルサイズ**: メール内のGIFの最大サイズについて普遍的な基準はありませんが、ファイルが大きいほど読み込みに時間がかかります。特にモバイルユーザー向けにスムーズな読み込みを確保するため、GIFは200 KB未満にすることを目指してください。
- **モバイルネットワークに関する考慮事項**: 多くのユーザーはWi-Fiに接続できるものの、ほとんどのユーザーがスマートフォンでメールにアクセスすることを考慮すると、さまざまなモバイルネットワーク速度を考慮することが不可欠です。
- **メール全体のサイズ**: メールは理想的には100 KBの範囲内に収め、上限は110 KBにする必要があります。この上限を超えると、特にGmailではメッセージが切り詰められます。メディアのサイズはメールサイズにあまり影響しないことに注意してください。メールサイズに影響するのは、HTMLコードとラップされたリンクです。
- **推奨画像サイズ**: 画像については、500 KB未満の画像サイズを使用することを推奨します。GIFはファイルサイズが大きくなることが多いため、上限を800 KB程度に設定することをお勧めします。
- **許容されるダウンロード速度**: GIFを含むメールのコンテンツが、さまざまな接続環境ですばやく読み込まれるようにしてください。
  - 3G接続: 4秒未満
  - 4G接続: 3秒未満
  - LTE接続: 2.5秒未満
  - デスクトップ接続: 2秒未満

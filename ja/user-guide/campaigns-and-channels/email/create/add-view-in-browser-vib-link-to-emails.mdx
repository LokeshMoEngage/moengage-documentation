# 概要

MoEngageのView in Browser（VIB）機能を使用すると、メールの受信者はWebブラウザでメールコンテンツを開くことができます。この機能は、受信者のメールクライアントで表示の問題が発生する場合や、受信者がWebベースの形式でメールを表示したい場合に特に便利です。

# ユースケース

VIBリンクを含めることは、すべての受信者にとってメールがアクセスしやすく、視覚的に魅力的なものになるようにするための、メールマーケティングにおけるベストプラクティスです。このリンクを組み込むことで、次のようなケースに効果的に対処できます。

- **アクセシビリティの向上**: 特に受信者のメールクライアントで複雑なHTMLや画像の表示が難しい場合に、メールコンテンツを表示するための代替手段を提供します。
- **バックアップの表示オプション**: メインのメール表示が不完全であったり崩れていたりする場合でも、受信者が常にメールの全コンテンツにアクセスできるようにします。
- **インタラクティブ性の向上**: 高度なHTML、複雑なCSS、またはすべてのメールクライアントで完全にはサポートされていない可能性のあるインタラクティブな要素を含むメールの場合、VIBリンクは信頼できるフォールバックとして機能します。受信者はメールの完全な機能とデザインを体験でき、本来であれば損なわれてしまうインタラクティブ性を実現できます。

# View in Browser（VIB）リンクを追加する

<Info>
  View in Browserリンクの位置はメールに表示され、View in Browser機能が有効になっている場合にのみ変更できます。アカウントでこの機能を有効にするには、MoEngageのカスタマーサクセスマネージャー（CSM）またはサポートチームにお問い合わせください。
</Info>

MoEngageのEmailキャンペーンモジュールでは、View in Browserリンクはデフォルトで常にメールキャンペーンの上部、ヘッダーの上に配置されます。VIBリンクを任意のカスタム位置に配置するには、使用しているエディターに応じて以下の手順に従ってください。

<Tabs>
  <Tab title="ドラッグアンドドロップエディター">
    ドラッグアンドドロップエディターでView in Browser（VIB）リンクを直接挿入するには、次の手順を実行します。

    1. VIBリンクを挿入するテキストを選択します。
    2. テキストエディターで、**Special links** \> **Frequently used** \> **View in Browser Link** をクリックします。

    ![VIB link.gif](/images/moengage_776194.png)
  </Tab>
  <Tab title="カスタムHTMLエディター">
     カスタムHTMLエディターを使用してView in Browserリンクの位置をカスタマイズするには、必要な位置に次のHTMLタグを配置します。

     \<a id="moe\_email\_vib"\>Enter text here\</a\>

     このHTMLタグは、ドラッグアンドドロップエディターのHTMLブロック内に追加するか、HTMLコードエディターに直接追加できます。また、CSS要素を使用してスタイルを設定し、色やフォントなどの外観をカスタマイズできます。
  </Tab>
</Tabs>

<Info>
  - **クリックトラッキング**: VIB機能はクリックトラッキングをサポートしていません。たとえば、ユーザーがVIBリンクを使用してブラウザでメールを開き、そのブラウザ表示内のリンクをクリックした場合、MoEngageはそれらのクリックを記録しません。
  - **パーソナライズ:**
    - **動的パーソナライズ**: VIBページでは「その時点での」パーソナライズが使用されます。つまり、メールが最初に送信された時点ではなく、リンクを開いた時点で利用可能なユーザーデータに基づいてコンテンツが表示されます。そのため、同じメールでも、メールとブラウザ表示とで情報が異なる場合があります。
    - **イベントトリガー型のパーソナライズ**: イベントトリガー型キャンペーンの場合、イベントデータに基づくパーソナライズはVIB表示では機能しません。つまり、ユーザーがリンクを開くと、イベント固有のパーソナライズは失敗し、フォールバック値が設定されている場合はその値が表示されます。そのため、同じメールでも、メール（イベントデータ）とブラウザ表示（フォールバックデータ）とで情報が異なる場合があります。すべてのパーソナライズのユースケースで、VIBページが元のメールのコンテンツと完全に一致するようにするには、[Message Archival](/ja/user-guide/campaigns-and-channels/campaign-management-and-reports/message-archival/message-archival)アドオンを使用できます。この機能は送信時点のメールの正確なコピーを保存するため、メールクライアントとブラウザ表示の間で完全な一貫性が確保されます。
</Info>

# FAQ

<Accordion title="VIBリンクはどのくらいの期間有効ですか？">
  VIBリンクは無期限に有効です。ユーザーは、メールがいつ送信または配信されたかにかかわらず、VIBリンクからメールを開くことができます。
</Accordion>

<Accordion title="メールキャンペーンでVIBリンクのデフォルトの上部位置を変更できますか？">
  はい、VIBリンクをカスタム位置に移動できます。位置を変更する方法は、ドラッグアンドドロップエディターとカスタムHTMLエディターのどちらを使用しているかによって異なります。詳細については、[View in Browser（VIB）リンクを追加する](#add-view-in-browser-vib-link)を参照してください。
</Accordion>

<Accordion title="ドラッグアンドドロップエディターを使用する場合、VIBリンクはどのように追加されますか？">
  デフォルトでは、機能が有効になっている場合、VIBリンクはメールの上部に自動的に追加されます。VIBリンクをカスタム位置に移動することもできます。位置を変更する方法は、このドキュメントで説明しているように、ドラッグアンドドロップエディターとカスタムHTMLエディターのどちらを使用しているかによって異なります。
</Accordion>

<Accordion title="テストメールを送信する場合、VIBリンクは追加されますか？">
  いいえ、テストキャンペーンにはVIBリンクは追加されません。
</Accordion>

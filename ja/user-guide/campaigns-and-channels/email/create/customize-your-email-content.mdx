送信者画像の追加、Gmail マークアップ、カスタムフォントの使用によって、メールコンテンツをカスタマイズできます。この記事では、これらのオプションを使用してメールキャンペーンのコンテンツをカスタマイズする方法について説明します。

# メールに送信者画像を追加する

すべてのメールキャンペーンに送信者画像を追加するには、次のいずれかの方法を使用します。

### **BIMI を使用する**

BIMI は、ブランドを認証し、メールのアバター欄にブランドロゴを表示できるようにする検証フレームワークです。Yahoo! Mail と [Google](https://cloud.google.com/blog/products/identity-security/bringing-bimi-to-gmail-in-google-workspace) が BIMI 方式を採用しています。BIMI の実装の詳細については、[Why, What, and How BIMI](https://bimigroup.org/all-about-bimi/) および [How BIMI differs from other authentication methods.](https://sendgrid.com/blog/what-is-bimi/) を参照してください。

次の点を確認してください。

- DMARC 認証が組織のポリシーに基づいていることを確認します。**quarantine** または **reject** のいずれかに設定します。
- SVG 形式のロゴインジケーターまたは Verified Mark Certificate（VMC）を含む BIMI レコードを DNS に公開します。
- MoEngage サポートチームにお問い合わせいただくこともできます。

**メールアカウントを使用する**

メールアカウントを使用して送信者画像を追加するには、次の前提条件を満たす必要があります。

- - 送信元アドレスにメールボックスまたはメールアカウントがあることを確認します。
  - メールボックスまたはメールアカウントで送信者画像を簡単に追加できることを確認します。

Settings に移動し、送信者画像をアップロードまたは変更するオプションを使用します。Outlook および Google で送信者画像を追加する方法の詳細については、[Outlook](https://support.microsoft.com/en-us/office/change-your-profile-photo-or-name-in-outlook-com-fb6a40cf-0dc8-4ee8-95ae-fa506586f120) および [Google](https://support.google.com/a/users/answer/9308932?hl=en) を参照してください。

# Gmail マークアップを使用する

マークアップを使用すると、件名にコールトゥアクションボタンやリンクを追加することで、ユーザーは Gmail でメールを開かずに操作できるようになります。Gmail では、メールテンプレートにコード（マークアップ）を追加するために使用できるオープンスタンダードのマークアップ語彙である schema.org を使用しています。マークアップを使用すると、重要な情報を強調し、コンバージョン（クリック率）を向上させることができます。たとえば、Gmail マークアップを使用して、ユーザーの旅行情報（出発時刻、日付、フライト情報など）を強調するカードを受信トレイに表示できます。同様に、注文確認、配送情報、予約の詳細を追加して強調したり、メールにアクションを追加してユーザーが行動を起こせるようにしたりできます。

<Tip>
  マークアップを機能させるには、ドメインを Google に登録する必要があります。詳細については、[Registering with Google](https://developers.google.com/gmail/markup/registering-with-google) を参照してください。
</Tip>

## メールテンプレートにマークアップを追加する

メールテンプレートにマークアップを追加するには、次の操作を行います。

1. 追加したい種類から目的のマークアップを選択し、[こちら](https://developers.google.com/gmail/markup/reference)から該当ページに移動します。たとえば、メールテンプレートにワンクリックアクションを追加するには、[one-click action のリファレンスページ](https://developers.google.com/gmail/markup/reference/one-click-action)に移動します。
2. 目的のアクションの **Micro Data（JSON-LD ではありません）** をコピーし、キャンペーン作成時に MoEngage のメールテンプレートに貼り付けます。

**例**

フライト予約確認メールでフライトの詳細をカードに表示するには、次の操作を行います。

1. [Flight Reservation.](https://developers.google.com/gmail/markup/reference/flight-reservation) からマイクロデータをコピーします。
      ![MicroData\_\_1\_.png](/images/moengage_7915f8.png)
2. これをメールテンプレートの本文に追加し（カスタム HTML テンプレートの Body 内にコードを貼り付けるか、ドラッグ＆ドロップエディターで HTML ブロックを追加してその中にコードを貼り付けます）、キャンペーンを公開します。
      ![AddMarkuptoEmail.gif](/images/moengage_32a02d.png)

---
title: "ユーザーのメール ID が変更された場合、Hard Bounce、Spam、Unsubscribe の値はどうなりますか？"
description: "ユーザーのプロファイルでメール ID が更新されたときに、MoEngage が Hard Bounce、Spam、Unsubscribe の抑制値をどのように扱うかについて説明します。"
---
 
ユーザープロファイルのメール ID が更新されると、バウンスステータスはユーザーの以前のメールアドレスに適用されていたものであるため、MoEngage は **Hard Bounce** の値をデフォルトの状態（`false`）にリセットします。**Spam** と **Unsubscribe** の値はメール ID の更新によって変更されず、プロファイルに保持されます。
 
これらの属性の詳細については、[Derived User Attributes](/ja/user-guide/data/user-data/derived-user-attributes) を参照してください。

---
title: "メールエラー"
description: "SMTP の失敗や配信の問題など、MoEngage でよく発生するメールキャンペーンのエラーと、推奨される解決手順をまとめたリファレンス表です。"
---

次の表は、いくつかのメールエラーとその解決策を示しています。

| エラーの種類 | エラーコード | 説明 | 解決策 |
| --- | --- | --- | --- |
| Failed to Deliver | SMTPSenderRefused | Simple Mail Transfer Protocol（SMTP）が送信者のアドレスを拒否しました。 | SMTP プロバイダーに確認するか、後でもう一度メールを送信してください。エラーが解決しない場合は、MoEngage のカスタマーサクセスマネージャー（CSM）またはサポートチームにお問い合わせください。 |
| Failed to Deliver | SMTPRecipientRefused | Simple Mail Transfer Protocol（SMTP）が受信者のアドレスを拒否しました。 | 1. SMTP プロバイダーに確認するか、後でもう一度メールを送信してください。<br />2. メール ID を確認し、データの問題を修正してください。 |
| Failed to Deliver | Error in Attachments | これらのエラーは、ファイルサイズが大きい、URL が無効である、追加した URL にファイルが存在しないなどの理由で発生する可能性があります。 | 1. Step 2（Content）で追加した添付ファイルを確認してください。<br />2. 添付ファイルの URL が正しいことを確認してください。<br />3. ファイルの種類、添付ファイルの数、個別および合計のサイズが、定められた制限内であることを確認してください。 |
| Failed to Deliver | MaximumLimitExceeded | SMTP 側のクレジット上限を超えました。 | SMTP に確認し、クレジットが更新された後にもう一度メールを送信してください。<br />- MoEngage をメールサービスプロバイダー（ESP）として使用している場合は、MoEngage のカスタマーサクセスマネージャー（CSM）またはサポートチームにお問い合わせください。<br />- 独自の ESP を使用している場合は、クレジットをチャージするか、ESP のアカウントエグゼクティブにお問い合わせください。 |
| Failed to Send | Duplicate emails removed | セグメント内のメール ID が重複していたため、ユーザーが抑制されました。 | 1. データクリーンアップを実行して、重複したプロファイルを削除してください。<br />2. 抑制された顧客に連絡する必要がある場合は、ブランドベースの重複排除コントロールの有効化をリクエストするか、ワンタイムのフローキャンペーンを使用して重複排除をオフにしてください。 |
| Failed to Send | BUC | これらのユーザーは、過去にバウンスが発生した、配信停止リクエストが行われた、またはスパム苦情が寄せられたために抑制されました。 | 対応は不要です。これらのユーザーを抑制することで、ネガティブなエンゲージメントを防ぎ、ドメインレピュテーションを保護できます。 |
| Failed to Send | GCG | Global Control Group を設定しているため、これらのユーザーは抑制されました。このグループは、キャンペーンでターゲットにしたユーザーのパフォーマンスを比較するのに役立ちます。 | キャンペーン作成の Step 1 で Global Control Group の除外をオフにするか、メール設定から Global Control Group を完全に削除してください。 |
| Failed to Send | Users removed due to CCG | Campaign Control Group を設定しているため、これらのユーザーは抑制されました。このグループは、キャンペーンでターゲットにしたユーザーのパフォーマンスを比較するのに役立ちます。 | キャンペーン作成の Step 1 で Campaign Control Group の除外をオフにしてください。 |
| Failed to Send | FC Removed | このエラーは、受信者がフリークエンシーキャップ（FC）によるメッセージの上限に達したため、メッセージが抑制された場合に発生します。 | FC の設定を更新してください。 |
| Failed to Send | DND Removed | このエラーは、設定したおやすみモード（DND）の時間帯にメッセージがトリガーされた場合に発生します。 | DND はイベントトリガー型キャンペーンにのみ適用されます。DND は、ワンタイム、定期、およびビジネスイベントトリガー型キャンペーンには適用されません。これらの種類のキャンペーンは、スケジュールに従って配信されます。 |
| Failed to Send | Not sent due to campaign-level minimum delay | このエラーは、イベントトリガー型キャンペーンでのみ発生します。 | 1. キャンペーンが重複しないように、ユーザーのセグメント化を変更してキャンペーンをスケジュールしてください。<br />2. 最小遅延の設定を削除してください。 |
| Failed to Send | Invalid emails removed | このエラーは、無効なメールアドレスを持つユーザーが抑制された場合に発生します。 | データの修正またはメールリストの検証を実行してください。 |
| Failed to Send | Encryption/Decryption Failure | このエラーは、暗号化または復号の失敗が原因で発生します。 | MoEngage のカスタマーサクセスマネージャー（CSM）またはサポートチームにお問い合わせください。 |
| Failed to Send | IP Warm-Up Removed | このエラーは、IP ウォームアップが削除されたために発生します。 | ウォームアッププランを更新してください。 |
| Failed to Send | Invalid API response | このエラーは、無効な API レスポンスが原因で発生します。 |  |
| Failed to Send | Personalisation Failure | このエラーは、パーソナライズの失敗が原因で発生します。 | 欠落しているデータに対処してください。 |

## 問題

送信したメールのフォントが、メール作成時に使用したフォントと異なって表示されます。

## 説明

送信したメール全体で一貫したレンダリングを実現するには、Web セーフフォントのみを使用する必要があります。カスタムフォントを使用すると、受信者の受信トレイでサポートされていない場合があり、その場合はメールボックスがサポートするフォールバックフォントが使用されます。このフォールバックフォントの順序を制御するには、次の HTML コードをテンプレートに挿入し、_font-family_ プロパティを目的の Web セーフフォントに更新してください。

たとえば、次の HTML コードでは、_Noto Sans_ がプライマリフォントです。受信者のメールクライアントで _Noto Sans_ がサポートされていない場合は _Arial_ にフォールバックします。_Arial_ もサポートされていない場合は、_sans-serif_ フォントが使用されます。

<CodeGroup>

```html HTML wrap
<p style="font-family: 'Noto Sans', Arial, sans-serif;">This is sample text.</p>
```

</CodeGroup>

HTML を編集する代わりにダッシュボードから独自のフォントをアップロードしてフォールバックフォントを設定するには、[カスタムフォント](/ja/user-guide/campaigns-and-channels/email/getting-started-with-email/custom-fonts)を参照してください。

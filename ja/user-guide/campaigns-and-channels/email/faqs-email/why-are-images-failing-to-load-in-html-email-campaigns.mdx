## 問題

HTML メールキャンペーンの作成時に、アップロードした画像の URL がメールのプレビューやテスト中に表示されない場合があります。

## 説明

この問題は、URL に括弧が含まれている場合に発生します。

## 解決策

背景色などで画像を追加する場合は、`URL()` 構文内で一重引用符を使用してください。

## 例

これを修正するには、構文エラーを防ぐために URL を一重引用符で囲みます。正しい CSS コードは次の形式に従う必要があります。

<CodeGroup>

```css Code wrap
background-image:
  url('https://abc....');
```

</CodeGroup>

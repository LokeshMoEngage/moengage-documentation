---
title: "画像以外のファイルが Image ブロックのファイルマネージャーに表示されないのはなぜですか？"
description: "メールエディターの Image コンテンツブロックからアップロードした PDF やその他の画像以外のファイルが表示されない理由と、代わりにそれらのファイルの公開 URL を取得する方法について説明します。"
---

## 問題

メールエディターの Image コンテンツブロックは、画像ファイルのみを受け付けます。Image ブロックから開いたファイルマネージャーを使用して画像以外のファイル（例：`.pdf`）をアップロードしようとすると、MoEngage はエラーを表示せず、アップロードは成功したように見えます。公開 URL が生成され、フォルダーのファイル数も増えますが、実際にはファイルはファイルマネージャーに表示されません。

<Note>
  エディターが何も表示せずに失敗するのではなく、明示的なエラーを表示する関連ケースについては、[.mp4 ファイルのアップロードが失敗するのはなぜですか？](/ja/user-guide/campaigns-and-channels/email/faqs-email/why-does-uploading-mp4-files-fail)を参照してください。
</Note>

## 解決策

サードパーティの BEE エディターに組み込まれたフィルタリングにより、Image コンテンツブロックのファイルマネージャーは画像ファイルのみを受け付けます。画像以外のファイル（例：アプリ内キャンペーンなど別の場所で使用する PDF）の公開 URL が必要な場合は、Image ブロックではなく、テキスト要素またはボタンで **Link File** / **Insert-Edit Link** アクションを使用してください。このファイルマネージャーの入り口にはフィルタリングがないため、ファイルが正常にアップロードされ、公開 URL が生成されます。

詳細については、[PDF のアップロードとリンクに関する BEE のドキュメント](https://support.beefree.io/hc/en-us/articles/360004494892--How-can-I-upload-a-pdf-and-insert-a-link-to-it-to-my-design)を参照してください。

<Warning>
  Image コンテンツブロックのファイルマネージャーは、画像ファイルのみを受け付けます。ファイルマネージャーがアップロードを受け付けたように見える場合でも、MoEngage はこのブロックを介した動画、PDF、その他の画像以外のファイルのアップロードをサポートしていません。
</Warning>

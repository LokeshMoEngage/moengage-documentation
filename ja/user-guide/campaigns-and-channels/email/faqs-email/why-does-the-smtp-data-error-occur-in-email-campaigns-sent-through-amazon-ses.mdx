## 問題

"SMTPDataError" により、Amazon Simple Email Service (Amazon SES) 経由でメールを送信できませんでした。

## 説明

- このエラーは、メール送信用の Simple Mail Transfer Protocol (SMTP) 接続が正しく確立されていない場合に発生します。
- Amazon SES は、24 時間以内 (1 日の送信クォータ) および 1 秒あたりに送信できるメール数を制御するための送信制限を設けています。
- メッセージ数が AWS アカウントの 1 日の上限を超えた場合、MoEngage から Amazon SES への API 呼び出しは拒否され、"454 Throttling failures: Daily message quota exceeded error(SMPTDataError)" が発生します。

## 解決策

一括メール送信時にこのエラーを回避するには、お客様または Amazon サポートチームと連携して、次の点を検討してください。

- **IP の使用状況**   
  お客様が Amazon の専用 IP と共有 IP のどちらを使用しているかを確認します。
  - *専用 IP:* リクエスト制限は IP ごとに 1 秒あたり 40 通です。たとえば、お客様が 3 つの専用 IP を使用している場合、制限は 1 秒あたり 120 通になります。
  - *共有 IP:* リクエスト制限は 1 秒あたり 500 通ですが、複数の Amazon のお客様が同じ IP を使用している場合、ドメインレピュテーションが低下する可能性があります。
- **スロットリング設定**   
  グローバルレベルのスロットリングと、キャンペーンレベルの配信制御を調整します。たとえば、1 回限りの Email キャンペーンで 55L (550 万) のユーザーをターゲットにする場合は、10 個の専用 IP または共有 IP を使用し、グローバル設定とキャンペーン設定でスロットリングを 1 分あたり 20000 通に設定することをお勧めします。
- **1 日のメールリクエスト制限**   
  お客様の Amazon アカウントにおける 1 日あたりのメールリクエストの総制限数を確認します。

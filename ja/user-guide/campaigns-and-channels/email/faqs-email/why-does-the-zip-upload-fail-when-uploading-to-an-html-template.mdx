## 問題

Email キャンペーンで HTML テンプレートに ZIP ファイルをアップロードできず、次のエラーメッセージが表示されます。

Oh snap! Zip upload failed. Please contact our support team.

![](/images/moengage_26821b.png)

## 前提条件

アップロード時に、ZIP ファイルが次の要件を満たしていることを確認してください。

- ファイルサイズが 5 MB 未満であること。
- ファイル名に \*、/、、&、~、" の文字が含まれていないこと。
- インライン CSS を含む HTML ファイルが 1 つだけ含まれていること。
- 画像には JPG、JPEG、PNG、または GIF 形式を使用すること。
- 画像のパスが、大文字と小文字の区別を含めて ZIP のフォルダー構造と一致していること。

## 説明

- HTML はマークアップ言語であり、コードに軽微な問題があっても、通常はローカルホストやサーバーでのレンダリングに影響しません。
- HTML エディターはエラーのないコードを受け付けるため、アップロードするコードにはエラーがないようにする必要があります。

## 手順

- 正しく機能させるためには開始タグと終了タグの両方が不可欠なため、両方が存在することを確認してください。たとえば、正しいコードは次のようになります。
  <CodeGroup>
  ```html HTML
  <div><p> contents  </p></div>
  ```
  </CodeGroup>
- 作成したすべてのクラスに対応する閉じ括弧があることを確認してください。たとえば、正しいコードは次のようになります。
  <CodeGroup>
  ```text Code
  .myclass{
  color:"red"
  }
  .mysecondclass{
  color:"blue"
  }
  ```
  </CodeGroup>

<Info>
  使用している CSS をチェックすることもできます。
</Info>

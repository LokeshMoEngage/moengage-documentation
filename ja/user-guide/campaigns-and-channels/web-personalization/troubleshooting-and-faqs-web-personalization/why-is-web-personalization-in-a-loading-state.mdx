## 問題

Web パーソナライズ機能に問題があります。Web パーソナライズエディターの読み込みに失敗し、コンソールに多数のエラーが表示されます。読み込みプロセスが応答しなくなります。  
 <img  src="/images/moengage_b10c60.png"  />

## 原因

このエラーは、[Content Security Policy とパーソナライズへの影響](/ja/user-guide/personalize/things-to-know/content-security-policy-and-impact-on-personalization)のドキュメントに従って、推奨される URL をお客様側でホワイトリストに登録していない場合に発生します。

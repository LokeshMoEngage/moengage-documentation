Web Personalization キャンペーンを作成するには、以下の手順を実行します。

1. MoEngage のサイドバーメニューで、**Engage** メニュー項目 <img alt="Screenshot 2025-06-04 at 4.32.53 PM.png" src="/images/moengage_2dba4e.png" /> にカーソルを合わせます。**Engage** メニューが表示されます。
2. **\+ New Campaign** をクリックします。

![1.png](/images/moengage_851b9d.png)

**Engage** メニューで **All Campaigns** をクリックし、All campaigns ページで **\+ Create campaign** をクリックすることもできます。

3. **New Campaign** ダイアログボックスの **Personalization** で、**Web** をクリックします。

![Screenshot 2025-06-17 at 12.09.30 PM.png](/images/moengage_8b2d11.png)

Web Personalization キャンペーンの作成ページが表示されます。

# Web パーソナライズキャンペーンを作成する手順

Web Personalization キャンペーンを作成する手順は以下のとおりです。

1. [セグメンテーション](#step-1:-segmentation): キャンペーンのターゲットオーディエンスを定義します。
2. [キャンペーンデータ](#step-2:-campaign-data): 送信するキャンペーンのコンテンツを定義します。
3. [スケジュール設定](#step-3:-scheduling): キャンペーンの配信スケジュールと目標を定義します。

## ステップ 1: セグメンテーション

1. 以下のフィールドで構成されるキャンペーンの詳細を入力します。
   - **Campaign name**: キャンペーンを管理および識別するためのキャンペーン名を入力します。キャンペーン名は 5 文字以上である必要があり、文字数制限は 5～50 文字です。
   - **Campaign tags**: ドロップダウンリストからキャンペーンタグを選択します。最大 5 つのタグを選択できます。詳細については、[キャンペーンタグ](/ja/user-guide/campaigns-and-channels/getting-started/introduction/campaign-tags)を参照してください。
     <Frame>
       ![W Pcampaignnameandtag 1](/images/WPcampaignnameandtag-1.png)
     </Frame>
2. ターゲットにするプラットフォームのチェックボックスをオンにします。
   - **Web**
   - **Mobile web**
3. キャンペーンをトリガーする方法に応じて、以下のいずれかの条件を選択できます。
   <Tabs>
     <Tab title="ページ読み込み時">
       Web ページの読み込み時にキャンペーンをトリガーする場合は、このオプションを選択します。 <img src="/images/moengage_8aee04.png" alt="on page load.png" /> Web ページにキャンペーンを表示するトリガー時間として、以下のいずれかを選択できます。
       - **Immediately**\
         ページの読み込みが完了した直後にキャンペーンが表示されます。 <img src="/images/moengage_3d2d8a.png" alt="immediately.png" />
       - **After Delay**ページの読み込みが完了してから、指定した時間が経過した後にキャンペーンが表示されます。 <img src="/images/moengage_0db22a.png" alt="on page load after delay.png" />
       - **After Scroll**ページの読み込みが完了した後、ユーザーがページを指定した割合だけスクロールするとすぐにキャンペーンが表示されます。 <img src="/images/moengage_f3b71c.png" alt="on page load scroll.png" />
     </Tab>
     <Tab title="カスタムイベント発生時">
       カスタムイベントとそれに関連付けられたイベント属性でキャンペーンをトリガーする場合は、このオプションを選択します。 <img src="/images/moengage_032f50.png" alt="on custom event.png" /> たとえば、ユーザーがアプリを更新したときにのみキャンペーンを表示する場合は、ドロップダウンからイベントとして _App Update_ を選択します。\
       **\+ Add Attribute** をクリックして、フィルターに属性を追加することもできます。 <img src="/images/moengage_7fb8d0.png" alt="web personalization select event.png" />
       <Warning>
         Data API やその他のサーバーサイドのソースから送信されたイベントは、トリガーアクションとしてサポートされていません。
       </Warning>
     </Tab>
     <Tab title="セルフハンドル">
       必要なときにキャンペーンを明示的に取得する場合は、このオプションを選択します。 <img src="/images/moengage_34b6af.png" alt="self handled web personalization.png" /> この方法を使用するには、[セルフハンドル型 Personalize API エクスペリエンス](/ja/developer-guide/personalize-sdk/sdk-integration/self-handled-personalize-api-experiences)を参照してください。
     </Tab>
   </Tabs>
4. 以下のように、必要なオーディエンスを選択します。
   - **All Users**
   - 以下に示す **Customers that satisfy the filters**: \\
     <Tabs>
       <Tab title="ユーザープロパティ">
         このフィルターオプションを使用すると、初回確認日時、最終確認日時、都市などのユーザープロパティに基づいてユーザーをターゲットにできます。**User Properties** フィルターを使用するには、以下の手順に従います。
         1. **User Properties** タブをクリックし、ドロップダウンリストで目的の属性を選択します。 <img src="/images/moengage_a70b2d.png" alt="WP User properties.png" /> たとえば、数値属性には 'is equal to'、'is not equal to'、'is between' などのフィルター条件があり、文字列属性には別のフィルターがあります。\
            詳細については、[セグメンテーションのフィルター](/ja/user-guide/segment/advanced-concepts/filters-in-segmentation)を参照してください。
         2. フィルター値を入力して、目的のユーザーセグメントを作成します。
         **Add Filters** ボタンをクリックし、AND 条件または OR 条件を使用して、複数のフィルターを追加できます。
       </Tab>
       <Tab title="ユーザー行動">
         このフィルターオプションを使用すると、アプリ/サイトの起動、製品の閲覧などのユーザーアクションに基づいてユーザーをターゲットにできます。**User Behavior** フィルターを使用するには、以下の手順に従います。
         1. **User behavior** タブをクリックします。 <img src="/images/moengage_959d68.png" alt="WP user behavior.png" />
         2. 実行条件と目的のユーザーアクティビティ（イベント）を選択します。
         3. イベントの頻度と、イベント実行の期間を入力します。
         4. **\+ Attributes** をクリックし、フィルター条件付きのイベント属性を追加します。
         5. フィルター値を入力してルールを作成します。
         **\+ Add Filters** をクリックし、AND 条件または OR 条件を使用して、複数のフィルターを追加できます。
       </Tab>
       <Tab title="カスタムセグメント">
         このフィルターオプションを使用すると、カスタムセグメントをターゲットオーディエンスとして選択できます。**Custom Segments** フィルターを使用するには、以下の手順に従います。
         1. **Custom Segments** タブをクリックし、ドロップダウンから目的のカスタムセグメントを選択します。 <img src="/images/moengage_42f8e2.png" alt="WP custom segments.png" />
         **\+ Add Filters** をクリックし、AND 条件または OR 条件を使用して、複数のフィルターを追加できます。
       </Tab>
     </Tabs>
   - さらに、以下の操作も実行できます。
     - **Exclude Users**: 以下の条件に基づいてユーザーをキャンペーンから除外するには、このチェックボックスをオンにします。
       - User Properties
       - User Behavior
       - Custom Segments
     - **Show Count**: Show Count ボタンをクリックすると、設定したセグメントに含まれるユーザーの総数が表示されます。
     - **Gobal control group**: Global control group トグルはデフォルトで有効になっており、グローバルコントロールグループのユーザーがキャンペーンを受信しないように除外することで、設定したターゲットオーディエンスがキャンペーンにアクセスできるようにします。詳細については、[コントロールグループ](/ja/user-guide/campaigns-and-channels/getting-started/introduction/control-groups)を参照してください。
     - **Campaign control group**: キャンペーンコントロールグループに追加されたユーザーにキャンペーンを送信しない場合は、このトグルを有効にできます。詳細については、[コントロールグループ](/ja/user-guide/campaigns-and-channels/getting-started/introduction/control-groups)を参照してください。
5. **Next** をクリックします。

<Info>
  [_Portfolio_](/ja/user-guide/settings/account/portfolio/portfolio) 機能は Web Personalization チャネルをサポートしていません。Web Personalization キャンペーンでは、プロジェクトの選択とプロジェクト横断のターゲティングは利用できません。
</Info>

## ステップ 2: キャンペーンデータ

このセクションでは、以下のようにキャンペーンにコンテンツを追加する方法について説明します。

1. ****Campaign Tag**** を入力します。
   Campaign Tag は、MoEngage のアカウントのアクティブなキャンペーンのリストから、正しいキャンペーンデータを取得するために使用されます。\
   たとえば、Web サイトに 3 つのアクティブなキャンペーンがあるとします。\
   キャンペーン 1: ホームページのバナー用\
   キャンペーン 2: ホームページのベストセラー商品用\
   キャンペーン 3: ホームページのおすすめ商品用 ホームページの該当するフィールドに適切なキャンペーンデータを配信するには、正しいデータを取得するためのキャンペーンタグを設定する必要があります。ユーザーが Web サイトのホームページを開くと、MoEngage SDK は同じ Campaign Tag に関連付けられた上記 3 つのキャンペーンを取得し、パーソナライズされたデータを Web サイトに配信します。
2. パーソナライズした **Campaign Data** を入力します。\
   キャンペーンデータは、ユーザーが Web ページを開いたときに配信されるメッセージです。このデータは JSON 形式である必要があり、画像 URL、テキスト、または Web サイトで使用されるその他のキーと値のペアを含めることができます。 <img src="/images/moengage_450a0b.png" alt="Content.png" />
   <Accordion title="キャンペーンのテスト（任意）">
     テストキャンペーンを使用すると、テストデバイスでキャンペーンをプレビューし、通知が意図したとおりに伝わることを確認できます。以下のいずれかのオプションを選択し、テストユーザーに対して選択した属性の値を指定することで、作成したキャンペーンをテストできます。
     - Unique ID
     - Email ID
     - Mobile Number (Registered With MoEngage)
     - Mobile Number (External/Not Registered with MoEngage)
     - Google Advertising identifier
     - iOS Identifier For Advertising
     - Device Push Token
     - Custom Segment <img src="/images/moengage_63028b.png" alt="WP test campaign.png" />
   </Accordion>
3. **Next** をクリックします。

## ステップ 3: スケジュール設定

このセクションには以下が含まれます。

1. [キャンペーンのタイミング](#campaign-timing): キャンペーンをユーザーに配信するタイミングと配信の周期を選択します。
2. [コンバージョン目標](#conversion-goals): キャンペーンで追跡するコンバージョン目標と収益指標を選択します。
3. [キャンペーンの優先度](#campaign-priority): キャンペーンの表示の優先度の値を選択します。

### キャンペーンのタイミング

キャンペーンを表示する開始期間と終了期間を定義します。

![CampaignTiming.png](/images/moengage_548082.png)

### コンバージョン目標

キャンペーンのパフォーマンスを評価するのに役立つコンバージョン目標を定義します。コンバージョントラッキングは、MoEngage ダッシュボードの他のキャンペーンタイプと同じように機能します。\
1 つのキャンペーンに最大 5 つの異なるコンバージョン目標を定義できます。

### キャンペーンの優先度

キャンペーンの表示の優先度の値を選択します。この優先度は、同じユーザーに対して複数のキャンペーンが対象となる場合に使用されます。

キャンペーンの優先度は、既存のキャンペーンを優先度の高いキャンペーンで上書きしたい場合（セール期間中や重要なお知らせの場合など）に役立ちます。

![Screen\_Shot\_2018-10-29\_at\_3.01.15\_PM.png](/images/moengage_9fef20.png)

**Launch** ボタンをクリックして、キャンペーンの作成を完了します。

Campaign Analytics ページを使用して、キャンペーンのパフォーマンスを可視化できます。

<Info>
  すべての指標は、アプリのタイムゾーンで計算および表示されます。
</Info>

# Web パーソナライズ分析ページへのアクセス

Experience Analytics ページにアクセスするには、以下の手順に従います。

1. MoEngage のサイドバーメニューで、**Engage** メニュー項目 <img alt="Screenshot 2025-06-04 at 4.32.53 PM.png" src="/images/moengage_301d8e.png" /> にカーソルを合わせます。**Engage** メニューが表示されます。
2. **\+ All Campaigns** をクリックします。 <img src="/images/moengage_df1b00.png" alt="Screenshot 2025-06-17 at 12.14.06 PM.png" /> 作成したすべてのキャンペーンを含む All campaigns ページが表示されます。
3. 分析情報を表示する Web Personalization キャンペーンの行をクリックします。\
   新しい画面では以下のセクションを利用できます。
   - [キャンペーンの詳細](#campaign-details)
     - [分析](#analytics)
       - [キャンペーンの集計統計](#aggregate-campaign-statistics)
       - [キャンペーンのパフォーマンス](#campaign-performance)
       - [コンバージョン目標の統計](#conversion-goals-statistics)
     - [情報](#info)

## キャンペーンの詳細

![WP campaign details.png](/images/moengage_727be9.png)

このセクションでは、以下のように Web Personalization キャンペーンの詳細の概要を確認できます。

- キャンペーン名とタイプ
- キャンペーン ID
- キャンペーンが作成された日時
- キャンペーンを作成したユーザー
- キャンペーンのステータス
- キャンペーンを編集/複製/一時停止/再開するオプション

## 分析

キャンペーンのパフォーマンスを示すために、以下の指標が表示されます。

![WP analytics.png](/images/moengage_d451d4.png)

- **Date Range** - キャンペーンを追跡する期間です。
- **Attribution Type** - ドロップダウンから選択した属性に基づいてキャンペーンの統計を表示します。コンバージョンをこのキャンペーンに帰属させるために、MoEngage は以下の 3 つのモデルをサポートしています。
  - **View Through** - メッセージを表示した後に実行されたコンバージョンイベント。
  - **Click Through** - メッセージをクリックした後に実行されたコンバージョンイベント。
  - **In Session** - メッセージを表示してから 30 分以内に実行されたコンバージョンイベント。

Web Personalization キャンペーンの分析は、以下のコンポーネントで構成されています。

### キャンペーンの集計統計

選択した期間、アトリビューションタイプ、プラットフォームにおけるキャンペーンの集計指標は以下のとおりです。

![Screen\_Shot\_2020-11-30\_at\_7.37.07\_PM.png](/images/moengage_eb5e3c.png)

- **Impressions** - このキャンペーンのメッセージが表示された回数。
- **Clicks** - このキャンペーンのメッセージがクリックされた回数。
  - **CTR** - クリック率。CTR = Clicks / Impressions で計算されます。
- **Close** - このキャンペーンのメッセージが閉じられた回数。
- **Conversion Events** - このキャンペーンのメッセージのインプレッション/クリック後に、プライマリコンバージョン目標が実行された合計回数。この数は、選択したアトリビューションタイプによって異なります。
- **Conversions** - このキャンペーンのメッセージのインプレッション/クリック後に、プライマリコンバージョン目標が実行された合計回数。この数は、選択したアトリビューションタイプによって異なります。
  - **CVR** - コンバージョン率。CVR = Conversions / Impressions で計算されます。

#### **キャンペーンの収益**

以下に示すように、オンサイトメッセージングキャンペーンの作成時に、プライマリコンバージョン目標とともに収益属性を定義できるようになりました。

定義すると、キャンペーン分析ページに以下の指標が表示され、キャンペーンがもたらしている正確な収益を確認できます。

![Screen\_Shot\_2020-11-30\_at\_7.40.58\_PM.png](/images/moengage_e2e564.png)

- **Total Campaign Revenue** - このキャンペーンを通じて生み出された総収益を表します。
- **Average Order Value** - 平均注文額は、このキャンペーンを通じたコンバージョンの平均値を表します。Average Order Value = Total Campaign Revenue / Total Conversion Events。
- **Average Revenue Per Converted Use**r - コンバージョンイベントを実行した各ユーザーが生み出した総収益を表します。ARPCU = Total Campaign Revenue / Total Conversion

<Info>
  キャンペーン分析でこの収益情報を確認するには、コンバージョンイベントに収益属性を設定する必要があります。
</Info>

<Note>
  収益属性がオブジェクト配列内にある場合、MoEngage の計算結果が想定と一致しない可能性があります。詳細については、[オブジェクト属性を使用した収益トラッキング](/ja/user-guide/campaigns-and-channels/campaign-management-and-reports/conversion-and-attribution#how-revenue-is-calculated-for-object-array-attributes)を参照してください。
</Note>

### キャンペーンのパフォーマンス

このセクションでは、特定の期間におけるキャンペーン指標（Impressions、Clicks、Conversions、Conversion Events）のパフォーマンスの推移を、時系列データのグラフで表示します。

![Screen\_Shot\_2020-11-30\_at\_7.41.11\_PM.png](/images/moengage_c7b4c3.png)

時間軸はアプリのタイムゾーンに従って表示されます。

より詳細なデータを確認するには、選択した期間内で特定の時間スケール（時間、日、週、月）を選択できます。

表のラジオボタンを選択して、キャンペーン統計の表形式ビューに切り替えることもできます。

![WP table view stats.png](/images/moengage_29e1a7.png)

### コンバージョン目標の統計

このセクションでは、**Primary** コンバージョン目標の **Total Conversions** と **Unique Conversions** の数、および各コンバージョン目標のパフォーマンスが表示されます。

Web Personalization キャンペーンでは、最大 5 つのコンバージョン目標を追加し、このセクションで各コンバージョン目標のパフォーマンスを確認できるようになりました。

![Screen\_Shot\_2020-11-30\_at\_7.41.21\_PM.png](/images/moengage_d56489.png)

ここで、**(Primary)** とマークされたコンバージョン目標は、キャンペーンの作成時に設定したプライマリコンバージョン目標です。

**Aggregate** ビューと **Time Series** ビューを切り替えて、データをさまざまな表示スタイルで確認できます。

## 情報

![WP Info.png](/images/moengage_56150d.png)

このセクションには Web Personalization キャンペーンの概要が表示され、セグメント化したユーザー、キャンペーンに含めたメッセージ、キャンペーン表示の開始時刻と終了時刻、キャンペーンの配信先として選択したプラットフォーム、キャンペーンタグ、キャンペーン目標を把握できます。

また、選択したプラットフォームでのメッセージのプレビュー（JSON 形式）を確認することもできます。

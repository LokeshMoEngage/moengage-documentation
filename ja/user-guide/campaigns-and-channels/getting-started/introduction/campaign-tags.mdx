キャンペーンタグは、"onboarding"、"retention"、"country"、"all users" など、キャンペーンに説明的なコンテキストを追加します。キャンペーンにタグを追加すると、キャンペーンをフィルタリングしたり、ユーザーがそれらのキャンペーンとどのようにやり取りしているかを特定したりできます。

たとえば、セールイベント中の携帯電話の割引キャンペーンを作成する場合、_Discount_、_Diwali Sale_、_Mobile_、_India_ などのタグを追加できます。

MoEngage でのタグの管理の詳細については、[タグの管理](/ja/user-guide/settings/advanced-settings/manage-tags)を参照してください。

## タグカテゴリ

タグをカテゴリにグループ化することもできます。カテゴリはタグの整理に役立ちます。

たとえば、年次セール中に "Electronics Sale" や "Home Decor Sale" に関連する複数のキャンペーンを送信したい場合があります。_Annual Sale_ というカテゴリを作成し、その下にカテゴリの各分野の個別のタグを追加できます。

MoEngage では、デフォルトで 2 つのカテゴリが用意されています。

- **Default:** このカテゴリには、MoEngage が提供するすべてのデフォルトタグが含まれます。
- **Uncategorized:** このカテゴリには、どのカテゴリにも割り当てていないすべてのタグが含まれます。

## キャンペーンにタグを追加する

キャンペーンにタグを追加するには、次の手順に従います。

1. キャンペーン作成のステップ 1 で、**Campaign Tags** オプションを見つけます。

   ![Screenshot 2025-08-04 at 5.12.36 PM.png](/images/moengage_fc0aee.png)
2. ドロップダウンメニューには、カテゴリ別にグループ化されたすべてのタグの一覧が表示されます。

   <img
     alt="CampaignTags_DropdownOptions.png"
     src="/images/moengage_6c70cb.png"
     style={{ width:"44%" }}
   />

<Info>
  ワークスペースには合計で最大 500 個のタグを含めることができます。1 つのキャンペーンで使用できるタグは最大 12 個です。
</Info>

3. ドロップダウンリストからタグを選択するか、新しいタグを作成します。新しいタグを作成するには、タグ名を入力して **Enter** を押します。MoEngage が新しいタグを作成します。

<Info>
  MoEngage は、新しく作成されたすべてのタグを自動的に **Uncategorized** カテゴリに移動します。
</Info>

## タグを使用してキャンペーンを特定する

タグでキャンペーンをフィルタリングするには:

1. All Campaigns ページで **More filters** をクリックします。

   ![Screenshot 2025-08-04 at 5.29.40 PM.png](/images/moengage_427c0f.png)
2. **Has campaign tags** には、2 つのオプションがあります。

   <img
     alt="Screenshot 2025-08-04 at 5.31.02 PM.png"
     src="/images/moengage_8942fa.png"
     style={{ width:"47%" }}
   />

- **Any of these:** このオプションでは、選択したタグのうち少なくとも 1 つを含むキャンペーンが表示されます。たとえば、_Tag A_ と _Tag B_ を選択した場合、MoEngage は _Tag A_ または _Tag B_ のいずれかを持つキャンペーンを表示します。
- **All of these:** このオプションでは、選択したすべてのタグを含むキャンペーンが表示されます。たとえば、_Tag A_ と _Tag B_ を選択した場合、MoEngage は _Tag A_ と _Tag B_ の両方を持つキャンペーンを表示します。

## タグに基づいてユーザーを分析・セグメント化する

キャンペーンタグに基づいてユーザーをフィルタリングできます。フィルタークエリを使用して、特定のタグを持つキャンペーンを受信したユーザーを見つけます。これらのフィルターオプションは **Campaign Tags** フィルターにあります。

![Screenshot 2025-08-04 at 5.09.19 PM.png](/images/moengage_4495b5.png)

#### タグでユーザーをセグメント化する

次のシナリオを考えてみましょう。

- _Country_ と _Sale_ の 2 つのカテゴリがあります。
- _Country_ カテゴリには、_India_ と _US_ のタグが含まれています。
- _Sale_ カテゴリには、_Mobile_ と _Apparel_ のタグが含まれています。
- C1、C2、C3 の 3 つのプッシュキャンペーンがあります。
  - C1 には _US_ と _Mobile_ のタグが含まれています。
  - C2 には _India_ と _Apparel_ のタグが含まれています。
  - C3 には _India_ と _Mobile_ のタグが含まれています。

モバイル関連のキャンペーンをクリックしたユーザーをセグメント化するには、次の手順に従います。

1. MoEngage UI の左側のナビゲーションメニューで **Segments** をクリックし、**Create segment** をクリックします。
2. Create segment ページで **Filter users by** をクリックします。
3. **User behavior** タブで、**Notification clicked** **iOS** または **Notification clicked** **Android** イベントを選択します。
4. **\+ Attributes** をクリックし、フィルターオプションから **Campaign Tags** を選択します。
5. 必要な演算子を選択し、**Mobile** を選択します。

この操作により、国のタグに関係なく、キャンペーン C1 と C3 の通知をクリックしたすべてのユーザーがセグメント化されます。

セグメントの詳細については、[Segments のドキュメント](/ja/user-guide/segment)を参照してください。

## キャンペーンレポートのタグ

すべてのキャンペーンタグは、キャンペーンレポートで利用できます。レポートには、各タグカテゴリが個別の列として含まれます。

上記のシナリオでは、出力レポートに "Tag category Country" と "Tag category Sale" の 2 つの列が追加されます。各列には、特定のキャンペーンで選択されたタグが一覧表示されます。

![Screenshot_2021-03-26_at_12.54.05_PM.png](/images/moengage_d3afc9.png)

<Info>
  カスタムの自動レポートを作成する場合は、**Tags** を選択する必要があります。詳細については、[キャンペーンレポートのドキュメント](/ja/user-guide/campaigns-and-channels/campaign-management-and-reports/create-ad-hoc-campaign-reports)を参照してください。
</Info>

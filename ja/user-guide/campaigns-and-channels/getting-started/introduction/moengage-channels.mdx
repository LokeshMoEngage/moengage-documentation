MoEngage における _チャネル_ とは、ユーザーにメッセージを配信するために使用する手段を指します。スマートフォンへの直接のアラートであれ、受信トレイへのメールであれ、チャネルはオーディエンスとつながるための手段です。

マーケターは、MoEngage の多様なチャネルを使用して、さまざまなタッチポイントでオーディエンスと効果的にエンゲージできます。適切なチャネルを選択することで、関連性の高いコンテンツを配信し、エンゲージメントを促進し、キャンペーンの目標を達成できます。

# MoEngage のチャネル

MoEngage は、オーディエンスとつながるために次のチャネルをサポートしています。

| チャネル名 | チャネルの概要 | メリット | ユースケース |
| --- | --- | --- | --- |
| **Mobile Push** | モバイルプッシュ通知は、アプリが閉じている場合でも、ユーザーの Android および iOS デバイスにタイムリーなアラートやメッセージを直接配信します。このチャネルは、非アクティブユーザーの再エンゲージメント、プロモーションの告知、重要なアップデートの送信をユーザーのスマートフォンに直接行うのに役立ちます。詳細については、[Mobile Push](/ja/user-guide/campaigns-and-channels/mobile-push) を参照してください。 | <ul><li>高い視認性</li><li>直接的なリーチ</li><li>即時のアクションを促すのに最適</li></ul> | <ul><li>動的な製品画像を含むカート放棄のリマインダーを送信する。</li><li>アプリの使用パターンに基づいて非アクティブユーザーを再エンゲージする。</li><li>フラッシュセールを告知する。</li></ul> |
| **Web Push** | Web プッシュ通知は、ユーザーのデスクトップおよびモバイルの Web ブラウザにアラートを送信します。ウェブサイトの訪問者が離脱した後でも再エンゲージし、サイトに呼び戻すための強力な手段です。詳細については、[Web Push](/ja/user-guide/campaigns-and-channels/web-push) を参照してください。 | <ul><li>Web 訪問者への高いリーチ</li><li>メールアドレス不要</li><li>トラフィックの誘導に効果的</li></ul> | <ul><li>閲覧したアイテムの値下げをユーザーに通知する。</li><li>新しいブログ記事を告知する。</li><li>ウェブサイトのショッピングカートに残っているアイテムをリマインドする。</li></ul> |
| **Email** | メールを使用すると、パーソナライズされたメッセージ、ニュースレター、プロモーションコンテンツを登録ユーザーの受信トレイに送信できます。この従来型のチャネルは、詳細なコミュニケーション、顧客ロイヤルティの構築、リードの育成に不可欠です。詳細については、[Email](/ja/user-guide/campaigns-and-channels/email) を参照してください。 | <ul><li>リッチコンテンツに柔軟に対応</li><li>長期的なエンゲージメントに強い</li><li>広く普及している</li></ul> | <ul><li>新規登録者にウェルカムシリーズを送信する。</li><li>閲覧履歴に基づいてパーソナライズされた製品レコメンデーションを送信する。</li><li>動的コンテンツを含む月刊ニュースレターを送信する。</li></ul> |
| **SMS** | SMS（Short Message Service）を使用すると、登録ユーザーにテキストベースのメッセージを直接送信できます。SMS は、迅速で優先度の高いアラートに最適です。詳細については、[SMS](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/sms/getting-started-with-sms/introduction-to-sms) を参照してください。 | <ul><li>高い開封率</li><li>即時配信</li><li>緊急のメッセージに効果的</li></ul> | <ul><li>SMS で OTP、配送状況の更新、予約のリマインダーを送信する。</li><li>RCS でインタラクティブなカスタマーサービスフローや製品紹介を送信する。</li></ul> |
| **RCS** | Rich Communication Services（RCS）は、企業がよりダイナミックかつインタラクティブにユーザーとエンゲージできるメッセージングの一種です。RCS を使用するマーケターは、画像、動画、インタラクティブな要素などのリッチメディアを活用して、より魅力的で視覚に訴えるメッセージを作成できます。詳細については、[RCS](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/rcs/getting-started-with-rcs/introduction-to-rcs) を参照してください。 | | |
| **MMS** | Multimedia Messaging Service（MMS）は Short Message Service（SMS）の拡張機能で、テキストに加えて、画像、GIF、音声、動画、連絡先カードなどのよりリッチなコンテンツを送信できます。詳細については、[MMS](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/mms/getting-started-with-mms/introduction-to-mms) を参照してください。 | | |
| **In-app Messaging** | アプリ内メッセージは、ユーザーがモバイルアプリケーションをアクティブに使用している間に、アプリ内に直接表示されます。このチャネルを使用すると、ユーザーのワークフローを中断することなく、機能の案内、状況に応じたヘルプの提供、新機能の告知、アクションの促進を行えます。詳細については、[In-app Messaging](/ja/user-guide/campaigns-and-channels/in-app-message) を参照してください。 | <ul><li>高いコンテキスト性</li><li>邪魔にならない</li><li>アプリ内アクションの促進に最適</li></ul> | <ul><li>アプリの初回起動時にウェルカムメッセージを表示する。</li><li>新機能のチュートリアルを提供する。</li><li>ポジティブな体験の後にレビューを促す。</li></ul> |
| **On-site Messaging** | オンサイトメッセージは、ユーザーがデスクトップまたはモバイルのウェブサイトを訪問している際に、ポップアップ、アンケート、リード獲得フォームを直接表示します。これにより、リードの獲得、フィードバックの収集、リアルタイムのパーソナライズされた体験の提供が可能になります。詳細については、[On-site Messaging](/ja/user-guide/campaigns-and-channels/on-site-message/getting-started-with-on-site-message/portfolio-for-on-site-messaging) を参照してください。 | <ul><li>リアルタイムのパーソナライゼーション</li><li>即時のフィードバック収集</li><li>リード獲得</li></ul> | <ul><li>初回訪問者に割引のポップアップを表示する。</li><li>離脱意図フォームでメール登録を集める。</li><li>製品ページで簡単なアンケートを実施する。</li></ul> |
| **Cards** | Cards は、アプリに埋め込まれた専用フィード内にメッセージを表示するための多目的なチャネルです。ユーザーは、ニュースの更新、パーソナライズされたオファー、製品レコメンデーションなどのコンテンツを都合の良いときに閲覧できます。詳細については、[Cards](/ja/user-guide/campaigns-and-channels/cards) を参照してください。 | <ul><li>ユーザー主導のエンゲージメント</li><li>邪魔にならない</li><li>エバーグリーンコンテンツに最適</li></ul> | <ul><li>パーソナライズされた記事のフィードをキュレーションする。</li><li>ユーザーのロイヤルティプログラムのステータスを表示する。</li><li>ユーザーの好みに合った新着製品を紹介する。</li></ul> |
| **WhatsApp** | WhatsApp を使用すると、WhatsApp でのコミュニケーションをオプトインしたユーザーにテンプレートメッセージを送信できます。このチャネルは、カスタマーサポート、トランザクションの更新、プロモーションコンテンツのために、非常にパーソナルで広く普及した方法でオーディエンスとつながることができます。詳細については、[WhatsApp](/ja/user-guide/campaigns-and-channels/whatsapp) を参照してください。 | <ul><li>高いエンゲージメント率</li><li>信頼されたコミュニケーションチャネル</li><li>リッチメディアのサポート</li></ul> | <ul><li>注文確認、配送通知、カスタマーサービスの返信を送信する。</li><li>事前承認済みのテンプレートを使用して、パーソナライズされたプロモーションオファーを送信する。</li></ul> |
| **Facebook Audience** | Facebook Audience を使用すると、MoEngage のデータを Facebook Ad Audience と同期して、Facebook Audience Network でユーザーをリターゲティングできます。これにより、Facebook 上の特定のユーザーセグメントに関連性の高い広告を配信できます。詳細については、[Facebook Audience](/ja/user-guide/campaigns-and-channels/facebook-audience) を参照してください。 | <ul><li>既存の広告費を活用</li><li>精密なターゲティング</li><li>ソーシャルプラットフォームでの幅広いリーチ</li></ul> | <ul><li>カートを放棄したユーザーを Facebook 広告でリターゲティングする。</li><li>高価値顧客から類似オーディエンスを作成する。</li><li>既存顧客を獲得キャンペーンから除外する。</li></ul> |
| **Google Ads Audience** | Google Ads Audience を使用すると、データを Google Ads Audience と同期して、Google Display Network 全体でユーザーをリターゲティングできます。これにより、精密な広告ターゲティングとキャンペーンパフォーマンスの向上が可能になります。詳細については、[Google Ads Audience](/ja/user-guide/campaigns-and-channels/google-ads-audience) を参照してください。 | <ul><li>購買意欲の高いターゲティング</li><li>幅広いネットワークリーチ</li><li>広告 ROI の向上</li></ul> | <ul><li>特定の製品カテゴリを閲覧したユーザーに特定の広告を表示する。</li><li>アプリで高いエンゲージメントを示すユーザーに高い入札を行う。</li><li>最近コンバージョンしたユーザーを除外する。</li></ul> |
| **Connectors** | Connectors は、MoEngage を任意のサードパーティツールやチャネルと統合するための柔軟な方法を提供します。Connectors を使用して、CRM システム、データウェアハウス、その他の専用メッセージングサービスなどのプラットフォームにユーザーデータを転送したりコミュニケーションをトリガーしたりすることで、エンゲージメント機能を拡張できます。詳細については、[Connectors](/ja/user-guide/campaigns-and-channels/connectors) を参照してください。 | <ul><li>カスタム統合が可能</li><li>データフローを自動化</li><li>MoEngage のリーチを拡張</li></ul> | <ul><li>営業のフォローアップのために、購入データを CRM（例: Salesforce）に同期する。</li><li>高度な分析のためにデータウェアハウスにデータを送信する。</li></ul> |
| **Connected Apps** | Connected Apps を使用すると、MoEngage を外部のアプリケーションやサービスとシームレスに統合できます。これにより、データの統合、ワークフローの自動化、MarTech スタック全体にわたる MoEngage の機能拡張が可能になります。詳細については、[Connected Apps](/ja/user-guide/campaigns-and-channels/connected-apps) を参照してください。 | <ul><li>データの一元管理</li><li>自動化の強化</li><li>プラットフォーム機能の拡張</li></ul> | <ul><li>分析プラットフォームと統合して、より深いインサイトを得る。</li><li>カスタマーサポートツールに接続して、統合された顧客ビューを提供する。</li><li>eコマースプラットフォームとのデータ同期を自動化する。</li></ul> |
| **Web Personalization** | Web Personalization を使用すると、ユーザーがウェブサイトにいる間の体験をカスタマイズできます。ユーザーの行動、好み、リアルタイムのインタラクションに基づいて動的なコンテンツ、オファー、レコメンデーションを表示し、コンバージョンとエンゲージメントの向上につなげることができます。詳細については、[Web Personalization](/ja/user-guide/campaigns-and-channels/web-personalization) を参照してください。 | <ul><li>ユーザー体験の向上</li><li>コンバージョン率の向上</li><li>リアルタイムの適応性</li></ul> | <ul><li>ホームページにパーソナライズされた製品レコメンデーションを表示する。</li><li>ユーザーセグメントに基づいてターゲットを絞ったバナーを表示する。</li><li>リピーター向けにウェブサイトのコンテンツを動的に変更する。</li></ul> |

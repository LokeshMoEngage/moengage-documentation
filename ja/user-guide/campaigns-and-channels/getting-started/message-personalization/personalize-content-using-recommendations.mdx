# 概要

レコメンデーションとは、一緒に販売またはマーケティングされることが多い関連商品のグループです。e コマース、小売、デジタルプラットフォームで一般的に利用されています。レコメンデーションは、次の点でユーザーに役立ちます。

- **発見のしやすさ**: セット内の関連商品をすばやく見つけられるため、大規模なカタログでのナビゲーションが簡単になります。
- **意思決定の簡素化**: 厳選された選択肢を提示するため、ニーズに合った商品を選びやすくなります。
- **ユーザーエクスペリエンスの向上**: 関連アイテムをセットにまとめることで、補完的な商品を探す時間を短縮できます。

パーソナライズされたレコメンデーションは、ユーザーの好みや購入履歴に基づいて商品の選択を最適化し、次のようなメリットをもたらします。

- **関連性の高いレコメンデーション**: ユーザーはニーズにより合った商品を目にすることができます。
- **満足度の向上**: パーソナライズされたセットがユーザーの関心に合致し、エンゲージメントが向上します。
- **より高い価値**: ユーザーは自分に合った割引やバンドルを受け取り、価値をより高く感じられます。
- **効率的なクロスセル**: 補完的な商品を提案し、追加購入を促します。

# キャンペーンでレコメンデーションを使用する

キャンペーンの作成時に、次の 2 つの方法でレコメンデーションをパーソナライズできます。

<Tabs>
  <Tab title="Custom HTML Editor">
    1. コンテンツの作成中に、**Custom HTML Editor** タブで目的のテンプレートにカーソルを合わせ、**Choose** をクリックしてエディターを開きます。

    ![HTMLEDITORFINAL1.gif](/images/moengage_e8e5f0.png)

    2. **Template Editor** セクションで _@_ と入力します。
    3. **Personalization** ダイアログボックスで、**Data personalization** タブをクリックします。

    ![CUSTOMHTML2.gif](/images/moengage_103ac8.png)

    4. **Select Attribute** リストで、**Product sets** の下にある目的のセットをクリックし、**Done** をクリックします。

    ![CHTMED1.png](/images/moengage_c6091b.png)

    5. **Template Editor** セクションで _@_ と入力して目的の商品セットを選択し、Jinja コードを記述して商品セット属性のリストを取得し、ユーザーの好みに基づいて商品セットをコミュニケーションで送信します。

    ![personalization@jinjaproductset.gif](/images/moengage_9e504f.png)

    6. **Preview** をクリックします。

    ![Screenshot 2024-11-25 at 2.24.05 PM (1).png](/images/moengage_832cab.png)
  </Tab>
  <Tab title="Drag and Drop Editor">
    1. コンテンツの作成中に、**Drag and drop editor** タブで目的のテンプレートにカーソルを合わせ、**Choose** をクリックしてエディターを開きます。

    ![DRAGANDDROP1.gif](/images/moengage_a64254.png)

    2. テンプレートエディターセクションの **ROWS** タブで、リストから _Product Sets_ をクリックします。
    3. **ADD PRODUCT SET ROW** ダイアログボックスの **Select product set** リストで、定義済みの商品セットをクリックし、**Create** をクリックします。

    ![DRAGANDROP2.gif](/images/moengage_d438a2.png)

    4. **Row layout** アコーディオンを展開し、目的の行レイアウトをクリックします。

    ![DRAGANDDROP3.png](/images/moengage_5d6c2e.png)

    5. **Product Block Layout** アコーディオンを展開し、目的の商品ブロックレイアウトをクリックします。

    ![DRAGANDDROP4.png](/images/moengage_733d7a.png)

    6. **Information Mapper** アコーディオンを展開し、インフォメーションマッパーを定義します。

    ![DRAGANDROP5.png](/images/moengage_766408.png)

    7. **Create** をクリックします。
    8. 定義した商品セットをテンプレートにドラッグ＆ドロップします。

    ![DRAGANDDROP7.gif](/images/moengage_8d33cc.png)

    9. **Preview** を選択します。

       <Frame>
         ![Preview を選択](/images/select-preview.png)
       </Frame>
  </Tab>
</Tabs>

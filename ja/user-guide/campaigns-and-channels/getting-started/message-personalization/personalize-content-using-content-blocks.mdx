# 概要

<Tip>
  コンテンツブロックの利用を開始する前に、コンテンツブロックを作成する必要があります。詳細については、[コンテンツブロック](/ja/user-guide/content/content-blocks/content-blocks)を参照してください。
</Tip>

コンテンツブロックを使用すると、マーケターは同じコンテンツを複数のキャンペーンで再利用できます。

# コンテンツブロックを使用したパーソナライゼーションをサポートするチャネル

次のチャネルを通じて送信されるキャンペーンにコンテンツブロックを追加できます。

| チャネル                                                                                                        | パーソナライゼーションのサポート |
| -------------------------------------------------------------------------------------------------------------- | ------------------------- |
| [Push(モバイルプッシュと Web プッシュ)](/ja/user-guide/campaigns-and-channels/mobile-push/create/personalize-push-campaigns) | Yes                       |
| [Email](/ja/user-guide/campaigns-and-channels/email/create/personalize-email-content)                             | Yes                       |
| [SMS](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/sms/personalize-sms-campaign)                         | Yes                       |
| [In-App](/ja/user-guide/campaigns-and-channels/in-app-message/create/create-in-app-campaign)                      | Yes                       |
| [On-Site Messaging](/ja/user-guide/campaigns-and-channels/on-site-message/create/personalization-of-osm-content)  | Yes                       |
| Cards                                                                                                          | Yes                       |
| [Whatsapp](/ja/user-guide/campaigns-and-channels/whatsapp/create/personalize-whatsapp-campaign)                   | Yes                       |
| [Connectors](/ja/user-guide/campaigns-and-channels/connectors/create/create-a-connector-campaign)                 | Yes                       |
| Facebook Audience                                                                                              | NA                        |
| Google Ads Audience                                                                                            | NA                        |

# コンテンツブロックでサポートされるパーソナライゼーション属性

次のパーソナライゼーション属性を使用して、コンテンツブロックをパーソナライズできます。

| パーソナライゼーションの種類     | サポート | 追加情報                                                                                                                                                                                                                                                        |
| ------------------------ | ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ユーザー属性           | Yes        | -                                                                                                                                                                                                                                                                             |
| イベント属性          | Yes        | Jinja を使用して、イベント属性に基づいてコンテンツをパーソナライズできます。パーソナライゼーションに使用するイベントが、イベントトリガーキャンペーンのトリガー条件で選択されていることを確認してください。これにより、コンテンツブロックを使用したキャンペーンコンテンツのパーソナライゼーションが確実に成功します。 |
| Product Set             | No         | -                                                                                                                                                                                                                                                                             |
| Content API              | No         | -                                                                                                                                                                                                                                                                             |
| コンテンツブロック            | Yes        | -                                                                                                                                                                                                                                                                             |
| Auxiliary Data           | No         | -                                                                                                                                                                                                                                                                             |
| キャンペーン属性       | Yes        | Jinja を使用して、キャンペーン属性に基づいてコンテンツをパーソナライズできます。  **注**: これは現在、Email でのみ利用できます。                                                                                                                                             |
| ビジネスイベント属性 | Yes        | Jinja を使用して、ビジネスイベント属性に基づいてコンテンツをパーソナライズできます。コンテンツブロックのパーソナライズに使用した属性を持つビジネスイベントと同じものを選択してください。  **注**: これは現在、Email、SMS、Push でのみ利用できます。                   |

<Info>
  - コンテンツブロックは、メールキャンペーンの Inbox プレビューではサポートされていません。
  - コンテンツブロックに追加され SMS で使用される URL はトラッキングできません。
  - アクティブなイベントトリガーキャンペーンおよび定期キャンペーンで使用されているコンテンツブロックは、これらのアクティブなキャンペーンを停止するオプションがないため、アーカイブできません。これらのコンテンツブロックは、該当するキャンペーンの有効期限が切れた後にのみアーカイブできます。
</Info>

# コンテンツブロックの使用方法

<Info>
  プレーンテキストエディターを使用してパーソナライゼーションの条件またはロジックを作成すると、チップとして表示されます。チップアクションの詳細については、[こちら](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/dynamic-content-personalization)を参照してください。
</Info>

コンテンツブロックは、次の 2 つの方法で使用できます。

- [目的のコンテンツブロックを選択する](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/personalize-content-using-content-blocks#select-the-desired-content-block)
- [コンテンツブロックのブロックラベルを直接挿入する](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/personalize-content-using-content-blocks#insert-the-block-label-of-your-content-block-directly)

## 目的のコンテンツブロックを選択する

<Tabs>
  <Tab title="キャンペーンの作成時">
    1. コンテンツの作成中に @ と入力します。
    2. Personalization ポップアップで、**Content blocks** タブをクリックします。

       ![20.png](/images/moengage_62254e.png)
    3. **Select content block** リストで、目的のコンテンツブロックをクリックします。
    4. コンテンツブロックのコンテンツのみを挿入するには、**Insert only the content of the content block** トグルをオンにします。

       <img
         src="/images/moengage_d20d8b.png"
         alt="Screenshot_2022-01-04_at_3.44.38_PM.png"
         style={{ width:"63%" }}
       />

       これにより、既存のコンテンツブロックから切り離されてコンテンツのみが挿入され、今後の更新は反映されません。
    5. **Done** をクリックしてコンテンツブロックを挿入します。
  </Tab>
  <Tab title="アラートの作成時">
    1. コンテンツの作成中に、**Text personalization** をクリックします。
    2. Inform personalization ポップアップウィンドウで、**Content block** タブをクリックします。

       ![21.png](/images/moengage_62be40.png)
    3. **Select content block** リストで、目的のコンテンツブロックをクリックします。

       ![22.png](/images/moengage_327116.png)
    4. コンテンツブロックのコンテンツのみを挿入するには、**Insert only the content of the content block** トグルをオンにします。

       <img
         src="/images/moengage_22df45.png"
         alt="23.png"
         style={{ width:"68%" }}
       />

       これにより、既存のコンテンツブロックから切り離されてコンテンツのみが挿入され、今後の更新は反映されません。
    5. **Copy & Close** をクリックして、パーソナライズされた属性をクリップボードにコピーします。
    6. キーボードショートカットを使用して、コピーした値をメッセージエディターに貼り付けます。
  </Tab>
</Tabs>

## コンテンツブロックのブロックラベルを直接挿入する

1. Content Block ページから _Block label_ をコピーします。

   ![contentblockkkk.png](/images/moengage_7c4e37.png)
2. _Block label_ をキャンペーン/テンプレート/別のコンテンツブロックに貼り付けます。

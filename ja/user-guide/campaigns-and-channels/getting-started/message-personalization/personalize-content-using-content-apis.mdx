# 概要

Content API を使用すると、レコメンデーション、クーポン、その他のパーソナライゼーション API に基づいてキャンペーン送信時にデータを動的に取得し、パーソナライズされたキャンペーンを作成できます。このようにターゲットを絞った、関連性の高いタイムリーなコミュニケーションは、一般的なメールキャンペーンよりも[エンゲージメントとコンバージョン率がはるかに高く](https://www.moengage.com/blog/power-of-push-notifications/ "https://www.moengage.com/blog/power-of-push-notifications/")なります。

<Tip>
  Content API の利用を開始する前に、MoEngage に Content API を追加する必要があります。詳細については、[Content API](/ja/user-guide/campaigns-and-channels/getting-started/campaign-content/content-apis) を参照してください。
</Tip>

MoEngage に API を追加した後は、コンテンツに API 呼び出しを埋め込んだ既存のコンテンツテンプレートを使用してキャンペーンを作成できます。これらのキャンペーンには、必要な書式、セグメンテーション、トリガースケジュールとともに、さまざまな SKU のプレースホルダーを含めることができます。

| [SMS](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/sms/personalize-sms-campaign)                         | Yes                       |

| [On-Site Messaging](/ja/user-guide/campaigns-and-channels/on-site-message/create/personalization-of-osm-content)  | Yes                       |

</Info>

# Content API を使用したパーソナライズ

Content API を使用してコンテンツをパーソナライズするには、次の手順を実行する必要があります。

1. [MoEngage への Content API の追加](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/personalize-content-using-content-apis#add-content-api-to-moengage)
2. [Content API を使用したパーソナライズされたキャンペーンの作成](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/personalize-content-using-content-apis#create-a-personalized-campaign)

## MoEngage への Content API の追加

MoEngage キャンペーン用に Content API を設定するには、次の手順を実行します。

<img
  alt="Screenshot 2025-07-23 at 11.51.38 AM.png"
  src="/images/moengage_52fce1.png"
  style={{ width:"77%" }}
/>

1. MoEngage で **Dashboard** \> **Settings** \> **APIs** に移動し、**Content API** タブをクリックします。
2. **Add** をクリックします。
3. **Add Content API** ページで、次の詳細を入力します。

   | フィールド                    | 説明                                                                                                                                                                                                                                          |
   | ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
   | **API Name**             | Content API の名前を入力します                                                                                                                                                                                                                            |
   | **API Type**             | タイプとして _Single_ を選択します。                                                                                                                                                                                                                         |
   | **API URL**              | Content API の完全な URL を入力します。                                                                                                                                                                                                            |
   | **Header**               | プラス記号をクリックし、Content API で使用するヘッダーのキーと値を入力します                                                                                                                                                                   |
   | **Key Value Parameters** | プラス記号をクリックして、Content API で使用するパラメーターのキーと値を追加します。値フィールドで "@" を使用すると、定義済みのユーザー属性のリストから選択できます。値フィールドでイベント属性を使用してパラメーターをパーソナライズすることはできません。 |
4. **Save** をクリックします。

## パーソナライズされたキャンペーンの作成

MoEngage に Content API を追加した後は、Content API を使用してパーソナライズされたキャンペーンを作成できます。

キャンペーン作成のステップ 2 の "Content" で、_ContentApi_ 変数を使用して、設定済みのすべての Content API ソースにアクセスします。Content API は、コード内で _ContentApi_ 変数を直接呼び出すか、パーソナライゼーションエディターから必要な Content API を選択することで使用できます。

1. キャンペーンのコンテンツエディターで _@_ と入力します。
2. Personalization ダイアログボックスで、**Data personalization** タブをクリックします。
3. **Select attribute** リストで、作成した Content API をクリックします。

   ![Email_ContentAPI.png](/images/moengage_e3d08d.png)
4. **Done** をクリックします。Content API がメッセージに追加されます。\
   たとえば、次のスクリーンショットでは、Content API が指定されたユーザー ID のおすすめ商品を動的に取得しています。この機能を使用して、商品レコメンデーションでユーザーのエンゲージメントを高め、購入を促すことができます。value パラメーターには、動的パラメーター(@ と入力して Content API に渡すユーザー属性を追加)または value セクションに入力できる静的パラメーターを指定できます。

   ![ContentAPI_RecoPdt_EmailPersonlizationUI.png](/images/moengage_e088b3.png)

   追加すると、Template editor に次のように表示されます。

   ![ContentAPI_added_in_Email_Editor.png](/images/moengage_0cb9aa.png)
5. **Preview** をクリックして、ユーザーの受信トレイでどのように表示されるかを確認します。

### 例 1

次の JSON を持つ _cart_ データソースがあるとします。

<CodeGroup>

```json JSON wrap
{
"date": "March 10, 2016",
"items": [
{
"name": "belt",
"image": "http://mydomain.com/images/1001.jpg",
"price": 11
}, {
"name": "shoes",
"image": "http://mydomain.com/images/1002.jpg",
"price": 12
}, {
"name": "hat",
"image": "http://mydomain.com/images/1003.jpg",
"price": 10
}
]
}
```

</CodeGroup>

コンテンツ作成では、次のコードを使用します。

<CodeGroup>

```text Code wrap
{% for cart_item in ContentApi.cart().items %}

## {{ cart_item.name }}: ${{ cart_item.price|round(2) }}

__PROTECTED_6__

{% endfor %}
```

</CodeGroup>

### 例 2

キャンペーンには、必要な書式、セグメンテーション、トリガースケジュールとともに、さまざまな SKU(この場合はホテル)のプレースホルダーが含まれています。

<img
  src="/images/moengage_1445a9.png"
  alt="SavedContentAPI.png"
  style={{ width:"66%" }}
/>

キャンペーンの送信時に、システムは次の処理を行います。

- Content API を呼び出し、目的地、チェックイン日とチェックアウト日、大人と子どもの人数などの検索パラメーターに基づいて、ユーザーにおすすめのホテルを取得します。
- 名前、評価、価格、画像、ランキングなどのおすすめホテルの詳細を、HTML 形式のパーソナライズされたメールでキャンペーンに入力します。
- 手動入力なしで、指定されたセグメントに属するすべてのユーザーに対してこれを動的に行います。

<img
  src="/images/moengage_f751ff.png"
  alt="DynamicContentExample.png"
  style={{ width:"63%" }}
/>

パーソナライゼーション言語の詳細については、[テンプレート言語のドキュメント](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/jinja-templating-language "/user-guide/campaigns-and-channels/getting-started/message-personalization/jinja-templating-language")を参照してください。

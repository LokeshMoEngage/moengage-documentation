# はじめに

パーソナライゼーションとは、エンゲージメントとコンバージョン率を向上させるために、マーケティングメッセージを個々のユーザーに合わせて調整する手法です。ユーザーを名前で呼びかけたり、過去のインタラクションに言及したり、閲覧した商品を表示したりすることで、企業はユーザーとのより関連性が高く有意義なつながりを築くことができます。

このアプローチは、競争の激しい市場でキャンペーンを差別化し、ユーザーとのより強固な関係を育み、開封率、リテンション、キャンペーン全体の効果を高めるのに役立ちます。

マーケターは、MoEngage でキャンペーンのコンテンツをパーソナライズできます。同じメッセージや画像内で、1 つまたは複数の属性をパーソナライズできます。

# ユースケース

- **ユーザーとのつながりを強化する**: ユーザーを名前で呼びかけ、最後のアクティビティに言及するパーソナライズされたメッセージを送信します。
- **収益を向上させる**: 個々のユーザー向けに固有のクーポンコードを作成して送信し、購入を促進します。
- **顧客を効果的にリターゲティングする**: 閲覧履歴に基づいて、ユーザーが閲覧したものの購入しなかった商品のパーソナライズされた画像を表示し、再検討を促します。
- **購入者のターゲティングを改善する**: 閲覧したものの購入しなかったユーザーにパーソナライズされた商品画像を使用し、購入の完了を促します。
- **ブランドの評判を大きく向上させる**: 各顧客に関連する商品を強調するようにメッセージを調整し、ブランドに対する印象を高めます。

<Tip>
  - MoEngage のキャンペーン作成、ユーザー属性、イベントトラッキングについての基本的な知識が必要です。
  - 高度な使用には、Jinja テンプレートの基本的な理解が推奨されます。
</Tip>

# コンテンツをパーソナライズする方法

MoEngage では、次の 2 つの方法でコンテンツをパーソナライズできます。

- エディターを使用する
- JINJA テンプレート言語を使用する

## エディターを使用したコンテンツのパーソナライズ

エディターを使用してコンテンツをパーソナライズする手順は次のとおりです。

1. キャンペーン作成のステップ 2 のコンテンツセクションで、任意のフィールド値に _@_ と入力してパーソナライゼーションを挿入します。\
   **Personalization** ページが表示され、パーソナライズしたいパラメーターに基づいてコンテンツを設定できます。
2. **Data Personalization** タブの **Select Attribute** リストで、該当するユーザー属性の値をクリックします。
3. 選択したユーザー属性について、何らかの理由でパーソナライゼーションが失敗した場合に使用するフォールバック値を定義します。次のオプションがサポートされています。
   - **No fallback**\*:\* パーソナライゼーションが機能しない場合に代替値がないことを定義します。
   - **Do not send**: パーソナライゼーションが機能しない場合にコンテンツを送信しないことを定義します。
   - **Replace text**: このオプションを選択した後、**Fallback text** フィールドに、パーソナライゼーションが機能しない場合に使用するテキストを入力または貼り付けます。
4. **Done** を選択します。

## Jinja テンプレート言語を使用したコンテンツのパーソナライズ

MoEngage のテンプレート言語は、人気がありシンプルなテンプレート言語である Jinja をベースにしており、カスタマイズやパーソナライゼーションの要件を最大限にコントロールできます。詳細については、[MoEngage テンプレート言語(JINJA)](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/jinja-templating-language)を参照してください。

<Info>
  MoEngage は現在、Jinja バージョン 2.8 をサポートしています。
</Info>

たとえば、次の Jinja コードは、Product Set から最初の商品を取得する方法を定義しています。

Jinja

```text wrap
{% if ProductSet.Observabilitytests%}{{ProductSet.Observabilitytests[0].description}}{% else %}MOE_NOT_SEND{% endif %}
```

### フォールバックの定義

MoEngage のメールテンプレートでは、null 値を含むメッセージは送信されません。そのため、このような状況を避けるためにデフォルトのフォールバック値を割り当てる必要があります。次の例では、ユーザーの所在地がない場合、MoEngage はメッセージを送信しません。

```text wrap
Welcome to {{ UserAttribute['Location'] }}
```

このような状況でもメッセージが送信されるようにするには、値が null の場合に変数が返すデフォルトのフォールバック値を指定する必要があります。MoEngage のメールテンプレートでは、属性が null を返す状況に対処するためのさまざまなオプションを含むオーバーレイポップアップが表示されます。

![5d92aaf1-31be-4708-ba15-6695728879c7.png](/images/moengage_dc779f.png)

選択したオプションは、返される値に基づいてメッセージを送信する際に自動的に使用されます。デフォルト値が指定されている場合、パーソナライズされたメッセージは次のようになります。

`Welcome, {{ UserAttribute['First name']|default('Guest') }}`

または、次のコードを使用することもできます。

<CodeGroup>

```text Jinja wrap
{% set firstName = UserAttribute['First name'] %}
{% if firstName %}
Welcome, {{ firstName }}
{% else %}
Welcome!
{% endif %}
```

</CodeGroup>

# パーソナライゼーションの種類

次の要素を使用してコンテンツをパーソナライズできます。

## ユーザー属性

所在地や好みなどのユーザーの特性に基づいてメッセージを調整し、各ユーザーが関連性の高いコンテンツを受け取れるようにします。

たとえば、パーソナライズされたメールは、メールのコンテキストを活用し関連性が高いため、開封率とコンバージョン率が高くなります。名前、所在地、その他の属性などのユーザー属性に基づいて、メールキャンペーン(一般メールとイベントトリガーメールの両方)をパーソナライズできます。

### 例

#### 名前のパーソナライゼーション

ユーザーに最後のアクティビティ(閲覧した商品、購入した商品)を思い出してもらうために、ユーザーを名前で呼びかけます。

![first name person push new.gif](/images/moengage_e3c311.png)

#### 画像のパーソナライゼーション

ユーザーが閲覧したものの購入しなかった商品を販売するために、パーソナライズされた画像を送信します。

![2024-08-26_12-06-46.gif](/images/moengage_d3233c.png)

#### クーポンコードのパーソナライゼーション

すべてのユーザーに固有のクーポンコードを送信するには、ユーザーレベルのクーポンをカスタム属性として保存し、パーソナライゼーションで使用する必要があります。この例では、ユーザー固有のクーポンコードが **Promo Code** という名前の属性に保存されています。

![coupon personalisation push.gif](/images/moengage_ec89ee.png)

#### キーと値のペアのパーソナライゼーション

固有のユーザー属性をアプリに渡し、それに基づいて判断を行いたい場合、定義したキーと値のペアを使用して、フィードバックフォームやユーザーアンケートなどに事前入力できます。

![keyvalue person push.gif](/images/moengage_ff3c96.png)

<Warning>
  例ではサンプルの属性名を使用しています。これらの名前は標準のものではなく、MoEngage での保存方法によって異なります。
</Warning>

#### URL のパーソナライゼーション

ユーザーがリンクをクリックしたときのリダイレクト先となる URL やディープリンクもパーソナライズできます。

1. **Template Editor** セクションで、**Link personalization** をクリックします。

   ![Screenshot 2024-09-11 at 5.40.42 PM.png](/images/moengage_5ad082.png)

   ![](https://help.moengage.com/hc/en-us/article_attachments/207981506/Screen_Shot_2016-09-28_at_4.14.20_PM.png)
2. 表示されるテキストボックスに @ と入力します。
3. **Personalization** ダイアログボックスの **Data personalization** タブで、属性をクリックしてから **Done** をクリックします。

   ![2024-09-11_17-54-36.gif](/images/moengage_a742c2.png)
4. その後、このリンクをコピーして、HTML コード内の必要な場所に貼り付けることができます。

   ![Screenshot 2024-09-11 at 5.44.17 PM.png](/images/moengage_e1bb1c.png)

<Info>
  パーソナライズされた URL でユーザー属性が見つからない、または解決できない場合、メールはユーザーに送信されません。パーソナライズされた URL にはフォールバックの仕組みはありません。パーソナライズされたメールキャンペーンの作成で問題がある場合は、MoEngage の Customer Success Manager(CSM)またはサポートチームにお問い合わせください。
</Info>

## イベント属性

アプリの使用状況や過去の購入などのユーザーインタラクションを活用してコンテンツをパーソナライズし、タイムリーで関連性の高いメッセージを配信できます。

イベント属性ベースのパーソナライゼーションは、イベントトリガーキャンペーンでのみ利用できます。たとえば、ユーザーが _Add to Cart_ イベントを実行したものの購入を完了しなかった場合、そのイベントに基づいて特定のルールを適用できます。これらのルールが一致すると、MoEngage はイベントの属性を使用してメッセージを表示します。次の画像は _Account registered_ イベントの例です。

![image (5).png](/images/moengage_2a22a0.png)

## ビジネスイベント属性

トランザクションや予約などの特定のビジネスイベントの詳細を使用して、ユーザー向けのパーソナライズされた通知やリマインダーを作成できます。

<Info>
  パーソナライゼーションをサポートするすべてのチャネルにおいて、ビジネスイベント属性ベースのパーソナライゼーションは、ビジネスイベントトリガーキャンペーンでのみサポートされます。
</Info>

### 例

#### ビジネスイベントトリガーのプッシュキャンペーンの場合

ビジネスイベントトリガーのプッシュキャンペーンでは、キャンペーンにマッピングされたビジネスイベントの属性を使用してキャンペーンをパーソナライズできます。手順は次のとおりです。

1. コンテンツ作成ステップで _@_ と入力して、パーソナライゼーションエディターを呼び出します。
2. 次に示すように、キャンペーンにマッピングされたビジネスイベントの属性が Business Event Attribute の見出しの下に表示されます。

   ![PushPersonalization triggeres with aux.png](/images/moengage_420780.png)
3. パーソナライゼーションに使用する属性を選択し、メッセージをカスタマイズします。

ビジネスイベントを使用したパーソナライゼーションでは、1 つのテンプレートを使用して複数のキャンペーンを送信できるため、作業量と自動化の面で大きな違いが生まれます。たとえば、同じキャンペーンで公開予定の 3 つの新しいウェブシリーズに関する情報を伝えることができます。イベント属性を使用し、シリーズ名、画像、キャスト、放送日で各シリーズのメッセージをパーソナライズして、ユーザーの関心(たとえば好みのジャンル)がシリーズのジャンルと一致する動的セグメントにコミュニケーションを送信できます。

## キャンペーン属性

レポートや分析の目的で、キャンペーン固有の詳細に基づいてメッセージを調整し、パーソナライズされたコンテンツを作成できます。たとえば、次の属性を動的属性として設定することで、メールキャンペーンのコンテンツにパーソナライゼーションを追加できます。

- Campaign ID
- Campaign name
- Campaign tags

## レコメンデーション

ユーザーの好み、属性情報、購買履歴に合ったアイテムをカタログから選択することで、パーソナライズされた Product Set のレコメンデーションを配信できます。このアプローチにより、個々の顧客のニーズに合わせて提案を調整し、エンゲージメントと潜在的な売上を向上させます。詳細については、[こちら](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/personalize-content-using-recommendations)を参照してください。

## Content API

Content API を使用して、パーソナライズされたキャンペーンを作成できます。Content API は、レコメンデーション、クーポン、その他のパーソナライゼーション API に基づいて、メッセージ送信時にデータを動的に取得します。このようなターゲットを絞ったタイムリーなコミュニケーションにより、一般的なキャンペーンと比較してエンゲージメントとコンバージョン率が大幅に向上します。詳細については、[Content API を使用したコンテンツのパーソナライズ](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/personalize-content-using-content-apis)を参照してください。

# パーソナライゼーションをサポートするチャネル

MoEngage は、次の種類の機能のパーソナライゼーションをサポートしています。

| 機能/チャネル                          | Push | SMS | Email | WhatsApp | In-app Messaging | On-site Messaging | Cards | Connectors | Personalize |
| ------------------------------------------ | ---- | --- | ----- | -------- | ---------------- | ----------------- | ----- | ---------- | ----------- |
| **ユーザー属性**                        | Yes  | Yes | Yes   | Yes      | Yes              | Yes               | Yes   | Yes        | Yes         |
| **イベント属性**                       | Yes  | Yes | Yes   | Yes      | Yes              | Yes               | Yes   | Yes        | No          |
| **ビジネスイベント属性**              | Yes  | Yes | Yes   | No       | No               | No                | No    | NA         | No          |
| **キャンペーン属性**                    | No   | No  | Yes   | No       | No               | No                | No    | No         | No          |
| **レコメンデーション**                        | Yes  | Yes | Yes   | Yes      | Yes              | Yes               | Yes   | Yes        | Yes         |
| **Auxiliary Data 属性**              | Yes  | Yes | Yes   | Yes      | Yes              | Yes               | Yes   | Yes        | No          |
| **Content API によるパーソナライゼーション**        | Yes  | Yes | Yes   | Yes      | Yes              | Yes               | No    | No         | Yes         |
| **テキストコンテンツブロックによるパーソナライゼーション** | Yes  | Yes | Yes   | Yes      | Yes              | Yes               | Yes   | Yes        | Yes         |
| **HTML コンテンツブロックによるパーソナライゼーション** | NA   | NA  | Yes   | NA       | Yes              | No                | No    | No         | Yes         |

# パーソナライズされたプレビュー

パーソナライゼーションプレビュー機能を使用すると、パーソナライズされたコンテンツがエンドユーザーにどのように表示されるかを視覚化できるため、企業はターゲットオーディエンスに合わせてコンテンツを調整できます。Jinja コード内のエラーを検出し、文字レベルのエラー通知を提供するため、ユーザーは問題に効率的に対処し、エンゲージメントを向上させることができます。詳細については、[パーソナライズされたプレビュー](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/personalized-preview)を参照してください。

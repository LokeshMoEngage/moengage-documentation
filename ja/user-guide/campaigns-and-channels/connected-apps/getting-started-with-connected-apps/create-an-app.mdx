# はじめに

_Connected Apps_ プラットフォームを使用すると、MoEngage を既存のマーケティングテクノロジー (MarTech) ツールと統合できます。この統合により、データを送受信するための新しい MoEngage チャネルが作成され、キャンペーンや顧客とのインタラクションを効率化できます。

# ステップ 1: Connected App を作成する

Connected App を作成するには、次の手順を実行します。

1. MoEngage ダッシュボードの左側のナビゲーションメニューで、**App marketplace** をクリックします。
2. App marketplace ページで、**\+ Create app** をクリックします。 <img alt="Screenshot 2024-11-13 at 2.09.03 PM.png" src="/images/moengage_c50e01.png" />
3. **Create app** ダイアログボックスで、次の詳細を入力します。

   | フィールド | 説明 |
   | --- | --- |
   | **App name** | アプリ名を入力します。 |
   | **App type** | **Channel** をクリックします。 |

   <img src="/images/moengage_5f333a.png" alt="Screenshot 2024-11-13 at 2.07.07 PM.png" />
4. **Create** をクリックします。これにより、Connected App が MoEngage の接続済みチャネルとして追加されます。その後、Connected App のページに移動します。 <img src="/images/moengage_a1b284.png" alt="Screenshot 2024-11-14 at 9.35.46 PM.png" />

# ステップ 2: チャネルコネクタを追加する

接続済みチャネルを作成したら、そのユースケースを定義する必要があります。これらのユースケースにより、MoEngage がアプリのキャンペーンを実行および分析する方法を定義します。

ユースケースを理解するには、次の例を参照してください。

| **チャネル** | **コネクタ (ユースケース)** |
| --- | --- |
| リターゲティングアプリ (TikTok、Snapchat、LinkedIn など) | &nbsp;&nbsp;&nbsp;&#8226;&nbsp; オーディエンスにユーザーを追加する。<br/>&nbsp;&nbsp;&nbsp;&#8226;&nbsp; オーディエンスからユーザーを削除する。 |
| メッセージングアプリ (Telegram、Line、Viber、WeChat など) | &nbsp;&nbsp;&nbsp;&#8226;&nbsp; ユーザーに SMS を送信する。<br/>&nbsp;&nbsp;&nbsp;&#8226;&nbsp; ユーザーに MMS を送信する。<br/>&nbsp;&nbsp;&nbsp;&#8226;&nbsp; グループにメッセージを送信する。<br/>&nbsp;&nbsp;&nbsp;&#8226;&nbsp; コミュニティにメッセージを送信する。 |
| サポートツール (Zendesk、Freshdesk など) | &nbsp;&nbsp;&nbsp;&#8226;&nbsp; 新しいチケットを作成する。<br/>&nbsp;&nbsp;&nbsp;&#8226;&nbsp; チケットをクローズする。<br/>&nbsp;&nbsp;&nbsp;&#8226;&nbsp; 既存のチケットを更新する。 |

ユースケースを定義したら、これらのコネクタをアプリに追加します。

## ステップ 2.1: Config ファイルを作成する

すべてのコネクタには、MoEngage がアプリとやり取りする方法を指示する設計図として使用される Config が必要です。コネクタ用の Config ファイルの作成について詳しくは、[チャネルコネクタ Config ガイド](/ja/user-guide/campaigns-and-channels/connected-apps/getting-started-with-connected-apps/create-a-channel-connector-config-file)を参照してください。

## ステップ 2.2: 新しいコネクタを追加する

Config ファイルの準備ができたら、次の手順を実行してチャネルのコネクタを作成します。

1. App marketplace の Connected App ページで、**Configure** タブをクリックし、**\+ Add configuration** をクリックします。
2. **Upload config** セクションで、[ステップ 2.1](/ja/user-guide/campaigns-and-channels/connected-apps/getting-started-with-connected-apps/create-an-app#step-2-1-create-a-config-file) で作成した Config ファイル (.json) をアップロードします。アップロードが成功したら、次のステップに進みます。 <img alt="Screenshot 2024-11-14 at 9.49.31 PM.png" src="/images/moengage_a8047c.png" />
3. **Add** をクリックします。 <img alt="Screenshot 2024-11-14 at 9.58.30 PM.png" src="/images/moengage_615f2a.png" />

チャネルコネクタが正常に追加されました。統合してキャンペーンで使用する準備が整いました。

<Info>
  複数のコネクタを追加するには、**\+ Add configuration** をクリックします。
</Info>

## コネクタ Config を編集する

以前の Config に問題がある場合は、新しいファイルに置き換えます。

1. **Upload config** セクションで、省略記号アイコン ( <Icon icon="ellipsis-vertical" />) をクリックします。
2. **Edit** をクリックします。
3. バツアイコンをクリックします。
4. [ステップ 2.2](/ja/user-guide/campaigns-and-channels/connected-apps/getting-started-with-connected-apps/create-an-app#step-2-2-add-a-new-connector) に記載されている手順を繰り返して、新しい Config を追加します。 <img alt="Screenshot 2024-11-13 at 3.52.29 PM.png" src="/images/moengage_8111a5.png" />

<Warning>
  既存のキャンペーンでは、引き続き古いフィールドと関連する指標が表示されます。キャンペーンの実行中にコネクタを変更すると、一貫性のない動作につながる可能性があるため、推奨されません。
</Warning>

# ステップ 3: 接続済みチャネルを統合する

アプリにチャネルコネクタを追加したら、キャンペーンで使用するために、接続済みチャネルを MoEngage と統合する必要があります。

1. App marketplace の Connected App ページで、**Integrate** タブをクリックし、**\+ Add integration** をクリックします。
2. **Connection details** セクションで、次の詳細を入力します。

   | 用語 | 説明 |
   | --- | --- |
   | **Connection name** | キャンペーンの作成時にコネクタを識別するために使用できる、わかりやすい名前です。 |
   | **Additional fields** | これらは、コネクタ Config で他の入力フィールドを定義した場合にのみ使用できます。これらのフィールドに適宜詳細を入力します。 |

   <img src="/images/moengage_af625f.png" alt="Screenshot 2024-11-14 at 10.51.07 PM.png" />
3. **Connect** をクリックします。チャネルアプリが MoEngage と正常に統合されました。 <img src="/images/moengage_553505.png" />

<Info>
  **\+ Add integration** をクリックすると、複数の統合を追加できます。
</Info>

# ステップ 4: キャンペーンを実行する

接続済みチャネルを MoEngage と統合したら、MoEngage キャンペーンを実行できます。こちらの手順に従って [Connected App キャンペーンを作成](/ja/user-guide/campaigns-and-channels/connected-apps/create/create-a-connected-app-campaign)し、そのパフォーマンスを分析します。

# 概要

RCS はブランドの信頼性を高め、ビジネスエンゲージメントを向上させるのに役立ちます。パーソナライズされたメッセージやビジュアルメディアを顧客に送信し、効率を改善し、自動通知を実現できます。RCS メッセージは、**Rich Card**、**Simple Text**、または **Carousel** のメッセージタイプを使用して送信できます。

企業は、魅力的なテンプレートを使用して作成した RCS メッセージを通じて、顧客とインタラクティブにコミュニケーションできます。テンプレートは、簡単にカスタマイズして再利用できる事前設計されたコンポーネントで、RCS メッセージを効率的に作成できます。迅速かつシームレスなコンテンツ作成が可能になり、時間を節約しながら、魅力的で視覚的に訴求力のあるメッセージの作成に役立ちます。

インド国外のユーザーの場合、テンプレートの承認は不要で、自由形式の RCS メッセージを送信できます。これらのユーザーに対して RCS テンプレートの使用は必須ではありませんが、メッセージコンテンツを再利用できる利便性のため、使用を推奨します。

<Info>
  テンプレートの承認プロセスは、インドのユーザーに RCS メッセージを送信する場合にのみ必要です。これらのテンプレートは、RCS プロバイダーを通じて作成された RCS エージェントに紐付けられます。
</Info>

<Info>
  - これはアドオン機能です。アカウントで有効にするには、MoEngage の CSM(カスタマーサクセスマネージャー)または[サポートチーム](/ja/user-guide/contact-support/raise-a-support-ticket-through-moengage-dashboard)にお問い合わせください。
  - RCS Carousel のサポートは RCS サービスプロバイダーによって異なり、すべてのプロバイダーで利用できるとは限りません。テンプレートタイプの選択時に **Carousel** がオプションとして表示されない場合は、サポートされているかどうかをプロバイダーに確認してください。
</Info>


# ユースケース

RCS は複数のユースケースで使用できます。RCS のユースケースについては、[RCS の概要](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/rcs/getting-started-with-rcs/introduction-to-rcs)を参照してください。

  <Tip>
    **RCS Carousel と Recommendations を組み合わせて ROI を最大化**: MoEngage の Recommendations エンジンは、製品カタログと各ユーザーの過去の行動やブランドとのインタラクションを使用して Carousel カードをパーソナライズし、クロスセルやアップセルの提案、または類似ユーザーの行動やアイテムの類似性に基づくレコメンデーションを通じて、ユーザーが最も関心を持つ可能性の高いアイテムを表示できます。全員に同じ静的なカルーセルを送信する代わりに、1 つのキャンペーンで各受信者にパーソナライズされたカードセットを配信できます。詳細については、[Recommendations](https://www.moengage.com/docs/user-guide/content/recommendations/getting-started/overview) を参照してください。
  </Tip>


# テンプレート管理

**RCS template management** ページでは、MoEngage で追加のテンプレートの作成、既存テンプレートの検索、テンプレートのフィルタリング、編集、表示、複製、削除を行えます。すべての RCS テンプレートを管理するには:

1. MoEngage ダッシュボードで、**Settings** \> **SMS, MMS & RCS** \> **RCS template management** に移動します。

   ![template management.png](/images/moengage_1fed99.png)
2. **RCS template management** ページには、次のフィールドが表示されます:

   | フィールド | 説明 |
   | --- | --- |
   | **Search template by name, content** | この検索バーを使用して、名前またはコンテンツでテンプレートを検索します。 |
   | **Filter** (<Icon icon="bars-filter" iconType="solid" /> ) | この追加フィルターオプションを使用して、**Template Type**、**Provider**、**Sender profile** に基づいてテンプレートをフィルタリングします。 |
   | **Add Template** | **Add Template** をクリックして、MoEngage アカウントにテンプレートを追加します。 |
   | **Template name** | テーブルの **Template name** 列には、作成されたすべてのテンプレートの名前が一覧表示されます。テンプレート名はハイパーリンクになっており、クリックすると閲覧専用モードでテンプレートが表示されます。 |
   | **Content** | **Content** 列には、各テンプレートの作成時にコンテンツセクションに追加されたメッセージが表示されます。カーソルを合わせるとメッセージ全体が表示されます。 |
   | **Template Type** | **Template type** 列には、テンプレートが Simple Text、Rich Card、Carousel のいずれであるかが表示されます。 |
   | **Sender Profile** | **Sender** **Profile** 列には、各テンプレートの送信者プロファイル名が表示されます。 |
   | **Provider** | **Provider** 列には、各テンプレートのプロバイダー名が表示されます(例: Karix、Gupshup)。 |

テンプレートを追加した後は、アクティブなキャンペーンで使用されているかどうかに応じて管理できます。テンプレートの **View**、**Edit**、**Duplicate**、**Delete** が可能です。

![vedd.png](/images/moengage_17c6bc.png)

<Info>
  アクティブなキャンペーンで使用されているテンプレートは、削除するとキャンペーンに影響する可能性があるため削除できません。テンプレートを削除する前にキャンペーンを停止してください。
</Info>

| テンプレートの使用状況 | 許可されるテンプレート操作 |
| --- | --- |
| テンプレートがアクティブなキャンペーンで使用されていない場合 | View、Edit、Duplicate、Delete |
| テンプレートがアクティブなキャンペーンで使用されている場合 | View、Duplicate |

## MoEngage でテンプレートを追加する

MoEngage でテンプレートを追加するには、次の手順を実行します:

1. **Settings** \> **SMS & RCS** \> **RCS template management** に移動します。**\+ Add Template** をクリックします。

![settings rcs.png](/images/moengage_a1d019.png)

2. **Add template** ページのテンプレート **Settings** セクションで、次の詳細を入力します:

![settin.png](/images/moengage_37793b.png)

| フィールド | 説明 |
| --- | --- |
| **Select Provider** | このテンプレートメッセージの送信に使用するサービスプロバイダーを選択します(例: Karix、Gupshup)。 |
| **Select sender** | 選択したプロバイダーに関連付けられ、このテンプレートが承認されている送信者を選択します。追加できる送信者は 1 つのみです。これはプロバイダーのポータルで作成された RCS エージェントです。 |
| **Template Name** | テンプレートの名前を入力します。名前は最大 100 文字です。 |
| **Template ID** (任意) | テンプレート ID を入力します。テンプレート ID はプロバイダーのダッシュボードで確認できます。 |
| **Template type** | テンプレートタイプを選択します。MoEngage は **Simple Text**、**Rich Card**、**Carousel** をサポートしています。 |

<Info>
  インドの顧客に RCS メッセージを送信する場合、**Template Name** と **Template ID** はプロバイダーのダッシュボードの情報と一致している必要があります。
</Info>

3. Add templates ページの **Content** セクションで、次の詳細を入力します。顧客に伝えるメッセージのコンテンツを追加できます。

      | **Mode** | ユーザーの端末でターゲットの Web ページをどのように表示するかを選択します。オプションは次のとおりです: <ul><li>**Browser:** ユーザーのネイティブまたは任意のスタンドアロン Web ブラウザアプリ(Chrome、Safari、Firefox など)でリンクを直接開きます。これが**デフォルト**のモードです。</li><li> **Webview - Full:** 端末の画面全体に広がる埋め込み Web コンテナ内でリンクを開きます。</li><li> **Webview - Half:** アクティブなチャット画面の下部 50% に広がる埋め込みドロワー内でリンクを開きます。</li><li> **Webview - Tall:** アクティブな画面の約 75% に広がる埋め込みドロワー内でリンクを開きます。</li></ul> |
      
      <Info>
     URL アクションのクリックは自動的にトラッキングされ、Campaign Analytics で確認できます。有効にしている場合は、説明文に含まれるリンクのクリックもトラッキングされます。
     </Info>
     </Tab>
   </Tabs>
   
5. すべての設定が完了したら、**Save** をクリックします。

テンプレートが **RCS template management** ページに一覧表示されます。

### RCS コンテンツのパーソナライズ

MoEngage は特定のパーソナライズ形式を使用します。タイトル、説明、CTA タイトルなど、すべてのパーソナライズフィールドには常に二重波括弧(`{{ }}`)を使用してください。\
異なる構文を使用するプラットフォームでコンテンツを作成している場合は、MoEngage でテンプレートを保存する前に、変数を二重波括弧を使用する形式に更新してください。そうしないと、変数はプレーンテキストとして送信されます。\
変数名には英数字、アンダースコア、波括弧のみを使用してください。例: `{{v1}}`、`{{custom_param}}`。

詳細については、[RCS キャンペーンのパーソナライズ](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/rcs/personalize-rcs-campaign)を参照してください。

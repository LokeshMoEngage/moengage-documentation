<Info>
  RCS Campaign Info はアドオン機能です。アカウントで有効にするには、MoEngage の CSM(カスタマーサクセスマネージャー)または[サポートチーム](/ja/user-guide/contact-support/raise-a-support-ticket-through-moengage-dashboard)にお問い合わせください。
</Info>

Campaign Info には、公開後の RCS キャンペーンの詳細が表示されます。この情報は **Info** タブで確認できます。**Info** タブにアクセスするには、次の手順を実行します:

1. MoEngage ダッシュボードの左側のナビゲーションメニューで **Engage** をクリックし、**Campaigns** をクリックします。
2. **All campaigns** ページで、表示するキャンペーンの名前をクリックします。
3. **Campaign info and analytics** ページで、**Info** タブをクリックします。Info タブには次の詳細が表示されます:

   <Tabs>
     <Tab title="タイムライン">
       このセクションは、ワンタイムキャンペーンと定期キャンペーンで利用できます。タイムラインには、キャンペーンの公開プロセスのさまざまな段階と現在のステータスが表示されます。これにより、キャンペーンのライフサイクルに対する完全な透明性とインサイトが得られます。オーディエンスの選択から最終配信までキャンペーンの進行状況を監視でき、トラブルシューティング、最適化、パフォーマンスの検証に不可欠です。表示される時刻はアプリのタイムゾーンに基づいています。このセクションには次の情報が含まれます:
       - **Segmentation query**: セグメンテーションクエリの開始時刻と完了時刻に関する情報が含まれます。
       - **Campaign ready**: 内部処理の後、MoEngage からキャンペーンを送信する準備が整った時刻に関する情報が含まれます。ASAP キャンペーンの場合、これはキャンペーンの送信時刻です。
       - **First sent**: MoEngage からメッセージの最初のバッチが送信された時刻と、最初のメッセージが送信された時刻に関する情報が含まれます。
       - **Last sent**: キャンペーンの最後のメッセージが送信された時刻に関する情報が含まれます。

     </Tab>
     <Tab title="オーディエンス">
       **Audience** タブには、キャンペーンのターゲットとなったユーザーに関する情報が含まれます。これらのユーザーは、キャンペーン作成のステップ 1 で定義されます。このタブは、キャンペーンのターゲティングロジックの完全かつ透明な記録を提供するため便利です。キャンペーンの送信先を検証するための情報源となり、正確な分析とコンプライアンスに不可欠です。このタブには次の詳細が含まれます:
       - **Segment**: セグメントとは、特定のプロパティ、値、またはルールによって定義されたユーザーのグループです。\
         **Segment** の詳細には、このキャンペーンの作成に使用されたセグメンテーション条件が表示されます。そのため、このセグメントが実行されるたびに、条件を満たすすべてのユーザーがセグメントに含まれ、キャンペーンを受信します。詳細については、[セグメントの作成](/ja/user-guide/segment/create-segments/rule-based-filter-segments)を参照してください。
       - **Control group**: [コントロールグループ](/ja/user-guide/campaigns-and-channels/getting-started/introduction/control-groups)とは、除外リストに追加されたユーザーのセットです。これらのユーザーはマーケティングキャンペーンを受信しません。コントロールグループをターゲットオーディエンスと比較することで、キャンペーンの効果を測定できます。Global Control Group と Campaign Control Group の 2 種類があります。\
         **Control group** の詳細には、キャンペーン作成時にコントロールグループが有効になっていたかどうかが表示されます。
       - **Filter by**: この詳細には、キャンペーン作成時に適用されたセグメンテーションフィルターと除外条件が表示されます。ユーザーは、すべてのユーザー、プロパティ、アフィニティ、行動、または AND/OR 条件を使用した複雑なクエリを含むカスタムセグメントに基づいてセグメント化できます。詳細については、[セグメントの作成](/ja/user-guide/segment/create-segments/rule-based-filter-segments)を参照してください。

         ![SMS_Audience.png](/images/moengage_f17f05.png)
     </Tab>
     <Tab title="トリガー条件">
       **Trigger criteria** タブには、このキャンペーンの作成時に追加されたトリガー条件が表示されます。このタブは、キャンペーンを起動する特定の条件について、透明で検証可能な記録を提供します。下の画像は、_App/Site Opened_ イベントベースのトリガーが追加された Event Triggered キャンペーンを示しています。\
       **注**: このセクションは、[Event Triggered](/ja/user-guide/campaigns-and-channels/getting-started/triggers/event/create-an-event-triggered-campaign) キャンペーンと [Business Event Triggered](/ja/user-guide/campaigns-and-channels/getting-started/triggers/business-event/business-event-triggered-campaigns) キャンペーンでのみ利用できます。

       ![SMS_TriggerCriteria.png](/images/moengage_6f4021.png)
     </Tab>
     <Tab title="スケジュール">
       **Scheduling** タブには、キャンペーン作成のステップ 3 で設定した、キャンペーンの配信スケジュール、配信コントロール、詳細コントロールに関する情報が表示されます。このタブは、キャンペーンのタイミングと配信コントロールについて、完全で検証可能な記録を提供します。配信スケジュールにより、キャンペーンをいつ、どのくらいの頻度でユーザーに送信するかを決定できます。次の詳細が含まれます:
       - **Time selection**: キャンペーンが送信された時刻を表示します。
       - **Start on**: キャンペーンの送信が開始された日時を表示します。
       - **Time zone**: キャンペーン配信のタイムゾーンを表示します。
       - **Best time to send**: キャンペーン送信の推奨時間帯を表示します。詳細については、[Best time to send](/ja/user-guide/ai-and-intelligence/timing/best-time-to-send) を参照してください。
       - **Ends on**: キャンペーンの終了日を表示します。
       - **Repeat:** キャンペーンの周期を表示します。詳細については、[スケジュールと目標](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/rcs/create-an-rcs-campaign)を参照してください。

       配信コントロールは、Frequency capping 機能を使用してユーザーに送信されるキャンペーンの数を制限するのに役立ちます。配信コントロールには次の詳細が含まれます:
       - **Frequency capping**: この機能は 1 日にユーザーに送信されるメッセージの数を制御するのに役立ちます。**Frequency capping** の詳細には、このキャンペーンでこの機能が有効になっているかどうかが表示されます。詳細については、[Frequency capping](/ja/user-guide/settings/channels/delivery-controls/frequency-capping) を参照してください。
       - **Count for FC:** この詳細には、**Count for the frequency capping** トグルがオンになっているかどうかが表示されます。オンの場合、このキャンペーンはフリークエンシーキャップの対象としてカウントされます。
       - **Request limit**: この詳細には、このキャンペーンのスロットル制限が表示されます。スロットリングにより、キャンペーンの送信レートを制御できます。詳細については、[Throttling](/ja/user-guide/settings/channels/delivery-controls/throttling) を参照してください。<br/>
       ![Screenshot 2025-03-25 at 11.50.52 AM.png](/images/moengage_3bfcaf.png)
     </Tab>
     <Tab title="コンバージョン目標">
       **Conversion goals** タブには、キャンペーンでトラッキングされるコンバージョン目標と収益指標が表示されます。プライマリコンバージョン目標には、目標名の横に '**P**' アイコンが表示されます。

       - **Attribution window**: ユーザーがキャンペーンを受信またはクリックした後に計算される、コンバージョン目標をキャンペーンに帰属させる期間(ウィンドウ)を表示します。

       **Control goals** には次の情報が表示されます:

       - **Goal Name**: キャンペーンに設定されたキャンペーン目標の名前を表示します。
       - **Event Name**: キャンペーン目標の設定に使用されたイベント名を表示します。
       - **Attribute Name**: キャンペーン目標の設定に使用された属性名を表示します。
       - **Attribute Value**: キャンペーン目標の設定に使用された属性値を表示します。

      Revenue Performace Info Value には次の情報が表示されます:

       - **Event Name**: キャンペーンの収益情報の設定に使用されたイベント名を表示します。
       - **Attribute Name**: キャンペーンの収益情報の設定に使用された属性名を表示します。
       - **Currency**: キャンペーンの収益の計算に使用された通貨を表示します。

       <Note>
         収益属性がオブジェクト配列内にある場合、MoEngage の計算結果が想定と一致しないことがあります。詳細については、[オブジェクト属性を使用した収益トラッキング](/ja/user-guide/campaigns-and-channels/campaign-management-and-reports/conversion-and-attribution#how-revenue-is-calculated-for-object-array-attributes)を参照してください。
       </Note>

       ![Screenshot 2025-04-08 at 6.02.29 PM.png](/images/moengage_3029ee.png)
     </Tab>
     <Tab title="プレビューとコンテンツ">
       **Preview and Content** セクションには、送信者、送信されるメッセージ、およびユーザーのモバイルデバイスでメッセージがどのように表示されるかのプレビューに関する情報が含まれます。キャンペーンに設定されたすべてのバリエーションとロケールの組み合わせをここで確認できます。

       **Content** セクションには、RCS キャンペーンに関する次の情報が表示されます:

       - **Connector**: 設定された RCS コネクター(サービスプロバイダー)。
       - **Sender**: RCS サービスプロバイダーの設定時に指定した送信者名。
       - **Template Name**: RCS テンプレートの設定時に指定したテンプレート名。
       - **Template Type**: テンプレートの種類。テンプレートタイプは **Simple Text**、**Rich Card**、**Carousel** のいずれかです。
       - **Title Parameters**: キャンペーンコンテンツ内のタイトルパラメーター。
       - **Description Parameters**: キャンペーンコンテンツ内の説明パラメーター。
       - **Suggestion Parameters**: キャンペーンコンテンツ内のサジェスチョンパラメーター。
       - **URL Tracking**: RCS のクリックをトラッキングするために使用される、RCS メッセージ内の URL。

     </Tab>
   </Tabs>

<Info>
  Rich Communication Services（RCS）チャネルは、有料アドオンとして利用できます。アカウントで有効にするには、MoEngageのカスタマーサクセスマネージャー（CSM）または[サポートチーム](/ja/user-guide/contact-support/raise-a-support-ticket-through-moengage-dashboard)にお問い合わせください。
</Info>

MoEngageでは、RCSをエンゲージメントチャネルとして利用できます。これにより、ユーザーのモバイルデバイスに直接アプローチし、RCSメッセージングの高い開封率と既読率を活用できます。

MoEngageでRCSキャンペーンを作成するには、以下の手順を実行します。

1. MoEngageのサイドバーメニューで、Engageメニュー項目 <img alt="Screenshot 2025-06-04 at 4.32.53 PM.png" src="/images/moengage_9cad7b.png" style={{ display:"inline" }} /> にカーソルを合わせます。**Engage**メニューが表示されます。
2. **\+ New Campaign**をクリックします。**Engage**メニューで**All Campaigns**をクリックし、All campaignsページで**\+ Create campaign**をクリックすることもできます。
3. **New Campaign**ダイアログボックスの**Outbound**で、**RCS**をクリックします。

   - [Business Event Triggered](/ja/user-guide/campaigns-and-channels/getting-started/triggers/business-event/business-event-triggered-campaigns)\

# RCSキャンペーンの作成手順

RCSキャンペーンを作成する手順は以下のとおりです。

1. [ターゲットユーザー](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/rcs/create-an-rcs-campaign#step-1-target-users): キャンペーンのターゲットオーディエンスを定義します。
2. [コンテンツ](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/rcs/create-an-rcs-campaign#step-2-content): 送信するRCSキャンペーンのコンテンツを定義します。
3. [スケジュールと目標](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/rcs/create-an-rcs-campaign#step-3-schedule-and-goals): キャンペーンの配信スケジュールと目標を定義します。

## ステップ1: ターゲットユーザー

このセクションには以下が含まれます。

### キャンペーンの詳細

キャンペーンの詳細セクションには、以下のフィールドがあります。

| フィールド | 説明 |
| --- | --- |
| **Teams** | 組織でチームが有効になっている場合は、ドロップダウンリストからチームを選択します。詳細については、[MoEngageのチーム](/ja/user-guide/settings/account/team-management/teams-in-moengage)を参照してください。 |
| **Campaign name** | キャンペーンを管理および識別するためのキャンペーン名を入力します。キャンペーン名は5文字以上である必要があり、上限は256文字です。 |
| **User attribute that stores user’s mobile number** | MoEngageは、設定で構成された属性を携帯電話番号のデフォルトのユーザー属性として自動的に選択します。ただし、携帯電話番号を含む別の属性を選択することで、キャンペーンレベルでこのデフォルトを上書きできます。 |
| **Campaign tags** | ドロップダウンリストからキャンペーンタグを選択します。最大5つのタグを選択できます。詳細については、[キャンペーンタグ](/ja/user-guide/campaigns-and-channels/getting-started/introduction/campaign-tags)を参照してください。 |
| **Trigger criteria** | このフィールドは、配信タイプとして**Event Triggered**を選択した場合にのみ表示されます。キャンペーンを開始する特定のトリガー条件を追加する必要があります。詳細については、[イベントトリガーキャンペーンの作成](/ja/user-guide/campaigns-and-channels/getting-started/triggers/event/create-an-event-triggered-campaign)を参照してください。 |
| **Select business event** | このフィールドは、配信タイプとして**Business Event Triggered**を選択した場合にのみ表示されます。キャンペーンのビジネスイベントを選択する必要があります。詳細については、[ビジネスイベントトリガーキャンペーンの作成](/ja/user-guide/campaigns-and-channels/getting-started/triggers/business-event/business-event-triggered-campaigns)を参照してください。 |

### オーディエンスの選択

このセクションには、キャンペーンのターゲットオーディエンスを選択するためのセグメンテーションフィルターが含まれています。以下のオプションを利用できます。

<Tabs>
  <Tab title="すべてのユーザー">
    このフィルターオプションを使用すると、すべてのアプリユーザーにキャンペーンを送信できます。このオプションを使用する場合、複数のフィルターを追加することはできません。

    ![all users.png](/images/moengage_852ebc.png)
  </Tab>
  <Tab title="ユーザープロパティでフィルター">
    このフィルターオプションを使用すると、初回確認日時、最終確認日時、都市などのユーザープロパティに基づいてユーザーをターゲットにできます。**User property**タブをクリックし、以下を実行します。

    1. ドロップダウンリストから目的の属性を選択します。これにより、選択した属性に基づくフィルターが有効になります。たとえば、数値の属性には「is equal to」、「is not equal to」、「is between」などのフィルター条件がありますが、文字列の属性には異なるフィルターがあります。
    2. フィルター値を入力して、目的のユーザーセグメントを作成します。
    3. **\+ Nested Filter**をクリックしてフィルターを追加し、ネストされたANDまたはOR条件を作成します（任意）。

    詳細については、[セグメントの作成](/ja/user-guide/segment/create-segments/rule-based-filter-segments)を参照してください。

    ![6.png](/images/moengage_690f41.png)
  </Tab>
  <Tab title="ユーザー行動でフィルター">
    このフィルターオプションを選択すると、アプリ/サイトの起動、商品の閲覧など、ユーザーの行動に基づいてユーザーをターゲットにできます。**User Behavior**タブをクリックし、以下を実行します。

    1. 実行条件と目的のユーザーアクティビティ（イベント）を選択します。
    2. イベントの頻度とイベント実行の期間を入力します。
    3. **\+ Attributes**をクリックし、フィルター条件付きのイベント属性を追加します。
    4. フィルター値を入力してルールを作成します。
    5. **\+ Aggregation**ボタンを使用して集計機能を追加します。詳細については、[集計操作](/ja/user-guide/segment/advanced-concepts/aggregation-operations)を参照してください。
    6. **\+ Nested Filter**をクリックしてフィルターを追加し、ネストされたANDまたはOR条件を作成します（任意）。

    詳細については、[セグメントの作成](/ja/user-guide/segment/create-segments/rule-based-filter-segments)を参照してください。

    ![7.png](/images/moengage_a9f2ff.png)
  </Tab>
  <Tab title="ユーザーアフィニティでフィルター">
    このフィルターオプションを選択すると、特定の属性値でアクションを実行したユーザーに基づいて作成されたユーザーグループをターゲットにできます。詳細については、[ユーザーアフィニティ](/ja/user-guide/segment/create-segments/affinity-segments)を参照してください。**User Affinity**タブをクリックし、以下を実行します。

    1. 目的のユーザーイベントまたは属性を選択します。
    2. 以下からユーザーアフィニティのパラメーターを選択します。

    - **Predominantly**: フィルター条件付きのアフィニティ属性を選択し、アフィニティ値を指定します。
    - **For a minimum of**: フィルター条件付きのアフィニティ属性を選択し、アフィニティ値を指定します。
    - **Most no. of times**: 値を入力するか矢印を使用して、上位何パーセントのユーザーかを指定します。
    - **Least no. of times**: 値を入力するか矢印を使用して、下位何パーセントのユーザーかを指定します。

    3. 値を入力するか矢印を使用して、イベント実行の期間を指定します。
    4. **\+ Attribute**をクリックして、フィルターに属性を追加します。
    5. **\+ Nested Filter**をクリックしてフィルターを追加し、ネストされたANDまたはOR条件を作成します（任意）。

    詳細については、[セグメントの作成](/ja/user-guide/segment/create-segments/rule-based-filter-segments)を参照してください。

    ![5.png](/images/moengage_4fc85e.png)
  </Tab>
  <Tab title="カスタムセグメントでフィルター">
    このフィルターオプションを選択すると、カスタムセグメントをターゲットオーディエンスとして選択できます。

    1. 利用可能なカスタムセグメントのリストから、ターゲットオーディエンスとしてカスタムセグメントを選択します。
    2. **\+ Nested Filter**をクリックしてフィルターを追加し、ネストされたANDまたはOR条件を作成します（任意）。

    詳細については、[カスタムセグメント](/ja/user-guide/segment/create-segments/manage-segments)を参照してください。

    ![8.png](/images/moengage_f6bf66.png)
  </Tab>

アカウントでチームが有効になっている場合は、チームが作成したカスタムセグメントを確認できます。キャンペーンを作成するチームに指定されたセグメンテーション条件は、AND条件でセグメンテーションフィルターに追加されます。たとえば、チームのセグメンテーション条件が_最後に確認された都市がロサンゼルスのユーザー_で、キャンペーンのターゲットオーディエンスとして_過去3日以内に商品を購入したユーザー_を選択した場合、ターゲットオーディエンスは_過去3日以内に商品を購入し、かつ最後に確認された都市がロサンゼルスのユーザー_になります。詳細については、[MoEngageのチーム](/ja/user-guide/settings/account/team-management/teams-in-moengage)を参照してください。

<Info>
  これはアドオン機能です。アカウントで有効にするには、MoEngageのCSM（カスタマーサクセスマネージャー）または[サポート](/ja/user-guide/contact-support/raise-a-support-ticket-through-moengage-dashboard)チームにお問い合わせください。
</Info>

フィルター条件を選択した後、以下の操作も行えます。

- **複数のフィルターの作成**: このオプションを使用すると、複数のユーザープロパティルール、ユーザーアクティビティルール、カスタムセグメントルールを作成して組み合わせ、複雑なユーザーセグメントを作成できます。
  1. **\+ Filter**をクリックします。
  2. **AND**または**OR**をクリックします。
  3. 属性またはイベントを選択し、フィルター条件を定義します。
- **Exclude Users**: このチェックボックスを選択すると、キャンペーンから除外するユーザーのフィルター条件を定義できます。
- **Send campaign to the users opted-out in subscription management**: このトグルをオンにすると、オプトアウトしたユーザーをキャンペーンに自動的に含めます。詳細については、[サブスクリプション管理](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/other-settings/configure-subscription-and-keywords)を参照してください。
- **Reset filters**: このオプションをクリックすると、セグメンテーションフィルターがリセットされます。
- **Show count**: このボタンをクリックすると、設定したセグメントに現在含まれるユーザーの総数が表示されます。

### コントロールグループ

このセクションには、キャンペーンのコントロールグループに関する情報が含まれています。コントロールグループとは、除外リストに追加されたユーザーのセットです。これらのユーザーにはマーケティングキャンペーンが送信されません。コントロールグループはプロモーションキャンペーンでのみ有効であり、トランザクションキャンペーンには適用されません。プロモーションキャンペーンを送信する際に適用するコントロールグループを有効にできます。

**Enable control groups**セクションでは、以下を設定します。

<ul><li>グローバルコントロールグループは、どのマーケティングキャンペーンも受信しないユーザーのリストです。**Global control group**トグルをオンにすると、コントロールグループ内のすべてのユーザーにキャンペーンが送信されません。</li>
<li>キャンペーンコントロールグループは、キャンペーンの対象となるユーザーベースを組み合わせて作成されます。**Campaign control group**トグルをオンにすると、特定のキャンペーンがコントロールグループに送信されません。詳細については、[コントロールグループ](/ja/user-guide/campaigns-and-channels/getting-started/introduction/control-groups)を参照してください。</li></ul>

## ステップ2: コンテンツ

このセクションでは、RCSキャンペーンのコンテンツを作成する方法について説明します。RCSキャンペーンのコンテンツを作成するには、以下の手順を実行します。

![Step 2- Create rcs.png](/images/moengage_b28307.png)

1. **Select sender**リストで、RCS送信者（サービスプロバイダー）を選択します。フォールバックSMSを送信する場合は、ここで選択する送信者がフォールバックとしてのSMSをサポートしている必要があります。この送信者がフォールバックSMSをサポートしていない場合、**Use SMS as Fallback**チェックボックスは無効になります。
2. **Select templates**リストで、テンプレートを検索または選択します。詳細については、[RCSテンプレート](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/rcs/getting-started-with-rcs/rcs-templates)を参照してください。
3. テンプレートで定義されたとおりにコンテンツをカスタマイズします。
4. メッセージをパーソナライズするには、フィールドに@を入力します。**RCS Personalization**ポップアップウィンドウが表示されます。詳細については、[RCSキャンペーンのパーソナライズ](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/rcs/personalize-rcs-campaign)を参照してください。 <img alt="RCS1.png" src="/images/moengage_412a3f.png" />
    <Info>
     いずれかのカードにパーソナライズ変数が設定された**Carousel**テンプレートを選択した場合、このステップではカルーセル内のカード数に応じた**Card 1からCard 10**のタブ構造が表示されます。各カードのタブ内では、パーソナライズフィールドが他の箇所と同じグループ分けに従ってタイプ別にグループ化されます。つまり、タイトル関連の変数、説明関連の変数、推奨アクション関連の変数がそれぞれまとめて表示されます。変数を含む各カードについて、パーソナライズの詳細を個別に入力する必要があります。
   </Info>
5. メッセージの配信を確実にするには、**Use SMS as Fallback**チェックボックスを選択します。MoEngageはまずRCSメッセージとして送信を試み、受信者のデバイスまたはネットワークがRCSをサポートしていない場合は、メッセージを自動的にSMSで配信します。フォールバックSMSについて、以下の詳細を入力します。 <img src="/images/moengage_e81d0d.png" alt="Screenshot 2025-09-15 at 4.32.50 PM.png" />
   1. **SMS sender**リストで、送信者を選択します。ここで選択するSMS送信者は、**Configure RCS Message**セクションで選択したRCS送信者と同じである必要があります。\
      たとえば、Sender AとSender BをRCSおよびSMS送信者として設定しているとします。**Configure RCS Message**セクションでRCS送信者としてSender Aを選択した場合は、SMSセクションでもSMS送信者としてSender Aを選択してください。
   2. **Template ID**フィールドに、テンプレートのIDを入力します。インドのDLT規制により、Template IDは必須フィールドです。指定する必要があるかどうかは、プロバイダーに確認してください。
   3. **Message**フィールドに、SMSに表示するコンテンツを入力します。
      - デフォルトのテンプレートを選択した場合は、フォールバックSMSに表示するメッセージを追加します。
      - フォールバックSMSにカスタムテンプレートを選択した場合、テンプレートはすべてのフィールドの詳細とともにUIに読み込まれます。詳細については、[カスタムテンプレートを使用したコンテンツの作成](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/sms/create-an-sms-campaign#create-content-using-custom-template)を参照してください。
      - **Template actions**をクリックすると、テンプレートを変更できます。

### URLの追加と短縮

RCSメッセージにURLを追加すると、そのURLのRCSクリックを追跡できます。MoEngageはURL短縮サービスを使用してURLを短縮し、URLをクリックしたユーザーを追跡します。RCSアクションに含まれるURLは、クリックされるとデフォルトで追跡されるため、短縮する必要はありません。

URL短縮について、以下の点に注意してください。

1. 短縮リンクは14日で期限切れとなり、期限切れ後は追跡できません。顧客が期限切れのリンクを開くと、「**This link is no longer active**」というメッセージが表示されます。
2. 短縮リンクでユーザー属性やイベント属性を使用する場合、属性名は以下の条件を満たす必要があります。
   1. スペースを含まないこと。
   2. 属性にリンクが含まれる場合、その値にhttp://またはhttps://を含めないこと。これらはリンクを短縮するために属性の前に追加できます。
3. 短縮リンクでは、アポストロフィやカンマなどの特殊文字はサポートされていません。
4. 短縮するリンクでは、複数のJINJA操作はサポートされていません。たとえば、（短縮するリンク内で）Product内でContent APIリンクを使用する、またはその逆はサポートされていません。

### ロケールの追加

ロケールは、ターゲットオーディエンスをさらにサブセグメント化してローカライズされたメッセージを送信するための基準です。キャンペーンにロケールを追加するには、コンテンツ作成ステップの右上にある**\+ Locale**をクリックします。新しいロケールを追加することも、既存のロケールをキャンペーンに追加することもできます。詳細については、[キャンペーンメッセージのローカライズ](/ja/user-guide/campaigns-and-channels/getting-started/campaign-content/localize-campaign-messages)を参照してください。

### バリエーションの追加

キャンペーンのバリエーションを作成すると、変更した変数が他のキャンペーン変数に与える影響を判断できます。また、キャンペーンのバリエーション間でパフォーマンスを比較することもできます。キャンペーンにバリエーションを追加するには、コンテンツ作成ステップの右上にある**\+ A/B test**をクリックします。新しいバリエーションを追加することも、既存のバリエーションをコピーすることもできます。バリエーションを追加すると、以下に示すように、コンテンツエディター上部のリボンにバリエーションがタブとして表示されます。 <img alt="Variations_Added.png" src="/images/moengage_f95de7.png" /> 右上にある**User Distribution**をクリックすると、各バリエーションのユーザー配分を指定できます。詳細については、[A/Bテスト](/ja/user-guide/ai-and-intelligence/ab-testing/what-is-ab-or-multivariate-testing/overview)を参照してください。

  **イベントトリガーキャンペーンはいつ送信されますか？**

  キャンペーンは以下の場合にのみ送信されます。

  - この種類のトリガーの作成に使用されるイベントプロパティ/属性（flight\_timeの例など）が、有効な日時形式である。日時形式でない場合、文字列のデータは[サポートされている形式](/ja/user-guide/campaigns-and-channels/getting-started/triggers/event/create-an-event-triggered-campaign#supported-formats)のいずれかである必要があります。選択した属性にこれらのいずれかの形式のデータが含まれていない場合、キャンペーンはユーザーに送信されません。
  - 属性の日時の値が、トリガー条件が満たされた時刻よりも後である。
  - 属性の日時の値が、トリガー条件が満たされた時刻 \+ 30日よりも前である。たとえば、トリガー条件が日付Dに満たされた場合、属性値がD\+30未満の場合にのみ通知が送信されます。
  - インテリジェント遅延最適化（**With Delay**）は、相対タイミングで送信されるキャンペーンでは機能しません。

  ![DT\_ActiveContinously.png](/images/moengage_5a7f19.png)
</Accordion>

### コンバージョン目標

    **フリークエンシーキャップ**

    この機能を使用すると、1日にユーザーに送信されるRCSメッセージの数を制御できます。

    - **Ignore frequency capping**: このトグルを有効にすると、このRCSキャンペーンのフリークエンシーキャップの上限を無視します。キャップを無視しつつ、このキャンペーンをカウントの対象にしたい場合は、**Ignore frequency capping**をクリックしてRCSキャンペーンのキャップを無視します。たとえば、フリークエンシーキャップの値が3に設定されているとします。今日、あるユーザーグループにすでに3つのキャンペーンを送信しました。このキャンペーンによってトリガーされるRCSメッセージは緊急であり、一部の顧客がすでに3つのキャンペーンを受信していても、高い優先度で送信する必要があると判断しました。Ignore Frequency Capを使用すると、すでに3つのキャンペーンを受信したユーザーにもこのキャンペーンが送信されます。詳細については、[フリークエンシーキャップ](/ja/user-guide/settings/channels/delivery-controls/frequency-capping)を参照してください。
    - **Count for the frequency capping**: このコネクターをフリークエンシーキャップの上限にカウントしたい場合は、このトグルを有効にします。**Count for frequency capping**を使用すると、すでに2つのコミュニケーションを受信しているユーザーにこのキャンペーンも送信した場合、このキャンペーンの送信後に受信数は3になります。**スロットリング** スロットリングは、RCSキャンペーンの送信レートを制御できる機能です。**Request limit**セクションに、RCSキャンペーンで1分あたりに送信するリクエスト数を入力します。たとえば、デフォルトの60,000 rpm（1分あたり最小60,000リクエスト、最大200,000リクエスト）でリクエストURLを送信します。詳細については、[スロットリング](/ja/user-guide/settings/channels/delivery-controls/throttling)を参照してください。 <img src="/images/moengage_98d487.png" alt="del control.png" />

# キャンペーンアクション

キャンペーンを公開した後、**Engage** \> **Campaigns**でキャンペーンを確認できます。**Actions**の下にある省略記号アイコンをクリックすると、以下のキャンペーンアクションが表示されます。

- **View:** このオプションでは、[キャンペーン情報](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/rcs/rcs-campaign-info)を表示できます。このオプションをクリックすると、**Campaign analytics and info**ページに移動します。
- **Duplicate:** このオプションでは、既存のすべての詳細を含むキャンペーンのコピーを作成し、キャンペーン名に**_Duplicate_**を付加します。
- **Edit**: このオプションでは、キャンペーンの詳細を編集できます。
- **Pause:** このオプションでは、キャンペーンを一時停止できます。
- **Archive**: このオプションでは、キャンペーンをアーカイブできます。アーカイブしたキャンペーンはアーカイブ解除できます。
- **Unarchive**: このオプションでは、キャンペーンのアーカイブを解除できます。

![RCS camp.png](/images/moengage_9f0385.png)

キャンペーンの**Campaign info and analytics**ページでも、以下のキャンペーンアクションを確認できます。

![RCS 2.png](/images/moengage_7d5f1d.png)

- **Campaign Status**: キャンペーンには、**_Active_**、**_Expired_**、**_Not Sent_**、**_Paused_**、**_Scheduled_**、**_Sending_**、**_Sent_**、**_Stopped_**などのさまざまなステータスがあります。[キャンペーン承認ワークフロー（CAF）](/ja/user-guide/settings/account/team-management/campaign-approval-workflow)が有効な場合は、**_Under Review_**や**_Rejected_**などの追加のステータスも利用できます。

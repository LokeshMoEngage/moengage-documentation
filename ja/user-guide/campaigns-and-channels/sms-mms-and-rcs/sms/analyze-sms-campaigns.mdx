# 概要

SMS キャンペーンのパフォーマンスを分析することで、メッセージング施策に関する重要なインサイトが得られ、メッセージがオーディエンスに対してどのように機能しているかを把握できます。送信率、配信率、既読率などの重要な指標をクリック数とあわせて追跡することで、キャンペーンの効果を明確に把握できます。この分析により、戦略を改善し今後のキャンペーンを向上させるためのデータに基づいた意思決定が可能になります。

<Tip>
 SMS の分析と情報は、**MoEngage Go** モバイルアプリで確認できます。パフォーマンス統計の監視、コンバージョンの追跡、キャンペーン詳細の確認をスマートフォンから直接行えます。詳細については、[MoEngage Go](/ja/user-guide/moengage-go/moengage-go-overview) を参照してください。
</Tip>

SMS キャンペーンを分析することには、次のようなメリットがあります。

- **キャンペーンコンテンツの改善**: 特定のオーディエンスに最も響くメッセージコンテンツやコピーを追跡することで、キャンペーンを最適化し、エンゲージメントとコンバージョンを高めることができます。
- **パフォーマンスの最適化**: 分析を使用して、最も高いエンゲージメントとコンバージョンを生み出すメッセージコンテンツ、オファー、コールトゥアクションを特定します。また、オーディエンスにメッセージを送信する最適な時間を特定し、さまざまな送信頻度をテストして成果を最大化することもできます。
- **配信率の向上**: メッセージが配信されない理由をすばやく診断できます。これにより、無効な番号やネットワークエラーなどの問題を特定し、今後の配信率を改善できます。

各 SMS キャンペーンを分析するには、**Engage** \> **Campaigns** に移動し、分析を表示したいキャンペーンの行をクリックします。

表示されるページでは、次のセクションを利用できます。

- **Campaign Details**: キャンペーンとそのステータスに関する情報が含まれます。詳細については、[Campaign Details](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/sms/analyze-sms-campaigns#campaign-details) を参照してください。
- **Analytics**: キャンペーンで追跡されるさまざまな指標に関する情報が含まれ、次のセクションで構成されています。

# Campaign Details

このセクションには次の情報が含まれます。

- **キャンペーンタイプ**
- **キャンペーン ID**
- **キャンペーンの作成および更新の詳細**
- **チーム情報**
- **承認者リスト/承認者/却下者（CAF が有効な場合）**
- **キャンペーンステータス**: キャンペーンには、_Active_、_Expired_、_Not Sent_、_Paused_、_Scheduled_、_Sending_、_Sent_、_Stopped_ などのさまざまなステータスがあります。Campaign Approval Workflow（CAF）が有効な場合は、_Under Review_ や _Rejected_ などの追加ステータスも利用できます。

Campaign Details セクションで実行できるアクションは次のとおりです。

| **アクション** | **説明** |
| ------------- | --------- |
| **Refresh**   | このアクションは、現時点でのキャンペーンの詳細でページを再読み込みします。 |
| **Edit**      | このアクションでは、キャンペーンを編集できます。 |
| **Duplicate** | このアクションでは、キャンペーンを複製し、現在のキャンペーンのすべての詳細が入力されたキャンペーンエディターページを開きます。複製されたキャンペーンの名前には「Duplicate -」が付加されます。 |
| **Approve**   | このアクションでは、CAF が有効な場合にレビュー中のキャンペーンを承認できます。このアクションは、キャンペーンのレビュー担当者リストに追加されているユーザーのみが利用できます。詳細については、[Campaign Approval Workflow](/ja/user-guide/settings/account/team-management/campaign-approval-workflow) を参照してください。 |
| **Reject**    | このアクションでは、CAF が有効な場合にレビュー中のキャンペーンを却下できます。このアクションは、キャンペーンのレビュー担当者リストに追加されているユーザーのみが利用できます。詳細については、[Campaign Approval Workflow](/ja/user-guide/settings/account/team-management/campaign-approval-workflow) を参照してください。 |
| **Stop**      | このアクションは、キャンペーンが「Sending」状態のときに利用でき、キャンペーンを停止できます。 |

## キャンペーンパフォーマンス統計

![SMS_Stats.png](/images/moengage_5899d9.png)

キャンペーンパフォーマンスは、SMS キャンペーンの効果を示します。このセクションで実行できるアクションは次のとおりです。

- 数値ビューまたはパーセンテージビューを選択して、統計を数値またはパーセンテージ値で表示します。
- セクション上部のドロップダウンで Unique または Total を選択して、統計のユニーク件数または合計件数を表示します。
- 右上隅の **Pin metrics** リストを使用して、表示したい指標をピン留めします。最大 5 つの指標をピン留めできます。選択した指標のピンは **Pinned metrics** セクションで利用できます。
- **Show all** metrics をクリックすると、キャンペーンで追跡されているすべての指標が表示されます。ピン留めされていない指標を非表示にすると、キャンペーンのピン留めされた指標のみが表示されます。

  ![SMS_GlobalFilters.png](/images/moengage_187d3b.png)

次のキャンペーンパフォーマンス統計を利用できます。

### コンバージョン指標

これらの指標は、キャンペーンに設定されたコンバージョン目標に関するものです。これらの指標が高いほど、キャンペーンの効果が高いことを示します。MoEngage は、配信レシートを受信したユーザーに対してのみコンバージョンをアトリビュートします。

統合 SMS コネクタの場合、コンバージョンは配信レシートを受信した顧客に対してのみアトリビュートされます。

カスタム SMS コネクタの場合:

- コンバージョンは、カスタム SMS コネクタの配信トラッキングが有効かどうかに基づいてアトリビュートされます。
- カスタム SMS コネクタの配信トラッキングが設定されている場合、コンバージョンは MoEngage が配信レシートを受信したユーザーに対してのみアトリビュートされます。
- 配信トラッキングが設定されていない場合、コンバージョンは MoEngage から SMS が正常に送信されたユーザーにアトリビュートされます。

| 指標 | 説明 |
| -------------------- | ---------- |
| Converted Users      | この指標は、コネクタインスタンスの送信成功または SMS Delivered（該当する方）から 36 時間以内に、コンバージョンイベントを少なくとも 1 回実行したユニークユーザーの数を示します。Converted Users は以前は Conversions と呼ばれていました。 |
| Event (Primary)      | この指標は、コネクタインスタンスの送信成功または SMS Delivered（該当する方）から 36 時間以内のプライマリコンバージョン目標イベントの合計数を示します。イベントプライマリカードでアップリフト率を確認することもできます。詳細については、[キャンペーンにおけるアップリフト](/ja/user-guide/campaigns-and-channels/getting-started/introduction/control-groups#uplift)を参照してください。 |
| Conversion Rate(CVR) | この指標は、コンバージョンイベントを実行したユーザーの割合を示します。コンバージョンイベントが多いほど、キャンペーンがビジネス目標の達成に効果的であることを示します。CVR = ((コンバージョン数) / (Delivered)) \* 100 <br /> **注**: 配信トラッキングが設定されていないカスタムコネクタを使用して送信されたキャンペーンの場合、CVR = (コンバージョン数/Sent)\*100 |
| Revenue Metrics      | コンバージョン目標を設定する際（キャンペーン作成のステップ 3）に、収益を追跡するかどうかを選択できます。収益トラッキングが有効な場合、キャンペーン統計に収益指標が表示されます。プライマリ目標で有効になっている場合、キャンペーンには 3 つの収益指標があります。 <ul><li>**Total Campaign Revenue** は、キャンペーンにアトリビュートされたコンバージョンイベント全体の合計注文額です。</li><li>**Average Order value** = (総収益/コンバージョンイベント数)</li><li>**Average Revenue per user** = (総収益/ユニークコンバージョン数)</li></ul> これらの収益指標は、ビュースルー、クリックスルー、インセッションのすべてのアトリビューションタイプで追跡されます。 |

<Note>
  収益属性がオブジェクト配列内にある場合、MoEngage の計算結果が想定と一致しない場合があります。詳細については、[オブジェクト属性を使用した収益トラッキング](/ja/user-guide/campaigns-and-channels/campaign-management-and-reports/conversion-and-attribution#how-revenue-is-calculated-for-object-array-attributes)を参照してください。
</Note>

### 配信指標

SMS キャンペーンで追跡される配信指標は次のとおりです。

| 指標 | 説明 |
| -------------- | ---------- |
| Attempted      | この指標は、キャンペーンの対象となり、MoEngage がメッセージの送信を試みたユーザーの数を示します。 |
| Sent           | この指標は、SMS プロバイダーに対して行われた SMS 送信リクエストが正常に受け付けられたユーザーの数を表します（SMS リクエストがプロバイダーに送られると、受信側サーバーはそのリクエストの処理結果を示すレスポンスコードを返します）。送信率は、MoEngage が送信を試みたメッセージのうち、送信されたメッセージの割合を示す指標です。**Sent rate** は _(Sent/Attempted)\*100_ で計算されます。 |
| Delivered      | この指標は、メッセージが正常に配信されたユーザーの数を表します。SMS が送信されると、SMS プロバイダーは携帯通信事業者から受信した確認済みの配信レシートに関する情報を MoEngage に送信します。顧客がネットワークやバッテリーの問題で到達不能な場合は配信が遅れることがあるため、通常この数値は時間の経過とともに増加します。配信率は、MoEngage が送信したメッセージのうち、正常に配信されたメッセージの割合を示す指標です。**Delivered rate** は _(Delivered/Sent)\*100_ で計算されます。 \*\*注:\*\*カスタムコネクタ経由で送信された SMS の場合、この指標は配信トラッキングが有効な場合にのみ取得されます。詳細については、[配信トラッキング](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/sms/getting-started-with-sms/configure-custom-connector-for-sms)を参照してください。 |
| Failed To Send | この指標は、メッセージが送信されなかったユーザーの数を表します。失敗率は、MoEngage が送信を試みたもののうち、失敗したキャンペーンの割合を示す指標です。**Failed rate** は _(Failed To Send/Attempted)\*100_ で計算されます。 |

### エンゲージメント指標

SMS キャンペーンで追跡されるエンゲージメント指標は次のとおりです。

| 指標 | 説明 |
| ------- | ---------- |
| Clicked | Clicked は、メッセージを受信したユーザーが SMS 内の URL をクリックした回数です。MoEngage は、キャンペーンでクリックトラッキングを有効にしている場合にのみクリックを追跡します。CTR（クリック率）= (Total Clicked/Delivered)\*100 <br /> **注**: 配信トラッキングが設定されていないカスタムコネクタを使用して送信されたキャンペーンの場合、CTR = (Total Clicked/Sent)\*100 \*\*免責事項:\*\*SMS メッセージ本文に追加されたすべての URL は、キャンペーン/メッセージの送信日から 15 日以内に失効します。失効後、MoEngage はこれらの URL のクリックを追跡しません。 |

## ロケールとバリエーションのパフォーマンス

各ロケール（デフォルトロケールを含む）とバリエーションごとのパフォーマンス指標（Clicked、Delivered、Conversions、Conversion Goals）の内訳を確認でき、さまざまなロケールとバリエーションの組み合わせの効果を評価・比較できます。ロケール/バリエーションのパフォーマンスの表形式ビューでアップリフト率を確認できます。詳細については、[キャンペーンにおけるアップリフト](/ja/user-guide/campaigns-and-channels/getting-started/introduction/control-groups#uplift)を参照してください。

指標のドロップダウンで比較を表示したい指標を選択し、次の方法でフィルタリングできます。

1. **Group by locale** - 選択した指標について、各バリエーションのパフォーマンスをロケールごとにグループ化して一覧表示します。棒グラフにカーソルを合わせると、ロケール内の特定の指標で各バリエーションがどのように機能したかを確認できます。配信指標は「All Locales」ビューでのみ利用でき、個々のロケールの分析を表示している場合は利用できません。

   ![SMS_GroupByLocale (1).png](/images/moengage_f98935.png)
2. **Group by variation** - すべてのロケールにおける各指標のパフォーマンスをバリエーションごとにグループ化して一覧表示します。棒グラフにカーソルを合わせると、バリエーション内の特定の指標で各ロケールがどのように機能したかを確認できます。 <img alt="SMS_GroupByVariation.png" src="/images/moengage_74a711.png" />

## コンバージョン目標のパフォーマンス

このセクションは、キャンペーンに複数のコンバージョン目標を設定した場合に表示されます。このセクションでは、マーケターがキャンペーンに設定した目標のパフォーマンスを比較します。

\*\*Total Conversions:\*\*それぞれの目標のすべての目標イベントが表示されます。つまり、ユーザーが 2 回購入した場合は 2 回と表示されます。これは、上記のセクションで説明したコンバージョンイベントに相当します。

**Unique Conversions:** 目標は、キャンペーンインスタンスごとにコンバージョンしたユーザー全体でユニークです。これは、上記のセクションで説明した Conversions 指標に相当します。

コンバージョン目標のパフォーマンスの表形式ビューでアップリフト率を確認できます。詳細については、[キャンペーンにおけるアップリフト](/ja/user-guide/campaigns-and-channels/getting-started/introduction/control-groups#uplift)を参照してください。

## アトリビューションの詳細

アトリビューションタイプ（クリックスルー、インセッション、ビュースルー）を選択すると、指定したアトリビューションタイプの分析情報が表示されます。

<Info>
  アトリビューションタイプは、キャンペーンにコンバージョン目標を設定している場合にのみ適用されます。
</Info>

アトリビューションの種類は次のとおりです。

- **ビュースルーアトリビューション**: ユーザーがメッセージを見てクリックせずに、その後コンバージョンした場合、ビュースルーコンバージョンとしてアトリビュートされます。
- **クリックスルーアトリビューション**: ユーザーがメッセージをクリックしてコンバージョンした場合、クリックスルーコンバージョンとしてアトリビュートされます。
- **インセッションアトリビューション**: ユーザーがメッセージをクリックしてから 30 分以内にコンバージョンした場合、インセッションコンバージョンとしてアトリビュートされます。\
  たとえば、ユーザー A、B、C の 3 人の顧客がキャンペーン C1 からメッセージを受信した場合を考えます。
  - ユーザー A はメッセージをクリックし、クリックから 30 分以内（同じセッションとみなします）にコンバージョンイベントを実行しました。
  - ユーザー B はメッセージをクリックし、クリックから 2～3 時間後にコンバージョンイベントを実行しました。
  - ユーザー C はメッセージを見た後、アプリを直接起動してコンバージョンしました。

このコンバージョンをキャンペーン C1 にアトリビュートする場合、ユーザー A は直接アトリビューション、ユーザー B と C は間接アトリビューションとなります。

|                  |                |                |
| ---------------- | -------------- | -------------- |
| アトリビューションタイプ | 説明 | 例 |
| View through     | ビュースルーアトリビューションは、コミュニケーションを_受信した_ユーザーが、キャンペーンを受信した時点から設定されたアトリビューションウィンドウ\*内に実行したコンバージョン目標の総数です。これは、キャンペーンパフォーマンスのデフォルトフィルターとして表示されます。 | ユーザーが午前 7 時にメッセージを受信し、アトリビューションウィンドウが 12 時間の場合、午後 7 時までのユーザーのコンバージョンイベントは、ビュースルーアトリビューションを使用してこのキャンペーンにアトリビュートされます。 |
| Click through    | クリックスルーアトリビューションは、クリックベースのトラッキングです。クリックスルーアトリビューションは、通知を_クリックした_ユーザーが、クリックした時点から設定されたアトリビューションウィンドウ内に実行したコンバージョン目標の数です。 | ユーザーが午前 7 時にメッセージを受信し、午前 8 時にクリックし、アトリビューションウィンドウが 12 時間の場合、午後 8 時までのユーザーのコンバージョンイベントは、クリックスルーアトリビューションでこのキャンペーンにアトリビュートされます。 |
| In-session       | インセッションアトリビューションは、インセッショントラッキングに基づいています。インセッションアトリビューションは、ユーザーがコミュニケーションをクリックしてから 30 分以内に実行したコンバージョン目標の数です。 | ユーザーが午前 7 時にメッセージを受信し、午前 8 時にクリックし、アトリビューションウィンドウが 12 時間の場合、午前 8 時 30 分まで（セッション開始から 30 分以内）のユーザーのコンバージョンイベントは、インセッションアトリビューションでこのキャンペーンにアトリビュートされます。 |

**\*アトリビューションウィンドウ**: アトリビューションウィンドウとは、ユーザーが特定のコンバージョン目標を持つキャンペーンを受信した時点から計算される期間です。たとえば、購入をコンバージョン目標とする 2 つのキャンペーンが作成されたとします。キャンペーン C1 は H 時、キャンペーン C2 は H+12 時に作成されました。顧客が H+15 時にキャンペーン C1 と C2 で購入のコンバージョン目標を達成した場合、顧客のコンバージョンは C1 と C2 の両方にアトリビュートされます。

MoEngage の SMS キャンペーンにおけるアトリビューションウィンドウの最大値は 7 日間です。7 日未満の間隔で複数のキャンペーンを送信する場合は、アトリビューションウィンドウを次のように設定します。

- 7 日未満。
- キャンペーンの送信間隔に合わせた期間。

たとえば、12 時間の間隔でキャンペーンを送信する場合は、アトリビューションウィンドウを 12 時間に設定します。

## エラーの内訳

このセクションでは、キャンペーンの配信失敗の件数とその理由について詳しく説明します。失敗は次の 2 つに分類されます。

- **Failed to Send** - このセクションには、一部のメッセージが MoEngage から SMS プロバイダーに送信されなかった理由が表示されます。これは、パーソナライゼーションの失敗や SMS プロバイダー側のエラーなど、さまざまな理由で発生する可能性があります。
  - **パーソナライゼーションの失敗**は、リクエストに含まれる 1 つ以上のイベント/ユーザー属性が特定のユーザーについて見つからない場合に発生します。詳細については、[パーソナライゼーションエラー](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/common-personalization-errors-and-faqs)を参照してください。
  - **SMS プロバイダー側のエラー**: このようなエラーの場合、画像に示すように、エラーコードと、SMS プロバイダーからそのエラーを受信したリクエストの集計数が UI に表示されます。これらのエラーについては、SMS プロバイダーのドキュメントで確認できます。
  - 定義されたローリングウィンドウ内でキャンペーンの **Limit Message** 設定にすでに達していたために除外されたユーザー。詳細については、[定期キャンペーンおよびトリガー型キャンペーンのメッセージ制限](/ja/user-guide/settings/channels/delivery-controls/limit-messages-for-periodic-and-triggered-campaigns)を参照してください。
- **Failed to Deliver** - このセクションには、SMS プロバイダーによってメッセージが配信されなかった理由が表示されます。SMS の配信は、SMS プロバイダーの配信レシートに基づいて記録されます。SMS プロバイダーから直接返されるエラーに加えて、MoEngage が SMS プロバイダーからの配信レシートを待機している間の転送中のエラーも確認できます。

パーソナライズにより、マーケティングメッセージは顧客にとってより関連性の高いものになります。SMS キャンペーンをカスタマイズすることで、オーディエンスとのつながりを強化し、メッセージの受け入れられ方を改善できます。

この記事では、ワンタイム、定期、イベントトリガー型のメッセージを含む MoEngage SMS キャンペーンでパーソナライズを使用する方法について説明します。

パーソナライズ可能な SMS コンテンツフィールドには、プレースホルダーテキスト **Type @ to personalize** が表示されます。

<Info>
  SMS チャネルのパーソナライズ条件またはロジックを作成すると、チップとして表示されます。チップアクションの詳細については、[こちら](user-guide/campaigns-and-channels/getting-started/message-personalization/dynamic-content-personalization#chip-actions)を参照してください。
</Info>

# データパーソナライズ

ユーザー属性、Product Sets、Content APIs を使用して[メッセージをパーソナライズ](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/overview)できます。メッセージフィールドにパーソナライズを挿入するには、@ を入力します。以下の画像のように、パーソナライズメニューが開きます。

![SMS1.png](/images/moengage_fe8b84.png)

## フォールバックの選択

メッセージをパーソナライズする際、フォールバックオプションを使用すると、選択した属性がユーザーに対して利用できない場合や正しく表示されない場合でも、常にコンテンツが表示されるようになります。

以下のフォールバックオプションから選択できます。

- 失敗した属性の代替がない場合は、**No Fallback** を選択します。パーソナライズに失敗した場合、パーソナライズされた属性は空の文字列に置き換えられます。
- パーソナライズに失敗した場合に SMS を送信しないようにするには、**Do not send SMS** を選択します。
- 失敗した属性を任意のテキストに置き換える場合は、**Replace text** を選択します。パーソナライズに失敗した場合、パーソナライズされた属性は **Fallback text** フィールドに入力したテキストに置き換えられます。

<Info>
  カスタム属性の名前は、MoEngage の標準属性とは異なる名前にしてください。同じ名前のカスタム属性と標準属性をパーソナライズに使用すると、パーソナライズが正しく行われない可能性があります。
</Info>

## ビジネスイベントトリガー型キャンペーンのパーソナライズ

ビジネスイベントトリガー型の SMS キャンペーンでは、マッピングされたビジネスイベントの属性を使用してメッセージをパーソナライズできます。これにより、単一のテンプレートを複数のキャンペーンに使用できるため、作業量を大幅に削減し、自動化を実現できます。たとえば、さまざまな新しい Web シリーズに関する情報を伝えるキャンペーンテンプレートを 1 つ作成し、ユーザーの興味に基づいてシリーズ名、画像、キャスト、放送日などの詳細で各メッセージをパーソナライズできます。

ビジネスイベント属性を使用してコンテンツをパーソナライズするには、以下の手順を実行します。

1. コンテンツ作成ステップで **@** を入力して、パーソナライズエディターを呼び出します。
2. 以下の画像のように、キャンペーンにマッピングされたビジネスイベントの属性が **Business Event Attribute** の下に表示されます。

   ![SMS2.png](/images/moengage_d44b55.png)
3. パーソナライズに使用する属性を選択し、メッセージをカスタマイズします。

詳細については、[メッセージのパーソナライズ](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/overview#user-attributes)を参照してください。

# コンテンツブロックを使用したパーソナライズ

コンテンツブロックは、さまざまなキャンペーンで使用できる再利用可能なコンテンツスニペットです。ヘッダー、フッター、署名ブロック、利用規約などの標準的な要素に特に役立ちます。

コンテンツブロックを使用してメッセージをパーソナライズするには、以下の手順を実行します。

1. メッセージセクションで @ を入力します。
2. 表示されるパーソナライズメニューで、**Content blocks** タブをクリックします。

   ![SMS3.png](/images/moengage_527adc.png)
3. **Done** をクリックして選択したコンテンツブロックを追加すると、以下のようにメッセージに追加されます。
4. **Insert only the content of the content block** トグルをオンにすると、コンテンツが既存のコンテンツブロックから切り離され、今後コンテンツブロックが更新されてもキャンペーンには反映されません。この手順は任意です。

![sms content block.png](/images/moengage_b60088.png)

詳細については、[コンテンツブロックを使用したコンテンツのパーソナライズ](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/personalize-content-using-content-blocks)を参照してください。

# 補助データを使用したパーソナライズ

パーソナライズエディターで補助データ属性を選択することで、補助データを使用して SMS コンテンツをパーソナライズできます。

補助データ属性を使用してコンテンツをパーソナライズするには、以下の手順を実行します。

1. **Message** フィールドに @ を入力して、パーソナライズエディターを呼び出します。
2. **Aux Data** タブを選択します。
3. **Aux data** ドロップダウンリストで、パーソナライズに使用する属性を含む補助データファイルを選択します。
4. **Lookup value** ドロップダウンリストで、インポート時に補助データに指定したプライマリキーを選択します。これにより、補助データを取得する対象のユーザーが識別されます。
5. **Attribute** ドロップダウンリストで、補助データを使用してパーソナライズする属性を指定します。
6. **Done** をクリックします。補助データの JINJA がフィールドまたはエディターに追加されます。

   ![SMS4.png](/images/moengage_a30d8c.png)

詳細については、[補助データを使用したキャンペーンコンテンツのパーソナライズ](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/personalize-content-using-auxiliary-data)を参照してください。

# Content APIs を使用したパーソナライズ

SMS キャンペーンは Content APIs を使用してパーソナライズでき、関連性の高いタイムリーな情報をユーザーに届けることができます。

## Content APIs の追加

Content APIs は MoEngage ダッシュボードに追加できます。**Settings** \> **APIs** \> **Content API** に移動して Content API にアクセスし、**Add** をクリックして Content API を追加します。詳細については、[Content APIs を使用したコンテンツのパーソナライズ](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/personalize-content-using-content-apis)を参照してください。

## Content API を使用したパーソナライズキャンペーンの作成

1. コンテンツ作成ステップで **@** を入力して、パーソナライズエディターを呼び出します。
2. **SMS personalization** ポップアップで、**Data Personalization** タブに移動します。
3. Content API を検索し、リストから API を選択します。

   ![SMS5.png](/images/moengage_c26cfc.png)

<Info>
  パーソナライズエラーの詳細については、[よくあるパーソナライズエラーと FAQ](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/common-personalization-errors-and-faqs)を参照してください。
</Info>

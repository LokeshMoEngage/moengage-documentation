# 概要

SMS の送受信プロセスには、複数の関係者が関与しています。SMS に関連するさまざまなエンティティについては、以下の用語集を参照してください。

# 知っておくべき用語

| 用語           | 説明                                                                                                                                                                                                                                                                                                                                     |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Brand**      | 消費者とコミュニケーションを行うエンティティまたは企業です。ブランドの例としては、Starbucks、Amazon、Athleta、Chipotle などがあります。コミュニケーションは、トランザクションまたはマーケティングのいずれかの性質を持ちます。消費者が認識しているのはブランドのみで、コミュニケーションプロセスに関与するその他のエンティティはバックグラウンドで動作します。 |
| **ISV**        | Independent Software Vendor（独立系ソフトウェアベンダー）。ブランドと CPaaS（Communications Platform as a Service）ベンダーをつなぎます。MoEngage は ISV の一例です。                                                                                                                                                                                                 |
| **CPaaS**      | Communications Platform as a Service。CPaaS は、SMS コミュニケーションのためのクラウドベースの配信手段（API）を提供します。ISV とアグリゲーターをつなぐ役割を担います。CPaaS の例としては、Twilio、Plivo、Sinch などがあります。                                                                                                                   |
| **Aggregator** | 通信事業者と直接の関係を持つ企業です。CPaaS と通信事業者をつなぐ役割を担います。アグリゲーターの例としては、OneMarket や Vibes などがあります。Vibes のように、CPaaS としても機能するアグリゲーターもあります。                                                                                                                    |
| **Carriers**   | 消費者や企業に携帯電話プランを提供する企業です。通信事業者の例としては、AT&T、Verizon、T-mobile などがあります。                                                                                                                                                                                                                 |
| **Handset**    | SMS メッセージを受信できるモバイルデバイスです。SMS について説明する際、"Consumer" と "Handset" はしばしば同じ意味で使用されます。                                                                                                                                                                                                                     |

**SMS の送信 - MT（Mobile Terminated）**

ブランドからユーザーに送信される SMS は、最終的にユーザーの携帯電話に届くメッセージであるため、Mobile Terminated（MT）メッセージと呼ばれます。以下の画像は、メッセージがブランドからエンドユーザーの端末にどのように届くかを示しています。

**SMS の受信 - MO（Mobile Originated）**

ユーザーからブランドに送信される SMS は、ユーザーの携帯電話から発信されるメッセージであるため、Mobile Originated（MO）メッセージと呼ばれます。以下の画像は、メッセージがユーザーの端末からブランドにどのように届くかを示しています。

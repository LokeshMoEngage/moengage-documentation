SMS 送信者は MoEngage がメッセージの送信に使用する認可されたエンティティであるため、その設定は重要です。RCS キャンペーンを実行するための必須の前提条件となります。

統合コネクターまたはカスタムコネクター（サービスプロバイダー）の送信者を設定する必要があります。スレッドを分けることで、1 つの SMS サービスプロバイダーに対して複数の送信者を設定し、ブランドや種類ごとに SMS コミュニケーションを効率化できます。さらに、SMS キャンペーンの作成時に、キャンペーンごとに異なる送信者を選択できます。

SMS 送信者は、SMS、MMS & RCS 設定の **Sender configuration** タブで追加および管理できます。**Sender configuration** タブには、**Settings** \> **Channels** \> **SMS, MMS & RCS** \> **Sender configuration** のパスでアクセスできます。

![CONFIGURE sms.png](/images/moengage_ec5794.png)

# 送信者を設定する

SMS 送信者を追加するには、次の手順を実行します。

1. **SMS & MMS** タブで、**Add SMS Sender** をクリックします。Add sender ページが表示されます。

   ![CONFIGURE sms 2.png](/images/moengage_bc3510.png)
2. ステップ 1 の **Service Provider** で、サービスプロバイダーを選択します。統合サービスプロバイダーから選択するか、カスタムサービスプロバイダーを追加できます。カスタムサービスプロバイダーの追加の詳細については、[カスタムサービスプロバイダーの設定](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/sms/getting-started-with-sms/configure-custom-connector-for-sms)を参照してください。

   ![Screenshot 2025-09-16 at 6.10.59 PM.png](/images/moengage_49a740.png)
3. ステップ 2 の **Sender Details** で、選択した送信者の詳細を追加します。統合サービスプロバイダーに共通する送信者詳細フィールドの一部は次のとおりです。

   | フィールド       | 説明                                                                                                                                                                                                                                                                                                                                         |
   | ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
   | Sender type | Sender type は、送信者がプロモーション用とトランザクション用のどちらのメッセージングに使用されるかを示します。ユースケースに応じて **Promotional** または **Transactional** を選択します。                                                                                                                                                                                  |
   | Sender name | Sender name は、設定する送信者を識別する名前です。この名前は、キャンペーン作成時の送信者選択ドロップダウンに表示されます。SMS キャンペーンの送信には、設定されたデフォルトの送信者が使用されます。ただし、このデフォルト設定は、キャンペーン作成のステップ 2 でキャンペーンレベルで上書きできます。 |
   | Sender ID   | Sender ID は、SMS メッセージの送信者として表示される名前または番号です。                                                                                                                                                                                                                                                             |

   設定する送信者によって、UI のフィールドは異なります。たとえば、ユーザー名とパスワードが必要な送信者もあれば、API エンドポイント URL が必要な送信者もあります。ベンダー固有の設定の詳細については、[SMS Providers](https://partners.moengage.com/hc/en-us/categories/4701102365972-SMS-Providers) を参照してください。
4. ダッシュボードに表示される **Delivery tracking URL** をコピーし、サービスプロバイダーのコールバック Webhook 設定に貼り付けます。
5. **Send a test SMS** をクリックして、設定をテストします。
6. **Save** をクリックします。
7. 送信者を追加すると、**Sender configuration** \> **SMS & MMS** タブに表示されます。
8. 省略記号アイコン（<Icon icon="ellipsis-vertical" iconType="solid" /> ）をクリックして、送信者に対して **Mark as default**、**Edit,**、または **Delete** を実行します。

   ![Screenshot 2025-09-17 at 11.26.34 AM.png](/images/moengage_97bd16.png)
   - 送信者をデフォルトとしてマークすると、キャンペーンレベルで別の送信者が選択されない限り、すべての SMS キャンペーンの送信にこの送信者が使用されます。
   - 送信者を削除すると、その送信者に関連付けられているアクティブなキャンペーンは、デフォルトの送信者を使用して送信されます。デフォルトの送信者は削除できないことに注意してください。デフォルトの送信者を削除するには、まず別の送信者をデフォルトとしてマークします。これにより、削除したい送信者の削除オプションが有効になり、送信者を削除できるようになります。

<Warning>
  - **Sender ID** フィールドには、DLT プラットフォームで承認された **Header ID** を必ず追加してください。DLT の詳細は[こちら](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/compliance-and-deliverability/dlt-impact-on-sms)に記載されています。
  - 承認されていないヘッダーで SMS を送信しようとすると、SMS は拒否され、ユーザーに配信されません。
</Warning>

# Dynamic Sender Routing

<Info>
  この機能は Inform アラートにのみ適用されます。
</Info>

_Dynamic Sender Routing_ を使用すると、SMS アラートの送信者を動的に割り当てるカスタムルールを定義できます。ユーザー属性や API 属性に基づいてカスタムルーティングルールを定義することで、次のことが可能になります。

- メッセージングを最適化して到達率を向上させる。
- 送信コストを管理する。
- 現地の規制へのコンプライアンスを確保する。

詳細については、[Dynamic Sender Routing](/ja/user-guide/inform/advanced-concepts/dynamic-sender-routing) を参照してください。

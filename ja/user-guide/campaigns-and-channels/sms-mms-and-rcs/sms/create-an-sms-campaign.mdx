<Tip>
  SMS キャンペーンの作成を開始する前に、[SMS チャネルが設定されている](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/sms/getting-started-with-sms/configure-an-sms-sender)ことを確認してください。
</Tip>

# SMS キャンペーンの作成手順

SMS キャンペーンを作成する手順は次のとおりです。

1. [ターゲットユーザー](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/sms/create-an-sms-campaign#step-1-target-users): キャンペーンのターゲットオーディエンスを定義します。
2. [コンテンツ](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/sms/create-an-sms-campaign#step-2-content): 送信する SMS キャンペーンのコンテンツを定義します。
3. [スケジュールと目標](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/sms/create-an-sms-campaign#step-3-schedule-and-goals): キャンペーンの配信スケジュールと目標を定義します。

## Step 1: Target Users

このセクションには次の内容が含まれます。

### キャンペーンの詳細

次のフィールドを使用して、キャンペーンの詳細セクションを定義します。

![4.png](/images/moengage_0ccb24.png)

| フィールド | 説明 |
| --- | --- |
| **Teams** | 組織でチームが有効になっている場合は、ドロップダウンリストからチームを選択します。詳細については、[MoEngage のチーム](/ja/user-guide/settings/account/team-management/teams-in-moengage)を参照してください。 |
| **Campaign name** | キャンペーンを管理および識別するためのキャンペーン名を入力します。キャンペーン名は 5 文字以上である必要があり、上限は 256 文字です。 |
| **User attribute that stores user’s mobile number** | MoEngage は、設定で構成された属性を携帯電話番号のデフォルトのユーザー属性として自動的に選択します。ただし、携帯電話番号を含む別の属性を選択することで、キャンペーンレベルでこのデフォルトを上書きできます。 |
| **Campaign tags** | ドロップダウンリストからキャンペーンタグを選択します。最大 5 つのタグを選択できます。詳細については、[キャンペーンタグ](/ja/user-guide/campaigns-and-channels/getting-started/introduction/campaign-tags)を参照してください。 |
| **Trigger criteria** | このフィールドは、配信タイプとして **Event Triggered** を選択した場合にのみ表示されます。キャンペーンを開始する特定のトリガー条件を追加する必要があります。詳細については、[イベントトリガーキャンペーンの作成](/ja/user-guide/campaigns-and-channels/getting-started/triggers/event/create-an-event-triggered-campaign)を参照してください。 |
| **Select business event** | このフィールドは、配信タイプとして **Business Event Triggered** を選択した場合にのみ表示されます。キャンペーンのビジネスイベントを選択する必要があります。詳細については、[ビジネスイベントトリガーキャンペーンの作成](/ja/user-guide/campaigns-and-channels/getting-started/triggers/business-event/business-event-triggered-campaigns)を参照してください。 |

**Select Audience** セクションでは、次のセグメンテーションフィルターを使用してキャンペーンのターゲットオーディエンスを選択できます。

<Info>

フィルター条件を選択した後、次の操作を実行できます。

- **Create Multiple Filters**: このオプションを使用すると、複数のユーザープロパティルール、ユーザーアクティビティルール、カスタムセグメントルールを作成して組み合わせ、複雑なユーザーセグメントを作成できます。
  1. **\+ Filter** をクリックします。
  2. **AND** または **OR** をクリックします。
  3. 属性またはイベントを選択し、フィルター条件を定義します。
- **Exclude Users**: キャンペーンから除外するユーザーのフィルター条件を定義するには、このチェックボックスを選択します。
- **Send campaign to the users opted-out in subscription management**: このトグルをオンにすると、オプトアウトしたユーザーがキャンペーンに自動的に含まれます。詳細については、[サブスクリプション管理](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/other-settings/configure-subscription-and-keywords)を参照してください。
- **Reset filters**: セグメンテーションフィルターをリセットするには、このオプションをクリックします。
- **Show count**: 設定したセグメントに現在含まれているユーザーの総数を表示するには、このボタンをクリックします。

### コントロールグループ

このセクションには、キャンペーンのコントロールグループに関する情報が含まれています。コントロールグループとは、除外リストに追加されたユーザーのセットです。これらのユーザーはマーケティングキャンペーンを受信しません。コントロールグループはプロモーションキャンペーンでのみ有効で、トランザクションキャンペーンには適用されません。プロモーションキャンペーンを送信するコントロールグループを有効にできます。

<img
  alt="control groups.png"
  src="/images/moengage_23b898.png"
  style={{ width:"71%" }}
/>

- グローバルコントロールグループは、どのマーケティングキャンペーンも受信しないユーザーのリストです。\
  **Global control group** トグルをオンにすると、コントロールグループ内のすべてのユーザーにキャンペーンが送信されなくなります。
- キャンペーンコントロールグループは、キャンペーンの対象となるユーザーベースを組み合わせて作成されます。**Campaign control group** トグルをオンにすると、その特定のキャンペーンがコントロールグループに送信されなくなります。\
  詳細については、[コントロールグループ](/ja/user-guide/campaigns-and-channels/getting-started/introduction/control-groups)を参照してください。

**Next** をクリックするか、キャンペーン作成ナビゲーションの上部にあるタブを使用して、Step 2: Content に移動します。

## Step 2: Content

このセクションでは、SMS キャンペーンのコンテンツを作成する方法について説明します。SMS キャンペーンのコンテンツは、次のオプションを使用して作成できます。

- [デフォルトテンプレート](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/sms/create-an-sms-campaign#create-content-using-default-template)
- [カスタムテンプレート](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/sms/create-an-sms-campaign#create-content-using-custom-template)

### Create Content Using Default Template

SMS キャンペーンのコンテンツを作成するには、次の手順を実行します。

1. 空白のテンプレートを選択します。Content タブが表示されます。<img src="/images/moengage_5b31d8.png" alt="ContentCreation_SMS.png" />
2. **SMS sender** リストから、SMS コネクター（サービスプロバイダー）を選択します。ICS、GupShup、Kaleyra など、DLT 規制の対象となるコネクターの場合は、以下に示すように **Template ID** 情報の表示が必須です。DLT 規制の詳細については、[こちら](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/compliance-and-deliverability/dlt-impact-on-sms)をクリックしてください。<img src="/images/moengage_4f7b07.png" alt="268368DA-C881-4A7A-9908-4E28D48A3861_1_201_a.jpeg" />
3. **Message** フィールドに、SMS に表示されるコンテンツを入力します。<img src="/images/moengage_8d9f10.png" alt="Message.png" />
4. メッセージをパーソナライズするには、**Message** フィールドに @ を入力します。**SMS Personalization** ポップアップウィンドウが表示されます。詳細については、[パーソナライゼーション](/ja/user-guide/personalize/overview/overview-personalize)を参照してください。<img src="/images/moengage_1d6adb.png" alt="6A582B4B-1963-4498-A2E2-1692B129AD94_1_201_a.jpeg" />
5. 選択した属性がユーザーに存在しない場合や、属性の表示に失敗した場合は、上に示すようにフォールバックオプションを選択できます。失敗した属性の代替がない場合は、**No Fallback** を選択します。SMS を送信しないことを選択するか、**Replace text** オプションを使用して、失敗した属性を任意のテキストに置き換えることができます。\
   メッセージの文字数と SMS の件数が表示されます。<img src="/images/moengage_2e6348.png" alt="mceclip1.png" />

### Create Content Using Custom Template

<Note>
  これは Early Access 機能です。アカウントで有効にするには、MoEngage のカスタマーサクセスマネージャー（CSM）またはサポートチームにお問い合わせください。
</Note>

カスタムテンプレートは、[Custom Template API](https://www.moengage.com/docs/api/sms-templates/create-sms-template) を使用して MoEngage にアップロードされます。このオプションを使用すると、MoEngage エコシステムの外部で作成された事前定義済みのテンプレートセットを利用できます。これらのテンプレートは再利用したり、ダッシュボードでプレビューしたり、顧客へのキャンペーン送信に使用したりできます。

カスタムテンプレートセクションでは、次の操作を実行できます。

- **Select a template**: テンプレートをクリックして選択します。
- **Sort templates**: 並べ替えアイコン（ <Icon icon="arrow-up-arrow-down" iconType="solid" /> ）をクリックして、テンプレートの最終更新日時の昇順または降順でテンプレートを並べ替えます。
- **Search templates**: カスタムテンプレートセクションの右上にある検索ボックスにテンプレート名を入力して、特定のテンプレートを検索します。
- **Preview a template**: 以下に示すように、テンプレートにカーソルを合わせ、表示されるプレビューアイコンをクリックすると、テンプレートをプレビューできます。<img src="/images/moengage_5295fd.png" alt="PreviewCustomSMSTemplate.gif" />

カスタムテンプレートを選択すると、テンプレート内のすべてのフィールドの詳細とともに UI に読み込まれます。フィールドを表示することはできますが、編集できるのは「Edit Templates」権限がある場合のみです。

<Info>
  - 次のロールを持つユーザーはテンプレートを編集できます: Default Admin、Manager、Marketer。
  - 他のユーザーに編集アクセスを付与するには、そのユーザーに「Edit Templates」権限が必要です。
</Info>

### URL の追加と短縮

URL は次の方法でトラッキングできます。
 
- **Message** フィールドに URL を入力または貼り付けると、**Shorten and track URL(s)** セクションに自動的に表示されます。
- **Add URL** ボタンを使用して、個々のユーザー向けに動的に生成されるリンクを含む、特定のリンクをトラッキングします。

#### Message フィールドに URL を入力または貼り付ける
 
SMS の **Message** フィールドに URL を直接入力または貼り付けると、**Shorten and track URL(s)** セクションに自動的に表示されます。MoEngage は URL 短縮サービスを使用して URL を短縮し、リンクをクリックしたユーザーをトラッキングします。
 
 <img alt="track_url_sms.png"  src="/images/track_url_sms.png" />
 
この場合、次の点に注意してください。
 
- 短縮リンクは 15 日で期限切れになり、期限切れ後はトラッキングできません。顧客が期限切れ後にリンクを開くと、**This link is no longer active** というメッセージが表示されます。
- 短縮リンクでユーザー属性やイベント属性を使用する場合、属性名は次の条件を満たす必要があります。
  - スペースを含まないこと。
  - 属性にリンクが含まれる場合、その値に `http://` または `https://` を含めないこと。リンクを短縮するために、これらは属性の前に追加できます。
- アポストロフィやカンマなどの特殊文字は、短縮リンクではサポートされていません。
- 短縮するリンクでは、複数の JINJA 操作はサポートされていません。たとえば、短縮するリンク内で、Product 属性に Content API リンクを使用すること、またはその逆はサポートされていません。

#### Add URL ボタンを使用する
 
**Add URL** ボタンを使用して、個々のユーザー向けに動的に生成されるリンクを含む、SMS キャンペーン内の特定のリンクをトラッキングします。次の種類の URL を入力してトラッキングできます。
 
- **Static URLs**
- **User Attributes**: ユーザーのプロファイル内に保存されているリンク（例: 固有の紹介リンク）。
- **Event Attributes**: ユーザーの最近のアクションの一部として渡されるリンク（例: カート放棄のリカバリーリンク）。
- **Auxiliary (Aux) Data**: アップロードされた Aux ファイルから動的に取得されるリンク。
<Info>
ここで定義した URL がメインの **Message** フィールドにまだ存在しない場合、MoEngage はその URL を自動的に短縮し、ユーザーに送信する前に SMS メッセージの末尾に追加します。
</Info>

### ロケールを追加する

キャンペーンにロケールを追加するには、コンテンツ作成ステップの右上にある **\+ Locale** をクリックします。新しいロケールを追加することも、既存のロケールをキャンペーンに追加することもできます。詳細については、[キャンペーンメッセージのローカライズ](/ja/user-guide/campaigns-and-channels/getting-started/campaign-content/localize-campaign-messages)を参照してください。

  **イベントトリガーキャンペーンはいつ送信されますか？**

  キャンペーンは、次の場合にのみ送信されます。

  - この種類のトリガーの作成に使用するイベントプロパティ/属性（flight\_time の例など）が、有効な日時形式である場合。日時形式でない場合、文字列には[サポートされている形式](/ja/user-guide/campaigns-and-channels/getting-started/triggers/event/create-an-event-triggered-campaign#supported-formats)のいずれかのデータが含まれている必要があります。選択した属性にこれらのいずれかの形式のデータが含まれていない場合、キャンペーンはユーザーに送信されません。
  - 属性の日時の値が、トリガー条件が満たされた時刻よりも後である場合。
  - 属性の日時の値が、トリガー条件が満たされた時刻 \+ 30 日よりも前である場合。たとえば、トリガー条件が日付 D に満たされた場合、通知は属性値が D\+30 未満の場合にのみ送信されます。
  - インテリジェントな遅延最適化（**With Delay**）は、相対タイミングで送信されるキャンペーンでは機能しません。

### Conversion Goals

コンバージョン目標を追加して、キャンペーンのビジネス指標をトラッキングできます。最大 5 つのコンバージョン目標をトラッキングできます。任意のアプリイベントをコンバージョン目標のアクティビティとして選択でき、複数のコンバージョン目標を設定できます。最初の目標がプライマリ目標として扱われます。

### Delivery Controls

<Tabs>
  <Tab title="1 回限り、定期、ビジネスイベントトリガーキャンペーンの配信コントロール">
    このセクションには次のオプションが含まれます。

    **Frequency Capping**

    この機能は、1 日にユーザーに送信される SMS メッセージの数を制御するのに役立ちます。

    - **Ignore frequency capping**: この SMS キャンペーンでフリークエンシーキャップの上限を無視するには、このトグルを有効にします。キャップを無視しつつ、このキャンペーンをカウント対象にしたい場合は、**Ignore frequency capping** をクリックして SMS キャンペーンのキャップを無視します。たとえば、フリークエンシーキャップの値が 3 に設定されており、今日すでにあるユーザーグループに 3 つのキャンペーンを送信したとします。一部の顧客がすでに 3 つのキャンペーンを受信していても、このキャンペーンでトリガーされる SMS メッセージは緊急で優先度が高いと判断したとします。Ignore Frequency Cap を使用すると、すでに 3 つのキャンペーンを受信したユーザーにもこのキャンペーンが送信されます。詳細については、[フリークエンシーキャップ](/ja/user-guide/settings/channels/delivery-controls/frequency-capping)を参照してください。
    - **Count for the frequency capping**: このコネクターをフリークエンシーキャップの上限にカウントする場合は、このトグルを有効にします。**Count for frequency capping** を使用すると、すでに 2 件のコミュニケーションを受信したユーザーにこのキャンペーンも送信した場合、キャンペーン送信後の受信数は 3 件になります。

    **Throttling**

    スロットリングは、SMS キャンペーンの送信レートを制御できる機能です。**Request limit** セクションに、SMS キャンペーンで 1 分あたりに送信するリクエスト数を入力します。たとえば、デフォルトの 60,000 rpm（1 分あたり最小 60,000 リクエスト、最大 200,000 リクエスト）でリクエスト URL を送信します。詳細については、[スロットリング](/ja/user-guide/settings/channels/delivery-controls/throttling)を参照してください。<img src="/images/moengage_9c5146.png" alt="del control.png" />
  </Tab>
  <Tab title="イベントトリガーキャンペーンの配信コントロール">
    このセクションには次のオプションが含まれます。

    |  |  |
    | --- | --- |
    | <ul><li>**Minimum delay between two messages**: 同じユーザーが受信する 2 つのメッセージ間の最小時間間隔を設定します。</li><li>**Ignore DND settings**: DND 設定を無視するには、このトグルを有効にします。</li><li>**Ignore frequency capping**: この Connector キャンペーンでフリークエンシーキャップの上限を無視するには、このトグルを有効にします。詳細については、[フリークエンシーキャップ](/ja/user-guide/settings/channels/delivery-controls/frequency-capping)を参照してください。</li><li>**Count for the frequency capping**: このコネクターをフリークエンシーキャップの上限にカウントする場合は、このトグルを有効にします。</li></ul> | <br /><img alt="delivery controls.png" src="/images/moengage_c3b494.png" style={{ display:"inline-block",textAlign:"center",verticalAlign:"middle" }} /> |

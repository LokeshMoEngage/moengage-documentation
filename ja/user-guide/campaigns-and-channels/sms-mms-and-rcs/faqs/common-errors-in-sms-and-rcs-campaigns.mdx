---

この記事では、MoEngage を通じて SMS および RCS メッセージを送信する際に表示される可能性のある一般的なエラーについて説明します。

# 内部エラー

以下は、SMS および RCS メッセージの送信中に MoEngage によって生成されるエラーの一部です。

| エラー | 説明 |
| --- | --- |
| Personalization Failed | このエラーは、メッセージのパーソナライゼーションに失敗し、フォールバックメッセージが設定されていない場合に発生します。システムはユーザーにメッセージを送信せず、Personalization Failed エラーを生成します。 |
| Invalid Mobile Number | このエラーは、ユーザーの携帯電話番号が無効な場合に表示されます。これには次のようなケースが含まれます。   <br />- **Mobile number** フィールドが空であるか、**None**、**N/A**、**undefined**、**null**、**0** などのプレースホルダー値が含まれている。 <br />- **Mobile number** に数字以外の文字や Unicode 文字が含まれている、または 4 桁未満である。 <br />- 携帯電話番号を E.164 形式に変換できない。 |
| Users removed due to Global Control Group | このエラーは、ユーザーが Global Control グループに含まれているため、MoEngage がユーザーにメッセージを送信しなかった場合に発生します。 |
| Rejected because of DND | このエラーは、設定された DND 時間帯にメッセージを送信しようとした場合に発生します。この場合、MoEngage はユーザーにメッセージを送信しません。 |
| Not sent due to campaign level min delay | このエラーは、ユーザーが同じキャンペーンの複数のメッセージの対象となっているものの、キャンペーン間の最小遅延設定によりメッセージが送信されなかった場合に発生します。 |

# サービスプロバイダーエラー

| エラー | 説明 |
| --- | --- |
| Failed to send | このエラーは、ユーザー ID が GupShup ダッシュボードで許可リストに登録されていない場合に表示されます。 |

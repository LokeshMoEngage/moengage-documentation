# 電話番号の種類

米国でブランドが SMS マーケティングを行うために使用できる電話番号には、次の 3 種類があります:

1. **ショートコード -** ショートコードは、ブランドが購入して SMS および MMS メッセージの送信に使用できる 5〜6 桁の番号です。ショートコードには、ランダムとバニティの 2 種類があります。ランダムは、その名のとおりランダムに割り当てられるショートコード番号です。バニティショートコードは、ブランドが[利用可能なコード](https://www.usshortcodes.com/find-short-code)から好みに基づいて具体的に選択するものです。
2. **ショートコードのリース -** ショートコードは usshortcodes.com を通じてリースすることもできます。リースの場合、ほとんどのベンダーが管理手数料を請求するため、総費用が増加します。そのため、ショートコードをリースする場合と直接購入する場合の差はごくわずかです。
3. **10 桁ロングコード(10-DLC) -** 10 桁ロングコード(10-DLC)は、米国内での A2P(Application to Person)メッセージングに使用されます。10DLC は 2021 年まで、マーケティング活動に関連するメッセージングでの使用が制限されていました。ブランドは、10 桁の番号またはローカル番号を 10DLC として選択できます。

### **認証済みフリーダイヤル番号**

フリーダイヤル番号は、消費者に費用がかからない 10 桁の番号であり、そのためフリーダイヤル(toll-free)と呼ばれます。フリーダイヤル番号はビジネスメッセージング用に指定されており、使用前に認証プロセスを経る必要があります。すでに音声通話で使用している独自のフリーダイヤル番号を持つブランドは、同じ番号をブランドの A2P メッセージング送信に使用するよう申請できます。

**オプション** - 申請者は、利用可能な番号のリストから選択するか、独自の番号を持ち込むことができます。

# 電話番号タイプの比較

スループット(1 秒あたりに送信できる SMS の数)、プロビジョニングまでの期間、費用に基づいた、各電話番号タイプの比較は次のとおりです。

|   |   |   |   |
| --- | --- | --- | --- |
| 電話番号タイプ/指標 | ショートコード  | 10-DLC    | 認証済みフリーダイヤル番号 |
| 標準スループット      | ショートコードあたり 100 メッセージ/秒。ショートコードは最も高いスループットを持ちます。 <br/> **注**: 一部のプロバイダーでは、ブランドが追加料金を支払うことでショートコードのスループットを増やすことができます。         | 10-DLC の導入当初は 1 メッセージ/秒でしたが、現在はブランドの Trust Score とユースケース(キャンペーン)タイプによって異なります。T-mobile などの一部のキャリアは、10-DLC 経由で送信される A2P メッセージに 1 日あたりのメッセージ上限も設けています。 | 3 メッセージ/秒。追加費用で番号のスループットを追加購入できます。ショートコードは高価なため、これは新しいブランドにとって優れた選択肢となります。時間の経過とともにブランドが大きく成長すると、より高いスループットが必要になるため、フリーダイヤル番号でスループットを追加購入できるオプションは非常に有用です。一部のベンダーでは、追加料金で 25、50、75、100、125、150 メッセージ/秒のスループットを追加購入できます。100 メッセージ/秒のスループットを持つフリーダイヤル番号の費用は、標準スループットが 100 メッセージ/秒のランダムショートコードと同じです。 |
| プロビジョニングまでの期間    | ショートコードは通常、申請の承認後 8〜12 週間以内に割り当てられます。ただし、それ以上かかる場合もあります。たとえば、パンデミックの初期段階では、パンデミック関連のニーズを持つ申請が優先されたため、キャリアがショートコードを提供するまでに通常より長い時間を要しました。 | 10-DLC 番号を取得するには、ブランドが米国の A2P ブランド登録を完了している必要があります。その場合、10-DLC は通常 1〜5 日以内に割り当てられます。                                                                 | フリーダイヤル番号は通常、申請から数日〜1 週間以内に割り当てられます。    |
| 総費用の考慮事項 | 一般的な費用は、セットアップ料金、継続費用、管理手数料です。セットアップ料金と継続費用の料金はプロバイダーによって異なります。        | 初期費用またはセットアップ費用は低く、継続費用はユースケースによって異なります。   | フリーダイヤル番号には、少額のセットアップ料金と継続費用がかかります。                                                                                      |
| セットアップ費用      | セットアップ費用は約 1000 で、追加で 500 の料金と追加の申請が必要です   | セットアップ費用は約 44 です。T-mobile はほとんどのユースケースで \$50 のキャンペーン有効化料金を請求します。                     | セットアップ費用は \$1 です。                                               |
| 継続費用           | 継続費用は四半期ごとに請求されます。ランダム番号の場合、料金は 4500 です。年払いの場合は割引が適用されることがよくあります。       | 継続費用もショートコードと比べて低く、番号あたり月額約 \$0〜10 です。                                                                                                                                                               | ランダムに割り当てられた番号の場合、継続費用は月額 \$2 で、ブランドが独自の番号を持ち込む場合は月額 50 セントです。    |

<Info>
  CTIA では、いかなる番号(ショートコード、10 DLC、フリーダイヤル)の共有も認められていません。以前はショートコードを複数のブランドで共有できましたが、2021 年に CTIA はそのサポートを廃止し、現在は番号の共有を禁止しています。たとえば、GAP は多くのブランドを所有していますが、そのブランドである Athleta と Old Navy は同じショートコードを共有できません。それぞれが独自の番号を持つ必要があります。
</Info>

# 概要

MoEngage の Fuzzy Opt-Out 機能は、SMS サブスクリプション管理に関する米国連邦通信委員会（FCC）の最新規制への準拠を支援します。この機能により、ユーザーがオプトアウトキーワードを誤って入力したり、スペルを間違えたり、別の表現を使用したりした場合でも、オプトアウトリクエストの識別と処理の精度が向上します。配信停止を意図しているユーザーに SMS マーケティングメッセージを送信することを防ぎ、ユーザーエクスペリエンスを保護するとともにコンプライアンスリスクを軽減します。この機能は、一般的なオプトアウトフレーズや特定の不快な用語を効果的に処理し、キャンペーンがユーザーフレンドリーかつ規制に準拠した状態を保てるようにします。

# 主な特長

この機能の主な特長は次のとおりです。

- **新しい属性**: ブール型属性 *Is Fuzzy Match* が *SMS Keyword Received* イベントに追加されました。
  - *Is Fuzzy Match* が *True* の場合:
    - キーワードタイプは *OPTOUT* として保存されます。
    - ユーザーのサブスクリプションステータスは *OPTOUT* に更新されます。
- **高度なキーワード検出**: アルゴリズムは次のようなケースに対応します。
  - 大文字と小文字の違い。
  - 先頭または末尾のスペース。
  - オプトアウトキーワードの一般的なタイプミス、略語、または別のスペル（ファジーマッチングを使用）。
- **不快な言葉の処理**: 不快または下品な言葉を含むメッセージは、不要なコミュニケーションでユーザーを不快にさせないよう、オプトアウトリクエストとして扱われます。
- **エラー管理**:
  - **オプトアウトの見逃し**: アルゴリズムは多くのケースに対応しますが、オプトアウトを意図した一部のユーザー入力が正しく検出されない場合があります。
  - **誤った分類**: ユーザー入力があいまいなため、一部のメッセージが誤ってオプトアウトリクエストとして分類される場合があります。

# Fuzzy Opt-Out の仕組み

ユーザーが SMS キャンペーンに返信すると、Fuzzy Opt-Out アルゴリズムは次のようにメッセージを処理します。

- **直接一致**: ユーザーのメッセージは、事前定義されたオプトアウトキーワードのリストと照合されます。これには、完全一致（例: STOP や unsubscribe）と、大文字・小文字の違いや余分なスペースを含むバリエーション（例: stop や UNSUBSCRIBE）が含まれます。
- **スペルミスや別表現のキーワードに対するファジーマッチング**: ファジー検索ロジックにより、タイプミスやバリエーションを含むメッセージが識別されます。たとえば、Stahp、Cansel、Unsubcribe、opt-out などのメッセージはオプトアウトリクエストとして検出されます。オプトアウトの意図と無関係なメッセージは検出されません。
- **不快な言葉の識別**: ユーザーが一般的に受け取りたくないと考える不快な言葉を含むメッセージは、オプトアウトリクエストとしてマークされます。
- **サブスクリプションの更新**: オプトアウトの意図が（直接一致またはファジーマッチングによって）確認されると、ユーザーのサブスクリプションステータスが *OPTOUT* に更新されます。

# Fuzzy Opt-Out が無効な場合の動作

Fuzzy Opt-Out 機能が無効な場合、MoEngage は次のもののみを認識します。

- キーワードの完全一致。
- 大文字と小文字の違いや、先頭および末尾のスペースなどの軽微なバリエーション。

タイプミス、略語、または別のスペルは認識されません。

## シナリオ例

次の表は、さまざまなユーザーの返信がどのように処理されるかを示しています。

| ユーザーの返信 | 実行されるアクション | 理由 |
| --- | --- | --- |
| STOP | オプトアウト | 事前定義されたオプトアウトキーワードと完全一致。 |
| stop | オプトアウト | キーワードに一致。大文字と小文字の違いを処理。 |
| Stahp | オプトアウト | Stop のタイプミスとしてファジーマッチを検出。 |
| stopppppppp | オプトアウト | Stop のタイプミスとしてファジーマッチを検出。 |
| atop | オプトアウト | Stop のタイプミスとしてファジーマッチを検出。 |
| *不適切な言葉を含むメッセージ* | オプトアウト | 明示的な不快な用語をオプトアウトとして識別。 |
| Cancel my subscription | オプトアウト | オプトアウトキーワード *Cancel* を含む。 |
| "Hey, just opt me out!" | オプトアウト | ファジーマッチングにより *opt-out* を検出。 |
| HELP | アクションなし | オプトアウト以外のキーワードを検出。 |
| Hello 😊 | アクションなし | 中立的な意図を検出（オプトアウトではない）。 |

# コンプライアンス上のメリット

コンプライアンス上の主なメリットは次のとおりです。

- **ユーザーエクスペリエンスの向上**: スペルミスや余分なスペースがあっても、ユーザーがオプトアウトの意図を示した場合は確実にキャンペーンから除外されます。
- **FCC への準拠**: オプトアウトリクエストに迅速かつ正確に対応することを企業に求める米国の規制への準拠を支援します。
- **リスクの軽減**: オプトアウトリクエストの誤処理や見逃しによる罰金や苦情の可能性を低減します。

# 制限事項と考慮事項

制限事項と考慮事項は次のとおりです。

- **偽陰性**: ユーザーの入力があいまいな場合や、アルゴリズムが検出できない非常に独特な表現が使用されている場合、一部のオプトアウトの試みが見逃される可能性があります。
- **偽陽性**: 一部のメッセージ、特に境界線上の表現やくだけた表現を含むメッセージは、誤ってオプトアウトリクエストとして分類される場合があります。
- **カスタムキーワードの処理**: 独自のシナリオに対応するため、企業はセットアップ時に追加の特定オプトアウトキーワードを定義する必要があります。

# まとめ

Fuzzy Opt-Out 機能は、SMS キャンペーンの規制準拠を維持し、ユーザーの信頼を築き、リスクを最小限に抑えるための有用なツールです。ただし、考えられるすべてのケースに対応できるわけではありません。改善すべき点を特定するため、オプトアウトの動向を定期的に監視することをお勧めします。この機能を活用して、規制に準拠しながら顧客満足度を維持してください。

この記事では、SMS 通信を保護するためのインド電気通信規制庁 (TRAI) の重要なコンプライアンス更新について説明します。

## 変更内容

TRAI は、SMS メッセージで使用されるすべての URL 短縮ドメインを登録し、許可リストに追加することを義務付けました。これは、カスタムドメインとサードパーティの短縮サービスの両方に適用されます。

## これが重要な理由

SMS 通信における詐欺やスパムの増加を受けて、TRAI はセキュリティを強化し消費者を保護するためにこれらの変更を実施しています。SMS のリンクで使用されるドメインを規制することで、TRAI はフィッシングやその他の悪意のある行為のリスクを軽減することを目指しています。

## 必要な対応

### MoEngage ダッシュボードで実行する対応

1. SMS キャンペーンでリンクの短縮に使用しているすべてのドメインを確認します。
2. MoEngage ダッシュボードの SMS 設定の一部として Sender ID を追加します。  
   - *Listed connectors* の場合、Sender ID はすでに取得されています。設定の一部として Sender ID を再確認してください。
   - *Custom connectors* の場合、送信者の設定を編集し、コネクター設定の一部として Sender ID を追加します。  
      <img alt="TRAI.png" src="/images/moengage_d6d285.png" />

<Info>
Sender ID は一般に *Headers* とも呼ばれます。
</Info>

### 各 Sender ID について DLT ポータルで実行する対応

1. MoEngage を使用してリンクを短縮する場合は、DLT ポータルで以下の手順を実行します。   
   - Airtel DLT ポータルの手順:
     1. DLT ポータルに移動し、**Manage CTA** をクリックします。
     2. **Add New** をクリックし、ポップアップウィンドウで **Yes** をクリックします。
     3. URL & Short URL を選択します。
     4. URL として http://ux.mnge.co/Your Sender ID/ を追加し、サンプル URL として http://ux.mnge.co/Your SenderID/12345 を入力して、**Confirm** をクリックします。
        - *x* はお使いのダッシュボードに置き換えてください。たとえば、dashboard-01 の場合、短縮 URL は http://u1.mnge.co/your senderID/ になります。
        - URL の承認プロセスは 24〜48 時間で完了します。
   - その他の DLT ポータルについては、以下の詳細なガイドラインを参照してください。
     - [BSNL](https://app-cdn.moengage.com/outbound-ui/whatsapp/resources/pdf/BSNL.pdf)
     - [VI](https://app-cdn.moengage.com/outbound-ui/whatsapp/resources/pdf/VI+Business.pdf)
     - [Reliance](https://app-cdn.moengage.com/outbound-ui/whatsapp/resources/pdf/Reliance.pdf)
     - [Tata Tele Services](https://app-cdn.moengage.com/outbound-ui/whatsapp/resources/pdf/Tata+TeleBusiness+Service.pdf)
2. カスタムドメインを使用してリンクを短縮する場合は、DLT ポータルで以下の手順を実行します。
   1. Airtel DLT ポータルの手順:
      1. DLT ポータルに移動し、**Manage CTA** をクリックします。
      2. **Add New** をクリックし、ポップアップウィンドウで **Yes** をクリックします。
      3. URL & Short URL を選択します。
      4. URL として http://yourbrand.domain/Your SenderID/ を追加し、サンプル URL として http://yourbrand.domain/Your SenderID/12345 を入力して、**Confirm** をクリックします。
         - MoEngage でカスタムドメインを検証していない場合は、このガイドに記載されている手順に従ってください。
         - DLT での URL の承認プロセスは 24〜48 時間で完了します。
   2. その他の DLT ポータルについては、以下の詳細なガイドラインを参照してください。
      - [BSNL](https://app-cdn.moengage.com/outbound-ui/whatsapp/resources/pdf/BSNL.pdf)
      - [VI](https://app-cdn.moengage.com/outbound-ui/whatsapp/resources/pdf/VI+Business.pdf)
      - [Reliance](https://app-cdn.moengage.com/outbound-ui/whatsapp/resources/pdf/Reliance.pdf)
      - [Tata Tele Services](https://app-cdn.moengage.com/outbound-ui/whatsapp/resources/pdf/Tata+TeleBusiness+Service.pdf)

<Info>
複数の Sender ID がある場合は、Sender ID ごとに手順を繰り返してください。たとえば、dashboard-01 に SenderID1 と SenderID2 がある場合は、MoEngage の短縮 URL を http://u1.mnge.co/SenderID1/ および http://u1.mnge.co/SenderID2/ として許可リストに追加します。
</Info>

問題が発生した場合は、DLT サービスプロバイダーにお問い合わせください。

## 手順に従わなかった場合

MoEngage は引き続きパートナーにメッセージを送信しますが、上記のガイドラインに準拠していない場合、TRAI がメッセージの配信を拒否する可能性があります。

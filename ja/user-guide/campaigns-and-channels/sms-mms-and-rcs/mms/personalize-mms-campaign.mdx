パーソナライゼーションにより、マーケティングメッセージを顧客にとってより関連性の高いものにできます。MMS キャンペーンをカスタマイズすることで、オーディエンスとのつながりを強化し、メッセージの受け入れられ方を向上させることができます。

この記事では、ワンタイム、定期、イベントトリガー型メッセージを含む、MoEngage MMS キャンペーンでのパーソナライゼーションの使用方法について説明します。

パーソナライゼーションをサポートする MMS コンテンツフィールドには、プレースホルダーテキスト **Type @ to personalize** が表示されます。

<Info>
MMS チャネルでパーソナライゼーションの条件やロジックを作成すると、チップとして表示されます。チップアクションの詳細については、[こちら](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/dynamic-content-personalization#chip-actions)を参照してください。
</Info>

# データのパーソナライゼーション

ユーザー属性、プロダクトセット、Content API を使用して[メッセージをパーソナライズ](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/overview)できます。メッセージフィールドにパーソナライゼーションを挿入するには、@ を入力します。次の画像のように、MMS Personalization ダイアログボックスが開きます。

<img alt="SMS1.png"  src="/images/moengage_c06774.png"  />

## フォールバックの選択

メッセージをパーソナライズする際、フォールバックオプションを使用すると、選択した属性がユーザーに対して利用できない場合や正しく表示されない場合でも、常にコンテンツが表示されるようにできます。

次のフォールバックオプションから選択できます。

- 失敗した属性の代替がない場合は、**No Fallback** を選択します。パーソナライゼーションが失敗した場合、パーソナライズされた属性は空の文字列に置き換えられます。
- パーソナライゼーションが失敗した場合に MMS を送信しないようにするには、**Do not send MMS** を選択します。
- 失敗した属性を任意のテキストに置き換える場合は、**Replace text** を選択します。パーソナライゼーションが失敗した場合、パーソナライズされた属性は **Fallback text** フィールドに入力したテキストに置き換えられます。

<Info>
カスタム属性には、MoEngage の標準属性とは異なる名前を付けてください。同じ名前のカスタム属性と標準属性をパーソナライゼーションに使用すると、誤ったパーソナライゼーションが発生する可能性があります。
</Info>

## ビジネスイベントトリガー型キャンペーンのパーソナライズ

ビジネスイベントトリガー型 MMS キャンペーンでは、マッピングされたビジネスイベントの属性を使用してメッセージをパーソナライズできます。これにより、単一のテンプレートを複数のキャンペーンに使用でき、作業量を大幅に削減し、自動化を実現できます。たとえば、単一のキャンペーンテンプレートを作成して、さまざまな新作ウェブシリーズに関する情報を伝え、ユーザーの興味に基づいてシリーズ名、画像、キャスト、放送日などの詳細で各メッセージをパーソナライズできます。

ビジネスイベント属性を使用してコンテンツをパーソナライズするには、次の手順を実行します。

1. コンテンツ作成ステップで **@** を入力して、パーソナライゼーションエディターを呼び出します。次の画像のように、キャンペーンにマッピングされたビジネスイベントの属性が **Business Event Attribute** の下に表示されます。  
    <img alt="mMS2 per.png"  src="/images/moengage_8f26ff.png"  />
2. パーソナライゼーションに使用する属性を選択します。
3. メッセージをカスタマイズします。

詳細については、[メッセージのパーソナライゼーション](https://moengage-user-guide.mintlify.app/user-guide/campaigns-and-channels/getting-started/message-personalization/overview#user-attributes)を参照してください。

# コンテンツブロックを使用したコンテンツのパーソナライズ

コンテンツブロックは、さまざまなキャンペーンで使用できる再利用可能なコンテンツスニペットです。ヘッダー、フッター、署名ブロック、利用規約などの標準的な要素に役立ちます。

コンテンツブロックを使用してメッセージをパーソナライズするには、次の手順を実行します。

1. メッセージセクションで @ を入力します。
2. 表示されるパーソナライゼーションメニューで、**Content blocks** タブをクリックします。  
    <img alt="mMS3 per.png"  src="/images/moengage_4ccb33.png"  />
3. 必要なコンテンツブロックを選択します。
4. **Done** をクリックします。選択したコンテンツブロックがメッセージに追加されます。
5. **Insert only the content of the content block** トグルをオンにすると、コンテンツを既存のコンテンツブロックから切り離せます。今後コンテンツブロックを更新しても、キャンペーンには反映されません。この手順は任意です。

詳細については、[コンテンツブロックを使用したコンテンツのパーソナライズ](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/personalize-content-using-content-blocks)を参照してください。

# 補助データを使用したコンテンツのパーソナライズ

パーソナライゼーションエディターで補助データ属性を選択することで、補助データを使用して MMS コンテンツをパーソナライズできます。

補助データ属性を使用してコンテンツをパーソナライズするには、次の手順を実行します。

1. **Message** フィールドで @ を入力して、パーソナライゼーションエディターを呼び出します。
2. **Aux Data** タブを選択します。
3. **Aux data** ドロップダウンリストで、パーソナライゼーションに使用する属性を含む補助データファイルを選択します。
4. **Lookup value** ドロップダウンリストで、インポート時に補助データに指定したプライマリキーを選択します。これにより、補助データを取得する対象のユーザーが識別されます。
5. **Attribute** ドロップダウンリストで、補助データを使用してパーソナライズする属性を指定します。
6. **Done** をクリックします。補助データの JINJA がフィールドまたはエディターに追加されます。  
    <img alt="mMS4 per.png"  src="/images/moengage_31990f.png"  />

詳細については、[補助データを使用したキャンペーンコンテンツのパーソナライズ](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/personalize-content-using-auxiliary-data)を参照してください。

# Content API を使用したコンテンツのパーソナライズ

Content API を使用して MMS キャンペーンをパーソナライズし、関連性が高くタイムリーな情報をユーザーに届けることができます。

## Content API の追加

MoEngage ダッシュボードに Content API を追加できます。

1. **Settings** \> **APIs** \> **Content API** に移動して、Content API にアクセスします。
2. **Add** をクリックして Content API を追加します。

詳細については、[Content API を使用したコンテンツのパーソナライズ](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/personalize-content-using-content-apis)を参照してください。

## Content API を使用したパーソナライズされたキャンペーンの作成

1. コンテンツ作成ステップで **@** を入力して、パーソナライゼーションエディターを呼び出します。
2. **MMS personalization** ポップアップで、**Data Personalization** タブに移動します。
3. Content API を検索し、リストから API を選択します。   
    <img alt="mMS5 per.png" src="/images/moengage_d462a9.png" />

<Info>
パーソナライゼーションエラーの詳細については、[一般的なパーソナライゼーションエラーと FAQ](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/common-personalization-errors-and-faqs)を参照してください。
</Info>

# 概要

メッセージングの規制遵守の一環として、ユーザーは SMS、MMS、RCS の受信に同意する必要があります。メッセージングコンプライアンスの詳細については、[メッセージング規制](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/compliance-and-deliverability/messaging-regulations-for-us)を参照してください。サブスクリプションとキーワードの機能を使用すると、キーワードを使用してユーザーの SMS サブスクリプションステータスを追跡できます。

この設定を使用して、キーワードカテゴリと自動応答メッセージを追加および構成できます。キーワードは、SMS 通知の購読（受信）および購読解除（受信拒否）に関するユーザーの同意を取得します。また、キーワードは SMS アラートの購読に関するサポートやヘルプを受けるためにも使用されます。

この記事では、SMS、MMS & RCS チャネルのサブスクリプション管理と、SMS および MMS チャネルのキーワード管理を構成する手順について説明します。

SMS & RCS のサブスクリプションは **Settings** \> **Channels** \> **SMS & RCS** \> **Subscription management** タブで管理でき、SMS のキーワードは **Keyword management** タブで構成できます。

# サブスクリプション管理

<Info>
  - **Keyword management** タブで **Manage keyword-based responses** トグルをオンにすると、**Opt-out users** トグルがデフォルトで自動的にオンになります。これにより、オプトアウトしたユーザーに誤ってメッセージを送信することを防げます。ただし、**Manage keyword-based responses** トグルをオフにしても、**Opt-out users** トグルは自動的にオフになりません。
  - サブスクリプション管理は、SMS チャネルにおけるユーザーのリーチャビリティに影響します。
</Info>

サブスクリプション管理を有効にするには、次の手順を実行します。

1. **Opt-out** **users** トグルをオンにします。
2. **Criteria for opting out users** で、次のいずれかを選択します。
   - **Default**：**opt-out** が有効な場合、このオプションがデフォルトで選択されます。このオプションを選択すると、**SMS subscription status**（ユーザープロパティ）の値が **Optin** であるユーザーがキャンペーンのターゲットオーディエンスとして扱われます（ブランドからのコミュニケーションの受信を選択したユーザーは、キャンペーンのセグメンテーション条件を満たしていれば、MoEngage からキャンペーンが送信される際にターゲットになります）。
   - **Custom**：このオプションでは、ユーザーのオプトインステータスを格納するカスタムユーザー属性を選択できます。たとえば、ユーザーのサブスクリプションステータスを格納するユーザー属性を _custom_user_property_ とし、この属性の値が _Opt-out_ であるとします。この場合、ドロップダウンでこのユーザー属性を選択し、値を _custom_user_property is equal to Opt-out_ に設定することで、この属性の値が _Opt-out_ であるユーザーをキャンペーンの受信対象から除外できます。

## キーワードベースの応答の管理

アカウントでサブスクリプション管理が有効になった後、キーワードを構成できます。SMS、MMS のキーワードを構成するには、次の手順を実行します。

1. **Manage keyword-based responses** トグルをオンにします。
2. **\+ Add new keyword** をクリックして、キーワードを追加および構成します。

**Add Keyword Category** ウィンドウでは、次のオプションを使用できます。

![Screenshot 2025-07-15 at 4.38.59 PM.png](/images/moengage_6ac0be.png)

| フィールド            | 説明 |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Keyword category | キーワードカテゴリ名を入力または貼り付けます。キーワードカテゴリ名は最大 50 文字です。 |
| Keyword          | キーワードを入力または貼り付け、Enter キーを押してキーワードを追加します。たとえば、キーワードカテゴリが Opt-In の場合、キーワードは subscribe、start、resubscribe、enable などにできます。 <br /> **注**：1 つのキーワードカテゴリに追加できるキーワードは 20 個までです。 |
| Message          | ユーザーが受信する SMS 自動応答メッセージを入力または貼り付けます。たとえば、再購読の場合のメッセージは次のようにできます：_You have successfully re-subscribed for receiving messages from this number. Reply HELP for more info. Reply STOP to unsubscribe._ <br /> **注**：メッセージには 200 文字までしか含めることができません。 |
| Status           | ステータスには次の値があります。 <ul><li>**Active**：システムは自動応答メッセージを送信し、キーワードを **SMS Keyword Response Sent** イベントで追跡します。MoEngage は、受信メッセージを受け取ったのと同じ送信者を使用して自動応答メッセージを送信します。</li><li>**Inactive**：システムは自動応答メッセージを送信しません。ただし、引き続き _SMS Keyword Received_ イベントをユーザーのプロファイルに記録し、それに応じて _SMS Subscription Status_ ユーザー属性を更新します。つまり、次のようになります。 <ul><li> システムが OPTIN キーワードを受信すると、ステータスは OPTIN に変わります。</li>  <li> システムが OPTOUT キーワードを受信すると、ステータスは OPTOUT に変わります。</li></ul></li></ul> |

**Save** をクリックして、キーワードとキーワードカテゴリを保存します。

<Info>
  - 自動応答メッセージは _SMS Keyword Response Sent_ イベントに記録され、次の属性を持ちます。
    - _timestamp_
    - _sender_number_
    - _sender_id_
    - _keyword_
    - _keyword type_
    - _keyword response_
    - _SDK version_
    - _App version_
    - _MOE Event Category_
    - _api_t_
    - _profile attribution_
    - _MOE Event Source_
  - SMS または MMS キャンペーンへの応答としてユーザーが送信したメッセージはすべて、_SMS Keyword Received_ イベントで追跡されます。
    - _Event Time_
    - _Event Received Time_
    - _SDK Version_
    - _App Version_
    - _Consent Acquisition Medium_
    - _api_t_
    - _sender_number_
    - _Source_
    - _Mobile Number_
    - _MOE Event Category_
    - _callback_type_
    - _profile_attribution_
    - _Is Fuzzy Match_
    - _MOE Event Source_
    - _Keyword type_
    - _keyword_
    - _timestamp_
  - ユーザーが応答として MMS を送信した場合、MoEngage はテキストコンテンツのみを保存し、添付されたメディアは破棄されます。
</Info>

## リードの獲得

**Capture leads from unknown numbers** トグルをオンにすると、MoEngage は新しい番号から受信した SMS メッセージから新しいユーザープロファイルを自動的に作成します。この機能により、SMS でのやり取りから潜在ユーザーを直接獲得できるため、リード獲得の取り組みが効率化され、より効果的なリターゲティングとキャンペーンエンゲージメントが可能になります。このトグルはデフォルトでオンになっています。

- 新しく作成されたユーザープロファイル（リード）は、MOE_INC_7814d0a55f という形式で保存されます。7814d0a55f の部分は暗号化されています。
- 新しい電話番号は、SMS チャネルの **General Settings** で構成された **User attribute that stores user's mobile numbers** 属性に保存されます。

## 一般応答の構成

**Set a general response** トグルをオンにすると、特に定義および管理されているキーワード以外の SMS キーワードに対して送信する、一般的なデフォルトメッセージを構成できます。オフにした場合、MoEngage は定義されていないキーワードには応答しません。

このトグルを有効にすると、デフォルトメッセージが表示されます。このメッセージは、ユーザーが誤ったキーワードや認識されないキーワードを送信した場合に送信できます。このデフォルトメッセージを変更するには、**Edit message to** をクリックします。**Edit message** ウィンドウでメッセージを入力し、**Save** をクリックします。

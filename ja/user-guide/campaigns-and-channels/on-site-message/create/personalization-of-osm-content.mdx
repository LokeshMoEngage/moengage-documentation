---

On-Site Messaging (OSM) キャンペーンのコンテンツはパーソナライズできます。**@** 記号を使用して、テキストや画像に動的コンテンツを追加します。

キャンペーンコンテンツは、以下のデータタイプを使用してパーソナライズできます。

- User Attributes
- User Events
- Product Catalogs
- Content APIs
- Content Blocks
- Auxiliary Data

これらのパーソナライズオプションの詳細については、以下を参照してください。

- [MoEngage Templating Language (Jinja)](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/jinja-templating-language)
- [Derived Events & Attributes](/ja/user-guide/data/event-data/derived-events-and-attributes)
- [Product Catalogs](/ja/user-guide/content/recommendations/getting-started/catalogs)
- [Content APIs](/ja/user-guide/campaigns-and-channels/getting-started/campaign-content/content-apis)
- [Content Blocks](/ja/user-guide/content/content-blocks/content-blocks)
- [Auxiliary Data](/ja/user-guide/data/imports/auxiliary-data)

OSM キャンペーンのコンテンツをパーソナライズするには、以下の手順に従います。

1. キャンペーン作成のステップ 2 で、**テキストボックス**または **Image Property URL** をクリックします。
2. テキストをパーソナライズするには、**テキストエリア**内の任意の場所で **@** を押します。Data Personalization ポップアップウィンドウが表示されます。  
    <img alt="@ を押してデータを選択し、テキストをパーソナライズする方法を示す GIF。" src="/images/moengage_0e3ce2.png" />
3. 画像をパーソナライズするには、**@** ボタンをクリックします。Data Personalization ポップアップウィンドウが表示されます。  
    <img alt="@ ボタンをクリックして画像をパーソナライズする方法を示す GIF。" src="/images/moengage_eb44e9.png" />
4. Data Personalization ポップアップで、以下のいずれかを行います。
   1. **Data Personalization** を選択します。
      1. ドロップダウンリストから、以下のいずれかのデータタイプを選択します。
         - **User Attributes**
         - **Product Catalogs**
         - **Content API**
           1. Content API パラメータの値を変更します。詳細については、[こちら](/ja/user-guide/campaigns-and-channels/getting-started/campaign-content/content-apis)を参照してください。
      2. 以下のいずれかのフォールバックオプションを選択します。
         - **No Fallback**: パーソナライズに失敗した場合、代替コンテンツは表示されません。
         - **Do not send In-App**: パーソナライズに失敗した場合、In-App メッセージは送信されません。
         - **Replace Text**: パーソナライズに失敗した場合に表示するテキストを入力または貼り付けます。
   2. **Content Block** を選択します。
      1. 挿入する **Content Block** を選択します。
      2. **Insert only the content of the content block** をクリックします。

         <Info>
         このオプションではコンテンツのみが挿入され、元の Content Block とのつながりは切り離されます。元の Content Block に対する今後の更新は、挿入されたコンテンツには反映されません。
         </Info>
5. 属性または Content Block を選択した後、**テキストエリア**で Jinja コードを編集します。
6. **Done** をクリックします。
7. Jinja コードを再度編集するには、**テキストボックス**内のパーソナライズ部分をクリックします。

   <Warning>
   ドロップダウンリストから別の属性を選択しないでください。選択すると、テキストボックス内の Jinja コード全体が置き換えられます。
   </Warning>

   <img alt="パーソナライズ部分をクリックして Jinja コードを再編集する方法と、新しい属性を選択しないよう注意を示す GIF。" src="/images/moengage_85e57f.png" />

<Info>
カスタム属性の名前が MoEngage の標準属性と同じにならないようにしてください。同じ名前のカスタム属性と標準属性をパーソナライズに使用すると、正しくパーソナライズされない可能性があります。
</Info>

# 概要

On-site Messaging (OSM) キャンペーンは、作成中にテストすることをお勧めします。これにより、さまざまなデバイスやブラウザでメッセージが想定どおりに表示されることを確認できます。Web サイト上のメッセージの表示は、ダッシュボードのプレビューとは異なる場合があります。**Test Campaign** 機能を使用して、On-site メッセージを有効化する前に自分のデバイスでプレビューしてください。

## Test Campaign 機能へのアクセス

**Test Campaign** 機能は、キャンペーン作成の 2 番目のステップにあります。以下の画像を参照してください。

![MoEngage ダッシュボードの Test Campaign 機能を示すスクリーンショット。](/images/moengage_55a875.png)

## Test Campaign 機能の使用

**Test Campaign** 機能を使用すると、On-site メッセージが Web サイト上でどのように表示されるかを確認できます。ライブユーザー向けにキャンペーンを有効化する前にテストメッセージを自分のデバイスに送信するには、以下の手順に従います。

1. キャンペーン作成中の **Test Campaign** セクションで、キャンペーンを表示したい URL を貼り付けます。
   ![テストキャンペーンの URL 入力フィールドを示すスクリーンショット。](/images/moengage_56ff40.png)
2. テストキャンペーンを表示するには、対象の URL に MoEngage SDK が統合されていることを確認してください。
3. **Test Campaign** ボタンをクリックします。同じブラウザで新しいタブが開き、そこに On-site メッセージが表示されます。このテストメッセージは、MoEngage ダッシュボードでボタンをクリックしたブラウザでのみ表示され、Web サイトの他の訪問者には表示されません。
4. テストキャンペーンは 30 秒間有効です。この間は、ページを更新しても同じブラウザでキャンペーンが表示されます。この動作はライブキャンペーンとは異なります。

<Warning>
**Test Campaign** 機能は Safari (iPhone および Mac) では動作しません。新しく開かれたウィンドウに対する Safari のより厳格なセキュリティポリシーのため、テスト送信は Safari ではレンダリングもリダイレクトもされません。これはブラウザの制限であるため、Safari でテスト送信を有効にする設定はありません。ライブキャンペーンは Safari でも通常どおりリダイレクトされます。Safari での OSM キャンペーンの動作を検証するには、[ダミー URL 方式](#test-on-mobile-web-devices)を使用して自分を対象としたライブキャンペーンを公開し、Safari でキャンペーンを開いてください。
</Warning>

## モバイル Web デバイスでのテスト

モバイル Web デバイスでキャンペーンをテストするには、以下のいずれかのオプションを使用できます。

<Tabs>
  <Tab title="Chrome のデバイスモードを使用してテストする">
    Chrome のデバイスモードでシミュレーションするには、以下の手順に従います。

    1. Chrome ブラウザで Web サイトを開き、**Developer Options** を開きます。
    ![Chrome で Developer Options を開く方法を示すスクリーンショット。](/images/moengage_7f64d2.png)
    2. Web サイトをモバイル Web ビューに切り替えます。
    ![Chrome のデベロッパーツールでモバイルビューに切り替える方法を示すスクリーンショット。](/images/moengage_37058e.png)

    **注:** この方法は近似的なものです。結果が常に正確であるとは限りません。詳細については、[Chrome Device Mode](https://developers.google.com/web/tools/chrome-devtools/device-mode) を参照してください。
  </Tab>
  <Tab title="ダミー URL を使用してテストする">
    ライブキャンペーンでダミー URL をテストするには、以下の設定で OSM キャンペーンを作成します。

    1. キャンペーン作成のステップ 1 で、特定のページを選択し、その URL に `?source=moe_onsite_test` などのダミーの source パラメータを追加します。これにより、キャンペーンはライブユーザーがアクセスできない Web ページに限定されます。
    ![キャンペーン設定で URL にダミーの source パラメータを追加した状態を示すスクリーンショット。](/images/moengage_ab1c76.png)
    2. 詳細については、[OSM キャンペーンの作成](/ja/user-guide/campaigns-and-channels/on-site-message/create/create-osm-campaign)を参照してください。
    3. ステップ 2 で、OSM のコンテンツを定義します。
    4. キャンペーンを公開します。その後、モバイルブラウザからダミー URL にアクセスし、モバイル Web サイトで OSM メッセージがどのように表示されるかを確認します。
    5. 必要に応じてキャンペーンを編集し、表示を調整します。
  </Tab>
</Tabs>

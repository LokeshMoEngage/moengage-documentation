On-site Messaging は、ユーザーがデスクトップまたはモバイルのウェブサイト、あるいは TV アプリをアクティブに閲覧している間に、ポップアップ、アンケート、リード獲得フォームをその画面上に直接表示します。これにより、リードの獲得、フィードバックの収集、リアルタイムでパーソナライズされた体験の提供が可能になります。

In-App Messaging と同様に、On-site Messaging はインバウンドチャネルです。メッセージは Push や Email のようにユーザーが利用している画面の外に配信されるのではなく、ユーザーがすでに利用している画面内に表示されます。

<Note>
  1 つのワークスペースでは、In-App または On-Site Messaging のアクティブなキャンペーンを同時に最大 200 件まで保持できます。この上限を引き上げるには、サポートにお問い合わせください（MTU に基づいて追加料金が発生します）。
</Note>

# ユースケース

On-site Messaging は、次のようなリアルタイムのページ上でのエンゲージメント目標をサポートします。

- **リアルタイムのパーソナライズ**: 訪問者のセッションを中断することなく、行動や属性に基づいてパーソナライズされたコンテンツを表示します。
- **リード獲得**: ページ上のフォームを通じて、メールアドレスの登録やその他の連絡先情報を収集します。訪問者が離脱しようとしたときにトリガーされる [exit-intent](/ja/user-guide/campaigns-and-channels/on-site-message/create/exit-intent-technology) フォームも利用できます。
- **即時のフィードバック収集**: ページ上で簡単なアンケートを実施し、訪問者の意見を把握します。
- **プロモーションと割引**: 初回訪問者に割引のポップアップを表示したり、Spin the Wheel や Scratch Card などの[ノーコードのゲーミフィケーションテンプレート](/ja/user-guide/campaigns-and-channels/on-site-message/create/no-code-gamification-templates-osm)を使用してプロモーションを実施したりできます。
- **TV アプリのエンゲージメント**: 重要なタイミングで、[TV アプリケーション](/ja/user-guide/campaigns-and-channels/on-site-message/create/create-osm-campaign-for-tv)のユーザーにパーソナライズされたメッセージを配信します。

# 次のステップ

On-site Messaging の概要を理解したら、次のステップに進みましょう。

- [**キャンペーンを作成する**](/ja/user-guide/campaigns-and-channels/on-site-message/create/create-osm-campaign): ターゲティング、コンテンツ、スケジュール設定を含め、最初の OSM キャンペーンを作成する手順を説明します。
- [**キャンペーンを分析する**](/ja/user-guide/campaigns-and-channels/on-site-message/analyze/analyze-on-site-messaging-campaigns): 公開後のキャンペーンのパフォーマンスを測定するための主要な指標について説明します。
- [**OSM 向けに Portfolio を設定する**](/ja/user-guide/campaigns-and-channels/on-site-message/getting-started-with-on-site-message/portfolio-for-on-site-messaging): 複数のウェブサイトを管理している場合に、Portfolio によってセグメンテーション、パーソナライズ、分析のための統合ビューがどのように提供されるかを説明します。

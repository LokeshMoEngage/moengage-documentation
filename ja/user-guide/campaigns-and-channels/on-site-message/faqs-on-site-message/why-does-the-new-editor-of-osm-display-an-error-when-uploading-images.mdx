## 問題

OSM キャンペーンの新しいエディターで画像をアップロードしようとすると、以下のエラーが発生します。  
"File extension is not supported."

<img  src="/images/moengage_2a874f.png"  />

## 説明

- ソーシャルメディアアプリは、画像をアップロードする前に、画像ファイル名の先頭にピリオド (ドット) を含む文字を追加します。
- MoEngage はドット以降のテキストをファイル拡張子として解釈するため、エラーが発生します。

## 解決策

このエラーを修正するには、ファイル名からドットを削除してください。

## 例

- 画像ファイル名の先頭に追加の文字が付加されると、"Snapinsta.app\_431485390\_745691364337715\_8350453286241390781\_n\_1080.jpg" のように表示されます。
- ファイル名からドットを削除すると、ファイル名は以下のようになります。  
  "Snapinstaapp\_431485390\_745691364337715\_8350453286241390781\_n\_1080.jpg"

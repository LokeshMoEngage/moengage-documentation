---
title: "OSM テンプレートの背景オーバーレイの色と透明度を変更する方法"
description: "MoEngage の On-site Messaging テンプレートの背景オーバーレイの色と透明度をカスタマイズします。不透明度を調整するためのステップバイステップガイドです。"
---

カラーグラデーションには、テンプレートの背景の透明度を 0 (透明) から 100 (不透明) の間で指定するオプションのパラメータが含まれています。不透明度が低いほど透明度が高く、不透明度が高いほど透明度が低くなります。

On-site Message (OSM) 用に選択したテンプレートをカスタマイズする際に透明度パラメータを使用するには、以下の手順を実行します。

<Tip>
[OSM キャンペーンの作成](/ja/user-guide/campaigns-and-channels/on-site-message/create/create-osm-campaign)プロセスを開始していることを確認してください。
</Tip>

1. キャンペーン作成プロセスのステップ 2 "Content" に移動します。
2. 必要なテンプレートを選択します。
3. エディターの右上にある設定アイコンをクリックし、3 番目のタブを選択して背景色のプロパティを表示します。
4. カラーグラデーションバーを上から下にスクロールして、背景色を選択します。
5. 不透明度バーを上から下にスクロールして、テンプレートとその背後の画面との間の透明度をカスタマイズします。
6. 縦の三点リーダーをクリックして **Save template** を選択するか、**Next** をクリックしてキャンペーン作成プロセスを続行します。

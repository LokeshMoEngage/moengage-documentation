MoEngage を使用すると、[_AMP_](https://amp.dev/)（Accelerated Mobile Pages）フレームワークで構築された Web ページで Web プッシュ通知をオプトインしたユーザーに、Web Push 通知を送信できます。AMP はページの高速読み込みなど、モバイルユーザー向けの Web エクスペリエンスの最適化に特化しているため、AMP ページではサードパーティのスクリプトを実行できないなど、フレームワークによって強制されるいくつかの制限があります。

さらに、AMP ページの連携方法は、MoEngage SDK を使用した通常の Web Push 連携とは異なります。詳細については、[AMP Web Push の連携](/ja/developer-guide/web-sdk/other-supported-web-sdk-integration/configure-and-integrate-amp-web-push)を参照してください。この機能は **HTTPS** のウェブサイトでのみ利用できます。

## 連携の基本事項

AMP は Android と iOS のすべての主要ブラウザーでサポートされています（[完全なリストはこちらを参照](https://amp.dev/support/faq/supported-browsers/)）。ただし、ユーザーが AMP ページで Web Push 通知を購読できるのは Android デバイスのみです。

AMP 連携の設定は、MoEngage アカウントでデフォルトで有効になっています。既存の Web Push 連携に AMP 連携を追加することも、AMP 連携を単独で使用することもできます。

この連携により、次のことが可能になります。

1. AMP ページで Web Push をオプトインできる
2. Web Push オプトインボタンの表示をカスタマイズできる
3. エンドユーザーがオプトイン後に Web Push をオプトアウトできる
4. 購読ユーザーに Web Push を配信できる。Web Push はパーソナライズでき、画像表示やアクションボタンなどのリッチな機能を含めることができます。\
   パーソナライズエディターで補助データ属性を選択することで、補助データを使用して Web Push コンテンツをパーソナライズできます。詳細については、[補助データを使用したキャンペーンコンテンツのパーソナライズ](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/personalize-content-using-auxiliary-data)を参照してください。
5. Web Push のインプレッションとユーザーアクション（ボタンクリック、通知クリック）を追跡できる
6. システムイベントとすべてのカスタムイベントを追跡できる

## AMP Web Push の購読者をターゲットにするには

AMP for Web Push の連携が完了すると、公開された AMP ページの訪問者は、購読ウィジェット（ボタン）をクリックして Web Push をオプトインできます。

### AMP ページからの Web Push 購読の識別

購読が成功すると、ユーザーの **Subscribed to Web Push** イベントが自動的にトリガーされます。これらのユーザーは、**User behavior** セグメンテーションフィルターを使用して確認できます。

**Has Executed** イベントを使用し、**Subscribed to Web Push** に設定して頻度と期間を設定することで、ユーザーをフィルタリングします。

![](/images/moengage_789814.png)

_AMP_ ページで購読したユーザーの数を特定するには、**is\*\*\*\*AMP** 属性が **True** の **Subscribed to Web Push** イベントを実行したユーザーをフィルタリングします。

![](/images/moengage_7026b3.png)

<Info>
  ユーザーが AMP 以外のページですでに購読しており、その後 AMP ページに移動した場合、そのユーザーは自動的に _Subscribed to AMP_ として表示されます。
</Info>

### AMP ページの購読者への Web Push の送信

ユーザーに Web Push 通知を送信するには、次の手順を実行します。

1. プッシュキャンペーンを作成し、ターゲットプラットフォームの 1 つとして **Web** を選択します。
2. 次の方法で、APM ページから Web Push を購読したユーザーをターゲットにできます。
   - ターゲットオーディエンスとして All Users セグメントを使用する。
   - ここに示すように、識別済みユーザーのカスタムセグメントを作成する。
3. 送信するメッセージを作成し、それに応じてキャンペーンをスケジュールします。Web Push キャンペーンの詳細については、[こちらのページ](/ja/user-guide/campaigns-and-channels/web-push/create/create-web-push-campaign)を参照してください。

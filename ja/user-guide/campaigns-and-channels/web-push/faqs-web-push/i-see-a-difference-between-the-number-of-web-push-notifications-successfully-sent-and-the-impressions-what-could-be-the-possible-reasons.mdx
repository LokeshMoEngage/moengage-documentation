MoEngage が Firebase Cloud Messaging（FCM）に正常に渡した Web プッシュ通知の数が、Successfully Sent として表示されます。

インプレッションは、ユーザーに届いた通知の数です。

インプレッション数が Successfully Sent より少なくなる場合があります。

この差は次の要因によって生じます。

- 通知の有効期限が切れる前にユーザーがオンラインにならない。
- ユーザーのデバイスでブラウザーが実行されていない。
- FCM、ブラウザー、オペレーティングシステム間の通信が失敗する。

<Note>
オペレーティングシステムの設定は、この差の要因にはなりません。ユーザーがブラウザーで Web プッシュの権限を許可していても、オペレーティングシステムレベルでそのブラウザーの通知をオフにしている場合、ブラウザーは通知を受信するため、オペレーティングシステムが画面上の表示を抑制していても、MoEngage はインプレッションをカウントし、*Notification Received Web* イベントを追跡します。MoEngage はこのユーザーを、Web プッシュの購読済みかつ到達可能なユーザーとしてもカウントします。詳細については、[ブラウザーの権限と OS レベルの通知設定](/ja/user-guide/campaigns-and-channels/web-push/getting-started-with-web-push/web-push-permission-and-reachability#browser-permission-versus-os-level-notification-settings)を参照してください。
</Note>

ターゲットユーザーを選択する段階から、ユーザーが Web プッシュ通知を受け取る段階までのファネル別の分析は、Campaign Reports で確認できます。

この記事では、**2023 年 3 月以降に見られる Web プッシュ購読者総数の減少の問題**について詳しく説明します。

# どのような問題ですか？

2023 年 2 月から 3 月以降、MoEngage SDK を連携していないウェブサイトも含め、ほとんどのウェブサイトで Web プッシュ購読者が減少していることが確認されました。

次の事象が確認されました。

- Web プッシュ購読者数の減少。

- プッシュトークンが FCM によって誤って「Not Registered」とマークされることがあり、送信失敗が増加している。
- 特定の日付に「Unsubscribed to web push」イベントが大量に発生している。

# なぜこの問題が発生しているのですか？

- 他の複数のウェブサイトからも同様の報告があります。
- [Chromium 109.0.5414.22 リリース](https://www.gitclear.com/open_repos/chromium/chromium/release/109.0.5414.22)の一環として、[アプリレベルの権限に関する変更](https://github.com/chromium/chromium/commit/a14acf5afd8b6d024003d8ad29e3740703d399b8)が行われました。
- これにより、ユーザーのデバイスで Chrome ブラウザーに通知を送信する権限（アプリレベルの権限）がない場合、ユーザーがウェブサイトで権限を許可していても（サイトレベルの権限）、ブラウザーは 3 日間の猶予期間後にプッシュトークンを無効にします。

# 新しいシステムでのユーザーの動作はどうなりますか？

- ウェブサイトの新規ユーザーの場合、アプリレベルの権限がオフになっていると、サイトレベルの権限を付与するための「Hard ask」の表示がブロックされます。
- サイトレベルの権限を持つ既存ユーザーの場合、アプリレベルの権限がオフになった後にユーザーがサイトを開くと、ブラウザーは 3 日間の猶予期間後にプッシュトークンを無効にします。
- 3 日後にユーザーが再度サイトにアクセスすると、次のことが発生します。

    - MoEngage Web SDK が「Unsubscribed to web push」イベントをトリガーします。
    - MoEngage Web SDK がそのユーザーの Web Push トークンを削除します。
    - Chrome がブラウザーの権限を「Ask」または「Blocked」に設定します。
    - 3 日後にユーザーがサイトに戻らず、このデバイスに通知を送信しようとすると、「Not registered」エラーが発生する場合があります。この動作については Chromium や FCM のドキュメントに具体的な記載はなく、このような場合に「not registered」エラーが表示されるまでに時間がかかることもあります。それまでの間、この顧客に対する通知は正常に送信・配信されたものとしてマークされます。
    - 現時点では、Chrome はウェブサイトが Chrome のアプリレベルの権限を読み取ることを許可していないため、MoEngage は次の操作を事前に行うことができません。

            - サイトレベルの権限のリセット
            - アプリレベルの権限を有効にするようユーザーに促すこと
            - 購読解除の理由としてデバイスレベルの権限を追跡すること
            - ソフトアスクの表示

# この変更は自分のユーザーに適用されていますか？

影響は、新しいシステムを使用しているユーザーの数によって異なります。

- ユーザーが Chrome 110 以降を使用している必要があります。
- これは段階的なロールアウトであり、最新バージョンの Chrome を使用しているユーザーであっても、地域によってはこの変更がまだ適用されていない場合があります。
- これまでのところ、この変更はアカウントによって影響が異なり、Chrome が一部のユーザーに対してこの変更をロールアウトするリリース日があることが確認されています。多くの購読解除が発生した「ピーク時」が 1 回以上確認されたアカウントがあり、その結果、全体の購読解除率がわずかに増加しました。

# どのような影響がありますか？

以下は一般的な観察結果であり、アカウントによって動作が異なる場合があります。

- 「ピーク時」の後、**Web プッシュ購読者はおよそ 30% 減少します**。
- Web プラットフォームのみを対象とするプッシュキャンペーンでは、送信数とインプレッション数が減少する可能性がありますが、**配信率はほぼ変わりません。**
- この変更はアプリレベルの権限がオフになっているデバイスにのみ影響するため、影響を受けるのはもともと通知を表示できなかったユーザーのみであり、キャンペーンから得られるエンゲージメントには影響しません。**CTR が上昇する**場合があります。
- Android や iOS プラットフォームのプッシュ到達可能性や、Web 上のユーザーデータの追跡には影響しません。

この変更について、Chromium 開発チームに問い合わせました。チームは引き続きこの機能を監視しており、最近のリリースで問題を確認しているため、今後変更を加える予定です。これは Chromium チームによる反復的な変更となり、サイトレベルとアプリレベルの権限の連動方法について、さらに変更が加えられる可能性があります。

## 文字数制限

通知のタイトルとメッセージの長さは、画面サイズ、幅、入力言語など、さまざまな要因によって異なります。デバイスごとに異なる場合があります。

**許容されるデータの合計上限は 4 KB です。** 文字数がデバイスタイプに適した上限を超えると、そのデバイスに配信されたときにタイトルやメッセージが切り詰められて (末尾に ... が付いて) 表示される場合があります。

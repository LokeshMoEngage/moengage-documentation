## 問題

イベントはエクスポートできるにもかかわらず、特定のプッシュキャンペーンで NOTIFICATION\_SENT\_ANDROID イベントを送信できません。

## 解決策

次の手順を実行してください。

- プッシュキャンペーンがエンドユーザーに送信されたことを確認します。
- Amazon S3 (Simple Storage Service) または Streams のエクスポートを確認し、プッシュキャンペーンのイベントが存在するかどうかを確認します。
- この問題が解決されると、既存の Inform キャンペーンのイベントも更新されます。

<Warning>
NOTIFICATION\_SENT\_ANDROID イベントは、Inform アラートのプッシュキャンペーンではサポートされていません。
</Warning>

## 問題

Web プッシュ通知でディープリンクが機能しません。

## 解決策

1. リンクが正しいリソースに解決されることを確認します。
2. ディープリンクのアプリレベルのリダイレクトが正しく構成されていることを確認します。

<Info>
  **情報**

  パネルの色やスタイルをカスタマイズするには、メニューから目的のオプションを選択します。
</Info>

Chrome は、Web プッシュ購読に Quieter permissions を導入することを発表しました。これは、多くのウェブサイトがユーザージャーニーの中で文脈に沿ったタイミングではなく初回訪問時に通知の権限を要求し、結果として悪いユーザーエクスペリエンスを与えているという、ユーザーからのよくある苦情に対処するためのものです。

Chrome バージョン 80 以降、Chrome は最初のページ読み込み時（Web 訪問時）に邪魔になる Web プッシュのオプトイン権限を表示せず、代わりにデフォルトでブロックします。ユーザーは必要に応じてこれを上書きできます。これは Quieter permissions と呼ばれ、ブラウザーのデスクトップ版とモバイル版の両方で利用できます。以下は動作の例です。

![First Run Desktop Mobile Together](/images/First-Run-Desktop-Mobile-Together.gif)

Chrome バージョン 80 は 2020 年 2 月 4 日に一般公開され、Chrome ユーザーはブラウザーの設定セクションから Quieter permissions を有効にできるようになります。以下のケースでは、Quieter permissions がデフォルトで有効になります。

1. Chrome ブラウザーで、さまざまなウェブサイトの通知を繰り返しブロックしているユーザー
2. Chrome ブラウザープラットフォーム全体でオプトイン率が非常に低いウェブサイト

そのため、Web プッシュ購読に 1 ステップのオプトインを使用している場合、2020 年 2 月 4 日以降、新規購読が大幅に減少する可能性があります。このような事態を避けるため、Web Push 設定に移動し、2 ステップのオプトインまたはセルフハンドルのオプトインに変更してください。2 ステップのオプトインとセルフハンドルの文脈に沿ったオプトインは、どちらも通知の権限リクエストに必要な文脈を提供し、ユーザーにとって関連性の高いものにします。オプトイン方法を変更する手順については、[こちらをクリック](/ja/developer-guide/web-sdk/web-push/configure-self-handled-opt-in)してください。

この記事では、Google Chrome でウェブサイトのオプトイン権限をクリアする手順について説明します。

## HTTP サイトからのオプトイン

1. HTTP サイトにアクセスし、ブラウザーで右クリックして **Inspect** -\> **Application** -\> **Local Storage** に移動します。ローカルストレージにあるものをすべてクリアします。
2. オプトイン権限は HTTPS ドメインでのみ付与できるため、オプトインには独自の HTTPS ドメインまたは yoursitename.moengage.com を使用している必要があります。別のタブでこのサイトにアクセスし、ローカルストレージにあるものをすべてクリアします。
3. 同じサイトで、アドレスバーの鍵アイコン（Secure）をクリックし、Notifications を「Use global default」に変更します。ウェブサイトに入った後、ページの再読み込みを求められます。
4. ページを再読み込みします。これでこのウェブサイトを閉じてかまいません。
5. HTTP ページを再読み込みすると、オプトインプロンプトが表示されるはずです。

## HTTPS サイトからのオプトイン

1. HTTPS サイトにアクセスし、ブラウザーで右クリックして **Inspect** -\> **Application** -\> **Local Storage** に移動します。ローカルストレージにあるものをすべてクリアします。
2. アドレスバーの鍵アイコン（Secure）をクリックし、Notifications を「Use global default」に変更します。ウェブサイトに入った後、ページの再読み込みを求められます。
3. ページを再読み込みします。オプトインプロンプトが表示されるはずです。

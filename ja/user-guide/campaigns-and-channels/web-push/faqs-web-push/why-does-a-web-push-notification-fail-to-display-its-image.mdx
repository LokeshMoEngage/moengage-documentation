## 問題

Web プッシュ通知で画像が表示されません。

## 解決策

1. 画像の更新が完了し、正しく表示されていることを確認します。
2. 画像 URL を使用している場合は、URL を検証し、画像が正常に読み込まれることを確認します。

新しいブラウザタブで URL を開くことで確認できます。

プッシュ通知は、トークンの有効期限切れや、プッシュメッセージが大きすぎてプッシュサービスで処理できないなど、さまざまな理由で失敗することがあります。以下に、最も頻繁に発生するエラーとその理由を示します。

| エラーまたは代替エラー | 説明 |
| --- | --- |
| Unregistered  別名:<br />- Gone<br />- Not Found | 既存の登録トークンは、次のようなさまざまなシナリオで無効になる場合があります。<br />- 登録トークンの有効期限が切れた場合<br />- クライアントアプリが更新されたが、新しいバージョンがメッセージを受信するように構成されていない場合<br />- デバイスが非アクティブな場合 |
| Sender temporarily  別名:<br />- unavailable<br />- Internal Error<br />- Internal Server Error from FCM Service<br />- Temporary Error from FCM Service<br />- The request timed out - Unknown server error | 送信元サーバーがリクエストの処理中に内部エラーを起こしたか、一時的に利用できない状態です。 |
| Authorization Error  別名:<br />- Bad Authorization<br />- Forbidden | APNS または Web Push の認証キーが無効であるか、有効期限が切れています。プッシュの認証設定を確認してください。 |
| Invalid Vapid Details | Web Push 用に生成された Vapid キーが誤っているか無効です。Web SDK の統合を確認するか、MoEngage のカスタマーサクセスマネージャー (CSM) またはサポートチームにお問い合わせください。 |

## 問題

キャンペーンのセグメンテーション数ではリーチ可能ユーザーが N と表示されますが、送信数は N を超えています。

## 解決策

次の手順を実行してください。

1. セグメンテーションではユニークユーザー数が表示されますが、プッシュキャンペーンはユニークユーザーのすべてのアクティブなデバイストークンに送信されます。  
    <img alt="送信数 1.png" src="/images/moengage_ef9172.png" />
2. 複数のデバイスを持つユーザーの場合、プッシュ通知はセグメンテーション数 (ユニークユーザー) ではなく、リーチ可能なすべてのデバイス (アクティブなトークンの数に基づく) に送信されます。   
    <img alt="送信数 2.png" src="/images/moengage_13424e.png" />

<Info>
複数のデバイスを持つユーザーは、iOS デバイスと Android デバイスを任意の数だけ持つことができます。
</Info>

## 問題

キャンペーンが幅広いユーザーにリーチしエンゲージしているにもかかわらず、プッシュメッセージが送信されませんでした。

## 原因

この問題は、ユーザーが DND (Do Not Disturb) 期間中である場合、フリークエンシーキャッピング (FC)、またはキャンペーンレベルの最小遅延が原因で発生する可能性があります。

## 解決策

- この問題を解決するには、セグメンテーション条件を変更する際にネストされたフィルターを削除します。
- ユーザーがセグメントに含まれていることを確認します。
- キャンペーンのステータスが停止または一時停止に設定されていないことを確認します。

<Warning>
ネストされたフィルターは Smart Trigger キャンペーンではサポートされていません。
</Warning>

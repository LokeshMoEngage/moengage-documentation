画像サイズはターゲティングによって異なります。以下に、モバイルとデスクトップのターゲティングにおける最適な画像サイズとアスペクト比を示します。

**デスクトップの場合** - 画像は幅 360px、高さ 180px 以上で、アスペクト比は 2:1 にする必要があります

**モバイルの場合** - 画像は幅 720px、高さ 240px 以上で、アスペクト比は 3:1 にする必要があります

コンテナのサイズに応じて、大きい画像は縮小され、小さい画像は引き伸ばされます。  
  
同じキャンペーン内でモバイルユーザーとデスクトップユーザーに異なる画像をターゲティングする場合は、モバイルユーザー用とデスクトップユーザー用に異なるロケールを作成することをお勧めします。これにより、Web キャンペーンの設定時に、設定した各ロケールで異なる画像を使用するオプションが表示されます。

たとえば、"Web Push Subscription Status is True AND Mobile User is True" というロケールをモバイルユーザー用に設定し、キャンペーン作成時に、作成したロケールのメッセージ内でアスペクト比 3:1 の画像を選択できます。

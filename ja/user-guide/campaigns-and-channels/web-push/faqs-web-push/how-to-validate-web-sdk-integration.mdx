ウェブサイトのユーザーを追跡する前に、MoEngage Web SDK をウェブサイトに連携する必要があります。すべての連携手順を完了すると、[MoEngage Assist](https://chrome.google.com/webstore/detail/moengage-sdk/dhggnkfnnoebbfofpimfehcklnekmbgi) を使用して連携をその場でチェックし、利用を開始できます。

## MoEngage Assist 拡張機能の仕組み

1. Chrome ウェブストアから Google Chrome ブラウザーに [MoEngage Assist 拡張機能](https://chrome.google.com/webstore/detail/moengage-sdk/dhggnkfnnoebbfofpimfehcklnekmbgi)をインストールします。
2. MoEngage SDK が連携されているウェブサイトを開きます。MoEngage Assist 拡張機能のアイコンが青色に変わります。
3. アイコンをクリックすると、すべての連携手順のステータスを示すモーダルが開きます。すべての手順を実施したかどうかを確認します。

## MoEngage Assist の機能

- SDK が連携されているページでのみ有効になります。
- すべての設定に関する基本情報を表示します。
- 設定を強制的に取得できます（更新まで 24 時間待つ必要はありません）。
- `serviceworker` の連携におけるエラーを表示します。
- 追跡されたイベントと属性のリストを表示します。
- デバイスが追加されているかどうか（ユーザーが作成/購読済みかどうか）を通知します。
- 任意のイベントを追跡できます。
- 任意の属性を追加できます。
- On-site messaging（OSM）と Web Personalization が有効かどうかを通知します。
- On-site キャンペーンのリストとそのトリガー条件を読みやすい形式で表示します。
- Web Personalization キャンペーンのリストとそのトリガー条件を読みやすい形式で表示します。
- On-site および Web Personalization キャンペーンを強制的に取得できます（更新まで 15 分待つ必要はありません）。

マーケターの目標は、エンゲージメントとコンバージョンを促進することです。Google の [Android 版 Chrome 向けの新しいスパムフィルター](https://blog.chromium.org/2025/05/fighting-unwanted-notifications-with.html)は、スパムと判断した通知を非表示にするため、この目標の達成に直接影響します。このガイドでは、キャンペーンのパフォーマンスを守り、メッセージが確実に表示されるようにする方法について説明します。

## スパムフィルターがキャンペーンに与える影響

Chrome が通知のいずれかにフラグを付けると、オーディエンスには丁寧に作成したメッセージが表示されず、代わりに警告プロンプトが表示されます。

### ステップ 1: 警告プロンプト

ユーザーには、2 つのオプションを含む一般的な警告が表示されます。

- **Unsubscribe**: ワンタップで購読者リストから離脱します。
- **See Notification**: ユーザーはコンテンツを表示するために追加の操作を行う必要があります。

<img alt="chrome.png"  src="/images/moengage_97e99f.png"  />

### ステップ 2: 通知の表示

ユーザーが通知を表示することを選択すると、メッセージが 2 つの新しいオプションとともに表示されます。

- **Always allow**: ユーザーはサイトをホワイトリストに登録でき、今後の通知は警告なしで通常どおり配信されます。
- **Unsubscribe**: オプトアウトのオプションも引き続き利用できます。

<img alt="chrome2.png"  src="/images/moengage_50cfa8.png"  />

このプロセスによりユーザーの制御権が強まるため、マーケターは高品質で関連性の高いコンテンツを送信することが重要になります。

## フィルターがトリガーされる主な要因

分析によると、フィルターは主に次の 3 つの領域に敏感です。

- **通知コンテンツ**: フィルターはキーワード、言い回し、絵文字を精査します。クリックベイト、緊急性の高い言葉、曖昧な表現は大きな危険信号です。
- **個々のユーザー履歴**: ユーザーがドメインからの通知を頻繁に閉じたり無視したりすると、そのユーザーに対する今後のメッセージにフラグが付けられる可能性が高くなります。
- **メッセージの繰り返し**: 同じ通知をユーザーに繰り返し送信すると、フィルターがコンテンツを非表示にする強いシグナルとなります。

## フラグを付けられないためのベストプラクティス

対応するには、コンテンツの品質と継続的なテストに重点を置いた戦略が必要です。

- **明確で誠実なコンテンツを作成する**
  - **扇情的な表現を避ける**: 目標は価値を提供することであり、ユーザーをだましてクリックさせることではありません。
  - **スパムと判断されやすいキーワードを避ける**: 「FREE」、「WIN」、「URGENT」、「ACT NOW」などの言葉は避けてください。
  - **具体的にする**: テストでは、「Klean Beauty to Cart Delivery!」のような曖昧なタイトルは一貫してブロックされましたが、「Your Klean Beauty order now qualifies for free delivery」は問題なく表示されました。
- **システムアラートを装わない**
  - 通知を公式のシステムや OS のメッセージのように見せないでください（例: 「Your system may be at risk」）。Chrome はこれを検出してペナルティを科すように特別にトレーニングされています。
- **厳密かつ継続的にテストする**
  - **メッセージの変動性**: 一度表示されたメッセージが、再度表示されるとは限りません。
  - **自分のデバイスでテストする**: キャンペーンの前に、Android のテストデバイスに通知を複数回送信してください。一度でも非表示になった場合は、コンテンツを修正してください。
  - **問題のある言葉を特定する**: テストでは、「FREE」のような単語を 1 つ削除するだけで、通知のブロックが解除される場合があることがわかりました。これはフィルターの感度の高さを示しています。
- **メッセージをパーソナライズし、変化を持たせる**
  - **関連性のないメッセージ**: 画一的な一斉配信は多くのユーザーにとって関連性がないため、マイナス要因になります。
  - **繰り返しを避ける**: 同じユーザーにまったく同じコンテンツを繰り返し送信しないでください。
  - **セグメント化とパーソナライズ**: MoEngage を使用して、ユーザーの行動や好みに基づいた関連性の高いメッセージを送信してください。
- **キャンペーン分析を監視する**
  - MoEngage UI を注意深く確認してください。購読解除率の急上昇や CTR の低下は、キャンペーンにフラグが付けられていることを示している可能性があります。

## 重要なポイント: 戦略を進化させる

この機能は、Web プッシュ通知における根本的な変化を表しています。機械学習モデルは常に進化し続けることを忘れないでください。今日有効な戦略が、明日も有効とは限りません。  
品質に重点を置き、継続的にテストし、ユーザーを尊重してください。真の価値を提供することで、信頼を築き、メッセージが確実に届き続けるようにできます。

## よくある質問

<Accordion title="どのデバイスが影響を受けますか？">

現在、このフィルターは Android 版 Google Chrome で有効になっています。

</Accordion>
<Accordion title="通知がブロックされた場合、コールバックはありますか？">

いいえ。フィルターはデバイス上で動作するため、MoEngage SDK やウェブサイトにシグナルは送信されません。

</Accordion>
<Accordion title="フラグが付けられた通知のインプレッションは追跡されますか？">

はい。通知が警告プロンプトの背後に非表示になっている場合でも、配信時にインプレッションがカウントされます。

</Accordion>
<Accordion title="プロンプトからの購読解除はどのように追跡されますか？">

このイベントはリアルタイムでは追跡されません。MoEngage がユーザーを購読解除済みとして識別できるのは、そのユーザーが次回ウェブサイトにアクセスしたときのみです。

</Accordion>
<Accordion title="ウェブサイト全体の評判が悪くなりますか？">

モデルは、ドメインに対する個々のユーザーの履歴から学習します。多くのユーザーが購読を解除したりメッセージを無視したりすると、オーディエンスに効果的にリーチすることが難しくなります。

</Accordion>

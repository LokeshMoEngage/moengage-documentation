Web Push キャンペーンは強力なツールです。これは、受信にオプトインした顧客に送信されるウェブサイト通知です。MoEngage を活用して、Web Push キャンペーンをレベルアップしましょう。

MoEngage Web Push の詳細については、次のページを参照してください:

1. [Web Push 設定の構成](/ja/user-guide/campaigns-and-channels/web-push/getting-started-with-web-push/configure-web-push-settings)
2. [Web Push キャンペーンの作成](/ja/user-guide/campaigns-and-channels/web-push/create/create-web-push-campaign)
3. [Web Push キャンペーン分析](/ja/user-guide/campaigns-and-channels/mobile-push/analyze/push-analytics-and-info)

<Info>
  iOS デバイスの Safari で Web Push を機能させるには、次の要件を満たす必要があります:

  - ウェブサイトが Progressive Website App (PWA) であること。
  - Web アプリのマニフェストファイルが作成され、リンクされていること。
  - MoEngage のサービスワーカーファイルがインポートされ、ルートフォルダに配置されていること。
  - PWA がホーム画面に追加されていること。
  - Web プッシュ通知の受信許可をユーザーに求めること。2 ステップのオプトインプロセスを推奨します。

  詳細については、[iOS および iPadOS の Safari 向け Web Push 統合手順](/ja/developer-guide/web-sdk/web-push/safari-web-push-for-i-os-and-i-pad-os)を参照してください。
</Info>

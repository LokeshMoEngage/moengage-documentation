Recommendations ページでは、作成したレコメンデーションを管理できます。レコメンデーションのステータスは一覧ページ上に表示されます。レコメンデーションの編集、アーカイブ、アーカイブ解除を行えます。

# レコメンデーションの編集

レコメンデーションを編集するには、次の手順を実行します。

1. MoEngage のサイドバーメニューで、Content メニュー項目 <img alt="content icon.png"  src="/images/moengage_74beb9.png"  /> にカーソルを合わせます。**Content** メニューが表示されます。
2. **Recommendations** をクリックします。   
    <img  src="/images/moengage_8bda2f.png"  />   
   Recommendations ページが表示されます。
3. 編集するレコメンデーションの鉛筆アイコンをクリックします。Edit Recommendation ページが表示されます。  
    <img src="/images/moengage_04e53e.png" />
4. 更新する設定を選択して必要な変更を行い、ページ下部の **Save** をクリックします。

変更を保存する前に、いくつかのサンプルユーザーで結果をテストすることをお勧めします。

# アーカイブまたはアーカイブ解除

Recommendations ページの **Actions** 列にある **Archive** アイコンをクリックすると、アクティブなレコメンデーションを無効にできます。 <img src="/images/moengage_ba58a4.png" />

**Actions** 列にある **Unarchive** アイコンをクリックすると、アーカイブされたレコメンデーションを有効にできます。 <img src="/images/moengage_3be281.png" />

# 結果のテスト

レコメンデーション設定の下部に、**Test recommendation** オプションがあります。顧客の一意の MoEngage ID を入力し、**Show results** をクリックすると、その時点でのユーザーの結果を確認できます。

<img src="/images/moengage_bf60a3.png" />

以前に作成したレコメンデーションの結果をテストするには、Recommendations ページに移動し、対象のレコメンデーションの鉛筆アイコンをクリックします。レコメンデーション設定が表示されるので、下にスクロールして結果をテストします。

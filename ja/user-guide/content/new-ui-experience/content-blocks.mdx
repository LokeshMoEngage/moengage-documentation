コンテンツブロックを使用すると、同じコンテンツを複数のキャンペーンで再利用できます。たとえば、よく使用するヘッダー、フッター、コールトゥアクションボタンなどをブロックにできます。

コンテンツブロックでは、次のことが可能です。

- **一貫性の維持**: すべてのキャンペーンで同じヘッダー、フッター、ブランドアセットを使用できます。
- **アセットの再利用**: あらゆるチャネルやキャンペーンタイプで使用できる定義済みのアセットを作成できます。
- **大規模な更新**: ソースとなるコンテンツブロックを更新することで、複数のキャンペーンを同時に編集できます。

# コンテンツブロックの作成

新しいコンテンツブロックを作成するには、次の手順を実行します。

1. MoEngage のサイドバーメニューで、**Content** メニュー項目 <img alt="content icon.png"  src="/images/moengage_24b340.png"  /> にカーソルを合わせます。**Content** メニューが表示されます。
2. **Content Blocks** をクリックします。   
    <img  src="/images/moengage_4cced1.png"  />   
   Content blocks ページが表示されます。
3. 右上の **Create content block** をクリックします。コンテンツブロックページが表示されます。
4. 次の詳細を入力します。 <img alt="create content block_new UI.png" src="/images/moengage_2b8d6a.png" />   
     

   | フィールド | 説明 |
   | --- | --- |
   | **Teams** | 組織でチームが有効になっている場合は、ドロップダウンからチームを選択します。 |
   | **Name** | 一意の名前を入力します。この名前は、キャンペーン、テンプレート、アラートでブロックを識別するために使用されます。英数字とアンダースコアを使用してください。 |
   | **Description** | ブロックに含まれる内容と、使用すべき場所についての説明を入力します。 |
   | **Tags** | ブロックを分類するためのタグを追加します。既存の[キャンペーンタグ](/ja/user-guide/campaigns-and-channels/getting-started/introduction/campaign-tags)を使用できます。 |
   | **Communication Type** | コミュニケーションの種類です。サポートされている値は次のとおりです。 - Engage - Inform |
   | **Content block type** | コンテンツブロックの種類です。サポートされている値は次のとおりです。 - **Plain text**: テキストベースのコンテンツブロックは、すべてのキャンペーンチャネルでサポートされています。 - **HTML**: HTML コンテンツブロックは、Email、In-App、Personalize でサポートされています。ユースケースに応じて種類を選択してください。たとえば、シンプルなクーポンコード(スタイルなし)には Plain text タイプを、メールのヘッダー/フッターには HTML タイプを使用できます。 |
   | **Content** | コンテンツブロックの内容を入力します。 - キャンペーンの場合: @ を入力して、キャンペーン向けにコンテンツをパーソナライズします。 - アラートの場合: **Text personalization** ボタンをクリックして、アラート向けにコンテンツをパーソナライズします。 |
5. **Publish** をクリックします。   
   コンテンツブロックはパーソナライズすることもできます。詳細については、[コンテンツブロックを使用したコンテンツのパーソナライズ](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/personalize-content-using-content-blocks)を参照してください。

# コンテンツブロックの管理

次のオプションを使用してコンテンツブロックを検索できます。

- **名前またはラベルで検索**: 名前またはラベルでブロックを検索します。
- **Select updated by**: ブロックを最後に更新したユーザーで結果を絞り込みます。
- **Content type**: コンテンツタイプで結果を絞り込みます。
- **Filter**: Type、Teams、Status、Tags、またはブロックを最後に更新したユーザーで結果を絞り込みます。

ページ上のアイコンを使用して、好みに応じてリストビューとグリッドビューを切り替えることができます。

Content blocks ページでは、次のフィールドを使用できます。

| フィールド | 説明 |
| --- | --- |
| **Name** | コンテンツブロックに付けられた一意の名前を表示します。 |
| **Content type** | ブロックが Plain text か HTML かを示します。 |
| **Status** | ブロックの現在の状態(例: Published または Draft)を示します。 |
| **Teams** | ブロックが属する特定のチームを示します。 |
| **Updated by** | ブロックを最後に変更したユーザーを表示します。 |
| **Usage** | 現在このブロックを使用しているアクティブなキャンペーン、アラート、テンプレートの数を示します。 |

## コンテンツブロックの表示

コンテンツブロックを表示するには、次のようにします。

- コンテンツブロック一覧の行末にある3点アイコンをクリックし、**View** を選択します。
- または、行の任意の場所をクリックしてプレビューを開きます。

プレビューウィンドウでは、ブロックの設定と顧客への表示内容を包括的に確認できます。次のタブとオプションが含まれます。

- **Web** ビューと **Mobile** ビューを切り替えて、さまざまなデバイスでのコンテンツの表示を確認できます。
- プレビュー画面から直接 **Edit** および **Duplicate** オプションにアクセスできます。
- **Details タブ**には、次のようなブロックのメタデータが表示されます。  
  - **Block label**
  - **Communication type**
  - **Content type**
  - **Updated by**
  - **Teams**
  - **Description**
- **Content blocks** タブには、このブロックがより大きなコンテンツ構造の一部である場合に、ネストされたブロックの名前と種類が表示されます。 <img alt="view content block_new UI.png" src="/images/moengage_94033e.png" />

## コンテンツブロックの編集

コンテンツブロックを編集するには、次のようにします。

- コンテンツブロック一覧の行末にある3点アイコンをクリックし、**Edit** を選択します。または、行の任意の場所をクリックしてプレビューを開き、プレビューページで **Edit** オプションをクリックします。
- 編集ページでは、**Teams**、**Name**、**Description**、**Tags**、**Content** フィールドを変更できます。

<Info>
ブロックの作成後に **Communication type** または **Content block type** を変更することはできません。
</Info>

## コンテンツブロックの複製

コンテンツブロックを複製するには、次のようにします。

- コンテンツブロック一覧の行末にある3点アイコンをクリックし、**Duplicate** を選択します。
- 複製ページで **Publish** をクリックします。

新しいブロックには、先頭に **Duplicate** が付きます。

## コンテンツブロックの削除

コンテンツブロックを削除するには、次のようにします。

- コンテンツブロック一覧の行末にある3点アイコンをクリックし、**Delete** を選択します。
- 表示される確認メッセージで **Delete** をクリックします。

ブロックを削除できるのは、アクティブなキャンペーンで現在使用されていない場合のみです。

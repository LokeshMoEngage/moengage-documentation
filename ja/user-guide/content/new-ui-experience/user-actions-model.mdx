# はじめに

User Actions レコメンデーションモデルは、ユーザー行動を利用して、ルールベースのパーソナライズされたレコメンデーションを作成します。カート放棄、ウィッシュリスト、その他特定の商品やサービスへの関心を示す行動など、ユーザーが強い意図を示している場合に効果的です。User Action レコメンデーションには、企業にとって次のようなメリットがあります。

- パーソナライズされたエンゲージメント
- 精度の高いターゲティング
- 再エンゲージメントの機会

### ユースケースの例

- カート放棄のリマインダーで失われた売上を回復する。
- 再入荷アラートを受け取り、機会を逃さない。
- ユーザーのウィッシュリストに基づくパーソナライズされたキャンペーンでエンゲージメントを高める。
- 最近閲覧したアイテムでユーザーを再エンゲージする。
- さりげない後押しでリピート購入を促進する。

<Tip>
続行する前に、ユーザーアクションをマッピングし、カタログを追加する必要があります。詳細については、[ユーザーアクション](/ja/user-guide/content/recommendations/getting-started/map-user-actions-settings)および[カタログ](/ja/user-guide/content/recommendations/getting-started/catalogs)を参照してください。
</Tip>

# ユーザーアクションレコメンデーションの作成

<Info>
レコメンデーションを作成できるのは、Admin / Manager / Marketer ロールのみです
</Info>

ユーザーアクションレコメンデーションを作成するには、次の手順を実行します。

1. MoEngage のサイドバーメニューで、Content メニュー項目 <img alt="content icon.png"  src="/images/moengage_14d0ec.png"  /> にカーソルを合わせます。**Content** メニューが表示されます。
2. **Recommendations** をクリックします。   
    <img  src="/images/moengage_100d91.png"  />   
   Recommendations ページが表示されます。
3. **+ Create recommendation** をクリックします。 <img src="/images/moengage_52078a.png" />
4. **User Actions** モデルを選択し、**Next** をクリックします。 <img src="/images/moengage_0fe234.png" />
5. **Recommendation name** フィールドに、レコメンデーションの名前を入力します。
6. **Recommendation description** フィールドに、レコメンデーションの説明を入力します。
7. **Catalog** ドロップダウンリストで、レコメンデーションの取得元となる適切なカタログを選択します。
8. **Item where user performed** ドロップダウンリストから、ユースケースに基づいて適切なユーザーアクションを選択し、アクティビティの期間を定義します。たとえば、過去 7 日間に実行された Added to wishlist などです。特定の種類のインタラクション済みアイテムを除外することもできます。  
    <img src="/images/moengage_c4b894.png"  />
9. **Filter items by item attributes** トグルをオンにすると、フィルター条件を追加して、顧客にどのアイテムをレコメンドするかを制御できます。これらのフィルターは、User Action モデルのレコメンデーションに適用されます。 <img src="/images/moengage_ad52a7.png" />
10. **Sort the filtered items** セクションで、任意の数値属性(例: 価格)でレコメンデーション結果を並べ替えます。  
     <img src="/images/moengage_576be6.png"  />
11. **Save** をクリックします。レコメンデーションが作成され、Recommendations ページに 'Active' 状態で表示されます。

カート放棄やウィッシュリストのアイテムなど、特定のユーザーアクションを活用することで、企業はユーザーを再エンゲージし、コンバージョンを促進できます。

フィルター

フィルター設定を使用すると、カタログで利用可能な情報に基づいて、顧客に表示されるレコメンデーションを絞り込むことができます。これらのフィルターは User Action モデルの出力をカスタマイズし、提案されるアイテムの関連性を高めます。

### ユースケースの例

- 現在在庫切れのアイテムを除外したカート放棄リマインダーで、失われた売上を回復する。
- セール中のウィッシュリストアイテムをレコメンドする。
- 特定のブランドの最近閲覧したアイテムをレコメンドする。

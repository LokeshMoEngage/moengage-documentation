<Info>
レコメンデーションを作成できるのは、Admin / Manager / Marketer ロールのみです
</Info>
<Tip>
続行する前に、ユーザーアクションをマッピングし、カタログを追加する必要があります。詳細については、[ユーザーアクション](/ja/user-guide/content/recommendations/getting-started/map-user-actions-settings)および[カタログ](/ja/user-guide/content/recommendations/getting-started/catalogs)を参照してください。
</Tip>

レコメンデーションを作成するには、次の手順を実行します。

1. MoEngage のサイドバーメニューで、Content メニュー項目 <img alt="content icon.png"  src="/images/moengage_247c78.png"  /> にカーソルを合わせます。**Content** メニューが表示されます。
2. **Recommendations** をクリックします。  
    <img  src="/images/moengage_054d37.png"  />   
   Recommendations ページが表示されます。
3. **+ Create recommendation** をクリックします。Create recommendation ページが表示されます。 <img src="/images/moengage_82987a.png" />
4. ユースケースに応じて適切なモデルを選択し、**Next** をクリックします。  
    <img src="/images/moengage_69c183.png" />
5. **Recommendation name** フィールドに、レコメンデーションの名前を入力します。
6. **Recommendation description** フィールドに、レコメンデーションの説明を入力します
7. **Catalog** ドロップダウンリストで、レコメンデーションの取得元となる適切なカタログを選択します。  
   **注:** すべての AI レコメンデーションは 1 つのカタログを参照します。いずれかの AI レコメンデーションでカタログを使用すると、そのカタログは他のすべての種類の AI レコメンデーションにも自動的に設定されます。
8. ユースケースに基づいて、ドロップダウンリストから適切な **user actions** を選択します。
   - Similar items、Frequently bought together items、Frequently viewed together items の場合、設定したユーザーアクションイベントに基づく最新のアイテムを使用してレコメンデーションが生成されます。
   - Recommended items の場合、ユーザーアクションを設定する必要はありません。ユーザーが実行したすべてのユーザーアクションが考慮されて行動パターンが自動的に学習され、個人の変化する興味に合わせたレコメンデーションが生成されます。
9. **Filter items by user actions** トグルをオンにすると、フィルター条件を追加して、顧客にどのアイテムをレコメンドするかを制御できます。これらのフィルターは、コアレコメンデーションの結果にさらに適用されます。ユーザーアクションには 2 種類のフィルターがあります。  
    <img alt="user action filter.png" src="/images/moengage_961199.png" />
   - **Select user action to keep items**: マーケターは、フィルタリング用のユーザーアクション条件とレコメンデーション結果の両方に共通するアイテムのみを含めるユーザーアクション条件を定義できます。**+ User actions** をクリックし、含めるアイテムを選択します。
   - **Select user action to remove items**: マーケターは、フィルタリング用のユーザーアクション条件に従ってレコメンデーションアイテムからアイテムを除外するユーザーアクション条件を定義できます。**+ User actions** をクリックし、除外するアイテムを選択します。
10. **Filter items by item attributes** トグルをオンにすると、カタログ情報に基づくフィルター条件を追加できます。これらのフィルターも、コアレコメンデーションの結果にさらに適用されます。 <img src="/images/moengage_4ccdd3.png" />
11. **Save** をクリックします。レコメンデーションが作成され、Recommendations ページに 'Processing' 状態で表示されます。レコメンデーションがアクティブになるまで最大 24 時間かかる場合があります。  
     <img alt="mceclip5.png" src="/images/moengage_6c48ff.png" />
12. レコメンデーションの準備ができたら、キャンペーンで使用する前にサンプルユーザーで結果をテストできます。

# ベストプラクティス

- すべてのビジネス提供物、またはレコメンデーションを生成したい提供物の種類を含むグローバルカタログを選択します。
- 関連するすべてのイベントを、適切なユーザーアクションバケットにマッピングします。
- 一意のアイテム ID 属性が、カタログ内の一意のアイテム ID と同じ情報を持っていることを確認します。
- Recommended Items の設定で、Product Viewed、Added to Wishlist、Added to Cart、Product Purchased など、考えられるすべてのユーザーとアイテムのインタラクションを設定します。これにより、アルゴリズムが幅広いユーザー行動から学習し、急速な変化に適応できるようになります。
- キャンペーンに組み込む前に、サンプルユーザーで結果をテストします。

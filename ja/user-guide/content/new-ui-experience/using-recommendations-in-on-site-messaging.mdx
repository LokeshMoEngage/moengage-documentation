# はじめに

On-site メッセージのプリセットワークフローを使用すると、購入ジャーニーのさまざまな段階や、ユーザーが関心を示したときに、商品やアイテムを提案してユーザーと自動的にインタラクションできます。これらのインタラクションポイントには、ランディングページ、訪問したページ、離脱意図、その他のパラメーターが含まれます。

MoEngage では、メールキャンペーンの作成は 3 つのステップで行います。

1. Target users
2. Content
3. Schedule and goals

2 番目のステップ 'Content' で、レコメンデーションを使用してキャンペーンコンテンツをパーソナライズできます。レコメンデーションに基づいてパーソナライズした OSM キャンペーンを作成してみましょう。

<Warning>
目的のレコメンデーションが作成済みであることを確認してください。キャンペーンのパーソナライズに使用できるのはアクティブなレコメンデーションのみです。[レコメンデーションの作成と管理](/ja/user-guide/content/recommendations)方法を確認してください。
</Warning>

# レコメンデーションを使用した OSM キャンペーンの作成

レコメンデーションを使用した OSM キャンペーンを作成するには、次の手順を実行します。

1. MoEngage のサイドバーメニューで、Engage メニュー項目 <img alt="Screenshot 2025-06-04 at 4.32.53 PM.png"  src="/images/moengage_365073.png"  /> にカーソルを合わせます。**Engage** メニューが表示されます。
2. **+ New Campaign** をクリックします。  
    <img alt="1.png"  src="/images/moengage_6ccf13.png"  />   
   **Engage** メニューの **All Campaigns** をクリックし、All campaigns ページで **+ Create campaign** をクリックすることもできます。
3. **New Campaign** ダイアログボックスの **INBOUND** で、**On-site** をクリックします。 <img   src="/images/moengage_c0968f.png"   />
4. ステップ 1 'Target users' で、キャンペーンの基本的な詳細を入力してオーディエンスを定義し、**Next** をクリックします。
5. ステップ 2 の **Content** タブで、利用可能なオプションからテンプレートを選択します。この記事の範囲では、'Text based CTA' のナッジ**テンプレート**を選択します。 <img  src="/images/moengage_5e50d1.png"  />
6. 既存のテキスト OSM テンプレートを削除し、在庫が非常に少ないアイテムを紹介するために、レコメンデーションで値をパーソナライズします。 <img  src="/images/moengage_f7c729.png"  />
7. 必要に応じて、背景色を変更したり、背景画像を追加したりできます。
8. テキストブロックに **'@'** を入力すると、パーソナライズのポップアップが開きます。データパーソナライズのドロップダウンで、目的のレコメンデーション名を検索して選択します。 <img  src="/images/moengage_44dcb9.png"  />
9. 選択したら、Jinja コードブロック内の Jinja コードを次のように更新する必要があります。

   アイテムタイトル用の JINJA

   ```
   {% if ProductSet.
   DemoOnlyFewLeft
   %}
   {% for product in ProductSet.
   DemoOnlyFewLeft
   [0:1]%}
   {{product.title}}
   {% endfor %}
   {% else %}
   MOE_NOT_SEND
   {% endif %}
   ```
10. 同様に、レコメンデーションアイテムの画像リンクを使用して次のようにパーソナライズします

    アイテム画像用の JINJA

    ```
    {% if ProductSet.
    DemoOnlyFewLeft
    %}
    {% for product in ProductSet.
    DemoOnlyFewLeft
    [0:1]%}
    {{product.image_link}}
    {% endfor %}
    {% else %}
    MOE_NOT_SEND
    {% endif %}
    ```

    <img  src="/images/moengage_64528d.png"  />
11. 次のように、CTA の Web ページリンクをパーソナライズすることもできます

    アイテム画像用の JINJA

    ```
    {% if ProductSet.
    DemoOnlyFewLeft
    %}
    {% for product in ProductSet.
    DemoOnlyFewLeft
    [0:1]%}
    {{product.link}}
    {% endfor %}
    {% else %}
    MOE_NOT_SEND
    {% endif %}
    ```

    <img  src="/images/moengage_e473d2.png"  />
12. 公開する前にキャンペーンをテストして、OSM でのレコメンデーションの配信をプレビューすることをお勧めします。テストキャンペーンの入力欄にページ URL を入力し、Test をクリックします。 <img  src="/images/moengage_0a5bb0.png"  />
13. 次のようにテスト結果をプレビューできます。 <img  src="/images/moengage_2724ad.png"  />
14. レコメンデーションを使用したコンテンツの設定が完了したら、下部の **Next** をクリックして、キャンペーン設定のステップ 3 である 'Schedule and Goals' に進みます。
15. 適切なスケジュールと配信コントロールを設定し、キャンペーンを公開します。

# 概要

Map User Action 機能を使用すると、ユーザーとアイテムのインタラクションイベントを標準のユーザーイベントに分類し、ユーザーエンゲージメントに基づくパーソナライズされたレコメンデーションを実現できます。Map User Action 機能は、ユーザーエンゲージメントイベントと、カタログ内の対応するアイテムの属性とを結び付ける役割を果たします。

<Warning>
これらの設定には、Admin/Manager のアクセスロールを持つユーザーがアクセスできます。
</Warning>

# ユーザーアクティビティイベント

行動ベースのレコメンデーションには、アイテム ID 属性を含むユーザーイベントのトラッキングが不可欠です。ユーザー行動を正確に解釈してパーソナライズされたレコメンデーションを提供するために、MoEngage ではアプリ固有のイベント名を MoEngage の標準イベントにマッピングする必要があります。

<img alt="Screenshot 2025-06-17 at 12.55.38 PM.png" src="/images/moengage_0e64d2.png" />

このマッピングプロセスにより、標準化されたイベントデータで高度なアルゴリズムとモデルを使用できるようになり、ユーザーの好みや行動に沿った正確で独自のレコメンデーションが得られます。

# ユーザーアクションイベントのマッピング

ユーザーイベントを MoEngage の標準イベントにマッピングするには、次の手順に従います。

1. MoEngage のサイドバーメニューで、Content メニュー項目 <img alt="content icon.png"  src="/images/moengage_528e7c.png"  /> にカーソルを合わせます。**Content** メニューが表示されます。
2. **Recommendations** をクリックします。  
    <img  src="/images/moengage_dbc2b7.png"  />   
   Recommendations ページが表示されます。
3. **Map user actions** をクリックします。  
    <img alt="Screenshot 2025-06-17 at 12.52.13 PM.png" src="/images/moengage_167981.png" />
4. User Action バケットの下にあるイベントのドロップダウンリストをクリックし、ドロップダウンメニューから適切なアクションを選択します。
5. 適切なイベントと、特定のアイテムとのインタラクションを表す対応する一意のアイテム ID 属性を選択します。インタラクション時のアイテムに関連する情報を持つ価格属性と数量属性をマッピングすることもできます。例:
   - イベント "**Add to Cart**" を選択します。
   - イベント属性 "**Product ID**" を選択します。
   - アイテムインタラクションのイベント属性 "**Price**" を選択します。
   - アイテムインタラクションのイベント属性 "**Quantity**" を選択します。 <img src="/images/moengage_8026fa.png"  />
6. MoEngage Recommendations は、マッピング時点以降に実行されたすべての該当イベントについて、このユーザーイベントと属性の組み合わせの受信を開始します。バケットを展開すると、イベントのマッピング時刻を確認できます。 <img src="/images/moengage_dcc326.png" />

**注:** 2024 年 2 月より前にマッピングされたイベントについては、アイテムのマッピング時刻は表示されません。

全体として、ユーザーアクションのマッピング設定は、レコメンデーションシステムがユーザー行動を理解し、アイテムとユーザーの関係を確立できるようにするため、パーソナライズされたレコメンデーションに不可欠です。

# はじめに

Coupons ページでは、マーケティングキャンペーンやフロー用のクーポンリストを作成、管理、追跡できます。キャンペーンでクーポンを確実に利用できるようにするために、クーポンリストに事前にクーポンを追加できます。

- **クーポンリスト**: システム内に保存されている、ある種類のすべてのクーポンのリポジトリです。各クーポンの使い切り型クーポンコードのみが含まれます。これらのリストは、クーポン関連のすべての操作の基盤となります。MoEngage では複数のクーポンリストを作成できるため、コードの種類やキャンペーンごとに個別のリストを管理できます。
- **クーポンファイル**: クーポンファイルをインポートすることで、既存のクーポンリストにクーポンを追加できます。クーポンファイルはダッシュボードから直接アップロードすることも、Coupons API を使用してタスクを自動化し、より効率的で合理化されたインポートプロセスを実現することもできます。この機能により、クーポンリストが常に最新の状態に保たれ、マーケティングキャンペーンですぐに使用できるようになります。

MoEngage はコードの作成を管理しません。クーポンベースのキャンペーンにおける MoEngage の役割は、使い切り型クーポンコードを割り当て、設定されたマーケティングチャネル全体に配布することです。

# 前提条件

MoEngage はプロモーションコードの配布と管理の効率化に重点を置いているため、コードの生成と利用時の検証はお客様側で実装していただく必要があります。サードパーティツールや社内システムからクーポンコードを作成し、CSV ファイルにまとめることができます。このクーポンファイルを MoEngage の Coupons プラットフォームにインポートして、クーポンベースのキャンペーンを送信できます。

# クーポンの追加

<Info>
Admin、Manager、Marketer のロールはクーポンを作成できます。クーポンリストを *Create and manage* する権限を持つカスタムロールを定義することもできます。
</Info>

## クーポンリストの作成

1. MoEngage のサイドバーメニューで、Content メニュー項目 <img alt="content icon.png"  src="/images/moengage_665ab3.png"  /> にカーソルを合わせます。**Content** メニューが表示されます。
2. **Coupons** をクリックします。  
    <img  src="/images/moengage_314e1a.png"  />   
   Coupons ページが表示されます。
3. **+ Coupon list** をクリックします。
4. **Create coupons** ページで、次の詳細を入力します: <img src="/images/moengage_385a9f.png" />
5. **Coupon List name** ボックスに、クーポンリストの一意の名前を入力します。クーポンリストに対して、クーポンの **Personalization snippet** が自動的に作成されます。このスニペットは、クーポンのパーソナライゼーションキャンペーンで Jinja プレースホルダーの参照として使用されます。クーポンリストの名前は後で変更できますが、パーソナライゼーションスニペットは変更されません。
6. **Expires on** フィールドで、対応する有効期限を定義します。この日付は、このリストに含まれるすべてのコードに適用されます。リストの有効期限が切れると、コードは MoEngage システムから削除されます。その結果、このクーポンリストを参照するキャンペーンはコードを取得できなくなります。
7. **Select Coupon file** で、システムのクーポンを含む CSV ファイルをアップロードします。クーポンリストの作成後に、さらにファイルを追加できます。CSV ファイルには *Coupon Code* というヘッダーが必要です。[サンプルファイルをダウンロード](https://cdn.moengage.com/static-files/Sample%5FCoupon%5FFile.csv)して形式を確認することもできます。
8. **File preview** で **Preview file** をクリックして、アップロード用に正しいファイルが選択されていることを確認し、正常にアップロードされたことを確認します。
9. **Alert configuration** で、クーポンリストに関連するアラートを設定して、キャンペーン中のクーポンの在庫状況を事前に管理します。アラートシステムは継続的に監視を行い、特定の条件が満たされるとメールアラートをトリガーします。アラートの受信者として最大 50 件のメールアドレスを追加できます。次の場合にアラートを送信できます。  
   - **Success**: クーポンファイルが正常に処理されたときにアラートを受け取るには、チェックボックスを選択します。
   - **Failure**: クーポンファイルの処理に失敗した場合にアラートを受け取るには、チェックボックスを選択します。
   - **Coupon Shortage**: クーポンリストが設定したしきい値を下回った場合に通知を受け取り、クーポンの追加を促すには、チェックボックスを選択します。
   - **Expiry alert**: 事前に設定した日数から、クーポンリストの有効期限までの間、毎日リマインダーを受け取るには、チェックボックスを選択します。
10. **Create** をクリックします。クーポンリストが作成され、Coupons ランディングページに *Active* ステータスで表示されます。 <img src="/images/moengage_6caa66.png" /> その後、システムがクーポンファイルの処理を開始します。処理とリストへのクーポンの追加には時間がかかる場合があります。
11. クーポンリストページで、クーポンリストのリンクをクリックして、クーポンファイルの処理ステータスを確認します。 <img src="/images/moengage_8ae53b.png" />

## クーポンの追加登録

クーポンベースのキャンペーンを継続するためにさらにクーポンを作成する場合は、クーポン生成システムからクーポンの CSV ファイルを生成し、アップロードして MoEngage のクーポンリストを補充する必要があります。

1. クーポンリストの詳細ページで、クーポンリストの横にある縦三点アイコンをクリックし、**Add coupon** をクリックします。  
   クーポンリストページから **+ Add coupons** をクリックすることもできます。 <img src="/images/moengage_875579.png" />
2. Add Coupons ダイアログボックスで、クーポンファイルを添付します。システムのクーポンを含む CSV ファイルをアップロードします。CSV ファイルには *Coupon Code* というヘッダーが必要です。[サンプルファイルをダウンロード](https://cdn.moengage.com/static-files/Sample%5FCoupon%5FFile.csv)して形式を確認することもできます。
3. **File preview** で **Preview file** オプションを使用して、アップロード用に正しいファイルが選択されているかを確認し、正常にアップロードされたことを確認します。 <img src="/images/moengage_66b49a.png" />   
   システムがクーポンファイルの処理を開始します。
   <Info>
   通常は数分で完了しますが、ファイルの行数や並行してキューに入っているファイルの数など、複数の要因によっては、リストへのクーポンの追加に最大数時間かかる場合があります。
   </Info>

   <img src="/images/moengage_80e28f.png" />

   <Info>
   - 1 つのワークスペースで最大 50 個の個別のクーポンリストを作成できます。
   - 1 つのワークスペースで最大 1 億件のクーポンをインポートでき、1 つのクーポンリストに追加することも、複数のリストに分割することもできます。
   - クーポンリストにアップロードできるファイルの最大サイズは 100 MB です。
   </Info>

# クーポンの管理

クーポンリストは、Coupons ランディングページまたはクーポンリストページから管理できます。クーポンリストの横にある縦三点アイコンをクリックすると、サブメニューが開き、クーポンリストを管理するオプションを選択できます。

## クーポンリストの編集

アクティブなクーポンリストの名前やアラート設定を更新できます。クーポンリストの名前は後で変更できますが、パーソナライゼーションスニペットは変更されません。新しい将来の日付を選択して、クーポンリストの有効期限を更新することもできます。これは含まれるすべてのコードに適用されます。

## クーポンリストのアーカイブ

リストがアーカイブ済みとしてマークされると、利用可能なクーポンは MoEngage システムから削除されます。その結果、このクーポンリストを参照するキャンペーンはコードを取得できなくなります。

## クーポンリストのアーカイブ解除

アーカイブ済みまたは期限切れのステータスからリストを再度有効にした場合、有効になるのはリストのみで、クーポンは復元されません。そのため、キャンペーンで使用する前に、リストに新しいクーポンを追加する必要がある場合があります。

# 使用状況レポートの生成

MoEngage はクーポンコードの利用を検証しません。さまざまなキャンペーンで使用されたクーポンリストの監査レポートを生成できます。詳細については、[サンプル使用状況レポート](https://cdn.moengage.com/static-files/SampleCouponReport+-+Sheet1.csv)を参照してください。

<Warning>
クーポン消費レポートには、失敗したキャンペーンのクーポンは含まれません。
</Warning>

1. クーポンリストの横にある縦三点アイコンをクリックし、**Generate usage report** をクリックします。   
   クーポンリストページから **Generate usage report** をクリックすることもできます。 <img src="/images/moengage_d1203c.png" />
2. Download usage report ダイアログボックスで、クーポン配布レポートをエクスポートする日付範囲を選択します。 <img src="/images/moengage_0c1e75.png" />
3. **Download** をクリックします。これにより、リクエストに応じてレポートの準備が開始され、お客様のメールアドレスへのメール送信がスケジュールされます。  <img src="/images/moengage_bb06ea.png" />
4. レポートは数分以内にお客様のメールアドレスに送信されます。

   <img src="/images/moengage_fa6b2d.png"  />

<Info>
- 使用状況レポートは 1 日に最大 10 回エクスポートできます。
- 1 つの使用状況レポートには最大 2,000 万件のレコードを含めることができます。
</Info>

コンテンツブロックを使用すると、同じコンテンツを複数のキャンペーンで再利用できます。たとえば、頻繁に使用するヘッダー、フッター、またはコールトゥアクションボタンをブロックにすることができます。

コンテンツブロックを使用すると、次のことが可能です。

- **一貫性の維持**: すべてのキャンペーンで同じヘッダー、フッター、またはブランドアセットを使用できます。
- **アセットの再利用**: あらゆるチャネルやキャンペーンタイプで使用できる定義済みのアセットを作成できます。
- **大規模な更新**: ソースとなるコンテンツブロックを更新することで、複数のキャンペーンを同時に編集できます。

# コンテンツブロックを作成する

<Note>
  コンテンツブロックの作成には、**Content** 権限セットだけでは不十分です。カスタムロールでコンテンツブロックを作成できるようにするには、**Campaigns, Inform, Flows & Personalize > Create, Manage & Publish** も付与してください。Content 権限だけでは十分ではありません。
</Note>

新しいコンテンツブロックを作成するには、次の手順に従います。

1. MoEngage のサイドバーメニューで、**Content** メニュー項目 <img alt="コンテンツアイコン.png"  src="/images/moengage_24b340.png"  /> にカーソルを合わせます。**Content** メニューが表示されます。
2. **Content Blocks** をクリックします。   
    <img  src="/images/moengage_4cced1.png"  />   
   Content blocks ページが表示されます。
3. 右上隅の **Create content block** をクリックします。コンテンツブロックページが表示されます。
4. 次の詳細を入力します。 <img alt="コンテンツブロックの作成_新UI.png" src="/images/moengage_2b8d6a.png" />   
     

   | フィールド | 説明 |
   | --- | --- |
   | **Teams** | 組織でチームが有効になっている場合は、ドロップダウンからチームを選択します。 |
   | **Name** | 一意の名前を入力します。この名前は、キャンペーン、テンプレート、またはアラートでブロックを識別するために使用されます。英数字とアンダースコアを使用してください。 |
   | **Description** | ブロックに含まれる内容と使用場所についての説明を入力します。 |
   | **Tags** | ブロックを分類するためのタグを追加します。既存の[キャンペーンタグ](/ja/user-guide/campaigns-and-channels/getting-started/introduction/campaign-tags)を使用できます。 |
   | **Communication Type** | コミュニケーションのタイプ。サポートされている値は次のとおりです。<ul><li>Engage</li><li>Inform</li></ul> |
   | **Content block type** | コンテンツブロックのタイプ。サポートされている値は次のとおりです。<ul><li>**Plain text**: テキストベースのコンテンツブロックは、すべてのキャンペーンチャネルでサポートされています。</li><li>**HTML**: HTML コンテンツブロックは、Email、In-App、Personalize でサポートされています。</li></ul>ユースケースに応じてタイプを選択してください。たとえば、シンプルなクーポンコード (スタイルなし) には Plain text タイプを、メールのヘッダー/フッターには HTML タイプを使用できます。 |
   | **Content** | コンテンツブロックの内容を入力します。<ul><li>キャンペーンの場合: @ を入力して、キャンペーン用にコンテンツをパーソナライズします。</li><li>アラートの場合: **Text personalization** ボタンをクリックして、アラート用にコンテンツをパーソナライズします。</li></ul> |
5. **Publish** をクリックします。   
   コンテンツブロックはパーソナライズすることもできます。詳細については、[コンテンツブロックを使用したコンテンツのパーソナライズ](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/personalize-content-using-content-blocks)を参照してください。

# HTML コンテンツブロックのベストプラクティス

<Warning>
  コンテンツブロックにカスタム HTML を追加する場合は、`div`、`section`、見出し、段落、リストなどのタグを含むボディレベルのコンテンツのみを含めてください。`<html>` タグやグローバルな `<style>` ブロックは追加しないでください。

  すべてのコンテンツブロックは、独自の親 `<html>` タグをすでに持つテンプレートに挿入されます。HTML コンテンツブロックに別の `<html>` タグやグローバルな `<style>` ブロックが含まれている場合、それらのスタイルはブロック内に限定されず、親テンプレート全体を上書きします。これにより、テンプレート内の他の行のレンダリングに影響が及び、場合によってはエディター UI 自体の外観にも影響する可能性があります。
</Warning>

コンテンツブロック内の HTML にスタイルを適用するには、必要な特定の要素に直接適用する**インライン CSS** を使用してください。これにより、スタイルがテンプレートの他の部分に漏れることなく、コンテンツブロック内に限定されます。

# コンテンツブロックを管理する

次のオプションを使用してコンテンツブロックを検索できます。

- **名前またはラベルで検索**: 名前またはラベルでブロックを検索します。
- **更新者を選択**: ブロックを最後に更新したユーザーで結果を絞り込みます。
- **コンテンツタイプ**: コンテンツタイプで結果を絞り込みます。
- **フィルター**: Type、Teams、Status、Tags、またはブロックを最後に更新したユーザーで結果を絞り込みます。

好みに応じて、ページ上のアイコンを使用してリストビューとグリッドビューを切り替えることができます。

Content blocks ページでは、次のフィールドを使用できます。

| フィールド | 説明 |
| --- | --- |
| **Name** | コンテンツブロックに付けられた一意の名前を表示します。 |
| **Content type** | ブロックが Plain text か HTML かを示します。 |
| **Status** | ブロックの現在の状態 (Published や Draft など) を示します。 |
| **Teams** | ブロックが属する特定のチームを示します。 |
| **Updated by** | ブロックを最後に変更したユーザーを表示します。 |
| **Usage** | このブロックを現在使用しているアクティブなキャンペーン、アラート、またはテンプレートの数を示します。 |

## コンテンツブロックを表示する

コンテンツブロックを表示するには、

- Content block リストの行末にある 3 つのドットをクリックし、**View** を選択します。
- または、行の任意の場所をクリックしてプレビューを開きます。

プレビューウィンドウでは、ブロックの設定と顧客への表示内容を包括的に確認できます。次のタブとオプションが含まれます。

- **Web** ビューと **Mobile** ビューを切り替えて、さまざまなデバイスでのコンテンツの表示を確認できます。
- プレビュー画面から **Edit** および **Duplicate** オプションに直接アクセスできます。
- **Details タブ**には、次のようなブロックのメタデータが表示されます。  
  - **Block label**
  - **Communication type**
  - **Content type**
  - **Updated by**
  - **Teams**
  - **Description**
- **Content blocks** タブには、このブロックがより大きなコンテンツ構造の一部である場合に、ネストされたブロックの名前とタイプが表示されます。 <img alt="コンテンツブロックの表示_新UI.png" src="/images/moengage_94033e.png" />

## コンテンツブロックを編集する

コンテンツブロックを編集するには、

- Content block リストの行末にある 3 つのドットをクリックし、**Edit** を選択します。または、行の任意の場所をクリックしてプレビューを開き、プレビューページの **Edit** オプションをクリックします。
- Edit ページでは、**Teams**、**Name**、**Description**、**Tags**、**Content** フィールドを変更できます。

<Info>
ブロックの作成後に **Communication type** または **Content block type** を変更することはできません。
</Info>

## <img alt="コンテンツブロックの編集_新UI.png" src="/images/moengage_5a0ef5.png" />

## コンテンツブロックを複製する

コンテンツブロックを複製するには、

- Content block リストの行末にある 3 つのドットをクリックし、**Duplicate** を選択します。
- Duplicate ページで **Publish** をクリックします。

新しいブロックには **Duplicate** というプレフィックスが付きます。

## コンテンツブロックを削除する

コンテンツブロックを削除するには、

- Content block リストの行末にある 3 つのドットをクリックし、**Delete** を選択します。
- 表示される確認メッセージで **Delete** をクリックします。

ブロックを削除できるのは、アクティブなキャンペーンで現在使用されていない場合のみです。

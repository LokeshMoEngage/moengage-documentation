# 概要

Map User Action 機能を使用すると、ユーザーとアイテムのインタラクションイベントを標準のユーザーイベントに分類し、ユーザーのエンゲージメントに基づいたパーソナライズされたレコメンデーションを実現できます。Map User Action 機能は、ユーザーのエンゲージメントイベントと、カタログ内の対応するアイテムの属性とをつなぐ橋渡しの役割を果たします。

<Warning>
  これらの設定には、Admin/Manager のアクセスロールを持つユーザーがアクセスできます。
</Warning>

# ユーザーアクティビティイベント

アイテム ID 属性を含むユーザーイベントのトラッキングは、行動ベースのレコメンデーションにとって不可欠です。ユーザーの行動を正確に解釈し、パーソナライズされたレコメンデーションを提供するために、MoEngage ではアプリ固有のイベント名を標準イベントにマッピングする必要があります。

![](/images/moengage_45ed9e.png)

このマッピングプロセスにより、標準化されたイベントデータで高度なアルゴリズムとモデルを使用できるようになり、ユーザーの好みや行動に沿った、正確で独自のレコメンデーションが得られます。

# ユーザーアクションイベントのマッピング

ユーザーイベントを MoEngage の標準イベントにマッピングするには、次の手順に従います。

1. 左側のナビゲーションから **Content** \> **Recommendations** に移動します。Recommendations ページが表示されます。<img alt="スクリーンショット 2024-02-08 12.11.16 PM.png" src="/images/moengage_36e204.png" />
2. **Map user actions** をクリックします。
3. User Action バケットの下にあるイベントのドロップダウンリストをクリックし、ドロップダウンメニューから該当するアクションを選択します。
4. 適切なイベントと、特定のアイテムとのインタラクションを表す一意のアイテム ID 属性を選択します。インタラクション時のアイテムの関連情報を含む価格属性と数量属性もマッピングできます。例:
   - イベント「**Add to Cart**」を選択します。
   - イベント属性「**Product ID**」を選択します。
   - アイテムインタラクションのイベント属性「**Price**」を選択します。

![](/images/moengage_50d9f6.png)

5. MoEngage は、マッピングを保存した時点から、マッピングされたイベントのデータの記録を開始します。それ以前の過去のイベントはバックフィルされません。マッピングがいつ保存されたかは、そのバケットを展開すると確認できます。<img src="/images/moengage_6f8476.png" />

<Note>
  2024 年 2 月より前にマッピングされたイベントについては、アイテムのマッピング時刻は表示されません
</Note>

全体として、ユーザーアクション設定のマッピングは、レコメンデーションシステムがユーザーの行動を理解し、アイテムとユーザーの関係を確立できるようにするため、パーソナライズされたレコメンデーションにとって極めて重要です。

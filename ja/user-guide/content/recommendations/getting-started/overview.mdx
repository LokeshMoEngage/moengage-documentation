Recommendations を使用すると、各顧客が最も反応しやすい商品、コンテンツ、オファーを、自動的かつ大規模に表示できます。全員に同じアイテムを宣伝するのではなく、パーソナライズされたおすすめ、関連する代替品、タイムリーな値下げアラートなど、適切なアイテムを適切なタイミングで提示できます。

![MoEngage Recommendations エンジンの概要](/images/moengage_78b355.png)

Recommendations エンジンは、厳選した同じアイテムを全員に宣伝することから、類似ユーザーの行動やアイテムの類似性に基づいて各個人に合わせた関連アイテムを特定することまで、幅広い用途に対応します。

## Recommendations の仕組み

レコメンデーションの設定は 4 つのステップで行います。最初のステップは一度完了すれば、作成するすべてのレコメンデーションで再利用できます。

<Steps>
  <Step title="データを準備する">
    **アイテムカタログ**（商品、コンテンツ、リスティング）を接続し、**ユーザーアクションイベント**（閲覧、カート追加、ウィッシュリスト保存、購入）を MoEngage の標準イベントにマッピングします。[前提条件](/ja/user-guide/content/recommendations/getting-started/overview)を参照してください。
  </Step>
  <Step title="レコメンデーションの種類を選択する">
    **Basic**（ユーザーが定義するルール）と **Advanced**（機械学習モデル）のどちらを使用するかを決定します。下記の[モデルの選択](#choosing-a-model)を参照してください。
  </Step>
  <Step title="作成する">
    必要なフィルターと並べ替えを使用してレコメンデーションを設定します。
  </Step>
  <Step title="テストする">
    リリース前に、実際のユーザー、ランダムなサンプル、または特定のアイテムで結果をプレビューします。[レコメンデーションのテスト](/ja/user-guide/content/recommendations/getting-started/test-a-recommendation)を参照してください。
  </Step>
  <Step title="キャンペーンで使用する">
    レコメンデーションを Push、Email、In-App などのキャンペーンに挿入し、パーソナライズされたコンテンツをユーザーに配信します。
  </Step>
</Steps>

## Basic と Advanced のレコメンデーションの比較

MoEngage には 2 種類のレコメンデーションがあります。ほとんどのアカウントでは、キャンペーンに応じて両方を使用しています。

| | **Basic** | **Advanced** |
| --- | --- | --- |
| **決定方法** | ユーザーが定義するルール | 機械学習モデル（Merlin AI） |
| **最適なケース** | 何を宣伝するかが明確に決まっている場合 | パーソナライズを自動的に適応させたい場合 |
| **作業量** | フィルターと並べ替えを自分で作成する | モデルが行動から学習する |
| **データの準備状況** | カタログ（一部のモデルではユーザーアクションも） | カタログ**に加えて**、学習に十分なマッピング済みユーザーアクション履歴 |
| **モデル** | Item Attributes、User Actions、Catalog Alerts | Recommended Items、Similar Items、Frequently Viewed Together、Frequently Bought Together、Trending Items、Popular Items |

## モデルの選択

目的から逆算してモデルを選びます。

| 目的 | 使用するモデル | 種類 |
| --- | --- | --- |
| 新着商品、特定のブランド、季節のおすすめなど、特定の商品を宣伝したい | **Item Attributes** | Basic |
| カート、ウィッシュリスト、最近閲覧したアイテムなど、ユーザーが関心を示したアイテムを思い出させたい | **User Actions** | Basic |
| 値下げ、再入荷、売れ行きの速いアイテムをユーザーに通知したい | **Catalog Alerts** | Basic |
| 各ユーザーにパーソナライズされた「あなたへのおすすめ」を提供したい | **Recommended Items** | Advanced |
| ユーザーが閲覧しているアイテムの代替品を表示したい | **Similar Items** | Advanced |
| 一緒に閲覧されることが多いアイテムをクロスセルしたい | **Frequently Viewed Together** | Advanced |
| 一緒に購入されることが多いアイテムをバンドルしたい | **Frequently Bought Together** | Advanced |
| 全体、またはカテゴリーや地域内でトレンドになっているものを提示したい | **Trending Items**（デフォルトのフォールバックとして **Popular Items**） | Advanced |

## メリット

- **エンゲージメントとコンバージョンの向上** — 関連性の高い提案により、ユーザーのアクティブな状態が維持され、購入の可能性が高まります。
- **クロスセルとアップセルの改善** — 状況に応じたバンドルやアドオンにより、平均注文額が向上します。
- **解約の削減** — 適切なタッチポイントで適切なアイテムを提示することで、ユーザーの再訪を促します。
- **ロイヤルティの強化** — パーソナライズされた体験により、顧客は理解されていると感じます。

## 業界別の Recommendations

Recommendations は、カタログを中心とするほぼすべてのビジネスに適用できます。代表的なユースケースをいくつか紹介します。

| 業界 | ユースケースの例 |
| --- | --- |
| 小売 | 補完的な商品、アドオン、アップグレードを推奨する。放棄されたカートやウィッシュリストで再エンゲージメントを図る。 |
| 銀行・金融 | 顧客のプロフィールに基づいてローン、保険、投資を提案する。関連するカードのオファーを提示する。 |
| 求人・不動産 | 求職者のスキルに合った求人や、ユーザーの所在地に近い物件を推奨する。 |
| Ed-Tech | 学習者の目標や関心に基づいてコースや資格を推奨する。 |
| エンターテインメント・メディア | 視聴履歴や類似ユーザーに基づいて番組、記事、動画を推奨する。 |
| 旅行 | 旅行者の好みや過去の旅行に基づいてパッケージや目的地を推奨する。 |
| ゲーム | プレイヤーがすでにプレイしたジャンルやゲームに基づいて新しいタイトルを提案する。 |

## 次のステップ

最初のレコメンデーションを作成する前に、データの準備ができていることを確認してください。

- [アイテムカタログ](/ja/user-guide/content/recommendations/getting-started/catalogs)を接続します。
- [ユーザーアクションイベントをマッピング](/ja/user-guide/content/recommendations/getting-started/map-user-actions-settings)します。

データの設定が完了したら、[Basic](/ja/user-guide/content/recommendations/basic-recommendations/overview-basic-recommendations) または [Advanced](/ja/user-guide/content/recommendations/advanced-recommendations/overview-advanced-recommendations) のレコメンデーションを選択します。その後、[Push](/ja/user-guide/content/recommendations/personalize-campaign-with-recommendations/using-recommendations-in-push)、[Email](/ja/user-guide/content/recommendations/personalize-campaign-with-recommendations/using-recommendations-in-email)、[On-Site Messaging](/ja/user-guide/content/recommendations/personalize-campaign-with-recommendations/using-recommendations-in-on-site-messaging) の各キャンペーンでレコメンデーションを使用する方法を確認してください。

# **アルゴリズムの詳細**

各モデルは、それぞれ異なるアルゴリズムを使用して学習し、レコメンデーションを生成します。

| レコメンデーションモデル | アルゴリズム | データポイント |
| --- | --- | --- |
| **Recommended Items**<br />(類似ユーザー) | Hierarchical Recurrent Neural Network (HRNN) | <ul><li>閲覧された商品</li><li>カートに追加された商品</li><li>ウィッシュリストに追加された商品</li><li>購入された商品</li><li>ユーザー属性</li></ul> |
| **Similar Items** | アイテム間協調フィルタリング +<br />アイテム属性の類似度 | <ul><li>閲覧された商品</li><li>カートに追加された商品</li><li>ウィッシュリストに追加された商品</li><li>購入された商品</li><li>カタログ属性</li></ul> |
| **Frequently Bought Together** | アイテム間協調フィルタリング | <ul><li>購入された商品</li></ul> |
| **Frequently Viewed Together** | アイテム間協調フィルタリング | <ul><li>閲覧された商品</li></ul> |

## **Hierarchical Recurrent Neural Network (HRNN)**

HRNN は、ユーザーがプラットフォーム上のさまざまなアイテムとどのようにインタラクションしているかのパターンを識別します。これにより、過去の行動に基づいて、ユーザーが次に関心を持つ可能性が高いアイテムを予測できます。このアプローチは、あるセッションにおいてユーザー A がユーザー B (インタラクションパターンの観点で類似したユーザー) と同じ意見を持つ場合、別のセッションでも A はランダムなユーザーよりも B の意見を持つ可能性が高い、という前提に基づいています。

1. **ユーザー行動パターン:** HRNN の有効性の鍵は、アイテム同士を結び付ける明示的な属性がない場合でも、インタラクションパターンに基づいてアイテム間の関係を推測できる点にあります。これらのパターンには、一緒に閲覧されたアイテムや、近い順序で閲覧されたアイテムなどが含まれます。
2. **埋め込み層:** HRNN では、ユーザーとアイテムの両方が埋め込み (浮動小数点値の密なベクトル) として表現されます。モデルはこれらの埋め込みを使用して、高次元空間におけるアイテムとユーザーの「近さ」を表現します。ユーザーによって頻繁にインタラクションされるアイテム同士は、この空間内で互いに近くに配置されます。
3. **再帰層**: HRNN は再帰層を使用して長いデータシーケンス全体のパターンを記憶し、より優れた予測を行い、アイテム間の複雑な関係を識別できるようにします。インタラクションイベントのタイムスタンプにより、シーケンスだけでなく時間的な要素もレコメンデーションに反映されます。

## **協調フィルタリング**

アイテム間協調フィルタリングは、ユーザー間ではなくアイテム間の関係に焦点を当てた特定のアプローチです。アイテムの嗜好はユーザーの嗜好ほど頻繁に変化しないため、アイテム間協調フィルタリングは類似ユーザー行動モデルよりも安定する傾向があります (ただし、パーソナライズの度合いは低くなります)。

このアプローチでは、ユーザーとアイテムの共起インタラクションを調べ、インタラクションデータに基づいてグローバルレベルでアイテムの類似度を判定します。イメージをつかむために、計算方法の基本的な解釈を以下に示します。

## **アイテム属性の類似度**

アイテム間の関係を捉えるために、各アイテム ID に対してアイテムメタデータの埋め込みが作成されます。これは本質的に多次元空間で表現され、各次元は隠れ変数または潜在因子に対応します。これらの埋め込みは、ジャンルやカテゴリなどのアイテムの属性を表します。

ユーザーとアイテムのインタラクションおよびアイテムメタデータからアイテムの埋め込みを生成した後、それらは融合層で統合されます。この層は、トレーニング中にアイテムの特性とユーザーの嗜好に基づいて重みを調整するよう学習します。ユーザーインタラクションに由来する埋め込みとアイテムメタデータに由来する埋め込みの重要度を決定します。ディープラーニングモデルを通じて、インタラクションデータとアイテムメタデータの類似度の両方を重み付けすることで、レコメンデーションのバランスを効果的に取ります。

## **人気度カウント**

人気度カウントは重み付き集計ベースのモデルで、全体のインタラクション数に基づいて最も人気のあるアイテムを提案します。これは、履歴データが最小限または利用できない場合のフォールバックとしての役割を果たします。

## **Trending Items**

Trending Items は、購入、閲覧、ウィッシュリストへの追加、カートへの追加などのユーザーとアイテムのインタラクションイベントを定義された期間にわたって集計し、選択したインタラクション指標でアイテムをランク付けします。集計はカタログ全体で実行してグローバルトレンドを生成することも、`category` や `city` などのカテゴリ型カタログ属性の値の範囲内で実行して属性トレンドを生成することもできます。このモデルは、トレーニング済みのユーザーとアイテムの履歴ではなく最近のインタラクションを読み取るため、Frequently Viewed Together や Frequently Bought Together などのモデルでインタラクションデータが不足している場合のフォールバックとしても機能します。

詳細については、[Trending Items](/ja/user-guide/content/recommendations/advanced-recommendations/category-trending-items) を参照してください。

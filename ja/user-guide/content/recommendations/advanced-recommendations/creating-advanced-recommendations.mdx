<Info>
レコメンデーションは Admin / Manager / Marketer ロールのみが作成できます
</Info>
<Info>
  **前提条件**

  Advanced Recommendations を作成する前に、次の要件を満たしていることを確認してください。

  - アカウントで Advanced Recommendations が有効になっていること。
  - ユーザーアクションイベントを MoEngage と統合し、各イベントに一意のアイテム ID が含まれていること。
  - 関連するユーザーとアイテムのインタラクションイベントをトラッキングし、MoEngage の標準イベントにマッピングしていること。
  - アカウントにアクティブなカタログがあること。

  詳細については、[Map User Actions](/ja/user-guide/content/recommendations/getting-started/map-user-actions-settings) および [Catalogs](/ja/user-guide/content/recommendations/getting-started/catalogs) を参照してください。
</Info>

レコメンデーションを作成するには、次の手順を実行します。

1. MoEngage のサイドバーメニューで、Content メニュー項目 <img alt="content icon.png"  src="/images/moengage_247c78.png"  /> にカーソルを合わせます。**Content** メニューが表示されます。
2. **Recommendations** をクリックします。  
    <img  src="/images/moengage_054d37.png"  />   
   Recommendations ページが表示されます。
3. **+ Create recommendation** をクリックします。Create recommendation ページが表示されます。 <img src="/images/moengage_82987a.png" />
4. ユースケースに応じて適切なモデルを選択し、**Next** をクリックします。

    ![フィルターモデルと予測モデルのオプションを含む、Select recommendation model ステップを表示した Create recommendation ページ](/images/recommendations-select-model.png)

    <Note>
      この記事では、Recommended Items、Similar Items、Frequently Viewed Together、Frequently Bought Together のレコメンデーションについて説明します。トレンドのレコメンデーションについては、[Trending Items](/ja/user-guide/content/recommendations/advanced-recommendations/category-trending-items) を参照してください。
    </Note>
5. **Recommendation name** フィールドに、レコメンデーションの名前を入力します。
6. **Recommendation description** フィールドに、レコメンデーションの説明を入力します
7. **Catalog** ドロップダウンリストで、レコメンデーションを取得するカタログを選択します。  
   **注:** すべての AI レコメンデーションは 1 つのカタログを使用します。いずれかの AI レコメンデーションでカタログを使用すると、そのカタログは他のすべての種類の AI レコメンデーションに自動的に設定されます。
8. **Number of items to show** フィールドに、レコメンデーションで返すアイテムの数を入力します。MoEngage はこのフィールドに 10 を入力し、その下にワークスペースの上限を表示します。上限を引き上げるには、MoEngage Support にお問い合わせください。詳細については、[Fallback Items](/ja/user-guide/content/recommendations/getting-started/fallback-items) を参照してください。
9. ユースケースに応じて、ドロップダウンリストから適切な **user actions** を選択します。
   - Similar items、Frequently bought together items、Frequently viewed together items の場合は、設定したユーザーアクションイベントに基づく最新のアイテムが生成に使用されます。
   - Recommended items の場合は、ユーザーアクションを設定する必要はありません。ユーザーが実行したすべてのユーザーアクションが考慮されて行動パターンが自動的に学習され、個人の変化する関心に合わせたレコメンデーションが生成されます。
10. **Filter items by user actions** トグルをオンにしてフィルタリング条件を追加し、顧客にレコメンドするアイテムを制御します。これらのフィルターは、コアレコメンデーションの結果にさらに適用されます。ユーザーアクションには 2 種類のフィルターがあります。  
    <img alt="user action filter.png" src="/images/moengage_961199.png" />
   - **Select user action to keep items**: マーケターは、フィルタリング用のユーザーアクション条件とレコメンデーション結果の両方に共通するアイテムのみを含めるユーザーアクション条件を定義できます。**+ User actions** をクリックし、含めるアイテムを選択します。
   - **Select user action to remove items**: マーケターは、フィルタリング用のユーザーアクション条件に従ってレコメンデーションアイテムからアイテムを削除するユーザーアクション条件を定義できます。**+ User actions** をクリックし、除外するアイテムを選択します。
11. **Filter items by item attributes** トグルをオンにして、カタログ情報に基づくフィルタリング条件を追加します。これらのフィルターも、コアレコメンデーションの結果にさらに適用されます。 <img src="/images/moengage_4ccdd3.png" />
12. **Save** をクリックします。Recommendations ページに、'Processing' 状態のレコメンデーションが作成されます。レコメンデーションがアクティブになるまで最大 24 時間かかる場合があります。キャンペーンでこのレコメンデーションを使用する前に、実際のユーザー、ランダムサンプル、または特定のアイテムに対してテストしてください。詳細については、[Test a Recommendation](/ja/user-guide/content/recommendations/getting-started/test-a-recommendation) を参照してください。  
     <img alt="mceclip5.png" src="/images/moengage_6c48ff.png" />
13. レコメンデーションの準備ができたら、キャンペーンで使用する前にサンプルユーザーの結果をテストできます。

# ベストプラクティス

- すべてのビジネス提供物、またはレコメンデーションを生成したい提供物の種類を網羅したグローバルカタログを選択してください。
- 関連するすべてのイベントを、該当するユーザーアクションバケットにマッピングしてください。
- 一意のアイテム ID 属性が、カタログ内の一意のアイテム ID と同じ情報を持っていることを確認してください。
- Recommended Items の設定では、Product Viewed、Added to Wishlist、Added to Cart、Product Purchased など、考えられるすべてのユーザーとアイテムのインタラクションを設定してください。これにより、アルゴリズムは幅広いユーザー行動から学習し、急速な変化に適応できます。
- キャンペーンに組み込む前に、サンプルユーザーの結果をテストしてください。

SMS キャンペーンにレコメンデーションを追加すると、全員に同じメッセージを送信するのではなく、各ユーザーの関心に合った商品を送信できます。SMS チャネルでは、レコメンデーションは [Jinja テンプレート言語](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/jinja-templating-language)を使用してメッセージテキストに挿入されます。

MoEngage では、SMS キャンペーンの作成は 3 つのステップで行います。

1. Target users
2. Content
3. Schedule and Goals

2 番目のステップ「Content」で、レコメンデーションを使用してキャンペーンをパーソナライズできます。それでは、レコメンデーションを使用してパーソナライズした SMS キャンペーンを作成してみましょう。

<Warning>
  目的のレコメンデーションが作成済みであることを確認してください。キャンペーンのパーソナライズには、アクティブなレコメンデーションのみを使用できます。[レコメンデーションの作成と管理](/ja/user-guide/content/recommendations)の方法を確認してください。
</Warning>

<Note>
  SMS には文字数の制限があります。プロダクトセットをそのまま追加するとセット内のすべてのアイテムが挿入されるため、メッセージが複数の SMS に分割される可能性があります。手順 11 で説明するように、Jinja コードを変更して単一のアイテムを取得してください。文字数と SMS の件数はプレビューの下に表示されます。
</Note>

# レコメンデーションを使用した SMS キャンペーンの作成

レコメンデーションを使用した SMS キャンペーンを作成するには、次の手順を実行します。

1. MoEngage のサイドバーメニューで、Engage メニュー項目 <img alt="Engage メニューアイコン" src="/images/moengage_3a6ded.png" style={{ display: "inline-block", height: "20px", width: "auto" }} /> にカーソルを合わせます。**Engage** メニューが表示されます。
2. **+ New Campaign** をクリックします。<img src="/images/moengage_f884be.png" alt="New Campaign オプションが表示されている Engage メニュー" /> **Engage** メニューの **All Campaigns** をクリックし、All campaigns ページで **\+ Create campaign** をクリックすることもできます。
3. **New Campaign** ダイアログボックスの **OUTBOUND** で、**SMS** をクリックします。
4. **Periodic** キャンペーンをクリックします。他の SMS キャンペーンタイプでも同じ手順を実行できます。配信タイプの詳細については、[配信タイプ](/ja/user-guide/campaigns-and-channels/getting-started/introduction/delivery-types-moengage-channels)を参照してください。<img src="/images/sms-new-campaign-periodic.png" alt="Outbound で SMS が選択され、Periodic 配信タイプが表示されている New Campaign ダイアログボックス" />
5. ステップ 1「Target users」でキャンペーンの基本情報を入力してオーディエンスを定義し、**Next** をクリックします。
6. ステップ 2 の **Content** タブで、**Default templates** の **Blank Template** をクリックするか、**Custom templates** からテンプレートを選択します。<img src="/images/sms-select-template.png" alt="Blank Template オプションと Custom templates リストが表示されている Content タブ" />
7. **SMS sender** リストで送信者を選択します。
8. **Message** フィールドで、レコメンデーションを表示する位置に「@」と入力します。**SMS Personalization** ウィンドウが開きます。
9. **Data personalization** タブの **Select attribute** リストで、レコメンデーションを検索し、**Product sets** の下で選択します。<img src="/images/sms-personalization-window.png" alt="Data personalization タブ、Select attribute リスト、Choose Fallback オプションが表示されている SMS Personalization ウィンドウ" />
10. **Choose Fallback** でフォールバックを選択し、**Done** をクリックします。
    **Choose Fallback** オプションは、ユーザーのパーソナライズが失敗した場合にそのユーザーが受け取る内容を制御します。

    | フォールバック | 動作 |
    | --- | --- |
    | **No fallback** | レコメンデーションは空の値に置き換えられます。 |
    | **Do not send SMS** | そのユーザーには SMS が送信されません。 |
    | **Replace text** | レコメンデーションは入力したテキストに置き換えられます。 |
11. レコメンデーションから利用可能なすべてのアイテムリストを取得する Jinja コードが自動的に入力されます。ユースケースに合わせてコードを変更できます。たとえば、次は 1 つのアイテムを表示するように変更したコードです。
    <CodeGroup>
    ```jinja Item Title
    {% if ProductSet.Recommendations %}
    {% for product in ProductSet.Recommendations[0:1] %}
    {{product.title}}
    {% endfor %}
    {% else %}
    MOE_NOT_SEND
    {% endif %}
    ```

    ```jinja Item Link
    {% if ProductSet.Recommendations %}
    {% for product in ProductSet.Recommendations[0:1] %}
    {{product.link}}
    {% endfor %}
    {% else %}
    MOE_NOT_SEND
    {% endif %}
    ```
    </CodeGroup>
    <img src="/images/sms-message-jinja.png" alt="プロダクトセット用に自動入力された Jinja コードが表示されている Message フィールド" />
    <Note>
      `MOE_NOT_SEND` は、ユーザーのプロダクトセットが空の場合にメッセージの送信を停止するため、商品が欠けた SMS を受け取るユーザーはいません。
    </Note>
12. アイテムの属性を表示するには、`for` ループ内にカーソルを置いて「@」と入力し、**Select attribute** リストで属性を選択します。属性はループ内に挿入されます (例: `{{product['price']}}`)。
13. 残りの各レコメンデーションについて、手順 8 ～ 12 を繰り返します。メッセージの部分ごとに、レコメンデーションによるパーソナライズまたは静的なテキストコンテンツを選択できます。
14. 設定が完了したら、**Preview type** で **Personalized** をクリックします。MoEngage がユーザーを選択し、実際の値でメッセージを表示します。
15. 特定のユーザーのメッセージをプレビューするには、編集アイコン <img alt="編集アイコン" src="/images/personalized-preview-edit-icon.png" style={{ display: "inline-block", height: "16px", width: "auto" }} /> をクリックします。**Personalized preview** スライドアウトが開きます。
16. **Select user by** リストで、使用する識別子を選択します。
17. **User identifier value** フィールドに、ユーザーの識別子を入力します。
18. **Fetch user data** をクリックします。**Personalization inputs** の下に、そのユーザーが利用できるアイテムを含むプロダクトセットが JSON として表示されます。
19. プレビューしたい内容に合わせて JSON を変更します。(任意)
20. **Update preview** をクリックします。<img src="/images/sms-personalized-preview.png" alt="プロダクトセットの JSON と Update preview ボタンが表示されている Personalized preview スライドアウト" />
    <Note>
      アカウントで **Update preview** を有効にするには、MoEngage の CSM または Support チームにお問い合わせください。詳細については、[パーソナライズされたプレビュー](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/personalized-preview)を参照してください。
    </Note>
21. すべてのユーザーに対してスケジュールする前に、テストキャンペーンを配信してエンドツーエンドの配信を確認することもできます。<img src="/images/moengage_64d866.png" alt="Test Campaign パネル" />
22. レコメンデーションを使用したコンテンツの設定が完了したら、下部の **Next** をクリックし、キャンペーン設定のステップ 3 である「Schedule and Goals」に進みます。
23. **Schedule and Goals** で適切な設定を行い、キャンペーンを公開します。

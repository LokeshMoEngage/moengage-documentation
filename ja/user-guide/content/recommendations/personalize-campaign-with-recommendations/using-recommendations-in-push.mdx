このヘルプ記事では、パーソナライズされたレコメンデーションを Push キャンペーンに統合して、動的なレコメンデーションを配信する方法を紹介します。Push チャネルでは、コンテンツのパーソナライズは [Jinja テンプレート言語](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/jinja-templating-language)を使用して行います。

MoEngage では、Push キャンペーンの作成は 3 つのステップで行います。

1. Target users
2. Content
3. Schedule and Goals

2 番目のステップ「Content」で、レコメンデーションを使用してキャンペーンをパーソナライズできます。それでは、レコメンデーションを使用してパーソナライズしたキャンペーンを作成してみましょう。

<Warning>
  目的のレコメンデーションが作成済みであることを確認してください。キャンペーンのパーソナライズには、アクティブなレコメンデーションのみを使用できます。[レコメンデーションの作成と管理](/ja/user-guide/content/recommendations)の方法を確認してください。
</Warning>

# レコメンデーションを使用した Push キャンペーンの作成

レコメンデーションを使用したプッシュキャンペーンを作成するには、次の手順を実行します。

1. MoEngage のサイドバーメニューで、Engage メニュー項目 <img alt="スクリーンショット 2025-06-04 4.32.53 PM.png" src="/images/moengage_3a6ded.png" /> にカーソルを合わせます。**Engage** メニューが表示されます。
2. **+ New Campaign** をクリックします。<img src="/images/moengage_f884be.png" alt="1.png" /> **Engage** メニューの **All Campaigns** をクリックし、All campaigns ページで **\+ Create campaign** をクリックすることもできます。
3. **New Campaign** ダイアログボックスの **OUTBOUND** で、**Push** をクリックします。
4. **Periodic** キャンペーンをクリックします。他のプッシュキャンペーンタイプでも同じ手順を実行できます。配信タイプの詳細については、[配信タイプ](/ja/user-guide/campaigns-and-channels/getting-started/introduction/delivery-types-moengage-channels)を参照してください。<img src="/images/moengage_ff7060.png" />
5. ステップ 1「Target users」でキャンペーンの基本情報を入力してオーディエンスを定義し、**Next** をクリックします。
6. ステップ 2 の **Content** タブで、利用可能なオプションからテンプレートを選択します。
7. 任意のテキストブロックに「@」と入力すると、パーソナライズのポップアップが開きます。データパーソナライズのドロップダウンでレコメンデーション名を検索し、**Done** をクリックします。<img src="/images/moengage_e3bdbd.png" />
8. レコメンデーションから利用可能なすべてのアイテムリストを取得する Jinja コードが自動的に入力されます。ユースケースに合わせてコードを変更できます。たとえば、次は 1 つのアイテムを表示するように変更したコードです。
   <CodeGroup>
   ```jinja JINJA
   {% if ProductSet.RealTimeAIRecommendations%}
   {% for product in ProductSet.RealTimeAIRecommendations[0:1]%}
   {{product.title}}
   {% endfor %}
   {% else %}
   MOE_NOT_SEND
   {% endif %}
   ```
   </CodeGroup>
   ![](/images/moengage_850d2a.png)
9. 要件に応じて、タイトル、メッセージ、サマリーを入力します。ブロックごとに、レコメンデーションによるパーソナライズまたは静的なテキストコンテンツを選択できます。
10. 同様に、画像 URL を定義して、推奨商品の画像で通知をパーソナライズします。<img src="/images/moengage_df5f9b.png" />
11. 設定が完了したら、**Preview** をクリックして意図したとおりに表示されることを確認します。<img src="/images/moengage_07b108.png" />
12. すべてのユーザーに対してスケジュールする前に、テストキャンペーンを配信してエンドツーエンドの配信を確認することもできます。<img src="/images/moengage_64d866.png" />
13. レコメンデーションを使用したコンテンツの設定が完了したら、下部の **Next** をクリックし、キャンペーン設定のステップ 3 である「Schedule and Goals」に進みます。
14. **Schedule and Goals** で適切な設定を行い、キャンペーンを公開します。

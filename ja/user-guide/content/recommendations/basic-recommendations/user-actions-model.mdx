# はじめに

User Actions レコメンデーションモデルは、ユーザーの行動を活用して、ルールベースのパーソナライズされたレコメンデーションを作成します。これらは、カート放棄、ウィッシュリスト、その他特定の製品やサービスへの関心を示す行動など、ユーザーが強い意図を示している場合に効果的です。User Action レコメンデーションは、企業に次のようなメリットをもたらします。

- パーソナライズされたエンゲージメント
- 精度の高いターゲティング
- 再エンゲージメントの機会 

### ユースケースの例

- カート放棄のリマインダーで失われた売上を回復する。
- 再入荷アラートを受け取り、チャンスを逃さない！
- ユーザーのウィッシュリストに基づくパーソナライズされたキャンペーンでエンゲージメントを高める。
- 最近閲覧したアイテムでユーザーを再エンゲージする。
- さりげない後押しでリピート購入を促進する。

<Tip>
  続行する前に、ユーザーアクションをマッピングし、カタログを追加する必要があります。詳細については、[User Actions](/ja/user-guide/content/recommendations/getting-started/map-user-actions-settings) および [Catalogs](/ja/user-guide/content/recommendations/getting-started/catalogs) を参照してください。
</Tip>

# User Action レコメンデーションの作成

<Info>
  レコメンデーションは Admin / Manager / Marketer ロールのみが作成できます
</Info>

User Action レコメンデーションを作成するには、次の手順を実行します。

1. MoEngage のサイドバーメニューで、Content メニュー項目 <img alt="content icon.png" src="/images/moengage_14d0ec.png" /> にカーソルを合わせます。**Content** メニューが表示されます。
2. **Recommendations** をクリックします。 <img src="/images/moengage_100d91.png" /> Recommendations ページが表示されます。
3. **\+ Create recommendation** をクリックします。 <img src="/images/moengage_52078a.png" />
4. **User Actions** モデルを選択し、**Next** をクリックします。 <img src="/images/moengage_0fe234.png" />
5. **Recommendation name** フィールドに、レコメンデーションの名前を入力します。
6. **Recommendation description** フィールドに、レコメンデーションの説明を入力します。
7. **Catalog** ドロップダウンリストで、レコメンデーションを取得するカタログを選択します。
8. **Number of items to show** フィールドに、レコメンデーションで返すアイテムの数を入力します。MoEngage はこのフィールドに 10 を入力し、その下にワークスペースの上限を表示します。上限を引き上げるには、MoEngage Support にお問い合わせください。詳細については、[Fallback Items](/ja/user-guide/content/recommendations/getting-started/fallback-items) を参照してください。
9. ユースケースに応じて **Item where user performed** ドロップダウンリストから適切なユーザーアクションを選択し、アクティビティの日付範囲を定義します。例: 過去 7 日間に実行された Added to wishlist。特定の種類のインタラクション済みアイテムを除外することもできます。 <img src="/images/moengage_c4b894.png" />
10. **Filter items by item attributes** トグルをオンにしてフィルタリング条件を追加し、顧客にレコメンドするアイテムを制御します。これらのフィルターは、User Action モデルのレコメンデーションに適用されます。 <img src="/images/moengage_ad52a7.png" />
11. **Sort the filtered items** セクションで、任意の数値属性 (例: price) でレコメンデーション結果を並べ替えます。 <img src="/images/moengage_576be6.png" />
12. **Save** をクリックします。Recommendations ページに、'Active' 状態のレコメンデーションが作成されます。

カート放棄やウィッシュリストのアイテムなど特定のユーザーアクションを活用することで、企業はユーザーを再エンゲージし、コンバージョンを促進できます。

## フィルター

フィルター設定を使用すると、カタログで利用可能な情報に基づいて、顧客に表示されるレコメンデーションを絞り込むことができます。これらのフィルターは User Action モデルの出力をカスタマイズし、提案されるアイテムの関連性を高めます。

### ユースケースの例

- 現在在庫切れのアイテムを除外して、カート放棄のリマインダーで失われた売上を回復する。
- セール中のウィッシュリストのアイテムをレコメンドする。
- 特定のブランドの最近閲覧したアイテムをレコメンドする。

キャンペーンでこのレコメンデーションを使用する前に、実際のユーザー、ランダムサンプル、または特定のアイテムに対してテストしてください。詳細については、[Test a Recommendation](/ja/user-guide/content/recommendations/getting-started/test-a-recommendation) を参照してください。

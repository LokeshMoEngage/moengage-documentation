# はじめに

Item Attributes レコメンデーションモデルを使用すると、カタログのアイテム属性フィルターを適用してルールベースのレコメンデーションを作成できます。これにより、特定のアイテムのプロモーションやユーザープロファイルに基づくパーソナライズされた提案など、マーケティング目標に応じてレコメンデーションをカスタマイズできます。

<Tip>
続行する前に、カタログを追加する必要があります。詳細については、[Catalogs](/ja/user-guide/content/recommendations/getting-started/catalogs) を参照してください。
</Tip>

## 汎用ルール

汎用ルールはアイテム属性を使用し、パーソナライズされません。新着商品、季節のアイテム、特定のブランドやカテゴリのプロモーションを多くのユーザーに訴求します。アイテム属性を活用することで、企業はレコメンデーションをマーケティング目標に合わせ、認知度を高めることができます。

ユースケースの例

- 'New arrivals' セクションを公開する。
- ブランドコレクションで興味を喚起する。
- 季節のおすすめ商品でお祝いする。

## ターゲットルール

ターゲットルールは、ユーザープロファイルに基づいてアイテム属性をフィルタリングし、各ユーザーの特性に合わせた提案を提供します。これにより、特定のユーザープロファイルに適した関連性の高いレコメンデーションが保証されます。

**ユースケースの例**

- ユーザーのスキルに合った理想的な求人をレコメンドする
- 顧客の近くにある地元のレストランを見つける。

## 位置情報ルール

位置情報ルールは、ロケーション固有のレコメンデーションを提供するのに役立ちます。これらのルールを使用して、ユーザーの現在地またはカスタム定義されたロケーションの近くで利用可能なアイテムやサービスを提案できます。

位置情報ルールを設定するには、次の手順を実行します。

1. **Item where** ドロップダウンリストで、`store_location` などのロケーション型カタログ属性を選択します。
2. 比較ポイントとして、**User's current location** またはカスタムロケーションを選択します。
3. 半径を設定します (例: 10 km 以内)。

![ロケーションのカタログ属性を選択し、比較ポイントを選び、半径を設定して位置情報ルールを設定する](/images/recommendations-geo-location-rule.gif)

**ユースケースの例**

- ユーザーの現在地に基づいて、近くのレストラン、店舗、サービスを提案する。
- ユーザーの現在地に基づいて、近くの掲載物件を提案する。

# フィルター

フィルター設定を使用すると、顧客に表示されるレコメンデーションを絞り込むことができます。これらのフィルターは Item Attribute モデルのルールと組み合わせて機能し、提案されるアイテムの関連性を高めます。

アイテムは次の 2 つの方法でフィルタリングできます。

- **Keep Items**: このフィルターを使用すると、アイテム属性ルールの結果とユーザーアクションフィルター条件の両方に共通するアイテムのみを含めるユーザーアクション条件を定義できます。
- **Remove Items**: このフィルターを使用すると、アイテム属性ルールの結果からアイテムを削除するユーザーアクション条件を定義できます。

<Info>
レコメンデーションフィルターを適用した後の最終的な商品の計算は次のとおりです。

- A = コアレコメンデーションフィルターからの商品
- Keep items:  
  - B = 'keep item' フィルター設定からの商品
  - 最終結果 = A ∩ B
- Remove items:
  - C = 'remove item' フィルター設定からの商品
- 最終結果 = A ∩ B - C
</Info>

**ユースケースの例**

- Ethnic wear カテゴリのアイテムをレコメンドしつつ、個々のユーザーが過去 7 日間にカートに追加したアイテムを削除する。
- Flash Deals のアイテムをレコメンドしつつ、個々のユーザーが過去 14 日間にウィッシュリストに追加したアイテムのみを残す。
- ユーザーのロケーションにある物件をレコメンドしつつ、ユーザーが過去 30 日間に訪問した物件を削除する。
- 映画をレコメンドしつつ、ユーザーが過去 30 日間に視聴した映画を除外する。

# Item Attribute レコメンデーションの作成

<Info>
レコメンデーションは Admin / Manager / Marketer ロールのみが作成できます
</Info>

Item Attribute レコメンデーションを作成するには、次の手順を実行します。

1. MoEngage のサイドバーメニューで、Content メニュー項目 <img alt="content icon.png"  src="/images/moengage_99d274.png"  /> にカーソルを合わせます。**Content** メニューが表示されます。
2. **Recommendations** をクリックします。  
    <img  src="/images/moengage_208537.png"  />   
   Recommendations ページが表示されます。
3. **+ Create recommendation** をクリックします。  
    <img src="/images/moengage_c8b5a6.png" />
4. **Item attributes** モデルを選択し、**Next** をクリックします。 <img src="/images/moengage_a34177.png" />
5. **Recommendation** **name** フィールドに、レコメンデーションの名前を入力します。
6. **Recommendation description** フィールドに、レコメンデーションの説明を入力します。
7. **Catalog** ドロップダウンリストで、レコメンデーションを取得するカタログを選択します。
8. 次に、汎用ルールまたはターゲットルールを設定できます。
   - 汎用ルールを作成するには、**Item where** ドロップダウンリストで該当するアイテム属性を選択し、**Custom Value** オプションを選択します。 <img src="/images/moengage_68ec84.png" />
   - ターゲットルールを作成するには、**Item where** ドロップダウンリストで該当するアイテム属性を選択し、**User Property** オプションを選択します。  
     **注:** 定義したアイテム属性とユーザー属性が同じ種類の情報を持っていることを確認してください。
   - 汎用ルールとターゲットルールを組み合わせて作成することもできます。 <img src="/images/moengage_5bfdb0.png" />
9. **Filter items by user actions** トグルをオンにしてフィルタリング条件を追加し、顧客にレコメンドするアイテムを制御します。これらのフィルターは、コアレコメンデーションの結果にさらに適用されます。ユーザーアクションには 2 種類のフィルターがあります。  
    <img alt="user action filter.png" src="/images/moengage_583be5.png" />   
   - **Select user action to keep items**: マーケターは、フィルタリング用のユーザーアクション条件とレコメンデーション結果の両方に共通するアイテムのみを含めるユーザーアクション条件を定義できます。**+ User actions** をクリックし、含めるアイテムを選択します。
   - **Select user action to remove items**: マーケターは、フィルタリング用のユーザーアクション条件に従ってレコメンデーションアイテムからアイテムを削除するユーザーアクション条件を定義できます。**+ User actions** をクリックし、除外するアイテムを選択します。
10. **Sort the filtered items** セクションで、任意の数値属性 (例: price) でレコメンデーション結果を並べ替えます。
11. **Save** をクリックします。レコメンデーション一覧ページに、'Active' 状態のレコメンデーションが作成されます。

キャンペーンでこのレコメンデーションを使用する前に、実際のユーザー、ランダムサンプル、または特定のアイテムに対してテストしてください。詳細については、[Test a Recommendation](/ja/user-guide/content/recommendations/getting-started/test-a-recommendation) を参照してください。

# Basic Recommendations

Basic Recommendations は、フィルターとして機能するシンプルなカスタムルールのセットです。さらに、数値のカタログ属性でこれらのアイテムを並べ替えることもできます。Basic Recommendations は次のモデルで構成されています。

## 1. Item attributes

このモデルは、カタログ属性フィルターと数値のカタログ属性 (例: price) による並べ替えを使用して、手動のマーチャンダイジングルールを適用します。これらのレコメンデーションは、特定の種類の商品をプロモーションしたい場合に使用します。また、これらのレコメンデーションはユーザーのプロファイルに合わせてカスタマイズすることもできます。

### ユースケースの例

- 'New arrivals' セクションを公開する
- ブランドコレクションで興味を喚起する
- 季節のおすすめ商品でお祝いする
- ユーザーのスキルセットに合った理想的な求人をレコメンドする
- 顧客の近くにある地元のレストランを見つける。

## 2. User actions

このモデルは、ユーザーが最近エンゲージしたアイテムを思い出させるのに役立ちます。小売業界では、ユーザーがウィッシュリストを作成したりアイテムをカートに追加したりすることは、強い購入意欲を示しています。同様に、クラシファイド業界では、アイテムの閲覧は強い関心の指標と見なすことができます。これらのインタラクションを思い出させることに焦点を当ててキャンペーンをカスタマイズすることで、決定的な要因として機能させることができます。

### ユースケースの例

- カート放棄のリマインダーで失われた売上を回復する
- ユーザーのウィッシュリストに基づくパーソナライズされたキャンペーンでエンゲージメントを高める
- 最近閲覧したアイテムでユーザーを再エンゲージする
- さりげない後押しでリピート購入を促進する。

## 3. Catalog Alerts

Catalog Alerts は、価格や数量の変動などカタログの変化を監視し、ユーザーのインタラクションを分析することで、パーソナライズされたタイムリーなレコメンデーションをユーザーに提供します。カタログが更新されると大きな差異を検出し、エンゲージメントを高めてコンバージョンを促進できるパーソナライズされたコンテンツを含む、ターゲットキャンペーン向けのカスタマイズされたアラートを生成できます。

### ユースケースの例

- 値下げアラート
- 残りわずかアラート
- 再入荷アラート
- 値上げアラート

# よくある質問

<Accordion title="1 つのアカウントで作成できるレコメンデーションの上限数はいくつですか?">

1 つのアカウントで同時に保持できるアクティブなレコメンデーションは、Basic と Advanced の両方を含めて最大 100 件です。

</Accordion>
<Accordion title="ユーザーアクションレコメンデーションの保持期間はどのくらいですか?">

ユーザーアクションレコメンデーションは、[ユーザーアクションマッピング](/ja/user-guide/content/recommendations/getting-started/map-user-actions-settings)で設定したイベントについて、過去 30 日間のイベントデータに基づいて生成できます。

</Accordion>

キャンペーンでレコメンデーションを使用する前に、実際のユーザーまたはサンプルに対してテストしてください。詳細については、[Test a Recommendation](/ja/user-guide/content/recommendations/getting-started/test-a-recommendation) を参照してください。

Recommendations ページでは、作成したレコメンデーションを管理できます。レコメンデーションのステータスは一覧ページに表示されます。レコメンデーションの編集、アーカイブ、アーカイブ解除を行うことができます。

# レコメンデーションの編集

レコメンデーションを編集するには、次の手順を実行します。

1. MoEngage のサイドバーメニューで、Content メニュー項目 <img alt="content icon.png"  src="/images/moengage_74beb9.png"  /> にカーソルを合わせます。**Content** メニューが表示されます。
2. **Recommendations** をクリックします。   
    <img  src="/images/moengage_8bda2f.png"  />   
   Recommendations ページが表示されます。
3. 編集するレコメンデーションの鉛筆アイコンをクリックします。Edit Recommendation ページが表示されます。  
    <img src="/images/moengage_04e53e.png" />
4. 更新する設定を選択して必要な変更を行い、ページ下部の **Save** をクリックします。

変更を保存する前に、いくつかのサンプルユーザーで結果をテストすることをお勧めします。

# アーカイブまたはアーカイブ解除

Recommendations ページで、**Actions** 列の **Archive** アイコンをクリックすると、アクティブなレコメンデーションを無効にできます。 <img src="/images/moengage_ba58a4.png" />

**Actions** 列の **Unarchive** アイコンをクリックすると、アーカイブされたレコメンデーションを有効にできます。 <img src="/images/moengage_3be281.png" />

<Note>
  アーカイブされたレコメンデーションは結果を返しません。アーカイブされたレコメンデーションを参照しているアクティブなキャンペーンでは、アイテムが表示されません。これを防ぐには、キャンペーンでフォールバックが設定されていることを確認してください。
</Note>

# レコメンデーションのテスト

キャンペーンでこのレコメンデーションを使用する前に、実際のユーザー、ランダムサンプル、または特定のアイテムに対してテストしてください。詳細については、[Test a Recommendation](/ja/user-guide/content/recommendations/getting-started/test-a-recommendation) を参照してください。

HTML ランディングページエディターを使用すると、独自の HTML からランディングページを作成できます。これは、次のような場合に役立ちます。

- 別のツールで設計したランディングページをインポートする。
- チームがすでに開発した HTML を取り込む。
- MoEngage で直接カスタム HTML を記述して作成する。

HTML は次の 2 つの方法のいずれかで追加できます。

- **HTML Upload**: コードビューで HTML を記述または貼り付けます。
- **HTML Zip Upload**: HTML とそのアセットを含む ZIP ファイルをアップロードします。

# HTML エディターを開く

1. 左側のナビゲーションメニューで、**Content** をクリックし、**Landing pages** をクリックします。
2. **Create a landing page** をクリックし、ページ名とタグを定義します。
3. **Content** ステップの **Blank Templates** カードで、**Select** をクリックします。

<img alt="Blank Templates カードが選択された、ランディングページ作成の Content ステップ。" src="/images/lp-html-content-blank-templates.png" />

4. **Select a template** ダイアログで、**HTML Upload** または **HTML Zip Upload** を選択します。

<img alt="Blank Template、HTML Zip Upload、HTML Upload オプションが表示された Select a template ダイアログ。" src="/images/lp-html-select-template.png" />

# HTML Upload

**HTML Upload** を選択すると、**Code View** エディターで HTML を直接記述または貼り付けることができます。HTML が参照する画像やその他のアセットを追加するには、**Upload files to use in your template** の横にある **Upload** をクリックします。最初からやり直すには、**Clear** をクリックします。

<img alt="HTML ソースと、テンプレートで使用するファイルをアップロードするオプションが表示された、HTML Upload の Code View エディター。" src="/images/lp-html-upload-code-view.png" />

# HTML Zip Upload

**HTML Zip Upload** を選択すると、HTML とそのアセットを含む ZIP ファイルをアップロードできます。**Zip template** ダイアログで、ファイルをドラッグアンドドロップするか **Upload from computer** をクリックし、**Done** をクリックします。

<img alt="サイズ制限とファイルのガイドラインが表示された、HTML ZIP ファイルをアップロードするための Zip template ダイアログ。" src="/images/lp-html-zip-upload.png" />

アップロードできるのは 5 MB 以内の ZIP ファイルのみです。ZIP ファイルについては、次のガイドラインに従ってください。

- ZIP 内のファイル名に `*`、`/`、`\`、`&`、`~`、`"` を含めないでください。
- すべての画像は JPG、JPEG、PNG、または SVG 形式である必要があります。
- 画像に指定する相対パスは、大文字と小文字の区別を含め、ZIP のフォルダー構造と一致している必要があります。
- すべてのコンテンツファイルを含むフォルダーから ZIP ファイルを作成してください。

# プレビューと公開

HTML を追加したら、**Preview Landing page** をクリックして期待どおりに表示されることを確認し、ランディングページを公開します。

# ページをインタラクティブにする

カスタム HTML ランディングページでクリックの追跡、フォーム送信の取得、またはメール購読カテゴリの読み取りと書き込みを行うには、MoEngage JavaScript ブリッジを使用します。利用可能なメソッドと例については、[JavaScript Bridge for On-Site Messaging and Landing Pages](/ja/developer-guide/components-for-sdk/javascript-bridge/javascript-bridge-for-on-site-messaging-and-landing-pages) を参照してください。

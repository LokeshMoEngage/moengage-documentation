ランディングページとは、公開されたキャンペーンをクリックした顧客の注目を集めるために設計された専用の Web ページです。

これらのページは、製品の購入、イベントへの登録、追加情報の受け取りへのオプトインなど、顧客を望ましい成果へと導くために不可欠です。キャンペーンから得られた質の高いリードを、実際のエンゲージメントへと転換する効果的な方法です。

マーケターにとって、ランディングページは Web トラフィックの増加とコンバージョン率の向上を促進する重要な役割を果たします。

## ランディングページを使用する理由

通常の Web ページは静的で、一般的に多くの目標を持ち、Web サイト内の回遊を促します。カスタムのパーソナライズされたランディングページを使用すると、特定の顧客セグメントに合わせた最小限のページを作成できます。この最小限のアプローチを使用することで、訪問者をコンバージョン目標に集中させ、気が散る要素を排除できます。

ランディングページは、Push、E-mail、SMS、In-app、Web キャンペーンなど、他の MoEngage の戦略をシームレスに補完します。これにより、ユーザーはメールや通知から詳細情報を掲載したランディングページへとスムーズに移行でき、一貫したユーザー体験を実現できます。

# ランディングページ: トライアルとサブスクリプション

*Landing Pages* 機能では、柔軟なトライアル体験を提供しています。デフォルトでは、5 つの構築済みランディングページテンプレートを閲覧して、その構造と可能性を理解できます。これらのテンプレートを表示することはできますが、新しいページを作成したり公開したりすることはできません。

すべての機能を利用するには、30 日間の無料トライアルを開始できます。トライアルを有効にすると、次のことができます。

- エディターを使用してカスタムランディングページを作成する。
- ランディングページを公開する。

<Info>
トライアル期間中は、残り日数を示すバナーが UI の上部に表示されます。
</Info>

30 日間のトライアル期間が終了すると、作成したランディングページは 7 日間保存されますが、編集することはできません。その後、有料プランにアップグレードするか、トライアルをさらに 30 日間延長できます。

<Warning>
トライアルの延長は 1 回限りのオファーです。延長期間が終了した後は、トライアルを延長するオプションはありません。
</Warning>

延長トライアルもアップグレードなしで終了した場合、アクセス権は 5 つの構築済みテンプレートの閲覧のみに戻り、作成したページは保存されたままですが編集できません。フルアクセスを回復してページを使用するには、有料プランに移行する必要があります。

アップグレードする場合、またはプランについてご質問がある場合は、カスタマーサクセスマネージャー（CSM）に連絡するか、[サポートチケットを作成](/ja/user-guide/contact-support/raise-a-support-ticket-through-moengage-dashboard)してください。

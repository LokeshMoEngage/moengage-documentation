分析ページでは、ランディングページのパフォーマンスを明確に把握できます。主要な指標を追跡して、訪問者に響いている点や改善が必要な点を確認できます。このデータを使用してページのどの部分に改善が必要かを確認し、変更を加えてより良い成果を得ましょう。

# 分析ページにアクセスする

ランディングページを正常に作成すると、分析ページにリダイレクトされます。または、次の手順を実行して分析ページにアクセスします。

1. MoEngage ダッシュボードの左側のナビゲーションメニューで、**Content** をクリックし、**Landing pages** をクリックします。
2. 公開済みのランディングページをクリックします。分析ページにリダイレクトされます。

# ランディングページの詳細

このセクションでは、次のようなランディングページの詳細の概要を確認できます。

- 名前
- URL
- ランディングページの作成者
- ランディングページ ID
- ランディングページの作成日時

<img alt="スクリーンショット 2025-04-03 午前11.26.03.png" src="/images/moengage_3ea922.png" />

また、右上隅からランディングページの **Refresh**、**Duplicate**、**Edit** を行うことができます。

# 分析

このセクションには、選択したフィルターを使用したランディングページのすべての指標が表示されます。次の指標を確認できます。

- **Views**: ユーザーがランディングページを閲覧した回数。
- **Clicks**: ユーザーがランディングページをクリックした回数。
- **CTR**: クリック率。CTR = (Clicks/Impressions)\*100 として計算されます。

<img alt="スクリーンショット 2025-04-03 午前11.42.22.png" src="/images/moengage_e71712.png" />

### フィルター

次の条件で分析をフィルタリングできます。

- **Date range**: 選択した日付範囲の指標が表示されます。  
   <img alt="スクリーンショット 2025-04-03 午前11.46.25.png"  src="/images/moengage_4b13f2.png"  />
- **Metric**: 次の方法でランディングページの指標を表示できます。  
   <img alt="2025-04-03_11-49-37 (1).gif" src="/images/moengage_2556c6.png" />   
  - **Total metrics**: 閲覧数、クリック数、CTR にわたるユーザーエンゲージメントの包括的な概要が表示されます。
  - **Unique metrics**: 閲覧数、クリック数、CTR にわたる個々のユーザーエンゲージメントのユニーク数が表示されます。

## パフォーマンスの傾向

このセクションでは、ランディングページの指標が時間の経過とともにどのように変化したかを視覚化できます。以下に示すように、Chart ビューと Table ビューを切り替えて、データをより分かりやすく視覚化できます。

<img alt="2025-04-03_12-12-24 (1).gif" src="/images/moengage_6f2b8f.png" />

### Chart ビュー

<img alt="2025-04-03_12-15-18 (1).gif" src="/images/moengage_04a87a.png" />

Chart ビューでは、次の操作を実行できます。

- ランディングページのパフォーマンスについて、CTR、閲覧数、クリック数を視覚化します。
- 個々の指標を切り替えて、それぞれを個別に視覚化します。
- チャートの任意のセクションを拡大します。拡大するには、注目したい領域をクリックしてドラッグします。
- チャートをダウンロードします。ダウンロードするには、右上隅の **Export chart** をクリックします。

### Table ビュー

<img alt="スクリーンショット 2025-04-03 午後12.17.14.png" src="/images/moengage_8a1905.png" />

Table ビューでは、次の操作を実行できます。

- すべての指標を表形式で表示します。指標は日付ごとに表示されます。
- テーブルをエクスポートできます。エクスポートするには、右上隅の **Download CSV** をクリックします。

## コホートとバリアントの分析

このセクションには、ランディングページ用に作成されたコホートの各バリアントの指標が表示されます。

<img alt="スクリーンショット 2025-04-03 午後12.45.37.png" src="/images/moengage_23ddde.png" />

次の操作を実行できます。

- テーブルビューとチャートビューを切り替えます。
- データをコホートまたはバリアントでグループ化します。これらは行に表示されます。
- 表示する指標を選択します。これらは列に表示されます。
- 右上隅の **Export chart** または **Download CSV** をクリックして、それぞれチャートとテーブルをダウンロードします。

<img alt="2025-04-03_12-53-48 (1).gif" src="/images/moengage_662a97.png" />

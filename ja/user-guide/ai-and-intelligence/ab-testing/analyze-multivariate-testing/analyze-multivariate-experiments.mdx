A/B テストまたは多変量テストのパフォーマンスは、MoEngage Dashboard \> All Campaigns Page \> Campaign \> Analytics に移動して、キャンペーン分析ページで分析します。

# Push

プラットフォームごとにバリエーションのパフォーマンスを比較できる分析を表示します。王冠が付いた列は勝者バリエーション、つまりクリック率が最も高いバリエーションを表します。

# In-App Message

分析結果の用語について、以下で説明します。

## Best Variant

キャンペーンで最もパフォーマンスの高いバリアントを示します。テストのユーザー配分が静的な場合、MoEngage は各バリアントのクリック率を利用して勝者バリエーションを決定します。配分が動的な場合、MoEngage は選択された最適化指標を利用して勝者バリエーションを決定します。

## Chances to beat all other variations

各バリエーションが他のすべてのバリエーションを上回る確率を示します。これも、静的なユーザー配分の場合はクリック率に基づいて、動的な配分の場合は選択された最適化指標に基づいて計算されます。

## Uplift

コントロールグループと比較した、キャンペーンの主要コンバージョン目標におけるアップリフトを示します。この指標により、キャンペーンが成功したかどうかがわかります。アップリフトの測定方法の詳細については、[こちら](/ja/user-guide/campaigns-and-channels/getting-started/introduction/control-groups#uplift)を参照してください。

# On-site Message

以下の分析が表示され、バリエーションのパフォーマンスを比較して、最もパフォーマンスの高いバリエーションを導き出すことができます。

**Variation Performance** パネルの **View** トグルを使用して、テーブルとグラフを切り替えます。

# SMS

バリエーションごとのパフォーマンス指標(Clicked、Delivered、Conversions、Conversion Goals)の内訳を確認でき、バリエーションの効果を評価・比較できます。指標のドロップダウンで比較を表示する指標を選択し、ロケールまたはバリエーションでフィルタリングできます。バリエーションでグループ化することを選択すると、すべてのロケールにおける各指標のパフォーマンスがバリエーションごとにグループ化されます。棒グラフにマウスを合わせると、バリエーション内の特定の指標について各ロケールがどのようなパフォーマンスだったかを確認できます。グラフの横にあるテーブルオプションをクリックすると、表形式のビューに切り替えられます。

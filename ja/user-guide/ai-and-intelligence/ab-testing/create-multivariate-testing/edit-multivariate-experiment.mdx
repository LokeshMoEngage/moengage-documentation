---
title: "多変量テストを編集する"
description: "MoEngage で、配信前または配信中に、プッシュ、メール、アプリ内、オンサイトメッセージキャンペーンのアクティブな A/B テストおよび多変量テストを編集します。"
---

<Warning>
  アクティブなキャンペーンの配分率を編集すると、予期しない結果が生じます。MoEngage では、希望する新しい配分率で新しいキャンペーンを作成することをお勧めします。
</Warning>

次のステータスのキャンペーンでは、多変量テストを編集できます。

# Push

| キャンペーンタイプ | ステータス | 許可されている編集オプション |
| --- | --- | --- |
| One-Time Push | スケジュール済みだが未送信 | <ul><li>バリエーションの追加または削除。</li><li>バリエーションメッセージの編集。</li><li>バリエーションの配分率の編集。</li></ul> |
| Periodic Push | スケジュール済みで、1 つのインスタンスも送信されていない | <ul><li>バリエーションの追加または削除。</li><li>バリエーションメッセージの編集。</li><li>バリエーションの配分率の編集。</li></ul> |
| Periodic Push | スケジュール済みで、少なくとも 1 つのインスタンスが実行済み | <ul><li>バリエーションメッセージの編集は可能だが、バリエーションの追加または削除は不可。</li><li>バリエーションの配分率の編集。</li></ul> |
| Event-Triggered Push | Active または Paused | <ul><li>バリエーションメッセージの編集は可能だが、バリエーションの追加または削除は不可。</li><li>バリエーションの配分率の編集</li></ul> |

| --- | --- |
| Scheduled | <ul><li>バリエーションの追加または削除。</li><li>バリエーションメッセージの編集。</li><li>バリエーションの配分率の編集。</li></ul> |

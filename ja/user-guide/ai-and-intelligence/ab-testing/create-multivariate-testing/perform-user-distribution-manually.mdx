---

<Note>
  すべてのチャネルとキャンペーンで利用できます。
</Note>

# 手順

次の手順に従います。

1. キャンペーン作成プロセスのステップ 2 で、**\+ A/B test** をクリックします。
2. New Variation をクリックして新しいバリエーションを作成します。\
   または\
   Copy Variation をクリックして、以前に作成したバリエーションをコピーします。
3. **User Distribution** をクリックします。
4. 表示される User Distribution 画面で「Manual」をクリックします。 <img src="/images/moengage_16ebdc.png" alt="UserDistribution_Manual.png" />
5. 次の項目を設定します。
   | フィールド | 説明 |
   | --- | --- |
   | Objective (Optional) | テストの目的。 <br />**注**: In-App Message、On-Site Message、Web Personalization にのみ適用されます。 |
   | Variation | キャンペーンバリエーションのバリエーション名を変更します(In-App、On-Site Messaging、Web Personalization にのみ適用されます)。 <br />**注**: 作成できるバリエーションは最大 5 つまでです。 |
   | Campaign control group | キャンペーンを受け取るユーザーの割合を設定します。 <br />**注**: 次の場合、MoEngage は 2 回目のキャンペーンの受信を保証しません。 <ul><li>ユーザーが、いずれかのアクティブなキャンペーンのグローバルコントロールグループまたはキャンペーンコントロールグループに属している場合</li><li>ユーザーがキャンペーンを 2 回受け取る資格を満たしている場合</li></ul> |
   ![SetDistribution.png](/images/moengage_c36269.png)
6. **Done** をクリックしてキャンペーンバリエーションを保存します。\
   または\
   **Cancel** をクリックしてキャンペーンバリエーションを破棄します。

<Note>
  手動配分では、MoEngage はクリック率(CTR)に基づいて勝者バリエーションを決定します。コンバージョン率や収益など、勝者の選択に使用する指標を選ぶには、代わりに [Merlin AI による動的配分](/ja/user-guide/ai-and-intelligence/ab-testing/create-multivariate-testing/perform-user-distribution-dynamically-using-merlin-ai)を使用してください。
</Note>

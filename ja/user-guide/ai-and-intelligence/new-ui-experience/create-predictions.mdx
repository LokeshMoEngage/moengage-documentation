# ナビゲーション

予測は次のいずれかの方法で作成できます。

1. MoEngage のサイドバーメニューで、**Segment** メニュー項目 <img alt="Screenshot 2025-06-17 at 12.57.34 PM.png"  src="/images/moengage_75082e.png"  /> にカーソルを合わせます。**Segment** メニューが表示されます。
2. **Predictive Segments** をクリックします。  
    <img alt="7766.png"  src="/images/moengage_7d8230.png"  />
3. **All predictions** ページで、**Create prediction** をクリックします。  
    <img alt="Screenshot 2025-06-17 at 1.00.30 PM.png" src="/images/moengage_22abae.png" />

# 予測の定義

次の内容を定義できます。

- 何を予測したいか
- ビジネスにおけるコンバージョン（アンインストール、休眠など）の意味を定義し、必要な予測ユーザーを取得する

<img alt="Create_101.png" src="/images/moengage_83d833.png" />

作成ページで次の詳細を入力します。

| フィールド | 説明 |
| --- | --- |
| Prediction name | 予測の名前を入力します |
| Prediction type | 次のいずれかを選択します:   - Predict dormancy - Predict Uninstall - Predict Conversion - Predict Custom |
| Define Prediction | 予測期間は 7 日の倍数でのみ定義します。 |

<Warning>
デフォルトの予測タイプごとに、同時に実行できる予測は 1 つだけです。たとえば、アンインストール予測を作成し、それをアーカイブしてから再度作成することができます。
</Warning>

## 予測の設定

デフォルトの予測について、予測の定義と予測の設定を必要に応じて変更できます。MoEngage の予測では任意の予測を定義することもでき、カスタム予測を使用すると、目的の定義と設定で予測を作成できます。

ユーザーのアクションと非アクションの両方を予測できます。たとえば、購入する見込みのあるユーザーや、アプリを開かない見込みのあるユーザーなどです。また、イベント属性フィルターを適用して、iOS プラットフォームのみを対象とした予測やカテゴリー「フルーツ」を対象とした予測など、特定のアクションに対して予測することもできます。

<img alt="Pre_Set.png" src="/images/moengage_4c434d.png" />

MoEngage Merlin AI が予測の生成に使用するデータ量を定義し、予測を更新して最新の傾向カテゴリーを利用可能にする頻度を設定できます。また、予測を利用可能にする曜日も定義できます。

このフェーズでは、過去 60 日間のデータを使用して予測が生成され、予測は 7 日ごとに更新されます。

最初の予測インスタンスでは、予測の計算に最大 24～48 時間かかる場合があります。2 回目以降の予測インスタンスは、選択した曜日に利用可能になります。

これまで *Sherpa AI* と呼ばれていたすべての MoEngage AI 製品は、現在 *Merlin AI* という名称になっています。

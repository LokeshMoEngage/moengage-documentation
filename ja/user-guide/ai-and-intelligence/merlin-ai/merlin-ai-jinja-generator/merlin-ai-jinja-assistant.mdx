# はじめに

Merlin AI Jinja Assistant は、自然言語のクエリから、わかりやすい説明付きのパーソナライズされた Jinja コードを生成することで、キャンペーンにおける動的コンテンツの実装を簡素化するように設計されています。

## ユースケース

効果的なキャンペーンのパフォーマンスは、動的コンテンツとパーソナライズに依存しています。Jinja コーディングの技術的な習熟度が限られていても、Merlin AI Jinja Assistant を使用すると次のことが可能です。

- **複雑なロジックの生成**: 目的のパーソナライズを平易な言葉で記述すると、Merlin AI Jinja Assistant が複雑な Jinja コードを生成します。
- **エラーの削減**: 生成された Jinja コードは MoEngage の Jinja 向けに最適化されているため、手動で記述するよりもエラーが少なくなります。また、問題が発生した場合は、エラーを参照してコードを再生成できます。
- **技術的な依存の軽減**: 技術チームへの依存を最小限に抑えながら、高度なパーソナライズを実現できます。
- **理解の促進**: 生成されたすべてのコードには説明が付いているため、Jinja をより効果的に理解し学習できます。

<Info>
  - Merlin AI Jinja Assistant は、ユーザー属性、イベントデータ、商品のおすすめ、パーソナライズタイプに対応したロジック駆動の Jinja コードを生成し、メッセージが各ユーザーのコンテキストに固有の関連性を持つようにします。
  - 正確な Jinja コードを生成するには、構造化されたプロンプトを使用してロジックを平易な言葉で記述し、リクエストにパーソナライズタイプと属性名を指定する必要があります。ベストプラクティスについては、[Merlin AI Jinja Assistant のインスピレーションライブラリ](/ja/user-guide/ai-and-intelligence/merlin-ai/merlin-ai-jinja-generator/inspiration-library-for-merlin-ai-jinja-assistant)を参照してください。
</Info>

# 動的パーソナライズのタイプ

動的パーソナライズのタイプは次のとおりです。

| 動的コンテンツ | 説明 |
| --- | --- |
| ユーザー属性 | ユーザー属性は、各ユーザーについて保存されているユーザーのプロパティです。 |
| イベント属性またはキャンペーン属性 | イベント属性は、イベントトリガー型キャンペーンでのみ使用できます。イベントトリガー型キャンペーンに関連付けられた特定の属性値を使用して、パーソナライズを追加できます。 |
| Product set または recommendation set | MoEngage のレコメンデーションシステムは、レコメンデーションの設定と、構成された各カタログで利用可能なアイテムに基づいて、商品、コンテンツ、その他のアイテムを提案します。Product set はアイテムのセットを返します。パーソナライズのために、利用可能な特定のアイテム属性を Jinja に追加できます。 |

# Jinja コードを生成する

Merlin AI Jinja Assistant を使用して Jinja コードを生成するには、次の手順を実行します。

1. MoEngage ダッシュボードの左側のナビゲーションメニューで **Test & Debug** をクリックし、**Jinja AI** をクリックします。Jinja AI ページが表示されます。
2. **Generate Jinja** ボックスに、自然言語でクエリを入力します。
3. **Generate** をクリックします。Merlin AI Jinja Assistant がクエリを処理し、関連する Jinja コードを生成します。生成される Jinja コードの精度は、自然言語クエリの具体性に正比例します。
4. **Code** タブに、クエリから生成された Jinja コードが表示されます。
5. 生成されたコードの上に **Explanation** セクションが表示されます。**\>** 展開アイコンをクリックすると、生成された Jinja コードの機能に関する詳細な説明が表示されます。 <img src="/images/moengage_1e961e.png" />

# Jinja コードをテストする

コードをテストするには、次の手順を実行します。

1. Jinja AI ページで、**Test Code** タブをクリックします。
2. **Select user by** リストで、Email ID などのテストユーザープロファイルを選択します。
3. **User identifier value** ボックスにユーザーのメール ID を入力し、**Fetch user data** をクリックします。
4. **Output** セクションで、動的コンテンツの表示をプレビューして確認します。 <img src="/images/moengage_2efbc3.png" />
5. テストコードでエラーが発生した場合は、**Fix with AI** をクリックしてコードを再生成します。
6. テストコードの結果が得られたら、**Copy Code** をクリックし、MoEngage キャンペーンテンプレート内の該当するパーソナライズフィールドに Jinja コードを貼り付けて、動的コンテンツを実装します。

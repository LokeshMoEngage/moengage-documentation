# はじめに

Campaign Insights Agent は、MoEngage のキャンペーン分析ページに直接組み込まれた会話型 AI アシスタントです。シンプルな自然言語のクエリを使用して、キャンペーンのパフォーマンスを分析し、配信の問題を診断し、実用的なおすすめを受け取ることができます。

統計テーブルを手動で操作して指標を比較する代わりに、「クリック率が低いのはなぜですか?」や「このキャンペーンのパフォーマンスは過去のキャンペーンと比べてどうでしたか?」などの質問をエージェントに尋ねるだけで、数秒以内にコンテキストに沿った詳細な回答を受け取ることができます。

エージェントはマルチターンの会話をサポートしているため、フォローアップの質問をして、キャンペーンのパフォーマンスのあらゆる領域をさらに深く掘り下げることができます。

# エージェントの仕組み

Campaign Insights Agent は、一般的なアドバイスに頼りません。提供されるすべてのおすすめは、ワークスペースの実際のキャンペーンデータ、過去のパフォーマンス、キャンペーン固有のコンテキストに基づいています。

## ワークスペースを考慮した分析

エージェントを開いた時点で、エージェントは表示中のキャンペーンと、ワークスペースのより広範なコンテキストにすでにアクセスできます。

- **パフォーマンスのベースライン**: エージェントは、現在のキャンペーンの指標を、業界全体の平均ではなく、ワークスペース内の過去のパフォーマンスと比較します。
- **キャンペーン履歴**: 勝ちパターンの発見や過去のキャンペーンの比較をエージェントに依頼すると、エージェントはワークスペースからキャンペーンを取得して分析し、オーディエンスに対して特に効果があった戦略を特定します。
- **配信設定**: フリークエンシーキャップ、DND 設定、送信タイミングに関するおすすめは、ワークスペースの実際の設定に基づいています。

## キャンペーン固有のおすすめ

エージェントは、表示中の特定のキャンペーンに合わせて分析を調整します。

- **キャンペーンのテーマとコンテンツ:** エージェントは、件名、メッセージコピー、HTML テンプレート、A/B バリエーションなど、キャンペーンの実際のコンテンツを読み取ります。
- **チャネルと配信のコンテキスト**: エージェントは、キャンペーンがメールかプッシュ通知か、1 回限り、定期、イベントトリガー型のいずれであるかを把握し、それに応じて分析を調整します。
- **オーディエンスとターゲティング**: エージェントは、ターゲットにしたオーディエンスと反応したセグメントを評価し、ユーザーがこの特定のキャンペーンにどのようにエンゲージしたかに関するインサイトを提示します。

ワークスペースレベルの履歴とキャンペーンレベルのコンテキストを組み合わせることで、すべてのインサイトとおすすめを次のキャンペーンに直接活用できます。

## 専門エージェントによる詳細な分析

複雑なクエリの場合、Campaign Insights Agent は特定の種類の分析に特化した専門エージェントに処理を委任します。

| エージェント | 目的 |
| :-: | :-: |
| Analyzer | 複数の指標にわたる詳細なパフォーマンス分析を同時に実行します。 |
| Diagnostics | 根本原因分析を行い、特定の指標のパフォーマンスが低い理由を説明します。 |
| Comparator | 期間間またはセグメント間の比較を実行し、傾向とパターンを明らかにします。 |
| Reporter | 最終的な出力を整形・要約し、明確で構造化された回答にします。 |

この委任は、クエリの複雑さに基づいて自動的に行われます。これらのエージェントを選択または設定する必要はありません。

# Campaign Insights Agent にアクセスする

Campaign Insights Agent にアクセスするには、次の手順を実行します。

1. 1 回限り、定期、またはイベントトリガー型の Push または Email キャンペーンのキャンペーン分析ページに移動します。
2. 選択した期間のキャンペーン統計が存在する場合、AI によるインサイト機能を説明するプロモーションバナーがページに表示されます。キャンペーン分析ページには 2 つの呼び出しポイントがあります。
   <Frame>
     ![Insight Agent へのアクセス](/images/insight-agent-access.png)
   </Frame>
3. バナーまたは専用ボタンをクリックして、Insights Agent を開きます。5 つの事前構築済みのおすすめプロンプトを含むチャットインターフェースが開きます。

<Note>
  Campaign Insights Agent のエントリーポイントは、選択した期間にキャンペーンの統計が利用可能な場合にのみ表示されます。キャンペーンが保留中、スケジュール済み、または記録された統計がない場合、エージェントは表示されません。
</Note>

# Campaign Insights Agent を使用する

## おすすめのプロンプトを選択する

エージェントを開くと、最も一般的な分析ニーズをカバーするように設計された 5 つの事前構築済みプロンプトが表示されます。表示される具体的なプロンプトは、キャンペーンの配信タイプによって異なります。1 回限りのキャンペーンと定期キャンペーンは同じセットを共有し、イベントトリガー型キャンペーンにはトリガーファネルに合わせたセットが用意されています。どちらのセットも Email チャネルと Push チャネルで利用できます。任意のプロンプトを選択すると、すぐに分析を開始できます。

**1 回限りのキャンペーンと定期キャンペーン**

<Frame>
  ![プロンプトオプション](/images/prompt-options.png)
</Frame>

Campaign Insights Agent は現在、次のキャンペーンタイプで利用できます。

| プロンプト | 機能 |
| :-: | :-: |
| Summarize Performance | キャンペーンの主要なパフォーマンス指標の概要を提供し、効果があった点の特定、配信およびエンゲージメントのファネルにおける離脱の発見、最適化のための明確な次のステップの提示に役立ちます。 |
| Find winning patterns | 過去のキャンペーンを分析して、優れた成果をもたらした繰り返し現れるパターンや戦略を明らかにし、今後の送信で成功を再現できるようにします。 |
| Improve performance | オーディエンス、コンテンツ、タイミング、配信設定にわたってキャンペーンを評価し、エンゲージメント率とコンバージョン率を向上させるための具体的なステップを推奨します。 |
| Diagnose delivery failures | 送信パイプライン全体の配信失敗を調査し、バウンス、フリークエンシーキャップ、DND フィルタリングなどの根本原因を特定して、リーチを改善するための是正措置を提案します。 |
| Identify underperforming metrics | 低い開封率、低いクリック率、弱いコンバージョンなど、期待されるベンチマークを下回る指標を検出し、考えられる要因を説明します。 |

| Find winning patterns | 過去のトリガー型キャンペーンを比較して、最良の成果をもたらした戦略とパターンを明らかにします。 |

| Diagnose delivery failures | トリガーファネル全体での離脱の根本原因を明らかにし、是正措置を提案します。 |

## カスタムクエリを作成する

おすすめのプロンプトで質問がカバーされていない場合は、テキスト入力フィールドに独自の自然言語クエリを入力できます。エージェントは、キャンペーンのパフォーマンス、配信、コンテンツ、オーディエンスに関する幅広い質問に回答できます。

<Frame>
  ![Merlin AI サイドパネル](/images/merlin-ai-side.png)
</Frame>

### クエリの例

尋ねることができるカスタムクエリの例を次に示します。

| 目的 | プロンプトの例<br /> |
| :-: | :-: |
| エンゲージメントが低い根本原因を見つける | 「このキャンペーンの開封率が以前の送信よりも低いのはなぜですか?」 |
| 次のキャンペーンに向けた実用的なおすすめを得る | 「クリック率を向上させるために、次のキャンペーンで何を変更すべきですか?」 |
| 配信の離脱を理解する | 「配信ファネルのどこで最も多くのユーザーを失っていますか? また、その原因は何ですか?」 |
| 送信タイミングを最適化する | 「このキャンペーンは適切な時間に送信されましたか? エンゲージメントを高めるには、次のキャンペーンをいつ送信すべきですか?」 |
| オーディエンスの問題を診断する | 「ターゲティングが広すぎませんか? このキャンペーンに最も反応したオーディエンスセグメントはどれですか?」 |
| 効果があったことから学ぶ | 「過去のキャンペーンのうち、コンバージョン率が最も高かったのはどれですか? また、それらの共通点は何ですか?」 |
| A/B テスト戦略を改善する | 「どのバリエーションが勝ち、その理由は何ですか? 次回は何を変えてテストすべきですか?」 |
| コンテンツの改善点を特定する | 「件名やメッセージコピーのどのような点が、ユーザーがクリックする前に離脱する原因になっている可能性がありますか?」 |
| 送信間でキャンペーン形式を比較する | 「Push のタイマーベースのキャンペーンと画像ベースのキャンペーンを比較してください。」 |
| どのコンテンツスタイルがエンゲージメントを促進するかをテストする | 「緊急性を訴えるコンテンツが、感情に訴えるトーンのコンテンツよりも高い CTR をもたらすかどうかを調べてください。」 |
| コネクターの配信パフォーマンスを比較する | 「過去 30 日間のキャンペーンで、配信率が最も高かった SMS コネクターはどれですか?」 |
| SMS テンプレートのパフォーマンスを分析する| 「過去のキャンペーンの SMS テンプレートのうち、クリック率が最も高かったのはどれですか? また、それらの共通点は何ですか?」|
| パフォーマンスの高いキーワードを特定する| 「SMS コンテンツのどのキーワードが最も高いエンゲージメント率をもたらしていますか?」|
| メッセージの長さと形式を最適化する| 「SMS メッセージの長さは、配信やクリック率のパフォーマンスに影響していますか?」|

## 会話機能

Campaign Insights Agent は、次の会話機能をサポートしています。

**ストリーミング応答**

エージェントがクエリを処理するにつれて、応答が段階的に表示されます。応答全体が完了する前に分析を読み始めることができます。

**マルチターンの会話**

エージェントは、セッション内の会話履歴全体を保持します。コンテキストを繰り返すことなく、フォローアップの質問をすることができます。たとえば、配信パフォーマンスについて尋ねた後に、「バウンス率が平均より高いのはなぜですか?」とフォローアップすると、エージェントは前のクエリからコンテキストを理解します。

会話は無期限に保持されます。エージェントを閉じても、後で戻って中断したところから続けることができます。各会話はユーザー固有のものです。キャンペーンに関する会話はあなただけのものであり、同じキャンペーンを表示している他のユーザーには表示されません。

**AI が生成するフォローアップの質問**

各応答の後、エージェントはコンテキストに沿ったフォローアップの質問をクリック可能なプロンプトとして提案する場合があります。これらのフォローアップは分析に基づいて生成され、調査において論理的な次のステップに進むのに役立ちます。

<Note>
  フォローアップの提案は条件付きです。エージェントは、関連する次のステップが存在する場合にのみ提案を表示します。すべての応答にフォローアップの提案が含まれるわけではありません。
</Note>

| 分析領域 | 説明 |
| :-: | :-: |
| Audience | ターゲティングの効果とオーディエンスの構成を評価します。 |
| Content & Copy | メッセージコンテンツを分析し、エンゲージメントを高めるための改善点を提案します。 |
| Send Timing | キャンペーンが最適な時間に送信されたかどうかを評価します。 |
| Frequency Capping (FC) | フリークエンシーキャップの設定がキャンペーンのリーチに影響したかどうかを特定します。 |
| Do Not Disturb (DND) | DND 設定によってメッセージがドロップされたかどうかを特定します。 |
| Templates | キャンペーン間でテンプレートのパフォーマンスを比較します。 |
| Delivery Funnel | 送信済み、配信済み、失敗、開封、クリックという配信パイプライン全体を分析します。 |
| Click Performance | URL ごとのクリックの内訳を提供し、どのリンクがどのくらいの頻度でクリックされたかを示します。 |
| Device & OEM Breakdown | デバイスメーカー、アプリバージョン、休眠ステータス別にパフォーマンスを分類します。 |
| A/B Test Variations | コンバージョンや収益を含め、A/B テストのバリエーション間でパフォーマンスを比較します。 |
| Campaign Content | A/B バリエーションを含む実際のキャンペーンコンテンツ(メールの場合は HTML、プッシュの場合はメッセージテキスト)を確認します。 |
| Historical Comparisons | 現在のキャンペーンを類似の過去のキャンペーンと比較します。 |

# よくある質問

<Accordion title="Campaign Insights Agent はどこにありますか?">
  Campaign Insights Agent は、1 回限り、定期、イベントトリガー型の Email キャンペーンと Push キャンペーンのキャンペーン分析ページで利用できます。選択した期間の統計が利用可能な場合に表示されるプロモーションバナーを探してください。
</Accordion>

<Accordion title="フォローアップの質問はできますか?">
  はい。エージェントは、セッション内の会話履歴全体を保持します。必要な数だけフォローアップの質問をすることができ、エージェントは以前のクエリのコンテキストを使用します。
</Accordion>

<Accordion title="エージェントはどのチャネルをサポートしていますか?">
  エージェントは現在、1 回限り、定期、イベントトリガー型の配信タイプの Email キャンペーンと Push キャンペーンをサポートしています。追加のチャネルと配信タイプのサポートは、今後のリリースで追加される予定です。
</Accordion>

<Accordion title="エージェントはキャンペーンを変更できますか?">
  いいえ。Campaign Insights Agent は、キャンペーンデータへの読み取り専用のアクセスを提供します。パフォーマンスの分析、問題の診断、おすすめの提供は可能ですが、キャンペーンの作成、編集、削除はできません。
</Accordion>

<Accordion title="キャンペーン分析ページにエージェントが表示されないのはなぜですか?">
  エージェントのエントリーポイントは、選択した期間にキャンペーンの統計がある場合にのみ表示されます。キャンペーンが保留中、スケジュール済み、または記録された統計がない場合、エージェントは表示されません。また、これは早期アクセス機能であるため、CSM またはサポートチームによってお使いのアカウントで有効にしてもらう必要があります。
</Accordion>

<Accordion title="エージェントは他のワークスペースやテナントのデータにアクセスできますか?">
  いいえ。エージェントの範囲は、認証されているワークスペースに厳密に限定されています。テナントの分離はインフラストラクチャレベルで適用されており、クエリの入力内容に関係なく、エージェントが他のワークスペースのデータにアクセスすることはできません。
</Accordion>

<Accordion title="クエリできる期間に制限はありますか?">
  はい。分析クエリでは、リクエストごとに最大 30 日間の期間がサポートされます。
</Accordion>

<Accordion title="エージェントを閉じると、会話はどうなりますか?">
  会話は無期限に保持されます。エージェントを閉じても、後で戻って中断したところから続けることができます。
</Accordion>

<Accordion title="別のキャンペーンについて質問できますか?">
  エージェントの範囲は、現在表示しているキャンペーンに限定されています。別のキャンペーンの指標について単独で質問すること(たとえば、このキャンペーンを表示中に別のキャンペーンの配信率を尋ねること)はできません。ただし、「このキャンペーンのパフォーマンスを以前のメールキャンペーンと比較してください」などの比較の質問はできます。
</Accordion>

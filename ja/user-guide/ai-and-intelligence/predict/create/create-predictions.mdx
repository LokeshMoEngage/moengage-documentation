# ナビゲーション

予測は次のいずれかの方法で作成できます。

<Tabs>
  <Tab title="予測の作成">
    1. 左側のメニューで、**Segment** \> **Predictive Segments** をクリックします。 <img src="/images/moengage_2983d7.png" alt="pre 1.png" />
    2. **All predictions** ページで、**Create prediction** をクリックします。 <img src="/images/moengage_c9451e.png" alt="pre 2.png" />
  </Tab>
  <Tab title="新規作成">
    1. MoEngage ダッシュボードの左側のメニューで、**\+ Create new** をクリックします。 <img src="/images/moengage_239813.png" alt="pre 3.png" />
    2. **Prediction** をクリックして、Create prediction ページを開きます。 <img src="/images/moengage_e7c565.png" alt="pre 4.png" />
  </Tab>
</Tabs>

# 予測の定義

次の内容を定義できます。

- 何を予測したいか
- ビジネスにおけるコンバージョン（アンインストール、休眠など）の意味を定義し、必要な予測ユーザーを取得する

![Create\_101.png](/images/moengage_d1965a.png)

作成ページで次の詳細を入力します。

| フィールド | 説明 |
| --- | --- |
| Prediction name | 予測の名前を入力します |
| Prediction type | 次のいずれかを選択します: <ul><li>Predict dormancy</li><li>Predict Uninstall</li><li>Predict Conversion</li><li>Predict Custom</li></ul> |
| Define Prediction | 予測期間は 7 日の倍数でのみ定義します。 |

<Warning>
  デフォルトの予測タイプごとに、同時に実行できる予測は 1 つだけです。たとえば、アンインストール予測を作成し、それをアーカイブしてから再度作成することができます。
</Warning>

## 予測の設定

デフォルトの予測について、予測の定義と予測の設定を必要に応じて変更できます。MoEngage の予測では任意の予測を定義することもでき、カスタム予測を使用すると、目的の定義と設定で予測を作成できます。

ユーザーのアクションと非アクションの両方を予測できます。たとえば、購入する見込みのあるユーザーや、アプリを開かない見込みのあるユーザーなどです。また、イベント属性フィルターを適用して、iOS プラットフォームのみを対象とした予測やカテゴリー「フルーツ」を対象とした予測など、特定のアクションに対して予測することもできます。

![Pre\_Set.png](/images/moengage_e44f8a.png)

MoEngage Merlin AI が予測の生成に使用するデータ量を定義し、予測を更新して最新の傾向カテゴリーを利用可能にする頻度を設定できます。また、予測を利用可能にする曜日も定義できます。

このフェーズでは、過去 60 日間のデータを使用して予測が生成され、予測は 7 日ごとに更新されます。

最初の予測インスタンスでは、予測の計算に最大 24～48 時間かかる場合があります。2 回目以降の予測インスタンスは、選択した曜日に利用可能になります。

これまで _Sherpa AI_ と呼ばれていたすべての MoEngage AI 製品は、現在 _Merlin AI_ という名称になっています。

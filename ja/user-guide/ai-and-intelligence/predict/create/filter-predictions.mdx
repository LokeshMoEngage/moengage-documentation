# All Predictions ページ

作成されたすべての予測は、All Predictions ページに一覧表示されます。

![Allpredictionpage](/images/allpredictionpage.png)

All Predictions ページには次の情報が表示されます。

- 予測名
- 予測タイプ
- 予測のステータス
- 予測の作成日
- 予測の最終更新日時
- 予測品質
- 各傾向バケット間のユーザー分布

3 点メニューをクリックしてから **Archive** をクリックすると、任意の予測をアーカイブできます。

予測品質は、予測の精度を示す尺度です。予測が、アクションを実行するユーザーとアクションを実行しないユーザーをどの程度区別できるかを示します。品質が高いほど、予測は優れています。良好な予測の品質スコアは 60 を超える必要があります。これは、ROC 曲線下面積（AUC）の標準的な手法を使用して計算されます。

予測名、作成日、タイプ、ステータスで予測をフィルターできます。

いずれかの予測をクリックすると、予測の詳細ページが表示されます。

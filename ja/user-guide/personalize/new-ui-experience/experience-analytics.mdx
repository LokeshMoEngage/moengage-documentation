エクスペリエンス分析では、インプレッション、クリック、コンバージョンに関してエクスペリエンスがどのようなパフォーマンスを示したかについての重要な情報が提供されます。この情報は、ビジネス指標のパフォーマンスと価値の向上に役立ちます。

# Experience Analytics ページへのアクセス

Experience Analytics ページにアクセスするには、次の手順を実行します。

1. MoEngage のサイドバーメニューで、Personalize メニュー項目 <img alt="Screenshot 2025-06-13 at 2.31.12 PM.png"  src="/images/moengage_926fbc.png"  /> にカーソルを合わせます。**Personalize** メニューが表示されます。
2. **All Experiences** をクリックします。  
    <img alt="all experiences.png"  src="/images/moengage_b2cc62.png"  />
3. 分析情報を確認したいエクスペリエンスをクリックします。  
   新しい画面では、次のセクションを使用できます。

## Experience Details

このセクションには次の情報が含まれます。

- エクスペリエンスのタイプと名前
- エクスペリエンス ID
- エクスペリエンスの作成日時と更新日時
- エクスペリエンスを作成および更新したユーザー
- エクスペリエンスのステータス（*Active*、*Expired*、*Paused*、**Scheduled**）
- キャンペーンを **refresh/edit/duplicate/pause/resume** するオプション

## Analytics

このセクションの次の指標には、選択したエクスペリエンスについて追跡されたさまざまな統計情報と収益指標が表示されます。

<img alt="experience analytics.png" src="/images/moengage_d7f269.png" />

- **Date range** - キャンペーンが追跡される期間です。
- **Attribution type** - ドロップダウンから選択した属性に基づいてキャンペーンの統計情報を表示します。コンバージョンをこのキャンペーンに帰属させるために、MoEngage は以下で説明する 3 つの異なるモデルをサポートしています。  

  Click Through In-session View Through

  Click-Through Attribution は、ビジュアルエディターで設定された CTA をクリックしたユーザーが、クリック時点から設定されたアトリビューションウィンドウ内に実行したコンバージョン目標の数です。たとえば、ユーザーに午前 7 時に Web エクスペリエンスが配信され、午前 8 時に CTA をクリックした場合、アトリビューションウィンドウが 12 時間であれば、午後 8 時までのユーザーのコンバージョンイベントは Click-Through Attribution においてこのエクスペリエンスに帰属されます。

  In-session attribution は、セッション内トラッキングに基づいています。In-session attribution は、ビジュアルエディターで設定された CTA をクリックしてから 30 分以内にユーザーが実行したコンバージョン目標の数です。たとえば、ユーザーに午前 7 時に Web エクスペリエンスが配信され、午前 8 時に CTA をクリックした場合、アトリビューションウィンドウが 12 時間であれば、午前 8 時 30 分まで（セッション開始から 30 分以内）のユーザーのコンバージョンイベントは In-Session Attribution においてこのエクスペリエンスに帰属されます。

  View Through attribution はインプレッションベースのトラッキング方法であり、エクスペリエンス分析の読み込み時にデフォルトで表示されます。View-through attribution は、パーソナライズされた Web エクスペリエンスが配信されたユーザーが、エクスペリエンスを表示した時点から設定されたアトリビューションウィンドウ内に実行したコンバージョン目標の総数です。これは Experience Performance のデフォルトフィルターとして表示されます。たとえば、ユーザーに午前 7 時にある URL の Web エクスペリエンスが配信され、エクスペリエンスのアトリビューションウィンドウが 12 時間だった場合、午後 7 時までのユーザーのコンバージョンイベントは View-Through Attribution を使用してこのエクスペリエンスに帰属されます。

  ###
- **Select audience** - デフォルトでは、MoEngage はエクスペリエンス分析を **All Users** でフィルタリングします。ただし、エクスペリエンスの作成時に設定したターゲットオーディエンスをドロップダウンから選択して、関連する分析を確認することもできます。  
  <Info>
  すべての指標は、アプリのタイムゾーンで計算および表示されます。
  </Info>

### Experience Performance Stats

Experience performance では、エクスペリエンスがユーザーに与えた影響を確認できます。選択した期間内で特定のタイムスケール（時間、日、週、月）を選択することで、より簡潔なデータを確認できます。

キャンペーンの統計情報は、グラフ表示と表形式の表示を切り替えることもできます。

**統計セクションで実行できるアクション:**

- *数値表示* *(#)* または *パーセンテージ表示* *(%)* を選択して、統計情報を数値またはパーセンテージ値で表示します。  
   <img alt="performance stats number and percentage view.gif"  src="/images/moengage_8b96a3.png"  />
- セクション上部の*ドロップダウンで Unique または Total* を選択して、統計情報のユニーク数または合計発生数を表示します。  
   <img alt="total and unique occurrences.gif"  src="/images/moengage_3be2c4.png"  />

次の統計情報を使用できます。

|  |  |
| --- | --- |
| 指標 | 説明 |
| Impressions | この指標は、ターゲットオーディエンスのユーザーがマーケターによって設定されたパーソナライズされたバリエーションを受信した回数を表します。インプレッションが多いほど、エクスペリエンスのリーチが広いことを示します。 |
| Clicked | この指標は、パーソナライズされたバリエーションを受信した後にユーザーがターゲット要素をクリックした総数を表します。 |
| Conversions | この指標は、各パーソナライズされたバリエーションからユーザーがコンバージョンした回数を表示します。アクティブなエクスペリエンスの場合、コンバージョンはアクティブなエクスペリエンスのインスタンスごとにコンバージョンしたユニークユーザー数を表します。例:   - - - ユーザーが X 日に 1 つのパーソナライズされたバリエーションを受信し、Y 日に別のバリエーションを受信して、両日に 1 回ずつコンバージョンした場合、コンバージョンは 2 としてカウントされます（以前のバージョンでは 1 としてカウントされていました）。     - ユーザーが X 日に 1 つのパーソナライズされたバリエーションを受信し、同じバリエーションから 2 回コンバージョンした場合、コンバージョンは 1 としてカウントされます。     - ユーザーが X 日に同じエクスペリエンスの 2 つのパーソナライズされたバリエーションを受信し、両方でコンバージョンした場合、コンバージョンは 2 としてカウントされます。 |
| Click Through Rate (CTR) | 配信されたインプレッションの総数に対する総クリック数の割合（パーセンテージ）です。Click through rate = ((Total clicks) / (Total Impressions)) \* 100 |
| Conversion Rate (CVR) | 配信されたインプレッションの総数に対するプライマリ目標の総コンバージョン数の割合（パーセンテージ）です。  **Primary Goal Conversions** は、ユーザーが通知を受信した時点からアトリビューションウィンドウ（設定可能）内に発生したプライマリコンバージョン目標イベントの総数です。  **Conversion Rate -** コンバージョンイベントを実行したユーザーの割合（パーセンテージ）です。コンバージョン数はユニークとして追跡されます。各アトリビューションタイプのコンバージョン率は次のとおりです。   - - - View through attribution CVR = ((Unique conversions) / (Total impressions)) \* 100     - Click through attribution CVR - ((Unique conversions) / (Total clicks)) \* 100     - In-session attribution - ((Unique conversions) / (Total clicks)) \* 100 |

## Audience/Variation Performance

各オーディエンスおよびバリエーションにおけるパフォーマンス指標（インプレッション、クリック、コンバージョン、コンバージョン目標）の内訳を確認できるため、さまざまなオーディエンスとバリエーションの組み合わせの効果を評価および比較できます。指標のドロップダウンで比較を確認したい指標を選択し、次の方法でフィルタリングできます。

- **Group by audience** - 各バリエーションについて選択した指標のパフォーマンスを、オーディエンスごとにグループ化して一覧表示します。棒グラフにカーソルを合わせると、オーディエンス内で各バリエーションが指定した指標においてどのようなパフォーマンスを示したかを確認できます。
- **Group by variation -** すべてのオーディエンスにおける各指標のパフォーマンスを、バリエーションごとにグループ化して一覧表示します。棒グラフにカーソルを合わせると、バリエーション内で各オーディエンスが特定の指標においてどのようなパフォーマンスを示したかを確認できます。

## Conversion Goals Performance

このセクションは、エクスペリエンスに複数のコンバージョン目標を設定した場合に表示されます。このセクションでは、マーケターがエクスペリエンスに設定した目標のパフォーマンスを比較します。

**Total Conversions:** 各目標のすべての目標イベントが表示されます。つまり、ユーザーが 2 回購入した場合は 2 回と表示されます。これは、上記のセクションで説明したコンバージョンイベントに相当します。

**Unique Conversions:** 目標は、エクスペリエンスインスタンスごとにコンバージョンしたユーザー間でユニークです。これは、上記のセクションで説明した Conversions 指標に相当します。

**Revenue Metrics**

プライマリ目標で収益指標が有効になっている場合、エクスペリエンスについて 3 つの収益指標が表示されます。

- **Total Revenue** は、エクスペリエンスに帰属するコンバージョンイベント全体の合計注文金額の合計です。
- **Average Order value** = (Total Revenue)/(Number of Conversion Events)
- **Average revenue per user** = (Total Revenue)/(Number of Unique Conversions)

これらの収益指標は、View through、Click Through、In-session attribution のすべてのアトリビューションタイプで追跡されます。

## Info

エクスペリエンスのオーディエンス、スケジュール、コンバージョン目標に関する情報が含まれます。

Audience Scheduling Conversion Goals

このセクションには、エクスペリエンスのターゲット対象（エクスペリエンス作成の最初のステップで定義）に関する次のような情報が含まれます。

- ターゲットセグメント
- セグメンテーションフィルターと除外 - ユーザーセグメントには、すべてのユーザー、特定のユーザープロパティ、アフィニティ、行動に基づいてセグメント化されたユーザー、または AND/OR 条件を使用した複雑なクエリを用いるカスタムセグメントを指定できます。
- オーディエンスに定義されたセッション内クエリパラメーターが表示されます。

このセクションには、エクスペリエンスの配信スケジュールと配信制御（エクスペリエンスの優先度）に関する情報が含まれます。

- Delivery Schedule: このセクションには、エクスペリエンスが公開される時期に関する情報が含まれます。時間の選択、開始日時、終了日時、タイムゾーン情報の値を使用できます。
- Delivery Control: このセクションには、エクスペリエンスの優先度に関する情報が含まれます。

このセクションには、エクスペリエンス作成のステップ 3 で定義したコンバージョン目標に関する情報が含まれます。プライマリコンバージョン目標は、目標名の横に「**P**」アイコンが付いて表示されます。各コンバージョン目標について、次の情報を確認できます。

| Attribute Name | エクスペリエンスの目標設定の基準となる属性名です。 |
| Attribute Value | エクスペリエンスの目標設定の基準となる属性値です。 |

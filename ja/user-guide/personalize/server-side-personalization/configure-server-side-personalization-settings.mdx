この記事では、**APIs** 設定ページから MoEngage Dashboard でサーバーサイドパーソナライゼーションを簡単に構成する方法について説明します。

# API 設定

API 設定にアクセスするには、**MoEngage Dashboard -\> Settings -\> APIs** に移動します。

<img alt="Screenshot 2024-09-13 at 5.00.19 PM.png" src="/images/moengage_922718.png" />

次のパラメーターを使用できます。

- **Workspace ID** - MoEngage でアカウントを作成すると、Workspace ID と呼ばれる一意の識別子が割り当てられます。この値は、アカウントの識別と認証に使用されます。
- **API SECRET**- API SECRET は、Workspace ID とともに提供される認証キーです。Regenerate API Secret アイコンをクリックすると、API SECRET を再生成できます。
  <Warning>
  セキュリティ侵害が発生した場合を除き、MoEngage はキーの再生成を推奨していません。別の API SECRET を生成して保存すると、古い SECRET を使用した API 呼び出しは機能しなくなります。
  </Warning>

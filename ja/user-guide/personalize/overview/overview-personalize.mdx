# 概要

MoEngage Personalize は、ユーザーのニーズとプロダクトエクスペリエンスのギャップを埋める、つながったエクスペリエンスの作成に役立ちます。これらのリアルタイムでつながったエクスペリエンスは、プロダクトのコンバージョンの加速に役立ちます。

<img alt="Without_Personalize.png" src="/images/moengage_5dad20.png" />

<img alt="With_Personalize.png" src="/images/moengage_102aab.png" />

Web サイトのあらゆるコンポーネントを、スピーディーかつ大規模にパーソナライズできます。オーディエンスの過去の行動や好みのデータに基づいたパーソナライズされたオファーや商品レコメンデーションなど、さまざまなものが対象となり、初めて訪れる匿名の訪問者に対しても同様のことが可能です。

<Note>
  1 つのワークスペースで同時にアクティブにできる Personalize エクスペリエンスは最大 20 個です。この上限を引き上げるには、MoEngage の CSM またはサポートチームにお問い合わせください。
</Note>

## Personalize のメリット

- 各訪問者の好みに合わせたエクスペリエンスですべての訪問者を満足させ、コンバージョンを最大化します。
- 平均注文額（AOV）を高める商品レコメンデーション
- その瞬間のコンテキストを追加
- 大規模な A/B テスト
- 詳細な分析
- 匿名の訪問者向けのパーソナライゼーション

# ユースケース

**小売および E コマース**

- 訪問者の所在地や言語の好みに基づいて、メッセージ、コンテンツ、商品レコメンデーション、Web サイトのバナーをパーソナライズします
- 地域限定のセール割引やオファーを開始します

**銀行および金融**

- パーソナライズされた住宅ローンのオファー、コンテンツ、およびローンや商品レコメンデーションなどのその他のおすすめオファーを表示します。
- トラフィックソースや閲覧したページに基づいて、カスタマイズされたオムニチャネルキャンペーンを作成します。たとえば、訪問者がクレジットカードのオファーに関する Facebook 広告をクリックした場合、Web サイトで同じオファーを表示し、パーソナライズされたメールを送信して購入を促すことができます。
- リピーターには、ホームページでその訪問者専用に設計されたプロモーションオファーを表示できます。たとえば、訪問者が銀行の Web サイトでローン計算ツールに入力したもののローンを申し込まなかった場合、計算ツールに入力された変数に基づいてパーソナライズされたバナーを表示し、ローンの申し込みを促すことができます。

**メディアおよびエンターテインメント**

- 特定の地域の購読者向けに、購読プランのアップグレードオファーを表示する Web サイトバナーをパーソナライズします。
- 訪問者の過去の視聴履歴、関連商品、または最も人気のあるカテゴリに基づいて、コンテンツのレコメンデーションを表示します。
- プレミアム購読者と下位プランの購読者それぞれの購読プランに基づいて、カスタマイズされたオファーを含む異なる Web サイトバナーを表示します。
- ビジュアルノーコードエディターを使用して、コールトゥアクション（CTA）ボタンなどの Web サイトレイアウトをカスタマイズし、おすすめの番組やバナーを表示します。

**旅行およびホスピタリティ**

- インテント、最も閲覧されたフライト、ホテル、旅行先、好み、セグメントに基づいて、ページレイアウトを動的に再構成したり、Web サイトのバナーを差し替えたりします。
- リアルタイムのアクティビティに基づいて Web サイトのバナーを動的に差し替えることで、既知または匿名の訪問者を顧客に転換します。
- セグメントプロファイルとアフィニティに基づいて、訪問者向けのホームページバナーを変更します。たとえば、低予算の旅行者には格安の旅行先を、プレミアム顧客には高級旅行パッケージを表示できます。

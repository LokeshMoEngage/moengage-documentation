---

Edit HTML code を使用すると、選択した要素の HTML コードを編集して、より高度な変更を加えることができます。

**要素を編集するには、**

- Web ページ上で編集したい要素をクリックします
- **Edit HTML code** を選択します。その要素の HTML コードウィンドウに移動し、HTML で編集できます。

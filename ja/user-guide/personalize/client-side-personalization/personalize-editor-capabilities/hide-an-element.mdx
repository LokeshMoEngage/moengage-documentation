---
title: "要素の非表示"
description: "MoEngage Personalize エディターを使用して、Web ページ要素を DOM に残したまま一時的に非表示にします。レイアウト変更のテストに最適です。"
---

**要素を非表示にするには、**

- Web ページ上で非表示にしたい要素をクリックします
- **Hide element** を選択します。その要素の HTML コードウィンドウに移動し、HTML で編集できます。

Web ページ上の要素を非表示にすると、その要素は表示状態が更新された状態で、元の位置のまま DOM 内に残ります。

![hide unhide.gif](/images/moengage_3f2a87.png)

アプリの Recommendations セクションのレイアウトを変更して、MoEngage の Product Grid を使用することを検討しているとします。このような場合、レイアウトを確定する前に、現在のレイアウトを一時的に非表示にして MoEngage の Product Grid に置き換え、結果をテストしたいと考えるかもしれません。このような場面で非表示アイコンを使用すると、セクション、テキスト、画像、ボタンなど、アプリケーション内の定義済みの要素を非表示にできます。

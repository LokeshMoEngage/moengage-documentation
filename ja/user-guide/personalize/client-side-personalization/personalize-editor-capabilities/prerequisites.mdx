---
title: "前提条件"
description: "アプリケーションのインターフェース、テーマ、ウィジェットをカスタマイズするための MoEngage Personalize エディターの機能について説明します。"
---

Personalize Editor を使用すると、アプリケーションのインターフェース、要素、テーマ、ウィジェットを、ビジネスの基準、ワークフロー、好みに合わせてカスタマイズできます。

Personalize Editor は、[エクスペリエンスの作成](/ja/user-guide/personalize/client-side-personalization/client-side-personalization/create-client-side-personalization-experience#urls-to-personalize)ワークフローのステップ 2 で使用できます。この記事では、Personalize Editor の機能について詳しく説明します。

<Info>
  - MoEngage ダッシュボードに移動し、エクスペリエンスの作成を開始していることを確認してください。
  - パーソナライズする Web ページのアドレスを入力していることを確認してください。詳細については、[エクスペリエンスの作成](/ja/user-guide/personalize/client-side-personalization/client-side-personalization/create-client-side-personalization-experience#step-2-content)を参照してください。
</Info>

---
title: "Personalize エディターによる Web ページ内の要素の編集"
description: "MoEngage Personalize ビジュアルエディターのツールを使用して、Web ページの外観、背景色、配置、行動喚起ボタンをカスタマイズします。"
---

**Edit elements** を使用して、選択した要素やボタンの外観、背景色、配置、行動喚起（CTA）アクションをカスタマイズできます。

<img
  src="/images/moengage_5c27f3.png"
  alt="edit element.png"
  style={{ width:"79%" }}
/>

<Tabs>
  <Tab title="要素">
    選択した要素は、次の 2 つのセクションで編集できます。

    - **Appearance**
      |  |  |
      | --- | --- |
      | <ul><li>**Text:** 選択した要素に関連するテキストを追加します。</li><li>**Type Settings:** テキストのフォントスタイル、サイズ、色、太さ、配置をカスタマイズします。</li><li>**Background:** 選択した要素の背景に対して、次の編集を行うことができます。<ul><li>背景色を変更する。</li><li>画像 URL を埋め込む。</li><li>ローカルストレージから背景画像をアップロードする。</li></ul></li><li>**Dimensions:** 選択した要素の高さ、幅、角の丸みをピクセルまたはパーセンテージで設定します。</li><li>**Margin:** 選択した要素の上、下、左、右のマージンをピクセルまたはパーセンテージで設定します。</li><li>**Padding:** 上、下、左、右のパディングを設定して、選択した要素の境界線の内側でテキストの周囲にスペースを作ります。</li></ul> | <br /><img alt="Text settings appearance.png" src="/images/moengage_0ea650.png" style={{ display:"inline-block",textAlign:"center",verticalAlign:"middle" }} /> |
    - **Advanced**
      |  |  |
      | --- | --- |
      | カスタムスクリプトを使用して、選択した要素を編集することもできます。<ul><li>**CSS Classes:** クラス名を入力して、選択した要素にカスタムスタイルを適用します。</li><li>**Z index:** Z index の値を入力して、選択した要素が他の要素と重なる場合の表示方法を変更します。</li></ul> | <br /> <img alt="text settings advanced.png" src="/images/moengage_9bec74.png" style={{ display:"inline-block",textAlign:"center",verticalAlign:"middle" }} /> |
  </Tab>
  <Tab title="ボタン">
    選択したボタンは、次の 3 つのセクションで編集できます。

    - **Appearance**
      |  |  |
      | --- | --- |
      | <ul><li> **Text:** 関連するボタンラベルを追加します。</li><li> **Type Settings:** ボタンラベルのフォントスタイル、サイズ、色、太さ、配置をカスタマイズします。</li><li> **Background:** ボタンの背景に対して、次の編集を行うことができます。<ul><li>背景色を変更する。</li><li> ユーザーを関連する Web ページにリダイレクトする URL をボタンラベルに埋め込む。</li><li>ローカルストレージから背景ボタン画像をアップロードする。</li></ul></li><li> **Dimensions:** ボタンの高さ、幅、角の丸みをピクセルまたはパーセンテージで設定します。</li><li> **Margin:** ボタンの上、下、左、右のマージンをピクセルまたはパーセンテージで設定します。</li><li> **Padding:** 上、下、左、右のパディングを設定して、ボタンの境界線の内側でラベルの周囲にスペースを作ります。</li></ul>| <br /> <img alt="button appearance.png" src="/images/moengage_bfdb0c.png" style={{ display:"inline-block",textAlign:"center",verticalAlign:"middle" }} /> |
    - **Redirection**
      |  |  |
      | --- | --- |
      | <ul><li> **Enter webpage URL:** ユーザーがボタンをクリックしたときに関連するページにリダイレクトする URL を入力します。</li></ul> | <img alt="button redirect.png" src="/images/moengage_3647b5.png" style={{ display:"inline-block",verticalAlign:"middle" }} /> |
    - **Advanced**
      |  |  |
      | --- | --- |
      | カスタムスクリプトを使用して、選択したボタンを編集することもできます。<ul><li> **CSS Classes:** クラス名を入力して、ボタンにカスタムスタイルを適用します。</li><li> **Z index:** Z index の値を入力して、選択したボタンが他の要素と重なる場合の表示方法を変更します。</li></ul> | <br /> <img alt="button advanced.png" src="/images/moengage_01f1e8.png" style={{ display:"inline-block",textAlign:"center",verticalAlign:"middle" }} /> |
  </Tab>
</Tabs>

---
title: "要素の削除"
description: "MoEngage Personalize ビジュアルエディターの要素削除オプションを使用して、パーソナライゼーションの設定中に不要な Web ページ要素を削除します。"
---

要素を削除するには、

- 削除する要素をクリックします。
- **Delete element** を選択します。

<Info>
Web ページ上の要素を削除すると、その要素は DOM から削除されます。
</Info>

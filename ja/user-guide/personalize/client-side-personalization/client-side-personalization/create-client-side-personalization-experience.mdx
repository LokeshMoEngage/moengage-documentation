# 概要

MoEngage Personalize を使用すると、コンバージョンを加速させるリアルタイムでつながったエクスペリエンスを作成できます。これにより、顧客のニーズとブランドエクスペリエンスを結び付けることができます。

**前提条件**

1. パーソナライズされた Web エクスペリエンスを作成するには、Web SDK を統合する必要があります。詳細については、[Web SDK の統合](https://www.moengage.com/docs/developer-guide/personalize-sdk/sdk-integration/web-personalization-v2)を参照してください。
2. ブラウザーで広告ブロッカーを無効にしてください。広告ブロッカーが有効になっていると、パーソナライゼーションエディターは読み込まれません。

パーソナライズされたエクスペリエンスを作成するには、次のいずれかを行います。

1. **Create New** -\> **Experience** -\> **Web** **&** **App** -\> **Web (WYSIWYG)** に移動します。
2. **Personalize** -\> **All Experiences** に移動し、画面右上の **\+ Experience** をクリックします。次に、**Create experience** ペインで **Web (WYSIWYG)** をクリックします。

# Web エクスペリエンスの作成

新しい **Web Experience** を作成するには、次の 3 つのステップがあります。

1. **Target Users**: Web エクスペリエンスのオーディエンスを指定します。
2. **Content**: 選択したユーザー向けのバリエーションとパーソナライズされたコンテンツを指定します。
3. **Schedule and goals**: エクスペリエンスの配信スケジュール、コンバージョン目標、配信コントロールを指定します。

# ステップ 1: Target Users

このセクションには次の内容が含まれます。

### エクスペリエンスの詳細

- **Experience name** - エクスペリエンスを管理および識別するための名前を入力します。エクスペリエンス名は 5 文字以上 256 文字以下である必要があります。
- **Experience tags** - ドロップダウンリストからエクスペリエンスタグを選択します。タグを使用すると、エクスペリエンスにコンテキストを追加できます。たとえば、プラットフォームやアプリへのユーザーのオンボーディング用に作成したエクスペリエンスに、'onboarding' というタグを追加できます。詳細については、[タグ](/ja/user-guide/campaigns-and-channels/getting-started/introduction/campaign-tags)を参照してください。

### コントロールグループ

_Global control group_ をオンに切り替えると、グローバルコントロールグループ内のユーザーをエクスペリエンスから除外できます。詳細については、[コントロールグループ](/ja/user-guide/campaigns-and-channels/getting-started/introduction/control-groups)を参照してください。

この情報を入力したら、**Next** をクリックします。ポップアップが開きます。

## パーソナライズする URL

必要に応じて、パーソナライズする URL を指定します。

### Single Page

このオプションでは、パーソナライズする URL を 1 つ指定できます。

### Multiple Pages

このオプションでは、パーソナライズする URL を複数指定できます。これは、特定のユーザーセット向けに一連のページをパーソナライズしたい場合に特に便利です。たとえば、ユーザーがジーンズの広告をクリックした後に e コマース Web サイトにアクセスした場合を考えてみましょう。マーケターは、そのようなユーザー向けに、ジーンズや、ショートパンツやズボンなどの類似アイテムを一覧表示するページをカスタマイズしたいと考えるかもしれません。このような場合に、複数ページのパーソナライゼーションオプションが役立ちます。

複数のページを追加するには、**\+** 記号をクリックして、パーソナライズするページの URL を追加します。フィルター条件 _is_ および _is not_ を使用して、含める URL または除外する URL を正確に指定できます。また、特定のフレーズで始まる、終わる、または含む URL を含めたり除外したりするよう指定することもできます。たとえば、jeans を含む URL をすべて含めるには、次のようにフィルター条件を指定します。

### Custom Attributes

このオプションでは、Web ページの種類や Web ページ上の情報に基づいて、複数の Web ページをパーソナライズできます。これは、特定のユーザーセット向けに一連のページをパーソナライズしたい場合に特に便利です。たとえば、Web ページの URL 構造に依存せずに、その Web ページがサイトのホームページなのか、カテゴリページ（家具や電化製品など）なのかを判別できます。

複数の属性を追加するには、**\+** 記号をクリックし、ドロップダウンから属性を選択します。フィルター条件 _is_ および _is not_ を使用して、含める属性または除外する属性を正確に指定できます。また、特定のフレーズで始まる、終わる、または含む属性を含めたり除外したりするよう指定することもできます。たとえば、属性 pageType が product であるすべての Web ページをパーソナライズできます。

事前定義された属性タイプのリストから選択するか、[こちら](https://www.moengage.com/docs/developer-guide/personalize-sdk/sdk-integration/custom-attributes)の手順に従って独自のカスタム属性を定義できます。

![Custom Attributes Personalize.gif](/images/moengage_dbd359.png)

パーソナライズする URL を指定したら、**Validate** をクリックします。これにより、次の処理が行われます。

- - Web SDK が統合されているかどうかを確認します。
  - パーソナライズ対象として指定した URL に対して、すでにエクスペリエンスが設定されているかどうかを確認します。URL にすでにエクスペリエンスが追加されている場合は、UI にメッセージが表示されます。<img src="/images/moengage_bda644.png" alt="URLHasExperienceAlready.gif" />

ポップアップ右下の **Personalize URL** をクリックして、URL をパーソナライズできます。

# ステップ 2: Content

このステップでは、MoEngage の WYSIWYG エディターを使用して Web ページをパーソナライズします。エディターの機能の詳細については、[こちら](/ja/user-guide/personalize/client-side-personalization/personalize-editor-capabilities)を参照してください。

さらに、次のいずれかの方法を使用して A/B テストを実施できます。

1. バリエーション間でユーザートラフィックを手動で割り当てる
2. MoEngage の Merlin AI を使用して、バリエーション間でトラフィックを自動的に割り当てる

![Personalize AB Testing.gif](/images/moengage_818c99.png)

## ユーザートラフィックの手動割り当て

| フィールド | 説明 |
| --- | --- |
| Variation | デフォルトで次の 2 つのオプションがあります。 1. Default Variation 2. Variation 1  画面左下の _\+ Variation_ をクリックすると、別のバリエーションを追加できます。注: 各ターゲットオーディエンスに対して最大 5 つのバリエーションを追加できます。詳細については、[手動多変量テスト](/ja/user-guide/ai-and-intelligence/ab-testing/what-is-ab-or-multivariate-testing/manual-multivariate-experiment)を参照してください。 |
| Users (%total) | このフィールドでは、各バリエーションのユーザーの割合を定義できます。 |

パーソナライズされたエクスペリエンスの公開前でも公開後でも、バリエーション間のユーザートラフィックの割り当てはいつでも編集できます。

## Merlin AI を使用したユーザートラフィックの自動割り当て

| フィールド | 説明 |
| --- | --- |
| Variation | デフォルトで次の 2 つのオプションがあります。 1. Default Variation 2. ### その他のアクション

1. **View** - このオプションでは、選択したバリエーションのパーソナライズされたページを表示できます。
2. **Copy link** - このオプションでは、選択したバリエーションのパーソナライズされた URL のリンクをコピーできます。このオプションはデフォルトのバリエーションでは使用できません。これを使用して、レビューや承認のためにパーソナライズされた URL のリンクをチームと共有できます。
3. **Edit Page to Personalize -** 画面右上にあるペンアイコン付きの **Page to Personalize** リンクをクリックして、パーソナライズ対象の URL を編集することもできます。

すべてのバリエーションとオーディエンスセグメントの URL をパーソナライズしたら、**Next** をクリックして、エクスペリエンスの配信スケジュールと配信コントロールの定義に進みます。

# ステップ 3: Schedule and goals

このステップでは、エクスペリエンスのスケジュール条件を設定します。エクスペリエンスの開始日時と終了日時を設定できます。

![DeliverySchedule.png](/images/moengage_07a60d.png)

**コンバージョン目標**

コンバージョン目標を追加して、エクスペリエンスのビジネスメトリクスを追跡できます。最大 5 つのコンバージョン目標を追跡できます。任意のアプリイベントをコンバージョン目標のアクティビティとして選択でき、複数のコンバージョン目標を設定できます。最初の目標がプライマリ目標として扱われます。

複数のコンバージョン目標を使用すると、複数のビジネスメトリクスを追跡したり、ユーザーアクションのファネルを可視化したりできます。たとえば、次の内容を確認したい場合、複数のコンバージョン目標を使用して確認できます。

1. 商品ページを閲覧したユーザーは何人か？
2. そのうち何人がその商品をカートに追加したか？
3. そのうち何人が注文を完了したか？

**収益パフォーマンスの追跡**

MoEngage を使用すると、キャンペーンの収益を非常に簡単に追跡できます。キャンペーンの収益と ROI を確認できます。たとえば、コミュニケーションを送信した後に製品がどれだけの収益を上げたかという質問に答えることができます。

コンバージョン目標を設定する際に、'Revenue Performance' トグルを有効にすることで、収益を追跡する目標を選択できます。以下の例では、**_orderSuccessful_** イベントの収益を追跡するために、'Revenue performance' トグルを有効にする必要があります。

![ordersuccessful.png](/images/moengage_c0889a.png)

収益の追跡はオプションであり、必須ではありません。Revenue performance トグルを無効にすると、収益の追跡を無効にできます。目標を選択した後、注文の合計金額を取得する数値属性を選択できます。以下の例では、**_cartValue_** に注文の合計金額が含まれています。金額が報告される通貨を選択することもできます。

![Trackrevenue.png](/images/moengage_7d674b.png)

**アトリビューションウィンドウの設定**

アトリビューションウィンドウ、つまりユーザーがキャンペーンを受信した時点から計算される、コンバージョン目標を特定のキャンペーンに帰属させる期間を設定することもできます。デフォルトでは 36 時間に設定されています。上記の例では、5 時間に設定したとします。

![AttributionWindow.png](/images/moengage_9cc194.png)

**配信コントロール**

このオプションでは、エクスペリエンスに優先度を割り当てることができます。エクスペリエンスの優先度として、Low、Medium、High、Critical を割り当てることができます。**URL に複数のエクスペリエンスが作成されている場合、優先度の高いエクスペリエンスがユーザーに表示されます。**

画面右下の Publish をクリックして、エクスペリエンスを公開します。

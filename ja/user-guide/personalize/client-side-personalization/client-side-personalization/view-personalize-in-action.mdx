パーソナライゼーションの力を実際に確かめてみませんか？ガイドに従って、デモサイトで MoEngage Personalize の動的な機能を体験してください。以下に示す順序で、記載されているタスクを完了するだけです。各ステップを進めるにつれて、ブラウジングエクスペリエンスがあなたの操作に合わせてますますカスタマイズされていく様子をご覧ください。

私たちが作成したカスタマイズされたジャーニーを十分に体験するために、必ず所定の順序で手順に従ってください。

[デモ Web サイト](https://moecom-8605.myshopify.com/)

# 匿名訪問者向けのパーソナライゼーション

## 地理的位置に基づくエクスペリエンス

### 手順

インド、MEA、ヨーロッパ、米国のいずれかの地域から訪問している場合、ホームページが Designer Handbags カテゴリを強調するようにパーソナライズされていることがわかります。

さらに、ホームページをさらに下にスクロールすると表示されるオファーセクションも、同じカテゴリ内の特定のブランド向けにパーソナライズされています。

![地理的位置に基づくパーソナライゼーション](/images/moengage_591a82.png)

### 実装方法

Personalize の [In-session attributes](https://moengage-user-guide.mintlify.app/user-guide/personalize/client-side-personalization/client-side-personalization/create-client-side-personalization-experience#target-audience) に基づくターゲティングを使用すると、新規/匿名の訪問者が地理的位置に合わせてパーソナライズされたエクスペリエンスを得られるようにできます。

## コネクテッドエクスペリエンス

コネクテッドエクスペリエンスを使用すると、Google/FB/Instagram 広告などのチャネルからのメッセージングを Web サイトでも継続できます。

このシナリオでは、ユーザーが Instagram で **Sunglasses** カテゴリの広告を閲覧し、その広告をクリックして Web サイトにアクセスしたと仮定します。

### 手順

ブラウザーでこの [Web ページのリンク](https://moecom-8605.myshopify.com/?utm_campaign=sunglass)を開きます。

Web サイトは広告からのメッセージングを継続するようにカスタマイズされているため、コンテキストの継続性が維持され、ユーザーの直帰を防ぐのに役立ちます。

![コネクテッドエクスペリエンス](/images/moengage_50aa0e.png)

### 実装方法

[Query Parameter](/ja/user-guide/personalize/client-side-personalization/client-side-personalization/create-client-side-personalization-experience#target-audience) セッション内属性を使用すると、クエリパラメーターに基づいてソースを識別し、それに応じてエクスペリエンスを変更できます。同様のエクスペリエンスを設定するには、[こちらのユースケースドキュメント](/ja/use-cases/personalize/how-to-rearrange-elements-on-a-webpage-using-personalize)を参照してください。

## セッション内行動に基づくパーソナライズ

### 手順

[Furniture](https://moecom-8605.myshopify.com/collections/furniture) カテゴリにアクセスします。Furniture カテゴリまたは Web サイト上の他のカテゴリの商品をいくつか閲覧することもできます。

いくつかの商品を閲覧したら、[ホームページ](https://moecom-8605.myshopify.com/)にアクセスします。

ホームページが、最近閲覧したカテゴリを強調するようにカスタマイズされていることがわかります。さらに、Offers セクションも関連するオファーを表示するように更新されています。

![セッション内行動に基づくパーソナライゼーション](/images/moengage_f7abb7.png)

### 実装方法

このようなパーソナライゼーションは、Personalize の [In-session behavior](/ja/user-guide/personalize/client-side-personalization/client-side-personalization/create-client-side-personalization-experience#target-audience) 機能を使用して実現できます。

## ユーザー行動に基づくレコメンデーション

### 手順

Web サイトで、さまざまなカテゴリの商品ページをいくつか閲覧します。完了したら、ホームページに戻ります。

ホームページのバナーの下に **Recently Viewed** 商品グリッドが表示されることもわかります。Personalize を使用すると、ユーザー行動に基づくレコメンデーションを設定できます。

![最近閲覧した商品](/images/moengage_d7b1a6.png)

### 実装方法

Personalize を使用した商品レコメンデーショングリッドの設定については、こちらの[ユースケース記事](/ja/use-cases/personalize/how-to-show-recently-viewed-products-on-website)を参照してください。

さらに、[高度なレコメンデーションモデル](/ja/user-guide/content/recommendations/advanced-recommendations)を活用して、商品ページやカート/チェックアウトページにレコメンデーションを表示することもできます。

## ターゲティングとパーソナライゼーションにおけるカスタム属性の使用

### 手順

[Brass Maang Tika](https://moecom-8605.myshopify.com/products/yugshajewels-elegant-brass-maang-tikka) と [Gamebox](https://moecom-8605.myshopify.com/products/reliance-gamebox-elite-400black) の商品ページにアクセスして、実際の動作を確認してください。**Eligible for Free Shipping** タグは、**Sale Price \> 2000** の商品にのみ表示されます。

![ページ属性を使用したパーソナライズ](/images/moengage_1e3805.png)

### 実装方法

[MoEngage SDK では、データレイヤーを定義できます](https://www.moengage.com/docs/developer-guide/personalize-sdk/sdk-integration/custom-attributes)。これはカスタム属性とも呼ばれます。Personalize では、[これらのカスタム属性を使用して](/ja/user-guide/personalize/client-side-personalization/client-side-personalization/create-client-side-personalization-experience#target-audience)ターゲットを絞ったエクスペリエンスを提供できます。

### 手順

Password: Test@123

## コンテンツのパーソナライズに使用されるユーザー属性

### 手順

[ホームページ](https://moecom-8605.myshopify.com/)は、ユーザーのお気に入りのカテゴリ（バナー、オファー）に合わせてカスタマイズされています。ユーザープロファイルに保存されている属性を使用して、コンテンツをパーソナライズできます。

このエクスペリエンスでは、コンテンツ内でユーザーのファーストネームが使用されていることがわかります。

### ![ユーザープロファイルに基づくパーソナライゼーション](/images/moengage_441cfd.png)

### 実装方法

Personalize ビジュアルエディターでは、ユーザー属性、Content API、Content Block を使用して、ログインユーザー向けのエクスペリエンスをカスタマイズできます。詳細については、[こちらのセクション](/ja/user-guide/personalize/client-side-personalization/personalize-editor-capabilities/personalizing-content-in-webpage)を参照してください。

## セクションの並べ替え

### 手順

上部のカテゴリセクションが並べ替えられ、ユーザーのお気に入りのカテゴリ（この場合は **Gaming**）が前面に表示されています。

![セクションの並べ替え](/images/moengage_0638b1.png)

### 実装方法

ビジュアルエディターの[並べ替え機能](/ja/use-cases/personalize/how-to-rearrange-elements-on-a-webpage-using-personalize)を使用して、特定の要素やセクションを目立たせることができます。

## 過去の行動に基づくレコメンデーション

### 手順

ホームページには **Buy Again** 商品グリッドも表示されます。

これはログインユーザー向けに設定されていますが、ゲストチェックアウトを行った可能性のあるユーザーに対しても同じことができます。

![過去の行動に基づくレコメンデーション](/images/moengage_4597ad.png)

### 実装方法

Personalize を使用した商品レコメンデーショングリッドの設定については、こちらの[ユースケース記事](/ja/use-cases/personalize/how-to-show-recently-viewed-products-on-website)を参照してください。

さらに、[高度なレコメンデーションモデル](/ja/user-guide/content/recommendations/advanced-recommendations)を活用して、商品ページやカート/チェックアウトページにレコメンデーションを表示することもできます。

## インラインウィジェット: カスタム HTML/JS

### 手順

ログインユーザーとしてホームページを下にスクロールすると、ユーザー向けに動画が表示されます。

![カスタムコードによるパーソナライゼーション](/images/moengage_908be9.png)

### 実装方法

ホームページに埋め込まれた動画からわかるように、Personalize では[カスタム HTML/JS コードを追加](/ja/user-guide/personalize/client-side-personalization/personalize-editor-widgets/adding-widgets)できます。さらに、[既存の HTML コードを編集](/ja/user-guide/personalize/client-side-personalization/personalize-editor-capabilities/editing-elements-in-html)して、ユーザーエクスペリエンスを向上させることもできます。

## インラインウィジェット: カウントダウンバナー

### 手順

[Gaming カテゴリ](https://moecom-8605.myshopify.com/collections/gaming)にアクセスすると、カウントダウンタイマーが表示されます。Countdown Timer ウィジェットを使用すると、期間限定のオファーやプロモーションに注目を集めることができます。

![カウントダウンタイマーウィジェット](/images/moengage_29c9b0.png)

### 実装方法

Personalize WYSIWYG エディターには、開発者のリソースを必要とせずに Web ページ内に埋め込むことができる、すぐに使えるウィジェットが用意されています。

[このウィジェットには複数のセクションがあり](https://moengage-user-guide.mintlify.app/user-guide/personalize/client-side-personalization/personalize-editor-widgets/adding-widgets)、必要に応じて有効化、無効化、変更できます。

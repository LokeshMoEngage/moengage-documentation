エクスペリエンス分析では、インプレッション、クリック、コンバージョンの観点からエクスペリエンスがどのように機能したかに関する重要な情報が提供されます。この情報は、ビジネスメトリクスのパフォーマンスと価値を向上させるのに役立ちます。

# エクスペリエンス分析ページへのアクセス

エクスペリエンス分析ページにアクセスするには、次の手順に従います。

1. MoEngage ダッシュボードに移動し、左パネルの **Personalize** をクリックします。
2. **All Experiences** をクリックして、作成したすべてのエクスペリエンスを表示します。
3. 分析情報を表示したいエクスペリエンスの行をクリックします。\
   新しい画面では、次のセクションを利用できます。
   - [エクスペリエンスの詳細](/ja/user-guide/personalize/client-side-personalization/client-side-personalization/experience-analytics#experience-details)
   - [分析](/ja/user-guide/personalize/client-side-personalization/client-side-personalization/experience-analytics#analytics) - 選択したエクスペリエンスで追跡されるさまざまなメトリクスに関する情報が含まれます。[エクスペリエンスのパフォーマンス統計、](/ja/user-guide/personalize/client-side-personalization/client-side-personalization/experience-analytics#experience-performance-stats) [アクション/バリエーションのパフォーマンス、](/ja/user-guide/personalize/client-side-personalization/client-side-personalization/experience-analytics#audience/variation-performance) [コンバージョン目標のパフォーマンス](/ja/user-guide/personalize/client-side-personalization/client-side-personalization/experience-analytics#conversion-goals-performance)
   - [情報](/ja/user-guide/personalize/client-side-personalization/client-side-personalization/experience-analytics#experience-info) - エクスペリエンスのオーディエンス、スケジュール、コンバージョン目標に関する情報が含まれます。

# エクスペリエンスの詳細

このセクションには、次の情報が含まれます。

- エクスペリエンス名とタグ
- Experience ID - MoEngage におけるエクスペリエンスの一意の識別子です。
- エクスペリエンスの作成および更新の詳細
- チーム情報 - エクスペリエンスを作成および更新したユーザーです。
- エクスペリエンスのステータス - エクスペリエンスには、_Active_、_Expired_、_Paused_、**Scheduled** の状態があります。

# 分析

分析セクションには、パフォーマンス統計と収益メトリクスに関する情報が含まれます。

## グローバル分析フィルター

これらのフィルターは、Analytics タブのすべてのセクションに適用されます。

- **Date range** - パフォーマンス統計を表示する期間を選択します。
- **Attribution type** - ドロップダウンからアトリビューションタイプ（Click through、In-session、View through）を選択して、指定したアトリビューションタイプの分析情報を表示します。デフォルトのアトリビューションタイプは **View through attribution** です。詳細については、[コンバージョンとアトリビューション](/ja/user-guide/campaigns-and-channels/campaign-management-and-reports/conversion-and-attribution)を参照してください。
- **Select audience** - パフォーマンス統計を表示するオーディエンスを選択します。デフォルトのオーディエンスは **All Audiences** です。

## アトリビューションタイプ

コンバージョントラッキングを使用すると、マーケターはカスタムコンバージョンとして設定されたビジネス目標の達成につながったエクスペリエンスを確認できます。アトリビューションタイプには次の 3 つがあります。

- **View through attribution** - ビュースルーアトリビューションはインプレッションベースのトラッキングであり、エクスペリエンス分析の読み込み時にデフォルトで表示されます。ビュースルーアトリビューションは、パーソナライズされた Web エクスペリエンスが配信されたユーザーが、エクスペリエンスを閲覧した時点から設定されたアトリビューションウィンドウ内に実行したコンバージョン目標の合計数です。これは、Experience Performance のデフォルトフィルターとして表示されます。たとえば、ユーザーに午前 7 時にある URL の Web エクスペリエンスが配信され、エクスペリエンスのアトリビューションウィンドウが 12 時間の場合、午後 7 時までのユーザーのコンバージョンイベントは、ビュースルーアトリビューションを使用してこのエクスペリエンスに帰属されます。
- **Click-through attribution** - クリックスルーアトリビューションは、ビジュアルエディターで設定された CTA をクリックしたユーザーが、クリックした時点から設定されたアトリビューションウィンドウ内に実行したコンバージョン目標の数です。たとえば、ユーザーに午前 7 時に Web エクスペリエンスが配信され、午前 8 時に CTA をクリックし、アトリビューションウィンドウが 12 時間の場合、午後 8 時までのユーザーのコンバージョンイベントは、クリックスルーアトリビューションでこのエクスペリエンスに帰属されます。
- **In-session attribution -** セッション内アトリビューションは、セッション内トラッキングに基づいています。セッション内アトリビューションは、ビジュアルエディターで設定された CTA を _クリックしてから 30 分以内_ にユーザーが実行したコンバージョン目標の数です。たとえば、ユーザーに午前 7 時に Web エクスペリエンスが配信され、午前 8 時に CTA をクリックし、アトリビューションウィンドウが 12 時間の場合、午前 8 時 30 分まで（セッション開始から 30 分以内）のユーザーのコンバージョンイベントは、セッション内アトリビューションでこのエクスペリエンスに帰属されます。

**Attribution Window** - アトリビューションウィンドウは、特定のコンバージョン目標を持つエクスペリエンスをユーザーが受信またはクリックした時点から計算される期間です。たとえば、購入をコンバージョン目標とする 2 つのエクスペリエンスが作成されたとします。エクスペリエンス E1 は H 時間の時点で、エクスペリエンス E2 は H\+12 時間の時点で作成されます。顧客は、H\+15 時間の時点でエクスペリエンス C1 および C2 により購入のコンバージョン目標を達成します。顧客のコンバージョンは、E1 と E2 の両方に帰属されます。

<Info>
  すべてのメトリクスは、アプリのタイムゾーンで計算および表示されます。
</Info>

## エクスペリエンスのパフォーマンス統計

エクスペリエンスのパフォーマンスでは、エクスペリエンスの効果を確認できます。

**統計セクションで実行できるアクション**

- _数値ビュー_ _(#)_ または _パーセンテージビュー_ _(%)_ を選択して、統計を数値またはパーセンテージ値で表示します。

![performance stats number and percentage view.gif](/images/moengage_2c25a4.png)

- セクション上部の _ドロップダウンで Unique または Total_ を選択して、統計のユニーク件数または合計件数を表示します。

![total and unique occurrences.gif](/images/moengage_9570b0.png)

次の統計を利用できます。

|  |  |
| --- | --- |
| メトリクス | 説明 |
| Impressions | このメトリクスは、ターゲットオーディエンスのユーザーが、マーケターが設定したパーソナライズされたバリエーションを受信した回数を表します。インプレッションが多いほど、エクスペリエンスのリーチが広いことを示します。 |
| Clicked | このメトリクスは、パーソナライズされたバリエーションを受信した後に、ユーザーがターゲット要素をクリックした合計回数を表します。 |
| Conversions | このメトリクスは、各パーソナライズされたバリエーションからユーザーがコンバージョンした回数を表示します。アクティブなエクスペリエンスの場合、コンバージョンはアクティブなエクスペリエンスのインスタンスごとにコンバージョンしたユニークユーザーの数を表します。例: <br />- ユーザーが X 日目に 1 つのパーソナライズされたバリエーションを受信し、Y 日目に別のバリエーションを受信して、両日に 1 回ずつコンバージョンした場合、コンバージョンは 2 としてカウントされます（以前のバージョンでは 1 としてカウントされていました）。<br />- ユーザーが X 日目に 1 つのパーソナライズされたバリエーションを受信し、同じバリエーションから 2 回コンバージョンした場合、コンバージョンは 1 としてカウントされます。<br />- ユーザーが X 日目に同じエクスペリエンスの 2 つのパーソナライズされたバリエーションを受信し、両方でコンバージョンした場合、コンバージョンは 2 としてカウントされます。 |
| Click Through Rate (CTR) | 配信されたインプレッションの合計数に対する合計クリック数の割合（パーセンテージ）です。クリックスルー率 = ((合計クリック数) / (合計インプレッション数)) \* 100 |
| Conversion Rate (CVR) | 配信されたインプレッションの合計数に対するプライマリ目標の合計コンバージョン数の割合（パーセンテージ）です。**Primary Goal Conversions** は、ユーザーが通知を受信した時点からアトリビューションウィンドウ（設定可能）内に発生したプライマリコンバージョン目標イベントの合計数です。**Conversion Rate** - コンバージョンイベントを実行したユーザーの割合（パーセンテージ）です。コンバージョン数はユニークとして追跡されます。各アトリビューションタイプのコンバージョン率は次のとおりです。 - - - ビュースルーアトリビューション CVR = ((ユニークコンバージョン数) / (合計インプレッション数)) \* 100     - クリックスルーアトリビューション CVR - ((ユニークコンバージョン数) / (合計クリック数)) \* 100     - セッション内アトリビューション - ((ユニークコンバージョン数) / (合計クリック数)) \* 100 |

## オーディエンス/バリエーションのパフォーマンス

各オーディエンスおよびバリエーションにおけるパフォーマンスメトリクス（インプレッション、クリック、コンバージョン、コンバージョン目標）の内訳を確認できるため、さまざまなオーディエンスとバリエーションの組み合わせの有効性を評価および比較できます。メトリクスのドロップダウンで比較を表示したいメトリクスを選択し、次の方法でフィルタリングできます。

- **Group by audience** - オーディエンスごとにグループ化して、各バリエーションで選択したメトリクスのパフォーマンスを一覧表示します。棒グラフにカーソルを合わせると、オーディエンス内の指定したメトリクスについて各バリエーションがどのように機能したかを確認できます。
- **Group by variation -** バリエーションごとにグループ化して、すべてのオーディエンスにおける各メトリクスのパフォーマンスを一覧表示します。棒グラフにカーソルを合わせると、バリエーション内の特定のメトリクスについて各オーディエンスがどのように機能したかを確認できます。

## コンバージョン目標のパフォーマンス

このセクションは、エクスペリエンスに複数のコンバージョン目標を設定した場合に表示されます。このセクションでは、マーケターがエクスペリエンスに設定した目標のパフォーマンスを比較します。

**Total Conversions:** 各目標のすべての目標イベントが表示されます。つまり、ユーザーが 2 回購入した場合は 2 回表示されます。これは、上記のセクションで説明したコンバージョンイベントに相当します。

**Unique Conversions:** 目標は、エクスペリエンスインスタンスごとにコンバージョンしたユーザー全体でユニークです。これは、上記のセクションで説明した Conversions メトリクスに相当します。

**収益メトリクス**

プライマリ目標で有効になっている場合、エクスペリエンスには次の 3 つの収益メトリクスが表示されます。

- **Total Revenue** は、エクスペリエンスに帰属されたコンバージョンイベント全体の合計注文金額の合計です。
- **Average Order value** = (Total Revenue)/(コンバージョンイベント数)
- **Average revenue per user** = (Total Revenue)/(ユニークコンバージョン数)

これらの収益メトリクスは、すべてのアトリビューションタイプ（ビュースルー、クリックスルー、セッション内アトリビューション）で追跡されます。

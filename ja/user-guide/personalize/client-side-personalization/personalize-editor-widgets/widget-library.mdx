---

ウィジェットライブラリを使用すると、カスタマイズしたウィジェットを保存して再利用できます。

### ライブラリにウィジェットを追加する

- 要素を右クリックします
- **+ Add Widget** を選択します
- 商品グリッドを選択します

ウィジェットを Web ページに追加する際に **Add to widget library** オプションを選択すると、そのウィジェットをライブラリに保存できます。

<img alt="ライブラリにウィジェットを追加.gif" src="/images/moengage_a7e93d.png" />

- すでにエクスペリエンスの一部となっているウィジェットを追加するには、エクスペリエンスを編集し、ウィジェットを選択して **Add to widget library** を選択するだけです。

### ライブラリに保存したウィジェットを再利用する

ウィジェットがライブラリに追加されると、作成した任意のエクスペリエンスで再利用できます。

<img alt="ライブラリからウィジェットを再利用.gif" src="/images/moengage_648f42.png" />

MoEngageには、製品ダッシュボードに組み込まれた機能リクエストシステムが用意されており、機能を提案できます。これにより、MoEngageのプロダクトチームおよびリーダーシップチームと直接アイデアを共有できます。

## どのように役立つのか

MoEngageはお客様からの提案を大切にしており、アイデアやリクエストをレビューまたは更新した際にはお知らせします。また、次のことも可能になります。

- 製品の意思決定者からリクエストに対するタイムリーなフィードバックを得る
- 今後のリリースについてより深い洞察を得る
- 機能開発への影響力を高める

毎月、MoEngageのプロダクトチームと関係者が上位5〜10件の顧客リクエストをレビューし、個別に回答します。条件を満たしたものはロードマップに組み込まれます。

これらの優先順位付け会議でリクエストを取り上げてもらうには、**Submit a request** ページで必要な詳細をすべて入力してください。

## 製品アイデアを送信する

機能または製品アイデアを提案するには、次の手順を実行します。

1. MoEngageダッシュボードで、上部のナビゲーションバーにある **Need help** をクリックします。
2. **Submit product idea** をクリックします。Feedback Portalに移動します。
3. 左側のナビゲーションパネルには、次の3つのセクションがあります。

### リクエストを作成する

新しい機能リクエストまたは製品アイデアを送信するには:

1. MoEngageダッシュボードで、上部のナビゲーションバーにある **Need help** をクリックします。
2. **Submit product idea** をクリックします。Feedback Portalが開きます。

<Frame>
  ![製品アイデアの送信](/images/SubmitProductIdea.png)
</Frame>

3. 左側のナビゲーションパネルで、**Requests** をクリックします。ワークスペースで以前に送信されたすべてのリクエストのリストが表示されます。
4. **\+ Create** をクリックします。**Create a ticket** ウィンドウが表示されます。

<Frame>
  <img
    src="/images/create-a-feed.png"
    width="896"
    height="1058"
    alt="フィードの作成"
    title="フィードの作成"
  />
</Frame>

5. 次のフィールドに入力します。

| フィールド | 必須 | 説明 |
| --- | --- | --- |
| **Title** | はい | リクエストを要約した簡潔なタイトルを入力します。 |
| **Description** | はい | ユースケースや期待される成果を含め、機能やアイデアの詳細な説明を入力します。 |
| **Attachment** | いいえ | クリックまたはドラッグして、補足資料、スクリーンショット、参考資料をアップロードします。 |
| **Module** | いいえ | ドロップダウンから関連する製品モジュールを選択します。利用可能なオプションには、Campaigns、Flows、Push Notifications、Email、SMS, MMS & RCS、WhatsApp、Inbound Channels、Cards、Data、Account Management、Analyticsなどがあります。 |
| **Submodule** | いいえ | 該当する場合はサブモジュールを選択します。利用可能なサブモジュールは、選択したモジュールによって異なります。たとえば、**SMS, MMS & RCS** を選択すると、SMS、MMS、RCS、TCPA & SMS complianceなどのサブモジュールオプションが表示されます。 |
| **Type** | いいえ | リクエストのタイプとして、Feature request、Issue、Otherのいずれかを選択します。 |
| **Requester email** | いいえ | リクエスト者のメールアドレスです。 |
| **Created by** | いいえ | リクエストを作成する人のユーザーIDまたは名前を入力します。 |

6. **Create ticket** をクリックします。チケットが作成され、Requestsリストに表示されます。

### リクエストを表示および追跡する

リクエストを送信した後は、**Requests** セクションから追跡できます。リクエストリストには、各エントリについて次の詳細が表示されます。

| 列 | 説明 |
| --- | --- |
| **Title** | 送信されたリクエストのタイトルです。クリックすると展開され、説明の全文が表示されます。 |
| **Created at** | リクエストが送信された日付です。 |
| **Insights** | リクエストに関連付けられたインサイトまたはインタラクションの数です。 |
| **Created by** | リクエストを送信したユーザーの名前です。 |

**All** ドロップダウン、**Filter** オプション、または検索アイコンを使用して、リクエストのリストを絞り込むことができます。

### Labs

1. 左側のナビゲーションパネルで **Labs** をクリックすると、作業項目に変換されたリクエストが表示されます。
2. **Active** タブと **Past** タブを使用して、進行中の作業項目と完了した作業項目を切り替えます。
3. 特定の項目を検索したり、価値があると思う作業項目に賛成票を投じたり、コメントを追加して追加のコンテキストを共有したりできます。

### Roadmaps

左側のナビゲーションパネルで **Roadmaps** をクリックすると、今後の四半期に予定されている機能と機能強化が表示されます。

## 機能のステータス

送信したすべての機能リクエストに表示されるステータスは次のとおりです。

| ステータス | 意味 |
| --- | --- |
| Awaiting feedback | 他のお客様からの需要を見極めている間、リクエストはこのステータスのままになります。 |
| Planned | このリクエストはロードマップに含まれていますが、まだ着手していません。 |
| Building | このリクエストは現在開発中です。 |
| Released | このリクエストは完了しています。使用方法についてはステータスメッセージを参照してください。 |
| Declined | このリクエストは内容が不明確であるか、すでに存在するか、製品の方向性と一致していません。詳細についてはステータスメッセージを参照してください。 |

このプロセスについてご質問がある場合は、[product@moengage.com](mailto:product@moengage.com) までご連絡ください。

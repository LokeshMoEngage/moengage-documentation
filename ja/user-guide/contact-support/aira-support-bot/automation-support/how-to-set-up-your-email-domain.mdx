MoEngageでのメールドメインの設定がよりすばやく簡単になり、プロモーションメール、トリガーメール、トランザクションメールの送信を遅延なく開始できます。この記事では、AIRAを使用してリクエストを送信するための主な手順とベストプラクティスを説明します。

## 前提条件

- **MoEngageダッシュボード** へのアクセス権。
- 設定したいメールドメイン。

## 手順

**MoEngageダッシュボード** から直接AIRAボットを使用して、新しいメールドメインの設定リクエストを送信するには、次の手順を実行します。

1. AIRAボットを起動するには、**Need help** をクリックし、**Support** を選択します。

   <img
     src="/images/moengage_5e1ff0.png"
     style={{ width:"50%" }}
   />
2. **Ask a question** をクリックし、チャットウィンドウにプロンプトを入力します。

   <img
     src="/images/moengage_1d5cff.png"
     style={{ width:"58%" }}
   />

   <Info>
     メールドメインを設定したいことを示すプロンプトであれば、どのようなものでも使用できます。以下のオプションは、ドメイン設定プロセスを開始するためのほんの一例です。
     1. Set up an email.
     2. New email setup.
     3. Email onboarding.
     4. Add a new email domain.
   </Info>
1. **メールドメインタイプを選択する**:\
   AIRAから直接、1つ以上のメールドメインタイプの設定リクエストを送信できるようになりました。
   1. Transactional: 注文確認やパスワードリセットなどの重要なメッセージ用。
   2. Promotional: マーケティングおよびキャンペーン関連のメール用。
   3. Triggered: カート放棄メールなどの行動ベースのコミュニケーション用。

      <Info>
        ルートドメインはトランザクションメールにのみ使用してください。その他のすべてのタイプについては、送信者レピュテーションを維持し、到達率を向上させるために、サブドメインを設定することをお勧めします。
      </Info>
      詳細については、[IPアドレスとドメイン](/ja/user-guide/campaigns-and-channels/email/getting-started-with-email/ip-addresses-and-domains)を参照してください。
2. **ドメインの詳細を送信する**:\
   リクエストが送信されると、次の手順が開始されます。
   1. **DNSレコードの生成**: MoEngageチームが、指定されたドメインに必要なDNSレコードを生成します。
   2. **DNSの設定**: 提供されたレコードをドメインレジストラ(GoDaddy、Cloudflareなど)に追加する必要があります。
   3. **検証**: レコードを追加したら、MoEngageチームに連絡してください。ドメインの検証と有効化を行います。
3. **ドメインの有効化**:\
   検証が完了すると、ドメインが設定され、MoEngageでメールを送信する準備が整います。

   <Info>
     プロセスが完了したら、AIRAでのエクスペリエンスを評価してください。
   </Info>

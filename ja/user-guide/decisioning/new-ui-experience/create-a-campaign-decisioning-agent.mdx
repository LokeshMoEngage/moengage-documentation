# 概要

専用のAIを使用して「デジタルボディランゲージ」を追跡することで、推測に頼る必要がなくなり、MoEngageが最良の結果を得られるようにコミュニケーションを自動的に最適化できます。これにより、オーディエンス内の各個人に対して最も効果的なメッセージとタイミングをAIが自律的に判断するために必要な、具体的なビジネス目標と運用上のガードレールが確立されます。

この記事では、新しいCampaign Decisioning Agentの作成、既存のエージェントの管理、およびエージェントがユーザーコミュニケーションをどのように最適化するかについて説明します。

<Info>
Admin、Manager、またはMarketerのロールを持つユーザーがエージェントを作成できます。エージェントを作成・管理する権限を持つカスタムロールを定義することもできます。
</Info>

# 知っておくべき用語

Decisioning Agentに関連するさまざまなエンティティについては、以下の用語集を参照してください。

| 用語 | 説明 |
| --- | --- |
| **オーディエンス** | **Agent Segment**はAI最適化の対象となる母集団全体を定義し、意図を分析して長期的な価値を最大化するための幅広いデータセットを提供します。一方、**Campaign Segment**は戦術的なガードレールとして機能し、ユーザーがメッセージを受信する前に特定の適格基準（例：「新規ユーザー」ステータス）を満たしていることを保証します。この二層構造のアプローチにより、AIは特定のキャンペーンのビジネスルールを遵守しながら、全体的にパフォーマンスを最適化できます。 |
| **探索（Exploration）** | 探索では、新しい戦略に関するデータを収集するために、*ワイルドカード* のキャンペーンオプションを少数のトラフィックに配信します。このプロセスにより、新しいアセットの *コールドスタート* 問題が解決され、ユーザーの関心や市場トレンドの変化に伴う「モデルドリフト」にエージェントが適応できるようになります。 |
| **報酬イベント** | ユーザーのアクションをポジティブまたはネガティブな「シグナル」に分類し、エージェントのインテリジェンスを調整します。ポジティブなイベント（例：購入やクリック）はAIが最大化を目指す成功した結果を表し、ネガティブなイベント（例：アンインストール）はAIが最小化を学習する摩擦を表します。このバランスの取れたフィードバックループにより、エージェントは長期的なユーザーとの関係を保護しながらエンゲージメントを最大化できます。 |

# 作成

エージェントの作成とは、ビジネス目標、成功指標（報酬）、ターゲットオーディエンス、運用上の制約を定義することで、専門的なAIの「頭脳」を構成するプロセスです。

エージェントを作成するには、次の手順を実行します。

- MoEngageのサイドバーメニューで、Decisioningメニュー項目 <img alt="Screenshot 2025-07-11 at 2.29.45 PM.png"  src="/images/moengage_326ee4.png"  /> にカーソルを合わせます。**Decisioning** メニューが表示されます。
- **Campaign Decisioning** をクリックします。  
   <img  src="/images/moengage_0c7b9f.png"  />
- **Campaign Decisioning** ページで、**+ Create agent** をクリックします。  
   <img  src="/images/moengage_60a449.png"  />

このプロセスは2つのステップで構成されます。

- [ステップ1：基本情報と報酬の分類](#step-1-basic-details-and-reward-classification)
- [ステップ2：コンテンツ（ターゲティングと最適化）](#step-2-content)

## ステップ1：基本情報と報酬の分類

このステップでは、エージェントのIDと成功指標（報酬）を定義します。

1. **Basic details** セクションで次の操作を行います。  
   - **Agent name**：ビジネス目標を識別するための一意の名前を入力します（例：「Resell Agent」）。
   - **Purpose**：このエージェントが達成しようとしていることを簡潔に説明します（例：「休眠ユーザーのエンゲージメントを最大化する」）。   <img  src="/images/moengage_0d3dfd.png"  />
2. **Reward classification** セクションで、AIが意思決定の最適化に使用する *インテントシグナル* を定義します。
3. これらのシグナルを変更するには、右上隅にある鉛筆アイコン  <img  src="/images/moengage_aac2e8.png"   />  をクリックします。  
    <img src="/images/moengage_8dea93.png" />
4. **Edit Event Group** ダイアログボックスで、次の操作を行います。
   - タブの切り替え：**Positive events** または **Negative events** タブをクリックして、特定のシグナルを管理します。
   - イベントの選択**：** イベントリストで、AIに追跡させたい特定のユーザーアクションをクリックします（例：*WhatsApp Message Clicked*）。
   - 重要度の定義：**Classification** リストで重要度レベルをクリックし、イベントの重要度を定義します（オプションには *Good*、*Very Good*、*Bad*、*Very Bad* があります）。
   - イベントの追加：**+ Add Event** をクリックして、追加のシグナルを含めます。最大10個のイベントを追加できます。
   - イベントの削除：任意のイベント行の横にあるゴミ箱アイコン <img  src="/images/moengage_cec033.png"  />  をクリックすると、分類ロジックからそのイベントが削除されます。
5. **Save** をクリックしてロジックを更新します。
6. **Next** をクリックしてステップ2に進みます。   
    <img src="/images/moengage_6db19c.png" />

## ステップ2：コンテンツ

運用上の境界とAIアルゴリズムの動作を定義します。

1. **Eligibility and Exclusion** セクションでは、次のセグメンテーションフィルターを使用して、オファリングのターゲットオーディエンスを選択できます。

   すべてのユーザー ユーザープロパティでフィルター ユーザー行動でフィルター ユーザーアフィニティでフィルター カスタムセグメントでフィルター

   このフィルターオプションでは、すべてのユーザーがオファリングの対象になります。これ以上のフィルタリングは適用できません。

   <img alt="all users.png"  src="/images/moengage_19ae5a.png"  />

   初回確認日、都市、サブスクリプションプランなどのプロパティ（属性）に基づいてユーザーをターゲットにできます。**User property** タブをクリックし、次の操作を行います。

   1. リストから目的の属性を選択して、関連するフィルターを有効にします。たとえば、数値属性には「is equal to」、「is not equal to」、「is between」などのフィルター条件があり、文字列属性には異なるフィルターがあります。
   2. フィルター値を入力して、目的のユーザーセグメントを作成します。
   3. **+ Nested Filter** をクリックしてフィルターを追加し、ネストされたANDまたはOR条件を作成します（任意）。

   詳細については、[セグメントの作成](/ja/user-guide/segment/create-segments/rule-based-filter-segments)を参照してください。

   <img alt="user property.png" src="/images/moengage_e63058.png" />

   *app opened* や *viewed product* など、ユーザーが実行したアクション（イベント）に基づいてユーザーをターゲットにできます。**User Behavior** タブをクリックし、次の操作を行います。

   1. 実行条件と目的のユーザーアクティビティ（イベント）を選択します。
   2. イベントの頻度と実行期間を入力します。
   3. **+ Attributes** をクリックして、フィルター条件付きのイベント属性を追加します。
   4. フィルター値を入力してルールを作成します。
   5. **+ Aggregation** ボタンを使用して集計機能を追加します。詳細については、[集計操作](/ja/user-guide/segment/advanced-concepts/aggregation-operations)を参照してください。
   6. **+ Nested Filter** をクリックしてフィルターを追加し、ネストされたANDまたはOR条件を作成します（任意）。

   詳細については、[セグメントの作成](/ja/user-guide/segment/create-segments/rule-based-filter-segments)を参照してください。

   <img alt="user behavior.png" src="/images/moengage_fb292e.png" />

   特定の属性値に対するアフィニティに基づいて、ユーザーグループをターゲットにできます。詳細については、[ユーザーアフィニティ](/ja/user-guide/segment/create-segments/affinity-segments)を参照してください。**User Affinity** タブをクリックし、次の操作を行います。

   1. 目的のユーザーイベントまたは属性を選択します。
   2. 次の中からユーザーアフィニティパラメーターを選択します。
      - **Predominantly**：フィルター条件付きのアフィニティ属性を選択し、アフィニティ値を指定します。
      - **For a minimum of**：フィルター条件付きのアフィニティ属性を選択し、アフィニティ値を指定します。
      - **Most no. of times**：値を入力するか矢印を使用して、上位のユーザーの割合を指定します。
      - **Least no. of times**：値を入力するか矢印を使用して、下位のユーザーの割合を指定します。
   3. 値を入力するか矢印を使用して、イベントの実行期間を指定します。
   4. **+ Attribute** をクリックして、フィルターに属性を追加します。
   5. **+ Nested Filter** をクリックしてフィルターを追加し、ネストされたANDまたはOR条件を作成します（任意）。

   詳細については、[セグメントの作成](/ja/user-guide/segment/create-segments/rule-based-filter-segments)を参照してください。

   <img alt="5.png" src="/images/moengage_5ec561.png" />

   事前に作成したカスタムセグメントをターゲットにできます。

   1. 利用可能なカスタムセグメントのリストから、ターゲットオーディエンスとしてカスタムセグメントを選択します。
   2. **+ Nested Filter** をクリックしてフィルターを追加し、ネストされたANDまたはOR条件を作成します（任意）。

   詳細については、[カスタムセグメント](/ja/user-guide/segment/create-segments/manage-segments)を参照してください。

   <img alt="custom segment.png" src="/images/moengage_a1d952.png" />
2. **Optimization Preference**：スライダーを調整して、AIが学習とパフォーマンスのバランスをどのように取るかを定義します。

   - **High Exploration**：AIは多くのオプションを試して、何が最も効果的かを学習します。新しいキャンペーンに最適です。
   - **Low/No Exploration**：AIは既存のデータに基づいて結果を最大化します。確立されたキャンペーンに最適です。 <img src="/images/moengage_49824e.png" />
3. **Agent Distribution Control**：過剰なメッセージ送信を防ぐために、頻度のガードレールを設定します（例：「1日に最大1件のコミュニケーションを送信」）。 <img src="/images/moengage_6eee69.png" />
4. **Agent Control Group**：このトグルをオンにすると、コミュニケーションを受信しないユーザーのランダムサンプル（例：10%）が確保されます。これは、AIの実際の効果を測定するためのベースラインとして機能します。 <img src="/images/moengage_c606fe.png" />
5. **Create** をクリックしてエージェントを公開します。

## エージェントの管理

**Campaign Decisioning** ページには、作成したすべてのエージェントが一覧表示されます。エージェントを作成した後、**Decisioning** \> **Campaign Decisioning** に移動します。

このページでは、次の操作を行えます。

- 検索とフィルター：**search by agent name** ボックスを使用してエージェント名で検索するか、**Select Status** リストを使用してActive、Paused、Stoppedでフィルタリングします。
- 一時停止と再開：省略記号（⋮）アイコンをクリックして **Pause** を選択すると、エージェントの意思決定ロジックを一時的に停止できます。
- 編集：エージェントの構成を変更します。  
   <img src="/images/moengage_540232.png" />

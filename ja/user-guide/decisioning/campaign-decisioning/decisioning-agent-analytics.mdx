# 概要

Decisioning Agent Analyticsページでは、複数のキャンペーンにわたるAIエージェントのパフォーマンスを一元的に評価できます。**Agent Treatment Group** と **Agent Control Group** を比較することで、AIの「増分価値」を測定します。

このUIを使用して、次のことができます。

- AIがユーザーの行動にリアルタイムでどのように適応するかを追跡する。
- AIで最適化された配信とタイミングの効果を定量化する。
- エンゲージメントのアップリフトが最も高いチャネルとキャンペーンを特定する。

次の画像は、Decisioning Agent Analytics UIを示しています。

## 知っておくべき用語

Decisioning Agent Analyticsに関連するエンティティについては、次の用語集を参照してください。

| 用語 | 説明 |
| :-- | :-- |
| Engagement Uplift | エージェントコントロールグループと比較して、エージェントトリートメントグループが達成したエンゲージメント率の増加率。 |
| Weightage Score | エージェントの作成時に定義されたとおり、ユーザーアクション（報酬）に特定のポイントを割り当てることで算出される累積値。 |
| オーディエンス | AI最適化のために定義された母集団全体で、意図を分析して長期的な価値を最大化するための幅広いデータセットを提供します。これは、メッセージの関連性を確保するための戦術的なガードレールとして機能するCampaign Segmentとは異なります。 |
| 探索（Exploration） | 新しい戦略に関するデータを収集するために、ワイルドカードのキャンペーンオプションを少数のトラフィックに配信する仕組み。このプロセスにより、新しいアセットの「コールドスタート」問題が解決され、エージェントは変化するユーザーの関心や市場トレンドに適応できます。 |
| 報酬イベント | エージェントのインテリジェンスを調整するために、ユーザーのアクションをポジティブまたはネガティブな「シグナル」に分類したもの。ポジティブなイベント（例：購入やクリック）は最大化すべき成功した結果を表し、ネガティブなイベント（例：アンインストール）は最小化を学習する摩擦を表します。 |
| Agent Treatment Group | AIで最適化されたタイミングと配信の決定に基づいてキャンペーンを受信するユーザー。 |
| Agent Control Group | AIによる増分効果を測定するためのベースラインとして、AI最適化なしでキャンペーンを受信する、ランダムに選択されたユーザーグループ。 |

# エージェントのパフォーマンスの分析

**Analytics** タブでは、データパターンを可視化し、AI戦略の有効性を検証できます。このセクションでは、フィルターとコントロールを使用してデータを解釈する方法について説明します。

## ステップ1：パフォーマンスデータのフィルタリング

ページ上部にある次のフィルターを使用して、分析するデータを選択します。

- **Date Range**：分析の期間を定義します。**Today**、**Yesterday**、**Last 7 Days**、**Last 30 Days**、**This Week**、**Last Week**、**This Month**、**Last Month**、**Since** などの事前定義されたオプションを選択できます。特定の期間を定義するには、**Custom Range** を選択します。**Last input** ボックスに数値を入力し、**D**（日）、**W**（週）、または **M**（月）をクリックすると、ローリング期間を表示することもできます。ページ上のすべてのサマリーカードとチャートは、選択内容を反映して自動的に更新されます。
- **Select Channel**：特定のプラットフォーム（**Email**、**Push**、**SMS**、または **WhatsApp**）を選択して、そのチャネルのパフォーマンス指標を切り分けます。
  <br />
  ![Recent6](/images/recent6.gif)

## ステップ2：運用規模と達成状況の確認

次の **Agent summary** カードには、エージェントの運用ステータスと全体的な有効性を監視するのに役立つ概要指標が表示されます。

- **Engagement Uplift**：コントロールグループと比較したエンゲージメントの正味の増加率を表示します。
- **Decisions Made**：AIエンジンによって処理された個別の1対1の選択の総数を示します。
- **Campaigns Sent**：適格なプール全体から正常に配信されたユニークなキャンペーンの数を示します。
- **Channels**：現在使用中のアクティブなチャネルの数を示します（例：4/4）。

![Recent7](/images/recent7.png)

## ステップ3：パフォーマンスサマリーの分析

Performance Summaryテーブルでは、**Agent Treatment Group** と **Agent Control Group** の詳細な比較を確認できます。このビューは、グローバルフィルターの選択内容に基づいて動的に更新され、関連する指標が表示されます。

たとえば、特定のチャネルのパフォーマンスを表示するには、次の手順を実行します。

1. **Date Range** リストで、分析する期間を選択します。
2. **Select channel** リストで、チャネル（例：**Email**）を選択します。テーブルが更新され、_Email Opened_ や _Email Clicked_ など、そのチャネルの報酬イベントが表示されます。
3. 両方のグループの **Sent**、**Delivered**、**Engagement** 指標を確認します。
4. **Engagement** 行の横にある矢印アイコン <img src="/images/Analyze-icon.png" alt="Analyze Icon" /> をクリックして展開し、詳細なイベントデータを表示します。 \
   **注**：報酬イベントは、報酬戦略での定義に従って、緑色のドット（ポジティブイベント）または赤色のドット（ネガティブイベント）で示されます。
   <Frame>
     ![Step3 1](/images/step3.1.gif)
   </Frame>

<Info>
  **計算式**

  - エンゲージメント率 = (エンゲージメント加重スコア / 配信されたコミュニケーション数) \* 100
  - エンゲージメントアップリフト = ((エージェントターゲットグループのエンゲージメント率 − コントロールグループのエンゲージメント率 )/ (コントロールグループのエンゲージメント率))\*100
</Info>

## ステップ4：最適化トレンドの可視化

Performance Trendセクションでは、AIモデルが時間の経過とともに結果をどのように最適化するかを可視化できます。

- **報酬の選択**：左側のサイドバーを使用して特定のイベントを選択し、折れ線グラフでそのトレンドを切り分けます。
- **粒度**：タイムラインのビューを **Days**、**Weeks**、**Months** の間で切り替えます。
- **エクスポート**：**Export chart** をクリックすると、現在の可視化をPNGファイルとしてダウンロードできます。

![Recent9](/images/recent9.gif)

## ステップ5：チャネルとキャンペーンのパフォーマンスの確認

チャネルとキャンペーンのパフォーマンスセクションには、戦略の中で最も大きな効果をもたらしている特定のセグメントを特定するのに役立つ、次の詳細な指標が表示されます。

- **Channel Breakdown**：ドーナツグラフで、使用されているチャネル全体におけるキャンペーンの割合分布を確認します。
  <Frame>
    ![Recent10](/images/recent10.gif)
  </Frame>
  <br />
- **Channel Performance**：棒グラフを使用して、使用されている各チャネルの **Agent Treatment Group** と **Agent Control Group** のパフォーマンスを比較します。
  <br />
  ![Recent11](/images/recent11.gif)
- **Campaign Performance Table**：**Agent Treatment Group** 向けに管理されているすべてのキャンペーンの詳細なリストです。このリストを **Sent**、**Delivered**、または **CTR** で並べ替えて、成果の高いバリエーションを特定できます。

個々のキャンペーンの結果を絞り込んで分析するには、次の手順を実行します。

1. **Search by Campaign name, ID** ボックスに、特定のキャンペーンの名前または識別子を入力します。
2. **Select channel** リストで、1つ以上のチャネルを選択してテーブルをフィルタリングします。
3. **Published on** リストで、日付または期間を選択すると、その期間にリリースされたキャンペーンが表示されます。
4. 並べ替えアイコン <img src="/images/recent12.png" alt="Recent12" /> をクリックして、リストを **Sent**、**Delivered**、または **Clicks**（CTR）で並べ替えます。

# 配信統計のトラブルシューティング

**Sent** の件数が **Decisions Made** の数より少ない場合は、AIファネルにおける次の配信失敗の理由を確認してください。

| 理由（UI） | 説明 |
| :-- | :-- |
| Agent Inactive | キャンペーンの処理中にエージェントが一時停止または非アクティブになっています。 |
| Control Group Exclusion | ユーザーは、アップリフト測定に使用されるホールドアウトのベースライングループに属しています。 |
| Frequency Limit Reached | 頻度の上限設定、またはキャンペーンが関連性の高いメッセージの「上位N件」にランクインしなかったため、ユーザーがスキップされました。 |
| User not eligible | 配信時点で、ユーザーが特定のセグメント、プラットフォーム、またはロケールの要件を満たしていません。 |

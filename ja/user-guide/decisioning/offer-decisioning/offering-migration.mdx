# 概要

オファリング移行機能を使用すると、同じデータクラスター内のあるワークスペースから別のワークスペースにオファリングを移動できます。例えば、下位環境でオファリングを構築・テストしてから、ゼロから作り直すことなく本番ワークスペースに複製できます。表示されるのは、アクセス権を持つワークスペースのみです。

<Info>
  **Active**、**Scheduled**、**Archived**、**Expired** の状態のオファリングを移行できます。**Draft** 状態のオファリングは移行できません。Decision PolicyとPersonalize APIエクスペリエンスは移行されません。
</Info>

# 前提条件

- **移行元** ワークスペースでは、**Offerings** コンポーネントに対して少なくとも **View** 権限が必要です。**移行先** ワークスペースでは、**Offerings** コンポーネントに対して **Create & Manage** または **Create, Manage & Publish** 権限が必要です。
- 移行元と移行先のワークスペースは同じデータクラスター内にある必要があり、両方へのアクセス権が必要です。

# オファリングのインポート

![右上隅のImport offeringボタンが強調表示されたAll Offeringsページ](/images/offering-migration-offerings-list.png)

あるワークスペースから別のワークスペースにオファリングを移行するには、次の手順を実行します。

1. MoEngageダッシュボードのAll Offeringsページに移動します。
2. 右上隅にある **Import offering** をクリックします。Import offeringウィンドウが表示されます。

オファリングのインポートには、次の2つのステップがあります。

1. [オファリングの選択](/ja/user-guide/decisioning/offer-decisioning/offering-migration#step-1-select-offerings)
2. [インポートしたオファリングの確認](/ja/user-guide/decisioning/offer-decisioning/offering-migration#step-2-review-imported-offerings)

## ステップ1: オファリングの選択

![移行元ワークスペースが選択され、その下にインポートするオファリングのリストが表示されたImport offeringウィンドウ](/images/offering-migration-select-offerings.png)

1. **Source workspace** リストで、オファリングのインポート元となるワークスペースを選択します。これは、オファリングが最初に作成されたワークスペースです。アクセス権を持つワークスペースは、Offer Decisioningが有効になっていなくてもすべてこのリストに表示されます。Offer Decisioningが有効になっていないワークスペースを選択すると、次のメッセージが表示され、続行できません: *The Offer decisioning feature is not enabled for the selected source workspace. Please select a different workspace.* 有効な移行元ワークスペースを選択すると、そのオファリングが **Select offerings to import** リストに表示されます。
2. 必要なオファリングを名前で検索します。
3. 作成日、タグ、ステータスでオファリングをフィルタリングできます。
4. 移行するオファリングを選択します。各オファリングには、名前、ステータス、作成日、タグ、作成者が表示されます。
5. **Import** をクリックします。ステップ2「インポートしたオファリングの確認」に移動します。

![複数のオファリングが選択され、Importボタンがアクティブになっているインポートオファリングウィンドウ](/images/offering-migration-select-offerings-selected.png)

<Info>
  1回のインポートで選択できるオファリングは最大15個です。
</Info>

## ステップ2: インポートしたオファリングの確認

1. インポートの実行後、各オファリングに **Import status** が表示されます。次の表に、考えられるインポートステータスを示します。
   | **ステータス** | **定義** | **例** |
   | --- | --- | --- |
   | **Successfully imported** | オファリングが正常にインポートされ、確認と作成の準備ができていることを示します。 |  |
   | **Imported with errors** | インポートされたオファリングに必須フィールドの値が欠けていることを示します。オファリングを作成する前に、これらのエラーを修正する必要があります。 | 例えば、移行元ワークスペースのオファリングが、移行先ワークスペースで利用できないユーザーイベントやユーザー属性を使用している場合、**Imported with errors** ステータスが表示されます。 |
   | **Imported with warnings** | インポートされたオファリングにオプションの値が欠けているか、移行先ワークスペースで有効になっていない機能を使用していることを示します。警告がある状態でもオファリングを作成できますが、修正は任意です。 | 例えば、オファリングで使用されている機能(Global Control Groupなど)が移行先ワークスペースで有効になっていない場合、**Imported with warnings** ステータスが表示されます。 |
   | **Imported with errors & warnings** | インポートされたオファリングに、必須フィールドとオプションフィールドの両方の値が欠けていることを示します。オファリングを作成する前に、すべてのエラーを修正する必要があります。 |  |

   ![Successfully importedやImported with warningsなどのインポートステータスと、それぞれのReviewリンクが表示されたインポート済みオファリングのリスト](/images/offering-migration-import-status.png)
2. 個々のオファリングを確認して問題を修正するには、**Actions** 列の **Review** をクリックします。
3. インポートしたすべてのオファリングを表示するには、**View imported offerings** をクリックします。All Offeringsページの **Drafts** タブが開きます。ここでは、インポートされたオファリングのソースは **Imported** と表示され、ワークスペースで直接作成されたオファリングのソースは **Original** と表示されます。エラーまたは警告のあるオファリングには、**Source** 列の **Imported** ラベルの横に警告またはエラーの記号が表示されます。

   ![Imported ラベルと警告およびエラーアイコンを含むSource列が表示されたAll OfferingsページのDraftsタブ](/images/offering-migration-drafts-imported.png)

# インポートしたオファリングのエラーと警告の特定と解決

エラーまたは警告のあるインポート済みオファリングを開くと、オファリングエディターで開きます。各セットアップステップの上部に、次の情報を含むセクションが表示されます。

| **フィールド** | **定義** |
| --- | --- |
| **Errors & warnings on this page** | 現在のセットアップステップにおけるエラーと警告の数。 |
| **Total errors & warnings in this offering** | すべてのステップにおけるエラーと警告の合計数。**View details** をクリックすると、保留中および解決済みのすべての問題を1か所で確認できます。 |
| **Resolved** | 解決したエラーと警告の数。 |
| **Fix pending** | このセクションには、エラーと警告の理由が一覧表示されます。この情報を使用して問題を修正します。問題を修正したら、**Update Changes** をクリックして数を更新します。 |

![エラーと警告の数、および解決すべき問題のFix pendingリストが表示されたオファリングのセットアップステップ](/images/offering-migration-validation-banner.png)

オファリングの保留中および解決済みのすべての問題を1か所で確認するには、合計数の横にある **View details** をクリックします。

![移行先ワークスペースで有効になっていない機能に関する保留中の警告が表示された、エラーと警告の合計ポップアップ](/images/offering-migration-errors-warnings.png)

<Info>
  エラーは、オファリングを作成する前に修正が必要な必須値の欠落です。警告は、作成を妨げないオプション値の欠落です。
</Info>

<Info>
  インポートしたオファリングが、移行先ワークスペースに存在しない **タグ**、**カスタムセグメント**、または **コンテンツブロック** を使用している場合、システムはそれらを自動的に作成します。これらを手動で再作成する必要はありません。
</Info>

次の表に、表示される可能性のある一般的なエラーと警告、およびその解決方法を示します。

| **問題** | **タイプ** | **解決方法** |
| --- | --- | --- |
| オファリングで使用されているユーザー属性が移行先ワークスペースに存在しない。 | エラー | 移行先ワークスペースでユーザー属性を作成します。 |
| セグメンテーションまたはコンバージョン目標で使用されているユーザーイベント(Product Purchaseなど)が存在しない。 | エラー | 移行先ワークスペースでイベントを作成するか、別のイベントを選択します。 |
| ユーザーイベント内で使用されている属性が存在しない。 | エラー | 移行先ワークスペースでイベント属性を作成します。 |
| バリエーションで使用されているパーソナライゼーションテンプレートが存在しない。 | 警告 | テンプレートを作成するか、そのバリエーションに別のテンプレートを選択します。そうしない場合、MoEngageはOffering ContentタイプとしてJSONをデフォルトで使用します。 |
| オファリング属性、またはそのドロップダウン値のいずれかが存在しない。 | 警告 | 移行先ワークスペースでオファリング属性とその値を作成します。 |
| オファリングで使用されている機能(Global Control Group、Offering Control Group、Session Attributesなど)が有効になっていない。 | 警告 | 移行先ワークスペースで機能を有効にします。 |

<Info>
  インポートしたオファリングのスケジュールは、新しいオファリングと同じデフォルトに従います。**Start date** は現在時刻の1時間後に設定され、**End date** は開始日の1年後に設定されます。これらは、オファリングを作成する前に **Schedule and goals** ステップで変更できます。
</Info>

# インポートしたオファリングの作成

エラーを解決したら、**Schedule and goals** ステップで **Create** をクリックしてオファリングを有効にします。エラーが残っている間は、**Create** ボタンは無効のままです。警告のみのオファリングは作成できますが、エラーのあるオファリングは作成できません。

各インポートは、ワークスペースの監査ログに **Offering Imported** アクティビティとして記録されます。

# FAQ

<AccordionGroup>
  <Accordion title="どのような種類のオファリングをインポートできますか?">
    移行元ワークスペースで **Active**、**Scheduled**、**Archived**、または **Expired** 状態のオファリングをインポートできます。**Draft** 状態のオファリングはインポートできません。
  </Accordion>

  <Accordion title="アクセス権を持つ任意のワークスペースからオファリングをインポートできますか?">
    アクセス権があれば、Offer Decisioningが有効かどうかにかかわらず、移行元ワークスペースはドロップダウンに表示されます。ただし、インポートできるのはOffer Decisioningが有効になっているワークスペースからのみです。有効になっていないワークスペースを選択すると、別のワークスペースを選択するよう求めるメッセージが表示されます。想定しているワークスペースがドロップダウンにまったく表示されない場合は、そのワークスペースへのアクセス権がない可能性が高いです。ワークスペース管理者に確認してください。
  </Accordion>

  <Accordion title="オファリング移行を使用するにはどのような権限が必要ですか?">
    両方のワークスペースで権限が必要です。

    - **移行元ワークスペース:** **Offerings** コンポーネントに対して少なくとも **View** 権限。
    - **移行先ワークスペース:** **Offerings** コンポーネントに対して **Create & Manage** または **Create, Manage & Publish** 権限。

    権限が不明な場合は、MoEngageワークスペース管理者に確認してください。
  </Accordion>

  <Accordion title="オファリングをインポートすると、移行元ワークスペースの元のオファリングに影響しますか?">
    いいえ。インポートすると、移行先ワークスペースに独立したコピーが作成されます。移行元ワークスペースの元のオファリングは変更されず、そのステータス、設定、および配信中のライブトラフィックは影響を受けません。
  </Accordion>

  <Accordion title="インポート中に自動的に作成されるものは何ですか?">
    移行先ワークスペースにまだ存在しない場合、インポートによって次のものが自動的に作成されます。

    - オファリングで使用されているタグ
    - オファリングで参照されているコンテンツブロック
    - 適格性のターゲティングに使用されているカスタムセグメント

    これらを手動で作成する必要はありません。
  </Accordion>

  <Accordion title="自動的に作成されないものは何ですか?">
    一部の項目は自動的に作成されません。欠落している **必須** 項目は **エラー** として表示され(オファリングを作成する前に修正する必要があります)、欠落している **オプション** 項目は **警告** として表示されます(オファリングは作成できます)。

    **エラー** として表示されるもの:

    - 適格性、コンバージョン目標、またはJinja式で使用されているユーザー属性
    - セグメンテーションまたはコンバージョン目標として使用されているユーザーイベント
    - セグメンテーションまたはコンバージョン目標として使用されているイベント属性

    **警告** として表示されるもの:

    - バリエーションで使用されているパーソナライゼーションテンプレート
    - オファリング属性とそのドロップダウン値
    - 移行先ワークスペースで有効になっていないGlobal Control Group、Offering Control Group、Session Attributesなどの機能

    移行先ワークスペースで欠落している要素を作成し、オファリング内で再度リンクしてください。完全なリストについては、上記のエラーと警告の表を参照してください。
  </Accordion>

  <Accordion title="オファリングを作成する前にすべてを修正する必要がありますか?">
    オファリングを作成する前に、すべての **エラー** を修正する必要があります。**警告** は作成を妨げません。警告が残っている状態でもオファリングを作成できますが、それぞれを確認することをお勧めします。
  </Accordion>

  <Accordion title="インポート後に対応が必要な項目はどこで確認できますか?">
    **Drafts** タブからインポートしたオファリングを開きます。オファーのセットアップステップの上部にある検証バナーに、現在のページの問題数、オファリング全体の合計数、および解決済みの数が表示されます。その下の **Fix pending** セクションには、各問題が具体的なメッセージとともに一覧表示されます。例: "User Attribute: 'loyalty_tier' with data type: String is not present."
  </Accordion>
</AccordionGroup>

_Offerings_ 機能を使用すると、ユーザー向けのターゲットを絞ったプロモーションを作成および管理できます。この機能は、関連性の高いコンテンツやインセンティブでオーディエンスとエンゲージするための、柔軟で強力な方法を提供するように設計されています。

## Offeringsとは

MoEngageのOfferingsは、次の要素を含む定義済みのプロモーションです。

- **User Eligibility**: Offeringの対象となるユーザーを決定するルールです(例: 特定のプランを利用している顧客、特定の地域にいる顧客)。
- **Schedule**: Offeringが有効な期間です。
- **Priority**: 重要度を示す手動で割り当てるスコアです。値が大きいほど重要度が高くなります。
- **Usage Limits**: Offeringを全体および個々のユーザーが使用できる回数の制御で、定期的なリセット(例: 毎日、毎週、毎月)のオプションがあります。
- **User Interface & Content**: 画像、説明、法的条項など、ユーザーに実際に表示されるコンテンツです。

# Offeringの作成

MoEngageでOfferingを作成するには:

1. MoEngageダッシュボードの左側のナビゲーションメニューで、**Decisioning** をクリックし、次に **Offerings** をクリックします。
2. **Offerings** ページで、**\+** **Create Offering** をクリックします。

![offer 1.png](/images/moengage_6da837.png)

Offeringは次の3つのステップで作成できます。

- [ステップ1: ターゲットユーザー](/ja/user-guide/decisioning/offer-decisioning/create-offerings#step-1-target-users)
- [ステップ2: コンテンツ](/ja/user-guide/decisioning/offer-decisioning/create-offerings#step-2-content)
- [ステップ3: スケジュールと目標](/ja/user-guide/decisioning/offer-decisioning/create-offerings#step-3-schedule-and-goals)

## ステップ1: ターゲットユーザー

### 基本情報

このセクションでは、次のフィールドを使用してOfferingの基本情報を定義します。

![Screenshot 2025-06-24 at 3.35.12 PM.png](/images/moengage_75cb0c.png)

- **Name**: オファーを識別および管理するためのOffering名を入力します。
- **Description**: オファーの目的、主な特徴、または条件の概要を入力します。
- **Tags**: Offeringを分類し、簡単にフィルタリングできるようにタグを選択または作成します。タグは複数のOfferingをグループ化するのに役立つため非常に重要です。タグはDecision Policyに組み込むことができ、ストラテジーが特定のタグを持つすべてのポリシーから選択できるようになります。

### 対象条件と除外

このセクションでは、次のセグメンテーションフィルターを使用してOfferingのターゲットオーディエンスを選択できます。

#### In-session attributes

***In-session attributes*** を使用すると、***Personalize Experience Fetch*** リクエスト内で直接Key-Value(KV)ペアとして渡される属性を介して、動的な条件に基づいてリアルタイムに訪問者をグループ化できます。
リクエストで指定された値は、Offeringのターゲットセグメントで定義された条件に対して即座に評価されます。これにより、ユーザーのジャーニー中にコンテキストが変化するのに合わせて、対象となるOfferingを動的に変更できます。

 次のin-session attributesを追加できます。
     | フィールド | 説明 |
     | --- | --- |
     | Session Attributes | Session Attributeタイプを使用すると、カスタムのKey-Valueペアを使用して、特定のターゲットオーディエンスのユーザーを識別して含めることができます。これらのKey-Valueペアは、すでに定義されているセグメンテーションルールを補完する、追加のターゲティング条件レイヤーとして機能します。  **例:** アプリが英語やスペイン語など複数の言語のコンテンツをサポートしている場合、_language\_preference_ というキーと、対応する値を定義できます: **en**: 英語のコンテンツを好むユーザーをターゲットにします。**es**: スペイン語のコンテンツを好むユーザーをターゲットにします。  このフィールドを活用することで、ユーザーの好みや属性に基づいて適切なオーディエンスにマッチさせ、よりパーソナライズされたコンテキストに即したエクスペリエンスを提供できます。 |
     | Geolocation | このフィールドを使用すると、ユーザーがアプリやウェブサイトにアクセスした地理的位置に基づいてユーザーをセグメント化できます。ユーザーがいる国、州/地域、都市を選択したり、特定の国を除外したりできます。 |

  ***Exclude Users***

  _Exclude Users_ をクリックし、特定のin-session attributesに対する除外条件を指定することで、ユーザーを除外できます。

### コントロールグループ

このセクションには、キャンペーンのコントロールグループに関する情報が含まれます。コントロールグループのユーザーを除外するには:

- **Global control group** トグルをオンにすると、グローバルコントロールグループのすべてのユーザーがこのOfferingから除外されます。
- **Offering control group** トグルをオンにすると、この特定のOfferingからコントロールグループが除外されます。

詳細については、[コントロールグループ](/ja/user-guide/campaigns-and-channels/getting-started/introduction/control-groups)を参照してください。

**Next** をクリックして、ステップ2: **Content** に進みます。

## ステップ2: コンテンツ

このステップでは、ユーザーに実際に表示されるコンテンツを定義します。MoEngageには、Offeringのコンテンツを作成するための2つのオプション、**JSON** と **Personalization Template** が用意されています。さらに、効果を最大化するために、さまざまなコミュニケーションチャネルや配置に合わせてコンテンツを調整することを検討してください。

### JSON

JSONオプションでは、オファーのコンテンツを完全に制御できます。JSONオプションを選択し、オファーの構造とデータを定義するJSONコンテンツを直接入力できます。この方法は、カスタムレイアウトや動的コンテンツが必要なユーザー、または既存のJSON構造を利用したいユーザーに最適です。

![offering-json.png](/images/moengage_415443.png)

### Personalization Template

このオプションは、事前に設計された構造を提供することでコンテンツ作成を簡素化します。コードを書かずにOfferingを作成したいマーケターに最適です。テンプレートを使用してコンテンツを作成するには、次の手順を実行します。

1. **Personalization Template** オプションを選択します。
2. 利用可能なテンプレートのリストから目的のテンプレートを選択します。
3. 選択したテンプレートに基づいて必須フィールドに入力します。プロモーションがエンドユーザーにどのように表示されるかをライブプレビューで確認できます。
4. テンプレートの選択によって生成された基盤となるJSON構造を確認するには、いつでも **JSON** タブに移動します。 <img src="/images/moengage_75f76f.png" alt="offering-personal template.png" />

### \+A/B test

右上隅にある **\+A/B test** オプションをクリックしてバリエーションを追加またはコピーすることで、ストラテジーを改善できます。これにより、さまざまなコンテンツやオファーをテストして、オーディエンスに最も響くものを確認できます。

![variation 5.png](/images/moengage_17c1cf.png)

バリエーションを作成したら、Distributionステップでバリエーション間のトラフィックの配分方法を選択できます。

- **Manual Distribution**: 各バリエーションに特定の割合を手動で割り当てます。続行するには、配分の合計が100%である必要があります。
- **Merlin AI (formerly Sherpa)**: Merlin AIを有効にすると、Offeringを自動的に最適化できます。エンゲージメント指標に基づいて、最もパフォーマンスの高いバリエーションにトラフィックを動的に配分します。いつでも手動配分にリセットできます。

![user distribution.png](/images/moengage_60bdd6.png)

**有効なOfferingの管理**\
公開中のOfferingでは、コンテンツと配分の割合を変更できます。ただし、データの整合性を維持するため、Offeringが有効になった後は、バリエーションの追加や削除、配分タイプの変更はできません。

詳細については、[A/Bテスト](/ja/user-guide/ai-and-intelligence/ab-testing/what-is-ab-or-multivariate-testing/overview)を参照してください。

## ステップ3: スケジュールと目標

### Offeringの送信

このセクションでは、次のフィールドを使用してOfferingの有効期間を定義します。

- **Start** **Date**: Offeringが有効になる日付を選択します。
- **End** **Date**: Offeringの有効期限が切れる日付を選択します。
- **Send Time**: Offeringが有効になる時刻を選択します。
- **End Time**: Offeringの有効期限が切れる時刻を選択します。

デフォルトでは、開始/終了の日付と時刻は、ワークスペースに設定されたタイムゾーンになります。Offeringのタイムゾーンは更新できます。

![send offering.png](/images/moengage_fa97ff.png)

### コンバージョン目標

コンバージョン目標を追加して、Offeringのビジネス指標をトラッキングできます。最大5個のコンバージョン目標をトラッキングできます。任意のイベントをコンバージョン目標のアクティビティとして選択でき、複数のコンバージョン目標を設定できます。複数のコンバージョン目標がある場合は、いずれかのコンバージョン目標をPrimaryとしてマークできます。

**Track above goals for** フィールドで、コンバージョン目標をトラッキングする期間を指定します。最小1時間、最大10日間を入力できます。

### Offering Attributeの設定

Decision PolicyのCustom Formulaランキングストラテジーでスコアリングできるように、Offeringに[属性](/ja/user-guide/decisioning/offer-decisioning/managing-offering-attribute)を割り当てます。Offeringごとに最大5個の属性を割り当てることができます。

**\+ Add offering attribute** ドロップダウンには、アカウント設定で設定された属性が表示されます。属性を選択して、Offeringに追加します。

- **Fixed Value attributes:** 属性を追加した後、ドロップダウンから1つ以上の選択肢を選択し、各選択肢にスコア(0～100)を割り当てます。選択したすべての選択肢のスコアの合計は100である必要があります。
  ![Fixed Valueの設定](/images/config-fixed-value.png)
- **Dynamic Value attributes**: 属性を追加した後、ドロップダウンから1つ以上の選択肢を選択します。スコアは、評価時にユーザーのプロファイルに基づいて自動的に計算されます。\
  割り当てた属性を削除するには、属性名の横にある削除アイコンをクリックします。
  <Frame>
    ![Dynamic Valueの設定](/images/config-dynamic-value.png)
  </Frame>

ドロップダウンに利用可能な属性がない場合は、まず **Settings** \> **Offer Decisioning** \> **Offering Attributes** で設定する必要があります。詳細については、[Offering Attributesの管理](/ja/user-guide/decisioning/offer-decisioning/managing-offering-attribute)を参照してください。

### 優先度

**Priority** セクションで、**Priority Score** リストを使用してオファーの表示優先度を選択します。スコアが高いほど、ユーザーが同時に複数のOfferingの対象となった場合に、そのOfferingが表示される可能性が高くなります。

![Screenshot 2025-06-24 at 3.37.39 PM.png](/images/moengage_b375c5.png)

### キャッピングルール

**Capping Rules** セクションで、ユーザーがオファーを閲覧または獲得する頻度と回数を定義します。次のいずれかのオプションを選択して、オファーの表示制限を設定します。

![Screenshot 2025-06-24 at 3.38.22 PM.png](/images/moengage_25e757.png)

- **Overall Capping**: この制限は、ターゲットセグメント内のすべてのユーザー全体でこのOfferingを獲得できる回数を指定します。Offeringを使用できる最大回数を指定し、リセット頻度を **Daily**、**Weekly**、**Monthly** から選択することもできます。\
  たとえば、Offeringを1日に100回だけ表示したい場合は、Overall Cappingを100、頻度を「Daily」に設定します。100回目の表示後は、毎日のリセットが行われるまで、Offeringは誰にも提供されなくなります。
- **User Level Capping**: この制限は、ターゲットセグメントに含まれる1人のユーザーがオファーを獲得できる回数を指定します。ユーザーが獲得できる最大回数を指定し、リセット頻度を **Daily**、**Weekly**、**Monthly** から選択することもできます。\
  たとえば、各ユーザーが週に1回だけOfferingを獲得できるように制限するには、User Cappingを1、Frequencyを「Weekly」に設定します。Offeringを獲得したユーザーは、翌週の初めに上限がリセットされるまで、再び対象になりません。

**Create** をクリックします。

# 作成したOfferingの表示と管理

![Screenshot 2025-06-24 at 12.42.09 PM.png](/images/moengage_e00bb2.png)

作成したオファーは、**Offerings** ページに **Active**、**Scheduled**、**Expired**、**Archived** のいずれかのステータスで一覧表示されます。このページでは、次の操作を実行できます。

- 名前またはタグを使用してOfferingを検索します。
- タグとステータスに基づいてOfferingをフィルタリングします。
- オファーの横にある省略記号 <Icon icon="ellipsis-stroke-vertical" size={32} /> アイコンをクリックして、Offeringを **Edit** または **Archive** します。

<Info>
  詳細については、[Offeringsに関するFAQ](/ja/user-guide/decisioning/offer-decisioning/faqs-on-offerings)を参照してください。
</Info>

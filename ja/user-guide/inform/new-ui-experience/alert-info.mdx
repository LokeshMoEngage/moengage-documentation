アラート情報を表示するには、次の手順に従います。

1. MoEngage のサイドバーメニューで、Inform メニュー項目 <img alt="Screenshot 2025-06-13 at 2.08.54 PM.png"  src="/images/moengage_8fe624.png"  /> にカーソルを合わせます。**Inform** メニューが表示されます。
2. **All Alerts** をクリックします。  
    <img alt="all alerts.png"  src="/images/moengage_c69a1a.png"  />
3. 目的のアラートをクリックし、そのアラートの **Info** タブに移動します。

このセクションには、次のようなアラートに関する情報が含まれます。

1. 1. アラートが設定されているチャネル、およびチャネル順序が順次送信の場合はデフォルトチャネルとフォールバックチャネルに関する情報。
   2. リクエストの詳細: <img src="/images/moengage_0e8a36.png" />
   3. チャネルレベルのメッセージプレビュー  
       <img alt="Screenshot 2025-01-22 at 3.47.08 PM.png" src="/images/moengage_b6d29d.png" />   
       <img alt="AlertInfo" src="/images/moengage_e72c68.png" />

以下に示すように、さまざまな言語のコードスニペットを使用して、外部コンソールでアラートをテストできます。

詳細については、[アラートのテスト](/ja/user-guide/inform/create/test-alert)を参照してください。

<Info>
- ライブアラートを送信する際は、上記のコードスニペットに記載されている Alert ID または Reference ID を使用する必要があります。アラート作成時に利用できる Test Alert ID を使用すると、リクエストは失敗します。
- API リクエストを受信するとログは即座に記録され、Alert Logs タブで確認できます。
</Info>

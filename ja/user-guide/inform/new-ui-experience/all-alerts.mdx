All Alerts ページでは、現在 Active、Paused、Archived、Stopped、Draft の状態にあるすべてのアラートを確認できます。

すべてのアラートを表示するには、次の手順に従います。

1. MoEngage のサイドバーメニューで、Inform メニュー項目 <img alt="Screenshot 2025-06-13 at 2.08.54 PM.png"  src="/images/moengage_1652dc.png"  /> にカーソルを合わせます。**Inform** メニューが表示されます。
2. **All Alerts** をクリックします。  
    <img alt="all alerts.png"  src="/images/moengage_4e9893.png"  />
3. 特定のチームのすべてのアラートを表示するには、**All Teams** リストでチームを選択します。

アラートに対して操作を実行するには、次の手順に従います。

1. 行をクリックすると、アラートの詳細を確認し、パフォーマンスを分析できます。
2. 行の末尾にある <img alt="Icon.png" src="/images/moengage_fd3c04.png" /> アイコンをクリックすると、アラートで許可されているオプションのリストから選択できます。

# Total Alerts

このタブには、選択したチームのダッシュボードにあるすべてのアラート(アクティブ、一時停止、停止)が一覧表示されます。

許可されている操作

1. 1. Edit
   2. Duplicate
   3. Pause
   4. Stop
   5. Archive

# Active Alerts

このタブには、選択したチームのダッシュボードにあるすべてのアクティブなアラートが一覧表示されます。

許可されている操作

1. 1. Edit
   2. Duplicate
   3. Pause
   4. Stop
   5. Archive

# Archived Alerts

このタブには、選択したチームのダッシュボードにあるすべてのアーカイブ済みアラートが一覧表示されます。

許可されている操作:

1. 1. Duplicate
   2. Unarchive

# Paused Alerts

このタブには、選択したチームのダッシュボードにあるすべての一時停止中のアラートが一覧表示されます。

許可されている操作:

1. 1. Edit
   2. Duplicate
   3. Resume
   4. Stop
   5. Archive

# Stopped Alerts

このタブには、選択したチームのダッシュボードにあるすべての停止済みアラートが一覧表示されます。

許可されている操作:

1. 1. Duplicate
   2. Archive

# Drafts

このタブには、あなたが作成したダッシュボード内のすべての下書きアラートが一覧表示されます。

許可されている操作:

1. 1. Edit
   2. Duplicate
   3. Delete

# アラートの検索

下の画像に示すように、次のフィルター条件を指定して、任意のタブでアラートを検索できます。

1. 1. Alert Name または Alert ID で検索
   2. Channels で検索
   3. Status で検索
   4. Created Date で検索
   5. Alert Tags で検索
   6. Created By で検索

# アラートの作成

All Alerts ページの右上にある **+CreateAlert** ボタンを使用して、アラートを作成することもできます。詳細については、[アラートの作成](/ja/user-guide/inform/create/create-alert)を参照してください。

# アラートの編集

このオプションでは、アラートで設定されたチャネルに定義されたメッセージを変更できます。アラートを編集してテストし、ログを確認してエラーやリクエストの失敗の原因を把握できます。

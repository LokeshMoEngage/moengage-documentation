## 問題

SMS メッセージはユーザーに正常に送信されているにもかかわらず、アラートの統計(Inform)が表示されません。

## 解決策

統計を確実に受け取るには、リクエストにユーザー ID を含めてください。

<Warning>
  現在の製品仕様では、ユーザー ID が渡されない場合、MoEngage は統計をサポートしていません。
</Warning>

<Accordion title="Inform を通じて送信されたメッセージの数をセグメント化するにはどうすればよいですか?">
  Inform を通じて送信されたメッセージは、キャンペーンイベントを **Alert ID** 属性でフィルタリングすることで追跡できます。このセグメントを作成するには、次の手順に従います。

  1. MoEngage ダッシュボードに移動し、**Create segment** をクリックします。
  2. **User behavior** を選択し、関連するチャネルイベント(例: `Email Sent`、`SMS Sent`、`Notification Sent iOS, Notification Sent Android`、`WhatsApp Message Sent`)を選択します。
  3. 期間を定義します(例: "in the last 3 days")。
  4. 属性 **Alert ID** のフィルターを追加します。
  5. 演算子を **exists** に設定します。_(例: これにより、どのアラートがメッセージをトリガーしたかに関係なく、指定した期間中に Inform メッセージが送信されたすべてのユーザーが返されます)。_

  <Note>
    すべてのアラートではなく特定の 1 つのアラートのリーチを追跡したい場合は、上記と同じ手順に従い、演算子を **exists** から **is** に変更して、値フィールドに特定の Alert ID を選択します(例: _Alert ID is 69c63d7218dfa5e41e2f1c73_)。
  </Note>
</Accordion>

<Accordion title="MoEngage Inform を通じて送信されたメッセージの総数を確認するにはどうすればよいですか?">
  MoEngage ダッシュボードで、配信と使用状況に関する包括的な統計を確認できます。**Settings** \> **Billing** \> **Usage** に移動すると、Inform を通じてすべてのチャネルで送信された Inform メッセージの総数を確認できます。詳細については、[Usage Details](https://www.moengage.com/docs/user-guide/settings/account/billing/usage-details) を参照してください。
</Accordion>

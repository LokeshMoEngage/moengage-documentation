All Alertsページでは、現在Active、Paused、Archived、Stopped、およびDraftの状態にあるすべてのアラートを確認できます。

**ナビゲーション**:

MoEngageダッシュボードのサイドナビゲーションで、Inform-\> Alertsを選択します。

特定のチームのすべてのアラートを表示するには、Teamsドロップダウンでチームを選択します。

アラートに対して操作を実行するには、次の手順を実行します。

1. 行をクリックすると、アラートの詳細を確認し、パフォーマンスを分析できます。
2. 行の末尾にある <Icon icon="ellipsis-stroke-vertical" /> アイコンをクリックすると、アラートで許可されているオプションの一覧から選択できます。

# Total Alerts

このタブには、選択したチームのダッシュボード内のすべてのアラート（アクティブ、一時停止、停止）が一覧表示されます。

許可されている操作

   1. Edit
   2. Duplicate
   3. Pause
   4. Stop
   5. Archive

# Active Alerts

このタブには、選択したチームのダッシュボード内のすべてのアクティブなアラートが一覧表示されます。

許可されている操作

   1. Edit
   2. Duplicate
   3. Pause
   4. Stop
   5. Archive

# Archived Alerts

このタブには、選択したチームのダッシュボード内のすべてのアーカイブ済みアラートが一覧表示されます。

許可されている操作:

   1. Duplicate
   2. Unarchive

# Paused Alerts

このタブには、選択したチームのダッシュボード内のすべての一時停止中のアラートが一覧表示されます。

許可されている操作:

   1. Edit
   2. Duplicate
   3. Resume
   4. Stop
   5. Archive

# Stopped Alerts

このタブには、選択したチームのダッシュボード内のすべての停止したアラートが一覧表示されます。

許可されている操作:

   1. Duplicate
   2. Archive

# Drafts

このタブには、ダッシュボード内でお客様が作成したすべての下書きアラートが一覧表示されます。

許可されている操作:

   1. Edit
   2. Duplicate
   3. Delete

# アラートを検索する

以下の画像に示すように、次のフィルター条件を指定して、任意のタブでアラートを検索できます。

   1. Alert NameまたはAlert IDで検索
   2. Channelsで検索
   3. Statusで検索
   4. Created Dateで検索
   5. Alert Tagsで検索
   6. Created Byを使用して検索

# アラートを作成する

All Alertsページの右上にある **+CreateAlert** ボタンを使用して、アラートを作成することもできます。詳細については、[アラートを作成する](/ja/user-guide/inform/create/create-alert)を参照してください。

# アラートを編集する

このオプションを使用すると、アラートで設定されたチャネルに対して定義されたメッセージを変更できます。アラートを編集してテストし、ログを確認してエラーやリクエストの失敗を把握できます。

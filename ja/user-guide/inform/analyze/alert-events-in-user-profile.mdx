ユーザーに関連するすべてのイベントは、User ProfileのActivity Infoタブに表示されます。特定のユーザーについて、アラートに関連するイベントを確認するには、次の手順を実行します。

1. Segmentationでユーザーを検索します（Create Segment -\> 検索結果で目的のユーザーをクリックするか、Create Segment画面上部の検索バーを使用してユーザーIDで特定のユーザーを検索します）。
2. User Profileで、Activity Infoタブをクリックします。
3. サポートされている各チャネルでは、次のイベントを確認できます。
   - Push - Notification Sent iOS、Notification Sent Android、Notification Sent Web、Notification Clicked iOS、Notification Clicked Android、およびNotification Clicked Web
   - SMS - SMS Sent、SMS Delivered
   - Email - Email Sent、Email Delivered
4. 以下に示すように、目的のイベントをクリックしてイベントの詳細を表示します。 <img alt="AlertEvents.png" src="/images/moengage_55479a.png" />

## Activity Infoで確認できる情報

次の情報を確認できます。

- イベント間の所要時間
- 各アラートイベントで確認できる情報:
  | 属性 | 説明 |
  | --- | --- |
  | Event Time | デバイス上でイベントが実行された時刻（デバイスで取得可能な時刻）を示します。デバイスで生成されないイベント（MoEngageが生成したイベント）やデバイス時刻を持たないイベント（Data APIイベント）の場合、イベント時刻はユーザーのタイムゾーンで記録されます。これが利用できない場合は、Appのタイムゾーンが表示されます。どちらも利用できない場合は、UTC時刻がEvent Timeとして使用されます。 |
  | Event Received Time | イベントがSDKまたはData APIからMoEngageに到達した時刻を示します。 |
  | Transaction ID | ユーザーにアラートが送信される対象のトランザクションを示す一意の識別子を示します。詳細については、[Inform API Request Details](/ja/api/inform/inform-overview)を参照してください。 |
  | Request Type | リクエストの種類を示します。Live（イベントがLiveアラートに関連する場合）またはTest（イベントがテストアラートに関連する場合）のいずれかです。 |
  | Time to send | MoEngageがメッセージ/Eメール/通知の送信に要した時間を示し、次のイベントに含まれます: SMS Sent/ Email Sent/ Notification Sent iOS/ Notification Sent Android/ Notification Sent Web |
  | Time to deliver | メッセージ/Eメール/通知の配信に要した時間を示し、次のイベントに含まれます: SMS Delivered/ Email Delivered/ Notification Clicked iOS/ Notification Clicked Android/ Notification Clicked Web  <br />SMSチャネルの場合、_Time to deliver _には次の内容が含まれます。 <ul><li>Kalyera、Gupshup、およびICSの場合は、ユーザーへのアラートの配信に要した正確な時間（配信コールバックで受信した配信タイムスタンプに基づくため）</li><li>TwilioおよびSinchの場合は、配信コールバックを受信した時刻（受信した配信コールバックに配信タイムスタンプが含まれないため）</li></ul> Emailチャネルの場合、Time to deliverの情報はSendGridおよびAmazon SESでのみ確認できます。|
  | Alert Name | アラートの名前を示します。 |
  | Request ID | イベントを生成したアラートに関連付けられたリクエストの一意の識別子を示します。 |
  | Alert ID | アラートの一意の識別子を示します。 |
  | Alert Channel | イベントに関連付けられたアラートチャネルを示します。 |
  | Notification Type | この通知がInformを使用して送信されたことを表します。 |

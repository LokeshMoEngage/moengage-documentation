MoEngage モバイルアプリ（MoEngage Go）を使用すると、スマートフォンからキャンペーンのパフォーマンスを監視し、実行中のキャンペーンを管理し、レビュー待ちのキャンペーンを承認できます。これは MoEngage Web ダッシュボードのコンパニオンアプリであり、デスクを離れているときに完了する必要があるタスクに重点を置いています。

<Info>
  このアプリは iOS と Android で利用できます。
</Info>

## アプリでできること

モバイルアプリでは、キャンペーンデータへの読み取りアクセスと、外出先で実行できる厳選されたアクションが提供されます。Web ダッシュボードに代わるものではなく、デスクでの作業時間外に最も頻繁に必要となる情報とコントロールを表示します。アプリは、下部のナビゲーションバーからアクセスできる 3 つのメインタブと、専用の詳細画面で構成されています。
     <img alt="moe-go-campaign-screen1.png"  src="/images/moe-go-campaign-screen1.png" width="50%" />
- **Campaigns**: キャンペーンを監視および管理できるデフォルトのランディング画面です。この画面の上部では、ドロップダウンを使用してワークスペースを切り替えることができます。All Campaigns と My Campaigns を切り替えたり、検索バーやフィルターアイコンを使用して特定のキャンペーンを見つけたりできます。各キャンペーンは、ステータス、チャネル、タイムスタンプ、および概要レベルのパフォーマンス指標（Sent、Open、Clicks など）を要約したカードとして表示されます。
- **Notifications**: アラート、配信の失敗、保留中の承認リクエストにアクセスします。
- **Profile**: アカウントの詳細、アプリのバージョン、ヘルプリソース、サインアウトオプションにアクセスします。
- **Campaign Details**: Campaigns タブで個々のキャンペーンカードをタップすると、その詳細画面が開きます。キャンペーンの主要な情報、分析、情報が表示されます。

## 対象ユーザー

このアプリは、Web ダッシュボードを開かずに以下のタスクを実行する必要があるマーケター、キャンペーンマネージャー、プロダクトオーナーを対象としています。

- キャンペーンのパフォーマンスを確認する。
- キャンペーンの一時停止や停止など、キャンペーンに対して即座にアクションを実行する。
- チームから送信されたキャンペーンを承認または却下する。
- キャンペーンの失敗、有効期限切れ、主要指標の大幅な変化について常に把握する。

## ユースケース

以下のユースケースでは、アプリがサポートするように設計されたタスクについて説明します。

- **キャンペーンのパフォーマンスを監視する**: 会議中や通勤中など、Web ダッシュボードから離れているときに、Campaigns 画面を開いてキャンペーンのパフォーマンスを確認できます。キャンペーンカードをスクロールして個々のキャンペーンの概要レベルのパフォーマンス指標を一目で確認し、現在有効、スケジュール済み、または送信済みのキャンペーンを簡単に見分けることができます。
- **キャンペーンを即座に一時停止または停止する**: 実行中のキャンペーンのパフォーマンスが低い場合、誤ったオーディエンスに送信している場合、または外部イベントの影響を受けている場合、デスクに戻るのを待たずに対処できます。Campaigns タブからキャンペーンを開き、その詳細と現在のパフォーマンスを確認して、キャンペーン詳細画面から一時停止または停止します。
- **チームから送信されたキャンペーンを承認または却下する**: チームでキャンペーン承認ワークフローが有効になっている場合、レビュー待ちのキャンペーンは Notifications タブと Campaigns 画面の My Campaigns に表示されます。スマートフォンでキャンペーンの詳細を確認して承認または却下できるため、ダッシュボードから離れている間もキャンペーン作業が滞ることはありません。
- **キャンペーンの詳細とオーディエンスを確認する**: キャンペーンの内容やターゲットを確認する必要がある場合は、Campaigns タブで検索とフィルターを使用してキャンペーンを見つけ、キャンペーンカードをタップしてキャンペーン詳細画面を開きます。そこでは、キャンペーンの主要な情報、クリエイティブのプレビュー、キャンペーン分析、送信先のセグメントまたはオーディエンスを確認できます。

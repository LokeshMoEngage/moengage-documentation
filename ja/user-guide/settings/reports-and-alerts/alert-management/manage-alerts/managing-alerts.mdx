アラートは Alert Management ダッシュボードから管理できます。作成されたアラートはすべてダッシュボードに一覧表示されます。編集、購読、複製などの操作を行うには、必要なアクセス権限が必要です。詳細については、[Alert Management のアクセス権限](/ja/user-guide/settings/account/team-management/access-roles)を参照してください。

## ナビゲーション

MoEngage ダッシュボードで Alert management にアクセスするには、**Settings** **-\> Reports and Alerts -\> Alert management** に移動します。

ダッシュボードでは、次のタブを利用できます。

1. **All alerts** - このセクションには、MoEngage アカウントで作成されたすべてのアラートが含まれます。
2. **System alerts** - このセクションには、Alert Management の一部として提供されるデフォルトのアラートが含まれます。システムアラート (デフォルトアラート) には、Campaign Expiry、Facebook Token Expiry、APNS Token Expiry などがあります。
3. **Custom alerts** - このセクションには、お客様のリクエストに応じて MoEngage アカウント用に作成されたカスタムアラートが含まれます。

## アラート情報

3 つのタブすべてに一覧表示されるすべてのアラートについて、次の情報を確認できます。

1. Alert name - この列にはアラートの名前が表示されます。
2. Create alerts on - この列にはアラートの種類が表示されます。システムアラートの種類は、Campaign expiry、Facebook token expiry、APNS token expiry、Campaign Stats、Flows Stats、Events and User Attribute Usage、Events Volume、Active Users Volume です。
3. Created by - この列には、アラートを作成したメンバーのメール ID が表示されます。
4. Subscribed by - この列には、アラートを購読しているメンバーのメール ID が表示されます。
5. Subscription - この列には、ログインしているユーザーのアラートに対する購読ステータスが表示されます。たとえば、アラートを購読している場合、ステータスは **Subscribed to Email** となり、購読していない場合、ステータスは **Subscribe to Email** となります。_Subscribe to_ リンクをクリックすると、アラートを購読できます。
6. Actions - <Icon icon="ellipsis-stroke-vertical" />をクリックすると、利用可能なオプションが表示されます。詳細については、[アラートに対して実行できる操作](/ja/user-guide/settings/reports-and-alerts/alert-management/manage-alerts/managing-alerts#actions-that-can-be-performed-on-alerts)を参照してください。

## アラートに対して実行できる操作

行の末尾にある省略記号アイコン <Icon icon="ellipsis-stroke-vertical" />をクリックすると、アラートに対して次の操作を実行できます。

![2.png](/images/moengage_363a76.png)

| フィールド | 説明 |
| --- | --- |
| View | この操作では、作成されたアラートを表示できます。Alert management ダッシュボードへのアクセス権を持つメンバーであれば、誰でもアラートを表示できます。 |
| Edit | この操作では、アラートを編集できます。編集できるのは、次のセクションのフィールドのみです:   - Alert condition - Filter by - Members  <br />**注**: **General details** セクションのフィールドは編集できません。  アラートを複製または削除することもできます。 <br /><img alt="9.gif" src="/images/moengage_eba429.png" /> |
| Duplicate | この操作では、アラートを複製できます。システムアラートは複製できません。 |
| Unsubscribe | この操作では、アラートの受信を購読解除できます。 |
| Subscribe others | この操作では、他のメンバーをアラートを受信する購読者として追加できます。たとえば、新しいメンバーがチームに加わり、特定のイベントに関するアラートを受信する購読者として追加したい場合に、このオプションを使用できます。 <br /><img alt="3.gif" src="/images/moengage_8076da.png" /> |
| Delete | この操作では、アラートを削除できます。削除したアラートは、ダッシュボードで表示できなくなります。 |

アラートは、種類、作成者、購読者でフィルタリングできます。アラートをフィルタリングするには、右上の **Filter alerts** をクリックし、次に示すようにフィルタリングの条件を指定します。

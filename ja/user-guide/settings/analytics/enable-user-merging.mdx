---
title: "ユーザーマージの有効化"
description: "MoEngageのユーザーマージを使用して、匿名ユーザーとログインユーザーのプロファイルを単一のアイデンティティに統合し、より正確な分析レポートを実現します。"
---

MoEngage Analyticsのユーザーマージは、分析レポート専用に、異なるデバイスやセッション(匿名とログイン済み)にまたがるアクティビティを単一の統合されたユーザープロファイルに集約します。これにより、MoEngage Analytics内でより正確なユーザー数と[行動分析](/ja/user-guide/analyze/analytics/behavior/behavior-overview)が可能になります。

MoEngageでは、ユーザーが異なるデバイスを使用している場合でも、各ユーザーに単一のユーザーIDを持たせることができます。ユーザーがWebサイトやアプリにアクセスすると、MoEngageはユーザーがシステムにログインした後に、匿名ユーザープロファイルを登録済みユーザープロファイルとマージします。ユーザーマージの詳細については、[ユーザーマージ](/ja/user-guide/data/user-data/anonymous-to-registered-user-merge)を参照してください。

ユーザーマージを有効にするには、次の手順を実行します。

1. MoEngageダッシュボードの左側のナビゲーションメニューで、**Settings** \> **Analytics** \> **User merging** に移動します。
2. User mergingページで、**Analytics user merging** トグルをオンにします。

<Info>
MoEngageのセグメンテーション機能には、独自のユーザーマージロジックがあります。Analyticsのユーザーマージが無効になっている場合、同じ条件でもセグメンテーションクエリとAnalyticsレポートの間でユーザー数に差異が生じることがあります。これは、Analyticsが匿名セッションとログイン済みセッションを別々のユーザーとして扱うためです。**Analytics user merging** トグルを有効にすると、MoEngage Analytics内でマージロジックが適用され、これらの数値を揃えることができます。
</Info>

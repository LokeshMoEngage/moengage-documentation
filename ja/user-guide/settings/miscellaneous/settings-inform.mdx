MoEngage Dashboard には、Inform に関する 2 つの設定があります。

1. [API 設定](/ja/user-guide/settings/miscellaneous/settings-inform#api-settings) - Workspace ID と API SECRET を表示します。
2. [ユーザー属性設定](/ja/user-guide/settings/miscellaneous/settings-inform#user-attribute-settings) - アラートのパーソナライズ用フォールバックとしてユーザー属性を使用するかどうかを有効化または無効化できます。

# API 設定

Inform の API 設定にアクセスするには、MoEngage Dashboard -\> Settings -\> APIs -\> General Settings -\> Inform に移動します。

次のパラメーターを使用できます。

- **Workspace ID** - MoEngage でアカウントを作成すると、Workspace ID と呼ばれる一意の識別子が割り当てられます。この値は、アカウントの識別と認証に使用されます。

- **API SECRET**- API SECRET は、Workspace ID とともに提供される認証キーです。Regenerate API Secret アイコンをクリックすると、API SECRET を再生成できます。**注意**: セキュリティ侵害がない限り、MoEngage はキーの再生成を推奨していません。別の API SECRET を生成して保存すると、古い SECRET を使用した API 呼び出しは機能しなくなります。

# ユーザー属性設定

MoEngage のユーザープロファイルで利用可能な **User Attributes** は、Inform でのパーソナライズのフォールバックとして追加できます。たとえば、アラートでパラメーターとして 'name' を送信したいものの、アラートの送信時に API リクエストでその値が渡されない場合（マイクロサービスが 'name' の値を把握していなかったため）、フォールバックを定義できます。アラートの送信先となるユーザーのユーザー属性（リクエスト内の 'name' パラメーターの値を含むもの）からフォールバックを取得するように設定できます。リクエスト対象のユーザーでこのフォールバックが利用できない場合は、リクエストを完了するために使用するデフォルト値を定義できます。

**注意**: User Attributes を有効にすると、Inform リクエストの SLA が 3 秒（p90）から 4 秒（p90）に増加します。

テキストパーソナライズのフォールバックの一部としてユーザー属性を利用するには、次の手順を実行します。

1. MoEngage Dashboard -\> Settings -\> Inform -\> User Attributes に移動します。
2. *Enable user attributes* トグルをオンにします。
3. ポップアップで Enable をクリックし、以降の Inform リクエストで SLA が長くなることを確認します。   

   <img alt="EnableUserAttributeConfirmation__1_.png"  src="/images/moengage_5e20c0.png"  />

ユーザー属性を有効にすると、それに基づいてフォールバックを定義できるようになり、以降の API 呼び出しではフォールバックアルゴリズムの一部としてユーザー属性が考慮されるようになります。詳細については、[ユーザー属性を使用したパーソナライズ](/ja/user-guide/inform/create/personalize-alert)を参照してください。

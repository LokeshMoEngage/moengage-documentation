## 問題

MoEngage ダッシュボードにログインする際、ブラウザーで reCAPTCHA との通信に問題が発生します。

## 手順

reCAPTCHA が読み込まれない、または正しく機能しない場合は、次の手順を実行してください。

1. **ブラウザーを更新する**:
   - ブラウザーが最新であり、最小システム要件を満たしていることを確認します。
2. **JavaScript を有効にする**:
   - ブラウザーで JavaScript が有効になっていることを確認します。詳細については、[Allow JavaScript in your browser](https://support.google.com/adsense/answer/12654?hl=en) を参照してください。
3. **拡張機能を無効にする**:
   - reCAPTCHA に干渉する可能性のあるブラウザー拡張機能をオフにします。
4. **ブラウザーをリセットする**:
   - ブラウザーの設定をリセットしてみます。
5. **マルウェアを確認する**:
   - ブラウザーの機能に影響を与える可能性のあるマルウェアがないか、デバイスをスキャンします。
6. **DNS を変更する**:
   - Google DNS に切り替えて、接続に関する潜在的な問題を解決します。
7. **VPN やプロキシサービスを避ける**:
   - VPN やプロキシサービスは、reCAPTCHA のセキュリティ対策をトリガーする可能性があります。これらを無効にしてから、もう一度お試しください。

# 概要

新しい場所や新しいデバイスからログインする場合は、メールアドレスに送信される OTP を使用した追加の認証が必要です。MoEngage は、お使いの ID で新しいデバイスや新しい場所を検出するたびに、登録済みのメールアドレスに OTP を送信します。これには、ログイン認証情報のみを使用する場合と比べて次のような利点があります。

- 認証のレイヤーが追加されることで、セキュリティが向上します。
- 認証情報が漏洩した場合のリスクが軽減されます。

# ログイン

ログインページでログイン認証情報を入力すると、MoEngage はデバイスまたは場所が認識されていないことを検出し、OTP の入力を求める新しいページに移動します。

<img
  alt="Screenshot_2022-10-11_at_12.49.04_AM.png"

  style={{ width:"58%" }}
/>

1. 登録済みのメールアドレスで受信した OTP を入力します。
2. **Verify** をクリックします。

<Info>
  - 受信トレイにメールが見当たらない場合は、件名が MoEngage login OTP のメールを検索してください。
  - OTP の有効期間は 3 分間のみです。3 分が経過すると OTP の有効期限が切れ、認証情報を再入力する必要があります。
</Info>

これで MoEngage アカウントに移動します。それでも問題が解決しない場合は、MoEngage サポートチームにお問い合わせください。

---

## 問題

MoEngage ダッシュボードにログインできません。

## 解決策

次の手順を実行します。

- データクラスターの URL を確認します。ログインに使用している URL が正しいことを確認してください。次の表に、各データセンターの正しい URL を示します。データセンターを確認するには、管理者またはカスタマーサクセスマネージャー (CSM) にお問い合わせください。
  | データセンター名 | ダッシュボード URL |
  | --- | --- |
  | DC-01 | [https://dashboard-01.moengage.com/v4/#/auth](https://dashboard-01.moengage.com/v4/#/auth) |
  | DC-02 | [https://dashboard-02.moengage.com/v4/#/auth](https://dashboard-02.moengage.com/v4/#/auth) |
  | DC-03 | [https://dashboard-03.moengage.com/v4/#/auth](https://dashboard-03.moengage.com/v4/#/auth) |
  | DC-04 | [https://dashboard-04.moengage.com/v4/#/auth](https://dashboard-04.moengage.com/v4/#/auth) |
  | DC-05 | [https://dashboard-05.moengage.com](https://dashboard-05.moengage.com)[v/4/#/auth](https://dashboard-04.moengage.com/v4/#/auth) |
  | DC-06 | [https://dashboard-06.moengage.com](https://dashboard-06.moengage.com)[v/4/#/auth](https://dashboard-04.moengage.com/v4/#/auth) |
- ダッシュボードに参加済みかどうかを確認します。"Password or email incorrect" エラーが表示され、パスワードリセットのリンクが届かない場合は、ダッシュボードにサインアップまたは参加済みかどうかを確認してください。
  - アカウントの管理者に連絡して、ステータスを確認します。
  - ステータスが Pending の場合は、MoEngage からのサインアップメッセージがメールに届いていないか確認し、手続きを完了します。 <img alt="joined.png" src="/images/moengage_38669d.png" />
- ブラウザーのキャッシュと Cookie をクリアします。パスワードをリセットしてもログインできない場合は、ブラウザーのキャッシュと Cookie をクリアしてみてください。
  - ログインページを開きます。
  - ページを右クリックし、**Inspect** をクリックします。
  - **Applications** タブで、**Storage** セクションに移動します。
  - 次のスクリーンショットのように、**Local Storage** と **Session Storage** をクリアします。 <img alt="cache.png" src="/images/moengage_52c3a0.png" />

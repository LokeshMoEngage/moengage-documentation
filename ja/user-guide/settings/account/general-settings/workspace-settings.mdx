## ワークスペース設定を構成する

ワークスペース設定を構成するには、次の手順を実行します。

1. MoEngage ダッシュボードの左側のナビゲーションメニューで、**Settings** \> **Account** \> **General settings** をクリックします。 <img src="/images/moengage_988348.png" />
2. General settings ページで、次の詳細を入力します。

| セクション | フィールド | 説明 |  |
| :-- | :-- | :-- | --- |
| **Basic details** | Workspace ID (earlier app id) | MoEngage が現在のワークスペースに割り当てた一意の ID です。読み取り専用のフィールドです。組織内の開発者は、次の場合にこの Workspace ID が必要になります: <ul><li>SDK を統合する場合</li><li>API リクエストを認証する場合</li></ul> |  |
|  | Time zone | タイムゾーンは、現在のタイムゾーンに基づいて自動的に選択されます。必要に応じて別のタイムゾーンを選択してください。適切なタイムゾーンを選択することで、ユーザーのローカルタイムゾーンに基づいて、メッセージや通知が適切な時間に配信されます。 |  |
| **Goal mapping** | Conversion goal | コンバージョン目標とは、ユーザーに完了してほしい特定のアクションです。製品の購入、サインアップ、コンテンツの閲覧など、ビジネス目標における進捗や価値を示す主要なインタラクションであれば何でもかまいません。この目標を定義することで、キャンペーンが望ましいユーザー行動をどれだけ効果的に促進しているかをトラッキングできます。コンバージョン目標を選択した後、**Revenue attribute** フィールドで属性を選択する必要があります。 <br /><br />コンバージョンに関するインサイトを確認するには、コンバージョン目標と収益属性を選択する必要があります。設定した属性は、Key Metrics ダッシュボードにコンバージョン指標として表示されます。変更がワークスペース全体に反映されるまでに最大 30 分かかります。Key Metrics ダッシュボードのコンバージョン指標は、24 時間後に反映され始めます。詳細については、[Key Metrics](/ja/user-guide/analyze/dashboards/key-metrics) を参照してください。 |  |
|  | Revenue attribute | 収益属性とは、ユーザーのアクションに関連付けられた特定のデータで、そのアクションによって生み出された金銭的価値を示します。たとえば、コンバージョン目標が "product purchased" の場合、その購入に費やされた金額を測定する収益属性は "price" になります。このフィールドは **Conversion goal** フィールドに依存します。コンバージョン目標を選択すると、その目標に関連する収益属性がこのリストに表示されます。 <br /><br />目標のマッピングは、顧客生涯価値 (LTV) の計算に役立ち、[Key Metrics](/ja/user-guide/analyze/dashboards/key-metrics#engagement) ダッシュボードにコンバージョンと収益のトレンドを表示します。 |  |
|  | Currency | 正しい通貨を設定することは、正確な価格情報、オファー、プロモーションを顧客に提供するうえで重要です。現地通貨で価格を表示することで、顧客体験が向上し、混乱や食い違いを防ぐことができます。また、なじみのあるわかりやすい形式で情報を提示することで、信頼と信用の構築にも役立ちます。このフィールドは **Revenue attribute** フィールドに依存します。収益属性を選択すると、利用可能な通貨がこのリストに表示されます。 |  |
| **Workspace classification** | Classify your workspace environment | このワークスペースを本番用と非本番用のどちらに使用するかを指定します。 <ul><li>このワークスペースで実際のエンドユーザーのデータとキャンペーンを扱う場合は、**Production** を選択します。</li><li>このワークスペースを UAT、ステージング、またはテストに使用する場合は、**Non-Production** を選択します。</li></ul> |  |

<Frame>
  ![General Settings の分類](/images/general-settings-classify.png)
</Frame>

3. **Save** をクリックします。

## ワークスペースの分類

<Info>
  - ワークスペースの分類データは、今後、ロールアウトの各段階で通知される自動リリースサイクルのプロビジョニングに使用されます。
  - この機能は、Enterprise プランのお客様のみが利用できます。
</Info>

ワークスペースの分類を使用すると、ワークスペースに **Production** または **Non-Production** のタグを付けることができます。これにより、MoEngage は機能のロールアウトをより細かく管理できます。新機能はまず非本番ワークスペースにロールアウトされ、その後の段階で本番ワークスペースにロールアウトされます。

### 既存のワークスペースの分類を設定する

1. MoEngage ダッシュボードの左側のナビゲーションメニューで、**Settings** \> **Account** \> **General settings** をクリックします。
2. **Classify your workspace environment** フィールドで、次のいずれかのオプションを選択します。
   - **Production**: ワークスペースで実際のエンドユーザーのデータとキャンペーンを扱う場合は、このオプションを選択します。
   - **Non-Production**: ワークスペースを UAT、ステージング、またはテストの目的で使用する場合は、このオプションを選択します。
3. **Save** をクリックします。

### オンボーディング時にワークスペースの分類を設定する

新しいワークスペースを作成する際、オンボーディングフローにはワークスペースの分類を設定する必須のステップが含まれます。最後のステップで、ワークスペースの作成を完了する前に **Production** または **Non-Production** のいずれかを選択する必要があります。

<Frame>
  ![分類](/images/classify.png)
</Frame>

<Note>
  - 分類が事前に選択されていない既存のワークスペースは、デフォルトで **Non-Production** として扱われます。
  - **Test environment** (Live/Test 環境の切り替えによるもの) は常に **Non-Production** としてマークされ、変更できません。
</Note>

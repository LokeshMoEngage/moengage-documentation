MoEngageは、次の機能によってアクセスを制限し、データ保護を確保するセキュリティを提供しています。

- [ログイン](/ja/user-guide/settings/account/security/overview#login)
- [2段階認証/2FA](/ja/user-guide/settings/account/security/overview#2-step-verification)
- [API Firewall](/ja/user-guide/settings/account/security/overview#api-firewall)
- [Firewall](/ja/user-guide/settings/account/security/overview#firewall)
- [MoEngageアクセス](/ja/user-guide/settings/account/security/overview#moengage-access)

<Info>
  上記の機能を設定するには、Adminである必要があります。
</Info>

# ログイン

チームメンバーがログインするための認証方法を定義できます。MoEngageは次のログイン方法をサポートしています。

- パスワードまたはGoogleサインイン
- Googleサインインのみ
- シングルサインオン（SSO）のみ

![セキュリティの概要](/images/overview-security.png)

詳細については、[ログイン方法を設定する](/ja/user-guide/settings/account/security/set-up-the-login-method)を参照してください。

# 2段階認証

ワークスペースに2段階認証または2要素認証を設定できます。2段階認証を有効にすると、チームメンバーはログイン時に追加の認証を求められます。詳細については、[2要素認証（2FA）または2段階認証](/ja/user-guide/settings/account/security/2-step-verification-or-two-factor-authentication-2fa)を参照してください。

# API Firewall

API Firewallを設定すると、APIカテゴリ（Data、Segmentation、Campaigns、Partner Integration、Content）ごとに特定のIPアドレスのセットをホワイトリストに登録できます。カテゴリが強制されている場合、MoEngageはホワイトリストにないIPアドレスからのそのカテゴリのAPIへのリクエストを拒否するため、API認証情報が漏洩した場合でもデータを保護できます。詳細については、[API Firewall](/ja/user-guide/settings/account/security/api-firewall)を参照してください。

# Firewall

ファイアウォールを有効にすると、特定のIPアドレスまたは範囲を許可またはブロックすることで、ダッシュボードへのアクセスを制限および制御できます。詳細については、[Firewall](/ja/user-guide/settings/account/security/firewall)を参照してください。

# MoEngageアクセス

MoEngageサポートチームがワークスペースにアクセスして問題をトラブルシューティングできるようにすることができます。詳細については、[MoEngageチームのアクセス](/ja/user-guide/settings/account/security/moengage-access)を参照してください。

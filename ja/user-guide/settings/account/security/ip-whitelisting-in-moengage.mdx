## 概要

IPホワイトリスト（IP許可リスト）は、組織がネットワーク、システム、リソースへのアクセスを事前に定義したIPアドレスに制限し、それ以外をすべてブロックできるセキュリティ手法です。このサイバーセキュリティの仕組みにより、企業は不正アクセスを防止し、機密データを保護できます。企業はIPホワイトリストを使用して、ツール、ソフトウェア、アプリケーション、Webサイト、重要なリソースへのアクセスを制御できます。

このドキュメントでは、IPホワイトリストの重要性と、マーケターや開発者がそれを効果的に活用する方法について説明します。

## IPホワイトリストの主な利点

IPホワイトリストには次の利点があります。

- **セキュリティの強化**: 既知の信頼できるIPアドレスからの接続のみを許可することで、ホワイトリストは不明なソースからの潜在的な脅威を効果的にブロックし、不正アクセスやマルウェア攻撃のリスクを大幅に低減します。全体として、機密データを保護するための追加のセキュリティレイヤーとなります。
- **プロアクティブな防御**: 既知の脅威を特定してブロックすることに依存するブラックリストとは異なり、ホワイトリストは承認されたアクセスのみを許可するプロアクティブなアプローチをとるため、新たな脅威に対してより効果的です。
- **誤検知の削減**: ホワイトリストは未承認のソースからの接続のみをブロックするため、正当なユーザーを誤ってブロックする可能性が最小限に抑えられ、ストレスや業務の中断が軽減されます。
- **ネットワーク可視性の向上**: 許可されたIPアドレスのリストを積極的に管理することで、組織は誰がネットワークにアクセスしているかをより正確に把握でき、不審なアクティビティを容易に特定できます。

## MoEngageのIPをホワイトリストに登録する

MoEngageは、顧客またはパートナーのサーバーとの間でデータを送受信します。IPホワイトリストを使用すると、リクエストが実際にMoEngageから送信されていることを検証でき、追加のセキュリティレイヤーを確保できます。

MoEngageはマルチテナントのSaaSベンダーであるため、スケールとセキュリティの観点からサービスのIPを頻繁に変更します。サービスの稼働を維持し、顧客に影響を与えないようにするため、状況に応じて別のサーバーからデータを送信する必要がある場合があります。MoEngageは、顧客またはパートナーのサーバーとの間でデータを送受信する際に、このドキュメントに記載されているIPの一部またはすべてを使用する場合があります。

### キャンペーン送信

MoEngageは動的IPを使用します。ただし、MoEngageに静的IP経由でお客様のサービスにアクセスさせる必要がある場合は、お客様側でMoEngageのIPをホワイトリストに登録する必要があります。メッセージングチャネルで静的IPを有効にするには、カスタマーサクセスマネージャー（CSM）またはサポートチームに連絡し、_Send via Static IPs for `<Messaging Channel>`_ の有効化をリクエストしてください。メッセージングチャネルの静的IPが有効になったら、ワークスペースが配置されているデータセンターに基づいて、該当するMoEngageのIPをホワイトリストに登録できます。MoEngageのデータセンターの詳細については、[こちら](/ja/user-guide/data/key-concepts/data-centers-in-moengage)を参照してください。

## MoEngage APIのIPホワイトリスト

[API Firewall](/ja/user-guide/settings/account/security/api-firewall)を使用して、MoEngage APIを呼び出すことができるIPアドレスを制限します。**Settings** > **Account** > **Security** > **API firewall** で、APIカテゴリごとにホワイトリストルールを作成して公開します。

## お客様のIPをホワイトリストに登録する

MoEngageサービスにアクセスできる、お客様またはパートナーのネットワークのIPは次のとおりです。

| タイプ | 説明 | 手順 |
| --- | --- | --- |
| ダッシュボードアクセス | MoEngageダッシュボードにアクセスできる、お客様またはパートナーのネットワークのIPをホワイトリストに登録できます | MoEngageダッシュボードでFirewallを有効にできます。詳細については、[Firewall](/ja/user-guide/settings/account/security/firewall)を参照してください。 |
| Open Analytics | MoEngage Open Analyticsにアクセスできる、お客様またはパートナーのネットワークのIPをホワイトリストに登録できます。 | 件名を _Whitelist IPs for Open Analytics Access_ としてMoEngageのカスタマーサクセスマネージャー（CSM）またはサポートチームに連絡し、ホワイトリストに登録するIPのリストをチケットで共有してください。 |
| MoEngage API | Data、Segmentation、Campaigns、Partner Integration、Contentの各カテゴリにわたって、MoEngage APIを呼び出すことができるIPをホワイトリストに登録できます。 | MoEngageダッシュボードでルールを自分で設定します。詳細については、[API Firewall](/ja/user-guide/settings/account/security/api-firewall)を参照してください。 |

## まとめ

IPホワイトリストは、MoEngageサービスを利用する際のデータセキュリティを維持するうえで重要です。IPホワイトリストの手順に関するサポートや説明が必要な場合は、MoEngageサポートチームにお問い合わせください。

## よくある質問

**MoEngageはMoEngage APIに対するIPホワイトリストを提供していますか？**

はい。[API Firewall](/ja/user-guide/settings/account/security/api-firewall)を使用して、**Settings** \> **Account** \> **Security** \> **API firewall** からIPルールを自分で設定できます。各ルールでは、Data、Segmentation、Campaigns、Partner Integration、Contentのうち1つ以上のAPIカテゴリをホワイトリストに登録します。ルールを公開すると、MoEngageはホワイトリスト外のIPアドレスからそれらのカテゴリへのリクエストを `403` レスポンスで拒否します。

**ブランドはAPIキーのレベルでMoEngage APIにアクセスできるIPを制限できますか？**

いいえ。API Firewallのルールはワークスペースレベルで適用され、個々のAPIキーではなくAPIカテゴリ単位でスコープが設定されます。キーごとのIP制限をリクエストするには、次の手順を実行します。

1. MoEngageダッシュボードにログインします。
2. 右上隅で **Need help** をクリックし、**Submit product idea** をクリックします。

MoEngage は、いくつかのシナリオでアカウントから自動的にログアウトします。次の表に、それらのシナリオと再度アカウントにログインする方法を示します。

| シナリオ | 再度ログインするには: |
| --- | --- |
| セッションの有効期限が切れた場合。適用されるタイムアウト期間については、[Session Expiry](#session-expiry) を参照してください。 | <ol><li>MoEngage アカウントのログイン URL にアクセスします。</li><li>[認証情報を使用してログインします](/ja/user-guide/getting-started/initial-setup/log-in-to-moengage)。</li></ol> |
| ログイン方法が異なるワークスペース間を切り替えた場合。<br/>たとえば、ワークスペース 1 では Google Sign In only を使用し、ワークスペース 2 では Single Sign On (SSO) only を使用している場合です。 | <ol><li>MoEngage アカウントのログイン URL にアクセスします。</li><li>[SSO を使用してログインします](/ja/user-guide/getting-started/initial-setup/log-in-to-moengage)。</li></ol> |
| 認証メカニズムが異なるワークスペース間を切り替えた場合。<br/>たとえば、ワークスペース 1 では 2 段階認証が無効で、ワークスペース 2 では有効になっている場合です。 | <ol><li>[デバイスで 2 段階認証を設定します](/ja/user-guide/getting-started/initial-setup/log-in-to-moengage#set-up-2-step-verification-on-your-device)。</li><li>MoEngage アカウントのログイン URL にアクセスします。</li><li>認証情報を使用してログインします。</li><li>2-Step Verification ページで、認証アプリで生成された 6 桁の確認コードを入力して確認します。</li></ol> |
| Admin がワークスペースレベルで 2 段階認証を有効にしていない状態でアカウントにログインしており、あなたまたは Admin がワークスペースの 2FA 設定を有効にした場合。 | <ol><li>[デバイスで 2 段階認証を設定します](/ja/user-guide/getting-started/initial-setup/log-in-to-moengage#set-up-2-step-verification-on-your-device)。</li><li>MoEngage アカウントのログイン URL にアクセスします。</li><li>認証情報を使用してログインします。</li><li>2-Step Verification ページで、認証アプリで生成された 6 桁の確認コードを入力して確認します。</li></ol> |
| Admin が Google ログインまたは SSO オプションを有効にした場合。 | <ol><li>MoEngage アカウントのログイン URL にアクセスします。</li><li>[Sign in with Google オプションを使用してログインします](/ja/user-guide/getting-started/initial-setup/log-in-to-moengage)。</li></ol> |
| Admin がワークスペース内でのあなたのアクセス権を取り消した場合。 | Admin に再度アクセス権を付与するよう依頼してください。付与されない場合、アカウントにログインできません。 |
| IT チームがワークスペースのファイアウォール設定を有効にしたが、あなたの認証情報がファイアウォールの条件を満たしていない場合。つまり、あなたの IP アドレスが、ワークスペースへのアクセスが許可されている IP アドレスのリストと一致しない場合です。 | IT チームに連絡して、IP アドレスを変更するか、ワークスペースへのアクセスが許可されている IP アドレスを変更してもらってください。 |
| Admin があなたのロールを変更した場合。 | <ol><li>MoEngage アカウントのログイン URL にアクセスします。</li><li>[認証情報を使用してログインします](/ja/user-guide/getting-started/initial-setup/log-in-to-moengage)。</li></ol> |

## Session Expiry

MoEngage は、セッションを終了するために次のタイムアウト期間を適用します。

- **アイドルタイムアウト (24 時間)**: 操作がない状態が 24 時間続くと、MoEngage は自動的にプラットフォームからログアウトします。この期間内に何も操作しなかった場合、セッションの有効期限が切れ、作業を再開するには再認証が必要です。
- **リフレッシュタイムアウト (60 日)**: ワークフローの中断を最小限に抑えるため、MoEngage はリフレッシュトークンを使用してアクティブなセッションを延長します。セキュリティコンプライアンスのため、MoEngage は 60 日ごとにセッションの絶対的な上限を適用します。この期間が経過すると、最近のアクティビティに関係なく、再度ログインする必要があります。

この機能は、追加の認証手段により、MoEngage ダッシュボードへのアクセスを承認された IP アドレスまたは範囲のみに制限・制御します。これにより、セキュリティが向上し、アカウントが侵害されるリスクが低減されます。

<Info>
  ファイアウォールを追加するには、MoEngage ワークスペースの Admin である必要があります。詳細については、[Access Roles](/ja/user-guide/settings/account/team-management/access-roles) を参照してください。
</Info>

# ファイアウォールの追加

ファイアウォールを追加するには、次の手順を実行します。

1. MoEngage ダッシュボードの左側のナビゲーションメニューで、**Settings** \> **Account** \> **Security** をクリックします。
2. Security ページで、**Firewall** タブをクリックします。
   ![](/images/moengage_8b5692.png)
3. **Add** **firewall** をクリックします。 <img src="/images/moengage_58c730.png" />
4. **Add firewall** ダイアログボックスで、次の詳細を入力します。
   ![Screenshot 2025-04-17 at 8.29.37 PM.png](/images/moengage_a31121.png)
5. **Select Type** で、オプションを選択します。
   - **Allowed**: 任意の IP をホワイトリストに登録するには、このオプションを選択します。特定の IP アドレスまたは範囲を追加し、MoEngage ダッシュボードへのアクセス権限を付与できます。これらの IP からの接続のみが成功します。これは、オフィスや指定された VPN など、承認されたユーザーとネットワークにアクセスを制限するためのセキュリティ対策です。
   - **Blocked**: 任意の IP をブラックリストに登録するには、このオプションを選択します。特定の IP アドレスまたは範囲を追加し、MoEngage ダッシュボードへのアクセスをブロックできます。これらの IP からの接続は、MoEngage ダッシュボードへのアクセスが事実上ブロックされます。ユーザーがブロックされた IP アドレスからログインしようとすると、ログインは失敗します。
6. **Enter IPs/ip range** ボックスに、許可またはブロックする IP アドレスとサブネットを Classless Inter-Domain Routing (CIDR) 範囲として入力します。

   <Warning>
     **重要**

     /0 または /32 のサブネットマスクを持つ IP アドレスをブロックしないでください。

     - /0 のサブネットマスクを持つ IP アドレスをブロックすると、考えられるすべての IPv4 アドレスがブロックされ、ワークスペースにアクセスできなくなります。

       <img src="/images/moengage_d57bba.png" />

     - /32 のサブネットマスクを持つ IP アドレスをブロックすると、個々の IP アドレスで意図しないワークスペースへのアクセス不能の問題が発生する可能性があります。

       <img src="/images/moengage_d7c082.png" />
   </Warning>

7. **Save** をクリックします。

   <Warning>
     - 現在の IP がファイアウォールの条件を満たしていない場合、次のエラーメッセージが表示されます。

       ![Screenshot\_2023-06-02\_at\_1.45.15\_PM.png](/images/moengage_b11750.png)

       この場合、ワークスペースにファイアウォールを追加することはできません。

     - ファイアウォールが正常に追加されると、登録されたネットワークに接続していないログイン中のユーザーは自動的にログアウトされます。
   </Warning>

# IP または IP 範囲の編集

IP または IP 範囲を編集するには、次の手順を実行します。

1. Security ページで、**Firewall** タブをクリックします。
2. **Actions** の下にある IP/IP 範囲の横の省略記号アイコンをクリックします。
3. **Edit** をクリックします。
   ![](/images/moengage_44f8c6.png)
4. **Edit firewall** ダイアログボックスで、必要な編集を行います。詳細については、[こちら](/ja/user-guide/settings/account/security/firewall) を参照してください。
   ![](/images/moengage_2ca49d.png)
5. **Save** をクリックします。

これで IP のステータスが更新されました。

# IP または IP 範囲の削除

IP または IP 範囲を削除するには、次の手順を実行します。

1. Security ページで、**Firewall** タブをクリックします。
2. **Actions** の下にある IP/IP 範囲の横の省略記号アイコンをクリックします。
3. **Delete** をクリックします。
   ![](/images/moengage_51eafb.png)
   Delete Config ポップアップウィンドウが表示され、設定を削除するかどうかの確認を求められます。
4. **Delete** をクリックします。
   ![](/images/moengage_5c6234.png)

これで IP または IP 範囲が削除されました。

# FAQ

- ****MoEngage ダッシュボードへのアクセスが拒否されるのはなぜですか?****
  MoEngage へのアクセスは、管理者が設定した特定の IP アドレスに制限されている場合があります。
  たとえば、オフィス VPN の IP アドレスはホワイトリストに登録されていても、個人のデバイスが接続しているネットワークは登録されていない場合があります。オフィス VPN の外部から MoEngage ダッシュボードにアクセスしようとすると、MoEngage はアクセスを拒否します。その場合は、オフィス VPN に接続してから MoEngage ダッシュボードにアクセスする必要があります。
  MoEngage ダッシュボードにアクセスできない場合は、MoEngage 管理者に連絡して、ホワイトリストに登録された IP アドレスを使用しているかどうかを確認してください。現在の IP アドレスを確認するには、[What is My IP Address](https://whatismyipaddress.com/) などのウェブサイトを使用してください。

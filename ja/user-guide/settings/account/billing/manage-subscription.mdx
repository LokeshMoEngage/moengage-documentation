サブスクリプションによって、チームが MoEngage でキャンペーンを計画・実行する際に使用できる製品とチャネルが決まります。**Billing** 設定を使用して、サブスクリプションの有効化、現在のプランの確認、契約に含まれる製品の確認を行います。MoEngage が提供するプランの比較については、[Plans and Pricing](https://www.moengage.com/plans-and-pricing/) を参照してください。

## サブスクリプションを有効化する

サブスクリプションを有効化すると、ワークスペースで契約したプランと、そのプランに含まれる製品が利用可能になります。次のいずれかの方法を使用します。

### 方法 A: ウェルカムガイド

サインアップ後、MoEngage にウェルカムプロンプトが表示されます。

1. Subscription Code を入力します。
2. **Submit** をクリックします。

![Subscription Code フィールドと Submit ボタンがあるウェルカムプロンプト](/images/moengage_1db7e6.png)

### 方法 B: セットアップガイド

1. 右上隅にある **Need help** ドロップダウンをクリックし、**Setup Guide** をクリックします。
2. Subscription Code を入力し、**Submit** をクリックします。

![Subscription Code フィールドと Submit ボタンがあるセットアップガイド](/images/moengage_f54fae.png)

## 現在のプランの詳細を表示する

プランの詳細を確認して、チームが利用できる機能を確認します。

1. **Settings** > **Billing** に移動し、**Subscription** タブを選択します。
2. **Compare plans** をクリックして MoEngage が提供するプランを比較するか、特定のプランの **View details** をクリックしてその機能の一覧を確認します。

![Compare plans と View details のオプションを含む、現在のプランを表示した Subscription タブ](/images/viewcurrentplan.png)

## 契約製品を表示する

**Subscribed products** セクションには、有効な契約に含まれる製品とアドオンが一覧表示されます。このセクションで、チームが使用できる MoEngage 製品と、各サブスクリプション期間の終了日を確認できます。

契約製品を表示するには:

1. **Settings** > **Billing** をクリックし、**Subscription** タブを選択します。
2. **Search by product name** フィールドを使用して、特定の製品を検索します。

テーブルには、契約製品ごとに次の詳細が表示されます。

| フィールド | 説明 |
| --- | --- |
| Name | 契約に含まれる製品またはアドオンの名前です。 |
| Start date | 製品のサブスクリプション期間の開始日です。 |
| End date | 製品のサブスクリプション期間の終了日です。 |

<Info>
  この一覧には、有効な契約に含まれる製品が表示されます。製品を追加する場合や契約条件を確認する場合は、カスタマーサクセスマネージャーにお問い合わせください。
</Info>

![検索フィールド、ダウンロードアイコン、Name・Start date・End date 列がある Subscribed products テーブル](/images/subscribedproducts.png)

### 契約製品をダウンロードする

**Download** アイコンをクリックすると、社内レポートや契約の確認用に契約製品の一覧をエクスポートできます。ダウンロードしたファイルには次の列が含まれます。

| 列 | 説明 |
| --- | --- |
| Date | エクスポートが生成された日付です。 |
| Workspace Name | エクスポートの生成元のワークスペースです。 |
| Account Name | ワークスペースに関連付けられた請求アカウントです。 |
| Product | 契約に含まれる製品またはアドオンの名前です。 |
| Subscription Start Date | 製品のサブスクリプション期間の開始日です。 |
| Subscription End Date | 製品のサブスクリプション期間の終了日です。 |

### アクセス権限

契約製品の表示とダウンロードには、Usage ページと同じ権限が必要です。詳細については、[アクセス権限](/ja/user-guide/settings/account/billing/usage-details#access-permissions)を参照してください。

### よくある質問

  <Accordion title="Subscribed products の一覧に製品が表示されないのはなぜですか?">
    この一覧には、契約に含まれる製品が表示されます。製品を追加する場合や契約条件を確認する場合は、カスタマーサクセスマネージャーにお問い合わせください。

    Subscribed products の一覧には、有効な契約に含まれる製品とアドオンが、それぞれのサブスクリプション期間とともに表示されます。請求指標に対する使用量の内訳については、[使用状況の詳細](/ja/user-guide/settings/account/billing/usage-details)を参照してください。
  </Accordion>

  <Accordion title="製品のサブスクリプション終了日を過ぎるとどうなりますか?">
    アクセスを中断せずに維持するには、サブスクリプション終了日より前にカスタマーサクセスマネージャーに連絡し、更新や契約の変更についてご相談ください。
  </Accordion>
</AccordionGroup>

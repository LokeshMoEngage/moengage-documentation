この機能を使用すると、MoEngage のワークスペースにメンバーを招待し、各メンバーのワークスペースへのアクセスレベルを定義できます。

# メンバーの表示

メンバーを表示するには、次の手順を実行します。

1. MoEngage ダッシュボードの左側のナビゲーションメニューで、**Settings** \> **Account** \>**Team management** をクリックします。
2. Team management ページでは、デフォルトで **Members** タブが表示されます。
   ![](/images/moengage_6b6145.png)

Team management ページでは、データが表形式で表示され、各列に各メンバーに関する詳細が含まれています。

| 列 | 説明 |
| --- | --- |
| Member(s) | メンバーの名前とメール ID を示します。 |
| Status | Joined、Pending、Access revoked などのメンバーのステータスを示します。 <ul><li>**Pending** ステータスは、メンバーが招待を受け取ったものの、ワークスペースに参加していないことを意味します</li><li>**Joined** ステータスは、メンバーが招待を受け取り、ワークスペースに参加したことを意味します</li><li>**Access revoked** ステータスは、メンバーのワークスペースへのアクセスが取り消されたことを意味します</li></ul> |
| Role | Admin、Marketer、Analyst などのメンバーのロールを示します。 |
| Action | 管理者がアクセスの付与、アクセスの取り消し、メンバーのロールの編集などのアクションを実行できます。 |

# メンバーの招待

<Info>
  - **Team Members** コンポーネントで **Create & Manage** 権限レベルを持つメンバーは、他のメンバーをワークスペースに招待できます。
  - 1 つのワークスペースに追加できるユーザーは最大 100 人です。
  - メンバーがすでにワークスペースに所属している場合、そのロールは変更できません。
  - 既存のメンバーに影響を与えることなく、メンバーにロールを一括で割り当てることができます。
</Info>

メンバーをワークスペースに招待するには、次の手順を実行します。

1. **Members** タブで、右上隅にある \+ **Invite Member** をクリックします。
   ![](/images/moengage_f23481.png)
   Invite members ポップアップウィンドウが表示されます。
   ![Screenshot 2025-04-20 at 7.23.24 AM.png](/images/moengage_f6b186.png)
2. **Email addresses** ボックスに、招待するメンバーのメールアドレスを入力します。
   <Info>
     複数のメールアドレスをカンマで区切って追加し、Enter キーを押すことができます。
   </Info>
3. **Next** をクリックします。Invite members ポップアップウィンドウが更新されます。
4. **Assign Role and teams** で、次の詳細を入力します。
   | フィールド | 説明 |
   | --- | --- |
   | Member(s) | 追加したメールアドレスに基づいて入力されたメンバーの名前を編集します。 |
   | Role | 個々のメンバーのロールを選択します。 |
   | Edit role | すべてのメンバーのロールを変更します。 |
   ![](/images/moengage_923e8f.png)
5. **Invite** をクリックします。

# メンバーのフィルタリング

メンバーは 2 つの方法でフィルタリングできます。

### メンバーの検索

1. MoEngage ダッシュボードの左側のナビゲーションメニューで、**Settings** \> **Account** \>**Team management** をクリックします。**Team management** ページが表示されます。
2. **Search members(s)** ボックスに、メンバーの名前またはメール ID を入力します。 <img src="/images/moengage_aeebe3.png" />

### メンバーのフィルタリング

1. **Filter members** アイコンをクリックします。
2. Filter ダイアログボックスで、次の詳細を入力します。
   | フィールド | 説明 |
   | --- | --- |
   | Role | メンバーのロールを選択します。 |
   | Status | Joined や Pending などのメンバーのステータスを選択します。 |
   ![](/images/moengage_6d49bf.png)
3. **Apply** をクリックします。

## メンバーのロールの編集

<Info>
  **Edit role** オプションは、ステータスが **Pending** または **Joined** のメンバーに対して表示されます。
</Info>

メンバーのロールを編集するには、次の手順を実行します。

1. **Members** タブで、**Action** 列の下にある、編集するメンバーの横の省略記号アイコンをクリックします。
   ![](/images/moengage_d1872a.png)
2. **Edit role** をクリックします。 <img src="/images/moengage_2f879e.png" /> **Edit role(s)** ポップアップウィンドウが表示されます。
3. **Select Role** リストで、目的のロールを選択します。
4. **Done** をクリックします。
   ![](/images/moengage_e23666.png)

これで、メンバーのロールが正常に割り当てられました。

<Info>
  ロールの変更後、メンバーはダッシュボードから自動的にログアウトされます。
</Info>

## メンバーのアクセスの取り消し

<Info>
  - **Revoke access** オプションは、ステータスが **Pending** または **Joined** のメンバーに対して表示されます。
  - ユーザーのアクセスが取り消されても、そのユーザーが作成したキャンペーン、レポート、セグメントなどのデータはシステムから削除されません。
</Info>

メンバーのワークスペースへのアクセスを取り消すには、次の手順を実行します。

1. **Members** タブで、**Action** 列の下にある、アクセスを取り消すメンバーの横の省略記号アイコンをクリックします。 <img src="/images/moengage_d1872a.png" />
2. **Revoke access** をクリックします。 <img src="/images/moengage_d9c629.png" /> **Revoke access** ポップアップウィンドウが表示され、メンバーのアクセスを取り消すかどうかの確認を求められます。
3. **Revoke** をクリックします。
   ![](/images/moengage_f18a46.png)

メンバーのアクセスが正常に取り消されました。

## メンバーへのアクセスの付与

<Info>
  **Grant access** は、ステータスが **Access revoked** のメンバーに対して表示されます。
</Info>

メンバーにワークスペースへのアクセスを付与するには、次の手順を実行します。

1. MoEngage ダッシュボードの左側のナビゲーションメニューで、**Settings** \> **Account** \> **Team Management** \> **Members** をクリックします。
2. **Members** タブで、**Action** 列の下にある、アクセスを付与するメンバーの横の省略記号アイコンをクリックします。
   ![](/images/moengage_d1872a.png)
3. **Grant access** をクリックします。
   ![](/images/moengage_ed7571.png)

メンバーのアクセスが正常に付与されました。

## メンバーへの招待の再送信

<Info>
  **Resend invite** は、ステータスが **Pending** のメンバーに対して表示されます。
</Info>

メンバーに招待を再送信するには、次の手順を実行します。

1. **Members** タブで、**Action** 列の下にある、再招待するメンバーの横の省略記号アイコンをクリックします。
   ![](/images/moengage_d1872a.png)
2. **Resend invite** をクリックします。 <img src="/images/moengage_355bab.png" />

招待がメンバーに正常に送信されました。

## メンバーの削除

<Info>
  - **Delete user** オプションは、ステータスが **Pending**、**Joined**、または **Access Revoked** のメンバーに対して表示されます。メンバーを削除すると、そのプロファイルがワークスペースから完全に削除されます。そのユーザーが作成したキャンペーン、レポート、セグメントなどのデータはシステムに残ります。
  - メンバーを削除できるのは、そのメンバーのロールの権限が自分のロール以下の場合のみです。たとえば、Admin ロールを持つ別のユーザーを削除できるのは、Admin ロールを持つユーザーのみです。
</Info>

メンバーを削除するには、次の手順を実行します。

1. **Members** タブで、**Action** 列の下にある、削除するメンバーの横の省略記号アイコンをクリックします。
   ![](/images/moengage_d1872a.png)
2. **Delete user** をクリックします。 <img src="/images/moengage_83b0e8.png" />\
   **Delete User** ポップアップウィンドウが表示され、メンバーを削除するかどうかの確認を求められます。
3. **Delete** をクリックします。
   ![](/images/moengage_605998.png)
   メンバーが正常に削除されました。

## メンバーのロールの編集

メンバーを一括編集するには、次の手順を実行します。

1. MoEngage ダッシュボードの左側のナビゲーションメニューで、**Settings** \> **Account** \> **Team Management** \> **Members** をクリックします。
2. **Team management** ページでは、デフォルトで **Members** タブが表示されます。
   ![](/images/moengage_d1872a.png)
3. 一括編集する 1 人以上のメンバーの横にあるチェックボックスを選択します。
4. 選択したメンバーのリストを表示するには、**Show Selected** トグルをオンにします。
   ![](/images/moengage_e6832a.png)
5. 省略記号アイコンをクリックし、**Edit** をクリックします。
   ![](/images/moengage_95277c.png)
   Edit Members ポップアップウィンドウが表示されます。
6. **Edit Role** をクリックし、メンバーのロールを変更します。すべてのメンバーに同じロールが割り当てられます。
7. **Done** をクリックします。
   ![](/images/moengage_4a8980.png)
   メンバーが正常に更新されました。

# FAQ

**元の Admin アカウントが無効化された場合、Admin アクセスを回復して新しいユーザーに割り当てるにはどうすればよいですか？**\
組織で唯一の管理者アカウントが無効化され、そのアカウントにアクセスできなくなった場合でも、次の手順に従って管理者アクセスを回復し、新しい管理者権限を割り当てることができます。

- 組織の IT 管理者またはドメイン所有者に連絡して、ワークスペースの管理者のメールアカウントを一時的に再有効化し、アクセスを付与してもらいます。
- アカウントが再有効化されたら、MoEngage ログインページの Forgot Password オプションを使用して、その管理者ユーザーアカウントのパスワードをリセットします。
- パスワードをリセットした後、アカウントにログインし、ワークスペース内の既存ユーザーに管理者アクセスを割り当てるか、Admin アクセスを持つ新しいユーザーを招待します。この新しい管理者は、そのプロジェクトの MoEngage ダッシュボードにアクセスできるようになります。
- _（オプション）_ 以前の管理者のワークスペースへのアクセスを取り消します。

今後同様の問題を防ぐため、MoEngage では少なくとも 2 人のユーザーに管理者ロールを割り当てることを推奨しています。これにより、一方の管理者が退職したり不在になったりした場合でも、もう一方の管理者がワークスペースを管理し、必要な管理タスクを実行できます。

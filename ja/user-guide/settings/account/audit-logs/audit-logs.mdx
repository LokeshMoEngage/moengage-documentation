---

監査ログは、ユーザーのログインや設定など、MoEngage ワークスペース内で発生するすべてのアクションと変更の記録を一元的に保存する場所です。どのような変更が、いつ、誰によって行われたかを把握するのに役立ちます。

監査ログの例を次に示します。

- ユーザーがアカウントにログインする
- ユーザーがアカウントを編集する
- ユーザーがコンテンツブロックを作成する
- ユーザーがアラートを編集する

<Info>
  - 監査ログを表示およびダウンロードできるのは管理者のみです。
  - 監査ログは、ワークスペースで監査ログ機能を有効にした後のイベントを追跡します。
  - **Teams** は、アカウントでこの機能が有効になっている場合にのみ表示されます。（特定のアクションが実行されたときにユーザーが所属しているチームを示します。）
  - 監査ログを変更または更新できるユーザーはいません。
</Info>

# 監査ログを表示する

監査ログを表示するには、次の手順を実行します。

1. MoEngage UI の左側のナビゲーションメニューで、**Settings**\> **Account** \> **Audit logs** に移動します。Audit logs ページが表示されます。 <img src="/images/moengage_b58d43.png" />

Audit logs ページでは、ユーザーまたはチームが実行した各アクティビティに関する詳細を含む列とともに、データが表形式で表示されます。

| 列 | 説明 |
| -------- | -------- |
| Time | 特定のアクションが実行された日、月、年を記録したタイムスタンプを示します。 |
| Teams | 特定のアクションが実行されたときにユーザーが所属しているチームを示します。 |
| Entity | 特定のアクションが実行されたときのイベントの種類を示します。 |
| Activity | 特定のアクションが実行されたときの概要を示します。 |
| Action | 実行されたタスクの種類を示します。例: CREATE、UPDATE、DELETE、EXPORT、INVITE、Campaign duplicated、Campaign resumed、Campaign archived、Campaign unarchived、Campaign paused。 |
| Actor | 特定のアクションを実行したユーザーのメール ID を示します。 |
| IP | ユーザーが特定のアクションを実行するために使用したシステムの IP アドレスを示します。 |

# 監査ログをフィルタリングする

MoEngage では、選択した条件に基づいて、ワークスペース内の監査ログを検索および並べ替えることができます。監査ログは次の 2 つの方法でフィルタリングできます。

### ログを検索する

1. MoEngage UI の左側のナビゲーションメニューで、**Settings** \> **Account** \> **Audit logs** に移動します。Audit logs ページが表示されます。
2. **Search logs by** ボックスに、Team、Entity、Activity、Action、Actor、IP などのキーワードを入力します。
3. **Enter** キーを押します。

   ![](/images/moengage_67fc03.png)

### ログをフィルタリングする

1.  <Icon icon="bars-filter" /> フィルターアイコンをクリックします。
2. Filter ダイアログボックスで、次の詳細を入力します。

   | フィールド | 説明 |
   | ------------------- | ------------------- |
   | **Team(s)** | 特定のアクションが実行されたときにユーザーが所属しているチームを選択します。 |
   | **Action** | 実行されたタスクの種類を選択します。 |
   | **Actor** | 特定のアクションを実行したユーザーのメール ID を選択します。 |
   | **Date time Range** | 特定のアクションが実行された日付範囲を選択します。 |

   ![](/images/moengage_ada366.png)
3. **Apply** をクリックします。

選択した条件に基づいて監査ログが表示されます。

# 監査ログをダウンロードする

MoEngage では、監査ログレポートを CSV ファイルでエクスポートおよびダウンロードできます。ダウンロードするには、次の手順を実行します。

1. MoEngage ダッシュボードの左側のナビゲーションメニューで、**Settings** \> **Account** \> **Audit logs** に移動します。Audit logs ページが表示されます。 <img src="/images/moengage_b58d43.png" />
2. 必要に応じて [監査ログをフィルタリング](#filter-audit-logs) します。
3. 右上隅にある **Export audit logs** をクリックします。 <img src="/images/moengage_4ccc83.png" />\
   監査ログレポートがメール ID に正常に送信されます。

<Info>
  - 監査ログレポートは、次のファイル命名規則を使用して CSV ファイルでエクスポートおよびダウンロードできます: WorkspaceName_ExportID_YYYY-MM-DD。
  - 監査ログは過去 90 日間分のみ利用できます。
</Info>

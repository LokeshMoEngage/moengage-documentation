# 概要

Urchin Tracking Module（UTM）パラメーターは、URL の末尾に追加されるタグまたはシンプルなスニペットコードです。これらのパラメーターは要件に応じてカスタマイズでき、分析ソフトウェアでさまざまなトラフィックソースからのユーザーエンゲージメントを正確にトラッキングできます。

オーディエンスがこれらのパラメーターが付加された URL にアクセスすると、分析ソフトウェアは、クリックの発生元、どのキャンペーンがウェブサイトへのクリックを誘導したか、訪問者がどのようにウェブサイトにアクセスしたか、訪問者がキャンペーンに関連するコンテンツを操作したかどうかなどの情報をトラッキングできます。

# 機能サポートマトリックス

次の表は、MoEngage 内のさまざまなチャネルや機能で UTM パラメーターがサポートされているかどうかを示しています。

| チャネル / モジュール | サポート |
| --- | --- |
| **Email** | ✅ |
| **Push** | ✅ |
| **SMS** | ✅ |
| **WhatsApp** | ✅ |
| **In-App** | ✅ |
| **OSM** | ✅ |
| **Inform** | ❌ |
| **Flows** | ✅ |
| **Connectors** | NA |
| **RCS** | ❌ |
| **Cards** | ✅ |

UTM パラメーターはキャンペーンごとに個別に設定できます。キャンペーンレベルで UTM パラメーターに加えた変更は、アカウントレベルで設定された一般的な UTM パラメーターよりも優先されます。これらの変更は作成中または編集中の特定のキャンペーンにのみ適用され、一般的な UTM パラメーターには影響しません。詳細については、[アカウントレベルでの一般的な UTM パラメーターの設定](/ja/user-guide/settings/advanced-settings/configure-general-utm-parameters-at-account-level)を参照してください。

<Info>
  - MoEngage は、すべてのキャンペーンで使用されるリンクの末尾に、一般的な UTM パラメーターを自動的に挿入します。
  - 現在のキャンペーンの URL の一部として UTM パラメーターを手動で渡した場合、MoEngage は一般的な UTM パラメーターをスキップします。
  - **UTM parameters** トグルのオン/オフを切り替えられるのは、キャンペーンとフローの作成を許可されたロール（Marketer、Manager、および CAF がオフの場合の Admin）のみです。
</Info>

# キャンペーンの UTM パラメーターの設定

次の例では、Email キャンペーンに UTM パラメーターを追加する手順を説明します。

1. **Settings** \> **App** \> **UTM tracking** で、一般的な UTM パラメーターがオンになっていることを確認します。 <img src="/images/moengage_34bf4f.png" alt="10 - general to email.png" />
2. メールテンプレートエディターで、**UTM parameters** セクションに移動します。 <img src="/images/moengage_19bf8e.png" alt="7 - email.png" />
3. アコーディオンをクリックしてパラメーターを展開します。
   <Info>
     一般設定で UTM パラメーターが有効になっている場合、現在のキャンペーンの **UTM parameters** トグルはオンになっています。デフォルトでは、一般設定で設定された UTM パラメーターがキャンペーンに引き継がれます。
   </Info>
   ![8 - email 2.png](/images/moengage_6fa7c6.png)
4. UTM パラメーターの値を編集します。すべての値フィールドで、静的な値を入力するか、動的な値を選択できます。'@' を入力すると、検索可能な値のドロップダウンリストが表示されます。値フィールドを空にすることはできません。
5. 個々のパラメーターを有効または無効にします。_utm\_source_ パラメーターと _utm\_medium_ パラメーターは無効にできません。 <img src="/images/moengage_248449.png" alt="12 - email disabled.png" />
6. **\+ Create custom parameter** をクリックして、カスタム UTM パラメーターをキーと値のペアとして追加します。
7. 不要になったカスタムパラメーターの削除アイコンをクリックします。一般設定から引き継がれたカスタム UTM パラメーターも削除できます。 <img src="/images/moengage_c8dbef.png" alt="11 - email custom.png" />
8. 現在のキャンペーンで UTM パラメーターの使用を無効にするには、**UTM parameters** トグルをオフにします。この場合、MoEngage は現在のキャンペーンで使用されるリンクに UTM パラメーターを挿入しません。 <img src="/images/moengage_0910bf.png" alt="12 - disabled at email.png" />

# Flows 内のキャンペーンの UTM パラメーターの設定

スタンドアロンのキャンペーンに加えて、MoEngage Flow の一部であるキャンペーンにも特定の UTM パラメーターを設定できます。Flow 内で作成されたキャンペーンには、アカウントレベルでフロー用に設定された一般的な UTM パラメーターがデフォルトで入力されます。これらの値を上書きしたり、カスタムパラメーターを追加したりできます。

次の例では、Flows 内の Email に UTM パラメーターを追加する手順を説明します。

1. **Settings** \> **App** \> **UTM tracking** で、一般的な UTM パラメーターがオンになっていることを確認します。例： <img src="/images/moengage_34bf4f.png" alt="10 - general to email.png" />
2. フローのキャンバスで **\+** をクリックします。
3. **Add Stage** ページで、**Actions** \>  **Messaging** \> **Email** を選択します。 <img src="/images/moengage_718802.png" alt="Addstageflows.gif" />
4. **Email** にカーソルを合わせ、**Edit** アイコンをクリックします。
5. メールテンプレートエディターで、**UTM parameters** セクションに移動します。 <img src="/images/moengage_e06d27.png" alt="14 - flow.png" />
6. これらのパラメーターを編集するプロセスは、スタンドアロンのキャンペーンの場合と同じ方法になります。次の操作を行えます。
   - 任意のパラメーターの値を編集する。
   - 個々のパラメーターを有効または無効にする。
   - **\+ Create custom parameter** を使用して新しいカスタムパラメーターを追加する。
   - カスタムパラメーターを削除する。

これらの各操作の詳細なガイドについては、上記の[キャンペーンの UTM パラメーターの設定](/ja/user-guide/settings/advanced-settings/add-utm-parameters-to-campaigns#feature-support-matrix)セクションの手順 4～7 を参照してください。

<Info>
  - メールに追加したリンクは、UTM パラメーターでラップされます。ユーザーがリンクをクリックすると、URL 内に UTM パラメーターとその値が表示されます。
  - SMS と WhatsApp の場合、UTM パラメーターは短縮リンクにのみ追加できます。
  - SMS と WhatsApp で短縮リンクを使用した場合、UTM パラメーターはリンクをクリックして遷移先のページに到達した時点で表示されます。
  - 動的な値は実行時に取得されます。キャンペーンで動的パラメーターが利用できない場合、その動的な値を使用する UTM パラメーターはリンクに付加されません。
  - Content API から取得された URL は、実行時に UTM パラメーター付きでリンクに追加されます。
  - リンクの一部として UTM パラメーターを送信する際にスペースや特殊文字を使用した場合は、URL エンコードがサポートされます。
</Info>

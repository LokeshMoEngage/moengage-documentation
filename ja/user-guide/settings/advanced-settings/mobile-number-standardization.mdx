# 概要

マーケターは、MoEngageに携帯電話番号を送信するための標準形式を設定し、+や国番号の追加などの必要な詳細を選択できます。これにより、MoEngageはWhatsAppおよびSMSコネクターに携帯電話番号をE.164形式(+国番号携帯電話番号)で送信できます。

MoEngageに携帯電話番号を保存する際は、次のいずれかの形式を使用することをお勧めします。以下は、米国/カナダの顧客に送信する携帯電話番号の例です。

- [E.164形式](/ja/user-guide/settings/advanced-settings/e164-phone-number-format)、つまり+国番号携帯電話番号。例: +1999999999
- +(プラス)記号なしの番号。例: 19999999999
- 国番号と+記号なしの携帯電話番号。例: 999999999

<Info>
現在、MoEngageはSMSおよびWhatsAppコネクターに携帯電話番号を送信する際、すべての携帯電話番号にデフォルトの国番号として+91を追加します。
</Info>

# 携帯電話番号形式の設定

国番号を設定するには、次の手順を実行します。

1. **Settings** \> **Advanced settings** \> **Mobile number management** に移動します。**Mobile number management** ページが表示されます。
2. 携帯電話番号にプラス(+)記号がない場合にプラス(+)記号を追加するには、**Add '+' sign to mobile number if missing** トグルをオンにします。
   <Info>
   **Preview as per above set standard** で、MoEngageが想定する携帯電話番号の形式を確認できます。プラスなしの国番号と携帯電話番号で構成されます。

   <img alt="11.png" src="/images/moengage_2623c9.png" />
   </Info>
3. 携帯電話番号に国番号がない場合に国番号を追加するには、**Include a default country code if missing** トグルをオンにします。
4. **Include a default country code if missing** トグルをオンにすると、**Select the country code** ドロップダウンが表示されます。ドロップダウンリストから国番号を選択します。
   <Info>
   **Preview as per above set standard** で、MoEngageが想定する携帯電話番号の形式を確認できます。プラスと国番号のない携帯電話番号のみで構成されます。

   <img alt="12.png" src="/images/moengage_cf0386.png" />
   </Info>
5. **Save** をクリックします。Confirm Changesポップアップが表示されます。
6. **Confirm** をクリックして変更を保存します。

<Info>
この機能はTwilioコネクターではサポートされていません。
</Info>

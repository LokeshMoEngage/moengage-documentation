---

キャンペーンメッセージをローカライズして、さまざまな言語、文化、地域のユーザーとエンゲージできます。ローカライズにより、特定の言語的・文化的な期待に合わせてコミュニケーションを調整でき、エンゲージメントの向上につながります。ロケールを通じて関連性の高いコンテンツを配信することで、ブランドはコンバージョン率を大幅に向上させ、顧客ロイヤルティを高め、最終的に顧客生涯価値(LTV)を高めることができます。詳細については、[キャンペーンメッセージのローカライズ](/ja/user-guide/campaigns-and-channels/getting-started/campaign-content/localize-campaign-messages)を参照してください。

## 新しいロケールの追加

新しいロケールを追加するには、次の手順を実行します。

<Info>
ワークスペースで作成できるロケールの数に制限はありません。
</Info>

1. MoEngageダッシュボードの左側のナビゲーションで、**Settings** \> **Advanced settings** \> **Locales** をクリックします。Localesページが表示されます。
2. 右上隅にある **+ Create locale** をクリックします。  
    <img alt="RevampedUI_Locale.png" src="/images/moengage_af2206.png" />
3. Add new localeダイアログボックスで、次の詳細を入力します。

   | フィールド | 説明 |
   | --- | --- |
   | Locale name | ロケールの名前を入力します。 |
   | User property | ロケールのプロパティを定義します。たとえば、*Last Known Country* が *US* である *English* をロケールとして追加できます。 |
   | + Filter | ロケールを定義するには、単一の属性または属性の組み合わせ(ANDまたはOR)を使用できます。 |
   | Exclude Users | このチェックボックスを選択し、キャンペーンから除外するユーザーのフィルター条件を定義します。 |

   <img alt="NewLocale.png" src="/images/moengage_4e09de.png" />
4. **Add** をクリックします。ロケールが作成され、Localesページに表示されます。

## ロケールの表示

1. MoEngageダッシュボードの左側のナビゲーションで、**Settings** \> **Advanced settings** \> **Locales** をクリックします。Localesページでは、データが表形式で表示され、各列に各ロケールに関する詳細が含まれています。

   | 列 | 説明 |
   | --- | --- |
   | Name | ロケールの名前 |
   | Definition | ロケールの定義 |
   | Created on | ロケールが作成された日時 |
   | Locale number | MoEngageがロケールに割り当てた一意の番号。 |
   | Campaigns associated | ロケールが関連付けられているキャンペーンの数。 |

   <img alt="スクリーンショット 2025-04-22 4.22.23 PM.png" src="/images/moengage_2271ea.png" />
2. 以下のように、ロケールを名前で検索できます。

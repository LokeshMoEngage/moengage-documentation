# 概要

グローバルコントロールグループとは、マーケティングキャンペーンを一切受信しないユーザーのリストです。これはユーザーベース全体から戦略的に選択されたサブセットであり、利用可能なすべてのチャネルでマーケティングキャンペーンを受信しないよう意図的に除外されています。詳細については、[コントロールグループ](/ja/user-guide/campaigns-and-channels/getting-started/introduction/control-groups)を参照してください。

グローバルコントロールグループはアカウントレベルで設定され、ユーザーベース全体の一部を対象とします。ワークスペースごとに作成できるグローバルコントロールグループは1つだけです。このグループは、すべてのチャネルとキャンペーンタイプにわたって、すべてのマーケティングキャンペーンから一貫して除外されます。その主な目的は、マーケティング活動全体の増分効果を測定するための、アカウント全体を網羅したベンチマークを提供することです。

多数のマーケティングキャンペーンを同時に実行すると、特定の施策に起因する増分効果を正確に定量化することが難しくなります。エンドユーザーが(キャンペーンレベルのコントロールグループによって)特定のキャンペーンのコミュニケーションを受信しないよう意図的に除外されていても、同時に実行されている他のキャンペーンのコミュニケーションに接触して影響を受け、コンバージョンに至る可能性があります。そのため、マーケティング活動の真の全体的な効果を正確に測定するには、グローバルレベルのコントロールグループが必要です。このグループは、設計上、キャンペーンのコミュニケーションにまったく接触しないため、比較のための信頼できるベースラインとなり、実際のアップリフトを正確に判断できます。

<Tip>
  **前提条件**

  グローバルコントロールグループを管理するには、**Channel Configuration** コンポーネントに対する **Setup & manage** 権限を持つAdminロールが必要です。詳細については、[アクセスロール](/ja/user-guide/settings/account/team-management/access-roles)を参照してください。
</Tip>

# グローバルコントロールグループの有効化

1. MoEngageダッシュボードの左側のナビゲーションメニューで、**Settings** \> **Advanced settings** \> **Control groups** をクリックします。Control groupsページが表示されます。
2. **Global control group** セクションで、**Status** トグルをオンにしてグローバルコントロールグループを有効にします。<img src="/images/moengage_e5ac9c.png" />\
   現在のワークスペースでグローバルコントロールグループが有効になります。右下に確認メッセージが表示されます。
   ![スクリーンショット 2025-05-01 11.13.05 PM.png](/images/moengage_d5b691.png)
3. **Edit** をクリックして、グローバルコントロールグループに詳細を追加します。次のページが表示され、コントロールグループを定義できます。
   ![スクリーンショット 2025-05-01 8.57.41 PM.png](/images/moengage_e20a59.png)
4. グローバルコントロールグループは、次の2つの方法で作成できます。
   - **ランダム割り当て:** この方法では、全ユーザーのうち一定の割合をグローバルコントロールグループにランダムに割り当てます。
     1. **Random allocation** オプションをクリックします。
     2. 下のテキストボックスに、グローバルコントロールグループに割り当てる全ユーザーの割合を入力します。グローバルコントロールグループには、全ユーザーの最大10%を割り当てることができます。
        ![スクリーンショット 2025-05-01 9.05.47 PM.png](/images/moengage_39e6e5.png)
        <Info>
          - ランダム割り当てでグローバルコントロールグループを作成すると、その時点でワークスペースに存在するすべてのユーザーを対象に作成されます。たとえば、コントロールグループを全ユーザーの10%と定義した場合、10人に1人のユーザーがこのコントロールグループに含まれます。
          - グローバルコントロールグループへのユーザーの割り当ては完全にランダムです。
          - コントロールグループの作成後にワークスペースに追加された新規ユーザーも、ランダム割り当てで定義された全ユーザーの割合に従ってグループに含まれます。つまり、新規ユーザーの10人に1人がコントロールグループに含まれます。
        </Info>
   - **ユーザーリストのアップロード:** この方法では、ユーザーIDのリストを含むCSVファイルをアップロードしてグローバルコントロールグループを作成できます。リスト内のすべてのユーザーが自動的にコントロールグループに追加されます。
     1. **Upload users list** オプションをクリックします。
     2. **Upload file or drag and drop here** をクリックして、CSVファイルをアップロードします。
        ![スクリーンショット 2025-05-01 9.08.22 PM.png](/images/moengage_920d65.png)
        **注:** アップロードできるのはCSVファイルのみです。アップロードできるファイルの最大サイズは50 MBです。
5. 既存のすべてのキャンペーンにグローバルコントロールグループを適用する場合は、**Apply global control group in all existing campaigns** チェックボックスを選択します。これは、既存のスケジュール済みキャンペーンや今後の定期キャンペーンに影響します。
   ![スクリーンショット 2025-05-01 9.38.30 PM.png](/images/moengage_1935f4.png)
6. キャンペーンの作成時に、グローバルコントロールグループ内のユーザーにキャンペーンを送信するかどうかをマーケターが決定できるようにする場合は、**Allow marketers to send campaigns to these users** チェックボックスを選択します。これは、トランザクションコミュニケーションや、必須のアプリアップデートなどの重要なメッセージを送信する場合に特に便利です。\
   デフォルトでは、グローバルコントロールグループはすべての新規キャンペーンに適用されます。このチェックボックスを選択すると、マーケターはキャンペーンの作成時にコントロールグループを使用するかどうかを決定できます。
   ![スクリーンショット 2025-05-01 9.39.01 PM.png](/images/moengage_d91b87.png)
7. **Save changes** をクリックします。Save changes to control groupポップアップウィンドウが表示され、確認を求められます。変更を保存すると、既存のすべてのキャンペーンに適用されます。
8. **Confirm** をクリックします。
   <Info>
     - グローバルコントロールグループの作成が完了してから、システムがグローバルコントロールグループを有効にするまでに最大24時間かかる場合があります。コントロールグループが使用可能になり次第、通知されます。
     - ユーザーがコントロールグループに追加されると、MoEngageは _User added to control group_ という名前のイベントを発生させます。このイベントには、値が _Global_ の属性 **Control Group** **type** が含まれます。
     - キャンペーンの対象となるユーザーベースが非常に小さい場合、対象ユーザーベースの中にグローバルコントロールグループに属するユーザーが1人もいないことがあります。その場合、MoEngageはそのキャンペーンのコントロールグループの統計を[Uplift](/ja/user-guide/campaigns-and-channels/getting-started/introduction/control-groups)に表示しません。
   </Info>
9. **Download users** をクリックすると、グローバルコントロールグループ内のすべてのユーザーをダウンロードできます。MoEngageはレポートを生成し、お客様のメールアドレスに送信します。
   ![スクリーンショット 2025-05-01 9.26.27 PM.png](/images/moengage_f0b655.png)
10. コントロールグループを削除するには、次の手順を実行します。
    1. **Delete** をクリックします。Delete control groupポップアップウィンドウが表示され、確認を求められます。コントロールグループを削除すると、MoEngageはそのすべてのユーザーを解放します。以降、それらのユーザーはキャンペーンメッセージを受信するようになります。
       ![スクリーンショット 2025-05-01 9.28.46 PM.png](/images/moengage_09f3b5.png)
    2. 確認のため、**Delete** をクリックします。

# APIによるユーザーの追加または削除

**Uploading user list** 方式でグローバルコントロールグループを設定した後は、MoEngage APIを使用してプログラムでユーザーベースを管理できます。[Global Control Group API](https://www.moengage.com/docs/api/update-campaigns/update-global-control-group)を使用すると、除外リストに新しいユーザーを追加したり、既存のユーザーを削除してキャンペーンを再び受信できるようにしたりできます。

<Info>
  APIによる管理は、グローバルコントロールグループが **Uploading user list** 方式で作成された場合にのみ使用できます。グループが **Random Allocation** で設定されている場合、APIを使用してユーザーを追加または削除することはできません。
</Info>

APIでユーザーを管理するには、次の要件を満たしていることを確認してください。

- **ファイル形式:** 入力はCSVファイルである必要があります。列名 `uid` を含む1行のヘッダー行があり、その後の行にユーザーIDが含まれている必要があります。
- **ファイルのホスティング:** CSVファイルは、公開アクセス可能なURLでホストされている必要があります。現在、**Amazon S3** の公開URLのみがサポートされています。
- **ファイルサイズ:** CSVファイルは150 MB未満である必要があります。
- **処理:** APIリクエストは順番に処理されます。別の追加または削除リクエストを開始する前に、1つのファイル処理リクエストが完了するまで待つ必要があります。

**通知とステータス**\
ユーザーを追加または削除するAPI呼び出しをトリガーすると、システムはファイルを非同期で処理します。処理が完了すると、APIリクエストで指定されたメールアドレス(`updated_by` フィールド)にメール通知が送信されます。このレポートには次の内容が含まれます。

- 正常に処理されたユーザー数。
- 失敗したユーザー数。
- 失敗の考えられる理由。

**キャンペーンへの影響**\
APIによる更新は、処理が正常に完了すると直ちに有効になります。

- **ユーザーの追加:** APIでユーザーがコントロールグループに追加されると、そのユーザーは既存または新規のキャンペーンの今後の実行でメッセージを受信しなくなります。
- **ユーザーの削除:** ユーザーがコントロールグループから削除されると、そのユーザーは今後のキャンペーン実行でメッセージを受信できるようになります。

<Info>
  技術的な詳細、エンドポイントURL、JSONペイロードの例については、[Global Control Group APIドキュメント](https://www.moengage.com/docs/api/update-campaigns/update-global-control-group)を参照してください。
</Info>

# グローバルコントロールグループの無効化

ワークスペースでグローバルコントロールグループを有効にした後は、いつでも無効にできます。

1. MoEngageダッシュボードの左側のナビゲーションメニューで、**Settings** \> **Advanced settings** \> **Control groups** をクリックします。Control groupsページが表示されます。
2. **Global control group** セクションで、**Status** トグルをオフにしてグローバルコントロールグループを無効にします。\
   現在のワークスペースでグローバルコントロールグループが無効になります。右下に確認メッセージが表示されます。
   ![スクリーンショット 2025-05-01 11.13.12 PM.png](/images/moengage_1545b7.png)

グローバルコントロールグループを無効にすると、グループに属していたユーザーはキャンペーンを受信するようになります。これは、既存のスケジュール済みキャンペーンや今後の定期キャンペーンに影響します。

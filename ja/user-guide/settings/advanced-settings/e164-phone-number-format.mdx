# はじめに

E.164電話番号形式は、電話番号を表記するための国際標準です。この形式は、国際電気通信連合電気通信標準化部門(ITU-T)によって定義されています。E.164番号は最大15桁で、国番号を含みますが、国際電話のプレフィックスは含みません。

# E.164形式の主な構成要素

E.164形式の電話番号には、次の要素が含まれます。

- プレフィックス「+」。
- **国番号**: 国を識別する1〜3桁のコードです。たとえば、「1」は米国とカナダの国番号、「91」はインドの国番号です。国番号の完全なリストについては、[国番号](https://en.wikipedia.org/wiki/List_of_telephone_country_codes)を参照してください。
- **National Destination Code(NDC)**: 国内の特定の地域またはネットワークを識別するコードです。
- **Subscriber Number(SN)**: 加入者に割り当てられた一意の番号です。

以下は、E.164形式の電話番号の例です。

米国の番号のE.164形式の電話番号は、次のようになります: +12125551234

- 「+」はE.164形式のプレフィックスを示します。
- 「1」は米国の国番号です。
- 「212」はNDC(この場合は市外局番)です。
- 「5551234」は加入者番号です。

<Info>
- 国番号を含める場合は、国内電話番号の先頭のゼロを省略してください。
- ハイフン、スペース、括弧はE.164形式には含まれません。
</Info>

# ローカル形式からE.164への変換

国番号がわかっていれば、ローカル形式の電話番号をE.164形式の番号に簡単に変換できます。次の手順を実行します。

1. スペース、括弧、その他の句読点を削除します。
2. 番号がゼロで始まる場合は、先頭のゼロを削除します。
3. 国番号を先頭に付加します。
4. 「+」を先頭に付加します。

<Warning>
MoEngageに取り込む電話番号はE.164形式である必要があります。電話番号の形式が無効な場合、キャンペーンの到達率が低下する可能性があります。
</Warning>

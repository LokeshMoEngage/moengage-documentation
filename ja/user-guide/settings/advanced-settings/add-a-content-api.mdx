---
title: "Content API の追加"
description: "MoEngage で Content API を追加・設定し、キャンペーンで動的な外部データを使用します。ユーザー属性を使用して API パラメーターをパーソナライズできます。"
---

MoEngage キャンペーンで使用する API を設定するには、次の手順を実行します。

1. MoEngage ダッシュボード \> **Settings** \> **Advanced Settings** に移動します。
2. **Content API** をクリックします。
3. **+ Add content API** をクリックします。Add content API 画面がポップアップ表示されます。  

   <img alt="Screenshot 2024-12-23 at 3.03.21 PM.png" src="/images/moengage_6801a5.png" />
4. 次の詳細を入力します。

   | フィールド | 説明 |
   | --- | --- |
   | API name | Content API の名前をここに追加します。 |
   | Method | Content API では次のメソッドがサポートされています。 <ul><li>GET</li><li>POST</li><li>PUT</li></ul> 設定する Content API の HTTP リクエストメソッドを選択します。<br/><br/>**注**：POST オプションはリクエストに応じて有効化されます。有効にするには、CSM または MoEngage サポートチームにお問い合わせください。 |
   | Enable OAuth | Content API で OAuth 2.0 認証が必要な場合は、このトグルを有効にします。ドロップダウンメニューが表示され、事前に設定された OAuth 設定を選択できます。<br/>OAuth 設定の作成および管理方法については、[OAuth 2.0 による認可設定](/ja/user-guide/settings/advanced-settings/authorization-configuration-with-oauth-20)を参照してください。<br/><br/><Info><ul><li>ドロップダウンで選択できるのは、ステータスが "*Active*" の OAuth 設定のみです。</li><li>API で使用しているアクティブな OAuth 設定の有効期限が切れると、ステータスが "Failed" に変わります。Content API を編集するとエラーメッセージが表示されるため、新しいアクティブな OAuth 設定を選択する必要があります。</li></ul></Info><br/>**注**：OAuth オプションはリクエストに応じて有効化されます。有効にするには、CSM または MoEngage サポートチームにお問い合わせください。 |
   | URL | リクエストの送信先となる Content API の URL を追加します。 |
   | URL Parameters | リクエストで渡す URL パラメーターを追加します。複数の URL パラメーターが必要な場合は、*+KV pair* をクリックします。 |
   | Headers | リクエストに追加するヘッダーを追加します。複数のヘッダーが必要な場合は、*+KV pair* をクリックします。 |
   | Dynamic values | API が正しく設定されていることを確認するために、パラメーターのサンプル値を指定します。任意のユーザープロファイルまたはイベントを選択して、これらの値を入力できます。 |
5. [パラメーターをパーソナライズ](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization)するには、@ を入力し、ユーザー属性を使用してパーソナライズします。  
   詳細については、[派生イベントと属性](/ja/user-guide/data/event-data/derived-events-and-attributes)を参照してください。

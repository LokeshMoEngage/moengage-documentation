#### Core 11.0.0
<span style={{ background: 'rgba(0,135,103,0.1)', color: '#008767', border: '1px solid #B5F5EC', borderRadius: '4px', padding: '2px 8px', fontSize: '12px', fontWeight: '600' }}>新機能</span>

- JWT 認証のサポートを追加しました。詳細については、[JWT Authentication](/ja/developer-guide/flutter-sdk/sdk-integration/advanced/jwt-authentication) を参照してください。
- Movable Nudges を追加しました。ユーザーはアプリ内で Nudge の位置を移動できます。

<span style={{ background: 'rgba(212,56,13,0.1)', color: '#D4380D', border: '1px solid #FFCCC7', borderRadius: '4px', padding: '2px 8px', fontSize: '12px', fontWeight: '600' }}>破壊的変更</span>

- **プラットフォーム要件を更新しました。** このプラグインには Dart 3.6.0 以上および Flutter 3.44.0 以上が必要です。先にツールチェーンをアップグレードしてください。アップグレードしない場合、依存関係の解決に失敗します。
- **SDK の初期化が必須になりました。** 初期化前にアプリが他の MoEngage API を呼び出すと、ネイティブ SDK は即座に失敗するようになりました。Android では `IllegalStateException` がスローされ、iOS では `fatalError` が発生します。他の MoEngage API より前に `initialise()` を呼び出してください。
- Android
  - このプラグインは Android Gradle Plugin 9.1.1 と Kotlin 2.3.20 でビルドされています。プロジェクトを互換性のある AGP および Kotlin バージョンに更新してください。
  - Compile SDK と Target SDK が 36 に変更されました。アプリの `build.gradle` で `compileSdk` と `targetSdk` を更新してください。
  - 「Remind Later」および「Snooze」通知アクションを削除しました。これらのアクションを使用するキャンペーンでは表示されなくなり、通知がスヌーズタイマーで再投稿されることもなくなります。

<span style={{ background: 'rgba(0,135,103,0.1)', color: '#008767', border: '1px solid #B5F5EC', borderRadius: '4px', padding: '2px 8px', fontSize: '12px', fontWeight: '600' }}>改善</span>

- Android
  - MoEngage SDK BOM 4.2.0 に更新しました。
  - SDK の初期化時およびイベント処理時の ANR を削減しました。アプリ起動時やフォアグラウンドとバックグラウンドの切り替え時に、初期化ロックがメインスレッドを保持する時間が短くなりました。
- iOS
  - MoEngage-iOS-SDK を 11.0.0 に更新しました。

<span style={{ background: 'rgba(212,107,8,0.1)', color: '#D46B08', border: '1px solid #FFE58F', borderRadius: '4px', padding: '2px 8px', fontSize: '12px', fontWeight: '600' }}>修正</span>

- Android
  - アプリ起動時の通知チャネル設定が原因で発生していた ANR を修正しました。チャネル設定がメインスレッドをブロックしなくなりました。
  - プッシュ通知の画像が部分的にしかレンダリングされない問題を修正しました。画像が完全にレンダリングされるようになりました。
  - `source` がディープリンク URL に埋め込まれず、バンドルの extra として渡された場合に、プッシュのディープリンクで新しいセッションが開始されない問題を修正しました。この問題により、キャンペーンのアトリビューションが正しく行われていませんでした。
  - アプリがマニフェストで `configChanges` を宣言していない場合に、回転やその他の構成変更時に HTML Nudge が消える問題を修正しました。
  - 画面の向きの変更後に以前のキャンペーンが閉じられた場合に、`showInApp()` でキャンペーンが表示されない問題を修正しました。
  - `SurfaceView` を使用する画面で、動画 Nudge がアプリ独自の動画コンテンツの背後にレンダリングされる問題を修正しました。
  - 一部の OEM で HTML Nudge がシステムナビゲーションバーと重なる問題を修正しました。
- iOS
  - シーンベースのアプリで SDK に URL を渡す際に発生する可能性のあったデッドロックを修正しました。
  - Nudge の表示チェックが現在の画面単位で正しく適用されるように修正しました。
  - デバイスの向きの変更時に HTML の非割り込み型アプリ内メッセージが切り取られる問題を修正しました。
  - コンテンツが表示領域を超えた場合に、下部に配置された Nudge が画面の上部にレンダリングされ、閉じるボタンに到達できなくなる問題を修正しました。
  - ストレージ暗号化が有効な場合に、プッシュ受信インプレッションが失われる問題を修正しました。

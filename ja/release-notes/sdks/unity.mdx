#### Core 6.0.0
<span style={{ backgroundColor: 'rgba(0, 135, 103, 0.1)', color: '#008767', border: '1px solid #B5F5EC', padding: '2px 10px', borderRadius: '12px', fontSize: '0.85em', fontWeight: 'bold' }}>新機能</span>

* **Android**: ネイティブ Android の依存関係を **12.10.02** から **14.10.00** に更新しました。
* **Android**: 最小 SDK バージョンを **23** から **25** に引き上げました。
* **iOS**: ネイティブ iOS の依存関係を **9.18.1** から **10.12.0** に更新しました。
* **iOS**: 代替の依存関係マネージャーとして SPM (Swift Package Manager) を追加しました。
* `MoEInitializer.initializeDefaultInstance()` を追加しました。削除された `initialize()` および `initialiseDefaultInstance()` API に代わるものです。
* `moengage_config.properties` によるファイルベースの SDK 初期化を追加しました。
* `MoEAnalyticsHelper.IdentifyUser()` を追加しました。1 回の呼び出しで複数のユーザー ID を設定します。
* `MoEAnalyticsHelper.GetUserIdentities()` を追加しました。SDK に設定されている現在のユーザー ID を取得します。
* `MoEngageClient.SetUserAttributeEpochTime()` を追加しました。Unix エポックタイムスタンプを使用して日付型のユーザー属性をトラッキングします。
* `MoEGameObject.LogoutCompleteCallback` を追加しました。SDK のログアウトが完了したときにトリガーされるコールバックです。
* `MoEInAppHelper.ShowNudge()` を追加しました。指定した画面位置にナッジタイプのアプリ内メッセージを表示します。
* iOS の仮承認プッシュ (iOS 12 以降) 用に `MoEngageClient.RegisterForProvisionalPush()` を追加しました。
* 必要な Unity バージョンを 2023.1.7f1 から **Unity 6.4** (Hub バージョン 6000.4.1f1) に更新しました。
* ビルド環境の要件を更新しました: AGP 8.10.0、Gradle 8.13、Min SDK 25、Target SDK 35/36。

<Info>
  **iOS でのカスタムブール型属性のトラッキング**

  このバージョンにアップデートすると、iOS ではデフォルトで、MoEngage がカスタムのブール型ユーザー属性を `1/0` ではなく `TRUE/FALSE` としてトラッキングするようになります。これにより、セグメンテーションやトリガー条件に影響が出る可能性があります。

  この設定は変更できます。詳細は [カスタム属性のトラッキングのセクション](/ja/developer-guide/react-native-sdk/data-tracking/tracking-user-attributes-and-user-identity#custom-boolean-user-attribute) を参照してください。プラットフォーム間の一貫性を保つため、`TRUE/FALSE` への移行をお勧めします。
</Info>

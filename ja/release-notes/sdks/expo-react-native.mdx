<Note>
このリリースは MoEngage React Native プラグイン [13.0.0](/ja/release-notes/sdks/react-native#1st-october-2026) をラップしています。このプラグインでは、Android で MoEngage SDK BOM 4.4.0、iOS で MoEngage-iOS-SDK 11.2.0 に更新されています。
</Note>

#### Expo 2.0.0
<span style={{ backgroundColor: 'rgba(212, 56, 13, 0.1)', color: '#D4380D', border: '1px solid #FFCCC7', padding: '2px 10px', borderRadius: '12px', fontSize: '0.85em', fontWeight: 'bold' }}>破壊的変更</span>

* **Expo SDK 58.0.0 以降が必要です。** Android のビルドツールチェーンが AGP 9.1.1、Gradle 9.3.1、Kotlin 2.3.20、compile SDK 36 に移行しました。それより前の Expo SDK バージョンは AGP 9 をサポートしていません。
* **Android: プッシュ登録で FCM トークンの代わりに Firebase Installation ID を使用するようになりました。** MoEngage を使用してプッシュ登録を行っている場合は、アップグレードの前に `com.google.firebase:firebase-messaging` を 25.1.2 以上に移行し、Firebase Installation ID の統合を完了してください。詳細については、[Firebase Installation ID への移行](/ja/developer-guide/android-sdk/migration/migrating-to-firebase-installation-id)を参照してください。
* **Android: `passFcmPushToken()` は非推奨になりました。** 引き続き動作しますが、`passFirebaseInstallationId()` への移行をお勧めします。
* **Android: `pushTokenGenerated` イベントは非推奨になりました。** 引き続き動作しますが、`MoEPushToken` の代わりに `MoEFirebaseInstallationIdResult` を配信する `firebaseInstallationIdAvailable` への移行をお勧めします。
* **React Native の旧アーキテクチャのサポートを廃止しました。** プラグインは New Architecture のみをサポートするようになりました。

<span style={{ backgroundColor: 'rgba(0, 135, 103, 0.1)', color: '#008767', border: '1px solid #B5F5EC', padding: '2px 10px', borderRadius: '12px', fontSize: '0.85em', fontWeight: 'bold' }}>新機能</span>

* MoEngage React Native プラグイン [13.0.0](/ja/release-notes/sdks/react-native#1st-october-2026) に更新しました。Expo アプリケーションでは Swift Package Manager はサポートされておらず、引き続き MoEngage Expo の config プラグインを変更なしで使用します。

</Update>

#### Core SDK 15.03.00
<span style={{ backgroundColor: 'rgba(229, 57, 53, 0.1)', color: '#E53935', border: '1px solid #FFCDD2', padding: '2px 10px', borderRadius: '12px', fontSize: '0.85em', fontWeight: 'bold' }}>破壊的変更</span>

* **プッシュ登録で Firebase Installation ID を使用するようになりました:** 15.03.00 以降、SDK は FCM トークンの代わりに Firebase Installation ID を使用してデバイスをプッシュ登録します。

  * SDK がアプリケーションのプッシュ登録を処理している場合は、`com.google.firebase:firebase-messaging` を **25.1.2** 以上に更新し、アプリケーションのマニフェストファイルに `firebase_messaging_installation_id_enabled` メタデータを追加してください。いずれかの手順が欠けていると、アプリケーションはプッシュ通知を受信できなくなります。詳細は [Case 1: The MoEngage SDK Registers the Token](/ja/developer-guide/android-sdk/migration/migrating-to-firebase-installation-id#case-1-the-moengage-sdk-registers-the-token) を参照してください。
  * アプリケーション自身がトークンを渡している場合、プッシュは引き続き機能します。MoEngage のトークン API は非推奨となり、今後のリリースで削除されます。詳細は [Case 2: Your Application Registers the Token](/ja/developer-guide/android-sdk/migration/migrating-to-firebase-installation-id#case-2-your-application-registers-the-token) を参照してください。

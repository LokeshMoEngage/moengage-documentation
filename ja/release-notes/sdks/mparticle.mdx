#### Android Kit 3.3.0
<span style={{ backgroundColor: 'rgba(229, 57, 53, 0.1)', color: '#E53935', border: '1px solid #FFCDD2', padding: '2px 10px', borderRadius: '12px', fontSize: '0.85em', fontWeight: 'bold' }}>破壊的変更</span>

* **MoEngage SDK によるプッシュトークン登録はサポートされなくなりました:** SDK は Firebase Installation ID を使用してデバイスをプッシュに登録するようになりました。アップグレードする前に、`com.google.firebase:firebase-messaging` を **25.1.2** 以上に更新し、アプリケーションのマニフェストファイルで Firebase Installation ID を有効にしてください。MoEngage SDK がトークンを登録しているアプリケーションで両方の手順を完了していない場合、プッシュの登録が停止し、通知を受信できなくなります。[Migrating to Firebase Installation ID](/ja/developer-guide/android-sdk/migration/migrating-to-firebase-installation-id) を参照してください。

<span style={{ backgroundColor: 'rgba(0, 135, 103, 0.1)', color: '#008767', border: '1px solid #B5F5EC', padding: '2px 10px', borderRadius: '12px', fontSize: '0.85em', fontWeight: 'bold' }}>改善</span>

* MoEngage Android SDK を **15.03.00** に更新しました。[リリースノート](/ja/release-notes/sdks/android#23rd-september-2026)
* MoEngage は、Jetpack Compose のユーザーインターフェースに Cards を直接埋め込む `cards-ui-compose` モジュールを導入しました。[Cards in Jetpack Compose](/ja/developer-guide/android-sdk/cards/cards-ui-compose) を参照してください。
* カードのコンテンツがシステムによって強制的にダーク化されなくなりました。カードは、ライトテーマとダークテーマの両方で、設定した色でレンダリングされます。

</Update>

#### iOS Kit 3.2.0
<span style={{ backgroundColor: 'rgba(229, 57, 53, 0.1)', color: '#E53935', border: '1px solid #FFCDD2', padding: '2px 10px', borderRadius: '12px', fontSize: '0.85em', fontWeight: 'bold' }}>破壊的変更</span>

* **デフォルトの Dismiss 通知アクションを削除:** SDK のデフォルトの **Dismiss** アクションが通知カテゴリから削除されました。通知には、設定したアクションのみが表示されるようになりました。アプリがこのボタンに依存している場合は、独自のカテゴリ定義に明示的に追加してください。
* **Inbox API がメインアクターにバインド:** `presentInboxViewController`、`pushInboxViewController`、`getInboxViewController` が Swift の並行処理モデルに従うようになりました。メインアクター外の Swift の呼び出し箇所は更新が必要です。Objective-C の呼び出し元には影響しません。
* **`trackUserPushPreference` を非推奨化:** この API は本リリースでは引き続き動作しますが、将来のメジャーバージョンで削除される予定です。

<span style={{ backgroundColor: 'rgba(0, 135, 103, 0.1)', color: '#008767', border: '1px solid #B5F5EC', padding: '2px 10px', borderRadius: '12px', fontSize: '0.85em', fontWeight: 'bold' }}>改善</span>

* MoEngage iOS SDK を **11.2.0** に更新しました。[リリースノート](/ja/release-notes/sdks/ios#16th-september-2026)
* MoEngage フレームワークは、動的フレームワークとして埋め込まれるのではなく、ホストバイナリに静的にリンクされるようになりました。CocoaPods および Swift Package Manager での統合には変更は必要ありません。
* Inbox の完了ブロックがメインスレッドで呼び出されるようになったため、完了ブロックから直接 UI を更新できます。
* Inbox のエントリーはイミュータブルなスナップショットになりました。`isRead` や `clickedDate` などの既読状態の変更は、すでに保持しているエントリーオブジェクトを変更するのではなく、次回の取得時に反映されます。エントリーを既読にした後は、Inbox を再取得してください。

</Update>

#### iOS Kit 3.0.0
<span style={{ backgroundColor: 'rgba(229, 57, 53, 0.1)', color: '#E53935', border: '1px solid #FFCDD2', padding: '2px 10px', borderRadius: '12px', fontSize: '0.85em', fontWeight: 'bold' }}>破壊的変更</span>

* **API 使用前の SDK 初期化を強制:** 基盤となる MoEngage iOS SDK は、パブリック API を使用する前に初期化を強制するようになりました。順序どおりに呼び出されない場合、Debug、Release、TestFlight のすべてのビルド構成で `fatalError` が発生します。
* **Objective-C の enum を Swift に移行:** `MoEngageInAppActionType` と `MoEngageNudgePosition` が Swift の enum になりました。古い Objective-C スタイルのケース名を参照しているコードを更新してください。移行表については、[iOS SDK リリースノート](/ja/release-notes/sdks/ios#22nd-july-2026)を参照してください。
* **パブリック API が型付きタスクオブジェクトを返却:** 以前は `Void` を返していた API（例: `trackEvent`、`showInApp`、`setPushToken`、`initializeDefaultLiveInstance`）が、型付きタスクオブジェクトを返すようになりました。直接呼び出しはそのままコンパイルされますが、明示的な `Void` 戻り値型を持つ Swift の関数参照の代入はコンパイルできなくなります。
* **Cards ビューコントローラー API が `@MainActor` に:** `presentCardsViewController`、`pushCardsViewController`、`getCardsViewController` に `@MainActor` アノテーションが付与されました。メインアクター以外のコンテキストからこれらを呼び出す Swift の呼び出し元は、メインアクターに切り替える必要があります。
* **属性値に `Sendable` 準拠が必要:** Swift 6 言語モードまたは厳格な並行処理チェックでは、`setUserAttribute`、`setDeviceAttribute`、`MoEngageProperties` の属性 API の値が `Sendable` に準拠している必要があります。

* MoEngage iOS SDK を **11.0.0** に更新しました。[リリースノート](/ja/release-notes/sdks/ios#22nd-july-2026)

</Update>

* **AGP を 9.1.1 に更新:** ビルドパフォーマンスと互換性を向上させるため、Android Gradle Plugin をバージョン 9.1.1 にアップグレードしました。
* **Kotlin を 2.3.20 に更新:** 最新の言語機能と安定性の向上を活用するため、Kotlin をバージョン 2.3.20 にアップグレードしました。
* **Compile SDK と Target SDK を 36 に更新:** 最新の Android プラットフォームの機能に合わせて、Compile SDK と Target SDK を 36 にアップグレードしました。
* **DataCenter の Clinit 最適化:** 起動パフォーマンスを向上させるため、`DataCenter` の初期化を最適化しました。これにより Java の破壊的変更が発生し、`MoEngage.Builder` コンストラクタのシグネチャが更新されている点に注意してください。詳細については、[Android SDK リリースノート](/ja/release-notes/sdks/android#7th-july-2026)を参照してください。
* **SDK 未初期化時の例外:** SDK が初期化される前に API が呼び出されると、SDK は `IllegalStateException` をスローするようになりました。処理されない場合、ランタイムクラッシュが発生します。SDK API を呼び出す前に、必ず `MoEngage.initialiseDefaultInstance()` を呼び出してください。

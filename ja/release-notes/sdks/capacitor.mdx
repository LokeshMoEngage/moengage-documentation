<Info>
  **iOS でのカスタムブール型属性のトラッキング**

  このバージョンにアップデートすると、iOS ではデフォルトで MoEngage がカスタムのブール型ユーザー属性を `1/0` ではなく `TRUE/FALSE` としてトラッキングするようになります。これにより、セグメンテーションやトリガー条件に影響が出る可能性があります。

  この設定は変更できます。詳細については、[カスタム属性のトラッキングのセクション](/ja/developer-guide/react-native-sdk/data-tracking/tracking-user-attributes-and-user-identity#custom-boolean-user-attribute)を参照してください。プラットフォーム間の一貫性を保つため、`TRUE/FALSE` への移行をお勧めします。
</Info>

### リリース概要

<CardGroup cols={2}>
  <Card title="パッケージ">
    - <span style={{ color: '#00C896', fontWeight: 'bold' }}>Core 2.0.0</span>

  <Card title="依存関係">

    **iOS**
    - MoEngage-iOS-SDK: 9.2.0+
    - MoEngageGeofence: 5.2.0+
  </Card>
</CardGroup>

#### Core 2.0.0
<span style={{ backgroundColor: 'rgba(212, 56, 13, 0.1)', color: '#D4380D', border: '1px solid #FFCCC7', padding: '2px 10px', borderRadius: '12px', fontSize: '0.85em', fontWeight: 'bold' }}>破壊的変更</span>

* 公開されているすべての API で、末尾の追加パラメーターとして `appId` が必要になりました。
* `MoEPushToken` の名前を `MoEPushTokenData` に変更しました。

**名前が変更された API:**

| 変更前 | 変更後 |
| :--- | :--- |
| `optOutDataTracking({ shouldOptOut: true })` | `enableDataTracking(options: { appId: string }): Promise<void>` |
| `optOutDataTracking({ shouldOptOut: false })` | `disableDataTracking(options: { appId: string }): Promise` |

**削除された API:**

| 削除済み |
| :--- |
| `selfHandledPrimaryClicked(campaignData: MoEInAppSelfHandledCampaignData): Promise<void>` |
| `enableSDKLogs(): Promise<void>` |
| `optOutInAppNotification(options: { shouldOptOut: boolean }): Promise<void>` |
| `optOutPushNotification(options: { shouldOptOut: boolean }): Promise<void>` |

<span style={{ backgroundColor: 'rgba(0, 135, 103, 0.1)', color: '#008767', border: '1px solid #B5F5EC', padding: '2px 10px', borderRadius: '12px', fontSize: '0.85em', fontWeight: 'bold' }}>新機能</span>

* **Android**: Android SDK バージョン `12.5.04` 以上をサポートしました。Android 13 の通知権限をサポートしました。AGP を 7.3.1 に更新しました。Target SDK / Compile SDK を 31 に更新しました。
* **Android — 更新された API:**

| 変更前 | 変更後 |
| :--- | :--- |
| `MoEInitializer.initialize(context, builder)` | `MoEInitializer.initialiseDefaultInstance(context, builder)` |
| `MoEInitializer.initialize(context, builder, isSdkEnabled)` | `MoEInitializer.initialiseDefaultInstance(context, builder, sdkState)` |

* **iOS**: iOS SDK バージョン `9.2.0` 以上をサポートしました。
* **iOS — 更新された API:**

| 変更前 | 変更後 |
| :--- | :--- |
| `initializeWithSDKConfig(_:andLaunchOptions:)` | `initializeDefaultInstance(_:andLaunchOptions:)` |
| `initializeWithSDKConfig(_:withSDKState:andLaunchOptions:)` | `initializeDefaultInstance(_:withSDKState:andLaunchOptions:)` |

#### Geofence 2.0.0
<span style={{ backgroundColor: 'rgba(0, 135, 103, 0.1)', color: '#008767', border: '1px solid #B5F5EC', padding: '2px 10px', borderRadius: '12px', fontSize: '0.85em', fontWeight: 'bold' }}>新機能</span>

* MoEngageGeofence の依存関係を `5.2.0` 以上に更新しました。
* 公開されているすべての API で、末尾の追加パラメーターとして `appId` が必要になりました。

</Update>

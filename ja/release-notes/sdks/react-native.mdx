#### Core 12.9.0
<span style={{ background: 'rgba(0,135,103,0.1)', color: '#008767', border: '1px solid #B5F5EC', borderRadius: '4px', padding: '2px 8px', fontSize: '12px', fontWeight: '600' }}>新機能</span>

- Push to In-App を追加しました。プッシュ通知のクリックでアプリ内メッセージをトリガーできるようになりました。詳細については、[トリガー条件](/ja/user-guide/campaigns-and-channels/in-app-message/create/create-in-app-campaign#trigger-criteria)を参照してください。
- iOS
  - Scene Delegate のサポートを追加しました。`UISceneDelegate` を使用するアプリでは、追加設定なしで SDK のすべての機能を利用できます。
  - Movable Nudges を追加しました。ユーザーはアプリ内で Nudge の位置を変更できます。
  - SDK がアプリのバッジ数を管理するかどうかを制御するため、`Info.plist` のルートレベルに Boolean キー `MoEngageBadgeUpdateEnabled` を追加しました。このキーのデフォルトは `YES` です。アプリでバッジ数を独自に管理する場合は `NO` に設定してください。詳細については、[バッジリセットの無効化](/ja/developer-guide/ios-sdk/push/advanced/custom-notification-handling#disable-badge-reset)を参照してください。

<span style={{ background: 'rgba(0,135,103,0.1)', color: '#008767', border: '1px solid #B5F5EC', borderRadius: '4px', padding: '2px 8px', fontSize: '12px', fontWeight: '600' }}>改善</span>

- Android
  - UI スレッドでの処理を削減し、アプリ内メッセージのレンダリングパフォーマンスを向上しました。
  - アプリ内メッセージにおける電話番号の検証を改善しました。
  - Nudge が表示されない理由のレポートを改善しました。
  - バックグラウンドでのデータ同期中のロック解放メカニズムを最適化し、例外発生時にロックがすばやく解放されるようにしました。
- iOS
  - 従来の増減ロジックに代わり、バッジ数が通知センター内の MoEngage 通知の数と同期するように更新しました。

<span style={{ background: 'rgba(212,107,8,0.1)', color: '#D46B08', border: '1px solid #FFE58F', borderRadius: '4px', padding: '2px 8px', fontSize: '12px', fontWeight: '600' }}>修正</span>

- 下部の Nudge が左下または右下の Nudge と同時に表示される問題を修正しました。これらの位置は相互排他的になりました。
- Android
  - メモリ不足で動作しているローエンドデバイスで、HTML WebView が原因で発生する ANR を修正しました。
  - ピクチャーインピクチャー（PiP）モードで動画を再生中に、アプリ内メッセージが正しく表示されない問題を修正しました。
  - 予測型「戻る」ジェスチャーが有効な状態で、アニメーション実行中にアプリ内メッセージが閉じられた場合に、戻るボタンを押すとクラッシュする問題を修正しました。
  - 一部のデバイスで、プッシュ通知の大きな画像が要約テキストと重なる問題を修正しました。
- iOS
  - iOS 15.x および 16.x で、認識されないサードパーティの Swift クラス名に対して `NSClassFromString` が呼び出されることにより、SDK の初期化中にクラッシュする問題を修正しました。

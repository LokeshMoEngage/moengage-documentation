このリリースでは、履歴同期の重複を防止し、失敗したレコードのみを再処理するインテリジェントな再試行メカニズムを導入することで、システムパフォーマンスとユーザーによる制御が強化されています。エラー回復の信頼性を向上させるため、履歴同期はレート制限エラーが発生した後に自動的に再試行されるようになりました。さらに、ナビゲーションを容易にするクリック可能な Record ID ハイパーリンクや、管理者が例外レコードを削除できる機能など、UI の改善も提供されています。

# 新機能

## (UI の更新) 履歴同期の動作

競合を防止し、同期の信頼性を向上させるため、次の制限が設けられました。

MoEngage の User オブジェクトと Event オブジェクトについて、**ワークスペース/接続ごとに一度に開始できる履歴同期は 1 つのみ**です。同期の進行中 (完了、失敗、または部分的に成功するまで) は、同じ MoEngage オブジェクトに対する他のすべての同期で 'Sync' ボタンが無効になります。

**例:** MoEngage User オブジェクトの履歴同期が開始された場合、MoEngage User に対する他の同期は無効になります。ただし、MoEngage Event オブジェクトの同期は引き続き利用できます。

## (UI の更新) Record ID ハイパーリンク

Sync Queue と Exception の作成対象となる基になるレコードへのアクセス性を向上させるため、次の対応を行いました。

  * Exception オブジェクトの '**All** ' リストビューおよびレコード詳細ページに '**Record Id** ' を表示し、Exception が発生したレコードにリダイレクトできるようにしました。
  * Sync Queue オブジェクトの 'Real-Time Syncs' リストビューおよびレコード詳細ページに '**Record Id** ' をハイパーリンクとして表示し、Sync Queue が作成されたレコードにリダイレクトできるようにしました。



## (UI の更新) Exception レコードの削除機能

管理者ユーザーが Exception レコードを削除できるようにしました。

  * Exception レコードに Salesforce 標準の **Delete** ボタンを追加しました。



## プロセスの改善

### レート制限からの回復

"Rate Limit Exceeded" エラーが発生した履歴同期は、再試行回数が 0 にリセットされた状態で自動的に再試行されるようになりました。

### よりスマートな再試行ロジック

履歴同期の再試行では失敗したレコードのみが再処理されるようになり、冗長な処理が大幅に削減され、効率が向上します。これは次のエラータイプに適用されます。

  * Account Suspended
  * Authentication Required
  * BlockedClient
  * Rate Limits Exceeded
  * Server Error
  * Unsupported Media Type



# リストビューとページレイアウトの変更に関するパッケージアップグレード時の動作

## リストビューの動作

パッケージをアップグレードしても、リストビューは自動的に更新されません。ユーザーは、'**Record ID'** フィールドを含めるようにリストビューを手動で更新する必要があります。更新が必要なリストビュー:

  * **All** – Exception オブジェクトにあるリストビュー
  * **Real Time Syncs** – Sync Queue オブジェクトにあるリストビュー



## ページレイアウトの動作

パッケージをアップグレードしても、ページレイアウトは自動的に更新されません。ユーザーは、'Record ID' フィールドを含めるようにページレイアウトを手動で更新し、レイアウト上に以前の 'Record ID' (テキスト) フィールドがある場合は削除する必要があります。更新が必要なページレイアウト:

  * **Exception Layout** – Exception オブジェクトのページレイアウト
  * **Historical Sync Layout** – Sync Queue オブジェクトのページレイアウト (Record ID の更新に加えて、'Failed Sync Queues' 関連リストに 'Record ID' ハイパーリンクフィールドも追加します。)
  * **Sync Queue Layout** – Sync Queue オブジェクトのページレイアウト

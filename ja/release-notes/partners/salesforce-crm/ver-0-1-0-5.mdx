このリリースでは、バッチサイズを調整可能な履歴同期、Apex Flex Queue の検証、新しいユーザー権限と管理者権限を含む更新された権限セットに重点を置いた機能強化と改善が導入されています。 

# 新機能

このバージョンで導入された新機能と改善点は次のとおりです。

### 履歴同期のバッチサイズオプションの強化

  * 履歴同期機能に追加のバッチサイズオプションを導入しました。
  * 新しいバッチサイズとして、5、10、15、20、25、50、75、100、125、150、175、200 のオプションを利用できるようになりました。



### 履歴同期における Apex Flex Queue のロジックチェック

履歴同期の実行ロジックを強化し、Apex Flex Queue の空き状況を確認するようにしました。保留中のジョブが 50 件を超える場合、Apex Flex Queue は満杯とみなされます。

  * 履歴同期の実行ロジックを改善し、Apex Flex Queue の空き状況を検証するようにしました。
  * 保留中のジョブが 50 件を超える場合、Apex Flex Queue は満杯とみなされます。



**キューが満杯の場合** :

  * **Sync** ボタンが無効になります。
  * 次のメッセージが表示されます: Salesforce Apex Flex Queue is complete. Please try again later.



**ユーザーがページを更新した場合** :

  * **Sync** ボタンが再度有効になります。
  * ボタンをクリックすると、Apex Flex Queue が満杯かどうかのチェックが再度実行されます。



### 権限セットの強化

  * 既存の**MoEngage Sync Configuration Permission** の名前を **MoEngage Admin Permission** に変更しました。
  * 新しい権限セット **MoEngage User Permission** を導入しました。これにより、次へのアクセスが提供されます。 
    * パッケージのカスタムオブジェクトとフィールド
    * カスタム設定とメタデータ
    * Apex クラスへのアクセス

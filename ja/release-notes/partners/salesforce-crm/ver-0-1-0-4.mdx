このリリースでは、特にデータ同期、フィールド選択、文字数制限を中心に、使いやすさと機能性に重点を置いた機能強化と改善が導入されています。このバージョンの機能強化には次のものが含まれます。

- **使いやすさの向上** : サブ見出しにより、正しい API フィールドを簡単に選択できます。
- **フィールド長の拡張** : Salesforce API フィールド名の切り捨てを防止します。
- **同期の改善** : Individual オブジェクトをサポートするために、より幅広いデータ同期機能を実現します。
- **オブジェクトマッピングの拡張** : Individual、Campaign Member、Service Appointment オブジェクトのマッピングを可能にします。

# 新機能

このバージョンで導入された新機能と改善点は次のとおりです。

### 新しい標準オブジェクトのサポート

_Individual_、_Campaign Member_、_Service Appointment_ を同期できるようになりました。これにより、より幅広いデータの整合と統合が可能になります。 <img src="/images/partner_37446552202644.png" />

### フィールド選択の強化

設定時に適切なフィールドを選択できるように、API 名 (統合や開発の目的で使用されるプログラム上またはシステム固有の名前) が **Salesforce** **Field** リストにサブ見出しとして表示されるようになりました。 <img src="/images/partner_37446552203284.png" />

### 文字数制限の拡大

より多くのデータ入力をサポートするため、**Mapping** オブジェクトの **Salesforce Field** にある API 名、およびパッケージ化されたオブジェクトのその他のフィールドの文字数制限が拡大されました。

<Info>
  一部のオブジェクトでは、フィールドのマッピング時に特別な注意が必要です。スムーズなデータ同期のために、次の必須マッピングが設定されていることを確認してください。

  - **Campaign member** : Lead ID (API 名: `LeadId`) または Contact ID (API 名: `ContactId`) をイベント属性にマッピングします。これらのフィールドは **Others** セクションにあります。
  - **Service appointment** : Earliest Start Permitted (API 名: `EarliestStartTime`) フィールドと Due Date (API 名: `DueDate`) フィールドは必須であり、Unix エポック時間の値を含むイベント属性にマッピングする必要があります。
    - Parent Record (API 名: `ParentRecordId`) も必須であり、**Others** セクションでマッピングする必要があります。Parent Record はポリモーフィックフィールドです。MoEngage は、_Work Order_、_Work Order Line Item_、_Account_、_Opportunity_、_Asset_、_Lead_、_Case オブジェクト_のレコード ID を処理できます。

  これらのマッピングを確実に行うことで、上記のシナリオに対応しながら、MoEngage と Salesforce 間でデータを効率的に同期できます。
</Info>

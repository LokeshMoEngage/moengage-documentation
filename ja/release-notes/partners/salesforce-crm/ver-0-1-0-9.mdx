このリリースでは、MoEngage User 権限セットを持つユーザーに "DML operation UPDATE not allowed on `moengage__Sync_Queue__c`" というエラーが発生していた問題に対処しています。同期プロセスがシステムモードで実行されるように強化され、DML 操作がスムーズに行われるようになり、報告された問題が解決されました。

# 実装された変更

MoEngage User Permission セットを持つユーザーに次のエラーが発生していたため:

  * "DML operation UPDATE is not allowed on `moengage__Sync_Queue__c`" - 同期バッチでの DML 操作をシステムモードで実行するようにプロセスを更新しました。



## 影響

  * MoEngage User 権限セットを持つユーザーの問題を解決します。
  * エンドユーザーによる追加の変更や対応は必要ありません。

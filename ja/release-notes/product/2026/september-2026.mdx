## Context Hub

Context Hub は、ブランド、ビジネス、コミュニケーションのアイデンティティを一度登録すれば、MoEngage のさまざまなワークフローで再利用できる一元的な場所です。Context Hub では次のことが可能です。

- **過去のキャンペーンからのバックグラウンド抽出**: Merlin AI が毎週、または 50 件のキャンペーンごとにバックグラウンドで実行され、過去のキャンペーンアクティビティを分析して、確認用のブランド情報を提示します。
- **AI を活用した Web およびファイルからの抽出**: Merlin AI とチャットし、テキストを貼り付けたり、ブランドガイドラインの PDF などのドキュメントを添付したり、Web サイトの URL を共有したりして、コンテキストを抽出できます。
- **ブランドのカテゴリ**: コンテキストは、Visual system (ロゴ、カラー、フォント)、Identity (ブランドストーリー)、Brand voice and tone、Formatting、Others (規制上の免責事項など) に分類されます。
- **保存内容の完全な管理**: 承認なしに追加されるものはありません。Merlin AI は検出結果をチェックボックスのツリー形式で **New additions** または **Updates** として提示するため、保存する詳細を正確に選択できます。
- **MoEngage 全体での活用**: Applicability マトリックスには、各エンティティが手動チャネル (Email、In-App、On-Site Messaging、Landing Pages) や、Custom Agents、Flows Assist、Email エージェントなどの Merlin AI 機能でどのように使用されるかが表示されます。

Context Hub は段階的に展開されています。**Settings \> Account \> Context Hub** に表示されない場合は、MoEngage サポートチームに有効化を依頼してください。

詳細については、[Context Hub](/ja/user-guide/ai-and-intelligence/merlin-ai/context-hub) を参照してください。

## All Campaigns ページの機能強化

All Campaigns ページで、関心のあるキャンペーンを見つけ、パーソナライズし、操作しやすくなりました。今回のリリースでは次の機能が追加されています。

- **Views**: フィルター、列、検索語、表示設定の任意の組み合わせを、再利用可能な View として保存できます。View を **Private** または **Public** (1 つ以上のチームと共有) に設定し、View をタブとしてピン留め、ピン留め解除、並べ替えできるほか、ページを開いたときに読み込まれる **Default View** を設定できます。System View (All、Active、Schedule、Drafts、Under Review/Rejected) は常に利用できます。1 つのワークスペースで最大 100 個の View がサポートされます。
- **Dynamic Columns**: テーブルに表示するデータポイントを選択できます。ドラッグして列を並べ替えたり、列の表示/非表示を切り替えたり、名前で列を検索したりできます。列の設定はユーザーごとに保存され、View ごとに設定できます。
- **タブ固有のデフォルト列**: 各システムタブには、そのタブに関連する列が表示されます。たとえば、Schedule タブには **Scheduled on** と **Estimated audience count** が表示され、Active タブにはパフォーマンスとエンゲージメントの指標が表示されます。統一されたレイアウトに戻すには、**Switch to classic view** を使用します。
- **Bulk Actions**: 最大 50 件のキャンペーンを選択し、**Tag**、**Download**、**Report**、**Archive**、**Pause**、**Stop**、**Resume**、**Delete** (Drafts のみ) を 1 回の操作で実行できます。適格性はキャンペーンごとにチェックされ、確定する前にアクションの対象となるキャンペーン数を確認できます。使用できるアクションはタブによって異なります。
- **Recent Searches**: 検索ボックスをクリックすると、結果が返された直近 5 件の検索が表示され、クリックするだけで再適用できます。
- **ページ読み込みの高速化**: キャンペーンデータと統計データが個別に読み込まれるようになり、大量のキャンペーン統計を持つワークスペースではページの読み込み時間が最大 80% 短縮されます。

これらの機能は段階的に展開されています。表示されない場合は、MoEngage サポートチームに有効化を依頼してください。

詳細については、[All Campaigns](/ja/user-guide/campaigns-and-channels/campaign-management-and-reports/all-campaigns) を参照してください。

## Custom Agents: コネクターと画像生成

Custom Agents が外部ツールと連携し、ブランドに沿った画像を生成し、専門のサブエージェント間で連携できるようになりました。

この機能により、次のことが可能になります。

- **外部アプリへの接続**: 実行中に Google Workspace、Slack、Atlassian、Salesforce でデータを読み取り、アクションを実行できます。アクセスは個々のユーザーの権限に安全に限定されます。
- **ビジュアルの作成と公開**: 過去のキャンペーンを分析し、Context Hub のブランドガードレールを使用して新しいクリエイティブを生成し、共有可能な URL を 1 回の実行で公開できます。
- **複雑なワークフローのオーケストレーション**: コーディネーターエージェントから専門のサブエージェントにタスクを委任し、出力を 1 つの統合された回答にまとめることができます。

<Info>
これらの機能は段階的に展開されています。アクセスについては CSM にお問い合わせください。
</Info>

詳細については、[外部アプリを接続する](/ja/user-guide/ai-and-intelligence/merlin-ai/connectors/connect-external-apps)、[画像を生成および分析する](/ja/user-guide/ai-and-intelligence/merlin-ai/custom-agents/create-and-manage-custom-agents#generate-and-analyze-images)、[マルチエージェントワークフローを構築する](/ja/user-guide/ai-and-intelligence/merlin-ai/custom-agents/build-multi-agent-workflows)を参照してください。

## Offering Migration

コンテンツ、ターゲティング、スケジュールを手動で再構築する代わりに、Offering を移行できるようになりました。Offering Migration では次のことが可能です。

- **ワークスペース間の移行**: あるワークスペースから別のワークスペースに Offering を移動できます。
- **環境間の移行**: 同じワークスペースの Test 環境と Live 環境の間で Offering を移行できるため、Test で検証してから 1 回の操作で Live に昇格できます。
- **Imported ステータス**: 移行された Offering は **Imported** ステータスで **Drafts** に配置されるため、準備ができたら識別、確認、有効化できます。
- **事前の依存関係チェック**: セグメント、属性、テンプレートなどの不足している要素が移行前に警告されるため、Offering を公開する前に不足を解消できます。

詳細については、[Offering Migration](/ja/user-guide/decisioning/offer-decisioning/offering-migration) を参照してください。

## Test a Recommendation

Test a Recommendation が、Basic と Advanced の両方のレコメンデーションモデルで利用できるようになりました。顧客に表示される内容をプレビューし、条件を調整して、キャンペーンの公開前に問題を見つけることができます。次のことが可能です。

- **特定のユーザーでテスト**: Email ID、Mobile Number、User ID、MoEngage ID で検索し、そのユーザーのパーソナライズされた結果を表示できます。
- **ランダムな対象ユーザーでテスト**: 1 回のクリックで、条件を満たすユーザー 10 人をサンプリングできます。
- **アイテムでテスト**: Similar Items、Frequently Bought Together、Frequently Viewed Together モデルで、特定の商品とどのアイテムが組み合わされるかを確認できます。
- **フィルターのリアルタイム調整**: 条件のオン/オフを切り替えると、結果がリアルタイムで更新されます。
- **除外されたアイテムの検出**: カタログの不一致を見つけることができます。
- **結果がゼロの場合のトラブルシューティング**: レコメンデーションが結果を返さない理由を確認できます。

詳細については、[Test a Recommendation](/ja/user-guide/content/recommendations/getting-started/test-a-recommendation) を参照してください。

## On-Site Messaging と Landing Pages の HTML エディター

ランディングページと On-Site Messaging (OSM) キャンペーンの作成時に、HTML を直接アップロードできるようになりました。次のことが可能です。

- 独自の HTML を追加し、そのアセットをアップロードする。
- HTML とアセットを含む ZIP ファイルをアップロードする。
- ページまたはキャンペーンをプレビューする。
- 準備ができたら公開する。

HTML エディターを使用すると、他のツールからエクスポートしたページを取り込んだり、デザインチームや開発チームから引き渡された HTML パッケージを公開したり、完成した HTML ページをドラッグ & ドロップエディターで再構築せずに公開したりできます。この機能は、すべてのデータセンターで段階的に有効化されています。

詳細については、[HTML Landing Page Editor](/ja/user-guide/content/landing-pages/create/html-landing-page-editor) および [カスタム HTML または HTML ZIP をアップロードする](/ja/user-guide/campaigns-and-channels/on-site-message/create/osm-templates-html-editor#upload-custom-html-or-an-html-zip)を参照してください。

## Business Events API (V5)

新しい Business Events API (V5) を使用して、ビジネスイベントを発火したり、ワークスペース内のビジネスイベントを検索したりできるようになりました。V5 エンドポイントは統合された MoEngage ゲートウェイを通じて提供され、バージョン管理された `{response_id, type, data}` エンベロープでレスポンスを返します。

**エンドポイント**

- [Trigger Business Event (V5)](/ja/api/business-events/trigger-business-event-v5): 登録済みのビジネスイベントを発火し、そのイベントに関連付けられたキャンペーンとフローをキューに追加します。
- [List Business Events](/ja/api/business-events/list-business-events): ワークスペース内のすべてのビジネスイベントを一覧表示するか、名前または ID で 1 つのイベントを検索します。キャンペーン数とトリガー数を返し、カーソルベースのページネーションをサポートしています。
- [Search Business Events (V5)](/ja/api/business-events/search-business-events-v5): すべてのビジネスイベントを一覧表示するか、名前または ID で複数のイベントを一度に検索します。List Business Events と同じフィールドを返し、カーソルベースのページネーションをサポートしています。

## Decisioning Agent Analytics (早期アクセス)

MoEngage は、Campaign Decisioning 向けに Decisioning Agent Analytics ダッシュボードを導入しました。AI で最適化された Agent Treatment Group とベースラインの Agent Control Group を比較することで、Decisioning Agents が生み出した増分価値を測定できます。このダッシュボードでは、エンゲージメントの向上率、実行された意思決定・送信されたキャンペーン・アクティブなチャネルの概要、チャネル別およびキャンペーン別にパフォーマンスを分析したトリートメントとコントロールの比較表がレポートされます。この機能は早期アクセス段階です。フェーズ 1 ではエンゲージメントの向上率を扱い、コンバージョン指標と CSV エクスポートは今後のフェーズで予定されています。

詳細については、[Decisioning Agent Analytics](/ja/user-guide/decisioning/campaign-decisioning/decisioning-agent-analytics) を参照してください。

## Offer Decisioning の Custom Formula ランキング戦略

MoEngage は Offer Decisioning に Custom Formula ランキング戦略を追加しました。各顧客に対するオファーのランキングにどの要素が影響し、各要素にどの程度の重みを持たせるかを定義でき、スコアはリアルタイムで再計算されます。数式は、各オファーに付与された固定の組織レベルの目標 (Boost AOV や Improve Retention など) と、動的なユーザーレベルのシグナル (Category Affinity、Churn Propensity、Spend Tier など) を組み合わせるため、ランキングは商業的な意図を反映しつつ、個人にとっても関連性の高いものになります。

詳細については、[Custom Formula ランキング戦略](/ja/user-guide/decisioning/offer-decisioning/custom-formula-ranking-strategy) と [Offering 属性の作成](/ja/user-guide/decisioning/offer-decisioning/create-offering-attribute) を参照してください。

## パートナー統合での Portfolio のサポート

MoEngage は、統合イベントをマルチアプリ (Portfolio) ワークスペース内の特定のプロジェクトに直接ルーティングするようになりました。これにより、ブランド固有のイベントデータが正しいプロジェクトに格納され、ローカライズされた分析とターゲティングの正確性が保たれます。Segment の場合は、Track Call アクションマッピングの新しい Project Name フィールドにターゲットプロジェクトを入力します。mParticle やその他のパートナーの場合は、イベントペイロード内で `moe_project_name` という名前のイベント属性としてプロジェクト名を渡します。サポート対象は、Segment、mParticle、Adobe CDP の各パートナー、CSV、S3、SFTP のファイルインポート、BigQuery、Snowflake、Databricks のウェアハウスインポートです。このリリースはすべてのデータセンターで利用可能で、後方互換性があるため、マルチアプリではないワークスペースには変更はありません。対象範囲はイベントのルーティングに限定されます。これらのパートナーからのユーザープロファイルのインポートとコホートの同期は、引き続きポートフォリオのルートレベルで取り込まれます。

## ユーザープロファイルの強化

MoEngage はユーザープロファイルを刷新し、まず DC3 で提供を開始しました。ロールと権限に基づいて UI からユーザーを削除したり、ユーザーのメールサブスクリプションステータスを変更したり (トラッキングイベントが生成され、下流の SendGrid の更新がトリガーされ、監査ログに記録されます)、SMS チャネルからユーザーの登録を解除したりできるようになりました。Multi-ID ワークスペースでは、識別子としてマークされたユーザー属性が基本情報セクションに表示されるようになりました。このリリースでは、タブの見つけやすさ、イベントのフィルタリング、用語の一貫性、読みやすさも改善されています。UI と UX の改善はデータセンターごとに展開され、削除機能とサブスクリプション機能は段階的に有効化されます。

詳細については、[ユーザープロファイル](/ja/user-guide/data/user-data/user-profile) を参照してください。

## Merlin AI In-App Template Generator: 参照としての画像

Merlin AI In-App Template Generator で、画像を参照として使用できるようになりました。Figma、Photoshop、Sketch などのツールからエクスポートしたデザインの PNG をアップロードし、目的を説明すると、Merlin がそれに合った HTML テンプレートを生成します。生成されたテンプレートは、フォローアッププロンプトで改善できます。生成されたテンプレートには、MoEngage のトラッキング、SDK に最適化されたレンダリング、レスポンシブ対応が含まれます。この機能は、Merlin AI テンプレートジェネレーターが有効になっているすべてのデータベースで利用できます。

詳細については、[Merlin AI In-App Template Generator](/ja/user-guide/ai-and-intelligence/merlin-ai/merlin-ai-in-app-template-generator/merlin-ai-in-app-template-generator#use-a-reference-image) を参照してください。

## All Campaigns ページの機能強化

MoEngage は、キャンペーン管理の使いやすさに関するいくつかの改善をリリースしました。

- **Copy Link**: All Campaigns ページから直接キャンペーンのリンクをコピーして、チームと共有できます。
- **Drafts タブでの検索語の保持**: All Campaigns ページで入力した検索語が、Drafts タブに切り替えたときにも引き継がれるようになりました。
- **アラート名の折り返し**: All Alerts ページで、アラート名が切り詰められるのではなく、一定の上限まで折り返して表示されるようになりました。
- **アクションアイコン**: 明確さとアクセシビリティを向上させるために、いくつかのアクションにアイコンが追加されました。

## Portfolio の進化: In-app Messaging と On-site Messaging

MoEngage は、Portfolio のオーケストレーション機能を拡張し、In-app Messaging と On-site Messaging (OSM) を含めました。このアップデートによりデータの統合とリアルタイムの実行の間のギャップが埋まり、ブランドはアクティブな関心が最も高まった瞬間に、アプリと Web のエコシステム全体でユーザーにエンゲージできます。

**主なハイライト:**

- **セッション内のオーケストレーション**: ユーザーがポートフォリオ内のいずれかのプロパティを操作した瞬間に、リッチなアプリ内メッセージまたは OSM メッセージをトリガーします。
- **クロスチャネルの検証**: アプリ横断的な行動データを使用して、高度にパーソナライズされた Web バナーやモーダルオファーを実現します。
- **オーガニックな成長**: 「ワンタップ」のアプリ内プロンプトを使用して既存のユーザーをブランドファミリー内の他のアプリにオンボーディングし、顧客獲得コスト (CAC) を削減します。
- **リーチの最大化**: プッシュ通知を無効にしているユーザーにも、アプリ内または Web サイト上でアクティブなときにリーチしてエンゲージします。

詳細については、[In-App 向け Portfolio](/ja/user-guide/campaigns-and-channels/in-app-message/getting-started-with-in-app-message/portfolio-for-in-app-campaigns) と [OSM 向け Portfolio](/ja/user-guide/campaigns-and-channels/on-site-message/getting-started-with-on-site-message/portfolio-for-on-site-messaging) を参照してください。

## 旧ナビゲーションの廃止

MoEngage は、最新のナビゲーションフレームワークへの移行を正式に完了しました。すべてのユーザーが最新のパフォーマンス強化と機能へのアクセス性の恩恵を受けられるよう、「Classic」インターフェイスは廃止されました。

**主なハイライト:**

- **必須の移行**: 2026 年 4 月 1 日より、すべてのアカウントが新しいナビゲーションに移行されます。**Switch to Classic** トグルは利用できなくなります。
- **合理化された UX**: 更新されたインターフェイスはメニューの煩雑さを軽減し、機能を発見しやすくすることで、マーケティングチームのより効率的なワークフローを実現します。
- **パフォーマンスの向上**: 新しいフレームワークは、今後のプラットフォーム機能をサポートするよう構築された、より応答性の高い環境を提供します。
- **グローバルでの提供**: この移行はすべてのデータセンターで完了しています。

## ダークモードの導入

標準の MoEngage インターフェイスに代わる、洗練されたハイコントラストの選択肢としてダークモードを導入しました。このアップデートにより、目の疲れを軽減し集中力を高めるようにワークスペースをカスタマイズできます。**Profile** \> **Appearance** に移動して、テーマを切り替えます。

**主なハイライト:**

- **カスタマイズ可能なテーマ**: 環境や個人の好みに合わせて、Light モードと Dark モードから選択できるようになりました。
- **システムとの同期**: インターフェイスをシステムまたはブラウザーの設定と自動的に同期させ、昼と夜でシームレスに切り替えることができます。
- **統一されたエクスペリエンス**: ダークモードは、すべてのデータセンターで新しいナビゲーションを使用しているすべてのユーザーが利用できます。

詳細については、[プロファイルの管理](/ja/user-guide/getting-started/initial-setup/manage-your-profile#appearance) を参照してください。

## In-App と OSM のキャンペーン対象資格の再評価

MoEngage は、In-app Messaging と On-site Messaging (OSM) に、キャンペーンの対象資格をリアルタイムで再評価する機能を導入しました。これにより、ユーザーはアプリを再起動することなく、現在のステータスに基づいて常に最も関連性の高いコンテンツを確認できます。

<Note>
  この機能を使用するには、In-app Android SDK バージョン 9.7.0\+ または iOS SDK バージョン 7.04.0\+ を使用していることを確認してください。
</Note>

**Re-evaluate campaign eligibility before displaying** トグルを有効にすると、トリガーが発生したときに SDK がバックエンドでライブチェックを実行します。セッション中にユーザーの属性が変化した場合 (「Free」から「Paid」へのアップグレードなど)、SDK は古いキャンペーンを自動的に破棄し、新しい状態に関連するコンテンツを取得します。

詳細については、[キャンペーン対象資格の再評価](/ja/user-guide/campaigns-and-channels/in-app-message/create/create-in-app-campaign#campaign-audience-limit) を参照してください。

## On-site Messaging 向けノーコードゲーミフィケーション

MoEngage は On-site Messaging (OSM) 向けにノーコードのゲーミフィケーションテンプレートを導入し、**Spin the Wheel** や **Scratch Cards** などのインタラクティブなエクスペリエンスを Web サイトにもたらしました。

これらのテンプレートは使いやすいエディター内で完全にカスタマイズでき、コードを記述することなく魅力的なエンゲージメントキャンペーンをデザインできます。これらのテンプレートを使用して、楽しくインタラクティブなインターフェイスでリワードを提供することで、リードの獲得、クーポンの配布、コンバージョン率の向上を実現できます。

隠れた割引を明らかにするバーチャルな「スクラッチ」でも、サインアップを促す賞品ホイールでも、これらのテンプレートは Web サイトの訪問者に記憶に残るエクスペリエンスを提供するのに役立ちます。

詳細については、[OSM のノーコードゲーミフィケーションテンプレート](/ja/user-guide/campaigns-and-channels/on-site-message/create/no-code-gamification-templates-osm) を参照してください。

## Flows の機能強化: ローカライズされた統計とリアルタイムセグメント

MoEngage は、ローカライズされた精度とリアルタイムの実行によって Flows をアップグレードしました。これらの機能強化により、タイムゾーンの混乱やデータ更新の遅延が解消され、キャンペーンのトリガーとレポートが完全に正確になります。

**主なハイライト:**

- **App Timezone でのレポート**: Flow の統計が、GMT ではなく設定した App Timezone に合わせられるようになりました。手動で計算することなく、実際の営業時間に合わせてパフォーマンスを監視できます。
- **リアルタイムのカスタムセグメント**: Real-Time Segment Engine (RTSE) を拡張し、Custom Segments をカバーするようにしました。条件を満たしたユーザーは、以前の 3 時間の更新サイクルを経ずに、即座に Flows に入るようになりました。
- **シームレスな移行**: 新しい Flows は自動的にローカルのタイムゾーンを採用し、既存のアクティブな Flows はデータの継続性のために GMT を維持します。
- **パフォーマンスの最適化**: 対象となるキャンペーンは、次回の編集と再公開時に自動的にリアルタイム実行にアップグレードされます。

詳細については、[フローの分析](/ja/user-guide/flows-cross-channel-messaging/analyze-flows/analyze-a-flow) を参照してください。

## Flows の機能強化: 直感的な Conditional Stages

MoEngage は Conditional Stages を再設計し、複雑なカスタマージャーニーをより速く、より視覚的に構築できるようにしました。設定ロジックを簡素化し、柔軟な編集ツールを追加することで、フローのオーケストレーションにおける技術的な障壁を取り除きました。

**主なハイライト:**

- **視覚的な設定**: 複雑なドロップダウンリストを、2 ステップのセットアップと視覚的なタイムスライダーに置き換えました。直感的なタイムライン上で、「何を」探すか、「いつ」それが発生すべきかを簡単に定義できるようになりました。
- **ブランチの即時複製**: Conditional Splits でのワークフローをスピードアップします。既存のブランチをワンクリックで複製し、ロジックをゼロから作り直すことなく、さまざまな属性値をすばやくテストできます。
- **ドラッグ & ドロップでの並べ替え**: ブランチの優先順位を完全に制御できます。ブランチをドラッグして簡単に並べ替えることができ、希望するロジックの階層に基づいてユーザーが正しいパスに入るようにできます。
- **Classic View トグル**: 柔軟性も引き続き重視しています。従来の設定インターフェイスを好む場合は、いつでも「Classic View」に戻すことができます。

詳細については、[Flows でのユーザーの分岐](/ja/user-guide/flows-cross-channel-messaging/create/conditions-and-controls-in-flows/branching-of-users-in-flows) を参照してください。

## WhatsApp Analytics and Info の刷新: より深いインサイトと詳細な追跡

MoEngage は WhatsApp Info and Analytics ダッシュボードを刷新しました。WhatsApp キャンペーンから、より豊富で実用的なインサイトを引き出せるよう設計された強力な新ツールを導入しています。

**主なハイライト:**

- **合計指標とユニーク指標:** 合計アクションとユニークユーザーのインタラクションを明確に区別することで、真のエンゲージメントリーチをより正確に把握できます。
- **柔軟なデータビュー:** **Number view** (実数) と **% view** (コンバージョン率) を即座に切り替えて、必要な形でデータを分析できます。
- **合理化されたクリック分析:** 視覚的なノイズを減らすために、Click Analysis を専用のタブに移動しました。これにより、メインダッシュボードを煩雑にすることなく、リンクのパフォーマンスだけに集中できます。

詳細については、[WhatsApp キャンペーンの分析](/ja/user-guide/campaigns-and-channels/whatsapp/analyze/analyze-whatsapp-campaign) を参照してください。

## Suppression Updates によるメールコンプライアンスの効率化

新しい **Suppression Updates** 機能で、グローバルなメールサブスクリプションリストを維持し、送信者の評価を守りましょう。このアップデートは、オプトアウトしたユーザー、バウンスしたユーザー、苦情を申し立てたユーザーがマーケティングメールを受信しないよう確実に制限するための、強力なセルフサービスツールを提供します。

**主なハイライト:**

- **簡単な移行のための一括インポート:** 従来の ESP から移行する場合は、過去の抑制リスト (バウンス、配信停止、スパム苦情) を CSV でシームレスに一括インポートし、初日から送信者の評価を守ることができます。
- **セルフサービスのステータス管理:** リストを完全に管理できます。セルフサービスが有効なワークスペースでは、サポートチケットを作成することなく、個々のユーザーの配信停止や再登録を直接行えます。
- **トランザクションメールの保護:** OTP やパスワードのリセットなど、重要で緊急性の高いアラートをブロックすることなく、マーケティングキャンペーン向けの厳格なグローバル抑制リストを維持できます。
- **SendGrid との自動同期:** MoEngage Managed Email を使用している場合、到達可能性の更新が自動的に SendGrid に反映されるため、手動の作業なしで非トランザクションの送信者を完全にコンプライアンスに準拠した状態に保てます。
- **詳細なイベントトラッキング:** ユーザーの抑制ステータスが変更されるたびに、MoEngage は正確なシステムイベント (_Email Resubscribed_、_Email Bounce Reset_、_Email Complained_ など) を自動的に生成するようになりました。

詳細については、[Suppression Updates](/ja/user-guide/campaigns-and-channels/email/getting-started-with-email/suppression-updates) を参照してください。

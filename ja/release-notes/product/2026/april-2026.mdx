## Merlin AI Campaign Insight Agent

MoEngage は Merlin AI Campaign Insight Agent を導入しました。このエージェントは、1 回限りおよび定期の Push キャンペーンと Email キャンペーンについて、キャンペーンの指標をわかりやすい言葉による説明と実行可能な次のステップに変換します。配信リスクのシグナルを提示し、現在のパフォーマンスを過去の送信と比較してベンチマークし、最適化の機会に関する推奨事項を提供します。これにより、チームはさまざまなダッシュボードを行き来する時間を削減し、インサイトに基づくアクションに集中できます。

詳細については、[Campaign Insight Agent](/ja/user-guide/ai-and-intelligence/merlin-ai/campaign-insights-agent) を参照してください。

## Just-in-Time ユーザープロビジョニング

MoEngage は、SSO が有効なワークスペースで **Just-in-Time (JIT) ユーザープロビジョニング** をサポートするようになりました。チームメンバーが初めて SSO でログインすると、ワークスペースのアカウントが ID プロバイダーから自動的に作成または更新されます。手動での招待は不要です。これにより、設定した期間限定のアクセスポリシーを含め、アクセス権が企業の ID ルールに沿った状態に保たれます。

詳細については、[Just-in-Time ユーザープロビジョニング](/ja/user-guide/settings/account/security/just-in-time-user-provisioning-jit) を参照してください。

## Background Update Push テンプレート

MoEngage は _Background Update Push Template_ をサポートするようになりました。表示される通知をトリガーすることなく、カスタムのキーと値のデータペイロードをアプリに直接配信できます。

このテンプレートは標準的なプッシュキャンペーンの設定を使用し、送信前にペイロード全体をプレビューできます。Android と iOS の両方で、1 回限り、定期、イベントトリガー型、Flows のキャンペーンをサポートしています。

**主な機能:**

- **サイレント配信**: プッシュ通知をオプトアウトしたオーディエンスにも、邪魔をすることなくリーチできます。
- **バックグラウンドアクション**: バックグラウンドでシームレスにアプリの状態を更新したり、機能フラグを更新したり、セキュリティ関連のワークフローをトリガーしたりできます。

詳細については、[Push テンプレート](/ja/user-guide/campaigns-and-channels/mobile-push/create/push-templates#background-update) を参照してください。

## パートナーエコシステムへの新たな追加

MoEngage は、いくつかの追加によってパートナーエコシステムを拡大しました。

- **Connected sources**: Behamics、Adapty、Zoho Landing により、インテント、サブスクリプション、リードのシグナルをユーザープロファイルとジャーニーに取り込めます。
- **広告オーディエンスの接続**: Amazon Ads と Microsoft Ads がオーディエンスの送信先として利用可能になりました。
- **サーバーサイドのコンバージョン配信**: Meta、TikTok、Snapchat、Microsoft Ads がサーバーサイドのコンバージョン API をサポートするようになりました。
- **Adobe Experience Manager (AEM) Experience Fragments**: AEM から複数ロケールのコンテンツをメールテンプレートとして直接同期できます。

パートナーのセットアップガイドについては、[パートナーガイド](https://partners.moengage.com) を参照してください。

## ユーザーごとのプライマリデバイスと Device Opt-Out API

MoEngage は、デバイスレベルでプッシュを制御するための 2 つの機能を導入しました。

- **ユーザーごとのプライマリデバイス**: ユーザーが最後にログインしたデバイスをマークし、Push、Inform、Flows、API 全体で送信をそのデバイスに制限できるようにします。これは、機密性の高いアラートや、ユーザーのタブレットとスマートフォン間での重複送信を減らす場合に便利です。
- **Device opt-out API**: [API](https://www.moengage.com/docs/api/device/device-opt-out) を通じて、特定のデバイスがプッシュ通知を受信することをブロックまたはブロック解除できます。これは、不正検出やデバイス紛失のシナリオに対応します。

詳細については、[ユーザーごとのプライマリデバイス](/ja/user-guide/campaigns-and-channels/mobile-push/notification-features-and-behavior/primary-device-per-user) を参照してください。

## カスタムセグメントの名前変更

**All Segments** ページまたはセグメントの詳細ビューから、カスタムセグメントの名前を変更できるようになりました。セグメント ID は変更されないため、既存の API 呼び出し、自動化、統合は変更なしで引き続き機能します。名前が変更されたセグメントは、ナビゲーション、最近のクエリ、キャンペーンビュー、編集履歴、監査エントリ全体に反映されます。

詳細については、[カスタムセグメントの名前変更](/ja/user-guide/segment/create-segments/manage-segments#renaming-a-custom-segment) を参照してください。

## All Campaigns ページと All Flows ページの改善

MoEngage は、**All Campaigns** ページと **All Flows** ページを次のように改善しました。

- データの読み込み中にシマープレースホルダーが表示されるため、取得中にリストが空の状態や誤解を招く状態で表示されなくなりました。
- アクティブなフィルターに一致する結果がない場合は、専用の空の状態のイラストが表示されます。
- **All**、**Active**、**Schedule** タブを切り替えても、検索テキストとフィルターの選択が保持されます。
- 検索ボックス内の検索アイコンがクリック可能になりました。

以前は、All Campaigns ページで結果の読み込み中に「No campaign found」メッセージが表示されることがありました。現在は、データの読み込みが完了するまで待ってから空の状態を表示します。

# 新しいゲーミフィケーションテンプレート: スクラッチカードとカウントダウンタイマー

MoEngage は、In-app Messaging 向けのノーコードゲーミフィケーションテンプレートのラインナップを拡充しています。

**Spin the Wheel** に加えて、**Scratch Cards** と **Countdown Timers** を作成できるようになりました。これらの新しいテンプレートも使いやすいエディターで完全にカスタマイズでき、コードを記述したりアプリの SDK を更新したりすることなく、魅力的なキャンペーンをデザインできます。

これらの強力な機能を活用して、ユーザーエンゲージメントの向上、リワードの配布、リードの獲得、緊急性の演出によるコンバージョンの促進を実現しましょう。

詳細については、[ノーコードゲーミフィケーションテンプレート](/ja/user-guide/campaigns-and-channels/in-app-message/templates/no-code-gamification-templates) を参照してください。

# Merlin AI: ブランドスタイルガイドライン

Merlin AI は、コンテンツの不統一をなくすために Brand Style の学習機能を導入しました。この機能は、過去のキャンペーンからトーン、カラーパレット、ビジュアルスタイルなど、ブランド独自の DNA を自動的に学習し、生成されるすべてのコピーと画像がブランドに完全に沿ったものになるようにします。

詳細については、[Merlin AI Copywriter](/ja/user-guide/ai-and-intelligence/merlin-ai/merlin-ai-copywriter/merlin-ai-copywriter) と [Merlin AI Designer](/ja/user-guide/ai-and-intelligence/merlin-ai/merlin-ai-designer/merlin-ai-designer) を参照してください。

# Merlin AI Designer: 新しい AI モデルで完璧な画像をより高速に生成

Merlin AI Designer は Google の Nano Banana AI モデルと統合され、世界最高水準の画像生成および編集機能をキャンペーンにもたらします。このアップグレードにより、優れた画質、完璧な商品レンダリング、卓越したスピードが実現し、プロフェッショナルでブランドに沿ったバナーを 20 秒以内に作成できます。

詳細については、[Merlin AI Designer](/ja/user-guide/ai-and-intelligence/merlin-ai/merlin-ai-designer) を参照してください。

# Flows でのトリガーイベントのパーソナライゼーション

MoEngage は、キャンペーンメッセージを強化するために *Trigger Event Personalization* を導入しました。この機能により、MoEngage Flows で使用するイベントデータを正確に制御でき、メッセージの一貫性と関連性を常に確保できます。

詳細については、[Flows でのパーソナライゼーション](/ja/user-guide/flows-cross-channel-messaging/create/actions-in-flows/personalization-in-flows) を参照してください。

# Zendesk と Heap の統合

Zendesk と Heap Analytics のカスタマーサポートデータと行動データを、MoEngage に直接シームレスに同期できるようになりました。この統合によりリアルタイムのデータフローが可能になり、データのサイロ化を解消して統合された顧客プロファイルを構築し、サポート履歴やユーザーアクションに基づいたトリガーベースの高度にパーソナライズされたキャンペーンを実施できます。

詳細については、以下の記事を参照してください。

- [Zendesk](/ja/partner-guide/support-and-service/support/zendesk)
- [Heap](/ja/partner-guide/data-and-analytics/analytics/heap-analytics)

# カスタムフォント

MoEngage は、完全にセルフサービスで利用できる Custom Font Management 機能をリリースし、サポートチームやエンジニアリングチームへの依頼を不要にしました。この機能強化により、マーケターはブランドフォントを直接アップロードし、クライアントとの互換性を確認し、優先順位付きのフォールバックフォントを定義できます。これにより、すべてのメールクライアントでブランドの一貫性と適切なフォールバック表示が確保されます。最終的には業務効率が向上し、メールにおけるブランドのビジュアルアイデンティティを即座に完全にコントロールできるようになります。

詳細については、[カスタムフォント](/ja/user-guide/campaigns-and-channels/email/getting-started-with-email/custom-fonts) を参照してください。

# UI の更新: RCS が独立したチャネルに

MoEngage は、RCS を SMS とは別の独立したチャネルとして正式に位置付ける大規模な UI 更新を展開しました。この変更では、新しい RCS チャネルタイルの導入、SMS フォールバックオプションの Step 2 への移動、関連するすべてのキャンペーンタイプとフィルターの「RCS」への名称変更を行い、プラットフォームの明確さと一貫性を高めています。これは UI の更新であり、既存のキャンペーン、アクティブなキャンペーン、下書きのキャンペーンはすべて中断なく引き続き機能します。

詳細については、[RCS](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/rcs) を参照してください。

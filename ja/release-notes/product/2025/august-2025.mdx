# Dynamic Content Personalization

<Note>
これは Early Access 機能です。アカウントで有効にするには、MoEngage のカスタマーサクセスマネージャー(CSM)またはサポートチームにお問い合わせください。
</Note>

*Dynamic Content Personalization* 機能は、コード不要のビジュアルインターフェイスで複雑な if-else ロジックを構築し、1つのマスターキャンペーンから複数の固有のエクスペリエンスを提供できるようにすることで、メッセージ作成を変革します。

この機能により、コードを書かずに、高度なデータ主導のパーソナライゼーションを構築できます。ロジックを再利用可能な「チップ」にまとめることで、キャンペーン全体の一貫性を確保し、貴重な時間を節約し、手作業によるエラーの可能性を低減できるため、より関連性が高く魅力的なユーザーエクスペリエンスにつながります。

Dynamic Content Personalization では、次のことができます。

- 直感的なビジュアルインターフェイスを使用して、複雑な if-else ロジックを構築できます。
- プロモーションバナー、行動喚起、製品レコメンデーションなどのコンテンツを、オーディエンスセグメントごとにパーソナライズできます。
- パーソナライゼーションロジックを「チップ」として保存・管理し、複数のキャンペーンやチャネルで再利用できます。

詳細については、[Dynamic Content Personalization](/ja/user-guide/campaigns-and-channels/getting-started/message-personalization/dynamic-content-personalization)を参照してください。

# Message Archival の新しい送信先

*Message Archival* 機能が送信先として SFTP をサポートするようになりました。これにより、Email、SMS、Push キャンペーンの完全なメッセージコンテンツとユーザーの詳細を、独自の SFTP サーバーに安全かつ自動的に直接エクスポートできます。

この機能により、組織はすべてのコミュニケーションの完全な長期記録を維持することで、厳格な法規制上のコンプライアンス要件を満たすことができます。手作業によるデータ収集が不要になり、監査、ビジネスインテリジェンス、社内データアーカイブのプロセスが効率化されます。

MoEngage SFTP Message Archival では、次のことができます。

- すべてのコミュニケーションをアーカイブすることで、法規制上のコンプライアンス要件を満たせます。
- 履歴データを使用して、カスタマーサービスのやり取りの品質監査を実施できます。
- メッセージコンテンツを分析して、ビジネスインテリジェンスや顧客のトレンドを明らかにできます。
- 過去の参照や eDiscovery のために、検索可能な長期アーカイブを維持できます。

詳細については、次の記事を参照してください。

- [ファイルパスと命名規則](/ja/user-guide/campaigns-and-channels/campaign-management-and-reports/message-archival/file-path-and-naming-convention)
- [ファイルの内容](/ja/user-guide/campaigns-and-channels/campaign-management-and-reports/message-archival/file-contents)

# キャンペーン下書きの有効期限の延長

MoEngage の *Campaign Drafts* 機能では、Campaigns、Flows、Experiences を含むすべての下書きが、180日間の延長期間にわたって保持されるようになりました。

下書きが早期に期限切れになるのを防ぐことで、計画サイクルの柔軟性が向上します。複雑な作業をやり直す必要がなくなるため、チームは十分なレビューと承認に必要な時間を確保できます。

このアップデートにより、次のことが可能になります。

- 関係者によるレビューと承認により多くの時間を充てられます。
- 期限のプレッシャーなしにキャンペーンをテストし、改善できます。
- より長い計画サイクルや季節キャンペーンに対応できます。
- 手戻りを減らし、生産性を向上できます。

詳細については、[キャンペーンの下書き](/ja/user-guide/campaigns-and-channels/getting-started/introduction/campaign-drafts)を参照してください。

詳細については、[Flow の作成](/ja/user-guide/flows-cross-channel-messaging/create/create-flows/create-a-flow)を参照してください。

# メールの開封分析と到達率分析

MoEngage は、マーケターがメールのパフォーマンスをこれまでにないほど詳細に把握できる2つの新しい分析機能をリリースしました。この機能群は基本的な指標にとどまらず、メールがどのように、どこで開封されたかを正確に把握するのに役立ち、個々のメールボックスプロバイダーごとの到達率の内訳も提供します。

- **Open Analysis**: デバイス、ブラウザー、オペレーティングシステムごとの内訳から、オーディエンスのエンゲージメントを把握できます。これにより、推測に頼ることなく、オーディエンスの好みに合わせたメールをデザインできるようになります。
- **Deliverability Analysis**: 集計指標にとどまらず、配信からエンゲージメントまでのメールファネル全体を、Gmail、Outlook、Yahoo などの個々のメールクライアント別に確認できます。

詳細については、[Email Analytics と情報](/ja/user-guide/campaigns-and-channels/email/analyze/email-analytics-and-info)を参照してください。

詳細については、[MoEngage でユーザーを検索する](/ja/use-cases/segmentation/find-users-in-moengage)を参照してください。

# BigQuery Imports

MoEngage は BigQuery Imports を導入しました。Google BigQuery データウェアハウスから MoEngage に、ユーザープロファイルとイベントをシームレスに直接同期できるようになりました。これにより、キャンペーンにリアルタイムの統合された顧客データを活用できます。

詳細については、[Google BigQuery](https://partners.moengage.com/hc/en-us/articles/7403404539412-Google-BigQuery)を参照してください。

# SMS キーワード管理のアップグレード

MoEngage は、制御と可視性を向上させるため、SMS キーワード管理に次のアップグレードを提供します。

- **リードの獲得**: キーワードをテキスト送信した新しい電話番号に対して、ユーザープロファイルを自動的に作成します。
- **重複の防止**: 新しい Status トグルにより、アクティブな場合にのみ自動応答が送信されるため、メッセージの重複を防げます。
- **パフォーマンスの追跡**: 自動応答ごとに新しい SMS Keyword Response Sent イベントが記録されるため、キャンペーンのパフォーマンスを完全に把握できます。
- **コンプライアンスの自動化**: Keyword Management を有効にすると、Subscription Management が自動的に有効になり、コンプライアンス対応が効率化されます。
- **一般応答**: 特定のキーワードに一致しない受信テキストに対して、デフォルトの一般応答メッセージを構成できます。

詳細については、[サブスクリプションとキーワードの構成](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/other-settings/configure-subscription-and-keywords)を参照してください。

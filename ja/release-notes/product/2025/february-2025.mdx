# Primary Device Per User

*Primary Device Per User* 機能を使用すると、ユーザーが最後にアクティブだったデバイスにのみプッシュ通知を送信できるため、機密性の高い通知を受信する際のプライバシーを保護できます。この機能は、Push キャンペーン(Campaigns API の使用を含む)、Push ステージを含む Flows、Push チャネルを使用する Inform アラート(Inform API の使用を含む)にのみ適用されます。

詳細については、[Primary Device Per User](/ja/user-guide/campaigns-and-channels/mobile-push/notification-features-and-behavior/primary-device-per-user)を参照してください。

# Gmail アノテーション

MoEngage は Gmail アノテーションを導入しました。アノテーションを使用すると、顧客は受信トレイからプロモーションを手軽に確認し、操作できます。メールにアノテーションを付けると、画像、特典、有効期限などの要素が組み込まれ、プロモーションフォルダー内のメールのコンテンツが強化されます。顧客はメールを開かなくても、これらの情報に直接アクセスできます。メールにアノテーションを付けて、Gmail の **Promotions** タブに次の機能を表示できます。

- 特典のアノテーション
- 製品カルーセル

詳細については、[Gmail アノテーション](/ja/user-guide/campaigns-and-channels/email/create/gmail-annotations)を参照してください。

# Recommendations API

MoEngage は Recommendations API を導入しました。この API を使用すると、ユーザーのレコメンデーション結果を MoEngage エコシステムの外部にエクスポートできます。この API では、レコメンデーション ID を使用して、レコメンデーションに関連付けられたメタデータを取得できます。メタデータには、レコメンデーション名、モデルタイプ、ステータス、作成日時と更新日時などが含まれます。

詳細については、[Recommendations API](https://www.moengage.com/docs/api/recommendations/recommendations-overview)を参照してください。

# Templates

MoEngage は、テンプレートの作成、整理、アクセス制御を効率化する高度な機能である *Templates* を導入しました。この機能は、チャネルを問わずすべてのテンプレートの依存関係を管理するための一元化された環境を提供し、キャンペーンの作成時にテンプレートを活用する高度な機能も提供します。

#### **メリット:**

- WYSIWYG エディターと HTML エディターで、テンプレートを簡単に作成・編集できます。
- テンプレートをフォルダーに整理し、チーム間で共有できます。
- テンプレートのフィルタリング、並べ替え、検索の機能が向上します。
- ロールと権限に基づいて、テンプレートのアクセス制御を強化できます。
- テンプレートの変更とバージョン管理をより適切に追跡できます。
- テンプレートマネージャーを外部システムに接続し、テンプレート API を使用してテンプレートを取り込んだり取得したりできます。
- 同様のインターフェイスでキャンペーン作成時にテンプレートとフォルダーを利用できるため、テンプレートをシームレスに使用できます。

詳細については、[Templates のドキュメント](/ja/user-guide/content/template/templates)を参照してください。

# Warehouse Segments での Databricks

MoEngage は、Warehouse Segments に Databricks を導入しました。ユーザーは、Databricks 内のデータをコピーしたり移動したりする手間なく、MoEngage ダッシュボードから直接すばやくアクセスして活用できます。この機能により、ワークフローが簡素化され、オーディエンスとのタイムリーなエンゲージメントが可能になります。

#### **主な機能:**

- **Query results:** 最近実行したウェアハウスクエリを、実行時間、スキャンされたデータ量、特定のクエリによって返されたデータの行数などのクエリ指標とともに一覧表示します。
- **Sample results:** クエリが成功すると、Query results セクションの行を展開して、各クエリのサンプル結果を確認できます。
- **Preview table:** スキーマセクションに表示されている任意のテーブルのサンプル行を、ワンクリックでプレビューできるようになりました。

詳細については、[Warehouse Segment のドキュメント](/ja/user-guide/segment/create-segments/warehouse-segments#step-1-set-up-your-data-source)を参照してください。

# Viber 統合

MoEngage は Viber との統合を強化しました。高度なセグメンテーション、予測機能、パーソナライゼーション、トリガー機能を活用して、Viber API を通じて Viber Bot 上のユーザーにメッセージを送信できます。

詳細については、[Viber](https://partners.moengage.com/hc/en-us/articles/4848015684116-Viber#step-3-create-connector-campaign-on-moengage-to-send-viber-message-0-5)を参照してください。

詳細については、[Flows の Next Best Action](/ja/user-guide/flows-cross-channel-messaging/create/intelligence-in-flows/next-best-action-in-flows)を参照してください。

# Jinja AI Assistant

MoEngage は、クエリに基づいて Jinja コードを記述するのに役立つツール、Jinja AI Assistant を導入しました。Jinja AI は、ロジックステートメントを含む構造化されたプロンプトを Jinja コードに変換します。

詳細については、[こちら](/ja/user-guide/ai-and-intelligence/merlin-ai/merlin-ai-jinja-generator)を参照してください。

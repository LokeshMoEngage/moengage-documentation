# Portfolio

_Portfolio_ 機能を使用すると、複数のアプリケーションや Web サイトを、単一の統合された MoEngage ワークスペース内の個別の _プロジェクト_ として管理できます。

この機能は、すべてのデジタルプロパティのユーザーデータを 1 つの顧客プロファイルに統合します。この統合ビューにより、ブランド横断的な戦略の実施、キャンペーン管理の効率化、ポートフォリオ全体のパフォーマンス分析が可能になります。

Portfolio は次のことに役立ちます。

- すべてのアプリと Web サイトのユーザーデータを 1 つの顧客プロファイルに統合する。
- ポートフォリオ全体のユーザー行動に基づいてセグメントを構築し、キャンペーンをトリガーする。
- 単一のダッシュボードから、すべてのプロパティのパフォーマンスを分析し、キャンペーンを管理する。
- すべてのブランドにわたってコミュニケーションの頻度を制御し、メッセージ疲れを防ぐ。

詳細については、以下の記事を参照してください。

# 構築済み HTML Nudge テンプレートの導入

MoEngage は、In-app Messaging キャンペーン向けに構築済みの HTML Nudge テンプレートのセットを導入しました。

Nudge は画面の上部または下部に表示される控えめなメッセージで、アプリのエクスペリエンスを妨げることなくユーザーとコミュニケーションを取ることができます。

これらのテンプレートは In-App HTML エディター内で直接完全にカスタマイズでき、フィードバックアンケート、プロモーションアラート、緊急のお知らせなど、美しくインタラクティブなキャンペーンを数分で開始できます。このアップデートにより、ゼロから作成する必要がなくなり、時間を節約しながらユーザーのインタラクションを高めることができます。

詳細については、[HTML Nudge テンプレート](/ja/user-guide/campaigns-and-channels/in-app-message/templates/html-nudge-templates) を参照してください。

# アプリ内メッセージ向けノーコードゲーミフィケーションテンプレート

MoEngage は、In-app Messaging キャンペーン向けにノーコードのゲーミフィケーションテンプレートのセットを導入しました。アプリをこれまで以上にインタラクティブで魅力的なものにするよう設計されています。

**Spin the Wheel** を使用して、ゲーミフィケーションエクスペリエンスを簡単に作成して開始できるようになりました。このテンプレートは使いやすいエディターで完全にカスタマイズでき、コードを記述したりアプリの SDK を更新したりすることなく、魅力的なキャンペーンをデザインできます。

この強力な新機能は、楽しく記憶に残るユーザーエクスペリエンスを提供しながら、ユーザーエンゲージメントの向上、リワードの配布、リードの獲得、緊急性の演出によるコンバージョンの促進に役立ちます。

詳細については、[ノーコードゲーミフィケーションテンプレート](/ja/user-guide/campaigns-and-channels/in-app-message/templates/no-code-gamification-templates) を参照してください。

# SMS キャンペーン設定の完全な透明性

_GET SMS Campaign Details_ API を使用すると、スタンドアロンキャンペーンと Flows 内のキャンペーンの両方について、設定とコンテンツの詳細をプログラムで取得できます。

この API を使用してキャンペーンデータを社内ツールと統合し、ガバナンスを自動化して手動での監視を減らすことができます。これにより、コンプライアンスチェックが改善され、クリエイティブアセットが一元化され、承認ワークフローが効率化されます。

_GET SMS Campaign Details_ API は次のことに役立ちます。

- 特定のキャンペーンまたはフィルタリングされたキャンペーンのリストを取得する。
- ブランドおよび法的コンプライアンスのためのコンテンツ監査を自動化する。
- アーカイブ用に SMS のコピーを中央リポジトリに取得する。
- キャンペーンのコンテンツを社内の承認ワークフローと統合する。

詳細については、[SMS キャンペーンの詳細の取得](https://www.moengage.com/docs/api/get-campaign-details/search-campaigns) を参照してください。

# User Lookup

_User Lookup_ 機能は、キャンペーン分析内の診断ツールで、プッシュ通知の配信状況を透明性の高いビューで提供し、キャンペーン内の特定ユーザーのジャーニーを調査できるようにします。

この機能により、特定の配信シナリオを正確に診断できます。任意のユーザーの詳細なタイムラインを提供することで、未配信の正確な理由を特定したり、オーディエンスのセグメンテーションを検証したりできます。これにより、キャンペーンの実行に自信を持つことができ、重要なメッセージが意図した受信者に確実に届くようになります。

_User Lookup_ 機能は次のことに役立ちます。

- 個々のユーザーが予期した通知を受け取らなかった理由を正確に調査する。
- 特定のユーザーがキャンペーンのオーディエンスに含まれた理由を検証し、セグメンテーションロジックを確認する。
- 対象資格のチェックから最終的なクリックまで、詳細なステップごとの配信タイムラインを分析する。

詳細については、[User Lookup](/ja/user-guide/campaigns-and-channels/mobile-push/analyze/push-debug) を参照してください。

# Dynamic Sender Routing

Dynamic Sender Routing は、API リクエストごとに最適な送信者を自動的に選択するカスタマイズされたルーティングシステムです。ユーザー属性や API 属性に基づいてカスタムルーティングルールを定義することで、到達率を向上させるためにメッセージングを最適化し、送信コストをより効果的に管理し、現地の規制へのコンプライアンスを確保できます。

詳細については、[Dynamic Sender Routing](/ja/user-guide/inform/advanced-concepts/dynamic-sender-routing) を参照してください。

# Analytics での Teams

MoEngage は、MoEngage Analytics スイートに Teams 機能を導入しました。

Behavior、Funnels、Retention などの Analytics モジュールや、Custom Dashboards、My Studio でチームを選択できるようになりました。この操作により、すべてのデータとレポートが自動的にフィルタリングされ、そのチームで定義されたユーザーに関連する分析のみが表示されます。

詳細については、[MoEngage の Teams 2.0](/ja/user-guide/settings/account/team-management/teams-20-in-moengage) を参照してください。

# Split-By 分析のテーブルビューの改善

MoEngage は、分析テーブルの読みやすさを向上させるユーザーエクスペリエンスの機能強化をリリースしました。

以前は、複数の「split-by」属性を使用して分析を実行すると、テーブルビューではすべての値が 1 つのカンマ区切りの列にまとめられていました。この問題を修正しました。現在は、分割に使用する各属性に専用の列が割り当てられるため、データが整理されて読みやすくなります。

このアップデートにより、乱雑に詰め込まれたデータが解消され、データをエクスポートすることなく結果をより効率的に分析できます。この改善は、Users、Behaviour、Funnels、Retention、Session Source の分析で利用できるようになりました。

# オブジェクトデータ型の Value Suggestions

MoEngage は、オブジェクトデータ型に対する _Value Suggestions_ のサポートを導入しました。

これまでも Value Suggestions は文字列や数値の値を提案してきましたが、この機能を複雑なオブジェクト属性にも拡張しました。セグメントを作成する際に、オブジェクト内の特定の値を検索できるようになりました。

詳細については、[Value Suggestions](/ja/user-guide/segment/advanced-concepts/value-suggestions) を参照してください。

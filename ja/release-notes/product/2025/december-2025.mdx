# Actionable Analytics

*Actionable Analytics* が更新され、チャートビューに新しい機能が追加されました。棒グラフの棒や折れ線グラフの点など、特定のデータポイントをクリックして、拡張されたアクションメニューにアクセスできるようになりました。

新しいオプションには、データを即座に検証するための **View sample users** と、データを直接取得するための **Export users** があり、セグメントやキャンペーンの作成などの既存の機能とあわせて利用できます。

詳細については、[Actionable Analytics](/ja/user-guide/analyze/analytics/actionable-analytics)を参照してください。

# Computed Traits

Computed Traits は、既存のイベントデータに計算を適用して、動的なユーザー属性を作成できる新機能です。この機能を使用すると、ライフタイムバリュー(LTV)、総注文数、コンテンツの好みなどの複雑な指標をプラットフォーム内で直接定義・追跡できるため、手動でのデータアップロードや追加の開発者リソースが不要になります。

主なハイライト:

- **柔軟な計算方法**: 標準ロジック(Count、Aggregation、First/Last Value)を使用してトレイトを生成するか、SQL を使用して高度なカスタム計算を行えます。
- **自動更新**: 計算を1回限りまたは定期的(毎週または毎月)に実行するようスケジュールして、リアルタイムの行動に基づいてユーザーデータを常に最新の状態に保てます。
- **シームレスな統合**: 作成した Computed Traits は標準のユーザー属性として機能し、セグメンテーション、キャンペーンのパーソナライゼーション、ワークフローですぐに使用できます。

詳細については、[Computed Traits](/ja/user-guide/data/computed-traits/computed-traits-overview)を参照してください。

# Merlin AI による AI 機能の統合

MoEngage は、予測、生成、意思決定のすべての AI 機能を、Merlin AI という単一のスイートに統合しました。このアップデートにより、すべての既存機能を維持しながら、以前の Sherpa AI ブランドが置き換えられ、プラットフォーム全体で一貫した製品アイデンティティが提供されます。

主なハイライト:

- **予測インサイト**: 予測セグメント、製品レコメンデーション、最適な送信時間の機能にアクセスして、ユーザーパスを最適化し、全体的なユーザーエクスペリエンスを向上できます。
- **生成型の構築ツール**: Copywriter、Designer、Segment Assist、Merlin AI Studio などの生成エージェントを活用して、キャンペーンをより効率的に作成できます。
- **意思決定エージェント**: 新しいオファーおよびキャンペーンの意思決定エージェントを実装して、戦略的なキャンペーンの選択を自動化できます。
- **ブランドの更新**: ダッシュボード、製品ドキュメント、MoEngage Web サイト全体で、新しい Merlin AI ブランドを確認できます。

# Merlin AI Designer: オムニチャネル画像のサポート

Merlin AI Designer にオムニチャネルの画像生成機能が追加され、従来の 21:9 のアスペクト比以外のビジュアルも作成できるようになりました。Merlin AI Studio 内で、主要なマーケティングチャネルや広告チャネルに最適なサイズのビジュアルを直接生成できるようになりました。

主なハイライト:

- **多様なアスペクト比**: MoEngage は 16:9、4:3、1:1、3:4、9:16 の比率のサポートを追加し、メール、On-site Messages、ソーシャルメディアのフィードにビジュアルがシームレスに収まるようにしました。
- **ソーシャル向けの最適化**: TikTok、Reels、Instagram、LinkedIn などの高パフォーマンスなチャネル向けに特別に設計された、最適化されたフォーマットを活用できます。
- **チャネルの汎用性**: MoEngage は、インパクトの大きいプッシュ通知向けに 21:9 フォーマットを維持しながら、モバイルファーストのコンテンツ向けに新しい縦長フォーマットと正方形フォーマットを利用できるようにしました。

詳細については、[Merlin AI Studio](/ja/user-guide/ai-and-intelligence/merlin-ai/merlin-ai-studio)を参照してください。

# Merlin AI Jinja Assistant の機能強化

MoEngage は、複雑なロジックやパーソナライズされたコンテンツの作成を簡素化するため、Merlin AI Jinja Assistant を強化しました。この機能強化により、日付の差の計算や URL のエンコードなど、一般的なマーケティングタスク向けの正確な Jinja クエリを、キャンペーンのワークフロー内で直接生成できます。

主なハイライト:

- **高度な日付と時刻のロジック**: タイムゾーンの変換や日付の差など、日付、曜日、時刻の形式に対応した効率的な Jinja コードを生成できるようになりました。
- **セキュリティとエンコードの強化**: アシスタントは SHA 256 暗号化、Base64 エンコード、URL エンコードをサポートしており、データが安全かつ正しく処理されます。
- **属性処理の改善**:*in* 演算子と *is* 演算子を使用して、配列型の属性をより効果的にクエリできます。
- **カスタムフォーマットとフォールバック**:MoEngage は、取り消し線テキスト、インド式の数値区切り、MOE\_NOT\_SEND の処理のための特定のフォールバック値をサポートしています。

詳細については、[Merlin AI](/ja/user-guide/ai-and-intelligence/merlin-ai)を参照してください。

# Alert Manager 向けの Microsoft Teams および Webhook 統合

Alert Manager 向けの新しい Microsoft Teams および Webhook 統合により、チームの日常のワークフロー内でリアルタイムのマーケティングインサイトを直接受け取れます。この機能を使用すると、重要なパフォーマンスデータやシステムアラートを Microsoft Teams や任意のメッセージングツールに接続できるため、ダッシュボードを頻繁に切り替える必要がなくなり、チームは新たなトレンドに即座に対応できます。この統合は、Enterprise プランの顧客のみが利用できます。

主なハイライト:

- **マルチチャネル接続**: Alert Manager を Microsoft Teams チャネルにシームレスにリンクしたり、柔軟な Webhook を使用して任意のサードパーティのメッセージングツールやプロジェクト管理ツールに更新情報を送信したりできます。
- **包括的なアラートの対象範囲**: キャンペーンのパフォーマンス(開封/クリック)や自動化の健全性から、データ使用量の超過やユーザーアクティビティのトレンドまで、あらゆるものをリアルタイムで監視できます。
- **コラボレーションのワークフロー**: チームがインサイトについてすぐに話し合い、1つのスレッド内で問題を解決できる共有スペースにアラートを取り込むことで、データ主導の文化を育めます。

詳細については、[アラートの作成](/ja/user-guide/settings/reports-and-alerts/alert-management/getting-started/create-an-alert)、[MS Teams のセットアップ](https://partners.moengage.com/hc/en-us/articles/42946320109460-MS-Teams?_gl=1*1vhfsa*_gcl_au*NTM0NjQzNjM3LjE3NjMzNjIyNjIuODg0MDMxMDk1LjE3NjQwNjA4NTcuMTc2NDA2MDg1Nw..*_ga*MTExMjkxMjU1MC4xNzIyOTQ0MjM3*_ga_SEBHW7YTZ7*czE3NjQzMTIxNTYkbzIwNiRnMSR0MTc2NDMyNTcxNCRqNTQkbDAkaDA.#h_01K590BF7VTPXAMPKCZ0K48B5W)、[Slack のセットアップ](https://partners.moengage.com/hc/en-us/articles/42946297014932-Slack?_gl=1*1vhfsa*_gcl_au*NTM0NjQzNjM3LjE3NjMzNjIyNjIuODg0MDMxMDk1LjE3NjQwNjA4NTcuMTc2NDA2MDg1Nw..*_ga*MTExMjkxMjU1MC4xNzIyOTQ0MjM3*_ga_SEBHW7YTZ7*czE3NjQzMTIxNTYkbzIwNiRnMSR0MTc2NDMyNTcxNCRqNTQkbDAkaDA)、および[Webhook のセットアップ](https://partners.moengage.com/hc/en-us/articles/42946297014932-Slack?_gl=1*1vhfsa*_gcl_au*NTM0NjQzNjM3LjE3NjMzNjIyNjIuODg0MDMxMDk1LjE3NjQwNjA4NTcuMTc2NDA2MDg1Nw..*_ga*MTExMjkxMjU1MC4xNzIyOTQ0MjM3*_ga_SEBHW7YTZ7*czE3NjQzMTIxNTYkbzIwNiRnMSR0MTc2NDMyNTcxNCRqNTQkbDAkaDA)を参照してください。

# Push Device Analytics

*Device Analytics* 機能を使用すると、特定のデバイス属性の観点からキャンペーンのパフォーマンスを即座に把握できます。このレポートツールは、大まかな推測をデータに裏付けられた詳細なインサイトに置き換えることで、配信率やクリック率の変動に関する曖昧さを解消します。

この機能により、OEM、OS Version、App Version、Device Recency、Browser などの重要な要素ごとに指標を分割し、パフォーマンスの問題を正確に診断できます。ヒートマップを使用してこれらの要素を相互参照することで、配信率の低さが特定のユーザー構成(特定の OEM の休眠ユーザーなど)によるものかどうかを判断したり、特定のアプリバージョンと OS アップデートの間の統合の問題を発見したりできます。これにより、適切な技術環境に合わせてメッセージングを最適化し、戦略の ROI を検証できます。

*Device Analytics* では、次のことができます。

- OEM、OS Version、App Version、Device Recency(Active と Dormant)、Browser などの主要なディメンション別に、キャンペーン指標を分析できます。
- ヒートマップを活用して、App Version と OS Version を照合するなど2つの要素を同時に相互参照し、SDK や統合の潜在的な問題をデバッグできます。
- 特定の OEM における休眠ユーザーの多さがリーチを低下させていないかなど、配信率低下の正確な原因を特定できます。
- ディープリンク処理の修正や、iOS Provisional Authorization によるコンバージョン率への影響など、最近の最適化の効果を検証できます。

詳細と構成の詳細については、[Push Device Analytics](/ja/user-guide/campaigns-and-channels/mobile-push/analyze/push-device-analytics)を参照してください。

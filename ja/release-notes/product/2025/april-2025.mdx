# My Studio

MoEngage は、中断したところから分析を正確に再開できるよう、**My Studio** に2つの新機能を導入しました。

## Drafts

MoEngage Analytics でデータを分析すると、進行状況が下書きとして自動的に保存されます。これらの下書きには、My Studio ページの **Drafts** タブから簡単にアクセスできます。

詳細については、[こちら](/ja/user-guide/analyze/dashboards/my-studio#drafts)を参照してください。

## Recents

分析の実行中に、進行中の分析にアクセスできるようになりました。**Recent** ボタンには、保存済みクエリと下書きにわたる過去7日間のアクティビティが表示されます。

詳細については、[こちら](/ja/user-guide/analyze/dashboards/my-studio#recents)を参照してください。

# Databricks 統合

MoEngage は、Warehouse Segments 向けに Databricks との直接統合をサポートするようになりました。Databricks ウェアハウスのデータを直接使用して、MoEngage でユーザーセグメントを作成できます。この機能により、次のことができます。

- 既存のデータウェアハウスを使用して、セグメンテーション機能を強化できます。
- データ転送プロセスを不要にすることで、効率を向上できます。
- MoEngage キャンペーン向けに、リアルタイムのデータ主導型オーディエンスを作成できます。

詳細については、[Databricks](/ja/partner-guide/data-and-analytics/data-warehouses/databricks)を参照してください。

# Unified Identity(Identity Resolution)

MoEngage の *Identity Resolution* 機能を使用すると、さまざまなオンラインおよびオフラインのデータソース(Data API、MoEngage SDK、CSV ファイルを介して MoEngage に取り込まれたもの)から取得した、異なる識別子属性(ID、EmailID、Mobile Number など)を使用して、同一ユーザーの複数のプロファイルを統合できます。複数のソースに顧客 ID、メール ID、電話番号などの明確な ID 情報が含まれている場合、これらの属性を識別子として使用して、MoEngage で単一の統合顧客プロファイルを構築できます。これにより、各ユーザーについて信頼できる唯一の情報源が維持され、アプリケーション上でのユーザーの行動をシームレスに追跡し、それに応じてビジネス戦略を設定できます。この機能により、ワークスペースレベルで最大5つの識別子を構成できるようになりました。詳細については、[Unified Identity(Identity Resolution)](/ja/user-guide/data/user-data/unified-identity-identity-resolution)を参照してください。

# ディープリンクドメイン

MoEngage でディープリンクドメインを構成し、メールキャンペーンの作成時に追加できるようになりました。ディープリンクは、アプリをホームページで開くのではなく、アプリ内の特定の場所にユーザーを誘導します。これは、アプリ内の特定のページ、機能、またはコンテンツである場合があります。このように、ディープリンクはよりパーソナライズされたユーザーエクスペリエンスを提供し、ユーザーを特定のアクションに誘導できるため、ユーザーエンゲージメントとコンバージョン率が向上します。詳細については、[ディープリンクドメインの構成](/ja/user-guide/campaigns-and-channels/email/getting-started-with-email/configure-a-deep-linking-domain)を参照してください。

# Snowflake Imports

MoEngage は Snowflake Imports を強化し、Snowflake Views からの直接インポートをサポートするとともに、マルチ ID サポートにより顧客プロファイルを統合できるようにしました。これにより、より強力なカスタマーデータプラットフォーム(CDP)のエクスペリエンスを実現します。

詳細については、[こちら](/ja/user-guide/data/imports/setting-up-a-data-warehouse-import)を参照してください。

# Freshsales CRM 統合

MoEngage は、Connected Sources を介して Freshsales CRM と統合できるようになりました。シームレスなデータ同期により、営業とマーケティングの自動化が強化され、統合された顧客ビューが得られます。詳細については、[Freshsales CRM](/ja/partner-guide/data-and-analytics/crm/freshsales-crm)を参照してください。

# Warehouse Segments での Redshift

Warehouse Segments が Redshift データウェアハウスをサポートするようになりました。これにより、Redshift に保存されているデータをコピーしたり移動したりすることなく、MoEngage から直接アクセスして使用できます。ワークフローを簡素化し、データをよりタイムリーにオーディエンスエンゲージメントに活用できます。

この Redshift 統合で利用できる主な機能は次のとおりです。

- **既存機能との互換性**: Query results、Sample data、Preview table、Actions などのすべての主要機能が Redshift でサポートされています。
- **Query results**: 最近実行したウェアハウスクエリの一覧を確認できます。この一覧には、各クエリの実行時間や、特定のクエリによって返されたデータの行数などの情報が含まれます。
- **Sample results**: クエリが正常に実行された後、Query results セクションでその行を展開すると、そのクエリによって返されたデータのサンプルを表示できます。
- **Preview table**: スキーマセクションに表示されている任意のテーブルのサンプル行を、ワンクリックでプレビューできるようになりました。
- **各クエリに対するアクション**: 各クエリでは、次のアクションを利用できます。
  - **Insert in SQL editor**: クエリを SQL エディターに追加します。
  - **Copy query**: クエリのテキストをコピーします。
  - **Run query**: クエリを実行します。
  - **Download results**: クエリの出力をダウンロードできます。

詳細については、[こちら](/ja/user-guide/segment/create-segments/warehouse-segments)を参照してください。

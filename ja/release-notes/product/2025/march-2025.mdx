# Heads-Up 通知

Heads-up 通知は優先度の高いプッシュ通知で、画面上部にフローティングバナーとして短時間表示され、すぐに目に留まるようにします。操作されない場合、数秒後に消えます。

この機能を使用すると、次のことができます。

- 支払いの失敗やセキュリティの問題についてユーザーに警告する。
- 期間限定のオファーをユーザーに通知する。
- 限定割引とともに、放棄されたカートをユーザーにリマインドする。

MoEngage は、Heads-up 通知を設定するための 2 つの方法をサポートするようになりました。

- **Reposting Method (デフォルト)**: 最初にテキストコンテンツを投稿し、その後メディアとテンプレート要素で更新することで、信頼性を確保します。
- **Direct Posting Method**: ユーザーは意図したとおりの Heads-up 通知を体験できます。テンプレートのコンテンツが通知に直接表示されます。

詳細については、[Heads-up 通知](/ja/user-guide/campaigns-and-channels/mobile-push/notification-features-and-behavior/android-push-heads-up-notifications) を参照してください。

# キャンペーンと Flows を監視するための詳細なアラート

Alert Manager で、より正確で柔軟なアラート設定が可能になりました。キャンペーンまたはフローの開始時刻に基づいて、カスタムの時間単位または日単位の間隔でアラートを設定できます。

この機能強化により、次のことができます。

- 特定の間隔でのアラートにより、異常をより迅速に検出する。
- 開始時刻ベースのアラートにより、ローンチ時からパフォーマンスを監視する。
- キャンペーンまたはフローごとに、異なる指標に対して複数のアラートを設定する。
- アラート条件が満たされたときに、即座にメール通知を受け取る。

MoEngage は次の機能をサポートするようになりました。

- **詳細な時間単位および日単位のアラート**: 固定の時間単位または日単位のトリガーではなく、カスタムの間隔でアラートを設定します。
- **開始時刻ベースのアラート**: キャンペーンが公開された瞬間からパフォーマンスを監視します。

詳細については、[アラートの作成](/ja/user-guide/settings/reports-and-alerts/alert-management/getting-started/create-an-alert) を参照してください。

# セッション内属性

In-app Messaging キャンペーンでセッション内属性がサポートされるようになりました。セッション内属性を使用すると、現在のアプセッション内でのアクションに基づいてユーザーをグループ化し、ターゲティングできます。

詳細については、[セッション内属性](/ja/user-guide/campaigns-and-channels/in-app-message/create/create-in-app-campaign) を参照してください。

# User Paths の改善

MoEngage は User Paths に次の機能強化を導入しました。

- **パスでの Split-by 属性**: 最大 5 つの Split-by 属性を追加して任意のイベントを分解し、複数のレポートを作成することなくセグメント化されたジャーニーを確認できるようになりました。
- **チャートエクスペリエンスの強化**: イベント名の視認性向上、よりスムーズなチャート操作、より優れたインサイトなど、User Paths チャートのさまざまな機能強化により、ひと目で明確に把握できるようになります。
- **チャートのプレゼンテーションモード**: 全画面モードに切り替えて、MoEngage Analytics から直接チャートをプレゼンテーションできるようになりました。

詳細については、[User Paths](/ja/user-guide/analyze/analytics/user-paths/user-path-analysis) を参照してください。

# Connected Sources: Streams と Treasure Data

MoEngage は、Streams と Treasure Data という 2 つの新しい統合をリリースし、Connected Sources の機能を拡張しました。これらの統合によりデータが MoEngage に接続され、顧客の統合ビューとエンゲージメントの強化が実現します。

- Streams の統合により、異なる MoEngage アプリ間でイベントデータをシームレスかつリアルタイムに同期できます。詳細については、[こちら](https://www.moengage.com/docs/api/data/moengage-streams#sync-events-from-one-moengage-app-to-another)を参照してください。
- Treasure Data の統合により、Treasure Data Customer Data Platform (CDP) から統合された顧客プロファイルを MoEngage に直接取り込むことができます。詳細については、[こちら](https://partners.moengage.com/hc/en-us/articles/26760984996628-Treasure-Data)を参照してください。

# Merlin AI Segmentation

MoEngage は Merlin AI for Segmentation を導入しました。これは MoEngage でのオーディエンスセグメンテーションを簡素化する画期的な機能です。Merlin AI を使用すると、ターゲットオーディエンスを説明するだけで正確なセグメントを作成できます。フィルターを手動で設定したり、複雑なセグメンテーションのセマンティクスを理解したりする必要はありません。

**主な機能**

- **サンプルプロンプト:** ユーザー属性、イベント属性、フィルター、結合など、一般的なセグメンテーション構造を示す定義済みのサンプルプロンプトですぐに開始できます。追加すべきよく使われるクエリがあればお知らせください。
- **Merlin AI クエリの結果:** AI が生成したクエリは手動のフィルターベースのクエリとは別に表示されるため、結果を解釈して次のアクションを実行しやすくなります。
- **クエリの再生成:** 結果に満足できない場合は、クエリを簡単に再生成できます。Merlin AI は、意図により合うようにフィルターを調整します。
- **Filter View でクエリを開く:** より細かく制御したい場合は、AI が生成したクエリを MoEngage のフィルターベースのセグメンテーションフローで開き、高度なフィルタリング、カスタムセグメント、アフィニティルールを適用できます。
- **ユーザーフィードバックの仕組み:** ぜひご意見をお聞かせください。各 Merlin AI クエリの結果には高評価/低評価のオプションがあり、正確性と関連性についてフィードバックを提供できます。いただいたご意見は、エクスペリエンスのさらなる向上に役立てられます。

詳細については、[Merlin AI Segmentation](/ja/user-guide/ai-and-intelligence/merlin-ai/merlin-ai-segment-assist) を参照してください。

# メールでのボットによる開封の識別

MoEngage は Bot Open Identification 機能を導入しました。この機能を使用すると、すべてのメールの開封をボットによる開封とユーザーによる開封に分類できるようになり、「Adjusted」指標のみを表示するか、MoEngage の現在の指標に加えて表示するかを制御できます。Adjusted 指標は、人間が開始した開封のみを使用して計算されます。   
詳細については、[メールマーケティングにおけるボットアクティビティとは](/ja/user-guide/campaigns-and-channels/email/faqs-email/what-is-bot-activity-in-email-marketing)、[Email チャネルの設定](/ja/user-guide/campaigns-and-channels/email/getting-started-with-email/configure-email-channel#general-settings-tab)、[Email の分析と情報](/ja/user-guide/campaigns-and-channels/email/analyze/email-analytics-and-info#campaign-performance-stats) を参照してください。

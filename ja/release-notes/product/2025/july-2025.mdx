# 新しい MoEngage ナビゲーションエクスペリエンスの導入

<Note>
  これは早期アクセス機能です。お使いのアカウントで有効にするには、MoEngage のカスタマーサクセスマネージャー (CSM) またはサポートチームにお問い合わせください。
</Note>

MoEngage のナビゲーションを大幅に刷新したことをお知らせします。これまで以上にスムーズかつ迅速で、直感的なワークフローを実現するよう設計されています。この全面的なリデザインにより、必要なものを簡単に見つけられ、大幅に少ないクリック数でタスクを完了できます。

### 主な改善点

- **少ないクリックで、より多くのアクション**: 新しいデザインでは、一般的なタスクに必要なクリック数が大幅に削減され、より短時間でより多くの作業を完了できます。
- **よりスマートな整理**: 改善された情報アーキテクチャに基づき、関連するメニュー項目を論理的に再グループ化しました。たとえば、Segment にカーソルを合わせると、オーディエンス関連のすべてのアクションが 1 か所にまとめられています。
- **発見しやすさの向上**: 改善された構造とすっきりとしたビジュアルレイアウトにより、必要な機能を見つけやすくなり、新しい機能を発見して MoEngage の可能性を最大限に引き出すことができます。

新しい合理化されたデザインをきっとお楽しみいただけると確信しています。ただし、新しいナビゲーションと従来のナビゲーションは簡単に切り替えることができるため、ご自身のペースで慣れていただけます。

### 新しいデザインのクイックツアー

- **洗練された折りたたみ可能なサイドバー**: 新しいサイドバーはコンパクトなアイコンのみのバーに折りたたむことができ、画面スペースを節約して作業に集中できます。
- **ホバーで開くメニュー**: プライマリアイコン (Analyze や Engage など) にマウスを合わせるだけで、すべてのコンテンツを含むセカンダリパネルが即座に開き、クリックすることなく必要なものにアクセスできます。
- **整理されたメニューグループ**: 新しいメニューでは関連するアクションがグループ化され、より整理されたワークフローを実現します。例:
  - Dashboards メニュー項目にカーソルを合わせると、**\+ New Dashboard** への直接のショートカットが表示されます。
  - Segment メニュー項目にカーソルを合わせると、**\+ New Segment** や **\+ New User Import** への直接のショートカットを含め、オーディエンス関連のすべてのアクションが 1 か所にまとめられています。
- **グローバルな「Create New」ボタン**: サイドバー上部の Create New ボタンは、プラットフォームのどこからでもキャンペーン、フロー、セグメント、ダッシュボードを作成するための中心的な出発点です。

新しいナビゲーションを体験して、作業を効率化しましょう。

# ライフサイクル全体を自動化する Push Campaign API の導入

MoEngage は強力な Push Campaign API をリリースしました。Push キャンペーンのライフサイクル全体をプログラムで完全に制御でき、効率的でスケーラブルなキャンペーン管理が可能になります。

この API を使用すると、次のことができます。

- Push キャンペーンをプログラムで作成、編集、検索、テスト、有効化する。
- CRM や CDP を使用して、高度にパーソナライズされた通知をリアルタイムでトリガーする。
- CMS から直接、定期的なコンテンツ配信を自動化する。
- 大規模な A/B テストを実行し、結果を社内システムと同期して迅速に最適化する。

この API により高度な自動化とパーソナライゼーション機能が利用可能になり、効率的な拡張とキャンペーンパフォーマンスの向上に役立ちます。

# Merlin AI を使用したカスタムイベントと属性の説明の生成

Merlin AI が、ワークスペース内のカスタムイベントと属性の説明を自動的に生成するようになりました。

この機能により、カスタム属性についての明確で文脈に沿った説明がユーザーインターフェイス内に直接表示されます。これにより、セグメンテーション、分析、キャンペーン作成の際に、正しい属性を正確に特定して選択できます。

### 主なハイライト

- **説明の自動生成**: Merlin AI はカスタム属性の読みやすい名前とデータ型を分析し、説明的な要約を生成します。ただし、MoEngage が提供する標準のシステムレベル属性には影響しません。
- **UI での表示**: 生成された説明は、次の主要な領域の属性選択ドロップダウンリストに表示されます。
  - Segmentation モジュールのセグメントフィルター。
  - MoEngage Analytics の **Filter users** セクション。
  - キャンペーン作成時の **Target audience** セクション。

詳細については、[Merlin AI のイベントと属性の説明](/ja/user-guide/ai-and-intelligence/merlin-ai/merlin-ai-event-and-attribute-descriptions) を参照してください。

# Web Push 向け Chrome の新しいスパムフィルター

Android 版 Google Chrome に、Web Push 通知の表示に影響を与える可能性があるスパムフィルターが搭載されました。

知っておくべきポイントは次のとおりです。

- 疑わしい通知は「Possible spam」プロンプトの背後に非表示になります。
- メッセージがフラグ付けされた場合でもインプレッションはカウントされるため、CTR の正確性に影響する可能性があります。
- メッセージがフラグ付けされても、アラートは送信されません。

リスクを軽減するには:

- 「Test Push」機能を使用して、Android デバイスで通知をプレビューします。
- 緊急性の高い表現や誤解を招く表現は避けます。
- システムアラートを模倣しないでください。

ベストプラクティスと例については、[Android での Web Push 通知に対する Google Chrome スパムフィルター](/ja/user-guide/campaigns-and-channels/web-push/faqs-web-push/google-chrome-spam-filter-for-web-push-notifications-on-android) を参照してください。

# Integration Validation

_Integration Validation_ 機能は、機能の実装を検証するダッシュボードインターフェイスを提供することで、MoEngage Android SDK の統合を簡素化します。

この機能により、開発者やマーケターは SDK の実装を独自にテストおよび検証でき、正確性を確保しながらサポートチームへの依存を減らすことができます。エラーを最小限に抑え、統合プロセスを効率化することで、シームレスなマーケティングコミュニケーションを実現し、ユーザーエンゲージメントを高めます。

Integration Validation は次のことに役立ちます。

- ダッシュボードから直接 Android SDK の機能をテストする。
- プッシュ通知に不可欠な設定の欠落など、設定の問題を特定して解決する。
- 実装の正確性を高め、より良い成果を得る。

詳細については、[Integration Validation](/ja/user-guide/getting-started/integration-validation/android-native-integration-validation) を参照してください。

# Offerings & Decision Policy

新しい Offerings & Decision Policy 機能は、マーケティングチームやビジネスチームが顧客にパーソナライズされた効果的なプロモーションを提供するのに役立つ強力なソリューションです。このツールは、モバイルアプリや Web サイトなどのデジタルプラットフォームにおけるターゲットプロモーションの設計・管理から表示までのプロセス全体を効率化します。

この機能を使用すると、次のことができます。

- **カスタマイズされたプロモーションの作成**: 特定のユーザーグループに合わせた **Offerings** と呼ばれるプロモーションを設計します。
- **配信の最適化**: インテリジェントな **Decision Policies** を使用して、プロモーションの関連性と効果を確保します。\
  詳細については、[Offerings と Decision Policy](/ja/user-guide/decisioning/offer-decisioning) を参照してください。

# Inform レポート

新しい Reports 機能は、Inform アラートの集計されたパフォーマンスデータを提供します。このツールにより手動でのデータ集計が不要になり、重要なコミュニケーションに関する包括的なインサイトが得られます。

Reports を使用すると、次のことができます。

- **詳細なパフォーマンス指標の取得**: 特定のアラートの詳細なパフォーマンスデータにアクセスします。
- **集計データへのアクセス**: 複数のアラートを組み合わせたデータを表示し、より広い視点で把握します。
- **エクスポートと自動化**: レポートデータを CSV 形式でダウンロードしたり、カスタムレポート用に REST API で取得したり、柔軟なスケジュール設定でレポート生成を自動化したりできます。

この機能により、トランザクションメッセージのモニタリングと最適化のプロセスが簡素化され、データに基づく意思決定を容易に行えます。詳細については、[Inform レポート](/ja/user-guide/inform/analyze/inform-reports) を参照してください。

# Email Content Blocks の機能強化

MoEngage は Content Blocks 機能によって Drag and Drop エディターを強化し、再利用可能なコンテンツをより迅速かつ直感的に作成できるようにしました。

主な改善点:

- Drag and Drop エディターに Content Block 専用のタイルが追加され、保存済みのコンテンツを簡単に追加できるようになりました。以前は複数のステップが必要だった操作が、シンプルなドラッグ & ドロップで完了するため、時間を節約してワークフローを効率化できます。
- メールエディターの任意の Row を HTML Content Block として直接保存できるようになりました。これにより、そのアセットは一元化された Content Block ライブラリからすぐに編集、管理、追跡できるようになります。
- Content Blocks は Enterprise 限定の機能ではなくなりました。MoEngage はすべての MoEngage のお客様にこの機能を提供します。すべてのマーケターが、一元管理された再利用可能なアセットのライブラリを構築し、メールだけでなく Push、In-App、SMS、WhatsApp などでも使用できるようになります。

詳細については、[Drag and Drop エディターでのコンテンツの作成](/ja/user-guide/campaigns-and-channels/email/create/create-content-with-the-drag-and-drop-editor) を参照してください。

# アクセシビリティ

MoEngage は、デジタルアクセシビリティに対応したマーケティングキャンペーンの作成に役立つ新機能を導入しました。これらの機能は、ベストプラクティスや欧州アクセシビリティ法 (EAA) などの今後の規制に沿って、障がいのある方にもキャンペーンを利用していただけるように設計されています。Push、In-App Messaging、Email、On-Site Messaging、Cards など、複数のチャネルでアクセシブルなキャンペーンを作成できます。

詳細については、[こちら](/ja/user-guide/campaigns-and-channels/getting-started/campaign-content/accessible-campaigns-in-moengage)を参照してください。

# Merlin AI Jinja Assistant

MoEngage は Merlin AI Jinja Assistant を導入しました。これは、自然言語を使用して動的コンテンツスニペットを簡単に作成できるよう設計された強力なツールです。このアシスタントは構造化されたプロンプトをすぐに使える Jinja コードに変換し、パーソナライゼーションのワークフローを効率化します。詳細については、[こちら](/ja/user-guide/ai-and-intelligence/merlin-ai/merlin-ai-jinja-generator)を参照してください。

# OAuth2 認証

MoEngage は Connected Channels 向けに OAuth2 認証を導入しました。これにより、より幅広い統合環境とシームレスに接続するための、安全で標準化されたプロトコルが提供されます。この機能強化により、手動でのトークン処理や機密性の高い認証情報の共有が不要になり、お客様は多数の新しいプラットフォームと接続できるようになります。詳細については、[こちら](/ja/user-guide/campaigns-and-channels/connected-apps/getting-started-with-connected-apps/create-a-channel-connector-config-file#oauth2)を参照してください。

# Connected Channels

MoEngage は OAuth2 認証の導入に伴い Connected Channels を導入し、広告プラットフォームとのシームレスで安全な接続を可能にしました。この機能強化によりセキュリティが向上し、統合の可能性が広がります。リリース時点では、Pinterest Ads、Snapchat Ads、Criteo Ads、TikTok との新しい直接統合が利用可能です。これらの機能を活用して価値の高いユーザーセグメントを同期し、これらの主要な広告チャネル全体でエンゲージメントの向上、コンバージョンの促進、広告費の最適化を実現しましょう。詳細については、[こちら](/ja/user-guide/campaigns-and-channels/connected-apps/getting-started-with-connected-apps/overview#supported-connected-channels)を参照してください。

# Merlin AI Designer v2.0

MoEngage は Merlin AI Designer v2.0 を導入しました。これは、魅力的でキャンペーンにすぐ使えるバナーを生成するためのクリエイティブワークフローを大幅にアップグレードするものです。この機能は、テキストを重視した完璧なビジュアルを提供し、ブランドの商品画像を活用したデザインを可能にするよう設計されています。これらの強化された機能を活用して、さまざまなマーケティングキャンペーン向けに効果的なビジュアルコンテンツを作成できます。詳細については、[こちら](/ja/user-guide/ai-and-intelligence/merlin-ai/merlin-ai-designer)を参照してください。

# Campaign Audience Limit

MoEngage は Campaign Audience Limits をサポートするようになりました。マーケターは、リアルタイムのエンゲージメント結果に基づいてキャンペーンのリーチを制御できます。

<Note>
  これは早期アクセス機能です。お使いのアカウントで有効にするには、CSM にお問い合わせいただくか、サポートチケットを作成してください。
</Note>

この機能を使用すると、次のことができます。

- Sent、Impressions、Opens、Delivered、Conversions などの主要なキャンペーンイベントの上限を定義する。
- 目的のしきい値に達したらキャンペーンを自動的に一時停止し、成果に基づいたスマートな制御を実現する。
- Total Limit、Daily Limit、Instance Limit のオプションから選択し、柔軟にオーディエンスを管理する。

主なメリット:

- 支出を実際の成果に結び付けることで、ROI を最適化し、過剰な支出を防ぐ。
- オファーの引き換えやコンテストへの応募を正確に制御する。
- 限定コンテンツや期間限定プロモーションへのアクセスを管理する。
- 量だけでなく、実際のエンゲージメントに基づいてキャンペーンを最適化する。

詳細については、[こちら](/ja/user-guide/settings/channels/delivery-controls/campaign-audience-limit)を参照してください。

# iOS Broadcast Live Activities

MoEngage は iOS の Broadcast Live Activities をサポートするようになりました。これにより、ブランドは対応デバイスのロック画面や Dynamic Island にリアルタイムの最新情報を直接配信できます。

この機能を使用すると、次のことができます。

- 注文状況、旅行の詳細、ライブスコアなどのリアルタイムの最新情報を表示する。
- ひと目で確認でき、常に表示される情報でユーザーエンゲージメントを向上させる。
- Live Activities の外観をブランドに合わせてカスタマイズする。
- Live Activity トークンと MoEngage API を使用して、安全にリアルタイムの最新情報を送信する。

詳細については、以下の記事を参照してください。

- [iOS Push キャンペーンの Broadcast Live Activities](/ja/user-guide/campaigns-and-channels/mobile-push/notification-features-and-behavior/broadcast-live-activities-for-ios-push-campaigns)
- [Broadcast Live Activity 開発者ガイド](https://www.moengage.com/docs/developer-guide/ios-sdk/push/optional/broadcast-live-activity)
- [API ドキュメント](https://www.moengage.com/docs/api/live-activities/live-activities-overview)


# WhatsApp Lead Management

MoEngage は WhatsApp Lead Management を導入しました。この新機能により、新しいリードを自動的に獲得し、受信したすべての WhatsApp メッセージを MoEngage 内で包括的に追跡できます。

主なメリットは次のとおりです。

- WhatsApp で会話を開始した新しい連絡先のユーザープロファイルを自動的に生成する。
- キャンペーン関連の返信だけでなく、受信したすべての顧客メッセージを完全に把握する。
- 顧客とのやり取りの完全な履歴を活用して、ユーザーをより深く理解し、エンゲージメントを高める。

詳細については、[WhatsApp の設定](/ja/user-guide/campaigns-and-channels/whatsapp/getting-started-with-whatsapp/configure-whatsapp) を参照してください。

# WhatsApp テンプレートの同期

WhatsApp テンプレートの同期機能が Karix でも利用できるようになりました。詳細については、[WhatsApp テンプレート](/ja/user-guide/campaigns-and-channels/whatsapp/getting-started-with-whatsapp/whatsapp-templates#sync-templates-from-vendors-to-moengage) を参照してください。

# Email オンボーディングのセルフサービス

MoEngage は Self-Service for Email Onboarding を導入しました。これは、MoEngage プラットフォームから直接メールを送信するために必要なインフラストラクチャと設定をセットアップするための合理化されたプロセスです。メールサーバーのセットアップやドメイン認証の確保などの重要なステップが含まれており、いずれも到達率を高め、Google、Yahoo、Microsoft などの主要なメールボックスプロバイダーの最新ガイドラインに準拠するよう設計されています。詳細については、[Email オンボーディングのセルフサービス](/ja/user-guide/campaigns-and-channels/email/getting-started-with-email/self-service-for-email-onboarding) を参照してください。

<Info>
  この機能は、MoEngage SendGrid 配信を使用している場合にのみ利用できます。
</Info>

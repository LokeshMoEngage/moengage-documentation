# Merlin AI Studio

MoEngage は Merlin AI Studio を導入し、すべての生成 AI 機能 (Copywriter、Designer、Segmentation Assist など) を 1 か所の直感的な場所に統合しました。Studio には、すべての AI エージェントと、テンプレートを含む新しいインスピレーションライブラリが含まれており、ワークフローを簡素化して新しい AI 機能をすばやく導入できます。

詳細については、[Merlin AI Studio](/ja/user-guide/ai-and-intelligence/merlin-ai/merlin-ai-studio) を参照してください。

# ネイティブ MMS キャンペーン

MoEngage は、テキストのみの SMS (Short Message Service) を超えるためのチャネルとして、MMS (Multimedia Messaging Service) をリリースしました。画像、GIF、動画を含む視覚的に魅力的なキャンペーンを、顧客の受信トレイに直接送信できるようになりました。

主なハイライト:

- **リッチメディア**: メッセージごとに最大 10 個のファイル (画像、GIF、動画) をアップロードできます。
- **拡張されたテキスト**: 1600 文字の上限で、詳細なストーリーを伝えることができます。
- **スマートな配信:** サポートされていないデバイス向けに、SMS への自動フォールバックが含まれています。
- **提供状況**: 米国、カナダ、オーストラリアで利用可能になりました (Twilio 経由)。

詳細については、[MMS](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/mms) を参照してください。

# メッセージのキューイング

MoEngage は、キャンペーンのリーチを最大化し、タイムリーなコミュニケーションを維持するための機能として、Message Queuing をリリースしました。キャンペーンの配信設定によってブロックされたメッセージを自動的にキューに入れて再試行し、ユーザーが対象になり次第配信できるようになりました。

主なハイライト:

- **自動再試行**: Frequency Capping (FC)、Minimum Delay、または DND によってブロックされたメッセージは、破棄されずに一時的にキューに入れられます。
- **配信の最大化**: MoEngage は、ユーザーが対象になり次第、自動的にメッセージの再送信を試みます。
- **設定可能な期間**: キャンペーンレベルで、キューの期間を最大 48 時間まで設定できます。
- **提供状況**: Push キャンペーン (1 回限り、定期、Business Event トリガー型) で利用可能になりました。

詳細については、[メッセージのキューイング](/ja/user-guide/settings/channels/delivery-controls/message-queuing) を参照してください。

# Content API と PII API での OAuth 2.0

MoEngage は、最高水準のセキュリティ基準を適用し、静的な API キーからの脱却を支援するアップグレードをリリースしました。Content API と個人を特定できる情報 (PII) Tokenization API の両方へのアクセスに、業界標準の OAuth 2.0 認証を使用できるようになりました。

主なハイライト:

- **OAuth 2.0 認証**: Content API と PII API へのアクセスの標準となり、マシン間セキュリティにおける業界最高水準を適用します。
- **トークン化のセキュリティ**: PII へのアクセスは、有効な短期間のトークンを持つアプリケーションに制限され、個人データの厳格な管理の連鎖が確保されます。
- **自動トークン管理**: トークンはプログラムで更新および取り消しができ、最新の安全な CI/CD パイプラインに最適です。
- **ビジネスへの影響**: リスクゼロと完全なコンプライアンス (GDPR/CCPA への準拠など) を実現し、明確な監査証跡を提供し、開発者の生産性を向上させます。

詳細については、以下を参照してください。

- [OAuth 2.0 の設定](/ja/user-guide/settings/advanced-settings/authorization-configuration-with-oauth-20)
- [Content API での OAuth 2.0 の使用](/ja/user-guide/settings/advanced-settings/add-a-content-api)
- [PII での OAuth 2.0 の使用](/ja/user-guide/data/privacy/personal-data-or-personally-identifiable-information-pii/pii-tokenized-sending)

# 言語サポートの拡充

言語サポートの拡充には、日本語版の完全なユーザーガイドの導入と、ダッシュボードインターフェイスへのブラジルポルトガル語の追加が含まれます。

このアップデートにより、グローバルなお客様にとってのアクセシビリティと包括性が大幅に向上します。主要なドキュメントとダッシュボードのナビゲーションを現地の言語で提供することで、これらの市場のユーザーはより直感的にプラットフォームを活用できます。これにより、海外のチームはプラットフォームを簡単に操作し、より自信を持ってキャンペーンを実行できます。

言語サポートの拡充により、次のことが可能になります。

- 包括的な製品ユーザーガイドにすべて日本語でアクセスし、機能を詳しく理解する。  
   <img alt="language_selection.png" src="/images/moengage_34d368.png" />
- 既存の英語と日本語のオプションに加わったブラジルポルトガル語で、ダッシュボードインターフェイスを操作する。
- 主要なグローバル地域のチームメンバーに、シームレスでローカライズされたユーザーエクスペリエンスを提供する。

# アウトバウンドチャネル

## Reply-to メールアドレスのパーソナライゼーション

この機能により、MoEngage はメールチャネルの **Reply-to email address** フィールドでパーソナライゼーションをサポートします。これにより、返信先メールアドレスを動的にマッピングし、顧客からの返信を、そのアカウントを担当するサポート担当者や CRM 担当者の受信トレイに振り分けることができます。

## メールのローカライゼーションサポート

今回のリリースで、メールチャネルにローカライゼーションのサポートが追加されました。メールキャンペーンにロケールバリエーションを追加し、キャンペーン分析でそれらのバリエーションのパフォーマンスを分析できます。詳細については、[バリエーションのパフォーマンス](/ja/user-guide/campaigns-and-channels/email/analyze/email-analytics-and-info#locale/variation-performance)を参照してください。

# インバウンドチャネル

## 非侵入型の Nudges(Android)

In-App Nudges は、シームレスで非侵入型の、コンテキストに即したアプリ内エクスペリエンスを提供します。今回のリリースで、MoEngage は10種類の新しい Nudge テンプレートを導入しました。これらのテンプレートを使用して、新規顧客のアクティベーション、機能の発見と導入の促進、重要な更新に関する顧客への通知、オファーのプロモーション、関連性の高いフィードバックの即時取得などを行えます。詳細については、[In-App Nudges](/ja/user-guide/campaigns-and-channels/in-app-message/templates/in-app-templates)を参照してください。

# Data

## Get User API

この API を使用すると、MoEngage に保存されているユーザーの個人情報を取得できます。これらの情報には、個人プロファイル属性、ユーザーが行ったアクティビティ、派生情報、ユーザーの予測インサイトが含まれます。詳細については、[Get User API](https://www.moengage.com/docs/api/user/get-user)を参照してください。

## Delete User API

この API を使用すると、MoEngage からユーザーを削除できます。削除したユーザーは復元できません。削除後も、これらのユーザーは24時間の猶予期間中はアクティブなままで、Segments、Analytics、Campaigns に表示されます。この期間中は、ユーザーの詳細を引き続き更新できます。猶予期間が終了すると、MoEngage はユーザーを完全に削除します。詳細については、[Delete User API](https://www.moengage.com/docs/api/user/delete-users)を参照してください。

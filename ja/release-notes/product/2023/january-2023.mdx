# 新機能

## Personalize

この機能を使用すると、開発者のリソースを使わずに、ビジュアルエディターで訪問者向けの独自のウェブエクスペリエンスを作成できます。詳細については、[Personalize](/ja/user-guide/personalize/overview/overview-personalize) を参照してください。

## キャンペーンとチャネル

**Push info の刷新**

Push Analytics と Info の UI を刷新しました。詳細については、[Push Analytics and Info (Beta)](/ja/user-guide/campaigns-and-channels/mobile-push/analyze/push-analytics-and-info) を参照してください。

**Android 13 のオプトインのサポート**

Android 13 デバイスのオプトイン設定の取得をサポートしました。詳細については、[ユーザーのオプトイン設定と Android プッシュの到達可能性](/ja/user-guide/segment/reachability/user-reachability)を参照してください。

**SMS カスタムコネクターの配信トラッキング**

この機能により、SMS カスタムコネクターの配信トラッキングが可能になります。詳細については、[カスタムコネクターの配信トラッキング](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/sms/getting-started-with-sms/configure-custom-connector-for-sms)を参照してください。

**HTML のコピーのサポート**

この機能を使用すると、ネイティブのアプリ内テンプレートの HTML コードをコピーできます。詳細については、[アプリ内テンプレートの HTML コードのコピー](/ja/user-guide/campaigns-and-channels/in-app-message/templates/html-in-app-templates)を参照してください。

**Campaign Stats でのタイムゾーンのサポート**

すべてのキャンペーン統計がアプリのタイムゾーンで利用できるようになりました。

**Resubscribe API**

Resubscribe API を使用すると、以前に購読を解除したユーザーを、MoEngage プラットフォームと外部のメールベンダープラットフォームで同時に再購読させることができます。詳細については、[Resubscribe Email API](https://www.moengage.com/docs/api/resubscribe/bulk-resubscribe-users) を参照してください。

## Flows

**Flow のスケジュール設定**

この機能を使用すると、指定したスケジュールで Flows をトリガーし、Flow に入るユーザー数を制限できます。詳細については、[Flow のスケジュール設定](/ja/user-guide/flows-cross-channel-messaging/create/create-flows/create-a-flow)を参照してください。

## データプライバシー

**PII データ暗号化**

この機能を使用すると、ユーザー属性とイベント属性を暗号化できます。詳細については、[PII データ暗号化](/ja/user-guide/data/privacy/personal-data-or-personally-identifiable-information-pii/pii-data-encryption)を参照してください。

## Analytics

**Retention での Actionable Analytics**

この機能を使用すると、リテンションテーブルのセルを選択して、キャンペーン作成用の動的セグメントまたは静的セグメントを作成できます。

**Funnels の Actionable Analytics での動的セグメント**

この機能を使用すると、Funnels の Actionable Analytics で動的セグメントを作成できます。

**Acquisitions UI の刷新**

Acquisition の UI を刷新しました。

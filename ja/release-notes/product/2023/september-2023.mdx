# アウトバウンドチャネル

## プッシュメッセージ向け Merlin AI

Merlin AI を使用すると、人工知能(AI)の力を活用して MoEngage でプッシュ通知を生成できます。

### ハイライト

- **パフォーマンス主導の最適化**: 過去のキャンペーンから継続的に学習し、今後の成果を最大化します。過去にどのキーワードが高いパフォーマンスを発揮し、どのキーワードがそうでなかったかをマーケターに示します。
- **コンテキストの認識**: オーディエンスを理解し、共感を呼ぶコンテンツを作成します。キャンペーンのユースケースやターゲットオーディエンスに基づいてメッセージをカスタマイズでき、さまざまなメッセージスタイルを試すことができます。
- **感情への訴求:** 感情に訴えるコンテンツは、オーディエンスの注目を集め、コンバージョンを促進するうえで非常に効果的です。さまざまなトーンでメッセージを生成したり、試したりできます。
- **シームレスな統合:** MoEngage のキャンペーンビルダーと直接連携しているため、スムーズなユーザーエクスペリエンスに加えて、キーワードを分析するオプションも利用できます。
- **使いやすいプロンプトビルダーで時間を節約:** プロンプトを作り込む必要はありません。プロンプトビルダーでフィルターや入力を指定するだけで、メッセージを生成できます。
- **A/B テストバリアントをすばやく作成:** ワンクリックで新しいコピーのバリエーションを生成し、アイデアをテストできます。

詳細については、[Merlin AI によるプッシュメッセージの生成](/ja/user-guide/ai-and-intelligence/merlin-ai/merlin-ai-copywriter/generate-push-messages-with-merlin-ai)を参照してください。

## プロモーション SMS キャンペーンの配信統計

今回のリリースで、MoEngage はトランザクションキャンペーンと同様に、MoEngage で実行されたプロモーション SMS キャンペーンの配信統計の表示をサポートします。これはすべての種類のキャンペーンに適用され、SMS キャンペーン指標の算出方法が改善されます。従来、クリック率(CTR)は送信された SMS の数に基づいて算出されていました。今後は MoEngage が配信された SMS の数を考慮するため、より正確になります。

## 標準属性としての Campaign ID の導入

今回のリリースで、MoEngage は標準属性として Moesms\_campaignId を導入しました。これにより、キャンペーンレベルのデータを生成できます。たとえば、各キャンペーンから送信されたメッセージの数や、特定のキャンペーンからメッセージを受信したユーザーの数を把握できます。この属性により、SMS サービスプロバイダーは、キャンペーンから送信されたメッセージの数に基づいて顧客に請求できます。詳細については、[カスタムコネクタ(サービスプロバイダー)の設定](/ja/user-guide/campaigns-and-channels/sms-mms-and-rcs/sms/getting-started-with-sms/configure-custom-connector-for-sms)を参照してください。

# インバウンドチャネル

## React Native および Flutter 向けの Self Handled Cards

今回のリリースで、MoEngage は React Native および Flutter SDK で Self Handled Cards のサポートを導入しました。React Native および Flutter 環境で、パーソナライズされた非侵入型のコミュニケーションにより、アプリをパーソナライズし、顧客のエンゲージメントを高めることができます。詳細については、[Self Handled Cards](https://www.moengage.com/docs/developer-guide/flutter-sdk/cards/self-handled-cards)を参照してください。

## In-App の表示遅延

今回のリリースで、MoEngage は In-App メッセージのオプションとして **After Delay** を導入しました。これにより、ポップアップを表示するタイミングを指定できます。この機能を使用すると、画面の読み込み中に In-App メッセージをすぐに表示するか、指定した時間だけ待ってから表示するかを柔軟に選択できます。Delayed In-App Visibility により、ポップアップをユーザーエクスペリエンスにシームレスに組み込み、ユーザーの満足度とエンゲージメントを高めることができます。

# Analytics

## キャンペーンへの Analytics の埋め込み

今回のリリースで、ファネルカードとリテンションカードがキャンペーン分析に埋め込まれ、キャンペーン分析ページで Conversion と Retention の指標を直接確認できるようになりました。ワンクリックで Funnel Analytics と Retention Analytics に移動できるため、チームがデータに基づいた意思決定を行えるようになります。

# アウトバウンドチャネル

## Email Custom Template API

この機能を使用すると、MoEngage の外部で作成したメールテンプレートを MoEngage にインポートできます。この機能を使用して、テンプレートを作成、更新、検索できます。詳細については、[Email Template API](https://www.moengage.com/docs/api/email-templates-2/email-templates-2-overview) を参照してください。

# Analytics

## Analytics での時系列比較

Analytics の時系列比較を使用すると、現在の期間の分析結果を、\
前日、前週、前月、前四半期、前年、または\
カスタムの日付範囲など、さまざまな過去の期間と比較できます。この機能は、主要な Analytics 製品である Behavior、Funnels、\
Retention、Session & Source、Custom Dashboards で利用できます。\
期間をまたいで分析を比較すると、貴重なインサイトが得られます。数週間にわたるユーザーの\
アクティビティの傾向を把握したり、月ごとのキャンペーンやイベントのトラフィックを比較したり、期間ごとのソースの\
パフォーマンスを評価したりできます。詳細については、[Analytics の比較モード](/ja/user-guide/analyze/analytics/compare-mode-in-analytics)を参照してください。

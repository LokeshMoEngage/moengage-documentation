# iOS での Web Push

iOS 16.4、Safari 16、MacOS 13 のリリースにより、Apple は標準化された方法で Safari のプッシュ通知を有効にし、Safari の PWA およびホーム画面に追加されたウェブサイトについて iOS での Web プッシュ通知のサポートを追加しました。今回のリリースでは、次のサポートを追加しました。

- ホーム画面に追加されたウェブサイトおよび PWA に対する、iPadOS と iOS での Safari プッシュ通知
- Windows と Android での Microsoft Edge プッシュ通知

詳細については、[Web Push for iOS](https://www.moengage.com/docs/developer-guide/web-sdk/web-push/safari-web-push-for-i-os-and-i-pad-os) および [MoEngage のブラウザー互換性マトリックス](https://moengage-user-guide.mintlify.app/user-guide/campaigns-and-channels/web-push/getting-started-with-web-push/configure-web-push-settings#browser-compatibility-matrix)を参照してください。

# Email

## 送信者名のパーソナライズ

キャンペーン内のユーザーごとにパーソナライズされた送信者名を使用して、専任の担当者やエージェントがメールを送信したことを示すことができます。詳細については、[送信者名のパーソナライズ](https://moengage-user-guide.mintlify.app/user-guide/campaigns-and-channels/email/create/create-an-email-campaign#personalization-in-emails)を参照してください。

## プレビューテキスト

プレビューテキストは開封率を向上させ、件名にさらにコンテキストを追加します。HTML コードをいじる代わりに、件名と同じようにダッシュボードでプレビューテキストを追加できます。指定したテキストは HTML コードに自動的に追加され、メールクライアントでプレビューテキストとして認識されます。詳細については、[メールのプレビューテキスト](https://moengage-user-guide.mintlify.app/user-guide/campaigns-and-channels/email/create/create-an-email-campaign#preview-text)を参照してください。

# Analytics

## イベントフィルターでの配列型属性のサポート

Behaviour、Funnels、Retention で、キャンペーンタグやカートアイテムなどの配列型属性を使用してイベントをフィルタリングできます。詳細については、次を参照してください。

## アプリのタイムゾーンでの Consolidated Campaign Stats Dashboard

Consolidated Campaign Stats Dashboard (CCSD) では、クライアントのキャンペーン分析を包括的に確認できます。このダッシュボードのレポート指標を、Analytics スイート全体でアプリのタイムゾーンに統一しました。詳細については、[アプリのタイムゾーンでの CCSD](/ja/user-guide/analyze/dashboards/campaign-stats) を参照してください。

## Analytics でのユニバーサルユーザーマージ

MoEngage は、Analytics スイートでユニバーサルユーザーマージをサポートするようになりました。ユーザーマージとは、未識別 (匿名) ユーザーと識別済み (登録済み) ユーザーをマージするプロセスです。ユーザーマージにより正確な検索結果が得られるため、アクション可能な分析を使用して作成されたセグメントでは、到達可能なユーザーの割合が高くなります。

# Custom Segment Public API

Custom Segments を使用すると、フィルター条件を定義してユーザーセグメントを作成できます。次の API を利用できます。

1. 指定したフィルターでカスタムセグメントを作成する
2. ID を指定してカスタムセグメントを更新する
3. ID を指定してカスタムセグメントの定義を取得する
4. 名前でカスタムセグメントを一覧表示する。

詳細については、[Overview -Custom Segment API](https://www.moengage.com/docs/api/custom-segments/custom-segments-overview) を参照してください。

# Android 12 のプレビュー

MoEngage ダッシュボードで、さまざまな Android SDK バージョンについて、ユーザーのデバイス上で通知がどのように表示されるかをプレビューできます。次のプレビューオプションを利用できます。

1. Android 11 以前
2. Android 12 以降

詳細については、[Android 12 のプレビュー](https://moengage-user-guide.mintlify.app/user-guide/campaigns-and-channels/mobile-push/create/push-templates#push-template-types)を参照してください。

# SFTP ファイルのインポート

SFTP フォルダー内に保存されたファイルを使用して、ユーザー (登録済みユーザーと匿名ユーザーの両方) とイベントをインポートできます。詳細については、[SFTP インポート](/ja/user-guide/data/imports/setting-up-a-file-import)を参照してください。

# PII を使用したデータ暗号化

MoEngage では、個人を特定できる情報 (PII) としてマークされたユーザー属性とイベント属性を暗号化できます。暗号化できない予約済み属性の一覧を除き、すべてのユーザー属性とイベント属性でデータ暗号化を有効にできます。詳細については、[PII データ暗号化](/ja/user-guide/data/privacy/personal-data-or-personally-identifiable-information-pii/pii-data-encryption)を参照してください。

# 使い切りクーポンコード向け Coupon Provisioning System

使い切りクーポンコードとは、マーケティング戦略の一環として個々のユーザーや顧客に配布される固有のクーポンで、2人のユーザーが同じクーポンを受け取ることがないようにするものです。従来、マーケティングキャンペーンは主に、すべての顧客が利用できる汎用のクーポンコードに依存していました。しかし、このようなキャンペーンでは、パーソナライズされたエクスペリエンスを提供できず、不正利用や詐欺が頻繁に発生していました。

MoEngage では、マーケターがクーポンを簡単にインポートしてユーザーに配布でき、監査やデバッグのための使用状況レポートも管理できます。さらに、クーポンの在庫状況や有効期限に関するプロアクティブな監視とアラートも提供します。

MoEngage は、シームレスに統合できるクーポン管理用の API も提供しており、手動での作業を削減できます。これらの API を使用して、社内システムから MoEngage にクーポンを追加、管理、監査できます。

詳細については、[Coupons](/ja/user-guide/content/coupons)および[Coupon API](https://www.moengage.com/docs/api/coupons/coupons-overview)を参照してください。

<Info>
- MoEngage はコードの作成を管理しません。使い切りクーポンコードを割り当て、構成されたマーケティングチャネル全体に配布するのみです。
- 企業やブランドは、独自に引き換えの検証を実装する必要があります。
- サードパーティツールまたは社内システムでクーポンコードを作成し、CSV ファイルにまとめる必要があります。その後、このクーポンファイルを MoEngage Coupons プラットフォームにインポートして、使い切りクーポンベースのキャンペーンを送信できます。
</Info>

# Data Management ダッシュボード

MoEngage の Data Management ダッシュボードの UI が刷新され、自動ブロックされたイベントとユーザー属性の数が表示されるようになりました。Data Management ダッシュボードの主な機能は次のとおりです。

- イベントとユーザー属性の許容クォータ全体のうち、MoEngage アカウントで追跡されている固有のイベントと固有のユーザー属性を明確に把握できます。
- 上限超過により自動的にブロックされたイベントとユーザー属性の数を表示します。
- MoEngage で処理されたユーザーとイベントの量を表示します。
- 量に基づく上位10件のイベントを表示します。

詳細については、[概要 - Data Management](/ja/user-guide/settings/data-management/overview-data-management)を参照してください。

# キャンペーンのバージョン管理

キャンペーンのバージョン管理により、キャンペーンの反復作業が簡素化され、マーケターはワークフローを中断することなくキャンペーンを最適化できます。この機能を使用すると、アクティブなキャンペーンを手軽に変更でき、継続的な改善とパフォーマンスの最適化を実現できます。

キャンペーンのバージョン管理では、次のことができます。

- アクティブなキャンペーン(Periodic および Triggered)のあらゆるコンポーネントを編集し、新しいバージョンをシームレスに公開できます。
- 新しいバージョンを公開すると古いバージョンが自動的に廃止され、以降のインスタンスでは更新されたオーディエンスとコンバージョン目標が対象になります。
- 個別のバージョンおよび *All Version* のキャンペーン統計を表示して、パフォーマンスの推移を追跡できます。
- バージョン履歴にアクセスして変更内容を確認し、変更者を特定することで、説明責任を強化できます。

詳細については、[キャンペーンのバージョン管理](/ja/user-guide/campaigns-and-channels/campaign-management-and-reports/campaign-versioning)を参照してください。

# Connected Apps

MoEngage は、シームレスな統合とデータフローを目指しています。これを実現するため、MoEngage は *Connected Apps* という使いやすいローコードプラットフォームを導入しました。このプラットフォームは、多様なデータソースやチャネルを手軽に統合できるように設計されており、手間のかからないエクスペリエンスを提供します。

*Connected Source* は、あらゆるパートナーアプリをサポートするように設計された汎用プラットフォームです。データのサイロ化を解消し、カスタマーデータプラットフォーム(CDP)、分析ツール、ロイヤルティプログラム、さらには社内のデータレイクなど、さまざまなソースの重要な情報を MoEngage に統合できます。

Connected Sources を使用すると、さまざまなソースのデータを MoEngage プラットフォームに直接簡単にマッピングできます。複雑な統合を行うことなく、CRM、モバイルウォレット、リード獲得フォームを統合できます。Connected Sources を使用すると、さまざまなデータソースを手軽に組み合わせ、MoEngage でその可能性を最大限に活用できます。

詳細については、[Connected Apps](/ja/user-guide/campaigns-and-channels/connected-apps)を参照してください。

# カスタムテンプレート向けウィジェットライブラリ

MoEngage は、カスタムウィジェットを保存して再利用できるウィジェットライブラリを導入しました。開発者やカスタマーサクセスマネージャーに頼ることなく、パーソナライズされたエクスペリエンスのためのウィジェットを設定し、再利用できるようになりました。

メリット:

- ウィジェットライブラリにより、新しいウィジェットを一から設計するのに必要な時間と労力が削減されます。
- 保存したテンプレートを使用して、Web サイト上の複数のタッチポイントで一貫したデザインとメッセージを維持できます。
- Web サイトの外観を制御できるため、パーソナライゼーションの変更における開発者への依存が軽減されます。
- テンプレートにより、さまざまなキャンペーンや Web ページ全体でブランドの美観とメッセージの一貫性が保たれます。
- さまざまなテンプレートを試して、エンゲージメントやコンバージョンの効果を確認できます。

詳細については、[Personalize エディターの機能](/ja/user-guide/personalize/client-side-personalization/personalize-editor-capabilities)を参照してください。

# MoEngage と Salesforce の双方向リアルタイム統合

MoEngage は、Salesforce(SFDC)とのシームレスな双方向データ統合を提供します。この統合により、どのキャンペーンが商談のコンバージョン率を高めているかについてより深いインサイトが得られ、マーケティング活動と営業活動を統合できます。この統合により、次のことができます。

- Salesforce の取引先責任者、リード、商談、カスタムオブジェクト、その他の Salesforce オブジェクトを、MoEngage でユーザーまたはイベントとして作成または更新できます。
- MoEngage Streams を使用して、MoEngage のキャンペーンインタラクションデータを、アクティビティ、イベント、または任意のカスタム Salesforce オブジェクトとして Salesforce に送り返すことができます。

詳細については、[こちら](/ja/partner-guide/data-and-analytics/crm/salesforce-crm-native/overview)を参照してください。

<Info>
Salesforce AppExchange から MoEngage アプリをインストールし、MoEngage ワークスペースに接続して、同期ジョブを設定する必要があります。
</Info>

# Warehouse Segment の機能強化

Warehouse Segment のこの機能強化により、MoEngage からデータウェアハウスに対してクエリを実行することで、セグメントの作成プロセスが迅速化されます。

MoEngage からクエリを実行すると、次のことが可能になりました。

- 実行時間、スキャンされたデータ量、特定のクエリによって返されたデータの行数などのクエリ指標とともに、最近のウェアハウスクエリの一覧が表示されます。これらの指標は、クエリのパフォーマンスの最適化に役立ちます。
- クエリが成功すると、**Query results** セクションの行を展開して、各クエリのサンプル結果を確認およびダウンロードできます。
- スキーマセクションに表示されている任意のテーブルのサンプル行をプレビューできます。
- SQL エディターへの挿入、クエリのコピー、クエリの実行、結果のダウンロードといったクエリアクションを実行できます。

詳細については、[Warehouse Segments](/ja/user-guide/segment/create-segments/warehouse-segments)を参照してください。

# Private Space および Hidden Mode での通知の動作

*Private Space* 機能と *Hidden Mode* 機能により、ユーザーはデジタル上のやり取りにおいて、プライバシーと制御を強化できます。これらの機能は、保護または隠された空間を提供することで、安全で目立たないコミュニケーションを確保し、シームレスかつ安全なユーザーエクスペリエンスを実現します。

Private Space では、ユーザーは次のことができます。

- 機密情報を保存するための安全な環境を作成できます。
- セキュリティを強化するため、パスワードまたは認証に基づくアクセスを有効にできます。
- 個人データやビジネスデータを不正アクセスから保護できます。

Hidden Mode では、次の機能が提供されます。

- メインインターフェイスから特定のアプリやデータを隠すオプション
- 特定のコンテンツを他の人から見えないようにすることによるプライバシーの向上
- 機密性を損なうことのない、効率的なユーザーエクスペリエンス

詳細については、[Private Space および Hidden Mode での通知の動作](/ja/user-guide/campaigns-and-channels/mobile-push/notification-features-and-behavior/push-notification-behavior-in-private-space-and-hidden-mode)を参照してください。

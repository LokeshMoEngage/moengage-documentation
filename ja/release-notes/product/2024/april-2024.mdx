# セグメンテーションフィルター

今回のリリースでは、マーケターがターゲットオーディエンスを迅速かつ正確に定義できるよう、さまざまな新しい高度なフィルターを提供します。

## 新しいフィルター

### First/Last Activity

最初または最後のアクティビティやイベントに基づいてユーザーを検索します。指定した期間内にイベントを初めて実行したユーザー、または最後に実行したユーザーをセグメント化できます。

### Contains Spaces

イベント属性またはユーザー属性の値にスペースが含まれている場合でも、それらの属性に基づいてユーザーをセグメント化できます。スペースは属性値の先頭、途中、末尾のいずれにあってもかまいません。

### Is Empty/Not Empty

イベント値または属性値が空かどうかに基づいてユーザーをセグメント化できるようになりました。このフィルターを使用すると、選択した属性に保存されている値が空の文字列かどうかを確認できます。

### 属性の比較

異なるユーザー属性を比較できます。たとえば、*Loan Amount* と *Loan Paid* のユーザー属性を比較して、ローンが未返済のユーザーを特定できます。

## 強化されたフィルター

MoEngage では、複数のフィルターから選択する際の時間と労力を最適化し、ユーザーが迷わずに目的のユーザーをセグメント化できるよう、一部のフィルターを統合・強化しました。

既存のフィルターに導入された主な機能強化は次のとおりです。

### 文字列フィルター

文字列フィルターでは、Is、Is not、Contains、Does not contain、Starts with、Ends with、Does not start with、Does not end with などのフィルターの機能を統合・強化しました。

### 数値フィルター

数値フィルターでは、Is equal to や Not equal to などのフィルターの機能を統合・強化しました。

## 制限事項

新しいフィルターは、現在次の機能ではサポートされていません。

- Conversion Goal
- Business Event: 現時点では、Business Event ではユーザー属性の比較はサポートされていません。
- Smart Trigger: 新しいフィルターは Dynamic Condition ではサポートされていません。
- Flows: 新しいフィルターは Dynamic Condition ではサポートされていません。

詳細については、[セグメンテーションのフィルター](/ja/user-guide/segment/advanced-concepts/filters-in-segmentation)を参照してください。

# サーバーサイドパーソナライゼーション

成功を妨げる不要なボトルネックに別れを告げ、オーディエンスにパーソナライズされたエクスペリエンスを提供する、より信頼性が高く効率的な方法を取り入れましょう。

*サーバーサイドパーソナライゼーション*を使用すると、読み込みが速く、広告ブロッカーの影響を受けず、頻繁に変わるセキュリティポリシーに左右されない、堅牢なパーソナライズされたエクスペリエンスを作成できるようになりました。このサーバーサイドソリューションにより、高速で信頼性が高く効率的なプラットフォームを維持し、ユーザー満足度を高め、顧客コンバージョンの可能性を向上させることができます。

サーバーサイドパーソナライゼーションは、クライアントサイドに関連する問題を解消し、さらに多くのメリットを提供します。既存システムとの統合が容易で、高度なパーソナライゼーションのために大量のデータを処理でき、パーソナライズされたコンテンツの配信をより細かく制御できます。

サーバーサイドパーソナライゼーションの実装については、次のドキュメントを参照してください。

- [サーバーサイドパーソナライゼーションとは](/ja/user-guide/personalize/server-side-personalization/create-server-side-personalization-experience)
- [サーバーサイドパーソナライゼーション設定の構成](/ja/user-guide/personalize/server-side-personalization/configure-server-side-personalization-settings)
- [サーバーサイドパーソナライゼーションエクスペリエンスの作成](/ja/user-guide/personalize/server-side-personalization/create-server-side-personalization-experience)
- [サーバーサイドパーソナライゼーションエクスペリエンスのテスト](/ja/user-guide/personalize/server-side-personalization/test-server-side-personalization-experience)
- [Personalize API](https://www.moengage.com/docs/api/personalize-experience/personalize-overview)

# Web Personalization エディター

一般的なユーザーは、日常的に何百もの製品に接しています。テクノロジー業界が急速に成長する中、多くの競合の中で際立つことは困難であると同時に、極めて重要です。効果的な戦略の1つは、ユーザーの興味、過去の行動、属性情報に基づいて、ユーザージャーニーのあらゆる節目をパーソナライズすることです。

このニーズに応えるため、MoEngage は Web Personalization(WebP)エディターを導入します。このエディターを使用すると、ビジネス標準、ワークフロー、好みに合わせて、アプリケーションのインターフェイス、要素、テーマ、ウィジェットを調整できます。

詳細については、[Personalize エディターの機能](/ja/user-guide/personalize/client-side-personalization/personalize-editor-capabilities)を参照してください。

# MoEngage Apps 向けの Outbound Segment Sync

Outbound Segment Sync を使用すると、MoEngage で作成した価値の高い顧客セグメントを、技術スタック内の他のプラットフォームに簡単に同期して送信できます。

これらのセグメントは、広告ネットワーク、ロイヤルティプラットフォーム、レコメンデーションエンジン、実験ツールなど、さまざまなプラットフォームに同期でき、ターゲットを絞ったエンゲージメントの促進や、よりデータに基づいた意思決定など、さまざまなビジネスユースケースに活用できます。

詳細については、[Outbound Segment Sync](/ja/user-guide/data/exports/segments/outbound-segment-sync)を参照してください。

# イベントトラッキングガイド

MoEngage は、イベントトラッキングに関する包括的なガイドを公開しました。このガイドでは、マーケティングにおけるイベントトラッキングの重要性から、MoEngage を使用した実践的な実装戦略まで、イベントトラッキングの世界を詳しく解説しています。

## このドキュメントの内容

このイベントトラッキングガイドは、イベントトラッキングの複雑さをわかりやすく解説するワンストップのリソースです。イベントの理解、イベントプロパティの定義、MoEngage でのトラッキングの実装、イベントトラッキング戦略の最適化など、主要な概念を詳しく説明しています。

## 対象読者

このガイドは、マーケティング、プロダクトマネジメント、データ分析に携わる方を対象としています。経験豊富なマーケターの方にも、これから始める方にも、イベントトラッキングを効果的に活用するために必要な知識とツールを提供します。

## メリット

イベントトラッキングの詳細を理解することで、ユーザー行動に関する貴重なインサイトを引き出し、マーケティングキャンペーンを最適化し、ビジネスの成長を促進できます。MoEngage のプラットフォーム固有のインサイトと戦略を活用して、マーケティング活動を次のレベルへと引き上げることができます。

さらに、eコマース、BFSI、Fintech、Media/OTT の4つの主要業界向けに、業種別のイベントトラッキングプランを作成したことをお知らせします。これらのカスタマイズされたプランでは、業界固有のガイダンスとベストプラクティスを提供し、イベントトラッキングの取り組みの効果を最大化できるよう支援します。

詳細については、[イベントトラッキング完全ガイド](/ja/user-guide/data/event-data/a-complete-guide-to-event-tracking)を参照してください。

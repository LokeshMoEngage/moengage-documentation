# アウトバウンドチャネル

## 標準化された UTM パラメータをキャンペーンと Flows に引き継ぐ機能

Urchin Tracking Module(UTM)パラメータは、URL の末尾に追加できるタグまたはシンプルなスニペットコードで、さまざまなトラフィックソースからのユーザーエンゲージメントを分析ソフトウェアで正確に追跡するために使用します。UTM パラメータには、utm\_source、utm\_medium、utm\_campaign、utm\_term、utm\_content の5つがあります。

### 既存の動作

マーケターは、キャンペーンで使用するすべてのリンクに UTM パラメータを手動で追加できます。マーケターは、複数のチャネルやプラットフォームにわたって多数のキャンペーンを実行している場合があります。これらのキャンペーンで使用するすべてのリンクに UTM パラメータを手動で追加すると、エラーが発生しやすく、担当者による監視も必要になります。

### 新しい動作

MoEngage は、UTM パラメータの作成プロセスを標準化するため、アカウントレベルの UTM パラメータ設定ページを導入しました。この機能により、各リンクに UTM パラメータを設定するマーケターの労力が軽減され、エラーの可能性も低減されます。

アカウントレベルで一般 UTM パラメータを有効にし、キャンペーンと Flows の値を定義できます。カスタムパラメータを作成することもできます。一般 UTM パラメータは、キャンペーンと Flows に自動的に引き継がれます。必要に応じて、キャンペーンレベルおよび Flow レベルで一般パラメータを上書きできます。

<Info>
- 現在、この機能はメールチャネルでのみサポートされています。
- アカウントレベルで構成した UTM パラメータは、スタンドアロンのメールキャンペーンと、Flows の一部として作成されたメールキャンペーンに影響します。
- その他のキャンペーンでは、リンクに UTM パラメータを手動で追加する必要があります。
- メールキャンペーンの作成時に URL の一部として UTM パラメータを手動で渡した場合、MoEngage はそのメールキャンペーンで自動 UTM パラメータをスキップします。
</Info>

詳細については、[アカウントレベルでの一般 UTM パラメータの構成
](/ja/user-guide/settings/advanced-settings/configure-general-utm-parameters-at-account-level)、[キャンペーンへの UTM パラメータの追加](/ja/user-guide/settings/advanced-settings/add-utm-parameters-to-campaigns)、および[メールキャンペーンの作成](/ja/user-guide/campaigns-and-channels/email/create/create-an-email-campaign)を参照してください。

# インバウンドチャネル

## OSM コンテンツのパーソナライゼーション

MoEngage は、On-site Messaging(OSM)キャンペーンのコンテンツをパーソナライズするための、より優れたオプションを導入しました。これにより、キャンペーンの作成機能とカスタマイズ機能が大幅に強化されました。今回のリリースの主な機能強化は次のとおりです。

- **画像のパーソナライゼーションと Product Sets**: 画像のパーソナライゼーションと Product Sets を使用して、よりダイナミックなキャンペーンを作成できます。オーディエンスの好みや行動に合わせて、ビジュアルや製品レコメンデーションをカスタマイズできます。
- **編集可能な Jinja コード**: テンプレート内で JINJA コードを直接編集して変更を保存できるため、より正確なカスタマイズと制御が可能になります。
- **コンパクトなパーソナライゼーション**: テンプレートに長い JINJA コードが表示される代わりに、必要な属性のみが表示されるようになりました。これにより、テンプレートがすっきりし、パーソナライゼーションが容易になります。

詳細については、[OSM コンテンツのパーソナライゼーション](/ja/user-guide/campaigns-and-channels/on-site-message/create/personalization-of-osm-content)を参照してください。

# Personalize

## Personalize を使用したモバイル Web サイトの編集機能

デスクトップ版と同じエクスペリエンスで、モバイルデバイス向けの Web サイトをパーソナライズできるようになりました。MoEngage の **Personalization Editor** の上部で、異なるデバイスを切り替えることができます。

**Personalization Editor** は、顧客が携帯電話やタブレットで見るのと同じように Web サイトを読み込みます。デスクトップ Web サイトと同じ方法で Web サイトをパーソナライズでき、**Interact Mode** 機能を使用してさらにカスタマイズすることもできます。

詳細については、[エクスペリエンスの作成](/ja/user-guide/personalize/client-side-personalization/client-side-personalization/create-client-side-personalization-experience)を参照してください。

# Analytics

## User Analysis

ユーザープロパティは、ユーザーエクスペリエンスのパーソナライズ、特定のオーディエンスのターゲティング、個々のニーズや好みに合わせたコンテンツ、サービス、製品の調整において非常に重要です。User Analysis を使用すると、ユーザー属性を分析してユーザーの好みを把握し、それに基づいたターゲットキャンペーンを実行できます。詳細については、[User Analysis](/ja/user-guide/analyze/analytics/users/analysis)を参照してください。

## User Path

MoEngage Analytics の User Paths モジュールを使用すると、ユーザーが Web アプリやモバイルアプリでどのように操作し、移動しているかを可視化できます。ユーザーパス分析とは、ユーザーのイベントの軌跡を分析することです。User Path は、特定のイベントを実行した後または前にユーザーが実行しているイベントを分析します。

この機能により、ユーザーが最もよく通るパスや、ユーザーエクスペリエンスにおけるボトルネックや摩擦点を特定できます。詳細については、[User Paths](/ja/user-guide/analyze/analytics/user-paths/user-paths-overview)を参照してください。

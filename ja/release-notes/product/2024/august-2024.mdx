# メールチャネル向け Merlin AI の導入

魅力的なメールコンテンツを作成するのは、特に綿密なリサーチ、分析、コンテンツの推敲が必要な場合、手間がかかり複雑な作業です。その解決策として、MoEngage はメールチャネルで Merlin AI をサポートし、メールの件名とプレビューテキストを生成できるようになりました。コンテキストを指定するか、手動で作成した件名を AI で強化することで、Merlin AI を使用して魅力的なメールの件名を作成できます。

詳細については、[Merlin AI によるメールの件名とプレビューテキストの生成](/ja/user-guide/ai-and-intelligence/merlin-ai/merlin-ai-copywriter/generate-email-subject-line-and-preview-text-with-merlin-ai)を参照してください。

# SFTP Exports の導入

MoEngage は、双方向統合ファミリーの新たな機能として SFTP Exports を導入しました。  
データを SFTP サーバーに直接エクスポートできるようになりました。

## メリット

- セルフサービスでのセットアップ: App Marketplace に移動し、SFTP の詳細を入力して、エクスポートするユーザー属性とイベントを選択します。
- 複数の頻度: データをエクスポートするタイミングを、15分ごと、毎日、さらには毎週から選択できます。
- 多数のエクスポート: 1つのアプリに対して複数のエクスポートを設定できます。つまり、同じ MoEngage アプリから、さまざまなニーズに応じて異なるデータセットをエクスポートできます。
- 接続テスト: 認証情報を簡単に検証できます。

詳細については、[SFTP](/ja/partner-guide/data-and-analytics/cloud-storage/sftp)を参照してください。

# Global Exit Criteria

*Global Exit Criteria* 機能により、Flow の管理をより細かく制御できます。ユーザープロパティやイベントに基づいて特定のルールを定義でき、その条件を満たすと、ユーザーが Flow 内のどこにいても自動的に Flow から除外されるようになりました。

## メリット

- 手動での除外が不要: すべてのコミュニケーションの前に条件ステージを追加する必要がなくなります。
- Flow の効率化: Flow をすっきりと保ち、分析しやすくします。不要なステージに煩わされることはありません。
- 少ない労力でより細かく制御: 最大5つの条件(それぞれ最大5つのサブ条件)を設定して、ユーザーの除外条件を最適に調整できます。
- 時間の節約: 細かな管理に費やす時間を減らし、戦略立案により多くの時間を充てられます。
- 関連性の維持: 最終目標との関連性がなくなったユーザーを Flow から自動的に除外します。

詳細については、[Global Exit Criteria](/ja/user-guide/flows-cross-channel-messaging/create/create-flows/create-a-flow#global-exit-criteria)を参照してください。

# 監査ログ

どのような変更が、いつ、誰によって行われたかを把握することは、どのクライアントにとっても非常に重要です。そのような変更が複数のキャンペーンに影響する場合や、顧客が重要なビジネス上の意思決定に使用するレポートに変更が生じる場合には、さらに重要になります。

MoEngage は、意図しない変更を検出して修正し、キャンペーンがエラーなく送信されるようにするため、監査ログを導入しました。

新しい監査ログでは、次の機能が追跡されます。

- Content Blocks
- UTM Parameters
- Tags
- Content API
- Global Control Group
- Reports
- Inform

これらの機能で追跡されるイベントの詳細については、[監査ログ](/ja/user-guide/settings/account/audit-logs/audit-logs)を参照してください。

# Auxiliary Import の機能強化

Auxiliary Imports が次の機能強化によりアップグレードされました。

- 保持期間を30日以上に延長できるようになり、2か月、3か月、または最長1年に設定できます。さらに、「Infinite retention」期間を設定することもできます。
- 既存の Auxiliary インポートの保持期間を延長できるようになりました。
- MoEngage UI で、Auxiliary の「Data expiry」という用語が「Data retention period」に更新されました。
- さらに、Auxiliary データを使用したパーソナライゼーションが、Push、SMS、InApps、Cards、Onsite キャンペーン、Website personalization、Connector キャンペーンにも拡張されました。

詳細については、[Auxiliary Data](/ja/user-guide/data/imports/auxiliary-data)を参照してください。

# Catalog API の導入

Catalog API は、価格や数量の変更などのリアルタイム更新を自動化することで、製品やアイテムの管理を強化する最新の方法です。処理スケジュールのたびにファイル全体を置き換える必要があるファイルベースのカタログとは異なり、これらの API は特定の製品のみを更新するため、効率性とスケーラビリティが向上します。これらの API には任意の場所からアクセスし、更新に使用できます。

Catalog API では、次のことができます。

- カタログの作成
- 新しいカタログ属性の追加
- カタログへのアイテムの取り込み
- カタログ内の既存アイテムの更新
- 既存アイテムの削除

詳細については、[Catalog API](https://www.moengage.com/docs/api/catalog/catalog-overview)を参照してください。

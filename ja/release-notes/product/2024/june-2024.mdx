# In-App メッセージおよび On-Site Messages 向け Merlin AI

Merlin AI は、リサーチ、分析、コンテンツの推敲といった手作業なしに、魅力的なマーケティングキャンペーンを作成できるよう顧客を支援します。このツールは、ビジネスのコンテキスト、ブランドのトーンとスタイル、ターゲットオーディエンスを理解し、ユーザーエンゲージメントを促進する関連性の高いコンテンツを提供するように設計されています。まさに、すべてのマーケターをヒーローにするための機能です。

## 特長

- コンテキストの認識: Merlin AI はオーディエンスを理解し、共感を呼ぶ高品質なマーケティングキャンペーン用の文章コンテンツを作成します。
- 感情への訴求: 感情に訴えるコンテンツは、オーディエンスの注目を効果的に集め、コンバージョンを促進します。マーケターは、さまざまなトーンでメッセージを生成したり、試したりできます。
- LLM から着想を得た創造性: キャンペーンのユースケースやターゲットオーディエンスに基づいてメッセージをカスタマイズでき、さまざまなメッセージスタイルを試すことができます。
- 使いやすいプロンプトビルダー: プロンプトの作成は MoEngage が担うため、マーケターがプロンプトを作り込む必要はありません。コンテキストのフィルターや入力を指定するだけです。
- キーワード分析: Push チャネルのヒーローキーワードを使用して、インバウンドチャネルにおける Merlin AI のキーワード候補を提示します。

詳細については、[Merlin AI による In-App メッセージの生成](/ja/user-guide/ai-and-intelligence/merlin-ai/merlin-ai-copywriter/generate-in-app-messages-with-merlin-ai)および[Merlin AI による On-site Messages の生成](/ja/user-guide/ai-and-intelligence/merlin-ai/merlin-ai-copywriter/generate-on-site-messages-with-merlin-ai)を参照してください。

# ベンダーから MoEngage への WhatsApp テンプレートの同期

MoEngage では、構成済みのパートナーから MoEngage プラットフォームにテンプレートを同期できます。テンプレートを同期すると、前回の更新以降に更新されたテンプレートがパートナーポータルから自動的に取得されます。現在は Gupshup からテンプレートを同期でき、完了まで最大15分かかる場合があります。

## 特長

- 重複ゼロ: 同じテンプレートを MoEngage プラットフォームで再作成する必要がなくなるため、労力と貴重な時間を節約できます。
- 正確な配信: 自動同期によりエラーが減少し、すべてのテンプレートの正確性が確保されるため、メッセージを確実に配信できます。
- 簡単な監視: MoEngage ポータル上で、テンプレートのステータスをリアルタイムで追跡できます。

詳細については、[WhatsApp テンプレート](/ja/user-guide/campaigns-and-channels/whatsapp/getting-started-with-whatsapp/whatsapp-templates)を参照してください。

# Flows へのユーザーの参加を制限する頻度オプションの追加

既存の年単位の制限オプションに加えて、日、週、月の単位でユーザーの参加頻度を指定できるようになりました。

## メリット

- ユーザー疲れの解消: ユーザーが Flow に接触する回数を制御することで、ユーザーの疲弊を防ぎ、マーケティング活動の効率を高めます。
- 最適なリソース配分: Flow へのリソース配分を最適化し、マーケティング予算をより効果的に活用できます。
- 精密なターゲティング: 日、週、月の頻度オプションにより、ユーザーの利用習慣に合わせたより精密なターゲティングが可能になり、マーケティングメッセージが見られる可能性を最大化し、ユーザーエンゲージメントの向上につながります。

詳細については、[Flow の作成](/ja/user-guide/flows-cross-channel-messaging/create/create-flows/create-a-flow)を参照してください。

# すべてのユーザーを対象に Push Opt-In イベントを有効化

Android 13 で通知の許可の仕組みが変更されたことを受けて、MoEngage は Android Push のリーチャビリティを改善・追跡するための機能を追加してきました。今回のリリースでは、次のイベントを追加しました。

- Subscribed to Push: このイベントは、ユーザーがオプトインプロンプトでデバイスのプッシュ許可を承認した場合、または設定でプッシュ許可をオンにした場合にトリガーされます。
- Unsubscribed to Push: このイベントは、ユーザーがオプトインプロンプトでデバイスのプッシュ許可をブロックした場合、または設定でプッシュ許可をオフにした場合にトリガーされます。

## 対象

これまでは、例外またはアドオンとして一部のワークスペース(DB)でのみ有効になっていました。2024年5月28日以降、すべての顧客に対してデフォルトで有効になりました。

このイベントは現在 Android でのみ利用可能で、iOS と Web 向けにも近日中にリリースされる予定です。これらのイベントにはプラットフォーム属性があり、プラットフォームごとにイベントを分類するために使用できます。

詳細については、[Android のプッシュ許可とリーチャビリティ](/ja/user-guide/campaigns-and-channels/mobile-push/notification-features-and-behavior/android-push-permission-and-reachability)を参照してください。

# Warehouse Segment

Warehouse Segment を使用すると、データウェアハウスのデータに基づいて MoEngage でセグメントを作成できます。  
*Warehouse Segment* を使用すると、ウェアハウスのデータを MoEngage にコピーしたり移動したりすることなく、簡単にアクセスして活用できるため、ワークフローが簡素化され、タイムリーなエンゲージメントが可能になります。

## メリット

- 同期の手間が不要: Warehouse Segment により、MoEngage への複雑なデータ同期が不要になります。
- 即時のオーディエンス: Warehouse Segment により、ウェアハウスのデータに即座にアクセスでき、データの利用可能性に関する遅延がなくなります。SQL 定義を MoE に保存し、キャンペーンの実行時にセグメントを処理することで、オーディエンスセグメントをその場で生成できます。
- プライバシーとコンプライアンス: データはウェアハウス内に安全に保持され、直接アクセスされるため、Warehouse Segment はデータセキュリティと規制遵守に関する懸念に対応します。
- 依存関係ゼロ: Warehouse Segment を使用すると、マーケターは、データを利用可能にするための ETL パイプラインの構築や保守をエンジニアリングチームに頼ることなく、ウェアハウスのデータから直接オーディエンスセグメントを作成できます。
- コスト効率: Warehouse Segment により、定期的なデータ転送パイプラインを構築するための追加の ETL ツールが不要になるため、データ同期に関連するオーバーヘッドコストが削減され、それらの管理に必要なリソースも不要になります。

詳細については、[Warehouse Segments](/ja/user-guide/segment/create-segments/warehouse-segments)を参照してください。

# Web ページ上の要素の並べ替え

MoEngage は、Personalize Editor に新機能 *Rearrange element* を追加して強化しました。この機能により、Web サイト訪問者のエクスペリエンスが大幅に向上します。この機能を使用すると、閲覧エクスペリエンスを調整し、好みやニーズに合わせた高度にパーソナライズされたレイアウトを作成できます。

詳細については、[要素の並べ替え](/ja/user-guide/personalize/client-side-personalization/personalize-editor-capabilities/rearranging-elements)を参照してください。

# Personalize のアンチフリッカーの強化

ページの読み込み時間の遅延に対応するため、アンチフリッカースニペットに最新のアップデートを実装しました。この更新されたスニペットは、パーソナライズされた要素のみを非表示にする機能を維持しながら、ページの読み込み時間の問題に対処します。  
パーソナライズされた変更が適切に表示されることを確保しつつ、よりスムーズなページ遷移と高速な読み込みを体験できるようになります。

詳細については、[フリッカーの管理](/ja/user-guide/personalize/things-to-know/how-to-manage-flicker-on-websites)を参照してください。

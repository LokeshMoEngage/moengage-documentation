# In-App キャンペーンのエラー内訳テーブル

MoEngage のエラー内訳テーブルは、In-App キャンペーンの問題を特定する時間を節約できる最新の新機能です。エラー内訳テーブルは、キャンペーン分析ページで確認できます。この機能により、次のことが可能になります。

- 即時診断の実行
- 自力でのトラブルシューティング
- キャンペーンの迅速な最適化

詳細については、[In-App キャンペーン分析](/ja/user-guide/campaigns-and-channels/in-app-message/analyze/analyze-in-app-campaigns)を参照してください。

# Apple Privacy Manifest の更新

WWDC23 で、Apple は SDK 向けの新しいプライバシーマニフェストと署名を導入しました。これは、アプリ開発者がサードパーティ SDK によるデータの使用方法をより深く理解し、ソフトウェアの依存関係を保護し、ユーザーに追加のプライバシー保護を提供できるようにするためのものです。

2024年春以降、新しいアプリまたはアプリのアップデートの申請で、App Store のアプリで一般的に使用されているサードパーティ SDK を追加する場合は、その SDK のプライバシーマニフェストを含める必要があります。

詳細については、[Apple Privacy Manifest の更新](/ja/user-guide/data/privacy/apple-privacy-manifest-update)を参照してください。

# シームレスな ID 管理のための SCIM

System for Cross-domain Identity Management(SCIM)は、2つのシステム間でユーザー ID 情報を交換できるオープン標準です。今回のリリースで、ID 管理のために SCIM を構成できるようになりました。ID プロバイダーと MoEngage の間でユーザー ID 情報を交換します。

詳細については、[System for Cross-domain Identity Management(SCIM)](/ja/user-guide/settings/account/security/system-for-cross-domain-identity-management-scim)を参照してください。

# Snowflake Exports の導入

Snowflake は、組織が大量の構造化データおよび半構造化データを、スケーラブルかつ効率的に保存、分析、処理できるデータプラットフォームです。

MoEngage は、Campaign Interaction Events を Snowflake テーブルに直接ダンプできるようになりました。これにより、MoEngage は Snowflake との双方向統合を実現し、2つのプラットフォーム間でデータをシームレスに同期できるようになりました。

詳細については、[Snowflake 統合](/ja/partner-guide/data-and-analytics/data-warehouses/snowflake)を参照してください。

MoEngage Message Archival API は、顧客に送信したコミュニケーションの履歴記録を保存し、アクセスする手段を提供します。この API を利用すると、特定のユーザーに特定の時点で配信された正確なコンテンツ（タイトル、メッセージ、メディア URL を含む）を取得できます。

これは、顧客が受信した内容を確認する必要があるカスタマーサポートチームや、メッセージングの履歴記録が必要なコンプライアンス監査に特に役立ちます。

## エンドポイント

Message Archival API は、次のエンドポイントで構成されています。

* [View Archived Message](/ja/api/message-archival/view-archived-message): Push、Email、SMS でユーザーに送信された特定のメッセージの完全なコンテンツとメタデータを取得します。

## よくある質問

<Accordion title="メッセージを取得するために一意に識別するにはどうすればよいですか？" icon="fingerprint">
  メッセージを取得するには、コミュニケーションの `user_id`、`campaign_id`、`sent_epoch_time`（Unix タイムスタンプ）を指定する必要があります。イベントトリガー型のキャンペーンの場合は、`event_id` を渡すことも必要です。
</Accordion>

<Accordion title="message_content と backup_content の違いは何ですか？" icon="copy">
  - **message_content**: ユーザーに送信された実際のパーソナライズされたコンテンツが含まれます。
  - **backup_content**: パーソナライズが失敗した場合や適用されなかった場合に使用される、元のテンプレートまたはデフォルトのコンテンツが含まれます。
</Accordion>

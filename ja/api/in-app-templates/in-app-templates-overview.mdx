MoEngage In-app Templates API を使用すると、MoEngage プラットフォーム内で In-app テンプレートをシームレスに管理できます。この API により、MoEngage エコシステムの外部で作成されたテンプレート（**Self-Handled** と **HTML** の両タイプに対応）をアップロードし、キャンペーンの作成に使用できます。

これらのエンドポイントを使用すると、テンプレートのバージョンの作成、さまざまなフィルターを使用した既存ライブラリの検索、テンプレートの更新をアクティブなキャンペーンに自動的に反映するかどうかの選択を行うことができます。

## エンドポイント

In-app Templates API は、次のエンドポイントで構成されています。

* [Create In-app Template](/ja/api/in-app-templates/create-in-app-template): 新しい In-app テンプレート（Self-Handled または HTML）を作成します。
* [Update In-app Template](/ja/api/in-app-templates/update-in-app-template): 既存のテンプレートを更新します。
* [Search In-app Templates](/ja/api/in-app-templates/search-in-app-templates): 名前、ソース、タイプ、作成者 ID などのフィルターを使用してテンプレートを検索します。

## よくある質問

<Accordion title="API ではどのテンプレートタイプがサポートされていますか？" icon="layer-group">
  現在、API は **SELF_HANDLED**（JSON ベース）および **INAPP_HTML** テンプレートタイプをサポートしています。
</Accordion>

<Accordion title="テンプレートの更新をアクティブなキャンペーンに適用するにはどうすればよいですか？" icon="arrows-rotate">
  **Update In-app Template** API を使用する際に、`update_campaigns` フラグを `true` に設定します。これにより、そのテンプレートを現在使用している実行中のすべてのキャンペーンが最新バージョンに更新されます。
</Accordion>

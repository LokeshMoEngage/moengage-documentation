コンテンツブロックを使用すると、マーケターは同じコンテンツを複数のキャンペーンで再利用できます。メッセージごとに標準的な要素を作り直す代わりに、ヘッダー、フッター、デザインされた Call-To-Action ボタンなどのブロックを一度作成すれば、あらゆる場所で参照できます。

MoEngage Content Block API を使用すると、MoEngage ダッシュボード上でこれらのコンテンツブロックを取得、作成、更新できます。

<Info>
  ワークスペースで作成できるコンテンツブロックの数に厳密な上限はありません。ただし、ワークスペース内のコンテンツブロックが約 30,000 個を超えると、エディターのパフォーマンスが低下し始める場合があります。この規模に近づいたら、使用しなくなったコンテンツブロックをアーカイブまたは削除することをお勧めします。
</Info>

## エンドポイント

Content Block API は、次のエンドポイントで構成されています。

- [Create Content Block](/ja/api/content-blocks/create-content-block): コンテンツブロックを作成します。
- [Update Content Block](/ja/api/content-blocks/update-content-block): ID で指定したコンテンツブロックを更新します。
- [Get Specific Content Blocks](/ja/api/content-blocks/get-specific-content-blocks): 利用可能なコンテンツブロックから特定のコンテンツブロックを取得します。
- [Search Content Blocks](/ja/api/content-blocks/search-content-blocks): MoEngage アカウントで作成されたコンテンツブロックを検索します。

MoEngage File Imports API を使用すると、MoEngage ダッシュボードに移動することなく、インポートおよびインポート内のファイルのステータスを事前に追跡できます。

## ユースケース

- MoEngage ダッシュボードに移動することなく、指定した期間のすべてのインポートの処理ステータスを取得します。
- 自動化されたキャンペーンでの失敗を事前に通知します。たとえば、インポートオプションを通じて MoEngage に取り込まれた最新のユーザーリストを使用して自動化されたキャンペーンを実行する必要がある場合に、何らかの理由でインポートが失敗すると、キャンペーンのリーチに影響する可能性があります。通常、インポートの失敗に気付くのは、MoEngage ダッシュボードに移動したときか、メールアラートを受け取ったときだけです。しかし、この API を使用すると、キャンペーンに影響が出る前にステータスを事前に追跡できます。

## エンドポイント

File Imports API は、次のエンドポイントで構成されています。

- [Trigger File Imports API](https://www.moengage.com/docs/api/file-import/trigger-file-imports): スケジュールされたファイルインポートをトリガーします。
- [Import Details API](https://www.moengage.com/docs/api/file-import/import-details): インポートレベルでステータスを取得します。
- [Import File Run History API](https://www.moengage.com/docs/api/file-import/import-file-run-history): インポートに含まれる各ファイルのファイル処理ステータスを取得します。

MoEngage SMS Template API を使用すると、マーケターは MoEngage エコシステムの外部で作成された SMS テンプレートを簡単に定義、再利用、更新、管理できます。同じテンプレートの複数のバージョンを作成し、現在アクティブなキャンペーンで使用できるかどうかを指定できます。ユーザーは Create SMS Template API を使用してテンプレートを作成し、Update SMS Template API を使用して更新するか、MoEngage ダッシュボードで編集できます（ロールに対して許可されたテンプレートの編集権限がある場合）。 

## エンドポイント

SMS Template API は、以下のエンドポイントで構成されています。

- [Create SMS Template](/ja/api/sms-templates/create-sms-template): SMS テンプレートを作成します。
- [Update SMS Template](/ja/api/sms-templates/update-sms-template): Template ID で指定された SMS テンプレートを更新します。
- [Search SMS Template](/ja/api/sms-templates/search-sms-templates): Template ID、またはテンプレート名、テンプレートバージョンなどのその他のフィルターを使用して SMS テンプレートを取得します。MoEngage で作成されたすべての SMS テンプレートを一覧表示することもできます。

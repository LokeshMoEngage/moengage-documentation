MoEngage Coupon Management API を使用すると、一意の使い捨てクーポンコードを大規模に整理して配布できます。これらのエンドポイントを使用して、作成やファイルのアップロードから、有効化、アーカイブ、詳細な使用状況レポートまで、クーポンリストのライフサイクルを自動化できます。

## エンドポイント

Coupon Management API は、3 つの機能領域に分類されています。

### クーポンリスト (メタデータとステータス)

- [Create a Coupon List](/ja/api/coupon-lists/create-a-coupon-list): 一意のコード用の新しいカテゴリを定義します。
- [Fetch All Coupon Lists](/ja/api/coupon-lists/fetch-all-coupon-lists): アクティブまたはアーカイブ済みのクーポンコンテナーの一覧を取得します。
- [Fetch Coupon List Details](/ja/api/coupon-lists/fetch-coupon-list-details): 利用可能なクーポン数と総クーポン数をリアルタイムで取得します。
- [Update a Coupon List](/ja/api/coupon-lists/update-a-coupon-list): 名前、有効期限、またはアラート設定を変更します。
- [Activate Coupon List](/ja/api/coupon-lists/activate-coupon-list): アーカイブ済みのリストを新しい有効期限で再有効化します。
- [Archive a Coupon List](/ja/api/coupon-lists/archive-a-coupon-list): リストを非アクティブに移行し、関連付けられたコードを削除します。

### クーポンファイル (在庫管理)

- [Upload Coupon File](/ja/api/coupon-files/upload-a-coupon-file-to-the-coupon-list): ホストされたファイルの URL を介してリストにデータを投入します。
- [Fetch All Coupon Files](/ja/api/coupon-files/fetch-all-coupon-files-from-coupon-list): アップロードされたすべてのバッチのステータスを追跡します。
- [Fetch a Coupon File](/ja/api/coupon-files/fetch-a-coupon-file-from-coupon-list): 特定のファイルの処理ステータス (PENDING など) を確認します。
- [Delete a Coupon File](/ja/api/coupon-files/delete-a-coupon-file-from-the-coupon-list): 特定のバッチを削除します (アップロードエラーの修正に便利です)。

### レポート

- [Generate Usage Report](/ja/api/reports/generate-usage-report): 特定のクーポンリストの詳細な使用状況レポートを生成し、どのユーザーがどのクーポンを受け取ったかの詳細を提供します。

ロケールとは、ユーザープロパティのフィルターで構成された名前付きのオーディエンス定義であり、言語、文化、リージョンに合わせてキャンペーンメッセージをローカライズするために使用します。たとえば、`es-MX` という名前のロケールは、最後に確認された国がメキシコであるユーザーを対象にすることができます。

MoEngage Locales API を使用すると、ワークスペースで設定されているロケールを一覧表示し、名前または ID で単一のロケールを検索できます。ロケールを作成または編集するには、MoEngage ダッシュボードを使用してください。詳細については、[Locales](/ja/user-guide/settings/advanced-settings/locales) を参照してください。

## エンドポイント

Locales API は、次のエンドポイントで構成されています。

- [List Locales](/ja/api/locales/list-locales): ワークスペース内のすべてのロケール、または名前か ID で指定した単一のロケールを返します。

## ページネーション

一覧のレスポンスでは、1 ページあたり最大 20 件のロケールが返されます。`pagination.has_more` が `true` の場合は、`pagination.next_cursor` を `cursor` クエリパラメーターとして渡して次のページを取得します。カーソルは不透明な値として扱い、デコードや変更は行わないでください。

## よくある質問

### ロケールの管理

<AccordionGroup>
  <Accordion title="この API でロケールを作成または編集できますか？">
    いいえ。このエンドポイントは読み取り専用です。ロケールの作成と編集は MoEngage ダッシュボードから行ってください。詳細については、[Locales](/ja/user-guide/settings/advanced-settings/locales) を参照してください。
  </Accordion>
  <Accordion title="単一のロケールを検索するにはどうすればよいですか？">
    [List Locales](/ja/api/locales/list-locales) に `name` または `id` のいずれかを渡します。両方を指定すると `400` エラーが返されます。両方を省略すると、ワークスペース内のすべてのロケールが一覧表示されます。
  </Accordion>
  <Accordion title="作成できるロケールの数に制限はありますか？">
    いいえ。ワークスペースで作成できるロケールの数に制限はありません。
  </Accordion>
  <Accordion title="2 つのロケールに同じ名前を付けることはできますか？">
    いいえ。ロケール名はワークスペース内で一意であるため、正確な名前でロケールを検索できます。
  </Accordion>
</AccordionGroup>

### レスポンスについて

<AccordionGroup>
  <Accordion title="campaign_count は何を示していますか？">
    現在そのロケールを使用しているキャンペーンの数です。これは、ダッシュボードの Locales ページにある **Campaigns associated** 列と一致します。
  </Accordion>
  <Accordion title="custom_segment_id とは何ですか？">
    ロケールはユーザープロパティのフィルターによって定義され、MoEngage はそれをカスタムセグメントとして保存します。`custom_segment_id` はそのセグメントを識別します。カスタムセグメントを持つロケールの場合にのみ返されます。
  </Accordion>
</AccordionGroup>

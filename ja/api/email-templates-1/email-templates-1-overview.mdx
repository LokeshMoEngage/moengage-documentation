MoEngage Email Template API を使用すると、マーケターは MoEngage エコシステムの外部で作成されたメールテンプレートを簡単に定義、再利用、更新、管理できます。これらの API を使用して作成・更新されたテンプレートは、Custom HTML Editor（Froala Editor）でサポートされており、Drag and Drop Editor ではサポートされていません。

## エンドポイント
Email Template API（V1）は、次のエンドポイントで構成されています。

- [Create Email Template](/ja/api/email-templates/create-email-template-v1): メールテンプレートを作成します。
- [Update a Specific Email Template](/ja/api/email-templates/update-specific-template): Template ID で指定したメールテンプレートを更新します。
- [Bulk Create/Update Email Template](/ja/api/email-templates/bulk-createupdate-templates): メールテンプレートを一括で作成・更新します。
- [Get a Specific Email Template](/ja/api/email-templates/get-specific-template): Template ID を使用してメールテンプレートを取得します。
- [Get all Email Templates](/ja/api/email-templates/get-all-templates): MoEngage アカウント内のすべてのメールテンプレートを取得します。


## よくある質問

### Create Email Template

<Accordion title="この API を使用して作成したテンプレートに MoEngage ダッシュボードでアクセスするにはどうすればよいですか？" icon="sparkles">
  Create Email Template API を使用して作成したテンプレートには、以下の画像のように、MoEngage ダッシュボードでのキャンペーン作成の 2 番目のステップにある My Saved Templates タブからアクセスできます。

  ![保存済みテンプレートへのアクセス](/images/AccessSavedTemplates_CUSTOMTEMPLATEAPI.png)
</Accordion>

### Update a Specific Email Template

<Accordion title="リクエストで一部のフィールドを渡さず、作成済みのテンプレートにそれらのフィールドが既にある場合、更新後もそれらは保持されますか？" icon="sparkles">
  更新リクエストは、既存のテンプレートを更新リクエストで指定されたテンプレートで上書きします。作成済みのテンプレートにあったフィールドの一部が更新リクエストに含まれていない場合、更新後のテンプレートにもそれらのフィールドは含まれません。たとえば、更新リクエストで添付ファイルを渡さなかった場合、作成時に添付ファイルがあったとしても、更新後のテンプレートには添付ファイルが含まれません。
</Accordion>

### Bulk Create/Update Email Template

<Accordion title="作成リクエストとテンプレート更新リクエストはどのように区別されますか？" icon="sparkles">
  更新の場合、更新対象のテンプレートはテンプレート ID によって識別されます。テンプレート更新リクエストでは、id フィールドを渡すことが必須です。渡さない場合は、テンプレート作成リクエストとして扱われます。
</Accordion>

### Get a Specific Email Template

<Accordion title="削除済みのテンプレートを検索するとどうなりますか？" icon="sparkles">
  その場合、エラーの説明に次のメッセージが含まれます: "_Template for given template id is archived_"。
</Accordion>

MoEngage On-Site Messaging（OSM）Templates API を使用すると、Web サイトおよびアプリサイトのメッセージングテンプレートを管理できます。この API を使用して、MoEngage エコシステムの外部で作成されたカスタム HTML テンプレートをアップロードし、OSM キャンペーンで利用できるようにします。

この API は、**Banners**、**Pop-ups**、**Nudges** などの複数のテンプレート形式をサポートしています。この API で作成されたテンプレートは、MoEngage ダッシュボードの **Custom HTML Editor** 内でサポートされており、Drag and Drop Editor では使用できないことに注意してください。

## エンドポイント

OSM Templates API は、次のエンドポイントで構成されています。

* [Create OSM Template](/ja/api/osm-templates/create-osm-template): HTML ペイロードを使用して新しい OSM テンプレートを作成します。
* [Update OSM Template](/ja/api/osm-templates/update-osm-template): 既存の OSM テンプレートを更新し、キャンペーンのバージョン管理を行います。
* [Search OSM Templates](/ja/api/osm-templates/search-osm-templates): テンプレートタイプ、ソース、作成者などのフィルターに基づいてテンプレートを取得します。

## よくある質問

<Accordion title="どの OSM テンプレートタイプがサポートされていますか？" icon="layer-group">
  現在、API は **BANNER**、**POP_UP**、**NUDGE** テンプレートタイプの作成と管理をサポートしています。すべてのペイロードは HTML 形式である必要があります。
</Accordion>

<Accordion title="API で作成したテンプレートを Drag and Drop Editor で使用できますか？" icon="circle-exclamation">
  いいえ。API でアップロードされたテンプレートは、MoEngage ダッシュボードの **Custom HTML Editor** とのみ互換性があります。
</Accordion>

<Accordion title="ライブキャンペーンの更新はどのように処理すればよいですか？" icon="arrows-rotate">
  テンプレートを更新する際に、`update_campaigns` フラグを設定できます。
  - **True**: 実行中のすべてのキャンペーンを新しいテンプレートバージョンに自動的に更新します。
  - **False**: 既存のキャンペーンに影響を与えずに新しいバージョンを作成します。
</Accordion>

MoEngage Broadcast Live Activities API を使用すると、ブランドは iOS 上で大規模なオーディエンス向けの共有リアルタイムエクスペリエンスを管理できます。これは、複数のユーザーがロック画面や Dynamic Island で同じリアルタイムの更新情報を確認する必要がある、スポーツのライブイベント、選挙速報、ニュース速報などに最適です。

<Note>
  Live Activities を管理できるのは、[Create Push Campaigns API](/ja/api/create-campaigns/create-campaign) を通じて **BROADCAST_LIVE_ACTIVITY** 配信タイプで作成されたプッシュキャンペーンのみです。これらのキャンペーンは MoEngage UI からは作成できません。
</Note>

## エンドポイント

Broadcast Live Activities API は、次のエンドポイントで構成されています。

- [**Start Broadcast Live Activity**](/ja/api/live-activities/start-broadcast-live-activity): 共有アクティビティを開始し、ターゲットオーディエンスに初期コンテンツを送信します。
- [**Update Broadcast Live Activity**](/ja/api/live-activities/update-broadcast-live-activity): 購読しているすべてのデバイスに統一された更新情報（スコアの変化など）をプッシュします。
- [**End Broadcast Live Activity**](/ja/api/live-activities/end-broadcast-live-activity): すべてのデバイスでアクティビティセッションを終了します。

## よくある質問

<AccordionGroup>
  <Accordion title="Android でも使用できますか？">
    いいえ。Live Activities は iOS のネイティブ機能です。この API は、ActivityKit フレームワークをサポートする iOS デバイスを対象としています。
  </Accordion>
  <Accordion title="broadcast_live_activity_id と instance_id の違いは何ですか？">
    `broadcast_live_activity_id` は、Push API を通じて作成された全体のキャンペーン ID を指します。`instance_id` はオプションのフィールドで、特定のセッションをトラッキングしたり、同じイベントに対する重複リクエストを防いだりするために指定できます。
  </Accordion>
  <Accordion title="コンテンツをパーソナライズするにはどうすればよいですか？">
    コンテンツは `content_state` JSON オブジェクトを通じて更新されます。このオブジェクト内のキーは、iOS アプリケーションのコードで定義されている `ContentState` 構造体と一致している必要があります。
  </Accordion>
</AccordionGroup>

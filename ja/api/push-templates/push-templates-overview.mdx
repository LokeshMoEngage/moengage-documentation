MoEngage Push Templates API を使用すると、Android および iOS プラットフォーム向けのプッシュ通知テンプレートを作成、更新、検索できます。これらのエンドポイントを使用して、テンプレートライブラリを効率的に管理し、自動化されたワークフローに統合できます。

<Note>
  アカウントでこの API が有効になっていない場合は、MoEngage カスタマーサクセスマネージャー（CSM）またはサポートチームに連絡して、有効化をリクエストしてください。
</Note>

## エンドポイント

Push Templates API は、次のエンドポイントで構成されています。

- [Create Push Template](/ja/api/templates/create-push-template): プッシュテンプレートを作成します。
- [Update Push Template](/ja/api/templates/update-push-template): Template ID で指定したプッシュテンプレートを更新します。
- [Search for Push Templates](/ja/api/templates/search-for-push-templates): Template ID、またはテンプレート名やプラットフォームなどのその他のフィルターを使用してプッシュテンプレートを取得します。


## よくある質問

<AccordionGroup>
  <Accordion title="iOS のみでサポートされるテンプレートを作成できますか？">
    はい、iOS 用のテンプレートを作成したい場合は、iOS のペイロードのみを送信できます。
  </Accordion>
  <Accordion title="MoEngage ではどのような種類の画像、動画、音声ファイルがサポートされていますか？">
    音声と動画: 標準的な FCM/APNS プラットフォームでサポートされているすべての種類の動画および音声ファイル形式がサポートされています。

    **画像:** 次の形式がサポートされています: "image/png"、"image/jpeg"、"image/jpg"、"image/gif"。
  </Accordion>
  <Accordion title="同じ名前のテンプレートを複数作成できますか？">
    はい、バージョンが異なれば、同じ名前のテンプレートを複数作成できます。
  </Accordion>
</AccordionGroup>

MoEngage Subscription Categories API を使用すると、自社システムと MoEngage の間でユーザーのコミュニケーション設定を管理および同期できます。これらのエンドポイントは、個別の設定の取得、キャンペーンでのインタラクションによる設定の更新、大量の一括更新をサポートしています。Subscription Categories の詳細については、[Subscription Categories](/ja/user-guide/campaigns-and-channels/email/getting-started-with-email/configure-subscription-categories) を参照してください。 

## エンドポイント

Subscription Categories API は、以下のエンドポイントで構成されています。

- [Get Subscription Preferences](/ja/api/subscription-preferences/get-subscription-preferences): 特定のユーザーの購読カテゴリー設定情報を取得します。
- [Update Subscription Preferences](/ja/api/subscription-preferences/update-subscription-preferences): 送信されたメール通知からカスタムランディングページに移動して設定を更新した特定のユーザーについて、購読カテゴリー設定情報を更新します。
- [Bulk Update Subscription Preferences](https://moengage.mintlify.app/api/subscription-preferences/bulk-update-subscription-preferences): 購読カテゴリー設定を一括で更新します。大量のユーザー設定を MoEngage に更新する場合は、この API を使用してください。

## よくある質問

### Get Subscription Preferences

<AccordionGroup>
  <Accordion title="リクエストで渡すパラメーターはどのように取得しますか？" icon="sparkles">
    user_id（MoEngage ID）フィールドと cid（Campaign ID）フィールドは、ランディングページの URL から取得する必要があります。たとえば、カスタムランディングページへのリンクが `https://www.abc.com/managepreference` の場合、ユーザーがメールからそのリンクをクリックすると、リンクは次のようになります。

    ```json
    	https://www.abc.com/managepreference?user_id=7XvJW2dj3iS.rYAt4pg5ASBQtaqAMFDw9e89vZCXx_RFfN3eL0wBG008oI6cpncOQV6ESg&cid=5FGZGcA8FRv3Id89JCCczQjwxq6ApEyAarYDje2mzfRQ_WG7VyyFEc0w4L3MA.31a7wzR64fi7lfq8Km0AaeO4paGVul.4HxixDYnoUp21xyUjGtfvnrHSR2G1reTpYPHHU.r3Ac9vE&app_key=UY_GHXBXyaHbiYnCoNOu7eS.u5yIrrN3noTBNZX5mNSL4KN5C5PZ3zcXBKCCxl9w3m0ukw
    ```

    ここから user_id と cid を解析して取得できます。

    - user_id: 7XvJW2dj3iS.rYAt4pg5ASBQtaqAMFDw9e89vZCXx_RFfN3eL0wBG008oI6cpncOQV6ESg
    - cid: 5FGZGcA8FRv3Id89JCCczQjwxq6ApEyAarYDje2mzfRQ_WG7VyyFEc0w4L3MA.31a7wzR64fi7lfq8Km0AaeO4paGVul.4HxixDYnoUp21xyUjGtfvnrHSR2G1reTpYPHHU.r3Ac9vE となります。API をトリガーする際に、これらを渡してください。
  </Accordion>
</AccordionGroup>

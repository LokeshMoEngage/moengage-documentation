MoEngage Email Template API を使用すると、マーケターは MoEngage エコシステムの外部で作成されたメールテンプレートを簡単に定義、再利用、更新、管理できます。同じテンプレートの複数のバージョンを作成し、現在アクティブなキャンペーンで使用できるかどうかを指定できます。ユーザーは Create Email Template API を使用してテンプレートを作成し、Update Email Template API を使用して更新するか、MoEngage ダッシュボードで編集できます（ロールに対してテンプレートの特定の編集権限が許可されている場合）。これらの API を使用して作成・更新されたテンプレートは、Custom HTML Editor（Froala Editor）でサポートされており、Drag and Drop Editor ではサポートされていません。

## エンドポイント
Email Template API（V2）は、次のエンドポイントで構成されています。

- [Create Email Template API](/ja/api/email-templates/create-email-template-v2): メールテンプレートを作成します。
- [Update Email Template API](/ja/api/email-templates/update-email-template): Template ID で指定したメールテンプレートを更新します。
- [Search Email Template API](/ja/api/email-templates/search-email-template): Template ID、またはテンプレート名やテンプレートバージョンなどのその他のフィルターを使用してメールテンプレートを取得します。また、Create Email Template API を使用して MoEngage で作成されたすべてのメールテンプレートを一覧表示することもできます。

MoEngage GDPR / CCPA API は、一般データ保護規則（GDPR）およびカリフォルニア州消費者プライバシー法（CCPA）へのコンプライアンスのために、すべてのユーザーデータの権利が尊重され、管理されるようにします。この API を使用すると、特定のユーザーの個人データの完全消去を含むデータリクエストを送信できます。

<Info>
  MoEngage がこれらの規制にどのように対応しているかに関する詳細な実装ガイドについては、[GDPR Implementation](https://www.moengage.com/docs/user-guide/data/privacy/gdpr) および [CCPA Implementation](https://www.moengage.com/docs/user-guide/data/privacy/ccpa) のドキュメントを参照してください。
</Info>

<Note>
  ユーザープロファイルを消去せずにユーザー属性を更新するには、代わりに [Track User](/ja/api/user/track-user) API を使用してください。
</Note>

## エンドポイント

GDPR / CCPA API は、次のエンドポイントで構成されています。


- [Submit a Data Request](/ja/api/gdpr/submit-a-gdpr-ccpa-data-request): ユーザーの権利（消去リクエストなど）を作成または更新します。

## よくある質問

<AccordionGroup>
  <Accordion title="この API を使用して複数のユーザーを削除できますか？">
    いいえ。この API では、1 つのペイロードで複数のユーザーを削除することはできません。同じメール ID を共有している場合（上記の注記を参照）を除き、ユーザーごとに個別のリクエストを送信する必要があります。
  </Accordion>
  <Accordion title="複数のユーザーに関連付けられたメール ID を消去するとどうなりますか？">
    複数のユーザーが同じメール ID を持ち、そのメール ID が消去リクエストで渡された場合、MoEngage はその特定のメール ID に関連付けられた**すべての**ユーザーを削除します。
  </Accordion>
  <Accordion title="リクエストペイロードの最大サイズはどのくらいですか？">
    ペイロードの最大サイズは 128 KB です。この制限を超えた場合は、413 エラーレスポンスが返されます。
  </Accordion>
</AccordionGroup>

# はじめに

マーケティングの設定を管理することは、顧客との良好な関係を維持するうえで非常に重要です。ユーザーが受け取るコミュニケーションの種類を自分で管理できるようにすることで、企業はマーケティング活動をユーザーにとって関連性の高いものにし、ユーザーの設定を尊重できます。MoEngage の _Landing Pages_ 機能を使用すると、ユーザーが購読設定を管理するためのパーソナライズされた Web ページを作成できます。

このプロセスでは、ユーザーが希望するコミュニケーションカテゴリを選択できるランディングページを作成し、フォームの送信で選択内容を取得したうえで、コネクタキャンペーンを使用して MoEngage でこれらの設定を更新します。これにより、ユーザーはオプトインしたコミュニケーションのみを受け取るようになり、ブランドとの体験とエンゲージメントが向上します。

#### ランディングページを使用して設定管理センターを作成するメリット

- **ユーザーによる管理の強化:** ブランドから受け取りたいコミュニケーションの種類 (たとえば Newsletter や Promotional) を明確かつ簡単に管理できる手段をユーザーに提供します。
- **顧客との関係と満足度の向上:** ユーザーの設定を尊重し、関連性の高いコミュニケーションのみを届けることで信頼が生まれ、良好な関係が育まれて満足度が高まります。
- **コミュニケーションの関連性の向上:** ユーザーが明示的にオプトインしたコンテンツのみを送信するため、マーケティング活動を効果的にターゲティングできます。これにより、コミュニケーションの価値が高まり、無視されたりスパムとしてマークされたりする可能性が低くなります。
- **設定の自動同期:** フォームの送信によってトリガーされるコネクタキャンペーンを使用して、ユーザーの購読設定を MoEngage のプロファイル内で直接シームレスに更新します。手作業による処理が不要になり、データの正確性が確保されます。
- **ユーザーを尊重したマーケティング:** データと設定に関する透明性の高い管理手段をユーザーに提供することで、ユーザーを尊重したコミュニケーションへの取り組みを示せます。これはプライバシー規制への準拠にも役立ちます。

このユースケースは、次の 3 つのステップで実現します。

1. [ステップ 1: ランディングページを作成する](#step-1-create-a-landing-page)
2. [ステップ 2: テンプレートを設定する](#step-2-configure-the-template)
3. [ステップ 3: コネクタキャンペーンを使用してユーザーの設定を更新する](#step-3-update-email-subscription-preferences-for-users-using-connector-campaign)

# 期待される結果

設定管理用のランディングページにアクセスしたユーザーは、希望するコミュニケーションカテゴリ (たとえば Newsletter、Promotional、Product recommendations、Unsubscribe all) を選択して送信できます。送信されると、フォームデータが取得され、MoEngage でユーザーの購読設定の更新に使用されます。これにより、ユーザーはオプトインした種類のコミュニケーションのみを受け取るようになり、ブランドとの全体的な体験が向上します。

<Tip>
  - MoEngage の _Landing Pages_ 機能へのアクセス権が必要です。アクセス権がない場合は、MoEngage のカスタマーサクセスマネージャー (CSM) またはサポートチームに連絡して、アカウントで有効化してください。
  - MoEngage のカテゴリ購読管理システム内で使用できるように、購読カテゴリ名 (たとえば Newsletter、Promotional) を定義しておく必要があります。事前に定義されていない場合は、カスタムカテゴリとして設定する必要があります。
</Tip>

# ステップ 1: ランディングページを作成する

1. MoEngage ダッシュボードの左側のナビゲーションメニューで **Content** をクリックし、**Landing pages** をクリックします。
2. **Landing page**s ページで **Create a landing page** をクリックします。 <img src="/images/moengage_7b98bc.png" alt="create.png" />
3. 識別と管理がしやすいようにランディングページの名前を入力し、ページを分類するための適切なタグを選択します。
4. **Content** セクションで、あらかじめデザインされたテンプレートの中から **Subscription Category Management** テンプレートを選択します。 <img src="/images/moengage_ed0940.png" alt="2025-03-24_12-15-55 (1).gif" />

次のステップでは、設定管理テンプレートを設定します。

# ステップ 2: テンプレートを設定する

1. フォーム内で、ユーザーのメールアドレスの入力フィールドを編集します。
2. 要件に応じてテンプレートのコンテンツを編集します。たとえば、ここでは _Newsletter_、_Promotional_、_Product recommendations_、_Unsubscribe all_ という異なる購読カテゴリを追加します。 <img alt="2025-03-24_15-34-17 (2).gif" src="/images/moengage_db09f1.png" />
3. 以下のように、フィールド要素を **Checkbox** に変更します。 <img src="/images/moengage_19a070.png" alt="2025-03-24_15-43-35 (1).gif" />
4. 各チェックボックスを MoEngage の対応するユーザー属性にマッピングします。たとえば、_Email Address_ フィールドを属性 _Email_ に、_Newsletter_ を _Newsletter_ という名前の属性にマッピングします。手順は次のとおりです。
   1. フィールド要素をクリックし、<img alt="Screenshot 2025-03-21 at 1.37.57 PM.png" src="/images/moengage_7592fe.png" style={{ display: 'inline-block'}} /> アイコンをクリックします。
   2. **Advanced** の **UserAttribute** リストから適切なユーザー属性を選択します。ユーザー属性を選択しない場合、レスポンスはデフォルトの一意の ID (32 桁の属性) にマッピングされます。
5. 必要なユーザー属性が存在しない場合は、[Import User Data Using CSV](/ja/user-guide/data/imports/manual-uploads) に記載されている手順に従って新しい属性を作成します。
6. 必要に応じて、その他のフォーム設定を構成します。
7. ランディングページの URL と設定を構成します。詳細については、[こちら](/ja/user-guide/content/landing-pages/create/create-a-landing-page)を参照してください。
8. **Publish** をクリックしてランディングページを公開します。
9. 公開したランディングページの URL をコピーし、メールキャンペーン内で使用して、設定管理のためにユーザーに送信します。

これでランディングページの準備ができました。次のステップでは、ユーザーのレスポンスに基づいて設定を更新するコネクタキャンペーンを設定します。

# ステップ 3: コネクタキャンペーンを使用してユーザーのメール購読設定を更新する

<Info>
  コネクタキャンペーンのステップは、MoEngage の購読**カテゴリ管理**システムに適用されます。このシステムでは、メールの購読設定は通常のユーザー属性とは異なる動作をします。**通常のユーザー属性**を使用してメール購読を管理している場合は、このステップを省略できます。ユーザーはランディングページの UI から直接設定を更新します。
</Info>

コネクタキャンペーンの作成の詳細については、[こちら](/ja/user-guide/campaigns-and-channels/connectors/create/create-a-connector-campaign)を参照してください。

1. MoEngage ダッシュボードで **Engage** \> **Campaigns** に移動します。
2. All campaigns ページで **\+ Create campaign** をクリックします。
3. **Connectors** で **Custom** をクリックし、**Event Triggered** を選択します。 <img src="/images/moengage_6b4fff.png" alt="Screenshot 2025-03-21 at 2.38.25 PM.png" />
4. キャンペーンの名前とタグを定義します。
5. **Trigger criteria** セクションで、条件を _Has executed_ に設定して _Response submitted_ イベントを選択し、属性を _Landing Page ID_ に設定して、この特定のページからのフォーム送信でトリガーされるようにします。 <img src="/images/moengage_680754.png" alt="Screenshot 2025-03-27 at 12.14.34 PM.png" />
6. **Select audience** セクションで **All users** を選択し、**Next** をクリックします。
7. **Content** セクションで、次の手順を実行します。 <img src="/images/moengage_07c1d1.png" alt="Screenshot 2025-03-27 at 12.20.33 PM.png" />
   1. **Method** で **POST** を選択します。
   2. **Webhook URL** フィールドに [_https://api-02.moengage.com/v1/category-subscription/user-preferences_](https://api-02.moengage.com/v1/category-subscription/user-preferences) を入力します。
   3. appkey (MoEngage の設定から取得できる MoEngage アプリキー)、Content-Type (application/json)、認証設定などの必要なヘッダーを追加します。詳細については、[こちら](https://www.moengage.com/docs/api/subscription-preferences/bulk-update-subscription-preferences)を参照してください。
   4. **Body type** で **Raw** を選択し、ユーザーの設定を更新するための JSON ペイロードを指定します。\
      JSON ペイロードはフォーム送信のイベント属性を使用して構築し、対応するチェックボックスが選択されたかどうかに基づいて各カテゴリが設定されるようにする必要があります。ペイロードは次のようになります。
      <CodeGroup>
      ```json JSON
      {
      "channel": "email",
      "user_preferences": [
      {
      "customer_id": "{{UserAttribute['ID']}}",
      "categories": {
      {% if EventAttribute['Newsletter'
      ] %
      }
      "Newsletter": true,
      {% else %
      }
      "Newsletter": false,
      {% endif %
      }
      {% if EventAttribute['Promotional'
      ] %
      }
      'Promotional": true,
      {% else %
      }
      'Promotional": false,
      {% endif %
      }
      {% if EventAttribute['Product_recommendations'
      ] %
      }
      "Product_recommendations": true,
      {% else %
      }
      "Product_recommendations": false,
      {% endif %
      }
      {% if EventAttribute['moe_unsubscribe'
      ] %
      }
      "unsubscribe_all": true
      {% else %
      }
      "unsubscribe_all": false
      {% endif %
      }
      }
      ]
      }
      ```
      </CodeGroup>
   5. **Next** をクリックします。
8. 必要に応じて、キャンペーンの **Schedule and Goals** を定義します。詳細については、[こちら](/ja/user-guide/campaigns-and-channels/connectors/create/create-a-connector-campaign#step-3-schedule-and-goals)を参照してください。
9. **Publish** をクリックしてコネクタキャンペーンを有効化します。これにより、ランディングページでフォームが送信されるたびに、ユーザーの設定を更新するデータが送信されます。

# 検証

ユーザーの設定が正しく更新されていることを確認するには、次の手順を実行します。

1. 公開したランディングページにアクセスし、さまざまな設定の組み合わせ (たとえば、Newsletter をオン、Promotional をオフ、Unsubscribe all をオン) を選択して、テストデータでフォームを送信します。
2. ユーザープロファイルに移動するか、セグメント機能を使用して MoEngage でユーザーの購読設定を確認し、更新された属性 (Newsletter や Promotional) にフォームの送信内容が反映されていることを確認します。
3. _Unsubscribe all_ が選択された場合に、それがシステムに適切に反映され、場合によっては他のカテゴリの選択より優先されることを確認します。

# まとめ

このユースケースでは、ユーザーがマーケティングの設定を管理するためのランディングページを作成し、Newsletter、Promotional、Product recommendations、Unsubscribe all などのカテゴリのチェックボックスフィールドを使用して選択内容を取得するフォームを設定しました。さらに、送信内容に基づいて MoEngage でユーザーの設定を自動的に更新するコネクタキャンペーンを設定しました。

このアプローチにより、ユーザーの設定が尊重され、コミュニケーションがパーソナライズされた関連性の高いものになり、顧客満足度とエンゲージメントが向上します。

# はじめに

魅力的なセールス体験を生み出すことは、顧客のコンバージョンを促進し、収益を伸ばすうえで非常に重要です。MoEngage の _Landing Pages_ 機能を使用すると、ユーザーが商品を動的に閲覧して予約注文できる、パーソナライズされたランディングページを作成できます。

#### ランディングページを使用してセールスページを作成するメリット

- **動的な商品表示:** 商品はレコメンデーションを通じて商品カタログから自動的に取得されて表示されるため、手動で更新しなくても、ランディングページには常に最新の商品が表示されます。
- **シームレスなユーザー体験:** 顧客にとってスムーズな導線を実現し、1 つのランディングページから商品を閲覧して、各商品の特定のチェックアウトページに直接移動できます。
- **手作業の削減:** カタログが変更されるたびに (たとえば、新商品の追加や価格・リンクの変更など)、ランディングページの商品一覧を手動で作成・更新する必要がなくなります。
- **セールス効率の向上:** 複数の商品を動的に紹介するプロセスを効率化し、ユーザーが商品を見つけて購入しやすくなるため、コンバージョンの向上が期待できます。
- **商品管理の一元化:** MoEngage Catalogs を活用してすべての商品情報 (タイトル、画像、チェックアウトリンク) を 1 か所で管理し、一貫性を確保して更新を簡素化します。

このユースケースは、次の 3 つのステップで実現します。

1. [ステップ 1: 商品カタログを作成する](#step-1-create-a-product-catalog)
2. [ステップ 2: レコメンデーションを作成する](#step-2-create-a-recommendation)
3. [ステップ 3: ランディングページを作成する](#step-3-create-the-landing-page)

# 期待される結果

動的なセールランディングページにアクセスしたユーザーは、レコメンデーションに基づいて商品を動的に閲覧できます。各商品には、商品タイトル、画像、**Preorder now** ボタンが表示されます。ボタンをクリックすると、カタログで指定されたそれぞれの商品のチェックアウトページに移動し、シームレスな購入体験が実現します。\
商品はレコメンデーションから動的に取得されるため、新商品の追加や既存商品の変更など、カタログへの更新は手動で編集しなくても即座にランディングページに反映されます。

<Tip>
  - MoEngage の Landing Pages 機能へのアクセス権が必要です。アクセス権がない場合は、MoEngage のカスタマーサクセスマネージャー (CSM) またはサポートチームに連絡して、アカウントで有効化してください。
  - title、image\_link、link (チェックアウトページの URL) などの商品詳細を含む CSV ファイルを用意しておく必要があります。
</Tip>

# ステップ 1: 商品カタログを作成する

1. MoEngage ダッシュボードの左側のナビゲーションメニューで **Content** をクリックし、**Catalogs** をクリックします。 <img src="/images/moengage_9e9888.png" alt="Screenshot 2025-04-16 at 1.01.33 PM.png" />
2. Catalogs ページで **Create Catalog** をクリックします。 <img src="/images/moengage_b3d954.png" alt="2025-04-16_13-04-14.png" />
3. Catalog name ボックスに、カタログを識別するための名前を入力し、**Submit** をクリックします。 <img src="/images/moengage_e25b3e.png" alt="Screenshot 2025-04-16 at 1.05.57 PM.png" />
4. 次の列を含む CSV ファイルを用意します: title (商品名)、image\_link (商品画像の URL)、link (商品のチェックアウトページにつながる URL。例: [_https://www.example.com/productA/checkouts_](https://www.example.com/productA/checkouts))。フィードの例は次の画像のようになります。 <img src="/images/moengage_398368.png" alt="Screenshot 2025-04-16 at 12.59.28 PM.png" />
5. **Catalogs** ページで、新しく作成したカタログをクリックします。 <img src="/images/moengage_7abe26.png" alt="2025-04-16_13-10-20.png" />
6. **Add Feed** をクリックします。**Create feed** ポップアップウィンドウが表示されます。 <img src="/images/moengage_ed1e19.png" alt="Screenshot 2025-04-16 at 1.11.55 PM.png" />
7. コンピューターから CSV ファイルをアップロードし、**Submit** をクリックします。URL アップロードの使用方法については、[Creating a Catalog](/ja/user-guide/content/recommendations/getting-started/catalogs) を参照してください。 <img src="/images/moengage_e24691.png" alt="2025-04-16_13-16-49.png" />
8. アップロードが成功すると、アイテムフィードは次のようになります。 <img src="/images/moengage_54208f.png" alt="Screenshot 2025-04-16 at 1.19.44 PM.png" />

次のステップでは、カタログ用のレコメンデーションを作成します。

# ステップ 2: レコメンデーションを作成する

このセクションでは、カタログのすべてのアイテムを表示するレコメンデーションを作成します。

1. MoEngage ダッシュボードの左側のナビゲーションメニューで **Content** をクリックし、**Recommendations** をクリックします。
2. Recommendations ページで **\+ Create recommendation** をクリックします。
3. **Select recommendation model** セクションでは、**Item attributes** タイプを使用します。レコメンデーションの詳細については、[こちら](/ja/user-guide/content/recommendations/getting-started/overview)を参照してください。 <img src="/images/moengage_bf1dbb.png" alt="Screenshot 2025-04-16 at 1.23.32 PM.png" />
4. **Next** をクリックします。
5. レコメンデーションの名前と説明を入力します。
6. **Catalog** リストで、[ステップ 1](#step-1-create-a-product-catalog) で作成したカタログを選択します。 <img src="/images/moengage_a2f2e8.png" alt="2025-04-16_13-34-00 (1).gif" />
7. 以下のようにフィルターを設定します。 <img src="/images/moengage_38fb52.png" alt="Screenshot 2025-04-16 at 1.44.42 PM.png" /> これにより、このレコメンデーションを使用したときにすべての商品が表示されるようになります。フィルターの使用方法の詳細については、[こちら](/ja/user-guide/content/recommendations/basic-recommendations/item-attribute-model)を参照してください。
8. **Create** をクリックします。

次のステップでは、レコメンデーションを使用したランディングページを作成します。

# ステップ 3: ランディングページを作成する

このセクションでは、埋め込み HTML 要素を含むランディングページを作成し、商品をグリッドレイアウトで動的に表示します。各商品には、チェックアウトページにリンクする **Preorder now** ボタンが付きます。

1. MoEngage ダッシュボードの左側のナビゲーションメニューで **Content** をクリックし、**Landing pages** をクリックします。
2. Landing pages ページで **Create a landing page** をクリックします。
3. 識別と管理がしやすいようにランディングページの名前を入力し、分類するための適切なタグを選択します。
4. **Content** セクションで **Blank Template** をクリックします。 <img src="/images/moengage_dfa159.png" alt="Screenshot 2025-04-16 at 1.58.03 PM.png" />
5. ページに必要なテキストと画像を追加します。詳細については、[Landing Page Editor](/ja/user-guide/content/landing-pages/create/landing-page-editor) を参照してください。
6. エディターの左ペインから、"Embed" 要素をページにドラッグ＆ドロップします。この要素を使用すると、動的コンテンツ用のカスタム HTML コードを挿入できます。
7. Embed 要素内で設定バーの最初のアイコンをクリックし、次の HTML コードを貼り付けます。その際、YOUR\_RECOMMENDATION\_NAME をレコメンデーション名 (例: _LP\_test_) に置き換えます。
   <CodeGroup>
   ```html HTML wrap
   <style>.container {display: grid;grid-template-columns: auto auto auto;background-color: dodgerblue;padding: 10px;}.container > div {background-color: #F1F1F1;border: 1px solid black;padding: 10px;font-size: 30px;text-align: center;}</style><body><div class="container">{% if ProductSet.YOUR_RECOMMENDATION_NAME %}{% for product in ProductSet.YOUR_RECOMMENDATION_NAME[0:6] %}<div><h1>{{product.title}}</h1><img src="{{product.image_link}}" height="200px" width="200px"><br><a href="{{product.link}}" target="_blank">Preorder now</a></div>{% endfor %}{% else %}MOE_NOT_SEND{% endif %}</div></body>
   ```
   </CodeGroup>
   ![2025-04-16\_14-08-54 (1).gif](/images/moengage_13f511.png)
8. 色やグリッドレイアウトの変更など、好みのデザインに合わせて Embed 要素内の CSS をカスタマイズします。たとえば、背景色を変更したり、グリッドの列を調整したりできます。
9. 必要に応じて、テキストや画像 (ロゴなど) といった追加の要素を商品グリッドの上にドラッグ＆ドロップして、ランディングページの見栄えを向上させることができます。
10. ランディングページの URL と設定を構成します。詳細については、[Create a Landing Page](/ja/user-guide/content/landing-pages/create/create-a-landing-page) を参照してください。
11. **Publish** をクリックしてランディングページを公開します。ページは次のように表示されます。 <img src="/images/moengage_7daa3c.png" alt="Screenshot 2025-04-16 at 2.23.30 PM.png" />

# 検証

動的なセールランディングページが正しく機能していることを確認するには、次の手順を実行します。

1. 公開したランディングページにアクセスし、グリッドにカタログの商品が表示され、それぞれにタイトル、画像、正常に機能する **Preorder now** ボタンがあることを確認します。
2. **Preorder now** をクリックし、カタログで指定したとおり、各商品の正しいチェックアウトページに移動することを確認します。

# まとめ

このユースケースでは、商品カタログの設定、レコメンデーションの構成、動的な商品表示のための HTML の埋め込みを行い、動的なセールランディングページを作成しました。このアプローチにより、ユーザーはシームレスに商品を閲覧して予約注文できるようになり、セールス効率と顧客エンゲージメントが向上します。ランディングページを公開したら、閲覧数やクリック数を追跡して、キャンペーンの成果を把握できます。

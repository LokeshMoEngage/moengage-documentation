# はじめに

ユーザー (投資家) は株価の下落に対してさまざまな反応を示すため、企業はお気に入りの銘柄の株価下落についてユーザーにアラートを送りたいと考えています。株価の下落を、割安になったと考えて株式を買い増す機会と捉える投資家もいます。一方で、株価の下落が不安を引き起こし、さらなる損失を避けるためにパニック売りにつながる投資家もいます。

#### 株価下落アラートを設定するメリット

- **市場の認識**: ニュース、企業の発表、より広範な経済的要因によって引き起こされる可能性のある、市場の急激な価格変動についてユーザーに通知します。
- **リスク管理**: ネガティブなニュースや予期しない出来事によって株価が大幅に下落した場合に、損失を抑えられるようタイムリーな通知を送信します。
- **潜在的な購入機会**: 価格の下落は一時的な落ち込みを示している可能性があり、信頼している企業の株式を買い増す好機となる場合があります。
- **迅速な対応**: 株価下落アラートにより、ユーザーは株式を売却する、下落の理由を調査する、あるいは株式を買い増すなど、迅速に対応する機会を得られます。

このユースケースは、次の 2 つのステップで実現します。

1. [ビジネスイベントを作成する](/ja/use-cases/business-events/alert-about-drop-in-stock-price-using-business-events#step-1-create-a-business-event)
2. [Push キャンペーンを作成する](/ja/use-cases/business-events/alert-about-drop-in-stock-price-using-business-events#step-2-create-a-push-campaign)
3. [ビジネスイベントをトリガーしてキャンペーンをトリガーする](/ja/use-cases/business-events/alert-about-drop-in-stock-price-using-business-events#step-3-trigger-campaign-by-triggering-the-business-event)

# ステップ 1: ビジネスイベントを作成する

このセクションでは、アカウント用の [Business Event](/ja/user-guide/campaigns-and-channels/getting-started/triggers/business-event/overview-business-events) を作成します。これにより、必要なすべての詳細を取得するためのイベントテンプレートを作成できます。MoEngage Business Event のパブリック API を使用できます。この例では、次の情報がビジネスイベントに含まれます。

- イベント名: _Stock Price Drop Alert_
- イベントの属性とそのデータ型:
  - **Stock ID**: string
  - **Percentage Drop**: string
  - **Current Stock Price**: float

次の手順を実行します。

1. 上記の情報を JSON 形式で記述し、Postman を使用して MoEngage に送信します。JSON
   ```json
   {
   "event_name": "Stock Price Drop Alert",
   "event_attributes": [
   {
   "attribute_name": "Stock ID",
   "attribute_data_type": "string"
   },
   {
   "attribute_name": "Percentage Drop",
   "attribute_data_type": "string"
   },
   {
   "attribute_name": "Current Stock Price",
   "attribute_data_type": "float"
   }
   ],
   "created_by": "john.doe@example.com"
   }
   ```
2. 上記の JSON 形式の情報を使用し、ワークスペースが属する適切なデータセンターの認証情報を指定して API 呼び出しを行います。詳細については、[Create Business Event API](/ja/api/business-events/create-business-event) を参照してください。\
   API 呼び出しが行われ、イベントが正常に作成されると、MoEngage は次のレスポンスを送信します。JSON
   ```ruby
   {
   "message": "The business event has been created",
   "_id": "{{Business Event ID}}"
   }
   ```
3. イベントが正常に追加されたかどうかを確認するには、次の操作を行います。
   1. MoEngage ダッシュボードで、Business Event Triggered Push キャンペーンに移動します。
   2. **Select business event** リストに、_Stock Price Drop Alert_ イベントが表示されます。 <img src="/images/moengage_c89eb4.png" alt="6.png" />

# ステップ 2: Push キャンペーンを作成する

このセクションでは、ビジネスイベントでトリガーされるプッシュ通知を使用して、ユーザーのお気に入りの銘柄に関する株価下落アラートを作成します。

## ステップ 2.1: ユーザーをターゲットにする

1. MoEngage ダッシュボードの左側のナビゲーションメニューで **Engage** をクリックし、**Campaigns** をクリックします。
2. All campaigns ページで、**\+ Create campaign** をクリックします。
3. **Outbound** で、**Push** \> **Business Event Triggered** をクリックします。 <img src="/images/moengage_cfbf81.png" alt="BUSINESSPUSH.png" /> \
   キャンペーン定義の最初のステップである **Target users** に移動します。
4. 名前とタグを指定してキャンペーンを定義します。次の詳細を入力します。
   1. **Team**: 組織のアカウントでチームが有効になっている場合は、チームを選択します。詳細については、[Teams in MoEngage](/ja/user-guide/settings/account/team-management/teams-in-moengage) を参照してください。
   2. **Campaign name**: キャンペーンの名前を入力します。例: _Stock Price Drop Alert_。
   3. **Campaign tags**: 必要なキャンペーンタグを選択します。 <img src="/images/moengage_d524ed.png" alt="7usecase1.png" />
5. **Select business event** リストで、_Stock Price Drop Alert_ イベントを選択します。 <img src="/images/moengage_c89eb4.png" alt="6.png" />
6. **Target audience** セクションで、同じ _Stock ID_ の銘柄を閲覧したすべての顧客を特定するロジックを定義します。この例では、ターゲットオーディエンスは次のようになります。 <img src="/images/moengage_1e99a2.png" alt="7usecase3.png" /> \
   ビジネスイベントの属性がドロップダウンリストで利用できるようになりました。イベント属性の **Stock ID** は、ビジネスイベントがトリガーされるたびに動的な値を持つことができ、ビジネスイベント属性 **Stock ID** に対する値がセグメンテーションクエリに自動的に代入されます。
7. **Target Platforms** セクションで、**Android** を選択します。 <img src="/images/moengage_0a9037.png" alt="7usecase2.png" />
8. **Next** をクリックして、2 番目のステップである **Content** に進みます。ここでは、Push キャンペーンのコンテンツを定義できます。

## ステップ 2.2: コンテンツ

1. 使用するテンプレートを選択します。たとえば、**Basic notification** を選択します。 <img src="/images/moengage_8728a7.png" alt="7usecase4.png" />
2. キャンペーンに必要なコンテンツを入力します。タイトル、メッセージ、サマリーは手動で入力することも、Merlin AI を使用して生成することもできます。詳細については、[Generate Push Messages with Merlin AI](/ja/user-guide/ai-and-intelligence/merlin-ai/merlin-ai-copywriter/generate-push-messages-with-merlin-ai) を参照してください。 <img src="/images/moengage_98ca70.png" alt="8.png" /> \
   このようなコミュニケーションのコンテンツには、ビジネスイベントの属性から取得した値を含める必要があります。これは他のパーソナライゼーションと同様の方法で行えます。
3. ユーザー名などの情報を使用して、メッセージにパーソナライゼーションを追加します。このようなパーソナライゼーションにより、メッセージがより文脈に沿ったものになり、ユーザーはつながりを感じることができます。これを行うには、次の操作を行います。
   1. @ を入力します。
   2. **Push Personalization** ダイアログボックスで、ユーザーのビジネスイベントまたはユーザープロパティから関連する属性を見つけます。 <img src="/images/moengage_99707b.png" alt="9.png" />
4. ディープリンクオプションを使用して、ユーザーがチケットの詳細を確認できるアプリまたはウェブサイトのページにユーザーを誘導します。
   1. **Default click action** リストで、_Deeplinking_ を選択します。
   2. **URL** フィールドに、関連する URL を入力します。
5. **Next** をクリックして、3 番目のステップである **Schedule and goals** に進みます。ここでは、キャンペーンのスケジュールと目標を定義できます。

## ステップ 2.3: スケジュールと目標

1. 要件に基づいて、このキャンペーンの開始日時と終了日時、およびコンバージョン目標を定義します。
2. 要件に基づいて配信設定を変更します。詳細については、[Create Push Campaigns](/ja/user-guide/campaigns-and-channels/mobile-push/create/create-push-campaigns) を参照してください。 <img src="/images/moengage_0cf9f7.png" alt="10.png" />
3. **Publish** をクリックします。

# ステップ 3: ビジネスイベントをトリガーしてキャンペーンをトリガーする

これで、コミュニケーションのトリガーを開始する準備が整いました。株価の下落が検出されると、Trigger Business Event API を使用してキャンペーンをトリガーできます。このイベントをいつ MoEngage に渡すかのロジックは、ビジネス要件に基づいてお客様側で決定します。

ペイロードの例を次に示します。

JSON

```json
{
"event_name": "Stock Price Drop Alert",
"event_attributes": {
"Stock ID": "GOOG",
"Percentage Drop": "10%",
"Current Stock Price":136.65},
"triggered_by": "john.doe@example.com"
}
```

# まとめ

このユースケースでは、ユーザーのお気に入りの銘柄について、プッシュ通知による株価下落アラートを作成しました。これを実現するために、MoEngage の Business Events を使用しました。

キャンペーンを公開したので、MoEngage API を使用してテストできます。詳細については、[Business Event Triggered Campaigns](/ja/user-guide/campaigns-and-channels/getting-started/triggers/business-event/business-event-triggered-campaigns) を参照してください。

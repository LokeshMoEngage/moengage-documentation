# はじめに

マーケターにとって、クレジットカード利用に対する均等月賦払い (EMI) オプションを宣伝することには、多くのメリットがあります。このオプションを訴求することで、より大きな買い物と無理のない月々の支払いが可能になるため、顧客の購買力と支払い能力が高まります。さらに、信頼、ロイヤルティ、長期的な顧客関係の構築にも役立ちます。ただし、顧客の理解と満足を確保するためには、関連する利用規約を透明性をもって伝えることが不可欠です。

#### EMI オプションを訴求するメリット

- **支払いやすさの向上**: EMI オプションにより、顧客は購入代金を時間をかけて少額の無理のない分割払いで支払えるため、高価なアイテムをより幅広い顧客層が購入しやすくなります。
- **取引額の増加**: EMI が利用可能な場合、顧客はより高額な商品を選ぶ可能性が高くなり、平均取引額の増加につながります。
- **利便性と柔軟性の向上**: EMI により、顧客は全額を前払いせずに購入できるため、ショッピング体験と満足度が向上します。
- **アップセルとクロスセルの機会**: 顧客はすでに購入の意思がある状態では追加の商品やサービスを検討しやすくなるため、EMI はアップセルやクロスセルの機会を促進できます。
- **新しい顧客セグメントへの浸透**: EMI により、分割払いオプションがなければ特定の商品やサービスを購入できなかったかもしれない新規顧客を獲得できます。
- **在庫回転の高速化**: 顧客は全額が貯まるのを待たずに早くアイテムを購入し、時間をかけて支払えるため、EMI は在庫回転の高速化につながります。

このユースケースは、次の 2 つのステップで実現します。

1. [RFM セグメントを作成する](/ja/use-cases/push/highlight-an-emi-option#step-1-create-an-rfm-segment)
2. [Push キャンペーンを作成する](/ja/use-cases/push/highlight-an-emi-option#step-2-create-a-push-campaign)

# ステップ 1: RFM セグメントの作成

キャンペーンを作成する前に、RFM セグメントとその作成プロセスについて理解しましょう。これらの RFM セグメントを使用して、ターゲットオーディエンスを定義します。

RFM (Recency、Frequency、Monetary) モデルは自動セグメンテーションを提供し、ユーザーの行動に基づいて _Loyal_、_Promising_、_At Risk_ などのカテゴリーにユーザーを分類します。これらの自動セグメントは、ユーザー分析、離脱分析、効果的なユーザーターゲティングなど、さまざまな方法で使用できます。詳細については、[RFM Segments](/ja/user-guide/segment/create-segments/rfm-segments) を参照してください。

このセクションでは、最も多く支出している _Champion Users_ を見つけて EMI または分割払いオプションを紹介するための RFM セグメントを作成します。

1. MoEngage ダッシュボードの左側のナビゲーションメニューで **Segment** をクリックし、**RFM** **segments** をクリックします。
2. RFM segments ページの **Recency Event** リストで、Recency スコアの割り当ての基準となるイベントとして _App/Site Opened_ を選択します。
3. **Use the same event as Recency** チェックボックスを選択します。
4. **Monetary Event** リストで _Credit Card used_ を選択し、**Revenue Attribute** リストで _Amount_ を選択します。
5. **Show analysis for** の下で **All users** を選択します。<img src="/images/moengage_d2904a.png" alt="RFMusecase1.png" />
6. **Show analysis for** の下で **All users** を選択して、すべてのユーザーを対象に分析を実行します。
7. **Analysis Model** から \_RFM\_ を選択し、**Date Range**\* を定義します。\*
8. **Apply** をクリックします。<img src="/images/moengage_6d7b3e.png" alt="RFMusecase2.png" /> MoEngage は次のようなチャートを生成します。 <img alt="image-20240121-071605.png" src="/images/moengage_7c1956.png" />\
   任意のチャートを選択してカスタムセグメントとして保存したり、そのセグメントをターゲットオーディエンスとして直接キャンペーンを作成したりできます。
9. この例では、**Champions** ボックスをクリックします。
10. **Engage Users** ダイアログボックスで **Custom Segment** を選択し、カスタムセグメント名として _RFM-segment_ を入力します。
11. **SAVE SEGMENT** をクリックします。<img src="/images/moengage_7f9cc5.png" alt="RFMusecase3.gif" />

ターゲットとするセグメントが作成されたので、EMI オプションの可能性をユーザーに働きかけるキャンペーンの作成を開始できます。

# ステップ 2: Push キャンペーンの作成

このセクションでは、EMI オプションの可能性に関するプッシュ通知をトリガーする Push キャンペーンを作成します。これらの通知は、クレジットカードの利用分を手軽な EMI オプションに変換するようユーザーに働きかけます。

## ステップ 2.1: ユーザーのターゲティング

1. MoEngage ダッシュボードの左側のナビゲーションメニューで **Engage** をクリックし、**Campaigns** をクリックします。
2. All campaigns ページで **\+ Create campaign** をクリックします。
3. **Outbound** の下で **Push**\> **Event Triggered** をクリックします。<img src="/images/moengage_e4a657.png" alt="2.png" /> キャンペーンを定義する最初のステップ **Target users** に移動します。
4. キャンペーンの名前とタグを定義します。次の詳細を入力します。
   1. **Team**: 組織のアカウントで Teams が有効になっている場合は、チームを選択します。詳細については、[Teams in MoEngage](/ja/user-guide/settings/account/team-management/teams-in-moengage) を参照してください。
   2. **Campaign name**: キャンペーンの名前を入力します。たとえば、_EMI Option_ です。
   3. **Campaign tags**: 必要なキャンペーンタグを選択します。<img src="/images/moengage_1002bc.png" alt="RFMusecase4.png" />
5. **Trigger Criteria** セクションで、5000 を超える金額でクレジットカードを利用したすべての顧客を特定するためのロジックを定義します。
6. 上記のロジックを定義するには、次の手順を実行します。
   1. **IF user** セクションで、イベント _Credit Card used_ を選択します。
   2. **\+ Attribute** をクリックして、支出した _Amount_ が 5000 を超えているかどうかを確認する追加のフィルターを適用します。
   3. **THEN trigger the message** セクションで **Immediately** を選択します。EMI に関するお知らせであるため、少額の支出に対して EMI を提案しても意味がありません。そのため、この例ではターゲットオーディエンスを次のように設定できます。<img alt="RFMusecase6.png" src="/images/moengage_75115b.png" />
7. **Target audience** セクションで、[ステップ 1: RFM セグメントの作成](/ja/use-cases/push/highlight-an-emi-option#step-1-create-an-rfm-segment)で作成して保存したカスタムセグメント _RFM-segment_ を検索して選択します。<img alt="RFMusecase7.png" src="/images/moengage_1d2cb0.png" />
8. **Target Platforms** セクションで **Android** を選択します。<img src="/images/moengage_15f8c3.png" alt="RFMusecase8.png" />
9. **Next** をクリックして 2 番目のステップ **Content** に移動し、Push キャンペーンのコンテンツを定義します。

## ステップ 2.2: コンテンツ

1. 使用するテンプレートを選択します。たとえば、**Basic notification** を選択します。<img src="/images/moengage_87e019.png" alt="RFMusecase9.png" />
2. キャンペーンに必要なコンテンツを入力します。タイトル、メッセージ、サマリーは手動で入力することも、Merlin AI を使用して生成することもできます。詳細については、[Generate Push Messages with Merlin AI](/ja/user-guide/ai-and-intelligence/merlin-ai/merlin-ai-copywriter/generate-push-messages-with-merlin-ai) を参照してください。<img src="/images/moengage_7b1366.png" alt="RFMusecase10.png" /> \
   このようなコミュニケーションのコンテンツには、ビジネスイベントの属性から取得した値を含める必要があります。これは、他のパーソナライゼーションと同様の方法で行えます。
3. ユーザーの名前などの情報を使用して、メッセージにパーソナライゼーションを追加します。このようなパーソナライゼーションにより、メッセージがより状況に即したものになり、ユーザーはつながりを感じられます。これを行うには、次の手順に従います。
   1. _@_ と入力します。
   2. **Push Personalization** ダイアログボックスで、ユーザーのビジネスイベントまたはユーザープロパティから関連する属性を見つけます。たとえば、ここでは _Credit Card Transaction Amount_ を選択しています。<img src="/images/moengage_f277a9.png" alt="RFMusecase11.png" /> \
      パーソナライズされたコンテンツ画面の例を次に示します。<img src="/images/moengage_fbcfd0.png" alt="RFMusecase12.png" />
4. ディープリンクオプションを使用して、ユーザーがチケットの詳細を確認できるアプリまたは Web サイトのページにユーザーを誘導します。
   1. **Default click action** リストで _Deeplinking_ を選択します。
   2. **URL** フィールドに、関連する URL を指定します。
5. **Next** をクリックして 3 番目のステップ **Schedule and goals** に移動し、キャンペーンのスケジュールと目標を定義します。

## ステップ 2.3: スケジュールと目標

1. 要件に基づいて、このキャンペーンの開始日時と終了日時、およびコンバージョン目標を定義します。
2. 要件に基づいて配信設定を変更します。詳細については、[Create Push Campaigns](/ja/user-guide/campaigns-and-channels/mobile-push/create/create-push-campaigns) を参照してください。<img src="/images/moengage_155d3e.png" alt="RFMusecase13.png" />
3. **Publish** をクリックします。

# まとめ

この記事では、RFM セグメンテーションと Push キャンペーンを使用して、クレジットカードの利用分を手軽な EMI オプションに変換するようユーザーに働きかけました。

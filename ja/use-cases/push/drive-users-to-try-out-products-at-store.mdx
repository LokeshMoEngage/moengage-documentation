# はじめに

オンラインショッピングは普及していますが、購入前に商品を見たり、触ったり、試したりしたいと考える顧客は今でもいます。マーケターとして、こうしたユーザーが店舗の近くにいるときに働きかけることで、エンゲージメントを図ることができます。このアプローチは、ショッピング体験を向上させ、ユーザー満足度を高めることを目的としています。ユーザーが特定のエリアに入ったとき、出たとき、または特定の場所に一定時間滞在したときに、位置情報に基づくコミュニケーションをトリガーできます。

#### ユーザーを店舗での商品試用に誘導するメリット

- **直接的な感覚体験**: ユーザーは商品に実際に触れ、質感、重さ、フィット感を確かめることができます。これは衣類、靴、電子機器などのアイテムにとって非常に重要です。
- **視覚的な評価**: ユーザーは商品のデザイン、色、品質を直接確認できます。これは多くの場合、オンラインの画像だけに頼るよりも正確です。
- **即時のフィードバック**: ユーザーは、試着室で服を試着したり、店舗で電子機器を試したりするなど、実際の状況で商品を試すことができます。
- **返品リスクの軽減**: 事前に商品を試すことで、ユーザーは満足できない購入をして商品を返品しなければならない可能性を最小限に抑えられます。
- **インスピレーションと発見**: 店舗環境には多種多様な商品が並んでいることが多く、ユーザーがそれまで検討していなかった新しいアイテムやブランドを発見できます。
- **カスタマーサービスとアドバイス**: 店舗スタッフが専門的なアドバイスを提供し、質問に回答することで、ユーザーがニーズに合った商品を選ぶ手助けができます。

このユースケースは、ユーザーが店舗から 1 km 以内にいるときに実店舗での商品試用を促す [Push キャンペーンを作成する](/ja/use-cases/push/drive-users-to-try-out-products-at-store#create-a-push-campaign)ことで実現します。商品をカートに追加したものの、まだ購入していない顧客をセグメント化します。

# Push キャンペーンの作成

このセクションでは、ユーザーが定義された地域に入ったときにメッセージをトリガーする Push キャンペーンを作成します。

## ステップ 1: ユーザーのターゲティング

1. MoEngage ダッシュボードの左側のナビゲーションメニューで **Engage** をクリックし、**Campaigns** をクリックします。
2. All campaigns ページで **\+ Create campaign** をクリックします。
3. **Outbound** の下で **Push** \> **Location Triggered** をクリックします。<img src="/images/moengage_f2a9b9.png" alt="locationtriggu.png" /> キャンペーンを定義する最初のステップ **Target users** に移動します。
4. キャンペーンの名前とタグを定義します。次の詳細を入力します。
   1. **Team**: 組織のアカウントで Teams が有効になっている場合は、チームを選択します。詳細については、[Teams in MoEngage](/ja/user-guide/settings/account/team-management/teams-in-moengage) を参照してください。
   2. **Campaign name**: キャンペーンの名前を入力します。たとえば、_Try out your dress!_ です。
   3. **Campaign tags**: 必要なキャンペーンタグを選択します。<img src="/images/moengage_1efc95.png" alt="10usecase1.png" />
5. Geofence を定義します。定義する際に、ユーザーがこの地域に入ったとき、出たとき、または一定時間滞在したとき (Android のみ可能) にメッセージを表示するかどうかを決定できます。
   1. **Geofence** セクションで **\+ Add Geofence** をクリックします。<img src="/images/moengage_92ae98.png" alt="4usecase2.png" />
   2. Add Geofence ページの **Geofence name** フィールドに、Geofence の名前を入力します。たとえば、_Disneyland\_Park_ です。
   3. **Send notification when** リストで、コミュニケーションを表示するタイミングを選択します。この例では、_User enters the Geofence_ を選択します。
   4. **Notification responsiveness (only android)** リストで、応答性を _5 minutes_ に定義します。これは基本的に、ユーザーが定義された地域に入ったかどうかを MoEngage が確認する頻度です。<img src="/images/moengage_aab8d4.png" alt="10usecase2.png" />
   5. **Search for a place** 検索バーで、店舗の場所を検索します。この例では、_Disneyland Park, Anaheim, CA, USA_ を選択します。
   6. 地図の下で半径を定義します。<img src="/images/moengage_9a9ac9.png" alt="10usecase3.png" />
6. **Done** をクリックして Geofence を追加します。これによりフェンスが追加され、最初に **\+ Add Geofence** ボタンが表示されていた Geofence セクションで確認できます。<img src="/images/moengage_f3872c.png" alt="5.png" />
7. 複数のフェンスを追加する場合は、もう一度 **\+ Add Geofence** をクリックし、上記の手順を繰り返します。フェンスの内容を編集する場合は、編集アイコンをクリックして必要な変更を行います。<img src="/images/moengage_d33876.png" alt="10usecase4.png" />
8. **Target audience** セクションで **Filter users by** をクリックし、**User behavior** タブをクリックします。
9. 次に示すように、条件 _Has Executed_ を選択し、過去 30 日間の \_Added to Cart\_event を選択します。<img src="/images/moengage_27ca15.png" alt="10usecase5.png" />
10. **\+ Nested Filter** をクリックし、内部条件 **AND** を選択します。次に示すように、条件 _Has Not Executed_ を選択し、過去 30 日間の _Product Purchased_ イベントを選択します。<img src="/images/moengage_f69024.png" alt="10usecase5.gif" />
11. **Target Platforms** セクションで **Android** を選択します。<img src="/images/moengage_ea3f65.png" alt="10usecase6.png" />
12. **Next** をクリックして 2 番目のステップ **Content** に移動し、Push キャンペーンのコンテンツを定義します。

## ステップ 2: コンテンツ

1. 使用するテンプレートを選択します。たとえば、**Basic notification** を選択します。<img src="/images/moengage_a5b70e.png" alt="10usecase7.png" />
2. キャンペーンに必要なコンテンツを入力します。コンテンツは手動で入力することも、Merlin AI を使用して生成することもできます。詳細については、[Generate Push Messages with Merlin AI](/ja/user-guide/ai-and-intelligence/merlin-ai/merlin-ai-copywriter/generate-push-messages-with-merlin-ai) を参照してください。<img src="/images/moengage_e2d723.png" alt="10usecase8.png" />
3. **Advanced** セクションから URL などの情報を入力したり、ボタンを追加したり、クーポンを追加したりすることで、コンテンツをさらにパーソナライズできます。
4. ユーザーの名前などの情報を使用して、メッセージにパーソナライゼーションを追加します。このようなパーソナライゼーションにより、メッセージがより状況に即したものになり、ユーザーはつながりを感じられます。これを行うには、次の手順に従います。
   1. _@_ と入力します。
   2. Push Personalization ダイアログボックスで、Email、Google Advertising ID (Android)、first name などのユーザー属性を見つけます。<img src="/images/moengage_f47d15.png" alt="9.png" /> first name をクリックすると、メッセージの内容は次のようになります。<img src="/images/moengage_0acaf0.png" alt="10usecase9.png" />
5. すべてのユーザーが現在地から店舗を見つけられるわけではありません。そのため、次のいずれかを実行できます。
   - ディープリンクオプションから店舗へのリンクを追加します。
     1. **Default click action** ドロップダウンリストから _Deeplinking_ を選択します。
     2. **URL** フィールドに店舗へのリンクを入力します。<img src="/images/moengage_5d343f.png" alt="11.png" />
   - 店舗にリンクするアクションボタンを追加します。
     1. **Buttons** セクションを展開し、**\+ Action button** をクリックします。<img src="/images/moengage_8933a5.png" alt="10usecase11.png" />
     2. **Button name** フィールドに、ボタンの名前を入力します。たとえば、_Take me there_ です。
     3. **Click action** リストで _Deeplinking_ を選択します。
     4. **URL** フィールドに店舗へのリンクを入力します。<img src="/images/moengage_47486f.png" alt="10usecase10.png" />
6. **Next** をクリックして 3 番目のステップ **Schedule and goals** に移動し、キャンペーンのスケジュールと目標を定義します。

## ステップ 3: スケジュールと目標

位置情報トリガーキャンペーンは、常にできるだけ早く公開されます。ただし、特定の時間ルールに基づいてメッセージを表示するタイミングを制御できます。

1. **Time bound for Geofences** セクションで **Limited period** オプションを選択します。
2. **\+ Another time bound** をクリックしてルールを追加します。<img src="/images/moengage_113601.png" alt="10usecase12.png" />
3. **Conversion goals** セクションで、追跡したい目標を追加します。
4. 要件に基づいて **Delivery controls** と **Advanced** の設定を定義します。詳細については、[Create Push Campaigns](/ja/user-guide/campaigns-and-channels/mobile-push/create/create-push-campaigns) を参照してください。<img src="/images/moengage_c54f75.png" alt="14.png" />
5. **Publish** をクリックします。

# まとめ

このユースケースでは、商品をカートに追加したもののまだ購入していないユーザーに、オフライン店舗で商品を試してもらうための Push キャンペーンを作成しました。コンバージョンを最大化するために、_カート放棄キャンペーン_ を並行して設定することもできます。

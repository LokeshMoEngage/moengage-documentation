# はじめに

電気自動車 (EV) が交通分野に革命をもたらし続ける中、利用しやすく信頼性の高い充電インフラの必要性はますます高まっています。自社の新しい EV 充電ステーションの宣伝を担当するマーケターとして、最大限の認知度とユーザーエンゲージメントを確保したいと考えるでしょう。新しい EV 充電ステーションについてユーザーに知らせることは、すぐに利用できる充電オプションを EV ドライバーに認識してもらうことで「航続距離への不安」を和らげるのに役立つため、非常に重要です。

MoEngage プラットフォームの機能を活用することで、ユーザーが近くにいるときに新しい充電ステーションをシームレスに告知および宣伝でき、最終的に認知度の向上、利便性の提供、ブランドロイヤルティの構築につなげられます。

#### 新しい EV 充電ステーションをユーザーに知らせるメリット

- **EV 普及の促進**: 充電ステーションの場所を知ることで、EV の購入を検討しているユーザーは、必要なときに簡単に充電できるため、電気自動車への乗り換えに自信を持ちやすくなります。
- **既存の EV オーナーにとっての利便性**: 職場、ショッピングセンター、一般的な移動ルート沿いなど、便利な場所に新しい充電ステーションがあると、EV ドライバーは充電しやすくなります。電力切れを心配することなく、より長い距離を移動できます。
- **サステナビリティの推進**: EV 充電をより利用しやすくすることで、よりクリーンな交通手段の利用を促し、環境面でのメリットに貢献できます。
- **経済的なメリット**: 充電ステーションを設置する企業は、便利な充電オプションを求める新規顧客を引き付けることができます。
- **より良いインフラ**: 投資家や企業は、充電インフラ事業が採算に乗るだけの十分な数の EV が走行するようになるのを待っています。新しい充電ステーションについてユーザーに知らせることは、EV の普及を促進し、充電インフラを投資家にとってより魅力的なものにすることで、この問題の解決に役立ちます。

このユースケースは、ユーザーが定義された場所に入ったときに新しい EV ステーションについて知らせる[位置情報トリガー Push キャンペーンを作成する](/ja/use-cases/push/inform-users-about-new-charging-station-for-evs#create-a-push-campaign)ことで実現します。

# Push キャンペーンの作成

このセクションでは、ユーザーが定義された場所に入ったときに新しい EV ステーションについて知らせる Push キャンペーンを作成します。

## ステップ 1: ユーザーのターゲティング

1. MoEngage ダッシュボードの左側のナビゲーションメニューで **Engage** をクリックし、**Campaigns** をクリックします。
2. All campaigns ページで **\+ Create campaign** をクリックします。
3. **Outbound** の下で **Push** \> **Location Triggered** をクリックします。<img src="/images/moengage_6d6b9d.png" alt="locationtriggu.png" /> キャンペーンを定義する最初のステップ **Target users** に移動します。
4. キャンペーンの名前とタグを定義します。次の詳細を入力します。
   1. **Team**: 組織のアカウントで Teams が有効になっている場合は、チームを選択します。詳細については、[Teams in MoEngage](/ja/user-guide/settings/account/team-management/teams-in-moengage) を参照してください。たとえば、_Usecases_ です。
   2. **Campaign name**: キャンペーンの名前を入力します。たとえば、_New EV station Announcement_ です。
   3. **Campaign tags**: 必要なキャンペーンタグを選択します。<img src="/images/moengage_514990.png" alt="4usecase1.png" />
5. ジオフェンスを定義します。定義する際に、ユーザーがこの地域に入ったとき、出たとき、または一定時間滞在したとき (Android のみ可能) に通知を表示するかどうかを決定できます。
   1. **Geofence** セクションで **\+ Add Geofence** をクリックします。<img src="/images/moengage_7202fd.png" alt="4usecase2.png" />
   2. Add Geofence ページの **Geofence name** フィールドに、ジオフェンスの名前を入力します。たとえば、_ChargingStation@DisneylandPark_ です。
   3. **Send notification when** リストで、コミュニケーションを表示するタイミングを選択します。この例では、_User enters the Geofence_ を選択します。
   4. **Notification responsiveness** リストで、応答性を _5 Minutes_ に定義します。これは基本的に、ユーザーが定義された地域に入ったかどうかを MoEngage が確認する頻度です。<img src="/images/moengage_dd4ce5.png" alt="4usecase3.png" />
   5. **Search for a place** ボックスで、店舗の場所を検索します。この例では、_Disneyland Park, Anaheim, CA, USA_ を選択します。
   6. 地図の下で半径を定義します。<img src="/images/moengage_e630a5.png" alt="4usecase4.png" />
6. **Done** をクリックしてジオフェンスを追加します。これによりフェンスが追加され、最初に **\+ Add Geofence** ボタンが表示されていた **Geofence** セクションで確認できます。<img src="/images/moengage_9e19de.png" alt="EV2.png" />
7. 複数のフェンスを追加する場合は、もう一度 **\+ Add Geofence** をクリックし、上記の手順を繰り返します。フェンスの内容を編集する場合は、編集アイコンをクリックして必要な変更を行います。<img src="/images/moengage_0e2bee.png" alt="4usecase5.png" />
8. **Target audience** セクションで **Filter users by** をクリックし、**User behavior** タブをクリックします。
9. 次に示すように、条件 _Has Not Executed_ を選択し、過去 30 日間の _Added to Cart_ イベントを選択します。<img src="/images/moengage_b6c8b1.png" alt="4usecase6.png" />
10. **Target Platforms** セクションで **Android** を選択します。<img src="/images/moengage_a35cae.png" alt="4usecase7.png" />
11. **Next** をクリックして 2 番目のステップ **Content** に移動し、Push キャンペーンのコンテンツを定義します。

## ステップ 2: コンテンツ

1. 使用するテンプレートを選択します。たとえば、**Basic notification** を選択します。<img src="/images/moengage_6fb7b1.png" alt="4usecase8.png" />
2. キャンペーンに必要なコンテンツを入力します。タイトル、メッセージ、サマリーは手動で入力することも、Merlin AI を使用して生成することもできます。詳細については、[Generate Push Messages with Merlin AI](/ja/user-guide/ai-and-intelligence/merlin-ai/merlin-ai-copywriter/generate-push-messages-with-merlin-ai) を参照してください。<img alt="image-20240120-140052.png" src="/images/moengage_23968f.png" />
3. ユーザーの名前などの情報を使用して、メッセージにパーソナライゼーションを追加します。このようなパーソナライゼーションにより、メッセージがより状況に即したものになり、ユーザーはつながりを感じられます。これを行うには、次の手順に従います。
   1. _@_ と入力します。
   2. **Push Personalization** ダイアログボックスで、Email、Google Advertising ID (Android)、first name などのユーザー属性を見つけます。<img alt="image-20231225-101253.png" src="/images/moengage_068466.png" />\
      first name を選択すると、メッセージの内容は次のようになります。<img src="/images/moengage_2a2da7.png" alt="Screenshot 2024-01-20 at 7.32.26 PM.png" />
4. すべてのユーザーが現在地から充電ステーションを見つけられるわけではありません。そのため、次のいずれかを実行できます。
   - Deeplink オプションから充電ステーションへのリンクを追加します。
     1. **Default click action** リストで _Deeplinking_ を選択します。
     2. **URL** フィールドに店舗へのリンクを入力します。<img alt="Screenshot 2023-12-25 at 4.54.09 PM.png" src="/images/moengage_ee2e4e.png" />
   - 充電ステーションにリンクするアクションボタンを追加します。
     1. **Buttons** セクションを展開し、**\+ Action button** をクリックします。<img src="/images/moengage_48669f.png" alt="4usecase9.png" />
     2. **Button name** フィールドに、ボタンの名前を入力します。たとえば、_Take me there_ です。
     3. **Click action** リストで _Deeplinking_ を選択します。
     4. **URL** フィールドに充電ステーションへのリンクを入力します。<img src="/images/moengage_7b7b89.png" alt="4usecase10.png" />
5. **Next** をクリックして 3 番目のステップ **Schedule and goals** に移動し、キャンペーンのスケジュールと目標を定義します。

## ステップ 3: スケジュールと目標

位置情報トリガーキャンペーンは、常にできるだけ早く公開されます。ただし、特定の時間ルールに基づいてメッセージを表示するタイミングを制御できます。

1. **Time bound for Geofences** セクションで **Limited period** オプションを選択します。
2. **\+ Another time bound** をクリックしてルールを追加します。<img src="/images/moengage_c681dd.png" alt="4usecase11.png" />
3. **Conversion goals** セクションで、追跡したい目標を追加します。
4. 要件に基づいて **Delivery controls** と **Advanced** の設定を定義します。詳細については、[Create Push Campaigns](/ja/user-guide/campaigns-and-channels/mobile-push/create/create-push-campaigns) を参照してください。<img src="/images/moengage_fccdcf.png" alt="14.png" />
5. **Publish** をクリックします。

# まとめ

このユースケースでは、新しい EV 充電ステーションを告知するための Push キャンペーンを作成しました。このキャンペーンは、ユーザーが定義された場所に入ったときに、新しい EV ステーションについて知らせるプッシュ通知を送信します。

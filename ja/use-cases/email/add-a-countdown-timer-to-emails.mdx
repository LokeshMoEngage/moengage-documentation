# はじめに

マーケターは、Webサイトやアプリへのトラフィックを増やすために、ライトニングディール、深夜限定セール、フラッシュセール、製品ローンチ、イベント登録、メンバーシップ更新、期間限定セールなど、期限付きのオファーを活用します。こうしたキャンペーンでは、行動を起こすまでの残り時間を示すカウントダウンタイマーがよく使用されます。これによりユーザーの注意を引き、「見逃したくない」という感情(FOMO)を生み出して購入を後押しします。

#### メールキャンペーンにカウントダウンタイマーを追加するメリット

- **コンバージョンの向上**: 目に見えて時を刻む時計が即座の行動を促し、購読者が期間限定オファー中に購入する可能性が高まります。
- **Webサイトやアプリのトラフィック増加**: カウントダウンタイマーの視覚要素が注意を引き、メールへのインタラクションを促します。
- **期限付きオファーの強調**: フラッシュセール、限定版の製品、重要な締め切りのある今後のイベントに最適です。
- **希少性の演出**: カウントダウンによって入手機会が限られていると感じさせ、より早い行動を促します。
- **クリック率の向上**: カウントダウンタイマーは、メールキャンペーンのクリック率の向上につながることがよくあります。

このユースケースは、次の手順で実現できます。

1. [カウントダウンタイマーを作成する](/ja/use-cases/email/add-a-countdown-timer-to-emails#step-1-create-a-countdown-timer)
2. [タイマーのHTMLコードを生成する](/ja/use-cases/email/add-a-countdown-timer-to-emails#step-2-generate-html-code-for-the-timer)
3. [MoEngageのメールテンプレートにHTMLを埋め込む](/ja/use-cases/email/add-a-countdown-timer-to-emails#step-3-embed-html-in-your-moengage-email-template)

# ステップ1: カウントダウンタイマーを作成する

1. _CountdownMail_ のWebサイトにログインします。 <img alt="Timer_1.jpg" src="/images/moengage_91eaeb.png" />
2. 右上の **Create a Timer** をクリックしてタイマーを作成します。
3. ラベル、色、フォントサイズ、背景画像、リンクを定義してタイマーをカスタマイズします。
4. 右下の **Save Timer** をクリックします。

# ステップ2: タイマーのHTMLコードを生成する

<Info>
  外部ソースのHTMLコードを統合して、メールにカウントダウンタイマーを追加できます。タイマー用のカスタムHTMLコードを有効にするにはJavascriptが必要です。ただし、セキュリティ上の理由から、メールプラットフォームはJavascriptをサポートしていません。
</Info>

1. CountdownMailのWebサイトで、画面右下の **`</>` Get Embed Code** をクリックして、作成したタイマーのHTMLコードを生成します。
2. 次の埋め込みオプションを使用できます。
   - **Align**: タイマーをページの左、右、または中央に配置できます。
   - **Size**: タイマーを固定サイズにするか、画面サイズに応じたレスポンシブにするかを選択できます。
   - **For Retina display**: キャンペーンによっては、Retinaディスプレイの画面を対象とする場合があります。このトグルをオンにすると最大幅が調整されます。
   - **Enable HTTPS**: SSLを使用するページにタイマーを表示する場合、このオプションが必要です。
3. **Copy** をクリックして埋め込みコードをコピーします。
4. [ステップ3: MoEngageのメールテンプレートにHTMLを埋め込む](/ja/use-cases/email/add-a-countdown-timer-to-emails#step-3-embed-html-in-your-moengage-email-template)の説明に従って、コピーしたコードをMoEngageのメールに追加します。

![Generate](/images/moengage_1fe3c6.png)

# ステップ3: MoEngageのメールテンプレートにHTMLを埋め込む

このセクションでは、メールキャンペーンを作成し、メールテンプレートにHTMLコードを埋め込みます。

## ステップ3.1: ターゲットユーザー

1. MoEngageダッシュボードの左側のナビゲーションメニューで、**Engage** をクリックし、次に **Campaigns** をクリックします。
2. **All campaigns** ページで、**\+ Create new** をクリックします。
3. **Outbound** で **Email** をクリックし、次に **One Time** をクリックします。
   ![one time.png](/images/moengage_45e63c.png)
4. 任意のキャンペーン名、ターゲットオーディエンスのセグメント、コントロールグループを追加します。
5. **Next** をクリックして、2番目のステップである **Content** に進みます。

## ステップ3.2: コンテンツ

1. 任意のメールテンプレートを選択してドラッグアンドドロップエディターで編集するか、テンプレートをアップロードしてカスタムHTMLエディターで編集できます。
   <Tabs>
     <Tab title="ドラッグアンドドロップエディター">
     任意のテンプレートをドラッグアンドドロップエディターに読み込み、必要に応じてテンプレートをカスタマイズします。
      コピーしたHTMLを埋め込むには:
      1. エディターの **Content** タブに移動します。
      2. テンプレート内の任意の位置に空の行を追加します。
      3. **HTML** 要素をこの空の行にドラッグアンドドロップします。
      4. HTML要素をクリックし、右側のペインの **I'm a new HTML block** の部分にコピーしたコードを貼り付けます。コードを貼り付けると、以下のようにタイマー要素がメールテンプレートに追加されます。
      ![EmbedHTMLCode.gif](/images/moengage_a0e98c.png)
     </Tab>
     <Tab title="カスタムHTMLエディター">
     カスタムHTMLエディターを選択して任意のテンプレートをアップロードするか、HTMLコードをコピーしてエディターに貼り付けます。テンプレートが読み込まれたら、タイマーのコードを埋め込みます。
      コピーしたタイマーのコードを埋め込むには:
      1. エディター上部のオプションバーにある **_`</>`_** をクリックして、コードビューに切り替えます。
      2. HTML本文(`<body>`)内の任意の位置に空の行を追加します。この例では、テンプレートの先頭に空の行を追加しています。
      3. コピーしたコードを行(`<tr>`)内に貼り付けます。
      4. **Code View** をクリックして、テンプレートのプレビュー画面に戻ります。 <img alt="CustomEditor.gif" src="/images/moengage_7f75b4.png" />
     </Tab>
   </Tabs>
       
2. **Next** をクリックして、3番目のステップである **Schedule and Goals** に進みます。

## ステップ3.3: スケジュールと目標

1. **Send campaign** セクションで、メールメッセージを送信するタイミングを定義します。
2. **Conversion Goals** セクションで、トラッキングしたいコンバージョン目標を追加します。
3. **Delivery controls** セクションで、要件に応じてコントロールを定義します。
4. **Publish** をクリックします。

# まとめ

カウントダウンタイマーを作成し、それを含むキャンペーンを送信したら、[メールのアナリティクスと情報](/ja/user-guide/campaigns-and-channels/email/analyze/email-analytics-and-info)に移動してキャンペーンのパフォーマンスを確認してください。

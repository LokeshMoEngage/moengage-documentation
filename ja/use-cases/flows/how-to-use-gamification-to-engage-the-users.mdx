# 概要

ユーザーを獲得したら、次のステップはユーザーを維持することです。ユーザーを維持するには、ブランドのアプリを使い続けて最終的にコンバージョンするよう促すエンゲージメントのきっかけを作ることが不可欠です。ここで「Spin the Wheel」などのゲーミフィケーションテンプレートが重要な役割を果たし、次のメリットをもたらします。

- ユーザーエクスペリエンスの向上
- エンゲージメント指標の改善
- コンバージョンの向上

この記事では、Flows とゲーミフィケーションテンプレートを使用して、ユーザー向けのエンドツーエンドのエンゲージメントジャーニーを作成します。

# 期待される結果

# Flow を作成する

このセクションでは、Flow を作成します。

## Flow の詳細を追加する

1. **Engage** \> **Flows** に移動して **\+ Create Flow** をクリックするか、サイドバーに移動して **\+ Create new** をクリックしてから **Flow** をクリックします。
2. **\+ Start with a blank canvas** をクリックして、このユースケース用の Flow の作成を開始します。最初のステップ「Details and goals」に移動します。
3. 次の詳細を入力します。
   - **Flow name**: Flow 名を入力します。たとえば、「Gamification Flow」と入力します。
   - **Flow tags**: 必要な Flow タグを選択します。
4. **Next** をクリックして 2 番目のステップ「When will users enter the flow」に進みます。このステップでは、トリガー条件を指定して、ユーザーをいつ Flow に参加させるかを定義します。
5. **Users enter the flow** セクションで **On event trigger** を選択します。
6. **IF user** セクションで、ユーザーがアプリを更新したときにトリガーされるイベント「App Update」を選択します。
7. **THEN enter the user** セクションで、**Immediately** オプションを選択します。
8. **Flow schedule** セクションで、必要に応じて Flow の開始時刻と終了時刻を定義します。デフォルトでは、Flow は「As soon as possible」に開始され、終了しません。
9. **Limit user entry into this flow** トグルをオンにして、ユーザーが Flow に参加できる最大回数を定義します。\
   このような制限を定義すると、ユーザーが繰り返し Flow に再参加するのを制御でき、過剰なメッセージ送信を避けられるため、より良いユーザーエクスペリエンスを提供できます。 <img alt="image-20231125-123528.png" src="/images/moengage_5f49e1.png" />
10. **Next** をクリックして 3 番目のステップ「Who will enter the flow」に進みます。ここでは、Flow のターゲットオーディエンスを選択します。
11. **Audience** セクションで **All users** を選択します。イベントトリガー型の Flow に参加する資格を得るには、ユーザーが必要なイベントを実行する前にターゲットオーディエンスに含まれている必要があります。
12. **Next** をクリックしてキャンバスセクションに移動します。ここでは、ユーザーが進む Flow の構造を定義できます。

## Flow の構造を定義する

このセクションでは、ユーザーをエンゲージするためのマルチステップジャーニーを作成します。以下は一例であり、要件に応じて変更できます。

1. **\+** アイコンをクリックします。ドロワーが表示されます。
2. **Actions** で **In-app** を選択します。
   ![17.png](/images/moengage_fc7457.png)
3. In-app テンプレートの種類を選択します。たとえば、Fullscreen - Spin The Wheel を選択します。
   ![wheel 7.png](/images/moengage_37cabd.png)
4. 既製の HTML コードを変更し、コンバージョンの詳細を追加します。
   ![wheel 8.png](/images/moengage_3b4c3a.png)
5. HTML コードを変更して、ホイール上のアクションの名前を変更したり、デザインを変更したり、ホイールにアクションを追加したりできます。
6. ゲーミフィケーションの In-app が完成したら、ユーザーのアクションに応じて Flow を展開します。
   ![18.png](/images/moengage_cc7189.png)
   たとえば、ユーザーが In-app をクリックしたかどうかを確認します。クリックしていない場合は、Push キャンペーンでユーザーに働きかけます。クリックした場合は、コンバージョン目標のイベントを確認し、さらにさまざまなチャネルを通じてキャンペーンを送信して、ホイールを回してコンバージョンするよう促します。
   <img
     alt="19.png"
     src="/images/moengage_afe9c5.png"
     style={{ width:"52%" }}
   />
7. すべてのチャネルのコミュニケーションを追加して Flow の準備ができたら、**Publish** をクリックして Flow を公開します。

# まとめ

このユースケースでは、ゲーミフィケーションキャンペーンを追加して、ユーザーをエンゲージするためのマルチステップ、マルチチャネルのジャーニーを作成しました。Flows とゲーミフィケーションテンプレートを使用して、ユーザー向けのエンドツーエンドのエンゲージメントジャーニーを作成しました。

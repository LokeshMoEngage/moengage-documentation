# はじめに

マーケターにとって、設定した最終目標を達成する前に離脱したユーザーを把握することは重要です。これにより、マーケターはユーザーをリターゲティングし、離脱を減らすことができます。

この記事では、商品を閲覧した後、購入する前に離脱したユーザーをターゲットにする方法について、次の手順で説明します。

1. ユーザーを特定するためのファネルを作成します。
2. このファネルの定義を使用してセグメントを作成します。
3. このセグメントを使用して、離脱したユーザーをターゲットにする Push キャンペーンを作成します。

# 期待される結果

  - ユーザーが商品をカートに追加するアクションと商品を購入するアクションを追跡するイベント。この例では、それぞれ「addedToCart」と「Product Purchased」というイベント名にします。イベントの追跡方法については、[Developer Guide](/ja/developer-guide/introduction) を参照してください。

  - アカウントで Funnels が有効になっていること。

# ファネル分析でユーザーを見つける

ファネル分析では、さまざまなイベントを選択し、それらのイベントを実行したユーザー数を確認できます。このセクションでは、過去 30 日間に商品を閲覧した後、購入せずに離脱したユーザーを見つけます。

1. MoEngage ダッシュボードに移動します。
2. 左側のナビゲーションから **Analyze** \> **Funnels** を選択します。
3. **Steps** で、最初のドロップダウンリストから「Product Viewed」を選択します。
4. 2 番目のドロップダウンリストから「addedToCart」を選択します。
5. イベントをさらに追加するには、**\+ Add Step** をクリックし、ドロップダウンリストから「Product Purchased」を選択します。
   ![UC57-1.png](/images/moengage_1fbbd3.png)
6. **\+ OR** をクリックして、各ステップに他のイベントを追加します。これは、次のように、プラットフォームごとに複数のイベントがある場合や、最終目標につながる同じステップの一部として異なるアクションがある場合に役立ちます。
   ![UC57-2.png](/images/moengage_086374.png)
   これにより、実質的に (Product Viewed または Product Searched)、(addedToCart または Buy Now)、および Product Purchased のイベントを実行したユーザーが対象になります。
7. 特定のユーザーセグメントではなく、すべてのユーザーを対象にこの分析を行いたいため、**Filter Users** セクションで **All users** を選択します。
   ![UC57-3.png](/images/moengage_72c330.png)
8. **Funnel Options** セクションで、次の詳細を入力します。
   | フィールド | 説明 |
   | --- | --- |
   | **Funnel Type** | このユースケースでは、ユニークユーザー数を取得したいため、「Unique Users」を選択します。上記のすべてのイベントをユーザーが完了するまでにかかる時間を確認するのにも役立ちます。 |
   | **Duration** | このユースケースでは、「Last 30 days」を選択して、分析の対象とする期間を定義します。 |
   | **Funnel split** | デフォルト値のままにします。 |
   | **Holding Attribute** | デフォルト値のままにします。 |
   | **Funnel window** | このユースケースでは、7 days を選択します。これにより、ユーザーが「Product Viewed」を実行してから「Product Purchased」を実行するまでの最大間隔を 7 日間として分析が行われます。このオプションを使用すると、最初のイベントと最後のイベントの間の最大時間間隔を定義できます。 |
   | **Order** | このユースケースでは、このトグルをオンにして、定義したイベントを定義した順序どおりに実行したユーザーのみを対象にします。 |
   次の画像は、オプションの定義方法の例を示しています。
   ![UC57-4.png](/images/moengage_3c4f8b.png)
9. **APPLY** をクリックします。予想どおり、グラフには「Product Viewed」から「Product Purchased」までのイベントを実行したユーザーの離脱が表示されます。
   ![UC57-5.png](/images/moengage_5bfc16.png)

ファネル分析が完了したので、ユーザーをリターゲティングするためのカスタムセグメントを作成しましょう。

# セグメンテーションでユーザーをリターゲティングする

このセクションでは、「addedToCart」イベントを実行したものの、「Product Purchased」イベントを実行していないユーザーをリターゲティングするためのカスタムセグメントを作成します。

1. 「Step 3 Product Purchased」列（または 3 番目の列）をクリックします。Create segment ポップアップが表示されます。
   ![UC57-6.png](/images/moengage_898bba.png)
2. デフォルトで選択されている **Static segment** オプションのままにします。これは、この時点での現在の分析結果のユーザーのみがセグメントの対象になることを意味します。\
   必要に応じて、**Dynamic segment** を選択することもできます。これにより、セグメントが動的に更新され、過去 30 日間に条件を満たしたユーザーが取得されます。
3. **Segment name** フィールドに、セグメントの名前を入力します。たとえば、「AbandonCart\_Users」と入力します。
4. **Take action on the Custom Segment** チェックボックスを選択します。
5. **Create campaign for this segment** オプションを選択します。
6. ユーザーにプッシュ通知を送信したいため、**Campaign channel** ドロップダウンリストから「Push Campaign」を選択します。
7. ユーザーにプッシュ通知を 1 回だけ送信したいため、**Delivery type** ドロップダウンリストから「One Time Push Campaign」を選択します。
   ![UC57-7.png](/images/moengage_cef686.png)
8. **Create** をクリックします。Push キャンペーンの作成ページに移動します。
9. Push キャンペーンを作成します。Push キャンペーンの作成手順については、[Create Push Campaigns](/ja/user-guide/campaigns-and-channels/mobile-push/create/create-push-campaigns) を参照してください。

# まとめ

このユースケースでは、商品をカートに追加した後、購入する前に離脱したユーザーを特定するファネルを作成し、そのファネルの定義を使用してセグメントを作成しました。さらに、そのセグメントを使用して、離脱したユーザーをターゲットにする Push キャンペーンを作成しました。

高額商品やコンバージョンまでに時間がかかる商品の場合は、Flows を使用して、チャネルをまたいでユーザーに複数のコミュニケーションを送信できます。MoEngage の [User Paths](/ja/user-guide/analyze/analytics/user-paths/user-paths-overview) を使用して、ユーザージャーニーをさらに分析することもできます。

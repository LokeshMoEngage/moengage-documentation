# はじめに

マーケターとして、私たちは Web サイトを、訪問者一人ひとりの好みを先読みする、洗練された応答性の高いデジタルストアフロントへと進化させたいと考えています。MoEngage Personalize を使用すると、商品グリッドを使用してレコメンド商品を表示できます。高度なレコメンデーションアルゴリズムと直感的なノーコードの WYSIWYG エディターを組み合わせて活用することで、パーソナライズされた商品グリッドを Web インターフェイスに直接シームレスに埋め込むことができます。

これにより、ユーザーの行動や好みから生成された関連性の高いパーソナライズされたコンテンツが提示され、ユーザーはシームレスで楽しいショッピング体験を得られます。このようなパーソナライズされたレコメンデーションは、ユーザーにとって関連性が高く興味深いものである可能性が高いため、ユーザーエンゲージメント指標の向上、クリックスルー率の増加、サイトのコンバージョン向上の可能性につながります。

#### 商品グリッドを使用するメリット

- **販売実績の向上:** 商品グリッドを使用して商品をレコメンドすると、ユーザーは自分の興味に関連する他の類似商品や、一緒に購入する可能性のある商品を確認できます。これにより売上が増加し、ユーザーの追加購入が促されます。
- **パーソナライズされたレコメンデーション:** 商品グリッドを使用すると、ユーザーの興味に基づいてパーソナライズされた商品をレコメンドできます。これによりエンゲージメントが向上し、ユーザーは興味に基づいてさらに探索し、購入できるようになります。
- **効率的なマーケティング:** ユーザーの行動や興味に基づいて商品をレコメンドすることで、商品に興味のない一般のオーディエンスへのエンゲージメントに費やすマーケティングコストと労力を大幅に削減できます。
- **ブランド認知度の構築:** ユーザーの興味や行動に基づいたパーソナライズされたコンテンツでユーザーにエンゲージすることで、オーディエンスの間でのブランド認知度と評判が高まります。
- **より良いユーザー体験:** ユーザーの興味に基づいて商品をレコメンドすることで、ユーザーエンゲージメントが向上し、より良いユーザー体験が提供されるため、より多くのユーザーを引き付けられます。

このユースケースは、MoEngage Personalize を活用して、商品グリッドを使用してレコメンド商品を表示することで実現します。

# 商品グリッドの追加

Web サイトに商品グリッドを追加するには、次の手順に従います。

1. レコメンデーションセットを作成したら、新しい Personalize Experience の作成に進みます。詳細については、[Create an Experience](/ja/user-guide/personalize/client-side-personalization/client-side-personalization/create-client-side-personalization-experience) を参照してください。
2. Web のパーソナライズされた体験を作成する **ステップ 2** (Content) で、商品グリッドを追加するバリエーションの **Personalize** をクリックし、Web サイトの URL を指定します。
3. Web サイト上でグリッドを追加したい場所をクリックして、Personalize エディターを呼び出します。
4. リストから \+ Add Widget を選択します。
5. Select widget ウィンドウペインから Product grid をクリックします。
6. 画面上で選択した要素の前または後に要素を挿入するための位置 (before または after) を選択します。
7. **Edit Item Grid** では、Grid Appearance、Edit cards、Map Information を設定できます。

## ステップ 1: Grid Appearance

グリッドのレイアウトの詳細を指定します。次のオプションを使用できます。

| フィールド | 説明 |
| --- | --- |
| **Grid Layout** | レイアウトを選択し、次の項目を指定します: <ul><li>Columns</li><li>Grid Dimensions (Height、Width、Radius、Background)</li><li>Grid Scroll (Size、Opacity、Arrow color)</li><li>Border Properties (Style、Width、Color)</li></ul> |
| **Grid Title** | 商品グリッドにタイトルを追加します。タイトルのスタイルは、手動または CSS を使用して編集できます。 |
| **Grid Sub Title** | 商品グリッドにサブタイトルを追加します。タイトルのスタイルは、手動または CSS を使用して編集できます。 |
| **Grid CTA** | CTA テキストを追加し、そのスタイルを手動または CSS を使用して定義します。 |

![Grid Appearance.gif](/images/moengage_cf0e9a.png)

## ステップ 2: Edit Card

このオプションでは、各レコメンデーション (カードと呼ばれます) のレイアウト、スタイル、個々の要素を定義できます。プレビューに表示される情報 (画像、ラベル、価格など) は説明のためだけのものです。この情報は、ステップ 3 (Schedule and goals) でグリッドにマッピングされたレコメンデーションからレンダリングされます。

編集オプションは次のとおりです。

| フィールド | 説明 |
| --- | --- |
| **Layout** | レイアウトを選択し、**Dimensions**、**Margin**、**Border Properties** を指定します。 |
| **Title** | 商品グリッドにタイトルを追加します。タイトルのスタイルは、手動または CSS を使用して編集できます。 |
| **Sub Title** | 商品グリッドにサブタイトルを追加します。このフィールドは必要に応じて有効または無効にできます。タイトルのスタイルは、手動または CSS を使用して編集できます。 |
| **Image** | このフィールドは必要に応じて有効または無効にできます。画像のレイアウトとサイズを指定し、画像のスタイルを手動または CSS を使用して編集できます。 |
| **Label** | 各カードにはデフォルトで 2 つのラベルがあります。プレビューで確認でき、必要に応じて有効または無効にできます。各ラベルのスタイルは、手動または CSS を使用して編集できます。 |
| **Price** | 各カードには 2 つの価格要素と 1 つの割引要素があります。必要に応じて有効または無効にできます。各要素のスタイルは、手動または CSS を使用して編集できます。 |
| **Rating** | 各カードには評価要素があります。必要に応じて有効または無効にできます。スタイルは、手動または CSS を使用して編集できます。 |
| **Review** | 各カードにはレビュー要素があります。必要に応じて有効または無効にできます。スタイルは、手動または CSS を使用して編集することもできます。 |
| **CTA** | 各カードにはデフォルトで 2 つの CTA があります。プレビューで確認でき、必要に応じて有効または無効にできます。各 CTA のスタイルは、手動または CSS を使用して編集できます。 |

![EditCard.gif](/images/moengage_ca60c4.png)

## ステップ 3: Map Information

1. 商品グリッドをレコメンデーションにマッピングします。使用可能なオプションは次のとおりです。
   | フィールド | 説明 |
   | --- | --- |
   | **Name of your grid** | 商品グリッドの名前です。ユーザーインタラクションの統計を表示するために、MoEngage ダッシュボードの Experience Analytics ページに表示されます。 |
   | **Choose your recommendation** | 商品グリッドをマッピングするレコメンデーションを選択します。 |
   | **Map Recommendations from** | このセクションでは、次の画像に示すように、商品グリッド内の個々の要素を、選択したレコメンデーションの属性にマッピングできます。 |
   ![MapInformation.gif](/images/moengage_684b53.png)
2. **Save** をクリックして、商品グリッドを Web ページに追加します。ビジュアルエディターには、商品画像とカード上の個々の要素のプレースホルダー値を含む商品グリッドが表示されます。商品カタログの実際の値は、Web サイトの Web 体験が公開されると表示されます。グリッドとカード要素にカスタム CSS を適用した場合、グリッドの外観の変更は、Web サイトの Web 体験が公開されると表示されます。

# まとめ

このユースケースでは、MoEngage Personalize を使用して、商品グリッドを使用してレコメンド商品を表示しました。

レコメンド商品グリッドを含む体験が公開されたら、体験の Analytics セクションで商品グリッドに関連する統計を追跡できます。詳細については、[Experience Analytics](/ja/user-guide/personalize/client-side-personalization/client-side-personalization/experience-analytics) を参照してください。

## 一般的なユースケース

| ユースケース | 説明 | 実現方法 |
| --- | --- | --- |
| 最近閲覧した商品またはカートに追加した商品のグリッド | <ul><li>最近閲覧した商品やカートに追加した商品を見ることで、ユーザーは Web サイトが自分の興味を把握していると感じ、ロイヤルティが高まり、再訪問や再購入につながる可能性があります。</li><li>最近閲覧した商品を表示すると、ユーザーは商品を再度検索する必要がないため、時間の節約になります。この利便性はポジティブなユーザー体験につながり、顧客が将来 Web サイトに戻ってくることを促せます。</li><li>また、顧客が興味を持っていたものの忘れていた可能性のある商品をリマインドすることもできます。</li></ul> | 適切なユーザーアクションに対応する基本レコメンデーションセットを作成し、Web ページに商品ページを配置する際にこのレコメンデーションセットをマッピングします。エンゲージメントを高めるために、この商品グリッドを Web サイトのホームページに配置できます。 |
| 類似商品のレコメンド | 類似商品をレコメンドすることで、ユーザーは自分の興味に合ったより幅広い商品の選択肢を提示されます。顧客がさまざまな商品を探索して検討することで、エンゲージメントとクリックスルー率が向上する可能性があります。 | 類似アイテムアルゴリズムを使用して AI レコメンデーションセットを作成し、Web ページに商品ページを配置する際にこのレコメンデーションセットをマッピングします。この商品グリッドは、個々の商品の商品説明ページに配置できます。 |
| アップセルまたはクロスセルの機会 | 頻繁に購入または閲覧される商品のレコメンドは、クロスセルやアップセルに活用できます。ユーザーは、興味を持つ可能性のある関連商品や上位商品の購入を促されます。 | _Frequently Bought Together_ または _Frequently Viewed Together_ アルゴリズムを使用して AI レコメンデーションセットを作成し、Web ページに商品ページを配置する際にこのレコメンデーションセットをマッピングします。 |

以前は _Sherpa AI_ と呼ばれていたすべての MoEngage AI 製品は、現在 _Merlin AI_ と呼ばれています。

# はじめに

訪問者やユーザーの現在の Web 閲覧セッションをパーソナライズすることは非常に重要です。これにより、企業は個人の興味やニーズに合わせた、関連性の高いコンテンツと体験を提供できます。このレベルのパーソナライズは、ユーザーの全体的な閲覧体験を向上させ、より魅力的で楽しいものにします。

ユーザーの閲覧行動や好みを理解することで、企業はユーザーの心に響く可能性が高い、ターゲティングされたレコメンデーション、オファー、提案を提供できます。これにより、コンバージョンの可能性が高まるだけでなく、ユーザーとブランドとのつながりとロイヤルティも強化されます。

ユーザーの好みに基づいて Web サイトのレイアウト、ナビゲーションオプション、コンテンツの表示方法を調整することで、企業は一人ひとりに合わせたように感じられる使いやすいインターフェースを作成できます。これにより、満足度の向上、閲覧セッションの長時間化、再訪問の可能性の向上につながります。

この記事では、Personalize の In-session behavior ターゲティング機能を使用して、Web ページのレイアウトとコンテンツをパーソナライズします。

# 期待される結果

訪問者が In-Session behavior の一部として指定された条件を満たすたびに、Web ページにパーソナライズされたエクスペリエンスが表示されます。以下は、"Tops" に関心のある訪問者向けにパーソナライズされたホームページのサンプルです。

![6.png](/images/moengage_3c2f03.png)

<Tip>
  - MoEngage Web SDK を通じて Web サイト上のユーザーアクティビティを追跡するイベントがすでに設定されている必要があります。イベントの追跡方法については、[Developer Guide](/ja/developer-guide/web-sdk/web-sdk-overview/web-sdk-overview) を参照してください。
  - パーソナライズされた Web 体験を作成するために、MoEngage Personalize SDK を Web サイトに統合しておく必要があります。詳細については、[Personalize SDK Integration Guide](/ja/developer-guide/personalize-sdk/sdk-integration/web-personalization-v2) を参照してください。
  - ワークスペースで Personalize 機能が有効になっている必要があります。この機能を有効にするには、アカウントマネージャーにお問い合わせください。
</Tip>

# パーソナライズされたエクスペリエンスを作成する

このセクションでは、ユーザーに Web サイトで体験してもらいたいパーソナライズされたエクスペリエンスを作成します。

## ステップ 1: ターゲットユーザー

1. 左側のサイドバーに移動して **Personalize** **\>** **All Experiences** をクリックし、**\+ Experience** \> **Web (WYSIWYG)** をクリックするか、**\+ Create new** \> **Experience** \> **Web** \> **Web (WYSIWYG)** をクリックします。
   ![UC-88.png](/images/moengage_2e912d.png)
   パーソナライズされたエクスペリエンスを定義する最初のステップである "Target users" に移動します。
2. 次の詳細を入力します。
   - **Experience name**: 作成するパーソナライズの名前です。例: "Personalize Current Browsing Session"。
   - **Experience Tags**: 後で他のパーソナライズされたエクスペリエンスと区別できるように、ここにタグを追加します。
     ![6.png](/images/moengage_bad754.png)
3. **Target Audience** で **\+ Add Audience** をクリックし、**\+ New Audience** をクリックしてターゲットオーディエンスを定義します。新しいオーディエンスの作成の詳細については、[こちら](/ja/user-guide/personalize/client-side-personalization/client-side-personalization/create-client-side-personalization-experience)を参照してください。
   ![5.png](/images/moengage_03e3eb.png)
4. **\+ In-session Behavior** をクリックし、訪問者の閲覧セッションをパーソナライズするためのイベントを選択します。このユースケースでは、ユーザーが "Tops" の下にある任意の Web ページカテゴリにアクセスするたびに、ホームページのバナーとカテゴリレイアウトをパーソナライズします。
5. **Add** をクリックします。
6. **Next** をクリックして 2 番目のステップ "Content" に移動し、キャンペーンに含めるコンテンツを定義します。

## ステップ 2: コンテンツ

1. 最初のステップ "Target users" で **Next** をクリックすると、URL(s) to personalize ポップアップが表示されます。これを使用して、定義したパーソナライズを Web サイトのどこに表示するかを定義できます。\
   ![image-20240120-115200.png](/images/moengage_28172c.png)
2. 単一の Web ページと複数の Web ページのどちらでもパーソナライズできます。\
   **注**: 複数の Web ページの場合、パーソナライズする要素が、Web ページのフィルター条件に一致するすべてのページに存在している必要があります。要素が存在しない場合、パーソナライズはユーザーに表示されません。
3. **URL** フィールドに設定を行う URL を入力し、**Verify SDK setup** をクリックします。これにより、ページに SDK がインストールされているかどうかがチェックされます。
   ![2.png](/images/moengage_b3aa48.png)
4. **Personalize URL** をクリックして、エディターで Web サイトを開きます。
5. 目的のバリエーションの **Personalize** をクリックすると、新しいタブで MoEngage の WYSIWYG (What-You-See-Is-What-You-Get) ビジュアルエディターを使用して Web ページをパーソナライズする次のステップに進みます。\
   **注:** **Default** バリエーションを除くすべてのバリエーションでコンテンツをパーソナライズできます。
   ![3.png](/images/moengage_5e58eb.png)
6. 次の動画に示すように、ホームページのバナーと CTA (Call-to-Action) のリダイレクトリンクを更新し、ナビゲーションメニューを再編成します。\
   <iframe src="https://www.youtube.com/embed/CDmUHl91THM" title="YouTube 動画プレーヤー" frameborder="0" className="w-full aspect-video rounded-xl" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowfullscreen />
7. **Next** をクリックして 3 番目のステップ "Schedule and goals" に移動し、エクスペリエンスのスケジュールとゴールを定義します。

## ステップ 3: スケジュールとゴール

1. **Send experience** セクションで **Active continuously** を選択し、このエクスペリエンスを開始および終了するタイミングを定義します。
   ![image-20240120-130725.png](/images/moengage_a17f57.png)
2. **Conversion goals** セクションで、要件に応じてコンバージョンゴールを定義します。
3. **Delivery controls** の **Experience Priority** ドロップダウンから優先度を選択します。詳細については、[Create Experience](/ja/user-guide/personalize/client-side-personalization/client-side-personalization/create-client-side-personalization-experience) を参照してください。
4. **Publish** をクリックします。

# まとめ

このユースケースでは、Personalize の In-session behavior ターゲティング機能を使用して、Web ページのレイアウトとコンテンツをパーソナライズしました。

Web ページにすでに存在する要素を更新するだけでなく、新しいウィジェットを追加したり、Web ページ上の既存の要素を非表示にしたり削除したりすることもできます。

閲覧行動やカスタムアクションに基づいて訪問者の現在のセッションをパーソナライズしたら、[Persoanlize Analytics](/ja/user-guide/personalize/client-side-personalization/client-side-personalization/experience-analytics) に移動して、エクスペリエンスのパフォーマンスを確認してください。

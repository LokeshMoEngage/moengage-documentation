# はじめに

ユーザーがさまざまな商品を閲覧し、レビューや価格を比較して、選んだ商品をカートに追加すると、マーケターはそのユーザーに購入意欲があると判断します。しかし、さまざまな理由でユーザーが商品を購入しないことがあります。ユーザーの注意がそれてしまったと想定し、購入を完了するよう促す必要があります。Facebook 広告は、こうしたユーザーをリターゲティングする効果的な方法です。

#### Facebook Audience を使用して顧客をリターゲティングするメリット

- **見込みの高いオーディエンスへのリーチ**: リターゲティングは、以前にウェブサイト、アプリ、または Facebook ページを利用したことのあるユーザーを対象とします。つまり、こうしたユーザーはすでにブランドを知っており、商品やサービスに関心を持っている可能性があります。
- **コンバージョン率の向上**: 見込み客に自社の商品やサービスを思い出させることで、リターゲティングは購入の完了や目的のアクションの実行を促すことができます。
- **ブランド想起の向上**: リターゲティングキャンペーンは、特に購入せずにウェブサイトを離れたユーザーの記憶にブランドを留めるのに役立ちます。
- **費用対効果の高い広告**: すでにブランドを知っている特定のオーディエンスをターゲットにすることで、一般的な広告よりも高い ROI と低い広告費用を実現できます。
- **パーソナライズされた広告エクスペリエンス**: リターゲティングでは、ユーザーが以前に閲覧した商品やサービスを表示するダイナミック広告を作成できるため、ユーザーエクスペリエンスが向上し、エンゲージメントが高まります。
- **モバイルファーストのアプローチ**: Facebook ユーザーの多くはモバイルデバイスからプラットフォームにアクセスするため、Facebook 広告はモバイルファーストのマーケティング戦略に適しています。

このユースケースでは、[Facebook Audience キャンペーンを作成](/ja/use-cases/facebook/retarget-customers-using-facebook#add-or-remove-users-from-facebook-audience)して、購入意欲の高いユーザーをリターゲティングします。

# 期待される結果

カートを放棄したユーザーは Facebook Audience に追加され、購入を完了すると削除されます。

<Tip>
  - ユーザーがカートに商品を追加するアクションと、プラットフォーム、検索した商品の ID、名前、価格などの関連情報を追跡するイベントが MoEngage で利用可能である必要があります。この例では、_Added to Cart_ イベントと _Payment Success_ イベントを使用します。イベントの追跡方法の詳細については、[Developer Guide](/ja/developer-guide/introduction) を参照してください。
  - カスタムオーディエンスが MoEngage で利用可能である必要があります。この例では、_Cart\_Abandonment\_Users\_For\_Fb_ とします。
  - Facebook Audiences が MoEngage と統合されている必要があります。手順の詳細については、[こちら](/ja/user-guide/campaigns-and-channels/facebook-audience/getting-started-with-facebook-audience/understanding-facebook-setup-for-custom-audience-integration)を参照してください。
</Tip>

# Facebook Audience にユーザーを追加または削除する

理想的には、ユーザーがカートに商品を追加したときにエンゲージメントジャーニーを開始し、ユーザーをアプリに呼び戻して購入を完了させる必要があります。

たとえば、ユーザーが 7 日後もアプリに戻ってこない場合、次の選択肢は Facebook Audience を使用してユーザーをターゲットにすることです。

このユースケースは、次の手順で実現します。

- [ステップ 1: Facebook Audience にユーザーを追加する](/ja/use-cases/facebook/retarget-customers-using-facebook#step-1-add-users-to-the-facebook-audience)
- [ステップ 2: Facebook Audience からユーザーを削除する](/ja/use-cases/facebook/retarget-customers-using-facebook#step-2-remove-users-from-the-facebook-audience)

## ステップ 1: Facebook Audience にユーザーを追加する

このセクションでは、Facebook Audience キャンペーンにユーザーを追加します。

### ステップ 1.1: ターゲットユーザー

1. MoEngage ダッシュボードの左側のナビゲーションメニューで **Engage** をクリックし、**Campaigns** をクリックします。
2. All campaigns ページで **\+ Create campaign** をクリックします。
3. **Audience** で **Facebook** をクリックします。
   <img
     alt="fb1.png"
     src="/images/moengage_fb5a9f.png"
     style={{ width:"69%" }}
   />
   最初のステップ **Target users** に移動します。
4. キャンペーンの名前とタグを定義します。
5. **User qualification criteria** で **Based on a trigger event** をクリックします。これを選択すると、ユーザーが特定のイベントを実行したときにキャンペーンがトリガーされます。
6. **Select Trigger Condition** で、次のように、商品をカートに追加したものの購入していないユーザーを条件として定義し、遅延時間を 7 Days に設定します。 <img src="/images/moengage_e55823.png" alt="fb2.png" />
7. **Target users** で **All Users** をクリックします。
8. **Next** をクリックして 2 番目のステップ **Audience detail** に進み、オーディエンスを定義します。

### ステップ 1.2: オーディエンスの詳細

1. **Add or delete FB audience** で **Add users to FB audience** をクリックします。 <img src="/images/moengage_922043.png" alt="12.png" />
2. **Select/create custom audience** リストで、セグメント化されたユーザーを追加するオーディエンスを選択します。この例では、_Cart\_Abandonment\_Users\_For\_Fb_ を選択します。カスタムオーディエンスの作成の詳細については、[こちら](/ja/user-guide/campaigns-and-channels/facebook-audience/create/create-a-facebook-audience-campaign)を参照してください。\
   このリストには、Facebook Audience の設定ページで設定されたデフォルトの広告アカウント ID のオーディエンスが表示されます。詳細については、[こちら](/ja/user-guide/campaigns-and-channels/facebook-audience/getting-started-with-facebook-audience/facebook-audience-settings-on-moengage-dashboard)を参照してください。
3. **Identifiers** セクションで、要件に基づいて識別子を選択します。Facebook は選択された識別子に基づいてユーザーを照合します。詳細については、[Match Identifiers](/ja/user-guide/campaigns-and-channels/facebook-audience/create/create-a-facebook-audience-campaign#step-2-audience-detail) を参照してください。
4. **Next** をクリックして 3 番目のステップ **Schedule and goals** に進み、キャンペーンのスケジュールと目標を定義します。

### ステップ 1.3: スケジュールと目標

1. **Send campaign** セクションで、キャンペーンの開始時期と終了時期を定義します。
2. **Conversion goals** セクションで、追跡するコンバージョン目標を追加します。詳細については、[Create Facebook Audience Campaign](/ja/user-guide/campaigns-and-channels/facebook-audience/create/create-a-facebook-audience-campaign) を参照してください。
3. **Publish** をクリックします。

これで、カートを放棄したユーザーが Facebook Audience に送られるようになります。

## ステップ 2: Facebook Audience からユーザーを削除する

商品を購入した後、ユーザーの購入意欲は一時的に低くなります。こうしたユーザーに有料広告を表示すると、余分なコストが発生します。そのため、これらのユーザーをオーディエンス _Cart\_Abandonment\_Users\_For\_Fb_ から削除する必要があります。このセクションでは、Facebook Audience キャンペーンからユーザーを削除します。

### ステップ 2.1: ターゲットユーザー

1. MoEngage ダッシュボードの左側のナビゲーションメニューで **Engage** をクリックし、**Campaigns** をクリックします。
2. All campaigns ページで **\+ Create campaign** をクリックします。
3. **Audience** で **Facebook** をクリックします。 <img src="/images/moengage_fb5a9f.png" alt="fb1.png" /> 最初のステップ **Target users** に移動します。
4. キャンペーンの名前とタグを定義します。
5. **User qualification criteria** で **Based on a trigger event** をクリックします。これを選択すると、ユーザーが特定のイベントを実行したときにキャンペーンがトリガーされます。
6. **Select Trigger Condition** で、次のように、商品を購入したユーザーを条件として定義し、遅延時間を 10 分に設定します。 <img src="/images/moengage_f338e8.png" alt="fb3.png" />
7. **Target users** で **All Users** をクリックします。
8. **Next** をクリックして 2 番目のステップ **Audience detail** に進み、オーディエンスを定義します。

### ステップ 2.2: オーディエンスの詳細

1. **Add or delete FB audience** で **Delete users from FB Audience** をクリックします。 <img src="/images/moengage_063266.png" alt="13.png" />
2. **Select/create custom audience** リストで、ユーザーを削除するオーディエンスを選択します。この例では、_Cart\_Abandonment\_Users\_For\_Fb_ を選択します。
3. **Identifiers** セクションで、要件に基づいて識別子を選択します。Facebook は選択された識別子に基づいてユーザーを照合します。詳細については、[Match Identifiers](/ja/user-guide/campaigns-and-channels/facebook-audience/create/create-a-facebook-audience-campaign#step-2-audience-detail) を参照してください。
4. **Next** をクリックして 3 番目のステップ **Schedule and goals** に進み、キャンペーンのスケジュールと目標を定義します。

### ステップ 2.3: スケジュールと目標

1. **Send campaign** セクションで、キャンペーンの開始時期と終了時期を定義します。
2. **Conversion goals** セクションで、追跡するコンバージョン目標を追加します。詳細については、[Create Facebook Audience Campaign](/ja/user-guide/campaigns-and-channels/facebook-audience/create/create-a-facebook-audience-campaign) を参照してください。
3. **Publish** をクリックします。

これで、商品を購入したユーザーは Facebook Audience から削除されます。

# まとめ

このユースケースでは、Facebook Audience を通じて購入意欲の高いユーザーをリターゲティングするキャンペーンを作成しました。これらのユーザーは、有料キャンペーンに反応して購入する可能性が高くなります。ユーザーが購入すると、ユーザーのプロファイルで _Payment Success_ イベントがトリガーされ、LTV が向上します。さらに、そのユーザーは Facebook Audience から削除されます。

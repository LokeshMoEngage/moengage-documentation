---
title: "Web アクティビティを分析する方法"
---

MoEngage Web SDK(Javascript API)を使用すると、ウェブサイト(デスクトップとモバイルの両方)におけるすべてのユーザーアクティビティをトラッキングできます。アプリとウェブサイトにおけるユーザーアクティビティを、一意のユーザープロファイルにシームレスにマッピングします。その結果、ウェブサイト上のユーザー行動を簡単に確認し、複数のチャネルで効果的にユーザーをターゲティングできます。

イベントとユーザー属性のトラッキングの詳細については、[ウェブサイトイベントをトラッキングする](/ja/developer-guide/web-sdk/data-tracking/web-sdk-events-tracking)および[Web ユーザー属性をトラッキングする](/ja/developer-guide/web-sdk/data-tracking/web-sdk-user-attributes-tracking)を参照してください。

## 前提条件

Web インテグレーションから最適なデータを得るために、技術チームは次の点を確認する必要があります。

1. モバイル SDK(Android および iOS)をすでにインテグレーションしている場合は、アプリと Web のトラッキングで同じユーザー属性名とイベント名を使用してください。
2. ユーザーを一意に識別する識別子がある場合は、[こちらの説明](/ja/developer-guide/web-sdk/data-tracking/web-sdk-user-attributes-tracking)に従ってこのユーザー属性をトラッキングしてください。これにより、すべてのプラットフォームでこの識別子に基づいてユーザーをマージできるようになります。

## ダッシュボードでユーザーアクティビティを確認するには?

このインテグレーションが完了すると、Recent Events ページでユーザーアクティビティを確認できるようになります。

1. MoEngage ダッシュボードのサイドバーで *Test & Debug* セクションに移動し、Recent Events をクリックします。
2. ウェブサイトでトラッキングしたイベントに対してセグメンテーションクエリを実行できます。

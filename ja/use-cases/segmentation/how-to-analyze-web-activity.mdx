---
title: "Web アクティビティを分析する方法"
---

MoEngage Web SDK(Javascript API)を使用すると、ウェブサイト(デスクトップとモバイルの両方)におけるすべてのユーザーアクティビティをトラッキングできます。アプリとウェブサイトにおけるユーザーアクティビティを、一意のユーザープロファイルにシームレスにマッピングします。その結果、ウェブサイト上のユーザー行動を簡単に確認し、複数のチャネルで効果的にユーザーをターゲティングできます。

イベントとユーザープロパティのトラッキングの詳細については、[ウェブサイトイベントをトラッキングする](/ja/developer-guide/web-sdk/data-tracking/web-sdk-events-tracking)および[Web ユーザープロパティをトラッキングする](/ja/developer-guide/web-sdk/data-tracking/web-sdk-user-attributes-tracking)を参照してください。

## 前提条件

Web インテグレーションから最適なデータを得るために、技術チームは次の点を確認する必要があります。

1. モバイル SDK(Android および iOS)をすでにインテグレーションしている場合は、アプリと Web のトラッキングで同じユーザープロパティ名とイベント名を使用してください。
2. ユーザーを一意に識別する識別子がある場合は、[こちらの説明](/ja/developer-guide/web-sdk/data-tracking/web-sdk-user-attributes-tracking)に従ってこのユーザープロパティをトラッキングしてください。これにより、すべてのプラットフォームでこの識別子に基づいてユーザーをマージできるようになります。

## ダッシュボードでユーザーアクティビティを確認するには?

このインテグレーションが完了すると、ユーザープロファイルやセグメンテーションクエリでユーザーアクティビティを確認できます。

1. MoEngage ダッシュボードで **Segment** \> **Search Users** に移動してユーザーを検索し、その[ユーザープロファイル](/ja/user-guide/data/user-data/user-profile)を開いて、そのユーザーについてトラッキングされたイベントを確認します。
2. ユーザー全体のアクティビティを分析するには、**Segment** \> **Create Segment** に移動し、ウェブサイトでトラッキングしたイベントに対してセグメンテーションクエリを実行します。
3. 結果を Web ユーザーに絞り込むには、イベントプロパティ **Platform** is **WEB** を追加します。

ウェブサイトから送信されたイベントは、1〜2 分以内にユーザーのプロファイルに表示されます。

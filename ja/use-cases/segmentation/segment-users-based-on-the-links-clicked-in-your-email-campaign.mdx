# はじめに

マーケターとして、私たちはメールキャンペーンを送信した後、ユーザーがどのリンクをクリックしているかを知りたいと考えています。メールキャンペーンでクリックされたリンクに基づいてユーザーをセグメント化することで、ターゲットオーディエンスの関心に基づいたパーソナライズされたコミュニケーションを送信し、それに応じてエンゲージできます。

#### メールキャンペーンでクリックされたリンクに基づいてユーザーをセグメント化するメリット

- **パーソナライズされたフォローアップ**: ユーザーがどのリンクをクリックしたかを把握することで、その後のメールを特定の関心やニーズに合わせて調整でき、より関連性が高く魅力的なものにできます。
- **エンゲージメントの向上**: オーディエンスに響くものを知ることで、よりターゲットを絞ったコンテンツやオファーを作成でき、開封率、クリック率、全体的なエンゲージメントの向上につながります。
- **コンバージョン率の向上**: ユーザー行動に基づいてパーソナライズされたメールは、特定のニーズや関心に対応しているため、ユーザーがオファーを受け入れやすくなり、コンバージョンにつながる可能性が高くなります。
- **顧客理解の深化**: リンクのクリックをトラッキングすることで、ユーザーの行動や好みに関する貴重なインサイトが得られ、マーケティング戦略を改善し、より効果的なキャンペーンを作成できます。
- **より適切なリソース配分**: リンクのクリックに基づいてセグメント化することで、最もエンゲージしているユーザーにマーケティング活動を集中でき、ROI を最大化し、適切なメッセージで適切な人に確実にリーチできます。

このユースケースは、顧客満足度調査を通じてフィードバックを求めるメールキャンペーンで、ユーザーがクリックしたリンクに基づいてユーザーをセグメント化することで実現します。この調査では、ユーザーには次の選択肢があります。

- **Good** または **OK:** この選択肢を選んだユーザーには、感謝の気持ちを伝え、購入履歴に基づいて次の購入をおすすめするメールが送信されます。
- **Bad**: この選択肢を選んだユーザーには、IVR またはサポートチームがアプローチし、フィードバックの理由を調査します。

# ユーザーの回答に基づいてセグメントを作成する

1. MoEngage ダッシュボードの左側のナビゲーションメニューで **Segments** をクリックし、**Create segment** をクリックします。セグメントの作成の詳細については、[こちら](/ja/user-guide/segment/create-segments/rule-based-filter-segments)を参照してください。
   <img
     alt="att_1_for_4061496363.png"
     src="/images/moengage_52790e.png"
     style={{ width:"40%" }}
   />
2. Create segment ページで **Filter users by** オプションをクリックし、**User behavior** タブをクリックします。
3. ユーザーをセグメント化するには、メールをクリックしたユーザーを選択します。次の画像は、メールをクリックしたユーザーをトラッキングするためのサンプルセグメントを示しています。
   ![att\_4\_for\_4061496363.png](/images/moengage_854f00.png)
   1. _Email Clicked_ イベントは、ユーザーがメールをクリックしたときに取得されます。
   2. _Campaign Name_ は、クリックの発生元を識別する一意の識別子です。
   3. _link_ により、正確にどの選択肢がクリックされたかがわかります。
   4. **\+ Actions list** で、これまでの分類を使用してキャンペーンまたはカスタムセグメントを作成できます。

# ユーザーがクリックしたリンクを取得する

1. MoEngage ダッシュボードの左側のナビゲーションメニューで **Engage** をクリックし、**Campaigns** を選択します。
2. All campaigns ページで、一覧表示されているメールキャンペーンのいずれかをクリックします。
3. Campaign analytics and info ページで **Click analysis** タブを選択すると、メールキャンペーンからユーザーがクリックしたリンクをトラッキングできます。 <img alt="att_6_for_4061496363.png" src="/images/moengage_465b61.png" />

# まとめ

このユースケースでは、顧客満足度調査を通じてフィードバックを求めるメールキャンペーンで、ユーザーがクリックしたリンクに基づいてユーザーをセグメント化する方法を学びました。

作成したセグメントは、キャンペーンの作成や分析にも使用できます。これらのセグメントを使用することで、ユーザーの関心を理解し、クリックを分析して、それに応じた製品やサービスをおすすめできます。

# はじめに

アップセルとは、見込み客に対して、より高価値のコースパッケージや、選択したコースに組み込まれる追加サービスを販売する戦略です。これにより、学生は補足的なリソースを利用でき、全体としてより質の高い教育体験を得られるため、資格の取得を完了するよう促されます。一方、クロスセルでは、学生が最初に選んだコースを補完する可能性のある追加コースを提案します。たとえば、経営管理を学んだ学生は、リーダーシップやマネジメントのコースに興味を持つかもしれません。

この記事では、MoEngage のレコメンデーションを使用して、学生にコースや学習教材をアップセルまたはクロスセルする方法について説明します。

# 期待される結果

ユーザーの興味に合った新しいコースや別のコースをタイムリーに働きかけることで、ユーザーの注意を引き、コースや記事を閲覧してもらうことができます。ユーザーはより多くのコンテンツを閲覧して新しいコースについて学び、間接的に購入の可能性が高まります。

<Tip>
  - アプリのオンボーディング段階で、ユーザーにカテゴリーを選択してもらう際に、ユーザーのカテゴリーを取得する必要があります。値は CTA で取得し、ユーザー属性 Category に渡すことができます。
  - ユーザーのアクションを追跡するためのイベントが必要です。イベントの追跡方法については、[Developer Guide](/ja/developer-guide/introduction) を参照してください。
  - 追跡したこれらのイベントを、該当する MoEngage イベントにマッピングする必要があります。カスタムイベントを MoEngage イベントにマッピングする方法については、[Map User Actions Settings](/ja/user-guide/content/recommendations/getting-started/map-user-actions-settings) を参照してください。
  - Push、Email、SMS、WhatsApp などの 1 つ以上のチャネルの設定が必要です。
</Tip>

# カタログの作成

次のいずれかのレコメンデーションを使用できます。

- Basic: コースごとに特定のレコメンデーションのセットがあり、それらのコースを推進したい場合は、Basic Recommendations を使用することをお勧めします。各カテゴリーまたは商品に対応する列にレコメンデーションを追加できます。カタログは次のようになります。<img src="/images/moengage_bc2bc6.png" alt="2a.png" />
- AI: AI Recommendations を使用する場合は、次のカタログが便利です。さらに、カテゴリーに基づいて結果を絞り込むこともできます。<img src="/images/moengage_156a96.png" alt="2b.png" />

# レコメンデーションの作成

このセクションでは、レコメンデーションを作成します。

<Tabs>
  <Tab title="Basic Recommendation">
    1. MoEngage ダッシュボードに移動し、左側のナビゲーションから **Content** \> **Recommendations** を選択します。Recommendations ページが表示されます。詳細については、[Creating User Action Recommendations](/ja/user-guide/content/recommendations/basic-recommendations/user-actions-model) を参照してください。
    2. 右上隅にある **\+ Create recommendation** をクリックします。最初のステップ「Select recommendation model」に移動します。<img src="/images/moengage_25fb9f.png" alt="image-20231126-104436.png" />
    3. **Item attributes** モデルを選択し、**Next** をクリックします。2 番目のステップ「Create recommendation」に移動します。次の詳細を入力します。
       1. **Recommendation name**: レコメンデーションの名前を入力します。
       2. **Recommendation description**: レコメンデーションの説明を入力します。この説明は、モデルの目的を理解するのに役立ちます。
       3. **Catalog**: レコメンデーションの対象となるカタログを選択します。
    4. Item Attributes 内のモデルは次のようになります。<img src="/images/moengage_86a2f3.png" alt="2c.png" />
    5. 商品名を使用している場合は、Category で絞り込むことができます。
    6. **Create** をクリックして変更を保存し、モデルを実行します。Recommendations ホームページでのステータスは Active になります。
  </Tab>
  <Tab title="AI Recommendation">
    1. MoEngage ダッシュボードに移動し、左側のナビゲーションから **Content** \> **Recommendations** を選択します。Recommendations ページが表示されます。詳細については、[Creating User Action Recommendations](/ja/user-guide/content/recommendations/basic-recommendations/user-actions-model) を参照してください。
    2. 右上隅にある **\+ Create recommendation** をクリックします。最初のステップ「Select recommendation model」に移動します。<img src="/images/moengage_25fb9f.png" alt="image-20231126-104436.png" />
    3. **Similar items** モデルを選択し、**Next** をクリックします。2 番目のステップ「Create recommendation」に移動します。次の詳細を入力します。
       1. **Recommendation name**: レコメンデーションの名前を入力します。
       2. **Recommendation description**: レコメンデーションの説明を入力します。この説明は、モデルの目的を理解するのに役立ちます。
       3. **Catalog**: レコメンデーションの対象となるカタログを選択します。
    4. モデルは次のようになります。<img src="/images/moengage_421c4f.png" alt="2d.png" /> ここでは、Product\_id がカテゴリーです。絞り込みの際、値 category には CAT、UPSE などが含まれることに注意してください。これは User Attributes: Category (またはクライアントが使用したいその他のユーザー属性) と比較されます。これにより、そのカテゴリーの AI レコメンデーションが得られます。
    5. **Create** をクリックして変更を保存し、モデルを実行します。Recommendations ホームページでのステータスは Active になります。
  </Tab>
</Tabs>

レコメンデーションが作成されたので、Push キャンペーンを作成し、Recommendations を使用してパーソナライズしましょう。

# Push キャンペーンの作成

このセクションでは、キャンペーンを作成します。

## ステップ 1: ユーザーのターゲティング

1. 左側のサイドバーに移動し、**Engage** \> **Campaigns** をクリックして **\+ Create campaign** をクリックするか、**\+ Create new** \> **Campaign** をクリックします。
2. **Outbound** の下で **Push** \> **Periodic** を選択します。<img src="/images/moengage_0a11ca.png" alt="5.png" /> \
   キャンペーンを定義する最初のステップ「Target users」に移動します。
3. 次の詳細を入力します。
   - **Team**: 組織のアカウントで Teams が有効になっている場合は、チームを選択します。
   - **Campaign name**: キャンペーンの名前を入力します。
   - **Campaign tags**: 必要なキャンペーンタグを選択します。
4. **Target Audience** セクションで **All users** を選択します。<img src="/images/moengage_23fb55.png" alt="7.png" />
5. **Target Platforms** セクションで **Android** を選択します。<img src="/images/moengage_deb060.png" alt="8.png" />
6. **Next** をクリックして 2 番目のステップ「Content」に移動し、Push キャンペーンのコンテンツを定義します。

## ステップ 2: コンテンツ

1. 使用するテンプレートを選択します。この例では、**Basic notification** を選択します。<img src="/images/moengage_67a866.png" alt="9.png" />
2. **Message title** フィールドにタイトルを入力します。
3. メッセージを定義する際に、[定義した](/ja/use-cases/recommendations/how-to-nudge-users-to-continue-watching-content)レコメンデーションによって生成された商品セットを選択します。「@」と入力し、Push Personalization ポップアップで、作成したレコメンデーションの名前である「DemoRecommendations」を検索します。<img src="/images/moengage_2cef7d.png" alt="Image 15-10-24 at 10.17 AM.jpeg" /> <img src="/images/moengage_71c4d1.png" alt="Image 15-10-24 at 10.18 AM.jpeg" /> \
   レコメンデーションを使用すると、キャンペーンのタイトル、本文、ランディングページをパーソナライズできます。たとえば、クライアントが 3 種類のコミュニケーションを希望する場合、それぞれに異なるレコメンデーションを含む 3 種類のコミュニケーションを用意できます。同じ順序で Email を組み込むこともできます。<img src="/images/moengage_486997.png" alt="Image 15-10-24 at 10.20 AM.jpeg" /> \
   行 1 は Choice 1 のレコメンデーション、行 2 は Choice 2 のレコメンデーション、行 3 は Choice 3 のレコメンデーションです。これらは、商品またはカテゴリーに基づくレコメンデーションです。
4. **Next** をクリックして 3 番目のステップ「Schedule and goals」に移動し、キャンペーンのスケジュールと目標を定義します。

## ステップ 3: スケジュールと目標

1. **Send campaign** セクションで、キャンペーンをユーザーに配信するタイミングと配信の周期を選択します。
2. 要件に基づいて配信設定を変更します。これらの設定の詳細については、[Create Push Campaigns](/ja/user-guide/campaigns-and-channels/mobile-push/create/create-push-campaigns) を参照してください。<img src="/images/moengage_08e58e.png" alt="13.png" />
3. **Publish** をクリックします。

# まとめ

この記事では、MoEngage のレコメンデーションを使用して、学生にコースや学習教材をアップセルまたはクロスセルする方法を説明しました。

レコメンデーションは、アプリの利用を増やし改善するための鍵です。これらのアウトバウンドのレコメンデーションは、ユーザーに働きかけるだけでなく、適切なタイミングで送信することで、さらに多くのレコメンデーションやコースを試すようユーザーを誘うこともできます。

# はじめに

時代とともに、パーソナライゼーションはあらゆるコミュニケーションの鍵となりつつあります。マーケターは、ユーザーの次回の購入につながるきっかけを残したいと考えています。

たとえば、注文が確定したときに、マーケターは注文確認メールとともに、トレンド商品やおすすめ商品のリストを送信し、顧客が商品を閲覧できるようにしたいと考えるでしょう。

この記事では、レコメンデーションとパーソナライズされた発送キャンペーンを作成し、アプリでさらに多くの商品を視聴・閲覧するようユーザーにナッジまたは促します。

# 期待される結果

これらのキャンペーンには、基本的に 2 つの成果があります。

- 注文確認
- さらに商品を閲覧してもらうためのパーソナライズされたレコメンデーション

# S2S イベントを作成する

このイベントは、Shiprocket や Delhivery などの配送パートナーによって、商品が発送されたことを示すためにトリガーされるのが理想的です。配送パートナーは Event API を使用し、ペイロードの属性には次の情報を含めることができます。

- Order ID
- Order Value

# レコメンデーションを作成する

このセクションでは、ユーザーのアクションに基づいてレコメンデーションを作成します。ここでは、商品カタログと 2 つの商品セットが必要です。

1. MoEngage ダッシュボードに移動し、左側のナビゲーションから **Content** \> **Recommendations** を選択します。Recommendations ページが表示されます。詳細については、[Creating User Action Recommendations](/ja/user-guide/content/recommendations/basic-recommendations/user-actions-model) を参照してください。
2. 右上の **+ Create recommendation** をクリックします。最初のステップ "Select recommendation model" に移動します。  
    <img alt="image-20231126-104436.png" src="/images/moengage_b6f7e6.png" />
3. **Recommended items** モデルを選択し、**Next** をクリックします。2 番目のステップ "Create recommendation" に移動します。次の詳細を入力します。
   1. **Recommendation name**: レコメンデーションの名前を入力します。
   2. **Recommendation description**: レコメンデーションの説明を入力します。この説明は、モデルの目的を理解するのに役立ちます。
   3. **Catalog**: レコメンデーションの対象となるカタログを選択します。  
       <img alt="48fe4806-4e89-4f8c-a740-19e198c82ffb.png" src="/images/moengage_a206f6.png" />
4. **Create** をクリックして変更を保存し、モデルを実行します。Recommendations のホームページでは、ステータスが Active になります。

レコメンデーションを作成したので、次に Push キャンペーンを作成してパーソナライズしましょう。

# Email キャンペーンを作成する

このセクションでは、Email キャンペーンを作成します。

## ステップ 1: ターゲットユーザー

1. 左側のサイドバーで **Engage** \> **Campaigns** をクリックして **+ Create campaign** をクリックするか、**+ Create new** \> **Campaign** をクリックします。
2. **Outbound** で、**Email** \> **Event Triggered** を選択します。  
    <img alt="13.png"  src="/images/moengage_ed88c4.png"  />   
   キャンペーン定義の最初のステップ "Target users" に移動します。
3. 次の詳細を入力します。
   - **Team**: 組織のアカウントでチームが有効になっている場合は、チームを選択します。詳細については、[Teams in MoEngage](/ja/user-guide/settings/account/team-management/teams-in-moengage) を参照してください。
   - **Campaign Name**: キャンペーンの名前を入力します。
   - **Campaign Content Type**: **Transactional** を選択します。
   - **User attribute with email address**: "Email (Standard)" を選択します。  
      <img alt="5.png" src="/images/moengage_280b67.png" />
4. **Select condition** セクションで、購入の詳細を含むイベントをトリガーとして選択します。
5. **Target Audience** セクションで **All users** を選択します。
6. **Next** をクリックして 2 番目のステップ "Content" に移動し、Email キャンペーンのコンテンツを定義します。

## ステップ 2: コンテンツ

1. 使用するテンプレートを選択します。この例では、**Drag and drop editor** タブで **Blank Template** を選択します。
2. **Subject** フィールドでは、**First Name** やその他のユーザー属性でパーソナライゼーションを追加できます。 **<img alt="84992d3c-10fa-4537-80e2-a4af1c4bf286.png"  src="/images/moengage_5630e0.png"  />**
3. さらにパーソナライズするために、Order ID と Order Value を強調表示するテキストボックスを追加できます。  
    <img alt="0c6340b1-5745-4ffd-96d7-0b95e24045ba.png" src="/images/moengage_d5d0cf.png" />
4. パーソナライゼーションを追加するには、rows に移動して商品セットを選択します。  
    <img alt="a01f43f3-be3a-4f25-9a5d-1beb6df6f580.png"  src="/images/moengage_372049.png"  />
5. 商品を表示するレイアウトを選択できます。以下のオプションから選択してください。  
    <img alt="7d8f6888-16fb-45a8-90d9-eab5d45e0183.png" src="/images/moengage_55af73.png" />
6. 作成が完了したら、以下のように、パーソナライズされた商品セットを Email キャンペーン内の任意の場所にドラッグ＆ドロップします。  
    <img alt="14e9f756-3a4f-4a04-8e3a-40ce5bde3123.png" src="/images/moengage_b55ba5.png" />
7. **Next** をクリックして 3 番目のステップ "Schedule and goals" に移動し、キャンペーンのスケジュールとゴールを定義します。

## ステップ 3: スケジュールとゴール

1. 要件に応じて、キャンペーンの開始日時と終了日時、およびコンバージョンゴールを定義します。
2. 要件に応じて配信設定を変更します。詳細については、[Create Email Campaigns](/ja/user-guide/campaigns-and-channels/email/create/create-an-email-campaign) を参照してください。
3. **Publish** をクリックします。

# まとめ

このユースケースでは、レコメンデーションとパーソナライズされた発送キャンペーンを作成し、アプリでさらに多くの商品を視聴・閲覧するようユーザーにナッジまたは促しました。

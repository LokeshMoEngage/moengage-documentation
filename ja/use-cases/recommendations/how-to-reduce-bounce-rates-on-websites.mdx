# はじめに

マーケターであれば、Web サイトにおける新規ユーザーの直帰率を下げる方法について考えたことがあるでしょう。その鍵はパーソナライゼーションにあります。個々のユーザーの具体的なニーズや好みに合わせて Web サイトをカスタマイズすることで、より魅力的で関連性の高いエクスペリエンスを提供できます。

ユーザーが特定のアクション（商品の閲覧、商品のカートへの追加）を行った後に Web サイトを訪れた場合、ホームページで関連する商品が見つからなければ、Web サイトから離脱する可能性が高くなります。

この記事では、MoEngage の Recommendation 機能と Web Personalization 機能を使用して、直帰率を下げ、ユーザーエンゲージメントを最大化します。

# 期待される結果

ユーザーには、レコメンドされた商品を含むパーソナライズされた Web ページが表示されます。

<Tip>
  - ユーザーが商品を検索する、商品をカートに追加する、商品をウィッシュリストに追加する、購入を完了するといったアクションと、プラットフォーム、商品名、カテゴリー、ブランド、価格など各アクションに関連する情報をトラッキングするイベント。イベントのトラッキング方法については、[Developer Guide](/ja/developer-guide/introduction) を参照してください。
  - 上記でトラッキングしたイベントと、対応する MoEngage イベントとのマッピング。この例では、商品をカートに追加する、または今すぐ購入するというカスタムイベントを "Added to Cart" に、購入完了というカスタムイベントを "Product Purchased" にマッピングします。カスタムイベントを MoEngage イベントにマッピングする方法については、[こちら](/ja/user-guide/content/recommendations/getting-started/map-user-actions-settings) を参照してください。
  - 利用可能な商品のリストと、タイトル、カテゴリー、ブランド、価格などの関連情報を含むカタログとそれに対応するフィード。最新の情報を維持できるよう、フィードを適切な間隔で更新するように設定してください。商品カタログとフィードの詳細については、[Catalogs](/ja/user-guide/content/recommendations/getting-started/catalogs) を参照してください。
  - パーソナライズされた Web エクスペリエンスを作成するための、MoEngage Web SDK と Web サイトとの統合。詳細については、[Integrate Web SDK](/ja/developer-guide/personalize-sdk/sdk-integration/web-personalization-v2) を参照してください。
  - ブラウザで広告ブロッカーが無効になっていること。広告ブロッカーが有効な場合、パーソナライゼーションエディターは読み込まれません。
</Tip>

# レコメンデーションを作成する

パーソナライズされたエクスペリエンスを作成する前に、ユーザーのアクションに基づいてレコメンデーションを作成します。

1. MoEngage ダッシュボードに移動し、左側のナビゲーションから **Content** \> **Recommendations** を選択します。Recommendations ページが表示されます。詳細については、[Creating User Action Recommendations](/ja/user-guide/content/recommendations/basic-recommendations/user-actions-model) を参照してください。
2. 右上の **\+ Create recommendation** をクリックします。最初のステップ "Select recommendation model" に移動します。
   ![2.png](/images/moengage_47ff3c.png)
3. **Predictive** で、**Recommended Items** カードをクリックします。これにより、ユーザーが最近カートに追加したアイテムの情報とユーザーの過去の購入情報を使用して、ユーザーがカートに追加したいと思うアイテムをレコメンドできます。
4. **Next** をクリックします。2 番目のステップ "Create recommendation" に移動します。次の詳細を入力します。
   - **Recommendation name**: レコメンデーションの名前を入力します。例: "DemoRecommendations"。この名前を使用して、このレコメンデーションモデルの出力を参照します。
   - **Recommendation description**: レコメンデーションの説明を入力します。この説明は、モデルの目的を理解するのに役立ちます。
   - **Catalog**: 提供しているすべての商品のリストと関連情報を含むカタログを選択します。
     ![Screenshot 2024-01-20 at 10.02.00 PM.png](/images/moengage_d79a45.png)
5. **Create** をクリックして変更を保存し、モデルを実行します。\
   これには 24 時間かかります。モデルのステータスは Recommendations のホームページで確認できます。
   ![image-20240120-163521.png](/images/moengage_b4abd9.png)
   Recommendation エンジンは、最も多くインタラクションされている商品のセットを共有します。

レコメンデーションを作成したので、次に購入しようとしているアイテムと一緒に購入できるアイテムについてユーザーにナッジする、パーソナライズされたエクスペリエンスを作成しましょう。

# パーソナライズされたエクスペリエンスを作成する

このセクションでは、Web サイトでユーザーに提供したいパーソナライズされたエクスペリエンスを作成します。

## ステップ 1: ターゲットユーザー

1. 左側のサイドバーで **Personalize** **\>** **All Experiences** をクリックして **\+ Experience** をクリックするか、**\+ Create new** \> **Experience** \> **Web** をクリックします。
   ![UC-88.png](/images/moengage_b97a20.png)
   パーソナライズされたエクスペリエンス定義の最初のステップ "Target users" に移動します。
2. 次の詳細を入力します。
   - **Experience name**: 作成するパーソナライゼーションの名前。例: "Reduce Bounce Rates in New users"。
   - **Experience Tags**: 今後作成する他のパーソナライズされたエクスペリエンスの中からこのエクスペリエンスを識別できるよう、タグを追加します。
     ![image-20240120-163732.png](/images/moengage_c92138.png)
3. **Target Audience** で、オーディエンスを定義します。目標は新規ユーザーの直帰率を下げることなので、新しいオーディエンスを作成しましょう。
4. **\+ Add Audience** をクリックしてから **\+ New Audience** をクリックし、ターゲットオーディエンスを定義します。
   ![image-20240120-114653.png](/images/moengage_381661.png)
5. Add new audience ポップアップが表示されます。**Audience name** フィールドに名前を入力します。例: "New Users"。
   ![image-20240120-164055.png](/images/moengage_9b489b.png)
6. **All users** を選択してから **\+ In-session attributes** をクリックします。
7. **User Type** に **New** を選択し、**Add** をクリックします。 <img alt="image-20240120-164121.png" src="/images/moengage_8de7a4.png" />
8. **Next** をクリックして 2 番目のステップ "Content" に移動し、キャンペーンのコンテンツを定義します。

## ステップ 2: コンテンツ

1. 最初のステップ "Target users" で **Next** をクリックすると、URL(s) to personalize ポップアップが表示されます。これを使用して、定義したパーソナライゼーションを Web サイトのどこに表示するかを定義できます。\
   ![image-20240120-115200.png](/images/moengage_c2c7eb.png)
2. 新規ユーザーはホームページにアクセスする可能性が高いため、**Single page** オプションを選択します。
3. **URL** フィールドに設定を行う URL を入力し、**Verify SDK setup** をクリックします。これにより、ページに SDK がインストールされているかどうかが確認されます。
   ![2.png](/images/moengage_617a97.png)
4. **Personalize URL** をクリックして、エディターで Web サイトを開きます。
   ![3.png](/images/moengage_8d32f2.png)
5. ユーザーの分割、つまりこのエクスペリエンスのパーソナライズされたビューを何人のユーザーに表示するかを定義するよう求められます。
6. 必要に応じて **\+ Variation** をクリックして複数のバリエーションを追加し、定義します。
   ![image-20240120-164528.png](/images/moengage_40a6b0.png)
7. 対象のバリエーションの **Personalize** をクリックすると、新しいタブのエディターで Web サイトが開きます。\
   **Note:** **Default** バリエーションを除くすべてのバリエーションのコンテンツをパーソナライズできます。 <img alt="image-20240120-164640.png" src="/images/moengage_73b383.png" />
8. 読み込まれたページ内の任意の要素を選択して編集します。これにより、名前の編集から新しい要素の追加まで、さまざまな変更を行うことができます。
9. 要素を選択すると、次のボタンが表示されます。
   ![Screenshot 2024-01-20 at 6.04.04 PM (1).png](/images/moengage_5be8c0.png)
   **Note:** このオプションはデフォルトのバリエーションを除くすべてのバリエーションで使用でき、各バリエーションのコンテンツをパーソナライズできます。
10. このケースでは、3 番目のオプションを選択します。Select widget ポップアップウィンドウが表示されます。
11. レコメンドされたアイテムを表示する **Product grid** を選択します。
    ![Screenshot 2024-01-20 at 10.17.27 PM.png](/images/moengage_f6400e.png)
12. グリッドを選択した要素の前に追加するか後に追加するかを定義する場所を選択するよう求められます。この例では "After" を選択します。
    ![image-20240120-164835.png](/images/moengage_bdcc2e.png)
13. **Next** をクリックします。Edit Item Grid ポップアップウィンドウが表示され、次の項目を定義できます。
    - グリッドの表示方法（デザイン要素、位置、レイアウト）。
    - グリッドに表示するすべてのプレースホルダー。
    - 対応するプレースホルダーへのマッピング情報。
      ![image-20240120-124122 (1).png](/images/moengage_be0e4e.png)
14. ステップ 1 "Grid Appearance" で、希望するレイアウトを選択し、ポップアップの右側にある該当オプションをクリックしてタイトル、サブタイトル、CTA を定義します。
    1. この例では、別のデザインを選択し、5 アイテムのリストにします。
    2. タイトルに "Most Viewed Items" と入力します。
    3. Grid CTA を削除します。
       ![image-20240120-165049.png](/images/moengage_ab6e61.png)
15. ステップ 2 "Edit Card" で、グリッド内の各カードの外観を定義します。
    1. この例では、Labels、Rating、Reviews、Subtitles を無効にします。
    2. CTA ボタンの名前を変更します。
       ![image-20240120-165230.png](/images/moengage_fb7788.png)
16. ステップ 3 "Map Information" で、上記の[生成したレコメンデーション](/ja/use-cases/recommendations/how-to-reduce-bounce-rates-on-websites#create-a-recommendation)を選択します。 <img alt="image-20240120-165407.png" src="/images/moengage_7a4074.png" />
17. ドロップダウンリストを使用して、生成されたレコメンデーションが持つ情報を対応する属性にマッピングします。 <img alt="image-20240120-165352.png" src="/images/moengage_713977.png" />
18. **Save** をクリックします。グリッドの配置やその他の編集内容を確認できます。追加した要素をクリックして、さらに変更を加えることができます。 <img alt="image-20240120-165641.png" src="/images/moengage_444ebd.png" />
19. これらの要素のいずれかを選択し、次の画像に示すアイコンを選択して、Click Tracking を追加します。 <img alt="Screenshot 2024-01-20 at 6.33.29 PM (1).png" src="/images/moengage_f17b12.png" /> この例では、セクション全体に追加します。これにより、この位置に表示されたレコメンデーションが離脱の減少に役立っているかどうかを把握できます。
20. すべての編集が完了したら、右上の **Save & exit** をクリックします。 <img alt="image-20240120-165841.png" src="/images/moengage_80fd1d.png" /> このタブが閉じ、MoEngage ダッシュボードの Experience 定義ページに戻ります。 <img alt="image-20240120-165909.png" src="/images/moengage_8a8a2b.png" />
21. **Next** をクリックして 3 番目のステップ "Schedule and goals" に移動し、エクスペリエンスのスケジュールとゴールを定義します。

## ステップ 3: スケジュールとゴール

1. **Send experience** セクションで **Active continuously** を選択し、このエクスペリエンスの開始日時と終了日時を定義します。
   ![image-20240120-130725.png](/images/moengage_257ed6.png)
2. **Conversion goals** セクションで、要件に応じてコンバージョンゴールを定義します。
3. **Delivery controls** で、**Experience Priority** ドロップダウンから優先度を選択します。詳細については、[Create Experience](/ja/user-guide/personalize/client-side-personalization/client-side-personalization/create-client-side-personalization-experience) を参照してください。
4. **Publish** をクリックします。

# まとめ

このユースケースでは、MoEngage の Recommendation 機能と Web Personalization 機能を使用して、直帰率を下げ、ユーザーエンゲージメントを最大化しました。

パーソナライズされたエクスペリエンスを公開したので、[分析セクション](/ja/user-guide/personalize/client-side-personalization/client-side-personalization/experience-analytics)に移動して、エクスペリエンスのパフォーマンスを確認しましょう。

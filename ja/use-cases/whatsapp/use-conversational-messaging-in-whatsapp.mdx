# はじめに

会話型メッセージングとは、顧客が好むチャネル上でのブランドと顧客の双方向コミュニケーションです。会話型マーケティングでは、すべてのやり取りを 1 つのスレッド内で行うため、摩擦が減り、顧客体験が向上します。WhatsApp の即時性により、企業は顧客と効果的にエンゲージできます。

#### WhatsApp で会話型メッセージングを使用するメリット

- **コストの削減**: Meta の料金は 24 時間枠内のカテゴリーごとに 1 回のみ発生するため、2 通目以降のメッセージには費用がかかりません。
- **信頼の向上**: 顧客がブランドと直接やり取りできると、そのブランドを信頼する可能性が高くなります。これにより、売上と顧客ロイヤルティの向上につながります。
- **カスタマーサービスの向上**: 双方向メッセージングにより、優れたカスタマーサービスを提供できます。顧客は質問や問題について迅速かつ簡単にサポートを受けられます。これにより、顧客満足度とロイヤルティの向上につながります。
- **ブランド認知度の向上**: 顧客がブランドと直接やり取りすると、そのブランドを認識する可能性が高くなります。これにより、売上とブランド認知度の向上につながります。
- **革新的なエンゲージメント戦略:** 会話型メッセージングは、革新的なエンゲージメント戦略の推進に活用できます。革新的な戦略には次のようなものがあります。
  - WhatsApp で顧客にクイズを出し、関連するオファーを提供する。
  - 顧客の好みを収集し、パーソナライズされたおすすめを提供する。
  - 価格を直接提示する代わりに、**Reveal special price** などのボタンを提供して好奇心を刺激する。

## WhatsApp 会話型メッセージングのユースケース

WhatsApp 会話型メッセージングのユースケースには次のようなものがあります。

| 業界 | ユースケース |
| --- | --- |
| ヘルスケア | 予約の確認、顧客フィードバック、よくある質問への回答 |
| 小売・Eコマース | 製品のおすすめ、在庫に関する問い合わせ、配送状況の更新、顧客フィードバック |
| 銀行・金融・保険 | よくある質問への回答、顧客フィードバック、予約の確認 |
| エンターテインメント・メディア | イベント参加の確認、イベントリマインダーの送信 |
| 教育 | 予約の確認、コース情報の更新、クイズによるスキルテスト |

この記事では、会話型メッセージングを通じてユーザーに健康保険プランの選択を促す WhatsApp キャンペーンを作成します。

このユースケースは、次の 2 つのステップで実現します。

- [WhatsApp キャンペーンを作成する](#step-1-create-a-whatsapp-campaign)
- [作成した WhatsApp キャンペーン用の Flow を設定する](#step-2-create-a-flow)

# ステップ 1: WhatsApp キャンペーンを作成する

このセクションでは、WhatsApp キャンペーンを作成する手順について説明します。詳細については、[WhatsApp キャンペーンを作成する](/ja/user-guide/campaigns-and-channels/whatsapp/create/create-a-whatsapp-campaign)を参照してください。

## ステップ 1.1: ターゲットユーザー

1. MoEngage ダッシュボードに移動し、左側のナビゲーションから **Engage** \> **Campaigns** を選択します。**All campaigns** ページが表示されます。
2. 右上隅にある **\+ Create campaign** をクリックします。
3. **Messaging Apps** で **WhatsApp** をクリックし、**Event Triggered** をクリックします。
4. **Campaign name** を追加します。
5. 必要なオーディエンスを選択します。このユースケースでは、保険プランに加入していないユーザーを必要なオーディエンスとして選択できます。\
   詳細については、[WhatsApp キャンペーンを作成する](/ja/user-guide/campaigns-and-channels/whatsapp/create/create-a-whatsapp-campaign)の[ステップ 1: ターゲットユーザー](/ja/user-guide/campaigns-and-channels/whatsapp/create/create-a-whatsapp-campaign)にある **Select Audience** セクションを参照してください。
6. イベントトリガー型キャンペーンの場合は、必要なトリガー条件を選択します。詳細については、[WhatsApp キャンペーンを作成する](/ja/user-guide/campaigns-and-channels/whatsapp/create/create-a-whatsapp-campaign)の[ステップ 1: ターゲットユーザー](/ja/user-guide/campaigns-and-channels/whatsapp/create/create-a-whatsapp-campaign)にある **Event Triggered Campaigns** セクションを参照してください。

## ステップ 1.2: コンテンツ

1. 必要な送信者を選択します。
2. クイックリプライを含む必要なテンプレートを選択します。
3. 保険プランの選択を促すユーザーの名前や場所などの顧客属性やイベント属性を使用して、メッセージ本文をパーソナライズします。\
   詳細については、[WhatsApp キャンペーンを作成する](/ja/user-guide/campaigns-and-channels/whatsapp/create/create-a-whatsapp-campaign)の[ステップ 2: コンテンツ](/ja/user-guide/campaigns-and-channels/whatsapp/create/create-a-whatsapp-campaign)を参照してください。

## ステップ 1.3: スケジュールと目標

1. 次の項目を選択します。
   - イベントトリガー型キャンペーンの期間
   - 1 回限りまたは定期キャンペーンの公開日時
2. コンバージョンをトラッキングするためのコンバージョン目標を追加します(必要な場合)。\
   詳細については、[WhatsApp キャンペーンを作成する](/ja/user-guide/campaigns-and-channels/whatsapp/create/create-a-whatsapp-campaign)の[ステップ 3: スケジュールと目標](/ja/user-guide/campaigns-and-channels/whatsapp/create/create-a-whatsapp-campaign)を参照してください。
3. **Publish** をクリックします。キャンペーン ID が生成されます。

# ステップ 2: Flow を作成する

このセクションでは、対応する Flow を設定する手順について説明します。詳細については、[Flow を作成する](/ja/user-guide/flows-cross-channel-messaging/create/create-flows/create-a-flow)を参照してください。

## ステップ 2.1: Flow を定義する

次の Flow の詳細を定義します。

1. MoEngage ダッシュボードに移動し、左側のナビゲーションから **Engage** \> **Flows** を選択します。Flows ページが表示されます。
2. 右上隅にある **\+ Create Flow** をクリックします。
3. 次の **Create new flow** ページで、利用可能な Flow テンプレートを使用するか、**\+ Start with a blank canvas** を使用して Flow を作成できます。
4. **Flow name** を入力し、**Next** をクリックします。
5. **When will users enter the flow** セクションで **On event trigger** をクリックし、トリガー条件として **WhatsApp Message clicked** を選択します。
6. **\+ Attribute** をクリックし、前のセクションで作成した [WhatsApp キャンペーン](#step-1-create-a-whatsapp-campaign)を公開したときに生成されたキャンペーン ID を選択します。
7. 要件に応じて Flow をスケジュールし、**Next** をクリックします。
8. **Who will enter the flow** セクションで、この Flow に参加する必要なオーディエンスを選択し、**Next** をクリックします。

## ステップ 2.2: Flow のトリガーを設定する

Flow のトリガーを設定するには、次の手順を実行します。

1. **\+** をクリックします。
   ![conditional flow.png](/images/moengage_42052e.png)
2. **Conditions** で、エントリー条件として **Conditional Split** を追加します。
3. クイックリプライボタンごとにブランチを追加します。このユースケースでは、_Term Insurance_ と _Health Insurance_ の 2 つのクイックリプライボタンを作成できます。
   1. **Conditional Split** にマウスを合わせ、編集アイコンをクリックします。
      ![edit conditional split.png](/images/moengage_03855c.png)
   2. **Evaluate the following conditions** ドロップダウンリストで、**in the past** と必要な期間を選択します。
   3. **Condition is satisfied if the user** で、次の詳細を入力します。
      1. **Display name** フィールドに、ブランチまたはパスの名前を入力します。このユースケースでは、_Term Insurance_ と入力します。
      2. **User Behavior** で、**Has Executed** に **WhatsApp Message Clicked** を選択します。
      3. ボタンを _WhatsApp Message Clicked_ イベントにマッピングするための属性を追加します。
         1. **\+ Attribute** をクリックします。
         2. **Select attribute** ドロップダウンリストで、**b\_id** を選択します。
         3. **contains** を選択します。
         4. **Select Option** ドロップダウンリストで、ボタン名を選択します。この場合は _Term Insurance_ です。
            ![b\_id.png](/images/moengage_ab5135.png)
   4. **\+** アイコンを使用して、条件分岐ステージの一部としてブランチをさらに追加します。このユースケースでは、別のブランチとして _Health_ _Insurance_ を追加します。
   5. **Done** をクリックします。\
      次の画像は、2 つのクイックリプライボタン(Term Insurance と Health Insurance)のブランチを追加した状態を示しています。
      ![branches for quick reply.png](/images/moengage_3925af.png)
4. 必要なブランチのパス上にある **\+** をクリックします。
5. **Actions** で **WhatsApp** をクリックします。
   ![quick reply WA.png](/images/moengage_0282d2.png)
6. WhatsApp にマウスを合わせ、**Edit** アイコンをクリックして WhatsApp メッセージを設定します。
   ![configure WA message.png](/images/moengage_9d4230.png)
7. 各ブランチに、後続の WhatsApp メッセージを追加できます(必要な場合)。
   1. 必要な WhatsApp メッセージのパス上にある **\+** をクリックします。
   2. **Actions** で **WhatsApp** をクリックします。
      ![WA sub WA.png](/images/moengage_815d10.png)
   3. WhatsApp にマウスを合わせ、**Edit** アイコンをクリックして WhatsApp メッセージを設定します。
8. 各ブランチの各ステージで、クイックリプライボタン用のサブブランチを追加できます(必要な場合)。たとえば、ユーザーが T**erm Insurance** ボタンをクリックしたときに、2 つのクイックリプライボタンを表示できます。
   1. 1. 必要な WhatsApp メッセージのパス上にある \+ をクリックします。
      2. **Conditions** で **Conditional Split** をクリックします。
      3. **Conditional Split** にマウスを合わせ、**Edit** アイコンをクリックします。
      4. **Evaluate the following conditions** ドロップダウンリストで、**Since exiting the last node** と必要な期間を選択します。\
         **注:** 2 番目以降の条件では、**Evaluate the following conditions** ドロップダウンリストで **Since exiting the last node** を選択する必要があります。
      5. **Condition is satisfied if the user** で、必要な詳細を入力します。
      6. \+ アイコンを使用して、条件分岐ステージの一部としてブランチをさらに追加します。
      7. **Evaluate the following conditions** で定義した開始時刻から設定した期間内に条件が満たされる場合は、**Keep evaluating for the next** チェックボックスを有効にして期間を選択します。
      8. **Done** をクリックします。
         ![WA conditional WA.png](/images/moengage_01d7d7.png)

## ステップ 2.3: Flow を公開する

1. **Settings** をクリックします。
2. コンバージョンをトラッキングするためのコンバージョン目標を追加します(必要な場合)。
3. **Publish** をクリックします。

# まとめ

このユースケースでは、WhatsApp キャンペーンを作成し、その WhatsApp キャンペーン用の Flow を設定して、会話型メッセージングを通じてユーザーに健康保険プランの選択を促しました。

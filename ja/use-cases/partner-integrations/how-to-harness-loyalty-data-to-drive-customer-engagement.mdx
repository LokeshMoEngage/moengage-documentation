# はじめに

ロイヤルティデータは、企業が顧客エンゲージメントを引き出し、ビジネスの成長を促進するうえで非常に重要です。ロイヤルティデータからは、顧客の好み、行動、購入履歴に関する貴重なインサイトが得られます。顧客エンゲージメントの取り組みにロイヤルティデータを使用すると、次のような効果があります。

- **パーソナライズされたリワードプログラム**: エンゲージメントプラットフォームは、顧客の好み、行動、購入履歴について深いインサイトを持っています。これにより、ブランドはパーソナライズされたリワードプログラムを実施でき、顧客満足度とロイヤルティが向上します。
- **シームレスな顧客体験**: 連携により、すべてのタッチポイントでシームレスな顧客体験が実現します。顧客はエンゲージメントプラットフォームを通じてリワードにアクセスし、ロイヤルティポイントを確認し、リワードを交換できるため、一貫したブランド体験が保証されます。
- **ゲーミフィケーションとロイヤルティティア**: 連携により、ロイヤルティプログラムにゲーミフィケーションの要素を組み込むことができます。これには、顧客がより多くのロイヤルティポイントを獲得する動機となるプログレスバー、バッジ、チャレンジが含まれます。さらに、ブランドは段階的なロイヤルティレベルを導入でき、顧客はロイヤルティのランクを上がるにつれて限定特典やメリットを獲得できます。
- **ターゲティングされたマーケティングキャンペーン**: ブランドはロイヤルティ会員にパーソナライズされたオファー、プロモーション、通知を送信でき、エンゲージメントを高めてリピート購入を促進できます。
- **顧客フィードバックとアンケート**: ブランドはロイヤルカスタマーから貴重なフィードバックとインサイトを収集できます。アンケートへの回答、フィードバックの提供、市場調査への参加に対して顧客にインセンティブを提供することで、データに基づく意思決定と継続的な改善が可能になります。
- **オムニチャネルのカスタマージャーニー**: ブランドは複数のチャネルにわたって顧客データを統合できます。これにより、顧客はオンラインプラットフォーム、モバイルアプリ、店舗での購入、さらにはソーシャルメディアでのインタラクションを通じて、ロイヤルティポイントを獲得・交換できます。使用するプラットフォームにかかわらず、一貫したロイヤルティ体験が保証されます。

# ユースケース

ロイヤルティプログラムを顧客エンゲージメントプラットフォームと連携させることで、顧客維持率を高め、収益の成長を促進できる主なユースケースを次に示します。

- **ターゲットオーディエンスを絞り込む**ことで、プロモーションの効果とキャンペーンの反応率が高まり、最終的にエンゲージメントレベルが向上します。
- **パーソナライズされたマーケティングコンテンツ** (個別に最適化されたレコメンデーション、オファー、リワード) は、つながりの感覚を育み、顧客満足度を高め、エンゲージメントを向上させます。
- **強化されたロイヤルティプログラム**を使用すると、ブランドはギャップを特定し、リワード構造を改善し、新しいインセンティブを導入することで、ロイヤルティプログラムを進化・適応させ、顧客の関心とエンゲージメントを維持できます。

# ロイヤルティデータを MoEngage と連携する

このセクションでは、ロイヤルティデータを MoEngage と連携する方法について説明します。

## 掲載されているロイヤルティパートナー

MoEngage はすでに 12 社以上のロイヤルティパートナーと連携しています。[掲載されているパートナー](/ja/partner-guide/commerce-and-loyalty/loyalty/nector)のいずれかを使用している場合は、ガイドラインに従って MoEngage キャンペーンでロイヤルティデータの使用を開始できます。

## その他のロイヤルティプラットフォーム

お使いのロイヤルティプラットフォームが MoEngage に掲載されていない場合や、社内ツールを使用してロイヤルティデータを収集・管理している場合でも、MoEngage キャンペーンでロイヤルティデータを使用できます。こうしたツールの多くは、ロイヤルティコンテンツ (リワード、クーポン、バウチャー、ポイントなど) を取得するための API をサポートしています。MoEngage の Content APIs を使用して、これらのツールに接続できます。これらの API は、実行時にお使いのプラットフォームからロイヤルティデータを取得できます。Content APIs の詳細については、[こちら](/ja/user-guide/campaigns-and-channels/getting-started/campaign-content/content-apis)を参照してください。

## ロイヤルティツールを使用しない場合

ロイヤルティツールを使用していない場合でも、ロイヤルティデータを MoEngage に送信できます。

| ロイヤルティデータの保存場所 | 詳細 |
| --- | --- |
| CDP (Segment、mParticle、Adobe、Rudderstack など) | MoEngage は 5 つ以上の CDP との直接連携をサポートしています。これらの CDP に直接接続して、ユーザー属性またはイベントとして MoEngage にデータを送信できます。CDP 接続の設定の詳細については、[こちら](/ja/partner-guide/data-and-analytics/cdps/adobe-real-time-cdp/overview)を参照してください。 |
| データウェアハウス、データストレージ、社内データレイク (S3、SFTP、Snowflake など) | MoEngage は、多くのクラウドデータソースからの直接データインポートをサポートしています。CSV ファイル全体をユーザーまたはイベントとしてインポートできます。MoEngage とデータレイクの接続の詳細については、[こちら](/ja/partner-guide/data-and-analytics/data-warehouses/databricks)を参照してください。 |
| その他の社内ツール | ある程度の開発作業を行えば、これらの詳細を [MoEngage Data APIs](/ja/api/data/data-overview) に送信するスクリプトを作成できます。その後、ロイヤルティデータを直接使用して、セグメントを作成したり、パーソナライズされたキャンペーンを実行したりできます。 |
| Microsoft Excel または CSV ファイル | 連携性の高いツールを使用しておらず、直接的な API 接続の構築に手間をかけたくない場合は、シンプルな CSV ファイルとして MoEngage に[ロイヤルティデータをインポート](/ja/user-guide/data/imports/overview-imports)することもできます。 |

# まとめ

まとめると、ロイヤルティデータの活用は、顧客エンゲージメントを引き出したい企業にとって戦略的に不可欠です。これにより、顧客との関係を強化し、ロイヤルティを育み、リピート購入を促進して、最終的に持続可能なビジネスの成長を実現できます。MoEngage は、すべてのエンゲージメントとリターゲティングの取り組みでロイヤルティデータを使用するためのさまざまな方法をサポートしています。

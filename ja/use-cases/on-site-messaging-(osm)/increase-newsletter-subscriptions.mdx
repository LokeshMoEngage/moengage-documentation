# はじめに

ニュースレターによるエンゲージメントは、業界を問わずブランド認知度を高めるための一般的な手法です。多くのブランドが、エキサイティングな最新情報やオファーを伝えるために、購読者に定期的にニュースレターを送信しています。しかし、ユーザーにニュースレターを購読してもらうのは、多くの場合容易ではありません。

#### ニュースレターの購読数を増やすメリット

- **ロイヤルなオーディエンスとコミュニティの構築**: ニュースレターを使用するとオーディエンスと直接エンゲージでき、コミュニティ意識とロイヤルティを育むことができます。
- **リードの育成と獲得**: ニュースレターは、価値のあるコンテンツを提供し、ブランドや商品・サービスについて購読者に情報を伝えることで、リードを育成できます。また、リードを獲得して有料顧客に転換するためにも使用できます。
- **商品とサービスの宣伝**: ニュースレターは、商品、サービス、特別オファーを宣伝するための強力なツールであり、売上と収益の増加につながります。
- **オーディエンスの好みの理解**: ニュースレターの分析から、オーディエンスの好み、エンゲージメントレベル、コンテンツのパフォーマンスに関する貴重なインサイトを得られます。
- **関連性の維持**: 一貫したニュースレターの配信により、ブランドがオーディエンスの記憶に残り続けます。

このユースケースでは、[On-site Messaging (OSM) キャンペーンを作成](/ja/use-cases/on-site-messaging-(osm)/increase-newsletter-subscriptions#create-an-osm-campaign)して、ニュースレターの購読を促進します。アフィニティセグメントを使用して、スポーツセクションを読むユーザーをターゲットにします。ユーザーが次回の訪問時にページの 50% までスクロールすると、購読用のポップアップウィンドウが表示されます。

# OSM キャンペーンを作成する

このセクションでは、スポーツ愛好家が Web サイトにアクセスしてスポーツ関連の記事を 50% 読んだときに、購読を促す OSM キャンペーンを作成します。

## ステップ 1: ターゲットユーザー

1. MoEngage ダッシュボードの左側のナビゲーションメニューで **Engage** をクリックし、**Campaigns** をクリックします。
2. All campaigns ページで **\+ Create campaign** をクリックします。
3. **Inbound** で **On-site** をクリックします。
   ![Screenshot 2025-04-29 at 2.14.36 PM.png](/images/moengage_ede3aa.png)
   キャンペーン定義の最初のステップである **Target users** に移動します。
4. キャンペーンの名前とタグを定義します。
5. **Target Platforms** セクションで、アンケートを表示するプラットフォームを選択します。この例では、**Web** と **Mobile Web** を選択します。
   ![Screenshot 2025-01-27 at 11.30.23 AM.png](/images/moengage_718338.png)
6. ユーザーが Web サイトにアクセスしてページの 50% までスクロールしたときにポップアップを表示することが目的のため、**Trigger criteria** セクションで **On Page Load** をクリックします。
7. **Select trigger time** セクションで **After Scroll** をクリックし、**After page load wait until the user has scrolled by** の値を 50% に設定します。
   ![3.png](/images/moengage_d781d6.png)
8. **Select pages** セクションで **Specific pages** をクリックし、以下のように URL に _sports_ が含まれるように定義します。これにより、スポーツ関連のニュースにポップアップが表示されるようになります。
   ![4.png](/images/moengage_573e13.png)
9. **Target audience** セクションで、スポーツ愛好家を主にスポーツ関連のニュースを読むユーザーとして定義します。
   1. **Filter users by** オプションを選択し、**User affinity** タブをクリックします。詳細については、[Affinity Segments](/ja/user-guide/segment/create-segments/affinity-segments) を参照してください。
      ![5.png](/images/moengage_9202b8.png)
   2. **Has executed** リストから _News Read_ イベントを選択します。
   3. _Predominantly_ を選択し、このイベントの _URL_ 属性を使用して、以下のように定義します。
      ![6.png](/images/moengage_de7e23.png)
      上記のクエリでは、基本的に主にスポーツニュースを読むユーザーを見つけようとしています。これらのスポーツ愛好家が次回アプリを開き、スポーツ記事を 50% までスクロールしたときに表示されるポップアップを定義しています。
      ![7.png](/images/moengage_b30bb0.png)
10. **Next** をクリックして 2 番目のステップ **Content** に移動し、キャンペーンのコンテンツを定義します。

## ステップ 2: コンテンツ

1. **Search templates** フィールドに "Popup" と入力して、ポップアップテンプレートの一覧を表示します。
2. 目的のテンプレートにカーソルを合わせ、**Select Template** をクリックします。**Blank Popup Template** を選択して一から作成することもできます。
   ![2025-01-27\_11-56-41 (1).gif](/images/moengage_783e53.png)
3. 画面が読み込まれたら、要件に応じてテンプレートを編集できます。左側の **\+** アイコンをクリックして、キャンペーンに新しい要素を追加します。
   ![9.png](/images/moengage_6039cf.png)
4. キャンペーンにパーソナライズされた要素を追加できます。たとえば、一般的な言葉の代わりにユーザーの名前で挨拶できます。以下の GIF に示す手順に従ってください。詳細については、[Personalize](/ja/user-guide/personalize/overview/overview-personalize) を参照してください。
   ![2025-01-27\_12-00-54 (1).gif](/images/moengage_7c9bee.png)
5. **Next** をクリックして 3 番目のステップ **Schedule and goal** に移動し、キャンペーンのスケジュールとゴールを定義します。

## ステップ 3: スケジュールとゴール

1. **Send campaign** セクションで、OSM キャンペーンを開始および終了するタイミングを定義します。
   ![11.png](/images/moengage_e83fbf.png)
2. **Conversion Goals** セクションで、追跡したいコンバージョンゴールを追加します。
3. **Campaign priority** セクションで、このキャンペーンに優先度を割り当てます。たとえば、**Critical** を選択すると、ユーザーが対象となる他のキャンペーンがある場合でも、このキャンペーンが常に表示されるようになります。詳細については、[Create OSM Campaign](/ja/user-guide/campaigns-and-channels/on-site-message/create/create-osm-campaign) を参照してください。
4. **Global Delivery controls** セクションで **Ignore global minimum delay** トグルをオンにすると、設定で定義されている任意の 2 つのキャンペーン間の最小遅延をオーバーライドできます。
5. **Local Delivery controls** セクションで、要件に応じてコントロールを定義します。詳細については、[Create OSM Campaign](/ja/user-guide/campaigns-and-channels/on-site-message/create/create-osm-campaign) を参照してください。
   ![12.png](/images/moengage_856e62.png)
6. **Publish** をクリックします。

# まとめ

このユースケースでは、ニュースレターの購読を促進する OSM キャンペーンを作成しました。アフィニティセグメントを使用して、スポーツセクションを読むユーザーをターゲットにしました。これらのユーザーが次回の訪問時にページの 50% までスクロールすると、購読用のポップアップウィンドウが表示されます。

キャンペーンを公開したら、CTR とコンバージョン (定義している場合) を追跡して、パフォーマンスを把握できます。詳細については、[Analyze Onisite Messaging Campaigns](/ja/user-guide/campaigns-and-channels/on-site-message/analyze/analyze-on-site-messaging-campaigns) を参照してください。

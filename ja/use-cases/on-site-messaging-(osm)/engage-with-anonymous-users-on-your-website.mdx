# はじめに

特に e コマースでは、毎日何百人もの匿名ユーザーが Web サイトを訪れるため、マーケターがその正確な意図を把握するのは困難です。しかし、サイトへの再訪問や特定の商品の繰り返し閲覧といった特定の行動は、高い購買意欲を示している可能性があります。こうしたユーザーは関心が高いとみなし、関連性の高いコミュニケーションでのエンゲージメントを優先できます。

これらのユーザーは匿名 (アカウントを作成していない、または Web サイトにログインしていないユーザー) であるため、メールアドレスや電話番号がわからず、アウトバウンドのコミュニケーションは困難です。そのため、On-site Messaging (OSM) などのインバウンドのコミュニケーション戦略を使用して、これらのユーザーと効果的にエンゲージし、商品の購入を促す必要があります。

#### Web サイトの匿名ユーザーとエンゲージするメリット

- **未開拓の可能性をターゲットにする**: Web サイトの匿名ユーザーは、エンゲージメントの高い顧客になる可能性のある、大規模で多くの場合未開拓のオーディエンスです。匿名ユーザーを見過ごしてしまうマーケターもおり、その結果、関係を構築してエンゲージメントを高める機会を逃しています。
- **エンゲージメントの向上**: 匿名ユーザーと積極的にエンゲージするブランドは、エンゲージメントを大幅に高め、売上を増やすことができます。
- **コンバージョン率の向上**: 匿名ユーザー向けのパーソナライズされた体験とターゲティングされたメッセージは、コンバージョン率の向上につながります。
- **リテンションの強化**: 匿名ユーザーとの関係を構築することで、顧客生涯価値と長期的なリテンションを高めることができます。
- **マーケティング予算の有効活用**: 匿名ユーザーとのエンゲージメントに注力することで、マーケティング支出の効率を高め、より良い ROI を達成できる可能性があります。

このユースケースでは、[OSM キャンペーンを作成](/ja/use-cases/on-site-messaging-(osm)/engage-with-anonymous-users-on-your-website#create-an-osm-campaign)して、匿名ユーザーとエンゲージします。

# OSM キャンペーンを作成する

このセクションでは、OSM キャンペーンを作成します。

## ステップ 1: ターゲットユーザー

1. MoEngage ダッシュボードの左側のナビゲーションメニューで **Engage** をクリックし、**Campaigns** をクリックします。
2. All campaigns ページで **\+ Create campaign** をクリックします。
3. **Inbound** で **On-site** をクリックします。 <img src="/images/moengage_3f1631.png" alt="Screenshot 2025-04-29 at 2.14.36 PM.png" /> \
   キャンペーン定義の最初のステップである **Target users** に移動します。
4. キャンペーンの名前とタグを定義します。
5. **Target platforms** セクションで **Web** を選択します。 <img src="/images/moengage_bd0f13.png" alt="4.png" />
6. **Trigger criteria** セクションで **On Page Load** をクリックして、ユーザーが Web サイトにアクセスしたときにポップアップを表示します。
7. **Select trigger time** セクションで **After Delay** をクリックし、遅延を _5 秒_ に設定します。これにより、ユーザーが次回 Web サイトを開いたときに、5 秒後にオンサイトメッセージがトリガーされます。 <img src="/images/moengage_d1531e.png" alt="Screenshot 2025-01-27 at 12.25.06 PM.png" />
8. **Select pages** セクションで **All pages** をクリックします。 <img src="/images/moengage_a4a555.png" alt="Screenshot 2025-01-27 at 12.26.16 PM.png" />
9. **Target Audience** セクションで、以下のようにオーディエンスを _過去 10 日間に商品を複数回閲覧したがカートに追加していないユーザー_ として定義します。 <img src="/images/moengage_1533fb.png" alt="2025-01-27_12-35-47 (1).gif" />
   <Info>
     キャンペーンは公開後数分以内に表示されるようになります。
   </Info>
   詳細については、[こちら](/ja/user-guide/campaigns-and-channels/on-site-message/analyze/campaign-delivery-mobile-in-app-and-on-site-messaging-campaigns)を参照してください。
10. **Next** をクリックして 2 番目のステップ **Content** に移動し、キャンペーンのコンテンツを定義します。

## ステップ 2: コンテンツ

1. **Prebuilt and saved templates** タブで、検索ボックスにキーワード _lead_ を入力してテンプレートを検索します。
2. 目的のテンプレートにカーソルを合わせ、**Select Template** をクリックします。**Blank Popup Template** を選択して一から作成することもできます。 <img src="/images/moengage_d59f8b.png" alt="2025-01-27_12-46-02 (1).gif" />
3. キャンペーンにパーソナライズされた要素を追加できます。たとえば、一般的な単語の代わりに商品名をパーソナライズできます。以下の GIF に示す手順に従ってください。詳細については、[Personalize](/ja/user-guide/personalize/overview/overview-personalize) を参照してください。 <img src="/images/moengage_889980.png" alt="2025-01-27_14-14-13 (1).gif" />
4. **Next** をクリックして 3 番目のステップ **Schedule and goals** に移動し、キャンペーンのスケジュールとゴールを定義します。

## ステップ 3: スケジュールとゴール

1. **Send campaign** セクションで、OSM キャンペーンを開始および終了するタイミングを定義します。 <img src="/images/moengage_d33c31.png" alt="11.png" />
2. **Conversion Goals** セクションで、追跡したいコンバージョンゴールを追加します。
3. **Campaign priority** セクションで、このキャンペーンに優先度を割り当てます。たとえば、**Critical** を選択すると、ユーザーが対象となる他のキャンペーンがある場合でも、このキャンペーンが常に表示されるようになります。詳細については、[Create OSM Campaign](/ja/user-guide/campaigns-and-channels/on-site-message/create/create-osm-campaign) を参照してください。
4. **Global Delivery controls** セクションで **Ignore global minimum delay** トグルをオンにすると、設定で定義されている任意の 2 つのキャンペーン間の最小遅延をオーバーライドできます。
5. **Local Delivery controls** セクションで、要件に応じてコントロールを定義します。詳細については、[Create OSM Campaign](/ja/user-guide/campaigns-and-channels/on-site-message/create/create-osm-campaign) を参照してください。 <img src="/images/moengage_b713b3.png" alt="12.png" />
6. **Publish** をクリックします。

# まとめ

このユースケースでは、匿名ユーザーとエンゲージするための OSM キャンペーンを作成しました。

OSM は、ユーザーにリマインドしたり、次のステップに進むためのメッセージを送信したりするための強力なツールです。ユーザーが商品をカートに追加したり購入したりすると、LTV が向上するだけでなく、ユーザーが連絡先情報を共有するため、それを使用してアウトバウンドのコミュニケーションでエンゲージできるようになります。

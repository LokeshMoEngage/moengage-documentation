# はじめに

Web サイトには毎日多くのユーザーが訪れ、その多くはプラットフォームの無料プランを利用している可能性があります。これらのユーザーのうち、誰がアップグレードに関心を持っているかを特定するのは難しい場合がありますが、頻繁な訪問やサイトでの継続的なアクティビティなどの指標があります。このカテゴリに該当するユーザーは、プレミアムオプションの検討を促すターゲティングされたプロモーションを導入する機会を企業にもたらします。

この記事では、現在無料プランを利用しており、Web サイトで積極的に活動しているユーザーに焦点を当てます。こうしたユーザーはすでにプラットフォームに慣れているため、On-site Messaging (OSM) キャンペーンでプレミアムプランへのアップグレードのメリットを強調します。また、OSM では期間限定の割引も提供して、切り替えのインセンティブをさらに高めます。

この記事では、無料ユーザーからプレミアムユーザーへのコンバージョンを促進する OSM キャンペーンの作成手順を説明します。

# 期待される結果

無料プランのユーザーには、プレミアムプランのメリットを強調し、アップグレードの期間限定割引を提供するポップアップが表示されます。これにより、コンバージョンを増やし、ユーザーにプレミアムプランへのアップグレードを促すことを目指します。

# OSM キャンペーンを作成する

このセクションでは、OSM キャンペーンを作成します。

## ステップ 1: ターゲットユーザー

1. 左側のサイドバーに移動して **Engage** \> **Campaigns** をクリックし、**\+ Create campaign** をクリックするか、**\+ Create new**\> **Campaign** をクリックします。
2. **Inbound** で **On-site** をクリックします。 <img src="/images/moengage_5859ab.png" alt="2.png" /> キャンペーン定義の最初のステップである "Target users" に移動します。
3. 次の詳細を入力します。
   - **Campaign name**: キャンペーンの名前を入力します。例: "Premium Plan benefits"。
   - **Campaign tags**: 関連するキャンペーンタグを選択します。
4. **Target platforms** セクションで **Web** を選択します。
5. **Trigger criteria** セクションで **On Page Load** を選択して、ユーザーが Web サイトにアクセスしたときにポップアップを表示します。無料プランのユーザーが Web サイトにアクセスしたときにポップアップが表示されるようにトリガーを設定します。
6. **Select trigger time** セクションで **After Delay** を選択し、遅延を 10 秒に設定します。ターゲットユーザーが次回 Web サイトを開いたときに、10 秒後に OSM がトリガーされます。 <img src="/images/moengage_c72ede.png" alt="Screenshot 2024-07-28 at 3.02.48 PM.png" />
7. **Select pages** セクションで **All pages** をクリックします。
8. **Target Audience** セクションで、オーディエンスを "現在無料プランを利用しており、過去 30 日間に Web サイトでアクティブだったユーザー" として定義します。 <img src="/images/moengage_c09346.png" alt="Screenshot 2024-07-28 at 3.03.33 PM.png" />
   <Info>
     キャンペーンは公開後数分以内に表示されるようになります。
   </Info>
9. セグメントが更新されると、セグメントの条件を満たすユーザーがキャンペーンを表示できるようになります。詳細については、[こちら](/ja/user-guide/campaigns-and-channels/on-site-message/analyze/campaign-delivery-mobile-in-app-and-on-site-messaging-campaigns)を参照してください。
10. **Next** をクリックして 2 番目のステップ "Content" に移動し、キャンペーンに含めるコンテンツを定義します。

## ステップ 2: コンテンツ

このユースケースでは、40 種類以上のデザインが用意されている [New Editor](/ja/user-guide/campaigns-and-channels/on-site-message/create/create-osm-campaign) を選択します。

コミュニケーションには、次の 2 つのタイプがあります。どちらのコミュニケーションを使用しても、ユーザーに次のステップへ進むよう促すことができます。

- **パーソナライズされていないコミュニケーション**: クーポンコードなどのシンプルなメッセージを含む OSM です。
  <img
    src="/images/moengage_c53967.png"
    alt="66bf59d9-578f-4201-9adb-0e9adf56a82c.png"
    style={{ width:"58%" }}
  />
- **パーソナライズされたコミュニケーション**: 商品名や画像などの詳細と、魅力的なメッセージを含む OSM です。
  <img
    src="/images/moengage_f9f6f6.png"
    alt="e7bec2ee-34ae-4699-b562-8cb393eef480.png"
    style={{ width:"59%" }}
  />

1. MoEngage ライブラリからカスタマイズ可能なポップアップテンプレートを選択します。このユースケースでは、邪魔にならないポップアップ **Nudge: upgrade with CTA** を選択します。
2. 次の手順を実行して、ポップアップメッセージをデザインします。
   - **タイトルを追加する:** "Upgrade to Premium and Enjoy Exclusive Benefits!"
     - **スタイル**: 注意を引くために、太字で魅力的なフォントを使用します。
   - **メリットの一覧を含める:** プレミアムプランの主なメリットを強調します。例:
     - すべての機能への無制限のアクセス
     - 優先カスタマーサポート
     - 広告なしの体験
   - **割引オファーを追加する:** "Limited-Time Offer: Get 20% off when you upgrade today!"
     - **スタイル**: 対照的な色と大きめのフォントサイズを使用して、割引を強調します。
   - **CTA (Call-to-Action) ボタンを追加する:** "Upgrade Now"
     - **リンク**: ボタンのリンク先をアップグレードページに設定します。
     - **スタイル**: 鮮やかな色と読みやすいフォントでボタンを目立たせます。
   - **閉じるボタンを追加する:** 興味がないユーザーがポップアップを閉じられるようにします。
   - **アニメーションを追加する:** ポップアップにアニメーションを追加することもできます。\\
     <iframe src="https://www.youtube.com/embed/ptAOQjRdM2g" title="YouTube 動画プレーヤー" frameborder="0" className="w-full aspect-video rounded-xl" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowfullscreen />
3. **Next** をクリックして 3 番目のステップ "Schedule and goals" に移動し、キャンペーンのスケジュールとゴールを定義します。

## ステップ 3: スケジュールとゴール

1. **Send campaign** セクションで、OSM キャンペーンを開始および終了するタイミングと、メッセージが適切に表示されるようにするための頻度と上限を定義します。 <img src="/images/moengage_7f2c51.png" alt="11.png" />
2. **Conversion goals** セクションで、追跡したいコンバージョンゴールを追加します。
3. **Campaign priority** セクションで、この OSM キャンペーンに優先度を割り当てます。優先度を割り当てることで、ユーザーが特定の時点で複数の OSM の対象となる場合に、どの OSM を表示するかを決定できます。たとえば、**Critical** を選択すると、ユーザーが対象となる他のキャンペーンがある場合でも、このキャンペーンが常に表示されるようになります。詳細については、[Create OSM Pro Campaign](/ja/user-guide/campaigns-and-channels/on-site-message/create/create-osm-campaign) を参照してください。
4. **Global Delivery controls** セクションで **Ignore global minimum delay** トグルをオンにすると、設定で定義されている任意の 2 つのキャンペーン間の最小遅延をオーバーライドできます。
5. **Local Delivery controls** セクションで、要件に応じてコントロールを定義します。詳細については、[Create OSM Pro Campaign](/ja/user-guide/campaigns-and-channels/on-site-message/create/create-osm-campaign) を参照してください。ポップアップがユーザーごとに 1 回だけ表示されるように設定します。 <img src="/images/moengage_b26839.png" alt="12.png" />
6. **Publish** をクリックします。

# まとめ

このユースケースでは、無料ユーザーからプレミアムユーザーへのコンバージョンを促進する OSM キャンペーンを作成しました。

OSM は、ユーザーにリマインドしたり、次のステップに進むためのメッセージを送信したりするための強力なツールです。この OSM キャンペーンを実装することで、無料プランのユーザーにプレミアムプランへのアップグレードのメリットを伝え、期間限定の割引でインセンティブを与えることができます。このアプローチはコンバージョンの増加に役立ち、ユーザーにプレミアムプランの強化された機能を試すよう促します。

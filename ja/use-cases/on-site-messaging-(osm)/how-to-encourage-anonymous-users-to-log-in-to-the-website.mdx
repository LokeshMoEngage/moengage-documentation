# はじめに

多くのアプリユーザーはログインせずに匿名で利用しているため、その意図を完全に把握するのは困難です。しかし、アプリの繰り返し利用や特定のインタラクションは高い関心を示しており、こうしたユーザーはエンゲージメントの対象として価値があります。

ログインしていないため、メールや SMS などによる直接的なコミュニケーションはできません。こうしたユーザーにリーチする最善の方法は、On-site Messaging (OSM) を使用して、ログインを促すパーソナライズされたプロンプトを表示することです。

この記事では、匿名ユーザーをターゲットにして、ログインしてアプリのすべてのメリットを体験するよう促す OSM キャンペーンの作成方法について説明します。

# 期待される結果

匿名ユーザーが Web サイトにアクセスすると、ログインしてアプリを利用するよう促すパーソナライズされたメッセージ付きのポップアップが表示されます。これにより、ユーザー登録とエンゲージメントの増加を目指します。

![Screenshot 2024-07-28 at 3.49.49 PM.png](/images/moengage_999029.png)

<Tip>
  - Web サイトが [MoEngage Web SDK](/ja/developer-guide/web-sdk/web-sdk-overview/web-sdk-overview) と統合されている必要があります。
  - ユーザーの行動を取得するために、"Product Viewed" や "Added to Cart" などのイベントが統合されている必要があります。
  - [On-site Messaging](/ja/developer-guide/web-sdk/onsite-messaging/configure-and-integrate-on-site-messaging) を設定して統合してください。
</Tip>

# OSM キャンペーンを作成する

このセクションでは、OSM キャンペーンを作成します。

## ステップ 1: ターゲットユーザー

1. 左側のサイドバーに移動して **Engage** \> **Campaigns** をクリックし、**\+ Create campaign** をクリックするか、**\+ Create new**\> **Campaign** をクリックします。
2. **Inbound** で **On-site** をクリックします。 <img src="/images/moengage_c65951.png" alt="2.png" /> キャンペーン定義の最初のステップである "Target users" に移動します。
3. 次の詳細を入力します。
   - **Campaign name**: キャンペーンの名前を入力します。例: "Personalized message"。
   - **Campaign tags**: 関連するキャンペーンタグを選択します。
4. **Target platforms** セクションで **Web** を選択します。
5. **Trigger criteria** セクションで **On Page Load** を選択して、匿名ユーザーが Web サイトにアクセスしたときにポップアップを表示します。
6. **Select trigger time** セクションで **After Delay** を選択し、遅延を 10 秒に設定します。ターゲットユーザーが次回 Web サイトを開いたときに、10 秒後に OSM がトリガーされます。 <img src="/images/moengage_618854.png" alt="Screenshot 2024-07-28 at 3.02.48 PM.png" />
7. **Select pages** セクションで **All pages** を選択します。
8. **Target Audience** セクションで、オーディエンスを "ID を持たず、ログインせずにアプリを使用しているユーザー" として定義し、ログイン済みのユーザーやポップアップを繰り返し閉じたユーザーを除外します。 <img src="/images/moengage_cdc580.png" alt="Screenshot 2024-07-28 at 3.31.25 PM.png" />
   <Info>
     キャンペーンは公開後数分以内に表示されるようになります。
   </Info>
9. セグメントが更新されると、セグメントの条件を満たすユーザーがキャンペーンを表示できるようになります。詳細については、[こちら](/ja/user-guide/campaigns-and-channels/on-site-message/analyze/campaign-delivery-mobile-in-app-and-on-site-messaging-campaigns)を参照してください。
10. **Next** をクリックして 2 番目のステップ "Content" に移動し、キャンペーンのコンテンツを定義します。

## ステップ 2: コンテンツ

このユースケースでは、40 種類以上のデザインが用意されている [New Editor](/ja/user-guide/campaigns-and-channels/on-site-message/create/create-osm-campaign#step-2-define-content) を選択します。

コミュニケーションには、次の 2 つのタイプがあります。どちらのコミュニケーションを使用しても、ユーザーに次のステップへ進むよう促すことができます。

- **パーソナライズされていないコミュニケーション**: クーポンコードなどのシンプルなメッセージを含む OSM です。
  <img
    src="/images/moengage_06b964.png"
    alt="66bf59d9-578f-4201-9adb-0e9adf56a82c.png"
    style={{ width:"53%" }}
  />
- **パーソナライズされたコミュニケーション**: 商品名や画像などの詳細と、魅力的なメッセージを含む OSM です。
  <img
    src="/images/moengage_8c008c.png"
    alt="e7bec2ee-34ae-4699-b562-8cb393eef480.png"
    style={{ width:"58%" }}
  />

1. MoEngage ライブラリからカスタマイズ可能なポップアップテンプレートを選択します。

![Screenshot 2024-07-28 at 3.51.45 PM.png](/images/moengage_a141a6.png)

2. 次の手順を実行して、ポップアップメッセージをデザインします。
   - **タイトルを追加する:** "Unlock More Features by Logging In!"
     - **スタイル**: 注意を引くために、太字で魅力的なフォントを使用します。
   - **パーソナライズされたメッセージを含める:**
     - **テキスト**: "Hello! {name} you can do the following after logging in"
     - **スタイル**: テキストが親しみやすく魅力的なものになるようにします。
   - **ログインのメリットを強調する:**
     - **メリット 1:** "Access your personalized dashboard."
     - **メリット 2:** "Save your preferences for future visits."
     - **メリット 3:** "Enjoy a seamless experience across devices."
   - **CTA (Call-to-Action) ボタンを追加する:** "Log In Now"
     - **リンク**: ボタンのリンク先をログインページに設定します。
     - **スタイル**: 鮮やかな色と読みやすいフォントでボタンを目立たせます。
   - **閉じるボタンを追加する:** 興味がないユーザーがポップアップを閉じられるようにします。\\
     <iframe src="https://www.youtube.com/embed/B-XYkXUH3Yg" title="YouTube 動画プレーヤー" frameborder="0" className="w-full aspect-video rounded-xl" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowfullscreen />
3. **Next** をクリックして 3 番目のステップ "Schedule and goals" に移動し、キャンペーンのスケジュールとゴールを定義します。

## ステップ 3: スケジュールとゴール

1. **Send campaign** セクションで、OSM キャンペーンを開始および終了するタイミングと、メッセージが適切に表示されるようにするための頻度と上限を定義します。 <img src="/images/moengage_ac8e2a.png" alt="11.png" />
2. **Conversion Goals** セクションで、追跡したいコンバージョンゴールを追加します。
3. **Campaign priority** セクションで、この OSM キャンペーンに優先度を割り当てます。優先度を割り当てることで、ユーザーが特定の時点で複数の OSM の対象となる場合に、どの OSM を表示するかを決定できます。たとえば、**Critical** を選択すると、ユーザーが対象となる他のキャンペーンがある場合でも、このキャンペーンが常に表示されるようになります。詳細については、[Create OSM Pro Campaign](/ja/user-guide/campaigns-and-channels/on-site-message/create/create-osm-campaign) を参照してください。
4. **Global Delivery controls** セクションで **Ignore global minimum delay** トグルをオンにすると、設定で定義されている任意の 2 つのキャンペーン間の最小遅延をオーバーライドできます。
5. **Local Delivery controls** セクションで、要件に応じてコントロールを定義します。詳細については、[Create OSM Pro Campaign](/ja/user-guide/campaigns-and-channels/on-site-message/create/create-osm-campaign) を参照してください。ポップアップがユーザーごとに 1 回だけ表示されるように設定します。 <img src="/images/moengage_b1fd11.png" alt="12.png" />
6. **Publish** をクリックします。

# まとめ

このユースケースでは、匿名ユーザーからのコンバージョンを促進し、ログインしてアプリのすべてのメリットを体験するよう促す OSM キャンペーンを作成しました。

OSM は、ユーザーにリマインドしたり、次のステップに進むためのメッセージを送信したりするための強力なツールです。このログインを促すポップアップを実装することで、パーソナライズされたメッセージを通じて匿名ユーザーにログインのメリットを伝えることができます。このアプローチはユーザー登録とエンゲージメントの増加に役立ち、最終的にはユーザー全体のアクティビティと満足度の向上につながります。

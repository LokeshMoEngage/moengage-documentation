# はじめに

多くの Web ブラウザーがサードパーティ Cookie をブロックする今日のデジタル環境では、ファーストパーティデータの収集がこれまで以上に重要になっています。ファーストパーティデータは、顧客、見込み客、その他ブランドと関わる人々から直接収集されるため、他の種類のデータよりも正確で関連性が高くなります。

#### ファーストパーティデータを収集するメリット

- **データの正確性と信頼性**: 不正確さや偏りが生じる可能性があるサードパーティデータとは異なり、ファーストパーティデータは正確で信頼できます。顧客との直接的な関係構築に役立ちます。
- **パーソナライズの強化**: ファーストパーティデータにより、個々の顧客プロファイルを深く理解できます。これにより、高度にターゲティングされたマーケティングメッセージ、商品レコメンデーション、パーソナライズされた体験を提供できます。
- **顧客エンゲージメントの向上**: 顧客の好みや行動を理解することで、特定のオーディエンスに響くようにマーケティング活動を調整し、エンゲージメントとロイヤルティを高めることができます。
- **マーケティング ROI の向上**: 正確で関連性の高いデータは、キャンペーンの最適化、無駄な支出の削減、コンバージョン率の向上に役立ちます。
- **顧客との関係の強化**: パーソナライズと関連性の高いやり取りにより、企業と顧客との関係が強化されます。

このユースケースでは、[On-site Messaging (OSM) キャンペーンを作成](/ja/use-cases/on-site-messaging-(osm)/collect-first-party-data-using-typeform#create-an-osm-campaign)し、そこに [Typeform](https://www.typeform.com/) のアンケートを埋め込んで、Web サイトでファーストパーティデータを収集します。Typeform では使いやすいアンケートを作成でき、MoEngage は適切なオーディエンスが最適なタイミングでアンケートを目にするようにします。ここでは、ユーザーがオンラインストアで商品を購入した後に、購入体験についてのアンケートを実施します。

# OSM キャンペーンを作成する

このセクションでは、Typeform のアンケートを送信する OSM キャンペーンを作成します。

## ステップ 1: ターゲットユーザー

1. MoEngage ダッシュボードの左側のナビゲーションメニューで **Engage** をクリックし、**Campaigns** をクリックします。
2. All campaigns ページで **\+ Create campaign** をクリックします。
3. **Inbound** で **On-site** をクリックします。
   ![Screenshot 2025-05-12 at 10.27.58 AM.png](/images/moengage_0de64c.png)
   最初のステップである **Target users** に移動します。
4. キャンペーンの名前とタグを定義します。
5. **Target Platforms** セクションで、**Web** と **Mobile Web** の両方のオプションを選択します。
   ![Screenshot 2025-01-21 at 5.12.58 PM.png](/images/moengage_4855d5.png)
6. **Trigger criteria** セクションで、ユーザーにアンケートを表示するタイミングを選択します。このユースケースでは、商品の購入体験に関するフィードバックを得たいと考えています。そのため、**On custom event** をクリックし、条件を _Has Executed Product Purchase_ として定義して、ユーザーが商品を購入した直後にアンケートが表示されるようにします。詳細については、[Create OSM Campaign](/ja/user-guide/campaigns-and-channels/on-site-message/create/create-osm-campaign) を参照してください。
   ![22222.png](/images/moengage_12dcb5.png)
7. **Select pages** セクションで **All pages** をクリックします。
   ![Screenshot 2025-01-21 at 5.18.34 PM.png](/images/moengage_49b7bf.png)
8. **Target audience** セクションで **All users** をクリックします。アンケートの成功は質問内容とターゲットオーディエンスに左右されるため、これらはできるだけ具体的に定義してください。
9. **Next** をクリックして 2 番目のステップ **Content** に移動し、キャンペーンのコンテンツを定義します。

## ステップ 2: コンテンツ

このステップでは、キャンペーンのコンテンツを定義します。

1. **Search templates** フィールドでキーワード "Typeform" を検索し、目的のテンプレートを選択します。
   ![Screenshot 2025-01-21 at 5.26.56 PM.png](/images/moengage_829bd0.png)
2. 画面が読み込まれたら、空の Typeform 要素をクリックします。一連のアイコンが表示されます。
3. 最初のアイコンをクリックして HTML コード要素を編集し、ここでアンケートを接続します。
   ![2025-01-21\_17-45-08 (1).gif](/images/moengage_3b7a27.png)
4. _data-url_ 変数と _src_ 変数を探します。これらの変数に、クエリパラメーター付きの Typeform URL を追加します。一重引用符 ('') ではなく、二重引用符 ("") を使用してください。
   ![2025-01-21\_17-55-26 (1).gif](/images/moengage_1d71a9.png)
   ![5.png](/images/moengage_44b895.png)
5. **Next** をクリックして 3 番目のステップ **Schedule and goals** に移動します。

## ステップ 3: スケジュールとゴール

このステップでは、キャンペーンのスケジュールとゴールを定義します。

1. **Send campaign** セクションで、OSM キャンペーンを開始および終了するタイミングを定義します。
   ![6.png](/images/moengage_d0be31.png)
2. **Conversion goals** セクションで、追跡したいコンバージョンゴールを追加します。
3. **Campaign priority** セクションで、この OSM キャンペーンに優先度を割り当てます。たとえば、**Critical** を選択すると、表示すべき他のキャンペーンがある場合でも、このキャンペーンがユーザーに表示されるようになります。詳細については、[Create OSM Campaign](/ja/user-guide/campaigns-and-channels/on-site-message/create/create-osm-campaign) を参照してください。
4. **Global Delivery controls** セクションで **Ignore global minimum delay** トグルをオンにすると、設定で定義されている任意の 2 つのキャンペーン間の最小遅延をオーバーライドできます。
5. **Local Delivery controls** セクションで、要件に応じてコントロールを定義します。詳細については、[Create OSM Campaign](/ja/user-guide/campaigns-and-channels/on-site-message/create/create-osm-campaign) を参照してください。
   ![7.png](/images/moengage_eb4c20.png)
6. **Publish** をクリックします。

# まとめ

このユースケースでは、OSM キャンペーンを作成し、Typeform のアンケートを埋め込みました。キャンペーンを公開したら、そのパフォーマンスを分析できます。詳細については、[Analyze On-site Messaging Campaigns](/ja/user-guide/campaigns-and-channels/on-site-message/analyze/analyze-on-site-messaging-campaigns) を参照してください。

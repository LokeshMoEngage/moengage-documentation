# プラグインの初期化

**`MoECapacitorCore.initialize({ appId: "YOUR_WORKSPACE_ID", initConfig: initConfig});`** を呼び出して MoEngage プラグインを初期化します。Ionic-React の場合は **`useIonViewWillEnter()`** コールバックでプラグインを初期化し、Ionic-Angular の場合は **`ngOnInit()`** でプラグインを初期化します。

詳細については、[Ionic React のライフサイクル](https://ionicframework.com/docs/react/lifecycle)を参照してください。

## iOS

**capacitor-moengage-core** のバージョン 5.x.x 以降、カスタムブール型属性のデフォルトのトラッキングが double から bool に変更されます。これを設定するには **_MoEAnalyticsConfig_** を使用し、ブール値を double としてトラッキングする場合は true を、bool としてトラッキングする場合は false を渡します。

<CodeGroup>

```typescript Typescript
import { MoECapacitorCore, MoEAnalyticsConfig, MoEInitConfig} from 'capacitor-moengage-core'
      
const analyticsConfig: MoEAnalyticsConfig = {shouldTrackUserAttributeBooleanAsNumber: true};
const initConfig: MoEInitConfig = {analyticsConfig: analyticsConfig};

MoECapacitorCore.initialize({ appId: "YOUR_WORKSPACE_ID", initConfig: initConfig });
```

</CodeGroup>

詳細については、[ドキュメント](/ja/developer-guide/capacitor-sdk/data-tracking/tracking-user-attributes)を参照してください。

<Warning>
  **`initialize({ appId: "YOUR_WORKSPACE_ID", initConfig: initConfig })`** を呼び出す前に、プッシュ/InApp のコールバックリスナーを設定していることを確認してください。
</Warning>

Capacitor は、iOS および Android 上でネイティブに動作するモダンな Web アプリを簡単に構築できるクロスプラットフォームのネイティブランタイムです。

# MoEngage プラグインの追加

以下のように、**capacitor-moengage-core** プラグインを Capacitor プロジェクトに追加します。

<CodeGroup>

```Shell Shell
$npm install capacitor-moengage-core
```

</CodeGroup>

プラグインをインストールしたら、**_npx cap sync_** を実行して Capacitor のネイティブプラットフォームと依存関係を更新します。

プラグインの追加については、**_Capacitor_** フレームワークのガイドラインに従ってください。

<Info>
  動作するサンプルアプリは[こちら](https://github.com/moengage/Capacitor-Sample)にあります。
</Info>

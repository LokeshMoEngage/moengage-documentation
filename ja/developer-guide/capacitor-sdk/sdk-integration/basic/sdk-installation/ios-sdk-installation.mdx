---
title: "iOS SDK のインストール"
description: "ionic capacitor sync コマンドを実行して、Capacitor プロジェクトに MoEngage iOS SDK をインストールします。"
---

ネイティブ SDK である **MoEngage-iOS-SDK** は、**capacitor-moengage-core** プラグインの依存関係として追加されています。そのため、**ionic capacitor sync** を実行して、ネイティブ SDK を iOS プロジェクトに追加してください。

<Info>
  Swift Package Manager はバージョン 6.0.0 以降でサポートされています。
</Info>

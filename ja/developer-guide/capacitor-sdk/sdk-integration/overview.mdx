MoEngage Capacitor プラグインの統合は 2 つのステップで行います。プラグインとそのネイティブの依存関係を追加し、その後 SDK を初期化します。

初期化には 2 つの形式があります。ファイルベースの初期化では構成をネイティブの構成ファイルに保持し、フレームワークとプラットフォームのページでは代わりにコードで設定します。

## SDK のインストール

| ページ | 内容 |
| --- | --- |
| [フレームワークの依存関係](/ja/developer-guide/capacitor-sdk/sdk-integration/basic/sdk-installation/framework-dependency) | プラグインを追加し、ネイティブプラットフォームの依存関係を設定します。 |
| [Android SDK のインストール](/ja/developer-guide/capacitor-sdk/sdk-integration/basic/sdk-installation/android-sdk-installation) | BOM または手動の依存関係設定を使用して Android SDK をインストールします。 |
| [iOS SDK のインストール](/ja/developer-guide/capacitor-sdk/sdk-integration/basic/sdk-installation/ios-sdk-installation) | `ionic capacitor sync` を実行して iOS SDK をインストールします。 |

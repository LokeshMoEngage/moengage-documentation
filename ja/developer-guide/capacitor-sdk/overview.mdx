MoEngage Capacitor プラグインは、ネイティブの Android および iOS SDK をラップし、JavaScript または TypeScript のコードから利用できるようにします。イベントとユーザー属性をトラッキングし、両方のプラットフォームでプッシュトークンを登録し、アプリ内メッセージを表示します。

まず [Capacitor SDK の統合](/ja/developer-guide/capacitor-sdk/sdk-integration/overview)からプラグインを追加して初期化し、その後必要なチャネルを追加してください。

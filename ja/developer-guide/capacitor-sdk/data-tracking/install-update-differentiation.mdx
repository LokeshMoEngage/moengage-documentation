---
title: "インストール/アップデートの区別"
description: "移行トラッキングのために、MoEngage Capacitor SDK でアプリのステータスをインストールまたはアップデートとして設定します。"
---

これは MoEngage プラットフォームへの移行時にのみ必要です。ユーザーがアプリの新規ユーザーなのか、最新バージョンにアップデートした既存ユーザーなのかを SDK に伝える必要があります。ユーザーがすでにアプリケーションを使用しており、MoEngage SDK を含む新しいバージョンにアップデートしたばかりの場合はアップデートとなるため、以下の API を呼び出します。

<CodeGroup>
```javascript TypeScript
import { MoECapacitorCore, MoEAppStatus } from 'capacitor-moengage-core'
 
// For Existing user who has updated the app
MoECapacitorCore.setAppStatus({ appStatus: MoEAppStatus.UPDATE, appId: "YOUR_WORKSPACE_ID" });
```

</CodeGroup>

新規インストールの場合は、以下の API を呼び出します。

<CodeGroup>
```javascript TypeScript
import { MoECapacitorCore, MoEAppStatus } from 'capacitor-moengage-core'

//For Fresh Install of App
MoECapacitorCore.setAppStatus({ appStatus: MoEAppStatus.INSTALL, appId: "YOUR_WORKSPACE_ID" });
```

</CodeGroup>

---
title: "MoEngage サーバーからのユーザー削除"
description: "Android で Capacitor SDK を使用して、MoEngage サーバーから現在のユーザーを削除します。"
---

<Info>
この API は **capacitor-moengage-core** バージョン **3.1.0** からサポートされており、Android プラットフォームでのみ利用できます。その他のプラットフォームでは何も実行されません。
</Info>

MoEngage サーバーから現在のユーザーを削除するには、以下に示すように ***deleteUser()*** メソッドを使用します。

<CodeGroup>
```javascript TypeScript
import { MoECapacitorCore } from 'capacitor-moengage-core'
      
MoECapacitorCore.deleteUser({appId: "YOUR_WORKSPACE_ID"}, (userDeletionData) = {
  // add your code to handle the callback.
  console.log(this.tag + " deleteUser(): workspaceId: " + userDeletionData.accountMeta.appId + " isSuccess=" + userDeletionData.isSuccess)
    })
```

</CodeGroup>

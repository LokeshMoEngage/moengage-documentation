---
title: "広告 ID トラッキングの有効化"
description: "正確なデバイス分析のために、Capacitor アプリで広告 ID トラッキングを有効にします。"
---

デバイスに関する正確な分析と再インストールのトラッキングのためには、広告 ID をトラッキングすることが不可欠です。

## 広告 ID ライブラリの追加

アプリケーションレベルの **_build.gradle_** ファイルに以下の依存関係を追加します。

<CodeGroup>

```groovy Groovy
implementation("com.google.android.gms:play-services-ads-identifier:18.0.1")
```

</CodeGroup>

広告 ID トラッキングを有効にするには、以下に示すように _enableAdIdTracking()_ メソッドを使用します。

<CodeGroup>

```javascript TypeScript
import { MoECapacitorCore } from 'capacitor-moengage-core'
MoECapacitorCore.enableAdIdTracking({ appId: "YOUR_WORKSPACE_ID" });
```

</CodeGroup>

広告 ID トラッキングを有効にする前に、アプリケーションが広告 ID トラッキングに関する [Google Play ポリシー](https://support.google.com/googleplay/android-developer/answer/10144311)に準拠していることを確認してください。ポリシーの詳細については、[ヘルプドキュメント](https://www.moengage.com/docs/user-guide/data/privacy/android-advertising-id-tracking)を参照してください。

トラッキングを有効にした後に広告 ID を無効にする必要がある場合は、次のメソッドを使用します。

<CodeGroup>

```javascript TypeScript
import { MoECapacitorCore } from 'capacitor-moengage-core'
MoECapacitorCore.disableAdIdTracking({ appId: "YOUR_WORKSPACE_ID" });
```

</CodeGroup>

<Info>
  上記の API は、プラグインバージョン 1.0.2 以降でのみ利用できます。それより古いバージョンでは、広告 ID トラッキングはデフォルトで有効になっています。
</Info>

MoEngage Capacitor プラグインはトラッキング機能を JavaScript から利用できるようにするため、Android と iOS で同じ API を呼び出せます。まずユーザーを識別し、その後キャンペーンで使用するイベントをトラッキングしてください。

| [イベントのトラッキング](/ja/developer-guide/capacitor-sdk/data-tracking/tracking-events) | セグメンテーションとキャンペーンのために、ユーザーのアクションとイベントのプロパティをトラッキングします。 |
| [インストール/アップデートの区別](/ja/developer-guide/capacitor-sdk/data-tracking/install-update-differentiation) | 移行のトラッキングのために、アプリのステータスをインストールまたはアップデートとして設定します。 |
| [広告 ID トラッキングの有効化](/ja/developer-guide/capacitor-sdk/data-tracking/enable-advertising-identifier-tracking) | デバイス分析のために広告識別子のトラッキングを有効にします。 |

Capacitor のプッシュはプラットフォームごとに設定します。Android では Firebase の認証情報とランタイム権限、iOS では APNS 証明書を設定します。**基本**のページでは、両方の設定に加えて、トークンの生成と通知のクリックに使用するリスナーについて説明します。

## 基本

| ページ | 内容 |
| --- | --- |
| [Android プッシュ設定](/ja/developer-guide/capacitor-sdk/push/basic/android-push-configuration) | FCM のセットアップとプッシュの登録を含め、Android プッシュを設定します。 |
| [Android 通知のランタイム権限](/ja/developer-guide/capacitor-sdk/push/basic/android-notification-runtime-permissions) | Android 13 の通知ランタイム権限をリクエストします。 |
| [iOS プッシュ設定](/ja/developer-guide/capacitor-sdk/push/basic/ios-push-configuration) | APNS 証明書と登録を含め、iOS プッシュを設定します。 |
| [プッシュコールバック](/ja/developer-guide/capacitor-sdk/push/basic/push-callback) | プッシュトークンの生成と通知クリックのイベントをリッスンします。 |

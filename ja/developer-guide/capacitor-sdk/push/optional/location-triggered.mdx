# インストール

## ジオフェンスプラグインの追加

以下に示すように、**capacitor-moengage-geofence** プラグインを Capacitor プロジェクトに追加します。

<CodeGroup>

```auto Shell
$npm install capacitor-moengage-geofence
```

</CodeGroup>

## Android のインストール

## BOM を使用したインストール

BOM を使用した統合が推奨される統合方法です。[BOM を使用したインストールのドキュメント](/ja/developer-guide/android-sdk/sdk-integration/basic-integration/Install-Using-BOM)を参照してください。BOM を設定したら、以下に示すように _app/build.gradle_ ファイルに依存関係を追加します。

<CodeGroup>

```json build.gradle wrap
dependencies {
    ...
    implementation("com.moengage:geofence")
}
```

</CodeGroup>

BOM を設定したら、アプリケーションに必要な特定の MoEngage モジュールを含めます。 \
注: これらの依存関係にバージョン番号は必要ありません。BOM が自動的に管理します。

## 手動インストール

![Download](https://img.shields.io/maven-central/v/com.moengage/geofence)

Flutter プラグインをインストールしたら、アプリケーションの Android プロジェクトに MoEngage のネイティブ Android SDK の依存関係を追加します。\
**android/app/build.gradle** に移動し、**dependencies** ブロックに MoEngage Android SDK の依存関係を追加します。

<CodeGroup>

```css build.gradle
dependencies {
    implementation fileTree(dir: 'libs', include: ['*.jar'])
    implementation("com.moengage:geofence:$sdkVersion")
}
```

</CodeGroup>

ここで、**\$sdkVersion** は MoEngage Geofence SDK の最新バージョンに置き換えてください。

## iOS

iOS の場合、ネイティブの依存関係は Geofence Cordova SDK 自体に含まれているため、ジオフェンスをサポートするために追加の依存関係を含める必要はありません。

## 設定

### ジオフェンスモニタリングの開始

ジオフェンスパッケージを統合したら、**startGeofenceMonitoring()** メソッドを呼び出してジオフェンスモジュールを開始します。これにより、ユーザーの現在地周辺のジオフェンスが取得されます。ジオフェンスの詳細については、[iOS のドキュメント](/ja/developer-guide/ios-sdk/push/optional/location-triggered)と [Android のドキュメント](/ja/developer-guide/android-sdk/push/optional/location-triggered)を参照してください。デフォルトでは、ジオフェンス機能は有効になっていません。位置情報トリガー型のプッシュメッセージを受信するには、\*\*startGeofenceMonitoring()\*\*を呼び出す必要があります。

<CodeGroup>

```auto Typescript
import { MoECapacitorGeofence } from 'capacitor-moengage-geofence';
MoECapacitorGeofence.startGeofenceMonitoring({ appId: "YOUR_WORKSPACE_ID" });
```

</CodeGroup>

### ジオフェンスモニタリングの停止

ジオフェンスのモニタリングまたは機能を停止したい場合は、**stopGeofenceMonitoring()** API を使用します。この API は既存のジオフェンスを削除します。

<CodeGroup>

```auto Typescript
import { MoECapacitorGeofence } from 'capacitor-moengage-geofence';
MoECapacitorGeofence.stopGeofenceMonitoring({ appId: "YOUR_WORKSPACE_ID" });
```

</CodeGroup>

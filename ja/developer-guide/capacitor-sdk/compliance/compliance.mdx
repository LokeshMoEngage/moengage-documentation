ユーザーが与えた同意に基づいて、MoEngage SDK がトラッキングする内容を制御するには、以下の API を使用します。

## データトラッキングの有効化または無効化

SDK によるカスタムイベントとユーザー属性のトラッキングを停止するには、`disableDataTracking()` を呼び出します。

<CodeGroup>

```javascript JavaScript
import { MoECapacitorCore } from 'capacitor-moengage-core'
MoECapacitorCore.disableDataTracking({ appId: "YOUR_WORKSPACE_ID" })
```

</CodeGroup>

`enableDataTracking()` を呼び出すまで、SDK はすべてのイベントとユーザー属性を拒否します。データトラッキングはデフォルトで有効になっています。

<CodeGroup>

```javascript JavaScript
import { MoECapacitorCore } from 'capacitor-moengage-core'
MoECapacitorCore.enableDataTracking({ appId: "YOUR_WORKSPACE_ID" })
```

</CodeGroup>

## SDK の有効化または無効化

SDK によるユーザー情報のトラッキングや MoEngage へのデータ送信をすべて停止するには、`disableSdk()` を呼び出します。

<CodeGroup>

```javascript JavaScript
import { MoECapacitorCore } from 'capacitor-moengage-core'
MoECapacitorCore.disableSdk({ appId: "YOUR_WORKSPACE_ID" })
```

</CodeGroup>

`enableSdk()` を呼び出すまで、すべての SDK API は動作しません。SDK はデフォルトで有効になっているため、以前に無効にした場合にのみ `enableSdk()` を呼び出してください。

<CodeGroup>

```javascript JavaScript
import { MoECapacitorCore } from 'capacitor-moengage-core'
MoECapacitorCore.enableSdk({ appId: "YOUR_WORKSPACE_ID" })
```

</CodeGroup>

<Info>
  これらの API は **capacitor-moengage-core** バージョン **2.0.0** から利用できます。
</Info>

## ユーザーデータの削除

MoEngage サーバーから現在のユーザーのプロファイルを削除するには、[MoEngage サーバーからのユーザー削除](/ja/developer-guide/capacitor-sdk/data-tracking/delete-user-from-moengage-server)を参照してください。

このページでは、MoEngage Cordova SDK のメジャーバージョンのサポート状況を確認できます。現行のバージョン、引き続きサポートされているバージョン、非推奨のバージョンを、非推奨日とともに一覧にしています。このページは、Cordova SDK のバージョンステータスに関する正式な情報源です。ライフサイクルの仕組みと、非推奨がアプリにとって何を意味するかについては、[SDK 非推奨ポリシー](/ja/developer-guide/sdk-lifecycle-and-policies/sdk-deprecation-policy)を参照してください。Cordova SDK をセットアップするには、[統合ガイド](/ja/developer-guide/cordova-sdk/sdk-integration/sdk-installation/framework-dependency)を参照してください。

## バージョンのサポート状況

<Info>
  **現行（Current）** — 最新のメジャーバージョンです。新機能、修正、サポートが提供されます。

  **サポート中（Supported）** — 3 年間のサポート期間内にある旧メジャーバージョンです。引き続きサポートが提供されます。

  **非推奨（Deprecated）** — サポート期間外のバージョンです。修正やサポートは提供されなくなります。
</Info>

| メジャーバージョン | ステータス | 非推奨日 | 備考 |
| --- | --- | --- | --- |
| Core 10.x | 現行 | 未定 | 最新のメジャーバージョンです。新機能、修正、サポートが提供されます。 |
| Core 9.x | サポート中 | 未定 | サポートが提供されます。 |
| Core 8.7.0 以前 | 非推奨 | 2027 年 8 月 | サポート、デバッグ、修正は提供されなくなります。データは引き続き送信されます。現行バージョンにアップグレードしてください。 |

<Note>
  MoEngage は、各メジャーバージョンを最初のリリースから 3 年間サポートし、その後の 8 月に非推奨となります。詳細については、[SDK 非推奨ポリシー — サポート期間](/ja/developer-guide/sdk-lifecycle-and-policies/sdk-deprecation-policy#support-window)を参照してください。この表は、MoEngage がさらなる非推奨を発表した際に更新されます。事前通知を受け取るには、SDK ニュースレターを購読し、ワークスペース管理者のメールアドレスが最新であることを確認してください。
</Note>

## 非推奨ステータスについて

非推奨バージョンでも、引き続きデータの送受信は行われます。MoEngage はトラフィックをブロックしません。非推奨日以降、MoEngage はそのバージョン固有の問題のデバッグ、修正、サポートを行わなくなり、問題の解決策は現行バージョンへのアップグレードとなります。すべての修正は現行バージョンでのみ提供され、サポート中または非推奨のバージョンでは利用できません。ポリシーの全文については、[SDK 非推奨ポリシー](/ja/developer-guide/sdk-lifecycle-and-policies/sdk-deprecation-policy)を参照してください。

## サポート対象バージョンへのアップグレード

- 現行メジャーバージョンの変更点については、[Cordova SDK リリースノート](/ja/release-notes/sdks/cordova)を参照してください。
- 統合の変更点については、[Cordova SDK 移行ガイド](/ja/developer-guide/cordova-sdk/migration/migrating-to-4xx)を確認してください。
- サポートが必要な場合は、MoEngage のカスタマーサクセスマネージャー（CSM）またはサポートチームにお問い合わせください。

## よくある質問

<AccordionGroup>
  <Accordion title="非推奨になった後も非推奨バージョンを使い続けることはできますか？">
    非推奨バージョンのアプリは引き続き動作し、データも引き続き送信されます。ただし、MoEngage は非推奨バージョンに対するサポート、デバッグ、修正を提供しなくなります。[Cordova SDK リリースノート](/ja/release-notes/sdks/cordova)を参照して現行バージョンまたはサポート対象バージョンにアップグレードすることで、継続的なサポートを受けられます。
  </Accordion>
  <Accordion title="非推奨の事前通知を受け取るにはどうすればよいですか？">
    MoEngage は、非推奨日の 6～12 か月前に、ワークスペース管理者へのメール、四半期ごとの SDK ニュースレター、ダッシュボード内の通知、SDK リリースノートを通じて事前通知を送信します。通知スケジュールの詳細については、[SDK 非推奨ポリシー](/ja/developer-guide/sdk-lifecycle-and-policies/sdk-deprecation-policy)を参照してください。
  </Accordion>
</AccordionGroup>

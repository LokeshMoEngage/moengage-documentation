Cordova のプッシュはプラットフォームごとに設定します。Android では Firebase の認証情報とランタイム権限、iOS では APNS 証明書を設定します。**基本**のページでは、両方の設定に加えて、通知のクリックを処理する JavaScript コールバックについて説明します。

## 基本

| ページ | 内容 |
| --- | --- |
| [Android プッシュ設定](/ja/developer-guide/cordova-sdk/push/basic/android-push-configuration) | FCM のセットアップとプッシュトークンの処理を含め、Android プッシュを設定します。 |
| [Android 通知のランタイム権限](/ja/developer-guide/cordova-sdk/push/basic/android-notification-runtime-permissions) | Android 13 の通知ランタイム権限をリクエストします。 |
| [iOS プッシュ設定](/ja/developer-guide/cordova-sdk/push/basic/ios-push-configuration-7xx) | APNS 証明書とプッシュの登録を含め、iOS プッシュを設定します。 |
| [プッシュコールバック](/ja/developer-guide/cordova-sdk/push/basic/push-callback) | プッシュ通知のクリックイベント用の JavaScript コールバックをセットアップします。 |

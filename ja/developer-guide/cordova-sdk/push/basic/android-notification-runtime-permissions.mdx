---
title: "Android 通知のランタイム権限"
description: "MoEngage SDK を使用して、Cordova アプリで Android 13 の通知ランタイム権限を処理します。"
---

Android 13（API レベル 33）以降では、アプリから[適用除外ではない](https://developer.android.com/develop/ui/views/notifications/notification-permission#exemptions)通知（フォアグラウンドサービス（FGS）を含む）を送信するための[ランタイム権限](https://developer.android.com/guide/topics/permissions/overview#runtime) [POST_NOTIFICATIONS](https://developer.android.com/reference/android/Manifest.permission#POST_NOTIFICATIONS) がサポートされています。この変更により、ユーザーは自分にとって最も重要な通知に集中できるようになります。

詳細については、[公式ドキュメント](https://developer.android.com/develop/ui/views/notifications/notification-permission)を参照してください。

以下の API は、MoEngage core Android SDK バージョン **12.3.01** 以降でサポートされています。

アプリケーションが Android 13 で実行され、ユーザーに通知を表示したい場合は、ユーザーに通知の権限をリクエストする必要があります。MoEngage に権限の処理を任せるか、独自のコードで通知の権限を処理するかの 2 つのオプションがあります。

- MoEngage が通知の権限を処理する。
  - このページに記載されている 1 行のコードを呼び出すだけです。
- 通知の権限ロジックを自分で管理する。
  - プッシュ通知の権限が付与された場合は MoEngage SDK に通知します。

MoEngage にプッシュ通知の権限の処理を任せることをお勧めします。

## 権限の結果を SDK に通知する

アプリケーションがユーザーに通知の権限をリクエストしたら、以下の API を使用してユーザーの応答を SDK に通知します。_MoEngage SDK に通知の権限の処理を任せている場合は、この手順を無視してください。_

<CodeGroup>

```javascript JavaScript
var moe = MoECordova.init("YOUR_WORKSPACE_ID");
//isGranted = true/false
moe.pushPermissionResponseAndroid(requestCount)
```

</CodeGroup>

## 権限リクエスト回数の更新（オプション）

アプリケーションがユーザーに通知の権限をリクエストしたら、リクエストの試行回数を SDK に更新します。

**SDK が権限の試行回数を必要とするのはなぜですか？**

SDK は、権限リクエストが試行された回数を正確にトラッキングするために試行回数を必要とします。ユーザーが権限リクエストを 2 回拒否すると、アプリケーション/SDK はそれ以上権限をリクエストできなくなります。つまり、権限をリクエストしても、ユーザーにリクエストダイアログが表示されることなく自動的に拒否されます。SDK としては、ユーザーが権限を拒否した回数を確実に把握できないため、試行回数に基づいて権限リクエストの呼び出しを最適化しようとします。

<CodeGroup>

```javascript JavaScript
var moe = MoECordova.init("YOUR_WORKSPACE_ID");
moe.updatePushPermissionRequestCountAndroid(requestCount)
```

</CodeGroup>

## 通知チャネルのセットアップ

アプリケーションが既にユーザーから通知の権限を取得している場合は、以下の API を呼び出して、プッシュ通知を表示するための通知チャネルをセットアップします。

<CodeGroup>

```javascript JavaScript
var moe = MoECordova.init("YOUR_WORKSPACE_ID");
moe.setupNotificationChannelsAndroid()
```

</CodeGroup>

## MoEngage SDK に通知の権限の処理を任せる

MoEngage SDK は、エンドユーザーに権限リクエストを表示したり、通知を有効にするための設定画面にユーザーを遷移させたりするためのヘルパー API を提供しています。

ユーザーに権限リクエストダイアログを表示するには、以下の API を使用します。

以下の API を使用すると、SDK は上記の応答のトラッキングや必要な通知チャネルのセットアップなどを自動的に行います。

<CodeGroup>

```javascript JavaScript
var moe = MoECordova.init("YOUR_WORKSPACE_ID");
moe.requestPushPermissionAndroid();
```

</CodeGroup>

## 通知設定への遷移（状況に応じて/オプション）

デバイス上のアプリケーションの通知設定にユーザーを遷移させるには、以下の API を使用します。

_注_：Android 8（API レベル 26）未満では、ユーザーはアプリケーションのアプリ情報画面に遷移します。

<CodeGroup>

```javascript JavaScript
var moe = MoECordova.init("YOUR_WORKSPACE_ID");
moe.navigateToSettingsAndroid();
```

</CodeGroup>

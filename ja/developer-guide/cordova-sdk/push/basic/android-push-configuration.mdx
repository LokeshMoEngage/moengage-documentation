## 基本設定

- **MoEngage ダッシュボードでの FCM セットアップ** - FCM 認証は、Android デバイスにインストールされたアプリへのプッシュ通知の送信を有効にする方法です。[この記事](/ja/developer-guide/android-sdk/push/basic/fcm-authentication)に記載されている方法を使用して、MoEngage が Firebase サービスにアクセスできるよう認証してください。

## プッシュトークンの受け渡し

<CodeGroup>

```javascript JavaScript
var moe = MoECordova.init(YOUR_WORKSPACE_ID);
moe.passFcmToken()
```

</CodeGroup>

## プッシュペイロードの受け渡し

<CodeGroup>

```javascript JavaScript
var moe = MoECordova.init(YOUR_WORKSPACE_ID);
moe.passFcmPayload()
```

</CodeGroup>

<Info>
  JavaScript からのペイロードとトークンの受け渡しは、Firebase Messaging Service でのみサポートされています。
</Info>

<Warning>
  プッシュペイロードを MoEngage SDK に渡す際は、Cordova/JavaScript API ではなく Android ネイティブ API を使用することを強くお勧めします。アプリケーションが強制終了された状態では Cordova エンジンが初期化されない場合があり、プッシュの到達率や配信率の低下につながります。
</Warning>

## プッシュ通知のカスタマイズ

必要に応じて、アプリケーションはネイティブ Android コード（Java/Kotlin）を使用して通知の動作をカスタマイズできます。カスタマイズの詳細については、[高度なプッシュ設定](/ja/developer-guide/android-sdk/push/advanced/callbacks-and-customisation)のドキュメントを参照してください。上記のドキュメントに記載されている **_PushMessageListener_** を継承する代わりに、**_PluginPushCallback._** を継承してください。

Push Amp+、プッシュテンプレート、ジオフェンスについては、以下のドキュメントを参照してください。

- [Push Amplification](/ja/developer-guide/android-sdk/push/optional/push-amplification) 
- [Push Amp Plus](/ja/developer-guide/android-sdk/push/optional/push-amp-plus/push-amp-plus-integration) 
- [プッシュテンプレート](/ja/developer-guide/android-sdk/push/optional/push-templates)
- [ジオフェンスプッシュ](/ja/developer-guide/android-sdk/push/optional/location-triggered)

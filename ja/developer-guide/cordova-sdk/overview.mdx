MoEngage Cordova プラグインは、ネイティブの Android および iOS SDK をラップし、JavaScript のコードから利用できるようにします。イベントとユーザー属性をトラッキングし、両方のプラットフォームでプッシュトークンを登録し、アプリ内メッセージを表示します。

まず [Cordova SDK の統合](/ja/developer-guide/cordova-sdk/sdk-integration/overview)からプラグインを追加して初期化し、その後必要なチャネルを追加してください。

以下の API を使用すると、ユーザーが与えた同意に基づいて、MoEngage SDK がトラッキングする内容を制御できます。

## データトラッキングの有効化または無効化

SDK によるカスタムイベントとユーザー属性のトラッキングを停止するには、データトラッキングをオプトアウトします。再度オプトインするまで、SDK はすべてのイベントとユーザー属性を拒否します。データトラッキングはデフォルトで有効になっています。

<CodeGroup>

```javascript JavaScript
var moe = MoECordova.init(YOUR_WORKSPACE_ID);
moe.optOutDataTracking(true);  // Stop tracking events and user attributes
moe.optOutDataTracking(false); // Resume tracking events and user attributes
```

</CodeGroup>

## SDK の有効化または無効化

SDK によるユーザー情報のトラッキングや MoEngage へのデータ送信をすべて停止するには、`disableSdk()` を呼び出します。

<CodeGroup>

```javascript JavaScript
var moe = MoECordova.init(YOUR_WORKSPACE_ID);
moe.disableSdk();
```

</CodeGroup>

`enableSdk()` を呼び出すまで、すべての SDK API は動作しません。SDK はデフォルトで有効になっているため、`enableSdk()` は以前に SDK を無効にした場合にのみ呼び出してください。

<CodeGroup>

```javascript JavaScript
var moe = MoECordova.init(YOUR_WORKSPACE_ID);
moe.enableSdk();
```

</CodeGroup>

## ユーザーデータの削除

MoEngage サーバーから現在のユーザーのプロファイルを削除するには、[MoEngage サーバーからのユーザーの削除](/ja/developer-guide/cordova-sdk/data-tracking/delete-user-from-moengage-server)を参照してください。

---
title: "MoEngage サーバーからのユーザーの削除"
description: "Android で Cordova SDK を使用して、MoEngage サーバーから現在のユーザーを削除します。"
---

<Info>
この API は **cordova-moengage-core** バージョン **8.4.0** 以降でサポートされており、Android プラットフォームでのみ利用可能です。その他のプラットフォームでは何も実行されません。
</Info>

MoEngage サーバーから現在のユーザーを削除するには、以下のように ***deleteUser()*** メソッドを使用します。

<CodeGroup>
```javascript JavaScript
var moe = MoECordova.init(YOUR_WORKSPACE_ID);      
moe.deleteUser().then(result => 
//add your code to handle the callback
console.log("User Deletion Result",result.toString())
).catch(error => 
//add your code to handle the Error
console.error("Error while Deleting User",error.toString())
);
```

</CodeGroup>

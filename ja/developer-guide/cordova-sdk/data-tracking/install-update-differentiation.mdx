---
title: "インストール/アップデートの区別"
description: "移行トラッキングのために、MoEngage Cordova SDK でアプリのステータスをインストールまたはアップデートとして設定します。"
---

これは MoEngage プラットフォームへの移行時にのみ必要です。ユーザーがアプリの新規ユーザー（初回インストール）なのか、最新バージョンにアップデートした既存ユーザーなのかを SDK に伝える必要があります。

インストール/アップデートをトラッキングするには、以下のように **setAppStatus** メソッドを使用します。

<CodeGroup>
```javascript JavaScript
var moe = MoECordova.init(YOUR_WORKSPACE_ID);
// For fresh Install
moe.setAppStatus("INSTALL");
// For tracking App Update
moe.setAppStatus("UPDATE");
```

</CodeGroup>

# MoEngage プラグインの追加

以下のように、Cordova プロジェクトに **cordova-moengage-core** プラグインを追加します。

<CodeGroup>

```Shell Shell
$ cordova plugin add cordova-moengage-core
```

</CodeGroup>

プラグインをインストールした後、以下のプラットフォーム固有の設定を行います。

- [Android SDK のインストール](/ja/developer-guide/cordova-sdk/sdk-integration/sdk-installation/android-sdk-installation) 
- [iOS SDK のインストール](/ja/developer-guide/cordova-sdk/sdk-integration/sdk-installation/ios-installation)

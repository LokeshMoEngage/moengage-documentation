# Cordova コンポーネントの初期化

アプリケーションの **_index.js_** 内の **_onDeviceReady()_** で \*\*\*MoECordova.init()\*\*\*を呼び出して、MoEngage プラグインを初期化します。

<CodeGroup>

```javascript JavaScript
var moe = MoECordova.init("YOUR_WORKSPACE_ID");
```

</CodeGroup>

プラットフォーム固有の初期化については、以下を参照してください。

- [Android](/ja/developer-guide/cordova-sdk/sdk-integration/sdk-initialization/android-sdk-initialization) 
- [iOS](/ja/developer-guide/cordova-sdk/sdk-integration/sdk-initialization/ios-sdk-initialization)

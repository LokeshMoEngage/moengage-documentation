---
title: "制限事項"
description: "MoEngage Cordova プラグインを使用する際の、サポートされていない機能とネイティブ統合の要件を確認します。"
---

ネイティブの Android/iOS SDK と比較して、Cordova プラグインを使用する場合、サポートされていない機能や、ネイティブの Android/iOS 実装が必要な機能がいくつかあります。

# サポートされていない機能

* Nudge
* iOS 通知のアクションボタン

# サポートされているがネイティブ統合が必要な機能

* Inbox モジュール
* Cards モジュール

MoEngage Cordova プラグインの統合は 2 つのステップで行います。`cordova-moengage-core` プラグインとそのネイティブの依存関係を追加し、その後 JavaScript と各ネイティブプラットフォームで SDK を初期化します。

## SDK のインストール

| ページ | 内容 |
| --- | --- |
| [フレームワークの依存関係](/ja/developer-guide/cordova-sdk/sdk-integration/sdk-installation/framework-dependency) | `cordova-moengage-core` プラグインを追加し、プラットフォームの設定を構成します。 |
| [Android SDK のインストール](/ja/developer-guide/cordova-sdk/sdk-integration/sdk-installation/android-sdk-installation) | BOM または手動設定を使用して、Android SDK の依存関係を追加します。 |
| [iOS のインストール](/ja/developer-guide/cordova-sdk/sdk-integration/sdk-installation/ios-installation) | CocoaPods を使用して iOS SDK をインストールします。 |

## SDK の初期化

| ページ | 内容 |
| --- | --- |
| [フレームワークの初期化](/ja/developer-guide/cordova-sdk/sdk-integration/sdk-initialization/framework-initialization) | `MoECordova.init()` でプラグインを初期化します。 |
| [Android SDK の初期化](/ja/developer-guide/cordova-sdk/sdk-integration/sdk-initialization/android-sdk-initialization) | Android アプリケーションの `onCreate` で SDK を初期化します。 |
| [iOS SDK の初期化](/ja/developer-guide/cordova-sdk/sdk-integration/sdk-initialization/ios-sdk-initialization) | iOS アプリケーションのコードで SDK を初期化します。 |

<Note>
  統合を計画する前に、[制限事項](/ja/developer-guide/cordova-sdk/sdk-integration/limitations) を確認してください。一部の機能はサポートされていないか、ネイティブでの実装が必要です。
</Note>

MoEngage Web SDK は、JavaScript スニペットとして Web サイト上で動作します。訪問者の属性とイベントをトラッキングし、ブラウザーを Web プッシュに登録し、オンサイトメッセージやカードを表示します。

まず [Web SDK の統合](/ja/developer-guide/web-sdk/web-sdk-integration/overview)から SDK を追加して初期化し、その後必要なチャネルを追加してください。

## トラブルシューティング

### プッシュ通知が届かない場合

Chrome、Firefox、Opera、Edge、または Safari のプッシュで問題が発生している場合は、ご利用の環境が以下の最小バージョン要件を満たしていることを確認してください。

<AccordionGroup>
  <Accordion icon="chrome" title="Chrome プッシュ">
    **Chrome (バージョン 42 以降)** で以下の環境がサポートされています。

    - MacOS
    - Windows (デスクトップのみ)
    - Linux
    - Android
  </Accordion>
  <Accordion icon="firefox" title="Firefox プッシュ">
    **Firefox (バージョン 44 以降)** で以下の環境がサポートされています。

    - MacOS
    - Windows (デスクトップのみ)
    - Linux
    - Android
  </Accordion>
  <Accordion icon="opera" title="Opera プッシュ">
    **Opera (バージョン 37 以降)** で以下の環境がサポートされています。

    - MacOS
    - Windows (デスクトップのみ)
    - Linux
    - Android
  </Accordion>
  <Accordion icon="edge" title="Edge プッシュ">
    **Edge (バージョン 17 以降)** で以下の環境がサポートされています。

    - MacOS
    - Windows (デスクトップのみ)
    - Linux
    - Android
  </Accordion>
  <Accordion icon="safari" title="Safari プッシュ">
    以下の環境でサポートされています。

    - **MacOS (バージョン 13 以降)** と **Safari (バージョン 16 以降)**
    - **iOS (バージョン 16.4 以降)**
  </Accordion>
</AccordionGroup>


さらにサポートが必要な場合は、MoEngage のカスタマーサクセスマネージャー (CSM) またはサポートチームにお問い合わせください。

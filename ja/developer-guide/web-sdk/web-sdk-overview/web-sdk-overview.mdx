Web SDK の統合では、以下のモジュールがサポートされています。

## サポートされているモジュール

<CardGroup cols={2}>
  <Card icon="bell" title="Web プッシュ">
    許可ベースのメッセージで、ユーザーが Web サイトにアクセスしているかどうかに関係なく送信されます。
  </Card>
  <Card icon="chart-mixed" title="分析">
    ブランドで活用するためのユーザーに関するあらゆるデータ収集です。代表的なユースケースは、メッセージのパーソナライズや行動に基づくユーザーのセグメント化です。
  </Card>
  <Card icon="message-dots" title="オンサイトメッセージング">
    ユーザーが Web サイトにアクセスしているときに送信されるメッセージです。このモジュールでは、ユーザーの許可は必要ありません。
  </Card>
  <Card icon="user-gear" title="Web サイトのパーソナライゼーション">
    Web サイトにパーソナライゼーションを組み込み、シームレスでエンドユーザーに合わせた体験を提供します。
  </Card>
  <Card icon="bolt" title="AMP">
    モバイルデバイスで Web ページを瞬時に読み込めるようにする、オープンソースの Web フレームワークコンポーネントです。
  </Card>
</CardGroup>

## 統合手順

### 共通の統合手順

次の手順は、すべてのモジュールに共通する基本手順として必要です。

| モジュール                             | 統合手順                                                                 |
| :--------------------------------- | :-------------------------------------------------------------------------------- |
| すべてのモジュールに共通の統合 | [WEB SDK \> SDK Integration](/ja/developer-guide/web-sdk/web-sdk-integration/basic-integration/web-sdk-integration) |

### チャネル固有の統合手順

共通の統合が完了したら、選択したモジュールに固有の手順に従います。

| モジュール                      | 統合手順                                                                      |
| :-------------------------- | :------------------------------------------------------------------------------------- |
| **Web プッシュ**                | [WEB SDK -\> Web Push](/ja/developer-guide/web-sdk)                       |
| **データトラッキング**           | [WEB SDK -\> Data Tracking](/ja/developer-guide/web-sdk/data-tracking/web-sdk-data-tracking-introduction)             |
| **オンサイトメッセージング**       | [WEB SDK -\> Onsite Messaging](/ja/user-guide/campaigns-and-channels/on-site-message/getting-started-with-on-site-message/portfolio-for-on-site-messaging)       |
| **Web サイトのパーソナライゼーション** | [WEB SDK -\> Web Personalization](/ja/user-guide/campaigns-and-channels/web-personalization/getting-started-with-web-personalization/introduction) |

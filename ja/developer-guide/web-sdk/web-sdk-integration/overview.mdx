MoEngage Web SDK の統合は 1 つのページから始まります。SDK スニペットをサイトに追加して初期化してください。**高度な統合**のページでは、Content Security Policy、Cookie、プライバシー管理など、その後ほとんどのサイトで必要になる設定について説明します。

## 基本的な統合

| ページ | 内容 |
| --- | --- |
| [Web SDK の統合](/ja/developer-guide/web-sdk/web-sdk-integration/basic-integration/web-sdk-integration) | スクリプトベースまたは手動の初期化を使用して SDK を統合します。 |

## 高度な統合

| ページ | 内容 |
| --- | --- |
| [Content Security Policy (CSP) Nonce のサポート](/ja/developer-guide/web-sdk/web-sdk-integration/advanced-integration/content-security-policy-csp-nonce-support) | 厳格な Content Security Policy の下で SDK を実行します。 |
| [カスタムプロキシドメイン - Web](/ja/developer-guide/web-sdk/web-sdk-integration/advanced-integration/custom-proxy-domain-web) | 広告ブロッカーを回避するため、SDK のトラフィックを独自のサブドメイン経由でルーティングします。 |
| [Web SDK で使用される Cookie](/ja/developer-guide/web-sdk/web-sdk-integration/advanced-integration/cookies-used-by-web-sdk) | デバイスとセッションのトラッキングに使用されるファーストパーティ Cookie を確認します。 |
| [ボットトラフィックのブロック](/ja/developer-guide/web-sdk/web-sdk-integration/advanced-integration/bot-traffic-blocking) | ボットやクローラーのトラフィックを分析と請求から除外します。 |
| [Web SDK のライフサイクルコールバック](/ja/developer-guide/web-sdk/web-sdk-integration/advanced-integration/web-sdk-lifecycle-callbacks) | 初期化と設定取得のイベントをリッスンします。 |
| [Web SDK のオプトアウト](/ja/developer-guide/web-sdk/web-sdk-integration/advanced-integration/web-sdk-opt-out) | SDK を無効にしてトラッキングを停止し、プライバシー設定を尊重します。 |
| [デバッグモード](/ja/developer-guide/web-sdk/web-sdk-integration/advanced-integration/debugging-mode) | ブラウザーコンソールでデバッグログを有効にします。 |

title: "ボットトラフィックのブロック"
description: "ユーザーエージェントによるフィルタリングを使用して、ボットやクローラーのトラフィックが MoEngage の分析や請求に影響しないようにブロックします。"
---

ボットからのトラフィックは DAU/MAU や請求に影響を与える可能性があるため、MoEngage はそのようなトラフィックをすべて防止するよう努めています。ボットによって、実際のユーザーが行っていない Web アクティビティが発生し、その結果 DAU や MAU が高くなります。

クローラー、スパイダー、検索エンジンボットなどのボットは、インターネット上のあらゆる Web サイトからコンテンツをダウンロードしてインデックスを作成します。MoEngage は、ユーザーエージェントによるフィルタリング方式を使用して、ボットがその機能を使用するのを防ぎ、ボットトラフィックをブロックします。

## 統合の変更

追加のボットをブロックするには、[統合](/ja/developer-guide/web-sdk/web-sdk-integration/basic-integration/web-sdk-integration)時に `bots_list: ["bot_name"]` キーを更新します。

ブロックしたいボットの識別子を含む文字列の配列を指定します。各文字列は一意のボット識別子です。識別子には次のものを指定できます。

- 完全な **userAgent**
- 特定の**部分文字列**

次のコードのように、複数のボットを処理できます。

<CodeGroup>

```javascript JavaScript wrap
Moengage = moe({
  appId: moeAppID,
  botsList: ["bot_name1","bot_name2","bot_name3"],
});
```

</CodeGroup>

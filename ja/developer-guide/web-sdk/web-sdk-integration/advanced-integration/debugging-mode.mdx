---
title: "デバッグモード"
description: "MoEngage Web SDK でデバッグログを有効にし、ブラウザコンソールで統合の問題をトラブルシューティングします。"
---

SDK は、デバッグモードで多くの有用な情報をログに記録します。このモードは、**Test** 環境で SDK を読み込むと自動的に有効になります。

ただし、**Live** 環境でこれらのログを表示するには、ブラウザのデベロッパーツールの **Console** セクションで次のコマンドを入力します。

<CodeGroup>

```javascript JavaScript
Moengage.setDebugLevel(2)
```

</CodeGroup>

これを有効にすると、誤った統合のデバッグに役立つ詳細なログを、わかりやすく色分けされた形式で確認できます。

![Debug](/images/Debug.png)

## 複数の統合

SDK が Web サイトに複数回追加されている場合、SDK が予期しない動作をすることがあります。この状況が発生し、デバッグモードが有効になっている場合、ブラウザコンソールに次のエラーメッセージが表示されます。

`MoEngage Web SDK initialised multiple times. Please integrate the Web SDK only once!`

<Note>
  このエラーメッセージは、ドキュメントに記載されている最新の SDK 統合コードを使用している場合にのみ表示されます。
</Note>

<Info>
  **MoEngage Web SDK は、サードパーティ Cookie を使用またはトラッキングしません。**
</Info>

ファーストパーティ Cookie のみを使用し、使用するのは次の場合に限られます。

| Cookie 名 | 説明 |
| :-- | :-- |
| `moe_uuid` | デバイス ID が含まれます。AMP 統合の場合にも使用されます。 |

クロスサブドメイントラッキングが有効になっている場合は、次の Cookie が使用されます。

| Cookie 名 | 説明 |
| :-- | :-- |
| `moe_u_d` | デバイス ID、isDeviceAdded などのユーザーの詳細が含まれます。 |
| `moe_s_a_s` | Web Push 権限の Soft Ask のステータス |
| `moe_s_n` | ユーザーのセッションとソースの詳細が含まれます。 |
| `moe_o_s_t` | 通知のオプトインが表示された時刻 |
| `moe_h_a_s` | Web Push 権限のハードアスクのステータス |
| `moe_s_d` | プッシュ購読に関連する詳細が含まれます。 |
| `moe_d_d` | ユーザーのデバイス固有 ID が含まれます。 |
| `moe_c_s` | アカウントでクロスサブドメインのユーザー共有が有効になっているかどうかを示します。 |
| `moe_i_m` | ユーザーの現在および以前の ID（存在する場合）が含まれます。 |
| `moe_dis` | SDK が無効になっているかどうかを示します。 |
| `moe_dt_d` | データトラッキングが無効になっているかどうかを示します。 |

<Note>
  MoEngage Web SDK の Cookie は、設定されてから 2 年後に有効期限が切れます。
</Note>

## すべての Cookie を無効にする

MoEngage SDK に Cookie を設定または使用させたくない場合は、[SDK の初期化](/ja/developer-guide/web-sdk/web-sdk-integration/basic-integration/web-sdk-integration)時に次のように `disableCookies` を渡します。

<CodeGroup>

```javascript JavaScript wrap
Moengage = moe({
  appId: moeAppID,
  env: 'LIVE',
  logLevel: 0,
  disableCookies: true,
});
```

</CodeGroup>

<Warning>
  **クロスサブドメインのユーザートラッキングを有効にしている場合、Cookie を無効にするとその機能は動作しません。**
</Warning>

---
title: "その他の Web フレームワークとの統合"
description: "MoEngage Web SDK を React JS、Angular、またはその他の Web フレームワークと統合します。"
---

MoEngage Web SDK はいかなるフレームワークにも依存せず、また使用もしていないため、どの Web フレームワークとも統合できます。

React JS と Angular 向けの Web SDK 統合のサンプルコードについて、以下で説明します。

# React JS

index.html ファイルに SDK のコードを含めます。

サンプルコードの詳細については、[React のサンプルコード](https://github.com/moengage/webSDK-sample/blob/master/react-sample)を参照してください。

# Angular

index.html ファイルに SDK のコードを含めます。

サンプルコードの詳細については、[Angular のサンプルコード](https://github.com/moengage/webSDK-sample/tree/master/angular-sample)を参照してください。

さらにサポートが必要な場合は、MoEngage のカスタマーサクセスマネージャー (CSM) またはサポートチームにお問い合わせください。

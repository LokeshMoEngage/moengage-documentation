## シングルページアプリ (SPA) のサポート

Web サイトがシングルページアプリケーション (SPA) の場合、ページ全体が再読み込みされないため、デフォルトでは MoEngage SDK はルート変更時に `MOE_PAGE_VIEWED` イベントをトラッキングしません。

ルートが変更されるたびに `MOE_PAGE_VIEWED` イベントをトラッキングするには、[初期化](/ja/developer-guide/web-sdk/web-sdk-integration/basic-integration/web-sdk-integration)時に `enableSPA: true` を渡します。

<CodeGroup>

```javascript JavaScript lines wrap
Moengage = moe({
  appId: moeAppID,
  env: 'LIVE',
  logLevel: 0,
  enableSPA: true
});
```

</CodeGroup>

## カスタムアプローチ

`MOE_PAGE_VIEWED` を独自にトラッキングしたい場合 (ページの変更だけでなく、ログインポップアップを開くなどの一部の機能でもルートが変更される場合など) は、`MOE_PAGE_VIEWED` イベントをトラッキングしたいタイミングで `Moengage.trackPageView()` を使用してください。

## プログレッシブ Web アプリ (PWA)

プログレッシブ Web アプリ (PWA) は、Service Worker、マニフェスト、その他の Web プラットフォーム機能をプログレッシブエンハンスメントと組み合わせて使用し、ネイティブアプリと同等の体験をユーザーに提供する Web アプリです。

#### ブラウザのサポート

2023 年 1 月現在、Chrome と Edge の Web ブラウザ、および Opera Mini を除くすべてのモバイルブラウザでサポートされており、Safari iOS では部分的にサポートされています。\
参考: ["PWA" | Can I use... Support tables for HTML5, CSS3, etc](https://caniuse.com/?search=PWA)

#### MoEngage WebSDK のサポート

すべての機能はそのまま動作します。Web Push については、Web プッシュ通知を受信するために、PWA のインストールに使用したブラウザが開いたままになっているか、バックグラウンドで実行されている必要があります。

サンプルコードは[こちら](https://github.com/moengage/webSDK-sample/tree/master/pwa "https://github.com/moengage/webSDK-sample/tree/master/pwa")に追加されています。

さらにサポートが必要な場合は、MoEngage のカスタマーサクセスマネージャー (CSM) またはサポートチームにお問い合わせください。

Web SDK を統合した後、最初の Web Push キャンペーンを送信します。

Web SDK を統合するための前提条件は次のとおりです。

* [Web Push 設定を構成](https://www.moengage.com/docs/user-guide/campaigns-and-channels/web-push/getting-started-with-web-push/configure-web-push-settings)していること。
* アクティブな [Web Push キャンペーン](https://www.moengage.com/docs/user-guide/campaigns-and-channels/web-push/create/create-web-push-campaign)があること。

Web Push キャンペーンを送信した後、次のことができます。

* [データトラッキング](/ja/developer-guide/web-sdk/data-tracking)を実行する。
* [Web プッシュ通知の権限](/ja/developer-guide/web-sdk/web-push/configure-self-handled-opt-in)を変更する。

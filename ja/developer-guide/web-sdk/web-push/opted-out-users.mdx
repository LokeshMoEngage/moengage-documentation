  データトラッキングのためのオプションの手順です。
</Info>

MoEngage は、プッシュ通知にオプトインしたユーザーについてのみ行動データを提供します。オプトインファネルを最適化し、プッシュ通知の購読に同意またはブロックしたユーザー数の正確な統計を確認したい場合は、既存の分析ソリューションの一部としてトラッキングする必要があります。

これを実現するために、オプトインのコールバック操作イベントを公開しています。これらのイベントをリッスンすることで、独自の分析フローを使用してトラッキングできます。

## オプトイン操作コールバックの詳細リファレンス

イベントリスナーの構文

<CodeGroup>

```JavaScript JavaScript lines
window.addEventListener("MOE_OPT_IN",function(e){
  //Track events here
});
```

</CodeGroup>

イベント名は MOE_OPT_IN です。

イベントの種類は次のとおりです。

#### デフォルトのオプトイン操作イベント:

| イベント            | 説明                                           |
| ---------------- | ----------------------------------------------------- |
| opt_in_shown     | デフォルトのオプトインが表示された                                  |
| opt_in_allowed   | ユーザーが **_許可_** をクリックした                              |
| opt_in_blocked   | ユーザーが **_ブロック_** をクリックした                              |
| opt_in_dismissed | ユーザーがオプトインを閉じた（ダイアログボックスを閉じた） |

#### カスタムオプトイン（Soft-Ask）操作イベント:

| イベント            | 説明                     |
| ---------------- | ------------------------------- |
| soft_ask_shown   | カスタムオプトインが表示された             |
| soft_ask_allowed | ユーザーがオプトインを **_承認_** した |
| soft_ask_closed  | ユーザーがオプトインを **_閉じた_** |

さらにサポートが必要な場合は、MoEngage のカスタマーサクセスマネージャー（CSM）またはサポートチームにお問い合わせください。

Web プッシュには、サイト上の Service Worker と訪問者からのブラウザーの許可が必要です。まず概要でオーディエンスのブラウザーサポートを確認し、次に Service Worker を設定して、許可プロンプトの表示方法を決定してください。

| [Web プッシュの設定と統合](/ja/developer-guide/web-sdk/web-push/configure-and-integrate-web-push) | Service Worker と SDK の初期化を設定します。 |
| [セルフハンドルのオプトインの設定](/ja/developer-guide/web-sdk/web-push/configure-self-handled-opt-in) | ブラウザーの許可プロンプトを表示するタイミングと場所を制御します。 |

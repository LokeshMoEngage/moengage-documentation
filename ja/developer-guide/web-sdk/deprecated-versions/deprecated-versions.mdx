このページでは、MoEngage Web SDK の各バージョンのサポート状況を確認できます。最新のバージョン、引き続きサポートされているバージョン、非推奨のバージョンを、非推奨日とともに一覧表示しています。このページは、Web SDK のバージョンステータスに関する信頼できる唯一の情報源です。ライフサイクルの仕組みと、非推奨が統合に与える影響については、[SDK 非推奨ポリシー](/ja/developer-guide/sdk-lifecycle-and-policies/sdk-deprecation-policy)を参照してください。Web SDK をセットアップするには、[統合ガイド](/ja/developer-guide/web-sdk/web-sdk-overview/web-sdk-overview)を参照してください。

## バージョンのサポート状況

<Info>
  **Current (最新)** — 最新のバージョンです。新機能、修正、およびサポートが提供されます。

  **Supported (サポート対象)** — サポート期間内の古いバージョンです。引き続きサポートが提供されます。

  **Deprecated (非推奨)** — サポート期間を過ぎたバージョンです。修正やサポートは提供されなくなります。
</Info>

| バージョン | ステータス | 非推奨日 | 備考 |
| --- | --- | --- | --- |
| 2.78.x | Current | 未定 | 最新バージョン。新機能、修正、およびサポートが提供されます。 |
| 2.56.1 ～ 2.77.x | Supported | 未定 | サポートが提供されます。 |
| 2.56.0 以前 | Deprecated | 2027 年 8 月 | サポート、デバッグ、修正は提供されなくなります。データは引き続き送受信されます。最新バージョンにアップグレードしてください。 |

<Note>
  MoEngage は、各 SDK バージョンを初回リリースから 3 年間サポートし、その後の 8 月に非推奨となります。詳細については、[SDK 非推奨ポリシー — サポート期間](/ja/developer-guide/sdk-lifecycle-and-policies/sdk-deprecation-policy#support-window)を参照してください。この表は、MoEngage がさらなる非推奨を発表した際に更新されます。事前通知を受け取るには、SDK ニュースレターを購読し、ワークスペース管理者のメールアドレスが最新であることを確認してください。
</Note>

## 非推奨ステータスについて

非推奨のバージョンでも、データの送受信は引き続き行われます。MoEngage がトラフィックをブロックすることはありません。非推奨日以降、MoEngage はそのバージョン固有の問題のデバッグ、修正、サポートを行わなくなり、問題の解決策は最新バージョンへのアップグレードとなります。すべての修正は最新バージョンでのみ提供され、サポート対象バージョンや非推奨バージョンでは利用できません。ポリシーの全文については、[SDK 非推奨ポリシー](/ja/developer-guide/sdk-lifecycle-and-policies/sdk-deprecation-policy)を参照してください。

## サポート対象バージョンへのアップグレード

- 最新バージョンの変更点については、[Web SDK リリースノート](/ja/release-notes/sdks/web)を参照してください。
- サポートが必要な場合は、MoEngage のカスタマーサクセスマネージャー (CSM) またはサポートチームにお問い合わせください。

## よくある質問

<AccordionGroup>
  <Accordion title="非推奨になった後も非推奨バージョンを使い続けることはできますか?">
    非推奨バージョンを使用しているサイトは引き続き動作し、データも引き続き送受信されます。ただし、MoEngage は非推奨バージョンに対するサポート、デバッグ、修正を提供しなくなります。[Web SDK リリースノート](/ja/release-notes/sdks/web)を参照して最新バージョンまたはサポート対象バージョンにアップグレードすることで、継続的なサポートを受けることができます。
  </Accordion>
  <Accordion title="非推奨の事前通知はどのように受け取れますか?">
    MoEngage は、非推奨日の 6 ～ 12 か月前に、ワークスペース管理者へのメール、四半期ごとの SDK ニュースレター、ダッシュボード内の通知、および SDK リリースノートを通じて事前通知を送信します。通知スケジュールの詳細については、[SDK 非推奨ポリシー](/ja/developer-guide/sdk-lifecycle-and-policies/sdk-deprecation-policy)を参照してください。
  </Accordion>
</AccordionGroup>

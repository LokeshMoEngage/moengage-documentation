---
title: "Cards"
description: "MoEngage Cards をセットアップして、Web サイトでターゲットを絞った Inbox およびニュースフィードのメッセージを配信します。"
---

Cards を使用すると、ターゲットを絞った、または自動化された App Inbox/NewsFeed メッセージを作成できます。これらのメッセージはさまざまなカテゴリにグループ化でき、指定した期間 Inbox/フィードに表示され続けるさまざまな更新情報やオファーでユーザーをターゲットにできます。詳細については、[Cards](https://www.moengage.com/docs/user-guide/campaigns-and-channels/cards/create/create-a-card-campaign) を参照してください。

</Frame>

## SDK のインストール

以下に示すように、SDK の [初期化](https://www.moengage.com/docs/developer-guide/web-sdk/web-sdk-integration/basic-integration/web-sdk-integration) スクリプトで Cards の設定を渡します。

<CodeGroup>

```javascript JavaScript lines wrap
Moengage = moe({
    appId: moeAppID,
    env: 'LIVE',
  	logLevel: 0,
    cards: {
      enable: true,
      placeholder: '#cardIcon' // CSS selector of inbox icon 
    } 
  });
```

</CodeGroup>

`placeholder` は、クリックすると Inbox が開くアイコンです。このアイコンをご自身で用意し、DOM 内に存在することを確認してください。

## APIs

### 未クリック数

SDK には、ユーザーがクリックしていないカードの数を取得するための API が用意されています。数を取得するには、次の API を使用します。

<CodeGroup>

```javascript JavaScript lines wrap
<script type="text/javascript">
    Moengage.cards.getUnClickedCardCount().then(unclickedCardCount => {
    	console.log(unclickedCardCount); // unclickedCardCount is in Number format
    })
</script>
```

</CodeGroup>

### 新着カード数

SDK には、デバイス上のユーザーの新着カードを取得するための API が用意されています。数を取得するには、次の API を使用します。

<CodeGroup>

```javascript JavaScript lines wrap
<script type="text/javascript">
    Moengage.cards.getNewCardCount().then(newCardCount => {
    	console.log(newCardCount); // newCardCount is in Number format
    })
</script>
```

</CodeGroup>

## コールバック

SDK には、次のコールバックが用意されています。

### Inbox オープンコールバック

ユーザーが Inbox アイコンをクリックしたときと Inbox が開いたときにコールバックを受け取るには、以下に示すように setInboxOpenListener() メソッドにコールバック関数を登録します。

<CodeGroup>

```javascript JavaScript lines wrap
<script type="text/javascript">
    Moengage.cards.setInboxOpenListener(function(){
    	console.log('Inbox is opened.')
    })
</script>
```

</CodeGroup>

### Inbox クローズコールバック

ユーザーが Inbox を閉じたときにコールバックを受け取るには、以下に示すように setInboxCloseListener() メソッドにコールバック関数を登録します。

<CodeGroup>

```javascript JavaScript lines wrap
<script type="text/javascript">
    Moengage.cards.setInboxCloseListener(function(){
    	console.log('Inbox is closed.')
    })
</script>
```

</CodeGroup>

### カードクリックコールバック

ユーザーがカードをクリックしたときにコールバックを受け取るには、

setCardClickListener() メソッドにコールバック関数を登録します。

<CodeGroup>

```javascript JavaScript lines wrap
<script type="text/javascript">
    Moengage.cards.setCardClickListener(function(cardId){
    	console.log('Card clicked: ', cardId)
    })
</script>
```

</CodeGroup>

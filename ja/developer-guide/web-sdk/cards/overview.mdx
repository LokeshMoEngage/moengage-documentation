description: "MoEngage のカード UI または独自の UI を使用して、Web サイト上でインボックスやニュースフィードとして MoEngage のカードキャンペーンを配信します。"
keywords: ["web cards", "card campaigns", "self-handled cards", "inbox", "newsfeed"]
---

カードは、訪問者の操作を妨げることなく、通常はインボックスやニュースフィードとしてサイト内に表示される永続的なメッセージです。MoEngage のカード UI をそのまま使用することも、キャンペーンデータを取得して独自の UI を構築することもできます。

| ページ | 内容 |
| --- | --- |
| [カード](/ja/developer-guide/web-sdk/cards/cards) | ターゲットを絞ったインボックスやニュースフィードのメッセージを配信するようにカードをセットアップします。 |
| [セルフハンドルカード](/ja/developer-guide/web-sdk/cards/self-handled-cards) | カードキャンペーンのデータを取得し、カスタムのカード UI を構築します。 |

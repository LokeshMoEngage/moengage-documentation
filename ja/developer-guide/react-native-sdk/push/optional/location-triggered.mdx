# インストール

MoEngage Geofence SDK をアプリケーションに追加するには、ターミナルから以下のコマンドを実行します。

<CodeGroup>

```NPM npm
npm install react-native-moengage-geofence
```

</CodeGroup>

注: このプラグインは `react-native-moengage` プラグインに依存しています。`react-native-moengage` プラグインもインストールされていることを確認してください。

## Android でのインストール

<Info>
  位置情報トリガーのプッシュを動作させるには、アプリケーションが以下を満たしていることを確認してください。

  - 位置情報の権限
  - Play Services Location Library
  - デバイスの位置情報が有効になっていること
</Info>

## iOS でのインストール

新しい React アーキテクチャでアプリケーションを実行するには、以下の手順に従います。

1. iOS フォルダに移動します。
2. コマンド **_RCT_NEW_ARCH_ENABLED=1 bundle exec pod install_** を実行して、必要な依存関係をインストールします。

 古い React アーキテクチャでアプリケーションを実行するには、以下の手順に従います。

1. iOS フォルダに移動します。
2. コマンド **_pod install_** を実行して、必要な依存関係をインストールします。

# ジオフェンスの設定

デフォルトでは、ジオフェンス機能は有効になっていません。この機能を有効にするには、以下の API を呼び出します。

<CodeGroup>

```TypeScript TypeScript
import ReactMoEGeofence from 'react-native-moengage-geofence';
ReactMoEGeofence.startGeofenceMonitoring(YOUR_WORKSPACE_ID);
```

</CodeGroup>

ジオフェンスのモニタリングまたは機能をいつでも停止したい場合は、以下の API を使用します。この API は既存のジオフェンスを削除します。

<CodeGroup>

```TypeScript TypeScript
import ReactMoEGeofence from 'react-native-moengage-geofence';
ReactMoEGeofence.stopGeofenceMonitoring(YOUR_WORKSPACE_ID);
```

</CodeGroup>

React Native のプッシュはプラットフォームごとに設定します。Android では Firebase の認証情報とランタイム権限、iOS では APNS 証明書とエンタイトルメントを設定します。**基本**のページでは、両方の設定に加えて、JavaScript でトークンとクリックを受け取るためのコールバックについて説明します。

iOS では、リッチメディアとインプレッショントラッキングのために通知拡張機能も必要です。

---
title: "インストール/アップデート"
description: "MoEngage の setAppStatus を使用して、React Native アプリでアプリのインストールとアップデートを区別します。"
---

統合時にアプリがすでに App Store で公開されている場合、MoEngage はアプリの更新が実際の UPDATE（アップデート）なのか INSTALL（インストール）なのかを把握する必要があります。

インストールとアップデートを区別するロジックを用意し、以下のように `setAppStatus()` メソッドを使用してトラッキングしてください。

<CodeGroup>
```javascript JavaScript
import ReactMoE, {
  MoEAppStatus,
} from "react-native-moengage";
//For Fresh Install of App
ReactMoE.setAppStatus(MoEAppStatus.Install);
 // For Existing user who has updated the app
ReactMoE.setAppStatus(MoEAppStatus.Update);
```

</CodeGroup>

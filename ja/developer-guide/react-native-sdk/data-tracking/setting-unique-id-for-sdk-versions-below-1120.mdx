# ログイン/ログアウトの実装

- ユーザーがアプリにログインしたときに、ユーザー属性 Unique ID を設定することが重要です。
- これにより、既存のユーザーが存在する場合は新しいユーザーと既存のユーザーがマージされ、不要なユーザーや古いユーザーの作成を防ぐことができます。
- Unique ID の設定は、デバイス間、インストール/アンインストール間、およびすべてのプラットフォーム（iOS、Android、Windows、Web）間でユーザーを紐付けるための重要な要素です。ユーザーが**ログイン**したらすぐに **USER_ATTRIBUTE_UNIQUE_ID** 属性を設定してください。Unique ID には、メール ID、（一意の）ユーザー名、データベース ID、またはバックエンドで生成された任意の ID などを使用できます。
- ログインしていないユーザーには設定しないでください。

## ユーザーのログイン

<CodeGroup>

```javascript JavaScript
import ReactMoE from 'react-native-moengage'
ReactMoE.setUserUniqueID("abc@xyz.com");
```

</CodeGroup>

## ユーザーのログアウト

ユーザーがアプリケーションからログアウトするたびに、アプリケーションは MoEngage SDK に通知する必要があります。SDK に通知するには、ユーザーがアプリケーションからログアウトするたびに API を呼び出します。

<CodeGroup>

```javascript JavaScript
import ReactMoE from 'react-native-moengage'
ReactMoE.logout();
```

</CodeGroup>

## ユーザー属性 Unique ID の更新

ユーザー属性 Unique ID を更新するには、異なる値で \*setUniqueId()\* を使用するのではなく、**_setAlias()_** メソッドを使用してください。新しい値で **_setUniqueId()_** メソッドを使用すると、MoEngage に意図しないユーザーが作成されます。

<CodeGroup>

```JavaScript JavaScript
import ReactMoE from 'react-native-moengage'
ReactMoE.setAlias("asd@xyz.com");
```

</CodeGroup>

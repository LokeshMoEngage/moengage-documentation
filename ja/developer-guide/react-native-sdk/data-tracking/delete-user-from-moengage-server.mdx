---
title: "MoEngage サーバーからのユーザー削除"
description: "Android で React Native SDK を使用して、MoEngage サーバーから現在のユーザーを削除します。"
---

<Info>
  この API は **react-native-moengage** バージョン **8.6.0** 以降でサポートされており、Android プラットフォームでのみ利用可能です。その他のプラットフォームでは何も実行されません。
</Info>

MoEngage サーバーから現在のユーザーを削除するには、以下のように **_deleteUser()_** メソッドを使用します。**_UserDeletionData_** のインスタンスが返されます。

<CodeGroup>

```javascript TypeScript
import ReactMoE from 'react-native-moengage';
      
// Below method will return an instance of UserDeletionData
const userDeletionData = await ReactMoE.deleteUser();
```

</CodeGroup>

## UserDeletionData

以下は、API/メソッドを呼び出したときに返されるモデルです。

<CodeGroup>

```typescript TypeScript

/**
 * Delete User State Data while deleting the user from MoEngage SDK
 * @since 8.6.0
 */
class UserDeletionData {

    /**
     * Account Data, instance of { MoEAccountMeta }
     * @since 8.6.0
     */
    accountMeta: MoEAccountMeta;

    /**
     * User State, true if user delete succeeded else false
     * @since 8.6.0
     */
    isSuccess: boolean;
}
```

</CodeGroup>

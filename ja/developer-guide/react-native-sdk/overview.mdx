MoEngage React Native プラグインは、ネイティブの Android および iOS SDK をラップし、JavaScript または TypeScript のコードから利用できるようにします。イベントとユーザー属性をトラッキングし、両方のプラットフォームでプッシュトークンを登録し、アプリ内メッセージやカードを表示します。

まず [React Native SDK の統合](/ja/developer-guide/react-native-sdk/sdk-integration/overview)からプラグインをインストールして初期化し、その後必要なチャネルを追加してください。

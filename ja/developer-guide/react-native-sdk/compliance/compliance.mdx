ユーザーが与えた同意に基づいて MoEngage SDK がトラッキングする内容を制御するには、以下の API を使用します。

## データトラッキングの有効化または無効化

SDK によるカスタムイベントおよびユーザー属性のトラッキングを停止するには、`disableDataTracking()` を呼び出します。

<CodeGroup>

```javascript JavaScript
import ReactMoE from 'react-native-moengage';
ReactMoE.disableDataTracking();
```

</CodeGroup>

`enableDataTracking()` を呼び出すまで、SDK はすべてのイベントとユーザー属性を拒否します。データトラッキングはデフォルトで有効になっています。

<CodeGroup>

```javascript JavaScript
import ReactMoE from 'react-native-moengage';
ReactMoE.enableDataTracking();
```

</CodeGroup>

## SDK の有効化または無効化

SDK によるユーザー情報のトラッキングや MoEngage へのデータ送信をすべて停止するには、`disableSdk()` を呼び出します。

<CodeGroup>

```javascript JavaScript
import ReactMoE from 'react-native-moengage';
ReactMoE.disableSdk();
```

</CodeGroup>

`enableSdk()` を呼び出すまで、すべての SDK API は動作しません。SDK はデフォルトで有効になっているため、`enableSdk()` は以前に SDK を無効化した場合にのみ呼び出してください。

<CodeGroup>

```javascript JavaScript
import ReactMoE from 'react-native-moengage';
ReactMoE.enableSdk();
```

</CodeGroup>

## ユーザーデータの削除

MoEngage サーバーから現在のユーザーのプロファイルを削除するには、[MoEngage サーバーからのユーザー削除](/ja/developer-guide/react-native-sdk/data-tracking/delete-user-from-moengage-server)を参照してください。

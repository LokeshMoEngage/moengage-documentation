# Cards プラグインの初期化

コンポーネントがマウントされた後に Cards プラグインを初期化します。

<CodeGroup>
```typescript TypeScript
import ReactMoEngageCards from "react-native-moengage-cards";
ReactMoEngageCards.initialize(YOUR_WORKSPACE_ID);
```

</CodeGroup>

<Info>
プラットフォーム固有の初期化は必要ありません。
</Info>

カードは、通常は受信トレイやニュースフィードとしてアプリ内に表示され続けるメッセージです。Cards プラグインはメインの React Native プラグインとは別に提供されるため、何かを表示する前にインストールして初期化してください。

## インストール

| ページ | 内容 |
| --- | --- |
| [フレームワークの依存関係](/ja/developer-guide/react-native-sdk/cards/installation/framework-dependency) | npm を使用して Cards プラグインをインストールします。 |
| [Android](/ja/developer-guide/react-native-sdk/cards/installation/android) | Cards プラグインの Android 依存関係を設定します。 |
| [iOS](/ja/developer-guide/react-native-sdk/cards/installation/ios) | CocoaPods または Swift Package Manager を使用して iOS 依存関係を設定します。 |

| [セルフハンドルカード](/ja/developer-guide/react-native-sdk/cards/self-handled-cards) | セルフハンドルカードの API を使用して、カスタムのカードビューを構築します。 |
| [Cards データペイロード](/ja/developer-guide/react-native-sdk/cards/cards-data-payload) | Cards SDK が返すデータモデルとペイロードの構造です。 |

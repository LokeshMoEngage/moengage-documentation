npm パッケージマネージャーを使用して、MoEngage の Cards プラグインをアプリケーションにインストールします。 

![Download](https://badge.fury.io/js/react-native-moengage-cards.svg?style=flat)

<CodeGroup>

```shell Shell
$ npm install react-native-moengage-cards
```

</CodeGroup>

プラグインをインストールした後、以下のプラットフォーム固有の設定を行います。

- [Android](/ja/developer-guide/react-native-sdk/cards/installation/android)
- [iOS](/ja/developer-guide/react-native-sdk/cards/installation/ios)

<Warning>
  このプラグインは `react-native-moengage` プラグインに依存しています。`react-native-moengage` プラグインもインストールされていることを確認してください。詳細については、[ドキュメント](/ja/developer-guide/react-native-sdk/sdk-integration/react-native/sdk-installation/framework-dependency)を参照してください。
</Warning>

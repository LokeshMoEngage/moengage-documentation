---
title: "iOS"
description: "アーキテクチャのサポートを含め、MoEngage React Native Cards プラグインの iOS 依存関係を設定します。"
---

バージョン 3.0.0 以降、Turbo アーキテクチャをサポートしています。

新しい React アーキテクチャでアプリケーションを実行するには、次の手順に従います。

1. iOS フォルダーに移動します。
2. コマンド ***RCT\_NEW\_ARCH\_ENABLED=1 bundle exec pod install*** を実行して、必要な依存関係をインストールします。

従来の React アーキテクチャでアプリケーションを実行するには、次の手順に従います。

1. iOS フォルダーに移動します。
2. コマンド ***pod install*** を実行して、必要な依存関係をインストールします。

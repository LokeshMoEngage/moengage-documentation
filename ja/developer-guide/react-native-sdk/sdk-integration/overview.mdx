MoEngage React Native プラグインの統合は 2 つのステップで行います。プラグインとそのネイティブ依存関係をインストールし、次に SDK を初期化します。プロジェクトに合ったパス（**React Native** または **Expo**）を選択してください。

初期化には 2 つの方法があります。ファイルベースの初期化では構成をネイティブの構成ファイルに保持し、手動の初期化では各プラットフォームのコードで構成を設定します。

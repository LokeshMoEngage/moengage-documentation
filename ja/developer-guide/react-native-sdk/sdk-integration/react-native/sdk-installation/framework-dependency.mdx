npm パッケージマネージャーを使用して、MoEngage React Native プラグインをインストールします。

次のコードを使用して、ネイティブの依存関係をリンクします。

<CodeGroup>

```shell Shell

    $ npm install react-native-moengage
    # required only if you are using versions that do not support auto linking
    # This command is removed in version 0.69 of react-native
    $ react-native link react-native-moengage
```

</CodeGroup>

<Info>
  動作するサンプルアプリは[こちら](https://github.com/moengage/React-Native/tree/master/SampleApp)にあります。
</Info>

プラグインをインストールしたら、以下のプラットフォーム固有の設定を行います。

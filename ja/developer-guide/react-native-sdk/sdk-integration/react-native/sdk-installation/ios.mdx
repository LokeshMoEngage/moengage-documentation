---
title: "iOS"
description: "Turbo アーキテクチャをサポートする MoEngage React Native SDK 用に、iOS の依存関係を設定します。"
---

<Info>
  最近の [CocoaPods Specs Repo の非推奨化](https://blog.cocoapods.org/CocoaPods-Specs-Repo/)に伴い、プロジェクトを正常にビルドするには、依存関係のソースを明示的に定義する必要があります。

  `Podfile` の一番上、すべての `target` ブロックより前に、次の行を追加してください。

  ```ruby Ruby
  source 'https://github.com/moengage/PodSpecs.git'
  source 'https://github.com/CocoaPods/Specs.git'
  ```

  <ul><li>MoEngage Source は、MoEngage 固有の SDK Pod を正常に解決して取得するために必要です。</li><li>CocoaPods Source は、その他の標準的なサードパーティの React Native 依存関係が引き続き正しく解決されるようにするために必要です。</li></ul>

  これらの行を `Podfile` に追加したら、ios ディレクトリから次のコマンドを実行します。

  ```bash Bash
  pod install --repo-update
  ```
</Info>

バージョン 10.0.0 から、Turbo アーキテクチャをサポートしています。

新しいアーキテクチャでアプリケーションを実行するには、以下の手順に従います。

1. iOS フォルダに移動します。
2. コマンド **_RCT\_NEW\_ARCH\_ENABLED=1 bundle exec pod install_** を実行して、必要な依存関係をインストールします。

古い React アーキテクチャでアプリケーションを実行するには、以下の手順に従います。

1. iOS フォルダに移動します。
2. コマンド **_pod install_** を実行して、必要な依存関係をインストールします。

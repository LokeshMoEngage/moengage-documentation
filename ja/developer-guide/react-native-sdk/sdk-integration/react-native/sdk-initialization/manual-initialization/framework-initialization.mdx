# React-Native コンポーネントの初期化

コンポーネントがマウントされたら、アプリケーションの **App.js** または **_App_**\*.\*\*\*_ts_** で MoEngage プラグインを初期化します。

<CodeGroup>

```java TypeScript
import ReactMoE from 'react-native-moengage';
ReactMoE.initialize("YOUR_WORKSPACE_ID");
```

</CodeGroup>

**例**

<CodeGroup>

```java TypeScript
import ReactMoE from 'react-native-moengage';
useEffect(() => {
    ReactMoE.initialize("YOUR_WORKSPACE_ID");
}, []);
```

</CodeGroup>

<Info>
  クラスベースのコンポーネントを使用している場合は、**_render()_** または **_componentDidMount()_** で初期化できます。
</Info>

## 設定を指定した初期化（オプション）

<CodeGroup>

```java TypeScript
import ReactMoE from 'react-native-moengage';
import { MoEInitConfig, MoEPushConfig, MoEngageLogConfig, MoEngageLogLevel } from "react-native-moengage";
const moEInitConfig = new MoEInitConfig(
  MoEPushConfig.defaultConfig(),
  new MoEngageLogConfig(MoEngageLogLevel.DEBUG, isEnabledForReleaseBuild)
);
ReactMoE.initialize(YOUR_WORKSPACE_ID, moEInitConfig);
```

</CodeGroup>

<Warning>
  **_initialize()_** を呼び出す前に、Push/InApp のコールバックリスナーを設定してください。
</Warning>

## 概要

このガイドでは、MoEngage SDK の設定に使用できるパラメータについて説明します。プラグインレベルの設定はすべて app.json または app.config.js ファイル内で行います。コア SDK の認証情報は、プラットフォームごとの別ファイルに配置します。

<Check>
  SDK を設定する前に、[インストール](/ja/developer-guide/react-native-sdk/sdk-integration/expo/installation)ガイドを完了しておく必要があります。
</Check>

## プラグインによるネイティブ設定の管理

信頼性が高く効率的なセットアップを実現するために、MoEngage Expo プラグインはネイティブプロジェクトの設定を自動的に管理します。この方法では、prebuild プロセス中にプラットフォーム固有の要件を処理するため、手作業によるミスの可能性が減ります。

主な自動化の内容は次のとおりです。

- 重要な設定の適用: プラグインは、データの整合性を確保するために、Android のバックアップ除外ルールなどの必要な設定を自動的に追加します。
- 手動でのファイル編集が不要: AndroidManifest.xml（Android）や Info.plist（iOS）などのネイティブファイルを直接変更する必要はありません。

## SDK 初期化の設定（XML ファイルと Plist ファイル）

configFilePath プロパティで指定するとおり、MoEngage のコア認証情報と SDK 設定は app.json には記述しません。代わりに、プラットフォームごとに別のファイルで定義します。

- Android の場合: XML ファイル（例: android_initialisation_config.xml）を[生成](https://app-cdn.moengage.com/sdk/integration/config/index.html)します。
- iOS の場合: Plist ファイル（例: MoEngage-Config.plist）を[生成](https://app-cdn.moengage.com/sdk/integration/config/index.html)します。

## 設定パラメータ

app.json または app.config.js ファイルの react-native-expo-moengage プラグインエントリ内に、以下のプロパティを追加します。これらのパラメータは、ネイティブモジュールのリンクや設定ファイルの参照など、プラグインのビルド時の動作を制御します。

1. app.json または app.config.js ファイルを開きます。
2. plugins 配列に react-native-expo-moengage を追加します。

<Tabs>
  <Tab title="Android">
    <CodeGroup>

    ```json JSON
    [
            "react-native-expo-moengage",
            {
              "android": {
                "configFilePath": "assets/moengage/android_initilisation_config.xml",
                "smallIconPath": "assets/moengage/small_icon.png",
                "largeIconPath": "assets/moengage/large_icon.png",
                "disableMoEngageDefaultBackupFile": false,
                "includeFirebaseMessagingDependencies": true,
                "isExpoNotificationIntegration": true,
                "shouldIncludeMoEngageFirebaseMessagingService": true
              }
            }
    ]
    ```

    </CodeGroup>

    | キー | 説明 |
    | --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
    | configFilePath                                | MoEngage SDK のコア設定を含む設定ファイル（.xml）へのパスを指定します。 |
    | smallIconPath                                 | プッシュ通知で使用するスモールアイコンへのパスを指定します。 |
    | largeIconPath                                 | プッシュ通知で使用するラージアイコンへのパスを指定します。 |
    | disableMoEngageDefaultBackupFile              | MoEngage では、バックアップ時に特定のファイルを除外する必要があります。このフラグはそのプロセスを設定するためのものです。有効にすると設定が自動的に含まれ、それ以外の場合は手動で追加する必要があります。詳細については、[こちら](/ja/developer-guide/android-sdk/sdk-integration/basic-integration/exclude-mo-engage-storage-file-from-auto-backup)を参照してください。 |
    | includeFirebaseMessagingDependencies          | プラグインに、プッシュに必要な Firebase Cloud Messaging（FCM）ライブラリを含めます。 |
    | isExpoNotificationIntegration                 | MoEngage の通知サービスと併せて expo-notifications ライブラリを使用する場合に、互換性を確保し、プッシュペイロードを正しくルーティングするには true に設定します。 |
    | shouldIncludeMoEngageFirebaseMessagingService | 有効にすると、MoEngage によって通知サービスが含まれます。それ以外の場合は、ペイロードを MoEngage SDK に渡す必要があります。 |
  </Tab>
  <Tab title="iOS">
    <CodeGroup>

    ```json JSON
    [
            "react-native-expo-moengage",
            {
              "apple": {
                "configFilePath": "assets/moengage/MoEngage-Config.plist",
                "pushNotificationImpressionTrackingEnabled": true,
                "richPushNotificationEnabled": true,
                "pushTemplatesEnabled": true,
                "deviceTriggerEnabled": true,
                "liveActivityTargetPath": "assets/moengage/LiveActivity"
              }
            }
          ],
    ```

    </CodeGroup>

    | キー | 説明 |
    | ----------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
    | configFilePath                            | アプリケーションプロジェクトのルートパスを基準とした、MoEngage 設定 plist ファイルへのパスを指定します。この plist ファイルのデータは、アプリケーションの Info.plist 内の MoEngage キーに追加されます。パスが指定されていない場合は、assets/moengage/MoEngage-Config.plist がパスとみなされます。 |
    | pushNotificationImpressionTrackingEnabled | プッシュ通知の配信インプレッションのトラッキングを有効にするかどうかを指定します。指定されていない場合のデフォルト値は true です。 |
    | richPushNotificationEnabled               | プッシュ通知でリッチメディアコンテンツを有効にするかどうかを指定します。指定されていない場合は false です。 |
    | pushTemplatesEnabled                      | プッシュ通知テンプレートを有効にするかどうかを指定します。有効にしない場合は false です。詳細については、[こちら](/ja/developer-guide/android-sdk/push/optional/push-templates)を参照してください。 |
    | deviceTriggerEnabled                      | デバイストリガー通知を有効にするかどうかを指定します。有効にしない場合は false です。詳細については、[こちら](/ja/developer-guide/ios-sdk/push/optional/real-time-triggers)を参照してください。 |
    | liveActivityTargetPath                    | Live Activity ウィジェットのターゲットファイルへのパスを指定します。ウィジェットの UI とペイロードの定義、およびウィジェットに必要な追加リソースを含める必要があります。詳細については、[こちら](/ja/developer-guide/ios-sdk/push/optional/broadcast-live-activity)を参照してください。 |
  </Tab>
</Tabs>

## EAS Build での iOS App Extension の設定

EAS Build は、標準的な iOS アプリの設定を自動的に処理します。ただし、個別のネイティブターゲットを必要とする機能をアプリで使用している場合は、`eas.json` でそれらを設定する必要があります。これには次のような機能が含まれます。

- Notification Service Extension（NSE）: リッチプッシュとインプレッションのトラッキングに使用します。
- Notification Content Extension（NCE）: プッシュテンプレートまたは Live Activities に使用します。

iOS App Extension を設定するには、`expo.extra.eas.build.experimental.ios` オブジェクトに `appExtensions` キーを追加します。この設定により、EAS Build が追加のネイティブターゲットを正しくコンパイルして署名できるようになります。

<CodeGroup>

```json JSON
{
  "expo": {
    "extra": {
      "eas": {
        "build": {
          "experimental": {
            "ios": {
              "appExtensions": [
                {
                  "targetName": "MoEngageExpoRichPush",
                  "bundleIdentifier": "${YOUR Bundle Identifier}.MoEngageExpoRichPush",
                  "entitlements": {
                    "com.apple.security.application-groups": ["${YOUR AppGroup provided in apple.configFilePath}"]
                  }
                },
                {
                  "targetName": "MoEngageExpoPushTemplates",
                  "bundleIdentifier": "${YOUR Bundle Identifier}.MoEngageExpoPushTemplates",
                  "entitlements": {
                    "com.apple.security.application-groups": ["${YOUR AppGroup provided in apple.configFilePath}"]
                  }
                },
                {
                  "targetName": "MoEngageExpoLiveActivity",
                  "bundleIdentifier": "${YOUR Bundle Identifier}",
                  "entitlements": {
                    "com.apple.security.application-groups": ["${YOUR AppGroup provided in apple.configFilePath}"]
                  }
                }
              ]
            }
          }
        }
      }
    }
  }
}
```

</CodeGroup>

## ネイティブプロジェクトファイルの生成

パッケージをインストールしてプラグインエントリを追加したら、prebuild コマンドを実行する必要があります。このコマンドは設定を使用して、プロジェクトのネイティブな Android および iOS ディレクトリを生成します。

次のコマンドを実行します。

<CodeGroup>

```shell Shell
npx expo prebuild
```

</CodeGroup>

## 概要

このガイドでは、React Native Expo プロジェクトに MoEngage SDK を追加する方法について説明します。

<Check>
  **前提条件**

  以下が揃っていることを確認してください。

  - MoEngage アカウント。
  - Expo でセットアップされた React Native プロジェクト。
</Check>

## SDK パッケージのインストール

MoEngage SDK をパッケージとしてプロジェクトに追加します。`npx expo install` を使用すると、プロジェクトの Expo SDK と互換性のあるバージョンが自動的にインストールされるため、この方法を推奨します。

<Steps>
  <Step title="ルートに移動する">
    ターミナルを開き、プロジェクトのルートディレクトリに移動します。
  </Step>
  <Step title="パッケージをインストールする">
    次のコマンドを実行します。

    <CodeGroup>

    ```shell Shell
    npx expo install react-native-expo-moengage
    ```
    </CodeGroup>

    <CodeGroup>
    
    ```shell Shell
    npm install react-native-moengage
    ```

    </CodeGroup>
  </Step>
</Steps>

## 設定へのプラグインの追加

次に、Expo の設定ファイル（`app.json` または `app.config.js`）に MoEngage プラグインを追加する必要があります。

この手順は、ネイティブプロジェクトファイルを生成する前に必要です。

<Tabs>
  <Tab title="JSON">
    ```json
    {
      "expo": {
        "plugins": [
          "react-native-expo-moengage"
        ]
      }
    }
    ```
  </Tab>
</Tabs>

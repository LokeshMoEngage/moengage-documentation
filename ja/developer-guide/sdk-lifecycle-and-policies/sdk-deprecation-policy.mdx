新しい SDK バージョンがリリースされると、古いバージョンは非推奨になります。このページでは、そのプロセスの仕組みと、統合に与える影響について説明します。

MoEngage では、次の 3 つのバージョンステータスレベルを使用しています。

- **Current** — 最新のメジャーバージョンです。新機能、修正、サポートが提供されます。
- **Supported** — 3 年間のサポート期間内にある古いメジャーバージョンです。引き続きサポートが提供されます。
- **Deprecated** — サポート期間外のバージョンです。修正やサポートは提供されなくなります。

## サポート期間

- MoEngage は、各メジャー SDK バージョンを最初のリリースから 3 年間サポートします。
- 非推奨化は毎年 8 月の年次サイクルで適用されます。メジャーバージョンは、3 年間のサポート期間終了日以降の最初の 8 月に非推奨になります。
- MoEngage は非推奨日の 6～12 か月前に事前通知を行い、各バージョンの日付をプラットフォームの非推奨バージョンページで公開します。
- 3 年間の期間はメジャーバージョンの最初のリリースから計算されますが、メジャーバージョンはそのライフサイクル全体を通じてマイナーおよびパッチアップデートを受け取り続けます。そのため、公開される非推奨の境界はメジャーバージョン番号だけではなく、特定のマイナーまたはパッチバージョンになります。プラットフォームによっては、あるメジャーバージョンの初期ビルドを非推奨にしつつ、同じメジャーバージョンの後期ビルドは引き続きサポートする場合があります。正確なバージョンの境界については、各プラットフォームの非推奨バージョンページを確認してください。

## SDK の非推奨化がアプリに与える影響

### データフロー

MoEngage は非推奨バージョンからのトラフィックをブロックしません。ユーザーのデバイスにすでにインストールされているアプリは引き続きデータを送信し、MoEngage も引き続きそのデータを受信します。Push、In-App、分析は、使用している SDK バージョンの機能の範囲内で引き続き動作します。

### バグ修正とセキュリティパッチ

MoEngage は、バグ修正とセキュリティパッチを現行のメジャーバージョンでのみ提供します。Supported および Deprecated のバージョンにはパッチは提供されません。修正を受け取るには、現行バージョンにアップグレードしてください。

### 新規開発

既存の本番アプリは変更なしで引き続き動作します。新しいアプリビルドでは、最新の修正と機能を利用するために現行の SDK バージョンを使用してください。MoEngage は、非推奨バージョンを公開パッケージレジストリおよびアプリストアのツールから削除します。

## 非推奨化の通知

バージョンの非推奨化が予定されると、その日付の 6～12 か月前に通知が届くため、通常のリリースサイクルの一環としてアップグレードを計画できます。

MoEngage は、複数のチャネルを通じて通知を送信します。

- **四半期ごとの SDK ニュースレター。** MoEngage は、定期的な SDK アップデートに非推奨化のお知らせを含めます。
- **ワークスペース管理者へのメール。** MoEngage は、非推奨日より前に正式な通知を送信し、日付が近づくにつれて繰り返し送信します。
- **ダッシュボード内の通知。** MoEngage はダッシュボードにアラートを表示します。
- **リリースノート。** MoEngage は、各リリースにおいて、影響を受けるバージョンに対する非推奨化関連の変更を明示します。

これらの通知を受け取るには、ワークスペース管理者のメールアドレスを最新の状態に保ち、SDK ニュースレターを購読してください。

これらの統合により、ホストされたストアを MoEngage に接続します。Shopify には専用の MoEngage アプリがあり、WooCommerce と Magento は Google Tag Manager 経由または直接デプロイする Web SDK を使用します。

| ページ | 内容 |
| --- | --- |
| [Shopify 統合](/ja/developer-guide/ecommerce-platforms/shopify/overview) | MoEngage アプリをインストールし、ユーザー、注文、カタログを同期して、統合を検証します。 |
| [WooCommerce](/ja/developer-guide/ecommerce-platforms/woo-commerce/woocommerce) | Google Tag Manager を使用してストアを統合し、イベントとユーザーをトラッキングします。 |
| [Magento](/ja/developer-guide/ecommerce-platforms/magento/magento) | Google Tag Manager または直接統合を使用して Web SDK を統合します。 |

---
title: "WooCommerce"
description: "Google Tag Manager を使用して WooCommerce ストアを MoEngage と統合し、イベントとユーザーをトラッキングします。"
---

WooCommerce は WordPress 上に構築されたオープンソースの e コマースプラットフォームで、世界中の 300 万以上のオンラインストアで使用されています。このドキュメントでは、WooCommerce 上のストアを MoEngage と統合するために必要な手順について説明します。

- WooCommerce ストアに Google Tag Manager（GTM）を追加します。詳細な手順については、この[公式ドキュメント](https://woocommerce.com/document/gtm-ecommerce-woo-pro/#how-to-install)を参照してください。
- [こちら](/ja/partner-guide/data-and-analytics/analytics/google-tag-manager-gtm-server-side)の統合手順に従って、GTM と MoEngage の統合を完了します。
- GTM を介して、ストアから MoEngage に任意のユーザーイベントやユーザープロパティをトラッキングできます。
- この統合により、さらに以下の MoEngage チャネルと統合できます。  

| チャネル             | サポート                                                                                                          |
| ------------------- | ------------------------------------------------------------------------------------------------------------------- |
| On- site messaging  | はい                                                                                                                 |
| Web personalization | はい（[統合](/ja/developer-guide/personalize-sdk/sdk-integration/web-personalization-v2)スクリプトを追加する必要があります） |
| WebPush             | いいえ                                                                                                                  |

<Info>
  この統合を完了するには、ストアが WooCommerce Pro プランである必要があります。
</Info>

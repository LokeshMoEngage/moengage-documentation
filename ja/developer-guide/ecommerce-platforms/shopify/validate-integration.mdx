---
title: "Shopify 統合の検証"
description: "MoEngage Shopify 統合を検証して、ユーザーイベントとデータが正しくトラッキングされていることを確認します。"
---

Shopify ストアに MoEngage をインストールしたら、キャンペーンを本番稼働する前に統合を検証し、MoEngage がユーザーイベントとデータを正しくトラッキングしていることを確認します。この記事では、SDK の読み込みを確認する方法、主要なイベントがトリガーされることを確認する方法、およびストアでカスタマイズされた Shopify テーマやサードパーティのチェックアウトパートナーを使用している場合に想定される動作について説明します。

## 前提条件

検証プロセスを開始する前に、次のものが揃っていることを確認してください。

- ブラウザーに [**MoEngage Assist** **拡張機能**](https://chromewebstore.google.com/detail/moengage-sdk/dhggnkfnnoebbfofpimfehcklnekmbgi)がインストールされていること。
- 本番の Shopify ストアフロントへのアクセス権。
- イベントの取り込みを照合するために、MoEngage ワークスペースを別のタブで開いておくこと。

## ステップ 1: MoEngage SDK の読み込みを確認する

SDK の読み込みを確認するには、次の手順を実行します。

1. 新しいブラウザーウィンドウで Shopify ストアを開くか、既存のウィンドウでハードリフレッシュを実行します。
2. ストアフロントで **MoEngage Assist** Chrome 拡張機能を開きます。SDK が正常に読み込まれると、拡張機能のアイコンが青色になり、緑色の **Live** ステータスが表示されます。アイコンをクリックしてパネルを開くと、**Issues** タブに **No Issues Found** と表示されます。

   ![SDK が読み込まれ No Issues Found と表示されている MoEngage Assist 拡張機能](/images/ValidateIntegration1.png)

<AccordionGroup>
  <Accordion title="SDK の読み込みのトラブルシューティング">
    SDK の読み込みエラーを解決するには、次の点を確認します。

    - Shopify 管理画面で **Apps** > **MoEngage** > **App embed settings** を開きます。アプリ埋め込みブロックの保存を解除してから再保存します。この操作によりスクリプトの挿入が再トリガーされ、SDK の読み込みに失敗するほとんどのケースが解決します。
    - 再保存してもアイコンが青色にならない場合は、ブラウザーの開発者コンソールを開き、ページ上の JavaScript エラーを確認します。SDK の読み込みエラーはここに表示されます。

      ![SDK の読み込みエラーによる JavaScript エラーが表示されたブラウザーの開発者コンソール](/images/ValidateIntegration4.png)

    - 問題が解決しない場合は、MoEngage サポートにお問い合わせください。
  </Accordion>
</AccordionGroup>

<Info>
  **セットアップ手順に不整合があると SDK が読み込まれないことがあります**

  統合手順を順番どおりに完了しないと、SDK は読み込まれません。サポートチケットを作成する前に、Shopify テーマ設定でのアプリ埋め込みブロックの保存を含め、Shopify のセットアップ記事のすべての手順に従っていることを確認してください。
</Info>

## ステップ 2: イベントトラッキングを検証する

イベントをトリガーして確認するには、次の手順を実行します。

<AccordionGroup>
  <Accordion title="Product Viewed">
    **Product Viewed** イベントを検証するには、次の手順を実行します。

    1. ストアフロントの任意の商品ページに移動します。
    2. **MoEngage Assist** 拡張機能の **Track** タブのイベントストリームに、**Product Viewed** イベントが緑色の **Tracked** ステータスで表示されることを確認します。

       ![MoEngage Assist のイベントストリームでトラッキングされた Product Viewed イベント](/images/ValidateIntegration2.png)

    3. 拡張機能内のイベント行にあるドロップダウン矢印をクリックして展開し、価格、通貨、商品 ID などの主要な属性が正しい値でトラッキングされていることを確認します。

       ![トラッキングされた属性が表示された Product Viewed イベント行の展開表示](/images/ValidateIntegration5.png)

    <Warning>
      **Product Viewed はデフォルトの商品テンプレートでのみトリガーされます**

      このイベントは、Shopify のデフォルトの商品ページテンプレートを使用してトラッキングされます。ストアでカスタムの商品ページテンプレートを使用している場合、デフォルトではそれらのページでイベントはトリガーされません。
    </Warning>
  </Accordion>

  <Accordion title="Add to Cart">
    **Add to Cart** イベントを検証するには、次の手順を実行します。

    1. 任意の商品ページから、商品をカートに追加します。
    2. **MoEngage Assist** パネルに **Shopify - Add to Cart** イベントが表示されることを確認します。

    <Info>
      **キャンペーンではどの Add to Cart イベントが使用されますか？**

      MoEngage は、Web SDK と Shopify Webhook の両方で **Add to Cart** をトラッキングします。これら 2 つのイベントは名前が異なり、件数も一致しません。Shopify はカートの作成につながったセッション数をカウントし、MoEngage は **Add to Cart** アクションが発生した回数をカウントします。セグメントとキャンペーンのトリガーには、常に Webhook バージョン（**Shopify - Add to Cart**）を使用してください。詳細については、[**イベントとユーザーデータのトラッキング**](/ja/developer-guide/ecommerce-platforms/shopify/events-and-user-data-tracking)の記事を参照してください。
    </Info>
  </Accordion>
</AccordionGroup>

## Cart Token ユーザー属性を確認する

カートトークンを確認するには、次の手順を実行します。

1. **Product Viewed** と **Add to Cart** を検証する際に、ユーザープロファイルに **cart_token** ユーザー属性が設定されていることを確認します。
2. ブラウザー拡張機能の属性ダッシュボードで、**cart_token** ユーザー属性が一覧に表示され、**Tracked** としてマークされていることを確認します。カート放棄フローが正しく機能するには、カートトークンが必要です。

   ![拡張機能の属性ダッシュボードで Tracked としてマークされた cart_token ユーザー属性](/images/ValidateIntegration3.png)

## サードパーティのチェックアウトパートナー

チェックアウトパートナーのイベントトラッキングを管理するには、次の情報を確認してください。

MoEngage は、Shopify のデフォルトのチェックアウトプロセスを使用してチェックアウトイベントをトラッキングします。ストアで **GoKwik**、**Razorpay Magic Checkout**、または同様の高速チェックアウトツールなどのサードパーティのチェックアウトパートナーを使用している場合、次の動作が発生します。

| シナリオ                              | 発生する動作                                                                                                                                                                                                                  |
| ------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| チェックアウト開始後の SDK イベント    | Shopify では、サードパーティのチェックアウトフローが開始された後に Web SDK イベントをトリガーできません。SDK イベントに依存する **On-Site Messaging（OSM）**キャンペーンは、チェックアウト時またはチェックアウト後にトリガーできません。                            |
| イベント内のチェックアウトページ URL           | URL が存在しない場合、関連するイベントには **checkout page URL** 属性が含まれません。                                                                                                                                     |
| Add to Cart SDK イベント                 | サードパーティのチェックアウトパートナーがカートの操作を横取りする場合、**Add to Cart** SDK イベントがトリガーされないことがあります。このイベントの Webhook バージョンは影響を受けません。                                                                |

<Info>
  **Webhook ベースのイベントは影響を受けません**

  **Order Placed** およびその他の Webhook ベースのイベントは、使用するチェックアウトパートナーに関係なく、引き続き正常にトラッキングされます。この影響は、チェックアウト段階およびそれ以降の SDK ベースのイベントトラッキングに限定されます。
</Info>

## 大幅にカスタマイズされた Shopify テーマ

カスタムテーマでのイベントトラッキングを管理するには、次の情報を確認してください。

MoEngage Web SDK は、Shopify のデフォルトのストアフロントのワークフローと統合されています。大幅にカスタマイズされた Shopify テーマでは、このワークフローが変更されていることがあり、SDK が正常に読み込まれていてもイベントが発火しない場合があります。プラグインにイベントが表示されない場合は、ストアで標準の Shopify ページテンプレートやカートの動作を上書きするカスタムテーマを使用していないか確認してください。使用している場合は、サポートに連絡して必要な追加実装を確認してください。

<Warning>
  **本番のストアフロントで検証してください**

  ストアで大幅にカスタマイズされたテーマを使用している場合は、キャンペーンを開始する前に、本番のストアフロントでイベントトラッキングを検証してください。開発プレビューでのカスタムテーマの動作は、公開されたストアと異なる場合があります。
</Warning>

## トラブルシューティング: プラグインにイベントが表示されない場合

イベントトラッキングの問題をトラブルシューティングするには、サポートチケットを作成する前に、次の手順を順番に実行してください。

1. MoEngage アプリが正しい Shopify ストアにインストールされていること、およびセットアップ時に入力したワークスペース ID がアクティブな MoEngage ワークスペースと一致していることを確認します。
2. 最近新しい API キーを生成した場合は、10 分待ってからテストします。新しく生成されたキーが有効になるまでには、最大 10 分かかります。
3. Shopify テーマ設定でアプリ埋め込みブロックが保存されていることを確認します。**Apps** > **MoEngage** > **App embed settings** に移動し、埋め込みブロックの保存を解除して再保存してから、再度テストします。
4. ストアでカスタムテーマやサードパーティのチェックアウトパートナーを使用しているかどうかを確認し、このページの関連セクション（[**サードパーティのチェックアウトパートナー**](#third-party-checkout-partners)および[**大幅にカスタマイズされた Shopify テーマ**](#heavily-customized-shopify-themes)）を確認します。
5. 商品ページまたはカートページでブラウザーの開発者コンソールを開き、JavaScript エラーを確認します。SDK の読み込みエラーはここに表示されます。

上記のいずれの操作でも問題が解決しない場合は、MoEngage サポートにお問い合わせください。その際、ワークスペース ID、発火していない具体的なイベント、テストページの URL、ストアでカスタムテーマまたはサードパーティのチェックアウトパートナーを使用しているかどうかをお知らせください。

詳細については、[FAQ](/ja/developer-guide/ecommerce-platforms/shopify/faqs) を参照してください。

---
title: "ユーザーデータの同期"
description: "既存の Shopify ユーザーと注文履歴を MoEngage に同期して、セグメンテーションとエンゲージメントに活用します。"
---

初期統合が完了したら、既存の Shopify ユーザーとその過去の注文データを MoEngage に同期できます。このプロセスにより、MoEngage の使用を開始した時点から、過去のユーザー行動に基づいてセグメントの作成、キャンペーンのトリガー、コミュニケーションのパーソナライズを行えます。

## 同期可能なデータ

同期プロセスでは、次の 2 つの主要なデータタイプを MoEngage にインポートします。

| データタイプ          | 説明                                                                                                                                                                                                                  |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **注文履歴**  | MoEngage は、選択した期間内の過去の注文を個別の [`Shopify - Order Placed`](/ja/developer-guide/ecommerce-platforms/shopify/events-and-user-data-tracking) イベントとして取り込みます。各イベントには Shopify の元の注文タイムスタンプが使用されます。 |
| **ユーザープロファイル**  | MoEngage は、Shopify ストアのすべての登録ユーザーをインポートします。システムは、統合セットアップ時に選択した一意の識別子（メールアドレスまたは携帯電話番号）を使用してプロファイルを作成または更新します。                              |

### ユーザー属性のマッピング

Shopify のレコードで利用可能な場合、MoEngage は次の属性をユーザープロファイルに同期します。

- Email
- First name
- Last name
- Phone
- City
- Country
- State
- Shopify ID
- Accepts marketing
- Order count

<Info>
  **除外されるデータ**

  デフォルトでは、MoEngage は Shopify 顧客メタフィールド（カスタムデータフィールド）を同期しません。パーソナライズにメタフィールドのデータが必要な場合は、カスタム統合の手順について[イベントとユーザーデータのトラッキング](/ja/developer-guide/ecommerce-platforms/shopify/events-and-user-data-tracking)の記事を参照してください。
</Info>

## 同期の前提条件

### イベント保持期間

イベント保持の設定が同期しようとしているデータの期間に対応していることを確認するため、同期プロセスを開始する前に次の点を確認してください。

MoEngage は、特定の保持期間でイベントを保存します。選択した同期期間が保持期間を超える場合、MoEngage は上限に達した時点で注文の同期を停止します。同期ステータスは「Sync successful」と表示されますが、古いデータはダッシュボードに表示されません。

<Warning>
  **警告**

  60 日を超える履歴を同期する予定の場合は、同期を開始する**前に**、カスタマーサクセスマネージャーに連絡するか、サポートチケットを作成してイベント保持期間を延長してください。これらの変更を遡って適用することはできません。
</Warning>

### ユーザー識別子

MoEngage は、統合セットアップ時に選択した一意の識別子に基づいてユーザーとその注文を同期します。

- **email** を選択した場合、システムはメールアドレスを持たないユーザーを通知なしに除外します。
- システムは、スキップされたレコードに対してエラーメッセージを生成しません。

## 同期プロセス

Shopify のデータを同期するには、次の手順を実行します。

1. MoEngage Shopify アプリを開き、**Sync Shopify data** タブをクリックします。
2. 注文履歴の期間を選択します。インストール日から最大過去 2 年間のデータを同期できます。
3. **Sync past data** をクリックします。

   ![MoEngage Shopify アプリの Sync past data セクション](/images/UserDataSync1.png-1.png)

**Sync progress** セクションで進行状況を監視します。

## 同期の確認

<Info>
  **同期ステータスはデータの到着を保証するものではありません**

  同期ステータスは、開始後数秒以内に **Sync successful** に更新される場合があります。これはリクエストが受信されたことを示すものであり、データの処理が完了したことを示すものではありません。大規模なデータセットでは数時間、非常に大規模なストアでは最大 24 時間かかる場合があります。必ずユーザープロファイルで直接確認してください。
</Info>

同期を確認するには、次の手順を実行します。

1. 同期を開始してから少なくとも 2 時間待ちます。
2. MoEngage UI で、同期期間内に注文した顧客のユーザープロファイルに移動します。
3. `Shopify - Order Placed` イベントが正しい元の注文日でプロファイルに表示されていることを確認します。
4. 同期ステータスが成功と表示されているにもかかわらず、24 時間経過してもデータが表示されない場合は、選択した期間とおおよその注文数を添えてサポートにお問い合わせください。

## イベントの自動更新

過去データの同期が完了すると、MoEngage は Shopify Webhook を介して新しい注文を自動的にトラッキングします。新しいデータのために同期を再度実行する必要はありません。

<Warning>
  **重要**

  同期は、過去データのバックフィルのための 1 回限りの操作です。同じ期間に対して同期を 2 回実行しないでください。MoEngage で重複したイベントが作成されます。
</Warning>

## 同期されるユーザー属性

MoEngage は、選択した期間内の一意の注文 ID ごとに `Shopify - Order Placed` イベントを作成します。各イベントの `Created at` 属性には、Shopify で注文が最初に行われた日時が反映されます。

イベント属性の一覧の詳細については、[イベントとユーザーデータのトラッキング](/ja/developer-guide/ecommerce-platforms/shopify/events-and-user-data-tracking)の記事を参照してください。

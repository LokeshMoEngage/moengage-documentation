このページでは、MoEngage iOS SDK のメジャーバージョンのサポート状況を確認できます。どのバージョンが現行で、どのバージョンが引き続きサポート対象で、どのバージョンが非推奨であるかを、非推奨日とともに一覧で示しています。このページは iOS SDK のバージョン状況に関する信頼できる情報源です。ライフサイクルの仕組みと、非推奨がアプリにとって何を意味するかについては、[SDK 非推奨ポリシー](/ja/developer-guide/sdk-lifecycle-and-policies/sdk-deprecation-policy)を参照してください。iOS SDK をセットアップするには、[統合ガイド](/ja/developer-guide/ios-sdk/sdk-integration/basic/sdk-integration)を参照してください。

## バージョンのサポート状況

<Info>
  **Current（現行）** — 最新のメジャーバージョンです。新機能、修正、サポートが提供されます。

  **Supported（サポート対象）** — 3 年間のサポート期間内にある古いメジャーバージョンです。引き続きサポートが提供されます。

  **Deprecated（非推奨）** — サポート期間外のバージョンです。修正やサポートは提供されなくなります。
</Info>

| メジャーバージョン | ステータス | 非推奨日 | 備考 |
| --- | --- | --- | --- |
| 11.x | Current | 未定 | 最新のメジャーバージョン。新機能、修正、サポートが提供されます。 |
| 10.x | Supported | 未定 | サポートが提供されます。 |
| 9.18.0 以上 | Supported | 未定 | サポートが提供されます。 |
| 9.17.5 以下 | Deprecated | 2027 年 8 月 | サポート、デバッグ、修正は提供されなくなります。データは引き続き送受信されます。現行バージョンにアップグレードしてください。 |

<Note>
  MoEngage は、各メジャーバージョンを最初のリリースから 3 年間サポートし、その後の 8 月に非推奨となります。詳細については、[SDK 非推奨ポリシー — サポート期間](/ja/developer-guide/sdk-lifecycle-and-policies/sdk-deprecation-policy#support-window)を参照してください。この表は、MoEngage が追加の非推奨を発表した際に更新されます。事前通知を受け取るには、SDK ニュースレターに登録し、ワークスペース管理者のメールアドレスが最新であることを確認してください。
</Note>

## 非推奨ステータスについて

非推奨バージョンでも、データの送受信は引き続き行われます。MoEngage がトラフィックをブロックすることはありません。非推奨日以降、MoEngage はそのバージョン固有の問題のデバッグ、修正、サポートを行わなくなり、問題の解決策は現行バージョンへのアップグレードとなります。すべての修正は現行バージョンでのみ提供され、サポート対象バージョンや非推奨バージョンでは利用できません。ポリシーの全文については、[SDK 非推奨ポリシー](/ja/developer-guide/sdk-lifecycle-and-policies/sdk-deprecation-policy)を参照してください。

## サポート対象バージョンへのアップグレード

- 現行メジャーバージョンの変更点については、[iOS SDK リリースノート](/ja/release-notes/sdks/ios)を参照してください。
- アップグレードの計画には、[iOS SDK リリースチェックリスト](/ja/developer-guide/ios-sdk/checklist/release-checklist)を使用してください。
- 最新のパッケージについては、[apple-sdk](https://github.com/moengage/apple-sdk) リポジトリを確認してください。
- サポートが必要な場合は、MoEngage のカスタマーサクセスマネージャー（CSM）またはサポートチームにお問い合わせください。

## よくある質問

<AccordionGroup>
  <Accordion title="非推奨になった後も非推奨バージョンを使い続けることはできますか？">
    非推奨バージョンのアプリは引き続き動作し、データも引き続き送受信されます。ただし、MoEngage は非推奨バージョンに対するサポート、デバッグ、修正を提供しなくなります。[iOS SDK リリースノート](/ja/release-notes/sdks/ios)と [iOS SDK リリースチェックリスト](/ja/developer-guide/ios-sdk/checklist/release-checklist)を使用して現行バージョンまたはサポート対象バージョンにアップグレードすることで、継続的なサポートを受けられます。
  </Accordion>
  <Accordion title="非推奨の事前通知はどのように受け取れますか？">
    MoEngage は、非推奨日の 6～12 か月前に、ワークスペース管理者へのメール、四半期ごとの SDK ニュースレター、ダッシュボード内の通知、SDK リリースノートを通じて事前通知を送信します。通知スケジュールの詳細については、[SDK 非推奨ポリシー](/ja/developer-guide/sdk-lifecycle-and-policies/sdk-deprecation-policy)を参照してください。
  </Accordion>
</AccordionGroup>

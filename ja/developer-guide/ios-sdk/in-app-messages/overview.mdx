description: "iOS アプリにコンテキストに応じたアプリ内メッセージを表示し、ディープリンクとカスタムアクションを処理します。"
keywords: ["iOS in-app messages", "In-App NATIV", "custom action handling", "deep link"]
---

アプリ内メッセージはユーザーがアプリを操作している間に表示されるため、コンテキストに応じたプロンプト、クロスセル、オンボーディングに役立ちます。メッセージは SDK が表示し、メッセージの表示を許可する場所と、ユーザーがメッセージをタップしたときの動作はアプリで制御します。

| ページ | 内容 |
| --- | --- |
| [In-App Nativ](/ja/developer-guide/ios-sdk/in-app-messages/in-app-nativ) | In-App NATIV SDK を使用して、コンテキストに応じたアプリ内メッセージを表示します。 |
| [カスタムアクションの処理](/ja/developer-guide/ios-sdk/in-app-messages/custom-action-handling) | アプリ内メッセージからのディープリンクのコールバックとカスタムアクションを処理します。 |

<Note>
  HTML アプリ内メッセージは、JavaScript から SDK を呼び出すことができます。[HTML In-App 向け JavaScript Bridge](/ja/developer-guide/components-for-sdk/javascript-bridge/javascript-bridge-for-html-in-apps)を参照してください。
</Note>

---
title: "MoEngage SDK の CocoaPods から SPM への移行"
---

CocoaPods は非推奨になりつつあります。MoEngage では、すべての新規統合に Swift Package Manager（SPM）を使用することを推奨しています。

## ステップ 1：CocoaPods の削除

既存の CocoaPods 統合を削除するには、まず構成ファイルをクリーンアップします。

1. テキストエディターで `Podfile` を開き、`pod 'MoEngage-iOS-SDK'` に一致する行を削除します。
2. ターミナルを開き、プロジェクトのルートディレクトリに移動して、次のコマンドを実行してワークスペースを更新します。

```bash Bash wrap
 pod install
```

## ステップ 2：Swift Package Manager の追加

CocoaPods の依存関係が削除されたので、Xcode アプリケーションに移って新しいパッケージを構成します。

SPM を使用して MoEngage-iOS-SDK をインストールするには、[SPM 統合ガイド](https://www.moengage.com/docs/developer-guide/ios-sdk/sdk-integration/basic/sdk-integration#integration-through-swift-package-manager)を参照してください。

<Note>
  アプリで使用している MoEngage の機能に対応する Swift パッケージのプロダクトを含めてください。
</Note>

これで MoEngage-iOS-SDK パッケージがインストールされました。

## 移行後の検証

パッケージが正常に統合されたことを確認します。

1. Xcode でプロジェクトのワークスペースを開きます。
2. Project Navigator を確認し、MoEngage-iOS-SDK パッケージが正しく表示されていることを確認します。
3. プロジェクトをビルドして実行し、アプリケーションがエラーなくコンパイルされることを確認します。

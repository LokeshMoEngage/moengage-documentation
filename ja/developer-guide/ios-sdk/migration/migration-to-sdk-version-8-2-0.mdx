---
title: "SDKバージョン8.2.0への移行"
description: "更新されたPod名、インポート、初期化方法を使用して、MoEngage iOS SDKをバージョン8.2.0に移行します。"
---

SDKバージョン8.2.0では大きな変更が加えられています。古いバージョンのSDKを使用していて、バージョン8.2.0以上への移行を計画している場合は、移行時に以下の変更を行ってください。

# Pod名の更新

SDKバージョン `8.2.0` から、一部のPod名が更新されました。以下の表を参照してPodfileを更新してください。

| SDKバージョン7.0.0         | SDKバージョン8.2.0               |
| :------------------------ | :------------------------------ |
| import MOGeofence         | import MoEngageGeofence         |
| import MORichNotification | import MoEngageRichNotification |

# インポートの更新

SDKバージョン `8.2.0` から、一部のフレームワーク名が更新されました。以下の表を参照して、各モジュールのインポート文を更新してください。

| SDKバージョン7.0.0         | SDKバージョン8.2.0               |
| :------------------------ | :------------------------------ |
| import MoEngage           | import MoEngageSDK              |
| import MOInApp            | import MoEngageInApps           |
| import MOCards            | import MoEngageCards            |
| import MOGeofence         | import MoEngageGeofence         |
| import MORichNotification | import MoEngageRichNotification |

# 初期化メソッドの変更

以前の初期化メソッドは非推奨となり、新しいメソッドが導入されました。

**非推奨のメソッド**

<CodeGroup>

```swift Swift wrap
let sdkConfig = MOSDKConfig(withAppID: "YOUR_WORKSPACE_ID")
#if DEBUG
	MoEngage.sharedInstance().initializeTest(with: sdkConfig, andLaunchOptions: launchOptions)
#else
	MoEngage.sharedInstance().initializeLive(with: sdkConfig, andLaunchOptions: launchOptions)
#endif
```


```objective-c Objective C wrap
MOSDKConfig* sdkConfig = [[MOSDKConfig alloc] initWithAppID:@"YOUR_WORKSPACE_ID"];
#ifdef DEBUG
   [[MoEngage sharedInstance] initializeTestWithConfig:sdkConfig andLaunchOptions:launchOptions];
#else
   [[MoEngage sharedInstance] initializeLiveWithConfig:sdkConfig andLaunchOptions:launchOptions];
#endif
```

</CodeGroup>

新しい初期化メソッドの詳細については、こちらの[リンク](/ja/developer-guide/ios-sdk/sdk-integration/basic/sdk-initialization)を参照してください。

# リージョン/データセンターの設定

MODataCenter: SDKバージョン `8.2.0` でDataCenter名が更新されました。以下は、SDKバージョン `7.0.0` 以上で使用されていた既存のものです。

<CodeGroup>

```swift Swift
typedef enum {              
      DATA_CENTER_01, 
      DATA_CENTER_02, 
      DATA_CENTER_03 
}MODataCenter;
```


```objective-c Objective C
typedef enum {
    DATA_CENTER_01,
    DATA_CENTER_02,
    DATA_CENTER_03
}MODataCenter;
```

</CodeGroup>

新しいDataCenterの値の詳細については、こちらの[リンク](/ja/developer-guide/ios-sdk/sdk-integration/basic/data-center)を参照してください。

# App Target: App Group IDの設定

App TargetのApp Group IDは以前は `setAppGroupID:` を使用して設定していましたが、これはサポートされなくなりました。最新のSDKバージョンでは、MOSDKConfigを使用して設定してください(詳細については[リンク](/ja/developer-guide/ios-sdk/sdk-integration/basic/sdk-initialization)を参照してください)

**以前のメソッド[6.3.1以下]**

<CodeGroup>

```swift Swift
MoEngage.setAppGroupID("AppGroupID")
```


```objective-c Objective C
[MoEngage setAppGroupID:@"AppGroupID"];
```

</CodeGroup>

# ログ有効化の変更

トラブルシューティングのためにSDKログを有効にするメソッドが、`debug:` から `enableSDKLogs :` に変更されました。以前のメソッドは以下のように使用されていました。最新のSDKバージョンでの更新された実装については、次の[ドキュメント](/ja/developer-guide/ios-sdk/troubleshooting-and-faqs/troubleshooting-and-faqs-ios)を参照してください。

**以前のメソッド[6.3.1以下]**

<CodeGroup>

```swift Swift
MoEngage.debug(LOG_ALL)
```


```objective-c Objective C
[MoEngage debug:LOG_ALL];
```

</CodeGroup>

# RealTimeTriggerおよびInboxモジュール

SDKバージョン8.0.0から、RealTimeTriggerおよびInboxモジュールはMoEngage-iOS-SDKから分離されました。そのため、これらは明示的に統合する必要があります。ドキュメントについては[リンク](/ja/developer-guide/ios-sdk/push/advanced)を参照してください。

# Location Triggered

SDKバージョン `8.2.0` から、Geofenceに関連するメソッドが更新されました。更新されたメソッドを使用するには、以下の表を参照してください。

| SDKバージョン7.0.0                                             | SDKバージョン8.2.0                                   |
| :------------------------------------------------------------ | :-------------------------------------------------- |
| MOGeofenceHandler.sharedInstance()?.startGeofenceMonitoring() | MOGeofence.sharedInstance.startGeofenceMonitoring() |
| MOGeofenceHandler.sharedInstance().delegate = self            | MOGeofence.sharedInstance.setGeofenceDelegate(self) |

Geofence機能の詳細については、こちらの[ドキュメント](/ja/developer-guide/ios-sdk/push/optional/location-triggered)を参照してください。

---

description: "MoEngage iOS SDK をメジャーバージョン間でアップグレードし、CocoaPods から Swift Package Manager に移行します。"

---

SDK のメジャーバージョンでは、クラス名、初期化、インポートが変更されます。アップグレードの際はこれらのガイドを使用し、複数のメジャーバージョンを飛ばしてアップグレードする場合は、バージョン順に適用してください。

## バージョンのアップグレード

| ページ | 内容 |
| --- | --- |
| [SDKバージョン9.0.0への移行](/ja/developer-guide/ios-sdk/migration/migration-to-sdk-version-9-0-0) | 更新されたクラス名と初期化メソッドです。 |
| [SDKバージョン8.2.0への移行](/ja/developer-guide/ios-sdk/migration/migration-to-sdk-version-8-2-0) | 更新された Pod 名、インポート、初期化です。 |
| [SDK バージョン 7.0.0 への移行](/ja/developer-guide/ios-sdk/migration/migration-to-sdk-version-7-0-0) | 更新された初期化と設定です。 |
| [SDK バージョン 6.0.0 への移行](/ja/developer-guide/ios-sdk/migration/migration-to-sdk-version-6-0-0) | 更新された初期化と API です。 |

## 依存関係マネージャー

| ページ | 内容 |
| --- | --- |
| [MoEngage SDK の CocoaPods から SPM への移行](/ja/developer-guide/ios-sdk/migration/migration-of-moengage-sdk-from-cocoapods-to-spm) | CocoaPods の依存関係を削除し、Swift Package Manager を使用して SDK を追加します。 |

<Note>
  アップグレードを計画する前に、[iOS SDK の非推奨バージョン](/ja/developer-guide/ios-sdk/deprecated-versions/deprecated-versions)を確認して、現在のバージョンが引き続きサポートされているかどうかを確認してください。
</Note>

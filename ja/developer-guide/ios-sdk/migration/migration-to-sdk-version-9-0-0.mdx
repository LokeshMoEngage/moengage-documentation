---
title: "SDKバージョン9.0.0への移行"
description: "更新されたクラス名と初期化メソッドを使用して、MoEngage iOS SDKをバージョン9.0.0に移行します。"
---

SDKバージョン9.0.0では一部のクラス名が更新されています。バージョン8.2.0以上のSDKを使用していて、バージョン9.0.0以上への移行を計画している場合は、移行時に以下の変更を行ってください。

# 初期化メソッドの変更

SDKの初期化メソッドが更新され、SDKConfigが必須パラメーター、sdkStateがオプションのパラメーターになりました。

### 非推奨のメソッド

<CodeGroup>

```swift file name wrap
let sdkConfig = MOSDKConfig(withAppID: "YOUR_WORKSPACE_ID")
#if DEBUG
	MoEngage.sharedInstance().initializeDefaultTestInstance(with: sdkConfig, andLaunchOptions: launchOptions)
#else
	MoEngage.sharedInstance().initializeDefaultLiveInstance(with: sdkConfig, andLaunchOptions: launchOptions)
#endif
```


```objective-c Objective C wrap
MOSDKConfig* sdkConfig = [[MOSDKConfig alloc] initWithAppID:@"YOUR_WORKSPACE_ID"];
#ifdef DEBUG
   [[MoEngage sharedInstance] initializeDefaultTestInstanceWithConfig:sdkConfig andLaunchOptions:launchOptions];
#else
   [[MoEngage sharedInstance] initializeDefaultLiveInstanceWithConfig:sdkConfig andLaunchOptions:launchOptions];
#endif
```

</CodeGroup>

新しい初期化メソッドの詳細については、こちらの[リンク](/ja/developer-guide/ios-sdk/sdk-integration/basic/sdk-initialization)を参照してください。

# リージョン/データセンターの設定

MoEngageDataCenter: SDKバージョン `9.0.0` でDataCenterのクラス名が更新されました。以下は、SDKバージョン `8.2.0` 以上で使用されていた既存のものです。

| SDKバージョン8.2.0 | SDKバージョン9.0.0  |
| :---------------- | :----------------- |
| MODataCenter      | MoEngageDataCenter |

新しいDataCenterの値の詳細については、こちらの[リンク](/ja/developer-guide/ios-sdk/sdk-integration/basic/data-center)を参照してください。

# インストール/アップデートの区別

| SDKバージョン8.x.x                             | SDKバージョン9.0.0                                       |

新しいDataCenterの値の詳細については、こちらの[ドキュメント](/ja/developer-guide/ios-sdk/data-tracking/basic/install-update-differentiation)を参照してください。

---

プライバシーを重視する今日のデジタル環境では、多くのユーザーが広告ブロッカーやプライベート DNS サービスを利用しています。これらのツールは、分析プラットフォームやエンゲージメントプラットフォームを含む既知のサードパーティドメインへのネットワークリクエストをブロックすることがよくあります。これらのリクエストがブロックされると、重要なデータを把握できなくなり、ユーザーがアプリ内メッセージやプッシュ通知を受信できなくなる可能性があります。

確実なキャンペーン配信とキャンペーンパフォーマンスを確保するために、MoEngage は **Custom Proxy Domain**(カスタムプロキシドメイン)機能を提供しています。これにより、MoEngage SDK のトラフィックを自社のプライマリドメインのサブドメイン(例: `data.yourcompany.com`)経由でルーティングできます。トラフィックはファーストパーティの通信として扱われるため、一般的な広告ブロックリストを回避できます。

## オンボーディングプロセス

カスタムプロキシドメインを設定するには、お客様のチームと MoEngage の間で 1 回限りの DNS 委任プロセスが必要です。

<Info>
  **前提条件**

  SDK のコードを更新する前に、DNS 委任の設定を完了する必要があります。ドメインの選択と NS レコードの構成に関する詳細なガイドについては、[DNS 委任](https://www.moengage.com/docs/user-guide/getting-started/integration/custom-proxy-sub-domains)を参照してください。
</Info>

### ステップ 1: サブドメインを選択する

短く、フィルターで一般的にフラグが立てられるキーワードを含まないサブドメインを選択します(例: "tracking"、"ads"、"moengage" は避けてください)。

### ステップ 2: DNS 委任をリクエストする

MoEngage のカスタマーサクセスマネージャー(CSM)またはサポートチームに連絡してリクエストを開始します。選択したサブドメインを伝えてください。

### ステップ 3: NS レコードを構成する

MoEngage からネームサーバー(NS)レコードのリストが提供されます。選択したサブドメインについて、これらのレコードを DNS プロバイダーの構成に追加する必要があります。

## 実装

DNS 委任が確認されたら、SDK の初期化ロジックを更新します。SDK は、すべての MoEngage エンドポイント(API 呼び出しと CDN アセット)を動的に書き換えて、カスタムプロキシドメインを使用するようにします。

### MoEngage の構成を更新する

<CodeGroup>

```swift Swift wrap
import MoEngageSDK

let sdkConfig = MoEngageSDKConfig(appId: "YOUR_WORKSPACE_ID", dataCenter: DATA_CENTER)
sdkConfig.customBaseDomain = "CUSTOM_DOMAIN"
#if DEBUG
MoEngage.sharedInstance.initializeDefaultTestInstance(sdkConfig)
#else
MoEngage.sharedInstance.initializeDefaultLiveInstance(sdkConfig)
#endif
```


```objective-c Objective C wrap
@import MoEngageSDK;

MoEngageSDKConfig* sdkConfig = [[MoEngageSDKConfig alloc] initWithAppId:@"YOUR_WORKSPACE_ID" dataCenter: DATA_CENTER];
sdkConfig.customBaseDomain = @"CUSTOM_DOMAIN";
#ifdef DEBUG
[[MoEngage sharedInstance] initializeDefaultTestInstance:sdkConfig];
#else
[[MoEngage sharedInstance] initializeDefaultLiveInstance:sdkConfig];
#endif
```

</CodeGroup>

## ベストプラクティスと検証

1. **ドメインの選択:** サブドメインの文字列は短く(5~8 文字)してください。
2. **ネットワークログ:** リクエストがカスタムサブドメインで始まっていることを確認します(例: `sdk-01.data.example.com`)。
3. **アセットの読み込み:** キャンペーン内の画像が正しく読み込まれることを確認します。

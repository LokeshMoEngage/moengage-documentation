このセクションでは、アプリで MoEngage iOS SDK を動作させるために必要なすべてについて説明します。依存関係の追加、Workspace ID とデータセンターを使用した初期化、その後に追加できるオプションのセキュリティ強化です。

まず**基本**を順番に進めてください。**高度な設定**のページは互いに独立しているため、統合に必要なものだけを追加してください。

## 基本

| ページ | 内容 |
| --- | --- |
| [SDK の統合](/ja/developer-guide/ios-sdk/sdk-integration/basic/sdk-integration) | Swift Package Manager または CocoaPods を使用して SDK をインストールします。 |
| [SDK の初期化](/ja/developer-guide/ios-sdk/sdk-integration/basic/sdk-initialization) | Workspace ID とデータセンターを使用して、`AppDelegate` で SDK を初期化します。 |
| [データセンター](/ja/developer-guide/ios-sdk/sdk-integration/basic/data-center) | データが正しいクラスターにルーティングされるように、データセンターのリダイレクトを設定します。 |
| [アーキテクチャ互換性のためのプロジェクト構成](/ja/developer-guide/ios-sdk/sdk-integration/basic/Configuring-Project-for-Architecture-Compatibility) | SDK v10.x.x で arm64 との互換性を確保するために Xcode プロジェクトを構成します。 |
| [CocoaPods による統合](/ja/developer-guide/ios-sdk/sdk-integration/basic/integration-through-cocoa-pods) | CocoaPods 依存関係マネージャーを使用して SDK をインストールします。 |

## 高度な設定

| ページ | 内容 |
| --- | --- |
| [カスタムプロキシドメイン - iOS](/ja/developer-guide/ios-sdk/sdk-integration/advanced/custom-proxy-domain-ios) | 広告ブロッカーを回避するために、SDK のトラフィックを独自のサブドメイン経由でルーティングします。 |
| [JWT 認証](/ja/developer-guide/ios-sdk/sdk-integration/advanced/jwt-authentication) | JWT で SDK リクエストに署名して、データ収集を保護します。 |
| [アドオンセキュリティ](/ja/developer-guide/ios-sdk/sdk-integration/advanced/add-on-security) | Keychain と暗号化ストレージを使用して、SDK がデバイスに保存するデータを暗号化します。 |

<Note>
  依存関係マネージャーを使用しないインストールについては、[手動統合](/ja/developer-guide/ios-sdk/manual-integration/manual-integration)で別途説明しています。
</Note>

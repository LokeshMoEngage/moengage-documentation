# Swift Package Manager による統合

Swift Package Manager(SPM)は、Swift コードの配布を管理するためのツールです。Swift のビルドシステムと統合されており、依存関係のダウンロード、コンパイル、リンクのプロセスを自動化します。

SPM を使用して MoEngage-iOS-SDK をインストールするには、以下の手順に従います。

1. File -> Add Package に移動します
2. SDK バージョン 9.23.0 以上の場合は URL [https://github.com/moengage/apple-sdk.git](https://github.com/moengage/apple-sdk.git) を、それ以外の SDK バージョンの場合は [https://github.com/moengage/MoEngage-iOS-SDK.git](https://github.com/moengage/MoEngage-iOS-SDK.git) を入力し、ブランチとして master または必要なバージョンを選択してパッケージをインストールします。
3. Add Package をクリックします。
4. これで MoEngage-iOS-SDK パッケージがインストールされます。

<Info>
  **情報**

  CocoaPods は非推奨になりつつあります。MoEngage では、すべての新規統合に Swift Package Manager を使用することを推奨しています。プロジェクトで CocoaPods が必要な場合は、[CocoaPods 統合ガイド](/ja/developer-guide/ios-sdk/sdk-integration/basic/integration-through-cocoa-pods)を参照してください。
</Info>

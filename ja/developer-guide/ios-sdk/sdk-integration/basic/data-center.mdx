---
title: "データセンター"
description: "MoEngage iOS SDK でデータセンターのリダイレクトを構成し、データを正しいクラスターにルーティングします。"
---

MoEngage は、異なるクラスターにあるサーバーへのデータのリダイレクトをサポートしています。[_MoEngageSDKConfig_](https://moengage.github.io/ios-api-reference/Classes/MoEngageSDKConfig.html) のイニシャライザーを使用して、アカウントの構成に応じたデータセンターを設定します。

<CodeGroup>

```swift Swift wrap
import MoEngageSDK

let sdkConfig = MoEngageSDKConfig(appId: "YOUR_WORKSPACE_ID", dataCenter: .data_center_01)

// Possible values for dataCenter:
// .data_center_01, .data_center_02, .data_center_03,
// .data_center_04, .data_center_05, .data_center_06 (available from SDK version 9.17.3)
```


```objective-c Objective C wrap
@import MoEngageSDK;

 MoEngageSDKConfig* config = [[MoEngageSDKConfig alloc] initWithAppId:@"YOUR_WORKSPACE_ID" dataCenter:MoEngageDataCenterData_center_01];

// Possible Values for Data Center
typedef enum {
    data_center_01,
    data_center_02,
    data_center_03,
    data_center_04,
    data_center_05,
    data_center_06   /// Data center 06 available SDK version 9.17.3
}MoEngageDataCenter;
```

</CodeGroup>


以下は各データセンターのホストです。SDK API ドメインを許可リストに登録する場合は、データセンターに応じてアプリの構成を更新してください。

| データセンター | SDK ホスト          | ダッシュボードホスト      |
| :------------- | :------------------ | :------------------------ |
| data_center_01 | sdk-01.moengage.com | dashboard-01.moengage.com |
| data_center_02 | sdk-02.moengage.com | dashboard-02.moengage.com |
| data_center_03 | sdk-03.moengage.com | dashboard-03.moengage.com |
| data_center_04 | sdk-04.moengage.com | dashboard-04.moengage.com |
| data_center_05 | sdk-05.moengage.com | dashboard-05.moengage.com |
| data_center_06 | sdk-06.moengage.com | dashboard-06.moengage.com |

<Warning>
  **重要**

  アカウントのデータセンターを確認するには、ダッシュボードのホストを参照してください。この方法で SDK のデータセンターを変更する前に、必ず MoEngage チームにご相談ください。
</Warning>

MoEngage のデータセンターの詳細については、[MoEngage のデータセンター](https://www.moengage.com/docs/user-guide/data/key-concepts/data-centers-in-moengage)を参照してください。

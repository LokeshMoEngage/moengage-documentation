---
title: "CocoaPods による統合"
description: "CocoaPods 依存関係マネージャーを使用して、Xcode プロジェクトに MoEngage iOS SDK をインストールします。"
---

<Info>
  **情報**

  CocoaPods は非推奨になりつつあります。MoEngage では、すべての新規統合に Swift Package Manager を使用することを推奨しています。詳細については、[こちら](/ja/developer-guide/ios-sdk/sdk-integration/basic/sdk-integration)を参照してください。
</Info>

[![Version](https://img.shields.io/cocoapods/v/MoEngage-iOS-SDK.svg?style=flat)](http://cocoapods.org/pods/MoEngage-iOS-SDK)

CocoaPods は Objective C および Swift プロジェクト向けの依存関係マネージャーであり、統合を容易にします。

1. CocoaPods がインストールされていない場合は、ターミナルで以下の行を実行してインストールできます。

   <CodeGroup>

   ```ruby Ruby
   sudo gem install cocoapods
   ```

   </CodeGroup>

2. Podfile がない場合は、`pod init` コマンドを使用して作成します。その後、以下のように `MoEngage-iOS-SDK` pod を Podfile に追加します。

   <CodeGroup>

   ```ruby Ruby
   pod 'MoEngage-iOS-SDK'
   ```

   </CodeGroup>

   <Info>
     **情報**

     `~>` 演算子は記述した最後の要素のみを更新するため、固定する要素の数によって受け取る更新が決まります。

     - パッチ更新のみを受け取るには、3 つの要素すべてを固定します: `pod 'MoEngage-iOS-SDK', '~> 11.02.0'`。これは `>= 11.2.0, < 11.3.0` に解決されます。
     - マイナー更新とパッチ更新を受け取るには、2 つの要素を固定します: `pod 'MoEngage-iOS-SDK', '~> 11.02'`。これは `>= 11.2, < 12.0` に解決されます。
     - メジャー変更を含む最新バージョンを受け取るには、`pod 'MoEngage-iOS-SDK'` を使用します。

     MoEngage はマイナーバージョンをゼロ埋めしていますが、このゼロ埋めは表記上のものであり、解決には影響しません。`11.02.0` はセグメント `[11, 2, 0]` として解析されるため、`~> 11.02.0` と `~> 11.2.0` は同じ要件です。
   </Info>
3. プロジェクトのルートディレクトリでターミナルから以下を実行して、MoEngage iOS SDK を統合します。

   <CodeGroup>

   ```ruby Ruby
   pod repo update
   pod install
   ```

   </CodeGroup>

4. プロジェクトのワークスペースを開き、MoEngage SDK が正しく追加されていることを確認します。

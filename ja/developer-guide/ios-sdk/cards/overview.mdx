---
title: "iOS のカードキャンペーン"
description: "Cards SDK を使用して iOS アプリに MoEngage のカードキャンペーンを表示するか、独自のカード UI を構築します。"
keywords: ["iOS cards", "card campaigns", "self-handled cards", "MoEngage Cards SDK"]
---

カードは、ユーザーの操作を妨げることなくアプリ内に表示され続ける、控えめなメッセージです。MoEngage のカード UI をそのまま使用することも、カードのペイロードを取得して独自のビューを構築することもできます。

| ページ | 内容 |
| --- | --- |
| [iOSのカード](/ja/developer-guide/ios-sdk/cards/cards-in-i-os) | SPM または CocoaPods 経由で Cards SDK を使用して、カードキャンペーンを作成して表示します。 |
| [セルフハンドルカード](/ja/developer-guide/ios-sdk/cards/self-handled-cards) | セルフハンドルカードの SDK と API を使用して、カスタムのカードビューを構築します。 |

---
title: 'リリースチェックリスト'
description: "App Storeに提出する前に、このチェックリストでMoEngage iOS SDKの統合を確認します。"
---
App Storeでリリースする前に、以下のリリースチェックリストで確認を行ってください。

# 1. MoEngage SDKを更新する

*   MoEngage SDKを最新バージョンに更新してください。最新のSDKバージョンについては、[リリースノート](/ja/release-notes/sdks/ios)を確認してください。

# 2. 正しいAppIDを設定する

*   複数のMoEngageアプリを使用している場合は、リリース前にSDKの初期化時に正しいAppIDが設定されていることを確認してください。
*   App Storeに提出するビルドでinitializeProdWithApiKeyメソッドが呼び出されていることを確認してください。これにより、データがMoEngageアプリのLive環境でトラッキングされるようになります。詳細については、[リンク](/ja/developer-guide/ios-sdk/sdk-integration/basic/sdk-initialization)を参照してください。

# 3. プッシュ通知をテストしてAPNS証明書を確認する

*   本番用のAPNS証明書が、Live環境のMoEngageダッシュボード設定にアップロードされていることを確認してください。また、本番公開前にいくつか通知を送信してテストしてください。

# 4. アプリのインストールとアップデートのトラッキング

*   インストール/アップデートキャンペーンを実行する場合は、[それら](/ja/developer-guide/ios-sdk/data-tracking/basic/install-update-differentiation)をトラッキングしていることを確認してください（推奨ですが任意です）。

# 5. ユーザー属性Unique ID

*   アプリにログイン機能がある場合は、ユーザーのログイン時にUSER_ATTRIBUTE_UNIQUE_ID属性をトラッキングしていることを確認してください。デバイス、インストール/アンインストール、および異なるプラットフォーム間でユーザーを紐付けるには、USER_ATTRIBUTE_UNIQUE_IDの設定が必須です。この[リンク](/ja/developer-guide/ios-sdk/data-tracking/basic/tracking-user-attributes)を参照してください。
*   また、ユーザーのログアウト時にresetUserメソッドが呼び出されていることを確認してください。この[リンク](/ja/developer-guide/ios-sdk/data-tracking/basic/tracking-user-attributes)を参照してください。

# 6. ユーザー属性を設定する

*   デバイスやインストールをまたいで属性に基づいてユーザーをターゲティングするために必要なすべてのユーザー属性を設定していることを確認してください。これはキャンペーンのパーソナライゼーションにも役立ちます。詳細については、[リンク](/ja/developer-guide/ios-sdk/data-tracking/basic/tracking-user-attributes)を参照してください。

# 7. イベントをトラッキングする

*   アプリ内のユーザー行動をトラッキングし、後で適切なユーザーをターゲットとするキャンペーンの作成に使用できるよう、すべてのイベントをトラッキングしていることを確認してください。詳細については、[リンク](/ja/developer-guide/ios-sdk/data-tracking/basic/tracking-events)を参照してください。

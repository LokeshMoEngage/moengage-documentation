MoEngage iOS SDK は、Swift または Objective-C のアプリ内で動作します。イベントとユーザー属性をトラッキングし、APNs にプッシュトークンを登録し、アプリ内メッセージとカードを表示します。Swift Package Manager または CocoaPods を使用してインストールします。

まず [SDK の統合](/ja/developer-guide/ios-sdk/sdk-integration/overview)から始めて SDK をインストールして初期化し、その後必要なチャネルを追加してください。

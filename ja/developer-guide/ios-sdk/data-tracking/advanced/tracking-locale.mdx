---
title: "ロケールのトラッキング"
description: "MoEngage SDKを使用して、iOSアプリでユーザーのデバイスのロケール設定をトラッキングします。"
---

ユーザーのデバイスのロケール設定をトラッキングするには、以下のように [_trackLocale()_](https://moengage.github.io/ios-api-reference/Classes/MoEngageSDKAnalytics.html#/c:@M@MoEngageAnalytics@objc\(cs\)MoEngageSDKAnalytics\(im\)trackLocale) メソッドを使用します。

<CodeGroup>

```swift Swift wrap
MoEngageSDKAnalytics.sharedInstance.trackLocale()
```


```objective-c Objective C wrap
[[MoEngageSDKAnalytics sharedInstance] trackLocale];
```

</CodeGroup>

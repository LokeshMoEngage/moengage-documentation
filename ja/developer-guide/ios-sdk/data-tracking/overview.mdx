データトラッキングは、ユーザーが誰で、何をしているかをアプリから MoEngage に伝える仕組みです。ダッシュボードでのセグメント化、ターゲティング、分析はすべて、ここで送信するイベントと属性に基づいています。

まず、ユーザー ID とイベントトラッキングを扱う**基本**から始めてください。**高度な設定**では、ロケール、セッション、Personalize エクスペリエンスのレポートなどのコンテキストを追加します。

## 基本

| ページ | 内容 |
| --- | --- |
| [インストール/アップデートの区別](/ja/developer-guide/ios-sdk/data-tracking/basic/install-update-differentiation) | `appStatus` API を使用して、新規インストールとアップデートを区別します。 |
| [ユーザー属性のトラッキング](/ja/developer-guide/ios-sdk/data-tracking/basic/tracking-user-attributes) | ユーザー属性と、プラットフォームをまたいでユーザーを識別する Unique ID を設定します。 |
| [SDKバージョン9.23.0未満でのUnique IDの設定](/ja/developer-guide/ios-sdk/data-tracking/basic/setting-unique-id-for-sdk-versions-below-9-23-0) | SDK バージョン 9.23.0 未満でのログインとログアウトを処理します。 |
| [イベントのトラッキング](/ja/developer-guide/ios-sdk/data-tracking/basic/tracking-events) | カスタムイベントとその属性をトラッキングします。 |

## 高度な設定

| ページ | 内容 |
| --- | --- |
| [ロケールのトラッキング](/ja/developer-guide/ios-sdk/data-tracking/advanced/tracking-locale) | ユーザーのデバイスのロケール設定をトラッキングします。 |
| [セッションとソースのトラッキング](/ja/developer-guide/ios-sdk/data-tracking/advanced/session-and-source-tracking) | ユーザーセッションとディープリンクのソース情報をトラッキングします。 |

<Warning>
  ユーザーがサインアウトしたときは、ログアウト API を呼び出してください。呼び出さないと、次のユーザーのアクティビティが前のプロファイルに紐付けられます。[ユーザー属性のトラッキング](/ja/developer-guide/ios-sdk/data-tracking/basic/tracking-user-attributes)を参照してください。
</Warning>

ユーザーのトラッキングを停止するには、[コンプライアンス](/ja/developer-guide/ios-sdk/compliance/compliance)を参照してください。

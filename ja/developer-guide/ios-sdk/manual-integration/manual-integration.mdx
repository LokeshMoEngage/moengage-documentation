フレームワークを手動でインストールするには、以下の手順に従ってください。

GitHub リポジトリから最新の SDK をダウンロードします。各 SDK のダウンロード URL は [package.json](https://github.com/moengage/apple-sdk/blob/master/package.json) で確認できます。

![Manualintegration1 1](/images/manualintegration1-1.png)

 

# アプリターゲットへのフレームワークの埋め込み

以下の画像に示すように、必要なフレームワークをアプリターゲットに埋め込み、MoEngage のフレームワークファイルの Embed オプションを **Embed & Sign** に設定してください。

![Manualintegration2 1](/images/manualintegration2-1.png)

必須のフレームワーク：

| フレームワーク | ステータス | 目的 |
| --------------------- | -------- | --------------------------------------------------------------------------------------------- |
| MoEngageCore          | 必須 | SDK の基盤となるサービス、初期化、ライフサイクル管理を提供します。 |
| MoEngageSDK           | 必須 | MoEngage SDK のすべての機能の主要な公開インターフェースおよびオーケストレーターとして機能します。 |
| MoEngageSecurity      | 必須 | アクセス時および送信時のデータ保護を可能にします。 |
| MoEngageMessaging     | 必須 | プッシュ通知の登録、ペイロードの処理、コアとなるメッセージング機能を管理します。 |
| MoEngageCampaignsCore | 必須 | キャンペーンのペイロードの処理と表示を管理します。 |

アドオンのフレームワーク：

| フレームワーク | ステータス | 目的 |
| ------------------------ | -------- | ---------------------------------------------------------------------------------------------------------------- |
| MoEngageTriggerEvaluator | 任意 | AND トリガー条件に基づいて、アプリ内メッセージとデバイストリガー型プッシュ通知の表示を可能にします。 |
| MoEngageInApps           | 任意 | ポップアップやモーダルなどのアプリ内メッセージの表示を可能にします。 |
| MoEngageGeofence         | 任意 | 位置情報ベースのキャンペーントリガーのためのジオフェンスモニタリングを可能にします。 |
| MoEngageInbox            | 任意 | アプリケーション内で永続的な通知センター（Inbox）を利用可能にします。 |
| MoEngageCards            | 任意 | Content Cards の表示と管理を可能にします。 |
| MoEngageRichNotification | 任意 | プッシュ通知でリッチメディアコンテンツ（画像、動画、音声）とテンプレートを利用可能にします。 |
| MoEngageRealTimeTrigger  | 任意 | ユーザーイベントに基づく高頻度のリアルタイムキャンペーントリガーを実現します。 |
| MoEngageLiveActivity     | 任意 | Live Activities の登録、ペイロードの処理、トラッキングを管理します。 |

# App Extension での MoEngageRichNotification フレームワークのリンク

これは、プロジェクトで `MoEnagageRichNotification` フレームワークを使用している場合にのみ必要です。以下に示すように Extension ターゲットでフレームワークをリンクし、この場合は既にアプリターゲットに埋め込まれているため、**Embed** オプションを **Do Not Embed** に設定してください。

<Frame>
  ![Manualintegration3](/images/manualintegration3.png)
</Frame>

Extension ターゲットのビルド設定で、追加の `LD_RUNPATH_SEARCH_PATHS` として `@executable_path/../../Frameworks` を追加します。

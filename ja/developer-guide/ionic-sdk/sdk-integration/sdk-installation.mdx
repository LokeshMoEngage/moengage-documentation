# MoEngageプラグインの追加

以下のように、`cordova-moengage-core` プラグインをIonicプロジェクトに追加します。

<CodeGroup>

```Shell Shell
$ ionic cordova plugin add cordova-moengage-core --variable APP_ID="[YOUR_WORKSPACE_ID]"
```

</CodeGroup>

# 変数

- **APP_ID** = MoEngageダッシュボードの設定ページにあるWorkspace ID。

# プラグイン名の更新

バージョン5.0.2から、プラグインの名前が変更されました。以前は `moengagesdk` として登録されていましたが、現在は `cordova-moengage-core` に名前が変更されています。バージョン5.0.1以前から更新する場合は、以下のように、まず古いバージョンのプラグインを削除してから新しいプラグインをインストールしてください。

<CodeGroup>

```Shell Shell
$ ionic cordova plugin rm cordova-plugin-moengage
$ ionic cordova plugin add cordova-moengage-core --variable APP_ID="[YOUR_WORKSPACE_ID]"
```

</CodeGroup>

# MoEngageの宣言

MoEngage SDKのAPIを呼び出す前に、TypeScriptファイルに以下の行を追加してください。

<CodeGroup>

```TypeScript TypeScript
declare var MoECordova: any;
```

</CodeGroup>

<Info>
  **Cordovaのドキュメントを参照**

  ここでIonicに使用しているプラグインは、Cordovaフレームワーク向けに構築したものと同じです。そのため、プラグインをプロジェクトに統合し、プラグインが提供するさまざまな機能を使用するには、[SDKのインストール](/ja/developer-guide/cordova-sdk/sdk-integration/sdk-installation/framework-dependency)から始まるCordova SDKのドキュメントに従ってください。
</Info>

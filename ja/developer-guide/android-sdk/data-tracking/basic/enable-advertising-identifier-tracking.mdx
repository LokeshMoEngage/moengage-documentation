---
title: "広告識別子のトラッキングの有効化"
description: "正確なデバイス分析のために、MoEngage Android SDK で広告識別子のトラッキングを有効にします。"
---

デバイスに関する正確な分析と再インストールのトラッキングには、広告識別子をトラッキングすることが不可欠です。詳細については、[Android 広告 ID のトラッキング](https://www.moengage.com/docs/user-guide/data/privacy/android-advertising-id-tracking)を参照してください。

## 広告識別子ライブラリの追加

アプリケーションレベルの **_build.gradle_** ファイルに以下の依存関係を追加します。

<CodeGroup>

```groovy Groovy wrap
implementation("com.google.android.gms:play-services-ads-identifier:18.0.1")
```

</CodeGroup>

広告識別子のトラッキングを有効にするには、以下のように [enableAdIdTracking()](https://moengage.github.io/android-api-reference/core/com.moengage.core/enable-ad-id-tracking.html) メソッドを使用します。

<CodeGroup>

```Kotlin Kotlin wrap
import com.moengage.core.enableAdIdTracking
enableAdIdTracking(context)
```


```Java Java wrap
MoESdkStateHelper.enableAdIdTracking(context);
```

</CodeGroup>

アプリケーションが広告 ID のトラッキングに関する [Google Play のポリシー](https://play.google/developer-content-policy/)に準拠していることを確認してください。

<Info>
  広告識別子のトラッキングを無効にする方法や、広告 ID とあわせて Android ID をトラッキングする方法については、[デバイス識別子のトラッキング](/ja/developer-guide/android-sdk/data-tracking/advanced-or-optional/device-identifier-tracking)を参照してください。
</Info>

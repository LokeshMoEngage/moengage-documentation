---
title: "インストールまたはアップデートのトラッキング"
description: "setAppStatus API を使用して、MoEngage Android SDK でアプリのインストールとアップデートを区別します。"
---

`setAppStatus()` を呼び出して、現在の起動が新規インストールなのか既存インストールのアップデートなのかを SDK に通知します。SDK はこれを自動的に推測しません。アプリ側で状態を判断し、正しい enum 値を渡す必要があります。

<CodeGroup>

```kotlin Kotlin wrap
// Fresh install of the app
MoEAnalyticsHelper.setAppStatus(context, AppStatus.INSTALL)

// Existing user who updated the app
MoEAnalyticsHelper.setAppStatus(context, AppStatus.UPDATE)
```

```java Java
// Fresh install of the app
MoEAnalyticsHelper.INSTANCE.setAppStatus(context, AppStatus.INSTALL);

// Existing user who updated the app
MoEAnalyticsHelper.INSTANCE.setAppStatus(context, AppStatus.UPDATE);
```

</CodeGroup>

<Info>
  アプリをアンインストールしてから再インストールした場合、SDK はそれを新規インストールと見なします。
</Info>

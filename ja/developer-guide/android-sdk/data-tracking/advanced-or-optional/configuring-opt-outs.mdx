---
title: "オプトアウトの設定"
description: "MoEngage Android SDK で、GAID や Android ID などのデバイス識別子のトラッキングのオプトアウトを設定します。"
---

デフォルトでは、SDK は GAID、Android-id、アクティビティ名などの特定のデバイス識別子をトラッキングします。必要に応じて、TrackingOptOutConfig を使用してこのトラッキングをオプトアウトできます。\
利用可能なオプトアウトの詳細については、[TrackingOptOutConfig](https://moengage.github.io/android-api-reference/core/com.moengage.core.config/-tracking-opt-out-config/index.html) の API リファレンスを参照してください。[configureTrackingOptOut()](https://moengage.github.io/android-api-reference/core/com.moengage.core/-mo-engage/-builder/configure-tracking-opt-out.html) を使用して、構成を SDK に渡します。

<CodeGroup>

```Kotlin Kotlin wrap
val trackingOptOut = mutableSetOf<Class<*>>()
trackingOptOut.add(YourActivityName::class.java)
val trackingOptOutConfig = TrackingOptOutConfig(
    isCarrierTrackingEnabled = true,
    isDeviceAttributeTrackingEnabled = true,
    trackingOptOut
)

val moengage = MoEngage.Builder(
        application = application,
        appId = appId,
        dataCenter = DataCenter.DATA_CENTER_X
    )
    .configureTrackingOptOut(trackingOptOutConfig)
    .build()
MoEngage.initialiseDefaultInstance(moengage)
```


```Java Java
Set<Class<?>> trackingOptOut = new HashSet<>();
trackingOptOut.add(YourActivityName.class);
MoEngage moEngage = new MoEngage.Builder(application, appId, DataCenter.DATA_CENTER_X)
    .configureTrackingOptOut(new TrackingOptOutConfig(true, true, trackingOptOut))
    .build();
MoEngage.initialiseDefaultInstance(moEngage);
```

</CodeGroup>

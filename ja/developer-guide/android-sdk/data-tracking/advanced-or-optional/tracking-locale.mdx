---
title: "ロケールのトラッキング"
description: "MoEngage SDK を使用して、Android アプリでデバイスのロケールをオプションでトラッキングします。"
---

<Info>
  **オプション**

  これはオプションであり、ロケールをトラッキングする場合にのみ必要です。
</Info>

SDK はデフォルトではロケールをトラッキングしません。特定の JVM インスタンスに設定されたロケールをトラッキングするには、[MoEAnalyticsHelper.trackDeviceLocale()](https://moengage.github.io/android-api-reference/core/com.moengage.core.analytics/-mo-e-analytics-helper/track-device-locale.html) を呼び出します。

<CodeGroup>

```Kotlin Kotlin wrap
MoEAnalyticsHelper.trackDeviceLocale(context)
```


```Java Java wrap
MoEAnalyticsHelper.INSTANCE.trackDeviceLocale(context);
```

</CodeGroup>

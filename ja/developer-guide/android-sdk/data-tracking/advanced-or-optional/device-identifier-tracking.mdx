## Android ID のトラッキング

SDK バージョン **11.5.00** 以降、SDK はオプションでデバイスの Android-id をトラッキングします (デフォルトでは Android-id はトラッキングされません)。Android-id のトラッキングを有効にするには、以下のように [enableAndroidIdTracking()](https://moengage.github.io/android-api-reference/core/com.moengage.core/enable-android-id-tracking.html) メソッドを使用します。

<CodeGroup>

```Kotlin Kotlin wrap
import com.moengage.core.enableAndroidIdTracking
enableAndroidIdTracking(context)
```


```Java Java
MoESdkStateHelper.enableAndroidIdTracking(context);
```

</CodeGroup>

Android-id のトラッキングを有効にする前に、アプリケーションは [Google のポリシー](https://developer.android.com/identity/user-data-ids)に従ってユーザーの同意を得る必要があります。トラッキングが有効になると、明示的にオプトアウトされるまで SDK は Android-id のトラッキングを継続します。Android-id のトラッキングをオプトアウトするには、[disableAndroidIdTracking()](https://moengage.github.io/android-api-reference/core/com.moengage.core/disable-android-id-tracking.html) メソッドを使用します。

<CodeGroup>

```Kotlin Kotlin wrap
import com.moengage.core.disableAndroidIdTracking
disableAndroidIdTracking(context)
```


```Java Java
MoESdkStateHelper.disableAndroidIdTracking(context);
```

</CodeGroup>

SDK バージョン **11.5.00** 未満の場合は、MoEngage SDK の初期化時に _TrackingOptoutConfig_ を使用してください。

## 広告識別子のトラッキング

<Info>
  広告 ID のトラッキングを有効にする前に、[広告識別子のトラッキングの有効化](/ja/developer-guide/android-sdk/data-tracking/basic/enable-advertising-identifier-tracking)で説明されている `play-services-ads-identifier` の依存関係を追加していることを確認してください。
</Info>

SDK バージョン **12.1.00** 以降、SDK はオプションでデバイスの広告識別子をトラッキングします (デフォルトでは広告識別子はトラッキングされません)。広告識別子のトラッキングを有効にするには、以下のように [enableAdIdTracking()](https://moengage.github.io/android-api-reference/core/com.moengage.core/enable-ad-id-tracking.html) メソッドを使用します。

<CodeGroup>

```Kotlin Kotlin wrap
import com.moengage.core.enableAdIdTracking
enableAdIdTracking(context)
```


```Java Java
MoESdkStateHelper.enableAdIdTracking(context);
```

</CodeGroup>

広告識別子のトラッキングを有効にする前に、アプリケーションは [Google のポリシー](https://support.google.com/googleplay/android-developer/answer/10144311)に従ってユーザーの同意を得る必要があります。

トラッキングが有効になると、明示的にオプトアウトされるまで SDK は広告識別子のトラッキングを継続します。広告識別子のトラッキングをオプトアウトするには、[disableAdIdTracking()](https://moengage.github.io/android-api-reference/core/com.moengage.core/disable-ad-id-tracking.html) メソッドを使用します。

<CodeGroup>

```Kotlin Kotlin wrap
import com.moengage.core.disableAdIdTracking
disableAdIdTracking(context)
```


```Java Java
MoESdkStateHelper.disableAdIdTracking(context);
```

</CodeGroup>

SDK バージョン **12.1.00** 未満の場合は、MoEngage SDK の初期化時に _TrackingOptoutConfig_ を使用してください。

MoEngage Android SDK は、イベントとユーザー属性を通じてユーザーの行動をトラッキングします。**基本**のページでは、すべての統合で必要となる内容（ユーザーの識別、イベントのトラッキング、起動がインストールかアップデートかを MoEngage に伝える方法）について説明します。

**高度またはオプション**のページでは、デバイス識別子、ロケール、トラッキングのオプトアウトについて説明します。

## 基本

| ページ | 内容 |
| --- | --- |
| [イベントのトラッキング](/ja/developer-guide/android-sdk/data-tracking/basic/track-events) | カスタムのユーザーイベントとその属性をトラッキングします。 |
| [ユーザー属性のトラッキング](/ja/developer-guide/android-sdk/data-tracking/basic/track-user-attributes) | ユーザー属性をトラッキングし、ユーザーの識別に使用する一意の識別子を設定します。 |
| [インストールまたはアップデートのトラッキング](/ja/developer-guide/android-sdk/data-tracking/basic/track-install-or-update) | `setAppStatus` API を使用して、インストールとアップデートを区別します。 |
| [広告識別子のトラッキングの有効化](/ja/developer-guide/android-sdk/data-tracking/basic/enable-advertising-identifier-tracking) | デバイス分析のために広告識別子のトラッキングを有効にします。 |
| [SDK バージョン 13.6.00 未満での Unique ID の設定](/ja/developer-guide/android-sdk/data-tracking/basic/setting-unique-id-for-sdk-versions-below-13-6-00) | SDK バージョン 13.6.00 未満で、ログインとログアウトのための一意のユーザー ID を設定します。 |

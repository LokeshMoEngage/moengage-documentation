---
title: "Push AMP Plus の統合"
description: "MoEngage Push Amp+ を統合して、Android OEM デバイスでのプッシュ通知の配信率を向上させます。"
---

通知のおよそ 25～30% が OEM 関連の理由で配信されていません。Push Amplification+ を使用すると、これらの顧客にリーチし、リテンション率を即座に向上させることができます。\
そこで私たちは OEM での配信率の問題の解決に注力し、OEM と提携してこの問題に取り組んできました。

アプリケーションに余分な肥大化をもたらさないよう、OEM ごとに異なる SDK を用意しています。アプリケーションのデバイスシェアに応じて、関連する SDK を統合できます。

以下の各 OEM 固有のサービスのドキュメントを参照し、関連するものをアプリケーションに統合してください。

サポートされている統合は以下のとおりです。

- [HMS Push Kit の設定](https://www.moengage.com/docs/developer-guide/android-sdk/push/optional/push-amp-plus/configuring-hms-push-kit)

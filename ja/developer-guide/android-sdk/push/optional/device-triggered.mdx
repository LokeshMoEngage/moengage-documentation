# 概要

デバイストリガーキャンペーンは、MoEngage SDK でトラッキングされたユーザーイベント（カートの放棄、商品の閲覧、チュートリアルの完了など）に応じて、デバイス上でローカルにプッシュ通知を発火します。`realtime-trigger` モジュールは、トラッキングしたイベントに対してデバイス上でキャンペーンの条件を評価し、サーバーとの往復通信なしで通知をレンダリングするため、レイテンシーが短縮されます。

これらのトリガーを動かすキャンペーンの作成と設定については、[デバイストリガーキャンペーン](https://www.moengage.com/docs/user-guide/campaigns-and-channels/push/create/device-triggered-push)に関するダッシュボードガイドを参照してください。

# 前提条件

- [プッシュトークンの登録と表示](/ja/developer-guide/android-sdk/push/basic/push-token-registration-and-display)の連携を完了してください。realtime-trigger モジュールは、同じプッシュパイプラインを通じて通知をレンダリングします。
- デバイストリガーキャンペーンが依存するイベントをトラッキングしてください。[イベントのトラッキング](/ja/developer-guide/android-sdk/data-tracking/basic/track-events)を参照してください。

# SDK のインストール

## BOM を使用したインストール

BOM を使用した連携が推奨される方法です。[BOM を使用したインストール](/ja/developer-guide/android-sdk/sdk-integration/basic-integration/Install-Using-BOM)を参照してください。BOM を設定したら、`app/build.gradle` に依存関係を追加します。

<CodeGroup>

```groovy build.gradle wrap
dependencies {
    ...
    implementation("com.moengage:realtime-trigger")
}
```

</CodeGroup>

この依存関係にバージョン番号は必要ありません。BOM によって管理されます。

# 仕組み

依存関係を追加すると、SDK は関連付けられたイベントがトラッキングされるたびに、デバイストリガーキャンペーンを自動的に評価してレンダリングします。追加のコードは必要ありません。個々のキャンペーンは MoEngage ダッシュボードから設定します。

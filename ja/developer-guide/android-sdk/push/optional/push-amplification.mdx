# 概要

Push Amplification は、FCM の障害、OEM レベルのスロットリング、ネットワークの問題などにより Firebase Cloud Messaging (FCM) 経由でデバイスに届かなかった通知を回復することで、プッシュの配信率を向上させます。

OEM 固有のチャネル (Huawei) が必要な場合は、[Push Amp Plus の統合](/ja/developer-guide/android-sdk/push/optional/push-amp-plus/push-amp-plus-integration)を参照してください。

# 前提条件

- まず、[プッシュトークンの登録と表示](/ja/developer-guide/android-sdk/push/basic/push-token-registration-and-display)の統合を完了してください。Push Amplification は FCM による主要な配信を補完するものであり、置き換えるものではありません。

# SDK のインストール

## BOM を使用したインストール

BOM を使用した統合が推奨される方法です。[Install Using BOM](/ja/developer-guide/android-sdk/sdk-integration/basic-integration/Install-Using-BOM) を参照してください。BOM を設定したら、`app/build.gradle` に依存関係を追加します。

<CodeGroup>

```groovy build.gradle wrap
dependencies {
    ...
    implementation("com.moengage:push-amp")
}
```

</CodeGroup>

この依存関係にバージョン番号は不要です。BOM が管理します。

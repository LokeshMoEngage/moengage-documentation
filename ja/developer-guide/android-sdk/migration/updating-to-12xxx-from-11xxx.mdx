# 動作の変更

* ビルド設定が以下のように更新されました
	+ compileSdk 30
	+ minSdk 21
	+ targetSdk 30
* SDK バージョン 12.0.00 以降、moe-android-sdk を依存関係として追加しても、以下の機能はデフォルトでは連携されません。これらの機能を使用している場合は、それぞれの連携ドキュメントを参照して依存関係を更新してください。
	+ [InApp](https://www.moengage.com/docs/developer-guide/android-sdk/in-app-messages/in-app-nativ)
	+ [Push Amplification](https://www.moengage.com/docs/developer-guide/android-sdk/push/optional/push-amplification)
	+ [Device Trigger](https://www.moengage.com/docs/developer-guide/android-sdk/push/optional/device-triggered)
* SDK を初期化する API は、App-id が null または空の場合に [*IllegalStateException*](https://developer.android.com/reference/java/lang/IllegalStateException) をスローするようになりました。

## 外部ライブラリのバージョン更新

* androidx.core:core 1.3.1 --> 1.6.0
* androidx.appcompat:appcompat 1.2.0 --> 1.3.1
* androidx.lifecycle:lifecycle-process 2.2.0 --> 2.4.0
* com.google.firebase:firebase-messaging 22.0.0 --> 23.0.0
* Kotlin Standard Library 1.4.20 --> 1.6.0

## Firebase Messaging の変更点

*FirebaseEventListener* は削除されました。代わりに以下のコールバックを使用してください

* [*TokenAvailableListener*](https://moengage.github.io/android-api-reference/pushbase/com.moengage.pushbase.listener/-token-available-listener/index.html) - プッシュトークンが生成されるたびにトークンを取得します。
* [*NonMoEngagePushListener*](https://moengage.github.io/android-api-reference/moe-push-firebase/com.moengage.firebase.listener/-non-mo-engage-push-listener/index.html) - MoEngage サーバー以外からのプッシュを受信するたびにコールバックを取得します。
* *MoEFireHelper* から以下のメソッドが削除されました
	+ setEventListener(FirebaseEventListener)
	+ addEventListener(FirebaseEventListener)

代わりに、TokenAvailableListener と NonMoEngagePushListener を追加するために提供されているメソッドを使用してください。

## HMS Push Kit の変更点

*PushKitEventListener* は削除されました。代わりに以下のコールバックを使用してください

* [*TokenAvailableListener*](https://moengage.github.io/android-api-reference/pushbase/com.moengage.pushbase.listener/-token-available-listener/index.html) - プッシュトークンが生成されるたびにトークンを取得します。
* [*NonMoEngagePushListener*](https://moengage.github.io/android-api-reference/hms-pushkit/com.moengage.hms.pushkit.listener/-non-mo-engage-push-listener/index.html) - MoEngage サーバー以外からのプッシュを受信するたびにコールバックを取得します。
* *MoEPushKitHelper* から以下のメソッドが削除されました
	+ setEventListener(PushKitEventListener)
	+ addEventListener(PushKitEventListener)

リスナーの設定方法の詳細については、[Configuring HMS Push Kit](https://www.moengage.com/docs/developer-guide/android-sdk/push/optional/push-amp-plus/configuring-hms-push-kit) のドキュメントを参照してください。

# InApp の変更点

InAppMessageListener は削除されました。代わりに以下のコールバックを使用してください

* *OnClickActionListener* - アプリ内メッセージのクリックコールバック用です。
* [*SelfHandledAvailableListener*](https://moengage.github.io/android-api-reference/inapp/com.moengage.inapp.listeners/-self-handled-available-listener/index.html) - Self handled キャンペーンが利用可能になったときのコールバック用です。
* [*InAppLifeCycleListener*](https://moengage.github.io/android-api-reference/inapp/com.moengage.inapp.listeners/-in-app-life-cycle-listener/index.html) - 表示、閉じるなどのアプリ内メッセージのライフサイクルコールバック用です。

リスナーの設定方法の詳細については、[InApp](https://www.moengage.com/docs/developer-guide/android-sdk/in-app-messages/in-app-nativ) のドキュメントを参照してください。

*MoEInAppHelper* から削除されたメソッド

| --- | --- |
| MoEInAppHelper#getSelfHandledInApp(Context) | MoEInAppHelper#getSelfHandledInApp(Context, SelfHandledAvailableListener) |

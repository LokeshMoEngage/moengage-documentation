---
title: "addon-inbox 6.0.2 からの移行"
description: "MoEngage Android SDK で、addon-inbox 6.0.2 から更新された inbox-core および inbox-ui モジュールに移行します。"
---

<Info>
この移行は、*addon-inbox 6.0.2* 以下を使用していて、moe-android-sdk の *11.2.00* 以上のバージョンに移行する場合にのみ必要です。
</Info>

MoEngage の初期から、アプリケーションで通知センターを使用するための `addon-inbox` アーティファクトを提供してきました。今回、このモジュールを刷新し、より堅牢かつ軽量で、今後の改善や機能強化に対応できるスケーラブルなものにするため、複数のモジュールに分割しました。

# 更新されたアーティファクト

`inbox-core` - 受信トレイを構築するための API とヘルパーメソッドを含むモジュールです。メッセージの取得、クリックのトラッキングなどのための API を提供します。

`inbox-ui` - 受信トレイモジュールのユーザーインターフェースと、UI をカスタマイズするためのヘルパーメソッドを含むモジュールです。

# SDK の通知センターの使用

SDK が提供する UI を使用している場合は、アプリケーションに `inbox-ui` モジュールを含める必要があります。アーティファクト名の更新以外の主な変更点は以下のとおりです。

* ListView の代わりに RecyclerView を使用
* UI の更新
* UI をカスタマイズするための API の更新

デフォルトの UI の使用方法と可能なカスタマイズの詳細については、更新された [MoEngage のデフォルトの通知センター](https://www.moengage.com/docs/developer-guide/android-sdk/push/optional/notification-center)を参照してください。

# セルフハンドルの通知センター

MoEngage のデータを使用して独自の通知センターを構築していた場合、API がよりシンプルになり、SDK も軽量になりました。`inbox-core` モジュールを統合してください。

更新された API については、[セルフハンドルの通知センター](https://www.moengage.com/docs/developer-guide/android-sdk/push/optional/notification-center#self-handled-notification-center)を参照してください。

# パッケージの更新:

モジュールを刷新する一方で、可能な限り再統合を避けられるよう、一部のクラスは維持するようにしました。API 自体は変更していませんが、今後のより良い統合のために新しいパッケージに移動しています。

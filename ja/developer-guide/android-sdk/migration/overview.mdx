MoEngage Android SDK の各メジャーバージョンには、変更された API、モジュール、ビルド構成を説明する移行ページがあります。現在使用しているバージョンから順番に進めてください。

## バージョンのアップグレード

| ページ | 内容 |
| --- | --- |
| [11.x.xx から 12.x.xx への更新](/ja/developer-guide/android-sdk/migration/updating-to-12xxx-from-11xxx) | 更新されたビルド構成と、モジュール化された InApp と Push。 |
| [10.x.xx から 11.x.xx への更新](/ja/developer-guide/android-sdk/migration/updating-to-11xxx-from-10xxx) | 更新された API、Java 8 のサポート、モジュール化されたジオフェンスのセットアップ。 |
| [10.x.xx への移行](/ja/developer-guide/android-sdk/migration/migration-to-10xxx) | 更新された API、GCM サポートの削除、動作の変更。 |
| [4.x から 5.x への移行 (1 回限りの作業)](/ja/developer-guide/android-sdk/migration/migration-from-4x-to-5x-one-time-activity) | 更新されたレシーバーと API。 |

## インフラストラクチャとモジュールの変更

| ページ | 内容 |
| --- | --- |
| [Firebase Installation ID への移行](/ja/developer-guide/android-sdk/migration/migrating-to-firebase-installation-id) | BOM 4.4.0 にアップグレードする際に、Firebase Installation ID に移行します。 |
| [Maven Central への移行](/ja/developer-guide/android-sdk/migration/migration-to-maven-central) | 依存関係を JCenter から Maven Central に移行します。 |
| [Manifest ベースからコードベースの連携への移行](/ja/developer-guide/android-sdk/migration/moving-from-manifest-to-code-based-integration) | Manifest のメタデータからコードベースの初期化に移行します。 |
| [addon-inbox 6.0.2 からの移行](/ja/developer-guide/android-sdk/migration/migrating-from-addon-inbox-602) | `inbox-core` モジュールと `inbox-ui` モジュールに移行します。 |

<Note>
  アップグレードを計画する前に、[Android SDK の非推奨バージョン](/ja/developer-guide/android-sdk/deprecated-versions/deprecated-versions) で現在のバージョンのサポート状況を確認してください。
</Note>

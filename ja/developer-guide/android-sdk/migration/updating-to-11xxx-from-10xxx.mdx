# 動作の変更

* Target SDK バージョンが API レベル 29 に引き上げられました
* SDK バージョン `11.0.00` 以降、アプリケーションに `moe-android-sdk` を追加しても Geofence は含まれません。Geofence モジュールを連携して使用するには、[Location triggered Push](https://www.moengage.com/docs/developer-guide/android-sdk/push/optional/location-triggered) のドキュメントを参照してください。
* 内部ファイルと公開クラスを明確に分離するため、SDK が再パッケージ化されました。パッケージ名が `com.moengage.*.internal.*` のクラスは使用しないでください。これらのクラスの API は予告なく更新/削除される可能性があるため、連携するアプリケーションで使用しないでください。
* InApp は Activity のライフサイクルコールバック経由で表示されなくなりました。アプリ内メッセージを表示するには、Activity または Fragment で `showInApp()` を呼び出す必要があります。詳細については、[In-App NATIV](https://www.moengage.com/docs/developer-guide/android-sdk/in-app-messages/in-app-nativ) のドキュメントを参照してください。
* Source および Target Compatibility が Java 8 に更新されました。まだ有効にしていない場合は、アプリケーションで Java 8 を有効にしてください。
* このリリースでは、SDK が使用するホストを更新しました。アプリケーションのネットワーク設定で MoEngage のエンドポイントをホワイトリストに登録している場合は、エンドポイントを更新してください。詳細については、[Network Security Configuration](https://www.moengage.com/docs/developer-guide/android-sdk/sdk-integration/basic-integration/sdk-initialization) を参照してください。
* SDK はデフォルトで位置情報をトラッキングしなくなりました。

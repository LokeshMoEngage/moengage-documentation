---
title: "Maven Central への移行"
description: "MoEngage Android SDK の依存関係を JCenter から Maven Central に移行します。"
---

JFrog は最近、Bintray および JCenter のユーザーに影響を与える重要な変更を行うことを発表しました。開発者は 2021 年 3 月 31 日以降 Bintray に新しいパッケージを公開できなくなり、既存のパッケージは 2022 年 2 月 1 日以降利用できなくなります。  
詳細については、[ブログ記事](https://jfrog.com/blog/into-the-sunset-bintray-jcenter-gocenter-and-chartcenter/)をご覧ください。

MoEngage では、過去数年間 Android SDK およびアーティファクトを Jcenter に公開してきましたが、Maven Central への公開に移行しました。今後、すべてのアーティファクトは Maven Central 経由でのみ利用可能になります。

# どのような影響がありますか？

既存のパッケージは 2022 年 2 月 1 日までダウンロード可能なため、サービス終了による影響はすぐには発生しません。ただし、問題を回避するために、できるだけ早く Maven Central で公開されているバージョン（`11.0.04` 以上）に移行することを強くお勧めします。

<Info>
記載されているバージョンは、本ドキュメントの公開時点（2021 年 3 月 1 日）での最新バージョンです。各フレームワークのリリースノートを参照してください。
</Info>

# 11.x.xx の移行

MoEngage SDK の 11.x.xx バージョンを使用している場合は、バージョンを `11.0.04` 以上に変更するだけで Maven Central のアーティファクトに移行できます。  
他の非バンドル/依存 MoEngage SDK やモジュール（Push Amp Plus、Push Templates など）も互換性のあるバージョンに更新してください。  
以下は、Maven Central での最初のバージョンである `11.0.04` と互換性のあるバージョンの一覧です。

| アーティファクト | バージョン |
| --- | --- |
| moe-android-sdk | 11.0.04 |
| addon-inbox | 6.0.2 |
| cards | 2.0.02 |
| hms-pushkit | 2.0.02 |
| push-amp-plus | 3.0.02 |
| rich-notification | 2.0.03 |
| geofence | 1.0.02 |

# 10.x.xx の移行

最新の SDK バージョンに更新してください。複数のメジャーバージョンにまたがるため、`build.gradle` でのバージョン更新に加えて、追加のコード変更が必要です。以下の移行ガイドを順番に実施してください。

1. [10.x.xx から 11.x.xx への更新](/ja/developer-guide/android-sdk/migration/updating-to-11xxx-from-10xxx)
2. [11.x.xx から 12.x.xx への更新](/ja/developer-guide/android-sdk/migration/updating-to-12xxx-from-11xxx)

最新バージョンと完全なバージョン履歴については、[Android SDK リリースノート](/ja/release-notes/sdks/android)を参照してください。他の非バンドルまたは依存 MoEngage モジュール（Push Amp Plus、Push Templates など）も互換性のあるバージョンに更新してください。

技術的な制約やリソースの問題により `11.x.xx` に更新できない場合に備えて、最後の `10.x.xx` バージョンとアドオンモジュールを Maven Central にアップロードしています。以下のバージョンに更新できます。

| アーティファクト | バージョン |
| --- | --- |
| moe-android-sdk | 10.6.01 |
| addon-inbox | 5.3.1 |
| cards | 1.2.01 |
| hms-pushkit | 1.2.01 |
| push-amp-plus | 2.2.01 |
| rich-notification | 1.2.02 |

<Info>
最新の機能、改善、最適化をすべて活用するために、10.6.01 ではなく最新バージョンに更新することを強くお勧めします。
</Info>

# 10.x.xx 未満の移行

最新バージョンへの更新をお勧めします。9.x.xx 以下のバージョンを Maven Central に公開または移行する予定はありません。2 つのメジャーバージョンを更新することになるため、ドキュメントを確認したうえで適宜更新することをお勧めします。

# クロスプラットフォームフレームワーク

MoEngage は、React-Native、Flutter、Unity、Cordova など、多くのクロスプラットフォームフレームワークをサポートしています。クロスプラットフォームフレームワークは上記のネイティブ（Java/Kotlin）Android SDK に依存しているため、Jcenter のサービス終了の影響を同様に受けます。クロスプラットフォームのプラグインやパッケージは、Jcenter ではなく Maven Central で公開されたアーティファクトを使用するように更新済みです。  
以下はプラグインの最新バージョンです。

| フレームワーク名 | バージョン |
| --- | --- |
| React-Native | 7.0.0 |
| Flutter | 3.0.0 |
| Flutter Inbox | 2.0.0 |
| Cordova | 7.0.0 |
| Unity | 2.0.0 |

上記のバージョンは `11.x.xx` をベースに構築されており、上記以上のバージョンを使用することを強くお勧めします。

技術的な制約やリソースの問題により `11.x.xx` に更新できない場合に備えて、最後の `10.x.xx` バージョンとアドオンモジュールを Maven Central にアップロードしています。以下のバージョンに更新できます。これらのバージョンは、Maven Central 上の `10.x.xx` バージョンである `10.6.01` をベースに構築されています。

| フレームワーク名 | バージョン |
| --- | --- |
| React-Native | 6.1.7 |
| Flutter | 2.0.3 |
| Flutter Inbox | 1.0.2 |
| Cordova | 6.1.4 |
| Unity | 1.3.1 |

# Segment 連携

問題を回避するために、できるだけ早く Maven Central で公開されているバージョン（`5.1.00` 以上）に移行することをお勧めします。

# 5.x.xx の移行

MoEngage SDK の 5.x.xx バージョンを使用している場合は、バージョンを `5.1.00` 以上に変更するだけで Maven Central のアーティファクトに移行できます。  
他の非バンドル/依存 MoEngage SDK やモジュール（Push Amp Plus、Push Templates など）も互換性のあるバージョンに更新してください。

# 4.x.xx の移行

最新の SDK バージョン `5.1.00` 以上に更新してください。メジャーバージョンの更新となるため、gradle ファイルのバージョン番号の変更に加えて、追加のコード変更が必要になる場合があります。詳細については、[11.x.xx への更新](/ja/developer-guide/android-sdk/migration/updating-to-11xxx-from-10xxx)ドキュメントおよび[リリースノート](/ja/release-notes/sdks/android)を参照してください。  
他の非バンドル/依存 MoEngage SDK やモジュール（Push Amp Plus、Push Templates など）も互換性のあるバージョンに更新してください。

技術的な制約やリソースの問題により `5.x.xx` に更新できない場合に備えて、最後の `4.x.xx` バージョンとアドオンモジュールを Maven Central にアップロードしています。以下のバージョンに更新できます。

| アーティファクト | バージョン |
| --- | --- |
| moengage-segment-integration | 4.3.01 |
| addon-inbox | 5.3.1 |

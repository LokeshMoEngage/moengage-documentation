<Info>
  **過去の移行ガイド。** このページでは、GCM から FCM への移行以前の、MoEngage Android SDK 4.x から 5.x への移行について説明します。すでに SDK 5.x 以降を使用している場合は、このページをスキップしてください。代わりに、最新の [SDK の統合](/ja/developer-guide/android-sdk/sdk-integration/basic-integration/configuring-build-settings)およびバージョン別の移行ガイドを使用してください。
</Info>

[こちら](/ja/developer-guide/android-sdk/sdk-integration/basic-integration/Install-Using-BOM)に記載されているインストール手順に従ってください。

5.x への移行に必要な変更は最小限ですが、一部の構造的な変更により、いくつかのコード行を削除する必要があります。これは、疎結合で統合しやすくするために必要な変更です。

- Manifest の権限に変更はありません
- 基本的な統合ポイントは同じです
- レシーバーとサービスが変更されています
- いくつかの API を非推奨にし、代替を提供しています
- Inbox はメイン SDK から分離され、アドオンライブラリに追加されました

Play Services 7.3 を使用している場合、**以下のレシーバーに変更はありません**。

<CodeGroup>

```XML XML wrap
{/*  MOENGAGE RECEIVER FOR RECEIVING GCM BROADCAST MESSAGES  */}
<receiver
    android:name="com.moe.pushlibrary.PushGcmBroadcastReceiver"
    android:permission="com.google.android.c2dm.permission.SEND" >
    <intent-filter>
        <action android:name="com.google.android.c2dm.intent.RECEIVE" />
        <action android:name="com.google.android.c2dm.intent.REGISTRATION" />

        <category android:name="{YOUR_PACKAGE_NAME}" />
    </intent-filter>
</receiver>
{/*  MOENGAGE RECEIVER FOR RECEIVING INSTALLATION INTENT  */}
<receiver android:name="com.moe.pushlibrary.InstallReceiver" >
    <intent-filter>
        <action android:name="com.android.vending.INSTALL_REFERRER" />
    </intent-filter>
</receiver>
```

</CodeGroup>

# 以下のレシーバーを削除する

<CodeGroup>

```Java Java wrap
{/*  MOENGAGE RECEIVER FOR RECEIVING PACKAGE UPDATED INTENT  */}
<receiver android:name="com.moe.pushlibrary.PushUpdateReceiver" >
    <intent-filter>
        <action android:name="android.intent.action.PACKAGE_REPLACED" />
        <data
            android:path="{YOUR_PACKAGE_NAME}"
            android:scheme="package" />
    </intent-filter>
</receiver>
{/*  MOENGAGE SERVICE PROCESSING GCM MESSAGES  */}
<service android:name="com.moe.pushlibrary.PushGCMIntentService" />
{/*  MOENGAGE RECEIVER FOR INTERNAL PURPOSE  */}
<receiver android:name="com.moe.pushlibrary.PushGcmRegister" />
{/*  MOENGAGE RECEIVER FOR TRIGGERING INTERACTION DATA SYNC  */}
<receiver android:name="com.moe.pushlibrary.SendReport" />
```

</CodeGroup>

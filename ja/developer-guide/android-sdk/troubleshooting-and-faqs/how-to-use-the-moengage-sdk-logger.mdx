---
title: "MoEngage SDK Logger の使用方法"
description: "ダッシュボードから MoEngage SDK Logger を使用して、ビルドを共有せずに実装の問題をデバッグします。"
---

### 手順:

以下の手順を実行します。

1. MoEngage ダッシュボードにログインします。
2. **Test and Debug** セクションに移動します。

   <Frame>
     ![Sdk](/images/sdk.png)
   </Frame>
3. **SDK logger** タブを選択すると、QR コードが表示されます。

<Info>
  デフォルトでは、Logger セッションは 2 時間有効です。テスト用のモバイルデバイスから延長できます。

  MoEngage SDK Logger は、以下の SDK バージョンからサポートされています。

  - Android SDK 13.04.00
  - React Native SDK 10.3.0
  - Flutter SDK 9.0.0
  - Capacitor SDK 5.0.0
  - Cordova SDK 9.0.0
</Info>

<Frame>
  ![Sdklogger(1)](/images/sdklogger\(1\).png)
</Frame>

4. Logger を開始するには、モバイルデバイスで QR コードをスキャンします。リンクを含むポップアップが表示されます。

5. リンクを開き、**Click here** ボタンをクリックします。リンクによってアプリが開くか、MoEngage SDK と統合されたアプリケーションの一覧が表示されます。

<Frame>
  ![Popuplink(1)](/images/popuplink\(1\).png)
</Frame>

6. デバッグするアプリケーションを選択します。Logger の情報を表示するページが読み込まれます。

<Frame>
  ![Application(1)](/images/application\(1\).png)
</Frame>

 7. アプリを閉じてから再度開きます。問題を再現する手順を実行します。
 8. ダッシュボードに戻り、**Refresh** をクリックして、すべてのアクティブなセッションの一覧を表示します。

    <Frame>
      ![Refresh(1)](/images/refresh\(1\).png)
    </Frame>
 9. デバイスモデルで識別される最新のセッションを選択します。
10. ログが表示されない場合は、もう一度 **Refresh** をクリックします。ログが表示されたら、**Copy Session ID** をクリックし、デバッグのために ID を MoEngage サポートチームと共有します。

    <Frame>
      ![Sessionid(1)](/images/sessionid\(1\).png)
    </Frame>

<Info>
  開発者はログでエラーや例外を確認できます。検索フィールドを使用して特定のログを検索することもできます。
</Info>

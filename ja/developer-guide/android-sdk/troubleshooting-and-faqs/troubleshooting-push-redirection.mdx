title: "プッシュリダイレクトのトラブルシューティング"
description: "Android でのディープリンク、プッシュ CTA ボタン、リッチランディングページのリダイレクトに関する一般的な問題を解決します。"
---

この記事では、ディープリンクやプッシュ通知のクリック時に発生する一般的な問題について説明します。

## ディープリンクのリダイレクトが機能しない

これは、指定されたディープリンクを処理するアクティビティをマニフェストで設定していないことが原因である可能性があります。以下の adb コマンドを使用して、ディープリンクが正しく設定され、期待される画面にリダイレクトされるかを確認してください。

```text wrap
 adb shell am start
        -W -a android.intent.action.VIEW
        -d <URI> <PACKAGE>
```

上記のコマンドでナビゲーションが期待どおりに機能しない場合は、ディープリンクの設定方法に問題があります。アプリケーションでディープリンクを設定するには、こちらの[公式ドキュメント](https://developer.android.com/training/app-links/deep-linking)を参照してください。

## プッシュ通知の CTA ボタンのクリックが機能しない

これは、デフォルトの MoEngage ハンドラーとは別にカスタムプッシュリスナーを使用している場合に発生することがあります。プッシュ通知のデフォルトのクリックは処理しているものの、CTA ボタンのクリック処理を実装していない可能性が高いです。動作が期待どおりになるよう、CTA ボタンのクリック処理を追加してください。

## リッチランディングページで Web ページ / URL がレンダリングされない

Android の公式ドキュメントによると、WebView オブジェクトを使用すると、アクティビティレイアウトの一部として Web コンテンツを表示できますが、完全に開発されたブラウザの機能の一部が欠けています。

WebView はアプリ内でリッチランディングページを読み込むために使用されます。WebView は通常のブラウザがサポートするすべての機能をサポートしているわけではないため、リッチランディングのリダイレクトで Web サイトが読み込まれない可能性があります。

このケースに対処するには、Web ページを WebView に対応させるか、カスタムプッシュリスナーのコードを使用してユーザーをデバイスのブラウザにリダイレクトしてください。

## React Native、Flutter、Cordova でクリックコールバックが受信されない

これは、ハイブリッドフレームワークの実装で初期化コードの追加を忘れている場合に発生することがあります。

MoEInitializer.initializeDefaultInstance(applicationContext, moEngage)

初期化手順に従って、上記の行がコードに含まれていることを確認してください。 

## ディープリンクのクリックで、Android 11 ではアプリが開き、Android 12 ではブラウザが開く

Android 12（API レベル 31）以降、汎用的な Web インテントは、アプリケーションがその Web インテントの特定のドメインに対して承認されている場合にのみ、アプリケーション内のアクティビティに解決されます。アプリケーションがドメインに対して承認されていない場合、Web インテントはデバイスのデフォルトブラウザに解決されます。ドメインに対してアプリケーションを承認/検証する方法の詳細については、[Google の公式ドキュメント](https://developer.android.com/training/app-links/verify-android-applinks)を参照してください。

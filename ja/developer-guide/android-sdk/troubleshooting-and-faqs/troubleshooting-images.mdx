この記事では、Android プッシュ通知における画像レンダリングに関するよくある質問と、その解決方法について説明します。

## 通知でスモールアイコンが正しくレンダリングされないのはなぜですか？

次の画像のように、スモール通知アイコンがボックスや円として表示される場合があります。

![スモールアイコンの問題](/images/SmallIcon_Issue.png)

スモール通知アイコンを正しくレンダリングするには、スモール通知アイコンが次の条件を満たしていることを確認してください。

- フラットであること
- 正面から描かれていること
- 透明な背景に白色であること

詳細については、[スモール通知アイコンのガイドライン](/ja/developer-guide/android-sdk/push/basic/push-configuration)および [Android 通知ガイドライン](https://m2.material.io/design/platform-guidance/android-notifications.html#anatomy-of-a-notification)を参照してください。

## プッシュ通知でラージアイコンがレンダリングされない

次の場合、プッシュ通知にラージアイコンは表示されません。

- 通知のラージアイコンが SDK の初期化に含まれていない。ラージアイコンの設定方法については、[プッシュ設定](/ja/developer-guide/android-sdk/push/basic/push-configuration)のドキュメントを参照してください。
- キャンペーンで設定されたラージアイコンのダウンロードに失敗した。
- SDK の統合時に、通知設定でラージアイコンの表示を明示的に無効にしている。SDK の初期化時に _NotificationConfig_ オブジェクトで **_isLargeIconDisplayEnabled_** の値を false に設定していないか確認してください。値が false に設定されていないことを確認してください。false の場合、ラージアイコンは表示されません。
- キャンペーンのテンプレート設定でラージアイコンの表示が無効になっている。キャンペーンを確認してください。
- テンプレートがラージアイコンをサポートしていない。キャンペーンのプレビューを確認してください。

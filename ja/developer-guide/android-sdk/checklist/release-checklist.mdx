---

MoEngage SDK を統合したアプリケーションをリリースする前に、以下の項目が実装されているかどうかを確認してください。

# 全般

* SDK が Application クラスの *onCreate()* でメインスレッド上で初期化されている。
* ロギングを有効にしている場合は、リリースビルドで無効にしている。
* Java 8 のターゲットおよびソース互換性を有効にしている。

# データトラッキング

* インストール/アップデートの区別
* ユースケースに基づいて、イベントと属性が網羅的にトラッキングされている。
* 新規ユーザーと既存ユーザーの両方についてユーザー属性がトラッキングされている
* ログイン時に `identifyUser()` を使用してユーザーの一意の識別子をトラッキングしている。`setUniqueId()` は SDK 13.6.00 以降非推奨です。[ユーザー属性のトラッキング](/ja/developer-guide/android-sdk/data-tracking/basic/track-user-attributes#identifying-users)を参照してください。
* ユーザーがアプリケーションからログアウトしたときに logout メソッドが呼び出されている

# プッシュ通知

## FCM

* Firebase Messaging の依存関係と関連する Firebase プラグインが追加されている。
* スモールアイコンとラージアイコン、およびその他のオプションのメタデータが設定されている
* 通知アイコンにベクタードローアブル、.webp、または .png 画像以外のファイル形式を使用している場合は、アプリがサポートするすべての OS バージョンでテストしていることを確認してください。
* **AndoidManifest.xml** ファイルの Firebase レシーバーを確認する。マニフェストファイルにレシーバーが 1 つだけ追加されていることを確認してください。
* 実機でプッシュをテストする
* トークン登録とペイロードをアプリで処理する場合
	+ MoEngage SDK のトークン登録を無効にしている
	+ 新規インストール時、アプリのアップデート時、および FCM がトークンを更新するたびに、トークンを SDK に渡している。
	+ プッシュペイロードを SDK に渡している
* トークン登録とペイロードを SDK で処理する場合
	+ SDK の FCM レシーバーがマニフェストに追加されている
	+ 必要に応じてトークン変更リスナーが登録されている。

## Push Amp Plus

### Push Kit

* Push Kit の依存関係が追加され、関連する HMS プラグインが構成されている。
* PushKit の依存関係と **moe-android-sdk** のバージョン互換性を確認する
* Huawei デバイスでテストする

## プッシュテンプレート

* Push Templates の依存関係と **moe-android-sdk** のバージョン互換性を確認する
* デバイスでテンプレートキャンペーンをテストする。

# アプリ内メッセージ

* Glide の依存関係が追加されている。In-App バージョン 7.0.0 以降、画像と GIF の描画に必要です。
* アプリ内メッセージを表示するすべての Activity または Fragment で `showInApp()` を呼び出している。
* Nudge を表示する Activity または Fragment で `showNudge()` を呼び出している。
* デバイスでアプリ内キャンペーンをテストする。

# Inbox

* Inbox の依存関係と **moe-android-sdk** のバージョン互換性を確認する
* アプリケーションの受信トレイにキャンペーンが表示されるかどうかを確認する。

# Cards

* Cards の依存関係と **moe-android-sdk** のバージョン互換性を確認する
* デバイスにカードキャンペーンが表示されるかどうかを確認する。

# ジオフェンス

* Geofence の依存関係と **moe-android-sdk** のバージョン互換性を確認する
* アプリケーションに Google の Location Services が依存関係として追加されている。
* アプリケーションが OS バージョンに応じて適切な権限をリクエストしている。

# SDK のインストール

必要なモジュールを統合するには、**_app/build.gradle(.kts)_** ファイルに以下の依存関係を追加します。**\$sdkVersion** は適切な SDK バージョンに置き換えてください。

## Core

<CodeGroup>

```Kotlin build.gradle(.kts) wrap
dependencies {
    ...
    implementation("com.moengage:moe-android-sdk:$sdkVersion")
}
```

</CodeGroup>

## Self-Handled Cards

<CodeGroup>

```Kotlin build.gradle(.kts) wrap
dependencies {
    ...
    implementation("com.moengage:cards-core:$sdkVersion")
}
```

</CodeGroup>

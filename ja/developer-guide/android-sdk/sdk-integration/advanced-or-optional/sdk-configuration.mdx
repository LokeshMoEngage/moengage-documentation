<Info>
  このページでは、MoEngage Android SDK のコンパイルに使用されるビルド仕様 (target/compile/min SDK、Kotlin、AGP) と、SDK が依存するライブラリのバージョンを示します。機能の有効化、プッシュ、アプリ内メッセージ、分析などのランタイム設定オプションについては、**SDK Integration** の関連する統合ページを参照してください。
</Info>

# ビルド仕様

| 設定 | API レベル |
| --- | --- |
| Target SDK Version | 36 |
| Compile SDK Version | 36 |
| Minimum SDK Version | 23 |
| Kotlin Version | 2.3.20 |
| Android Gradle Plugin Version | 9.1.1 |
| Gradle Version | 9.3.1 |

バージョン名を確認するには、[API レベルとコード名の対応表](https://source.android.com/setup/start/build-numbers)を参照してください。

# ライブラリの依存関係

SDK は以下のバージョンを使用してコンパイルされていますが、アプリケーションはランタイム時にこれらを上書きできます。

SDK は以下のライブラリでコンパイルされています。

<CodeGroup>

```groovy Groovy wrap
androidx.core:core:1.16.0
androidx.appcompat:appcompat:1.7.1
androidx.lifecycle:lifecycle-process:2.10.0
```

</CodeGroup>

 

<Warning>
  ビルド構成は、現在の SDK バージョンについてのみ提供されています。古いバージョンの SDK を使用していてビルド構成を知りたい場合は、MoEngage サポートまたはアカウントマネージャーにお問い合わせください。
</Warning>

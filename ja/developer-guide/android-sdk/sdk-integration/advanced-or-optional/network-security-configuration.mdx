---
title: "ネットワークセキュリティ構成"
description: "カスタムの Android ネットワークセキュリティ構成で、MoEngage SDK のドメインをホワイトリストに登録します。"
---

<Info>
このセクションは、アプリケーションにカスタムのネットワークセキュリティ構成がある場合にのみ必要です。
</Info>

アプリケーションに、データの送信先ドメインをホワイトリストで制限するネットワークセキュリティ構成がある場合は、SDK の統合時に選択した MoEngage データセンターに応じて、以下のドメインをホワイトリストに登録してください。

| データセンター | ホスト |
| --- | --- |
| DATA\_CENTER\_1 | sdk-01.moengage.com |
| DATA\_CENTER\_2 | sdk-02.moengage.com |
| DATA\_CENTER\_3 | sdk-03.moengage.com |
| DATA\_CENTER\_4 | sdk-04.moengage.com |
| DATA\_CENTER\_5 | sdk-05.moengage.com |
| DATA\_CENTER\_6 | sdk-06.moengage.com |

デフォルトでは、SDK はデータを *DATA\_CENTER\_1* に送信します。SDK の初期化時にデータセンターを設定していない場合は、*DATA\_CENTER\_1* に対応するホストをホワイトリストに登録してください。

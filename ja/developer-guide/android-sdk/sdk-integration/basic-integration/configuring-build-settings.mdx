## Maven リポジトリを追加する

プロジェクトに `mavenCentral()` リポジトリを追加します。宣言する場所は、プロジェクトのリポジトリ管理方法によって異なります。

### `settings.gradle` を使用するプロジェクト (Android Studio Flamingo 以降)

新しい Android プロジェクト (Android Studio Flamingo 以降で作成) では、`settings.gradle(.kts)` でリポジトリを管理します。`dependencyResolutionManagement` に `mavenCentral()` を追加します。

<CodeGroup>

```Groovy settings.gradle
dependencyResolutionManagement {
    repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
    repositories {
        google()
        mavenCentral()
    }
}
```

```Kotlin settings.gradle.kts
dependencyResolutionManagement {
    repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
    repositories {
        google()
        mavenCentral()
    }
}
```

</CodeGroup>

### `allprojects` を使用するプロジェクト (古いバージョンの Android Studio)

プロジェクトで引き続きプロジェクトレベルの `build.gradle` を使用してリポジトリを宣言している場合は、そこに `mavenCentral()` を追加します。

<CodeGroup>

```Groovy build.gradle wrap
buildscript {
    repositories {
        mavenCentral()
    }
}
allprojects {
    repositories {
        mavenCentral()
    }
}
```

</CodeGroup>

## Java 8 を有効にする

SDK は Java プログラミング言語のバージョン 8 とターゲット互換およびソース互換です。まだ有効にしていない場合は、アプリケーションの `build.gradle(.kts)` で Java 8 を有効にしてください。

<CodeGroup>

```Groovy build.gradle wrap
android {
  ...
  compileOptions {
     sourceCompatibility JavaVersion.VERSION_1_8
     targetCompatibility JavaVersion.VERSION_1_8
  }
  kotlinOptions {
     jvmTarget = '1.8'
  }
}
```


```Kotlin build.gradle.kts
android {
  ...
  compileOptions {
     sourceCompatibility = JavaVersion.VERSION_1_8
     targetCompatibility = JavaVersion.VERSION_1_8
  }
  kotlinOptions {
     jvmTarget = "1.8"
  }
}
```

</CodeGroup>

サンプルの詳細については、[Android Sample](https://github.com/moengage/Android-Sample) を参照してください。

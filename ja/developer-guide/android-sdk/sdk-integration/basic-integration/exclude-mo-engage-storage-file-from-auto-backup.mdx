</Warning>

Android の自動バックアップサービスは、Shared Preference ファイルやデータベースファイルなどを定期的にバックアップします。

詳細については、[自動バックアップ](https://developer.android.com/guide/topics/data/autobackup)を参照してください。

このバックアップにより、MoEngage SDK の識別子がバックアップされ、再インストール後に復元されます。識別子が復元されると、データが破損し、プッシュ通知でユーザーにリーチできなくなります。

バックアップの復元後にデータが破損しないようにするには、MoEngage SDK のストレージファイルをバックアップ対象から除外してください。

# マニフェストファイルの _application_ タグにバックアップ記述子を追加します。

バックアップ記述子は、_application_ タグの _fullBackupContent_ 属性に割り当てる必要があります。

<CodeGroup>

```xml AndroidManifest.xml wrap
<application
...
android:fullBackupContent="@xml/backup_descriptor">
</application>
```

</CodeGroup>

# 記述子ファイルで MoEngage のファイルを除外します。

以下のデータベースファイルと Shared Preference ファイルを記述子で除外し、これらのファイルがバックアップ**_されない_**ようにします。

<CodeGroup>

```xml XML wrap
<?xml version="1.0" encoding="utf-8"?>
<full-backup-content>
<exclude domain="database" path="MOEInteractions"/>
<exclude domain="sharedpref" path="pref_moe.xml"/>
<exclude domain="sharedpref" path="pref_moe_common.xml"/>
</full-backup-content>
```

</CodeGroup>

MoEngage SDK のファイルのみを除外したい場合は、新しいファイルを作成する代わりに、以下のように SDK が提供するバックアップ記述子ファイルをマニフェストファイルに直接追加できます。

<CodeGroup>

```xml AndroidManifest.xml wrap
<application
...
android:fullBackupContent="@xml/com_moengage_backup_descriptor">
</application>
```

</CodeGroup>

**targetSdkVersion** が 31 以上のアプリケーションでは、新しい形式でも除外を行う必要があります。

# API レベル 31 以上での除外

## マニフェストフラグを追加する

以下のように、マニフェストファイルで新しい構成ファイルを宣言します。

<CodeGroup>

```xml XML wrap
<application
    ...
    android:fullBackupContent="@xml/old_config.xml"
    android:dataExtractionRules="@xml/new_config.xml"
    ...>
</application>
```

</CodeGroup>

# 構成ファイルで MoEngage のファイルを除外します。

以下のように、構成から MoEngage のファイルを除外できます。

<CodeGroup>

```xml XML wrap
<data-extraction-rules>
  <cloud-backup>
    ...
    <exclude domain="database" path="MOEInteractions"/>
    <exclude domain="sharedpref" path="pref_moe.xml"/>
    <exclude domain="sharedpref" path="pref_moe_common.xml"/>
  </cloud-backup>
  <device-transfer>
    ...
    <exclude domain="database" path="MOEInteractions"/>
    <exclude domain="sharedpref" path="pref_moe.xml"/>
    <exclude domain="sharedpref" path="pref_moe_common.xml"/>
    ...
  </device-transfer>
</data-extraction-rules>
```

</CodeGroup>

MoEngage SDK のファイルのみを除外したい場合は、新しいファイルを作成する代わりに、以下のように SDK が提供するバックアップ記述子ファイルとデータ抽出ルールファイルをマニフェストファイルに直接追加できます。

<CodeGroup>

```xml AndroidManifest.xml wrap
<application
...
android:fullBackupContent="@xml/com_moengage_backup_descriptor"
android:dataExtractionRules="@xml/com_moengage_data_extraction_rules"
>
</application>
```

</CodeGroup>

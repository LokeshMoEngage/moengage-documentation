# データのリダイレクト

データ規制ポリシーにより、アプリのデータを特定のゾーンにリダイレクトする必要がある場合は、MoEngage の初期化オブジェクトでゾーンを設定してください。データセンターを [_MoEngage.Builder_](https://moengage.github.io/android-api-reference/core/com.moengage.core/-mo-engage/-builder/index.html) の 3 番目の引数として渡します。

<CodeGroup>

```kotlin Kotlin wrap
// this is the instance of the application class and "YOUR_WORKSPACE_ID" is the APP ID from the dashboard.
val moEngage = MoEngage.Builder(
        application = this,
        appId = "YOUR_WORKSPACE_ID",
        dataCenter = DataCenter.DATA_CENTER_X
    )
    .build()
MoEngage.initialiseDefaultInstance(moEngage)
```


```java Java
// this is the instance of the application class and "YOUR_WORKSPACE_ID" is the APP ID from the dashboard.
MoEngage moEngage = new MoEngage.Builder(this, "YOUR_WORKSPACE_ID", DataCenter.DATA_CENTER_X)
    .build();
MoEngage.initialiseDefaultInstance(moEngage);
```

</CodeGroup>

以下は、各データセンターとダッシュボードホストの詳細です。

| データセンター   | ダッシュボードホスト            |
| ------------- | ------------------------- |
| DATA_CENTER_1 | dashboard-01.moengage.com |
| DATA_CENTER_2 | dashboard-02.moengage.com |
| DATA_CENTER_3 | dashboard-03.moengage.com |
| DATA_CENTER_4 | dashboard-04.moengage.com |
| DATA_CENTER_5 | dashboard-05.moengage.com |
| DATA_CENTER_6 | dashboard-06.moengage.com |

<Warning>
  **重要**

  ダッシュボードホストの URL から、アカウントのデータセンター情報がわかります。Android SDK でデータセンターを変更する前に、アカウントマネージャーに問い合わせるか、[サポートチケットを発行](https://www.moengage.com/docs/user-guide/contact-support/raise-a-support-ticket-through-moengage-dashboard)して、データセンターを確認してください。
</Warning>

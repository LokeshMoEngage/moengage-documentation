MoEngage Android SDK の統合は 3 つのステップで行います。ビルド設定を構成し、SDK の依存関係を追加し、Workspace ID とデータセンターを使用して `Application` クラスで SDK を初期化します。**基本的な統合**のページでは、これら 3 つすべてについて説明しており、すべての統合で必要です。

**高度またはオプション**のページでは、基本的な統合が動作した後に追加できる、セキュリティ、カスタムネットワーク、依存関係の選択について説明します。

## 基本的な統合

| ページ | 内容 |
| --- | --- |
| [ビルド設定の構成](/ja/developer-guide/android-sdk/sdk-integration/basic-integration/configuring-build-settings) | Android プロジェクトに Maven リポジトリを追加し、Java 8 を有効にします。 |
| [BOM を使用したインストール](/ja/developer-guide/android-sdk/sdk-integration/basic-integration/Install-Using-BOM) | MoEngage Bill of Materials を使用して、モジュールのバージョンの互換性を維持します。 |
| [SDK の初期化](/ja/developer-guide/android-sdk/sdk-integration/basic-integration/sdk-initialization) | Workspace ID とデータセンターを使用して、`Application` クラスで SDK を初期化します。 |
| [MoEngage ストレージファイルを自動バックアップから除外する](/ja/developer-guide/android-sdk/sdk-integration/basic-integration/exclude-mo-engage-storage-file-from-auto-backup) | Android の自動バックアップからの復元後にデータが破損するのを防ぎます。 |

## 高度またはオプション

| ページ | 内容 |
| --- | --- |
| [Artifact ID を使用した SDK のインストール](/ja/developer-guide/android-sdk/sdk-integration/advanced-or-optional/installing-sdk-using-artifact-id) | BOM の代わりに、Maven Central のアーティファクト ID で個々のモジュールをインストールします。 |
| [JWT 認証](/ja/developer-guide/android-sdk/sdk-integration/advanced-or-optional/jwt-authentication) | JWT で SDK のリクエストを認証して、データ収集を保護します。 |
| [アドオンセキュリティ](/ja/developer-guide/android-sdk/sdk-integration/advanced-or-optional/add-on-security) | 暗号化ストレージモジュールを使用して、SDK がデバイスに保存するデータを暗号化します。 |
| [カスタムプロキシドメイン - Android](/ja/developer-guide/android-sdk/sdk-integration/advanced-or-optional/custom-proxy-domain-android) | 広告ブロッカーを回避するために、SDK のトラフィックを独自のサブドメイン経由でルーティングします。 |
| [ネットワークセキュリティ構成](/ja/developer-guide/android-sdk/sdk-integration/advanced-or-optional/network-security-configuration) | カスタムのネットワークセキュリティ構成で MoEngage のドメインをホワイトリストに登録します。 |
| [SDK ビルド仕様](/ja/developer-guide/android-sdk/sdk-integration/advanced-or-optional/sdk-configuration) | SDK のコンパイルに使用されるビルド仕様とライブラリのバージョンを確認します。 |

<Note>
  モジュールを個別に固定する理由がない限り、[BOM を使用したインストール](/ja/developer-guide/android-sdk/sdk-integration/basic-integration/Install-Using-BOM) を使用してください。BOM は、MoEngage のモジュール間で互換性のあるバージョンを自動的に解決します。
</Note>

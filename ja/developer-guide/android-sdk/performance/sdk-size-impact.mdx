---

SDK を組み込むと最終的な APK / App Bundle のサイズに大きく影響し、ユーザーエクスペリエンスやダウンロード時間に影響を与える可能性があるため、SDK のサイズは私たちにとって重要な考慮事項の 1 つです。そのため、最終的な APK / App Bundle のサイズへの影響を可能な限り小さく抑えることを常に目指しています。

# MoEngage SDK

さまざまな MoEngage アーティファクトによる APK / App Bundle のサイズへの影響の詳細については、以下の表を参照してください。

<Info>
  以下のサイズは、MoEngage Version Catalog **3.2.2**（SDK リリースではなく、内部のアーティファクトセットのバージョン）に対して測定されたものです。新しい BOM リリースではこれらの数値が変動します。このページは正確な参照値ではなくベースラインとして参照し、リリースの判断に影響する場合は、最新のサイズについてアカウントマネージャーにお問い合わせください。
</Info>

| Artifact Id                                                    | バージョン  | サイズへの影響（概算キロバイト） |

# 外部 SDK

MoEngage SDK を使用する際に、アプリケーションに含める必要がある外部依存関係がいくつかあります。外部依存関係による影響については、以下の表を参照してください。

| 依存関係         | バージョン   | サイズへの影響（概算キロバイト） |
| ------------------ | --------- | ------------------------------- |
| Firebase Messaging | 23.1.2    | 158 KB                          |
| HMS Push SDK       | 6.3.0.304 | 443 KB                          |
| MI Push SDK        | 5.1.1     | 222 KB                          |

<Info>
  上記の表の一部のアーティファクトバージョン（例: `moe-android-sdk 12.10.02`）は、現在の BOM 推奨バージョンより古くなっています。サイズの測定値はモジュールごとのベースラインとして妥当ですが、新しいリリースでは数 KB の差異が生じることを想定してください。
</Info>

SDK のパフォーマンスを維持することは私たちにとって最も重要であり、リリースごとに常にパフォーマンスの改善に取り組んでいます。パフォーマンスには、SDK の初期化にかかる時間、メソッドが何ミリ秒以内に戻るか、アプリケーション実行時の SDK のメモリフットプリント、バックグラウンド処理によるバッテリー消費などが含まれます。

# SDK の初期化時間

SDK は Application クラスの [_onCreate()_](https://developer.android.com/reference/android/app/Application#onCreate\(\)) でメインスレッド上で初期化することをお勧めしています。そのため、良好なユーザーエクスペリエンスには起動時間が重要であることから、アプリケーションの起動時間に影響を与えないよう、初期化をシンプルかつ高速に保つことが重要です。\
初期化にかかる時間は平均で約 1〜5 ミリ秒です。さまざまな OEM でテストを行いましたが、結果は一貫しているようです。\
詳細については、以下の表を参照してください。

| デバイス         | デバイスの詳細        | 時間（ミリ秒） |
| -------------- | --------------------- | ---------------------- |
| Google Pixel 2 | Android 11   4 GB RAM | 0.878593               |
| Samsung A51    | Android 10   6 GB RAM | 1.95223                |
| One Plus 7     | Android 10   6 GB RAM | 0.365365               |
| Mi Y9          | Android 9   4 GB RAM  | 2.658177               |
| Vivo Y51A      | Android 7   3 GB RAM  | 1.667916               |
| Pixel 4a       | Android 12   6 GB RAM | 0.446823               |
| Tab A7         | Andriod 11   3 GB RAM | 0.889791               |
| Mi K20 Pro     | Android 10   6 GB RAM | 0.553854               |

## まとめ

上記でベンチマークを行ったデバイス全体で、SDK の初期化は 3 ミリ秒を大きく下回っています。これは、アプリの起動時間に測定可能な影響を与えることなく、`Application.onCreate()` で SDK を同期的に安全に初期化できるほど小さな値です。

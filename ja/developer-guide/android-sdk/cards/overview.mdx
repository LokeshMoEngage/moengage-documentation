カードは、ユーザーの操作を中断することなくアプリ内に表示され続ける、控えめで持続的なメッセージであり、通常は受信トレイやニュースフィードとして表示されます。MoEngage のカード UI をそのまま使用することも、Jetpack Compose のレイアウトに埋め込むことも、カードのペイロードを取得して独自のビューを構築することもできます。

| ページ | 内容 |
| --- | --- |
| [Cards](/ja/developer-guide/android-sdk/cards/cards) | Cards をセットアップして、持続的な受信トレイやニュースフィードのメッセージを配信します。 |
| [Jetpack Compose での Cards](/ja/developer-guide/android-sdk/cards/cards-ui-compose) | `cards-ui-compose` モジュールを使用して、カードフィードを Compose のインターフェースに埋め込みます。 |
| [Self Handled Cards](/ja/developer-guide/android-sdk/cards/self-handled-cards) | Self Handled Cards SDK を使用して、カスタムのカードビューを構築します。 |

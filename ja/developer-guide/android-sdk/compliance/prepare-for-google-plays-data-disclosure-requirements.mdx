2021 年 5 月、Google Play は[新しいデータセーフティセクションを発表しました](https://android-developers.googleblog.com/2021/05/new-safety-section-in-google-play-will.html)。これは、アプリのデータ収集、共有、セキュリティに関する取り組みについて、デベロッパーが提供する開示情報です。

このページは、MoEngage Android SDK の使用に関して、このデータ開示の要件を満たすのに役立ちます。このページでは、SDK がエンドユーザーのデータを扱うかどうか、またどのように扱うかについての情報を確認できます。これには、アプリケーションデベロッパーが管理できる該当する設定や構成も含まれます。

MoEngage はできる限り透明性の高いサポートを目指していますが、アプリのエンドユーザーデータの収集、共有、セキュリティに関する取り組みについて、Google Play のデータセーフティセクションのフォームにどのように回答するかを決定する責任は、アプリケーションデベロッパーであるお客様のみにあります。

# このページの情報の使い方

このページには、MoEngage Android SDK の *バージョン **12.2.01*** 以降で収集されるエンドユーザーデータのみを記載しています。

以前のバージョンの MoEngage Android SDK を使用している場合は、アプリの開示内容が正確になるよう、最新バージョンにアップデートしてください。MoEngage Android SDK は今後も継続的にアップデートされます。この記事にはそれらの変更が反映されるため、必要に応じて開示内容を更新してください。

# 収集されるデータ

## 必須で収集されるデータ

SDK は分析のために以下のデータを自動的に収集します。

| データ | デフォルトで、MoEngage SDK は... |
| --- | --- |
| IP アドレス | デバイスの IP アドレスを収集します。これはデバイスのおおまかな位置を推定するために使用される場合があります。 |
| ユーザーとプロダクトのインタラクション | アプリの起動、アプリケーションのフォアグラウンド/バックグラウンドなど、ユーザーとプロダクトのインタラクションおよびインタラクション情報を収集します。 |
| デバイスのメタデータ | デバイスモデル、OS バージョン、タイムゾーン、ネットワークタイプ (ユーザーが権限を付与した場合) などのデバイス情報を収集します。 |

## オプションで収集されるデータ

SDK は、アプリケーション/ユーザーがデータのトラッキングに同意しているかどうかに基づいて、以下のデータをオプションで収集します。 

| データ | MoEngage SDK は... |
| --- | --- |
| デバイスのメタデータ | 製品名、メーカー、デバイスの寸法、ディスプレイタイプ、通信事業者 (ユーザーが権限を付与した場合) などのデバイス情報を収集します。 |
| デバイス識別子 | 広告識別子や Android ID などのデバイス識別子を収集します。 |

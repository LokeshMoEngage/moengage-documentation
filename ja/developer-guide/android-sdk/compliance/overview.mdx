MoEngage Android SDK を組み込んだアプリを配布する際には、2 つの義務があります。Google Play で公開する際に SDK が収集するデータを申告すること、そしてトラッキングされるかどうかについてのユーザーの選択を尊重することです。

| [Google Play のデータ開示要件への対応](/ja/developer-guide/android-sdk/compliance/prepare-for-google-plays-data-disclosure-requirements) | データセーフティフォームの入力に必要な、SDK のデータ収集の詳細。 |
| [コンプライアンス](/ja/developer-guide/android-sdk/compliance/compliance) | データトラッキングを有効または無効にし、ユーザーの同意を管理します。 |

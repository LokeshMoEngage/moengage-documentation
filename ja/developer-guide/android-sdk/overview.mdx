MoEngage Android SDK は、Kotlin または Java のアプリ内で動作します。イベントとユーザー属性をトラッキングし、Firebase Cloud Messaging にプッシュトークンを登録し、アプリ内メッセージやカードを表示します。MoEngage Bill of Materials を使用して、Maven Central からインストールしてください。

まず [Android SDK の統合](/ja/developer-guide/android-sdk/sdk-integration/overview)から SDK を追加して初期化し、その後必要なチャネルを追加してください。

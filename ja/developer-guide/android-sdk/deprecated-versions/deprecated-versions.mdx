このページでは、MoEngage Android SDK の各メジャーバージョンのサポート状況を確認できます。最新のバージョン、引き続きサポートされているバージョン、非推奨となったバージョンを、非推奨日とあわせて記載しています。このページは、Android SDK のバージョンステータスに関する信頼できる唯一の情報源です。ライフサイクルの仕組みや、非推奨がアプリにとって何を意味するかについては、[SDK 非推奨ポリシー](/ja/developer-guide/sdk-lifecycle-and-policies/sdk-deprecation-policy)を参照してください。Android SDK をセットアップするには、[統合ガイド](/ja/developer-guide/android-sdk/sdk-integration/basic-integration/Install-Using-BOM)を参照してください。

## バージョンのサポート状況

### ステータスの定義

| ステータス | 定義 |
| --- | --- |
| **Current** | 最新のメジャーバージョンです。新機能、修正、サポートが提供されます。 |
| **Supported** | 3 年間のサポート期間内にある、以前のメジャーバージョンです。引き続きサポートが提供されます。 |
| **Deprecated** | サポート期間外のバージョンです。修正やサポートは提供されなくなります。 |

| メジャーバージョン | ステータス | 非推奨日 | 備考 |
| --- | --- | --- | --- |
| 15.x | Current | 未定 | 最新のメジャーバージョンです。新機能、修正、サポートが提供されます。 |
| 14.x | Supported | 未定 | サポートが提供されます。 |
| 13.x | Supported | 未定 | サポートが提供されます。 |
| 12.10.04 以下のバージョン | Deprecated | 2027 年 8 月 | サポート、デバッグ、修正は提供されなくなります。データは引き続き送受信されます。最新バージョンにアップグレードしてください。 |

<Note>
  MoEngage は、各メジャーバージョンを最初のリリースから 3 年間サポートします。その後、翌年の 8 月に非推奨となります。詳細については、[SDK 非推奨ポリシー — サポート期間](/ja/developer-guide/sdk-lifecycle-and-policies/sdk-deprecation-policy#support-window)を参照してください。この表は、MoEngage が追加の非推奨を発表した際に更新されます。事前通知を受け取るには、SDK ニュースレターに登録し、ワークスペース管理者のメールアドレスが最新であることを確認してください。
</Note>

## 非推奨ステータスについて

非推奨のバージョンでも、データの送受信は継続されます。MoEngage がトラフィックをブロックすることはありません。非推奨日以降、MoEngage はそのバージョン固有の問題のデバッグ、修正、サポートを行わなくなり、問題の解決策は最新バージョンへのアップグレードとなります。すべての修正は最新バージョンでのみ提供され、サポート中または非推奨のバージョンでは利用できません。ポリシーの全文については、[SDK 非推奨ポリシー](/ja/developer-guide/sdk-lifecycle-and-policies/sdk-deprecation-policy)を参照してください。

## サポート対象バージョンへのアップグレード

- バージョン間の変更点を確認するには、[Android SDK リリースノート](/ja/release-notes/sdks/android)を参照してください。
- アップグレードを計画して検証するには、[Android SDK リリースチェックリスト](/ja/developer-guide/android-sdk/checklist/release-checklist)に従ってください。
- アップグレードの計画についてサポートが必要な場合は、MoEngage のカスタマーサクセスマネージャー (CSM) またはサポートチームにお問い合わせください。

## よくある質問

<AccordionGroup>
  <Accordion title="非推奨になった後も、非推奨バージョンを使い続けることはできますか?">
    非推奨バージョンのアプリも引き続き動作し、データも引き続き送受信されます。ただし、MoEngage は非推奨バージョンに対するサポート、デバッグ、修正を提供しなくなります。[Android SDK リリースノート](/ja/release-notes/sdks/android)と [Android SDK リリースチェックリスト](/ja/developer-guide/android-sdk/checklist/release-checklist)を使用して最新バージョンまたはサポート対象バージョンにアップグレードすることで、継続的なサポートを受けられます。
  </Accordion>
  <Accordion title="非推奨に関する事前通知はどのように受け取れますか?">
    MoEngage は、非推奨日の 6 〜 12 か月前に、ワークスペース管理者へのメール、四半期ごとの SDK ニュースレター、ダッシュボード内の通知、SDK リリースノートを通じて事前通知を送信します。通知スケジュールの全体については、[SDK 非推奨ポリシー](/ja/developer-guide/sdk-lifecycle-and-policies/sdk-deprecation-policy)を参照してください。
  </Accordion>
</AccordionGroup>

MoEngage SDKは、アプリケーション内で動作する軽量でモジュール式のクライアントライブラリです。イベントトラッキング、ユーザー識別、プッシュトークンの登録、アプリ内メッセージのレンダリング、コンテンツカードの配信を処理し、オフラインキューイングを備えたバッチ処理のHTTPSリクエストを通じてMoEngageサーバーにデータを同期します。

**SDKはデフォルトで以下を自動収集します：** セッションの開始/終了、アプリバージョン、デバイスモデル、OSバージョン、タイムゾーン、ロケール。プッシュが設定されている場合、プッシュトークンは自動的に登録されます。その他のトラッキング（イベント、ユーザー属性）はすべて、API呼び出しによって明示的に行います。

## クイックスタート

プラットフォームを選択し、統合ガイドに従ってください。最初のイベント送信までの目安時間は、ネイティブSDKで **15～30分**、クロスプラットフォームで **30～60分**（追加のネイティブ設定が必要なため）です。

<Steps>
  <Step title="Workspace IDを取得する">
    MoEngageダッシュボードで、**Settings → Account → APIs → Workspace ID** に移動します。SDKの初期化にこのIDが必要です。
  </Step>
  <Step title="データセンターを設定する">
    データセンターによって、SDKが通信するAPIエンドポイントが決まります。ダッシュボードURLのホストからデータセンターを確認してください（例：`dashboard-01.moengage.com` → `dc_1`）。これはSDKの初期化時に設定する必要があります。
  </Step>
  <Step title="SDKをインストールする">
    上の表にあるプラットフォーム固有のインストールガイドに従ってください。
  </Step>
  <Step title="SDKを初期化する">
    Workspace IDとデータセンターを指定して初期化メソッドを呼び出します。開発中は **TEST** 環境を、本番環境では **LIVE** を使用してください。
  </Step>
  <Step title="最初のイベントをトラッキングする">
    イベントトラッキングAPIを呼び出してカスタムイベントを送信します。MoEngageダッシュボードの **Analytics → Event Analysis** に表示されることを確認してください。
  </Step>
</Steps>

### プラットフォーム別の前提条件

統合を開始する前に、以下を準備してください。

- **Android：** `google-services.json` が設定されたFirebaseプロジェクト（FCMプッシュに必要）。Gradle 7.0\+、AGP 7.0\+、Java 8\+。
- **iOS：** プッシュ通知のエンタイトルメントが有効なApple Developerアカウント。MoEngageダッシュボードにアップロードされたAPNs認証キー（`.p8` ファイル）。
- **Web：** HTTPS対応のドメイン（Service Workerを使用するWebプッシュに必要）。
- **クロスプラットフォーム（React Native / Expo / Flutter / Cordova / Capacitor）：** 上記のネイティブの前提条件すべてに加え、フレームワーク固有のツールチェーン。

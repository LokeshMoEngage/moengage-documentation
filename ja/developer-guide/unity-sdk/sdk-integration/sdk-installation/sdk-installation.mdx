<Info>
  MoEngage Unity パッケージには、Unity 6.4（Hub バージョン 6000.4.1f1）以降が必要です。
</Info>

<Note>
  統合を行う前に、サポートされている SDK バージョンと非推奨化のタイムラインについて [SDK 非推奨ポリシー](/ja/developer-guide/sdk-lifecycle-and-policies/sdk-deprecation-policy) を確認してください。
</Note>

## ビルド環境の要件

SDK を統合する前に、ビルド環境が以下の最小要件を満たしていることを確認してください。

| 要件       | 最小バージョン |
| ----------------- | --------------- |
| AGP               | 8.10.0          |
| Gradle            | 8.13            |
| Min SDK           | 25              |
| Target SDK        | 35 または 36        |

## External Dependency Manager

このプラグインは、Google の [External Dependency Manager](https://github.com/googlesamples/unity-jar-resolver) for Unity（EDM4U）（旧 Play Services Resolver / Jar Resolver）を使用します。SDK の統合を進める前に、プロジェクトに含めてください。

## MoEngage パッケージを追加する

MoEngage Unity SDK を統合するには、まず [こちら](https://github.com/moengage/MoEngage-Unity-SDK/releases) から Unity パッケージをダウンロードします。次に、Unity Editor で `Assets > Import Package > Custom Package` に移動し、`MoEngage.unitypackage` をインポートします。以下に示すようにすべてのファイルを選択し、`Import` をクリックします。

<Frame>
  ![SDK のインストール](/images/SDKInstallation.png)
</Frame>

プラグインを統合したら、SDK の初期化ドキュメントに進んで Unity プロジェクトをセットアップしてください。

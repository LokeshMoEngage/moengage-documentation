---
title: "制限事項"
description: "MoEngage Unity プラグインを使用する際の、サポートされていない機能とネイティブ統合の要件を確認します。"
---

ネイティブの Android/iOS SDK と比較して、Unity プラグインを使用する場合は、サポートされていない機能や、ネイティブの Android/iOS 実装が必要な機能がいくつかあります。

# サポートされていない機能

* iOS 通知のアクションボタン
* Huawei Push Kit
* Xiaomi Push

# サポートされているがネイティブ統合が必要な機能

* Inbox モジュール
* Cards

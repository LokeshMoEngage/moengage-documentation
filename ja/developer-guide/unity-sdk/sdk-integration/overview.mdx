MoEngage Unity SDK の統合は 2 つのステップで行います。Unity パッケージをプロジェクトにインポートし、次に SDK を初期化します。標準的な方法では、`MoEGameObject` スクリプトをシーンにアタッチし、そこでワークスペース ID を設定します。

プラットフォーム固有の制御が必要な場合は、代わりにネイティブの構成ファイルまたはネイティブコードから初期化します。

# Unity の初期化

Unity プロジェクトで、最初のシーンに空のゲームオブジェクトを追加し、**_MoEGameObject.cs_** スクリプトをアタッチして、以下に示すように **_App ID_** を設定します。

<Frame>
  ![SDK の初期化 1](/images/SDKIntialization1.png)
</Frame>

<Frame>
  ![SDK の初期化](/images/SDKIntialization.png)
</Frame>

\
MoEngage では、コードで手動で初期化する方法と、ネイティブの設定ファイルを使用する方法の 2 つの SDK 初期化方法がサポートされています。

<Info>
  Unity iOS SDK は、ファイルベースの初期化のみをサポートしています。手動初期化は Android でのみ利用できます。
</Info>

## 手動初期化

Android の Application クラスで、プログラムにより SDK を初期化します。

- [Android](/ja/developer-guide/unity-sdk/sdk-integration/sdk-initialization/manual-initialization/android)

## ファイルベースの初期化

ネイティブの設定ファイルを使用して SDK を初期化し、Workspace ID と設定をアプリケーションロジックから分離します。

- [Android](/ja/developer-guide/unity-sdk/sdk-integration/sdk-initialization/file-based-initialization/android)
- [iOS](/ja/developer-guide/unity-sdk/sdk-integration/sdk-initialization/file-based-initialization/ios)

このページでは、MoEngage Unity SDK のメジャーバージョンのサポートステータスを確認できます。Current のバージョン、引き続き Supported のバージョン、Deprecated のバージョンを、非推奨日とともに一覧表示しています。このページは、Unity SDK のバージョンステータスに関する正式な情報源です。ライフサイクルの仕組みと、非推奨化がアプリに与える影響については、[SDK 非推奨ポリシー](/ja/developer-guide/sdk-lifecycle-and-policies/sdk-deprecation-policy) を参照してください。Unity SDK のセットアップについては、[統合ガイド](/ja/developer-guide/unity-sdk/sdk-integration/sdk-installation/sdk-installation) を参照してください。

## バージョンのサポートステータス

<Info>
  **Current** — 最新のメジャーバージョンです。新機能、修正、サポートが提供されます。

  **Supported** — 3 年間のサポート期間内にある古いメジャーバージョンです。引き続きサポートが提供されます。

  **Deprecated** — サポート期間外のバージョンです。修正やサポートは提供されなくなります。
</Info>

| メジャーバージョン | ステータス | 非推奨日 | 備考 |
| --- | --- | --- | --- |
| Core 6.x | Current | 未定 | 最新のメジャーバージョンです。新機能、修正、サポートが提供されます。 |
| Core 5.x | Supported | 未定 | サポートが提供されます。 |
| Core 4.x | Supported | 未定 | サポートが提供されます。 |
| Core 3.2.0 以前 | Deprecated | 2027 年 8 月 | サポート、デバッグ、修正は提供されなくなりました。データは引き続き送信されます。現行バージョンにアップグレードしてください。 |

<Note>
  MoEngage は、各メジャーバージョンを最初のリリースから 3 年間サポートし、その後の 8 月に非推奨化が適用されます。詳細については、[SDK 非推奨ポリシー — サポート期間](/ja/developer-guide/sdk-lifecycle-and-policies/sdk-deprecation-policy#support-window) を参照してください。この表は、MoEngage が追加の非推奨化を発表したときに更新されます。事前通知を受け取るには、SDK ニュースレターを購読し、ワークスペース管理者のメールアドレスを最新の状態に保ってください。
</Note>

## Deprecated ステータスについて

非推奨バージョンでも、データの送受信は引き続き行われます。MoEngage はトラフィックをブロックしません。非推奨日以降、MoEngage はそのバージョン固有の問題のデバッグ、修正、サポートを行わなくなり、問題の解決策は現行バージョンへのアップグレードとなります。すべての修正は現行バージョンでのみ提供され、Supported または Deprecated のバージョンでは利用できません。ポリシーの全文については、[SDK 非推奨ポリシー](/ja/developer-guide/sdk-lifecycle-and-policies/sdk-deprecation-policy) を参照してください。

## サポート対象バージョンへのアップグレード

- 現行メジャーバージョンの変更点については、[Unity SDK リリースノート](/ja/release-notes/sdks/unity) を参照してください。
- 最新のパッケージについては、[MoEngage-Unity-SDK](https://github.com/moengage/MoEngage-Unity-SDK) リポジトリを確認してください。
- サポートが必要な場合は、MoEngage のカスタマーサクセスマネージャー（CSM）またはサポートチームにお問い合わせください。

## よくある質問

<AccordionGroup>
  <Accordion title="非推奨になった後も、非推奨バージョンを使い続けることはできますか？">
    非推奨バージョンのアプリは引き続き動作し、データも引き続き送信されます。ただし、MoEngage は非推奨バージョンに対するサポート、デバッグ、修正を提供しなくなります。[Unity SDK リリースノート](/ja/release-notes/sdks/unity) を参照して Current または Supported のバージョンにアップグレードすることで、継続的なサポートを受けられます。
  </Accordion>
  <Accordion title="非推奨化の事前通知を受け取るにはどうすればよいですか？">
    MoEngage は、非推奨日の 6～12 か月前に、ワークスペース管理者へのメール、四半期ごとの SDK ニュースレター、ダッシュボード内の通知、SDK リリースノートを通じて事前通知を送信します。通知スケジュールの詳細については、[SDK 非推奨ポリシー](/ja/developer-guide/sdk-lifecycle-and-policies/sdk-deprecation-policy) を参照してください。
  </Accordion>
</AccordionGroup>

Unity のプッシュはプラットフォームごとに設定します。Android では Firebase の認証情報とランタイム権限、iOS では APNS 証明書を設定します。**基本**のページでは、両方の設定に加えて、通知に応答するためのクリックオブザーバーについて説明します。

**オプション**の機能は個別の Unity パッケージとして提供され、必要なときにインポートします。

## 基本

| ページ | 内容 |
| --- | --- |
| [Android プッシュの設定](/ja/developer-guide/unity-sdk/push/basic/android-push-configuration) | Firebase とプッシュトークンのセットアップを含め、Android プッシュを設定します。 |
| [Android 通知のランタイム権限](/ja/developer-guide/unity-sdk/push/basic/android-notification-runtime-permissions) | Android 13 の通知ランタイム権限をリクエストします。 |
| [iOS プッシュの設定](/ja/developer-guide/unity-sdk/push/basic/ios-push-configuration) | APNS 証明書とプッシュ登録を含め、iOS プッシュを設定します。 |
| [プッシュコールバック](/ja/developer-guide/unity-sdk/push/basic/push-callback) | 通知の操作を処理するためのクリックオブザーバーをセットアップします。 |

---
title: "Push Templates の設定"
description: "RichNotifications パッケージをインポートして、Unity アプリにプッシュ通知テンプレートを追加します。"
---

Push Template を統合するには、Unity Editor で **Assets > Import Package > Custom Package,** に移動し、**RichNotifications.unitypackage** をインポートします。  
上記のパッケージは、インストール時にダウンロードした **.zip** ファイル内の Android フォルダーに含まれています。

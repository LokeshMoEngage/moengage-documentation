Geofence を統合するには、Unity Editor で `Assets > Import Package > Custom Package` に移動し、`Geofence.unitypackage` をインポートします。このパッケージは、インストール時にダウンロードした `.zip` ファイルに含まれています。

# 初期化

[Unity の初期化](/ja/developer-guide/unity-sdk/sdk-integration/sdk-initialization/sdk-initialization) の手順で作成したものと同じオブジェクトに **_MoEGeofenceGameObject.cs_** を追加し、**_App Id_** を設定します。

# Android の設定

## Geofence の前提条件

ジオフェンシングを使用するには、アプリで次の権限をリクエストする必要があります。

- ACCESS_FINE_LOCATION
- アプリが Android 10（API レベル 29）以降をターゲットにしている場合は ACCESS_BACKGROUND_LOCATION

<Warning>
  Geofence プッシュが機能するためには、アプリケーションに位置情報の権限があり、[Play Services の Location ライブラリ](https://developers.google.com/android/guides/setup#declare-dependencies) が含まれている必要があります。
</Warning>

Geofence の詳細については、[ドキュメント](https://developer.android.com/training/location/geofencing#RequestGeofences) を参照してください。

# iOS の設定

Geofence パッケージの統合後、iOS 向けに必ず [ビルドと置換](/ja/developer-guide/unity-sdk/sdk-integration/sdk-initialization/file-based-initialization/ios) を行ってください。

# 設定

## Geofence モニタリングの開始

Geofence パッケージを統合した後、**_StartGeofenceMonitoring()_** メソッドを呼び出して Geofence モジュールを開始します。これにより、ユーザーの現在地周辺のジオフェンスが取得されます。Geofence の詳細については、[iOS ドキュメント](/ja/developer-guide/ios-sdk/push/optional/location-triggered) および [Android ドキュメント](/ja/developer-guide/android-sdk/push/optional/location-triggered) を参照してください。デフォルトでは、Geofence 機能は有効になっていません。位置情報トリガー型の通知を受け取るには、**_S_**\*\*_tartGeofenceMonitoring_()\*\* を呼び出す必要があります。

<CodeGroup>

```c# c#
using MoEngage;
MoEngageGeofenceClient.StartGeofenceMonitoring();
```

</CodeGroup>

## Geofence モニタリングの停止

Geofence モニタリングまたは機能を停止する場合は、**_StopGeofenceMonitoring()_** API を使用します。この API は既存のジオフェンスを削除します。

<CodeGroup>

```c# c#
using MoEngage;
MoEngageGeofenceClient.StopGeofenceMonitoring();
```

</CodeGroup>

MoEngage Unity SDK は、ネイティブの Android および iOS SDK をラップし、C# のコードから利用できるようにします。イベントとユーザー属性をトラッキングし、両方のプラットフォームでプッシュトークンを登録し、アプリ内メッセージを表示します。

まず [Unity SDK の統合](/ja/developer-guide/unity-sdk/sdk-integration/overview)からパッケージをインポートして初期化し、その後必要なチャネルを追加してください。

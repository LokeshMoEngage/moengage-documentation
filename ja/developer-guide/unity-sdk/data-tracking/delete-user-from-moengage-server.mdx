---
title: "MoEngage サーバーからユーザーを削除する"
description: "Android 上で Unity SDK を使用して、現在のユーザーを MoEngage サーバーから削除します。"
---

<Info>
この API は **MoEngage Unity Package** の **3.1.0** 以降でサポートされており、Android プラットフォームでのみ利用できます。アセットは [こちら](https://github.com/moengage/MoEngage-Unity-SDK/releases/tag/moengage-v3.1.0) からダウンロードしてください。
</Info>

現在のユーザーを MoEngage サーバーから削除するには、以下に示すように **DeleteUser(UserDeletionResponseDelegate)** メソッドを使用します。**UserDeletionResponseDelegate** は **UserDeletionData** パラメーターを持つデリゲート関数で、ユーザーの削除が完了したときにトリガーされます。

<CodeGroup>
```javascript c#
using MoEngage;
public void DeleteUser() {
  Debug.Log("DeleteUser() : ");
  MoEngageClient.DeleteUser(MyUserDeletionResponseDelegate);
}
//Delegate function
public void MyUserDeletionResponseDelegate(UserDeletionData data) {
  Debug.Log("MyUserDeletionResponseDelegate() : isSuccess: " + data.isSuccess);
}
```

</CodeGroup>

MoEngage Unity SDK は C# からトラッキング機能を提供するため、プラットフォーム間で同じ API を呼び出せます。まずユーザーを識別し、次にキャンペーンで使用するイベントをトラッキングしてください。

| ページ | 内容 |
| --- | --- |
| [ユーザー属性のトラッキング](/ja/developer-guide/unity-sdk/data-tracking/tracking-user-attributes) | 属性をトラッキングし、ログインとログアウトの状態を管理します。 |
| [イベントのトラッキング](/ja/developer-guide/unity-sdk/data-tracking/tracking-events) | `TrackEvent` を使用して、カスタムのユーザーイベントとそのプロパティをトラッキングします。 |
| [インストールとアップデートの区別](/ja/developer-guide/unity-sdk/data-tracking/install-update-differentiation) | `setAppStatus` を使用して、インストールとアップデートを区別します。 |
| [広告 ID トラッキングの有効化](/ja/developer-guide/unity-sdk/data-tracking/enable-advertising-identifier-tracking) | 分析のために広告 ID のトラッキングを有効にします。 |
| [MoEngage サーバーからのユーザーの削除](/ja/developer-guide/unity-sdk/data-tracking/delete-user-from-moengage-server) | Android で現在のユーザーを MoEngage サーバーから削除します。 |

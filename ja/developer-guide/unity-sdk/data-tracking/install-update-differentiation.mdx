---
title: "インストール/アップデートの区別"
description: "MoEngage の setAppStatus API を使用して、Unity アプリでアプリのインストールとアップデートを区別します。"
---

SDK が、ユーザーによるアプリケーションのアップデートとインストールを区別できるようにするには、サポートが必要です。アプリ側で、アプリの _INSTALL_ と _UPDATE_ を区別するロジックを用意する必要があります。

ユーザーがすでにアプリケーションを使用していて、MoEngage SDK を含む新しいバージョンにアップデートしたばかりの場合は、アップデートになります。以下の API を呼び出します。

<CodeGroup>

```c# c#
using MoEngage;
MoEngageClient.SetAppStatus(MoEAppStatus.UPDATE);
```

</CodeGroup>

新規インストールの場合は、以下の API を呼び出します。

<CodeGroup>

```c# c#
using MoEngage;
MoEngageClient.SetAppStatus(MoEAppStatus.INSTALL);
```

</CodeGroup>

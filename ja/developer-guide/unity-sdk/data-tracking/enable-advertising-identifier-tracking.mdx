---
title: "広告識別子のトラッキングを有効にする"
description: "分析のために、MoEngage SDK を使用して Unity アプリで広告識別子のトラッキングを有効にします。"
---

デバイスに関する正確な分析と再インストールのトラッキングを行うには、広告識別子（Advertising Identifier）をトラッキングすることが不可欠です。

## Ad Identifier ライブラリを追加する

アプリケーションレベルの ***build.gradle*** ファイルに以下の依存関係を追加します。

<CodeGroup>
```groovy Groovy
implementation("com.google.android.gms:play-services-ads-identifier:18.0.1")
```

</CodeGroup>

広告識別子のトラッキングを有効にするには、以下に示すように *enableAdIdTracking()* メソッドを使用します。

<CodeGroup>
```javascript c#
using MoEngage;
MoEngageClient.EnableAdIdTracking();
```

</CodeGroup>

Advertising Id のトラッキングを有効にする前に、アプリケーションが Advertising Id のトラッキングに関する [Google Play ポリシー](https://support.google.com/googleplay/android-developer/answer/10144311) に準拠していることを確認してください。ポリシーの詳細については、[ヘルプドキュメント](https://www.moengage.com/docs/user-guide/data/privacy/android-advertising-id-tracking) を参照してください。

トラッキングを有効にした後で advertising-id を無効にする必要がある場合は、次のメソッドを使用します。

<CodeGroup>
```javascript c#
using MoEngage;
MoEngageClient.DisableAdIdTracking();
```

</CodeGroup>

<Info>
上記の API はプラグインバージョン 2.3.0 以降でのみ利用できます。それより古いバージョンでは、広告識別子のトラッキングはデフォルトで有効になっています。
</Info>

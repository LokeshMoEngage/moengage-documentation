<Info>
  **前提条件**

  カスタム属性を定義するには、Web ページに MoEngage Personalize SDK が統合されている必要があります。
</Info>

# カスタム属性とは

カスタム属性は、Web サイト上のどのページと、そのページ上のどの値を使用して訪問者の体験をパーソナライズできるかを定義するために使用されます。これにより、適切なページ群で体験を提供するために複数の URL の組み合わせを構成する手間を省くことができます。

以下は、ターゲティング条件として使用できる標準フィールドです。

- `pageType`
- `category`
  - `firstLevel`
  - `secondLevel`
  - `thirdLevel`
  - `fourthLevel`
- `unitPrice`
- `salePrice`
- `currency`

上記以外の値は、**custom** ブロックで定義してからターゲティングに使用できます。

<CodeGroup>

```javascript JavaScript wrap
window.moePageContext = {
  pageType: "product page",
  category: {
    firstLevel: "Clothing & Accessories",
    secondLevel: "T-shirts",
    thirdLevel: "Polos"
  },
  unitPrice: "24",
  salePrice: "18",
  discount: "25",
  currency: "USD",
  custom: {
    size: "Medium",
    color: "Black",
    gender: "Unisex"    
  }    
};
```

</CodeGroup>

**以下は、カスタム属性の使用例です**

## E コマース

| フィールド名  | 説明                                                                                                                                                                                                                                                                                                                     | 例                                                                                                                                                    |
| :------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :--------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **pageType**  | ページの種類を定義します。標準のページタイプの値は次のとおりです: _Homepage, category, cart, checkout, success_                                                                                                                                                                                                                           | `pageType: "Homepage"` <br /> **または** <br /> `pageType: "category"`                                                                                         |
| **category**  | 4 つのレベルのカテゴリのいずれに対しても体験をターゲティングできます。                                                                                                                                                                                                                                                              | `category: { firstLevel: "Electronics", secondLevel: "Home Audio", thirdLevel: "Speaker", fourthLevel: "Bluetooth Speakers" }`                             |
| **unitPrice** | 商品の元の価格に基づいて商品ページをターゲティングします。                                                                                                                                                                                                                                                                | `unitPrice: "24"`                                                                                                                                          |
| **salePrice** | 商品の割引価格に基づいて商品ページをターゲティングします。                                                                                                                                                                                                                                                              | `salePrice: "18"`                                                                                                                                          |
| **discount**  | 商品の割引額に基づいて商品ページをターゲティングします。                                                                                                                                                                                                                                                               | `discount: "25"`                                                                                                                                           |
| **currency**  | 商品の通貨に基づいて商品ページをターゲティングします。                                                                                                                                                                                                                                                                      | `currency: "USD"`                                                                                                                                          |
| **custom**    | パーソナライズのターゲットにしたいその他の特性。 <br /><br /> **例:** **男性**向けの**白、M** サイズのポロシャツを表示するすべてのページをパーソナライズする <br /> **または** <br /> カートの金額が \$500 以上、カートの割引が 0、かつカートに 2 点以上の商品が含まれている場合にのみチェックアウトページをパーソナライズする。 | **custom**: `{ color: "White", size: "M", gender: "Male" }` <br /> **または** <br /> **custom**: `{ cartAmount: "750", cartDiscount: "0", cartQuantity: "4" }` |

## 金融

| 属性         | 説明                                                                                                             | 例                                                                                                        |
| :----------- | :---------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------- |
| **pageType** | ページの種類を定義します。標準のページタイプの値は次のとおりです: _Homepage, blog, service/products, resources/downloads, offers_ | `pageType: "Homepage"` <br /> **または** <br /> `pageType: "products"` <br /> **または** <br /> `pageType: "services"` |
| **category** | 4 つのレベルのカテゴリのいずれに対しても体験をターゲティングできます。                                                      | `category: { firstLevel: "Insurance", secondLevel: "Health Insurance", thirdLevel: "Medical Insurance" }`      |

さらにサポートが必要な場合は、MoEngage のカスタマーサクセスマネージャー(CSM)またはサポートチームにお問い合わせください。

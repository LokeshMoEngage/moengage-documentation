# Offering Shown イベントのレポート

SDK には、Offering の表示イベントをトラッキングするメソッドが用意されています。

インプレッションは、Offering がユーザーに視覚的に表示されたときにレポートする必要があります。

Offering のインプレッションをレポートするには、**offeringContext** をマップとして渡します。

<CodeGroup>

```javascript Javascript wrap
<script type="text/javascript">
Moengage.personalize.offeringShown(offeringContext)
</script>
```

</CodeGroup>

# Offering Clicked イベントのレポート

SDK には、Offering のクリックイベントをトラッキングするメソッドが用意されています。

クリックイベントは、ユーザーが Personalize API のレスポンスに含まれるいずれかの Offering をクリックしたときにレポートする必要があります。単一の Offering のクリックイベントをレポートするには、その Offering の **offeringContext** を渡します。

ユーザーが Offering をクリックした場合、暗黙的に親の Experience もクリックしているものと見なされます。**offeringClicked** 関数には、オプションで experienceContext を渡せるようになりました。

### **これが意味すること**

- **両方のコンテキストを渡す場合、** MoEngage は Offering と Experience の**両方**のクリックを**自動的に**トラッキングします。親の Experience のクリックイベントをトラッキングするために、別途 2 回目の呼び出しを行う必要はなくなります。
- **offeringContext のみを渡す場合、** **experienceContext** はオプションです。渡さない場合は、Offering のクリックのみがトラッキングされます。必要に応じて、Experience のクリックを別途トラッキングする必要があります。

  <CodeGroup>

  ```javascript Javascript wrap
  <script type="text/javascript">
  Moengage.personalize.offeringClicked(offeringContext,experienceContext)
  </script>
  ```

  </CodeGroup>

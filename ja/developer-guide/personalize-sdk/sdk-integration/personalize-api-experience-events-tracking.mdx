このドキュメントでは、[MoEngage Personalize API](https://www.moengage.com/docs/api/personalize-experience/personalize-overview) で作成した API Experience のインプレッションとクリックをレポートするために、MoEngage Personalize SDK で利用できる新しいメソッドについて説明します。

# 前提条件

## SDK の統合

1. Web サイトに Web SDK を統合するには、[こちらの記事](/ja/developer-guide/web-sdk/web-sdk-integration/basic-integration/web-sdk-integration)を参照してください。
2. Web サイトに Personalize SDK を統合するには、[こちらの記事](/ja/developer-guide/personalize-sdk/sdk-integration/web-personalization-v2)を参照してください。

## MoEngage アカウントの構成

MoEngage ワークスペースで Personalize を利用できるようになっていることを確認してください。Personalize API Experience の設定の詳細については、[こちらの記事](https://www.moengage.com/docs/user-guide/personalize/server-side-personalization/create-server-side-personalization-experience)を参照してください。

# Experience Shown イベントのレポート

SDK には、Experience の表示イベントをトラッキングするメソッドが用意されています。Experience のインプレッションをレポートするには、以下の SDK メソッドを使用します。

<CodeGroup>

```javascript Javascript wrap
<script type="text/javascript">
MoEngage.personalize.trackImpression(experienceContext)
</script>
```

</CodeGroup>

**experienceContext** は、Personalize API の Experience Fetch 呼び出しに対するレスポンスで返される JSON オブジェクトです。詳細は[こちら](https://www.moengage.com/docs/api/experiences/fetch-experience#response-experiences)を参照してください。

# Experience Clicked イベントのレポート

SDK には、Experience のクリックイベントをトラッキングするメソッドが用意されています。Experience のクリックをレポートするには、以下の SDK メソッドを使用します。

<CodeGroup>

```javascript Javascript wrap
<script type="text/javascript">
MoEngage.personalize.trackClick(experienceContext,extraAttributes)
</script>
```

</CodeGroup>

**extraAttributes** は**オプション**の JSON オブジェクトで、ユーザーが操作したリンクや CTA に関する追加情報を渡すことができます。

<CodeGroup>

```json JSON wrap
{
  "button_id": "<submit-form-btn>",
  "button_name": "<Add to Cart>",
  "button_type": "<primary>",
}
```

</CodeGroup>

上記の JSON の例は、クリックに関する追加情報をトラッキングする際に含めることができるデータの種類を明確に理解していただくためのサンプル値です。具体的な実装のニーズに合わせて、これらの値を自由に調整してください。

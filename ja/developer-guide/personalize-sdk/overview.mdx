MoEngage Personalize SDK は、Web サイトの訪問者にパーソナライズされたエクスペリエンスを配信します。SDK にエクスペリエンスを表示させることも、ペイロードを取得して独自のフロントエンドコンポーネントで表示することもできます。

まず [Web パーソナライゼーション - V2](/ja/developer-guide/personalize-sdk/sdk-integration/web-personalization-v2) から始めて、SDK をインストールして設定してください。

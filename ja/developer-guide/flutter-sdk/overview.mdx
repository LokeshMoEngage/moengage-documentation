MoEngage Flutter SDK は、ネイティブの Android SDK と iOS SDK をラップし、Dart コードから利用できるようにします。イベントとユーザー属性をトラッキングし、両方のプラットフォームでプッシュトークンを登録し、アプリ内メッセージとカードを表示します。

まず [Flutter SDK の統合](/ja/developer-guide/flutter-sdk/sdk-integration/overview)から始めてパッケージを追加して初期化し、その後必要なチャネルを追加してください。

ユーザーが付与した同意に基づいて MoEngage SDK がトラッキングする内容を制御するには、以下の API を使用します。

## データトラッキングの有効化または無効化

SDK によるカスタムイベントとユーザー属性のトラッキングを停止するには、`disableDataTracking()` を呼び出します。

<CodeGroup>

```dart Dart wrap
import 'package:moengage_flutter/moengage_flutter.dart';
final MoEngageFlutter _moengagePlugin = MoEngageFlutter();

_moengagePlugin.disableDataTracking();
```

</CodeGroup>

`enableDataTracking()` を呼び出すまで、SDK はすべてのイベントとユーザー属性を拒否します。データトラッキングはデフォルトで有効になっています。

<CodeGroup>

```dart Dart wrap
import 'package:moengage_flutter/moengage_flutter.dart';
final MoEngageFlutter _moengagePlugin = MoEngageFlutter();

_moengagePlugin.enableDataTracking();
```

</CodeGroup>

## SDK の有効化または無効化

SDK によるユーザー情報のトラッキングや MoEngage へのデータ送信をすべて停止するには、`disableSdk()` を呼び出します。

<CodeGroup>

```dart Dart wrap
import 'package:moengage_flutter/moengage_flutter.dart';
final MoEngageFlutter _moengagePlugin = MoEngageFlutter();

_moengagePlugin.disableSdk();
```

</CodeGroup>

`enableSdk()` を呼び出すまで、すべての SDK API は動作しません。SDK はデフォルトで有効になっているため、`enableSdk()` は以前に無効にした場合にのみ呼び出してください。

<CodeGroup>

```dart Dart wrap
import 'package:moengage_flutter/moengage_flutter.dart';
final MoEngageFlutter _moengagePlugin = MoEngageFlutter();

_moengagePlugin.enableSdk();
```

</CodeGroup>

## ユーザーデータの削除

MoEngage サーバーから現在のユーザーのプロファイルを削除するには、[MoEngage サーバーからのユーザーの削除](/ja/developer-guide/flutter-sdk/data-tracking/delete-user-from-moengage-server)を参照してください。

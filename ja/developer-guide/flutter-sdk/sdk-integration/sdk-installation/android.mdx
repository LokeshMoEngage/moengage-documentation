# 依存関係を追加する

**_android/app/build.gradle_** ファイルに以下の依存関係を追加します。

## AndroidXライブラリを追加する

SDKの動作はいくつかのAndroidXライブラリに依存しています。まだ追加していない場合は、以下のAndroidXライブラリをアプリケーションに追加してください。

<CodeGroup>

```groovy build.gradle
dependencies {
    ...
implementation("androidx.core:core:1.6.0")
implementation("androidx.appcompat:appcompat:1.3.1")
implementation("androidx.lifecycle:lifecycle-process:2.7.0")
}
```

</CodeGroup>

MoEngage SDKのいくつかの主要機能は **lifecycle-process** ライブラリに依存しており、最新バージョンの **lifecycle-process** は **androidx.startup:startup-runtime** ライブラリに依存しています。そのため、マニフェストから **InitializationProvider** コンポーネントを削除しないでください。**startup-runtime** を使用して他のInitializerを追加する場合は、**lifecycle-process** ライブラリのInitializerも追加されていることを確認してください。Initializerの追加方法については、[ドキュメント](https://developer.android.com/jetpack/androidx/releases/lifecycle#2.4.0)を参照してください。

Flutterは、単一のコードベースからiOSおよびAndroid向けのネイティブコンパイルされたアプリケーションを構築するための、GoogleのUIツールキットです。

![Download](https://img.shields.io/pub/v/moengage_flutter.svg)

# プラグインのインストール

MoEngageのFlutter SDKをアプリケーションに追加するには、**_pubspec.yaml_** を編集して **_moengage_flutter_** を依存関係として追加します。

<CodeGroup>

```yaml pubspec.yaml
dependencies:
	moengage_flutter: $lastestVersion
```

</CodeGroup>

**_\$latestVersion_** はプラグインの最新バージョンを指します。

依存関係を追加したら、ターミナルで次のコマンドを実行して依存関係をインストールします。

<CodeGroup>

```yaml pubspec.yaml
flutter pub get
```

</CodeGroup>

<Info>
  動作するサンプルアプリは[こちら](https://github.com/moengage/Flutter-SDK)にあります。
</Info>

プラグインをインストールした後、以下のプラットフォーム固有の設定を行います。

- [Android](/ja/developer-guide/flutter-sdk/sdk-integration/sdk-installation/android)
- [iOS](/ja/developer-guide/flutter-sdk/sdk-integration/sdk-installation/ios)
- [Web](/ja/developer-guide/flutter-sdk/sdk-integration/sdk-initialization/web-sdk-initialization)

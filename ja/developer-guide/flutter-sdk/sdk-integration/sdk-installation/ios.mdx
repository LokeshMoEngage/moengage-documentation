---
title: "iOS"
description: "CocoaPodsまたはSwift Package Managerを使用して、FlutterプロジェクトにMoEngage iOS SDKの依存関係を設定します。"
---

ネイティブSDK `MoEngage-iOS-SDK` を `moengage_flutter` プラグインの依存関係として追加しています。そのため、`flutter build ios` コマンドを一度実行してiOSプロジェクト用のPodファイルを生成し、プロジェクトの `ios` ディレクトリ内で `pod install` を実行して、プラグインとネイティブSDKをiOSプロジェクトに追加してください。

<Info>
[Swift Package Manager](https://docs.flutter.dev/packages-and-plugins/swift-package-manager/for-app-developers) のサポートはバージョン10.3.0から利用できます。
</Info>

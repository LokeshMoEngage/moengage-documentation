# プラグインを初期化する

**MoEngageFlutter(YOUR_WORKSPACE_ID)** オブジェクトを作成し、プロジェクトのApp Widgetの **initState()** メソッド内で、以下のように **MoEngageFlutter** プラグインの **initialise()** を呼び出します。

<CodeGroup>

```Dart Dart
import 'package:moengage_flutter/moengage_flutter.dart';
final MoEngageFlutter _moengagePlugin = MoEngageFlutter(YOUR_WORKSPACE_ID);
@override
void initState() {
  super.initState();
  initPlatformState();
  _moengagePlugin.initialise();
}
```

</CodeGroup>

詳細については、[Flutter SDK](https://github.com/moengage/Flutter-SDK)を参照してください。

MoEngage Flutter SDK の統合は 2 つのステップで行います。`moengage_flutter` パッケージとそのネイティブの依存関係を追加してから、SDK を初期化します。

初期化には 2 つの形式があります。ファイルベースの初期化では設定をネイティブの設定ファイルに保持し、手動初期化では各プラットフォームのコードで設定します。

## SDK のインストール

| ページ | 内容 |
| --- | --- |
| [フレームワークの依存関係](/ja/developer-guide/flutter-sdk/sdk-integration/sdk-installation/framework-dependency) | `pubspec.yaml` に `moengage_flutter` を追加します。 |
| [Android](/ja/developer-guide/flutter-sdk/sdk-integration/sdk-installation/android) | 必要な Android の依存関係と AndroidX ライブラリを追加します。 |
| [iOS](/ja/developer-guide/flutter-sdk/sdk-integration/sdk-installation/ios) | CocoaPods または Swift Package Manager を使用して iOS の依存関係をセットアップします。 |

## ファイルベースの初期化

| ページ | 内容 |

| [移行と優先順位](/ja/developer-guide/flutter-sdk/sdk-integration/sdk-initialization/file-based-initialization/migration-and-precedence) | コードベースの初期化からファイルベースの設定に移行します。 |

# 基本セットアップ

MoEngage を使用して Android デバイスでプッシュ通知を有効にするには、このセクションで説明する基本セットアップに従ってください。

- **MoEngage ダッシュボードでの FCM セットアップ -** FCM 認証は、Android デバイスにインストールされたアプリにプッシュ通知を送信できるようにするための方法です。MoEngage が Firebase サービスにアクセスできるよう認証するには、[こちらの記事](/ja/developer-guide/android-sdk/push/basic/fcm-authentication)に記載されている方法を使用してください。
- **プッシュ通知のメタデータの追加 -** [こちらの記事](/ja/developer-guide/android-sdk/push/basic/push-configuration)の方法を使用して、スモールアイコンとラージアイコンの drawable、およびプッシュ通知を処理するためのその他のオプションを設定します。
- **Android 通知のランタイム権限** - アプリケーションが Android 13 で実行されている場合、ユーザーに通知を表示するには、アプリケーションがユーザーに通知権限をリクエストする必要があります。権限リクエストを処理するには、[こちらの記事](/ja/developer-guide/flutter-sdk/push/basic/android-notification-runtime-permissions)の方法を参照してください。
- **プッシュの登録と受信** - Flutter アプリケーションでプッシュ通知を使用するには、Firebase を設定する必要があります。要件に応じて、以下のいずれかの方法を参照してプッシュの登録と受信を有効にしてください。

<Tabs>
  <Tab title="MoEngage にプッシュを処理させる（推奨）">

# プッシュ用の Flutter API

MoEngage にプッシュトークンの登録と表示を処理させる場合、または Android ネイティブのメソッドを使用してトークンとペイロードを MoEngage SDK に渡す場合は、このセクションを完全にスキップできます。

MoEngage SDK の Flutter API を使用してトークンとペイロードを MoEngage SDK に渡したい場合は、引き続きお読みください。

<Warning>
  プッシュペイロードを MoEngage SDK に渡す際は、Flutter/Dart API ではなく Android ネイティブ API を使用することをお勧めします。アプリケーションが強制終了状態にある場合、Flutter Engine が初期化されない可能性があり、プッシュの到達率や配信率の低下につながります。
</Warning>

## プッシュトークンを渡す

<CodeGroup>

```auto Dart
import 'package:moengage_flutter/moengage_flutter.dart';
final MoEngageFlutter _moengagePlugin = MoEngageFlutter(YOUR_WORKSPACE_ID);
_moengagePlugin.initialise();
_moengagePlugin.passFCMPushToken();
```

</CodeGroup>

## プッシュ通知のカスタマイズ

必要に応じて、アプリケーションはネイティブ Android コード（Java/Kotlin）を使用して通知の動作をカスタマイズできます。カスタマイズの詳細については、[高度なプッシュ設定](/ja/developer-guide/android-sdk/push/advanced/callbacks-and-customisation)のドキュメントを参照してください。上記のドキュメントに記載されている **_PushMessageListener_** を拡張する代わりに、**_PluginPushCallback._** を拡張してください。

Push Amp+、プッシュテンプレート、ジオフェンスについては、以下のドキュメントを参照してください。

- [Push Amplification](/ja/developer-guide/android-sdk/push/optional/push-amplification)
- [Push Amp Plus](/ja/developer-guide/android-sdk/push/optional/push-amp-plus/push-amp-plus-integration)
- [プッシュテンプレート](/ja/developer-guide/android-sdk/push/optional/push-templates)
- [ジオフェンスプッシュ](/ja/developer-guide/android-sdk/push/optional/location-triggered)

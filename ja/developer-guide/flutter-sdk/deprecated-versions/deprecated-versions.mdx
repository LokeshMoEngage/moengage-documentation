このページでは、MoEngage Flutter SDK のメジャーバージョンのサポート状況を確認できます。最新のバージョン、引き続きサポートされているバージョン、非推奨となったバージョンを、非推奨日とともに一覧で示しています。このページは Flutter SDK のバージョンステータスに関する信頼できる唯一の情報源です。ライフサイクルの仕組みや、非推奨がアプリに与える影響については、[SDK 非推奨ポリシー](/ja/developer-guide/sdk-lifecycle-and-policies/sdk-deprecation-policy)を参照してください。Flutter SDK をセットアップするには、[統合ガイド](/ja/developer-guide/flutter-sdk/overview/getting-started-with-flutter-sdk)を参照してください。

## バージョンのサポート状況

<Info>
  **Current（最新）** — 最新のメジャーバージョンです。新機能、修正、サポートが提供されます。

  **Supported（サポート中）** — 3 年間のサポート期間内にある旧メジャーバージョンです。引き続きサポートが提供されます。

  **Deprecated（非推奨）** — サポート期間外のバージョンです。修正やサポートは提供されなくなります。
</Info>

<Note>
  MoEngage は、各メジャーバージョンを初回リリースから 3 年間サポートし、その後の 8 月に非推奨となります。詳細については、[SDK 非推奨ポリシー — サポート期間](/ja/developer-guide/sdk-lifecycle-and-policies/sdk-deprecation-policy#support-window)を参照してください。この表は、MoEngage が新たな非推奨を発表した際に更新されます。事前通知を受け取るには、SDK ニュースレターに登録し、ワークスペース管理者のメールアドレスが最新であることを確認してください。
</Note>

## 非推奨ステータスについて

非推奨のバージョンでも、データの送受信は引き続き行われます。MoEngage がトラフィックをブロックすることはありません。非推奨日以降、MoEngage はそのバージョン固有の問題のデバッグ、修正、サポートを行わなくなり、問題の解決策は最新バージョンへのアップグレードとなります。すべての修正は最新バージョンでのみ提供され、サポート中または非推奨のバージョンでは利用できません。ポリシーの全文については、[SDK 非推奨ポリシー](/ja/developer-guide/sdk-lifecycle-and-policies/sdk-deprecation-policy)を参照してください。

## サポート対象バージョンへのアップグレード

- 最新メジャーバージョンの変更点については、[Flutter SDK リリースノート](/ja/release-notes/sdks/flutter)を参照してください。
- 最新のパッケージについては、[Flutter-SDK](https://github.com/moengage/Flutter-SDK/) リポジトリを確認してください。
- サポートが必要な場合は、MoEngage のカスタマーサクセスマネージャー（CSM）またはサポートチームにお問い合わせください。

## よくある質問

<AccordionGroup>
  <Accordion title="非推奨になった後も、非推奨バージョンを使い続けることはできますか？">
    非推奨バージョンのアプリは引き続き動作し、データも引き続き送受信されます。ただし、MoEngage は非推奨バージョンに対するサポート、デバッグ、修正を提供しなくなります。[Flutter SDK リリースノート](/ja/release-notes/sdks/flutter)を参照して最新またはサポート中のバージョンにアップグレードすることで、継続的なサポートを受けられます。
  </Accordion>
  <Accordion title="非推奨に関する事前通知はどのように受け取れますか？">
    MoEngage は、非推奨日の 6～12 か月前に、ワークスペース管理者へのメール、四半期ごとの SDK ニュースレター、ダッシュボード内の通知、SDK リリースノートを通じて事前通知を送信します。通知スケジュールの全体については、[SDK 非推奨ポリシー](/ja/developer-guide/sdk-lifecycle-and-policies/sdk-deprecation-policy)を参照してください。
  </Accordion>
</AccordionGroup>

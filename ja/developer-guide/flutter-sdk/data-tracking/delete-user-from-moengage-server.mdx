---
title: "MoEngage サーバーからのユーザーの削除"
description: "Flutter SDK の deleteUser() メソッドを使用して、MoEngage サーバーから現在のユーザーを削除します。"
---

<Info>
この API は **moengage\_flutter** バージョン **6.1.0** 以降でサポートされており、Android プラットフォームでのみ利用可能です。その他のプラットフォームでは [UnImplementedError](https://api.flutter.dev/flutter/dart-core/UnimplementedError-class.html) エラーがスローされます
</Info>

MoEngage サーバーから現在のユーザーを削除するには、以下に示すように ***deleteUser()*** メソッドを使用します。[***UserDeletionData***](https://pub.dev/documentation/moengage_flutter_platform_interface/latest/moengage_flutter_platform_interface/UserDeletionData-class.html) のインスタンスが返されます。

<CodeGroup>
```javascript Dart

import 'package:moengage_flutter/moengage_flutter.dart';
final MoEngageFlutter _moengagePlugin = MoEngageFlutter(<YOUR_WORKSPACE_ID>);
_moengagePlugin.initialise();

// Below method will return an instance of <Future<UserDeletionData>>
_moengagePlugin.deleteUser().then((value) {
// Add your code to handle the callback.
}).catchError((onError) {
// Add your code to handle the Error.
});
```

</CodeGroup>

  
詳細については、[API ドキュメント](https://pub.dev/documentation/moengage_flutter/6.1.0/moengage_flutter/MoEngageFlutter/deleteUser.html)を参照してください。

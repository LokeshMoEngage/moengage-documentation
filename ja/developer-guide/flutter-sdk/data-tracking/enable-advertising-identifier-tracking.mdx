---
title: "広告 ID トラッキングの有効化"
description: "正確なデバイス分析のために、Flutter アプリで広告 ID のトラッキングを有効にします。"
---

デバイスに関する正確な分析と再インストールのトラッキングを行うには、広告 ID（Advertising Identifier）をトラッキングすることが不可欠です。

## 広告 ID ライブラリの追加

アプリケーションレベルの ***build.gradle*** ファイルに次の依存関係を追加します。

<CodeGroup>
```groovy Groovy
implementation("com.google.android.gms:play-services-ads-identifier:18.0.1")
```

</CodeGroup>

広告 ID のトラッキングを有効にするには、以下に示すように *enableAdIdTracking()* メソッドを使用します。

<CodeGroup>
```dart Dart
import 'package:moengage_flutter/moengage_flutter.dart';
final MoEngageFlutter _moengagePlugin = MoEngageFlutter(YOUR_WORKSPACE_ID);
_moengagePlugin.initialise();
_moengagePlugin.enableAdIdTracking();
```

</CodeGroup>

広告 ID のトラッキングを有効にする前に、アプリケーションが広告 ID のトラッキングに関する [Google Play ポリシー](https://support.google.com/googleplay/android-developer/answer/10144311)に準拠していることを確認してください。ポリシーの詳細については、[ヘルプドキュメント](https://www.moengage.com/docs/user-guide/data/privacy/android-advertising-id-tracking)を参照してください。

トラッキングを有効にした後に広告 ID を無効にする必要がある場合は、次のメソッドを使用します。

<CodeGroup>
```dart Dart
import 'package:moengage_flutter/moengage_flutter.dart';
final MoEngageFlutter _moengagePlugin = MoEngageFlutter(YOUR_WORKSPACE_ID);
_moengagePlugin.initialise();
_moengagePlugin.disableAdIdTracking();
```

</CodeGroup>

<Info>
上記の API は、プラグインバージョン 4.2.0 以降でのみ利用可能です。それより古いバージョンでは、広告 ID のトラッキングはデフォルトで有効になっています。
</Info>

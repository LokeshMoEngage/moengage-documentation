---
title: "インストールとアップデートの区別"
description: "MoEngage の setAppStatus API を使用して、Flutter アプリでアプリのインストールとアップデートを区別します。"
---

SDK が、ユーザーによるアプリケーションのアップデートとインストールを区別できるようにするためのサポートが必要です。アプリ側で、アプリの _INSTALL_ と _UPDATE_ を区別するロジックを用意する必要があります。

ユーザーがすでにアプリケーションを使用しており、MoEngage SDK を含む新しいバージョンにアップデートしたばかりの場合は、アップデートです。次の API を呼び出します。

<CodeGroup>

```Dart Dart
import 'package:moengage_flutter/moengage_flutter.dart';
final MoEngageFlutter _moengagePlugin = MoEngageFlutter(YOUR_WORKSPACE_ID);
_moengagePlugin.initialise();
_moengagePlugin.setAppStatus(MoEAppStatus.update);
```

</CodeGroup>

新規インストールの場合は、次の API を呼び出します。

<CodeGroup>

```Dart Dart
import 'package:moengage_flutter/moengage_flutter.dart';
final MoEngageFlutter _moengagePlugin = MoEngageFlutter(YOUR_WORKSPACE_ID);
_moengagePlugin.initialise();
_moengagePlugin.setAppStatus(MoEAppStatus.install);
```

</CodeGroup>

詳細については、[Flutter SDK](https://github.com/moengage/Flutter-SDK) を参照してください。

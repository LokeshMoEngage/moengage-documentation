title: "HTML In-App 向け JavaScript Bridge"

---

HTML In-App メッセージは、Web アプリが MoEngage SDK とやり取りするためのブリッジインターフェースをサポートしています。

ブリッジには、グローバル変数 `moengage` を使用してアクセスできる一連の API が含まれています。ほとんどの API は Android と iOS の両方で動作します。以下の表の **プラットフォーム** 列には、各 API が実装されているプラットフォームが記載されています。両方のプラットフォームに配信するテンプレートで API を使用する前に、この列を確認してください。

以下の表に JS Bridge のすべてのメソッドを示します。後続のセクションで、各 API について詳しく説明します。

| メソッド名 | プラットフォーム | 説明 |
| --- | --- | --- |
| moengage.dismissMessage() | Android, iOS | In-App メッセージを閉じるために、このメソッドをテンプレートに組み込みます |
| moengage.navigateToScreen("screen-name", "optional-data-json") | Android, iOS | テンプレート要素のクリック時にユーザーを特定の画面に遷移させるには、このメソッドを使用します。パラメータ：  "screen-name"：リダイレクト先の画面名  "optional-data-json"：追加のキーと値のペア |
| moengage.openDeepLink("deeplink-url", "optional-data-json") | Android, iOS | HTML In-App テンプレートからディープリンクを開く場合は、このメソッドを使用します  "deeplink-url"：ディープリンク URL  "optional-data-json"：追加のキーと値のペア |
| moengage.openRichLanding("richlanding-url", "optional-data-json") | Android, iOS | アプリの WebView 内で URL を開く場合は、このメソッドを使用します  "richlanding-url"：開きたい URL  "optional-data-json"：追加のキーと値のペア |
| moengage.openWebURL("web-url", "optional-data-json") | Android, iOS | アプリのデフォルトブラウザで URL を開く場合は、このメソッドを使用します  "web-url"：開きたい URL  "optional-data-json"：追加のキーと値のペア |
| moengage.copyText("text-to-copy", "message") | Android, iOS | HTML In-App テンプレートからクーポンコードやオファーコードをクリップボードにコピーするには、このメソッドを使用します  "text-to-copy"：このテキストがクリップボードにコピーされます  "optional-message"：コピー後にこのメッセージが表示されます |
| moengage.call("mobile-number") | Android, iOS | HTML In-App テンプレートから通話を開始するには、このメソッドを使用します  "mobile-number"：この番号がダイヤラーに表示されます |
| moengage.sms("mobile-number", "message") | Android, iOS | HTML In-App テンプレートから SMS を開始するには、このメソッドを使用します  "mobile-number"：SMS の送信先  "message"：SMS として送信されるメッセージ |
| moengage.share("share-text") | Android, iOS | デバイス上で利用可能な任意のアプリを介して共有アクションを開始するには、このメソッドを使用します。 |
| moengage.customAction("data-json") | Android, iOS | アプリで定義されたカスタムアクションを開始するには、このメソッドを使用します。  "data-json"：キーと値のペア |
| moengage.requestNotificationPermission() | Android, iOS | ユーザーに通知の許可をリクエストするには、このメソッドを使用します。 |
| moengage.navigateToNotificationSettings() | Android, iOS | 許可を先にリクエストせずに、ユーザーをアプリの通知設定画面に直接遷移させるには、このメソッドを使用します。 |
| moengage.showPushOptIn() | iOS | 現在の通知ステータスに基づいて、通知許可のプロンプトが表示されるか、通知ステータスを更新できる設定画面に遷移します。 |
| moengage.navigateToSettings() | iOS | デバイスの設定画面に遷移するには、このメソッドを使用します。このメソッドは Android では実装されておらず、呼び出しても何も起こりません。Android ユーザーを通知設定に誘導するには、代わりに `moengage.navigateToNotificationSettings()` を使用してください。 |
| moengage.trackEvent(eventName, generalAttrJson) | Android, iOS | HTML In-App テンプレートからイベントをトラッキングするには、このメソッドを使用します  "eventName"：トラッキングするイベントの名前  "generalAttrJson"：イベントとともにトラッキングされるイベント属性 |
| moengage.trackClick("widgetId") | Android, iOS | キャンペーンのパフォーマンス測定のためにクリック統計をトラッキングするには、このメソッドを使用します。  "widgetId"：オプションの引数で、渡すとクリック分布テーブルの作成に役立ちます。1 つのテンプレートに複数の CTA がある場合に効果的です |
| moengage.trackDismiss(widgetId) | Android, iOS | キャンペーンのパフォーマンス測定および In-App メッセージを閉じたユーザーの特定のために、閉じる操作の統計をトラッキングするには、このメソッドを使用します  "widgetId"：オプションの引数で、渡すとクリック分布テーブルの作成に役立ちます。1 つのテンプレートに複数の閉じる CTA がある場合に効果的です |
| moengage.setEmailId("value") | Android, iOS | ユーザーの email_id を取得するには、このメソッドを使用します。これはユーザープロファイルに自動的に保存され、メールキャンペーンの送信に使用できます。  リード獲得フォームやサインアップフォームで使用できます。  "value"：ユーザーの email_id |
| moengage.setMobileNumber("value") | Android, iOS | ユーザーの携帯電話番号を取得するには、このメソッドを使用します。これはユーザープロファイルに自動的に保存され、SMS キャンペーンの送信に使用できます。  リード獲得フォームやサインアップフォームで使用できます。  "value"：ユーザーの携帯電話番号 |
| moengage.setUserName("value") | Android, iOS | ユーザーの名前を取得するには、このメソッドを使用します。これはユーザープロファイルに自動的に保存されます。  リード獲得フォームやサインアップフォームで使用できます。  "value"：ユーザーのユーザー名 |
| moengage.setFirstName("value") | Android, iOS | ユーザーの名（ファーストネーム）を取得するには、このメソッドを使用します。これはユーザープロファイルに自動的に保存されます。  リード獲得フォームやサインアップフォームで使用できます。  "value"：ユーザーの名 |
| moengage.setLastName("value") | Android, iOS | ユーザーの姓（ラストネーム）を取得するには、このメソッドを使用します。これはユーザープロファイルに自動的に保存されます。  リード獲得フォームやサインアップフォームで使用できます。  "value"：ユーザーの姓 |
| moengage.identifyUser("value") | Android, iOS | ワークスペースで設定された一意の識別子でユーザーを識別するには、このメソッドを使用します。  "value"：ユーザーの一意の識別子 |
| moengage.setUniqueId() | Android, iOS | ユーザーの Client ID を設定するには、このメソッドを使用します。ユーザーの Client ID を渡します。 |
| moengage.setAlias() | Android, iOS | ユーザーの既存の Client ID を更新するには、このメソッドを使用します。新しい Client ID を渡します。 |
| moengage.setGender() | Android, iOS | ユーザーの性別を設定するには、このメソッドを使用します。使用できる値は "male"、"female"、"other" です。 |
| moengage.setBirthDate() | Android, iOS | ユーザーの生年月日を設定するには、このメソッドを使用します。生年月日を ISO 8601 形式で渡します。 |
| moengage.setUserLocation(lat, lng) | Android, iOS | ユーザーの位置情報（lat,lng）を設定するには、このメソッドを使用します。  lat：ユーザーの緯度  lng：ユーザーの経度 |
| moengage.setUserAttribute(name,value) | Android, iOS | 属性のデータ型が文字列、数値、またはブール値の場合に、ユーザーのカスタム属性を設定するには、このメソッドを使用します。  name：トラッキングするユーザー属性の名前  value：トラッキングするユーザー属性の値 |
| moengage.setUserAttributeDate(name,value) | Android, iOS | 属性のデータ型が日付の場合に、ユーザーのカスタム属性を設定するには、このメソッドを使用します  name：トラッキングするユーザー属性の名前  value：ISO 8601 形式のトラッキングするユーザー属性の値 |
| moengage.setUserAttributeLocation(name,lat,lng) | Android, iOS | 属性のデータ型が位置情報の場合に、ユーザーのカスタム属性を設定するには、このメソッドを使用します  name：トラッキングするユーザー属性の名前  lat,lng：ユーザーの位置情報 |
| moengage.trackRating() | Android, iOS | 評価テンプレートからユーザーの評価を取得するには、このメソッドを使用します。ユーザーが送信した評価値を渡します。 |

後続のセクションでは、各 API の使用方法について詳しく説明します。提供されている JS メソッドは、アクション用の JS メソッドとデータトラッキング用の JS メソッドの 2 つのカテゴリに分類されます。

# In-App メッセージを閉じる

In-App メッセージを閉じるには、`moengage.dismissMessage()` API を使用します。

<CodeGroup>

```javascript JavaScript
moengage.dismissMessage();
```

</CodeGroup>

<Info>
  `moengage.dismissMessage()` API を使用している場合は、他の API を使用しないでください。
</Info>

# ナビゲーションアクション

## 画面への遷移

`moengage.navigateToScreen(<screen-name>, <optional-data-json>)` を使用して画面を開くことができます。

<CodeGroup>

```javascript JavaScript
var screenName = "com.moengage.sampleapp.ui.activity.MainActivity";
// Optionally add data json object
var attributes = {
  "nav_screen_attr1": "val1",
  "nav_screen_attr2": 100,
  "nav_screen_attr3": 123.11,
  "nav_screen_attr4": true
};
    
moengage.navigateToScreen(value, attributes);
```

</CodeGroup>

## ディープリンク URL を開く

ディープリンク URL を開くには、`moengage.openDeepLink(<deeplink-url>, <optional-data-json>)` を使用します。

<CodeGroup>

```javascript JavaScript
var value = "moengage://testdeeplink/testActivity";
// Optionally add data json object
var attributes = {
  "nav_screen_attr1": "val1",
  "nav_screen_attr2": 100,
  "nav_screen_attr3": 123.11,
  "nav_screen_attr4": true
};
moengage.openDeepLink(value, attributes);
```

</CodeGroup>

## Richlanding 画面を開く

Richlanding 画面を開くには、`moengage.openRichLanding(<richlanding-url>, <data-json>)` を使用します。

<CodeGroup>

```javascript JavaScript
var value = "https://www.google.com";
// Optionally add data json object
var attributes = {
  "nav_screen_attr1": "val1",
  "nav_screen_attr2": 100,
  "nav_screen_attr3": 123.11,
  "nav_screen_attr4": true
};
moengage.openRichLanding(value, attributes);
```

</CodeGroup>

## Web URL を開く

Web ブラウザで URL を開くには、`moengage.openWebURL(<web-url>, <optional-data-json>)` を使用します。

<CodeGroup>

```javascript JavaScript
var value = "https://www.google.com";
// Optionally add data json object
var attributes = {
  "nav_screen_attr1": "val1",
  "nav_screen_attr2": 100,

```

</CodeGroup>

# プッシュ通知の許可

これらのメソッドを使用して、ユーザーにプッシュ通知を有効にするよう促したり、すでに通知を無効にしているユーザーを通知設定画面に誘導したりします。

## 通知の許可をリクエストする

通知の許可をリクエストするには、`moengage.requestNotificationPermission()` API を使用します。このメソッドは Android と iOS の両方で動作するため、両方のプラットフォームに配信する 1 つのテンプレートで使用できます。

<CodeGroup>

```javascript JavaScript
moengage.requestNotificationPermission();
```

</CodeGroup>

Android では、許可をまだリクエストできる間は、システムの許可ダイアログが表示されます。ユーザーが許可を 2 回拒否すると、Android はダイアログを表示しなくなり、代わりにユーザーは設定画面に遷移します。

## 通知設定に遷移する

許可を先にリクエストせずに、ユーザーをアプリの通知設定画面に直接遷移させるには、`moengage.navigateToNotificationSettings()` API を使用します。このメソッドは Android と iOS の両方で動作します。

これは、アプリのプッシュがすでに無効になっていて、許可のプロンプトが表示されない場合に使用します。たとえば、通知がオフになっていることをユーザーに伝え、再度オンにするための CTA を表示するアプリ内メッセージなどです。

<CodeGroup>

```javascript JavaScript
moengage.navigateToNotificationSettings();
```

</CodeGroup>

<Note>
  アプリ内メッセージではなくアプリのコードから通知の許可を処理するには、[通知のランタイム権限](/ja/developer-guide/android-sdk/push/basic/notification-runtime-permissions) を参照してください。
</Note>

## プッシュのオプトインプロンプトを表示する

iOS で通知の許可を求めるには、`moengage.showPushOptIn()` API を使用します。現在の通知ステータスに基づいて、SDK は通知許可のプロンプトを表示するか、通知ステータスを更新できる設定画面にユーザーを遷移させます。

<CodeGroup>

```javascript JavaScript
moengage.showPushOptIn();
```

</CodeGroup>

<Warning>
  `moengage.showPushOptIn()` は iOS でのみ実装されています。テンプレートを Android にも配信する場合は、代わりに両方のプラットフォームで動作する `moengage.requestNotificationPermission()` を使用してください。
</Warning>

# デバイスの設定に遷移する

デバイスの設定画面を開くには、`moengage.navigateToSettings()` API を使用します。

<CodeGroup>

```javascript JavaScript
moengage.navigateToSettings();
```

</CodeGroup>

<Warning>
  `moengage.navigateToSettings()` は iOS でのみ実装されています。Android では、このメソッドはブリッジ上に存在しますが何も行わないため、このメソッドを呼び出す CTA は Android ユーザーには反応しないように見えます。Android ユーザーを通知設定に誘導するには、代わりに `moengage.navigateToNotificationSettings()` を使用してください。
</Warning>

# データトラッキング

以下のセクションでは、データトラッキング用の JS メソッドについて詳しく説明します。

<Info>
  **データトラッキング用の JS メソッド**

  以下のユースケースでは、データトラッキング用の JS メソッドをテンプレートに統合する必要があります。

  - 統計のトラッキング（クリック、閉じる）
  - イベントのトラッキング（アンケート、評価、リード獲得向け）
  - ユーザー属性のトラッキング（リード獲得、サインアップなど向け）
</Info>

## イベントのトラッキング

イベントをトラッキングするには、`moengage.trackEvent(eventName, generalAttrJson, locationAttrJson, dateAttrJson, isNonInteractive, shouldAttachCampaignMeta)` API を使用します。

trackEvent() は最大 6 つのパラメータを受け取ります。

- eventName：String
- generalAttrJson：一般属性の JSON オブジェクト。使用可能なデータ型は string、float、boolean、int、JSON オブジェクトです。

<CodeGroup>

```javascript JavaScript
{
  " <attribute_name >": " <attribute_value >",
  " <attribute_name >": " <attribute_value >",
  ...  
}
```

</CodeGroup>

- locationAttrJson：位置情報属性の JSON オブジェクト。属性名と緯度・経度を受け取ります

<CodeGroup>

```javascript JavaScript
{
  " <attribute_name >": {
    "latitude":  <latitude >,
    "longitude":  <longitude >
  },
  " <attribute_name >": {
    "latitude":  <latitude >,
    "longitude":  <longitude >
  },
  ...
}
```

</CodeGroup>

- dateAttrJson：日時属性の JSON オブジェクト。ISO-8601 形式の日付のみを受け付けます

<CodeGroup>

```javascript JavaScript
{
  " <attribute_name >": "yyyy-MM-dd'T'HH:mm:ss.fff'Z'",
  " <attribute_name >": "yyyy-MM-dd'T'HH:mm:ss.fff'Z'",
  ...
}
```

</CodeGroup>

- isNonInteractive：イベントを非インタラクティブにする場合は true、それ以外の場合は false。
- shouldAttachCampaignMeta：キャンペーンのメタデータをイベントに添付する場合は true、それ以外の場合は false。

<Info>
  `eventName` パラメータ以外のパラメータは必須ではなく、`{}` を渡すことができます。\
  パラメータを渡す順序を維持することが重要です。つまり、位置情報属性のみを渡したい場合は、一般属性として `{}` を渡す必要があります。

  一般的なケースでは、イベント名とイベント属性の JSON のみを渡し、その他のパラメータは省略できます。
</Info>

次の例は、6 つのパラメータすべてを順番に指定する方法と、省略する属性タイプに `{}` を渡す方法を示しています。

<CodeGroup>

```javascript JavaScript
// All six parameters
moengage.trackEvent(
  "Order_Placed",
  {
    "product_name": "Running Shoes",
    "quantity": 2,
    "amount": 4599.00,
    "is_gift": false
  },
  {
    "store_location": {
      "latitude": 12.9716,
      "longitude": 77.5946
    }
  },
  {
    "delivery_date": "2026-09-15T10:30:00.000Z"
  },
  false,
  true
);

// Event name and general attributes only
moengage.trackEvent("Response_Submitted", {
  "response1": "johndoe@gmail.com",
  "response2": "approved"
});

// Location attributes only - pass {} for the general attributes you skip
moengage.trackEvent("Store_Located", {}, {
  "store_location": {
    "latitude": 12.9716,
    "longitude": 77.5946
  }
});
```

</CodeGroup>

## クリックイベントのトラッキング

ウィジェットのクリックイベントをトラッキングするには、`moengage.trackClick(widgetId)` API を使用します。`<widgetId>` は int または string である必要があり、それ以外の場合、クリックイベントはトラッキングされません。

<CodeGroup>

```javascript JavaScript
//track click event
moengage.trackClick("image_1");
moengage.trackClick(10);
```

</CodeGroup>

## 閉じる操作のトラッキング

In-App を閉じるイベントをトラッキングするには、`moengage.trackDismiss(widgetId)` API を使用します。`<widgetId>` は int または string を指定できます。渡されない場合、イベントは `<widgetId>` なしでトラッキングされます。

<CodeGroup>

```javascript JavaScript
moengage.trackDismiss("dismiss_btn_1");
moengage.trackDismiss(1);
```

</CodeGroup>

<Accordion title="非推奨: ウィジェット ID を指定しない trackDismiss()">
  引数なしで `moengage.trackDismiss()` を呼び出す方法は非推奨です。閉じる操作は引き続きトラッキングされますが、`<widgetId>` がないとクリック分布テーブルにデータが入力されません。代わりに、上記のように `<widgetId>` を渡してください。

  <CodeGroup>

  ```javascript JavaScript
  moengage.trackDismiss();
  ```

  </CodeGroup>
</Accordion>

## ユーザーの識別

ワークスペースで設定された一意の識別子でユーザーを識別するには、`moengage.identifyUser(<value>)` API を使用します。リード獲得、サインアップ、ログインのテンプレートからこのメソッドを使用して、セッションを既知のユーザーに関連付けます。

<CodeGroup>

```javascript JavaScript
moengage.identifyUser("unique-id");
```

</CodeGroup>

<Note>
  このメソッドを呼び出す前に、MoEngage で識別子を設定してください。識別子が 1 つのユーザープロファイルに解決される仕組みの詳細については、[Unified Identity と Identity Resolution](/ja/user-guide/data/user-data/unified-identity-identity-resolution) を参照してください。
</Note>

## デフォルトユーザー属性のトラッキング

デフォルトのユーザー属性をトラッキングするために、以下の JavaScript メソッドを使用できます。

| API 名 | API の説明 |
| ---------------------------- | ---------------------------------------------------------------------------- |
| moengage.identifyUser() | ワークスペースで設定された一意の識別子でユーザーを識別します |
| moengage.setAlias() | 以前に `moengage.setUniqueId()` で設定されたユーザーの一意の ID を更新します |
| moengage.setUniqueId() | ユーザーの UniqueId を設定します |
| moengage.setUserName() | ユーザー名を設定します |
| moengage.setFirstName() | ユーザーの名を設定します |
| moengage.setLastName() | ユーザーの姓を設定します |
| moengage.setEmailId() | ユーザーのメール ID を設定します |
| moengage.setMobileNumber() | ユーザーの携帯電話番号を設定します |
| moengage.setGender() | ユーザーの性別を設定します（"male"/"female"/"other"） |
| moengage.setBirthDate() | ユーザーの誕生日を設定します。値は ISO-8601 形式の日付である必要があります。 |
| moengage.setUserLocation() | ユーザーの位置情報を設定します |
| moengage.trackRating() | ユーザー入力アクションの評価をトラッキングします |

例：

<CodeGroup>

```javascript JavaScript
// Identify the user
moengage.identifyUser("unique-id");
// Set the Client ID
moengage.setUniqueId("unique-id");
// Update a Client ID that was set earlier
moengage.setAlias("new-unique-id");
// Set the user's name
moengage.setUserName("Jane Doe");
moengage.setFirstName("Jane");
moengage.setLastName("Doe");
// Set the user's contact details
moengage.setEmailId("jane.doe@example.com");
moengage.setMobileNumber("1234567890");
// Set the gender - accepted values are "male", "female", and "other"
moengage.setGender("female");
// Set the date of birth in ISO-8601 format
moengage.setBirthDate("2017-08-02T06:05:30.000Z");
// Set the user's location as latitude, longitude
moengage.setUserLocation(12.9716, 77.5946);
// Track a rating submitted from a rating template
moengage.trackRating(4.5);
```

</CodeGroup>

## カスタムユーザー属性のトラッキング

カスタムユーザー属性をトラッキングするために、以下の JavaScript メソッドを使用できます。

| API 名 | API の説明 |
| --------------------------------------- | ------------------------- |
| moengage.setUserAttribute() | カスタムユーザー属性を設定します |
| moengage.setUserAttributeDate() | カスタムユーザー日付を設定します |
| moengage.setUserAttributeLocation() | カスタムユーザー位置情報を設定します |

例：

<CodeGroup>

```javascript JavaScript
// Set string, numeric, and boolean attributes
moengage.setUserAttribute("loyalty_tier", "gold");
moengage.setUserAttribute("orders_placed", 12);
moengage.setUserAttribute("wallet_balance", 250.75);
moengage.setUserAttribute("newsletter_opted_in", true);

// Set a date attribute in ISO-8601 format
moengage.setUserAttributeDate("last_purchase_date", "2017-08-02T06:05:30.000Z");

// Set a location attribute as latitude, longitude
moengage.setUserAttributeLocation("preferred_store", 12.9716, 77.5946);
```

</CodeGroup>

---
title: "JavaScript Bridge"
description: "MoEngage JavaScript Bridge を使用して、HTML In-App メッセージ、On-Site Messaging キャンペーン、ランディングページから SDK とやり取りします。"
keywords: ["JavaScript bridge", "HTML in-app", "on-site messaging", "landing pages", "track event from HTML"]
---

JavaScript Bridge を使用すると、MoEngage が表示する HTML コンテンツから SDK を呼び出せるため、テンプレートでイベントのトラッキング、クリックの処理、テンプレート自体を閉じる操作を行えます。使用するブリッジは、HTML が実行される場所によって異なります。

| [On-Site Messaging およびランディングページ向け JavaScript Bridge](/ja/developer-guide/components-for-sdk/javascript-bridge/javascript-bridge-for-on-site-messaging-and-landing-pages) | On-Site Messaging キャンペーンやランディングページから、イベント、クリック、閉じる操作、フォーム送信をトラッキングします。 |

これらのコンポーネントは、各プラットフォームの SDK と併せて使用します。複数のプラットフォームにまたがって適用されるため、各 SDK ガイドで繰り返し説明するのではなく、ここにまとめて記載しています。

| ページ | 内容 |
| --- | --- |
| [リアルタイムのアンインストールトラッキング](/ja/developer-guide/components-for-sdk/tracking/real-time-uninstall-tracking) | 毎日のサイレントプッシュの代わりに Firebase Cloud Functions を使用して、アプリのアンインストールをリアルタイムでトラッキングします。 |
| [JavaScript Bridge](/ja/developer-guide/components-for-sdk/javascript-bridge/overview) | HTML In-App メッセージ、On-Site Messaging、ランディングページから SDK とやり取りします。 |
| [プッシュ通知](/ja/developer-guide/components-for-sdk/push-notification/android-push-configuration-for-hybrid-applications) | ハイブリッドアプリケーション向けの Android プッシュ設定。 |

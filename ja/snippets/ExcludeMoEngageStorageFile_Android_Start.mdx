Android の自動バックアップサービスは、Shared Preference ファイルやデータベースファイルなどを定期的にバックアップします。

詳細については、[Auto Backup](https://developer.android.com/guide/topics/data/autobackup) を参照してください。

このバックアップにより、MoEngage SDK の識別子がバックアップされ、再インストール後に復元されます。識別子が復元されると、データが破損し、プッシュ通知でユーザーにリーチできなくなります。

バックアップが復元された後にデータが破損しないようにするには、MoEngage SDK のストレージファイルをバックアップ対象から除外してください。

# Manifest ファイルの _application_ タグにバックアップ記述子を追加します。

バックアップ記述子は、_application_ タグの _fullBackupContent_ 属性に割り当てる必要があります。

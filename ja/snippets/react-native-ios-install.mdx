
  <Tab title="Swift Package Manager (SPM)">
    <Warning>
      SPM のサポートは試験的なもので、React Native 0.87 以降が必要です。サポートされているパッケージ、セットアップの詳細、制限事項については、[iOS インストール](/ja/developer-guide/react-native-sdk/sdk-integration/react-native/sdk-installation/ios)を参照してください。
    </Warning>

    1. `ios` ディレクトリに移動します。
    2. SPM をセットアップします。

       - iOS プロジェクトでまだ CocoaPods を使用している場合は、`npx react-native spm add --deintegrate` を使用して一度だけ変換します。詳細については、[CocoaPods から SPM への移行](/ja/developer-guide/react-native-sdk/migration/migration-of-moengage-sdk-from-cocoapods-to-spm)を参照してください。
       - iOS プロジェクトですでに SPM を使用している場合は、次のコマンドを実行します。

         ```bash Bash
         npx react-native spm
         ```

    SPM を使用すると、`pod install` を実行する必要はなくなります。MoEngage のネイティブ SDK は、それぞれの SPM リポジトリから自動的に解決されます。
  </Tab>
</Tabs>

MoEngage {props.sdk} SDK にはネイティブの MoEngage Android SDK がバンドルされているため、Android ビルドにはデバイス上での SDK デバッグをサポートするコンポーネントである `MoEDebuggerActivity` が含まれます。その機能については、[What is MoEDebuggerActivity?](/ja/developer-guide/android-sdk/troubleshooting-and-faqs/troubleshooting-and-faqs) を参照してください。

{props.sdk} アプリからこれを削除するには、Android プロジェクトの `AndroidManifest.xml` に次の内容を追加します。

```xml
       <activity
                android:name="com.moengage.sdk.debugger.MoEDebuggerActivity"
                tools:node="remove" />

```

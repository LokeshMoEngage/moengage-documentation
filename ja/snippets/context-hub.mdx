Context Hub は、MoEngage における Organization Context の保存場所です。Organization Context とは、一度登録すれば MoEngage のワークフロー全体で再利用できる、ブランド、ビジネス、コミュニケーションに関する情報（ブランドガイドライン、コミュニケーションおよび規制に関するガイドライン、チャネルの詳細、ビジネス固有のコンテキスト）のことです。

Context Hub は **Settings > Account > Context Hub** にあります。

## はじめに

初めて Context Hub を開く前に、Merlin AI がバックグラウンドでブランドとビジネスのコンテキストを抽出するため、通常はアクセスした時点で結果が準備され保存されています。抽出が完了すると、メールが届きます。

<Frame>
  ![Get started ボタンが表示された Context Hub の初回画面](/images/context-hub-get-started.png)
</Frame>

<Steps>
  <Step title="Context Hub を開いて Get started を選択する">
    **Settings > Account > Context Hub** に移動し、**Get started** を選択します。ほとんどの場合、Merlin AI によってすでにコンテキストが抽出されています。
  </Step>
  <Step title="AI Inferred context パネルを確認する">
    抽出結果は、ページ上部の **AI Inferred context** パネルに表示されます。[AI が推論したコンテキストを確認して追加する](#review-and-add-ai-inferred-context)を参照してください。
  </Step>
</Steps>

## Merlin AI によるコンテキストの抽出方法

Merlin AI は、ブランドとビジネスに関する情報を自動的に提示し、確認して Context Hub に追加できるようにします。

### 情報の抽出方法

- 過去のキャンペーンアクティビティとプラットフォームの利用状況から抽出します。
- Merlin AI が過去のキャンペーンデータからブランドのウェブサイトを特定できた場合は、ウェブ検索も実行してブランド情報を収集します。

### 抽出される内容

Merlin AI は、抽出したコンテキストをカテゴリに整理し、各カテゴリに特定のエンティティを格納します。

- **Visual system** — ロゴ、カラー、フォント、タイポグラフィ、ボタン、ハイパーリンク、ビジュアルスタイルガイドライン、画像のルール、アイコン、アクセシビリティのルール。
- **Identity** — ブランドストーリー、承認済みのタグライン。
- **Brand voice and tone** — トーン・オブ・ボイス、ブランドボイスのルール、禁止語、ブランドボイスの例文。
- **Formatting** — 命名規則、句読点と数値の書式。
- **Others** — 規制上の免責事項、チャネルごとのブランド適応。

### 実行タイミング

- Merlin AI は、手動でトリガーしなくてもバックグラウンドで自動的に実行されます。
- 実行は一定の間隔で行われます。1 週間後、または 50 件のキャンペーンが公開された後のいずれか早い方です。

### 追加した項目と追加しなかった項目の扱い

- デフォルトでは何も選択されていません。追加するカテゴリはユーザーが選択します。
- カテゴリを選択しなかった場合でも、恒久的に却下されたわけではありません。Merlin AI はそれを「現時点では関心がない」とみなし、以降の実行のたびにその内容を再度提示します。
- すでに追加したカテゴリについて、以降の実行でそのエンティティに関する新しい情報が見つからなかった場合、そのカテゴリは結果に表示されなくなります。

## ページ構成

Context Hub に情報が登録されると、ページ上部に **Last Updated** のタイムスタンプが表示されます。

コンテンツは **Brand** タブの下に配置され、左側にページ内ナビゲーションリスト（**Visual system**、**Identity**、**Brand voice and tone**、**Formatting**、**Others**）が表示されます。各セクションには関連するエントリがまとめられています。たとえば、Visual system には Logos と Colours が含まれます。まだエントリがないセクションには "No context added." と表示されます。

## AI が推論したコンテキストを確認して追加する

Merlin AI による情報の抽出が完了すると、ページ上部に "Context inferred from past campaign activity and platform usage." というラベルの付いた **AI Inferred context** パネルが表示されます。

<Frame>
  ![抽出されたカテゴリと + Add to context hub ボタンが表示された AI Inferred context パネル](/images/context-hub-ai-inferred-context.png)
</Frame>

<Steps>
  <Step title="カテゴリを確認する">
    一覧表示されたカテゴリ（**Visual system**、**Brand voice and tone**、**Identity**、**Formatting** など）を確認します。各カテゴリには抽出された内容の簡単な説明が表示され、展開すると含まれている個々の項目を確認できます。
  </Step>
  <Step title="追加する項目を選択する">
    カテゴリの横にあるチェックボックスを選択するとカテゴリ内のすべてが追加されます。また、カテゴリを展開して個々の項目を選択することもできます。デフォルトでは何も選択されておらず、少なくとも 1 つの項目を選択するまで **+ Add to context hub** は無効のままです。
  </Step>
  <Step title="選択した項目を追加する">
    **+ Add to context hub** をクリックして選択内容を確定します。
  </Step>
</Steps>

<Info>
  選択しなかったカテゴリは引き続き利用可能です。いつでも戻って追加できます。選択しなかったカテゴリの内容は、以降の抽出後に更新される場合があります。
</Info>

## Merlin AI を使用してコンテキストを追加する

Merlin AI とチャットすることで、必要に応じてコンテキストを追加することもできます。情報はテキスト、ファイル、またはウェブサイトとして共有します。Merlin AI は関連するコンテキストを抽出して確認用に表示し、承認した内容を追加します。

### チャットエージェントへのアクセス

<Steps>
  <Step title="Context Hub を開く">
    **Settings > Account > Context Hub** に移動します。
  </Step>
  <Step title="Add context ドロワーを開く">
    Context Hub ページで、**Add context** ドロワーを開きます。
  </Step>
</Steps>

<Frame>
  ![Visual system、Formatting、Brand voice and tone、Identity のスタートトピックカードと、下部にチャット入力欄がある Add context ドロワー](/images/context-hub-merlin-ai-add-context.png)
</Frame>

事前定義されたオプションのいずれかを選択して開始するか、独自のプロンプトを入力してコンテキストの抽出を開始します。

### ソースを提供する

Merlin AI に抽出元となる情報を提供します。チャット下部にある "Paste, type or attach context here or ask a question." というラベルの入力ボックスを使用します。次のことができます。

- **テキストを入力または貼り付ける**（コピーライター向けの注意事項リストなど）。
- **ドキュメントを添付する**（ブランドガイドラインの PDF など）。ファイルを添付するには **+** ボタンを選択します。
- **ウェブサイトを共有する。** ブランドのウェブサイトなどの URL を貼り付けます。
- **Merlin AI にウェブ検索を依頼する**（ブランドに関する情報など）。

1 つのメッセージで複数のソースを組み合わせることができます。たとえば、同じリクエスト内でドキュメントを添付し、ウェブサイトの URL を含めることができます。

<Info>
  Context Hub にすでに登録されている内容について Merlin AI に質問することもできます。Merlin AI は保存されたコンテキストを使用して回答し、何も追加しません。
</Info>

### 抽出された情報を確認する

リクエストを送信すると、抽出されたコンテキストが右側の **Extracted information** パネルにカテゴリ別に表示されます。パネルには、情報が最後に抽出された日時が表示されます。

Merlin AI は、抽出した内容とすでに保存されている内容を比較し、結果を 2 つのタブに分けます。

- **New additions** — Context Hub に新たに追加されるコンテキスト。
- **Updates** — Context Hub にすでに保存されている値を変更するコンテキスト。

<Frame>
  ![抽出されたコンテキストのチェックボックスツリーとともに New additions タブと Updates タブが表示された Extracted information パネル](/images/context-hub-merlin-ai-extracted-information.png)
</Frame>

各結果はチェックボックスツリーになっています。カテゴリを展開すると、そのエントリと、Merlin AI が各エントリについて見つけた個々の詳細を確認できます。カテゴリ、エントリ、または個々の詳細の横にあるチェックボックスを選択して、追加する内容を選びます。チェックボックスをオフにすると、その項目は除外されます。

<Note>
  Context Hub に追加されるのは、選択した項目のみです。抽出された項目を確認し、必要なものだけを選択してください。**Add to context hub** を選択するまで、Context Hub には何も保存されません。
</Note>

### Context Hub に追加する

選択内容を確認したら、**Add to context hub** を選択します。選択した新規追加項目と更新項目が Context Hub に保存されます。

選択しなかった項目は追加されません。

<Note>
  セッション中に抽出されたものの Context Hub に追加されなかったコンテキストは、ログインしている間のみ利用できます。ログアウトした場合は、再度 Merlin AI とチャットしてソースから情報を抽出する必要があります。
</Note>

### 会話履歴

Merlin AI は会話履歴を 30 日間保持します。

  </Step>
  <Step title="エントリを展開する">
    エントリをクリックして展開します。エントリが編集可能な状態で開きます。
  </Step>
  <Step title="変更を加える">
    展開したエントリで内容を直接編集します。変更は自動的に保存されます。
  </Step>

![フォント名、フォールバックフォント、Add font オプションが表示された Visual system の Fonts エントリ](/images/context-hub-fonts.png)

  一部のエントリには独自のフィールドがあります。たとえば、Visual system の Fonts エントリでは、フォールバックフォントの設定やフォントの追加ができます。追加したデフォルトフォントは、フォントの追加後に公開されたキャンペーンに適用されます。以前に公開されたキャンペーンは、作成時のフォントがそのまま維持されます。
</Note>

## コンテキストをクリアまたは削除する

Context Hub には標準の情報セットが含まれており、独自のカスタム情報を追加することもできます。各エントリには、クリアまたは削除のオプションがある三点メニューがあります。

エントリをクリアするには:

<Steps>
  <Step title="エントリを見つける">
    クリアするエントリを探します。
  </Step>
  <Step title="エントリのメニューを開く">
    そのエントリの三点メニューをクリックします。
  </Step>
  <Step title="内容をクリアする">
    **Clear content** を選択します。
  </Step>
</Steps>

<Warning>
  内容のクリアは即座に実行されます。確認ステップはなく、クリアした内容は復元できません。クリアするとエントリの値は削除されますが、エントリ自体は残ります。
</Warning>

**エントリの削除**

三点メニューには、エントリ名が付いた削除オプション（例: **Delete Logos**）もあります。削除できるのは、自分で追加したカスタム情報のみです。Context Hub に含まれる標準情報の場合、このオプションは無効になっています。削除すると、エントリ全体が削除されます。

<Frame>
  ![Clear content と無効化された Delete オプションが表示されたエントリの三点メニュー](/images/context-hub-clear-delete-menu.png)
</Frame>

## 適用範囲

適用範囲（Applicability）は、Context Hub のすべてのエンティティの上位にあるレイヤーです。これにより、そのエンティティが下流の MoEngage ネイティブの機能でどのように使用されるかが決まります。下流での使用には 2 種類あります。

- **Manual usage** — エンティティが直接適用される特定のチャネル: Email、In-app、OSM、Landing pages。
- **Merlin AI usage** — エンティティを利用する可能性のある MoEngage の AI 機能（Custom agents、Flows assist、Email agent、In-app agents、Segment assist など）。

各エンティティには、**Merlin AI only** または **Manual + Merlin AI** のいずれかの状態を示す使用状況インジケーターが表示されます。

### 適用範囲マトリクス

適用範囲マトリクスでは、各エンティティがサブカテゴリ別に一覧表示され、手動チャネルと Merlin AI 機能のどこに適用されるかが示されます。マトリクスを開くには、次のいずれかの方法を使用します。

- ページ上部のヘルプリンク "Click here to learn more about how information in Context Hub is used within MoEngage." の **here** を選択します。
- エントリのグリッド（ドット）アイコンにカーソルを合わせて使用状況のポップオーバーを開き、**View usage for all data points** を選択します。

<Frame>
  ![here ヘルプリンクと View usage for all data points オプションが表示されたエントリの使用状況ポップオーバー](/images/context-hub-usage-popover.png)
</Frame>

マトリクスでは、検索ボックス、**All / Manual usage / Merlin AI usage** フィルター、またはサブカテゴリセレクターを使用して一覧を絞り込めます。

<Frame>
  ![手動チャネルと Merlin AI エージェントにわたってマッピングされたコンテキスト項目を示す適用範囲マトリクス](/images/context-hub-applicability-matrix.png)
</Frame>

マトリクスでは次の列が使用されます。

- **Sub-category** — エンティティが属するカテゴリ（Identity や Visual system など）。
- **Information** — そのサブカテゴリ内の特定のエンティティ（Brand story、Approved taglines、Logos、Colours、Typography、Buttons、Hyperlinks、Fonts など）。

残りの列は、前述の **Manual usage** チャネルと **Merlin AI usage** 機能です。緑のチェックマークはそのチャネルまたは機能でエンティティが使用されることを示し、ダッシュは使用されないことを示します。

すべての Brand エンティティは、すべての Merlin AI 機能（Custom agents、Flows assist、Email agent、In-app agents、Segment assist）で利用できます。手動チャネルはエンティティによって異なります。

| Fonts | Email, In-app, OSM, Landing pages |
| Colours | Email, In-app, OSM, Landing pages |
| Logos | In-app のみ |
| Typography | Email, In-app |
| Buttons | Email, In-app |
| Hyperlinks | Email, In-app |
| Visual style guidelines | なし |
| Imagery rules | なし |
| Iconography | なし |
| Accessibility rules | なし |
| Brand story | なし |
| Approved taglines | なし |
| Tone of voice | なし |
| Brand voice rules | なし |
| Prohibited words | なし |
| Regulatory disclaimers | なし |
| Channel brand adaptations | なし |
| Brand voice exemplars | なし |
| Naming conventions | なし |
| Punctuation & number formatting | なし |

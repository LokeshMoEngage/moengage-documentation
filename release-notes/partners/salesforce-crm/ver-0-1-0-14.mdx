This release improves the graceful handling of scenarios where External Users do not have access to Package License Check,
adds history tracking on the Sync object & fixes the trigger deployment status check.

**Package Link:** Click [here](https://login.salesforce.com/packaging/installPackage.apexp?p0=04tOS00000MJhMLYA1)

## What's New?

### Process improvements

#### External Users lacks access to PackageLicense

- PackageLicense check is now done in running query under <code>SYSTEM MODE</code> bypassing the restriction on external users.

#### Trigger Deployment Status Check Fail

- Due to recent changes into Metadata API response pertaining to <code>locationsCovered</code> addition, code now checks trigger deployment status check without fail.

#### Enabling History Tracking on Sync Object

- Enabled history tracking on Sync object.
- Fields enabled for tracking are - Status, Salesforce Object & MoEngage Object

<b>Update instructions for existing customers:</b> Page layout changes do not auto-apply for package upgrades. You must manually update the "Sync Layout" to reflect these updates.

##### Enable History Tracking on Sync Object

For enabling History tracking, follow steps as below:

1. Go to Setup, Go to Object Manager.
2. Search and Click on Sync object.
3. Go to Detail section and click on "Edit".
4. Scroll, Check the "Track Field History" checkbox.
5. Go **"Fields & Relationships"** Click on **"Set History Tracking"** and select following fields:
    a. Select Status
    b. Salesforce Object
    c. MoEngage Object
6. Click Save.
7. Go to Page Layout, Click on 'Sync Layout', Drag 'Sync History' from Related Lists & add after 'Sync Queues', then Save Layout.

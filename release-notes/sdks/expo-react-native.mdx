<Note>
This release wraps the MoEngage React Native plugins [13.0.0](/release-notes/sdks/react-native#1st-october-2026), which update to MoEngage SDK BOM 4.4.0 on Android and MoEngage-iOS-SDK 11.2.0 on iOS.
</Note>

#### Expo 2.0.0
<span style={{ backgroundColor: 'rgba(212, 56, 13, 0.1)', color: '#D4380D', border: '1px solid #FFCCC7', padding: '2px 10px', borderRadius: '12px', fontSize: '0.85em', fontWeight: 'bold' }}>Breaking Changes</span>

* **Expo SDK 58.0.0 or later is required.** The Android build toolchain moves to AGP 9.1.1, Gradle 9.3.1, Kotlin 2.3.20, and compile SDK 36. Earlier Expo SDK versions don't support AGP 9.
* **Android: push registration now uses the Firebase Installation ID instead of the FCM token.** If you use MoEngage to register for push, move `com.google.firebase:firebase-messaging` to 25.1.2 or above and complete the Firebase Installation ID integration before upgrading. For more information, refer to [Migrating to Firebase Installation ID](/developer-guide/android-sdk/migration/migrating-to-firebase-installation-id).
* **Android: `passFcmPushToken()` is deprecated.** It continues to work. MoEngage recommends moving to `passFirebaseInstallationId()`.
* **Android: the `pushTokenGenerated` event is deprecated.** It continues to work. MoEngage recommends moving to `firebaseInstallationIdAvailable`, which delivers a `MoEFirebaseInstallationIdResult` instead of a `MoEPushToken`.
* **Removed support for the React Native old architecture.** The plugin now supports only the New Architecture.

<span style={{ backgroundColor: 'rgba(0, 135, 103, 0.1)', color: '#008767', border: '1px solid #B5F5EC', padding: '2px 10px', borderRadius: '12px', fontSize: '0.85em', fontWeight: 'bold' }}>What's New</span>

* Updated to the MoEngage React Native plugins [13.0.0](/release-notes/sdks/react-native#1st-october-2026). Swift Package Manager is not supported for Expo applications, which continue to use the MoEngage Expo config plugin with no change.

</Update>

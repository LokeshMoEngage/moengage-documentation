# Introduction

Equence is an enterprise mobility solutions provider that offers SMS, Voice, WhatsApp, and RCS messaging to enterprises across India. MoEngage integrates natively with Equence for RCS, which allows you to send RCS messages to your users through one or more Equence senders.

<Tip>
  **Prerequisites**

  Ensure you have access to your Equence account and have the authorization token for the account under which your RCS agent is registered. For help with your credentials, contact your Equence account manager or Equence support.
</Tip>

# Configure Equence as an RCS Connector (Service Provider)

Perform the following steps to configure Equence as a connector:

1. On the left navigation menu in the MoEngage UI, go to **Settings** \> **Channels** \> **SMS & RCS** \> **Sender configuration**.
2. On the **RCS** tab, click **\+ Add RCS Sender**.
3. Click the **Equence** tile.
   ![Select Equence as the RCS service provider](/images/configure-equence-rcs-select-provider.png)
4. On the **Sender Details** page, add the following details:
   ![Equence RCS Sender Details page](/images/configure-equence-rcs-sender-details.png)

| Field | Description |
| --- | --- |
| **Sender type** | Select the sender type. The available options are: <ul><li>**Transactional**: Select this option when you are using the sender to send alerts about transactions, security information, or any information that can be classified as transactional in nature.</li><li>**Promotional**: Select this option when you are using the sender to send information about your brand, promote deals, or engage with users.</li><li>**OTP**: Select this option when you are using the sender to send OTPs.</li></ul> |
| **Sender Name** | Enter the name of the sender. This field identifies the readable sender name that can be used while creating a campaign or alert. |
| **Sender ID** | Enter the sender ID. This is the RCS agent or bot ID that RCS Business Messaging (RBM) uses to send RCS messages to users. |
| **Authorization** | This is the bearer token used for authorization. You can get this token from your Equence account manager or Equence support. |

5. Copy the **Incoming Messages & Delivery callback URL** and paste it in your Equence portal to receive delivery acknowledgements.
6. Click **Save** to save this sender configuration.
